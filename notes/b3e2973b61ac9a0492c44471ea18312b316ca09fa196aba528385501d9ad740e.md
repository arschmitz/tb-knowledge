# Count unread-to-read changes at the database boundary

MarkHdrRead adds to Glean.mail.mailsRead only when the requested state differs from the stored state and the new state is read. Repeating mark-read on an already read message does not add another count; marking unread does not add one. A later unread-to-read transition can count again. This is a database state-change metric, not a unique-message lifetime count. The unit test initializes a profile and FOG, resets telemetry, marks five messages read and checks five. The MOZ_SUITE guard keeps this Thunderbird probe out of SeaMonkey. The test was inspected, not run.

Scope: Message database and telemetry.
