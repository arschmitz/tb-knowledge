# A cached message database must still have a live Mork store

The accepted nsMsgDBService code finds a cached DB by its .msf summary path only if m_mdbStore is present. FindInCache adds a reference before returning it. OpenFolderDB can attach a missing folder pointer (for a DB first opened from a file), update last-use time, and finish an asynchronous opening synchronously when m_thumb is set. For a newly opened nonvirtual folder, FinishDBOpen compares stored message count with the header table, syncs mismatches, attaches pending listeners, and remembers last use. This is observed code behavior in the cleanup, not a review-requested new contract; no focused test was added by this commit.

Scope: Message database lifecycle.
