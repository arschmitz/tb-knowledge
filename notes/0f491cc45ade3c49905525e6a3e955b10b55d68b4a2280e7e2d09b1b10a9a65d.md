# Release already-created MIME draft allocations on the new early return

937 adds delete[] newAttachData and PR_Free(body) before returning when NS_NewLocalFileInputStream fails. The historical body allocation uses PR_MALLOC and the attachment array has its own allocation family. Both were created before this new failure boundary. The accepted body-loading code now uses mime_draft_read_body_piece, so the exact historical branch is retired. Keep allocation family and owner lifetime in an early-return review; this is not proof that all MIME draft leaks are fixed.

Scope: Historical MIME draft early-return cleanup.
