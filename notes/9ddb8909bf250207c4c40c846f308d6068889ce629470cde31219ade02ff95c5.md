# UID-set formatting and its legacy wrapper have different empty-input contracts

The new UID formatter copies and sorts values, ignores duplicates, emits a pair as two values, and emits a longer consecutive run as a range. Its direct test includes empty input and exact output strings. The original AllocateUidStringFromKeys wrapper retains an empty-input error and assigns the returned text to its output. Inspected callers use fresh or truncated outputs, so those examples do not require append behavior; they do not prove every caller is equivalent. Later accepted source changes the input container signature and callers separately. Neither these formatting tests nor the wrapper implement or verify complete message-key/UID separation or protocol interoperability.

Scope: IMAP UID-set construction.
