# OpenPGP filter URL resolution uses the passed message header

getRequireMessageProcessing derives the URI from aMsgHdr.folder.getUriForMsg(aMsgHdr), then resolves it through the message service. It adds header=enigmailFilter using & when the URL already has a query, and returns the URL with requireBody. newMailListener.msgAdded passes the same header to the helper and processIncomingMail after checking that consumers exist. The wrapper-removal patch adopted the receiver correction in the exact landed code. This does not make malformed input impossible or establish a global rule to remove URL guards or try/catch. No new test or live filter/crypto execution was performed.

Scope: openpgp-filters.
