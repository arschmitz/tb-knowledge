# Commit an mbox message explicitly and preserve the rollback error

MboxMsgOutputStream is an nsISafeOutputStream. Finish commits the message; Close or destruction attempts rollback to the starting position. Current rollback flushes buffered data before Seek/SetEOF and keeps a rollback error when closing the inner stream also fails. Finish rolls back an earlier write error or final separator failure. Do not equate closing with successful commit. This is a current-source extension of the 374 ownership check; later Bug 1960252 is cited by the code but was not read externally. No storage-failure injection was run.

Scope: Mbox completion and failure contracts.
