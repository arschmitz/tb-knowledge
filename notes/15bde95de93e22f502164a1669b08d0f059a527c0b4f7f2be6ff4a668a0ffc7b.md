# Address-book navigation preserves UID selection across tab readiness

Local Account Hub creation resolves the new directory UID, closes the hub, navigates with cmd_displayAddressBook and resets after the helper returns. Current addressBookTab onLoad runs after its ready event and deferred initial selection for a new tab; a loaded reused tab can call back immediately. displayAddressBook queues an early UID until initial setup, otherwise selects that UID and focuses search. The load-ready event is one initialization boundary, not a per-command completion event. toAddressBook resolves the content window after command dispatch and does not await arbitrary command promises. The direct and integration tests assert the directory UID and searchInput focus; current integration registers ready observation before Enter and separately waits for selectedIndex. No browser or live accessibility test ran.

Scope: Account Hub address-book navigation and tab lifecycle.
