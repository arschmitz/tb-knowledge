# Notification description spacing belongs to the type that reserves the CTA area

Entry 1470 removes the fixed description bottom margin for blog, message and security notifications and leaves the reservation in the donation variant. The accepted stylesheet keeps the ordinary description margin at zero and the donation description/button rules separate. In this notification family, recommend attaching reserved action space to the layout variant that uses it instead of every description. Current donation placement has later refinements; this note is not a universal 60-pixel spacing rule. No rendered notification, clipping, zoom or text-reflow check was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Notification variant-specific action spacing.
