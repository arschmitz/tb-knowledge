# Calendar event dialogs find their anchor in the visible view

Event boxes expose data-event-id and optional data-recurrence-id. After loading an event, CalendarDialog selects the matching element below a visible child of #view-box and stores it as trigger. A recurrence native-time selector is added only after valid occurrence lookup. This supports context-menu opens without depending only on the opening event target. It establishes source inputs and selection; no rendered positioning or focus result was tested.

Scope: Thunderbird Calendar dialog anchor selection.
