# Calendar resize dispatch follows nonzero observed box dimensions

This landing observes the calendar view element inside once-guarded ensureInitialized and invokes onResize when the last observer entry has nonzero block and inline sizes. The month override skips an unchanged bounding rectangle before adjusting weekday labels; the multiday override requests both axes and passes its current scrollMinute. This replaces the inspected manual viewresize senders. The new size predicate is distinct from the separate font route's calendar-mode/current-view guard. No explicit disconnect is added, and no native observer lifecycle, layout timing, scroll preservation, accessibility or extension-event guarantee was tested.

Scope: Calendar view resizing.
