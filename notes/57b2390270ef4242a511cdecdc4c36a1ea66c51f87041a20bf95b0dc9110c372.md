# Removing the old Calendar cache repair does not remove the cache support gate

The cleanup removes two old repairs that deleted cache.enabled for calendars with cache.supported=false: the startup sweep and the observer's early-return branch. Home-calendar creation remains when no calendars exist. Fixed accepted source still checks cache.supported before wrapping a calendar in calCachedCalendar. Keep removal of obsolete stored-flag repair separate from support for caching; this source does not prove all old profiles were exercised.

Scope: Calendar cache migration cleanup.
