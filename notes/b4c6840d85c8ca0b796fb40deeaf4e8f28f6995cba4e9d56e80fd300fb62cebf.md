# After a folder move, reacquire the folder and assert the backend result

A folder move changes its URI and may change the object that should be looked up. The drag test waits for folderC.getChildNamed("folderB"), then checks the visible tree using the new URI. Proposed manual test rule: verify the model operation as well as the row change; use the moved identity rather than the old folder reference. The review also removed an invented dragend before the real drop.

Scope: browser-tests.
