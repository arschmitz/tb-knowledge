# The compose toolbox still has a concrete markup identity and completion hook

1881 deletes the unused getMailToolbox getter. Current compose startup looks up compose-toolbox directly and sets customizeDone to MailToolboxCustomizeDone with CustomizeComposeToolbar. The markup retains that dashed ID. Local naming guidance: keep this exact ID and customization callback coupled when editing the toolbox; it is an existing contract, not a rule for all new DOM IDs. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: compose toolbar integration.
