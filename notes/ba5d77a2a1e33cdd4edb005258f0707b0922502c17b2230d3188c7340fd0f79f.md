# Read each EWS response helper’s actual error policy

process_response_message_class accepts Success, logs and accepts Warning, and propagates Error. validate_response_message_count rejects unequal counts. single_response_or_error instead rejects zero and warns while returning the first item for multiple responses. These are distinct current policies. When reusing a helper, choose the one whose cardinality and warning behavior matches the operation, rather than describing all response validation as strict single-result rejection. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: EWS response helper policies.
