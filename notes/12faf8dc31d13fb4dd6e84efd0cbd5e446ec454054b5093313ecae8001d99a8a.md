# Distinguish optional docs config keys from disabling error checks

Accepted tb-doc only applies allowed_errors and fatal warnings checks when their keys exist and their disable flags are false. The current config explicitly supplies both and says not to add newly encountered failures as known exceptions; it also limits total warnings. Missing keys in a historical config are not equivalent to a clean build or permission to suppress new errors. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Thunderbird docs failure configuration.
