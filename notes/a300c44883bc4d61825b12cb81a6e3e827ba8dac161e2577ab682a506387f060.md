# Spam DTD migration changes labels while preserving J shortcuts

The historical DTD-to-Fluent migration changes menu and header wording to Spam while keeping key_markJunk/key_markNotJunk and their commands. Both localized key entries still contain j; the Not Junk key retains Shift. The migration recipe copies the old DTD key values separately from changed Spam wording. Fixed accepted code keeps this distinction. Do not infer a shortcut or API rename from a visible terminology change. Other locales and live keyboard behavior were not tested.

Scope: Spam localization and key bindings.
