# A failed tray preference lookup differs from an explicit false value

The Linux Rust tray helper maps a failed Boolean preference lookup to None. Construction uses unwrap_or(true), so an explicit false suppresses the tray while lookup failure keeps the fallback enabled. This patch adds a construction-time read, not a live preference observer. The review records a false/restart and true/restart check, but no new tray run occurred here. Later channel-specific defaults must be checked separately.

Scope: Linux tray preference.
