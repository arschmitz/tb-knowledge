# Map Spotlight paths with private profile and metadata directory state

Accepted Spotlight initialization stores #profileDir and #metadataDir in the constructor and builds the metadata location under Home/Library/Caches/Metadata/Thunderbird. Search path conversion swaps the profile prefix for that metadata prefix; reverse conversion resolves the resulting profile folder. The getter-only cache fix and larger indexing problem already have a shared lesson. This adds the concrete path mapping contract, without claiming Spotlight indexing works or the string replacement validates arbitrary paths. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/components/search.
