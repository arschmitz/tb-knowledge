# Account Hub redirect consent is remembered by email and host across view resets

The email view stores the accepted redirect host under the submitted email. It skips a repeated prompt only when that host matches. The first landing cleared this map during reset; the reland removes that assignment, so ordinary view reset retains consent. The manual-configuration test therefore runs before host acceptance. Accepted code keeps a separate resetRedirectAccepted method for tests. This is in-memory view state, not a persistent trust or certificate policy.

Scope: account-hub/redirect-consent.
