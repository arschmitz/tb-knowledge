# Centralize Panorama connection and statement lifetime in DatabaseCore

Current DatabaseCore establishes the profile panorama.sqlite connection and constructs the folder/message database objects at startup. It caches statements by name, finalizes those statements on profile-before-change, releases database objects, and closes the connection. FolderDatabase no longer owns the initial series static connection. Keep database-wide resources at this current owner when extending folder behavior. The inspected code asserts main-thread connection creation; it is not a complete thread-safety or shutdown-race audit. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama database resource owner.
