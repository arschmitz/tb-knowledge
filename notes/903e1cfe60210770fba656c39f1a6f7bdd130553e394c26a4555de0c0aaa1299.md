# Calendar occurrence identity must be cleared when switching back to a parent event

The dialog uses the shared event ID plus a recurrence-id nativeTime value to select a specific occurrence. The historical patch set the attribute for occurrences but did not clear it for parent events. The fixed setter explicitly removes recurrence-id when the new event has none. Its inspected test distinguishes the parent title from an exception title. Preserve those separate identities and the current reset behavior; no recurring-event or provider race ran.

Scope: Scoped source study.
