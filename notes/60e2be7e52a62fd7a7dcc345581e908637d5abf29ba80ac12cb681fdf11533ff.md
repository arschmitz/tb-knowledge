# Normalize and escape each Panorama path component separately

Current lookup splits the path on slash, percent-decodes each part and resolves it under its current parent; getFolderChildNamed performs normalization. getFolderPath percent-encodes slashes in individual names. Tests check composed/decomposed Unicode equivalence, case-sensitive lookup and slash escaping. Literal percent-encoding-like names remain a documented unresolved area with disabled assertions. Do not claim a complete URL-encoding round trip from these tests. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama folder path encoding.
