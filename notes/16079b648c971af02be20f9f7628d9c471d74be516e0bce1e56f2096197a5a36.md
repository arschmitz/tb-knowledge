# Subscription dialog teardown clears the delegated server listener before releasing its reference

SubscribeOnUnload clears gSubscribableServer.subscribeListener before assigning the local server reference null. The server property delegates to the subscribable model. Its completion callback accesses dialog controls and the same global server reference, so the listener lifetime must be considered separately from the connection. This landing also lets GetChildURIs return success for a valid node with no children while preserving missing-node and empty-name checks. The author-reported dead-window failure is historical; the static source does not reproduce a leak or crash. Required numbered Bug 1192098 comment 3 remains unavailable, with zero full-audit credit.

Scope: mailnews/news.
