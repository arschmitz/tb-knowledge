# Graph import generation follows the custom type identity beyond direct references

The original fix selects imports from a property's CustomRustType, checks that type's original schema name against the supported list, and emits its snake_case module name. This also handles composed or collection properties that are not direct OpenAPI references. The example adds ItemBody and the Message body/unique_body accessors. The fixed source later uses schema_name(), a BTreeSet and explicit self-import exclusion; its generated fields are owned. Do not treat the original borrowed accessor shape as the current API.

Scope: Microsoft Graph Rust generator.
