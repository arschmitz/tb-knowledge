# Use the current favicon retrieval promise after storing feed icons

The 2024 feed fix awaited setFaviconForPage and then wrapped a separate callback-based retrieval. Current FeedUtils directly awaits getFaviconForPage and reads favicon?.dataURI.spec. Preserve the store-before-read order without copying the historical callback wrapper into new code. Network rejection in MailUtils is an Error object, while the storage helper handles its own failure. No live feed/network or Places database test was run.

Scope: mailnews/extensions/newsblog.
