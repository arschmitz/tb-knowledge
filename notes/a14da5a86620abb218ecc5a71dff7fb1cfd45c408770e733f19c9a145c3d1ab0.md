# Optional EWS wire addresses do not remove the local parser and outgoing adapter contracts

The owned wire and borrowed header types make EmailAddress optional so a name-only EWS mailbox can be represented and formatted. The local mail_parser conversion still rejects a missing address field, and the outgoing BCC adapter explicitly wraps its address text in Some. Current header extraction preserves optional EWS fields; it can insert an empty formatted header if an enclosing mailbox exists with neither name nor address. The imported Charlie recipient test directly asserts the XML/model case, not successful live folder synchronization or universal malformed-message support.

Scope: EWS mailbox absence across wire/header/send adapters.
