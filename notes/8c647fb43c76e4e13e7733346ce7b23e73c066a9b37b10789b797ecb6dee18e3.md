# Authentication recovery retries a changed realm before the prompt decision

For a nonempty WWW-Authenticate value list, recovery extracts realm values and considers fewer than two results. A changed single realm, or an empty extracted result replacing a stored realm, is saved before returning Ok to the outer retry loop. This branch precedes the Silent/prompt decision. An entirely empty header list bypasses the branch, and multiple realms are ignored. This describes the inspected literal parser and state transition, not complete HTTP syntax, native cache matching or a successful authentication run.

Scope: Exchange HTTP realm recovery.
