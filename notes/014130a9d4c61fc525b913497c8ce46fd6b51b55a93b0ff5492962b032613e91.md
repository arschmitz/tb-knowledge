# OAuth token lookup is async while object initialization remains synchronous

getRefreshToken now resolves a token or empty string and can change _scope when a stored token covers the required scopes. Initialization waits for that lookup before constructing OAuth2 with _scope. The real Account Hub discovery gate awaits the token, while JSDoc still describes a plain string. The initializer has a settlement flag but no rejection handler that supplies a token value. Keep public Promise completion, scope side effects and the synchronous initializer separate; no authentication or rejection ran.

Scope: OAuth scope and completion contract.
