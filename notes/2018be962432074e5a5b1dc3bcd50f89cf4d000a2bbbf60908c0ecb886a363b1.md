# Keep account discovery in a privileged module and the wizard state in the view

The 1074 extraction adds FindConfig.sys.mjs, its build registration and a direct xpcshell test. Accepted FindConfig performs lookup and config conversion; the email view owns subview selection, loading state and discovered config display. Component naming pattern: privileged accountcreation modules use PascalCase .sys.mjs names, their direct unit test uses test_findConfig.js and the view remains email.mjs. This pattern is scoped to this integration, not a repository-wide filename rule. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/components/accountcreation.
