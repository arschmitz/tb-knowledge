# Folder URL drops check the feed parser result before reading spec

FeedUtils.getFeedUriFromDataTransfer returns null when no valid feed URI is found. The folder drop URL branch checks that result before reading spec and subscribing. Its final preventDefault still runs. This prevents the reported null access; it does not import inline images, guarantee subscription or catch every URI-construction exception. The separate dragover path applies target and item-count checks. No drag or browser test ran.

Scope: folder-pane-drag-and-drop.
