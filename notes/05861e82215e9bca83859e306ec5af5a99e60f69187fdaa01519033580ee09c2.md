# Tag import tests across components and retain the current manifest notation

The import tag is attached to selected Calendar and address-book tests and to the default import suite. Current manifests use TOML arrays such as tags = ["import"], while the historical INI uses tags = import. Preserve cross-component selection and use the notation of the current manifest when adding a related test. Default and per-test entries are shown separately; tag inheritance or merge semantics were not independently checked. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Import test tags and manifest syntax.
