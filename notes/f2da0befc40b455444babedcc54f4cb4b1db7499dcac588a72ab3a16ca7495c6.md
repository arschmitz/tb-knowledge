# Keep Windows child sandbox initialization before XPCOM glue

Entry 1043 removes the RemoteSandboxBroker-specific childData assignment. Accepted child startup still initializes sandbox target services before InitXPCOMGlue, then supplies target services and the Gecko setter to XRE_InitChildProcess. The nearby DPI initialization comment also requires it to happen after target services. Removing a retired broker branch does not remove this ordering contract or prove that sandbox protection changed. The paired Gecko implementation and its bug discussion were not inspected. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/app/windows-child-startup.
