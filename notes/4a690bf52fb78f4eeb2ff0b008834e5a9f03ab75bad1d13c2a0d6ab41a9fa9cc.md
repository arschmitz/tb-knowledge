# Tag-folder setup catches failures per tag

At revision d15c88407bf2ebb1363d33567fefa9ca43643178, the SmartMailbox tag-folder setup loop catches and logs an exception from each getTagFolder call, allowing later tags to be attempted. It calls saveVirtualFolders after the loop. Setup can therefore proceed despite a failed tag-folder lookup or creation; reaching the save call does not prove every tag folder exists. This catch does not cover getAllTags or saveVirtualFolders. This is static control-flow evidence, with no runtime validation or general error-handling convention established.

Scope: Smart mailbox tag-folder setup.
