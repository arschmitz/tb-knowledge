# Reset per-message filter state even when the constructor initializes it

Entry 912 initializes m_msgMovedByFilter, m_msgCopiedByFilter and related state. The accepted ApplyFilters method still resets move/copy flags at each message boundary. Constructor defaults protect first use; per-message resets protect object reuse. Preserve both lifecycle boundaries rather than treating constructor initialization as a replacement for repeated state reset.

Scope: mailnews/local/src.
