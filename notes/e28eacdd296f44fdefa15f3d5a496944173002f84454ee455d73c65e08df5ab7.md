# Gmail All Mail keeps archive semantics while using a separate display identity

The AllMail folder flag is separate from Archive, but IMAP kImapAllMail sets both. The owned label fix excludes that combination from the generic Archives name, so raw All Mail is displayed through fallback. Accepted later code adds a dedicated localized All Mail label and changes the test expectation. Preserve archive behavior, raw mailbox identity and display localization as separate contracts. Five direct added assertions check these fields; they were not executed here.

Scope: IMAP All Mail flag and folder label.
