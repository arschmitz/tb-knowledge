# Align folder-path helper documentation with the current signature

The helper header still documents an aScheme parameter that is absent from its signature, while implementation comments describe conversion back to a native charset although the result is nsString. Recommend updating both comments to the current escaped-URI, UTF-16 result and aIsNewsFolder roles. This is a scoped manual documentation proposal; it does not show that the conversion code itself is wrong. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
