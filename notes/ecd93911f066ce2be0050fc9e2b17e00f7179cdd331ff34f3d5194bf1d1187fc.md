# Thunderbird Calendar create/edit attribute-driven source loader

The loader’s plain contract is `{ sessionKey, identity: { calendarId, eventId, recurrenceId } }`. Route attributes remain authoritative: none is create mode; calendar plus event is edit mode; recurrence is optional. Redux holds snapshots only; raw events live in a session-keyed cache cleared on replacement, close, disconnect, or discard. [Task 1]

Scope: calendar.
