# Forced-colors changes share the message reload observer and its unload cleanup

The message shell registers forced-colors change events with the same observer used for dark-scheme changes and removes both listeners on unload. The change branch schedules a coalesced reload, while ReloadMessage returns when no message URI exists. This production trigger is separate from CSS-driven toggle visibility and does not prove a native contrast transition, message reload or accessibility result.

Scope: message-reader-forced-colors-reload-lifecycle.
