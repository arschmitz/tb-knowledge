# Filter-log formatting escapes the named message before its timestamp wrapper

LogFilterMessage first localizes the optional filter-name prefix, then escapes that whole message and passes the escaped string to the timestamp Fluent wrapper. LocalizeMessage builds named UTF-8 arguments and returns synchronous formatting errors. Both formatting stages now abort logging on failure; the old prefix fallback is not retained. This is the scoped data flow, not a measured speed improvement or a general security proof.

Scope: filter-log-localization.
