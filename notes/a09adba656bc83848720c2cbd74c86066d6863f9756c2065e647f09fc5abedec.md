# Release kinds select Lando destinations by project and release type

The July 2026 landing changes these three kinds to thunderbird-desktop-* production destinations. For try-comm-central, the destination is a nested by-release-type choice for beta, release or esr140, with an empty default. This selector is separate from the tag action's hg-repo-url, which maps source revisions. The fixed accepted endpoint retains that routing shape with esr153 names. The owned patch removes obsolete esr128 destination entries, but its early-tagging hg-repo-url still retains an esr128 source entry; the two fields are not interchangeable. The named Gecko keyed-by/task transforms and scriptworker-lando consume the configuration; their implementations and a generated task were not inspected here.
