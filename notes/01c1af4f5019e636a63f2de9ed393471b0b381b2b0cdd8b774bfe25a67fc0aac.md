# Column picker stays open after activation

At revision 1edc8d0674a61beb084c50f7d980c842080d2fcb, browser_columns.js documents that the column picker intentionally stays open after an item is activated. The helper sends Escape and waits for hiddenPromise to finish closing the popup. When maintaining this test flow, do not assume item activation closes the picker. This is a source-documented behavior and test pattern; the supplied evidence includes no runtime validation and does not establish a rule for other menus.

Scope: Thread pane column picker tests.
