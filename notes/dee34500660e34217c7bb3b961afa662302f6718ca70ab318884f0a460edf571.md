# Midnight test helper logging does not supply the missing assertion messages

The newly added checkMinimonthToday helper logs which control it checks, but its marker-count/date assertions have no message argument. The same new test also adds message-less visibility, showsToday and agenda assertions. These are scoped missing-message findings under the explicit nonempty expected-behavior requirement; test names and info calls do not satisfy it. Preserve the useful marker/selection separation while adding concrete failure messages in a future authorized test edit. This study changes no test and runs none.

Scope: Calendar midnight test diagnostics.
