# Name stored values for their role when one API contains several kinds of keys

D213704 reviewer found key versus key ambiguous: view-state storage key and messageKey were different identities. Current code uses currentUri/selectedUris and findIndexForMsgURI; synthetic or folderURI identifies the saved-state slot. Proposed manual naming rule: include role/domain for different identities in one method. URI storage is current behavior; old message keys and multifolder exclusion are historical.

Scope: mail/base/content.
