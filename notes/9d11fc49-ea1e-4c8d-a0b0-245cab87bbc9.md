# ICS property and component accessors preserve escaping, type conversion, and timezone references

Production privileged service/wrapper JS. Every method/getter/setter in
CalICSService.sys.mjs (618 lines) was read. calUtils.sys.mjs:140 imports this actual
icsService; src/moz.build:25–28 packages parser/serializer/service/worker modules.
The imported ICAL library remains a separate role; these are component-local
API contracts, not global JavaScript style instructions.

CalIcalProperty holds actual ICAL.Property and wrappedJSObject. icalString returns
escaped library serialization plus newline. value49–63 is unescaped joined text
for TEXT properties and otherwise valueAsIcalString. That getter65–89 handles
single-colon serialization directly, otherwise maps typed values to their actual
serialized representation; numeric/string values remain scalar text, objects
use toICALString or toString. Setter91–100 parses a mock property line and sets
multiple or first value according to current receiver isMultiValue.

Date getter102–107 only wraps values with actual icalclass=icaltime. Setter108–125
unwraps Calendar date, sets TZID for non-UTC/nonlocal zones, attempts parent
timezone reference insertion, otherwise removes TZID, then sets value.
Property parent42–44 returns raw inner parent, whereas component parent255–257
wraps it; the actual receiver of any parent.addTimezoneReference must be checked
before assuming these parent APIs are interchangeable. Full timezone/date callers
and this nonlocal-parent branch remain unresolved runtime scopes here.

Parameter methods131–202 lowercase ordinary names. VALUE is encoded as jCal type,
so getParameter synthesizes nondefault type. setParameter VALUE saves old value(s),
resets type (which clears values), reparses strings under prior design/type and
new requested type, and leaves empty on conversion error. A falsey single old
value produces empty oldValues in this code. Removing VALUE resets configured
default type through the same conversion. clearXParameters only warns. Parameter
generator can synthesize VALUE and visits jCal parameter names; next after done
can restart. It is owned by that wrapper.

Component scalar getters/setters303–382 read/update first library property value;
absent priority returns calIIcalComponent.INVALID_VALUE rather than null.
Time accessors384–465 wrap CalDateTime/Duration and update TZID plus referenced
zone on write. _getNextParentVCalendar526–532 walks wrapped parents or uses self.
addTimezoneReference549–560 deduplicates by tzid, inserts timezone component for
VCALENDAR when available, and retains zone reference. getReferencedTimezones
returns values. String and stream serializers468–473,566–573 delegate actual
library output; stream uses setUTF8Data. No asynchronous completion is introduced.

Service factories585–615 parse with actual ICAL.parse/Component, create lowercased
component/property types or parse trimmed property text. Async worker path has
separate completion/ownership analysis. Imported grammar/stringifier/date design
are not fully reviewed by this wrapper read.
