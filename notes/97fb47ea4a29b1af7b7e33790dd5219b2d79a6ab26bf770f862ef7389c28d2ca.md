# The shared toolbar icon-fill token is currentColor, separate from opacity

Shared host/root variables explicitly bind toolbarbutton-icon-fill to currentColor. The tab scrollbutton parts consume that token with their own currentColor fallback and read a separate opacity token. This is the selected declaration/consumer contract; it does not prove changed computed colors, all-icon coverage, contrast or upstream Nova behavior. No rendering or theme test ran.

Scope: Thunderbird toolbar icon color token.
