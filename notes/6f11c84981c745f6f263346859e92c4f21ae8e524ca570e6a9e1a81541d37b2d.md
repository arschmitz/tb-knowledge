# The DoH UI waits for resolved configuration before populating provider controls

The privacy-pane initializer awaits DoHConfigController.init before initDoH. Resolver controls then read the resolved providerList and fallbackProviderURI, using uri and UIName fields. This differs from the removed connection dialog’s JSON url/name list and from merely shipping settings dumps. Preserve initialization ordering and the actual record shape when changing provider setup. The outer pane-ready contract and upstream controller implementation are not proved here; no provider UI or network test ran.

Scope: DoH preferences initialization.
