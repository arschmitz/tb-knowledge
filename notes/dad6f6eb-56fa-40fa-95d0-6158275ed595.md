# Manifest V3 folder inputs use folder IDs across folder and message APIs

The schema declares separate Manifest V2 and V3 signatures for operations such as folders.create and messages.move. Manifest V3 takes folderId rather than a MailFolder or MailAccount object; Manifest V2 retains deprecated object forms. This is an API compatibility boundary, so review a new folder-taking method in both schema and implementation and do not document old object input as valid for Manifest V3.

Scope: WebExtension folder IDs.

- `mail/components/extensions/schemas/folders.json`
