# Forward addon-card context through Thunderbird embedder hooks

The historical port adds the upstream card-expanded and disabled-section options. Accepted code uses addon-card setEmbedderHooks after the custom element is defined, handles Thunderbird-specific warning cases, and delegates the same options to the upstream helper for other addons. Existing cards are refreshed after registration. A wrapper must preserve caller context as well as its addon argument when the dependency contract changes. The names isCardExpanded and isInDisabledSection identify separate states. Paired Gecko runtime behavior and live keyboard or screen-reader output were not tested.

Scope: mail/addons/embedder-hook.
