# Test both sides of a notification type transition

The current test_type sets blog and then donation and asserts the new class each time. It does not assert that the prior blog class was removed. When extending this test, assert both the new class and absence of the old class, and include a reused element rather than only a newly connected instance. That is a proposed local regression-test improvement; the production remove/add code already expresses the intended transition, and no failure was reproduced. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Notification type test completeness.
