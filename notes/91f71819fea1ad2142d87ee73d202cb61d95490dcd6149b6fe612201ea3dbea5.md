# Account Hub passes the Error after one logger message

The Account Hub header changes its existing gAccountSetupLogger call from debug to error. It passes one formatted message followed by the Error object as argument2. The fixed accepted header retains this call shape and adds a guard requiring the Error. The add-on failure caller also passes the Error after one message. Preserve these argument roles when editing these calls. This is a scoped source pattern. The console logger implementation, console output, and account operation did not run in this study. Bug 1971303 comment12 remains missing; this source-only lesson has zero full-audit credit.

Scope: Account Hub error logging.
