# Register the small notification icon at its actual chrome resource path

The blog icon lives at icons/sm/circle-question.svg, has a 16×16 viewBox, and is registered at the same path by jar.inc.mn. CSS references that chrome URL and supplies fill/stroke context colors. Its two paths consume context-fill and context-stroke; the opacity tokens are also present in the SVG but were not traced as CSS overrides. For this icon family, keep dashed resource filenames and matching manifest/CSS paths. No rendered icon, contrast ratio or high-DPI appearance was checked. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Notification icon resource naming.
