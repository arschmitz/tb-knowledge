# Global remote-content allow still checks explicit deny exceptions

For requests that reach this ShouldLoad branch, global allow checks content-URL DENY_ACTION and then the sender's DENY_ACTION before accepting. A rejection queues the existing observer notification while retaining the URI and context ID. The new stored-message tests directly check sender/URL permissions and image dimensions, plus a no-exception allow case; they do not assert the notification or every earlier bypass and failure path. Keep the later integrity and content-process harness phases separate from this initial patch.

Scope: Mail remote-content policy and browser regression tests.
