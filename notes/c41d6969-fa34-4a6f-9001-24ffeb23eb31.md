# Send Rust update-bot failures to the right recipient for the task level

The relanded tb-rust update bot sends nonproduction notices to the task creator by email and production notices to the sheriff Matrix room. support.py reads TASK_ID, fetches the task definition and its createdForUser tag, and skips cron and noreply users for direct email. The patch moves Matrix sending to the Taskcluster Notify service client. The Taskcluster kind grants route and API scopes per level. This is a coupled behavior change across Python task code, transforms, YAML routes, and external CI permissions; reviewing only the Python call misses deployment failures. No focused automated test was added in this commit.

Scope: Rust automation and Taskcluster.
