# The checkbox checked accessors retain state in the host attribute

Before the native input exists, checked reads fall back to host-attribute presence and writes still toggle that attribute. Connection copies the attribute into the input, and later internal input changes synchronize the host attribute. The setter Boolean conversion and HTML attribute presence are distinct from a string-valued false. The new test directly checks the initial checked fixture and expansion metadata; it does not directly execute every preconnection path. Other methods still require their actual native input, so this is a scoped accessor contract, not a universal optional-object rule. No runtime or accessibility test ran.

Scope: Account Hub checkbox checked-state lifecycle.
