# Address-book model-query documentation must reflect a string result

getModelQuery reads a character preference, strips a leading question mark for compatibility, and returns the query string. Its current JSDoc still says boolean. aboutAddressBook passes that result to generateQueryURI. Recommend a string result annotation when updating this helper, while keeping modelQueryHasUserValue as the separate boolean predicate. This is a scoped static documentation concern, not a runtime defect. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
