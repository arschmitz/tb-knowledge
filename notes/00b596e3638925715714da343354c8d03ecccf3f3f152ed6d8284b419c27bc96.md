# Sidebar wrappers keep theme inputs separate from their component consumers

The landing introduces --sidebar-background, --sidebar-color and --sidebar-border with fallbacks to existing theme input names and layout defaults. Consumers use the wrapper names. TagUtils updates only the no-color themed selected/focused text fallback; its colored-tag path remains separate. The search-window caller loads these rules into its document stylesheet. At the fixed accepted endpoint the external input names receive layout defaults and the wrappers alias them directly. This later declaration form must not be attributed to the original landing. The token and receiver wiring is static source evidence, not proof that every third-party theme renders correctly.

Scope: Thunderbird sidebar theme variables and legacy tag stylesheet consumers.
