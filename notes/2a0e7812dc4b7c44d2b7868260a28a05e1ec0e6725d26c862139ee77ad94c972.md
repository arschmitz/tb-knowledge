# The imported DeleteItem API is distinct from the later Thunderbird delete consumer

1275 introduces DeleteItem in the imported ews-rs API; that vendor landing is not itself a Thunderbird deletion implementation. At the fixed accepted endpoint, the owned delete_messages operation constructs hard-delete requests in chunks of 1000 and validates response count before pairing each response with its requested ID. The comment says the batch limit was learned from an error, not external documentation. This later code comparison does not cover a later chronological commit or validate the live service limit.
