# The config-message reland replaces a Promise double with the required iterator result

The original view already calls discoveryStream.next, but the new test supplied resolves(config), which returns a Promise without that iterator method. The reland changes only the test body to return next() resolving {value:config,done:true}; its other three owned blobs match the first landing. The double supplies one final config and does not exercise redirect feedback, cancellation or network providers. This static mismatch and correction are distinct from historical Try reports.

Scope: Account Hub discovery test protocol.
