# Overlay class names represent animation phases that tests must interpret together

The attachment overlay uses showing for its entrance animation, show for the steady visible state and hiding for its exit animation. The animationend handler adds show after showing-animation and removes show plus hiding after hiding-animation. _hideDropOverlay first removes showing and adds hiding. The contact drag test registers waitForTransition before synthesizing dragover, waits, checks absence of show, then verifies recipient pill count and labels after drop. A comparison of show and showing alone would falsely label the test as using the wrong class. Manual CSS state and test proposal: trace the event-driven phase transitions and wait behavior before judging an assertion. The assertion checks the steady-state class, not every instant of the animation, and no runtime result is claimed.

Scope: compose-overlay-animation-state.
