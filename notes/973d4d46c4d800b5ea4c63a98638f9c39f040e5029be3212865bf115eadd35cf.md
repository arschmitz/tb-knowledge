# Account Hub disabled tests must distinguish the host property from the internal select

The new disabled test assigns and rechecks host.disabled. The wrapper instead forwards an observed disabled attribute to its internal HTML select, and does not define a disabled property accessor. The outgoing form also assigns disabled on the custom hosts. The test never checks select.select.disabled or attribute forwarding, so its assertion cannot establish the internal control state. The accepted code retains these interfaces; no live disabled-state result was measured.

Scope: Account Hub custom select test contract.
