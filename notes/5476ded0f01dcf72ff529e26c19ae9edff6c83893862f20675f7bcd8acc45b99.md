# Use insertion and native close signals in the shortcut dialog test

Review replaced polling for the newly inserted shortcut dialog with a child-list mutation condition and polling for dismissal with the dialog's close event. It also changed the Escape key spelling to KEY_Escape. The final test covers sequential open, Escape close, reopen and button close. Its close-event wait is still registered after the action, so this example does not establish event-before-action ordering or remove every timing risk. This is source-checked test guidance for this dialog; no test was run.

Scope: mail/components/customizableshortcuts/test/browser/browser_shortcutsContainer.js.
