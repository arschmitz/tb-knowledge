# Thunderbird explicitly sets both add-on built-in certificate preferences false

The owned patch adds explicit false defaults for extensions.update.requireBuiltInCerts and extensions.install.requireBuiltInCerts; the fixed accepted source retains both. The reported purpose is compatibility with third-party security software and SSL proxies during add-on installation and updates. This comm change does not alter signing requirements or show the paired Gecko verifier implementation. Keep those defaults separate from claims that TLS, all certificate checks or signature verification are disabled. The missing primary comment remains an explicit discussion gap.

Scope: Add-on profile defaults.
