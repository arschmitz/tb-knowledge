# Preserve logical spacing and RTL illustration mirroring in notifications

The accepted shared notification content uses padding-inline-start and padding-inline-end, while :dir(rtl)::before mirrors the decorative layer with scaleX(-1). For this component, preserve logical spacing and the direction-specific decoration when adding a type; replacing them with physical left/right rules can change the RTL layout. Dark and high-contrast type colors have separate shared evidence. This is a scoped source-supported recommendation, not a global CSS policy or a rendered RTL result. Full Bugzilla and Phabricator timeline and inline discussion remain pending. No Thunderbird runtime, build, lint, keyboard or live accessibility validation ran.
