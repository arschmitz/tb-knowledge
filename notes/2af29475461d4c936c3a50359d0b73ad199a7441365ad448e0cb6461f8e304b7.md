# Preserve DOM descriptions without using HTML string insertion

The accepted Account Hub header uses Node.isInstance and replaceChildren for a DOM description; raw description strings go through textContent. The current component test supplies a DocumentFragment containing a span and a link, then checks text and the preserved link URL. Preserve this explicit DOM-versus-text boundary when adding notification descriptions. This is a verified rendering contract, not evidence that arbitrary caller-supplied nodes are trusted or that every link is safe.

Scope: mail/components/accountcreation.
