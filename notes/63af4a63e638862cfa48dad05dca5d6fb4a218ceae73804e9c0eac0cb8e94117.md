# The removed compose debug listener was not a save-completion signal

The cleanup removes the disabled logging listener, its native progressListener hookup and the gPersistObj debug reference. The compose file-save route remains cmd_saveAsFile → SaveAsFile → SaveDocument → OutputFileWithPersistAPI. The last helper calls native saveDocument and returns a synchronous Boolean; SaveDocument uses it for UI state, while SaveAsFile does not await the SaveDocument promise. The removed callbacks did not resolve a save-complete promise or drive a progress UI. Do not treat the command return or this listener removal as proof that file writing finished. Native persistence ownership and completion behavior remain outside the paired source scope, and no compose file save was run.

Scope: mail/compose/file-save.
