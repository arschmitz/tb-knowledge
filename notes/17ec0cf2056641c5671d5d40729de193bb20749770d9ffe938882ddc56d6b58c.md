# Propagate the post-update page promise to callers that inspect its result

Entry 775 changes showWhatsNewPage to async and awaits the new lastUpdateInstalled method. Current code retains that call and checks the installed update version against both the previous milestone and the running application version. The browser test awaits showWhatsNewPage before inspecting external-protocol URLs. The startup wrapper still calls it without awaiting because its caller continues startup. Manual asynchronous API proposal for this path: preserve the promise in tests and dependent callers, and review fire-and-forget startup calls separately. Do not generalize this patch into a rule that every call must await or that a ready update is equivalent to an installed update.

Scope: post-update-page.
