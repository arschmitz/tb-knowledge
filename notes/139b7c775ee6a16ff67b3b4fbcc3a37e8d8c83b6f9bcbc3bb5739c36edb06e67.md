# Current account creation restores loading state in finally

The accepted #createAccount establishes an AbortController, starts loading and calls #validateAndFinish on a copy. UserCancelledException and UserSkippedError return false; other errors are rethrown. Its finally cleans up the verifier, abortable state and loading UI. Recommend retaining that cleanup for all exit paths when modifying the historical OAuth prompt route. No prompt or cancellation was run. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
