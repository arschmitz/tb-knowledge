# The legacy Account Central version test expects the application version

The legacy Account Central no-server branch writes Services.appinfo.version to #version. Its explicit empty-folderURI browser test expects AppConstants.MOZ_APP_VERSION. The correction changes only the expected constant from MOZ_APP_VERSION_DISPLAY; it does not change the displayed production value or test Account Hub startup. The reported beta failure is historical. The native application-version implementation and generated AppConstants values were not independently paired or executed.

Scope: Legacy Account Central version display test.
