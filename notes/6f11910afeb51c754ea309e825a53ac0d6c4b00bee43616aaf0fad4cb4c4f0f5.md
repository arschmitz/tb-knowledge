# Issuer getter documentation omits the frozen built-in return contract

Review requested freezing returned sandbox copies and explaining the immutable return contract. The source freezes the copy and tests the top-level result, but the getter JSDoc still says it maps an issuer and returns ?IssuerDetails. Document the frozen built-in result and shared-versus-copy behavior when callers need that constraint. This is a scoped documentation suggestion; it does not claim deep immutability or extend to uninspected provider kinds.

Scope: OAuth provider caller documentation.
