# AutoSync sibling grouping means equal incoming servers

The manager-local IsSibling helper compares owner-folder incoming servers with Equals. It initializes false and propagates failures; its queue consumers use the result only after a successful status. Search excludes the same state, and queue chaining protects a representative already downloading. This is server grouping, not folder-tree sibling naming. The historical change removes the utility from the public state interface without adding a runtime test. No queue or download test ran.

Scope: AutoSync manager internal queue grouping contract.
