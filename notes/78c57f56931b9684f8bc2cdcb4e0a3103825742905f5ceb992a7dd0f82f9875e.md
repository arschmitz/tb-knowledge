# Distinguish intrinsic image size from authored display dimensions

574 marks an image overflowing when naturalWidth exceeds rendered clientWidth. It gives all eligible message images shrinktofit and uses overflowing separately to enable zoom. The fixture includes an intrinsically wide inline image, an authored stretched image and attachments. Comparing authored width only can give the wrong zoom state. Current code additionally skips images inside links so image zoom does not replace link activation. This is message content behavior, not a rule for arbitrary webpage images.

Scope: Message image geometry.
