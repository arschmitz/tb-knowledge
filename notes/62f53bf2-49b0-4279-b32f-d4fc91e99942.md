# Send Panorama rows to JavaScript in bounded chunks

The Panorama back end sends live-view rows to JavaScript in chunks. The mail.panorama.liveViewChunkSize preference sets the batch size, avoiding one large front-end transfer for a long message list.

Scope: panorama.
