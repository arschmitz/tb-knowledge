# The auth-popup helper documents the custom host as a native select

The helper's new HTMLSelectElement annotation does not match the object its caller passes. The incomingAuthMethod query returns an AccountHubSelect host, whose class extends HTMLElement and has a separate select field for the native element. Keep the host and its internal receiver distinct when reading the frame wait, synthetic click and parameter docs. This is a local static type-documentation mismatch, not a runtime failure or a global custom-element rule.

Scope: Account Hub browser-test helper receiver typing.
