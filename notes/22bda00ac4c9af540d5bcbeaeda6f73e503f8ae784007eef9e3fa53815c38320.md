# The selectedFolders setter uses a documentation alias without renaming the property

The selectedFolders setter documents @name FolderSelectionDataAdapter#setSelectedFolders and @private to avoid a jsdoc/sphinx-js duplicate-symbol problem with the getter. The source comment names that reason. The actual accessor remains set selectedFolders(selected); the tags neither rename the JavaScript property nor enforce runtime privacy. Keep this workaround scoped to the affected accessor and documentation tool behavior.

Scope: Folder selection adapter source documentation.
