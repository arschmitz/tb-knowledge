# Use SelectedItemText only with the focused selected row color state

In forced-colors message lists, restrict SelectedItemText to the focused current selected row. Selection, the active current row and focus are separate states. Giving all selected rows the focused foreground can mismatch the inactive background. Commit 287 fixed the focused selector. Current accepted code uses @media(forced-colors) with :focus/:focus-within and .card-layout tr.current.selected. Keep unfocused selected styling separate and check the paired background/foreground states.

Scope: message list colors.
