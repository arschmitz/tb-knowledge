# Historical background folder loading returns promise settlement to the main thread

The 1214 loader establishes its database connection on the main thread, asserts that InternalLoadFolders runs off that thread, and dispatches promise resolution back to the main thread. A main-thread pointer holder carries the promise between tasks, and Folder refcounting changes to the thread-safe declaration. This is the historical handoff contract, not proof that all Folder operations were thread safe or that on-disk reconciliation moved in the same patch. The accepted implementation has replaced this API; no thread-safety or profiler run was performed. Full bug and review discussion remains pending.

Scope: Historical Panorama thread ownership.
