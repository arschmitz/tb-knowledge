# Name recent destinations for destination usage rather than folder viewing

The label chain changes Recent to Recent Destinations for move/copy menus, and current menu ranking uses MRMTime. Folder-mode recency separately uses MRUTime; the extension API distinguishes lastUsed from lastUsedAsDestination. Preserve those meanings in UI labels, comments and query names. Existing filter/sort/limit guidance is reused; no ranking algorithm change is claimed from this label-only landing. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Recent folder and destination naming.
