# Keep the deliberate numeric Today Pane exception scoped to its tight label

formatDateOnly accounts for languages whose day number includes extra text. Month-view cells use it, but Today Pane deliberately displays start.day because those extra CJK characters will not fit its small day label. It still uses a whole month/year formatter for the adjacent month label. Preserve the documented size exception rather than teaching either raw numbers or formatted dates as mandatory for every date control. The actual CJK layout was not rendered. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: calendar/today-pane/day-label-exception.
