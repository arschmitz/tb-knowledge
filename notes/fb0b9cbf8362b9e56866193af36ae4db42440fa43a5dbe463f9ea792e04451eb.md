# Exchange biff continues known-folder message sync after a hierarchy error

Both folder-hierarchy success and failure callbacks stop activity feedback and invoke the supplied continuation. Biff uses that continuation to start message sync for existing descendants. Its active flag is cleared separately by the URL-listener completion map after tracked folders stop. Continuing after a hierarchy error does not itself prove that every folder callback occurs or every setup error completes; no regression test or protocol run was inspected.

Scope: Thunderbird Exchange new-mail synchronization completion.
