# Use an NNTP identity fallback without assuming an owning folder

When composing from a standalone newsgroup message with no identity, the accepted path finds the first NNTP incoming server and asks MailUtils for its identity. If no suitable identity is obtained, it falls back to getIdentityForHeader. The message header server getter also permits the first NNTP account when gFolder is absent. This is a fallback selection rule for this path, not proof that the first account is always the best match. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.
