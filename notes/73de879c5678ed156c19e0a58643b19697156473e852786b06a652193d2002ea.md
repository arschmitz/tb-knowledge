# Message undo metadata is an explicit interface with an unknown empty-stack result

nsIMsgTxn extends nsITransaction and adds readonly msgWindow and txnType attributes. Entry 684 replaces a generic property-bag type lookup with this interface. nsMessenger initializes the output to eUnknown, propagates PeekUndoStack/PeekRedoStack failure, returns success for an empty stack, and queries nsIMsgTxn before reading its type. nsMsgTxn starts at eUnknown and SetTransactionType asserts initialization only. Manual C++ interface proposal in this family: express required message metadata in the dedicated interface and keep empty-stack success distinct from query failure. Use the declared txnType name, rather than a magic property named type. This is a message transaction contract, not a rule against property bags for flexible metadata.

Scope: message-transactions.
