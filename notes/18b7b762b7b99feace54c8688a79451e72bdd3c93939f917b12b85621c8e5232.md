# Historical decision-task base literals are separate from current repository-derived bases

The owned port removes private base-guessing helpers and writes literal default/tip comm bases. Current code instead imports the base ref, fills a missing ref from the repository default branch and computes a latest-common revision when both revisions are present. The changed-files lookup is a separate step. Use the exact source phase when interpreting this history; the subject alone does not establish an API transport change or a current base-selection rule.

Scope: Comm Taskgraph decision parameters.
