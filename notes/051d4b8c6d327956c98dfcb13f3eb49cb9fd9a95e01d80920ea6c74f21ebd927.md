# Use locale date formatters instead of assembling month names

Historical380 repaired cal.l10n.formatMonth Fluent cases and callers. That method is gone in current accepted code: cal.dtz.formatter formats month/year or ranges with the locale formatter. Its monthNames comment forbids constructing a date string from those standalone names. Preserve grammar/order/year units by using the purpose-built formatter; zero-indexed month parameters are documented.

Scope: calendar.
