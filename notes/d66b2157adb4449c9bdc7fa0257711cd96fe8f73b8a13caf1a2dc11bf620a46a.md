# The six-job AMD rollout changes requested worker aliases while preserving each job role

This owned patch appends -amd to six requested worker aliases. Pin verification and the documentation webhook retain -noscratch-amd; clang, mozlint and Python task defaults and the standalone taskgraph diff job use t-linux-docker-amd. The diff leaves each image, command, selector, tier and scope unchanged. Source-test kind loading and the current alias route establish how these requested names are consumed. Later checkout/platform changes are separate. This is scoped configuration evidence, not a claim that every test moved, a generated graph passed or a physical worker was available.

Scope: Taskcluster source and pin job routing.
