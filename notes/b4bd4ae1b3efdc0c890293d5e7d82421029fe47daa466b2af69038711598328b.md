# Collapsed read thread roots have a separate visual cue for unread children

The CSS targets a table-layout row that is a collapsed container, hasUnread and read. It preserves underline and adds font-weight 600 to cells and the subject line. The root message remains read; aggregate unread descendants are a separate state. Marker fill/stroke comes from the literal nested rules plus existing unread and selected/focus rules, so inspect the complete cascade before claiming a selected-state result. This static source fact does not establish font availability, contrast or screen reader behavior.
