# The address-book drag test waits for compose dirty state before expecting the close prompt

After checking the dropped recipient pills, the shared test helper waits for gContentChanged before registering its close-confirmation expectation and issuing cmd_close. That flag is part of the normal production close-prompt predicate, so the test observes the state its next expectation needs. It still checks overlay/pill count and indexed labels with explicit messages and awaits prompt/window completion separately. Later helper receiver changes do not prove identical implementations. This is a scoped state-before-action wait, not a universal intermittent cure or all-close-path result. No drag, dialog or test ran.

Scope: Address-book drag-to-compose test state ordering.
