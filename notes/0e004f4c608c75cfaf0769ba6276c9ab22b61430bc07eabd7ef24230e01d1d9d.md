# The shared folder hard-delete test checks the EWS fixture for both protocols

runHardDeleteTest accepts mockServer and runs once for EWS and once for Graph. Its local disappearance helper uses the passed server, but the final remote deletion count and ID assertions read global ewsServer. The Graph invocation therefore does not directly assert its own server's recorded deletion. Keep local folder cleanup and protocol-specific remote evidence separate. This is a current source finding; no test ran.

Scope: Exchange folder deletion test oracle.
