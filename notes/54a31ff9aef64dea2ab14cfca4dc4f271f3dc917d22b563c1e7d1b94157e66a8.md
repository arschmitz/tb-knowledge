# Describe temporary values by their role when scopes overlap

830 distinguishes outer and inner signature offsets, the end marker, and the extracted armor block in extractSignaturePart. Use role-specific names for nested temporary values when their meanings differ. The patch supports this local readability proposal; the shadow/redeclare bans themselves are covered by lint and are not new manual style rules. Existing abbreviations are not a project-wide naming mandate.

Scope: OpenPGP armor parsing names.
