# The original related-part rewrite discarded allocations that later code releases

In the selected landing, the related-part URL returned from an allocating helper is overwritten by a new strdup result without releasing the original. The copied filename also loses its prior release. The hash value makes its own copy, and the local tail frees only the replacement URL. Later accepted code frees the filename in BuildRelatedPartUrl and the original URL in its caller. This is a static ownership finding, not a measured memory leak, crash or instruction to change unrelated allocation code.

Scope: MIME related-resource URL ownership.
