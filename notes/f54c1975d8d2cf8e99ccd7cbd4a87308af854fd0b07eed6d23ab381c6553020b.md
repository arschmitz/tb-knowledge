# The IMAP folder-URL window-opening service is removed with its content-handler path

The landing removes the messenger window-service interface, component registrations and implementation, and deletes the NewChannel branch that selected an IMAP folder then dispatched to that service. HandleContent now rejects content with NS_ERROR_WONT_HANDLE_CONTENT. The removed code was a reachable folder-URL behavior; the historical broken-for-years claim does not establish that it was dead. The fixed accepted handler still rejects content, while NewChannel has later changes. No live URL, command-line or window test was run.

Scope: Legacy IMAP folder URL handling.
