# Address-book telemetry counts directories even when contact enumeration is unsupported

Directory types use the URI scheme instead of numeric dirType. Directory count increments before trying childCardCount; a directory throwing NS_ERROR_NOT_IMPLEMENTED does not abort the whole report. The current test includes an LDAP directory count but does not prove remote LDAP contacts are loaded/counted. Keep the narrow best-effort contact operation and preserve other directory results.

Scope: address-book-telemetry.
