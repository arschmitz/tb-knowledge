# Custom reminder labels round units while the submitted value keeps whole minutes

For a custom default, the option value remains offsetMinutes. Its label instead selects minutes, hours or days and floors the displayed count for hours/days. Submit parses the minute value, so a displayed unit count can omit a remainder that the payload retains. The earlier seconds-to-minutes conversion also floors sub-minute remainders. This is static arithmetic and label wiring, not a rendered or backend result.

Scope: Calendar reminder choice precision.
