# Default message-list preferences do not rewrite existing folder state

Appearance exposes mailnews.default_view_flags, mailnews.default_sort_type and mailnews.default_sort_order. Its tests first access a folder, change the defaults, and assert that the old folder remains threaded, sorted by date and descending. Changing defaults and applying defaults to existing folders are separate actions. Preserve that user-visible distinction when modifying the pane. This behavior is supported by static assertions, without executing the browser test. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / components.
