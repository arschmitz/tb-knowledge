# Await stored SMTP credentials before serializing QR account data

The historical getAccountData was synchronous. Selected context-only entry 5729 changes it to async, awaits _getPasswordWithoutUI when the cached password is empty, and gathers account data with Promise.all before chunking. The current test explicitly clears outgoingServer.password and expects the stored SMTP password in the serialized array. A promise must not occupy a password slot in JSON. This study verified code and assertions without executing Login Manager or OS authentication.

Scope: mail/modules/QRExport.sys.mjs.
