# The Redux vendoring recipe coordinates relative module paths and source registration

The owned recipe pins Redux Toolkit and specifies relative import rewrites among the copied dependency modules, plus production environment substitutions. The build lists five module source paths, and lint metadata excludes the imported subtree. These declarations coordinate the integration but do not prove that generation ran or that generated artifacts match the patterns. The seventeen imported bodies stay outside this study; historical HTML license links and later build license groups remain separate phases.
