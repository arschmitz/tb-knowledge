# Thunderbird profile tooling is selected in both test fetches and toolchain references

XPCShell and Thunderbird Mochitest tasks list profiling helpers in platform-specific toolchain fetches. The toolchain kind must also reference the named upstream tasks. The checked configuration uses distinct x64 and aarch64 macOS tool sets and architecture-specific Windows node/samply entries. These declarations do not prove that upstream profiling code ran or that a symbolicated artifact was produced.

Scope: Taskgraph test profiling configuration.
