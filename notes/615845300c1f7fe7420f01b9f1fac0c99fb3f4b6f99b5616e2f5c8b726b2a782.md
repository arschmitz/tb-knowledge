# Choose the IMAP import listener for online or offline timing

Online import uses the notification service msgAdded event after server insertion. Offline import uses the mail-session added event because the server event does not fire. Cleanup removes the same listener interface that was registered. The test covers both modes and explicitly omits setting new in offline IMAP. Its cleanup comment says online but sets Services.io.offline=true; retain that as a source discrepancy. Static tests and comments do not establish actual network execution or proper final global state. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/import-listener-phase.
