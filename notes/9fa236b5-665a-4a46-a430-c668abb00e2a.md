# WebGL wrapper generation binds target paths and WebGL versions

Firefox repository `git:314d8065c5ad68c7e5c5f92d`, revision `1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b`. Scope: DOM Canvas WebGL conformance tests and the shared Mochitest harness. Languages in the cited files: Python, HTML. File roles are listed in the metadata. No production WebGL implementation is claimed.

WriteWrapper replaces path separators in the output name, adds the 2_ marker for WebGL2, fills TEST_PATH with the test entry, and adds ?webglVersion=2 only for WebGL2. It writes the template then records the wrapper path. WriteWrappers creates the generated directory and emits each enabled version.

## Scope and state

The generator runs synchronously. It writes wrapper files and appends their paths to `wrapperPathAccum`. The target and version remain separate member facts. This record follows `WriteWrapper` and `WriteWrappers`; it does not establish the full entry-list construction or exception handling of their outer caller.

**State:** Filesystem output plus wrapperPathAccum; each member keeps its target and version query.
