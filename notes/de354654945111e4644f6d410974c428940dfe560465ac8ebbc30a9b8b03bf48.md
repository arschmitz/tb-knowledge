# Declare the Windows environment requirement before including WindowsMain

The startup correction defines XRE_WANT_ENVIRON before its Windows entry-point include. The 2024 patch used mozilla/WindowsMain.h; current source includes nsWindowsWMain.cpp after the define. Keep that preprocessor order when changing this startup interface: the declaration controls what the header provides. This is a specific C++ startup requirement, beyond whitespace formatting.

Scope: mail/app/nsMailApp.cpp.
