# The first Graph delta tests omit messages and mislabel the terminal response

In the first delta landing, five added or replaced assert_eq! calls lack an expected-behavior message. The terminal-response test matches DeltaResponse::DeltaLink, but its else branch says 'next page should parse as such'. That text names the opposite response phase and would mislead a failure investigation. This is a scoped historical test-review finding, not evidence that the tests failed or that generated output defines message style. A terminal response message should name the expected DeltaLink, and each assertion should state its expected value.

Scope: Graph delta unit-test review.
