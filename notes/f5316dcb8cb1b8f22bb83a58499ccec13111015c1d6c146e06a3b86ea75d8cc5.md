# Pass the caught error as a separate logging argument

1020 changes many console.error calls from string concatenation or interpolation of the exception to a context string plus the exception object. The accepted account manager and SMTP settings code keep that form. Preserve the error object when logging a caught exception so its details remain available to the logger. Scope this to caught errors; MimeMessageUtils deliberately passes e.stack separately, so this evidence does not justify a ban on explicit stack logging.

Scope: Mailnews exception logging style.
