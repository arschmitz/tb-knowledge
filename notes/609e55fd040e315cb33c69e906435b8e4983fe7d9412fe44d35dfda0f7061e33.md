# Message-database docs encode a trailing space in interface-definition searches

The interface links use a Searchfox query such as interface+nsIMsgDatabase+, including the trailing plus that encodes a space. The implementation link uses its explicit header path. The author intends more direct definition navigation; this study checks the exact links and IDL spacing, not live redirects, forward-declaration filtering in every case or the full database architecture.
