# Exchange add-on selection gates the Account Hub continue state

The found-config widget considers the first add-on option, tests installation and disabled state, and applies its addonAccountType to Exchange incoming configurations when installed. Its bubbling config-updated detail.completed is true for a non-Exchange selection or an installed Exchange add-on. This is the implemented config-state gate, not proof that every installation failure restores the footer correctly. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: Account Hub Exchange add-on config state.
