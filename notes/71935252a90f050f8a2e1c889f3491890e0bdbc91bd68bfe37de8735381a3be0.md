# Check the resolved detached-signature result after awaiting it

GPGME.signDetached is async at the historical error-check landing. That landing checks the returned promise without awaiting it, so the falsy check cannot test its resolved null result. The fixed accepted RNP code awaits signDetached before checking the result. Read the actual callee declaration when adding success checks across an async boundary. This is a scoped source comparison; no external signing, error injection or complete encryption-state cleanup audit ran. Bug 1958968 separately withdraws the alleged environment-variable workaround; the guard must not be described as a smartcard or package-support repair.
