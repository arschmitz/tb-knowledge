# Popup primary styling follows the actual button-primary class in three footer consumers

The shared popup footer rule now targets enabled button-primary controls instead of primary. The inspected edit-contact Done, message-header Save and spaces Save controls already carry button-primary; spaces Restore does not. The CSS keeps its focus-visible outline and adds primary hover border/shadow with active shadow removal. Other local appearance/disabled overrides are removed, so these source facts do not prove the base-widget cascade, contrast, focus visibility or an accessibility result.

Scope: Popup footer button styling and controls.
