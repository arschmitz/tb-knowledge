# Searchfox rust-analyzer wiring declares both consumer fetches and the imported task

The Linux, macOS-cross and Windows-cross Searchfox jobs each request linux64-rust-analyzer in fetches.toolchain. The toolchain kind separately includes that label in reference-tasks for its merge loader. This is a paired configuration declaration, not proof that the upstream artifact was imported, downloaded or used successfully. Later worker/mozconfig changes are separate, and no taskgraph or indexing job ran.

Scope: Searchfox toolchain integration.
