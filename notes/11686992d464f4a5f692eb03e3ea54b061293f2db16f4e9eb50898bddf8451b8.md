# Popup template references are IDs of real menupopup elements

The toolbar popup test takes the first [popup] reference in each item template, finds that ID in the document and asserts menupopup. UnifiedToolbarButton gives its popup attribute priority over other click handling and anchors openPopup to itself. A scoped template recommendation is to keep the reference and consuming element in sync. The test does not inspect every popup descendant or prove focus, dismissal and keyboard behavior. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/unifiedtoolbar.
