# Documentation page targets and named-section labels use different links

The accepted guide uses objects.inv from a built documentation tree to find document references. Page links use a leading-slash document target such as /documentation/index. The current guide separately shows a named section label such as sqlitedirectory without that slash. Source file paths and version-specific published URLs are not interchangeable with those targets. Missing references can become plain text or build warnings. No documentation build or rendered link validation ran here.

Scope: Thunderbird documentation links.
