# Commands Meta Dashboard toolbar responsive alignment

The misalignment came from `justify-content: space-between` plus default centered flex alignment. Use bottom-aligned wrapping flex (`align-items: flex-end`, `justify-content: flex-start`, `gap: 12px 16px`), full-width selects, and controlled flex bases for Board/Child meta. On mobile, stack the toolbar, make actions full width, remove Child meta's minimum width, and stretch root links. [Task 1]

Scope: console.
