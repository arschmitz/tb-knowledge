# Calendar login-count checks await each state boundary but still lack a failure message

The Calendar helper and every existing caller now await countLoginsAsync, so the task finishes each count check before its next action. The changed shared Assert.equal still has no message; all callers inherit that diagnostic gap. The OAuth token-clear test instead keeps a nonempty message for its persisted-login count and separate memory-token assertions. This patch adds asynchronous ordering, not new authentication coverage or a fresh test result.

Scope: Authentication test ordering and diagnostics.
