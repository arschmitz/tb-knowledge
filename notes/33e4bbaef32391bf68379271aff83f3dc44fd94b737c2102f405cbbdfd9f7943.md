# Distinguish OAuth authorization completion from successful mail verification in tests

The granular-scope test requires OAuth authorization telemetry to report succeeded even in cases where mail verification should fail. No grant and a non-mail-only grant fail verification; mail-only and all scopes succeed and store only grantedScope in the login realm. The test retries when prompt teardown races with token completion. Keep these separate success criteria when diagnosing account setup failures.

Scope: mail/components/accountcreation.
