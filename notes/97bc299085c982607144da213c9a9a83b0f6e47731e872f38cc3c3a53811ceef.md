# Offline message size differs from logical server/header message size

The historical 1483 fetch path sets both messageSize and offlineMessageSize from locally stored bytes. The accepted ExchangeFetchMsgsToOffline sets only offlineMessageSize and explains that messageSize must represent the server size, including use by copy/save completion. Keep these two meanings distinct in this fetcher; the later refinement is accepted-source context, not full study of its introducing bug or a measured copy failure. No storage, copy-progress or size-comparison test was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Exchange offline versus logical message size.
