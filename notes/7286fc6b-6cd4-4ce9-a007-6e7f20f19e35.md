# Only send a CardDAV card when its vCard changed

The second Bug 1898136 patch compares the stored _vCard with the card returned by local modifyCard. It calls the asynchronous server update only if the vCard content changed. This avoids a needless PUT/GET cycle for local-only changes such as PopularityIndex while still saving the local card. Current code keeps the guard. The synchronous nsIAbDirectory.modifyCard contract means the network work is launched separately. Reviewer mentioned REV as a future idea, not part of this change.

Scope: CardDAV synchronization.
