# Test combined security state and serialized event extras

The current secure-mail test covers signed, encrypted and signed-plus-encrypted messages for both S/MIME and OpenPGP, plus plain messages. It registers the completion listener before selecting the row. Event extras are compared with String(is_signed) and String(is_encrypted); truthiness cannot distinguish the serialized string false from true. Check exactly one matching event for each expected combination. The inspected sequence proves the expected single-load cases if it passes; it is not a test of reopening a message or every callback race.

Scope: Crypto telemetry tests.
