# The nested MIME header follow-up separates lowercase lookup output from original boundary bytes

SniffPossibleMIMEHeader now fills a separate lowerCaseLine with the two-argument ToLowerCase call. Header lookup uses that buffer, but boundary and charset extraction still slice the original const line. Preserve the distinct case roles; the author-reported Coverity warning and false-positive opinion do not prove a real UAF or a tested fix. This source study does not inspect the external overload implementation.

Scope: Encrypted-search nested MIME header handling.
