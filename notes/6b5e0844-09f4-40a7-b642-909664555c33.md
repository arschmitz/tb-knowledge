# Exercise POP3 login verification and certificate errors when changing client cleanup

D206738 review tested a new profile with two POP3 accounts and a self-signed server certificate. That path called Pop3Client._actionDone without an onFree callback and reached an error with a null urlListener. The reviewer saw two TypeErrors and then a stalled mail check. The landed fix makes onFree and URL listener calls optional. verifyLogon does not enter through withClient, so tests of ordinary download alone would miss these failures. The current source retains optional calls. No independent runtime test was run in this study.

Scope: POP3 connection lifecycle.
