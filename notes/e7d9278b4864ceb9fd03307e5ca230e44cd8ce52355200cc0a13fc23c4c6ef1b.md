# Stack the manual form at the current font preference threshold

The manual incoming and outgoing setState methods toggle stacked when mail.uifontsize is at least 17. The corresponding CSS changes two-column manual form rows to one column. Preserve the state-to-layout link and logical dimensions when changing this layout family. The toggle occurs on setState in the inspected code; live updates during an already open step are not established. No zoom, localization, right-to-left or visual reflow check was run. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub manual form font layout.
