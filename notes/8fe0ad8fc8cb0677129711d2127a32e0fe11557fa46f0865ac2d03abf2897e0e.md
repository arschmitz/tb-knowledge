# The address-book master label and checkbox use separate names and an isolated row container

The tri-state control keeps separate Label and Input fields because localization targets the label span while click, checked, indeterminate and aria-controls target the checkbox. The inputs getter is scoped to the account container, so capture/reset and row operations do not include the master checkbox or remove its label. The checkbox ID remains the label for target. This is a concrete local role/selector convention, not a global suffix rule or proof that the label tab stop and keyboard/accessibility behavior are correct. Current selection algorithms later differ from the original counter-based patch. No UI or test ran.

Scope: Account Hub control-role naming and selector scope.
