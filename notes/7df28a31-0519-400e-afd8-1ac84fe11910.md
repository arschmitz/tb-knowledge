# Give busy and error folder icons their state colors over custom colors

A folder custom color sets --icon-color inline. The busy and error selectors must override that value so the clock and warning icon keep their state colors; the error rule uses --icon-color rather than fill. D209494 checked the relation with the existing fill rule and noted that the loading icon uses its stroke. Check custom-color folders in both states when editing these selectors.

Scope: folder tree icons.
