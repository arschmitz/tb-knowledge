# WebExtension support annotations override schema defaults without enabling runtime APIs

Annotation version_added accepts a Boolean or a version string and overrides schema-derived compatibility defaults. The README defaults mail schemas to supported and browser/toolkit schemas to unsupported. browser_settings.json marks browserSettings supported while overriding selected browser-only properties to false. Manifest-version bounds narrow annotation scope, and a note can request BCD export. These declarations feed a documented external generator; they do not themselves enable runtime APIs. Generator implementation, output and API tests were not inspected.

Scope: WebExtension support metadata.
