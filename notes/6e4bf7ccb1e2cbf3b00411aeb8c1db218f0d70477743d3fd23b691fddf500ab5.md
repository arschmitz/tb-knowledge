# Audit lazy module constants as well as method calls

Entry 1165 fixes a MailGlue permission bitmask that still referenced unqualified AddonManager, and fixes the three installer lookup/download branches to use lazy.AddonManager. Accepted source retains this receiver for both constants and methods. This is a migration lesson, not a mandate to make every import lazy. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending.
