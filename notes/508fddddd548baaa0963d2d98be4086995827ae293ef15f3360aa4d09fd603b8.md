# The message-container decoder callback deliberately bypasses its own override

The message container routes encoded bytes through its decoder, but decoded bytes use mimeObjectClass.parse_buffer. The base buffer callback dispatches ordinary parse_line work, so the decoded data does not reenter MimeMessage_parse_buffer. Source comments name setup, consumption and EOF/finalizer cleanup and explain this distinction, as requested in review. Decoder selection still has an exact raw/save-as bypass. The fixture checks attachment metadata and nonemptiness, not every message rendering or save path. Required primary gaps keep full-audit credit at zero.

Scope: MIME encoded message-container lifecycle.
