# Calendar notification times remain outside the inspected cache-copy list

The accepted dialog writes notifications.times before changing cache.enabled, while the inspected replacement whitelist does not include notifications.times. This is a scoped static transfer concern: the two code sections do not show that value copied to the replacement. Other persistence or observer behavior may affect the result, and no combined notification/cache toggle was run. Before extending this dialog, recommend checking the resulting replacement object instead of assuming that every earlier property write is preserved. This note does not claim a reproduced loss or prescribe an unverified repair. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.
