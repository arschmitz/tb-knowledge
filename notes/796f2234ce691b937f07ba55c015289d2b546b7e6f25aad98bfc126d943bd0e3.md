# Scope stale POP3 partial-message cleanup to the completed full session

EndMailDelivery calls DiscardStalePartialMessages only when m_uidlDownload is false. AbortMailDelivery does not call it. Pop3Client reaches successful delivery after its work queue is exhausted; fetching one UIDL is a different operation. This avoids using a single-message or aborted session as the inventory for deleting stale partial headers. The cleanup return is not propagated by EndMailDelivery. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
