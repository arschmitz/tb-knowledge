# Raw EWS retrieval tests do not establish offline-store integration

The accepted test_getMessage calls the EWS client and checks the RFC822 content delivered to its listener. test_saveDraft checks that one message exists after the save operation. Those assertions support raw retrieval and draft-count contracts, but they do not directly assert the store-read handoff, offline bytes, size metadata or later draft edit. For these integration changes, recommend identifying the asserted layer before treating a nearby test filename as full storage coverage. This is scoped test guidance; no test was executed. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Exchange storage test limits.
