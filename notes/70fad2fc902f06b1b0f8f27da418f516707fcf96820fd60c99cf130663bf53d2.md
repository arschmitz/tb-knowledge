# Make documented custom-element names match their registered tags

ThreadCard currently documents @tagname thread-row but registers thread-card; its card class and file agree with the latter. Recommend correcting that metadata to avoid presenting the row component as the card component. This is a scoped semantic documentation proposal supported by current registration, not an analyzer output or Storybook build failure reproduced here. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
