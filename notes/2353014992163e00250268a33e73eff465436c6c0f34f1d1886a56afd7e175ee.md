# Profile-directory case is compatibility data for legacy folder-cache keys

Normal-branding MOZ_APP_PROFILE uses Thunderbird on Windows/macOS and thunderbird on other platforms. Enterprise variants have separate names. Legacy GetFolderCacheElemFromFile passes the file persistent descriptor string to GetCacheElement. The historical upgrade report links profile-path casing changes to missed and duplicate folder-cache keys. Preserve exact stored path spelling when studying that failure. Configure/confvars precedence and filesystem normalization remain uninspected; acceptance and source identity do not prove them. No upgrade timing or runtime test ran.

Scope: Profile configuration and legacy folder cache.
