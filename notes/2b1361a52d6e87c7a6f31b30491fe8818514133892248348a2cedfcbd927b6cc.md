# A standalone eml without a folder can still receive phishing analysis

Phishing analysis treats expected folder lookup failure as an allowed folderless case. Folder-type and outgoing-folder exclusions run only if a folder was found. Other lookup errors propagate. The accepted code then requests body analysis through the current message actor with later navigation guards. The source does not make an eml automatically trusted. No live analysis was run.

Scope: message-phishing.
