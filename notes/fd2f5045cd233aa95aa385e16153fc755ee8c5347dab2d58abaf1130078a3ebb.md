# Address collection splits multiword display names at the last space

The accepted collector uses lastIndexOf(" ") to fill firstName and lastName for a newly created card or an existing blank displayName. A one-word displayName does not enter that split. This is the current local heuristic, not a complete personal-name parser or a reason to overwrite an existing chosen name. This is static source and test-code inspection.
