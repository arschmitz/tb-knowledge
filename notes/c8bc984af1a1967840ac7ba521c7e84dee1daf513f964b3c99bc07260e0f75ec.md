# Compose default identity lookup remains an internal fallback after its IDL removal

The c82061f08baf3737642ee0adbd90657020074338 patch removes nsIMsgComposeService.defaultIdentity from IDL while preserving a private C++ GetDefaultIdentity helper. The helper clears the output, propagates account lookup failure and returns NS_OK with null when no default account exists. Internal compose code still tries that fallback and handles a missing identity. The account API named in the commit is a separate access path; this removal does not authorize an unguarded defaultAccount.defaultIdentity chain or change default-account selection.

Scope: Compose service identity selection.
