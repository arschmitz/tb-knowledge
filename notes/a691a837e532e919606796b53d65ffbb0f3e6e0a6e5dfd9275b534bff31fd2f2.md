# Zoom join-link extraction preserves the non-delimited suffix after the meeting ID

The /j/ meeting pattern keeps subsequent characters until whitespace or an angle bracket, preserving pwd and other query fields. The added provider cases assert the exact string with one and two query parameters. The parser is pattern based rather than a password-field parser or URL validator; other Zoom routes and later /my support are separate. The Calendar dialog consumes the extracted string for row visibility and its saved meeting link. No meeting or UI action was run.

Scope: Calendar join link parser.
