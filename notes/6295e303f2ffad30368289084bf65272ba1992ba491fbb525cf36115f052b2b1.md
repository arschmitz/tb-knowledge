# Reset the Calendar dialog subview when replacing or clearing its event

The checked dialog calls showDefaultSubview after obtaining an event and when clearing displayed data. This prevents a later event/reset from retaining another subview; the existing manager clears its locked dimensions on return to default. The changed browser task checks both event replacement and reset routes. The patch also pairs row-class changes with fixtures, Storybook and slotted-grid CSS. These source/assertion checks do not prove focus, keyboard, zoom or assistive-technology behavior. Reviewer verify is a historical report only.

Scope: Calendar event-dialog lifecycle.
