# Check persisted folder rows as well as the public hierarchy

The move test checks getFolderParent/getFolderChildren after a move and calls checkOrdinals, which reads stored parent and ordinal values through connectionForTests. The flag test similarly verifies both getFolderFlags and the SQL row. Retain both views when testing a mutation of this cache-backed database; checking only the visible hierarchy could miss persistence drift. These tests were inspected, not run, and they do not prove restart durability or transaction rollback. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama mutation test contracts.
