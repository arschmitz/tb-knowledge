# Test registered content scripts before registration, after registration, and after unregistration

The Manifest V2 contentScripts.register test opens one content tab before registration, a second after registration, and a third after unregistration. The first and third remain unchanged; the second gets CSS and JavaScript. The test checks that unregistering does not retroactively erase JavaScript changes already made in the second page, while CSS returns to baseline when the extension unloads. This is a lifecycle contract, not just a call-success check. Related compose and message tests also distinguish existing documents from newly opened documents. The historical test uses a short timeout to assert absence of injection; current tests should be checked before reusing that timing pattern.

Scope: Extension scripting tests.
