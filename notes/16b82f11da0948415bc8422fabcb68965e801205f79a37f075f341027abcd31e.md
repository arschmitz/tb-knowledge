# Encrypted-message registration covers both message and display URI families

Entry 1205 moves OpenPGP tracking into the shared encrypted-URI service and registers both the message URI used by compose/reply consumers and the network display URL used by content policy. The accepted producer still saves both URI forms, and the service documents why they are separate key families. For this boundary, register the identities used by both consumers instead of assuming one URI spelling reaches both. This is source-traced behavior; no encrypted display, compose, reply or remote-content test was run. Full bug and review discussion remains pending.

Scope: Encrypted message URI consumers.
