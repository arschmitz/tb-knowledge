# The manual-config AccountConfig assertion has no caller-specific message

The new #updateFields assertion passes only config instanceof AccountConfig. Its actual custom assertion API accepts an error message and otherwise throws a generic programming-bug message. The same call remains in the accepted source. Add a nonempty message that states the expected AccountConfig value when changing this assertion; a nearby function comment does not supply the assertion message. This is a source diagnostic finding without a runtime failure or repair.

Scope: Account Hub manual-config assertion diagnostics.
