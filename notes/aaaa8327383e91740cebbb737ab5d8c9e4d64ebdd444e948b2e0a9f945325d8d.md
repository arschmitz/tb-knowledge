# Rust vendoring inherits upstream policy but checks the local resolved lockfile

Entry 875 imports the upstream unwanted-crate dictionary and required-override list, copies them into Thunderbird policy containers and checks the comm Rust Cargo.lock. Required overrides fail when package.get("source") is truthy; banned packages log their configured reason. Manual policy naming proposal: keep unwanted packages and packages requiring local overrides as different categories, and log the package, version and source that violated the rule. The empty local additions reserve room for Thunderbird-specific policy. The nearby comment says a source entry is expected for an in-tree override, but the actual branch rejects it; do not use that comment as the contract. This audit did not run Cargo or verify all upstream policy values.

Scope: rust-vendor-policy-categories.
