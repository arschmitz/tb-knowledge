# Clear Quick Search row storage before notifying both tree receivers

OnNewSearch removes keys, levels, flags and header hits before sending RowCountChanged(0, -oldSize). 1251 adds the matching JS tree notification beside the native tree call. Accepted about3Pane supplies an nsIMsgJSTree shim whose rowCountChanged forwards to threadTree outside a batch. Preserve both receiver paths and the mutation-before-notification order when changing this reset; the callback can observe the new row count. No new regression test is present in this landing. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
