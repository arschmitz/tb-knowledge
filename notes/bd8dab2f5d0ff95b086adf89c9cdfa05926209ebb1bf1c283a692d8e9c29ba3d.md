# Thunderbird RFC 7986 CONFERENCE read/write scope

RFC 7986 permits multiple URI-valued `CONFERENCE` lines on VEVENT/VTODO and `FEATURE`, `LABEL`, and `LANGUAGE` parameters. Current generic storage is keyed by property name, so `importUnpromotedProperties()` overwrites repeated entries; correct multi-entry support needs collection-aware import/export, cloning, recurrence, and storage changes.
