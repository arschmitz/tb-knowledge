# Treat the independent UID database API as a removed preparatory design

Entries 888 and 889 add uidOnServer and database lookup methods as preparation for separating IMAP UIDs from local message keys. Later context-only entry 5671 removes those public methods and the UID test task. The fixed accepted header and database interfaces do not contain the named API. Residual Mork tokens, an internal declaration and Panorama NOT_IMPLEMENTED stubs do not make the old public interface callable. Do not write new code against the 2024 API without checking the current interface.

Scope: mailnews/base/public.
