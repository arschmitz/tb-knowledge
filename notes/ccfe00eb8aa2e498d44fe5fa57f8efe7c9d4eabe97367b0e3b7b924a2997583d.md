# IMAP EmptyTrash return and shutdown completion are separate states

IMAP EmptyTrash checks Trash lookup and online DeleteAllMessages return before continuing local cleanup. Offline it records a delete-all operation instead. The shutdown caller starts waiting only after a successful IMAP return and clears its in-progress state from a separate URL stop listener. Returning successfully is therefore distinct from the shutdown completion signal. The local notification implementation checked here returns NS_OK; no new notification-error or remote-rollback behavior is established. No protocol or shutdown test ran.

Scope: imap-empty-trash-shutdown.
