# vCard photo URLs pass through data URIs before the new raw WebP prefix branch

photoURL first returns an existing data:image URI, including v3 cards with a mismatched binary type. Only raw binary values reach the new UklG-to-image/webp wrapping branch. The four new fixtures distinguish raw v3, two v3 URI forms and v4 URI; the test checks just the first40characters of each result. The prefix heuristic is not a complete image validator, and assigning the URL to the contact image does not prove successful decoding. No photo, importer or test runtime ran.

Scope: Address-book vCard photo representation handling.
