# The XZ migration needed a later extraction-flag correction

The 1369 Flatpak script downloads thunderbird.tar.xz but still uses tar jxf. Later context-only entry 1668 explicitly changes that extraction to tar Jxf and makes Snap use -Jxf as well. The accepted scripts retain the corrected flags. For these repackagers, pair the archive extension with the chosen decoder flag; a filename-only replacement missed this consumer. The exact later source delta supports the correction, but this batch does not establish the original failure mode, fully study entry 1668 or reproduce a failed package.
