# Use accepted current color-rule type guards before sanitizing a stylesheet

The original adapter passed every embedded sheet rule's style to sanitizeStyle. Accepted current source skips non-HTML style elements and non-CSSStyleRule objects, resolves needed variable colors from a matching element, collects those values first, and mutates only after collection. Preserve those current guards when editing this code. This is a later current comparison, not proof of a historical exception or full study of the later guard/performance changes.

Scope: Dark-reader accepted stylesheet guard refinement.
