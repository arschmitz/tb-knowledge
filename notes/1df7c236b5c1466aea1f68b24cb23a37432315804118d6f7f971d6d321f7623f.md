# Limit dark-reader mutations to unsuitable color properties

The adapter removes legacy body color/link attributes, edits only selected color/background properties, skips button nodes in the inline selector and changes dark SVG text fill to currentColor. The original browser fixture explicitly protects the button's blue/white style and checks that unrelated properties remain available. These are display mutations in the loaded message, not edits to stored MIME source. Current source broadens background/blend handling but keeps the inline button exclusion. No readability or visual contrast result was measured.

Scope: Dark-reader selective message display mutation.
