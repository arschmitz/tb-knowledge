# Translate UTF-8 folder names to the negotiated IMAP wire form

Create and rename use the original UTF-8 name when UTF8=ACCEPT is enabled and convert through UTF-16 to modified UTF-7 otherwise, then URL-escape the result. Subscription already receives the server-required modified UTF-7 or UTF-8 form and only escapes it. Preserve these distinct input contracts to avoid double conversion. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
