# Graph whole-folder mark-read asks the native caller to mark unread messages individually

The Graph whole-folder stub sends no request and returns success with UseLegacyFallback::Yes. The native receiver then enumerates unread headers and calls per-message MarkMessagesRead. Successful stub completion therefore requests further work; it does not mean remote folder items have already been marked.

Scope: Thunderbird Graph whole-folder read fallback.
