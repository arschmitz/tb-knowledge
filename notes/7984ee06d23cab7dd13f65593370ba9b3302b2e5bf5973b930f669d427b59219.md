# Hold a search-session reference across completion callbacks

InterruptSearch creates a RefPtr to itself because NotifyListenersDone can release the final external reference. The reference must outlive the completion callback and the remaining method work. Preserve this ownership guard when changing this callback path. Its historical kungFuDeathGrip identifier is observed local code, not a recommended name for new ownership variables. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Folder search callback lifetime.
