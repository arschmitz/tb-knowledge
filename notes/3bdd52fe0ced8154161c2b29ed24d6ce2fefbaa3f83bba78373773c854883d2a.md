# The outgoing username needs its own input listener

Entry 1635 replaces a repeated hostname listener with an outgoingUsername input listener. Current setup retains separate hostname, port and username handlers; hostname changes also update OAuth visibility, while username input marks the configuration changed. Preserve those field-specific event roles when wiring manual forms. The inspected outgoing component test focuses on OAuth option visibility, not a standalone username edit regression. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.
