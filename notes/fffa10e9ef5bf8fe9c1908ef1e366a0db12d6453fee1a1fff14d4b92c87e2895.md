# Pass copy-versus-move intent into the stream listener

Entry 1072 stops inferring a move from the source URL scheme. The accepted CopyMessageStreamListener receives the destination and isMove in its constructor. OnStopRequest passes NS_SUCCEEDED(aStatus) to EndCopy. Current code no longer uses the historical scriptable Init interface. Scoped syntax and API pattern: make operation intent an explicit typed constructor argument when one listener serves local and remote sources. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/base/src.
