# ESR128 retirement assigned both ESR alias families to ESR140

At the ESR 128-EOL change, removing the esr128 key and the separate esr140 divider puts both esr-latest and esr-next-latest families under esr140. The comment explicitly explains the single-surviving-ESR case. This is a historical transition: the fixed accepted mapping later separates esr140/latest and esr153/next. Preserve branch-key ownership as well as stable alias/product names when studying ESR handover. Configuration alone does not establish live service destinations or successful release execution.

Scope: Release Bouncer aliases.
