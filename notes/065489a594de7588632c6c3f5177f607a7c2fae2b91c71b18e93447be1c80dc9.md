# Quick Filter expands sender phrases through locally enumerable contact display names

For an enabled sender phrase, Quick Filter scans childCards, skips mailing lists and nonmatching display names, and collects the matching cards email addresses in a Set. It adds address Contains terms as OR clauses within the existing phrase group, alongside the original sender text. The regression uses a local Hotel Paradise contact with a different message-header name and checks the exact visible message set. It does not directly validate CardDAV synchronization or online LDAP searching. No query or browser test ran.

Scope: Quick Filter contact-name sender terms.
