# OAuth2 initialization passes already-borrowed override details directly

The incoming and outgoing AuthenticationProvider::oauth2_module methods take override_details as &IOAuth2CustomDetails. Their accepted InitFromMail and InitFromOutgoing calls pass that reference directly. Keep native status checking separate from the OAuth2-supported Boolean; a successful native call can still return no supported module. This is evidence for these receivers and parameter types, not a general rule to remove dereferences or change XPCOM ownership. Token retrieval and its listener completion occur later.

Scope: Rust / OAuth2 initialization.
