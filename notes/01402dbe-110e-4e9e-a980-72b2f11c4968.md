# Treat an outgoing server without a hostname as incomplete

An interrupted or partial setup can leave an outgoing server with no hostname. Account creation must test the optional default server, URI, and host before treating it as usable; an empty username can be valid for no-auth configurations. The 2026 follow-up also migrates abandoned unconfigured SMTP entries.

Scope: account creation.
