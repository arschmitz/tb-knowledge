# Unnamed Graph schema extraction is limited to non-delta request and response bodies

The original generator passes a schema role and delta flag into extraction. A non-delta object with properties becomes an anonymous body type only for a request or specific response, with names such as PostRequestBody or ResponseBody. Other schemas use the ordinary path, and nested anonymous objects remain explicitly unsupported. anyOf handles supported references and warns for other alternatives; ApiBody still asserts that extraction yields one top-level property. The accepted object module retains these boundaries after later enum/object refactoring. This is scoped support, not arbitrary nested or union-schema generation; no extractor or Graph request ran.

Scope: Graph OpenAPI anonymous body extraction.
