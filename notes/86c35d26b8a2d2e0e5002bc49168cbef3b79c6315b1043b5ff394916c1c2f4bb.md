# Own shared loading assets and keep packaging and consumers aligned

The first migration switched loading.png and its 2x source sets to a Gecko loading.svg. The follow-up introduced Thunderbird-owned spinning.svg and not-spinning.svg, registered them in jar packaging and changed consumers. A shared-module test helper was missed and fixed separately. Check the package registration, each active and idle asset, and the test’s expected URL together. Lower-case dash-separated SVG filenames describe this local asset family. ESR uplift of the large asset change was declined as an enhancement; dependent ESR work was told to use the existing Gecko spinner. No packaging or visual check was run.

Scope: Icon ownership and asset naming.
