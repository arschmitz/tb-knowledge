# Select the row before testing display-name updates

At revision 0e8b453a098bffeb6678d0c3b8bfc30fb8601acc, browser_preferDisplayName.js selects the target row before checking its initial state because selection invalidates that row. Preserve this setup when testing whether later display-name changes update an existing row; selecting it during the check could hide an update failure. The test also requires classic view and table layout. This is source evidence, not a reported test run or a rule for all thread-pane tests.

Scope: message browser tests.
