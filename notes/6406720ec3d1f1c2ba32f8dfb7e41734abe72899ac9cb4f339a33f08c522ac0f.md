# Respect the asyncScan return and callback boundary

The pluggable-store IDL promises that a synchronous failure produces no callbacks and that no callback runs before asyncScan returns. It holds the listener through the final onStopScan return. The empty-file branch implements delayed callbacks by dispatching a runnable with a strong listener capture. This is a scoped lifecycle contract; the checked empty branch ignores callback return values and dispatch status, so its full failure handling remains a static limit. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
