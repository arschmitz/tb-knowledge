# Compact a copy of the folder database

Before changing message store tokens, close the live folder database and work on a copy in .compact-temp. The initial compaction rewrite could modify the live .msf while still preparing a new mbox; a disk-full or interrupted run could leave the database pointing into the wrong file.

Scope: folder compaction.
