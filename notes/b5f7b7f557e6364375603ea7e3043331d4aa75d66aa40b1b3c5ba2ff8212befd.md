# Stop database initialization when a required table cannot be created

InitExistingDB checks both the table-creation result and the returned table pointer, translates either failure to NS_ERROR_FAILURE and returns before later initialization. The assigned fix prevents that error from being overwritten by a later operation. Preserve both result and non-null output checks in this table family; a successful method result alone is not the complete required-output contract. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message database table creation failures.
