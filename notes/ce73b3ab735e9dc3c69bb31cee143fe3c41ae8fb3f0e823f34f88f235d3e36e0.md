# Consolidating MV3 success cases does not preserve the removed scripting-permission rejection cases

Entry 4660 deletes standalone MV3 scripting CSS and JavaScript missing-host-permission rejection tasks. Its consolidated scripting matrices add MV3 success configurations with scripting and host_permissions, while the remaining negative tasks call the tabs API under MV2. Registration manifest-matching tests exercise another contract. Keep success coverage and API-specific rejection coverage separate when assessing this consolidation. This finding is limited to the owned test changes; it is not a claim that all repository permission coverage is absent. No test was executed.
