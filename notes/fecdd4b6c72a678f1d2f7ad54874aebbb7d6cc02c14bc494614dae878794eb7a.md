# Mailto parsing skips valueless tokens before decoding a value

The historical crash guard avoids calling strtok/decode-dependent handling for a token without an equals sign. The fixed implementation has moved to nsMsgComposeService.cpp and explicitly continues past tokens without a value separator or decoded name, rather than copying the old loop termination behavior. The inspected SMTP URL fixture directly checks URL specification and a conditional username; it does not verify every mailto field or native URI handling. Bug access is denied and restricted review content was not read. No parser test ran.

Scope: Mailto token parsing.
