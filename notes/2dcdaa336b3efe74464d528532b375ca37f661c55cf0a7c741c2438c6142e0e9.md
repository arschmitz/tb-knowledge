# Folder reset traverses descendants independently of each parent custom sort value

The historical reset skips a child whose userSortOrder is NO_SORT_VALUE before recursing into it. At fixed accepted source, clearUserSortOrder recurses first, then skips clearing that child own default value, refreshes changed rows and emits one completion event after the full walk. This preserves access to custom-sorted descendants under a parent with no custom order. Reset affects sibling order in the current hierarchy and cannot recover a prior parent. The existing browser test directly asserts its fixture row URI order after menu activation, but it does not separately assert the clean-ancestor/custom-descendant case or event count. No browser test ran.

Scope: mail folder pane manual sort reset.
