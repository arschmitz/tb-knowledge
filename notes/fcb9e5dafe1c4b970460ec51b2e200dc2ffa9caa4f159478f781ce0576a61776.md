# Keep historical IMAP host preferences separate from current offline support

The helper-removal landing still constructed host-specific disk-space and offline preference names and preserved their defaults. At the fixed accepted revision, GetOfflineSupportLevel instead propagates GetIntValue failure and replaces only UNDEFINED with REGULAR. The selected folder consumer checks the result before comparing the level. Do not reuse the historical host fallback as the current offline contract or equate disk-space support with queued offline operations. No preference matrix or server operation ran.

Scope: IMAP server preferences and folder capability.
