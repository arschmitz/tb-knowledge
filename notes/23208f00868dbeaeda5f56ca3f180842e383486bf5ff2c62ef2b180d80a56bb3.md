# S/MIME certificate testing reports a purpose-specific verifier result

The signing and encryption Test commands choose different certificate verification usages from the field ID. They resolve the configured database key, verify at current time and report success, an NSS error name/message or a numeric error. The current helper defaults flags to 0, so its call permits online checks. Buttons are enabled by a configured name, which does not establish validity. This does not test a private-key operation, identity-email match or successful message signing/encryption. Current lookup exceptions are caught; the initial landing lacked that catch. No certificate or UI test ran.

Scope: Account S/MIME certificate Test commands.
