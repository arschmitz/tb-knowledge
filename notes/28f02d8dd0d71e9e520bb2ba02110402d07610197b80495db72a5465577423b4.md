# The EmptyFolder vendor tests check XML shape separately from routing-type parsing

The same vendor update introduces EmptyFolder request/response types and two direct XML tests. One compares the serialized HardDelete request with DeleteSubFolders=true and a folder ID/change key. The other compares a Success/NoError response with the expected response structure. The called helpers perform exact equality checks. These tests do not exercise the separate SYSTEM routing-type fix or prove that either operation ran against a server.

Scope: ews-empty-folder-wire-tests.
