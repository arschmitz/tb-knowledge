# Deliver store metadata before streaming each message body

841 expands nsIStoreScanListener.onStartMessage with envelope address and date and calls it before onStartRequest. The current mbox scanner forwards the parsed fields before streaming; StoreIndexer supplies them to the parser. The store token, envelope metadata and subsequent body must refer to the same message. An empty sender or zero date remains a supported unknown value.

Scope: Message-store scan lifecycle.
