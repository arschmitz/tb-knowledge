# The Graph verifyLogon smoke test checks listener success, not rejected authentication

The initial Graph verifyLogon task waits for PromiseUrlListener. That helper resolves only for NS_OK and rejects another completion status, so the wait is a success-completion check. It is not a direct check of user fields, Authorization headers, query parameters or rejected credentials. The initial mock checks Basic credentials only when that header is supplied; absent or other schemes reach /me. The later accepted mock adds Bearer handling and version/method dispatch, but still does not reject an absent Authorization header in this dispatcher. Keep this test's local successful-connectivity coverage separate from an authentication-rejection claim.

Scope: Thunderbird Graph test-server and connectivity coverage.
