# Test local folder copy as a distinct object with an intact source

The Unicode copy test asserts that the original folder remains and the destination child is a different object, with its own file/summary under the destination .sbd directory. The test describes copyFolderLocal as synchronous with no listener callback. Preserve these scoped copy assertions rather than only checking a displayed name. This test comment does not establish every folder-copy API’s timing. Static source and test inspection only. No runtime, build, lint or live accessibility check ran.
