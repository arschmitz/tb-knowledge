# Image-overflow tests wait for document geometry and image completion before assertions

The current overflow test waits for a body-width condition and for every img.complete value, then compares scrollWidth with clientWidth and each image’s width and state. That tests the message document, rather than assuming the outer window resize event proves content layout. The fixed accepted test uses a 5000 px precondition, so the old 400 px threshold in the 1297 intermittent report is historical. This is scoped test guidance, not proof that the intermittent is resolved; no resize or image test was executed. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message image layout tests.
