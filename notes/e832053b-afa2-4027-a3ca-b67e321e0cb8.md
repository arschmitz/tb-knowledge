# Keep installer registry creation and cleanup compatible across upgrades

The 2025 ESR registry fix reviewed GeckoVersion cleanup as well as new ESR keys. The author first removed GeckoVersion because it could prevent a clean uninstall, but review and follow-up discussion found that removing the write would not remove old installations’ existing values. Shared Mozilla uninstaller cleanup would leave stale registry keys. The final accepted change kept the value and tracked the cleanup defect separately as Bug 1984509. When changing installer registry layout, check fresh install, update, uninstall, and existing keys. Do not infer that stopping a write migrates old entries.

Scope: Windows installer.
