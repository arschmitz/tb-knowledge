# Interpret mail-alert deduplication as a per-folder message-date watermark

MailNotificationManager keeps a Map from folder URI to the maximum notified message dateInSeconds. It filters NEW keys with a strict greater-than comparison and saves the watermark after the system alert call or opening the custom alert. This is not a wall-clock last-check time or a durable per-message identity set. Equal timestamps, older messages arriving later, process restarts, folder moves and overlapping async alert work need separate reasoning; source alone does not prove exactly-once delivery. Keep those limits when reviewing a deduplication claim. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Mail notification deduplication scope.
