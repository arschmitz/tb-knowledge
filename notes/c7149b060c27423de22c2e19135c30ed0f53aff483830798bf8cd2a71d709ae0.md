# MIME part-buffer reset clears the pointer and both size fields before reuse

The public source explicitly sets the freed part_buffer to nullptr and resets active length and capacity to zero. Write allocates a new memory buffer when neither memory nor file storage exists; its spill branch also nulls the freed memory pointer. Reset additionally closes streams and removes the temporary file, whereas Close preserves buffered content for readback. These are static state and ownership contracts. No accessible required discussion, reset-then-write reproduction, exploit or allocator-level runtime result is available for this audit. The accepted CheckedInt arithmetic is a later change.

Scope: MIME part buffering ownership.
