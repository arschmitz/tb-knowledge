# The discovery regression tests check a truthy config and an already-aborted generator

The Outlook-like task serves a priority fixture and a 401 Exchange response, then directly asserts that config is truthy. It does not directly assert the incoming protocol or absence of a password prompt. The abort task aborts before the first next call starts the async generator; its null assertion does not directly cover cancellation during an in-flight lookup or redirect. Browser option-count/visibility assertions are a separate mock UI layer. No test or provider flow ran.

Scope: Account discovery direct assertion coverage.
