# The drag-and-drop timeout checks special builds before the macOS fallback

The accepted browser_dragndrop.js branch requests3for coverage, ASAN, debug or TSAN, then requests2only for the remaining macOS case. A macOS debug build therefore follows the first branch. This patch changes the harness timeout request, not test actions, assertion ordering or event waits. The author calls slowness a log-based impression; no new timing or test run establishes a cure.

Scope: Tabmail browser timeout condition precedence.
