# Read displayed-notification targeting with its historical polarity

857 rejects a profile when any displayed_notifications ID has already been interacted with. The fixed accepted source rejects when any listed ID has NOT been interacted with, so all listed IDs are prerequisites. Preserve this historical/current polarity distinction when applying or reviewing the wire field. The later inversion landing and rationale were not fully studied; neither accepted code nor the name alone proves the old intent.

Scope: Notification displayed-history targeting.
