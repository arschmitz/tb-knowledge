# Folder UI locale refresh occurs after string initialization

MailGlue handles the raw locale change by initializing folder strings and view strings before emitting folder-strings-changed. Folder and thread panes listen to that later event so they consume refreshed values. The historical removal of cached pretty-name rewrites does not mean every UI can safely refresh on the original locale event. Current source preserves the ordering; no live locale switch was tested.

Scope: Locale refresh lifecycle.
