# External OAuth browser selection separates HTTP loopback eligibility from channel defaults

The original external path requires its preference and an HTTP loopback redirect. Its added preference is enabled in Nightly and disabled elsewhere, and the removed Microsoft override exposes the constructor http://localhost fallback. Accepted code later enables the pref generally and selects providers/custom schemes through later gates. Preserve these executable phases rather than copying the blanket disabled-for-now prose or claiming tested browser/passkey behavior.

Scope: OAuth browser selection and provider defaults.
