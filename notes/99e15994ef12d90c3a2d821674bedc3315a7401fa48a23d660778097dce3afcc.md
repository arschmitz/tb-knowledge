# Static CRT linkage is narrower than static library linkage

The Windows MAPI DLL uses USE_STATIC_MSVCRT to avoid depending on a CRT installation when loaded by explorer.exe. The owned RNP build integration uses the same setting only in its clang-cl branch. Recommend this exact setting for the same dependency intent after the Gecko variable rename, rather than reviving USE_STATIC_LIBS. No Windows build or loader execution, or paired Gecko build-variable consumer verification, ran. This is source and test-code inspection.
