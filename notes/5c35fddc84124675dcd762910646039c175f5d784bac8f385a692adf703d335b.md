# Mail-view names stay UTF-8 until the filter-service UTF-16 boundary

The mail-view API and mName use AUTF8String/nsCString. Localized prettyName uses the same UTF-8 representation and retains the stored-name fallback. Saving explicitly decodes the view name for UTF-16 CreateFilter; loading encodes the UTF-16 filter name back to UTF-8. JavaScript still reads prettyName for the menu label and assigns edited text through mailViewName. Keep these actual native conversion boundaries; the saved filter service did not change representation with the view API.

Scope: Mail views localization.
