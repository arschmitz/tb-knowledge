# Visited message links have a separate dark-reader color declaration

Under dark prefers-color-scheme with mail.dark-reader.enabled, the patch changes the broad anchor declaration to a:link and adds a:visited with VisitedText. The initial unvisited value is LinkText; accepted later source uses a highlight token for that branch while retaining VisitedText for visited links. This is the message-body stylesheet state contract, not a color rule for all application links or proof of the final cascade. No new test, visited-history, contrast, screenshot or rendering run was performed.

Scope: message-body-dark-reader.
