# Log an EWS fake-server exception and rethrow it to the HTTP handler

The fake Exchange server wraps its request handler so the original exception is logged before the generic HTTP-server error handling produces a response. 1020 retains throw e after the improved object log. Preserve that rethrow when improving diagnostics; returning normally would describe a different server failure path. This is test-server behavior, not a production Exchange recovery policy.

Scope: EWS fake-server diagnostic boundary.
