# Name numeric tab and window identifiers with an Id suffix in these tests

The event test renames initialTab/contentTab/calendarTab/etc. variables to ...Id and initialWindowId; those values are passed to browser.tabs APIs and compared with tabId/windowId payload fields. Scoped naming recommendation: use the Id suffix for numeric API identities and distinct names for native tab objects, DOM elements or returned API objects. Do not apply this suffix mechanically to every variable containing a tab. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: extension test naming.
