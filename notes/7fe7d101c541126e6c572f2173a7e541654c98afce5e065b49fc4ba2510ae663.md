# The direct-install policy tests assign location through the wrapped content window

The blocked and allowed direct-install tests assign the XPI URL through content.wrappedJSObject.location inside SpecialPowers.spawn. They prepare different expected popups before the navigation: policy-blocked for the nonmatching source and permissions for the matching source. The source records the test setup and its intended principal rationale. Paired Gecko wrapper behavior and a live install were not validated.

Scope: Enterprise-policy direct install test navigation.
