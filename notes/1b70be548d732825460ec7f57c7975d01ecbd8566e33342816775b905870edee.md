# Graph internet headers fill exact-name gaps after structured sent-time fields

Initial Graph sync explicitly selects InternetMessageHeaders. Reconstruction builds structured fields first and uses sentDateTime for Date, then fills only absent exact String keys from raw headers. Existing structured values and the first raw value for an absent exact name win; case variants remain separate, and HashMap iteration does not preserve the earlier insertion order. HeaderBlock stores and serializes the resulting pairs without normalization. The accepted source retains this contract with later typed access. No test changes cover duplicate/case variants or prove the reported sorting cure.

Scope: Graph message header reconstruction.
