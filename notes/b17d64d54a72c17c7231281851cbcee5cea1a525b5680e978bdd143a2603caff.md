# Preserve the calendar dialog selector and CSS naming boundary

Accepted styling targets [is="calendar-dialog"] for the customized native dialog, uses calendar-dialog-* custom tags and dashed state/role classes, while IDs such as reminderList and calendarDialogMainSubview remain lowerCamel. The file/resource remains calendarDialog.css. Recommend preserving this local mapping and logical inline/block dimensions when extending dialog styles; it does not justify renaming every existing camelCase CSS resource. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/themes/shared.
