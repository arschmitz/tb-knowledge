# The initial issuer freeze conflicts with the original Microsoft sandbox writes

This landing freezes built-in issuer objects and adds direct frozen-state tests for test.test. Its existing Microsoft sandbox branch still obtains the stored object and writes new client and endpoint fields into it. The new test.test assertions do not cover that branch. Accepted source later uses structuredClone before the sandbox writes and freezes the resulting copy. This is a bounded static phase conflict and later-source comparison; no authentication failure, thrown exception or runtime cure was reproduced.

Scope: OAuth2 provider immutability and sandbox phases.
