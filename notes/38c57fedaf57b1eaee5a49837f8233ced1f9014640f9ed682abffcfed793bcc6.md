# Use the warning text token with its warning surface

The historical dark-mode fix selected a lighter warning text color. Accepted colors now expose separate --color-text-warning-light and -dark values through one light-dark semantic token, and Account Hub warning banners consume that token with warning background/border tokens. Extend this token family rather than duplicate a light-theme literal in that banner. This is a scoped styling recommendation; no contrast ratio or forced-colors result was measured. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub warning colors.
