# The missing mbox-path directory branch does not prove a root-only invariant

The owned mbox DiscoverSubFolders comment says a missing-path directory is created only for a root folder, but the branch tests path existence and has no isServer guard. Its Local GetSubFolders caller also performs discovery before its later server-only defaults branch. Accepted0b93 replaces the root-only explanation with a virtual-folder backing-directory constraint: the empty directory is retained because a later move would fail without it. Keep that current stated workaround and the checked guard distinct from historical root-only wording. Neither source comments nor historical try reports prove all filesystem conditions or a fresh move result.

Scope: mailnews/local.
