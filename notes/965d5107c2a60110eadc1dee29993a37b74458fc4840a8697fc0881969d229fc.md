# The string-adapter patch preserves distinct raw-pointer and flat-string call roles

The owned patch uses PromiseFlatString for prompt/status nsAString arguments and dependent string adapters for raw property names, message ids, progress names, filenames and the search buffer. Actual local database receivers take nsACString names; the logging receiver still takes const nsCString&, so the patch does not establish zero-copy behavior at every call. Search appends the UTF8 conversion before freeing its UTF16 buffer. Scope these choices to the checked types and consumers; Gecko helper internals, allocation counts and native behavior were not executed.

Scope: Mailnews scoped C++ string adapter call sites.
