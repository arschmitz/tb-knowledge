# The IMAP sink completion comment describes offline finalization before body-required filters

The NormalEndMsgWriteStream comment identifies the protocol caller, the preceding message write and local database effects. Its implementation finalizes an existing offline message before the body-required filter branch. Finalization writes the store token and offline metadata on success; abort follows a separate discard path. Both caller layers ignore some returned errors, so the explanatory comment is not proof every write or filter succeeded. The interface still leaves Setup sequencing as a TODO. This is an accepted local contract example, not a full lifecycle, global comment template or new runtime behavior. No download/test ran.

Scope: Scoped sink comment and actual completion ordering.
