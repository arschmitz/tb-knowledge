# Derive thread row and header height from the selected font size

Bug 1880835 exposed clipped descenders when a user increased table-view font size. Row height in densityChange now uses ceil(1.4 times the current font size), then density padding and a minimum. Subject CSS line-height is 1.4 and its comment points to the JS calculation. Header CSS uses font-relative em sizes rounded up to whole pixels, including compact mode. Keep JS row geometry and CSS line-height in sync; check all densities, header and other table cells at larger fonts. The first landing failed tests, so fractional CSS geometry needs layout-test checks. Current checkout still uses these relationships.

Scope: Thread pane density and font sizing.
