# Move Again changed a JavaScript accessKey property before moving to Fluent

The historical initializer fixes the JavaScript property spelling to accessKey on the actual menu item. That makes the selected move/copy bundle key relevant; its English t differs from the old DTD i, and the author warns of a message-menu collision. The fixed accepted initializer uses Fluent attributes instead of this direct property write. Preserve the property-versus-localization distinction and the source phase; the one-line fix does not establish a global markup-casing or collision-free keyboard rule.
