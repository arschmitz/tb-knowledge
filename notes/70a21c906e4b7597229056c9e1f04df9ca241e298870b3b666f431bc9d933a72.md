# An abort before store install attempts to restore the original mbox

Before the listener commit callback the source is renamed to its backup and movedOriginal records successful movement. On prior failure or listener rejection, the code attempts to rename the backup back, then removes the .compacted and .compacting files. A failed restore is logged and the backup is left for recovery. This supports attempted rollback in that phase; it does not guarantee untouched data after every filesystem failure. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: mbox pre-install rollback boundary.
