# Contacts selection updates belong on the tree that dispatches selection

The contacts sidebar listens for select on gAbResultsTree, then updates the view selection and addrbook-select commands. The shared tree dispatches select from itself for immediate or delayed selection changes. The old inner-table listener and click-only command refresh could miss keyboard selection. Current command state derives To/Cc/Bcc availability from selected-card count. Manual control/test proposal for this sidebar: listen to the semantic selection event on its owner and exercise keyboard selection through the real tree. The commit supplies a manual reopen/Shift-Tab/Down/Enter recipe, but that recipe was not executed here. A mouse click test alone does not establish keyboard command state.

Scope: contacts-sidebar-accessibility.
