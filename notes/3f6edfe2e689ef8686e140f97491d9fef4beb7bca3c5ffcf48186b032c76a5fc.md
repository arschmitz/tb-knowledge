# News download localization preserves control attributes and shared number labeling

The download dialog loads messenger/news.ftl and supplies articleCount as the count argument. Radio/button/checkbox text uses label attributes, while the headers suffix uses .value. The number field and its radio share aria-labelledby="some number headers", and the suffix label controls the number input. The translator comment still calls the suffix n-headers.label; the actual attribute is .value. This is a source wiring contract, not a translated layout, focus or accessibility result.

Scope: nntp-download-headers-fluent-controls.
