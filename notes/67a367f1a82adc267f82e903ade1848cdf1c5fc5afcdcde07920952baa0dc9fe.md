# Keep the current adopt rejection guard scoped to its actual adapter

Current doAdoptItem sets callbackRan when its injected callback starts. If the provider also rejects after invoking that callback, the catch path returns instead of invoking it again. This guard is a later accepted refinement to the 2024 adapter. The inspected doModifyItem path does not contain the same guard, so do not describe duplicate completion protection as universal across both methods.

Scope: calendar/base/src.
