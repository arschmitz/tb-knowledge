# A strings-repository migration changes checkout, merge configuration and automation together

The human Git migration updates the locale checkout implementation, task configs, local helper and merge automation. Current desktop_comm_l10n prefers comm_git_repository and uses gittool with revision; the fallback uses hg and branch. Neutral config names such as comm_locales_file identify a changesets file regardless of version-control system. Current Lando bump configuration targets main and chooses shipped-locales for release branches versus all-locales by default; the original 2024 push flags have since been replaced. The graph action also tracks the new four-value fetch_graph_and_labels return. Manual proposal: audit producers, consumers and automation when migrating repository contracts; keep vcs-specific names only for values that actually select that vcs.

Scope: localization.
