# Graph request generation distinguishes bodyless methods from JSON responses

The generator selects a template from request-body presence and preserves operation.method. This enables bodyless POST /send and a generated DELETE operation with unit response types. The original client substitutes JSON null for an empty response before typed parsing. Fixed code keeps that behavior in its JSON-response helper, while the raw request method now returns Response without JSON parsing. These are separate request-body, method and response contracts. Generated DELETE code alone does not prove a wired folder-delete feature, and null substitution does not make every result type valid. No generator or HTTP run occurred.

Scope: ms_graph_tb operation body and response generation.
