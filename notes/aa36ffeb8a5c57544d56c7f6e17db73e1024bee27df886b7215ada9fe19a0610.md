# Keep MIME decoding separate from Panorama text normalization

The local Panorama add-message path parses MIME text before the per-folder adapter calls MessageDatabase.AddMessage. Database bindings then normalize the decoded fields through DatabaseUtils, which delegates to nfc_normalize. The original test directly checks author/subject text and their mime2Decoded getters across encoded/decomposed UTF-8 and selected legacy charsets. It does not directly prove messageId/tags normalization or every charset. The historical result-check request remains unapplied at the converter calls; current code adds a converter-service guard but still ignores decode results. No MIME or database test ran.

Scope: Panorama decoded text insertion.
