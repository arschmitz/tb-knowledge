# Check copied state identifiers for typos without claiming every typo is a failure

The historical forms write currentConifg rather than currentConfig. Current outgoing port adjustment still writes the misspelled public property, while its accepted state is #currentConfig and captureState calls getConfig to read current fields. This is an unresolved ownership/documentation hazard; the source does not prove that the user receives a wrong port. Proposed naming rule: use one exact state identifier and inspect every writer/reader after copying helpers. Private fields make accidental alternate public properties easier to notice.

Scope: Account Hub manual state naming.
