# Manifest OAuth providers serve Thunderbird connections for the active add-on lifetime

The manifest hook registers a provider for built-in mail, address-book and calendar authentication, then unregisters it on normal add-on shutdown. It does not supply the identity API with a provider list or implement full dynamic registration. The registry checks issuer/hostname collisions before insertion and protects built-in providers from removal. The lifecycle test checks mappings before startup, while active and after unload; no authentication ran. Fixed source later expands the validation and provider fields.

Scope: OAuth manifest provider ownership.
