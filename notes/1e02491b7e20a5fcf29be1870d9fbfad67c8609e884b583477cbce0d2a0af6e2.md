# The editorSelectAll cleanup keeps selection order and makes its receiver requirement explicit

Three selection calls now use this.editor.selectAll directly. replaceEditorText selects before overwrite padding and again before inserting final text; decryptQuote selects before inserting the decrypted parts. The removed wrapper silently skipped selection for a missing editor, while replaceEditorText already needed editor.textLength. The known compose-state listener installs the editor, but this static study does not prove every callback order or clipboard erasure. No tests change or run.

Scope: OpenPGP compose editor selection.
