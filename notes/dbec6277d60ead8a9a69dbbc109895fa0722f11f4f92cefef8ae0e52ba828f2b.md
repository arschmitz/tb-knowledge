# An attendee list does not guarantee a current-user invitation response

The dialog checks both a nonempty attendee list and the nullable getInvitedAttendee result before reading participationStatus. It hides the acceptance widget when either is absent. The helper can return null when no explicit or scheduling-supported attendee is found. Visibility assignment and the separate widget reset are distinct steps; the added guard does not itself remove status. No rendered dialog, response action or accessibility test was run.

Scope: Calendar read-dialog nullable attendee.
