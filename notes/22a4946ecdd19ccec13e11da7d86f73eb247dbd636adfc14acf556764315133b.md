# Use the configured proxy hostname and protocol login realm in mail tests

754 replaces real dynamic server ports and directly assigned passwords with the fixed test.test proxy endpoint and saved login-manager credentials. Current IMAP and POP setup retains protocol-specific login origins. The observable server endpoint and credential realm must match the NetworkTestUtils setup; the fake server listening port alone is not the account address. This does not prescribe these fake hostnames for product account settings.

Scope: Mail fake-server account setup.
