# Folder privileges open the management URL already supplied by the server

Entry 1301 removes the folder-privileges protocol operation that queried the URL again, and opens the stored URL from the properties UI. At the accepted revision, authentication can fetch server-management URLs through XServerInfo and store manageMailAccountUrl on the incoming server; the properties handler opens that server value. This is a historical-to-current ownership distinction, not proof every IMAP server advertises an admin URL. No authentication, external URL launch or folder-properties test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP folder privileges URL ownership.
