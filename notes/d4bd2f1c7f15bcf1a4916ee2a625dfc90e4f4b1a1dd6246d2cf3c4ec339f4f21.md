# Message property notifications carry old and new string values at the native boundary

The native msgPropertyChanged interface is documented for keywords and junkscore, with old/new UTF-8 string values. Folder keyword mutations notify only when a keyword was actually added or removed. Junk mutations capture the old score before writing the new score. Do not assume every arbitrary database-property write emits this notification. Keep native string values separate from the extension property bags derived from them. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: message property notifications.
