# The telemetry send test awaits each listener before replacing its deferred slot

The test creates one Promise.withResolvers slot on its shared delivery listener before each sendMailMessage call. onSendStop resolves that slot, and the loop awaits it before starting the next message. This preserves ordered completion instead of overwriting the slot while sends overlap. The listener does not check a stop status here; callback arrival and the separate telemetry assertion do not establish a fully drained server or a measured reliability improvement. No SMTP or telemetry test ran.

Scope: SMTP telemetry test completion.
