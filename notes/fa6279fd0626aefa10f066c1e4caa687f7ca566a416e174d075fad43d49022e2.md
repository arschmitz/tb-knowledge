# The disabled heading-offset CSS exception changes only test diagnostics

When dom.headingoffset.enabled is false, the CSS test adds a narrowly named html.css and Unknown pseudo-class heading exception. It does not enable the feature or change the stylesheet/parser. The existing matcher lesson explains how the source/error predicates combine; isFromDevTools is metadata rather than another ignoredError predicate. No parser test or reproduced error is established by this source-only check.

Scope: Static CSS parser-test conditional exceptions.
