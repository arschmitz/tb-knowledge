# The decryption option name states the exception to normal prompting

D211168 changed the proposed positive promptUser option to disablePrompts, with a documented false default. The author retained `options?.disablePrompts ?? false` so the instance field is always Boolean. The accepted code explicitly passes false from MimeTreeEmitter and true from ExtensionMessages. For this API, keep the negative option name and explicit caller choice, including a comment where skip/cancel and forbidden prompts share a branch. This is a scoped naming rule.

Scope: OpenPGP extension decryption naming.
