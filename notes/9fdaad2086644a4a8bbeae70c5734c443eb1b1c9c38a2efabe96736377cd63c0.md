# Builds must remain independent of graph actions

The imported Task 1 summary records an explicit user preference for independently visible, cancelable builds that continue during unrelated graph operations, including rebase and pull. Apply this requirement to Commands build orchestration: unrelated actions must neither wait for nor cancel a running build. This is a recorded product requirement, not proof that every operation currently meets it.

Scope: console builds.
