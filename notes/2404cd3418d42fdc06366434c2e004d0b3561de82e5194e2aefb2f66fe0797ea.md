# ProfileCreator prepares disk and preference input for account enumeration

ProfileCreator writes account/server preferences and raw mail storage for tests. findFolders creates mbox and Maildir input before accessing accounts.accounts, then loads the database. This is an on-disk fixture setup boundary, not a real profile-creation workflow or a guarantee that every harness has avoided the account-manager service. The initial addMailFolder accepts a name and makes empty storage; fixed source later accepts explicit summary/mbox fixtures. The module-global directory and static key are shared state, so this evidence does not establish isolated concurrent creators. No profile-loading test ran.

Scope: ProfileCreator fixture phase.
