# Style the native dark-toggle checkbox without replacing its input semantics

The checked header control is an input type=checkbox inside a label with for=disableDarkReader. Shared CSS draws the track/thumb, supplies focus-visible outline and only enables transitions when reduced motion is not requested. Retain native keyboard/checked behavior when extending this shared widget. The Fluent message currently supplies a title; computed accessible name, right-to-left thumb travel and forced-color rendering still need UI checks. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.

Scope: mail/base/content.
