# Gloda pauses indexing while a folder summary is rebuilt

Repair start purges relevant jobs, invalidates old message indexing and sets an in-memory rebuildingFolderSummary flag. The indexer avoids rebuilding folders. FolderLoaded clears the flag, marks the folder filthy, persists dirty status and requests a sweep. This flag is not a persistent restart-recovery protocol. Landed accessor JSDoc implements the review request for parameter/return details. No direct regression test or runtime repair was executed.

Scope: Gloda repair lifecycle.
