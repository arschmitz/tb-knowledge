# The about:addons port replaces script-global assumptions with explicit imports and element lookup

The landing imports utilities and retrieves element constructors through customElements after definition. It uses the permission-list constructor fragment instead of an assumed global importTemplate. This only identifies the local adaptation; upstream module consumers and realm behavior are not verified. Accepted code later imports utilities with global:current and uses AddonCard.setEmbedderHooks for warning messages, a separate integration phase. The original review was not accepted at landing and its suppression test was disabled. No live extension behavior or passing test is established.

Scope: Thunderbird about:addons integration.
