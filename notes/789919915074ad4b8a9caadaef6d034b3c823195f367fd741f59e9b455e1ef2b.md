# Standalone storage calendars own their batch and load notifications

Storage add/modify checks !mSuperCalendar. An unwrapped storage calendar opens a batch around its item notification, closes that batch, then sends onLoad. Wrapped storage leaves the outer cached calendar responsible. BaseClass stores that wrapper and only emits start/end notifications at outer batch-count boundaries. This is an observer contract, not a database transaction or a reproduced alarm result.

Scope: Storage Calendar observer notifications.
