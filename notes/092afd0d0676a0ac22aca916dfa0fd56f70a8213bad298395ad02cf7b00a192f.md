# HeaderReader raw values and message identification normalization have different contracts

HeaderReader skips one space or tab after the colon and exposes the remaining raw header value. The historical Message-Id fix separately trims surrounding space/tab before removing angle brackets. The fixed accepted ParseRawMailHeaders now passes the raw identification value to ParseIdentificationFields and takes the first nonempty ID. That later helper normalizes CR/LF/tab to spaces, splits tokens, strips paired optional brackets and drops empty tokens; it explicitly disclaims exact RFC5322 compliance. Preserve reader extraction and field-specific normalization as separate steps. No parser or regression test ran.

Scope: mail header parsing.
