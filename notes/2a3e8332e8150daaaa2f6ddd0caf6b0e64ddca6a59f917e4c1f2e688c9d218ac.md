# Aggregate folder snapshots before setting a labeled value

reportAccountSizes accumulates message counts and bytes in separate Maps across all folders, then sets each labeled snapshot and Total. Calling set per folder would overwrite the earlier folder of the same type. This was a specific accepted review correction. Skip a deferred POP account to avoid counting the destination account twice. Count messages with getTotalMessages(false), which does not recursively include descendants again. This function intentionally uses the listed special flags and Other; Virtual exists in the registry but is absent from this function’s key list.

Scope: Folder accounting.
