# Initialize the filter-run output before any exit used by IMAP notification logic

CallFilterPlugins initializes aFiltersRun to false immediately after validating the output pointer. The IMAP completion paths read filtersRun to decide whether to set the new-mail biff state. The assigned repair moved initialization above earlier work so those exits leave a defined value. Preserve that out-parameter boundary; the later true assignment precedes classification and does not itself prove the classifier succeeded. Earlier POP ownership knowledge remains separate. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP filter output and notification ownership.
