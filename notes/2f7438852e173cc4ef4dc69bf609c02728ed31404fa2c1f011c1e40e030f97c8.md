# The EWS advanced-configuration scenario explicitly enables its expected Graph option

This task selects EWS but expects Graph to be one of four visible configuration options. The owned follow-up pushes mail.graph.enabled=true before opening the dialog and pops it after account cleanup, so a build-dependent default does not remove an expected option. The actual helper checks option visibility/count/selection; the account wait checks an identity email. Those checks do not establish an authenticated EWS or Graph session. The accepted task later adds a separate manual-config preference condition; that is not part of this original patch.

Scope: Account Hub advanced-configuration browser test.
