# Complete cached writes before reporting operation completion

CalCachedCalendar cannot use only provider observer forwarding: provider completion may precede its onAddItem or onModifyItem observer. It performs the cache write first and then calls the listener, keeping local change events before provider endBatch. Preserve that ordering when changing adopt or modify adapters. The provider tests wait for add or modify observer promises after the operation, but no focused failure-callback test was added in entry 631.

Scope: calendar/base/src.
