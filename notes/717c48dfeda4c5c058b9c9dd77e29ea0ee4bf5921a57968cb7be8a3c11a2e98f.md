# Extend qualified Ci enum spelling in search and SMTP settings

The two self-reviewed 2024 cleanups remove aliases for nsMsgFilterAction, nsMsgAuthMethod and nsMsgSocketType. Accepted searchWidgets and am-smtp use Ci.<interface>.<member> directly. This extends the earlier search-code qualification lesson with the filter-action and SMTP settings families. Keep the interface visible at these enum uses. It is a supported scoped spelling pattern, not a rule that every Thunderbird alias is forbidden.

Scope: mailnews/search/content.
