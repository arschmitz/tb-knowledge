# System alert duration controls are separate from content preferences

The original customization patch disables totalOpenTime and its two labels when system alerts are active. The fixed accepted code hides those elements instead and keeps separate subject, sender and preview preferences. Review explicitly corrects the claim that Windows notifications cannot show a preview. Check the exact control and current state before documenting platform limits; hidden, disabled and unsupported mean different things. No native notification rendering was tested.

Scope: Notification preference controls.
