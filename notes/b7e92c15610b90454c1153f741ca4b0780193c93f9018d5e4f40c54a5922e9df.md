# Initialize the common decrypt and verify result per operation

DecryptVerifyResult defines the shared status fields and fresh nested signature and recipient objects. decryptArray and verifyDetached each construct a new result. Fresh construction supplies per-instance default nested fields, but decryptArray assigns options.encToDetails when alreadyDecrypted is true. Preserve that deliberate ownership exception; this class is the local shared result contract, not a rule that every result always isolates recipient details or that every return object needs a class. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
