# The experimental Calendar read-dialog setting is included only outside ESR

The original change encloses the experimental read-dialog checkbox block in #ifndef MOZ_ESR. Neighboring settings remain outside the condition, and the dialog preference stays registered. The fixed accepted markup retains this channel condition; its later optional-container check and feature-offer preference are a separate hiding layer. The patch changes the settings entry, not the whole dialog implementation. No ESR build or accessibility run was performed.

Scope: Calendar general preferences markup.
