# Keep Filelink placeholder byte-size assertions separate from uploaded file size

The compose caller serializes generated cloud-attachment HTML into htmlAnnotation and computes cloudHtmlFileSize from its UTF-8 TextEncoder byte length. The 1351 tests change htmlSize expectations when inline styles/icon markup change, while the uploaded file size and contentLocation remain separate fields. Update the generated-placeholder expectation to match the actual serialized markup; do not treat htmlSize as rendered geometry or the uploaded file byte size. The particular historical byte values are not universal constants. Static source/test reading only; no test ran.

Scope: Filelink generated placeholder and tests.
