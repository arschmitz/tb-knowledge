# Exclude the specialized autoscroller from historical generic panel theming

The historical patch narrows :is(panel, menupopup)::part(content) with :not(.autoscroller), so the generic panel colors do not override that specialized popup. Current messenger.css no longer contains that generic selector; the inspected notification-popup styling is explicitly scoped by ID. Keep the historical selector correction distinct from current CSS policy. No autoscroll rendering or contrast test ran. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mail panel styling.
