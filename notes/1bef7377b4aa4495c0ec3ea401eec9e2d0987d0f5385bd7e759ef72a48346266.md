# Show local-transfer status before an allowed null output-stream return

BeginCopy reports status for index values below 2 before initializing/using an output stream. Its comment explains IMAP transfers start at 0 while cross-account local multi-message transfers can start at 1. A null output stream is an allowed branch for IMAP without offline storage, not automatically an error. Keep status placement separate from OnProgress and stream readiness; no online/offline move was executed. This is static source and test-code inspection.
