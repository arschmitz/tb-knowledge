# Downloads script migration keeps its document loader and build declaration aligned

The downloads migration changes the deferred script URL and adds the same path to MOZ_SRC_FILES while removing its old jar mapping. The XHTML document stays in messenger.jar, and global overlay scripts keep their chrome addresses. The .js script does not become an ES module just because its address changes. Its document CSP already admits moz-src. This exact packaging relationship is not a successful build or runtime resolution result. No downloads test ran.

Scope: aboutDownloads script loader, MOZ_SRC_FILES and remaining jar document.
