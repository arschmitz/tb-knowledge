# Account Hub step subheaders prefer a Fluent ID and reveal a dedicated hidden heading

The step checks subheader-id first, assigns it to the subheader slot content, reveals the header h2 and returns before the raw subheader-text branch. With only raw text it assigns textContent and reveals the same hidden heading. Current tests cover ID and text cases separately plus hidden-to-visible behavior. They do not directly assert both-attribute precedence or mutation behavior, and the observed attribute list omits the two subheader attributes. This is the checked initialization/heading contract, not a promise of dynamic updates or successful accessibility announcements. Original tests were deferred; no test or UI ran.

Scope: Account Hub subheader producer, slot and tests.
