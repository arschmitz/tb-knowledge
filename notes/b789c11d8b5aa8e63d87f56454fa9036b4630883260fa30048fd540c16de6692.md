# Wait for observable layout state after resizing a test window

1021 adds an event-loop tick after the native resize event before reading message layout. The accepted test also waits until the content width is below the large fixture width and all images complete. A resize event alone is not an assertion that content measurements and image loading are ready. Preserve the dimensions and completion conditions required by this test rather than adding a longer arbitrary delay. This is a source test design lesson, not a measured rendering result.

Scope: Image sizing test layout waits.
