# The current EWS header block preserves the Reply-To recipient collection

The accepted EWS Message represents reply_to as Option<ArrayOfRecipients>. The active EWS sync path calls headerblock::extract_headers, whose core-field converter formats the collection and joins recipient strings with comma-space into REPLY_TO. Keep that current header-block route separate from the historical MessageHeaders-to-database-property adapter; the retained shared populate_from_message_headers definition has no caller in the bounded current Rust search. This source tracing does not prove all malformed-address behavior, native database storage, message download, or rendered reply results.

Scope: EWS / message header conversion.
