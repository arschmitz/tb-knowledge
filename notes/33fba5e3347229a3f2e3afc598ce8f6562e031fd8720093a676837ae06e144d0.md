# Treat an absent virtualFolders.dat as a normal first-profile state

Current LoadVirtualFolders propagates an Exists check failure, but when the file is absent it marks virtual folders loaded and returns NS_OK. Existing-file loading still initializes real account subfolders before reconstructing virtual folders and their search scopes. Current Panorama uses an earlier separate skip branch; the missing-file rule describes the legacy loader. Do not turn a not-yet-created optional profile file into a startup error. No first-profile runtime or file-error experiment was run.

Scope: mailnews/base/src.
