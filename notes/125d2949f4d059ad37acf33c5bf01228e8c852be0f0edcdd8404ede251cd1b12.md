# Iterate backward when removing MIME metadata from a live list

MIME refresh removal records the live meta list length and visits Item(i - 1) from the end toward zero before removing a matching node. This avoids shifting later unvisited entries when removing from this list. Retain the reverse traversal or another mutation-safe approach in this specific DOM cleanup. This is a source-derived manual iteration recommendation, not a project-wide requirement to reverse all loops. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: MIME mutation-safe list traversal.
