# Find Next formats the no-match alert asynchronously while its callers ignore the result

The Find Next handler returns early for a found match. For no match it awaits not-found-alert-title and not-found-alert-message through document.l10n.formatValues, alerts and then selects/focuses the find input. The historical and fixed dialogaccept/button callers do not branch on the old Boolean result; dialogaccept separately prevents closing. The dialog now links EdReplace.ftl and removes the old findBundle. This is the local async/result contract, not proof of a no-match prompt, focus behavior or locale migration run.

Scope: Compose Find and Replace no-match localization.
