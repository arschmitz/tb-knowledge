# Set test server properties before setting the cached password

The QR account helper sets the outgoing username, host, port and identity link, adds a Login Manager record, then sets outgoing.password last because earlier property setters can clear it. The stored-password test deliberately empties that cache to exercise retrieval rather than the convenient setup path. Scoped test setup rule: order properties according to their side effects and include a case that removes the cache when persistence is the behavior being tested. The helper’s async return type comment is not adopted as accurate documentation.

Scope: mail/base/test.
