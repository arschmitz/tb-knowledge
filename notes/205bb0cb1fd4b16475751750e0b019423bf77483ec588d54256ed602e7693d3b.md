# A private folder marker bounds the copy-move blanket implementation

The patch introduces a local FolderOperation marker for MoveFolder and CopyFolder before implementing CopyMoveOperation for that marker. The nearby comment explains that the private trait avoids conflicts with implementations upstream crates could add. The same bounded shape remains accepted. This is a local Rust trait-coherence solution with a reason comment, not a naming or marker-trait rule for other code. No compiler experiment ran.

Scope: ews-copy-move-traits.
