# Keep Autodiscover transport secure unless the response explicitly disables it

Exchange Autodiscover must default missing or unrecognized SSL/Encryption values to a secure connection. Explicit SSL off or Encryption none chooses plaintext. When secure, ports143/110/25/587 select STARTTLS and other ports select implicit SSL/TLS. This fixed misconfigured SSL=yes responses becoming plaintext. No server reproduction or runtime security check was run.

Scope: account-creation.
