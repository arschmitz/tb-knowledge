# Mbox MsgOffset is relative to the stream position at construction

The 1287 header clarification says MsgOffset identifies the From separator relative to the underlying position when MboxMsgInputStream was constructed. A prior seek becomes offset zero for that object. For callers of this API, preserve the base position when converting it to an absolute store token. This is scoped offset guidance, not a statement that every mailbox offset uses the same coordinate system. The documentation and relevant store diff were read; no seek or token conversion was executed. Full Bugzilla and Phabricator discussion remains pending.

Scope: Mbox stream offset coordinates.
