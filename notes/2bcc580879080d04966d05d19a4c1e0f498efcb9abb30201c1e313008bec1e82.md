# Do not use equal timezone rules alone to reject a timezone as unknown

The ICU workaround notes that Etc/Unknown and GMT can have the same rules. It creates a separate TimeZone and checks its actual ID before rejecting an unrecognized requested ID; an explicit Etc/Unknown request is allowed. Preserve this identity check if simplifying the workaround. The upstream issue link is context in source and was not read, so the library rationale beyond the comment remains unverified.
