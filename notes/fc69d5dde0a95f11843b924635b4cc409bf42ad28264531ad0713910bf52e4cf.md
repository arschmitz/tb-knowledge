# Require an identity before opening compose and focus account setup on failure

The service uses an explicit identity or the default identity. If neither exists, it focuses the most recent mail:3pane window and returns NS_ERROR_ABORT if no outer window is available. The command-line -compose route first opens the main window, then checks defaultAccount before opening compose. Current OpenComposeWindowWithParams also retains its params null guard; the original and reland removed it. Preserve the separate JS account check and C++ identity check. They are not the same predicate. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/compose/no-identity-routing.
