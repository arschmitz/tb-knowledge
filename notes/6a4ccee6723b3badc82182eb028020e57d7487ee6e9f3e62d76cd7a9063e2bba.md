# Context-menu selection and keyboard anchoring follow different paths

A right-click can temporarily override selection for an unselected row and opens at screen coordinates. A non-right-click requires an existing selection, scrolls the current row into view and opens relative to that row or its more button. The current test asserts that the off-screen row is present once the popup is shown. Keyboard focus, screen-reader announcements and every scroll event ordering remain untested. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/base/content.
