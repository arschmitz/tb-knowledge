# Disable the complete Account Hub subview action set during loading

The current automatic email form disabled setter disables its input elements and both manual/provider actions. The outgoing form setter disables hostname, port, connection security, authentication and advanced configuration controls. Treat disabled as a subview contract that includes its actions, not just text fields. Extending a subview should include any new action that can race with an active operation. This is a scoped recommendation, not proof that all Account Hub subviews have been audited. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Account Hub subview controls.
