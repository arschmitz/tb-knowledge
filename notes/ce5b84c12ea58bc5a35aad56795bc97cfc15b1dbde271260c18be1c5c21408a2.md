# The background fixture does not cover the earlier-return gradient state

sanitizeStyle has an early text-color branch before its final gradient cleanup. If background is absent or none and background-color is absent or transparent, that branch returns first. The new fixture uses opaque yellow background shorthands for both blocks, so its inline-property assertions do not directly cover an image-only/gradient-only longhand input or the early-return path. This is a static branch and fixture limit; no CSS parser state or visual failure was reproduced.

Scope: Dark-reader test branch coverage.
