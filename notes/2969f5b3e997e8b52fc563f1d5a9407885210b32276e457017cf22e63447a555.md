# Separate obsolete IMAP wrapper names from live escaping

The removed EscapeImapSearchProtocol wrapper only copied its input. The selected caller used false for reallyDredd, so the cleanup removes that unused branch and parameter. Current EncodeImapTerm still handles quotes and backslashes, keyword quoting and byte-length literals; EncodeImap retains temporary-term cleanup and UNDELETED construction. Do not infer loss of real escaping from removal of the misleading wrapper name. The caller search was bounded to mailnews/search; no external consumer or server behavior was proved. No IMAP search ran.

Scope: IMAP search encoder cleanup.
