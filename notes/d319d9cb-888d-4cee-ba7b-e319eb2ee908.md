# Recreate ordinary single-folder views for unsupported flag transitions

The DBViewWrapper flag setter recreates a nonvirtual single-folder view when grouped, unread-only, or show-ignored bits change; that view cannot apply those transitions in place. Cross-folder virtual and quick-search views can accept their flag changes, with the search backend rebuilding when necessary. The ordinary single-folder path still reapplies its sort after setting other flags. The distinction remains in the current checkout. A wrapper change must keep these per-view capabilities separate rather than assuming all folder views handle flags alike.

Scope: Message view wrapper.

Paths:

- `mail/modules/DBViewWrapper.sys.mjs`
