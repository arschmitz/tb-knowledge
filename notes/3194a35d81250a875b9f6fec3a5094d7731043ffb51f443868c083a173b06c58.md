# Saved-search old-state matching needs the replayed header flags

The saved-search listener matches the new header, sets old flags to test the old match, restores new flags even if matching fails, and clears scopes before returning an error. The search term reads header GetFlags, and its status branch consumes those flags. DB read-state calculation therefore needs the current header flags rather than an independently updated newsrc set. This explains the NNTP raw-header getter and separate set-update roles. Preserve restoration and scope cleanup if using early returns. No count or search test ran.

Scope: Scoped virtual-folder match and read-query state.
