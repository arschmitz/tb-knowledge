# A private JavaScript method can need an explicit documentation name

Entry 868 temporarily excludes NotificationManager from JSDoc parsing. Entry 885 removes that exclusion and puts @name NotificationManager.isNotificationWithUI plus @private on the actual static #isNotificationWithUI method. Current code retains both the parser workaround and language-level private syntax. Manual JSDoc proposal for this parser boundary: provide the qualified documentation name when required, retain @private and explain the workaround beside the method. This does not establish a general ban on private methods or a need to annotate every one. The method distinguishes visible notifications from donation_browser and donation_tab; those types open a website instead of emitting a new-notification UI event. JSDoc generation was not run.

Scope: jsdoc-private-method-name.
