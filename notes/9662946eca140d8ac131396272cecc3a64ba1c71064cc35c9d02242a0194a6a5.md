# Global popup IDs identify one shared notification list

GlobalPopupNotifications keeps popupNotificationsMap at module scope. getNotification(id) returns the first matching ID or null, and show removes that matching notification before adding its replacement. The browser helper explicitly says Thunderbird does not store notifications per browser. The remaining browser/ID-pair sentence in getNotification is stale relative to this implementation. Manual documentation proposal for this module: describe the actual ID lookup, shared storage and replacement behavior, and document null separately from a missing property. Correct type tags alone do not establish that the prose is correct. Do not infer all browser or window lifecycle behavior from this lookup.

Scope: global-popup.
