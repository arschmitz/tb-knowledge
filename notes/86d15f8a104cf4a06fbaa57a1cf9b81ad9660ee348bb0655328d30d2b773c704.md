# Use an available identity when OpenPGP key extraction fails

747 logs the requested key ID in the explicit-ID loop rather than accessing a partially initialized keyObj. The iterator loop derives an ID from the native handle. Both loops skip an extraction failure and destroy the native key handle in finally. Current code also logs the exception. A diagnostic should avoid introducing another property-access failure while describing the original failure. These guards and cleanup were read, without a native RNP fault-injection run.

Scope: OpenPGP key extraction failures.
