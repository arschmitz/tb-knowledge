# Identify grouped dummy rows from row flags during view transitions

isGroupedByHeaderAtIndex now guards a missing view and an out-of-range index, then reads the row Dummy flag. It does not require the wrapper still to report grouped sorting. saveSelection excludes these rows from both the current URI and the selected URI list. Otherwise a group header key can represent its first member and restore a message that was never selected. The regression selects row zero, changes grouped sorting and checks no selection survives. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/modules/DBViewWrapper.sys.mjs.
