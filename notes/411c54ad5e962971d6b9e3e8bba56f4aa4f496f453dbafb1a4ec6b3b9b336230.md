# Return a created initialized optional object rather than hide initialization behind bool

D210712 accepted a provider factory returning Result<Option<RefPtr<msgIOAuth2Module>>,nsresult>. None means unsupported domain, Err means failed operation, Some contains initialized module. Current provider retains this signature and then_some for supported result. The review allowed a small duplicate creation sequence to make consumers handle success explicitly. Do not expose preference branch details or parameters invalid for different auth methods merely to deduplicate lines.

Scope: rust/protocol_shared/src.
