# Release type and update channel are different selector inputs

Use the selector available for the artifact/task context. Product-details release-note entries select by release-types; an initial ESR update-channel condition broke beta release tasks and was replaced with release-types. Current show-url entries can require both release-types and update-channel for client update behavior. Do not substitute one field for the other from a superficially similar YAML block. Check both beta and ESR selection contexts when changing these URLs.
