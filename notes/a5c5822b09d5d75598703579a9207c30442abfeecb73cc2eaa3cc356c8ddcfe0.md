# Handle absent calendar discovery headers without masking the result

761 uses optional chaining for a missing Content-Type and accepts calendar evidence from known content types, an .ics Content-Disposition or a VCALENDAR body. This is a permissive discovery predicate, not a strict content-type validator. CalDAV detection also checks firstProps before reading its authentication error so an unparsed response does not become a different property-access exception. Proposed scoped syntax rule: guard genuinely optional response data at its access boundary and document the fallback evidence.

Scope: Calendar provider detection response guards.
