# Keep protocol log correlation and payload output distinct

The historical EWS logger introduced C: for client payloads and S: for server payloads. Current shared send_request logs operation ID/name and response status, while request and response bodies are logged only when THUNDERBIRD_LOG_NETWORK_PAYLOADS is present. The gate checks presence, not a particular value, and current payload conversion uses from_utf8_lossy. Preserve those distinctions when extending this shared request logger. Historical MOZ_LOG_FILE and release compile-level caveats are commit-reported and were not verified as current behavior. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Exchange protocol logging.
