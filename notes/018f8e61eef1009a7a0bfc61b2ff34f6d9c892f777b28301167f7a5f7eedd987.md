# The first Graph path generator emits GET while only recognizing other methods

The first path generator recognizes five HTTP method names during extraction, but its emission branch handles only Get and skips other methods. It stores the request body as _body without using it. The generated /me Get implements the existing unit-body request API and typed $select support. Success and body metadata guide code generation; they do not implement HTTP dispatch or runtime response validation. PATCH generation is a separate later entry.

Scope: Graph API code generation.
