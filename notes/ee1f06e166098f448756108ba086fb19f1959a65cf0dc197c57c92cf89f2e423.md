# Route fake IMAP account operations to that account's server instance

Entry2125 replaces the one shared fake IMAP server with a class and maps each incoming-server key to its own instance. Account options reach the constructor through both protocol wrapper heads; handler creation applies options.extensions names to that instance. Message injection looks up the server by folder.server.key before adding messages and awaiting its URL listener. Preserve receiver and key identity here. This is test configuration; no dedicated non-default extension-combination assertion is added in this patch, and no protocol test was executed.

Scope: Extension xpcshell fake IMAP server ownership.
