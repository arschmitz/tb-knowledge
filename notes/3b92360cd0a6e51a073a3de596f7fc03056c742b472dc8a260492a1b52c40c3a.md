# OAuth ignores a late cancelled result after accepting an authorization code

The accepted OAuth response sets _authorizationReceived before token exchange. onAuthorizationFailed ignores only cancelled results once that flag is true, so a verifier teardown does not overwrite the result through that path. A new requestAuthorization resets the flag; token settlement does not clear it in the inspected code. Other failure reasons and token-fetch errors still use their own settlement paths. This guard is a source contract, not proof the granular-scope retry test or a macOS hang now passes.

Scope: OAuth authorization-result cancellation.
