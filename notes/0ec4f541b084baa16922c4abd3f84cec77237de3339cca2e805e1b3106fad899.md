# Keep vendor warning exceptions attached to the affected source files

The RNP integration adds -Wno-unsafe-buffer-usage and -Wno-extra-semi-stmt to sha1.c, and only the first flag to ubc_check.c. The fixed accepted build still uses these per-source flags. Manual build review proposal for this integration: put a justified vendor exception on the affected SOURCES entry; do not widen it to the whole library merely because one imported file needs it. The niwcompat import itself is excluded as bulk vendor code and is not evidence of Thunderbird C style. No compiler run or proof of warning behavior is claimed.

Scope: build.
