# Shrink-to-fit image width uses the viewport allowance while image state remains a separate actor contract

The owned CSS replaces the 100% maximum on img[shrinktofit] with a small-viewport inline-size calculation minus 16px and the scrollbar environment value. The zoomed overflowing branch separately removes the maximum. Current message-actor clicks and resize handling maintain the state attributes, so CSS sizing and state decisions are separate contracts. The original test's 460-pixel outer resize does not guarantee its 400-pixel body requirement; accepted tests later wait for actual body geometry. No all-layout overflow cure or rendered result is established.

Scope: Message inline image sizing.
