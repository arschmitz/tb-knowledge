# Encode edited raw headers before serialization and keep MIME line endings

The serializer title-cases header names, writes every array entry, separates headers and body with CRLF, and uses the boundary parameter when writing nested parts. It does not apply header or body encoding. The test calls encodeMimeHeader before adding its new header. That utility accounts for headerName.length+2 and MIME_ENCODED_WORD_SIZE when folding. Manual raw-MIME proposal: preserve binary content, CRLF and pre-encoded values at this boundary rather than treating the raw string as ordinary Unicode text. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/raw-mime-syntax.
