# Test folder repair by removing the derived index and reparsing

844 stores dateless messages, captures dates, closes and removes the .msf index, awaits parseFolder, and compares the rebuilt dates. This checks persistence through rebuilding derived database state, rather than merely rereading the existing database. The source selects the configured default local store; it does not explicitly run both maildir and mbox in this test. No repair test ran in this study.
