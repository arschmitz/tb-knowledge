# Expose Account Hub input errors on the input itself

The current auto-form keeps decorative icon alt text empty and links each input to an error span with aria-errormessage. checkValidEmailForm sets aria-invalid only for invalid inputs that were touched or when errors are requested. Its test distinguishes an invalid touched email from an untouched empty name. This is newer accepted behavior than the icon-only 2024 styling. Preserve the input error relationship instead of communicating error state only through icon color. No screen-reader announcement was checked.

Scope: mail/components/accountcreation.
