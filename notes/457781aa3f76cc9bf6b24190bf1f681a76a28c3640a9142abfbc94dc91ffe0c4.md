# The narrowed Saved Passwords patch applies the surface token only to its root

The final patch gives #SignonViewerDialog background-color: var(--color-surface-base). The Saved Passwords HTML root has that ID and loads passwordmgr.css, so the rule has a concrete consumer. The final source does not implement the earlier broader settings/sidebar token proposal. This establishes selector and stylesheet scope, not a measured dark-theme, accent-color, contrast or accessibility result.

Scope: Saved Passwords dialog surface background.
