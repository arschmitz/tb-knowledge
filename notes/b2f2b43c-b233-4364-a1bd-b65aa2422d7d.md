# Keep tabs injection methods available only through Manifest V2

The second Bug 1896217 commit adds max_manifest_version: 2 to tabs.executeScript, tabs.insertCSS, and tabs.removeCSS in the schema, while new Manifest V3 tests use the scripting API. Manifest V2 still has tests for both the old tabs methods and scripting. D210103 was accepted without an inline code change request. Current tabs.json retains the version bounds. When moving an extension API, express version support in the schema and test the old and new manifest versions; avoid using the old methods in new MV3 examples.

Scope: WebExtension API versioning.
