# Update all toolchain references as a versioned set

The Clang 18 port renamed linux and Windows toolchain jobs and all fetched compiler-rt platform variants; kind.yml also changed reference-jobs. The linked -no-pie flag patch followed because Clang 18 changed accepted linker syntax. A partial version bump would leave jobs fetching mismatched artifacts. This exact Clang 18 patch was later backed out when the upstream Gecko patch was backed out, then re-landed later. Current checkout uses Clang 22, so this is an architecture and rollout lesson, not a current version rule.

Scope: Build toolchain.
