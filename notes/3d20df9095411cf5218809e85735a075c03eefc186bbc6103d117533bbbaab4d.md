# Cross-folder operations must keep each message attached to its source folder

649 groups selected message headers by their actual folder before deletion, copying or moving. m_folders tracks the source folder of each row; m_uniqueFoldersSelected and m_hdrsForEachFolder form parallel operation state. A cross-folder view cannot safely apply one displayed folder or one account setting to every selected message. Current grouping still derives the folder from each header. The focused test excerpt checked removal beneath a dummy thread row, not a mixed-account deletion policy matrix.

Scope: Cross-folder message operations.
