# Read locale-dependent week preferences after locale defaults are set

Entry 1051 moves weekStartOffset from connectedCallback to ensureInitialized. Its commit explains that attachment can happen too early and tab restoration needs the later phase. Current startup sets locale default preferences before loading the Calendar manager; switching views calls ensureInitialized before goToDay. setLocaleDefaultPreferences converts firstDayOfWeek from Monday=1 through Sunday=7 into Sunday=0 through Saturday=6. Read dependent preferences at the phase where their defaults are ready, not merely when a DOM node is attached. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: calendar/view/locale-initialization.
