# Read the early return in the shared mail-view test helpers

The extracted ensure_cards_view(doc) and ensure_table_view(doc) helpers find the current about3Pane through the passed document. If the row type already matches, they return before changing the layout preferences. Otherwise they register the rows-attribute wait before setting the view/layout preferences, then wait for the attribute and one animation frame. Therefore they do not always force vertical/classic layout, and completion does not mean every message or unrelated async task finished. This is the checked browser-test helper contract, not a production wait rule. Bug comment4 is unavailable; no full audit or browser test execution.

Scope: Browser test view-helper completion.
