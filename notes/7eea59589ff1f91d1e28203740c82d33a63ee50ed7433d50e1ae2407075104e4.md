# Linux cloud-menu icon visibility is scoped to provider radio items

The Linux override selects menuitem[name="context_convertCloud"] > .menu-icon and forces visibility for those provider choices. It removes the former broad parent-menu selectors, so this patch does not supply an image for the top-level Filelink menu. The exact markup passes the radio-group name and the generator assigns it to provider items. Keep this theme exception tied to those consumers; no general important or menu-icon rule follows. No theme or compose UI was rendered.

Scope: Scoped composer Linux CSS override.
