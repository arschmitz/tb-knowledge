# Shared tree-row connection no longer assigns selection attributes automatically

Connecting the shared table row now records its list/view without setting aria-selected. The explicit selected setter still writes row/cell selection attributes when a selection-aware caller uses it. Current-row updates use ariaActiveDescendantElement, clearing before reassignment; the base cell-focus path has a separate cell reference. Keep those source owners distinct from native ARIA reflection or spoken-output guarantees.

Scope: Tree selection ARIA ownership.
