# Maintain pending IMAP counts independently of a visible folder

Successful online copy and append paths update pending counts without the removed window criterion. The current helper counts messages, handles a single copied file specially and adjusts unread counts before SummaryChanged. The draft-append completion path updates the folder through its listener. Preserve those database/server-count actions when changing background operations; failure paths do not share every successful update. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP background count updates.
