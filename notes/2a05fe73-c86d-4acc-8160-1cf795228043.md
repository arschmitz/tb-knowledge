# Name Sync tests by store or tracker and cover unknown, deleted, and encrypted records

The rebuild splits xpcshell files by engine and role, for example test_server_store.js and test_server_tracker.js. Store suites name focused add_task functions such as testGetAllIDs, testItemExists, testCreateCachedUnknownRecord, testCreateDeletedRecord, testSyncUnknownType, and testSyncUnknownProperties. head.js supplies an encryption/decryption round trip and seeds unknown records. This naming and coverage pattern is directly supported across the four rebuilt engine suites; it is a scoped test convention, not a universal filename rule for all Thunderbird tests.

Scope: Thunderbird Sync tests.
