# Keep notification close and passive dismissal as different telemetry events

1031 records closed for a valid explicit dismissNotification call, interaction for the CTA, and dismissed when the active notification expires or disappears from the candidate list. It records shown when a UI notification is selected. Metric descriptions distinguish these transitions. Keep the semantic event names aligned with their actual producer, rather than calling every removal a close. The accepted code retains the distinction; no data submission or event execution was run.

Scope: Notification telemetry transition meanings.
