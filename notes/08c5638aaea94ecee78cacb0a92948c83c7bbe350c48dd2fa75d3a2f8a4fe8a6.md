# Calendar dialog Fluent messages must be checked against their actual targets

The original migration uses .title messages on HTML title nodes and a scalar Publish message on dialog/button targets. Accepted later source uses scalar window-title messages and a dialog .buttonlabelaccept message with explicit data-l10n-attrs. Close remains assigned to the accept button. Keep the exact value/attribute and element target together when describing this migration; adding data-l10n-id alone does not prove the final rendered result. Later fixes are comparison context, and no original failure or current translation was reproduced.

Scope: calendar-dialog-localization.
