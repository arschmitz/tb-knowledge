# Deferred compose-dialog scripts depend on shared-global initialization order

EdLinkProps.js must load before EdImageLinkLoader.js because the latter uses dialog globals established by the former. The reversed deferred script order caused gMsgCompInputElement to be undefined on dialog close. The accepted fix changed only script order, and current XHTML retains it. Review called the shared globals and multiple onload handlers fragile and suggested a future refactor; current loader still registers its own load handler, so that suggestion is not yet an established code pattern. Review acceptance confirmed the console-error fix, while checkbox behavior remained uncertain.

Scope: Compose link-properties dialog.
