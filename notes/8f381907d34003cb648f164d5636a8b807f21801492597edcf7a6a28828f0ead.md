# Folder-name assertion messages need to identify the expected representation

The owned local and IMAP tests check stored name, localizedName and database folderName separately, but eleven changed localizedName assertions have no message. A scoped review repair should name the folder case and expected representation, with should in each authored message. Keep these independent assertions: a correct translated display label does not prove the stored/server name or database metadata stayed unchanged. This is a test-diagnostic finding and proposed local repair under the deliberate assertion instructions, not a claim that the historical tests already follow that rule.

Scope: Native folder localization tests.
