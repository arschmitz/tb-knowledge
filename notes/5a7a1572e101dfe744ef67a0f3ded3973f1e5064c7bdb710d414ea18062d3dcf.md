# Preserve known network status when translating HTTP errors

482 added moz_http Error→nsresult conversion. Current borrowed conversion preserves known network and transport-security status, maps HTTP error response to NS_ERROR_NET_ERROR_RESPONSE, and maps unhandled variants to NS_ERROR_FAILURE. Its owned conversion delegates to the borrowed one. Preserve known status through the boundary and keep fallback behavior explicit.

Scope: rust/moz_http/src.
