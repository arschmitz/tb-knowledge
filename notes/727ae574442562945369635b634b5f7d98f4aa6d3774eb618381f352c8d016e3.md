# Calendar preference reporting and live preference observation have different scope

Accepted reportPreferences writes both mail and Calendar boolean lists to their own Glean namespaces. registerPrefObservers handles the mail boolean list and integer list but has no Calendar boolean branch. Thus these source paths do not establish immediate updates when a Calendar preference changes after reporting. A scoped review check is to distinguish initial collection from ongoing observation before promising live telemetry updates. No ping or runtime observation was performed. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
