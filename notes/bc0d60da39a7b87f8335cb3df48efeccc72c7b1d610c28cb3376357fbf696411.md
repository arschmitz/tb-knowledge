# Signed-and-encrypted MIME layer preference

At revision 0b93f0f7a926ed94c8a0646f18b6734ec7cc0f6d, mail.openpgp.separate_mime_layers defaults to false. The adjacent comment describes this preference as the choice between one combined MIME layer and separate layers for OpenPGP messages that are both signed and encrypted. This is a preference declaration and documented intent; the supplied excerpt does not show how consumers interpret the value or verify the resulting MIME output.

Scope: OpenPGP MIME layer configuration.
