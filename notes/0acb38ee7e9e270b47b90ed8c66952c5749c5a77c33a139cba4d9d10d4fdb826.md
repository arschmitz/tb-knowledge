# MV3 contact updates require a vCard change entry

At revision 5bc47cc15bfa2aa6abfd4d6f4eff817b9503ac81, onContactUpdated dispatches to Manifest V3 listeners only when changes contains _vCard. A change limited to other card properties does not dispatch an MV3 update through this handler. Account for this condition when designing event coverage; do not assume every internal contact-updated event reaches MV3 extensions. Manifest V2 follows a separate branch that dispatches filtered changes. This is verified static source behavior, with no runtime validation supplied.

Scope: WebExtension address book events.
