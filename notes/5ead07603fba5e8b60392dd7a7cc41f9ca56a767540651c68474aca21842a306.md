# Chat HTML rules distinguish attribute predicates from allowed style keys

The JSDoc migration makes rules dictionary shapes explicit. Attribute rules are accepted when the global or tag-specific rule is true or a predicate returns true. Style rules instead use membership of the property name; their stored values are unused. The implementation deletes rejected attributes/styles while compensating the live collection index. Manual schema-documentation proposal for this module: describe key membership, value meaning and combination semantics, rather than assuming two Record-shaped dictionaries are interchangeable. A false value in styles is not a deny rule. This is behavior learned from the documentation change and current sanitizer; Record syntax itself is handled by the JSDoc tooling, so it is not counted as a new manual syntax rule. No sanitizer runtime tests were executed.

Scope: chat-html-rendering.
