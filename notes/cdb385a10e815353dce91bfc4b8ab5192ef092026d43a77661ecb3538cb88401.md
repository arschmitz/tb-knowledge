# IMAP traversal names its Boolean root predicate isRootFolder

The traversal obtains GetIsServer into a bool named isRootFolder and uses that predicate both to exclude the root from message-folder work and to start the queued status chain at the root. The name states a yes/no role and matches the root terminology in the comments, rather than suggesting a folder object. This is an accepted local naming example, not a global is-prefix mandate or a change to the stored/public API name GetIsServer. The canOpen permission check is separate and does not itself name the traversal root. No server, network or test ran.

Scope: Scoped C++ Boolean role naming.
