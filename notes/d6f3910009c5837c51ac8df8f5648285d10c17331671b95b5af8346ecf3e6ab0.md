# The Graph cleanup changes constructor templates and generated output together

The patch adds must_use in constructor and reference-accessor generators and corresponding generated methods. It cleans imports and format captures while enabling wildcard_imports and uninlined_format_args warnings in this crate. The fixed constructor template still emits must_use, but Cargo now inherits workspace lints and Operation has changed. This is scoped historical generator/output evidence. It does not authorize manual generated-file edits or establish current repository-wide lint rules. No generator or Clippy run occurred.

Scope: ms_graph_tb generation and scoped lint history.
