# Calendar COMMENT has separate summary, invitation and mail-body consumers

The summary displays COMMENT in its own iframe, the invitation builder converts a separate comment field, and outgoing iTIP mail appends a labeled body section. The summary waits for iframe readiness, uses the shared text converter and handles trusted link clicks separately. The converter calls native text conversion and parseFragment with explicit sanitizer flags. These are checked local call paths, not a native sanitizer, accessibility or rendered-mail result. No test ran.

Scope: Calendar COMMENT presentation paths.
