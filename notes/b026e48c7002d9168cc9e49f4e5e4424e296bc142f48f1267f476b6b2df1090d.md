# Do not wait for a selection event when the operation preserves selection

The navigation test collapses all threads and then checks the selected message directly. The assigned selection fix avoids a selection notification when membership and row count remain unchanged. Register a selection-event wait only for an operation expected to change selection. This is the inspected navigation scenario, not a rule that all tree operations are synchronous. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Thread navigation event expectations.
