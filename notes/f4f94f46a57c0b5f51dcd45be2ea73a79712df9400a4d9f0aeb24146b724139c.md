# Keep callback-to-Future ownership and duplicate completion explicit

OAuthListener uses OnceCell<Result> and a Cell<Option<Waker>>. A successful/failing callback sets once, returns NS_ERROR_UNEXPECTED on duplicate completion and wakes any stored task. Poll returns a cloned Result because XPCOM RefPtr exposes the listener through immutable reference. Preserve that ownership reason instead of treating the clone as redundant. Current code moved to shared auth; no thread/runtime or token-service tests were run.

Scope: ews.
