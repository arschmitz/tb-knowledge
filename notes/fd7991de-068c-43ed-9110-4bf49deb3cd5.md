# Name actions as verbs and booleans as conditions in touched JS

Use an action name such as updateMessageCount for the operation. Avoid a boolean variable with the same name as the function it controls; use a condition spelling such as shouldUpdateMessageCount or skipUpdateMessageCount when such a flag is needed. This comes from D210487. The final patch eliminated that flag, so the suggested names are a review naming recommendation rather than examples of landed variables. Scope to local JS readability; this batch does not establish global prefix mandates.
