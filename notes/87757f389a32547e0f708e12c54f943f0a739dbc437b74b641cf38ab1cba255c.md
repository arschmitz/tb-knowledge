# The Rust HTTP cleanup makes the optional security guard explicit

The new let-else returns the original request error when security-info is absent, before any security-code query. A present object continues into the same NSS classification. This replaces an absence check plus justified unwrap and removes that obsolete unwrap explanation. It is a local guard and comment improvement, not permission to skip security checks, suppress required errors or apply an unconditional unwrap rule.

Scope: Rust HTTP request error and optional-object scope.
