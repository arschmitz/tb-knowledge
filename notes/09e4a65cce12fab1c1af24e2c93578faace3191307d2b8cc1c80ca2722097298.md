# DAV redirect callbacks reject a different prePath only when Authorization is present

The CalDAV and CardDAV callbacks compare URI.prePath. They copy Authorization for the same prePath; for a different prePath with a truthy Authorization header they report NS_ERROR_ABORT and return before later header/method copying. Missing or empty Authorization follows the existing continuation path. getHeader suppresses only NS_ERROR_NOT_AVAILABLE. This is a bounded callback rule, not a live redirect or setup result.

Scope: DAV authenticated redirect boundary.
