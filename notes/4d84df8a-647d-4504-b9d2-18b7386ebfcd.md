# Bookmark dialog resource links connect Fluent labels, CSS consumers and packaged files

## Observed resource chain

The properties dialog loads `editBookmark.js` and `bookmarkProperties.js` and preprocesses `editBookmarkPanel.inc.xhtml`. It loads `editBookmark.css` and the Fluent file `browser/editBookmarkOverlay.ftl`. It also loads the legacy string bundle `bookmarkProperties.properties`; dialog titles/default labels use that bundle rather than Fluent.

The included markup consumes Fluent IDs for name, URL, location, choose-folder item, folder expander, New Folder, tags, tag placeholder, tag expander, tag caption, keyword and keyword caption. Labels use exact `control` targets for their inputs. Tag/keyword inputs use `aria-describedby` for caption nodes. The English Fluent definitions provide each listed attribute. The folder tree is created dynamically with `bookmark-overlay-folders-tree`, whose definition supplies an `aria-label`.

The folder expander action changes `expander-up`/`expander-down`, row hidden state and the Fluent tooltip ID. `editBookmark.css` has matching selectors for those classes within `#bookmarkpropertiesdialog`. Folder selection writes `selectedGuid`; CSS matches toolbar/menu GUID values to special icons. The folder tree and tag selector IDs match stylesheet selectors. CSS also contains a `vbox#editBMPanel_nameRow` selector for which this checked include has no matching node; a transitive or historical consumer is unresolved.

The Places jar packages the dialog through a preprocessed entry, plus both JavaScript files. The theme jar packages `editBookmark.css` and `editBookmarkPanel.css`. This record checks the dialog stylesheet path; it does not claim the separate panel stylesheet is loaded by this dialog or that selectors render correctly on every platform.
