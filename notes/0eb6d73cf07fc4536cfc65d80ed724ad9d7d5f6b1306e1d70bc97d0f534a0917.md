# Use the Glean header for the metric definition group

The fixed compose implementation includes CommMailComponentsComposeMetrics.h for metrics defined under compose in mail/components/compose/metrics.yaml. Mail storage/database files include CommMailMetrics.h for mail metrics. Recommend the narrow generated definition-group header when adding a metric use in these native files, rather than the retired all-metrics GleanMetrics.h. Generated header production and paired Gecko build integration were not verified by a build. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
