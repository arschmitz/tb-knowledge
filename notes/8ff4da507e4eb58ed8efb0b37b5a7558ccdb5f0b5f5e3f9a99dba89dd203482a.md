# Opening a foreground tab dispatches TabOpen before TabSelect

The patch dispatches TabOpen for a new tab and then TabSelect only when background is false, with previousTabInfo=oldTab. Current tabmail retains that order after setting the selected panel/title/focus. This changes the native Thunderbird event seen by all listeners, not only the extension API. Background creation does not get this new activation event; page-load readiness remains separate. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: tab creation events.
