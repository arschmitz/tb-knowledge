# OpenPGP attachment test toggles depend on the starting default

The original default-off landing changes no tests. Its signed-with-key case signs and expects one key attachment without explicitly turning attachment on; other cases toggle attachment and expect none. toggleMessageKeyAttachment clicks the menu item, so its result depends on the starting state. Accepted signed-with-key source adds an explicit toggle after signing. This is a static setup/assertion dependency across source phases, not a reproduced explanation of every reported failure or credit for the later reland.

Scope: openpgp-tests.
