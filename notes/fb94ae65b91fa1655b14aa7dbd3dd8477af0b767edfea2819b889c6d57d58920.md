# Restore the import start flow when the saved profile pane lacks its prerequisite

The app pane cannot be restored directly because application selection belongs to the start flow. Current showTab redirects app to start with reset=true when there is no step history. This fixes the regression after the external-pane change. The browser test opens about:import#app, waits for #start and checks the start pane. Tests use a same-hash tick fallback because assigning the existing hash produces no hashchange event. The current file is registered under mailnews/import/test/browser/browser.toml; the historical mail/test/browser/import/browser.ini path is retired.

Scope: Import restoration and tests.
