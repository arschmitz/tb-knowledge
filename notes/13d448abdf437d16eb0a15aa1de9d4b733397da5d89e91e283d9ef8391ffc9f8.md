# Do not treat virtual-folder cache restoration as removal of the selected message

selectedMessageRemoved returns early while a virtual folder has not finished loading, preserving restoration state when obsolete cached hits are removed. The current code also defers invalidation with a generation token; that later mechanism is accepted context, not another studied chronological landing. The selection test registers allMessagesLoaded before displaying the virtual folder. Preserve the distinction between cache cleanup and user-visible message removal. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
