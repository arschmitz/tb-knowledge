# Resolve per-file Prettier width before reporting a Thunderbird formatting issue

At the checked accepted revisions, paired Gecko Prettier uses width 80 generally and a CSS override of 160 to avoid wrapping selectors. Thunderbird Calendar has its own width 100 configuration. Check the file's actual formatter resolution and nested overrides before reporting line width; a general EditorConfig width does not prove the formatter should wrap a CSS selector. These are configuration observations, not new policy or runtime validation. Recheck the target checkout when configuration changes.

Scope: formatting.
