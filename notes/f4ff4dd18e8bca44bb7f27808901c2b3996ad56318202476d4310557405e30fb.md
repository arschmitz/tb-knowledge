# Treat the Panorama folder cache as a bounded optimization

Current EnsureFolderCached fetches missing row data and returns a Result carrying failures. Its stand-in trim policy grows to 512 entries and discards an arbitrary quarter; it is not a least-recently-used cache. Mutations update existing cached data after successful SQL writes. Preserve correct DB-backed lookup when an entry is absent or evicted. This comparison does not benchmark the cache or establish cross-thread safety. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama folder cache behavior.
