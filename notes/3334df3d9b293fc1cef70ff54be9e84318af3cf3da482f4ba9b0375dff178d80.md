# Update cached folder flags only after the database write succeeds

Current updateFlags binds the complete requested flags value, executes the SQL, returns on failure, then updates a cached folder entry if present. It replaces flags rather than adding or clearing individual bits internally. The initial tests composed bit operations in the caller; current tests cover all values 0 through 15. Do not confuse a uint64_t update parameter with the current uint32_t getter/cache width or claim that high-bit values were covered by these tests. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama flag mutation and widths.
