# Match OAuth scope assertions to the scope the test actually checks

Proposed documentation/test correction in test_findConfig.js: the current assertion checks that the scope includes https://outlook.office365.com/owa/exchange.test/, while its message says EWS.AccessAsUser.All. A passing assertion therefore does not establish that the EWS scope exists. Align the assertion and message with the intended configuration contract before changing scopes. This is a static test-prose mismatch, not proof of a broken OAuth request or reviewer approval of a new scope policy. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
