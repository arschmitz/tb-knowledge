# Gloda indexes multiple-author messages through the first author identity

The indexer now rejects only an empty author list and assigns authorIdentities[0] to its single from field. This permits indexing without representing every author as from. The new test checks valid indexed state after a DB flush but does not directly assert the chosen author; the assignment proves that policy. Missing-author rejection remains. No runtime indexing ran.

Scope: Gloda author policy.
