# OAuth storage tests distinguish identity, scopes, rotation and unrelated logins

The 869–879 tests check cache object identity, reordered realm scopes, a wider granted scope, refresh-token rotation and preservation of unrelated origin or scope logins. The server helper rotates the token by adding or increasing a numeric suffix. The second refresh forces tokenExpires to 0 and checks both memory and saved token state again. Manual test proposal: name the particular storage transition, assert memory and persistent state, and include logins that must survive. Current tests use testOAuth2ObjectsReuse, testSetRefreshTokenWithNewScope and testSetRefreshTokenPreservesOthers. Their scope-set/cache contract already has shared lessons; these tests add evidence and do not establish a universal task-name style. The preservation test explicitly relies on login insertion order.

Scope: oauth-storage-transition-tests.
