# Keep template IDs and include names distinct from dashed element tags

The notification include uses inAppNotificationTemplates.inc.xhtml and the required ID inAppNotificationCloseButtonTemplate. The element looks up that exact ID. Current Account Hub uses accountHubFooterTemplate.inc.xhtml and accountHubFooterTemplate similarly. Keep camelCase template identifiers and the .inc.xhtml suffix in these families; a tag name and a template ID serve different roles. This supplements the retired conventions document with current accepted examples.

Scope: mail/components/inappnotifications.
