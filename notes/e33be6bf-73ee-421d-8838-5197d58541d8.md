# Keep resource checks in setup and skip only tasks that need the resource

The large offline store test checks free disk space in add_setup, then conditionally skips its two storage-heavy tasks with skip_if: () => !storageOk. Teardown remains a separate task. The 2024 fix removed .skip(!storageOk) from setup because that method unconditionally disabled it. Current code keeps the same arrangement. For resource-dependent xpcshell tests, let setup measure the environment, then put conditional skips on the dependent tasks so unrelated setup and cleanup still run.

Scope: xpcshell tests.
