# Check the URL-listener start status in the connectivity caller

SafeUrlListener.on_start_running_url returns the native nsresult. Current DoCheckConnectivity converts and propagates it before constructing or sending GetFolder, so a start-listener failure prevents that request. The owned historical migration ignored the same status. A safe wrapper does not by itself establish that the caller checked the callback result. The synchronously returned endpoint URI is separate from the later connectivity outcome. Static source only.

Scope: EWS connectivity callback boundary.
