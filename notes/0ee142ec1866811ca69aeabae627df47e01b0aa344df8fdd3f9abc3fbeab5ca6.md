# Document the external custom element contract with the supported tags

The current guide names @attribute, @cssproperty, @part, @slot and @tagname, alongside standard @fires and @property. It records the expected template as Template ID: #myElementTemplate. Use these names to document what a caller can set, receive or style. The boilerplate uses the platform handleEvent method with this as the listener. The prose line saying handleEvents has a different spelling; do not copy it as the actual callback name. No generated custom-element manifest was run. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.
