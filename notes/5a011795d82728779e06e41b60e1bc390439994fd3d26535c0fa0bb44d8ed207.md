# Apply Show All Headers after custom compose-header visibility

UpdateExpandedMessageHeaders derives custom compose-header visibility from the special-folder state, then lets Show All Headers clear hidden before populating the row. Placing the override after the custom state preserves this precedence. The pref reader trims comma-separated names, removes empty entries and normalizes case, but this is not complete validation of arbitrary header names. Review discussion contains an uncertain recollection about past malformed prefs, followed by acceptance; it does not establish the old cause or general safety. The source and full assigned context were checked; no message UI or sample email ran.

Scope: Message custom-header display precedence.
