# Expanded certificate scenarios still need expected-result messages in their shared helper assertions

The new NNTP scenarios call existing certificate helpers. In the inspected helper scope, the alert imageURL comparison, telemetry event count and telemetry extra-fields comparison omit assertion messages. The four checkButtons visibility comparisons also omit messages. These are unchanged assertion sites newly exercised by the expanded scenario, not assertion calls introduced by the NNTP patch. Scoped review recommendation under the current user rule: give each check a nonempty message that names the expected image, event or button state. Other checked dialog/override/status assertions already describe expected behavior. This is a source-review finding, not a runtime test result; required primary comment 3 is unavailable.

Scope: mail/tests.
