# The remote-content tamper helper changes a byte without validating OpenPGP integrity

The helper decodes the armor, XORs the byte at int(length*0.66) and writes new armor without a CRC line. It does not parse OpenPGP packet boundaries or run an integrity/decryption check. The known samples can be compared as encoded bytes, but this source transformation alone does not prove the docstring's promised MDC failure or arbitrary-input behavior. No helper or crypto tool ran.

Scope: OpenPGP fixture generation.
