# Use bracket indexing for asserted-present Account Hub test NodeLists

D228906 review requests addressBooks[0] instead of addressBooks.item(0) for the native DOM NodeList returned by querySelectorAll. The landed test and relocated fixed browser_accountHubSyncAccounts.js use bracket access. The fixed test asserts the collection lengths before reading these elements. Follow that local JavaScript test convention when the fixture guarantees the indexed element exists. Do not mechanically replace item on an unknown receiver or when absence handling matters: an absent NodeList.item result is null, while bracket access is undefined. This convention is scoped to these native collections, not arbitrary custom item methods. Existing backend-observer and focus lessons retain the test's behavior. Neither test was executed here.

Scope: Account Hub browser-test collection syntax.
