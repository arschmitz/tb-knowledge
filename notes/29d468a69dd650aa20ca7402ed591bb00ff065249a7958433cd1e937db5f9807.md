# Selected-message SaveAsTemplate waits for the folder but only dispatches the message copy

SaveAsTemplate awaits the identity's usable Templates folder, then calls copyMessages with a null completion listener. The copy API initiates queued asynchronous work and reports completion through a listener, so this function's Promise does not represent final template-copy completion. The actual selected-message command also calls it without awaiting or catching the Promise. Keep this helper separate from the compose-window function of the same name. No template-copy or failure run occurred, and this patch removes the legacy IMAP template test without adding a replacement for this path.

Scope: Selected-message template saving.
