# Exchange prefill maps the autodiscovered exchange type to EWS

The new prefill map treats the autodiscovered exchange type as EWS, alongside explicit ews and graph values. The original fallback is Graph, and the allowed authentication enum falls back to OAuth2. The two new component tasks directly assert EWS/password/hidden OAuth versus Graph/OAuth2/visible OAuth fields. Later accepted code instead uses a URL recommendation and an unselected EWS auth state; keep those phases distinct. This source/test scope does not establish live authentication or all invalid-input behavior.

Scope: Account Hub Exchange type/auth prefill.
