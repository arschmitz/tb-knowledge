# Pressed-button shadows keep theme choice in the color slot and check-button hover has its own state scope

The changed pressed-shadow token places inset geometry outside light-dark and theme colors inside its color argument. It also changes the geometry and dark color, so it is not merely equivalent formatting. The shared aria-pressed rule adds active background color, while check-button hover uses a separate selector that also matches unpressed check-buttons. The pressed marker remains an aria-pressed ::before rule. Quick Filter controls carry these actual classes; high contrast still disables the shadow. Keep the state scopes distinct and verify actual painting separately rather than treating a token name, author report or design approval as a rendered result.

Scope: Quick Filter and shared button styles.
