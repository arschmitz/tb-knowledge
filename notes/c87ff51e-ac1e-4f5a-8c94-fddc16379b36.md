# Normalize account hostnames as URLs before matching folder URI servers

A stored hostname "2" becomes 0.0.0.2 in a URI, so direct comparison could fail to find the server and leave the three pane blank. The 2024 fix normalized server hostnames with a standard URL parser and tested both imap://2 and imap://0.0.0.2. Current code normalizes both lookup and stored hostnames with MsgNewStandardURL, also handling IDN conversion; use that current path rather than a hand-written trailing-dot or numeric-host special case.

Scope: Account manager URI lookup.
