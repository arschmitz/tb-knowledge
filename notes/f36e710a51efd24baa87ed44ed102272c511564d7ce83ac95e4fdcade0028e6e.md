# The folder warning test waits for Fluent before reading the tooltip

The browser test first checks the warning row class and visibility, then awaits translateFragment(folderRow) before comparing statusIcon.title with the expected error text. That wait matters because the assertion consumes translated text rather than Fluent attributes. The selected settings-page action runs once across the scenarios; class, tooltip and warning-reset assertions have separate roles. A test that executes a handler is not automatically a direct assertion of every effect. No browser or localization test ran.

Scope: Scoped browser-test localization and direct assertion boundary.
