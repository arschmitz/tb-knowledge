# Native DNS calls require serialized worker ownership and shutdown

Current DNS.lookup uses one worker because native platform DNS C functions may use shared global state. Its synchronous worker event loop serializes requests; PromiseWorker maps replies to promises but is not by itself a thread-safety guarantee. The retained worker registers a webWorkersShutdown blocker to terminate and clear it. Historical2024 code instead retained each per-request worker in a Set until finally to prevent garbage collection; do not preserve that obsolete concurrency design as current guidance. The later review left native resolver redesign as a followup.

Scope: mail/dns.
