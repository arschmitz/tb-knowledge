# nsIPrompt_promptUsernameAndPassword behavior in mailnews/base/src/MsgAsyncPrompter.sys.mjs

Fills missing title from branded dialog strings. Copies username/password/check state into args with ok=false and promptUserAndPass type. Converts args to property bag, opens modal commonDialog.xhtml on activeWindow, copies existing property names back, then writes caller wrappers only if ok. Modal dialog accept updates args user/pass, checkbox command updates checked, and unload writes the bag before the helper reads it back.
