# The signed-only UTF-8 test diagnostic overstates its encryption check

The wording-only patch adds should to 55 diagnostics without changing their predicates. In testOpenSignedInlineWithUTF8, the summary says signed-only, but the wait text says on encrypted message while the following assertion negates hasEncryptedIconState for ok. That negative probe excludes only the matching source state; it does not assert a hidden encrypted icon. The shared hasNoEncryptedIconState helper is the distinct hidden-attribute check. The accepted source retains this diagnostic mismatch. No runtime result or test correction is claimed.

Scope: OpenPGP assertion diagnostic limits.
