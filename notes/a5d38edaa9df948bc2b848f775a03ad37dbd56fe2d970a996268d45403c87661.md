# Let TodayPane own the agenda’s selected-today condition

1098 removes Agenda's duplicate _showsToday field. Agenda.update clones its start date and creates a date-only interval; it spans numberOfDays when TodayPane.showsToday is true and one day otherwise. The minute metronome also uses the pane's condition before updating relative times. Keep this shared owner consistent when changing the date-selection flow. setDay updates its state even when the agenda is not visible.

Scope: Today pane agenda condition ownership.
