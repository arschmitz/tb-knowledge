# Calendar read-dialog organizer rows use display clones

The read dialog matches organizer and attendee IDs case-insensitively. It replaces a matching displayed attendee with a clone marked as organizer, or adds an organizer clone with no participation status. This preserves an existing attendee status and lets the row show an organizer label without a spurious status icon. The added test checks deduplication and that a stored attendee is not marked as organizer; it does not prove every event field or runtime accessibility.

Scope: Calendar read dialog.
