# PDF policy permissions use their own input field

The PDFjs callback writes pdfjs.disabled from !Enabled and pdfjs.enablePermissions from EnablePermissions in separate presence-guarded branches. The one-line historical correction changes only the latter field source. The inspected existing simple-pref case uses Enabled:false and EnablePermissions:true; both the old and corrected permissions expressions yield true for that case. No new distinguishing assertion or PDF/native execution is shown by this landing.

Scope: Enterprise policies.
