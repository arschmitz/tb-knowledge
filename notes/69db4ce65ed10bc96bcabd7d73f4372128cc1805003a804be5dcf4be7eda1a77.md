# Menu-typed action documentation links each action family to its menu context

The manifest annotations associate type menu with action_menu, browser_action_menu, compose_action_menu, or message_display_action_menu for the matching action family. Each annotation also links the menus API. These links describe existing context names; this documentation-only patch does not add runtime menu behavior. The accepted schema still distinguishes MV2 browser_action from MV3 action. No generated docs or extension UI was run.

Scope: webextensions.
