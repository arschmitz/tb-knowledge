# Center the notification close icon through the native control’s layout

Accepted CSS gives button[is="in-app-notification-close-button"] a 20px logical box, zero margin and padding, flex centering on both axes, and border-box sizing for its image. This replaces a pixel margin correction. For this close control, prefer the layout relationship and preserve its focus-visible outline while changing the icon. This is a local source pattern, not a ban on negative margins elsewhere. No rendered alignment, contrast or keyboard session was checked. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Notification close-control alignment.
