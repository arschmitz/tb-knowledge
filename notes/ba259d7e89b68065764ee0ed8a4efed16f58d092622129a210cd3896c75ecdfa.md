# The account-finished metric counts discovered sync resources before selection

The accepted #fetchSyncAccounts records address-book and calendar array lengths before showing the sync-selection step. The relocated browser test discovers two calendars, selects one for registration, then expects the finished event to contain calendars=2 and address_books=1. Keep discovery count distinct from added count when interpreting this metric. This is a scoped current caller/test contract, not a claim about all telemetry, exact serialized field types or data-review approval. No telemetry or registration test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub discovered-resource telemetry.
