# Preserve queued-stream errors and check successful short writes separately

The send-later change returns the actual stream-creation or Write failure instead of replacing it with an old compose error. A Write that succeeds but reports fewer bytes than requested becomes NS_ERROR_FAILURE. OnDataAvailable stops and returns a DeliverQueuedLine failure. The final leftover-buffer call in OnStopRequest ignores that function result, and stream Close is also unchecked there. Therefore this checked change does not establish end-to-end propagation for every queued-message write path. No disk-failure or short-write test was run or newly added by this patch. Source only: Bug 783526 comment 14 is unavailable; reviews are unread. No runtime validation.

Scope: Queued-message stream error boundaries.
