# Keep vCard text raw and encode it only at a URI boundary

Use toVCard()/abCardToVCard() for raw vCard text. Apply encodeURIComponent only when constructing a data:text/vcard URI; Blob/export consumers receive raw text. Replace ambiguous multi-format translateTo dispatch with explicit conversion methods when touching this API. toVCard ensures a UID if absent. Address-book lists are not supported as vCard in this path. Current accepted source retains the raw contract.

Scope: address book serialization.
