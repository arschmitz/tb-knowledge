# Retire the password appearance workaround after the native reveal control changes

The 2024 patch hides the upstream reveal button through textfield appearance in common.css and themeableDialog.css. Context-only entry 2971 later removes both rules and the Account Hub custom toggle button. Its title says to use the native visibility button after Bug 1920563. The fixed accepted password template has a native password input and no separate toggle button. Treat the old suppression as historical; do not copy it into new password fields. Native control keyboard behavior and accessible names need live verification with the paired Gecko version.

Scope: mail/themes/shared.
