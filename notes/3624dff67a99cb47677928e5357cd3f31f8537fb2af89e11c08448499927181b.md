# Avatar placeholders filter Unicode letters and decimal digits before choosing a code point

The sender header and current contact-avatar placeholder paths normalize candidate text, remove characters outside Unicode Letter and Nd, choose the first remaining code point with Array.from, then uppercase it or use an empty string. This skips leading quotes and punctuation. It does not compute initials from words or guarantee a single grapheme after case mapping. Photo/list branches and text-source fallbacks stay separate. Treat actual string consumers as the contract; optional chaining inside Array.from is not a general nullable-input guarantee. Static source only.

Scope: Sender and contact avatar placeholders.
