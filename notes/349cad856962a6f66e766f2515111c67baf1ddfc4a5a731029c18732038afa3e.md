# Provide the compose account before testing an early context menu

The scrolled-compose context-menu test creates an account and identity in setup before opening a new compose, then removes the fixed one-second delay before the context click. The checked account helper supplies an incoming server, and compose startup applies mail.spellcheck.inline only after initEditor. The test directly checks the extension menu entry, not spellchecker state or absence of startup errors. Preserve this setup dependency when maintaining the scenario; source inspection alone does not prove every early menu race is fixed.

Scope: WebExtension compose browser tests.
