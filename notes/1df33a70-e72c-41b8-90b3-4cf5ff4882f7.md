# Use XPCOM string types for message header interface fields

The May 2024 nsIMsgDBHdr change replaces raw IDL string fields such as messageId, author, recipients, ccList and bccList with AUTF8String. It avoids raw char pointer ownership at C++ and Rust boundaries. A reviewer requested the same for charset and accountKey; that follow-up landed in February 2025. Do not rely on the original claim that every raw header is ASCII: RFC 6532 permits raw UTF-8.

Scope: message header interfaces.
