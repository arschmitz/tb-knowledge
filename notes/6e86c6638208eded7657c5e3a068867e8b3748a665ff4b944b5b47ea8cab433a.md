# A profiler category port can need both Gecko support and a local header

The category port requires the upstream MAILNEWS category, but the immediate human repair also adds mozilla/ProfilerMarkers.h to nsLocalMailFolder.cpp. The fixed file still includes that header and uses AUTO_PROFILER_LABEL with MAILNEWS in local folder creation. Treat upstream availability and same-file declarations as separate dependencies when porting instrumentation.
