# Explicit multipart mixed signature processing stays separate from fallback multipart parsing

MimeMultipartMixed owns unobtrusive-signature parsing. Unknown multipart subtypes and selected basic-format or filter-sniffer cases use the plain MimeMultipartOther subclass instead. Preserve the actual class-selection boundary when maintaining this parser; a fallback displayed as mixed content is not automatically a signature-processing instance. No standards or runtime result is inferred.

Scope: MIME multipart class selection.
