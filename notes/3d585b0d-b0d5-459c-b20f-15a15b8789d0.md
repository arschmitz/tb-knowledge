# Name command state helpers for updating rather than enabling when they can do both

In D211548 the reviewer changed the proposed zoom helper name to updateZoomCommands because goUpdateCommand can enable or disable a command. The accepted helper also has a short JSDoc comment that states when it runs; current code keeps both. In command-controller code, choose an update name when the result depends on view state, and put the purpose comment above the helper instead of repeating it at each call site.

Scope: 3-pane command naming.
