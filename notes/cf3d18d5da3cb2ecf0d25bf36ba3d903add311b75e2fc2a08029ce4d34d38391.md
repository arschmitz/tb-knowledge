# Match a mutable-loop index to its temporary negative state

The historical biff loop removes an element and decrements its index to revisit the shifted entry. The follow-up makes that index signed; it also copies the entry before removal and reinsertion so its references stay alive. Accepted code now uses a range loop and no such decrement. Keep this as a lesson about that historical mutable-array algorithm, not a command to add signed counters to the current loop. The reported static-analysis diagnostic was not inspected. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Biff historical array iteration.
