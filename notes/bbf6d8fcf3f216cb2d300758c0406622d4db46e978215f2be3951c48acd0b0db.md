# Card copying writes the same vCard text under two clipboard flavors

Copy concatenates the selected contacts as vCard text and assigns the same string to text/vcard and text/plain. Its command rejects empty or mailing-list selections. The original enabled predicate also checks cards-table focus; the fixed accepted registration moves that focus check into separate command support. This clipboard contract is separate from selected-card file export. Tests check contents and flavor equality but several new assertions lack messages. No live clipboard or cross-application result was obtained.

Scope: Address-book clipboard copying.
