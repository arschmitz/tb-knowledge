# Message link and quote foreground overrides have different scopes

The unvisited-link override uses --color-text-highlight-dark only under the dark-scheme and dark-reader preference condition; visited links keep VisitedText. The cited-block foreground uses --color-text-highlight with a local important override outside that query. Existing nested border colors remain separate. No measured contrast or global important rule follows.

Scope: Message display and quote CSS color scope.
