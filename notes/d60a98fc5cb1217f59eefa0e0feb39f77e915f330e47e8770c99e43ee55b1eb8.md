# Disable filtered bulk deletion from the visible result count

Password Manager bases Remove All Shown on signonsTreeView._filterSet.length. The accepted code uses toggleAttribute to set native disabled state when the filtered result set is empty. The underlying database may still contain logins, so total stored-login count is not enough. Clearing the filter restores the full list through SignonClearFilter and LoadSignons. Preserve the filtered action contract when changing search behavior.

Scope: mail/components/preferences.
