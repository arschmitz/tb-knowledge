# Read metric values in assertions; metric handles are not recorded values

The readonly-calendar migration corrected a truthiness test of Glean.tb.calendarCount.storage into an assertion on testGetValue. Current unused Home checks expect null through the test API. Proposed manual test rule: read the stored value and assert the documented absence/value, not the existence of an accessor object. Do not make null a universal absence rule for unrelated APIs.

Scope: telemetry-tests.
