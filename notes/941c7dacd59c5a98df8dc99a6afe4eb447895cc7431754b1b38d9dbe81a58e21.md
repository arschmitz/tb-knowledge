# Choose keyboard events from the intended repeat behavior

The accepted guide says to consider keyup when repeated keyboard actions are not wanted. This is a conditional review question: decide whether holding the key should repeat the action, then choose and test the event accordingly. It does not establish a rule to replace all keydown handlers. Focus movement, default key behavior, modifier handling and screen-reader interaction still require a real keyboard test.

Scope: Custom-element keyboard behavior.
