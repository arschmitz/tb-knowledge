# Distinguish EWS save creation from send creation when sharing the item type

Both current create_message and send_message use RealItem::Message with the shared Message type. Saving uses SaveOnly and a saved folder ID, while sending uses SendOnly with no saved folder because Thunderbird MessageSend owns the Sent copy. A type unification must preserve those operation flags and ownership; it does not make save and send interchangeable. Existing Bcc and outgoing-listener lessons remain separate. No message was sent or saved during this study. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: EWS shared message operation semantics.
