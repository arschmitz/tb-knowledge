# The folder submenu factory explicitly sets native=false on the popup it creates

_buildMenuItemWithSubmenu creates either a folder-menupopup or a plain menupopup and then explicitly sets native=false. The expandable-folder caller passes inherited attributes through that factory. The original patch also labels root fixture popups explicitly; accepted roots later omit those attributes while the factory retains its setting. This source contract does not establish an engine-wide default or native-menu runtime result.

Scope: Folder popup construction.
