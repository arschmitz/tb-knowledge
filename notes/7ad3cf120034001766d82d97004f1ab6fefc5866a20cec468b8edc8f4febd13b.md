# The custom alert title migration and the later translation wait are separate phases

The migration replaces the XUL label with an HTML div and supplies count/account to a Fluent text value. Its original prefill only sets localization attributes before the alert measures content. Fixed accepted code explicitly translates the title and waits for prefillPromise before reading scrollHeight. Keep that later completion contract separate from the migration itself. The inspected custom-alert test checks sound and window lifetime, not localized title text or geometry. No rendering, timing or accessibility result was produced.

Scope: Custom new-mail alert localization.
