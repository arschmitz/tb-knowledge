# Recognize standalone newsgroup messages from headers as well as folder flags

Current reply-to-group enablement and Message menu classification accept currentHeaderData.newsgroups as well as the newsgroup folder flag. A message opened from a file or news URI can have no owning folder. Preserve that header-based route while keeping internal storage-dependent commands, such as moving or tagging a dummy message, guarded separately. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.

Scope: mail/base/content.
