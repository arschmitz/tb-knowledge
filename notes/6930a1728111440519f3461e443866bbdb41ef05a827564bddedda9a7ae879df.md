# Selection regression tests cover identity changes and visible state

Manual test-design proposal for the thread tree: test folder switching and popup closing with no selection, a current-but-unselected row, single selection and multiple selection. Add and delete messages before and inside the selected positions, and assert both selectedIndices/currentIndex and .selected/.current classes. Wait for allMessagesLoaded and a materialized row before opening its context menu. Fixed dates let insertion tests place messages before, between and after old rows. Reduced motion and disabled scroll-to-new-message preferences make the intended restoration behavior explicit, rather than silently changing the test contract.

Scope: message-list.
