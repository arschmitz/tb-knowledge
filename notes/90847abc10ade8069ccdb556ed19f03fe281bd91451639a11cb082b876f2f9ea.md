# Test the Account Hub font threshold transitions explicitly

The checked sync and manual forms branch at stored font preferences 18 and 17 respectively, while UIFontSize also supports an OS-derived default. Recommend focused tests around each threshold, returning below it, and changing font size while the form is open. First define whether an open form must update without setState. This is an unverified behavior/test proposal, not a reproduced default-font layout defect. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/components/accountcreation.
