# Panorama uses qualified nested namespace declarations

This human consistency change updates17 Panorama C++ and embedded-C++ IDL blocks from two nested namespace declarations to namespace mozilla::mailnews, and uses the same qualified name in the closing comment. The fixed DatabaseCore header retains that form. This supports a convention for neighboring Panorama C++ sections, not a new namespace name or a repository-wide rule. The author calls it a no-op build trigger; no behavioral database change was inspected.

Scope: Panorama C++ syntax.
