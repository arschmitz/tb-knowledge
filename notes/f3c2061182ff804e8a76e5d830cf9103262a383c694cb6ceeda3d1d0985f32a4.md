# CardDAV request declarations are added at each owned XML-body construction

Fresh complete two-module patch read. It prepends an XML1.0 UTF-8 declaration to one addressbook-multiget REPORT body and four CardDAV discovery PROPFIND body variants, leaving their namespace/property payloads in place. Fixed source retains them: _fetchAndStore calls the extracted _multigetRequest and discovery mutates requestParams.body for direct URL, well-known, principal and home-set/list steps. The author attributes Zimbra400/ignored bodies to the missing declaration. The reviewer launched Try then accepted without an explicit result; a reporter asked to test after landing and was pointed to Daily. Those are not server verification here. No changed test asserts the raw declaration; no HTTP byte encoding, redirect, Zimbra, CardDAV or broad XML-mandatory behavior was tested.

Scope: CardDAV XML request compatibility.
