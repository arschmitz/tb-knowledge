# The LDAP advanced test does not pass its filter value through searchFilter

The advanced LDAP utility test overrides filter, while the shared fixture still sets searchFilter to an empty string. createDirectory reads credentials.searchFilter when assigning ldapURL.filter. Comparing the result with credentials.filter therefore does not directly test a custom searchFilter input. A focused additional test would supply a non-default searchFilter and compare that same value after creation. This is a scoped source/test coverage finding, not a claim that the current helper fails for custom filters or that a test was run.

Scope: LDAP utility fixture and caller contract.
