# Use the shared selection color pair for the toggle track and thumb

Accepted toggle-checkbox checked states use selected-item-color and selected-item-text-color rather than direct AccentColor/AccentColorText. The header icon uses the same text token in its checked state. Proposed scoped styling rule: keep foreground and background tokens from this shared selection family together when changing this control, including hover and dark-color branches. Static token use does not prove contrast at runtime. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Toggle checkbox theme-token pairing.
