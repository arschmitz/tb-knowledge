# Compose command-line file attachments rebuild the URL from the resolved native path

This landing rebuilds existing local-file attachment URLs with PathUtils.toFileURI(uri.file.path), after the command-line resolver supplies an nsIFileURL. Missing local files are still rejected; other URI types keep uri.spec. AddAttachments later derives an absent filename from the final slash-delimited URL segment, which is the concrete consumer for this conversion. The new tests inspect names and a limited URI shape for temporary files and comma-separated attachments. They do not supply the literal percent-encoded Windows input from the report or prove native URI compliance. Fifteen of the new module's sixteen assertion sites lack messages; its explicit preference teardown also runs only on normal completion. These are scoped test findings, not accepted conventions.

Scope: Compose command-line attachments and Marionette coverage.
