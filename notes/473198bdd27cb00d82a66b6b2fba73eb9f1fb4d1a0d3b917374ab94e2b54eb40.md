# Use the current notification close button localization root

The 2024 close button attached and registered a shadow root. Current accepted code clones its template into the customized HTML button itself and translates this light DOM with messenger/inAppNotifications.ftl. Do not restore connectRoot/disconnectRoot from the historical patch when modifying this component. Its connection guard also prevents repeated template insertion and click listener registration.

Scope: mail/components/inappnotifications.
