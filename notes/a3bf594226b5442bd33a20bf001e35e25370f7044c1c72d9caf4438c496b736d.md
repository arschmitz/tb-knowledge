# The calendar bulk helper changes enabled checkbox state before acceptance

The historical and accepted helper is adjustCheckboxesForAllCalendars(checked), not setCalendarsSelected. It visits checkbox children of the network calendar list that have no disabled attribute and assigns the requested checked state. Select All and Select None invoke it with true and false. The selected accept handler registers checked calendars while skipping IDs already registered. Initial disabled-row state and acceptance registration are separate contracts. This corrects the older helper name while preserving its useful selection/eligibility observation. Native controls and static code do not establish keyboard navigation or live wizard success. No calendar-server/UI/accessibility test ran in this study.

Scope: Calendar creation bulk selection.
