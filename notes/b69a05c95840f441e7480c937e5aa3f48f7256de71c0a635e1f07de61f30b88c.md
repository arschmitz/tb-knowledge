# Traverse CSS rule containers before reading declaration text

The parsable-CSS test follows rule.styleSheet for imports and recurses into rule.cssRules before reading rule.style.cssText. Current code retains that traversal but uses a lexer for URL/custom-property extraction and handles style-query references separately. Definition stylesheet paths feed source-specific allowlist matching. The final CSS-error count is asserted, while an unused custom property is logged as info in the selected consumer. These are this static test's checks, not complete CSS coverage or a runtime parser result.

Scope: Static CSS rule traversal and check scope.
