# The initial EWS password test proves header construction rather than server authentication

The outgoing password patch looks up ews://host logins without the service port, filters by username and uses the first match. It propagates FindLogins failure after review and returns an empty password when no match remains. Its new test checks one stored ASCII credential in the emitted Basic header; the historical fake merely records that header and returns success. This does not cover a real Exchange service, non-ASCII credentials or missing-login failures. Fixed shared code now uses the password module and delegates Basic to Necko. No test ran.

Scope: EWS password lookup and fake-server oracle.
