# Account Hub password Back destination records the state that entered it

D227549 rejected a fixed password previousStep because manual outgoing configuration and discovered configuration enter the same password view. The landing assigns the originating currentState when entering that view. Fixed0b93 retains a currentState capture before #initUI and stores it as password previousStep afterward. Preserve that entry-path state when extending this flow. Review separately says manual edits persist within manual configuration and reset when leaving to autoconfig; a warning/refactor was deferred.
