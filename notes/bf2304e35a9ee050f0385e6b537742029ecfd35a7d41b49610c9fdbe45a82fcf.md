# ParseHeaderBlock returns blank metadata when raw serialization fails

ParseHeaderBlock remains an adapter through IHeaderBlock.AsRaw rather than direct field iteration. A failed AsRaw call logs a warning and returns a default RawHdr, so its caller receives metadata without that failure status. The inspected Exchange creation caller then applies protocol read and flagged state before database insertion. Preserve this fallback boundary when changing error handling; this row does not establish that an empty parse is rejected or that the planned direct-field design is implemented.

Scope: message-headers.
