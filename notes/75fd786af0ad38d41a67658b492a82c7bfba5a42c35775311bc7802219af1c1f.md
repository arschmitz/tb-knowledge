# Check that diagnostic template strings actually interpolate

747 fixes one warning interpolation, but the accepted get-signatures warning still contains 0x{keyObj.keyId} instead of a dollar-sign interpolation. It will print a literal placeholder in that message. Proposed manual syntax rule: verify that error-path diagnostics include the intended runtime value, especially after copying a template string. This is a narrow static logging defect, not evidence that signature verification itself fails or that every warning in the module is wrong.

Scope: OpenPGP diagnostic syntax.
