# Use font-relative calendar control size together with the platform floor

Entry 1609 replaces fixed calendar header/search heights with 1.5em and a minimum size. Current unifinder CSS uses logical block-size: 1.5em with a 35px floor on Linux/Windows and 32px on macOS. A scoped layout recommendation is to preserve both the scaling term and the platform floor when changing these controls. This does not ban pixel dimensions throughout Thunderbird and does not prove zoom or localization fit. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Calendar font-relative control style.
