# The repository root explicitly unsets Git text normalization

This landing adds the root pattern * -text, and the fixed accepted file retains it byte for byte. It is an explicit text-attribute opt-out, not an LF/CRLF preference or a conversion of existing file blobs. A bounded read-only source-revision attribute query resolves text as unset for three owned root/JS/Fluent samples; no add, checkout or renormalization ran. Nested imported attributes are outside this source scope, so the samples do not establish every path's effective attributes or change Thunderbird coding style.

Scope: Repository attributes.
