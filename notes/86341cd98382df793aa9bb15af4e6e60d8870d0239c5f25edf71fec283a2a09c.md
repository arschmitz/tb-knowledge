# Merged charset alias lookup checks Encoding before Thunderbird fallback aliases

After nsCharsetAlias merges into nsCharsetConverterManager, GetCharsetAlias lowercases the input, checks Encoding::ForLabel first, rejects replacement and then tries Thunderbird compatibility aliases. The removed helper checked the table first, so the merge changes lookup order rather than merely moving identical code. The owned new tests assert five selected alias results and a replacement failure; five scalar calls lack assertion messages in that historical patch. The accepted code keeps standard-first lookup with a later inline table and broader tests, which receive no credit here. This is not permission to remove compatibility labels or apply one alias/error contract to every charset query. No fresh alias test or build.

Scope: mailnews-charset-aliases.
