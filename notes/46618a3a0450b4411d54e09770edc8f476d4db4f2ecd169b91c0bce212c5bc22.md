# Give an animated search indicator a reduced-motion alternative

The quickfilter throbber is an image with empty alt, localized Searching metadata and AccentColor fill. Current CSS swaps spinning.svg for hourglass.svg when prefers-reduced-motion:reduce. This establishes decorative treatment and reduced-motion behavior in source; it does not establish a live accessible status announcement or rendered contrast.

Scope: mail/base/content.
