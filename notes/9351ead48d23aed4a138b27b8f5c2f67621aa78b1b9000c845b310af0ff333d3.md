# The original IMAP password-module port inverted the output guard

The port reads GetCachedPassword into value, but its final output branch uses value.IsEmpty before assigning aPassword. A nonempty cached password therefore is not copied by that branch. The accepted counterpart checks !value.IsEmpty. The actual protocol caller uses empty versus nonempty immediate output to decide whether to wait for prompt completion. This is a static source/phase finding; no IMAP hang, regression cause or cure was executed.

Scope: IMAP cached-password output phases.
