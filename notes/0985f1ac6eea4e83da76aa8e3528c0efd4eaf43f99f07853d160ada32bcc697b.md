# Style and script skipping compares tag prefixes without a name boundary

The new parser enters Style or Script skip mode when a bounded substring equals <style or <script. It does not check that the next character ends the tag name. The accepted implementation retains that condition. A longer tag name with the same prefix can therefore enter skipping in the static control flow. No such regression case or runtime failure was established.

Scope: Body-search HTML tag classification.
