# New Message can proceed without a selected folder or view wrapper

cmd_newMessage is enabled by available identities before the database-view requirement and maps to the New compose type. _composeMsgByType now checks gViewWrapper?.isSynthetic, so an absent wrapper does not throw when there is no folder. The adapter preserves its URI fallback, and ComposeMessage opens the New window without an original message. This is a narrow absence guard; it does not establish extension behavior, other compose branches or live folder-mode results.

Scope: Mail command compose state.
