# The conversation sort test detaches its listener even without a tree

Creating the adapter installs a LiveView listener before any tree assignment. The cleanup calls setTree(null), whose branch clears that listener and retained rows/references. The owned test places this after the five sort operations through finally without changing the ten expected scalar results. Those assertions still lack explicit messages. This historical choice does not override current harness-cleanup writing guidance, prove a garbage-collection result or attribute later JSContext repairs to this patch.
