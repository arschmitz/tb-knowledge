# Keep each Account Hub form responsible for its fields and state shape

The split moves field collection, sanitization, port/security adjustment and OAuth option visibility into incoming/outgoing form elements. The email controller owns flow transitions and passes state between them. Current incoming captureState returns {config, edited}, while outgoing captureState returns an AccountConfig. These shapes differ and callers must respect the declared return contract. A form extraction is incomplete until listeners, callers and returned data are all wired; the historical outgoing scaffold missed some of that wiring. No live account was created.

Scope: Account Hub controller and form boundaries.
