# The changed S/MIME unit-test sinks ignore the new start notification

Each of the three changed sink fixtures implements signatureProcessingStarted as an empty method. Existing result callbacks still increment countReceived and resolve their deferred result when the expected count is reached. Adding this method satisfies the new sink interface in those objects; it adds no direct assertion for the production overlay counter or smimeprocessed dispatch ordering. The existing browser telemetry assertions remain separate. No unit or browser test ran.

Scope: S/MIME sink fixture and completion-test boundaries.
