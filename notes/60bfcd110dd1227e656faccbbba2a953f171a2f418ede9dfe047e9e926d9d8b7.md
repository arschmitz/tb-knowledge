# IMAP subscription metadata reads can avoid creating a summary database

Subscription URL construction reads the hierarchy delimiter before a folder necessarily has an on-disk summary. GetHierarchyDelimiter now requests cacheOnly metadata, which exits before GetDBFolderInfoAndDB. SetupWithUrl separately uses OpenFolderDB with leaveInvalidDB=true; its implementation passes create=false to Open, so this Boolean is not permission to create a missing summary. Keep the cache read, existing-summary peek and separate database creation contracts distinct. The new test checks one immediate-directory matching summary after rediscovery; no live subscription or database test ran.

Scope: IMAP subscription and folder metadata.
