# Count completion falls through after rejection while selected-message completion returns

The inspected count listener stores a count only when a result row arrives. Its canceled/error branches invoke rejection and then reach MaybeResolve(mResult); the member has no initializer in the shown constructor or declaration. The selection listener returns after cancel/error rejection and resolves its accumulated array only on its completion path. Keep these distinct static paths visible when reviewing failure handling. This study did not inject a missing-row/error/cancel sequence, reproduce an uninitialized read or verify Promise-engine settlement internals.

Scope: Panorama native asynchronous query completion.
