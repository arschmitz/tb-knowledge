# Wait beyond the footer event before checking Account Hub address-book creates

The address-book sync tests register request-close before clicking Continue and await it before checking selected create calls. Their click helper only observes the footer forward event. The view awaits create callbacks, then dispatches request-close before resetting the tabmail overlay and calling toAddressBook. The added fixture div and navigation spy satisfy those environment accesses; they do not open a real tab. Tests assert zero, one or two creates and one navigation call, with corrected zero-count messages. The close event marks the creation phase boundary here, not completed real navigation.

Scope: account-hub/address-book/tests.
