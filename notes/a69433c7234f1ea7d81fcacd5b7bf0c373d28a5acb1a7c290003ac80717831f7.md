# The CardDAV password test waits for sync before checking persisted logins

The reland arms addrbook-directory-synced before discovery, calls create synchronously, then awaits sync before searching stored logins. It checks the second scenario against secondLogins and deletes that directory after the credential assertions. This separates the immediate directory return from the test completion boundary. The test does not directly assert return timing or reproduce event-listener cleanup.

Scope: CardDAV reland test ordering.
