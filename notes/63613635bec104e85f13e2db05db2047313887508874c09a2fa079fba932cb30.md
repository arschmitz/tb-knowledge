# Dark-reader tests distinguish theme completion from popup visibility

The current dark-reader test helper waits for message loading separately from windowlwthemeupdate. The popup test checks the old popup is closed before clicking, waits for the old popup to hide and the customization panel to show, checks toggle visibility changes and closes with Escape. Scoped test recommendation for this file: use the event for the operation under test and explicit panel state checks; a generic sleep or a message-load event alone does not establish a completed theme update. The reported intermittent was not reproduced. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran.
