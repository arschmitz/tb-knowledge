# Known invalid fields need enforcement at Save entry paths

The D332891 verification record at revision dab61204576552c4e7a6bce2f010ccb2b87047c1 reports that canSave=false did not disable Save or stop save(), and saveCalendarEventEdit also ignored draft validation. Controlled execution reportedly invoked the helper and completed one transaction with title validity set to false. For these dialog and edit-Save paths, the proposed contract is to consume known validity results for active fields at the button and Save entry paths; Save need not implement field validation itself. Preserve disabled-row behavior. This is a reported defect and recommendation, not an accepted fix: no amendment, human acceptance, or Thunderbird runtime test is recorded.

Scope: Calendar event Save validation.
