# Immutable recurrence rules replay an instance cache with one fixed start

An immutable CalRecurrenceRule caches its iterator, start and calculated values. New calls replay cached values and extend the same iterator only as the consumer needs more. A different compared start throws; mutable rules use fresh iterators. Range and count stops still apply, and the first out-of-range candidate may already be cached. RecurrenceInfo propagates immutability to its rules. No runtime or performance test was run, and the edited tests do not directly assert cache reuse.

Scope: Calendar recurrence iteration.
