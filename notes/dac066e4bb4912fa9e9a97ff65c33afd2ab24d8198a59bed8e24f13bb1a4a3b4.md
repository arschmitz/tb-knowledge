# The CSS exception port adds feature-gated diagnostics without changing shipping CSS

The original port adds three allowlist conditions: a non-mac font-smoothing diagnostic, a forms.css picker diagnostic when customizable select is disabled, and a webcompat scrollbar-pseudo diagnostic when fake WebKit scrollbars are disabled. It also removes older debugger/autocomplete exceptions. These are parser-test exemptions rather than product CSS or engine changes. Accepted source later changes picker to ::checkmark and removes the fake-scrollbar gate, so do not treat the original list as current feature support. No static CSS test or rendered behavior was executed.

Scope: Static CSS parser-test exception port.
