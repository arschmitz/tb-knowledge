# Microsoft sandbox selection changes from module-time constants to a cloned per-lookup override

The initial sandbox patch reads mail.microsoft.useM365Sandbox while evaluating the provider module and uses the chosen application/tenant in its issuer map. Accepted code later checks that preference inside getIssuerDetails, after extension-provider precedence, and clones and freezes the built-in details before overriding endpoints. Keep the initial configuration phase separate from later dynamic lookup and ownership behavior; neither is a successful login or a per-account override guarantee.

Scope: oauth-provider-sandbox.
