# Define notification update quota as a rolling successful-update window

The updater records timestamps after fetch, JSON parsing and synchronous return from onUpdate; it does not await a Promise returned by that callback, keeps the last quota-sized set, and schedules from the oldest timestamp when the rolling window is full. Failed fetches return before adding history. Preserve this actual update accounting; the source comment saying notifications have been shown does not describe what the quota counts.
