# Conversation LiveView filters by thread ID across folders and starts in date order

initWithConversation accepts a message thread ID and installs ConversationFilter. Its SQL clause matches threadId without a folder condition, while native notification matching compares Message.threadId. Initialization rejects an existing folder filter and sets date ascending. Sort setters remain mutable, so this is an initial order rather than an immutable always-ascending guarantee. Owned tests check counts and cross-folder membership; later distinct-date tests and asynchronous results are separate phases. Conversation-specific live notifications and invalid or large IDs were not executed.

Scope: Panorama conversation LiveView.
