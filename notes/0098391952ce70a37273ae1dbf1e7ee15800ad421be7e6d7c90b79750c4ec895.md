# Detect a localization Git worktree by its Git authority, not a .git directory

1009's RepoClient opens Mercurial only when root/.hg exists. Otherwise it asks git rev-parse --is-inside-work-tree and turns either a failed command or a non-true response into Unsupported repository. This permits Git layouts where .git is a file or the root is inside a worktree. This inspected Thunderbird fork is dependency integration evidence, not a source of global Thunderbird Python style.

Scope: Fluent migration repository detection.
