# Key usage display must preserve the case-sensitive encoded usage contract

EnigmailKeyObj.getUsageText maps lowercase e, s, c and a to localized component usages. Uppercase letters describe summary properties and are ignored. The moved helper belongs to the shared key object; the expiry dialog calls it with the selected component keyUseFor. Do not lowercase the whole input as a naming or parsing cleanup: that would change summary flags into displayed component capabilities. Document encoded input semantics when exposing or moving the helper. Scope: keyObj usage display. The current switch and caller were inspected; no new usage test ran.

Scope: OpenPGP key object.
