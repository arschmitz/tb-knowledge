# Scope the notification underline to its disclosure cue

The Account Hub landing removed the generic title-span underline and placed it on emailFormNotificationToggle. The accepted template puts that visual cue inside a native details/summary control. Preserve the summary as the interactive target; the underlined div is not a separate button. This scoped selector recommendation keeps a title from looking like an extra link. It does not prove screen-reader behavior, especially with the explicit alert role. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub notification affordance.
