# Use the shared brand term and rename consumers when message meaning changes

The Account Hub migration replaces hard-coded Thunderbird and brand-full-name with brand-short-name, and updates message IDs in the resource, template and view. Current failure/discovery strings retain the shared term. Preserve resource and consumer changes together when altering text for this family. A changed message ID is a localization migration boundary, not simply a JavaScript identifier rename. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub brand localization migration.
