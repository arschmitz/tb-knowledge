# The mbox end-of-line check was removed after a Windows performance regression

The removed preflight helper opens and reads the mailbox end, optionally appends a missing line ending, and increments a counter. This patch removes that work, the now-dead counter and its repair-specific regression task together. The author reports a Windows private-fixture slowdown and a failed read/write-open alternative; those are historical reports, not measurements here. Always adding an extra line ending and caching handles were not the accepted fix. Current stream wrappers must be studied separately before claiming they restore the removed recovery behavior.

Scope: Mbox append performance.
