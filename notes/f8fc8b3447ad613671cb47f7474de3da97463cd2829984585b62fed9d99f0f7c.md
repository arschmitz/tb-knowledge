# Maildir folder copying can continue when a saved search has no directory

Maildir CopyFolder checks whether the source filesystem path exists before copying the directory. It then separately handles the summary file and creates the destination folder object with the source flags. This lets a saved search with no physical Maildir directory reach those later steps. The guard checks existence rather than the Virtual flag; existing nonempty summary-copy failures still propagate. No new test or runtime move result is established.

Scope: mailnews/local/store-folder-copy.
