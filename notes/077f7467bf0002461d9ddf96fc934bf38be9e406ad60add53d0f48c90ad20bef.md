# Select the Mercurial runner explicitly in the language-pack push command

The language-pack push kind explicitly invokes /builds/worker/bin/run-task-hg before the Python ATN script. Its comm transform separately writes run-on-repo-type:[hg] and selects docker-worker with the tb-atn image. Keep the executable path, repository-type metadata and worker implementation as separate facts; the generic wording in the commit title does not change those contracts. The local Dockerfile inherits its parent and does not itself copy the runner, so static comm source alone does not prove the binary exists in a built image or that an upload succeeds.

Scope: Release task infrastructure.
