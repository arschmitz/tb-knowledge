# Give loading icons theme color and preserve their text alternative role

An SVG consumer must opt into the context fill it expects. Account Hub uses -moz-context-properties: fill and --selected-item-color; other contexts use their own semantic color. The calendar invitations spinner has alt="" next to a localized Updating label because that image is decorative. Keep a separate meaningful accessible label when an icon itself communicates status. The current spinner source contains a malformed stroke-opacity value, and motion, contrast and forced-color behavior were not checked. This patch is evidence for the consumer contract, not proof that every loading asset is visually or accessibly correct.

Scope: Loading icon theme and accessibility.
