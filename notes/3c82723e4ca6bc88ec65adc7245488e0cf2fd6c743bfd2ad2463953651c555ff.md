# Parser header accessors must preserve the caller's owned lifetime

GetNewMsgHdr AddRefs the returned header; SetNewMsgHdr changes the parser-held value. The POP caller keeps an nsCOMPtr because PublishMsgHeader clears the parser's header before later work finishes. StoreIndexer also consumes the result and clears parser state after attachment. The getter can return a null-pointer error; some callers instead guard the output pointer. Review defers wider callback result handling, so this visibility refactor must not be described as completing that cleanup. No POP or indexing test ran.

Scope: Parser header ownership.
