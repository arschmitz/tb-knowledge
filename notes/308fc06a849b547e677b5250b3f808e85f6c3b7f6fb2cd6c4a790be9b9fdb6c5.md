# Let the notification title wrap while keeping its toggle together

The notification CSS applies white-space: nowrap to #emailFormNotificationToggle, not the full title. When that toggle is visible, the title aligns to start. Icon spacing and input placement use logical inline properties. This is the observed local layout contract, suitable as a scoped recommendation for this notification. Long translations, RTL, zoom, contrast and rendered alignment were not tested. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
