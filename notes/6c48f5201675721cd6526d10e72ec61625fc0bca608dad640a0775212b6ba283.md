# Keep password storage separate from outgoing preference fields

2024 Part 7 left password lookup unimplemented while persisting nonsecret fields. Current OutgoingServer uses a password-auth module and login manager, not a password pref; absent passwords can be prompted for. It keeps username/auth method/endpoint presence checks separate from password recovery. Do not copy historical unimplemented password/unsupported NTLM claims into current architecture.

Scope: rust/protocol_shared/src.
