# The compose send listener separates its working weak handle from a temporary keepalive

The native listener keeps a weak compose handle for callback forwarding and a separate strong keepalive for the gap before deferred copy completion. MessageSend._doFcc2 queues onStopCopy without awaiting it. The listener releases keepalive on not-performed sends, selected stop-sending branches, stop-copy completion and the exact progress STATE_STOP path. In the progress path, Abort precedes the release. These are checked branch and ordering facts, not a proof that every native failure settles, that a cycle cannot remain, or that the historical stuck-progress report is cured.

Scope: Compose send/copy callback ownership.
