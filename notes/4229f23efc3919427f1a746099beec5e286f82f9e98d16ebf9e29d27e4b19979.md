# LDAP advanced-form names distinguish visible mode from retained data

The finalized LDAP form names its Boolean display-mode field #isAdvanced and its concrete form-body ID ldapFormBody. The click handler toggles that Boolean and the advanced class through the same form-body selector. #isAdvanced describes the displayed mode; it does not mean that advanced data exists or was cleared when hidden. Retaining values for reopening was accepted locally, with later captureState selecting advanced data only in advanced mode and replacing it with defaults in Simple mode. The concrete ID identifies this LDAP body within the shared Account Hub template scope. Keep the ID and its selectors together when changing this component. These are accepted local naming examples, not a mandatory is-prefix, a global ID scheme, a complete ID-uniqueness audit or a rendered accessibility result.

Scope: Account Hub LDAP local Boolean and template ID naming.
