# The Calendar touch-end reset checks the Map object instead of its empty size

The touch end/cancel handler deletes changed identifiers but guards its accumulator reset with !this.#mOngoingTouches. The field is an allocated Map, so deleting its final key does not make that object false. The intended reset after all drags stop therefore does not occur on this branch, and a partial offset remains for a later gesture. Accepted code retains the same condition. This is a static state/condition mismatch, not a reproduced touch-device failure or a tested repair.

Scope: Calendar month and multiweek touch-scroll state.
