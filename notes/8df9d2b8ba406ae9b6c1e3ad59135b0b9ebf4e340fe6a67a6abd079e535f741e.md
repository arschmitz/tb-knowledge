# Scope compose-only header visibility to outgoing folder ancestry with a view-all override

UpdateExpandedMessageHeaders recognizes Sent, Drafts, Queue and Templates including ancestors, then hides compose-only rows elsewhere. View all headers overrides that hiding. Therefore the outgoing-folder rule is not an unconditional prohibition on showing those headers in incoming folders. Preserve the override and per-message row reset rather than resurrect the removed unconditional output loop. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message header outgoing display scope.
