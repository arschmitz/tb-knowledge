# The tag visibility class diagnostic disagrees with its visible branch

subtest_assert_tags_visibility compares the class state with !isVisible, but its constant message always says the class should be applied. The accepted visible-branch call expects the class absent while its diagnostic says the opposite. The button assertions use separate visible/hidden messages. This is a specific source diagnostic mismatch, not a reproduced failure or a test repair.

Scope: Quick Filter Bar assertion diagnostics.
