# Use portable top-level fields for the minimum data needed to recreate synced objects

Bug 1888023 rebuilt Thunderbird Sync records around only the data needed to recreate a server, identity, network address book, or network calendar. The bug proposal moves essential fields out of prefs, uses consistent names, and uses string values such as socket and authentication modes instead of Thunderbird-only numeric constants. The server engine maps between strings and Ci constants in one place. Nonessential options such as calendar color were deferred. This is a scoped record-schema design decision for cross-client data, not a rule for all local preferences.

Scope: Thunderbird Sync record schema.
