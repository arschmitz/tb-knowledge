# Keep MSIX publisher identity in step with the active signing certificate

The MSIX publisher attribute for shippable builds must match the active signing certificate subject. Bug 1894264 changed the subject location to San Francisco in both regular and localized MSIX repackage kinds. When the upstream certificate change was backed out, Thunderbird reverted the two values because builds broke. The original D209020 review later records a reland once upstream was ready; current kind files again use San Francisco. Check signing state and both task kinds when making this port, and treat a backout as a temporary state rather than the final convention.

Scope: MSIX signing.
