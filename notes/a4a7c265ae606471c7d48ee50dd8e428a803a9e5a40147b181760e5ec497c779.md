# Define folder date query shapes explicitly rather than mixing recency and bounds

QueryDateRange has one object shape with required recent and another with optional after/before dates. The implementation prepares recency bounds in separate branches before filtering. Preserve that schema distinction when extending this query; an arbitrary mixture of recent and date bounds is not an established API contract. This is scoped schema guidance, not a universal preference for choices arrays. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension folder query syntax.
