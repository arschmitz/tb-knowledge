# Panel transition completion must filter the event and resolve on cleanup

The panel transition listener accepts transitionend only from the view stack and only for transform, because an unrelated height transition may not occur or may finish first. transitioncancel checks the target, and _cleanupTransitionPhase removes both handlers and invokes resolve if present. This lets closing the panel release a pending transition promise. Manual event-lifetime proposal for this transition: check the producing node and property, retain listener references for removal, and give cancellation/teardown a path to release the wait. Do not use the first bubbling transition event as completion. This is a panel transition contract, not a mandate for every animation implementation.

Scope: panel-transition-lifetime.
