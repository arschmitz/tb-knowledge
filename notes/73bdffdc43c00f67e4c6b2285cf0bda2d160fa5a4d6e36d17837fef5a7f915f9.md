# Rust workspace warning settings live in both the template and generated manifest

This patch adds the same 13 warning declarations to workspace_template and generated Cargo.toml. The actual build function formats that template before writing the manifest. unused_crate_dependencies remains commented because the source describes false positives from dependencies used on other platforms. Keep the generator, generated output and crate inheritance distinct; static declarations do not prove a successful lint run or define a rule for every Rust crate.

Scope: Rust workspace generation.
