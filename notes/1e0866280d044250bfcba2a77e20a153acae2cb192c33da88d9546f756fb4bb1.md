# Exercise link clicks on a child inside an open shadow root

The assigned landing uses BrowserUtils.hrefAndLinkNodeForClickEvent, which supplies a semantic link node already studied in the earlier accepted-link lesson. Its new fixture places the clicked span inside an anchor inside a declarative open shadow root. clickLink translates the local container:element test notation into a stringified content-process query. Preserve that fixture when checking retargeted clicks; this colon notation is a test convention, not a CSS selector grammar. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
