# The original channel refactor leaves a stale field name in its clone comment

The new AsyncChannelOpener struct calls its channel field inner, but the original moved explanation still says self.async_interface twice. That name belonged to the deleted generic wrapper. The accepted fallback-clone comment names self.inner. Keep the explanation tied to the actual field and retained-reference operation; no broader safety proof follows from this wording correction.

Scope: Rust XPCOM channel glue comments.
