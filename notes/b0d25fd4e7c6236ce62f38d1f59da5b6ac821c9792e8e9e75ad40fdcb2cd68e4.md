# The initial Graph update fallback creates after any listener error, before later narrowing to missing messages

The owned update implementation requires isRead and tries on_message_updated for every present item. Any returned callback error triggers creation, with a TODO naming the intended message-not-found distinction. Its test listener initially throws generic NS_ERROR_FAILURE for an unknown ID. Accepted code later creates only for NS_MSG_MESSAGE_NOT_FOUND and propagates other failures; its listener uses that exact error. The owned zero-size/false-flag placeholders remain limits, and the Graph tests skip those properties. A later narrowed result must not be projected onto the initial fallback.

Scope: Graph message update callback classification.
