# The S/MIME setup follow-up removes task-local certificate imports from the merged file

The merged file had a shared CA/Bob setup plus another NSS/CA/Bob/Alice sequence inside the opaque-rendering task. The follow-up corrects Bob's File/password argument placement, adds Alice to add_setup and removes that task-local import sequence. Both rendering and multipart-reply tasks then use the shared setup. The later accepted preference environment and certificate-removal registration are separate. This source establishes call placement and password ownership, not a reproduced failure or cryptographic validity.

Scope: S/MIME browser setup lifetime.
