# Adjust standard ports for protocol and security without replacing custom ports

The incoming and outgoing adjustment helpers return early when an existing port is not in standardPorts. The SMTP helper uses 465 for implicit TLS and moves 465 or an unset port to 587 for STARTTLS. Preserve custom ports and treat security/protocol changes together in this family. This is a UI configuration heuristic, not proof that any selected port offers encryption or that the later connection succeeds. The current outgoing lookalike configuration assignment is a separate static concern. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub port and security coupling.
