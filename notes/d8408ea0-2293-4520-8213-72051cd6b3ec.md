# Preserve the RSS title fallback before inventing a title

RSS feed naming uses title, then description, then URL. For RSS2, create a hostname/path title only when title and description are both empty and a valid link exists. A URL-derived title must not hide a useful description. Entry290 tests the actual subscription UI and current FeedParser keeps this behavior. This is feed-parser behavior, not a general rule for missing strings.

Scope: newsblog.
