# The midnight test separates weekday labels from a visible today box across months

The not-selected-today scenario keeps the day before yesterday selected and passes a cross-month flag to its month checks. The original patch allows zero today boxes for Sunday or Monday only in month view, after checking the weekday-label row. Accepted source narrows this exception to cross-month Sunday and adds a failure message to the zero-box assertion. Multiweek does not use that exception. These are test-expectation phases, not a fresh rendering result; the original added assertion lacked a message.

Scope: Calendar midnight-update test expectations.
