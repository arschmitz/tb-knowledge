# Raw-header flag parsing needs tests for independent field sources

Static inspection of the fixed parser finds three distinct concerns: out.flags is reset after MIME parsing may set Attachment; the eight-digit status branch reads mozstatus instead of the collected mozstatus2; and xflags |= xflags & 0xFFFF0000 does not discard lower bits. These observations do not prove a reproduced message failure. Minimum test coverage: a multipart/mixed header without stored status, distinct Status and Status2 values, runtime-only bits and the intended upper-bit behavior. Define the expected combined result before changing this incomplete producer. The AddMessageBatch2 caller stores the returned fields; no parser or database runtime test ran.

Scope: Raw-header flag parsing.
