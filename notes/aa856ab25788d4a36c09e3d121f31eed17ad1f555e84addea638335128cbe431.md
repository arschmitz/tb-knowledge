# The outgoing password entry point preserves the cancellation status

GetPasswordWithUI explicitly returns NS_MSG_PASSWORD_PROMPT_CANCELLED for internal None and returns NS_OK only after assigning a password. Its comment explains that the normal method macro would normalize successful statuses, so this entry point bypasses it. The helper treats cancellation before its generic error conversion. Preserve password, successful cancellation and error as distinct outcomes. This is local code and stated rationale; engine macro internals and interactive password behavior were not tested.

Scope: Rust outgoing password UI result contract.
