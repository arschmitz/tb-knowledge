# OAuth popup links share the browser-access implementation

browserRequest.js supplies the nsIBrowserDOMWindow implementation used by both the OAuth request window and extensionPopup.xhtml. A supported new-tab request opens a content tab in the most recent mail window and preserves the supplied principal, CSP, referrer and opener information. If no suitable window exists, the helper returns null; it does not create one despite the old comment. The regression test deliberately uses a non-private request window and checks the opened URL. This does not establish private-window support or printing behavior. No browser or security runtime test ran.

Scope: OAuth popup tab routing.
