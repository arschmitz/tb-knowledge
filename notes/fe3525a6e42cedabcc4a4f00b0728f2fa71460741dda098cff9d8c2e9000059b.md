# The ARM64 image-worker alias rename preserves its backend configuration

The human infrastructure change renames images-gcp-aarch64 to images-aarch64 while retaining its provisioner, docker-worker implementation, Linux OS and alias-derived worker type. The accepted file later declares images(|-aarch64). These are configuration phases, not proof that an upstream alias resolver or deployed worker pool accepts a task.
