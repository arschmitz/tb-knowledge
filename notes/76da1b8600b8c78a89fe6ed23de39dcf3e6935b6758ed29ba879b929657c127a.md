# A Panorama root has parent ID zero, while ordinary inserts require a parent

Current insertRoot normalizes its server key and passes parent 0 to the internal insert. insertFolder rejects parent 0. The table stores this zero root sentinel even though parent is declared as a self-reference. Keep zero meaning root/not-found distinct from a valid nonroot folder ID; no foreign-key enforcement assumption follows from the schema alone. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama folder identity.
