# POP local moves prepare store data and header flags before database attachment

MoveIncorporatedMessage creates a detached destination copy with nsMsgKey_None and addHdrToDB=false, writes the store data, sets the eligible New flag, then attaches with notify=true. The Mork receiver updates its database new list before onHdrAdded; the parser's later folder SetHasNewMessages precedes NotifyMsgAdded. These are distinct notification stages. The source supports their ordering, without proving saved-search UI behavior or making every state update precede every callback.

Scope: POP local move notification ordering.
