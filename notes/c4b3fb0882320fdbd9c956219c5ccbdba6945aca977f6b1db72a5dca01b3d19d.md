# Virtual tree row counts and flat indices stay separate from sibling positions

The visible-row update writes the view's rowCount to both table and body before returning for an empty view. Row fill writes a flat 1-based ariaRowIndex under the accessibility/automation guard. The optimized AutoTreeView row supplies that work itself rather than calling the base fill. Those values differ from hierarchy level and position within a sibling set. This patch adds no header-row increment and its changed tests do not directly assert the new count/index values; source arithmetic is not a screen-reader result.

Scope: Tree view virtualized row ARIA metadata.
