# Account Hub resets remote-address-book state between setup attempts

The remote form returns its current data object and the address-book view retains it across account, password and discovery steps. reset replaces the retained remote state with an empty object and resets supported subviews. Resetting only the visible form would leave the view state intact. This contract is specific to Account Hub remote-address-book setup; it is static source evidence, not a new execution result.

Scope: Account Hub CardDAV lifecycle.
