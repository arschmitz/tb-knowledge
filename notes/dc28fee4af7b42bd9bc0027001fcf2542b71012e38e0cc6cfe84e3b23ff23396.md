# Keep JavaScript folder-lock calls aligned with diagnostic arguments

The 1958426 JavaScript follow-up supplies a caller label to acquireSemaphore and releaseSemaphore after the native interface gained that argument. The local-mbox repair uses the same folder and label at both calls. The IMAP tests use MailServices.accounts as the same opaque holder at acquire and release, with a test-code label. The label explains the caller; it does not establish ownership or thread safety. Fixed fetch assertions distinguish a header fetched while locked from an offline body stored after release. No test ran here.

Scope: Folder operation contracts.
