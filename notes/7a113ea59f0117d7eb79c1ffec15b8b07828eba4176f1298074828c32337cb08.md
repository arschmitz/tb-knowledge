# Convert Path objects at the FileFinder boundary

657 changes FileFinder(base_path) to FileFinder(str(base_path)) for Windows local localization development. The current helper creates Path objects for both localization clones, converts them for FileFinder, and also passes a string destination to FileCopier.copy. Keep pathlib objects for local path composition and supply the value expected by the consuming API. The commit explicitly excludes CI automation from this fix. No Windows clone/copy run was performed.

Scope: Localization path API compatibility.
