# The send-error cleanup displays failure before offering a certificate exception

The historical cleanup uses the normal sendFailed localization fallback instead of a discarded replacement and a removed string lookup. It also calls fail before the security callback, so the send report is displayed before compose offers a certificate exception. Fixed accepted code keeps that order with Fluent text and a later overridable-NSS check. Reviewer reports EWS confirmation; no local send or dialog test ran.

Scope: Compose error text and certificate-dialog order.
