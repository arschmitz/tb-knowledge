# The compose helper inlining changes the Remove Links Boolean condition

Before inlining, SetElementEnabled negated its enabled argument. The Remove Links caller passed !isCollapsed || linkAtAnchor, so disabled meant isCollapsed && !linkAtAnchor. The replacement assigns isCollapsed || !linkAtAnchor. This changes the two cases where only one enabling condition held: a noncollapsed selection without a link at its anchor, and a collapsed selection inside a link. The adjacent comment still says a noncollapsed selection may remove links. EditorInitFormatMenu supplies the concrete menuitem, which observes cmd_removeLinks. Fixed accepted source retains the new predicate. This establishes changed expressions and a comment mismatch; intent, command-update interaction and live/native behavior remain unverified.

Scope: Compose Format menu state.
