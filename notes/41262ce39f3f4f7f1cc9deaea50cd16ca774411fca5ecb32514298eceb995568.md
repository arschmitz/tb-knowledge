# Temporary attachment creation keeps the unique file through the save step

The attachment path creates a process-specific temporary directory with mode0700 and a unique file with mode0600. The message-opening path keeps that created file for SaveToFile instead of deleting the placeholder first, preserves a sanitized message filename and caches the file by URL. The string-message helper has its own create/write/open path. This describes the inspected lifetime and permissions, not cryptographic unpredictability or an audited security guarantee. Private bug and review context is unavailable. No file creation, message opening or permission test ran.

Scope: AttachmentInfo.setupTempFile.
