# An absent tab icon source uses CSS file fallback rather than the load-error fallback

The tab CSS supplies --icon-file only when .tab-icon-image has no src attribute. setIcon removes src when neither icon nor fallback is supplied; this reaches the CSS fallback. A provided fallback for a missing or broken source is handled separately by JavaScript, and busy/thinking selectors can still hide the image. The current setter comment saying both null sources make the icon invisible is stale against the CSS. This is a decorative tab-image boundary, not proof that every failed image gets a default icon or a live accessibility result.

Scope: tab icon presentation.
