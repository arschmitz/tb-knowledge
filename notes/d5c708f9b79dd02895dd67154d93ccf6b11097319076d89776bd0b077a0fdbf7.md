# Remove a write-only news-host field through all producers and consumers

The two news cleanups remove the compose field, header producer, draft parsing, send-later storage and obsolete NNTP normalizer. Current send-later still prunes X-Mozilla-News-Host if an old message contains it. Preserve that compatibility pruning when removing dead production state; absence of a producer does not mean every old header spelling or cleanup branch should vanish. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: News-host metadata retirement.
