# Use component tokens and logical geometry for Account Hub styling

585 introduces hub-specific color/focus variables and decorative resources. Current source maps those --hub-* names to shared color tokens and uses inline-size, min-block-size and logical insets for the dialog. The source also supplies prefers-contrast overrides. Favor these newer accepted tokens and logical properties over the 2024 physical top/left/width rules and hard-coded color values. This is a scoped manual CSS convention; variable names alone do not prove contrast, focus visibility or responsive layout. The binary background images were not viewed.

Scope: Account Hub CSS naming and geometry.
