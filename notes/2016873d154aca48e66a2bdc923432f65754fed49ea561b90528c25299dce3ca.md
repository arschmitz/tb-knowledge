# External toolbar mutations end customization before touching wrapped buttons

The currentSet setter ends active customization before reordering nodes, after its equal-set guard. removeButton also ends customization before deleting both toolbar and palette copies. The toolbox listener finishes synchronously, and finishToolbarCustomization guards repeated teardown. The extension API calls this receiver only for a customizable toolbar. This source ordering is the local contract; no live extension or customization cycle was run.

Scope: Customizable toolbar and extension-button lifecycle.
