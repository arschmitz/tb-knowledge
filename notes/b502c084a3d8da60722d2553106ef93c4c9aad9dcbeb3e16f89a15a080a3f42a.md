# Body search decodes a named-entity subset after aggregating HTML

StripHtml runs on accumulated HTML, rather than each physical message line. Its lookup decodes only the fixed named-entity table; unsupported names and numeric references remain literal. The new tests check complete words and the space-versus-merged-word result. The curated parser's performance and safety claims remain historical claims; no benchmark or broad HTML conformance result was established.

Scope: Body-search HTML transformation.
