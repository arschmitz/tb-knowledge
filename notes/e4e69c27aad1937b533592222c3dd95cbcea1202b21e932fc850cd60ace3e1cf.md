# Create a default identity before a compose-window browser test

The attachment-event setup creates an account, identity, email address and incoming POP server, sets the default account and registers removal. Its test opens compose through the normal shortcut helper before attaching files. A bare incoming account does not establish an identity for this flow. This is a UI fixture requirement, not a need to set every application account as the default. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/test/browser.
