# A disabled show-missed default does not suppress every past alarm

Accepted addAlarmsForItem keeps future alarms scheduled. For a past DISPLAY alarm, the writable-calendar and item-modification checks and acknowledgement checks run before showMissed. If showMissed is true, the service fires the unacknowledged alarm immediately. With it false, the service can still fire when the item end or start is at or after now, which preserves reminders for ongoing or future items whose alarm time passed. Do not describe the two-line default change as disabling all past reminders. Current ignored acknowledgement handling is later accepted context, not part of the original two-line landing. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Calendar show-missed behavior.
