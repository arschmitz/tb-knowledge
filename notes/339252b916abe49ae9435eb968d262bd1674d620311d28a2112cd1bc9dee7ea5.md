# The SMTP fixtures await fake-server stop before resetting state or draining events

The send-later fixture awaits server.stop before resetTest and resetCounts. The 8BITMIME fixture awaits it in its existing finally block before processing pending thread events. The server now awaits the delayed reader cleanup path. These caller orderings are stronger than a cleared running/test flag, but do not prove every shutdown path is awaited or that final output was acknowledged.

Scope: SMTP fake-server test shutdown.
