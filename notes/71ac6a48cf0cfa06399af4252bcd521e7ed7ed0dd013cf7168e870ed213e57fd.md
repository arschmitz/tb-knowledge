# Release the optional IMAP part address on MIME URL-construction failure

The historical AppleDouble HTML branch may allocate id_imap when parts are missing, then fail to construct id_url. This landing adds PR_FREEIF(id_imap) before the existing id free and OOM return, matching mime_imap_part_address's explicit caller-free contract. The normal path already releases the temporaries. Accepted code later removes that whole link branch, so retain this as a bounded ownership/error-exit example rather than a current rendering recommendation. No allocation failure or leak was reproduced.

Scope: MIME AppleDouble temporary ownership.
