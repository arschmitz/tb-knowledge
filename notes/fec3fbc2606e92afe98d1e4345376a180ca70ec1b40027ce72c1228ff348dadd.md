# Thunderbird DNS policy keeps omitted lock state false for its preferences UI

At the inspected accepted revision the DNSOverHTTPS callback defaults an omitted Locked key to false and passes that binding to its preference calls. The preferences UI disables its DoH radiogroup when network.trr.mode is locked. The policy comparison records this exact Thunderbird difference and its UI reason. This is a scoped source contract, not a runtime preference or accessibility result.

Scope: Enterprise policies.
