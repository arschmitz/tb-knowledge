# Use one-way test messages when no reply is needed

In D210522 the author changed background test notifications from window.sendMessage to browser.test.sendMessage. The inline review states the distinction: await window.sendMessage() when the background must wait for an answer from the test; browser.test.sendMessage() when it only sends a notification. The landed message-display test uses browser.test.sendMessage("Ready") and matches it with extension.awaitMessage("Ready"). This is a component-specific test harness convention.

Scope: Extension test messaging.
