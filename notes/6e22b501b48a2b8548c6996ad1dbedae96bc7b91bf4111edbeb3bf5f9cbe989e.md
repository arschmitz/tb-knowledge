# DONTBUILD becomes a decision flag before backstop calculation

The port stops replacing target_tasks_method with nothing and instead sets dontbuild from a DONTBUILD substring plus tasks_for == hg-push, before calling the imported backstop helper. The updater accepts neither the old nothing target method nor dontbuild:true when choosing a push artifact. The added unit-test value is false and does not directly test either condition branch. These local inputs/call order do not prove unread upstream morph/backstop behavior or a release optimization outcome.

Scope: comm taskgraph decision parameters and fixture updater.
