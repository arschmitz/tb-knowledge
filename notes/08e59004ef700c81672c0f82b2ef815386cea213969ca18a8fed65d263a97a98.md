# Root task upload configuration points to its published worker artifact directory

The root task payload sets MOZ_UPLOAD_DIR to /builds/worker/artifacts. Its action and decision commands link that directory, and the public directory artifact uses the same path. This establishes the configuration connection. It does not verify why an upstream resource monitor timed out or prove that a decision task now completes.

Scope: taskgraph-root-upload-directory.
