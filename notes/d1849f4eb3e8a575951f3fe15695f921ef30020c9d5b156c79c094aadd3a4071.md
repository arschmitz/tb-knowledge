# check3PaneState checks the document URL as well as completion

The shared helper waits until its captured document is about:3pane and has readyState complete before checking pane layout. A complete about:blank document alone cannot satisfy that predicate. The document is captured before polling, so this source does not prove that the helper follows document replacement. Setup awaits the helper; the inspected cleanup caller does not. No navigation or test run was performed.

Scope: extensions/browser-tests.
