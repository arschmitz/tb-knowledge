# Reject an empty MIME override before the final object type handoff

Filename lookup must produce a successful nonempty type before mime_file_type allocates a candidate. mime_create also drops invalid candidates before selecting a class. That matters beyond the first selection guard: its later unchanged handoff assigns any surviving override pointer to obj->content_type. An empty allocated candidate previously could skip class-selection replacement yet still reach that final assignment. The patch guards the callback and rejects the candidate in the parser, preserving the declared type when lookup has no usable replacement. This is a local source/ownership check; no native MIME service, platform file association or message rendering was run.

Scope: MIME filename type fallback and pointer handoff.
