# Remove obsolete installer payloads from both packaging and file-use checks

1992 removes nssckbi from package-manifest.in and the Windows PushFilesToCheck list. Accepted source keeps both exclusions. Recommend checking both lists for this installer integration when removing a library: one controls payload, the other lists files whose use blocks installation. This source study does not establish the upstream NSS reason, generated installer result or runtime certificate behavior. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
