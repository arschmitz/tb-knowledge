# HTML reply tests distinguish full content from selected text

The added reply test checks the full message paragraphs separately from a selected text range. The current selected-text task creates the selection through SpecialPowers.spawn in the message content browser and asserts the quoted text. These assertions do not directly check link targets, form removal or embedded-image fidelity merely because those appear in the fixture.
