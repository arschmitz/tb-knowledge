# Identify image test fixtures by their DOM elements, not their shared URLs

1021 changes the imageIds collection from image.src to the actual image object. Multiple image elements can share a source while having different sizing or link context. The accepted test keeps object identity, waits for complete images and checks dimensions before asserting overflow behavior. Use the element as the diagnostic identity when testing multiple renderings of the same resource.

Scope: Message image test identity and readiness.
