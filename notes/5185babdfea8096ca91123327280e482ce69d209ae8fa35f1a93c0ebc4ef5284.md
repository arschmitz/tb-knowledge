# The async lazy row map reserves placeholders before returning synchronously

In this historical phase, rowAt must return synchronously while the database query is asynchronous. It reserves empty TreeDataRow entries across the requested buffer, so another lookup sees existing entries instead of scheduling the same missing range. The query replaces those placeholders and invalidates the range after completion, unless cleanup detached the adapter. A nonempty row object is not proof that its message has loaded. The direct test checks undefined before invalidation and exact data afterward. This original map is retired in the fixed accepted chunk-based adapter. Its replacement loop starts a separate output index at the requested buffer start, preserving the database offset while consuming returned messages.

Scope: Panorama original asynchronous sparse row cache.
