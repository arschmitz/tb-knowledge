# Calendar provider and iTIP constant uses keep the owning Ci interface visible

These three accepted cleanups replace cICL, kCalICalendar and cIOL with qualified interface references. The offline flags name calIChangeLog, item filters name calICalendar, and the completion switch names calIOperationListener. This keeps the role of each constant visible at its use. Existing state transitions, branch precedence and completion-label consumer remain separate behavior contracts. It is a local accepted naming example for these modules, not a blanket alias ban, runtime equivalence proof or new instruction. Later return-value and Fluent changes are separate. No Calendar/provider/iTIP test ran.

Scope: Scoped Calendar privileged-module naming.
