# Restored menu arrows use the matching parent background without clearing state images

The restoration paints the generic wantdropmarker=true arrow on the toolbar or formatting button background. The actual alignment menu requests that attribute. Formatting state rules set background-color while their arrow uses background-image; scoped end padding and RTL offsets reserve the arrow space. Split menu-button child dropmarkers remain a separate surface. iMIP More uses explicit layered background images instead of the generic attribute. This is receiver-specific CSS, not a rule to replace every background shorthand, recreate child DOM, remove all important flags, or assume a working hit target. No rendering or test ran.

Scope: Toolbar and formatting menu arrow CSS receivers.
