# The copy-from-file test targets the message body before awaiting its context popup

The task registers the mailContext shown-event watcher before synthesizing contextmenu on body inside getMessagePaneBrowser(). It awaits both the content event call and popup watcher before traversing the menu. The getter returns the messagepane content browser, rather than the outer standalone window used by the old call. This is a scoped receiver and ordering change, with no executed native-popup or copy result.

Scope: Message-window context-menu browser tests.
