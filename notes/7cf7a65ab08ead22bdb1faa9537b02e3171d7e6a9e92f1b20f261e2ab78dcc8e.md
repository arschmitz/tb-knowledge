# Check the actual single-page navigation boundary

The 2024 EOY tab requests linkHandler single-page. Accepted contentTab assigns that message-manager group, and StrictLinkClickHandlerChild compares specIgnoringRef, so fragments of the same page stay eligible while a different query/path is a different page. Other external/http(s) navigation is forwarded. Scoped recommendation: trace the actor as well as the tab option; single-page is not a same-domain allowance. The EOY caller itself was later removed. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/base/content.
