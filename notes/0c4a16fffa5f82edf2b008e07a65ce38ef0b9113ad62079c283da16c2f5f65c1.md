# Limit Account Hub label transitions to the no-preference motion setting

The accepted label styles place transition rules inside prefers-reduced-motion: no-preference. Focus and filled-input selectors still set the label transform outside that media query, so the required label position does not depend on animation being enabled. Preserve this separation when changing label motion. The actual reduced-motion rendering, zoom and focus contrast were not tested.

Scope: mail/themes/shared.
