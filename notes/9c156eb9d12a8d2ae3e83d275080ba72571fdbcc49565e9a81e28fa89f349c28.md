# EWS telemetry keeps an observed version separate from the request default

read_server_version returns an optional observed version. The telemetry recorder increments a version bucket only for Some, while the request handler independently uses DEFAULT_EWS_SERVER_VERSION when absent. The direct test expects no version bucket for an empty map and checks each known label separately. This avoids treating a compatibility default as a server observation. No telemetry test ran.

Scope: EWS version observation and telemetry.
