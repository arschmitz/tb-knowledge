# Keep raw Panorama database access restricted to tests

The initial FolderDatabase.connection property was automation-only; accepted raw access is DatabaseCore.connectionForTests and retains xpc::IsInAutomation guarding it. Tests use that connection to check persisted rows. Production folder callers should use the folder interface rather than the test-only connection. This guard establishes the inspected API restriction, not a database security boundary against all privileged code. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama test-only connection.
