# Remove unused out parameters across all message service backends

The saveMessageToDisk API returned an out URL that callers did not use. Removing it required the IDL signature, C++ local/IMAP/EWS implementations, JS IMAP/NNTP implementations, callers, and unit tests to change together. The IMAP C++ backend still needs an internal temporary out pointer for FetchMessage. Preserve protocol-specific internal needs when simplifying a shared public API. JS call sites use the IDL lower-camel saveMessageToDisk name; generated C++ methods remain SaveMessageToDisk.

Scope: message service API.
