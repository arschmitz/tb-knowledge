# Selection downloads resolve view rows through the shared header-selection path

Accepted DownloadForOffline uses GetHeadersFromSelection, which skips the None sentinel, handles dummy collapsed rows and resolves each header with GetMsgHdrForViewIndex. Collapsed children depend on the operation-on-collapsed-thread policy and front-end summary state. Do not read every selected row as a key in m_db; merged/search views and dummy rows require the shared resolver. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
