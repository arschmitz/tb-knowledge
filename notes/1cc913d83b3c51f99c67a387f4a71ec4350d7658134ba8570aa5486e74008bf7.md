# The folder-tree quirks test creates its own account instead of importing MessageInjection state

The historical patch removes MessageInjection import/construction and accounts[0] selection from this test. It creates a local account/Inbox, writes generated message strings to three folders and marks each folder read. Current setup keeps that ownership and cleanup removes the account. This is a scoped test isolation step, separate from earlier extraction/manifest setup and later load guards; it does not establish every other test is isolated. Cleanup is registered after setup and is not a recommended new-test ordering. No browser test ran.

Scope: Folder-tree browser-test fixture ownership.
