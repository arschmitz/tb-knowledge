# The Appearance accent selector stores a named preference and overrides shared selection tokens

The accent menu stores OS-following or named palette values in mail.appearance.accentColor. Outside contrast mode, custom media branches override selected-item color and text tokens used by actual primary-button and tabline consumers. The test asserts a purple preference and tabline/swatch background equality, then restores the OS choice. It does not measure every palette, theme interaction or accessibility contrast. Accepted native accent-color CSS and later selector/label changes are separate phases.

Scope: Appearance accent-color preference and theme consumers.
