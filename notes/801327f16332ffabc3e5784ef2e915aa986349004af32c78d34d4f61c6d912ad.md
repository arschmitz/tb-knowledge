# Copy-service teardown clears the request listener before normal request cleanup

This landing clears each remaining request's listener in the copy-service destructor, then calls ClearRequest with failure. ClearRequest still ends any eligible undo batch and removes/deletes the request. Its normal OnStopCopy callback remains for requests whose listener is present. The inspected filter listener can create localization and prompt services after a failed copy, which explains the local lifetime dependency. The source supports suppression of this request-listener branch, not a guarantee that every shutdown callback is disabled or the reported native crash is reproduced.

Scope: Copy service and filter completion.
