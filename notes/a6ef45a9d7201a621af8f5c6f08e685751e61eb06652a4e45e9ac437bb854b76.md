# POP message writes stopped seeking to the end for every line

The migration removes the per-line seek-to-end/debug workaround and calls SyncWriteAll with an error check. It also checks store finalization and attaches its token before publishing the parsed header. This does not eliminate every flush: the fixed completion still flushes before filter moves, and its later LF-only-header handling is a separate parser step. Abort delegates discard to the store rather than first closing independently. The review’s rv request is confirmed in the actual landed call. No POP, short-write or disk-failure test ran.

Scope: POP store write lifecycle.
