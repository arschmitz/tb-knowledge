# Use in-tree URL placeholders and structured annotations for API documentation

Newer accepted API documentation uses $(url:name)[Title] with entries in annotations/url-placeholders.json. It supersedes the 2024 HTML anchor and |link-*| forms. Structured annotation objects extend schema information rather than overwrite descriptions through external overlays. They keep notes, code examples and manifest-specific detail separate from the main API description. The README requires exactly one annotation property and identifies entries by hierarchy; min/max manifest version may disambiguate the target. Generate/inspect the downstream output when changing these contracts, because the later generator exposed wrong type/namespace/version/snippet/URL entries. No generator was run here, and the full followup patch has not been audited.

Scope: mail/components/extensions/annotations.
