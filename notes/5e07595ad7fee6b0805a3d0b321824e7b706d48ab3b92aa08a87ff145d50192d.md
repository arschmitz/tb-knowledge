# Before-unload prompts skip contexts that cannot present a current prompt

The accepted asyncBeforeUnloadCheck returns true without showing a prompt when a present docViewer disallows tab-modal prompts or ancestorsAreCurrent is false. This avoids prompting from stale/unavailable navigation state. Keep those entry guards before string lookup and dialog construction in this prompt family. Missing required localized strings take a distinct false path; no stale-context navigation was executed. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Before-unload context guards.
