# The Panorama onlineSearch getter passes a Boolean output to an integer writer

At the fixed accepted revision, VirtualFolderWrapper::GetOnlineSearch receives bool* and passes that pointer as int64_t* to FolderDatabase::GetFolderProperty. The called overload writes stmt->AsInt64(0) through its output when a property row exists. The original wrapper landing already has this cast. Preserve the actual pointed-to type when evaluating this path; a cast does not provide int64_t storage for the Boolean output. This is an exact static type/write mismatch and a focused validation gap, not a reproduced overwrite, crash or new runtime result.

Scope: Panorama virtual-folder numeric property output.
