# Name Exchange completion callbacks and guards for their actual role

Current listeners name constructor callbacks onSuccess and onFailure, store them as mOnSuccess/mOnFailure, and keep separate simple/message/fallible variants. GuardCopyServiceListener is [[nodiscard]] and returns MakeScopeExit that reports the final referenced nsresult when scope exits. For this listener family, preserve role names and hold the returned guard in a local variable for the whole operation. This is a scoped C++ ownership/naming pattern, not a requirement that all callback classes use the same hierarchy. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Exchange C++ listener naming and scope guards.
