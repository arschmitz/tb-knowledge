# Removing the compose command-line role preserves the compose service API

The migration handles -compose in MessengerContentHandler and removes the C++ service command-line interface and registration. The messengercompose contract still exposes nsIMsgComposeService, and Key Manager continues through MailServices.compose.OpenComposeWindowWithParams. Command validation, window readiness and compose-argument consumption remain separate contracts. The source change does not prove every parameter combination or an OpenPGP signing/encryption result.

Scope: compose-commandline-component-ownership.
