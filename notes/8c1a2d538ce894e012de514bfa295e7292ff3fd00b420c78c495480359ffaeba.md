# Use the OAuth role when naming Account Hub module instances

In D231105 the reviewer preferred oAuth2 to mod because the name gives more context about the instance. The checked landing uses oAuth2 for its CardDAV and CalDAV token-module instances, and the fixed CardDAV caller retains that name. This is a scoped naming example for this discovery code; the suggestion was nonblocking and its row remains Not Done. The separate module-getter suggestion was deferred to a follow-up. No authentication or test was run.

Scope: Account Hub OAuth instance naming.
