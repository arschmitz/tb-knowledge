# Enable language pack staging through the update service contract

920 sets app.update.langpack.enabled to true. The separately checked Gecko source uses that preference to begin stageLangpacksForAppUpdate for the target app version, records one staging promise per update and allows the application update to continue if staging fails. This is a source explanation of the gate, not a successful update or language pack install. The Gecko snapshot is named independently and was not built as a matched Thunderbird pair. Exact comm-to-Gecko revision pairing was not established.

Scope: Application update language pack staging.
