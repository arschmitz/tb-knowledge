# Windows tray activation handles both select notification events through one helper

The version 4 tray icon callback takes NIN_SELECT and NIN_KEYSELECT from the low event word and routes either event to HandleIconActivate. It no longer dispatches that action on WM_LBUTTONDOWN, while WM_CONTEXTMENU remains a separate branch. This is a static callback/receiver contract, not a measured native delivery or double-activation result.

Scope: Windows tray notification dispatch.
