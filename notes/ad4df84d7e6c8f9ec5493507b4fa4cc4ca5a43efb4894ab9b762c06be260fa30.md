# Flatpak APP_ID connects the launcher, package metadata and bundle names

The resolved APP_ID is copied into flatpak_name and reused for the launcher's --name, metainfo/desktop identity, locale/application refs, icon paths and bundle files. Branch and desktop VERSION_FLAG selection remain separate. The owned addition is immediately backed out by exact blob inverses, while accepted support includes later metainfo, argument-array and DBus changes. These static connections do not prove a launch, package or release push succeeded.

Scope: Flatpak application identity propagation.
