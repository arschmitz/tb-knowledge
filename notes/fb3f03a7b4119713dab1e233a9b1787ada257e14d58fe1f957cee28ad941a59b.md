# Expose skipped decryption separately from a successfully decrypted envelope

The expanded encrypted-message tests cover nested OpenPGP/MIME, an encrypted attachment, inline OpenPGP and two S/MIME envelope forms. getFull with decrypt: false returns skipped while retaining encryption evidence. In the signed-then-enveloped S/MIME case, successful outer decryption still returns an application/pkcs7-mime signed-data part. The test does not claim that the inner signed payload was decoded or its signature verified. Manual test description proposal: name the layer and action actually checked, and assert both status and returned MIME form. The renamed test_ext_messages_encrypted.js reflects the broader scope; the old attachment-only file is retired. Keep the local test_openpgp_enc_* and test_smime_enc_* task families when extending this file; this is a local naming pattern, not a repository-wide underscore rule.

Scope: encrypted-api-test-scope.
