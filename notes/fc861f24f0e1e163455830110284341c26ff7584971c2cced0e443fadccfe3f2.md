# The Calendar migration rewrites only existing persisted checked strings

For an existing profile below UI version 60, updateCheckedValue first checks xulStore.hasValue. It rewrites the exact string false to the -moz-missing newline marker and every other stored string to empty, for four named Calendar commands. Absent values stay absent, and new profiles skip the old migration blocks. Accepted source retains the mapping. This does not prove native restoration or an upgrade result, and the patch adds no test.

Scope: Calendar checked-state migration.
