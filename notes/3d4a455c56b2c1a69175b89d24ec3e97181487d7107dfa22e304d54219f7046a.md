# Document optional window hooks while preserving registration requirements

677 documents optional chromeURLs, onLoadWindow and onUnloadWindow properties, with the window argument in each callback signature. Current registration still requires an ID, rejects duplicate IDs and requires at least one callback. Optional individual properties do not make the whole hook empty or allow duplicate registration. Proposed manual JSDoc rule: describe the validation relationship between optional properties as well as their types. Type-first annotation syntax is covered by lint and is not counted as a new style rule here.

Scope: Extension window-hook documentation and validation.
