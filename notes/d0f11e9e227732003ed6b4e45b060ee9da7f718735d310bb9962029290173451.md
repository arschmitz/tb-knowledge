# The Localization review group is recorded in module metadata and governance docs

The Localization module covering calendar, chat and mail locale paths gains the thunderbird-l10n-reviewers group in metadata and the matching documentation table. The metadata declares that Markdown document as its export target; timestamp and hash fields change with the addition. This is a scoped historical registration, not proof that a generator ran or an automatic change to current instructions or reviewer policy.

Scope: Thunderbird shared Localization governance metadata.
