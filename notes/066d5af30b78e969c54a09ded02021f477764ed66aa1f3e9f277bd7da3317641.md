# Attachment fixtures and tasks use different local naming forms

The assigned fixture uses lowerCamel inlineBinaryAttachment.eml under messages. Its xpcshell harness is test_ext_messages_attachments.js and the task uses descriptive underscore words such as test_binary_attachments_as_inline_attachments. Scoped naming recommendation: follow the existing harness, task and fixture forms in this directory and name the MIME condition that the fixture exercises. These examples do not establish a project-wide ban on camel case test tasks; other test families use it. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: WebExtension attachment test naming.
