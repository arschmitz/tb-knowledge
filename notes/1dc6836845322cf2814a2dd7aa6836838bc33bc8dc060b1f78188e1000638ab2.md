# Name package locales separately from desktop translation locales

packaging_l10n converts package-locales-file and desktop-locales-file into separate JSON arrays named PKG_LOCALES and DESKTOP_LOCALES. The package loop uses the first to fetch XPIs; the desktop builder receives the second. The helper removes ja-JP-mac. Manual boundary naming proposal: keep the purpose in the name and state the serialization when passing a list through environment variables. Similar-looking locale lists are not interchangeable. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: taskcluster/packaging/locale-names.
