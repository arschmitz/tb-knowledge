# The legacy new-mail alert waits for translated title content before layout measurement

DOMContentLoaded starts prefillAlertInfo, which awaits explicit Fluent translation of the title before synchronously rendering folder-summary nodes. The load path awaits that same promise before checking messages and reading scrollHeight. This is a local completion contract; it does not verify screen-reader announcements, native window placement or a live layout result.

Scope: Legacy new-mail alert initialization.
