# Set subscribe-dialog minimum size on both the host and inner dialog

1105 extends the minimum-size selector from #subscribeWindow to the dialog element as well. Current accepted CSS uses min-inline-size and min-block-size for those same targets. Keep the actual inner dialog in sizing changes and favor the current logical properties. The author reported that the original size remained slightly too short on Windows; no Windows layout, zoom or translated-dialog run was made.

Scope: Subscribe dialog host and inner minimum size.
