# The libotr SDK directory and minimum macOS target are separate build inputs

The historical port aligns both task SDK directories and the script fallback on MacOSX15.5.sdk while retaining distinct x64 and ARM64 deployment targets. The checked script expands the SDK under the fetch directory for sysroot use, but passes MACOS_TARGET_SDK to -mmacosx-version-min. Fixed accepted defaults have advanced to MacOSX26.5.sdk; the old version is historical evidence, not a current SDK recommendation. This is a producer/script-consumer trace. SDK fetch contents, upstream toolchain compatibility and actual builds remain unvalidated.

Scope: libotr macOS toolchain configuration.
