# Sidebar tests wait for a view with positive rows after the document loads

Both tests query the actual auto-tree-view cards element and wait on view?.rowCount > 0. An absent view keeps the wait false instead of throwing, and zero or negative counts do not complete it. The receiver setter permits an absent view as an intermediate state. The following checks still decide the expected card names; this predicate alone does not prove the whole result set is ready. No wait, keyboard or UI run was performed, so the reported intermittent fix is not independently reproduced.

Scope: Address-book compose sidebar test readiness.
