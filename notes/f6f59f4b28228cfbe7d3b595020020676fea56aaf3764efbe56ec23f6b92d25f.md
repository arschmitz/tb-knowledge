# Exchange MIME conversion is selected by the channel URL and starts from RFC822

The protocol handler enables conversion when the URL spec contains part= or convert=true. The channel passes mConvert into AsyncReadMessageFromStore, which installs the message/rfc822-to-*/* converter before reading the pump. The MIME converter then interprets part/output query details; without conversion this helper streams raw message bytes. The current disposition helper parses parameters, while this conversion decision still searches the spec text, so these are separate conditions. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Exchange MIME conversion routing.
