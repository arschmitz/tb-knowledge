# Keep the first Gloda conversation view implementation explicitly historical

1017 introduces an experimental false-default mail.thread.conversation.enabled gate. A selected thread asks Gloda for its header collection, obtains the first item's conversation, then asks that conversation for messages and filters out items without folderMessage. The commit names duplicate sent messages and missing sent-message expansion/location indicators as known issues. The accepted code uses a separate conversation-view element instead of that nested about3Pane listener. Do not present this boilerplate query or its known limits as the final architecture. No Gloda indexing/query or UI run was made.

Scope: Historical Gloda conversation-view bootstrap.
