# The flag-only special-folder localization backout is a historical phase

The partial backout returns special-folder localized names from flags alone after removing both the remote-server exemption and name predicates. That behavior is historical. Fixed accepted remote code later keeps an Inbox name exception and gates other recognized flag/name aliases on a startup preference; local folders have their own override. Preserve those phases and the distinction between stored name and localizedName instead of teaching unconditional flag-only localization as current behavior. Private reports about releases, locales and preference changes are context; the cited code is the public behavior support.

Scope: Folder localization.
