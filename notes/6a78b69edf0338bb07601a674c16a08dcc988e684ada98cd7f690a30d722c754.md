# Preserve the difference between unifinder filtering and calFilter text matching

calFilter checks the same four fields and also categories; a whitespace-only normalValue is accepted as no text filter. Unifinder clears filtering only for an empty searchBox.value and has no category branch or trim guard. Similar normalization helpers do not make these callers identical. Keep the scope and empty-input policy explicit before merging them or claiming one shared behavior.

Scope: calendar/base/content.
