# Dropping the EWS sender's server reference is separate from canceling active work

The original shutdown patch uses an optional server reference as the sender's shutdown state. Its async shutdown drops that reference; server() clones it or returns ClientClosed. The IDL bridge detaches that work and returns. A request can already have obtained credentials before awaiting a later authentication step, so a successful earlier check does not cancel active work. Accepted shared source keeps an optional reference, with separate observer/auth-cache cleanup. Treat reference release, entry-point return and network completion as different events.

Scope: EWS operation sender shutdown ownership.
