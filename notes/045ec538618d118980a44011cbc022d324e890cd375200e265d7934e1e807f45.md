# Account input integer conversion truncates numbers and relies on bounded callers

InputSanitizer.integer returns existing integers, truncates other non-NaN numbers, and otherwise uses parseInt. This is a conversion contract rather than a finite-range guarantee: the accepted matrix explicitly expects positive infinity unchanged. integerRange converts first, then checks its minimum and maximum. The XML port caller supplies 1–65535. Keep the caller's domain check when reusing the conversion helper; the integer name alone does not establish a valid port or safe integer. This behavior was introduced in the historical Sanitizer module and remains in the fixed InputSanitizer module after separate renaming and error-ID changes. Static source and direct test expectations were read; no tests ran.

Scope: Account input sanitization.
