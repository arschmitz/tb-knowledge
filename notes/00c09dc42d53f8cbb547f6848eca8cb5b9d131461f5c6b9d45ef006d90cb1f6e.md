# A failed command-state query keeps each context-menu group's visibility rule

The local wrapper logs a synchronous state-query error and returns false. Ordinary mapped commands use that value to hide the item; always-visible commands use it to disable the item. The injected cmd_markThreadAsRead failure exercises the latter group and asserts that tag rebuilding and separator normalization still occur. This is a scoped fallback and simulated test contract, not a global error-swallowing rule or a runtime result.

Scope: Mail context-menu command-state error handling.
