# Use the folder hash helper as a returned value

1977 replaces an always-success nsresult plus mutated input with const-input overloads returning nsString. The declarations are nodiscard and callers store safeFolderName16 explicitly. Preserve this value-producing contract. Recommend encoding suffixes such as 16 where UTF-16 and UTF-8 copies coexist in these native callers; this is a local clarity pattern, not a universal variable-name requirement. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
