# S/MIME certificate request subject includes email when one is supplied

The CSR follow-up changed an always-empty certificate request subject to CERT_AsciiToName("E=" plus the email) when email is present, with the empty-name path retained when it is absent. Current nsCertGen.cpp still does that. Bug 1581796 explains why the private key must be generated and kept in NSS storage. The reviewer withdrew a post-land concern about ASCII conversion for email. This commit changed no test, so do not infer validation coverage from review acceptance alone.

Scope: S/MIME certificate request generation.
