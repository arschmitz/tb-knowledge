# Thundermail URL dispatch does not wait for account setup completion

The net.thunderbird dispatcher first waits for getOrOpen3PaneWindow, whose helper waits for startup when needed and then delayed startup. It selects an observer service by URL host and calls observe inside try/catch. ThundermailURLHandler.observe starts async #add without awaiting or returning that promise. Thus this dispatch catches synchronous lookup/observer errors and does not wait for Account Hub configuration or join its later rejection. This is a static boundary, not a reproduced error or proof that account creation has finished.

Scope: Thundermail URL observer completion boundary.
