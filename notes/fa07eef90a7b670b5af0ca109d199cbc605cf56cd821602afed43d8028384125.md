# EWS fake-server JavaScript member names do not use C++ m prefixes

Entry 2075 renames MockEWSServer to EwsServer, #mHttpServer to #httpServer, and RemoteFolder mId/mParentId/mDisplayName/mDistinguishedId to id/parentId/displayName/distinguishedId. Consumers and XML response generation change together. The author explicitly rejects m-for-member names in this JS change; it does not define every Thunderbird symbol family. Fixed RemoteFolder in MockServer.sys.mjs keeps these public names, while the adjacent Panorama C++ class legitimately uses m-prefixed fields. Preserve public test-model references and keep language/file-role scope.
