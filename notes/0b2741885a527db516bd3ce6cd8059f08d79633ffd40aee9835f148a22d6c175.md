# Check both the build flag and matching Sync preference block

Entry 1163 changes MOZ_SERVICES_SYNC to a Nightly milestone gate and moves the token-server preference inside the existing Sync preference block. Accepted enable_sync now returns False even for Daily, with a comment about unavailable working servers. The preferences remain under MOZ_SERVICES_SYNC and MailGlue checks AppConstants.MOZ_SERVICES_SYNC before initialization. The 2024 Nightly-enabled behavior is historical, not the current state. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/moz.configure.
