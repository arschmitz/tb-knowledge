# Generic queued operations erase the async future while keeping its borrow lifetime

The public queued-operation trait has an async perform method. Its separate erased trait returns a pinned boxed future tied to the operation borrow, allowing heterogeneous boxed operations in one channel. The EWS adapter keeps the typed response in its own oneshot channel; the runner awaits perform, and the caller awaits that typed response. Per-runner order does not imply a single globally serial request stream when several runners are started. The accepted shared crate is a later phase, and no compile or concurrency execution was performed.

Scope: EWS generic operation queue.
