# Build merge replacements from the transition that actually owns the repository

The 2024 release-to-ESR merge failed because it read from-repo where that configuration did not provide it. The patch used the destination repository, but later central-to-beta merges broke and the fix was backed out before further relands. Current code distinguishes the main-to-beta transition, whose .gecko_rev.yml uses a placeholder for a previously absent GECKO_HEAD_REV, from transitions that replace an existing value. Validate each branch transition and its input keys; one successful Try report is not proof for all merge modes. Current names and ESR versions supersede the historical branch names. No merge was executed.

Scope: Merge automation breakage and transition inputs.
