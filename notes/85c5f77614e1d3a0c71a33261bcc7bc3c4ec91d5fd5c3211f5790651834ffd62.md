# Use the preference-aware week service for calendar range boundaries

CalWeekInfoService reads calendar.week.start on each calculation. getStartOfWeek clones the input and makes it date-only; getEndOfWeek adds six days. Month view obtains both bounds through this service and makes them immutable. Keep displayed range endpoints separate from the exclusive query end, which is cloned and advanced one day. This is the accepted boundary contract, not a rule to use date.startOfWeek for configurable week starts.

Scope: calendar/base/src.
