# Treat folder ID 0 according to the individual Panorama operation

Current root folders have parent 0 and are their own root. getFolderChildren(0), getFolderChildNamed(0, name), and getFolderDescendants(0) may access roots or all folders; getFolderAncestors(0) is rejected. Path lookup returns 0 for a missing path. Do not pass a not-found 0 onward to an operation that interprets it as the root collection. These rules are checked for this interface, not all Thunderbird folder IDs. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama zero-ID contracts.
