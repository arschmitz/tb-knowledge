# Use unique CSS-safe TreeView column IDs

AutoTreeView.defaultColumns accepts each column only once and rejects missing IDs, IDs already in the document, and IDs containing characters outside ASCII word characters or hyphens. Rows derive class names from column.id.toLowerCase() and selectors use the ID. browser_autoTreeView.js tests duplicate IDs, punctuation, and spaces. This is a concrete naming rule for AutoTreeView columns, including extension-defined columns; it is not a rule for all DOM IDs. Current code keeps the guard.

Scope: Tree column naming.
