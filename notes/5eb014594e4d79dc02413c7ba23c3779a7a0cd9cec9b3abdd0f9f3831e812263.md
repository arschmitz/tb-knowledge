# Online-search capability preserves an allowed saved checkbox choice

Availability and checked are separate virtual-folder values. The original disabled port assigned checked to inverse capability unconditionally, replacing an allowed saved choice and checking the unavailable case. Accepted updateOnlineSearchState forces disabled when no selected server is online-capable and clears checked only then. The caller loads searchOnline before this check, reruns it after folder selection, and stores checked as onlineSearch on acceptance. The accepted branch preserves an allowed choice. This is source analysis, not a reproduced UI regression.

Scope: virtual folder properties.
