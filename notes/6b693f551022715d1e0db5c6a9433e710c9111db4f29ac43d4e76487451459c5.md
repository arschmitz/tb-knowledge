# Verify extension host-provided globals before removing imports

1027 removes redundant imports in the extension parent scripts and records host globals in the historical lint configuration. The independently identified Gecko snapshot's _createExtGlobal supplies AppConstants, XPCOMUtils and ExtensionCommon, plus a lazy ExtensionUtils. Current Comm still explicitly imports XPCOMUtils in ext-mail, so the cleanup is not a rule to remove every repeated import. Check the actual host scope for the code being edited; standalone ES modules need their own import contract. The Gecko snapshot was not built as a matched Comm pair.

Scope: Extension parent host global boundary.
