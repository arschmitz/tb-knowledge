# The Thundermail URL test needs messages on its field and error assertions

The new URL setup test checks account/server/identity fields and the repeated-setup error, but several assertions omit the message argument. The error helper also omits messages from its error-class and localization checks. These same examples remain in the selected accepted source. Nearby section comments and field values do not provide assertion diagnostics. A message should state each expected result; the missing messages do not make the checked values incorrect, and no test was run.

Scope: Thundermail URL browser test diagnostics.
