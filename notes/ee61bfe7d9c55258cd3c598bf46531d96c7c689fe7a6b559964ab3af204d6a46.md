# Queue documentation examples must match the actual receiver and owner

The README sketch implements perform() without the &self receiver required by QueuedOperation. Runner::new documentation also calls its returned owner a queue, although the implementation returns Arc<Runner> and run consumes Arc<Runner>. These local examples should name the actual receiver and value. Placeholder sketches and imported documentation are not proof of a compiled example; no documentation test ran.

Scope: operation-queue documentation accuracy.
