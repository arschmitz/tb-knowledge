# Disabled toolbar buttons are restored to stored order after customization

Customization emits old and newly persisted currentsets. A global tracker uses disabled-extension prefixes to restore missing IDs in the XUL store after the nearest surviving predecessor, or at the start when none survives. It avoids duplicates and does not recreate inactive DOM buttons. Manifest setup removes protection; non-app shutdown adds it. This preserves the intended stored-position contract without a live enable/disable/customize result.

Scope: Extension toolbar persistence protection.
