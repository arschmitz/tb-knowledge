# Calendar options default differs from destination list

For D332509 at revision bf9bb06ea004bd392f67d079c3145ab2978cafb2, the AI verification record reports that loadCalendarOptions returns null for defaultCalendar when no default ID is supplied. With an ID, the default result can include a calendar excluded from the filtered calendars list. The proposed documentation fix should explain these separate results and identify calendar.list.sortOrder as the ordering source, so callers do not assume the default is a usable destination. The record says the create caller supplies and checks the host default, while the edit caller supplies no ID. This is an AI-reported source interpretation, without source excerpts or independent confirmation in the supplied evidence. The documentation change remains unapplied.

Scope: Calendar event calendar options.
