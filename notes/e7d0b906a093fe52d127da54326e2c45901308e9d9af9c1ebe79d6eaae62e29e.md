# Native password reveal replaces custom buttons through shared icon resources

The d6d645366c7d652cf0f041bad8dc1de7bf5199dd patch removes custom password reveal buttons, click handlers, localized show/hide strings and textfield appearance rules. Required Account Hub password inputs and explicit labels remain. The theme manifest overrides the native eye and eye-slash resource URLs with two explicitly packaged lowercase SVGs. Each SVG uses context-fill and reduced opacity on one path. These resource URLs, jar entries and filenames must agree for resource lookup. Password-specific logical end padding changes in the selected setup stylesheets. The fixed revision retains the mappings and byte-identical icons. The changed legacy test helper keeps remember-password state checks but removes custom reveal and input-type assertions without adding native reveal coverage. Its two remaining assertions lack messages. No native behavior, build, accessibility check or test ran.

Scope: Account setup native password reveal integration.
