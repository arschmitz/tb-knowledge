# Transaction failure does not imply automatic rollback

The imported AI summary reports that CalTransactionManager.commit() removes a failed transaction from undoStack and rethrows without automatically calling undoTransaction(). It also reports that cross-calendar moves add the destination before deleting the source, with pendingMoveCopies tracking partial copies and cleanup retries. This matters when explaining failure recovery: a rejected operation must not be described as proof that all provider changes were undone. Treat these details as provisional until checked against current source; no source revision or independent execution evidence is supplied.

Scope: Calendar transaction failure recovery.
