# Database ownership names should describe acquisition rather than mere existence

The boolean weOpenedDB is derived before msgDatabase is accessed and controls cleanup of a missed lookup. Scoped manual naming recommendation in this helper: keep an ownership name for the fact that this operation caused acquisition, rather than renaming it to a generic databaseExists flag. A preexisting reference and a newly opened reference have different cleanup rules; the name alone does not guarantee all exceptional cleanup. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: MailUtils database acquisition naming.
