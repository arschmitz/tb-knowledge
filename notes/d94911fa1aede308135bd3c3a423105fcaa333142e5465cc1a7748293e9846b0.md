# The libotr SDK version is separate from its minimum macOS target

The landing updates the SDK directory for both macOS builds while retaining different x64 and aarch64 deployment minima. Current configuration uses an even newer SDK but still passes MACOS_TARGET_SDK to -mmacosx-version-min; MACOS_SDK_DIR selects the sysroot. Preserve those separate contracts when updating a toolchain. Acceptance and the configured directory name do not prove the SDK was fetched or the cross-build passed. No toolchain build ran.

Scope: libotr macOS toolchain.
