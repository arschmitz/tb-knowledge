# The legacy IMAP UID-string failure prints the previous result

The legacy standalone source checks uidString2 against 69,73 after an expunge, but its failure branch prints uidString and says not 71. A failure at that branch would therefore describe the earlier result rather than the checked buffer and expectation. This is a static diagnostic mismatch in unchanged context, not a failure introduced by the ImapUid patch. The examined current test build file does not explicitly select this standalone source; active registration and execution were not established.

Scope: Legacy standalone IMAP flag-state test diagnostics.
