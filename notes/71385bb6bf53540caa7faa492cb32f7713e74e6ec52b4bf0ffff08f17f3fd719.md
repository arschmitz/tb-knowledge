# Targeting payload names differ from JavaScript helper and test names

This notification schema uses serialized pref_true and pref_false keys. The local method is checkProfile, task names contain prefTrue or prefFalse, and the test filename is test_notification_filter.js. Keep the payload keys unchanged at this boundary while matching each local naming family for new helpers and tasks. This is a scoped syntax/naming recommendation from source; it does not justify renaming wire keys or imposing one case style across all Thunderbird code. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Notification targeting naming.
