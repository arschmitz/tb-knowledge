# Compose Find and Replace keeps its editor argument when opening a dependent window

The owned change replaces modal with dependent in the Find and Replace openDialog feature string. It keeps editorElement as the argument, and the dialog obtains its editor from window.arguments[0]. The current regression task clicks Replace All and closes the dialog before asserting that lowercase apples is absent. That direct check does not establish immediate repaint while the dialog remains open, plaintext-specific behavior or focus/accessibility results. Keep this window-feature change separate from later replacement-algorithm changes.

Scope: Compose Find and Replace dialog contract.
