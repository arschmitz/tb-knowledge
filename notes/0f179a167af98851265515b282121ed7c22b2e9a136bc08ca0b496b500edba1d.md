# Parser completion is a direct operation rather than a fake stream callback

nsParseNewMailState directly inherits the message-state parser, line buffer and filter notifier. DoneParsing publishes the current header and updates folder database information. POP3 EndMailDelivery and the legacy local AddMessageBatch call it explicitly instead of faking OnStopRequest(nullptr, NS_OK). The transport/store caller owns success and failure; DoneParsing is void and is not proof those earlier operations succeeded. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/local/src.
