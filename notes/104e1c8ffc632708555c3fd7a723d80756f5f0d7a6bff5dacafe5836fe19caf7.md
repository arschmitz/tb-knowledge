# Do not describe a spaces update as a transaction across windows

Current adapters convert cloned data before updating mail windows and only then commit tracker data. That avoids early tracker mutation on conversion failure, but each window is updated sequentially with no rollback. Create adds tracker data before creating all window buttons. Treat this as partial failure handling, not atomic multi-window publication. No failing-window experiment was run. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces multi-window updates.
