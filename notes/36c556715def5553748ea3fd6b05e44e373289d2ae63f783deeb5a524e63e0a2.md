# AutoSync activity reads pending counts through the base folder capability

The activity listener reads folder.autoSyncStateObj.pendingMessageCount without querying the IMAP folder interface. Fixed code retains that base capability inside its priority-queue callback, with later activity construction factored into a helper. This allows non-IMAP participants to supply state, but does not make every arbitrary folder a valid participant or prove activity UI updates. No activity test ran.

Scope: Activity module priority-queue listener.
