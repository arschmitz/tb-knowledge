# Refresh the baseline for each successive deletion assertion

The 741 test cancels deletion, accepts one deletion, then focuses the message pane and accepts another. In both success cases it compares the new selection with curMessage from before the first deletion. The second comparison alone cannot prove the third action deleted its own selected message, because that original message is already gone. Other helpers may check completion; their existence does not strengthen this particular inequality. Proposed manual test rule: capture a fresh baseline before each independent action. The stale baseline remains in the fixed accepted excerpt and was not repaired by this study.

Scope: Message deletion test assertions.
