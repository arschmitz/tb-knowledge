# Record OS settings and a regressed baseline when validating native tint

Observed Bug 1906037 corrected a false visual check: Reduce transparency disables wallpaper tint, and ESR 115 predates the regression. Its useful test setup uses wallpaper tint enabled, colorful wallpaper, and a version known to contain the regression. Current Thunderbird titlebar CSS remains preference-gated and transparent. Record those preconditions when checking the native appearance; browser_parsable_css success alone does not prove tint is visible. This study changed no OS settings and ran no visual experiment.

Scope: mail/themes/osx.
