# Linux Docker test worker aliases preserve the requested AMD suffix

The owned worker alias expansion adds t-linux-docker-amd and t-linux-docker-noscratch-amd while keeping docker-worker/Linux routing and worker-type {alias}. Current config uses optional noscratch/amd groups and a trust-domain provisioner; the source-test taskgraph job requests t-linux-docker-amd. Preserve the full requested alias when updating pool-name coverage. This is source configuration, not proof of live workers or a successful generated graph.

Scope: Taskcluster Linux test worker routing.
