# The location external-dispatch assertion lacks its expected-behavior message

The location test arms the external-protocol mock, clicks the link and compares the captured URI, but the changed Assert.equal call has no message argument. Its neighboring text/href and beforeunload checks do have messages. Add a nonempty message that says the location link should dispatch the expected URI externally. This is a scoped test-review finding; the source assertion and mock do not prove a native browser launch or a fresh passing test.

Scope: Calendar dialog location test review.
