# Distinguish a test preference default from enabling a feature

The 2024 Sync fix made the token-server preference available outside the nightly-only block so scheduled tests on other channels could read it. Review retained the Firefox-compatible preference order and added a blank line at the block boundary instead of relocating the entry as proposed. Current preferences are under MOZ_SERVICES_SYNC, and current configure explicitly disables Sync until working servers exist. Thus the old stage-server default is not a current recommendation to enable Sync or a server policy. No Sync request or scheduled test was run.

Scope: Sync configuration and rejected style feedback.
