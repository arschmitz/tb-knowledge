# Strip inherited body colors before restoring compose color preferences

NotifyComposeBodyReady invokes QuoteSanitizer for HTML documents that contain cited or forwarded markup, then calls loadHTMLMsgPrefs. The helper removes inherited body text/background attributes; preference loading sets those attributes only when they are absent. Keep that guard and order together. The original wrapper-background removal and the later dark-mode heuristic are separate phases, and DOM string tests do not establish rendered containment or visual equivalence.

Scope: Compose quote sanitizer caller contract.
