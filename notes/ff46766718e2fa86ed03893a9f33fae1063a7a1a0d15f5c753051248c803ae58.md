# Legacy address import separates token defaults from Mork token initialization

The nsAddrDatabase constructor explicitly zeroes the previously omitted row-scope and column-token members. InitMDBInfo later obtains token values from the Mork store under its existing store, environment and initialization guard. Scope helpers compare those stored tokens. A deterministic initial value is separate from opening the database or successfully resolving its token names; this constructor patch adds no runtime or migration validation.

Scope: Legacy address-book import database tokens.
