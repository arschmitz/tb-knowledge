# Skip tree transitions for reduced motion or a collapsed ancestor

At the accepted endpoint both tree directions avoid animation if prefers-reduced-motion matches or the row sits below a collapsed ancestor. Collapse applies hidden-state handling; expansion restores child height. Preserve the descendant/ancestor check alongside the user motion preference. This is current static behavior, not a rendered proof for every nested or interrupted transition. These are fixed accepted source and test-code observations.
