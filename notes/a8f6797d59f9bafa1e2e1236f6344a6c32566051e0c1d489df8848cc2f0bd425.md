# Removing the screenshot override retains built-in theme preview resources

This commit removes only the local getScreenshotUrlForAddon interception and its two-theme URI map. The built-in theme helper still maps configured theme paths to preview.svg, and the resource packaging still includes both light and dark previews. Those local source facts support the narrower decision to keep the assets. They do not prove the unpaired toolkit preview caller, SVG pixel equality or rendered UI behavior.

Scope: Thunderbird add-on manager theme preview integration.
