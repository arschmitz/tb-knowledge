# Change the selected-day border axis when the calendar rotates

The current normal multi-day grid uses inline borders for selected-day headers/hour boxes, while the rotated grid uses block borders. Preserve the same selected state while changing geometric axes; blindly replacing physical properties with one logical axis can still be wrong for rotation. RTL and orientation validation remain unrun.

Scope: calendar/base/themes/common.
