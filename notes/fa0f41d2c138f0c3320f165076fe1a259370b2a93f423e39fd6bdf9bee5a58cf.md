# Document the secret-key import result holder as keys

importSecKeyFromFile documents importedKeysObj.value, but writes importedKeysObj.keys. Its checked keyWizard caller consumes resultKeys.keys. The nearby public-key wrapper uses importedKeysObj.value, so the two entry points do not share one output-holder shape. For this secret-key method, document the actual keys property and its array contents rather than copying the public-import annotation. This is a scoped naming and documentation recommendation from the accepted caller and implementation. It does not establish a project-wide output-property convention or a runtime defect. No import, native-library, build, lint or live accessibility test ran. Full Bugzilla and Phabricator discussion remains pending.

Scope: OpenPGP secret import output documentation.
