# Blank custom DoH input and default mode use different preference values

The custom-provider input writes a single space to network.trr.uri when its field is empty. Default Protection instead clears the URI and disable-heuristics user preferences; Increased/Max protection fill fallbackProviderURI only if the URI is empty, and Off clears the URI. Do not replace the sentinel, empty check and clear operation with one generic fallback expression. These are UI preference transitions, not proof of a successful DNS request or backend fallback policy. No preferences or network test ran.

Scope: DoH custom URI state.
