# Scope shortcut localization cleanup to the component-owned instance

The shortcut review tentatively questioned disconnecting a DOMLocalization instance owned by this component, because a visible root could then remain disconnected. The final initial scaffold connects its own shadow root and contains no disconnectedCallback. This supplies the review rationale missing from the existing initialization lesson. It is an accepted local choice with tentative review wording, not permission to omit listener, observer or localization cleanup in other widgets. Reconnection and translation behavior were not executed.
