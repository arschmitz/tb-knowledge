# The read-dialog titlebar separates the calendar name from the cached event heading

The header places the visible calendar name and actions in one flex row, and the h2 event title in a second row. CalendarDialog caches that h2 as #title and updates or clears its text and combined calendar/event tooltip with the event lifecycle. The test selectors move from .event-title to .calendar-dialog-title. The calendar color marker and line clamp are scoped CSS behavior; separating the markup is not a tested accessible-name or rendered-layout result.

Scope: Calendar read-dialog titlebar.
