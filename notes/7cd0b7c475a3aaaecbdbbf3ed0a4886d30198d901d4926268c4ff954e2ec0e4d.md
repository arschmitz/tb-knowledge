# Keep Google vCard unescaping inside its value-type branches

VCardProperties.fromVCard normalizes Google-specific escaping only when isGoogleCardDAV is true. Array values remove escaped carriage returns and colons. Scalar URI/phone values additionally remove comma, semicolon and backslash escapes; scalar text additionally removes semicolon escapes. The scalar text branch is separate from the array branch. Preserve this boundary when changing normalization rather than applying one unescape expression to every parsed value. The scoped test compares property data and normalized serialization; no live CardDAV exchange or imported parser internals were verified. No test or runtime ran.

Scope: Address-book vCard normalization.
