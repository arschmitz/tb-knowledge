# Contact-photo keyboard paste reads supported clipboard sources without waiting for image validation

The keyboard path handles Meta+V on macOS or Control+V elsewhere because the non-editable photo button may not receive paste. Its transferable prefers application/x-moz-file and otherwise accepts only an https:// text URL, then reuses showWithFile/showWithURL. The Boolean result only says it forwarded a supported source; image loading and preview validation happen later. Existing browser code waits for that preview and checks an invalid-image banner. No clipboard, keyboard or accessibility test ran; the later accepted button repeat guard is a separate phase.

Scope: Address-book photo clipboard input.
