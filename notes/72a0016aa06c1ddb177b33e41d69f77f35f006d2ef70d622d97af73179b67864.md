# Keep asynchronous test predicates observational when checking inserted content

1026 replaces editor.selectAll() plus getSelectedElement("img") with a query of editor.document.body for an img. The wait now observes insertion without changing editor selection on every poll. The accepted helper also checks that inline content did not enter the attachment bucket. Use a read-only predicate for this insertion wait; it avoids making the act of waiting alter the state being tested. No editor drag operation was run.

Scope: Compose inline-image wait side effects.
