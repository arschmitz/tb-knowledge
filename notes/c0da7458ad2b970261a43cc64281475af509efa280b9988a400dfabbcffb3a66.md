# Scope notification focus monitoring to the displayed notification

1030 adds window focusout observation when a notification is shown and removes it on hide and disconnect. Keep this transient focus watcher tied to visibility; observing the whole window while no notification exists can change the saved restoration target for unrelated actions. This is a narrow focus-monitor ownership lesson. Current later keydown shortcut logic is a separate refinement and is not counted as part of 1030's original change.

Scope: In-app notification transient focus monitor.
