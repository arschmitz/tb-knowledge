# Offline append copy retains the temporary file and separates setup from asynchronous completion

Offline append clones the temporary file to avoid cached stat/size data, keeps m_curTempFile, and calls the named Copy service with this as completion listener. The immediate return checks call setup; completion/error arrives through OnStopCopy. Copy-service cleanup sets pending removal and notifies that listener before removing and deleting its request. Preserve these distinct file, receiver and request lifetimes during service-access cleanup. No runtime test.

Scope: imap-offline-copy-lifetime.
