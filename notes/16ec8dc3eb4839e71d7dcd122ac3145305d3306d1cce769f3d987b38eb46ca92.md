# A complete about:blank document does not satisfy the checked load waits

The changed address-book and message-browser guards wait when the document is incomplete or still about:blank. The generic browser/frame helper likewise rejects a blank location before evaluating the caller URL predicate. Address-book reuse waits for about-addressbook-ready; the message path waits for load. Preserve the actual consumer event and target check when reusing these guards. Static source does not establish remote sync, focus or all rendering completion.

Scope: Browser and address-book readiness.
