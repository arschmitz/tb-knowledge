# Validate manual inline review anchors

The imported Task 3 summary reports that `addGraphPatchReviewInline` accepts manual `{ filePath, lineNumber, lineLength }` anchors only for contiguous new-side lines in the rendered patch. This protects exact-patch comments from attaching to another file or an invalid range. Test locators must also include the file because line numbers repeat across files. This is a reported implementation detail, not independently checked source evidence; verify current behavior before reuse.

Scope: console patch review.
