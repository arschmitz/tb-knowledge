# IMAP mailbox status names are localized at the folder sink

ProgressEventFunctionUsingNameWithString forwards the protocol mailbox identity to the folder sink. ProgressStatusString resolves that identity with FindOnlineSubFolder, asks the matched folder for GetLocalizedName and formats the user-visible status. The IDL, implementation and synchronous wrapper change together from a UTF-16 display argument to a UTF-8 mailbox name. A missing local match leaves the substituted name empty; there is no raw-mailbox fallback in this path. The protocol's actual wire mailbox names remain separate.

Scope: IMAP status feedback.
