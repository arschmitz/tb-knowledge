# An asynchronous add-on state lookup is separate from immediate config rendering

EmailConfigFound stores a configuration and starts setAddon while updating the fields separately. setAddon awaits the first configured add-on installation and disabled-state checks; when installed, it updates addonAccountType on all exchange alternatives. Keep the asynchronous state check distinct from synchronous display rendering. The selected current source does not prove every interleaving or disabled-add-on callback path works; proposed tests should cover fast selection changes during lookup. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
