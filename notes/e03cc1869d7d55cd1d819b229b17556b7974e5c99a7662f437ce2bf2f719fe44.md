# SendListener completion and filing the sent copy are separate test conditions

SendListener resolves or rejects on send-stop, send-not-performed and transport-security callbacks. It does not implement copy-service completion. The FCC test therefore awaits sendListener.promise and then separately waits until the target folder contains one message. The original helper rejects raw failure statuses, while accepted later code rejects Error objects. The count wait establishes the fixture condition, not message-content correctness, copy-failure handling or a live server result. No test ran.

Scope: mail-send-test-completion.
