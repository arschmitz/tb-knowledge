# Removing the offline source-key shadow does not remove source-message identity

1252 removes the unused m_sourceMessageKey member and assignments while preserving GetSrcMessageKey/SetSrcMessageKey as database-property operations. Accepted IDL distinguishes the operation messageKey from srcMessageKey and srcUid. The destination offline operation stores the original source key, and counterpart matching checks both the source folder URI and source key. Replacing these values with a destination key would change identity even though the old shadow field is gone. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
