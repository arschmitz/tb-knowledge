# The shared EWS properties helper resolves a loaded window, not repair completion

The shared async openFolderProperties waits for the folder context popup, registers the window-open promise before activating Properties, then returns that promise. It resolves a dialog window. Callers own repair clicks and acceptance; the repair test separately waits FolderLoaded and dialog close. Replacing its earlier object-with-methods contract requires adapting both callers. Async promise completion and documentation should name what is ready. Static helper/caller inspection only.

Scope: EWS browser-test dialog helper.
