# The octet-stream quoted-printable task checks decoded part content after trimming

The local task supplies an already quoted-printable payload, marks its transfer encoding, injects one octet-stream attachment and fetches part 1.2. SyntheticPartLeaf returns the supplied body unchanged, while makeMessage places the ordinary body before that attachment. The direct assertion awaits the fetch and compares trimEnd() with key=value. This supports one decoded-content check. It does not check exact trailing whitespace, an attached .eml, inline rendering or Save/Open behavior. Static source inspection only.

Scope: MIME xpcshell attachment decoding.
