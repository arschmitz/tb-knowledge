# Choose the mock protocol promise path or recorded URL path and restore the service in cleanup

3040 centralizes external-protocol test observation. loadURI resolves a pending promiseLoad with uri.spec; only the other branch appends urls. Tests that await a load must compare the returned string. Tests using recorded history can call assertHasLoadedURL to check exactly one target and clear it; its Boolean return JSDoc is stale because no value is returned. reset clears history and rejects a pending wait. cleanup also checks unhandled URLs and restores XPCOM registration. A reset-only cleanup hook does not restore registration; the selected offline test still uses that form. These are mock contracts and static findings, not proof that a native browser opened.

Scope: mailnews test MockExternalProtocolService.
