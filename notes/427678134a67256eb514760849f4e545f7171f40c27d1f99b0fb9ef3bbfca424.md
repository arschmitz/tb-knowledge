# Forward every context paint property an SVG state uses

The checked/selected menu icon rule forwarded stroke but omitted fill, so a selected address-book icon looked solid rather than having a lighter fill. The accepted rule forwards fill and stroke together and the endpoint retains it. Inspect the SVG paint contract and checked/selected states when changing themed icons. Source and reported Linux QA were read; no contrast measurement or live theme/platform rendering was done.

Scope: mail/themes.
