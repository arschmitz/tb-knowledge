# The Today Pane test setup keeps mutable top-level var bindings

The setup patch changes calendar, today and startHour from eagerly initialized const bindings to top-level var bindings assigned inside add_setup. The accepted file retains that local choice while nearby stable DOM references remain const. This supports a scoped example for this shared test script, not a requirement to use var in other files or environments. No binding or timing experiment ran.

Scope: Calendar browser-test binding scope.
