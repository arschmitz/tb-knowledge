# Native graphic-cell values and displayed cell text have separate localization roles

The migration removes raw junk-score text from CellTextForColumn and formats graphic-cell values from about3Pane.ftl in GetCellValue. The accepted function guards positive attachment, starred and spam states, while the read column supplies both Read and Unread labels. Its older comment still lists Read among empty normal states. These are source roles; the upstream accessible fallback and spoken output were not independently verified.

Scope: db-view-graphic-cell-value-localization.
