# External EML key zero is distinct from a nonzero mailbox lookup failure

Accepted GetMsgHdrForKey returns NS_OK early for key zero to avoid walking all folders for an external EML. Its raw C++ branch does not initialize the out pointer itself, so do not claim a universal null out-param guarantee. The protocol takes the EML path before calling GetMessageHeader; nonzero failures propagate, and no matching database now returns NS_ERROR_UNEXPECTED rather than the historical benign return. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/local/src.
