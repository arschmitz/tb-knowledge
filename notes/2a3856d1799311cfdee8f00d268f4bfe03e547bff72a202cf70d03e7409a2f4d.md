# Keep monthly release aliases distinct from ESR alias families

945 enables the monthly release branch of release-bouncer-aliases for installer, SSL installer, MSI and MSIX products. The accepted configuration selects aliases by release-type and retains separate beta, release and ESR families; ESR version numbers have advanced since 2024. Preserve the release-type distinction when updating release automation. This source configuration does not verify the external download service or actual shipped alias destinations.

Scope: Release bouncer alias selection.
