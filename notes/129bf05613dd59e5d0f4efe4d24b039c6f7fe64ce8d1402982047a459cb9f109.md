# Arm shown and closed notification promises before triggering their events

The load-message notification test records the shown promise before message injection and the closed promise before restoring/selecting the folder’s message. This catches events that can happen during those actions. Waiting for a method return alone would not establish that the alert closed. The current test selects row zero after injection; this study does not infer every message-order or multi-alert case from that one fixture. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/test/browser.
