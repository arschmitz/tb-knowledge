# The permanent-decrypt signed-icon assertion checks src state rather than visibility

The added permanent-decrypt assertion says the signed icon should be shown, but hasSignedIconState only checks whether an element matches the requested image-src substring. It does not check the icon’s hidden attribute, hidden ancestors or rendered visibility. The markup carries hidden state separately. Keep the assertion’s claim limited to the verified src state, or add an actual visibility check if showing the icon is the intended requirement. This static mismatch does not establish that the test currently passes with a hidden icon or that a live UI regression exists.

Scope: OpenPGP browser test assertions.
