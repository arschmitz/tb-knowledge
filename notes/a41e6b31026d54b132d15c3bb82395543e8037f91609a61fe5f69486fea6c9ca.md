# The initial EWS Get Messages test patch signals sync success after all pages

The assigned first landing adds EWS to the shared Get Messages inbox scenarios and calls OnSyncComplete after the pagination loop, following each page token update. Its C++ callback emits FolderLoaded. This first landing was subsequently backed out for a Mac test failure and later relanded with changes; it is historical behavior, not the accepted callback implementation. Current completion has moved to a shared success wrapper and count-update/mOnStop consumer. No execution or later moved event-order resolution is claimed.

Scope: ews-sync-and-fakeserver-tests.
