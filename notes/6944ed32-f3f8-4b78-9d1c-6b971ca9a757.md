# Scope macOS in-content popup alignment to unpositioned popups

Thunderbird has its own common.css, so an upstream macOS fix needed a comm port. The rule resets margin-inline-start only for menulist popups without a position attribute. The bug reproduced a 13-pixel left shift in Settings font menus. Keep the platform and selector scope when editing popup alignment.

Scope: macOS menu layout.
