# Removing nsIMsgWindow.closeWindow does not remove DOM closure or other caller cleanup

The 485c41a phase removes the nsIMsgWindow.closeWindow API, its destructor call and its explicit callers. The removed native method performed docshell network-stop/listener cleanup and released its transaction manager. This is a different operation from DOM window.close. ComposeUnload still performs its other cleanup and closes the DOM window; searchOnUnload still closes its folder display and removes the controller. Later docshell and transaction-service changes explain the smaller fixed accepted nsMsgWindow. These source facts do not prove equivalent native shutdown or network behavior, and the changed tests only remove cleanup calls.

Scope: mail window lifecycle.
