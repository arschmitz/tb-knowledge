# Download-selected enablement permits an absent message view

The historical cmd_downloadSelected predicate adds optional access through gViewWrapper.dbView; fixed source uses gDBView?.numSelected. With no view, the comparison is false and the command remains disabled. The folder, server and online conditions stay in place. This does not change the command action or establish a complete compaction/display-loss fix.
