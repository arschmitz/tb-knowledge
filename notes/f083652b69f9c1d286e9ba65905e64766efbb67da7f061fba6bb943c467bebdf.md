# EWS hierarchy helpers move beside their operation while Exchange identifiers become shared

This change moves three private hierarchy helpers out of the general client impl and passes a borrowed client explicitly. It also moves the unchanged root string and ordered distinguished-ID values into protocol_shared with EXCHANGE_ names, then updates the EWS hierarchy/connectivity references. Sharing those constants does not implement Graph synchronization in this four-path patch. The explicit domain prefix is a scoped ownership choice; it is not a general Rust naming rule or proof that every provider returns responses in request order.

Scope: Rust EWS folder-sync ownership and shared constants.
