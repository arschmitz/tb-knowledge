# Check asserted relationship fields separately from declared expectations

In the accepted testRelations task, expectedRelations declares childIds, but the assertion loop checks roots, parents, ancestors, descendants and relationship predicates without reading childIds. The parent row even includes parent itself in that unused array. Declaring this value does not test getFolderChildren for that parent. testRootAccess separately checks children of ID0; it does not validate every declared non-root child list. This is a static test coverage gap, not proof of a failing folder implementation. When extending this exact test, make the expected fields that matter participate in assertions. No test ran.

Scope: Panorama hierarchy tests.
