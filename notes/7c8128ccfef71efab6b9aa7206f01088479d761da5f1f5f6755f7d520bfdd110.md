# Separate space tab data from button presentation data

The five-part spaces chain replaces a URL-only tracker with tabProperties and buttonProperties, extracts shared conversion into ExtensionSpaces.sys.mjs and updates both API adapters and the native toolbar. Accepted SpaceData retains this separation. Keep URL, container and browsing context in the tab branch, and title/icon/badge state in the button branch. A browser schema object and its converted native object have different contracts. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces data boundaries.
