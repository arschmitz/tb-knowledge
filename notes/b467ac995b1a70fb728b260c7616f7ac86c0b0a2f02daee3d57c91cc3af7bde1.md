# Tree selection no longer has a displayed-message fallback in nsMsgDBView

Entry 1512 removes cached currently-displayed-message state. Without a tree selection, current GetNumSelected returns zero and GetViewIndexForFirstSelectedMsg returns the None sentinel; GetHdrForFirstSelectedMessage then returns null. A separately displayed message is not an implicit DB-view selection. Keep display ownership in the front end rather than recreating the deleted native cache. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Message view selection.
