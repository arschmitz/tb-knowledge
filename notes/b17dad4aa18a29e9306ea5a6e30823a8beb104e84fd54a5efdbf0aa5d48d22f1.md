# Initialize custom thread columns through both row markup and the DB view handler

1272 changes first-load updateColumns: it appends cells for columns already in this.columns and calls addCustomColumn(id,false) for missing custom columns. Accepted addCustomColumn pushes the definition, reapplies persisted state and registers the gDBView handler, while the false update argument avoids recursive rebuilding. A row-template cell alone does not supply sorting/data behavior. No dedicated first-load custom-column test was added in this landing or run in this study. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
