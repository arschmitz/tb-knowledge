# The external OAuth manifest keeps redirectionEndpoint as an exact string

Only redirectionEndpoint drops the schema URL format while remaining a string; the other two endpoints keep URL format. The manifest consumer passes that value directly to registration. The xpcshell test expects http://localhost without an added slash, which checks stored provider details rather than a live redirect or authentication result.

Scope: Thunderbird external OAuth provider manifest.
