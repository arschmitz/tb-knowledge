# IDL method casing and its C++ call spelling are different surfaces

The converter declaration changes SetMimeOutputType to setMimeOutputType in IDL, while the fixed C++ implementation and compose caller retain SetMimeOutputType. The import service shows the same scoped distinction for createRFC822Message/CreateRFC822Message. Read the actual language consumer before changing caller names during an IDL cleanup. The review’s C++-only statement is supported for the named checked setter points, not a global absence proof for every interface member or external consumer. No generator or build ran.

Scope: IDL and C++ naming.
