# Account hub status icons use shared image classes and separate input state

The account hub replaces inline image sources with shared icon classes defined in widgets.css, as requested in review. The inspected markup combines an image class such as icon-success with an input-state class such as input-success, while the input and its error label keep their own validation association. Do not infer an image or severity contract from a class name alone; the fixed warning class uses the info image in this family. The 100ms discussion experiment was diagnostic, and later failures remained. No icon rendering, native timing or accessible-tree test ran.

Scope: Account hub status icons.
