# Read knowledge Git blobs in batches with explicit boundaries

Knowledge sync uses git cat-file --batch and validates each returned object ID, blob type, byte length and boundary before importing content. Reject files larger than 4,000,000 bytes. This removes per-file Git process creation while retaining input checks. A clean GitHub clone passed all record checks and citation checks. Repeated checkout import took about 189 ms in that measurement; fresh import still took about 8.4 seconds for 7,938 records.

Scope: knowledge.
