# Register space-tab load observation before opening the tab

The container test installs tabs.onUpdated first, remembers the expected URL and resolves only after that URL and status complete have both occurred. It then checks spaceId and query identity, and removes the listener. Keep that event/identity ordering for new nearby tests. The scenario name test_open_programmatically_with_cookieStoreId documents the condition; the browser_ext_spaces.js file keeps the extension harness family. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces asynchronous test naming.
