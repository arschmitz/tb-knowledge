# Filter counts move from a XUL value property to an HTML Fluent text target

The count target becomes an HTML div instead of a XUL label. updateCountBox stops writing value and assigns Fluent messages whose values use count for the full list or visible/total for a filtered list. The total is the filter model count; the visible count comes from the listbox. Keep the DOM target role and these two numeric producers separate. This is source/recipe inspection with no UI or localization execution.

Scope: Filter list count localization.
