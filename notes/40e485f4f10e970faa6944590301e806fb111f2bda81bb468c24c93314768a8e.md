# The optional folder mapper keeps absence separate from validation failure

The cleanup replaces an and_then closure returning Some(Result) with Option::map returning the Result directly. The surrounding filter_map still skips an absent optional folder while retaining validation and other errors for fallible collection. Accepted moved code keeps this shape and later adds another skipped response code. This exact expression supports the map choice; it is not a rule to replace every and_then or proof of provider/response behavior. No Rust or server test ran.

Scope: ews-well-known-folder-mapping.
