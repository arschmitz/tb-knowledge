# Derive the icon inventory from computed CSS variables

The icon story reads computed custom properties from the document root, keeps values that look like supported image URLs, sorts names and renders each name beside its preview. This keeps the inventory tied to icons.css instead of maintaining a second icon-name list. --icon-loading has its own sprite-animation treatment. The filter is a scoped implementation detail: it does not prove that every possible image representation is included or that each preview has a suitable accessible name. No Storybook render or assistive-technology check ran.

Scope: Storybook icon inventory.
