# The login-removal helper keeps an inaccurate add-login summary

The new removeLoginInfo helper constructs a login and awaits removeLoginAsync, but its JSDoc says that it adds logins. The fixed accepted helper retains the same mismatch. A scoped summary should describe removal, while keeping the hostname, username, password and default realm contract. This finding does not change unrelated comments or establish a runtime cleanup result.

Scope: Compose browser-test helper documentation.
