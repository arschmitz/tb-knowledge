# Deferred row filling once required the accessibility ID before the fill step

The historical tree inserts a row and assigns its ID before a debounced _fillRow can run. Review corrects the ID format to match the existing generator. This prevents an empty active-descendant lookup in that architecture. Fixed table-based TreeView uses ariaActiveDescendantElement references and later clearing before reassignment, so do not reuse the old ID pattern as current naming policy. Warning and accessibility impact were reported; no live assistive-technology result was measured.

Scope: Tree row accessibility timing.
