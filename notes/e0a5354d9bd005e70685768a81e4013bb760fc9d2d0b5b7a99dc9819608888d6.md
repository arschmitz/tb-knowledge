# UpdateBot URL bases omit the slash supplied by their callers

The human-authored UpdateBot fix removes the trailing slash from SECRET_URL_BASE and ARTIFACT_URL_BASE. The secret and artifact helpers already insert the next slash, so the old constants produce a doubled separator at that join. The inspected secret caller supplies a project/comm path without a leading slash; the artifact caller supplies public filenames. The fixed accepted source retains the new constants and join expressions. The existing artifact test covers returned text, 404-to-None and an HTTP-error path, but it obtains its mock URL from artifact_url itself and does not independently assert the expected URL text. Its bare result assertion has no message. No real request, credential read or test execution was performed.

Scope: Taskcluster UpdateBot URL construction.
