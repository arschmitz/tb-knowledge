# A loopback OAuth response page precedes token-result completion

The original callback sends its localized HTTP success response before dispatching authorization handling on the main thread. Token exchange and persisted-login results complete later. The test intercepts protocol dispatch and emulates the form/redirect, then waits for the OAuth result before checking tokens and saved login fields. The accepted generated success/error page is a later phase. Neither protocol observation nor HTTP 200 establishes a real browser launch or final token success.

Scope: OAuth loopback callback and mocked test completion.
