# RNP symbol extraction preprocesses the header before matching exports

The original export helper runs clang -E -DRNP_EXPORT before matching RNP_API declarations and sorting the extracted names. Current code adds optional feature defines, while the checked vendor recipe passes no -D options. The implementation reads stdout without an explicit process return-code check, so this source does not establish successful preprocessing or complete ABI coverage.

Scope: openpgp/rnp-symbol-preprocessing.
