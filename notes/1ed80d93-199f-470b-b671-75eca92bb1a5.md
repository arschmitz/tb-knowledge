# Reset visible columns and delete created folders in repeatable tests

browser_columns.js could start with visible columns left by other tests, then fail an exact INBOX_DEFAULTS assertion. The May patch turns off nondefault columns before asserting, deletes folders made by the test during registered cleanup, and gives outgoing-parent cases a separate folderParentOut fixture instead of reusing folderParent. It also deletes a temporary double-click folder. This made --verify runs more usable but the author reported remaining gloda collection errors, and Bug 1833776 stayed open before later WORKSFORME closure. Treat this as isolation and baseline repair, not proof the intermittent was completely fixed.
