# Exchange protocol tests separate visible auth state from user selection

The initial protocol-change handler hides password and NTLM for Graph and assigns the OAuth2 constant. EWS exposes the options. Tests explicitly choose a protocol and check option visibility and the custom select host value. Their authentication helper assigns the value and dispatches change, so that assertion alone does not show a user can choose the native popup item. The later checkbox step adds a separate popup interaction. No authentication, native accessibility or test run was performed.

Scope: Account Hub Exchange protocol authentication choices.
