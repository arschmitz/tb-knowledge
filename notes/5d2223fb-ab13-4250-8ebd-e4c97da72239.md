# Surface certificate errors from folder selection as well as Get Messages

Opening an IMAP folder checks for new mail without the Get Messages URL listener. This patch routes certificate failure security information through the IMAP server sink, mail session, and alertHook listener so those folder-triggered failures show a notification. It also replaces an immediate exception dialog with an error-specific notification. The browser test covers IMAP and POP3 Get Messages, IMAP folder selection, expired, future, self-signed, and hostname-mismatch certificates. The original decision to disable overrides for a mismatch was reversed in July 2024 by Bug 1903135.

Scope: mail certificate error flow.
