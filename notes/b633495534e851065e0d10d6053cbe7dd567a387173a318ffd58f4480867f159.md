# Thunderbird’s tab adapter uses -1 for unsupported Split Views

Tab.splitViewId returns -1 and its comment says Thunderbird does not support split views. The schema permits that sentinel in an optional integer field. This does not implement split-view creation or prove that the inherited converter always emits the optional field; the upstream base conversion contract remains unpaired. No extension or layout test was run.

Scope: Extension tab compatibility.
