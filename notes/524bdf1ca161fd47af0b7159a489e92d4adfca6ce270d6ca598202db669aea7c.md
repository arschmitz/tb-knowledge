# The Linux tray default was narrowed to Daily after review

The proposal enabled the Linux tray on Daily and Beta. Review asked for Daily only because Beta should track release and repeated early-Beta default changes could disturb user choice. The landed guard and fixed accepted source use Daily true and otherwise false. Treat this as the specific tray rollout decision; it does not define every feature default on Beta or override an explicit user preference.

Scope: Linux tray rollout.
