# The shared retention form preserves account defaults and inverts the starred-message policy

RetentionSettingsUI maps useServerDefaults only when the Folder Properties checkbox exists. Both forms map the same policy/count/age IDs, and Always keep starred is the inverse of applyToFlaggedMessages. The retention IDL defines that property and the incoming-server adapter uses applyToFlaggedMessages as the actual preference key. The source does not support replacing it with the old applyToFlagged spelling. This is static mapping and caller scope; numeric conversion and deletion behavior were not executed. Required primary and own-review discussion gaps remain, so this lesson gives zero full-audit credit.

Scope: Message retention UI and backend value mapping.
