# Apply profile exclusion before profile inclusion

NotificationFilter rejects when any exclude profile matches. If include is an array, at least one profile must match; empty[] therefore rejects, while absent/null include is unrestricted. Within one profile each supplied condition must pass. This is current targeting behavior supported by code and historical tests. Do not flatten exclude/include into one condition that changes precedence.

Scope: notifications.
