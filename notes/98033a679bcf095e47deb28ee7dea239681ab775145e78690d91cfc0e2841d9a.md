# Style the actual dropmarker surface after toolkit structure changes

853 moves the toolbar menu dropmarker glyph to a centered background on the direct dropmarker element instead of assuming the previous icon part. The current source uses min-inline-size:24px, background positioning and currentColor stroke on that surface. This separates the control surface from glyph size and supports direction-aware sizing. A CSS dimension alone does not prove the live hit target, keyboard action or accessible name.

Scope: Toolbar dropmarker structure and sizing.
