# Address-book selection clears its page class before the missing-directory guard

For a non-root selection, _onSelect removes all-ab-selected before looking up the directory. If the directory is missing, it returns before reading creation-control properties. It leaves their existing disabled values unchanged on that branch. Earlier display and command-update work has already run, so this is a narrow later-lookup guard rather than a complete deletion-race or row-lifetime fix. No test assertion was added.

Scope: Address-book selection and creation-control state.
