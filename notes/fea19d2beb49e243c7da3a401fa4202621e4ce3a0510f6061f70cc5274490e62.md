# Include grouped menu controls in the visibility inventory

The 2024 context-menu inventory only walked menus and menuitems before this patch. 1018/1022 also walk menugroup and collect its visible child menuitem IDs, so the top navigation strip is covered. The new test activates actual native controls and checks both the hidden/visible inverse and the changed message junk score. Current inventory tests use a newer object-based expectation layout. Retain the test intent rather than copying a retired helper shape. Pointer tests do not prove keyboard navigation or screen reader announcements.

Scope: Grouped context menu regression test scope.
