# The deletion-test timeout limits the wait without cancelling its folder listener

performDelete races DeleteOrMoveMsgCompleted against a 5000 ms rejecting timer and clears the timer after the event fulfills. promiseFolderEvent exposes a promise and removes its listener only when the matching folder/event arrives. The timeout branch therefore bounds diagnostic waiting but supplies no deletion cancellation or early listener removal. The later accepted helper keeps this boundary while changing the action from a Delete key to cmd_delete. No timeout or cleanup-failure branch was run.

Scope: Multiple-display deletion failure diagnostics.
