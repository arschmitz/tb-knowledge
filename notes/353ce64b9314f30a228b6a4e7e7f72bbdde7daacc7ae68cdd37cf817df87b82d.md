# Calendar connection alerts classify stream results separately from DAV and HTTP errors

The notification module ignores successful and unlisted status codes and maps selected network failures to hostname-bearing text. CalDAV passes that stream result separately from its DAV error and HTTP details. The original response exposes numeric streamStatus; accepted later code exposes streamError and forwards its result. Keep those roles and representation phases distinct: an HTTP/DAV failure alone does not establish a transport alert, and not every operation forwards a stream result.

Scope: calendar-connection-notification-error-roles.
