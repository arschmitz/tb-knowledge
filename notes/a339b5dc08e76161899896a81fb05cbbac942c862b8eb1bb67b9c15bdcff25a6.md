# Popup check icons consume menuitem-icon while GTK app icons need the receiver-specific candidate format

The historical popup patch moves check/selection content to real .menu-icon elements through --menuitem-icon with platform/state guards. It also changes the GTK generic-app fallback from CSS image-set text to a density candidate list; the application menu receiver is its image attribute. Current code uses makeMozIconSrcSet, and exposes a separate makeMozIconImageSet for CSS. Preserve those receiver contracts and historical/current selector differences. The human lint follow-up changes wrapping only, and historical display:hidden must not be credited as a rendered hiding result. No platform, visual, lint or accessibility run occurred.

Scope: Platform popup icons and preference handler image values.
