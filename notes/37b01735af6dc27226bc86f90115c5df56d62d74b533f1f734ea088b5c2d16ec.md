# Offline operation row identity and source identity must not share one setter

Entry 796 fixes SetSrcMessageKey so setting the source key does not overwrite m_messageKey, the operation’s own message key. Current code no longer caches m_sourceMessageKey: it writes aMessageKey directly to PROP_SRC_MESSAGE_KEY while SetMessageKey updates m_messageKey and PROP_MESSAGE_KEY. Current source also has a separate PROP_SRC_UID for the server UID. The destination move-result operation is found with a fake destination key and records originalKey as its source key. Manual native naming proposal in this family: keep operation ID, source message key and server UID distinct even when they share integer types. The historical 782 key/UID comment is insufficient for the newer split representation. This augments the prior fake-key lesson without claiming replay is fully correct.

Scope: offline-operation-identity.
