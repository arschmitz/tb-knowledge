# The DOM collection port keeps each caller's indexed or reverse traversal

The comm port uses strong dom::NodeList references for child offsets, first-child anchor inspection and recursive element conversion. It uses dom::ContentList for meta-refresh removal while preserving backward traversal during removal. These exact caller contracts explain why the index/order remains. The original Length(true) and later accepted Length() belong to different phases. The unpaired engine revision does not establish collection or build guarantees.

Scope: Compose and MIME DOM collection receivers.
