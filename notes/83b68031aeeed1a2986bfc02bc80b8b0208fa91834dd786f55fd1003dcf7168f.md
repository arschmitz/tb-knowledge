# POP forwarding replaces a detached header before the second filter pass

When PublishMsgHeader attaches an unmoved header, it replaces a matching m_msgToForwardOrReply reference with the returned live header. A local move uses the destination header instead. The second filter pass reads that reference and passes it to the compose service. This is a bounded header-ownership contract, not proof of successful sending or a general raw-pointer lifetime rule.

Scope: POP forwarding header lifetime.
