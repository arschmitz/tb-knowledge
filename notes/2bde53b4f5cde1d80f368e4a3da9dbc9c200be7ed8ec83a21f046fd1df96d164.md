# The remove-account localization test checks a binding rather than rendered text

The dialog passes accountName to remove-account-question, and the rewritten test checks document.l10n.getAttributes(question) for that ID and argument. It therefore checks the localization binding rather than the translated question text or punctuation. The touched Assert.deepEqual still lacks a message argument. The exact resource/consumer was inspected, but no rendered localization, migration or browser test result was established.
