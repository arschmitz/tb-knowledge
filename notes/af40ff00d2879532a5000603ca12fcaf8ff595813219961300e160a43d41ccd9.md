# The localized all-following choice remains unimplemented in the recurrence prompt

The migration gives all 24 recurrence-button messages both labels and accesskeys, including the all-following variants. The actual all-following button remains hidden, and promptOccurrenceModification still throws NS_ERROR_NOT_IMPLEMENTED for its result2. The occurrence and parent buttons retain results1 and 3. String migration is therefore separate from support for that future-occurrence action. No dialog, keyboard, accessibility or recurring-item edit was executed here.

Scope: Calendar recurrence dialog localization and action boundary.
