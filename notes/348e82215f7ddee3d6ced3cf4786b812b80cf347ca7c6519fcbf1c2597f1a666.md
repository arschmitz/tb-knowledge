# The first shared URL listener kept an interim unsafe EWS adapter

The first sharing step gives SafeUrlListener its own RefPtr-backed struct and an unsafe raw-listener clone accessor with a temporary-use warning. A private EWS UnsafeListener implementation calls that accessor inside an explicit safety block; the common EWS wrapper framework is not moved wholesale in this patch. Fixed accepted shared code later restores SafeUrlListener as a generic SafeListenerWrapper alias. Preserve that temporary phase and its visibility boundary; it is not a recommended general escape hatch or a proof that all unsafe callbacks were removed.

Scope: Shared Rust listener migration boundary.
