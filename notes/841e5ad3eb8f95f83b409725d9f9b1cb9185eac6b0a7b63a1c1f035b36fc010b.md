# Space navigation intercepts only an unmodified message-body key and respects the preference

1365 adds an about:message keydown handler only when mail.advance_on_spacebar is enabled. Accepted code intercepts Space for body targets without Alt/Ctrl/Meta, allows Shift, prevents the default and forwards cmd_space. It leaves form/control targets outside this path. Preserve the target/modifier guard so a message-body navigation shortcut does not hijack other content controls; keyboard/browser behavior was not executed.
