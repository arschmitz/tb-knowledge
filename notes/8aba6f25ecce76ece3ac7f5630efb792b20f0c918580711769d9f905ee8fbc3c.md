# Calendar formatter instances are discarded on application-locale changes

The new locale observer clears the formatter map. getFormatter keys that map only by formatting options, so later requests construct fresh locale-dependent formatters after a clear. Day-view range descriptions consume formatDateLong, and navigation assigns that description to its label. The existing browser test asserts label text, but this patch adds no forced startup-locale test and the callback itself does not repaint a label. No startup race or browser test was run.

Scope: Calendar date formatting.
