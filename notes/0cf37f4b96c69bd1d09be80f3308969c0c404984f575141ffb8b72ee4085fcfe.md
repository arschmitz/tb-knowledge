# The complete-mbox test helper accepts an empty file without weakening the single-message parser

Entry 1291 special-cases an empty mbox in ExtractFromMbox by clearing the result array and returning success. That helper returns all messages, so an empty file means an empty collection; a single-message read still requires a separator. The accepted helper keeps the distinction. For this test utility, keep the empty-collection case in the wrapper instead of changing the parser’s corrupt-token contract. This is scoped guidance; no gtest was run and the repair’s review discussion is pending.

Scope: Mbox test helper empty-input contract.
