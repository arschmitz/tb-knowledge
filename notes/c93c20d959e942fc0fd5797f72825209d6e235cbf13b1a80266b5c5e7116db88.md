# Commands console reliability, hidden browser, and review-queue workflows

In this environment, a configured Git fsmonitor can hang `git status` indefinitely at `refresh_fsmonitor -> fsmonitor_ipc__send_query -> read`. `lib/utils.mjs` prepends `-c core.fsmonitor=false` to Git invocations, including absolute Git paths, without changing repository configuration; configured-hook and absolute-path utility tests passed 9/9. A saved `/api/patch-update` session can resume with the same revision, `mode: "update"`, `checkoutMode: "main"`, and `resume: true`. [Task 15]

Scope: console.
