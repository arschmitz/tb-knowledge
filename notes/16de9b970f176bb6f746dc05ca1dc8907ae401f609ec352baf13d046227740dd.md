# Name menu-event promises and removable listeners for their role

The context-menu test names onShownRow1 as a Promise.withResolvers bundle and onShownListenerRow1 as the callback that is removed after its one event. The harness sends its response only after the popup is open. Follow those distinct promise/listener names for nearby cases so it is clear which value is awaited and which callback is unregistered. This is a local manual naming recommendation, not a required naming scheme for every Promise or event handler. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Extension menu-test promise and listener names.
