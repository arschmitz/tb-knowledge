# WebGL conformance results flow from the target to the outer assertion harness

Firefox repository `git:314d8065c5ad68c7e5c5f92d`, revision `1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b`. Scope: DOM Canvas WebGL conformance tests and the shared Mochitest harness. Languages in the cited files: JavaScript, HTML. File roles are listed in the metadata. No production WebGL implementation is claimed.

js-test-pre caches its document pathname and window.parent.webglTestHarness. reportTestResultsToHarness increments local pass/fail counts and calls that cached object when present. In the inspected embedding that receiver is mochi-single.window.webglTestHarness. Its reportResults ignores pathname and calls outer parent.ok(success, message). testPassed and testFailed feed this function; testFailed also appends failure markup and flushes buffered logs.

## Change impact

A change to `reportResults` can change the success and message values sent to the outer assertion harness. A change to the cached parent receiver can affect every target using this version of `js-test-pre.js`. Membership in the wrapper family alone does not prove that an individual target imports this helper version.

**State:** RESULTS belongs to the target document; SimpleTest assertion state belongs to the outer wrapper. The exact parent.ok binding and assertion internals were not inspected.

**Special case:** reportSkippedTestResultsToHarness adds a fourth true argument, but this mochi-single receiver only uses success and message, so it does not propagate that skip marker separately.

```javascript
const locationPathname = window.location.pathname;
const webglTestHarness = window.parent.webglTestHarness;

function reportTestResultsToHarness(success, msg) {
  if (success) {
    RESULTS.pass += 1;
  } else {
    RESULTS.fail += 1;
  }
  if (webglTestHarness) {
    webglTestHarness.reportResults(locationPathname, success, msg);
  }
```

```html
window.webglTestHarness = {
  reportResults(pathname, success, message) {
    if (parent) {

      console.log('ok(' + success + ', \'' + message + '\')');
```
