# Test week-start changes in both directions with a nonstandard default

The calendar view manifest starts weeks on Thursday specifically to expose built-in assumptions. Current week, month and multiweek tasks check seven numeric weekdays plus long and short labels, switch to Monday and then restore Thursday. The multiweek task waits for its first visible weekday before asserting. These assertions exercise rendered arrangement, not year-boundary week-number correctness or screen-reader navigation. The current pref push helper is required by lint and is not a new manual style rule.

Scope: calendar/test/browser.
