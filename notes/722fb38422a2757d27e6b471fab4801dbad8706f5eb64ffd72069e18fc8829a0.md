# Do not copy the retired DOMMouseScroll shim as a current mail test API

1907 removes the mail helper’s synthesizeMouseScroll export, including its DOMMouseScroll default and hand-built horizontal/vertical/pixel flags. The accepted mail EventUtils module has no matching identifier; it still provides mouse and key synthesis. This is the retired mail shim’s scope, not a claim that Thunderbird cannot scroll or that the Gecko test harness lacks wheel input. A replacement scroll helper, native event contract and scrolling behavior were not examined here. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: mail scroll-test API.
