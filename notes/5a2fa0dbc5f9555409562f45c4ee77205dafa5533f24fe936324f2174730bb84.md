# Thunderbird theme schema adds system to both existing color-scheme enums

color_scheme and content_color_scheme are existing optional string properties. This partial port adds system to both enum sets while retaining auto, light and dark. Static theme manifests and dynamic update details reference the common ThemeType. The schema allowance alone does not prove a paired engine implementation or a working OS light/dark transition; the upstream dependency remains unpaired.

Scope: WebExtension theme schema.
