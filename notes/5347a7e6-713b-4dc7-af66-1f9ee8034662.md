# Keep the no-PIE linker override after the default PIE flag

The Thunderbird mail/app/no-pie target uses OS_LIBS for -no-pie so the flag appears after -pie from MOZ_PROGRAM_LDFLAGS. The 2024 Clang 18 follow-up removed an old compiler-specific -nopie branch and used -no-pie for all supported compilers. Current code still keeps the same ordering comment and flag. When changing this target or compiler flags, preserve the link command order and verify the final command line; replacing OS_LIBS with LDFLAGS could put the override before the default -pie.

Scope: Build configuration.
