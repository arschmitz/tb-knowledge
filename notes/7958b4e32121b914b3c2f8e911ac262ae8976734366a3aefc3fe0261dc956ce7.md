# Notify outgoing-server observers before clearing the removed server values

Current deleteServer removes the key and cached server, emits message-smtpserver-removed, then calls clearAllValues. The comment states why: observers may still need the server properties, and a reused key must not inherit the old settings. Preserve this ownership and observer order when adding cleanup. The test cleanup in 373 uses the same service, but this current-source detail is not all attributed to that 2024 patch. Existing Sync lessons explain why deletion observers matter. No observer runtime test was run.

Scope: Outgoing server ownership and observer order.
