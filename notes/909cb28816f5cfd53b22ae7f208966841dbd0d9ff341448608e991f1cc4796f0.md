# Toolbar customization JSDoc describes per-space keys rather than a literal property

UnifiedToolbarCustomizationState is documented as {[key: string]: string[]}. Each space name is a key whose value is an ordered item-ID array. The prior spaceName property notation did not express that map. storeState serializes the supplied object, so the JSDoc repair alone does not add validation or restrict the object to one named property. This is a scoped accepted type form, not a global formatting rule.

Scope: unified toolbar customization state type.
