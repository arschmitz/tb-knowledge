# Keep key-wizard labels linked to their password control

The current wizard links the localized repeat-passphrase label to passwordConfirm with control="passwordConfirm". The input is a password field and its input event recalculates whether generation can proceed. For this mixed XUL and HTML dialog, retain an explicit label-to-control relationship when changing its layout. The source link supports intended labeling; it is not a screen-reader or keyboard validation result. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: OpenPGP wizard control labeling.
