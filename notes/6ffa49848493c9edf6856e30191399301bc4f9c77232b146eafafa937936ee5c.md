# Commands Submit recovery from detached main checkout

`checkoutCommit()` uses a matching local branch when available, otherwise deliberately runs `git switch --detach <hash>`. `moz-phab` requires a named local branch. `createBranchForCommit()` derives `Bug-<number>`, reuses an existing matching branch, picks an unused suffix, and refuses missing 4–8 digit Bug numbers or dirty-checkout recovery.
