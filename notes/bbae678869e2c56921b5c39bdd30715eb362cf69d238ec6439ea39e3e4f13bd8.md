# Common dialog Copy preserves selection from the context-menu gesture

Thunderbird overrides the global common dialog with its XHTML host. In that host, dialogShadowDom captures selection at contextmenu time and installs a cmd_copy controller that prefers current selection, then cached text. This keeps Copy supplied after menu interaction loses selection. The cache lasts until the next contextmenu event or window destruction, and clipboard errors are silent; the source does not prove current-selection fidelity for every input or successful writes. No clipboard or accessibility test ran.

Scope: Thunderbird common-dialog selection and command handling.
