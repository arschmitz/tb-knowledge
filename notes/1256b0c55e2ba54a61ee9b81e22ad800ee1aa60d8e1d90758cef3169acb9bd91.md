# Graph folder creation completes through its operation listener

The bridge schedules and detaches folder creation, then returns scheduling success. The operation awaits the POST response, extracts the server folder ID and passes it to the safe listener without a legacy fallback. The native folder callback creates local storage and reports the folder addition. The integration test therefore waits for the local child, then checks one matching mock remote folder and its parent. Its positive EWS/Graph assertions do not directly cover failures or cancellation. Current typed request construction is a later phase than the original consuming setter.

Scope: Graph create-folder bridge, operation and integration test.
