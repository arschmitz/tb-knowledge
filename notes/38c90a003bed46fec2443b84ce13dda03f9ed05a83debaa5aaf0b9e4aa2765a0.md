# Treat synchronous editor scrolling as a lifetime boundary

The accepted native compose code warns that ScrollSelectionIntoView can flush pending notifications and destroy presentation state or frames. It returns after the scroll in the affected quotation path. A semantic synchronous flag can introduce re-entry and lifetime changes; do not add frame-dependent work afterward without checking those objects again. This follows the current source warning, not a reproduced crash or full editor lifetime audit. This note is based on source inspection. Tests were not run, and full review discussion remains pending.
