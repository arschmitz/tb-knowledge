# Dialog position tests use distinct pure and DOM coordinate spaces

getIdealDialogPosition returns CSS pixel strings from viewport rectangles. Its unit test passes those rectangles directly. The browser fixture instead applies left/top styles inside a container, shows a real dialog and compares numeric DOMRect positions. Container offsets therefore change some browser expectations; the two tables are not interchangeable merely because their labels match. The fixed PositionedDialog also has later height, missing-trigger and resize cleanup refinements. All changed cases were read statically; no layout, resize or browser/unit test ran.
