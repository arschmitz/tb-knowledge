# Await message copy completion before selecting a secure fixture

The accepted secure-mail test creates a PromiseCopyListener for each fixture and awaits its promise after copyFileMessage. That orders folder population before the message-selection loop. The test imports the CA/recipient certificate and OpenPGP key and registers cleanup rather than using a fabricated MIME body. This fixture lifetime contract is local to the browser test; no copy or key import was executed. These are fixed accepted source and test-code observations.
