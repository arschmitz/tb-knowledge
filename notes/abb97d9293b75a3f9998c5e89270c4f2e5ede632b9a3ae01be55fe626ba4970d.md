# Required-field asterisks depend on the native input and adjacent label

The form stylesheet adds an asterisk for two structures: a label immediately before an input-control wrapper containing a required native input, or a required native input immediately followed by its label. AccountHubInput uses the first light-DOM structure; animated auto-form inputs use the second. Preserve the actual native required state and sibling order when adding help or error nodes. The pseudo-element supplies presentation only: it does not make a field required, create a label association or prove screen-reader reporting. The selected required-state tests do not assert the glyph or color. No rendering or accessibility test ran.

Scope: Account Hub form label required marker.
