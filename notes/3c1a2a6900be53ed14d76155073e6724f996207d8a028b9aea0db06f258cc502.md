# Toolbar field token resets also feed the Address Book contact border

The correction assigns toolbar-field color, background and border tokens from layout-1 under the non-contrast, no-lwtheme branch. The separate contrast branch retains system field colors. The accepted vCard input rule uses toolbar-field-border-color for its border, so this shared token has a concrete Address Book receiver. This source trace does not establish computed cascade or a cross-platform visual fix; the upstream override and live theme/media state remain outside the proof.
