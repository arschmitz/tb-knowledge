# Keep long saveURL arguments labeled with their API meaning in this call family

Save Link and Save Image each pass a long positional list whose inline comments identify URL, originalURL, fileName, cache/prompt flags, sourceDocument and principal. Scoped manual syntax recommendation: retain accurate parameter labels when changing these calls, and align the optional-document expression with its sourceDocument label. Such comments make a syntactically valid argument shift reviewable; this does not impose a comment rule on short or named-argument APIs. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: mail context call readability.
