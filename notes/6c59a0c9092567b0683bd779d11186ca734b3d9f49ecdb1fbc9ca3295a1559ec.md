# Calendar print injection follows both the print dialog and the source document

The calendar print observer waits for print-settings initialization in a print.html subdialog, then verifies that the active source browser is the calendar printing template before loading calendar scripts. Entry 770 makes the dialog URL match a prefix rather than one exact URL. calendar-print.js imports the calendar Fluent resource into the actual print options document before cloning the calendar form from the chrome window. A cloned form does not carry its source document’s localization setup. Manual lifecycle proposal for this path: distinguish the generic print dialog, its ready event, the calendar source URI and the destination document. Scope selectors and resources to those owners.

Scope: calendar-print-lifecycle.
