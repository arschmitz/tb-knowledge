# Clearing an OpenPGP key stores the normalized empty value before refreshing controls

useOpenPGPKey converts null or undefined to an empty string and uppercases a present string. The identity receives that same normalized gKeyId before the GnuPG attribute and key-list UI are refreshed. Empty key state selects None; signing and encryption can still remain available through separate S/MIME certificates. The owned patch and fixed accepted function agree. The selected key-wizard assertions cover a present key, not null removal. No key operation or browser test ran.

Scope: OpenPGP account key selection.
