# Address-book subdialog tests wait for load rather than one timer turn

promiseLoadSubDialog waits for the window load event after acquiring the subdialog. Its mailing-list caller separately waits for name-field focus before actions. Keep document-load completion and focus completion distinct; this source change adds no result assertion or tested intermittent cure.

Scope: Address-book subdialog completion.
