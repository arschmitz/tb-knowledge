# The Save Link regression test proves picker entry and filename selection

The changed test opens the actual link context menu and activates its save item. The accepted test resolves the picker defaultString and returns returnCancel, then expects Link to a web page. It checks that the command reaches the picker with the intended suggested name, not that bytes were downloaded or a file was written. A focused follow-up test for write completion would need separate file-content assertions and test-file cleanup. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: mail context save test.
