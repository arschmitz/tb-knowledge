# Exchange server registration requests inherited password-observer initialization

The server component registration names Init. The checked inherited nsMsgIncomingServer::Init adds a weak passwordmgr-storage-changed observer. This initialization contract is separate from recording telemetry and from changing the OAuth interface pointer type. The source study did not execute a generated factory or every password-cache update path.

Scope: Exchange incoming-server initialization.
