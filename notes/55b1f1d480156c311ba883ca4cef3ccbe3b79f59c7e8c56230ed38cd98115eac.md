# The about:policies CSP review preserves inline initialization without proving a debug crash

D247562 adds a meta CSP to the HTML about:policies document and retains its inline init handler. Reviewer could not reproduce the debug assertion on unpatched debug tip, but reported display errors after removing unsafe-inline and accepted the narrow policy. Broader upstream markup/policy modernization was deferred. The AccountWizard crash in the shared Bug is a different document. Fixed source keeps the policy and inline handler, with a later moz-src allowance. No runtime test ran.

Scope: Enterprise policies document CSP.
