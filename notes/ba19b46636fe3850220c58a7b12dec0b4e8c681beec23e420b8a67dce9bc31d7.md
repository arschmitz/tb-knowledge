# Report the measured geometry used by subscription-tree waits

The historical1190 subscription-tree wait checks clientHeight divided by rowHeight and reports both measured values in its diagnostic message. Reporting the operands makes a failed geometry wait easier to investigate. This is a scoped proposed test recommendation derived from the inspected test, not a claim that the timing failure was reproduced. The newer rendered-checkbox scrolling sequence already has a separate current-source note; the old XUL coordinates are historical. No browser test ran and full review discussion remains pending.

Scope: Subscription tree browser tests.
