# Graph default enablement keeps explicit preference-on and preference-off tests

The owned default becomes Nightly-dependent while Graph remains preference-gated. The model and provider tests explicitly set false and true, preserving those behaviors without relying on the build default. The old browser disabled-by-default task is still removed. Accepted source later defaults true; that is a separate phase. The retained provider assertions still lack messages, so restored cases do not establish clear diagnostics or a fresh test result.

Scope: Graph feature gating tests.
