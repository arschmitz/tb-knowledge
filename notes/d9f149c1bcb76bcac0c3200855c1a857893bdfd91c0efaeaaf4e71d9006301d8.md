# Manual input completeness and connection-tested completeness are different gates

Incoming validity combines isIncomingEditedComplete with native form.checkValidity. Accepted AccountConfig allows Exchange URL/username/auth or ordinary hostname/port/username for that input-completeness check. Config-updated controls footer Continue. The manual-flow test shows an edited incoming configuration can leave outgoing Continue disabled while Test stays enabled. Do not replace this gate with AccountConfig.isComplete or assume valid fields mean a verified server configuration. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/accountcreation.
