# Treat notification enablement as a startup integration contract

834 conditionally imports notification custom elements into the current window global and replaces the root contents with the manager. The browser tests separately assert template/root counts and custom-element class identity for enabled startup, and no manager for disabled startup. The inspected branch does not establish live preference toggling after startup. Preserve import realm and template packaging when moving this integration.

Scope: In-app notification window integration.
