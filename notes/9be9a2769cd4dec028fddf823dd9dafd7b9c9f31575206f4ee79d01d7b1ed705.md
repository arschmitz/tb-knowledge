# AArch64 shippable tasks require matching artifact names and downstream platform lists

The original adds separate Linux and Windows ARM shippable tasks along with artifact filename/stage mappings and repack/signing platform lists. Accepted source retains both architecture task names and downstream lists, while later task fields differ. The source configuration is one part of the build pipeline; it does not prove that an upstream taskgraph transform, signing service or nightly build succeeded. The separate backout and missing-mozconfig reland remain distinct phases.

Scope: Thunderbird AArch64 nightly task configuration.
