# The generated Graph move body is local to its path, and its representation changes later

The landing emits unnamed body definitions beside their operation instead of named-schema module/selection output. Unnamed accessor docs are suppressed under a local rustc-diagnostic workaround. request_with_body collects an anonymous request type or an anonymous response type through if/else-if, so simultaneous anonymous bodies are not established. The original generated PostRequestBody uses PropertyMap and DestinationId accessors. The accepted nested module later uses an optional destination_id field with PascalCase serialization and adds query selection. The real Graph caller sets that current field and passes JSON. Keep these phases distinct; no code generation, HTTP call or upstream compiler issue was reproduced.

Scope: Graph generated anonymous body emission and move consumer.
