# Keep grouping-row decoration out of active row states

Current grouped sort headers draw a separator between adjacent collapsed dummy rows only when neither row is hovered, focused, current or selected. The separator opacity transition is limited to no-preference reduced-motion. Preserve keyboard/current/selection states when styling non-message headers. This adds source evidence to the distinction between dummy grouping rows and real messages.

Scope: mail/themes/shared/mail.
