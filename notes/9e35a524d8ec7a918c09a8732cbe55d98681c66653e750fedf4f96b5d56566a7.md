# Use the current hostname property in feed migration code

The 2024 feed migration uses hostName; accepted source uses hostname for both the affected-account filter and the final assignment. Preserve the canonical property name of the current incoming-server interface instead of copying the historical spelling. The Feeds prefix check is this migration’s scope test, not general hostname validation. No new account or legacy profile was loaded.

Scope: mail/modules/MailMigrator.sys.mjs.
