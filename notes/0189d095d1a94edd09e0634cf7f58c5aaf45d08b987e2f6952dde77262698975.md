# The upload-error notification test handles two alert windows separately

The upload-error task rejects two pending attachments. Its outer alert callback waits for another alert to be accepted before clicking accept in its original window. The task then awaits that outer result and checks that the uploading notification stops. rejectUploads rejects all pending upload entries before clearing them. This is a scoped overlapping-dialog sequence, not permission to parallelize ordered prompt tests.

Scope: cloudfile-prompt-tests.
