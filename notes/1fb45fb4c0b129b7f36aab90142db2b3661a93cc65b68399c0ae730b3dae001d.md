# Preserve traversal order without including the folder itself

Accepted getFolderAncestors starts at the parent and returns decreasing depth up to the root. getFolderDescendants appends sorted children and recursively traverses them depth-first, excluding the queried folder; root 0 can enumerate everything. Current relationship predicates search ancestor IDs. Keep those ordered-array contracts when changing traversal; this source check does not prove behavior for a corrupt cyclic database. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama hierarchy traversal.
