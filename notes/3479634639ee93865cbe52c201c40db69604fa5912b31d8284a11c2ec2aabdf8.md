# Panorama Thread indexed traversal and direct-child enumeration have different scopes

Thread::GetChildKeyAt and GetChildHdrAt use a cached recursive ListThreadKeys result. Its descending-depth query is asserted as keys1,3,5,4 in the checked fixture. Thread::EnumerateMessages(parent) instead calls ListThreadChildKeys, which filters by folderId and immediate threadParent; the test expects parent1 to yield3,4 and parent3 to yield5. Do not substitute one API for the other. GetNewestMsgDate returns seconds after dividing the stored microsecond maximum. This does not prove missing-parent behavior or an ideal thread identity model: GetRootHdr still documents the root-message-ID assumption as a TODO, and several methods remain unimplemented.

Scope: Panorama database threading.
