# NNTP credential queries keep a full realm while the accepted origin uses prePath

The original JS move supplies signonUrl as both origin and httpRealm. The accepted query/removal methods later derive origin from the URL prePath and retain the full signonUrl as realm. The native getter can build a server-wide or group-specific URL and trims its trailing slash. Preserve those phase and field roles; the unread login-manager matching implementation prevents an equivalence or runtime-fix claim.

Scope: NNTP credential query identity phases.
