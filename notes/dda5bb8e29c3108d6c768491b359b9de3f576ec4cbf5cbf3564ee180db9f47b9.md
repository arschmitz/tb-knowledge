# Keep the documentation root inside Comm when reading its policy file

The historical 943 Mach command sets DOC_ROOT to topsrcdir/docs even though it adds the policy file at comm/docs/config.yml. The accepted command sets DOC_ROOT to topcommdir/docs and reads that file after Sphinx. Preserve the current root distinction in command helpers. This is exact historical/current source reconciliation; no original build failure was reproduced and the later root repair was not fully reviewed.

Scope: Source documentation policy root.
