# Set EWS saved-message flags explicitly instead of relying on server defaults

1108 writes the PR_MESSAGE_FLAGS extended property (tag 3591) with READ and either UNSENT for drafts or UNMODIFIED otherwise; it also uses SaveOnly. Current CreateMessage still has that explicit property and adds a separate is_read field, but its TODOs question always setting READ and the meaning of UNMODIFIED. Preserve the actual historical behavior and treat the current TODOs as unresolved questions, not proof of the server's full semantics. These flags were not tested against Exchange here.

Scope: EWS saved-message MAPI flag policy.
