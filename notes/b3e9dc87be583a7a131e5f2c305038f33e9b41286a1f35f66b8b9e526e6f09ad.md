# Replace incoming alternatives before displaying the selected account config

AccountConfig.replaceVariables mutates the main incoming and outgoing configs plus every incoming alternative. The selected-config view then uses the chosen incoming entry for its username and hostname display. Alternatives can have different username templates, such as the email local part versus the full address. The owned xpcshell assertions check alternate values and passwords; the browser test checks displayed values after switching protocols. Those checks do not prove account creation or tooltip output. This operation does not traverse outgoing alternatives, and an empty password does not clear stored config passwords.

Scope: Account Hub discovered config alternatives.
