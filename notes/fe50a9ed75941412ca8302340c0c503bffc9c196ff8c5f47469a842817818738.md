# The OAuth where description omits the distinct external modes

At fixed revision0b93f0f7a926ed94c8a0646f18b6734ec7cc0f6d, OAuth2.prototype.requestAuthorization writes telemetryData.where as internal, external-localhost or external-net-thunderbird. The mail.oauth2_authentication where description still lists internal and external as possible values. This is a static description/value mismatch; where is a string extra, so the wording does not establish an enforced enum error. This later location field is separate from the original2024 issuer/reason/result landing. No telemetry was collected and no external-browser flow was executed.

Scope: OAuth telemetry location documentation.
