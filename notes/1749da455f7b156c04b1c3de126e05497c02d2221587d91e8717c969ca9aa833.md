# Use the calendar caller color with a stylesheet fallback

The current calendar dialog caller derives a CSS-safe calendar ID and sets --calendar-bar-color from that calendar backcolor variable. The titlebar uses a blue fallback and logical insets instead of the original negative-offset geometry. Recommend retaining this local semantic variable/fallback pattern rather than copying the historical fixed dimensions. The caller also sets calendar-name text, so color is accompanied by text; live contrast and accessible naming were not tested. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/components/calendar.
