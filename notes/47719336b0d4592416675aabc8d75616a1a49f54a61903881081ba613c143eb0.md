# The legacy identity wizard skips only OS email lookup in automation

The account-central test opens the newsgroup AccountWizard document, which loads aw-identity.js and calls identityPageInit from its load handler. checkForEmail now requires !Cu.isInAutomation before reading the OS emailAddress for an empty input. Existing page data and normal user lookup remain. Adjacent checkForFullName still uses the service, so this is an email-specific automation guard, not a general OS-user-info rule. The patch removes the exact macOS 15.30 AArch64 test skip without adding a direct service-call assertion; no native permission dialog or test result was reproduced.

Scope: Legacy news-account identity initialization and account-central tests.
