# Notification tests replace OS integration for the whole test file before each DND scenario changes mock state

The fixed shared head registers MockOSIntegration for all notification browser tests and restores the service in cleanup. It adds the Windows-specific interface when required and exposes one shared _inDoNotDisturbMode flag. The DND task toggles that flag around new-mail injection and awaits the existing no-sound helper. The head comment explains that CI can already run in Do Not Disturb mode, so unrelated tests need controlled OS state too. The initial Windows patch instead registered a per-task mock and skipped the task on non-Windows. These are written test contracts; no task, CI result, native service or playback was executed here. The original added preference tests contain assertions without messages, so those sites are historical deficiencies rather than assertion-writing examples.

Scope: Notification browser-test environment isolation.
