# Calendar manager flag names remain visible at their use sites

The cleanup replaces cICM with Ci.calICalendarManager in removeCalendar, and the next follow-up does the same for calIErrors. Current source retains the fully named interfaces. This supports a local readability convention for these methods; it is not a blanket ban on aliases. Keep flag checks, capability modes and observer/provider actions distinct. The current asynchronous deleteCalendar call differs from the historical callback API, so spelling consistency does not establish unchanged behavior.

Scope: Calendar interface naming.
