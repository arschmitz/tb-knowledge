# Part4 listener constructors take callbacks by value and move them into members

The EWS Part 4 constructors accept std::function callback values and use std::move in member initializers. The accepted Exchange folder listener retains this local pattern, including its later error callback. Rvalue-reference arguments were an optional alternative in review and were not adopted here. This example documents the actual constructor convention, not a ban on &&, a promise of zero copies, or a measured performance result. Captured-object ownership and the callback operation contract still need separate checks. No build or performance test ran.

Scope: Scoped C++ listener constructor convention.
