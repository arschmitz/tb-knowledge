# PromptCollection Boolean results describe permission rather than button index

The accepted repost prompt returns true for its Continue result, before-unload returns true when leaving is allowed, and folder upload returns true only for the Upload result. The Gecko interface explicitly defines those Boolean meanings. Each dialog converts its own button number to that meaning; callers must not assume the same numeric button is affirmative in every dialog. This is a scoped prompt contract. Gecko source was inspected at a separate fixed revision, not built as a verified pair with comm. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: PromptCollection permission results.
