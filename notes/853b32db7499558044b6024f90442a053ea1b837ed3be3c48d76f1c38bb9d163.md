# Bouncer alias names encode release-channel policy

Bouncer aliases route stable download names to release products. The fixed configuration distinguishes beta, monthly release, older ESR and newer ESR, with an empty default mapping. Older ESR aliases use esr-latest while newer ESR aliases use esr-next-latest. The installer, MSI and MSIX variants retain distinct names and product mappings. The 2024 branch numbers in the landing are historical; at fixed 0b93 the branches are esr140 and esr153. Manual naming proposal for release aliases: keep channel and installer kind visible in the name and verify each by-release-type mapping. Alias changes are shipping configuration; no live download or release task was executed.

Scope: release.
