# Compose operations keep converted details on the observer while listeners change

MsgOperationObserver stores convertedData by extension ID before reporting send/save results. The after-send and after-save converters return a tab/details wrapper. A result callback reads that value from the observer, so replacing a persistent event listener does not require the old listener to keep its private map alive. Conversion is shared once per extension for the preparation event. Mode and optional outerWindowId filtering still govern result delivery. This is the checked observer/listener contract, not proof of every background-termination race.

Scope: Compose extension operation data ownership.
