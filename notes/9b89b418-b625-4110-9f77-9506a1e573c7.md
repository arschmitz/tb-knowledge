# Clone module configuration objects before UI code adds state

SmartMailboxUtils stores folder type definitions in a module, but the folder pane adds UI-owned fields such as a DOM child list to those objects. D208776 requested changes when the reviewer saw a shallow array clone would still share the element objects across consumers and possibly multiple about:3pane tabs. The accepted getFolderTypes maps each item to a new object, so extensions and other tabs cannot mutate shared module definitions through UI state. A new array alone is insufficient when its elements are mutable.

Scope: smart mailbox architecture.

- `mail/modules/SmartMailboxUtils.sys.mjs`
