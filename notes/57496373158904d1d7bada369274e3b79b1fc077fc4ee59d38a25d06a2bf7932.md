# Give QR form actions native types and associated labels

The account item uses a native checkbox enclosed by a label. The password checkbox has an explicit for label. Select All is type=button and Export is type=submit, so only the intended action submits the form. Manual control proposal for this pane family: retain those semantics when styling or renaming controls, and keep Fluent text attached to the label or action. The inspected markup and tests support these associations; they do not prove screen-reader announcements, focus order or measured contrast in a running pane.

Scope: mail/qrexport/native-form-semantics.
