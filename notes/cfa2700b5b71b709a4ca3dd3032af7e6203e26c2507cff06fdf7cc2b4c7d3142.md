# The EWS marker helper does not check the preference setter result

The helper says a preference-set failure returns an error. It propagates parse/host/root-branch failures, but its setter call has no returned-status check before Ok(()). The initializer separately ignores any helper error after storing the client, matching its best-effort comment. Keep the helper documentation mismatch separate from the caller policy. No setter-failure or network experiment ran.

Scope: EWS helper comment and error boundary.
