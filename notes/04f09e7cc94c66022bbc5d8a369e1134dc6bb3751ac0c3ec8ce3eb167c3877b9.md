# Name the current row in the thread-selection assertion message

In this thread-selection test, the .current class assertion compares the row list with [expectedCurrent], while its message says the class is present iff selected. Later cases deliberately keep currentIndex outside the selected set. Proposed wording for this assertion: "Rows should have the current class only at the expected current index." Keep the selected-row message tied to expectedSelection. The expected current index and selected indices are separate contracts; this is a message correction, not evidence of a selection implementation or runtime failure. The historical and accepted current source both retain the misleading message. No test ran.

Scope: mail/base/test/browser.
