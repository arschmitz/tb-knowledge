# Keep quota-test normalization narrow and preserve semantic assertions

1185 adapts quota-label assertions to regional decimal commas by replacing the first comma in usage and limit strings before comparing Fluent attributes. Accepted source retains this narrow change while separately checking meter value/max and warning/critical classes. The quota producer formats STORAGE byte sizes through nsIMessenger but keeps numeric percent as its own argument. This is not a universal locale normalizer and does not verify every grouping separator, digit system or rendered screen-reader output. This is source and test inspection only.
