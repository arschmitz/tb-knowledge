# about:policies shortens schema metadata only for its documentation display

This landing adds a display projection before about:policies renders policy schemas. The helper shortens URL, origin, JSON and selected anyOf shapes and omits verbose metadata; it does not replace the canonical schema export. The fixed accepted consumer renders the projected values as text. The original uses URI plus a truthy pattern, while later accepted code uses moz-url plus a :// check. The projection is intentionally lossy, so these labels do not establish validator behavior or general JSON Schema equivalence. No rendering or policy validation was run.

Scope: Enterprise Policies documentation.
