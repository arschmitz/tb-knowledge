# Keep attendee arrays and recipient header strings distinct at compose boundaries

Entry 1075 changes the item iframe caller to pass attendees directly to cal.email.sendTo. Accepted sendTo still documents a recipient string and assigns it to the AString composeFields.to attribute. createRecipientList explicitly maps attendee email addresses and joins them into a string. This is a visible caller/type mismatch worth a focused runtime check; it is not proof of the eventual binding string or a reproduced send failure. Proposed manual API rule: preserve the documented array-to-header conversion until its replacement is established. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: calendar/base/content.
