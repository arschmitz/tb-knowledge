# Saved patch history kept finished task worktrees registered

At the cited baseline, `background-jobs.mjs` presents an idle restored patch session as finished history. Its comment says: "Restored patch sessions have no live operation." The worktree cleanup loop instead protected sessions whose saved status remained `review`. Dismissal also did not make an idle review eligible for cleanup. Saved history could therefore retain paired Firefox and comm worktrees after work had stopped.

## Local change

An uncommitted local fix adds `canRetireSavedWorkspace` and `hasPendingWorkspaceOperation` in `task-worktree-policy.mjs`. Direct cleanup and the inactive sweep share checks for preparation, active AI processes, pending source decisions, pending publication, and busy linked rebases. Interrupted and failed-recovery sessions stay protected unless the user dismissed them or the task reached a terminal state. Idle saved history, terminal tasks, and dismissed sessions can release their worktrees. Idle rebase records whose parent review ended are reconciled before removing the parent workspace.

The cleanup uses the existing recovery-commit path before removing files. It keeps source edits and commits in hidden Git refs. Restoring a saved report does not by itself require retaining its source directories forever. This describes one console lifecycle fix, not a new global workflow rule.

## Validation and limits

The source change passed independent evidence and diff review, lint, and 65 related tests. Real local Git fixtures cover paired removal, retained edits, dismissed and saved sessions, interrupted work, pending publication, live AI, and busy rebase children. The protection test uses real UUID-shaped task IDs and waits until the inactive sweep finishes before checking retained workspaces.

A live repair exercised recovery refs and existing cancellation APIs. When the old runtime still owns removal, preserve source snapshots before cancellation and use a single removal owner; removing the same worktree from two processes can race on Git index updates. A stopped backend permits direct cleanup through the task manager after verifying the saved cancellation and recovery refs.

The fix remains local working source at the time of this note. Verify its committed form before relying on it at a later revision. The tests do not establish native Windows behavior or a packaged release result. Fixed daily-build and dependency-update workspaces are separate retained build caches; this fix concerns disposable task workspaces.
