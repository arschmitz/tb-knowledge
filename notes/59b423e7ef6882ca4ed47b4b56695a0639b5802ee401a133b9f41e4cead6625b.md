# Search menu label attributes remain distinct from native message-list values

The original search switches send message-priority/message-flag IDs to a helper that sets Fluent attributes on XUL menuitems, while those messages define values. The accepted source uses dedicated search-val IDs with .label attributes and loads searchWidgets.ftl. Preserve the menu attribute contract and its later source phase instead of treating a message value as an interchangeable menu label. No initial rendering failure or locale result was reproduced.

Scope: search-widget-fluent-value-label-phases.
