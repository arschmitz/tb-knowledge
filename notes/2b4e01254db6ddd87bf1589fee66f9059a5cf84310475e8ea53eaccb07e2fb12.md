# The bulk-created adapter test omits messages from its three initial row checks

testManyContactsCreated begins with three Assert.equal(rowCount, 0) calls that have no message. Later assertions state which view should update, but those later messages do not supply messages for the initial calls. Each initial check should have its own nonempty expected-behavior message naming the all-books, Personal or History view. The same three gaps remain at the fixed accepted revision. This is a scoped test-review finding, not evidence of a functional failure.

Scope: Thunderbird address-book test assertions.
