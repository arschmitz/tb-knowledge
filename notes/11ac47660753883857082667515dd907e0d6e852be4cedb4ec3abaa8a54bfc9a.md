# Pass the intended lint root instead of assuming a glob is equivalent

The stylelint task replaces comm/* with comm. Accepted source-test configuration keeps the root argument for stylelint, while the neighboring shellcheck command still uses a glob. Preserve the actual task argument contract when editing it; shell expansion to children is not textually equivalent to supplying the root. The lint path resolver, hidden-file coverage and Treeherder result were not tested, so no universal ban on globs is established. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
