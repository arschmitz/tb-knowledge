# Keep sync select-all controls in the title’s flex layout

The sync forms place native type=button select-all controls inside the title details after the selected-count span. Current CSS grows the details column and aligns the controls to the end with logical margins rather than absolute positioning. Decorative title images have alt="". Preserve these structural roles when changing font sizes. The historical manual check reported 12px to 22px; this study did not run it, and the commit says the underlying list-size change is not fully fixed. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: Account Hub sync layout.
