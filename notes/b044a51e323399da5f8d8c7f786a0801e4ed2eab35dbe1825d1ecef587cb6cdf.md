# Keep previous semantic-search errors without blocking a new runtime

The CLI index command checks semanticError while waiting for the local model. A persisted old error could reject a retry before the new worker became ready. A new semantic runtime now moves the previous diagnostic into semanticLastError and clears the current flag. New worker failures still set the flag. Tests verified retry behavior and preserved diagnostics. Exact local search remains available while the model is unavailable.
