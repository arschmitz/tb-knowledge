# Tab-move names distinguish source, target and stored insertion state

The owned tab-move cleanup replaces shortened source/target window and tabmail names with sourceWindow, targetWindow, sourceTabmail and targetTabmail. It also distinguishes lastInsertionMap from the scalar lastInsertion retrieved for one target. These names expose direction and state roles beside the index arithmetic. This is a scoped accepted implementation pattern, not a repository-wide ban on abbreviations. The earlier review-feedback record remains linked as provenance instead of being copied.

Scope: WebExtension tab-move naming.
