# Preserve all CalDAV addresses and use the first as the fallback

745 stops choosing the last mailto entry in calendar-user-address-set. The newer accepted code retains all unique lowercase mailto addresses, then organizerId falls back to the first one when no cached organizer exists. Preserve this collection and fallback together; replacing it with the historical single find would lose aliases. The code comment expresses an expectation about server ordering, not a protocol guarantee proved by this study. No server interoperability test was run.

Scope: CalDAV calendar user addresses.
