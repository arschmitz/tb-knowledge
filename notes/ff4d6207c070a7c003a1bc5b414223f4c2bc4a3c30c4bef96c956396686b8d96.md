# Manual forms validate numeric ports while preserving an explicit auto state

The current incoming form reads valueAsNumber and InputSanitizer.integerRange with 1–65535 bounds, and treats an auto placeholder as a separate allowed state. Its markup carries the same min/max bounds; validation sets custom errors and accessible error relationships. In this form, empty/auto and an invalid numeric port are distinct states. A shorter truthiness test must preserve that distinction. The native validity and sanitizer behavior were not executed. This is source and test inspection only.
