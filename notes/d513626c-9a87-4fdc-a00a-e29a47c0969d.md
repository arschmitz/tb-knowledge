# Do not discard LDAP dialog edits on an outside click

D209901 reviewer noted that an accidental click outside the LDAP dialog could close it and lose configuration despite its Cancel button. The author set consumeOutsideClicks:false on subdialog managers in both Address Book and Preferences, because that setting applied at page scope. The review also requested no-resize on the search textarea because the dialog itself is fixed-size. This is a user-data protection rule for editable dialogs, scoped to the SubDialog behavior used here.

Scope: LDAP settings UI.
