# What’s New compares profile history, installed update and running app version

specialTabs updates the profile milestone to Services.appinfo.version and reads the last installed update, including update history for a different profile. It opens a page only when the update version is newer than the old profile milestone and no newer than the running app. Post-update actions can suppress the page, and policy can reject an update-provided custom URL. Current showWhatsNewPage is async and the test awaits it before asserting URLs or absence. Do not retain the 2024 synchronous method assumption. The test covers same-version startup, different profiles and downgrade/stale-update history with mocked external protocol dispatch.

Scope: application-update.
