# Use the requested save destination instead of a shared temporary message path

The patch removes the implicit tempMessage.eml field from the base protocol. The mailbox save path obtains the file supplied by the message URL, checks that a file exists and opens the output stream with mode 00600. GetSpecialDirectoryWithFileName now releases the acquired file on AppendNative failure, and nsMsgCreateTempFile propagates helper/create failures before registering delete-on-exit. Fixed accepted source keeps these named boundaries. Both assigned discussions are restricted, so this records code behavior without inventing the private rationale or claiming a security exploit or runtime fix.

Scope: Temporary message file contracts.
