# Adding a keyserver checks connectivity rather than the keyserver protocol

addKeyServer checks an allowed URL prefix, parses input and awaits a host fetch. It does not inspect response status or a keyserver API result. It then stores protocol plus host, deduplicates that string and rerenders. Failure alerts and returns without another prompt. These are URL/connectivity boundaries, not a proved working keyserver or a network result from this study.

Scope: Privacy keyserver add flow.
