# Commands Thunderbird/Firefox desktop onboarding and guided setup

`desktop/setup-store.cjs` accepts `comm` or its Firefox parent, validates `.git`, `comm/mail/config/version.txt`, and parent `mach`, stores an absolute real path in `userData/checkout.json`, and reopens setup for invalid/moved paths without discarding the prior value. `--comm` and `TB_COMM_PATH` override it. Keep renderer hardening: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, sender/frame validation, fixed IPC allowlist. [Task 1]

Scope: general.
