# The Atom parsers prefer publication dates before modification dates

This landing selects a nonempty entry published value before updated for Atom, and issued before modified for Atom 0.3. The existing source/channel fallback remains after those entry values. New local XML tasks compare raw item date strings for entries with both dates and with only the fallback date. They do not test malformed preferred dates, message storage, or rendered sort order. The shared assertItemsEqual helper omits messages at its two assertion sites; that is a scoped test-review finding, not an accepted message style. All four selected files remain identical at the fixed accepted revision.

Scope: Newsblog Atom item date selection.
