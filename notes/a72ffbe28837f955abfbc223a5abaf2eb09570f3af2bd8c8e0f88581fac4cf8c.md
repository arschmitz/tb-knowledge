# Calendar descriptions have separate summary, full-view and reset contracts

The fixed dialog passes plain text to its summary and text plus HTML to the full description. Reset clears both consumers. The current browser task directly checks empty, populated and cleared content; the original added task checked only empty then populated. The expand button opens a named subview and carries the full-description label requested in review. The full consumer delegates HTML conversion to cal.view.textToHtmlDocumentFragment, whose internals were not audited here. Do not turn that call into a sanitization claim or a screen-reader result. No dialog or Storybook runtime ran.

Scope: Calendar description state.
