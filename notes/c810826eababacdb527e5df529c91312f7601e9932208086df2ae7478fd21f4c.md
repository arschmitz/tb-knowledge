# Non-Inbox IMAP biff reads the STATUS preference on each call

GetNewMessagesForNonInboxFolders uses local useStatus from Preferences::GetBool with true fallback instead of static first-read flags. Each invocation, including recursive visits, therefore reads the preference. The existing true branch queues a folder once for sequential STATUS/NOOP checks; false performs UpdateFolderWithListener. Eligibility and root-triggered queue order stay separate unchanged logic. This is a scoped state-lifetime cleanup, not a global static-variable naming rule. No preference-toggle or IMAP test ran.

Scope: IMAP non-Inbox new-mail checks.
