# The draft-header action forwards Shift state through the shared compose controller

The notification callback forwards its fourth argument to MsgComposeDraftMessage, which calls the shared Draft routing method. That method chooses OppositeOfDefault when the received event has shiftKey, and Default otherwise. The callback still returns true to keep the notification open. Preserve the original synchronous selection routing and later async selection implementation as separate phases; no live input or compose result was tested.

Scope: Draft message header action.
