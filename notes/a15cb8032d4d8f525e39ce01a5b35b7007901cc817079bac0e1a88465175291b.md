# Keep Exchange autodiscovery outside lower-priority config cancellation

FindConfig combines the external signal and its internal priority controller for the ordinary config sources. Exchange gets the external signal because its result may add an Exchange alternative even when a higher-priority ordinary source succeeded. Cancelling lower-priority config lookups must not discard that separate enrichment result. User cancellation still applies to both paths. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/components/accountcreation.
