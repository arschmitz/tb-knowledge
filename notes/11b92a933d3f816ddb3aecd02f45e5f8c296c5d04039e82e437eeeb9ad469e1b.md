# External key public import rechecks identity before wizard completion

External-key setup requires a key object with a UID matching the current identity email before saving the external key ID. Missing key/email shows a public-key import section. Its picker imports only the requested key ID, then calls the same completion gate again. importKeyDataSilent resolves a Boolean, which this caller ignores; awaiting it is not itself a success guarantee. The gate performs a case-insensitive UID email match, not a full cryptographic-validity check. Markup and Fluent messages identify the import section and requested key ID. Static inspection only.

Scope: OpenPGP external-key wizard.
