# Gate card-view hover and selection transitions on no reduced-motion preference

The cards-view patch animates color, border, shadow and selected-indicator transform only within prefers-reduced-motion:no-preference. The selected indicator is transformed into view for both selected/current and selected/unfocused states. D209965 review noted a media query cannot live inside a pseudo-element; the accepted CSS places the media query on the card container and nests &::before within it. Keep selection state correct without animation and put preference media queries on the element rule that owns the pseudo-element.

Scope: Thread card CSS.
