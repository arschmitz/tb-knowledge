# The later Yahoo/AOL notification flag follows the selected provider PKCE setting

In this historical phase, matching Yahoo/AOL initialization assigns mail.inappnotifications.pkceUpgradeForYahooAol to !issuerDetails.usePKCE after the client-ID guard. It can clear a previous true value when PKCE is enabled. The assignment still precedes token work and does not describe all accounts or successful authentication. The fixed accepted initializer later removes this notification write.

Scope: mailnews/oauth/inappnotifications.
