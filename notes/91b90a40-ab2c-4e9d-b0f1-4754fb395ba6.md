# Use static focus state for recorded iMIP controls

For the recorded D320277 revision, review concluded that `calImipBar.getButtons()` returned XUL `toolbarbutton` controls whose hidden and disabled states already kept them out of sequential focus. The approved change used static `tabindex="0"` and removed `updateButtonFocus()`. Treat this as a decision for those iMIP controls and that revision; recheck current control behavior before applying the same pattern elsewhere.
