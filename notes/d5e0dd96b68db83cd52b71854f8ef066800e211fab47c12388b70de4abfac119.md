# The original news-cancel listener guard disagreed with its optional caller

The original migration documents the cancellation URL listener as optional and the UI caller passes null in its new listener slot, but the original C++ receiver rejects null before retrieving the NNTP service. The unit test supplies a PromiseUrlListener, so that path does not cover the UI's null-listener case. At the fixed accepted revision the listener guard is absent. This records the original mismatch and later source state without claiming a current or reproduced cancellation failure.

Scope: NNTP cancellation feedback migration.
