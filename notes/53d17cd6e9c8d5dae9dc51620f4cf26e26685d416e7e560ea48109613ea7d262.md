# Downloads attachment tests wait for the save completion event before advancing the picker fixture

AttachmentInfo.save captures the chosen path before asynchronous work and dispatches attachmentSaved only after saveToFile resolves. That implementation awaits the download and non-temporary list addition. The test installs its listener before clicking Save, waits for the picker callback and completion event, then asserts detail.path matches the expected file. This replaces the earlier file-exists poll and hopeful tick. Cancellation and failed attempts do not produce that success event. The assertions do not establish saved bytes, all retry behavior or native Win32 correctness; no test ran.

Scope: Attachment saving and browser-test synchronization.
