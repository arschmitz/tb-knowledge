# Checkbox folder rows keep choice state separate from tree row selection

The original reusable row maps its native checkbox to the model checked property and updates the row dataset on change. Folder acceptance reads that property through selectedFolders instead of TreeView range selection. TreeDataRow property methods only modify the Set, so the handler owns UI synchronization. Accepted code later adds delegated handling and subtree aggregation; those later behaviors are separate from this original checkbox contract.

Scope: Folder picker native checkbox and model contract.
