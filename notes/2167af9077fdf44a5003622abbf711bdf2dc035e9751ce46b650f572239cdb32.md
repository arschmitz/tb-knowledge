# The search-textbox port changes input wiring and readiness as well as markup

The search-textbox port changes command-driven filtering to input-driven filtering and uses window load for preference focus and subscription startup. Fixed gSearchResultsPane.init registers input and focuses on load; handleEvent awaits category initialization. The checked subscription test types without Return, waits for the filtered row and exercises Escape clearing. These are scoped application and assertion facts. The review discussed whenDefined but retained load; it did not establish a universal custom-element readiness rule. Most checked comm fields later became native HTML search inputs, so the original custom-widget reset properties do not apply to all fixed receivers. No browser or accessibility validation ran.

Scope: Search control migration.
