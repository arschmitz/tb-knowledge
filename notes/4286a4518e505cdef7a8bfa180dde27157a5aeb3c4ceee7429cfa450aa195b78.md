# Calendar view tabs move focus separately from activating a view

Arrow Left/Right move focus with wrapping and RTL direction handling without selecting a new view. Enter, Space and clicks explicitly activate the button value. The selected-view loop updates ariaSelected and one zero tabIndex while the markup gives each tab its matching controls target and localized label. Focus and selection are separate states here; the local focused variable is a selected-type match. No keyboard, RTL, screen-reader or computed-accessibility run occurred, so this is an exact source contract rather than a general conformance claim.

Scope: Calendar view tablist keyboard and selection state.
