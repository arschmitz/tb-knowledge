# Offline-picker setup resets the fixture before tasks while cleanup keeps its files

The setup now explicitly requests the expected Offline bits for NNTP, IMAP and EWS folders, including clearing previously modified third/fourth folders and IMAP Trash. These writes occur after the relevant folder-discovery waits and before tasks consume the fixture. Cleanup still passes false for removeAccount's aRemoveFiles argument, so it removes accounts without requesting data-directory deletion. This separates fixture state reset from deleting files; it does not prove a verify pass or a general cache/timer cure.

Scope: Offline folder browser-test repeatability.
