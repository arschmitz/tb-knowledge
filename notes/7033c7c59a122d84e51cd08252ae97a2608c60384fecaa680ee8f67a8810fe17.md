# Unified-build identifier cleanup preserves MailNews stored key names

The patch makes the folder flags constant and IMAP initialization guard component-specific. It moves the shared DbRowID key to a guarded header and the shared ewsId key to EwsFolder.h. The exact Mork reader and database writer use the same DbRowID property. These C++ name and declaration changes do not rename the stored flags, DbRowID or ewsId keys. The later accepted Exchange constant has a different identifier but still stores ewsId; that later phase is not part of this original rename.

Scope: MailNews import and database identifier scope.
