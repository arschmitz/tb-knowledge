# A landed CI image port was replaced by excluding unused arm64 packages

Complete Bug 1959876 was read. After the initial landing the author reopens the Bug, says the image-building approach should be backed out, and chooses to ignore unused ub24-arm64 packages instead. Fixed accepted package selection explicitly excludes !ub24-arm64* and the docker reference list does not contain the two added ubuntu2404-arm64 tasks; image_builder_arm64 remains and the worker family is now images(|-aarch64). Final FIXED status is not proof that the initial whole patch was retained.

Scope: Taskgraph referenced images and package selection.
