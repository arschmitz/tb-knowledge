# The S/MIME override prompt is formatted as one localized message

The follow-up replaces a failure message plus a separately concatenated override question with one complete Fluent message per error branch. The NSS branch supplies errorMsg and errorCodeStr; the other branch supplies errorCode. The selection consumer passes the formatted result directly to the confirmation prompt. Current v2 messages later change line breaks and sentence order; that is a separate phase. No locale or dialog execution was performed.

Scope: Thunderbird S/MIME certificate override prompt localization.
