# Check fixture structure before trusting equality between lookup results

The Panorama test fix explains that wrong folder parents accidentally passed because null == undefined. The corrected fixture makes Sent, Junk and Trash siblings under the server. Current fixtures retain those parent relationships with deliberately unordered numeric IDs and current missing path lookup returns 0. In this test family, check expected fixture identities and parent shape before comparing two lookup outputs, so two missing results cannot stand in for a valid match. This is a scoped test recommendation, not a blanket ban on every loose assertion. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Panorama fixture false-positive lesson.
