# The original virtual-folder wait accepted either event before checking displays

The original keyboard-delete patch waits for Promise.any of completed and failed folder-event promises. promiseFolderEvent resolves the named event, so failure is also a fulfilled result; each listener removes itself only on its own match. The following display checks, not the wait or diagnostic line, check the expected next message. The fixed test later uses a shared command helper with completion versus timeout. Keep that later phase separate and do not reuse the original either-event wait as proof of successful deletion.

Scope: Virtual-folder deletion test lifecycle.
