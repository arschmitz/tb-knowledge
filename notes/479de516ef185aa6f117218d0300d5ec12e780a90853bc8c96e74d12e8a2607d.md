# Include week alignment in the multiday view reuse condition

The multiday view may reuse an already visible range only when its first weekday matches weekStartOffset as well as containing the requested date. Otherwise the week-info service calculates a new range from the user preference. Current method name is showDate; the historical name was goToDay. A date still being visible does not mean a changed first-day-of-week preference can be ignored.
