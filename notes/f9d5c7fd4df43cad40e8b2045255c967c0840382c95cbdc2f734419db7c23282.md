# The MIME test sink does not wire unobtrusive signature verification

The test helper assigns its supplied openpgpSink directly to the channel. The test object's complete definition records updateSecurityStatus but has no processUnobtrusiveSignature method. Native mixed-part EOF calls that method for unobtrusive signatures, and the production UI sink performs detached verification there. The fixture conversion and zero-result assertions therefore do not directly assert the production positive-verification path. Native wrapper behavior and runtime consequences were not tested.

Scope: mailnews/mime OpenPGP test sink contract.
