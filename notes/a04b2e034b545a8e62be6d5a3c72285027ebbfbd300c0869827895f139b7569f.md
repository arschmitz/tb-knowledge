# Keep window CSP exceptions tied to the resource kind and consumer

The accepted messenger policy permits resource scripts, moz-src scripts, data and moz-icon images, a specific add-on image origin and connect-src *. Feed subscriptions permits chrome/data images, while compose has resource workers and HTTP/HTTPS connections. Preserve these document-specific resource categories when editing policies. These strings are inspected configuration, not a claim that the historical policy is sufficient for every current window or that its security was tested here. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Window CSP resource categories.
