# Keep display time zones and exclusive all-day ends separate from stored dates

getItemDates converts available dates to the default timezone and subtracts a day from an exclusive all-day end before display. Date-only and floating values keep their user-relative fields; other values are adjusted by timezoneOffset and formatted as UTC because Gecko may not recognize the original timezone ID. The formatter uses that same adjustment for ranges. These are display transformations, not changes to event persistence or recurrence rules. No timezone runtime or daylight-saving matrix was executed. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: calendar/formatter/date-time-representation.
