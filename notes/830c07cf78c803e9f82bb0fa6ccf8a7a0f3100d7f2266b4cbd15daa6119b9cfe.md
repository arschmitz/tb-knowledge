# Encrypted body search reparses decrypted MIME text through a separate local parser

The enabled search preference gates encrypted-part handling. PGP body-search mode caches armored data separately from its normal multipart counter; the C++ proxy collects callback output per body-handler instance. S/MIME separately feeds the CMS decoder. GetRelevantTextParts then parses the decrypted MIME string, keeps relevant text and converts its declared charset to UTF-8 before search. This source boundary is separate from Gloda indexing, display decryption and any runtime or security guarantee.

Scope: Local encrypted-message body search.
