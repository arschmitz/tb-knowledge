# UIDPLUS COPY and MOVE wrappers hard-code UID mode for ordinary dispatch too

Ordinary fake-server dispatch calls the selected method with args only; UID dispatch also supplies true. The UIDPLUS COPY/MOVE wrappers accept only args and pass literal true to their saved implementations, so wrappers around the inspected base handlers force UID-set interpretation on both paths. The parser distinguishes that from sequence-position lookup when UIDs differ from message positions. The accepted source keeps this behavior. Preserve the caller's mode when repairing this boundary and cover both dispatch forms with nonmatching UIDs and positions. This is a bounded static source finding, not a production IMAP rule or a reproduced test failure.

Scope: IMAP fake-server dispatch.
