# Keep mbox escaping reversible across writes and document the final-line exception

The current mbox output contract adds one > to From-prefixed lines, including already quoted lines, and buffers only an undecided start fragment across Write calls. A missing final end-of-line is the documented exception to byte-exact round trips. TestMsgMboxWrite writes each message in chunks of 1, 3 and 4096 bytes, calls Finish and compares the expected mbox after removing only runtime-dependent separator timestamps. Its BadMessages case deliberately writes malformed message bytes. A parser or stream change needs boundary-sized cases, not only one full-buffer write. Only the header, relevant completion implementation and these test sources were read; the tests were not run.

Scope: Mbox format and meaningful stream tests.
