# Classify an already-uploaded langpack response narrowly as success

upload_all_locales treats a response without error as success and also accepts an error string starting exactly with "Version already exists. Latest version is:". Other returned errors are added to failed, and HTTP exceptions also fail that locale. This permits rerunning a partially completed upload without hiding unrelated errors. Manual automation proposal for this uploader: make idempotent-success exceptions specific to the remote response contract and preserve other failure paths. The source does not prove the remote service still uses this message or that uploads were tried in this study.

Scope: langpack-release-automation.
