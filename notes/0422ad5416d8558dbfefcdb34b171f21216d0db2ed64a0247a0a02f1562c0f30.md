# Keep instance timing fields distinct from class timing fields

The current manager stores _MAX_MS_BETWEEN_NOTIFICATIONS on each instance and _PER_TIME_UNIT on the class. The latter is deliberately adjustable for tests. Uppercase spelling does not by itself mean a JavaScript field is static or immutable. When extending this family, match the receiver used by production scheduling and restore changed timing state in tests. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: In-app notification field ownership.
