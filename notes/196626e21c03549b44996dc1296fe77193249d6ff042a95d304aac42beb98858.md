# A Panorama group Promise did not initially mean an asynchronous SQL query

The original selectMessagesInGroup builds its array by synchronous ExecuteStep calls and then resolves a DOM Promise. The async row loader therefore defers row population after await, but the original database query itself is synchronous. Fixed accepted code later starts ExecuteAsync and returns the listener-owned Promise. UI expansion deliberately does not await the loader; tests await row-count and invalidation signals. Keep the two source phases separate when reusing this API contract.

Scope: Panorama/group-query completion.
