# The temporary operation-queue pin restores the synchronous token API expected by EWS

The repair pins exactly 1.0.0 and restores synchronous token acquisition, which matches the owned EWS callers that immediately call or_token without awaiting a future. The fixed accepted dependency later uses 1.2.0 and its shared sender awaits acquisition. Preserve these API/version phases rather than carrying the temporary pin, RefCell implementation or non-awaiting call forward as current policy. Source and local checksum agreement do not prove a successful build or concurrency behavior.

Scope: EWS dependency version and operation-sender contract.
