# Address-book selection tests separate direct checkbox activation from attribute waits

The owned 4081 test replaces synthesized pointer actions with direct HTML checkbox/label click calls after asserting the first row is enabled and has an offsetParent. The widget updates checked/indeterminate properties, selected count and Fluent label IDs. Those direct checks exercise selection state, not pointer hit-testing or keyboard behavior. The owned first-row wait still observes attributes while testing the checked property; it must not be treated as proof that property changes generate that mutation. Current accepted source uses a later tick followed by an explicit unchecked assertion instead. Keep the direct-activation patch and later wait repair separate; no test run or general timing guarantee follows from the source.

Scope: account-hub/tests.
