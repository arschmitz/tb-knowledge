# OPML status migration keeps a synchronous return but fixes the order of translated fragments

The processor consumes importOPMLStatus as an immediate string, and its lazy Localization is explicitly synchronous. When total outlines exceed newly added feeds, the implementation formats two independently pluralized messages and joins them with a literal space and period. The deleted subscribe-OPMLImportStatus no longer lets a locale reorder that outer composition. Keep the separate added/total count meanings and this translation boundary; the author's qualified German-order remark is not an all-locale proof.

Scope: Feed subscription import status.
