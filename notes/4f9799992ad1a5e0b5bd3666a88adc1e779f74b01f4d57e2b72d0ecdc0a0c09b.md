# Attendee rendering caches pre-connection data but does not fully reset reused element state

setAttendee stores the object before its connection guard, and connectedCallback replays that object after finding template nodes. Production creates a fresh customized li for each attendee. On a reused element, however, the name's hidden state is not reset to false, role labels are not cleared and status classes accumulate through classList.add. Accepted source keeps these setter patterns. The bounded static concern applies to reuse; fresh production nodes and class-presence tests do not prove or reproduce a wrong rendered state.

Scope: Calendar attendee element state.
