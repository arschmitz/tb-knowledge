# Removing the commlint Black entry also removes its local runner

This change deletes the Black YAML registration and its black_lint function together. That function previously expanded paths and passed -l 99 to python.black.run_black. The accepted Ruff entry still selects only py extensions, while the deleted Black entry also listed build, configure and mozbuild. The accepted pyproject.toml retains a comment saying some ignored formatting rules are handled by black; that comment alone does not prove that the removed commlint entry still runs or that Ruff covers every former file type. Check the actual command and selected configuration before applying a formatter rule.

Scope: Thunderbird Python lint integration.
