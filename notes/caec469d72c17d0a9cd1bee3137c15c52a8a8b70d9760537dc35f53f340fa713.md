# The Save As filename assertion compares indexOf's result with the wrong sentinel

The multiple-message test looks up a filename suffix with expectedFilenames.indexOf, then asserts that the result is not undefined. indexOf returns -1 for no match, so that assertion cannot reject an unknown suffix before sourceMessages[index] is read. Compare the result with -1 or assert a nonnegative index so the expected-behavior message identifies the actual failure. The accepted test retains the mismatch. This is a static assertion finding; no browser failure was reproduced.

Scope: Message-save browser test.
