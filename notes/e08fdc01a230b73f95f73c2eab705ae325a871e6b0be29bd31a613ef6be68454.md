# Filelink type icons stay visible when their producer sets src without srcset

The filelink row sets its .typeIcon img src from account.iconURL. The shared type-icon style therefore hides an image only when both srcset and src are absent. The current fixture checks the expected src, but it does not directly test computed visibility or decoded image dimensions. This is a scoped attribute/selector contract, not a mandate to use src for all icon families. No rendering or browser test ran.

Scope: Preferences filelink icon attribute consumer.
