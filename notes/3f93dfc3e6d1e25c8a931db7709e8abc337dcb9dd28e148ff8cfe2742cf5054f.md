# Dismiss a matching mail notification at current message document completion

The historical 1086 path checked the captured New flag in a URL listener. A later selected change removes that path. Accepted messageProgressListener verifies a top-level current channel in onDOMContentLoaded, finishes attachments and closes the alert using gMessageURI before dispatching MsgLoaded. It no longer requires the historical New check. Keep the current completion boundary and notification identity together; do not restore the old URL listener just to close alerts. This note is based on source inspection. Tests were not run, and full review discussion remains pending.
