# Give notification test tasks different names for different removal reasons

The telemetry test has two function expressions both named test_notification_closed. The second actually verifies dismissed events from expiry and candidate clearing. Function-expression names can repeat, so this is not a syntax error or an enforced lint rule. Name that task for passive dismissal in future edits so logs and failures identify the scenario it tests. This is a proposed scoped test-name rule, not a claim that the existing name was rejected in review.

Scope: Notification telemetry test task naming.
