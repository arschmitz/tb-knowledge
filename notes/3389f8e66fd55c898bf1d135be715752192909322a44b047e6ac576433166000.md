# Refresh selection counts when the owning view changes

Current threadPaneHeader update refreshes selected count with folder/message data and hides stale header data when there is no folder, DB view, or synthetic view. A selection-only event is insufficient when folder changes replace the view. Do not reuse the previous folder count as a cached display value.

Scope: mail/base/content.
