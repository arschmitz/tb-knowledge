# The POP watchdog begins asynchronous completion before the global queue is released

Timer expiry calls _actionDone with a timeout status. That async path marks done, writes UIDL state and sends QUIT before scheduling its cleanup fallback. _cleanUp cancels the timer and eventually invokes onFree; the server's onFree closure clears the static busy flag and resolves the next waiter. A timeout callback is therefore not immediate queue release, and the later three-second fallback is not a three-second bound from expiry. This traces the normal inspected callback route, not every error path or a demonstrated deadlock cure.

Scope: POP cleanup and serialized-client completion.
