# Repair resets protocol state and recreates a store before folder discovery

Accepted FolderCommands resets IMAP message counts and UIDValidity before backing up the database, restores the transfer info after closing it, and clears EWS/Graph sync state tokens for those protocols. It then ensureLocalStore before updateFolder because folder discovery relies on the store’s existence. These are current protocol-specific repair steps, not proof of an atomic reset or completed download. This is static source and test-code inspection.
