# Invalidate the search-view sort when switching to unthreaded

The multi-folder saved-search bug was an unthreaded but unsorted message list. RebuildView sorts threaded and grouped views, but an unthreaded rebuild keeps the individual header sequence. On a transition to unthreaded, SetViewFlags clears m_sortValid before Sort so a cached valid sort cannot skip the work. This also restores the secondary sort when leaving grouped mode. D208830 asked for a code comment explaining that non-obvious case; the accepted comment remains in the current checkout. Test the list order, not only the mode bits.

Scope: Search message views.
