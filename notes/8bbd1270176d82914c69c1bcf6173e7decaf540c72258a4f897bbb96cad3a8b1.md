# Folder-picker tests keep popup opening in callers and nested checks in one helper

Each test opens its selected popup, then handlePopup waits for shown, compares child node types and labels, opens expected submenus recursively and waits for hidden after closing. Its JSDoc makes popup opening the caller’s responsibility. The two original deepEqual assertions have no messages, so their failures lack the expected-behavior diagnostics required by current guidance. These structural checks do not verify keyboard or accessible behavior.

Scope: Folder picker test-helper contract and diagnostics.
