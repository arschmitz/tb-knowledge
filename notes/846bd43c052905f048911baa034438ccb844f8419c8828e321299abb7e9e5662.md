# Profile export awaits file collection but progress counts attempted zip entries

ProfileExporter awaits its private recursive collector before writing the zip and the UI awaits startExport before finish. Each entry-add error is logged, while progress still increments and ends at the collected map size. Total progress therefore means attempted collection entries, not proof that every file was archived. Separate exists/stat awaits and the normal-path zip close also do not establish atomic filesystem checks or universal error cleanup.

Scope: profile-export.
