# Preserve an empty selection during view-flag changes

At revision 22e9360a4fba, DBViewWrapper sets selection.currentIndex to -1 before changing view flags when a selection object exists and its count is zero. The source comment explains that some views, including cross-folder virtual views, can otherwise select a row during the change. Preserve this guard when changing flag handling. It applies to an empty selection, not an existing selection. This is static source evidence; no runtime validation is supplied.

Scope: Message view wrapper.
