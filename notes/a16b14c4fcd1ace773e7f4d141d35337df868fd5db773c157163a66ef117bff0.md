# Clear only the matched legacy compaction threshold during migration

Entry 1162 advances UI migration to 46 and clears mail.purge_threshhold_mb only when its value is 20. Accepted source retains that version/value guard and adds a local catch because the old pref may be absent. New profiles skip old UI migrations. The value check does not distinguish an old default from a user who deliberately selected 20; do not claim all custom values are preserved. Other values do not match this branch.
