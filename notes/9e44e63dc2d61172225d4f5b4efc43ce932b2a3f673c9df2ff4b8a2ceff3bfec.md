# Distinguish an IMAP line-handler early return from cancelling the download

1025 adds NS_ENSURE_SUCCESS_VOID after the IMAP channel listener callback. In this void method that exits the current PostLineDownLoadEvent invocation. The later local-store ParseAdoptedMsgLine failure separately calls PseudoInterrupt(true). Do not describe the new check as an explicit network cancellation or an error result returned to the caller. The two branches have different failure contracts in the accepted source.

Scope: IMAP data listener failure scope.
