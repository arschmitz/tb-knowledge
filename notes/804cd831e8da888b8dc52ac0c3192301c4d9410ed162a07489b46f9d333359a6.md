# Keep automatic NNTP offline selection separate from explicit message keys

NewsDownloader uses folder download settings when it chooses keys itself. It excludes offline, killed and ignored messages and applies unread, age and optional size limits. Supplying explicit keys bypasses that selection. Servers may overlap, but each server downloads folders in order and each folder downloads messages in order. The message callback resolves without checking its status, and service entry points launch async work without returning its completion. A native method returning therefore does not establish that all requested articles downloaded successfully. This is a static source contract, not an executed offline-download result.

Scope: NNTP offline download selection and completion.
