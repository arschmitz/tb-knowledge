# Multimessage row headers import colors and use an explicit font size

The shared multimessage stylesheet imports colors.css and sets h2.item-header rows to 1.1rem. The actual thread template uses that class. Shared toolbar and panel separator aliases both point to color-surface-border, whose accepted definition selects light/dark surface tokens. These are exact stylesheet/consumer facts; rendered sizing, theme behavior and contrast were not tested.

Scope: Multimessage row-header and shared separator CSS.
