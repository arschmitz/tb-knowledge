# Expand wildcard virtual-folder searches for message APIs and state their count limit

A virtual tag folder stores searchFolderURIs as *, so its explicit searchFolders list alone does not identify message sources. getWildcardVirtualFolders walks account descendants and excludes Trash, Junk, Outbox, and other virtual folders. messages.list/query and folders.markAsRead combine those sources with any explicit search folders and apply the virtual search terms. By contrast, getFolderInfo counts for wildcard virtual folders can stay zero until the UI runs a search; the landed test asserts that known broken behavior and current code warns. Do not use those counts as proof the tag folder is empty.

Scope: WebExtension virtual folder messages.

- `mail/components/extensions/ExtensionAccounts.sys.mjs`
