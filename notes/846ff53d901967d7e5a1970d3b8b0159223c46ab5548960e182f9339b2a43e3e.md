# Panorama on-demand table helpers depend on the started singleton lifetime

The reference-removal patch replaces retained FolderDatabase/MessageDatabase RefPtrs in headers, threads, views and wrappers with helpers that directly dereference DatabaseCore::sInstance table members. The constructor no longer starts storage; account-manager initialization calls Startup explicitly. Startup fills the members and installs the shutdown observer; profile shutdown clears both table members and the singleton. These helpers therefore depend on callers staying within a successfully started lifetime. FolderInfo retaining its PerFolderDatabase is a separate ownership edge. This source evidence does not prove shutdown ordering, leak freedom, or failure safety. No lifetime test ran.

Scope: Panorama storage ownership.
