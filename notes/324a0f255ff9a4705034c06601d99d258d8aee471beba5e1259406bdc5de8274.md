# Custom select attribute mirroring must preserve attribute absence

The component renders cloned slotted options. When the source option loses an attribute, the observer removes that attribute from its clone; it copies a value only when the source still has the attribute. The regression scenario removes hidden, waits for removal on the clone and checks visibility. This source does not prove an EWS/OAuth setup or live native popup result.

Scope: Account Hub select option mutation.
