# An active POP3 socket close reports interruption while completion remains asynchronous

connect replaces the LineReader and clears the pending NOOP flag before opening a socket. On close, the client releases serverBusy, preserves authentication handling and passes NS_ERROR_NET_INTERRUPT to completion when the command is still active. _actionDone sets its done guard before awaiting UIDL/QUIT work; separate cleanup reports the URL result and frees the service run. Awaiting the close handler alone does not establish all completion work. These are static branch/order facts, not a reproduced network recovery.

Scope: POP3 close and per-connection state.
