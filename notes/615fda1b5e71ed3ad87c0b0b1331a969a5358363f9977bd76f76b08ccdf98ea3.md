# Tag initialization and import guard synchronous localized defaults differently

SetupLabelTags skips versions above1; otherwise it formats and writes five defaults sequentially, reads their color preferences, then stores version 2. Its constructor ignores the returned status before refreshing the key cache. Profile import has a separate guard: it replaces an existing legacy label only when both the color and localized default name match. These scoped paths do not prove atomic migration, error recovery, or successful import across every profile and locale. No migration ran.

Scope: Tag defaults and profile import.
