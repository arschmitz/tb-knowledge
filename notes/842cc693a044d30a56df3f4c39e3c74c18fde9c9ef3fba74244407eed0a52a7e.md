# Keep CSS keyframes outside selectors and provide a static reduced-motion state

The selection indicator landing was backed out because duplicate @keyframes were nested inside #photoDropTarget. The reland removes those nested blocks and leaves hourglass static unless prefers-reduced-motion is no-preference. Inspect the actual stylesheet structure as well as the screenshot when extracting/shared styling. Use the existing shipping CSS parse test for parser regressions. This is partly parser/lint territory, so the durable manual lesson is to preserve the static state and motion contract; it is not a new formatter-only rule. No CSS parse or rendering test was run here.

Scope: mail/themes.
