# The tree column picker restores a Fluent title on the generated button

The generated picker button receives tree-list-view-column-picker through optional document.l10n. The message supplies .title, while the restore-default menu item has a different .label message. If document localization is absent, this optional call does nothing. The inspected menu test asserts menu-item localization IDs and does not directly prove the button title or accessible name. No live accessibility result was checked.

Scope: Tree view column picker localization.
