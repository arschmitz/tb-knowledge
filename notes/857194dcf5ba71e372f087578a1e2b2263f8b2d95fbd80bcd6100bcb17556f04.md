# Failed filter-copy keys are removed from queued moves and their source headers are restored

After pending copies finish, deferred processing removes failed source keys from every move destination, skips their deferred deletes and restores their retained source headers. Successful delete keys are batched separately. An immediate StoreImapFlags error also enters the restoration path, but a queued request's return value does not establish later server acknowledgment. The fake APPEND-failure test checks preserved source state and later successful-copy body recovery; it does not inject a deferred STORE failure or arbitrary callback loss. This is static inspection with no native or test execution.

Scope: IMAP filter copy failure handling.
