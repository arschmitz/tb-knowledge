# Refresh stored credentials deliberately when observer ordering can expose stale memory

Current shared auth cache distinguishes Memory from Storage. For Storage it forgets the in-memory password before reading it because the cache observer can run before the server observer. This may read storage twice but avoids stale credentials. Preserve the documented ordering tradeoff and account/realm identity when changing observers; no authentication experiment performed.

Scope: ews.
