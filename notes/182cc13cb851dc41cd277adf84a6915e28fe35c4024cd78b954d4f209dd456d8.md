# Separate credential ownership from per-request authentication headers

Historical407 extracts auth out of IEwsIncomingServer and obtains credentials per client. Current shared AuthenticationProvider returns an optional per-request header: Basic/NTLM go through Necko and OAuth supplies Bearer. send_request awaits auth_header_value each request, avoiding reuse of expired tokens. The architecture has moved to protocol_shared; do not copy historical Basic base64 code or mark NTLM unsupported today.

Scope: ews.
