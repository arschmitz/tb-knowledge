# Gloda query expectations check both database membership and query predicates

The query expectation listener tests each returned item against aCollection.query.test(item), optionally verifies order, and makes the collection explicit on completion before checking for missing results. queryExpect preserves queryThis when invoking queryFunc and awaits the listener promise. These helpers cover exact membership and predicate agreement; an order verifier is required when order itself is the contract. This is static source and test-code inspection.
