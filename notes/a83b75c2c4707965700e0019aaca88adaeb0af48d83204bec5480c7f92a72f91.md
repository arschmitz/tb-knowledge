# All-headers whitespace scanning stops at the exclusive header end

This landing changes the all-headers leading-whitespace scan to test contents < end before reading *contents. Here end is the next header start or the final all_headers + all_headers_fp byte endpoint. The accepted producer and indexer preserve that bounded slice, and the buffer can be shrunk to its recorded byte length. The trailing trim and Assign(contents, end - contents) accept an empty value after whitespace is removed. These are scoped source facts; no crash, allocation-failure injection, sanitizer run or complete MIME-format guarantee was tested.

Scope: MIME inline forwarding.
