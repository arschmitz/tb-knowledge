# The imAccounts crash recipe names a different source key and target ID than its consumer

The consumer formats notification-single-crash-label with the suspected-account count. The recipe instead reads bundledMessagePreview from imAccounts.properties and creates accountsManager.notification.singleCrash.label. Those names do not match the removed source property and new consumer ID. The archived recipe retains the original blob. This is a static migration-contract mismatch; no migration failure or locale output was executed.

Scope: Chat account crash-warning migration.
