# Password deletion tests wait for storage after the dialog tree changes

The single-delete test first waits for one tree row, then waits until getAllLogins returns five entries. The remove-all test first waits for zero tree rows, then waits until the stored login list is empty. A UI update and a storage commit are separate test milestones. The source uses async predicates; the external polling helper and browser/storage behavior were not executed here.

Scope: Password manager browser tests.
