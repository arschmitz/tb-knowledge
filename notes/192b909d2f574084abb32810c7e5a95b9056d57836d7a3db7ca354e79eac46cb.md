# Match a replacement helper return shape to append or extend

Current mk_gecko_rev_replacement returns zero or one nested replacement triples. Callers use extend so unchanged values contribute nothing. Historical481 instead backed out to one flat triple plus append. The current helper/caller pair is the accepted contract; neither append nor extend is a universal style preference. Proposed manual Python rule: document and verify the collection shape at helper boundaries, especially optional no-op results. Bug 1905941 rationale remains unread because browser access stopped.

Scope: taskcluster/comm_taskgraph/transforms.
