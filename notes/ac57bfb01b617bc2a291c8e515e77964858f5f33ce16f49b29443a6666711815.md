# Folder ID parsing preserves delimiters inside paths

At revision 4ee1236e7d4268751bee94659b76acaf3adc60c2, the ordinary WebExtension folder-ID parser takes the first :/ separated part as accountId and rejoins all remaining parts with :/. This preserves occurrences of :/ inside the folder path. A parser that keeps only the second split part would lose path content. This applies to the ordinary ID branch; unified:// and tag:// IDs have separate earlier branches. The evidence is static source, with no parser test result supplied.

Scope: WebExtension folder ID parsing.
