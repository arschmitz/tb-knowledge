# The granular-scope test resets remembered OAuth objects before each original scenario

The one-line landing resets remembered OAuth objects between deleting saved logins and resetting FOG at subtest start. The helper clears token-bearing remembered objects; accepted code later repeats that setup inside its authorization retry loop. This separates scenario state from saved logins and telemetry, without establishing that the intermittent failure was cured.

Scope: Thunderbird granular OAuth scope browser test.
