# EWS XML field and shared-type names encode the wire schema

Entry 1487 moves the shared DeleteType into common wire types, defines DeleteFolder request/response structures and changes sync-folder deletion entries to named ID fields with PascalCase XML mapping. Empty folder content receives an explicit serde default. These are substantive vendored schema changes supporting the owned folder-delete API, not a bulk body import. Keep the Rust field mapping and XML names paired in this vendor boundary; do not promote third-party wire casing as Thunderbird's JavaScript or owned Rust naming style.
