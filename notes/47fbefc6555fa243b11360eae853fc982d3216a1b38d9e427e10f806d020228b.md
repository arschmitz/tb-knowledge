# Repeated blocked-content translation targets the notification message rather than its whole container

setBlockedContent creates a notification with a Fluent label and separate action buttons. On later blocked URIs, it updates the count on the existing notification messageText instead of localizing the entire notification object. The accepted nearby public-recipient consumer uses the same property. This is the adopted compose target-selection pattern; the initially proposed extra span query is not the final code. Engine property internals, live button preservation and keyboard/accessibility behavior remain unverified.

Scope: Compose notification localization target.
