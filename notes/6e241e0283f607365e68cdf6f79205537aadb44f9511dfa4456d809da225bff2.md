# Initial about:blank does not consume the mail-tab load callbacks

The mail-tab handlers return for about:blank before invoking a callback or removing the listener. This lets a later nonblank document event reach the callback; a closed tab skips it. MessagePane readiness also treats an initially complete blank document as needing a load, while the test helper separately requires the complete about:message document and then checks content-browser state. These predicates have different scopes: the production readiness handler waits for the next load without rechecking its URL. Do not treat an arbitrary load event or readyState alone as proof of the requested inner page.

Scope: Mail tab and message-pane initial loading.
