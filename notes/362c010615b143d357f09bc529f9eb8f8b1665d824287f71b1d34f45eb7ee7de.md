# Leaf twisties retain an alignment slot while recycled row structure controls animation

The owned icon/twisty change creates a wrapper with fixed button/icon sizes and flex centering. Leaf twisties use visibility:hidden, preserving the slot that aligns neighboring text. Its per-fill cell rebuild can replace the icon, so a CSS transition alone does not prove visible animation. Accepted source later caches cell structure and keeps an icon only when _twistyAnimating is set by explicit expand/collapse. These are distinct phases. Source tests check DOM and visibility, not a fresh animation, layout or accessibility result.

Scope: AutoTreeView icon and twisty layout.
