# Folder TLS warnings follow feedback events and connection-notification state

The feedback event adds tls-error to matching server rows, shows their status button and sets the localized title and settings action. A server-connection-succeeded observer notification removes the class and hides that button. _changeRows updates only present rows with the matching URI; it does not select a visible child when the server root is absent. Protocol producers report connection checkpoints, not completed mail operations. The current extracted listener and hidden-property handling are later phases beyond the initial patch. No connection or UI test ran.

Scope: Folder-pane row warning producer and reset boundary.
