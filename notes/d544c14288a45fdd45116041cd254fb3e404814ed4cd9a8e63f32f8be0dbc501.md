# Calendar centerscreen is a window-route option, not every dialog opener

Entry 2068 adds centerscreen to openEventDialog’s openDialog feature string. Although the bug title names the summary dialog, the changed window branch can also open the legacy event dialog. Fixed source first chooses editable-event versus summary URL, then a tab or feature-gated in-app dialog route, and finally the centered window route. Preserve those routes when changing shared openers. No initial-position or focus test changed or ran; platform placement, new-dialog positioning and live accessibility remain unverified.

Scope: Calendar item-editing window openers.
