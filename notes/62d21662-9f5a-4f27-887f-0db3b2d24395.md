# Preserve preformatted line breaks when quoting HTML selection

When replying to a selection inside an HTML pre element, preserve its whitespace and line breaks in the quote. HTML parsing strips the newline immediately after the opening pre tag, so tests must select the actual text-node range.

Scope: compose.
