# Yield asynchronously while parsing long multiline mail responses

LineReader is shared by POP3 and NNTP. Bug 1893307 found that spinEventLoopUntilEmpty during a very long POP3 LIST response could stall processing until server timeout. The accepted code makes read async and yields with setTimeout after each 1000 lines, while retaining line and done callbacks. Current code keeps that behavior. Do not describe this as a NOOP fix; the review says NOOP handling was a separate change.

Scope: Mail protocol line reader.
