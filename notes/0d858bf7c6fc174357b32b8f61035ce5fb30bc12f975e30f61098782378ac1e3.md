# MailServices lazy service declarations pass Ci interface objects

The accepted MailServices lazy service declarations pass Ci interface objects as their final argument. The compatibility port replaced quoted interface names while keeping service property names and contract IDs. This scope concerns XPCOMUtils service declarations, not every lazy getter or arbitrary string argument. Later service renaming is separate current context. The upstream getter implementation was not paired or executed.

Scope: mail-services.
