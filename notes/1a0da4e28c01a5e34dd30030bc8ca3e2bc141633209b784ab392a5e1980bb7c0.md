# Panorama pending-listener registration opens its compatibility view immediately

RegisterPendingListener calls OpenFolderDB and AddListener, so it does not wait for a separate per-folder physical database to open. The inspected UnregisterPendingListener remains a no-op success; avoid assuming symmetry from its name. Message.accountKey separately resolves folder root to server to account rather than reading a stored key. The original charset stub also returns an empty successful value and is not complete charset support. No listener test ran.

Scope: Panorama compatibility contracts.
