# Signature status display requires a usable sink and the current display context

Current displayStatus returns for null exitCode, an already displayed status, background jobs or a missing sink. On success it forwards the result fields and marks statusDisplayed. The missing-signature branch can therefore compute BAD_SIGNATURE without a visible status update in every context. Proposed focused checks should distinguish parser/result state from UI sink state. No duplicate-display, print/filter or missing-sink scenario was run. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: OpenPGP result display.
