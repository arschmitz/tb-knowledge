# Semantic color token names describe role, state and optional scheme

Entry 786 introduces semantic color families for surfaces, primary and secondary actions, success, warning, critical messages, text and accents. Current colors.css has light and dark backing tokens and scheme-independent aliases using light-dark. The primary family includes soft, default, hover and pressed variants; text-critical is distinct from critical-default. Manual CSS naming proposal for this token family: extend role and state names instead of inventing a hue name for a semantic purpose, and consume the unsuffixed alias when the component should follow its color scheme. Existing palette tokens and local component variables still coexist. These definitions alone do not show token adoption in every component or establish sufficient contrast.

Scope: semantic-css-tokens.
