# DMD script removal changes the package manifest scope

Entry827 removes the MOZ_DMD block that included dmd.py and fix_stacks.py in the Thunderbird package manifest. The fixed accepted manifest no longer contains those names. This is a script packaging removal, not evidence that DMD runtime instrumentation was disabled or that every support path was removed. The manifest header explains that some staging files are implicitly packaged, so this file alone does not prove all package contents. No package was built or inspected.
