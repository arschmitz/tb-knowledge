# Recent destination menus preserve time order before optional alphabetical sorting

The historical patch prevents a final label sort from replacing the recent-folder helper’s descending MRMTime order; favorites still sort alphabetically. Current code additionally permits alphabetical recent entries when mail.folder_widget.recent_sort_order is1, with lookup fallback0 preserving helper order. Mapping and label disambiguation happen between selection and insertion, so sorting there changes presentation order without changing which folders the helper selected. The current recent-menu test directly checks one destination and exclusion after delete/archive; it does not verify a multi-entry recency order or the alphabetical preference. Treat recency-first ordering as this menu policy, not a universal interface rule.

Scope: Move/copy destination menus.
