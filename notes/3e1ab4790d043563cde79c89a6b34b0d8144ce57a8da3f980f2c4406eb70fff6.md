# Attached-message drops await the copy callback before refreshing the folder

The drag receiver builds an AttachmentInfo for each URL and awaits each import before refreshing the destination. The importer fetches and normalizes data, writes a temp file and awaits a copy promise settled by onStopCopy. Refresh has a separate IMAP URL-listener completion. The original only removes the file after success; later try/finally cleanup belongs to the Copy To phase. The synthetic test replaces the importer, so it supports routing and canned-message assertions rather than the production fetch/cleanup path.

Scope: Attached-message drag import completion.
