# Splitter lock targets depend on which grid rows a pane spans

PaneLayout configures the message splitter for each layout. Wide and vertical layouts lock threadPane and folderPane; Classic locks only threadPane. In Classic the folder pane spans several rows, and fixing its height inflates row minimum sizes, preventing the thread pane from shrinking and leaving a gap. The caller now derives resize-lock-ids from the layout rather than hard-coding both panes in markup. Manual layout proposal: choose lock targets by their role and span in the active grid; test each layout before reusing a lock list. This current explanation does not establish the unknown cause of the 2024 backout.

Scope: pane-layout.
