# Spell interface callback names exactly even for no-op methods

Entry 505 corrects aetMessageKey to setMessageKey in a JS copy listener. The IDL contract still spells setMessageKey. These names are interface entry points, not ordinary local identifier preferences. Current junk handling delegates to folder.performActionsOnJunkMsgs instead of that listener, so do not restore the old no-op object as current architecture.

Scope: mailnews/base/public.
