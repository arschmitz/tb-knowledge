# Thunderbird error wording changed after a remote RSS consumer corrected the review premise

The appstrings override packages Thunderbird-specific error text and registers it for the global appstrings URI. In review, an initial claim that these messages only appear in remote tabs/add-ons is corrected by the remote RSS article view. The author then replaces website wording with server/content while retaining page for the two policy errors. Fixed strings preserve that decision. This is the scope of these messages, not a universal vocabulary rule. No RSS, locale or error-page runtime check ran.

Scope: Thunderbird error-message consumer scope.
