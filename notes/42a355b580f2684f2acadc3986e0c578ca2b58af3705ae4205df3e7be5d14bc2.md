# Privileged document CSP declarations differ by document and resource type

The owned patch adds six document-level CSP meta declarations with different script, style, image and connection source sets. Fixed three-pane/message policies additionally list data: images; other selected dialogs keep narrower declarations. The old account-setup document is absent at fixed source. Check the actual document and resource directive before reusing a policy. These are static declarations, not proof of a full document census or browser enforcement. No UI or CSP test ran.

Scope: Thunderbird privileged document CSPs.
