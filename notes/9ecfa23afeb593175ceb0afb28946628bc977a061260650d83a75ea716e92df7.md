# Favorite mode explicitly includes the smart-mailbox server

Favorite mode normally initializes servers in ordered accounts. The synthetic smart-mailbox server is added separately through findServer("nobody", "smart mailboxes", "none") because it is outside that normal account list. The favorite filter still requires the Favorite flag and avoids duplicate rows. Keep this synthetic source in mode rebuilding, not only in live flag-change notifications.
