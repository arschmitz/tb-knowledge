# Use stable account keys in QR selection and recalculate control state

The pane stores account.key in each checkbox value and places the user-facing prettyName next to it inside a label. getSelectedAccounts returns the values of checked inputs. Selection state disables Export when none are selected and Select All when no unchecked inputs remain. Select All assigns checked and then calls updateIntroState explicitly. Form submit prevents navigation before starting the next step. Keep stable identifiers separate from display text and update derived state after programmatic changes. Browser tests inspect real click and selection behavior, but were not executed here.

Scope: mail/qrexport/selection-controls.
