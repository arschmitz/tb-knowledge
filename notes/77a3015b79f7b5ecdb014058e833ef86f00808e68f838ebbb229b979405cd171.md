# Register the SAS verification listener before invoking verification

startVerification constructs a promise by registering VerifierEvent.ShowSas, then calls verify and awaits the event. It checks cancelled state before interpreting the challenge and supports emoji or decimal representations. A scoped async recommendation is to retain listener-before-action ordering when refactoring this SDK adapter; waiting only after verify could miss an event. Rejection/cancellation completion and live cryptographic behavior were not executed. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
