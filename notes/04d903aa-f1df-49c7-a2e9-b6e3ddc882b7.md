# Do not assume Panorama thread parents already exist

Panorama currently derives a new message's thread and parent IDs from references already in the database. The code calls this an unsustainable shortcut: real mail can arrive out of order, so future threading work must resolve missing parents and must not treat this assumption as a permanent contract.

Scope: panorama.
