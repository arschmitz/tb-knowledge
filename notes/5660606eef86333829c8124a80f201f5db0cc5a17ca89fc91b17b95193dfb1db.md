# The initial VCard add glyph takes its fill from the supplied context stroke

The original VCard patch selects the comm compact add.svg and supplies context stroke with stroke:currentColor. That SVG paints its path with fill="context-stroke", so the context channel and the SVG paint attribute have different names. The asset blob is identical at original and accepted revisions. Accepted VCard markup later removes the inline image and uses a circle-add pseudo-element; keep that later phase separate. No icon pixels or accessibility result was validated.

Scope: address-book-svg-css.
