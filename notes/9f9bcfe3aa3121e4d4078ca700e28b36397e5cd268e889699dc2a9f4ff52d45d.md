# The offline flag guard checks serialized UID content before dispatch

The owned historical guard checks !uids.IsEmpty() instead of using the CString data pointer as a content test. Key grouping and URL-listener handling remain. Its mapping TODOs are not a mapping implementation. Accepted source later passes a message-key array to SetImapFlags, whose receiver maps keys through the database before serializing UIDs; that later API phase is separate.

Scope: Thunderbird IMAP offline flag playback.
