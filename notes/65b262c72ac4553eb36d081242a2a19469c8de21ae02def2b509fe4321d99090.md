# The xMac metadata cleanup spans attachment storage and MIME forwarding

The 2614/2615 patches remove xMacType and xMacCreator from both attachment interfaces and native storage/accessors, then stop extracting and forwarding those values in MIME draft/attachment bridges. Current selected code still handles an AppleDouble content-type boundary and attachment name/type/size. The cleanup therefore does not establish removal of every Apple attachment path or a general rule about platform metadata. No MIME round-trip or native platform test ran. Required Bug scope is unavailable and own reviews deferred; source-only zero audit credit.

Scope: Attachment Mac metadata scope.
