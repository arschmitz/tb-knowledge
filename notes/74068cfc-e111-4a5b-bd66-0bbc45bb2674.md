# Prefer POP3 SASL methods while preserving fallback after a rejected command

Bug 1897045 changed the cleartext-password preference order to AUTH PLAIN, AUTH LOGIN, then USER/PASS. The Bugzilla report calls PLAIN and LOGIN obfuscation, not encryption; TLS still matters. Later Bug 1928026 exposed a server that advertised PLAIN but returned -ERR. Thunderbird stopped rather than trying USER/PASS. The later fix made failed AUTH PLAIN or LOGIN commands advance to the next supported method, and the reporter confirmed the repair. Current Pop3Client.sys.mjs retains both the order and the fallback. When changing protocol preference order, test rejected commands as well as unsupported capabilities.

Scope: POP3 authentication.
