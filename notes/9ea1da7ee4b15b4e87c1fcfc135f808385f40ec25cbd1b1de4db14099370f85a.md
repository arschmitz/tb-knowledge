# Create the Panorama folder schema only when the profile database is new

The historical open path checks whether panorama.sqlite exists before OpenUnsharedDatabase, then creates its folders table. Current EnsureConnection retains the existence check, uses CreateNewDatabase and propagates schema errors. Its folder schema has a unique parent/name pair, optional ordinal and flags default 0. This is schema creation for the new-file path, not proof of an upgrade migration or general database recovery. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama database schema.
