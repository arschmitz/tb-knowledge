# Set forwarded message MIME type independently of its filename

Forward-as-attachment explicitly sets message/rfc822 even when mail.forward_add_extension is false. The current test covers why.eml and why names and checks the same MIME type for both. Preserve explicit message type at this operation boundary instead of relying on a filename suffix to identify attached mail. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
