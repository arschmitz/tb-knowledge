# Database-view command availability is returned directly to JavaScript

getCommandStatus exposes one Boolean availability result. The base implementation derives it from the requested command, selection and folder support. JavaScript command and toolbar consumers use that result directly, replacing the old selectable/check-state out objects. The general command dispatcher rejects a missing view before its database-view cases, while the registered junk callback uses optional calls. This is the inspected interface and caller contract, not a guarantee that every derived implementation writes its output.

Scope: mail command controllers and nsIMsgDBView.
