# Documentation project and version share a cached property-load helper

The no-argument _read_project_properties helper now uses functools.cache, while its configuration-loading body and project/version accessors stay unchanged in this landing. Both accessors read keys from that helper’s returned mapping. This is a scoped decorator replacement; it does not establish every old memoize edge case, configuration-invalidation behavior or a successful documentation build.

Scope: Documentation command metadata cache.
