# Keep the single Account Hub selection variant outside the two-column grid

1961 changes the single selection-grid variant to display:block. Current normal selection grids use two minmax(0,1fr) columns; a .single ancestor switches the grid to block. This is a local large-font layout choice, not a recommendation to replace every grid or an independently verified ellipsis result. Proposed manual UI check: use the one-provider and multi-provider variants at the supported large font sizes and inspect wrapping/overflow separately. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: account hub font layout.
