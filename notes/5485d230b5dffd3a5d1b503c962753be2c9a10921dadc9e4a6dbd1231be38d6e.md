# The unobtrusive-key subtest keeps zero signature expectations after importing the key

The new unobtrusive case runs without Carol's key and then with it. The first pass changes the shared test object's sig to false and flags to null. The key-present branch imports the key but does not restore either field, so its expectedResultCount stays zero and its signed, key-ID and flag checks remain skipped. The same code remains at the fixed accepted revision. This is a static test-coverage limit, not a reproduced failure or cryptographic result.

Scope: mailnews/mime/test/unit OpenPGP MIME coverage.
