# The about-support test awaits localization readiness directly while retaining later data waits

The patch replaces a separately polled l10nDone flag with await l10n.ready and directly clicks the aboutsupport_open command on every platform. Localization rejection can now propagate instead of only logging while the flag wait times out. It keeps account/regional-data waits and an existing500ms delay for later localization, so it does not prove all timing is reliable or remove every delay. The former non-mac menu interaction path is no longer exercised by this helper. No browser, menu, localization or test ran.

Scope: About-support browser helper wait and failure behavior.
