# Merge configuration keys are dispatched into branch-specific replacement behavior

The 876 reland restores the configurable worker.gecko-rev mapping and zero-or-one replacement-list helper. The 877 workaround inserts a GECKO_HEAD_REV line by replacing the literal ###### marker for central-to-beta, where the key is absent. Current code uses main-to-beta and Git branch names, skips bump-main and bump-esr153, and still uses the marker for that transition. The old from-repo/to-repo keys are no longer the current recipe. Manual config naming proposal: preserve source branch, upstream repository, symbolic HEAD_REF and exact HEAD_REV as different values and verify each dispatch case. The existing shared lessons already cover append/extend shape, formatted regexes, tag traversal order and absent-key insertion; this batch adds the final reland evidence without duplicating those rules. Complete cached Bug 1905941 comments were read privately; D215538 has file bodies still Loading, so review inlines remain pending.
