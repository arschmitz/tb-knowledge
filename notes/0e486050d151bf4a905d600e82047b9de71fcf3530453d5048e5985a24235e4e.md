# Register built-in themes through the shared theme configuration

MailGlue calls ensureBuiltInThemes rather than repeating IDs and versions. That method installs each map entry with its version and complete resource path and awaits the collected install promises. Current theme configuration and both manifests agree on version 1.3.2, while the browser test compares installed add-ons with the configuration. Keep the configuration and manifests aligned when updating these themes. MailGlue cannot await that startup call at this point, so this source does not prove startup waits for installation. The existing complete-resource-path lesson is reused. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Built-in theme version authority.
