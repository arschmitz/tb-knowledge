# Hidden-alternative parsing restores shared output state only on its success tail

The cached-alternative helper saves its shared output callback and parser flags before parsing. Several negative-status exits precede the restoration tail. The owned comment and accepted implementation preserve that failure-path limitation. A guard return here must be assessed with the shared state lifetime; the normal restoration does not prove cleanup on failure. No failing MIME input or runtime corruption was reproduced.

Scope: MIME cached alternative failure paths.
