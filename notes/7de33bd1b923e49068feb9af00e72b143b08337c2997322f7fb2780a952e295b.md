# Authentication challenge consumers need the response header collection

Response::header exposes newline-separated channel values as Vec<String>. The historical NTLM helper searches the collection for an NTLM-prefixed challenge rather than assuming the first value is usable. The accepted sender still carries this collection in its401 authentication error. This API preserves multiple returned values; it does not prove parsing of all comma-combined authentication syntax or live negotiation.

Scope: moz_http repeated response headers.
