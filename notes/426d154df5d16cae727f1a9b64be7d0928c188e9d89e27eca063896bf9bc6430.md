# Separate original-message encryption from encrypted-draft storage policy

930 considers both historical OpenPGP and S/MIME trackers when determining encrypted-message status, while excluding Draft and Template from automatic related-original state. The accepted compose startup checks gEncryptedURIService and keeps the draft policy explanation: drafts can be stored encrypted regardless of the desired send setting. The accepted OpenPGP display path now registers encrypted URIs with the same service. Preserve the policy distinction without reintroducing the retired tracker calls. Later tracker consolidation was checked only as current context.

Scope: Compose encrypted-original versus draft policy.
