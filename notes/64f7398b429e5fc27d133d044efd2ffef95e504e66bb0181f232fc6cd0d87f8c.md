# Empty and about:blank notification endpoints bypass fetch failure handling

Entry 1378 returns false before fetch for a formatted empty URL or about:blank. The accepted function retains that check, after eligibility/callback checks but before daily-rate handling and the network try/catch. This is a deliberate no-fetch branch, not a fetch error that increments the failure count. The test checks false and no update callback for both inputs. No fetch, timer or retry test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Notification updater absent endpoint.
