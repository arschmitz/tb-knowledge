# Shared vCard markup can require a stylesheet supplied by its host

1264 adds variables.css to AccountManager and explains shared vCard editor usage at the host rather than inside vCardTemplates. Current template still shares vcard.css between AccountManager and the address book, but both host stylesheet stacks have since changed and no longer include variables.css directly in the inspected heads. A scoped recommendation is to check each host’s token dependencies when embedding shared markup. Do not impose the old variables.css include as a current blanket rule; no rendered vCard check ran. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
