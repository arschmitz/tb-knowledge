# SMTP socket errors await the active send listener before releasing the client

The socket-error handler now awaits its installed error callback before calling _free(true). The server callback awaits the terminal listener, while onFree returns the client to the pool and wakes a queued sender. The regression waits for two refused-connection listener results after a successful baseline with one cached client. This is source ordering and direct test-code coverage; callback rejection is not caught here and no live queue or universal cleanup result was established.

Scope: SMTP client error callback and server connection pool.
