# A listener alias can link the shared wrapper ownership documentation

The early sync-listener alias has no own doc comment. The later reland and accepted current alias use See SafeListenerWrapper, while the common constructor explains that RefPtr keeps the borrowed listener alive for the returned wrapper and asynchronous work. A short alias link avoids repeating that ownership text for each listener. This is an accepted local documentation shape for this wrapper family, not permission to omit distinct safety conditions, an unrestricted link-only documentation rule, or a fresh lifetime test. The historical reland narrows the alias to pub(crate); current shared code is public because other crates use it. Keep the exact crate and caller scope when evaluating visibility.

Scope: Scoped Rust alias documentation and duplication.
