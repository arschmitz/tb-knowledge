# Calendar divider ownership follows location presence while meeting visibility is separate

The location setter assigns divider to the location row when its input is nonempty, otherwise to the earlier meeting row. Meeting visibility is controlled separately by extracting a meeting URL. CSS draws the pseudo-element with logical block spacing and the surface-deep token. Keep class ownership, row visibility and rendered appearance distinct; inspected tests assert location visibility without directly checking divider rendering.

Scope: Calendar dialog optional location and meeting rows.
