# The native file-picker port adds an explicit null fourth argument at three legacy save sites

The owned patch changes only the Init arity at the overwrite, single-message save and multi-message directory pickers. Each keeps its browsing context and mode and passes nullptr as the fourth argument. Cancellation and null-output handling stay in the existing save helpers and callers. The fixed accepted nsMessenger source no longer has these functions; later JS MessageSaver code is a separate phase. The upstream owner-global contract and native build were not verified.

Scope: Historical native message-save file pickers.
