# Contact form Escape handling needs keydown and the exact Escape key

The form uses keydown to receive Escape, prevents the default action and requests a form reset. A dialog Escape test separately waits for photo dialog closure. Review corrects the proposed Esc spelling to Escape. The assigned patch changes the event type only; it does not add stopPropagation or prove every nested dialog interaction. The test-only wait proposal was rebutted because real contact editing also closed. Native keyboard behavior was not rerun.

Scope: Address-book keyboard contracts.
