# Use matching fixed-width operands for the EML header read bound

The original large-header patch used std::min(fileSize, 500 * 1024L) and was backed out for build failures. The adjusted reland uses int64_t(500 * 1024), matching fileSize. Current accepted code retains that expression. Keep both operands compatible when changing this C++ bound. The precise failed platform and compiler diagnostic remain unknown until the discussion is read.

Scope: mailnews/local/src.
