# Legacy folder type exposes only the first special use

At revision 4ee1236e7d4268751bee94659b76acaf3adc60c2, FolderManager.convert exposes specialUse from the folder flags, while the deprecated Manifest V2 type property contains only specialUse[0] and is added only when the array is nonempty. Manifest V3 omits type. The source explains that a folder can have more than one special use, so the legacy scalar cannot describe all of them. Apply this distinction when consuming converted MailFolder objects. This is static source evidence, not a test result.

Scope: WebExtension folder special-use compatibility.
