# Calendar Escape handling routes cancel through the custom close lifecycle

This landing registers CalendarDialog for cancel events and calls its custom close method when Escape requests a close. The checked close chain removes positioned-dialog resize state and resets CalendarDialog loading/data/showPromise state. The new test waits for cancel and checks that the same-event dialog closes; it does not directly test a different-event reopen after Escape or every reset field. The review's cancel-listener/custom-close routing is present, while its literal preventDefault proposal is absent in both owned and fixed branches. Native event-default ordering and live keyboard behavior were not exercised.

Scope: calendar-dialog.
