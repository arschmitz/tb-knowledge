# Supply required copy-listener state in its constructor

The old registered stream listener exposed Init; 1172 replaces it with CopyMessageStreamListener(destination, isMove). Current direct callers create a RefPtr with both values, and forwarding methods immediately use mDestination. Scoped design recommendation: keep destination and operation state required at construction for this helper, instead of allowing a successfully created but uninitialized component. The constructor itself has no null assertion, so caller correctness still matters. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mailnews/base/src.
