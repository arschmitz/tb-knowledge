# Map recurrence widget parents by element ID before localized reordering

The recurrence dialog captures each node’s original parent keyed by its element ID. It passes named day, ordinal, article and month variables to Fluent, then appends each returned ID to its captured parent. Locale order must not change which container owns a node. The code checks the number of returned tokens and reports missing nodes; it does not validate a complete unique permutation, so stronger malformed-string guarantees are not claimed. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: calendar/base/content.
