# UID validity separates cache entries and controls offline-operation replay

The checked cache lookup and cache opener both build a hexadecimal extension from the mailbox UID-validity value. Offline replay has a separate consumer: for non-pseudo IMAP playback, a changed value deletes stored operations before lookup. The type patch threads ImapUid through these existing contracts; it does not introduce the policies or prove cache/replay success. No server or offline operation ran.

Scope: IMAP validity consumers.
