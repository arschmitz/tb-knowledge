# Import parent traversal validates the replacement folder before assigning it

ImportMailThread retrieves a parent into a separate nsCOMPtr, rejects a failed or null result, then decrements depth and replaces curFolder. The patch also skips a mailbox after failed subfolder initialization or contains-child lookup. These skip branches do not themselves set fatalError, and the initial root initialization still ignores its result. This preserves the specific pointer and status contracts; it does not prove all import errors are handled or a reported crash is cured.

Scope: Mail import traversal and proxy failure handling.
