# EWS Rustdoc labels the protocol operation separately from its Rust type

The create-message function names a CreateItem operation in its reference label and supplies a colon-terminated reference definition pointing to the Microsoft protocol-operation page. This distinguishes the operation link from the Rust CreateItem type. Exact accepted source retains the label and definition. This is a scoped documentation example; it does not establish the linked page content, successful link resolution, rendered layout, or a repository-wide comment template.
