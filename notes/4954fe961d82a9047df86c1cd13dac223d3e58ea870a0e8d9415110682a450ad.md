# Exchange channel pending state delegates to the internal request when one exists

The historical new EWS offline channel returns false when it has a pump and true otherwise in IsPending. The accepted Exchange channel delegates to mReadRequest and otherwise reports whether a download is in progress. The historical-to-current source contrast identifies a request-state boundary; it does not establish which UI callers observed the older value or prove a runtime repair. For this channel, recommend making pending state describe actual active work rather than the presence test inverted from that work. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Exchange pending state source contrast.
