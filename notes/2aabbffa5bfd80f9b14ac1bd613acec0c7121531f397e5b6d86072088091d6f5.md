# Mbox diagnostics use distinct counter labels and generated-language names

The mbox_read_errors schema names a labeled counter for read failures. The C++ producer uses mbox_read_errors.Get("missing_from") or Get("unexpected_size"), while JavaScript tests read Glean.mail.mboxReadErrors with the same labels. For this metric family, keep the semantic label stable across producer and test and use the generated member form for each language. This is a local naming pattern, not a requirement to rename all metrics or a count of unique damaged mailboxes. The data-review URL was seen in source, but its approval text and submitted telemetry were not inspected. In this implementation, unexpected_size increments on each failing Read while mOverflow is set. Repeated failing reads can count the same message more than once.

Scope: Mbox telemetry naming.
