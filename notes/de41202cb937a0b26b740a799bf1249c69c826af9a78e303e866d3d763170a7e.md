# The classic OpenPGP protected wrapper labels signing mode with hp

In the classic/encrypted writeSecureHeaders branch, signMessage controls whether an hp parameter is added. Signed-only output uses clear; signed and encrypted output uses cipher; unsigned encrypted output adds neither through this branch. The parameter is attached to the multipart/mixed protected wrapper. Accepted unobtrusive output is a separate route, so this branch does not define every signature format's header location.

Scope: OpenPGP MIME header-protection parameter.
