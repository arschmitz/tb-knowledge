# Numeric flag keys do not preserve the folder color map declaration priority

folderColors uses computed numeric flag properties and iterates Object.entries until the first match. Those integer keys enumerate numerically, so Virtual32 comes before Inbox4096 despite the written declaration order. getSpecialFolderString instead checks Inbox before Virtual. Preserve that source/comment difference when reasoning about a folder with multiple mapped flags. No real multi-flag folder or rendered wrong-color outcome was exercised.

Scope: Folder color flag matching order.
