# Check platform tree rules before consolidating styles

Linux still displays the down icon for ascending tree sort, while macOS and Windows use the up icon. Windows contrast styling uses SelectedItem and SelectedItemText and a thicker current-row outline. Its current @media block no longer has the original :root:not([lwtheme]) qualifier. Prefer that accepted scope when reviewing a new change. Preserve intentional platform behavior rather than assuming identical selectors or arrows. No platform UI or forced-colors measurement was performed. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/legacy-tree/platform-style.
