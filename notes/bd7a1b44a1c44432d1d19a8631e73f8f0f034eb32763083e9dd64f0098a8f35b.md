# Symbol-upload runtime allowance is separate from the upload command

The assigned symbol-upload change raises worker.max-run-time from 900 to 1800. The accepted kind file uses 2700 in a later phase. The upload command, symbol artifact reference and secret are separate fields; the assigned patch changes none of them. The larger allowance does not itself show that an upload completed.

Scope: symbol-upload-task.
