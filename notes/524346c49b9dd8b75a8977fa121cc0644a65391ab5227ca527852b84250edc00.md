# The initial Graph schema hierarchy orders namespace module writes

The initial namespace support groups selected schemas by PathBuf in a BTreeMap, sorts each namespace module list, and writes ancestor pub mod entries. Parsed paths and schemas also use BTreeMap after a review concern about varying schema order. Selection still uses the explicit supported-type allowlist. The fixed accepted generator later uses ModuleHierarchy and complete generated-file writes, so the old recursive append helper is historical. Static source supports these ordering steps; no repeat-run determinism test was run.

Scope: rust/ms_graph_tb/ms_graph_tb_extract.
