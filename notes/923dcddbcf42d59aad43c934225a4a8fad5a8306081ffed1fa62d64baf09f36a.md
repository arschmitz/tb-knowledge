# Keyserver lookup and upload use different selections from the same preference

Lookup filters all supported vks/hkp/hkps entries from the comma-separated preference, while upload uses the first matching entry. No supported lookup server returns an all-false state object, and the key-ID caller destructures that object. The helper removal also narrows the former comma-or-semicolon splitting behavior. Backend defaults and network results require separate checks; this source-only entry has an unavailable primary bug comment.

Scope: OpenPGP keyserver preference consumers.
