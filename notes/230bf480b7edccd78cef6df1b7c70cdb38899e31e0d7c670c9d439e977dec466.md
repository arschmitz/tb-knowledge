# The update-verification GitHub fallback keeps the requested tag and file path

The fallback switches to thunderbird/thunderbird-desktop while keeping refs/tags/{rev}/{path}. The remote helper first tries the configured Mercurial URL and chooses GitHub only when that result is None. Its release-tag caller constructs PRODUCT_VERSION_RELEASE and may use a matching local tag instead. The change does not establish that a requested tag exists or that the second download succeeds. No remote request or update-verification job was run.

Scope: Release update verification.
