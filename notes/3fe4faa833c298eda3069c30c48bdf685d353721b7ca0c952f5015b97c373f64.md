# Message-header contact addition resolves a configurable address-book URI

This landing routes message-header contact addition through getDefaultAddDirectory, which resolves the URI in mail.addr_book.add_item_default_uri. Both the email-address popup and indicator button reach the same recipient method. The settings chooser filters read-only directories and permits remote candidates, but the helper itself has no local invalid-URI fallback. No broader New Contact behavior, provider synchronization or native failure guarantee is established.

Scope: message header and address-book defaults.
