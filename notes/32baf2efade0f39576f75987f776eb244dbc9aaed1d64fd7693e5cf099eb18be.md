# Move coalescing groups keys by destination and tracks later folder refresh

The coalescer uses parallel destination and source-key arrays and deduplicates keys within each destination. Successful CopyMessages starts increase m_outstandingMoves. Its copy listener can select a non-Junk/non-Trash IMAP destination, and OnStopRunningUrl decreases the count before conditional new-mail notification. Failure, skipped refresh and callback-balance paths were not tested; initialization alone does not prove that every move completion decrements exactly once. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
