# The config-option density patch omits an extra touch override, not inheritance from base padding

Entry2134 sets base config-option inline/block padding to 9px/6px and compact to 6px/3px. The touch selector adds no override for these variables, so it inherits base padding. The author rejected an additional3px relaxed-density increase as a local visual choice. The summary no changes for relaxed density does not prove unchanged inherited geometry against the prepatch literal values. Fixed0b93 retains these variables and selected/unselected consumers. This is a scoped exception to adding touch-specific values, not a new global density rule. No layout or accessibility run occurred.

Scope: Account Hub config option density inheritance.
