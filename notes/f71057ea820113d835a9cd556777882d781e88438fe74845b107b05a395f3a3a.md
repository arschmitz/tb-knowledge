# EWS server settings hide stable containers through exact server-type tokens

am-server onPreInit passes the account server type to hideShowControls. That helper splits comma-delimited hidefor values and sets or removes hidden based on an exact token match. EWS exclusions live on stable named containers, so the browser test checks each container exists and is hidden after awaiting account selection. The patch does not disable protocol backends or prove every child setting is unsupported. Current Graph tokens are a later scope. No settings or accessibility test ran.

Scope: Account settings protocol-specific visibility and browser tests.
