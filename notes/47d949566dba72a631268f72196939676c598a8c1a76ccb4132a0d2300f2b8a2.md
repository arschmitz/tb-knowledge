# Move dialog event handlers with their shared provider wiring

The small commonDialog port removes inline lifecycle, command, checkbox and popup handlers from the comm XHTML while retaining command and popup IDs and the shared commonDialog.js script. An independently inspected local Gecko snapshot binds those IDs through document command/popup listeners and lifecycle listeners. For this shared dialog, preserve provider wiring when removing inline attributes. That Gecko revision is not a verified paired build for the accepted comm revision or the historical upstream port. No dialog interaction was run. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / base.
