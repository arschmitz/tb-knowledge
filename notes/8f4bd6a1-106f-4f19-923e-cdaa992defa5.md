# Invalidate generated names and re-sort when name format changes

The adapter listens for mail.addr_book.lastnamefirst. On change it updates the static format, clears each row’s cached GeneratedName, then re-sorts if that is the sort column or resets the tree otherwise. This keeps both visible names and their order consistent after a preference change. Current code retains the same choice, with a cache-clear step before reset.

Scope: Address Book preferences.
