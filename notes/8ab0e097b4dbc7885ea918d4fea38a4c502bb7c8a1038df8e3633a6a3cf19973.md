# Preserve the OAuth test family’s existing acronym spelling and scenario suffixes

This family uses OAuth2Module.sys.mjs and OAuth2Providers.sys.mjs for production modules, test_oAuth2Module.js and test_oAuth2Providers.js for unit files, and browser_cardDAV_oAuth.js and browser_calDAV_oAuth.js for browser files. Named tasks include testGetRefreshToken and testCalendarOAuth_username_none. For additions to these families, keep their established acronym spelling and append meaningful scenario words rather than mechanically changing all names to one case. These are scoped file and test naming examples, not a repository-wide dash-versus-camel rule. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: OAuth file and test naming.
