# The Graph generator gives body-taking requests response selection support

The generator uses the response Selection type and actual HTTP method when emitting Select, including body-taking requests. The generated message PATCH and copy POST expose selection forwarding. Empty Selection emits no query; select replaces properties and extend_selection adds them. This enables a request-building capability, not every endpoint's support or automatic use by mark-read callers. The owned lifetime-bearing generator and later accepted owned-type form remain separate.

Scope: Thunderbird Graph request generation and selection.
