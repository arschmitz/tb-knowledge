# Gecko ctypes declared functions retain native libraries until close or finalization

Full Library.cpp403/header36 read; CTypes.cpp only named ranges, not entire file.
Actual Thunderbird DNS _open calls ctypes.open/library.declare. Library.Create:
99–196 creates library JS object with null native slot, attaches API, converts
path for platform, calls PR_LoadLibraryWithFlags and stores PRLibrary pointer.
Load failure reports native error; incomplete object finalization sees null safely.
Library is foreground-finalized by its JSClass; exact GC timing is not promised.

Declare:272–401 validates Library/open state and signatures, creates function
type/pointer or data type, resolves actual native symbol, then calls
CData::Create(typeObj,libraryObj,data,isFunction). Function CData stores name and
is frozen. CData::Create:7576–7667 stores library in SLOT_REFERENT for GC lifetime,
sets ownership flag and copies pointer bytes for an owned function object or
refers to borrowed data. A declared native function therefore retains its library,
independent of whether user code still holds a separate library variable.

Close:246–271 unloads PRLibrary and clears native slot; Finalize:216–218 also
unloads when non-null. FunctionType::Call:6999–7042 checks actual function-pointer
type/argument count then looks at Library referent and rejects call when closed.
Closing does not turn an old function object into a safe standalone pointer.
CData finalization:7669–7690 frees owned byte buffer and holder, not an arbitrary
DNS API record list. Native NSPR unload and complete CType conversion/bounds
implementations remain external scopes.

DNS worker creates per-query wrapper with function fields/library. It does not
explicitly close successful query's library. These local references can become
collectible after synchronous execute returns; native Library finalizer supplies
eventual unloading when collected. This is why missing explicit close is not
automatically proof of permanent leak. It does not certify timely release or
Windows list cleanup on mapping failure.

Direct test_jsctypes.js:348–379 closes library and asserts existing function
invocation/new declare throw; rejects close/declare on wrong receiver; confirms
declared function works as another object's property. Only ranges18–62,112–241,
321–405 were read, not all4199 lines. JIT tests read in full assert argument/type
conversion errors with declared hypot; they execute library open/declare but do
not directly check GC lifetime. None ran in this pass. Manifest registers
