# Restore thread expansion only after search or synthetic view results finish loading

Bug 1895097 reports that saved search collapse-all state was lost and quick-filter results expanded unexpectedly after bug 1892074. The fix calls threadPane.restoreThreadState after all results load when the view has search terms or is synthetic. DBViewWrapper initially clears kExpandAll for multi-folder and synthetic grouped views for performance, then the thread pane can restore the saved expansion state after loading. It also initializes _threadExpandAll for synthetic views from mailnews.default_view_flags. D209493 was accepted, but reviewer noted the view code was complex. Current mailCommon.js keeps the load-complete restore branch. Tests for this area must cover single-folder search, multi-folder saved search, and synthetic views, with both collapse and expand state.

Scope: Thread pane and DBViewWrapper.
