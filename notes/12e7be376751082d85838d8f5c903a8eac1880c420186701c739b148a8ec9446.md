# Do not assume stream-listener completion forwards every destination error

Accepted EndCopy returns a failed destination EndCopy result, but it calls mDestination->EndMove without returning that method’s result. The local destination reports move completion through its own folder events and copy callback. A source-stream success code is not the entire move result. Keep the callback and return-value boundaries explicit when adding tests or error handling; this is a static boundary observation, not a demonstrated failed move. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/base/src.
