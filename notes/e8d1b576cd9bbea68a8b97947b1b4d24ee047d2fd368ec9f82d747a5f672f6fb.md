# Virtual folder moves report completion after local storage work

The same-server virtual-folder move copies local summary state rather than sending an ordinary IMAP MoveFolder request. The owned fix avoids recreating an existing destination directory and reports completion after its local work. The copy service uses that notification to retire matching requests and start later queued work. Earlier error returns can still bypass this point. Accepted code later moves the virtual-folder operation into a shared helper; no live move or atomic filesystem guarantee is claimed.

Scope: imap/virtual-folders.
