# Address-card API removal does not remove ordinary display-name generation

generateChatName was removed from nsIAbCard and both implementations. generateName remains, with display/first-last/last-first formats and fallback logic. The native and vCard-backed implementations have different fallback ordering, and their current tests preserve those differences. Do not revive the removed interface for chat integration or assume its removal means all chat/contact properties vanished. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/addrbook/public.
