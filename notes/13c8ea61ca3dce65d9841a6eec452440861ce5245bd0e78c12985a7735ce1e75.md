# Critical color tokens do not require renaming the danger icon class

The scoped change replaces the danger-pressed custom property with critical-pressed for fill and stroke while keeping .icon-danger and the warning icon. The fixed source preserves that role/token distinction. Use actual CSS identifiers rather than misspelled commit-subject tokens. This example does not establish a global class rename, color value or contrast result. No rendering test ran.

Scope: Shared mail icon styling and color-token rename.
