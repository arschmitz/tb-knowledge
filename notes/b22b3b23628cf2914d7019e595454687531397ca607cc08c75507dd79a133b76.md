# Calendar HTML export replaces synchronous XHR without making export asynchronous

CalHtmlExporter replaces cal.xml.parseFile's synchronous XMLHttpRequest with a privileged NetUtil channel opened synchronously, then parses the template as XML. exportToStream still populates the DOM and writes UTF-8 output before returning. Its IDL returns void and saveEventsToFile closes the output stream immediately after calling it. The added browser test selects HTML and checks the exported calendar title and Event Två through UTF-8 file reads. Treat this as removal of that XHR dependency, not an async-export contract or rendered-layout result.

Scope: Thunderbird Calendar HTML export.
