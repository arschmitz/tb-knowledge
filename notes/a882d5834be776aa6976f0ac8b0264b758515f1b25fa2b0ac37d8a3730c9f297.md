# The suppression prompt rejects an install before the ordinary permission and update paths

The permissions observer emits addon-install-suppressed, calls info.reject and returns before normal update auto-acceptance or permission prompting. Its separate failure route replaces incompatible/blocklisted errors only; policy handling stays separate. A nonpersistent warning popup has its own localized markup and support link, while the installed card returns an alternative-search warning. The tests distinguish the shared terminal-reason listener from the listener returning an installed add-on. They assert install outcomes and banner visibility, not direct appDisabled or live accessibility behavior. The fixed accepted card uses a later embedder hook and localization IDs.

Scope: Thunderbird Experiment install and add-on warning UI.
