# Graph initialization first stores shared connection details

At 184f0054d15ef9fadf1818fbd6ccd366424f53d9, Graph initialize parses the endpoint, obtains credentials and retains the server before filling OnceCell<ExchangeConnectionDetails>. Parse failure returns NS_ERROR_INVALID_ARG. The occupied-cell error is checked after that preparation. The details value holds the URL, server reference and credentials; nearby Graph operations still return NS_ERROR_NOT_IMPLEMENTED. URL parsing does not enforce HTTPS or prove a working connection. At accepted revision 0b93f0f7a926ed94c8a0646f18b6734ec7cc0f6d, initialize instead constructs and stores an Arc client. Keep that later implementation separate from this first initialization phase.

Scope: Graph and shared Exchange protocol initialization.
