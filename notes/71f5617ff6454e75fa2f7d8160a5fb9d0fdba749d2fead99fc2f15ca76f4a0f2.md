# The header Trash test waits for deletion separately from message display

The focus test registers a folder-specific DeleteOrMoveMsgCompleted waiter before clicking Trash, then awaits it before checking one row disappeared. The click helper separately waits for message display and checks focus. These are distinct completion signals. PromiseTestUtils matches folder identity and event name and removes its listener when matched; it does not wait for all background work. No browser test or intermittent failure reproduction ran.

Scope: Message header focus and folder deletion browser test.
