# The missing-Date IMAP timestamp assertions omit expected-behavior messages

The new test directly checks both dateReceived and dateInSeconds against the first Received timestamp. Both Assert.equal calls omit a message argument. Give each timestamp check a nonempty message that states its expected value and role; the existing fetch check already names its expectation. The test's distinct Received dates make header order meaningful, while the assertion-message omission remains in the accepted comparison. This is a scoped test-review finding, not a runtime failure.

Scope: IMAP missing-Date regression test.
