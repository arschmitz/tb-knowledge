# Bind the tag identifier as query data

The historical filter uses a unique named SQL parameter for the tag value. Current TaggedMessagesFilter uses a positional placeholder and UTF8TextVariant, and the IDL explicitly calls the argument the tag identifier nsIMsgTag.key. Preserve the stable key/value contract rather than using a display label or interpolating text into SQL. The older UID-suffixed parameter naming scheme is historical; it is not current manual guidance. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Panorama tag query binding.
