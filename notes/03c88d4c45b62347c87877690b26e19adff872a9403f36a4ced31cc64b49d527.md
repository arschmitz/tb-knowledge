# Removing the account manifest debug skip restores selection rather than proving passes

The patch removes skip-if=["debug"] from DEFAULT in both account browser manifests. Accepted source keeps both manifests registered and retains separate per-test enterprise/Windows exceptions. The change restores debug-build eligibility under these defaults; it does not prove that every account test ran or passed or that all other selectors disappeared.

Scope: account-browser-manifest-debug-selection.
