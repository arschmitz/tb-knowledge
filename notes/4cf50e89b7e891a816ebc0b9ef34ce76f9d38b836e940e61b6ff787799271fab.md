# Name native folder objects separately from extension API folders in tests

The cross-account move/copy test names privileged folder objects nativePopTestFolder and nativeImapCopyTestFolder, then obtains separate extension folder values through browser.folders.query. The latter have API IDs used by move/copy. Manual test naming proposal: retain native* or another clear role when both representations appear in one test, and name the operation-specific one-time listener before issuing the action. The accepted local pattern is more useful than one repository-wide case rule. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/test-representation-names.
