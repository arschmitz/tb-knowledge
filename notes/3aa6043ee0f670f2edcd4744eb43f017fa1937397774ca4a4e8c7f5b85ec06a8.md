# OAuth account tests control authorization scope as well as the popup

The current OAuth setup test starts local IMAP, SMTP and OAuth servers, arms promiseOAuthWindow before Continue, and submits only test_mail scope to skip CardDAV/CalDAV discovery. It then asserts OAuth2 on the created account and a success view with zero discovered services. These controlled fixture assertions do not prove production provider behavior or the broader discovery flow. This is source and test-code inspection.
