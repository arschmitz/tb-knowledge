# The original Graph media fake reads length after a nullable lookup

The original media helper returns null if an item or its synthetic message is absent. Its caller then writes content using content.length without checking for null. Those shown missing-media branches reach that property access before returning from the media route. The added test fetches only known positive messages and does not assert this boundary. Accepted mock response handling is a later refactor; no HTTP error status, harness recovery or reproduced server failure is claimed.

Scope: Graph mock media endpoint negative-path boundary.
