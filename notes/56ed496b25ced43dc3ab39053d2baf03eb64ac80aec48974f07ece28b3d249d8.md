# commlint collects outgoing paths from the comm repository before delegating

When the outgoing option is present, commlint opens topsrcdir/comm with mozversioncontrol, requests added/modified outgoing files and appends them to explicit paths. A string option supplies the upstream; other present values use None. It clears outgoing before handing the prepared arguments to mozlint. This static source does not establish a successful lint run or the upstream library's path behavior.

Scope: Thunderbird lint command outgoing selection.
