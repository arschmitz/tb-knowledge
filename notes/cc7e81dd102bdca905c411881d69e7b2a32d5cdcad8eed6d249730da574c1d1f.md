# Mailbox-name injection does not wait for a client folder update

IMAPServer.addMessages accepts a mailbox-name string or a folder object. Both paths add messages to the fake mailbox. Only a folder object with update enabled waits for updateFolderAndNotify; a string returns a resolved promise after injection. The Thundermail URL test seeds INBOX by string before account creation. Awaiting that call does not prove a client has downloaded the messages; later message-count and idle waits are separate checks. No browser test ran.

Scope: Fake IMAP mailbox injection completion.
