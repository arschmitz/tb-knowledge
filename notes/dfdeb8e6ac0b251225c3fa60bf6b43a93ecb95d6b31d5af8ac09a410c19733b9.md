# Contact search API names depend on manifest version

At revision 5bc47cc15bfa2aa6abfd4d6f4eff817b9503ac81, the address-book schema exposes contacts.quickSearch only to Manifest V2 and contacts.query only to Manifest V3. quickSearch accepts an optional parentId and either a string or QueryInfo; query accepts QueryInfo. Match examples and callers to this versioned interface because changing only the method name does not preserve the argument contract. This is verified schema evidence, with no runtime validation supplied.

Scope: WebExtension contact search.
