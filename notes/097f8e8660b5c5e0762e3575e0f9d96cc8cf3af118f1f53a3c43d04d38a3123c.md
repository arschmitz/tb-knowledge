# Keep process permission distinct from main-thread scheduling

The message content policy only calls the docshell JavaScript-setting helper for parent-process documents. Parent work still checks the thread and synchronously dispatches to the main thread with retained location/loadInfo references when needed. Main-thread execution does not make a content process the parent process. Preserve both boundaries when changing this helper. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
