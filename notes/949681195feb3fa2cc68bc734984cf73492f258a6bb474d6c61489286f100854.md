# IMAP AddSubfolder fixes the child path before a virtual folder opens its summary

AddSubfolder derives the child path from the parent's stored directory and assigns it before returning the child. VirtualFolderHelper then opens the new child's database. The regression task sets a suffixed parent path, creates the wrong URI-derived directory too, and checks creation plus three completed moves. These are static path/order and test-oracle facts; the test simulates the collision state, and no filesystem, server or restart test ran.

Scope: IMAP virtual-folder local storage.
