# The filter execution fieldset no longer reserves a 150px minimum

The patch removes the fieldset-specific 150px minimum from #applyFiltersSettings. Its legend and execution-context controls stay in place, while neighboring search/action panes retain their own size rules. Accepted code keeps this local removal. Source inspection identifies the constraint removed; it does not measure the resulting gap, clipping, density or accessible layout.

Scope: Filter editor fieldset layout.
