# The taskgraph port changes the documentation parser as well as the Markdown pages

This landing changes verify_docs to single-backtick inline literals and hash-style heading expressions, and the active full_task_set attribute check requests attributes.md. The three other documented checks stay commented out. The actual comm register installs the local verification sequence. Its documentation module adds the comm path to the imported Gecko registry, while local verify.py constructs its own registry; this source does not establish that both receivers share state. The near-empty comm attributes page alone cannot cover task attributes. Markdown role/toctree conversions are read as source, not proof of a successful documentation build or repaired decision task. Upstream initialization and runtime remain unpaired.

Scope: Thunderbird taskgraph documentation verification.
