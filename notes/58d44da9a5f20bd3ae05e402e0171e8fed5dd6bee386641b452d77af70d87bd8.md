# API annotation filenames and namespace values follow different naming roles

The accepted annotation files browser_settings.json, content_scripts.json and declarative_net_request.json use underscore filenames. Their namespace values retain the API names browserSettings, contentScripts and declarativeNetRequest. Keep the filename family and namespace identifier separate when adding matching annotations. Keys such as version_added are structured data contracts. This is evidence for this schema/annotation family, not a global filename, DOM or JavaScript naming rule. No generator ran.

Scope: WebExtension annotation naming.
