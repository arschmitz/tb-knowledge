# Do not cache hidden TreeView height as the visible height

Bug 1883550 cached TreeView and header heights from ResizeObserver to avoid synchronous reflow during visible-height calculations. Bug 1896009 then found that hiding the whole widget reported zero height; when shown again, calculations could use that stale zero before the observer updated. The fix skips the widget zero-height event, while retaining the last usable height. The reported symptom was that a POP3 or local folder with newest mail first could open scrolled below its first message. Bugzilla includes a repeatable switch-between-folder-and-account-root sequence and a regression window; the fix was approved for ESR 115. Current BaseTreeView retains the guard. The commit adds no regression test and none was run in this study.

Scope: TreeView virtualized layout.
