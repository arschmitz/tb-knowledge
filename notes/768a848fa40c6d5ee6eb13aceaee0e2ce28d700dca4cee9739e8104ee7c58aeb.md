# Unsigned-warning configuration replaces the add-ons signing override while experiment settings stay distinct

The landing removes a window.isCorrectlySigned function that unconditionally returned true and adds both extensions.experiments.enabled and extensions.ui.disableUnsignedWarnings defaults. The accepted defaults retain those values beside the separate experiments.suppressed control. Treat permission for experiments, warning presentation and actual signing validation as different contracts. The inspected comm code proves the configuration and override removal; the upstream consumer was not paired and no add-ons UI or signature check ran.

Scope: Thunderbird add-ons integration preferences.
