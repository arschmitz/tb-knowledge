# Keep the full category description when limiting visible calendar chips

The calendar category element renders only the first three category items, but its overflow label receives both the additional count and a formatted list of every category for the tooltip. Setting an empty list replaces the old items and hides overflow. Current code also emits a row-visibility event and assigns category color variables; those are later than the first landing. The dialog supplies event categories and clears them when it resets. Direct source assertions cover these values, but this study did not run Calendar, localization, keyboard or screen-reader checks.

Scope: Calendar read-dialog category display.
