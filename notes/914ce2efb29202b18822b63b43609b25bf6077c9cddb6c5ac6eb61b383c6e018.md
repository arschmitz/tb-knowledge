# Keep the first custom-element registration when a later call uses another module

The lazy helper skips a tag already present in registeredTags or customElements.get. Its browser test registers test-element, then calls the helper with another module and asserts that the initial factory remains; a separate test protects an already defined existing-element. Keep this first-registration contract when adding callers. Replacing a module URI is not an override API.

Scope: Lazy custom-element duplicate registration contract.
