# Inspect notification button metadata through its current wrapper

The expired-key composition test now reads buttons[0].buttonInfo["l10n-id"] rather than reading l10n-id directly from the wrapper. This is the test’s current notification metadata shape; it does not test a translated accessible name or the button click. Keep exact metadata access separate from visible control validation. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: OpenPGP notification tests.
