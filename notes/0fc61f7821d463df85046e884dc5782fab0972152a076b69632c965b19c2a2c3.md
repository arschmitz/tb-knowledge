# Copied certificate-viewer comments and async return contracts need an explicit review

The current viewCert JSDoc contains an unrelated aDirToCheck/subdirectory sentence. The async viewSignatureCert wrapper calls viewCert without returning or awaiting its promise, and viewEncryptionCert does the same from a synchronous function. Scoped documentation/test recommendation: remove the copied directory sentence and state whether these command handlers intentionally start work without exposing completion. The current call shape does not prove an unhandled rejection, user-visible failure or a need for every UI command to return a promise. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: S/MIME viewer documentation.
