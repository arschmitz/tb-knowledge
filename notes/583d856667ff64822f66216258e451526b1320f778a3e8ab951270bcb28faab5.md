# Graph flag synchronization has distinct required and optional data phases

Original synchronization reads required flag and flagStatus getters and compares the enum with Flagged; missing or malformed data returns an error. Fixed accepted source instead matches an optional Flagged value and otherwise yields false. Its actual native update receiver sets or clears the Marked flag from that Boolean. Keep these data/error phases separate; the generated schema or fake-server fixture does not prove live service conformance.

Scope: Graph incoming message flag mapping.
