# The default browser-action icon check no longer observes the icon

The default-theme assertion constructs both its actual and expected values with makeIconSet. DEFAULT_ICON and defaultIcon refer to the same default.png URL, and makeIconSet uses its first URL when no second URL is supplied. The comparison is equal independently of the button's computed content. Custom dark/light assertions and the separate shared helper still read computed style. Preserve that narrower direct coverage; no rendered theme failure was reproduced.

Scope: Extension action theme tests.
