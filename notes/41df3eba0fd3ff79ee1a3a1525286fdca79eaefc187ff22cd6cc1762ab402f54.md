# Certificate callers ask overridability with converted NSS error results

The chat error observer and MessageSend delivery-exit path classify numeric NSS errors, convert them with getXPCOMFromNSSError, then pass the converted result to isErrorOverridable instead of matching copied errorCodeString lists. Chat opens its exception flow; compose reports failure and only then emits its transport-security notification for an overridable NSS error. The classification call neither adds an exception nor guarantees a successful retry. This documents comm callers only; upstream service contents/equivalence and source pairing remain unproved.

Scope: Chat and compose security-error dispatch.
