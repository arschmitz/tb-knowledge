# Keep attachment fetching, saving and temporary-file handling distinct

The historical helper wrote fetched bytes with IOUtils and started an unawaited Downloads chain for non-temporary saves. Current saveToFile instead fetches an ArrayBuffer, creates a Blob URL, awaits download.start and adds non-temporary downloads to the list; finally revokes the Blob URL. The isTmp flag now controls list inclusion, not whether a download is created. Favor this current contract when editing callers; it does not prove an operating-system attachment security result. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mail attachments.
