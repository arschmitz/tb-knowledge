# InitMDBInfo does not check every token conversion

The cleanup renames the result and flattens the initialization guard. Fixed InitMDBInfo checks the first scope StringToToken result, but later column and table token conversions still ignore their return values. The initialization flag is set before that first call; retry behavior after failure was not traced. Review expresses uncertainty about the legacy ignored results, not a general recommendation to discard errors. Keep the exact checked call separate from the unverified remainder.

Scope: Mork error handling.
