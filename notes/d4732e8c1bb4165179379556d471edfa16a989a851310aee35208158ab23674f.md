# The Account Hub recipe copies values and attributes through one target path

The recipe copies existing values and individual .accesskey, .title and .placeholder patterns from Account Setup into Account Hub IDs. It uses target = reference for this one output path and preserves the source brand term. Exact attribute casing matters to the static references. This is a scoped migration example, not a global naming rule or proof that the migration ran for every locale.

Scope: Account Hub Fluent migration recipe.
