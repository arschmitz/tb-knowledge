# Command routing checks controller support and enablement in the actual window

getEnabledControllerForCommand first checks the dispatcher-selected controller, then scans the top window controllers if needed. Both support and enablement are required, and the two controller sets are not identical. goDoCommand forwards arguments through the chosen JavaScript receiver. Registration updates the top window; command-state updates toggle a matching node or emit an event. The compact-folder button is one checked consumer. The review rejected an overly broad focus-first explanation; these local functions do not establish every dispatcher or tab contract.

Scope: XUL command routing and toolbar consumers.
