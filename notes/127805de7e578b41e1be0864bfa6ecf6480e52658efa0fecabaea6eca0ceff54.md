# Contacts pane registers display settings after widget setup but before deferred contacts loading

The contacts sidebar load callback first runs AbPanelLoad, then registers density and font sizing. AbPanelLoad sets the results row class and columns synchronously, but schedules ChangeDirectoryByURI on a later event turn to keep initial display quick. Thus the reordered registration follows widget setup; it does not wait for address-book data to load. Unload cleanup remains in the existing path. This is a local readiness boundary, not a blanket window-startup rule. No runtime or accessibility execution.

Scope: compose-contacts-pane-startup.
