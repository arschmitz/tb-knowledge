# The deletion command dispatch is separate from the folder completion wait

The test changes its action to window.goDoCommand("cmd_delete") while keeping the folder completion promise registered before dispatch. The accepted goDoCommand calls an enabled controller and catches synchronous exceptions; it does not return a deletion result or promise. The message controller delegates cmd_delete to cmd_deleteMessage. The helper’s separate folder-event wait and following display checks remain necessary evidence of completion and displayed state. This source contract does not prove that the historical intermittent failure is cured.

Scope: Multiple-display deletion command dispatch.
