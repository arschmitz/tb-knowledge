# The POP partial-download test opens a MIME-generated URL and checks a complete message, not a live link click

The test converts the partial message to HTML, checks banner/link and UIDL fields, then opens the extracted href through a channel. It checks fake POP commands and compares a nonpartial message’s normalized raw contents. It does not click rendered UI, check a live accessible link or assert that every old partial header has been removed when the complete one is found. Those are distinct from this static test intent; no test ran.

Scope: POP partial download test coverage.
