# The compose attachment list caps its block size separately from the splitter height

The attachment list keeps block-size tied to --attachmentSplitter-height and adds max-block-size: 30vh. Its vertical pane-splitter targets attachmentBucket directly. The fixed accepted code retains that cap. This is a scoped compose-layout workaround, not a general viewport-size rule or proof of clipping, scrolling or accessibility on every platform. The patch changes no test assertions.

Scope: compose-attachment-layout.
