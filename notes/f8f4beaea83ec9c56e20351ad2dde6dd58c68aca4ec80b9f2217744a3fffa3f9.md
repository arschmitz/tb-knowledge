# The checkmark port changes a preference-gated parser exception, not the native control

The owned change adds a forms.css/checkmark error exception only when customizable select is disabled. The accepted regex later matches ::checkmark text. The actual error matcher tests sourceName and errorMessage; it does not consult the entry's isFromDevTools field. The caller limits errors to the test iframe. This supports a narrow parser-test allowance, with no paired upstream or native-control behavior proof.

Scope: Static CSS parser test allowances.
