# Signature tree expansion must update the flattened row count

The signature tree counts one parent row per user ID and only counts its child signatures while expanded. toggleOpenState flips the row state, recalculates rowCount and reports the signed count difference through rowCountChanged. Keep the flattened count and native tree notification together in this view. No expansion or screen-reader behavior was executed. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: OpenPGP signature tree.
