# The JsAccount test head passes an explicit scope and unsafe-URL option for local factory scripts

The shared JsAccount xpcshell head creates a fresh scope for each local factory script, passes target:scope and allowUnsafeURL:true to loadSubScriptWithOptions, then supplies scope.xpcomFactory to registerFactory. Its manifest selects that head and the resources directory for the component tests. This records the checked test-harness configuration; the upstream loader implementation and native test outcome were not verified.

Scope: Thunderbird JsAccount xpcshell component loader.
