# Clip the standalone macOS title container and keep logical spacing

The accepted macOS message-window style clips #titlebar-title and uses padding-inline-end to balance the window-button box. The XUL title label still has crop=end, flex sizing and its title value. The small repair changes visual containment rather than deleting the title text. Keep logical spacing and the correct containing element when modifying this rule; accessible-name exposure, zoom and overlap were not tested live. This is static source and test-code inspection.
