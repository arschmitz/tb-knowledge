# Keep the Calendar dialog border token and shadow alpha scoped to the component

For the Calendar dialog border patch, the reviewer replaces a literal border color with --color-neutral-border and an opaque black shadow with rgba(0,0,0,.15); the landed CSS applies both. The fixed source keeps the alpha shadow but uses --color-surface-border and a radius variable. Use the current local theme token when extending this component. The temporary424x300px dimensions are not a general sizing rule, and no visual or accessibility test ran.

Scope: Calendar dialog CSS.
