# Panorama address-format function still refreshes cached static preferences

Moving address preferences into StaticPrefList.yaml did not remove AddressFormatFunction member caching or its preference observers. Construction reads both static accessors; Observe refreshes the matching cached member. The existing comment that this will be unnecessary once static preferences exist is stale relative to this implementation. Current test_sqlFunctions uses one prepared ADDRESS_FORMAT statement and directly asserts changed outputs after preference changes, but it was not run in this study. Keep this helper contract separate from the legacy view and do not infer observer removal from the declaration alone.

Scope: Panorama SQLite address formatting.
