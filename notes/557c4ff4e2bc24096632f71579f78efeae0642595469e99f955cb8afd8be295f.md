# The attachment Fluent migration retains strings used by the historical native consumer

AttachmentInfo switches its picker and confirmation text to awaited Fluent values. The original native messenger still reads fileExists, SaveAttachment and saveAttachmentFailed, so this conversion retains those properties entries. Keep the consumer and source phase explicit when removing localization keys. The fixed accepted native class has since lost the old implementation; the historical call sites do not prove current native use. No migration, attachment action or native test was run.

Scope: Attachment localization.
