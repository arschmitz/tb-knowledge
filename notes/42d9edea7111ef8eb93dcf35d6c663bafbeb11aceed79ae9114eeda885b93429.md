# Separate release eligibility from a package publishing channel

571 maps the historical ESR 128 Flatpak release to stable. Current code uses an esr.* channel pattern but separately lists eligible releases, currently esr153, in run-on-releases. A stable channel mapping does not by itself schedule every ESR, and the old explicit version is not a permanent rule. Keep both the release gate and channel mapping when updating release versions. No release graph or publishing task was run.

Scope: Flatpak release configuration.
