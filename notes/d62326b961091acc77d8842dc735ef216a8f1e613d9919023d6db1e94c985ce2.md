# Create-folder response messages and folder objects have separate cardinality checks

In the current EWS CreateFolder operation, the outer SOAP response-message list uses the previously documented single_response_or_error helper. The inner returned folder-object list still rejects any length other than one before extracting the folder. Keep this operation-specific shape check distinct from the shared response helper policy. The 2024 landing used exact outer message-count validation; that historical policy is not the current create-folder helper. This is static source evidence for this operation, not a project-wide rule. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: EWS create-folder response.
