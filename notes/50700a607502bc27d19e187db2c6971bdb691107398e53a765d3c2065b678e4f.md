# ContactAvatar prioritizes list and photo data before initial text

Callers insert contact-avatar before setData; an early call logs and returns without queued data. setData chooses list icon before photo, then falls back through card names/emails and recipient to normalized initial text. It clears several fields and all host classes, but does not explicitly hide the prior image in the placeholder branch. Existing tests do not cover every photo/list/placeholder reuse transition or Unicode casing. The fixed component blob equals its first landing; no rendering or accessibility run established broader behavior.

Scope: Reusable address-book avatar state.
