# The jump-list port passes argument arrays while keeping one switch per built-in task

The Compose and Address Book task definitions change from strings to one-element argument arrays. Startup retains those task objects, and _buildList passes task.args directly into each description's arguments field before calling populateJumpList. The built-in entries still contain one switch each, so these declarations do not demonstrate multiple arguments, quoting or native launch behavior. The paired Gecko/native implementation and Windows execution remain outside this source inspection.

Scope: Windows jump-list task declarations.
