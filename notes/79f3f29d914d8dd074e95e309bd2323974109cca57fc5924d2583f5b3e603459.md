# The host URL reopen checks still read the original dialog input

The host URL test gets ewsUrlElementReopened from the reopened advanced dialog, but the next existence and equality checks still use ewsUrlElement from the original dialog. The reopened input is then used for reset actions. These two checks therefore do not directly assert the reopened input's presence or value. This receiver mismatch remains in the accepted source; no dialog or test failure was reproduced.

Scope: Exchange server-settings test reopened-input coverage.
