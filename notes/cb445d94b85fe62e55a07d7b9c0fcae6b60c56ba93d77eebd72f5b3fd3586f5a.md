# Blend-only inline styles need both selector reachability and removal before the color guard

The adapter adds the literal blend substring to its inline selector and removes a present non-normal mix-blend-mode before returning for styles without color or background properties. Both steps matter for a blend-only inline declaration. Embedded rule styles use the same sanitizer, while normal is left alone. The new fixture/task checks computed normal for an embedded rule and absence of the inline declaration; no visual contrast, external-image behavior or runtime result was established.

Scope: Dark-reader CSS declaration adapter and browser regression task.
