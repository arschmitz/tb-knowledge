# Keep QR diagnostics behind the module log-level preference

QRExport uses a named lazy console instance with Warn as its default maximum level and mail.qrexport.loglevel as its control. Branch-specific rejection reasons use debug. Preserve that local prefix and preference when adding related diagnostics; account keys, email and fullName appear in debug messages, so these are diagnostics rather than user-facing guidance. This is a scoped logging pattern. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: QR export diagnostic namespace.
