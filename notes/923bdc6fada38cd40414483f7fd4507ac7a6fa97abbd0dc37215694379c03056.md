# Use a lexical block for the window subscript loader’s private bindings

1036 replaces the immediately invoked function wrapper in customElements.js with a lexical block. Its own comment states that this script runs in chrome windows through the subscript loader and the block prevents globals leaking onto window. Keep loader-private const/let bindings inside that block. This does not justify removing functions that supply a return value or capture other state.

Scope: Legacy custom-element loader lexical scope.
