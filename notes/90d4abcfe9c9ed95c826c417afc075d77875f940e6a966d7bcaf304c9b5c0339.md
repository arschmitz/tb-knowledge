# Certificate lookup recovery stays separate from certificate verification feedback

smimeTestCert rejects unsupported preference IDs before the lookup try/catch. If lookup throws, the null certificate reaches the existing not-found alert and returns before verification. Found certificates use a separate verifier result and success/failure messages. The catch is broad and does not establish that every invalid certificate behaves this way or preserve its native error detail. Keep programmer-ID errors, lookup absence and verification failure as separate paths. Static source only.

Scope: S/MIME Test lookup failures.
