# The initial Graph preview distinguishes property absence, null and type errors

At the initial crate landing, serde-flattened Cow maps keep raw JSON properties. Nullable text getters return NotFound for an absent key, Ok(None) for explicit null, and UnexpectedResponse for a wrong type. Nonnullable id and string-array getters keep their own type checks, and inherited views borrow the same map. The raw-map deserialization test does not exercise these getter error cases. Accepted current code uses later typed optional fields, so this historical getter contract must not be applied unchanged to current callers.

Scope: Initial ms_graph_tb JSON property access.
