# Header click-focus tests also check that the button action still occurs

The header listener prevents the mousedown default on its selected controls, so clicking trash or star does not retain focus on that button. It does not remove keyboard access. The fixed test compares Services.focus.focusedElement before and after each click, then checks that trash removes one message and starring removes none. Preserve both focus and action expectations when changing this listener. This source/test evidence does not validate every header control or native accessibility behavior.

Scope: Message header pointer focus.
