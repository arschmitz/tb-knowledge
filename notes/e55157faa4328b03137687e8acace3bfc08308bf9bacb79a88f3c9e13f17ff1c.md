# Keep tree expansion direction tied to writing direction

TreeListboxMixin maps ArrowLeft/ArrowRight using :dir(rtl), so collapse/move-to-parent and expand/move-to-child reverse in right-to-left UI. Enter toggles a selected parent. The same composite widget retains one tab stop and aria-activedescendant for current row. These are current source contracts; keyboard-only and assistive technology behavior still need manual runs.

Scope: tree accessibility navigation.
