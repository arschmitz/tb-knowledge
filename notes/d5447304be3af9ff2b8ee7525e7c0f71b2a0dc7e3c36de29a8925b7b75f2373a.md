# Measure the thread viewport after a frame when testing middle-click scrolling

The collapsed-thread middle-click helper waits a frame after entering the folder and collapsing threads, then records the first visible row. It selects that visible row so later tree reflow does not scroll to an unrelated current index. It waits for MsgLoaded before comparing the viewport. This is a targeted fix for measurement timing, not a blanket sleep to hide failed asynchronous state. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/test/browser.
