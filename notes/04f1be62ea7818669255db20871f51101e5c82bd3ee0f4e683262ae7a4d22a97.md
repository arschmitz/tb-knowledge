# Use temporary RNP stores for collected-key inspection

CollectedKeysDB calls the low-level key-list implementation for noninteractive inspection and requires exactly one key after merging material for a fingerprint. The RNP merge helper uses a temporary FFI and finally destroys it. This keeps temporary inspection separate from the application key cache and permanent import. Other temporary-store helpers in the checked source still use normal-path cleanup, so this is not proof that all exception paths are safe. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/extensions/openpgp.
