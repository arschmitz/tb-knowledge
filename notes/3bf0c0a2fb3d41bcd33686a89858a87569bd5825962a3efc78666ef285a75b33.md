# The mail charset port passes true in all three detector paths

The landed port adds the true argument to EncodingDetector::Create in the file, composition-string and MIME wrappers. Their existing Feed and Guess paths are unchanged. Accepted MIME and later string helpers still pass true; the signature caller later uses the string helper instead of the old file helper. The port title alone does not show Thunderbird disabling detection. No charset test or paired Gecko implementation was validated.

Scope: mail charset detector API port.
