# Search Messages selects its folder at the outer window before opening a fresh dialog

searchAllMessages returns when no accounts exist. An explicit folder wins. Otherwise it uses a main window and the first mail3PaneTab folder; a standalone message window with no main window passes the optional default account root. openSearchDialog always opens a new dialog. This lets callers outside a mail tab avoid relying on a selected-tab command controller. The synthetic-view test directly asserts a folder label; it does not cover all standalone and no-account branches. Static source inspection only.

Scope: Search dialog entry points.
