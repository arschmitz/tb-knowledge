# Keep native-theme preference defaults and CSS selectors in their exact scopes

At the accepted endpoint, mail.theme.native-theme defaults to true only for XP_MACOSX with NIGHTLY_BUILD; other builds default to false. The macOS main-window rule also requires :root[customtitlebar]:not([lwtheme]); the compose rule requires :root:not([lwtheme]). Both place -moz-window-titlebar appearance on a positioned ::after decoration while the toolbox remains transparent. This keeps the separator constraint in the existing code comment. Historical 474 removes the obsolete unified-toolbar appearance; its old preference name and tabsintitlebar selector are not the current forms. Complete downstream bug/review context records acceptance, author uncertainty without Mac hardware, and a reviewer report that the preference still has an effect. Those are historical reports. Upstream 1906037/D215596, screenshot pixels, visual tint, CSS parsing and accessibility were not independently checked.

Scope: mail/themes/osx/mail.
