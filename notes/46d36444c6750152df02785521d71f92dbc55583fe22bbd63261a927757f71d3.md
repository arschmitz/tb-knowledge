# Pane containment was accepted without a measured performance delta

The patch adds contain: strict to three pane roots, the folder-row container and table/card row selectors. These five declarations remain in the fixed accepted source. D253414 asks for a performance delta; the author says none is available and describes avoiding progress-animation relayout as a possibility. Keep that hypothesis separate from measured performance and from a general recommendation to apply strict containment elsewhere. Bug comments3/6/7/8/11 are unavailable; no layout or profiling run was made.

Scope: Three-pane and row CSS containment evidence.
