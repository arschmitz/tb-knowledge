# The selected-state CSS port matches presence while retaining separate focus and state gates

This landing replaces selected="true" selector tests with attribute-presence tests in 13 Thunderbird and Calendar CSS files. Focus, theme, current-item and account-state gates remain distinct parts of the affected selectors. The original conversation setter emits true or removes selected; later accepted JavaScript uses toggleAttribute and hasAttribute, and that cleanup is a separate phase. An arbitrary present value matches the new CSS, but complete native widget state propagation and visual results were not verified. This is a scoped source fact, not a global attribute-style rule.

Scope: XUL selection CSS.
