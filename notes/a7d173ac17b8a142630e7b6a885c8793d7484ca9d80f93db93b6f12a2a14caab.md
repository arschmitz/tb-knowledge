# NNTP folder documentation still names the removed credential method

The port removes the public getAuthenticationCredentials method and moves the work to a private JS helper. The remaining IDL intro still says callers must invoke getAuthenticationCredentials and describes its Boolean result. The actual remaining interface exposes urlForSignon and credential fields, so that instruction is stale. This is a scoped API-documentation finding, not a request to rewrite unrelated comments.

Scope: NNTP interface documentation after the JS move.
