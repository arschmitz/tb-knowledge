# POP3 error reporting selects a fallback alert window without awaiting session cleanup

For a non-password POP3 error, _actionError first requests failed session completion. It then prefers its stored msgWindow, tries the running URI's getter only when needed and catches getter failure. If no window remains, it returns without an alert; otherwise it uses the selected local domWindow. _actionDone is asynchronous and is not awaited here, so prompt selection is separate from UIDL/QUIT cleanup completion. No prompt or error-path runtime check ran.

Scope: POP3 error prompt ownership.
