# Shared RNP clang-cl definitions preserve inherited include paths and target library names

The shared RNP definitions hold the clang-cl EHs flag, niwcompat include and builtins library name. Target x86 is spelled i386 for that library; other target strings pass through. The library and both CLI files include these definitions, and their local include lists append rather than replace inherited paths. The patch also removes AArch64 EHa overrides, so it is a configuration change as well as deduplication. The accepted source keeps the shared settings. No Windows compiler, runtime exception or cryptographic operation was validated.

Scope: rnp-build.
