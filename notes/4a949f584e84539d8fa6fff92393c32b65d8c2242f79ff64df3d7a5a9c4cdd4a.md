# MailUtils warning migration changes both the equality boundary and low-preference guard

The removed helper prompted only when the preference exceeded 1 and count was at least that preference. The new tab/window callers prompt only when count exceeds the preference, without the old > 1 guard. At equality the prompt is removed, while 0/1 no longer disable it through that guard. Cancellation still returns before opening. Keep this behavior change separate from Fluent formatting; no preference setting or prompt was exercised.

Scope: Opening multiple message tabs and windows.
