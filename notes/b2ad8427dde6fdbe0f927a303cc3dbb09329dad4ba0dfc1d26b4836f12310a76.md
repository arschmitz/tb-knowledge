# Keep Search Messages ordinal persistence tied to its XUL tree contract

The moved tree markup retains persist="hidden ordinal" and a comment that ordinal is no longer a supported XUL layout attribute. The comment says toolkit tree code maps it to persisted CSS ordering. Current accepted SearchDialog keeps this special tree behavior. Do not generalize the presence of ordinal into a rule for ordinary HTML markup or delete the persistence field as cosmetic cleanup without checking the tree widget and stored column order. This is an observed compatibility explanation; the toolkit mapping and persisted reorder behavior were not independently executed. Static source and test inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending-single-browser-reader.

Scope: Search Messages XUL column ordering exception.
