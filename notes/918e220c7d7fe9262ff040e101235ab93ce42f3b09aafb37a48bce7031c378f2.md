# The SMTP replacement branch calls the close handler before closing the socket

When the old socket is open but reuse is false, connect evaluates _onClose(false) before close(true) and assigns that call's result to socket.onclose. _onClose is the arrow handler body, not a factory; if it returns normally, that result is undefined. False suppresses _free only, so other handler work remains possible. The ordinary open path instead assigns _onClose by reference. The caller/free chain shows why another pool release could wake a queued send, but no hang, reentrancy failure, host-setter effect or runtime cure was reproduced.

Scope: SMTP socket replacement callback boundary.
