# The initial policy-helper port leaves tests importing removed local exports

The port removes the local exported setAndLockPref, PoliciesUtils and runOnce helpers without re-exporting them. At that exact revision, registered tests still destructure those names from the local Policies module and call them. This is a checked static export/caller mismatch. Accepted source later imports runOnce from the shared helper and has no browser API test file. Those later changes are separate; no test was run and no claim about the paired Gecko helper implementation follows.

Scope: Enterprise policy helper exports and test callers.
