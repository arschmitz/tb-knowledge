# Graph extraction progress and fallback diagnostics use different log levels

The landing adds env_logger/log configuration and initializes logging with a warn default filter. Progress/file-written diagnostics move from println to info; unsupported-schema/type and fallback diagnostics move to warn. Usage output remains println. Parsing/generation return values and explicit unsupported-item skips are separate from the log messages. These are scoped code/configuration changes, not a general logging rule or proof of the logger's output destination or an executed generator run.

Scope: Microsoft Graph extractor diagnostics.
