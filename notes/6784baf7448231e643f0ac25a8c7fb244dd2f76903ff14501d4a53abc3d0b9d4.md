# Tree documentation separates display from user row selection

The new documentation calls BaseTreeView a TreeView without the row selection model and pairs CheckboxTreeTableRow with it for checkbox choices. It also removes selection extraction from Future Plans. At this documentation landing, the base view setter still creates an internal TreeSelection object; accepted later code moves that allocation to TreeView. Read the documentation as an input-behavior description and keep the historical internal state distinct. This entry changes no implementation or runtime evidence.

Scope: Tree class documentation and source-phase limits.
