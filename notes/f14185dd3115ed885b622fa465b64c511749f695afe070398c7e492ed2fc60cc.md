# Keep key import and public-key acceptance as separate results

The accepted RNP public-key path changes acceptance only for keys without secret material and actionable acceptance values. It preserves an existing rejected or verified decision, and can update undecided or repeated unverified acceptance for email addresses. Importing key bytes is therefore not the same operation as trusting the key. This describes the checked path, not a complete trust or cryptographic audit. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
