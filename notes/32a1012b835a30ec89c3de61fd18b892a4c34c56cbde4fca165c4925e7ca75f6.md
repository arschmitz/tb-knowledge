# Brand text colors are defined independently from pressed primary colors

The original text-brand addition defines its own light and dark literals and a light-dark expression. It does not alias the pressed primary token, even though the initial values match. At the fixed accepted revision the brand values differ from the pressed values. A checked Account Hub icon consumes text-brand with reduced fill alpha. This is a scoped source phase and consumer fact, not a universal token rule or a contrast measurement.

Scope: Thunderbird semantic brand text color token.
