# Run IMAP login on its protocol thread

RunLogonExclusive must invoke TryToLogon on the current IMAP protocol thread. The sink proxy would dispatch to the main thread and is deliberately not implemented for this method. Call the real receiver for this lock operation.

Scope: IMAP login.
