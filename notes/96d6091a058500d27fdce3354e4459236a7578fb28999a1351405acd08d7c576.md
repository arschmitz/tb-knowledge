# Commands Build/Run checkout, cache provenance, and freshness status

The duplicate daily scheduler bypassed `dependency-update.mjs`'s Rust checksum gate and failed with `Rust dependencies are out of sync`: `jxl = "^0.8.0"` was locked at `0.8.0` but vendored source had `0.7.4`. The scheduler was removed; shared logging lives in `commands/graph/logged-build.mjs`, and automatic work now uses guarded compatibility checks, detached paired worktrees, pinned revisions, retry state, and completed-snapshot validation.
