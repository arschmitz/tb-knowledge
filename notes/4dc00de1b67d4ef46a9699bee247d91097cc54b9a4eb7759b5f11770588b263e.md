# The S/MIME text-check predicate tests a false property instead of a missing key

Both check_smime_message runners use (!"check_text") in msg. Negating that nonempty string produces false, so the expression checks the property named "false". A good signed fixture without check_text or that property therefore skips plaintext inclusion, while HTML-wrapper and signature/encryption status checks remain. This exact original and accepted-source condition limits what those passing tests could establish; no test was executed or repaired here.

Scope: smime-test-coverage.
