# The first reusable banner keeps content in slots and limits update to variant and disclosure state

This component requires a consumer-supplied template and slot content. Its update method changes only variant/expanded, normalizes variants and skips absent option values; it does not replace title or description. Shadow-owned listeners remain attached across reconnects, while localization roots connect/disconnect. Without description it hides disclosure text, removes summary from tab order and prevents clicks, but native semantics and keyboard/announcement behavior are not proven by the mouse/property tests. Later explicit template namespace markup and advanced content updates are separate phases. No runtime or global lifecycle/import rule follows.

Scope: Thunderbird tb-banner static component.
