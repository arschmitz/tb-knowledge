# Virtual-folder helper inputs adapt to one typed search definition

nsIVirtualFolderWrapper exposes searchString and searchTerms as text and object forms of the same definition. The JavaScript implementation parses text through a temporary filter and serializes object terms back into searchString. VirtualFolderHelper adapts string terms and URI scope strings before assigning the typed interface; the saved-search dialog also resolves selected URIs to folder objects. Keep this helper boundary when changing callers. onlineSearch stores the requested configuration and does not prove remote search capability in every backend. This is a static interface/caller check, not a successful save or search run.

Scope: Virtual-folder wrapper interface and saved-search dialog.
