# Shared status cleanup keeps the test window as the timer owner

When clearStatusBar moves from test head closures to a shared module, callers pass window explicitly. The helper reads that window's MsgStatusFeedback and clears start, stop and status timers with window.clearTimeout or window.clearInterval. The patch also adds awaited compose and extension cleanup; extension tab closure remains before the wait and focus restoration after it. Later feedback-tick and service changes belong to the accepted implementation, rather than the original extraction. No cleanup run was executed.

Scope: Browser test cleanup.
