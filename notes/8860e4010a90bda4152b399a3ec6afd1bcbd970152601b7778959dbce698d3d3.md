# The tree-header toolbar role describes its existing roving focus model

The owned change adds role=toolbar to the row that contains column header buttons and the column picker. The existing keyboard model maintains one active tab stop and moves it among visible buttons with arrow keys. The fixed accepted constructor retains this role; the patch adds semantics rather than rewriting the focus algorithm. A source-level role and a tracking-Bug report do not establish a fresh accessibility API or platform test result.

Scope: Tree-view header semantics.
