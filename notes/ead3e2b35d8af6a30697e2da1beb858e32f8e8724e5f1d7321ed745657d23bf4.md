# Keep Rust field names separate from XML names and namespaces

EWS Message uses a PascalCase type and snake case Rust fields. Current deserialization has serde(rename_all = "PascalCase"), while XML serialization keeps explicit t namespace annotations. Proposed scoped manual naming rule: preserve idiomatic Rust field names and configure the wire representation explicitly; do not rename a Rust field to match XML casing or drop its namespace while refactoring. This rule applies to the EWS schema family and does not derive style from generated Cargo metadata.

Scope: EWS Rust and wire naming.
