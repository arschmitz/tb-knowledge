# The original Thundermail click detaches the normal forward error boundary

The original delegated click sends placeholder identity data to #handleForwardAction without await. The normal forward branch awaits the same action inside its UI error handler, and the action can rethrow failures. The click route therefore does not reuse that awaited catch boundary. Keep the later dedicated OAuth route separate from this original UI patch; no live login, failure reproduction or end-to-end error result was verified.

Scope: Account Hub Thundermail async event route.
