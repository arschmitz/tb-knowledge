# Compaction deliberately prepares fallible leaf names before its critical commit callback

The review proposes replacing cached names with a leafName helper, but the author rejects that change because nsIFile leaf-name access can fail. The landed preparation phase gets the leaf name, checks the result and derives staged filenames before OnCompactionComplete starts replacing files. Keep that reason with these cached values; it does not establish a general rule for cached members. The separate DB-service review request is covered by checked service acquisition. Static source and historical review only; no compaction or failure test ran.

Scope: Folder compaction.
