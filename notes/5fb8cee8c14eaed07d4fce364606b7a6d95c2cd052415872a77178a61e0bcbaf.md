# Commands dashboard reliability: Phabricator loading and automatic build status

`withConsoleBuildJobs()` must keep the current updater phase separate from a persisted `state.lastBuild` receipt. Store terminal `passed`, `failed`, `cancelled`, and `interrupted` before source checks and final save; compare completion timestamps so a newer manual checkout result outranks an older automatic result. Render `queued`/`building` as active states, while `fetching`/`waiting` retain cached metadata and say the selected checkout is being checked. [Task 3]

Scope: console.
