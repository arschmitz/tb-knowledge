# Use provider capability to show the OAuth authentication option

828 replaces the IMAP/POP-only visibility test with a provider lookup, allowing EWS when its hostname is supported. The fixed accepted helper supplies hostname, server type and username. Keep protocol additions in the provider capability path. The 2024 comment said hostname changes needed restart; that does not establish the current UI lifecycle. No provider login was tested.

Scope: Account settings OAuth capabilities.
