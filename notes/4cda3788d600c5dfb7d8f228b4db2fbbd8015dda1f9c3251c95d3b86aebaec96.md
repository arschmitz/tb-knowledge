# Attachment listing classifies header metadata in order and omits unrelated URL fields

The helper checks deleted/detached markers first, then an external linked URL, then a cloudFile header, otherwise normal. Only the selected linked/cloudFile branch supplies its URL field. Those fields are optional strings in the schema and omitted in other objects, not null values. The URL check excludes file: and catches parse failures; it is not an HTTP-only or safe-content allowlist. Listing metadata does not itself verify or download the remote file.

Scope: Extension attachment type metadata.
