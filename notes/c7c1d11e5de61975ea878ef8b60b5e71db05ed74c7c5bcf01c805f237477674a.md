# Keep Account Hub notification state and description references together

Current showNotification clears old data, shows the bar and sets its open state. It exposes the toggle and aria-describedby only when there is description content; the alternative sets aria-disabled. clearNotifications removes that state, hides the cue and clears localized/raw content. This is the actual current lifecycle checked for the title-style change. aria-disabled plus pointer-events is not proof of keyboard suppression or correct announcements. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub notification lifecycle.
