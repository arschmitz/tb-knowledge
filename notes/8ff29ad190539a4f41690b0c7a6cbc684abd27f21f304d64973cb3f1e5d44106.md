# Read a presence-based checked attribute with hasAttribute

Current encryption producer uses toggleAttribute(checked,gSendEncrypted), and current Compose API uses encButton.hasAttribute(checked). A present attribute can have an empty string value, so !!getAttribute would apply a different test. Proposed scoped syntax guidance: match presence-based boolean setters with presence tests. Preserve value tests for attributes whose strings carry real data. This newer source supersedes the historical double-negated getAttribute pattern.

Scope: mail/components/extensions/parent.
