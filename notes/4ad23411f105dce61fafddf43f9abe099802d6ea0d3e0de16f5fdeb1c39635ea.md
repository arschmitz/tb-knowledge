# Importer failure disables Start Import until the summary is rebuilt

When an in-progress import fails, showError removes progress state, enables Back and disables the .before-progress Start Import button. Profile, address-book and calendar summary builders enable that button again. Keep the failure state and summary reconstruction paired when changing retry navigation. This describes the controller code, not a tested retry or accessibility result.

Scope: Profile, address-book and calendar import recovery buttons.
