# Reset the local address-book form when revisiting its step

The local address-book step starts with Forward disabled. On input, the widget publishes native form validity. When the user selects this step again, the view calls setState and the widget resets its form. This keeps a retained valid name from appearing beside a newly disabled Continue button. The added integration assertions cover the initial empty form and the state after typing a name; they do not directly test the back-and-revisit case. The input was already required before this change.

Scope: Account Hub local address-book validation.
