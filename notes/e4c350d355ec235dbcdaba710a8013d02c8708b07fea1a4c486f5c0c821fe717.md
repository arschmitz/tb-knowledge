# Related MIME guards keep URI references and replay-buffer ownership separate

MakeAbsoluteURL guards the two temporary nsIURI references; the returned character string remains separate and inspected tag-rewrite callers free it. In EOF disk replay, another guard captures the allocated read buffer by value and frees it when that block exits, including after file-open failure. The outer output-restoration guard has a different lifetime, and retained streams/files are still cleaned by the object finalizer. These are distinct cleanup scopes in public code, not a claim that every allocation or native failure path was exercised.

Scope: related MIME temporary ownership.
