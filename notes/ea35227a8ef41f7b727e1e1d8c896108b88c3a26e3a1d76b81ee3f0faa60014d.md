# Outlook logging adopts MOZ_LOG_FMT while retaining local format exceptions

The affected Windows files remove their PRINTF wrappers. Many value-bearing messages use MOZ_LOG_FMT, while plain messages and UnicodeToWord retain MOZ_LOG. Dump now spells its byte format {:02x}, and MAPI HRESULT messages use {:08x}; output equivalence was not executed. The reviewer suggestion is locally adopted despite a Not Done badge, and the author endorses the newer facility. This does not establish a global formatting rule, a native MAPI result or correctness of the unpaired upstream formatter.

Scope: Windows address-book debug logging.
