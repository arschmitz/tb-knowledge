# Preserve binary fixture encoding when studying a removal

The five removed .oeaccount resources were UTF-16 XML. Their actual parent-revision bytes were decoded and saved as historical source, rather than treating the binary diff marker as full content. For a removal study, inspect the fixture representation and its test consumer before deriving behavior. This is a source-study recommendation; no deleted importer was executed and no encoding rule for current Thunderbird fixtures is proposed. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
