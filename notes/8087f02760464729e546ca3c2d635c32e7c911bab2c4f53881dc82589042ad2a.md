# Panorama exposes property text to JavaScript and returns empty text for absent values

The scriptable getter returns UTF-8 text from message_properties for an ID/name pair. Direct tests expect the strings0 and 303, plus empty text for a missing property and for an unknown message. The native function clears the output before stepping. keywords is stored through a separate tags path; this getter has a debug assertion against that name. Empty output is not a unique missing-row diagnostic because the checked function also returns NS_OK when ExecuteStep fails. Current name normalization can propagate an error before the step. No database or xpcshell test was run.

Scope: Panorama database JS property getter contract.
