# Use null for absent Gloda headers during compaction

The Gloda post-compaction path tests idBasedHeader == null to delete stale indexed IDs. Returning false for a missing header bypassed that case and logged a misleading warning. Bugzilla discussion indicates this likely predated the compaction rewrite, even though it was noticed during its testing.

Scope: Gloda indexing.
