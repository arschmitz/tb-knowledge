# Remove an obsolete send parameter together with its callers and test doubles

The follow-up removes the ignored status-feedback slot from sendMessageFile and shortens the interface, implementation, Calendar caller and capture-only test double together. The tail remains a message-to-replace header, a send listener and a password. Removing one null at a call site is a contract migration, not proof that the remaining null has the same role. Calendar's intercepted-request assertions check selected request fields and file existence; they do not prove transport delivery or the engine's old feedback interface handling.

Scope: Prepared-message send interface.
