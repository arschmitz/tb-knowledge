# Keep architecture and mode names consistent across build files

This Windows build family uses the lowercase dashed directory win64-aarch64, shared filenames common-win64/common-opt/l10n-mozconfig, and mode filenames debug/nightly/release without extensions. Task names add /debug or /opt; the task mozconfig platform stays win64-aarch64. Proposed scoped file naming rule: keep these exact architecture/mode references aligned across config paths, task keys, stage platform and fetched architecture artifacts. This family does not establish casing rules for unrelated source files.

Scope: Windows build file and task naming.
