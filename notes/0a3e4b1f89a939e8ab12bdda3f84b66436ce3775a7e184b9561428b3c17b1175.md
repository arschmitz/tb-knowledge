# Keep calendar control IDs, classes and localized labels linked

The calendar wizard creates a checkbox ID and assigns it to the label control attribute. New bulk buttons use dashed IDs selectcalendars-all and selectcalendars-none; row classes use calendar-selected and calendar-name; JavaScript uses setCalendarsSelected(checked). Proposed scoped naming and accessibility rule: preserve these separate namespaces and the explicit checkbox-label association. Native controls and localized labels provide static semantics, but keyboard access, focus order, announcements and disabled behavior were not validated live.

Scope: Calendar wizard naming and control semantics.
