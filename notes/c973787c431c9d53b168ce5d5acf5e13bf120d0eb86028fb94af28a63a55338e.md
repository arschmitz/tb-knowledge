# Keep FileLink ignored decisions separate from uploaded byte counts

FileLink ignored increments once when a send attempt has any attachment above the threshold that is not sent through FileLink. Current Now/Later/Background branches run after sendMsg returns, while saves are excluded; SendLater therefore exercises the decision without SMTP delivery. Uploaded size adds file.fileSize under provider type after uploadFile resolves, including a move that uploads, but not a pure rename. Neither metric is a general sent-message completion counter.

Scope: filelink-telemetry.
