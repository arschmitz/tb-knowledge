# A calendar import failure can follow already-added items

CalendarFileImporter adds items one at a time with await, rethrows the first add error, and increments progress only after each successful addition. There is no rollback in the inspected loop. Consequently a failed event in the controller can describe an import that already added earlier items. Preserve that partial-result possibility in tests and user-facing error handling; no actual partial import failure or atomicity guarantee was tested. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mailnews / import.
