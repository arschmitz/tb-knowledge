# Account Hub add-on parsing tolerates encoded arrays without hiding all failures

ensureJsonArray accepts an array directly or parses a string and requires an array result. Add-on processing validates entries, requires an HTTPS XPI, and catches malformed data at the per-entry/per-supported-type level so other options can still be considered. Scoped parser recommendation: keep those compatibility and isolation boundaries distinct from successful add-on discovery. The newer accepted locale negotiation is covered by existing knowledge, not the older substring-based locale choice. This is static source and test-code inspection at the frozen accepted revision.
