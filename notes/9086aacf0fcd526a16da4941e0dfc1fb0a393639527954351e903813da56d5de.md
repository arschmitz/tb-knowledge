# The message-window lookup becomes a failure-only stub while shutdown chooses its own DOM parent

The owned change removes message-window matching from GetTopmostMsgWindow. It always clears the output and returns NS_ERROR_FAILURE; the accepted source retains that stub. The inspected shutdown path ignores the lookup result, passes the null message window to progress and separately requires the most recent DOM window for the dialog. This is a static caller distinction, not proof that shutdown succeeds or fails.

Scope: Mail session window lookup.
