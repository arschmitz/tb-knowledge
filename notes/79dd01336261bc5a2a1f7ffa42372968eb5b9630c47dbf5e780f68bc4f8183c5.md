# Keep thread grouping decisions declarative and name the predicate result

1017 replaces a mutable oneThread loop with isSingleThread = messages.every(...) after obtaining the first root header message key. The accepted pane keeps the same positive predicate and chooses thread versus multipleselection from it. Use a named boolean that states what the collection satisfies for this grouping decision. This is a local clarity proposal, not a performance rule or a ban on loops.

Scope: Message summary grouping predicate syntax.
