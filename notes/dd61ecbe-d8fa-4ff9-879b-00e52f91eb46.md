# Keep Panorama date grouping in microseconds

Panorama message dates use microseconds. The future cutoff in DATE_GROUP must add 1800 * PR_USEC_PER_SEC, not a seconds-scale value. Test years, today, yesterday, and week groups through the SQL function to catch unit mistakes.
