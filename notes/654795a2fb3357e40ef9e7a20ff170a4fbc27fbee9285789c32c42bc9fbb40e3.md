# Compaction completion cleanup starts after the begin notification

The semaphore guard starts after acquisition, but the completion guard is created only after NotifyAboutToCompact. Early failures before that point therefore release the semaphore without sending a completion for an unannounced phase. Successful asynchronous handoff releases both guards and transfers completion to OnFinalSummary. This is the narrow follow-up to the reported unmatched-notification cleanup path. No compaction or leak test ran.

Scope: Compaction phase cleanup boundary.
