# Developer Tools menu visibility checks policy and both required preferences

This landing keeps the Developer Toolbox main-menu item hidden unless devtools.chrome.enabled and devtools.debugger.remote-enabled are both true, with a separate policy-denied parent-menu branch. The app-menu tools view checks the policy and both prefs when the view is shown, and applies the result to its item and separator. The added availability test covers each pref being false and both true, while the policy test covers the denied case. The source registers preference callbacks for the main menu; it does not prove live updates inside an already open app view or backend/keyboard access enforcement. Native preference observer, policy and UI behavior was not executed.

Scope: devtools-menu-visibility.
