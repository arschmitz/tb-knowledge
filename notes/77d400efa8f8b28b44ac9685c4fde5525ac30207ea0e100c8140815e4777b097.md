# Profile address-book import test proves preferences and file creation, not imported records

The address-book profile test imports SQLite and Mork fixtures, then checks six stored description/type/filename values and two target files. It expects a unique abook-1.sqlite name and Mork conversion to dirType101 with mork.sqlite. Backend source reserves unique leaf names and delegates Mork record import. These assertions do not inspect copied contacts, lists, renewed UIDs or database contents. Keep that direct coverage limit when extending migration tests; source delegation and historical build reports are separate evidence. No test or database import ran.

Scope: Thunderbird profile importer address-book test boundary.
