# News message retry observes the global online topic with a scoped URI guard

The message observer reloads only for ipc:network:set-offline with data false, a news-message URI and a current online state. The observer is registered during initialization and removed on unload. The comment ties this to about:neterror Try Again, but the code does not check a button source, so any matching global online notification can reach ReloadMessage. That helper dispatches displayMessage without an awaited completion result. No NNTP or UI test ran.

Scope: Message display online notification lifetime.
