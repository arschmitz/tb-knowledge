# Keep the Linux symbolic titlebar icon port separate from later theme refinements

The Linux port replaces packaged Windows control SVGs with stock symbolic image-set URLs selected for dark mode and 2x scale. Fixed accepted CSS later uses -moz-symbolic-icon and theme/size variables. The historical24px size, color percentages and image-set spelling are not universal current style rules. Bug comment3 is unavailable and review remains unread; no GTK, HiDPI or visual test ran.

Scope: Linux titlebar resource port.
