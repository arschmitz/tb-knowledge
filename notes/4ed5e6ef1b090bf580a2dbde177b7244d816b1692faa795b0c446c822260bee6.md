# Account-manager startup preference calls use explicit StaticPrefs qualification

The assigned final account-manager code and fixed accepted source call mozilla::StaticPrefs::mail_panorama_enabled_AtStartup explicitly. File scope imports only mozilla::Preferences in this section. This is the narrow source adoption of D255627’s nonblocking namespace-clarity feedback; it keeps the startup preference owner visible at the call. Other files in the same patch retain namespace imports, so this evidence does not establish a global ban, a mandatory formatter rule, or consistent adoption across all C++. No build or lint was run.

Scope: mailnews C++ account-manager startup.
