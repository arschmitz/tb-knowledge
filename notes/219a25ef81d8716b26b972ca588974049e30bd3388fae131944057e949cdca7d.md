# Copy parent folder view metadata after the folder-added notification

At the accepted endpoint newFolderOkCallback is in FolderCommands.mjs. It installs a folderAdded listener before createSubfolder, waits for the added folder and, for a non-server parent, copies viewFlags, sortType, sortOrder and columnStates before updating timestamps. The current browser test sets non-default parent metadata and waits for the new tree row before checking all four values. Root/server creation deliberately does not inherit that parent DB metadata. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.
