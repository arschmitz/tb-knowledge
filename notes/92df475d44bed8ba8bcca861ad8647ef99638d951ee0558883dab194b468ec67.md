# IMAP header download hands the whole queued UID list to the protocol

The historical patch removes preference-sized folder header chunks and its timing-sensitive chunk test. In accepted source GetMsgHdrsToDownload moves all queued UIDs and resets the queue. The protocol uses the returned list length for progress, clears the more-header flag, fetches that list and completes the header stage. This says nothing about other protocol limits or an ideal cross-folder scheduling policy. Static source only; no timing or server experiment.

Scope: imap-header-download-queue.
