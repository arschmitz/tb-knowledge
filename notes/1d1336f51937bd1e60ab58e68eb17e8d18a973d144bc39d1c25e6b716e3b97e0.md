# The shared Calendar view-switch assertion has no diagnostic message

The view tests call setCalendarView before their new checks. Its accepted helper asserts the selected view ID without a message, then awaits loading. The missing message is a scoped helper diagnostic gap under the existing assertion guidance; a failure should name the expected selected view. It is separate from the landing's new assertions, whose messages state expected behavior. No helper or test was changed or run.

Scope: Calendar browser-test helper assertions.
