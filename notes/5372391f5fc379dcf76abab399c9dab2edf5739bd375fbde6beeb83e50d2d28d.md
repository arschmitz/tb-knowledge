# Positioned dialog resize state lasts until close

The resize change retains the opening trigger, registers one stable arrow callback and debounces updates by 100 ms. close clears the trigger and timer and removes that same listener before closing the native dialog. Its new browser task checks geometry and height around a window reduction, but the helper may finish through a 400 ms fallback; it is not a dedicated dialog-update completion signal. Fixed accepted tests later add a condition wait. Keep source lifecycle, direct assertions and test wait completion separate; no layout or cleanup failure was reproduced.

Scope: Calendar positioned dialog lifecycle.
