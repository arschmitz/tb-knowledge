# The unknown-provenance case has no current source-description assertion

The accepted source-description helper returns undefined for an unmapped source and the notification builder passes its result to localization. The current unknown test uses descriptionId:null and skips the source-span assertion, while still checking the generic title and read-more node. The original neutral title fallback therefore must not be described as the current description behavior. Localization handling of the undefined ID and rendered output remain unverified.

Scope: Account Hub config-message test limits.
