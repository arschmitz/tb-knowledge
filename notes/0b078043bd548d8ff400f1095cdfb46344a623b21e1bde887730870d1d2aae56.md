# Load the stylesheet family used by the dialog controls

Entry 508 changes the LDAP dialog from themeableDialog.css to preferences/preferences.css. Current LDAP still uses the preferences stylesheet and selected tabs use current panel/selected color tokens. A shared control can need the matching sheet family to render correctly under dark themes. Actual theme and OS rendering were not tested.

Scope: mailnews/addrbook/prefs/content.
