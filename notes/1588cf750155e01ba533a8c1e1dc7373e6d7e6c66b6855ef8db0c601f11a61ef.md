# Insert Image permits remote preview images through img-src

The Insert Image dialog policy permits http: and https: images in img-src alongside chrome: and data:. LoadPreviewImage assigns the trimmed source input to the preview image after best-effort cache removal. The change concerns preview image loading; it does not broaden script-src or prove a general remote-message policy. No remote image or CSP enforcement test ran.

Scope: Compose image properties dialog.
