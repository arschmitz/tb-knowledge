# Keep Exchange discovery and EWS runtime activity names compatible

D230466 makes activity type required and exposes the difference between the exchange discovery configuration and ews runtime server type. The actual landing passes exchange to Autodiscover and supplies both provider keys, with a comment naming the conversion. The author reports that using ews too early left authMethod unset but does not fully explain why. Keep that cause uncertain. Reviewer reauthentication concerns and requesting-all/ requiring-none idea were nonblocking and untested, not the adopted policy. This is a scoped compatibility/naming example, not evidence of current account setup success.

Scope: OAuth Exchange activity compatibility.
