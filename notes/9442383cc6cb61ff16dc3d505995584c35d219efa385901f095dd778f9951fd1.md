# Keep font registration diagnostics specific to the rejected window

UIFontSize duplicate/loading diagnostics now log win.location.pathname. The loading check applies while the OS font value is first obtained; registration later stores the window, attaches an unload listener and applies the current size. Recommend retaining concrete page context in these diagnostics. Logging a path is not evidence that registration succeeded, and this source check did not exercise navigation or unload. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/modules/UIFontSize.sys.mjs.
