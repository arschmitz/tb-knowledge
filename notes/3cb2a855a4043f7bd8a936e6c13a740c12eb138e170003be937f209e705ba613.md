# Reload the selected folder after applying global view flags

The original Appearance landing only invalidated the thread tree after global-view-flags-changed. The fixed accepted handler instead dispatches a folderTree select event to reload the displayed list from updated folder settings. Keep this current behavior distinct from the historical repaint-only implementation. The observer and selected-folder handler were read; a live view refresh was not exercised.
