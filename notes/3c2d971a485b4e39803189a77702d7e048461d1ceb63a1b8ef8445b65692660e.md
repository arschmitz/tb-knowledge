# Remove-all tags sends a per-folder union of applied registered keys rather than the global tag dictionary

The remove-all command intersects each selected header keywords with the registered tag keys, then unions those matches by folder object. One removal call sends each folder selected-message array and its joined union; the folder backend removes only keys present on each message. Known-tag membership does not validate keyword syntax. The IMAP override changes the local database before requesting remote storage, so this frontend batching change alone does not prove server completion or eliminate local/server divergence. No changed test directly checks interleaved folders, malformed registered keys or remote failure.

Scope: Message tag removal batching.
