# A pasted news hyperlink must not silently embed its source message

Compose embeds news/snews content only with explicit moz-do-not-send=false; a plain hyperlink keeps being a link. Entry314 adds an HTML-clipboard draft regression test that checks no message source is attached and restores clipboard state. Current shouldEmbed retains this exception alongside existing data/nntp and HTTP-image rules. Do not broaden it to suppress all URI schemes.
