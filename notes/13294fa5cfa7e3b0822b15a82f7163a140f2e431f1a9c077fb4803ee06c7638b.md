# The getHeaders test count checks omit assertion messages

The two new scalar preconditions check one account and ten imported messages with browser.test.assertEq, but neither supplies a message. Add nonempty expected-behavior messages such as The test should have one account and The folder should contain ten messages. The three later structural comparisons already supply their own should messages. This is a scoped test-review finding; a nearby comment, test name or a different helper default does not supply the missing arguments.
