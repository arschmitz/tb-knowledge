# IMAP directory construction uses namespace values copied under the host-list monitor

This public Git landing adds GetNamespaceDetailsForMailboxForHost and copies the selected namespace's prefix and delimiter while gCachedHostInfoMonitor is held. The URL consumer then uses its own values after unlock, while namespace-clearing paths use the same monitor and may delete namespace objects. Missing host is an nsresult error; an existing host without a namespace is success with found false. The immediate helper checks that status, but AllocateServerPath ignores its result and uses its original transformed path when no added name is produced. The change is bounded to this consumer; older borrowed-pointer APIs remain. No native concurrency, crash-reproduction or general host-list shutdown-safety result is established by this static source.

Scope: IMAP namespace value lifetime.
