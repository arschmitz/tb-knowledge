# Keep URI conversion assertions as narrow as the tests actually exercise

The accepted Exchange service unit tests check ews-message→x-moz-ews, graph-message→x-moz-graph and pass-through internal schemes. They do not assert fragment-to-path conversion, retained queries, sequential same-folder display or message content. Those contracts have current source evidence and need distinct tests to claim runtime coverage. A successful scheme-only unit comparison is not full URI behavior validation. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/protocols/exchange.
