# Keep signer identifiers separate from the parent key identifier

SigListView copies parent sig.keyId to a user-ID row, but copies child s.signerKeyId to a certification row. It displays either as a key ID with a 0x prefix. RNP separately supplies the parent fingerprint as fpr. Preserve these local names and mappings; substituting the fingerprint or parent key ID for every child would change the displayed signer. This is observed source structure, not a new naming policy across OpenPGP. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: OpenPGP signature data.
