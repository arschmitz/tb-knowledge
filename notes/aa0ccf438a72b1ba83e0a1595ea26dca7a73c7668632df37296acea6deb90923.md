# Reuse OAuth objects and tokens only when required scopes are covered

Current object reuse checks issuer/login origin, authorization endpoint, username, and a granted/requested scope Set that is a superset of requiredScopes. Refresh-token lookup checks origin, username, and realm scope coverage. Keep those distinct predicates; matching a host or username alone is insufficient. The inspected tests verify object identity reuse and a broader returned scope, not every possible denied-permission path.

Scope: mailnews/base/src.
