# The news-menu migration retains a misspelled initial localization attribute

The initial menu_getnextnmsg markup says datal-10n-id and supplies count 500. Its enabled-state function separately assigns the localization ID with the selected NNTP server’s maxArticles count. The spelling persists in accepted source. The new message is value-only; its removed label/accesskey attributes and adjacent menu label messages are distinct shapes. This is a bounded metadata/resource finding, without a rendered-menu or keyboard result.

Scope: News menu Fluent metadata.
