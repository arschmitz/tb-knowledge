# Prevent internal navigation when sending a footer link to an external browser

Current footer click handling calls openLinkExternally for an anchor and also prevents default navigation and stops propagation. The historical 585 template used inline click handlers; those are not the newer handler style to copy. Keep an external-browser action from also navigating the setup surface. Source keyboard activation behavior was not tested, and no external link was opened.

Scope: Account Hub external link event handling.
