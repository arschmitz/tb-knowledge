# Matrix media fixtures separate an opaque media ID from its displayed filename

The 1276 owned tests remove .png from emote/sticker MXC IDs while preserving displayed text such as example.png in other attachment cases. Current tests expect the corresponding download path and validate sticker sender/system/delayed state. This is a scoped fixture pattern: distinguish the media identifier from the label shown to the user. It does not establish that all real MXC IDs must be extension-free or validate a network download. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
