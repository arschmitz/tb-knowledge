# POP3 settings share the standard OAuth controls and SMTP preference bridge with IMAP

This landing moves the existing standard OAuth controls into a shared IMAP/POP3 panel and uses the same settings round trip for both protocols. Accepted settings keep the incoming server-key namespace and copy typed custom values and the internal issuer to the account's default SMTP server when one exists. The parameterized browser helper checks control state, stored preferences, shared issuer and disable propagation for IMAP and POP3. The actual POP3 consumer uses the incoming OAuth module, whose global feature preference and per-account opt-in remain separate from UI storage. No login, native provider, token request, live accessibility or test execution is established.

Scope: account-settings-oauth.
