# Use the singleton Panorama service and its typed table accessors

The accepted DatabaseCore is registered as a singleton and exposes folderDB and messageDB table interfaces. Those declared accessors replace the historical folders object interface. For this database family, obtain table services through the shared service instead of constructing another connection owner or copying the old accessor name. Existing shared knowledge covers connection, cached-statement and shutdown ownership. This is static source evidence for the service registration and interface names. Full Bugzilla and Phabricator discussion remains pending. No runtime, build or shutdown test ran.

Scope: Panorama database ownership.
