# The S/MIME Test action waits for the verifier callback before showing a result

The S/MIME verifier call places an empty list after its time argument and before the object implementing verifyCertFinished. That callback resolves the promise used as the PR error code. Current smimeVerifyCert maps zero to ok and other results to NSS or generic error data; smimeTestCert then chooses localized feedback. Callback completion is not itself successful verification. The owned patch only repairs this call position; it adds no certificate/sub-identity test and does not establish the upstream list semantics.

Scope: S/MIME configured-certificate feedback.
