# Transfer owned message references across Panorama getter outputs

Entry 2117 changes GetMessage from assigning a raw newly allocated Message to constructing it in RefPtr and transferring ownership with forget. Per-folder getters and flag lookups receive the owned output with getter_AddRefs, so temporary references release on every return path. Per-folder header output adds its own reference before the local RefPtr is destroyed. Current GetMessage keeps owned C++/XPCOM outputs but Message is now a lightweight key object; membership/data validity is checked separately. The old snapshot fields and raw MessageDatabase pointer are historical. The historical GetMessageFlag still ignored GetMessage’s result despite using RefPtr; current code propagates its flag/cache read result with MOZ_TRY. Ownership cleanup and successful lookup are different contracts. The commit title reports leak fixes, but no leak profile, missing-key or lifetime test was run. Current native listener retention and explicit ClearListener behavior are reused from shared knowledge. Full discussion is pending.

Scope: Panorama message output ownership.
