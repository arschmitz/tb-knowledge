# Image zoom state is owned by message UI attributes rather than emitted MIME markup

Entry 1297 removes the generator’s shrinktofit="yes" attribute and makes message UI set shrinktofit as a presence attribute. The accepted header path sets the initial state, the MailMessage child actor toggles it on click, and messageBody.css consumes the presence selectors to choose size and zoom cursors. For this attribute protocol, use toggleAttribute and hasAttribute consistently rather than string-value tests. This is scoped DOM-state style guidance; the old contentAreaClick.js file is retired, and no zoom or MIME-rendering test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message image attribute protocol.
