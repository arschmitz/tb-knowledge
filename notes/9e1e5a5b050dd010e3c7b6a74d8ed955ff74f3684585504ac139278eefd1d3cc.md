# The mail-view reland falls back to its stored name when localization is unavailable

The reland accepts a localized pretty name only when formatting succeeds and returns a nonempty value. Otherwise it returns mName and NS_OK. It matches the default Not Spam literal; an old Not Junk value has no matching localization branch and falls back to its stored name. This describes the exact matcher and fallback, not a migration of every saved profile. The later accepted API returns UTF-8 but keeps this fallback. No mail-view or locale test ran.

Scope: Mail-view pretty name fallback.
