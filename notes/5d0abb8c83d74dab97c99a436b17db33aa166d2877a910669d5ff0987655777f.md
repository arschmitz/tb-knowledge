# Draw the grouped-header divider on the inner card decoration

The accepted grouped-header styling uses .card-container::after for the divider between adjacent dummy rows when the first row is collapsed; the second row only needs the dummy token. The divider starts transparent; it becomes visible only when both rows lack hover, focus, focus-within, current and selected states. The opacity transition runs only for prefers-reduced-motion:no-preference. This replaces the earlier collapsed-card border and radius override, keeping the divider separate from the pill border. Current source uses block-size, inline-size, border-block-start and margin-block-start for this decoration; grouped-card spacing uses padding-inline-start and --tree-card-content-inline. These names and properties belong to this section. The final accepted patch changes only threadCard.css; earlier keyboard, RTL, roving and mouse-test proposals do not prove interaction changes or test coverage. An unsubmitted author inline is excluded from the conclusion. No pointer, keyboard, forced-color or accessibility check ran.

Scope: mail/themes/shared/mail.
