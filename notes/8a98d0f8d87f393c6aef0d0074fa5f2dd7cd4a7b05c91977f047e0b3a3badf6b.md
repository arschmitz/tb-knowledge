# Create-folder migration keeps response validation inside the operation

The migration puts parent ID and name in DoCreateFolder and delegates listener completion through DoOperation. Response validation remains in do_operation: a successful response must contain exactly one normal folder with an ID before that ID becomes the success argument. The fixed accepted source retains those checks while later using a typed no-fallback value and queued request transport. Native start success and a completed server operation remain separate events. No malformed-response, callback, server or build test ran.

Scope: ews-create-folder-operation.
