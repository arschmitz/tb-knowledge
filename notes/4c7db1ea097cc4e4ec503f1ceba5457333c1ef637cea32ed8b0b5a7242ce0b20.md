# Popup timing can remain necessary after histogram removal

The legacy histogram cleanup removes dismissal-stat fields and recording calls. It keeps the security delay: current button handling checks the active window and elapsed time since timeShown before calling the action. Explicit dismissal also still changes a persistent notification to non-persistent. These are functional consumers, separate from telemetry statistics. Do not infer that every timing field or dismissal branch can be removed with a histogram. No popup UI or security-delay runtime test ran.

Scope: Popup notification security timing.
