# Return focus to the search input after clearing it

The search-bar reset event clears its value and focuses the search bar so a user can type another query. The bug says the clear button is not available to keyboard navigation and focus had moved out of the field. The landed code calls focus after reset; current search-bar.mjs still focuses the host on reset. For custom elements, verify both host focus and focus of the actual input in the shadow root when that is the user-visible result.

Scope: Search bar focus.
