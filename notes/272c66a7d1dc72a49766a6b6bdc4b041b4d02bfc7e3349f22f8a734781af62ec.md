# AccountHubInput documents its paired value accessors as one property

The component describes the string value getter and setter with one @type property comment and marks getter-only valueAsNumber read-only. Both delegate to the internal native input. The modern manual-config port template instantiates this custom component, and its controller writes value before reading valueAsNumber. Accessor bodies are retained; declaration order changes. The claimed documentation-build repair is historical and was not run here.

Scope: Thunderbird Account Hub input property documentation.
