# Calendar part 6 leaves an intermediate request guard against a removed verbose flag

Part 6 deletes the cal.verboseLogEnabled getter, but the same revision's CalDavRequest.commit still reads that property before upload and response diagnostics. With the ordinary exported cal object, the deleted property no longer enables those branches. The fixed accepted request implementation has removed both old guards. This is a bounded static mismatch in the intermediate revision, not a claim of current failure or a reproduced output result. The intervening change that removed the guards was not studied.

Scope: Calendar logging migration intermediate request phase.
