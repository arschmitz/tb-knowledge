# The icon-button RTL override follows its background-position shorthand

This landing moves the right-to-left background x-position into .button.icon-button, after the block's background-position shorthand. The fixed accepted stylesheet retains that order and the concrete Write Message button uses the icon-button class with a separately supplied image. Icon-only and check-button variants have separate positioning rules; no computed layout, native RTL or general CSS policy is established here.

Scope: mail/themes/shared/mail/widgets.css icon-button cascade.
