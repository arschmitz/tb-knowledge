# Decision tasks default the base reference and preserve a failed merge-base input

The decision function imports COMM_BASE_REF from the environment and fills a falsey value from the repository default_branch or an empty string. When both base and head revisions are present it asks for their latest common revision; an exception is logged and the provided base_rev remains. The nullable schema and fixture test do not validate that selection path or prove the fallback revision is usable. Keep base reference, base revision and downstream taskgraph-diff consumption separate.

Scope: Taskgraph comm base selection.
