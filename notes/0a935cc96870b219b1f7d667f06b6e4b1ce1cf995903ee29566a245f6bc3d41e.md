# TreeView selects on single clicks while the contacts sidebar activates the current selection

TreeView returns before selection handling for non-primary clicks or click detail other than 1 and restores focus to the table body. The compose contacts handler separately uses a primary detail2 click to insert the currently selected cards. Its browser scenarios first select with a single click, then activate, and directly check recipient labels. These checks do not directly prove no scrolling, focus retention or every native event sequence. This is a scoped selection/activation contract, not a ban on double-click handlers. Static inspection only.

Scope: TreeView and compose contacts selection.
