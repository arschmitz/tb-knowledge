# Devtools source-address migration keeps registration, loader and build paths together

This comm migration changes the DevToolsStartup component esModule URL, the devtools-loader require of tb-root-actor.js and the MOZ_SRC_FILES list together. The component identity and command-line category stay stable. The actor still uses its loader-managed CommonJS export contract, while startup remains an ES module. Check each entry route when changing these paths; the new URI alone does not change the module format. This scoped source relationship does not establish a global moz-src policy or successful runtime resolution. No devtools startup or build ran.

Scope: Developer tools startup.
