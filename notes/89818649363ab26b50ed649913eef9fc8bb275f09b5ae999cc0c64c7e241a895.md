# The properties reland changed native conversion spelling after the first landing

The first landing uses NS_ConvertUTF8toUTF16 for localized folder, column and filter-action values. The reland instead calls ToNewUnicode on nsAutoCString at those sites. Accepted folder-label code uses CopyUTF8toUTF16, and the later DB-view localization helper also converts explicitly. Keep these revisions separate when describing adoption. The cited comm code does not establish the external string overload or allocator contract, and no non-ASCII rendering or memory test ran.

Scope: Spam localization source phases.
