# Wait for the favicon state that the test actually needs

Entry 996 replaces an immediate favicon assertion with a condition wait. Accepted browser_contentTab now waits for a PNG data-URI prefix, while the historical test expected a URL string. The tab title can be ready before its favicon. Use the current representation in the condition rather than treating tab loading as icon completion. The removed assert_tab_has_favicon helper is not a current test API. This study read the test and the asynchronous update caller but did not reproduce the intermittent failure.

Scope: mail/test/browser.
