# Contract-ID migration preserves instance creation and service lookup as separate operations

The IMAP aliases map stable contract strings to the same URL, mock-channel and host-session classes. URL/channel and compose-fields callers still create instances; host-session callers still request a service. Keep these operation kinds and their result checks when changing a lookup identifier. Adding an alias is distinct from replacing the implementation or proving a mock intercepts the route. No component/runtime test ran.

Scope: Mailnews XPCOM lookup routes.
