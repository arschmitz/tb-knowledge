# Copy the selected Account Hub configuration before editing it

In the 1959752 repair, captureState returns selectedConfig.copy() rather than the widget-owned object. Selection also starts with a copy of the current config and places the chosen incoming alternative on that copy. The actual AccountConfig.copy method deep-copies its properties. This keeps the captured choice explicit when the editor changes values or the user returns to selection. The same landing temporarily hides native EWS editing with a tracked TODO; the fixed accepted source later permits EWS and Graph editing and updates every Exchange alternative after add-on state changes. That historical editability limit is not a permanent protocol policy. No account, add-on, credential or browser task was exercised here.

Scope: Account Hub selected configuration state.
