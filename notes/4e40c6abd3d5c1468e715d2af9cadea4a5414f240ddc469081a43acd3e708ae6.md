# The support-link document ranks formatted pref URLs before static Thunderbird URLs

The owned document adds an ordered preference for support links: format app.support.baseURL and append the article slug, or use a language-free static support.thunderbird.net/kb URL when JavaScript is unavailable. It discourages hardcoding support.mozilla.org and describes website redirects as a way to defer a disputed slug. The accepted pref and showDataDeletion consumer demonstrate the formatted-base pattern. This is scoped accepted documentation evidence; it does not verify deployed redirects, formatter internals or change deliberate user instructions.

Scope: Thunderbird support-link documentation.
