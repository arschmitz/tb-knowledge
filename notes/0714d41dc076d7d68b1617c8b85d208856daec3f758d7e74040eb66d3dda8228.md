# Scope test skips to the unavailable feature and explain the cause

The update-history dialog test skips Windows MSIX, whose updater panel is unavailable, rather than all builds without MOZ_UPDATER. The folder drag test restricts its known skip to Linux headless and links the cause. Proposed manual review rule: keep platform/package skips as narrow as the failed capability, and retain the explanatory bug or comment. A reviewer-reported Try pass is separate from local validation.
