# Account success actions require the created account object

Entry 1482 gives the success component a created-account state and uses its incomingServer to select the Encryption or general Account Settings page. The accepted happy path passes this.#account, and the current browser test clicks the actual Encryption button and expects that account's am-e2e.xhtml page. In this component, recommend passing the created account object rather than its setup configuration; matching display fields does not satisfy the incomingServer interface. No Account Hub, account creation, settings-selection or UI test was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Account success object contract.
