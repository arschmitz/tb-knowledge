# Search adapter retirement preserves the native result and charset contract

Entry 1462 removes unused adapter IDL methods and attributes while keeping search, validateTerms, currentUrlDone, addHit, addResultElement and read-only searchCharset. The accepted native Search still returns an nsresult and writes completion through a Boolean output pointer; GetSearchCharset provides UTF-8 by default with folder/news overrides. NntpMessageService still calls the lowerCamelCase addHit interface method. This retires dead interface surface, not search result delivery or charset selection. Bounded comm source checks do not prove all downstream consumers were absent. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Search adapter retained contract.
