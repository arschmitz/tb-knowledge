# The extracted queue takes a spawning callback and reports start failure

OperationQueue::new now returns an owned queue and takes a nonblocking function pointer for spawning runner futures. start returns Stopped after channel closure; EWS supplies detached moz_task::spawn_local and propagates startup errors. The original starts five runners, while later error conversion goes through ProtocolError. This does not add Send/Sync or establish five as a throughput limit. No build or concurrency test ran.

Scope: operation-queue extraction integration.
