# Use directory-service overrides to test profile discovery without a real installation

The current importer unit test directs AppData/ULibDir/Home to a temporary root and writes profiles.ini with absolute, relative and missing entries. This provides a test seam even though the historical author doubted testing the specific external-directory case. Proposed manual test rule: use the existing platform directory-service seam and real temporary fixtures for profile discovery. The current relative fixture is one component and does not cover the nested relative-path regression.

Scope: profile-import-tests.
