# The net.thunderbird guide separates consumer tests from protocol delivery

The guide registers one nsIObserver service under a host-named category, warns that arbitrary websites can construct URLs, and gives a direct observe call for component tests. That direct call bypasses OS and command-line routing. Confirm consequential actions in the component as the guide requires; the transport is not a trusted-origin guarantee. Later registration/profile guidance is a separate document phase.

Scope: Custom protocol documentation and trust boundary.
