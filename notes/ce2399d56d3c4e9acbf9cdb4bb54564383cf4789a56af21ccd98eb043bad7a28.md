# Keep the historical mailbox UNC rejection separate from current exceptions

The public 1958580 follow-up originally rejects mailbox file paths when the second character is slash, percent or backslash. Fixed accepted code instead decodes and normalizes the path, recognizes a UNC-shaped path, allows a path under the profile or an explicitly configured host, and otherwise blocks qualified network hosts identified by dot or colon. An unqualified local host can pass this specific check. Therefore the current source is not a blanket ban on every UNC mailbox. These are exact static path gates, not a full hostname/parser/Windows filesystem proof. Both assigned Bug and review are denied; zero full-audit credit and no file or network runtime test.

Scope: Scoped message-load input boundaries.
