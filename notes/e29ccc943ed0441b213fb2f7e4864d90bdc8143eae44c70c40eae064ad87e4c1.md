# The folder new-message star uses a separate image with retained layout

The folder template puts a decorative new-icon image beside the folder icon. Its CSS supplies the sparkle and hides it with visibility, preserving the image's layout slot. Only new-message folder rows without data-server-type reveal it. FolderTreeRow updates that class from the folder or collapsed descendant state, and the pane forwards notifications to both the row and its collapsed visible ancestor. The layout choice is present in source; an intermittent row-jump explanation in review is not a measured layout diagnosis.

Scope: Folder pane new-message indicator.
