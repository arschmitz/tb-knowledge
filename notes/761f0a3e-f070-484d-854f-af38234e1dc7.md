# Guard repaired Git refs

A historical BCT1 repair recovered intended branch targets from `git reflog --all` and used `git update-ref <ref> <new> <expected-old>`. The expected-old value guards against moving a ref that changed during repair. This applies to damaged refs in that stack; the recorded commit IDs are recovery-specific.
