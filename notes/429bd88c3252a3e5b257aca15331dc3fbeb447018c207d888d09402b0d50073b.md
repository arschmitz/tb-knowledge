# Read the extension window tracker when the shortcut action runs

MailExtensionShortcuts defines a dynamic getter for windowTracker instead of caching an undefined startup value. openShortcutSettings obtains topNormalWindow at call time and throws No mail window available if absent. Preserve the deferred lookup and explicit missing-window result; selecting a top-level browser-like window is not sufficient for this mail-specific opener. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
