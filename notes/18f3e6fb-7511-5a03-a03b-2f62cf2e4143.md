# AsyncTask::poll behavior in xpcom/rust/moz_task/src/executor.rs

Polls the fallible handle and exposes only successful Some(output). Maps both an unfinished task and completed cancellation None to Pending.

## Result and consumers

## Errors

Cancellation is converted to perpetual pending rather than error; future panic handling is delegated.

## Async completion

Uses caller Context/waker when polling; does not add a wake for Ready(None).

## Ownership and cleanup

Output moves to caller when ready; otherwise wrapper retains handle.

```text
    fn poll(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output> {
        // Wrap the future produced by `AsyncTask` to never resolve if the
        // Runnable was dropped, and the task was cancelled.
        match Pin::new(&mut self.task).poll(cx) {
            Poll::Ready(Some(t)) => Poll::Ready(t),
            Poll::Ready(None) | Poll::Pending => Poll::Pending,
        }
    }
```
