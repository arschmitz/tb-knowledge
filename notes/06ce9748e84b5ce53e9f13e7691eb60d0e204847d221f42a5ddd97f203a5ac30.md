# Name the ordered offline test phases after their work

Accepted test_downloadOffline.js has setup, downloadAllForOffline and verifyDownloaded tasks. The final stream argument controls localOnly and the IDL documents that a required network load must fail when this is true. Scoped test pattern: separate setup, asynchronous action and verification, and explain an opaque positional boolean at the call boundary. This is specific to this message-service API, not a universal rule to split every test into three tasks. This is source and test inspection only.
