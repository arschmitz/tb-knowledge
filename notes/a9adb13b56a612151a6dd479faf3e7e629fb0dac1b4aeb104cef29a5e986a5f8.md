# Use the exact database-header type in message helper documentation

The small human follow-up fixes nsIMsgHdr to nsIMsgDBHdr in Calendar drop hooks, MailUtils single-message helpers and alert/junk callbacks. These helpers use header fields such as folder, messageKey and mime2DecodedSubject. The fixed accepted source still has old nsIMsgHdr prose and array annotations elsewhere. Recommend checking related prose and collection annotations when correcting a type name; this is a scoped manual documentation check beyond formatting. This is source and test-code inspection.
