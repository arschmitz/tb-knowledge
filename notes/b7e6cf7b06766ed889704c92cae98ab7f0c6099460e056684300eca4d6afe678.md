# Calendar counts exclude the unused automatic Home calendar, not every disabled calendar

reportCalendars skips only the storage calendar with the localized Home name when it is disabled or has no items. Other calendar providers remain in the included population, and read-only counts use that same population. Types are lowercased at the label. The current test verifies unused Home absence, used Home inclusion and 3memory calendars with2readonly calendars. Provider labels can come from add-ons; unknown providers are not proof of unlimited label capacity.

Scope: calendar-telemetry.
