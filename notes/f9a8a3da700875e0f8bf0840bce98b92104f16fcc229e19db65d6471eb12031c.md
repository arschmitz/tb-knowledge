# Keep WKD absence and download failures distinct from key data

The accepted WKD downloader returns null for an unsuccessful response, an HTML response or a thrown fetch. It converts the successful ArrayBuffer through Uint8Array into a byte string. Its async return documentation says Promise<string> despite the explicit null paths. Recommend documenting Promise<?string> or the local equivalent when editing this function; this is a scoped type-contract recommendation, not a new global lint rule. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending.
