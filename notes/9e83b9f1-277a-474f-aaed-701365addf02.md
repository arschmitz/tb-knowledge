# Use pane inert state for modal editing and capability state for actions

Address-book edit mode makes booksPane, cardsPane and their splitters inert. New controls inside those panes inherit the interaction block. A removed standalone toolbar no longer needs a separate edit-time disable loop. Capability restrictions, such as read-only books and no mailing-list support, still need actual disabled properties outside edit mode. Check keyboard access as well as the visual backdrop.
