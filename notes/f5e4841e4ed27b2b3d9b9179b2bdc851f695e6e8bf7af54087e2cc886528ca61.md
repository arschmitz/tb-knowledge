# Clang full-tree formatting is a manual task variant rather than ordinary push work

Entry 1479 adds a clang-format-all variant for running through add-new-jobs on the whole tree. Its optimization always key removes it from ordinary scheduling; the author explicitly describes manual whole-tree invocation. The accepted clang kind no longer contains those historical variants. Treat the added task as a one-time/manual recovery tool, not evidence that every push runs whole-tree formatting or a new manual code-style rule. The 1480 bulk formatter sweep is excluded from unique style learning. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Clang full-tree manual recovery task.
