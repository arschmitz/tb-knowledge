# Initialize the NSS digest record and document the borrowed buffer

739 initializes the SECItem tag, pointer and length together. The surrounding signature verifier then borrows aDigestData.Elements() for NSS_CMSSignedData_SetDigestValue, whose source comment says it copies the input and will not mutate it. The const_cast depends on that specific contract; it is not permission to cast away const throughout S/MIME code. Keep initialization and buffer lifetime visible at C API boundaries. The NULL spelling in this historical structure is not promoted as a repository-wide syntax rule.

Scope: S/MIME signature verification.
