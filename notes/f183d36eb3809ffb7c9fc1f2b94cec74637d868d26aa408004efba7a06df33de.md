# Use a role name for stored paths rather than call every identifier id

The CalDAV provider uses locationPath for the remote resource and item.id for the ICS identity. Proposed manual naming guidance: state the role when an operation holds both storage location and logical identity. Preserve existing cache keys and wire values; no repository-wide id naming ban is established.

Scope: calendar/providers/caldav.
