# menus.getTargetElement checks the latest target and the requesting document

The message-menu subject forwards the context timestamp, and the parent exposes its floored integer when sensitive menu information and a truthy timestamp are available. The child lookup obtains the last target for the requesting browsing context, compares the floored timestamp, dereferences the target and requires its composed root to equal the requesting document. It returns null when those guards fail. This is a latest-target/document contract, not a durable element handle or a proved duration/uniqueness guarantee. The upstream actor that supplies target storage remains an unpaired dependency.

Scope: WebExtension child context-menu target lookup.
