# The Exchange interop rename updates its contract and Rust caller together

The factory rename changes its component contract from ews-interop to exchange-interop and updates the Rust create_instance call to match. The interface UUID and component CID remain. The original one-identifier factory still delegates to ForHostname. The accepted factory and its moved Rust consumer instead pass type, hostname and username to ForAccount; that expansion is a later phase. Matching source registration/caller names do not prove compiled ABI or live authentication equivalence.

Scope: Exchange language interop factory registration and caller.
