# Use explicit Searchfox trees when the role example requires a different source

The accepted Searchfox role defaults to comm-central, strips a leading comm/ path and supports an explicit tree before the first colon. Its docstring example still describes an unqualified browser path as generating a mozilla-central URL, which does not match the implementation default. For documentation written with this role, specify the tree when needed and keep examples consistent with the actual default. No generated link or live page was checked.

Scope: Searchfox role source-tree syntax.
