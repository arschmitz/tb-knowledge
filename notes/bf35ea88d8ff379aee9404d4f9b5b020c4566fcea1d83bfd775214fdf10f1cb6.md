# Calendar dialog instance values use lower camel case rather than constructor casing

The PositionedDialog review changes Container to container because the field holds an element, not a constructor. The accepted component also uses triggerSelector for its selector and PositionedDialog for the class. This supports the local JavaScript value/class distinction. It does not rename public attributes, CSS selectors, constants or types in other languages. Current fixed declarations were inspected; no runtime.

Scope: Calendar dialog naming.
