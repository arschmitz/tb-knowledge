# The nontrivial-memcall repair changes argument types without proving object lifetime safety

The compiler repair casts only the destination of existing memmove/memset calls to void*. The same buffers, byte counts, allocations and later callback/closure assignments remain. Mork's alternative wrapper branch is unchanged. This is a scoped way the patch addresses the reported diagnostic; it does not run constructors, establish ownership, validate every zero-initialized object, or prove all platforms compile. Keep existing typed MIME callback and closure contracts separate. No build or sanitizer ran.

Scope: Mork and MIME memory-call diagnostics.
