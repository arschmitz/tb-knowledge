# Notification position classes are replaced on every update

Entry 1472 adds notifications-bottom and notifications-top selection. At the fixed endpoint, setNotificationData toggles bottom-spaces-toolbar and bottom-today-pane on every update, then explicitly adds bottom-spaces-toolbar for an unknown or missing position. The old class names and showNotification method are historical. In this local component, test placement transitions as well as positive membership: the current five-case tests check expected classes but do not explicitly assert removal of the previous opposite class. This is scoped test advice and accepted source behavior, not a reproduced placement regression. No test, build, runtime placement or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending.

Scope: Notification placement transition state.
