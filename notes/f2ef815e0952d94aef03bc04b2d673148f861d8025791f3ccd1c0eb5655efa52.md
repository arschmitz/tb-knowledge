# Open and Show selects signed multipart bytes with the signed part boundary

The signed-part display path finds a nested multipart/signed part, uses that part’s own boundary, escapes it for a regular expression and copies the matched multipart substring from the original loaded message. It adds the signed part headers and preamble; parent headers are included only when the parent is not message/rfc822, with its Content-Type removed. The owned patch replaces the old parent-boundary extraction; the fixed accepted source adds later header-newline normalization. msgOpenMessageFromString writes the resulting byte string to a temporary EML file before opening it. The new forwarded-message test directly expects inner body text, a signed-ok icon and no encrypted-ok icon after Open and Show. It does not compare saved bytes or prove all MIME encodings and boundary layouts. Keep the original signed substring separate from decoded tree bodies when explaining this contract.

Scope: mail/OpenPGP/nested-message-display.
