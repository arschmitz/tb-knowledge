# Check GetIsServer before using the deletability output

D227880 explicitly requires checking GetIsServer status even after the reviewer first accepts. The actual landing and fixed Exchange GetDeletable propagate failure before deriving the deletable result from root/special-use state. The override still supplies menu capability; removing an unused earlier call did not mean deleting the override. This is a scoped fallible-output contract, not a live permissions or menu test.

Scope: Exchange folder deletability contract.
