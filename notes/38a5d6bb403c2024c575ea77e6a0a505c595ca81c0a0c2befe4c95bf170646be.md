# MessagePane display methods clear competing views while preserving explicit start-page state

Accepted clearAll leaves a marked start page open unless alwaysClearWebBrowser is set. displayMessage and displayMessages clear the web/other message view when showing content, dispatch count updates and return when collapsed. Preserve those transition rules when extracting display helpers; indiscriminate clearAll calls can change start-page behavior, while collapsed display does not fill a hidden browser.
