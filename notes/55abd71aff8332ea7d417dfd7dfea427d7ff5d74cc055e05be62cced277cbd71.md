# EWS batched hard deletion can finish remote blocks before local reconciliation

Accepted deletion sends sequential blocks of at most1000 IDs and validates each response count before pairing it with IDs. A later block can fail after earlier blocks were deleted remotely. The native all-header LocalDeleteMessages callback runs on final operation success, so remote partial progress and local cleanup are separate. ErrorItemNotFound is tolerated for retry recovery; other errors still fail. The current one-message tests do not exercise multi-block failure. No deletion or test ran.

Scope: EWS message deletion completion phases.
