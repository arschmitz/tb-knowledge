# Graph folder rename separates task scheduling from local rename completion

The Graph bridge detaches an update_folder task and returns Ok immediately. DoUpdateFolder sends a display-name PATCH, discards the response and returns no replacement IDs with legacy fallback disabled. The native Rename listener applies the local folder-name change after success. Keep those scheduling, remote-operation and local-update phases separate. The stable-ID comment is qualified; this study did not test external API identity or failure paths.

Scope: Exchange folder operation callbacks.
