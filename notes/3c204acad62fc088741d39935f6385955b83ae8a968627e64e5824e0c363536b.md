# File New Address Book visibility refresh remains behind the selected-folder guard

The initial patch adds legacy Local/CardDAV/LDAP creation under File New and an alternative single Account Hub item. With a selected folder, menu_new_init reads mail.accounthub.addressbook.enabled and passes inverse Boolean visibility values to ShowMenuItem, whose contract is hidden=!showItem and requires a real element. Without a selected folder, the existing early return leaves visibility unchanged. The menu items are MAIN_WINDOW markup. This records actual local scope and the accepted refresh limit, not immediate Settings-tab updates or behavior in every window. The initial landing was backed out; later reland and fixed accepted source retain its four implementation blobs, with a separate added test path not audited here. No UI or test run.

Scope: Main-window File New menu and Account Hub selection.
