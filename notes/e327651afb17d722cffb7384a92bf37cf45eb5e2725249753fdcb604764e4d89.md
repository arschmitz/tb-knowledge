# Account Hub subheader keeps a paired class spelling alongside its one-word API names

The accepted template and stylesheet both use sub-view-sub-header. The same component uses subheader-id/subheader-text attributes, slot subheader, ID accountHubHeaderSubheader and variable --hub-subheader-margin-block-start. A one-word class spelling must not be claimed as adopted from these sources. Scoped naming suggestion: if the class is deliberately renamed, change the template and selector together while preserving the separate attribute, slot and ID contracts. This is a documented local naming mismatch and a suggestion, not a new rule or a verified visual defect. No rendering, stylesheet or accessibility test ran.

Scope: Account Hub subheader scoped naming.
