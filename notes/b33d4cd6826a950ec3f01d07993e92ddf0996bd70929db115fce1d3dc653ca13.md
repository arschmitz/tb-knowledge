# Test OpenPGP send-mode transitions separately from MIME encoding

Proposal: add coverage that reaches the inspected OpenPGP send-mode decision, rather than treating the MIME encoder unit test as proof of that decision. Check signed-only PGP/MIME, encrypted-only, sign-and-encrypt and the supported GPGME signing exception against the actual current predicate. Include changing modes in an existing compose window and inspect forceMsgEncoding before building the MIME message. The field starts false and its setter stores the value, but this scoped study does not establish every reset caller or an observed stale-state failure. Existing encoder tests cover classic signatures, clean unobtrusive-signature7bit and non-ASCII/control/long lines; they do not send OpenPGP or switch window modes. Keep output and signature verification separate. Assertion messages should state expected behavior and contain should. No test was added or run.

Scope: mail/extensions/openpgp.
