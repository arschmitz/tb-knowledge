# The UNC attachment exception matches only configured host patterns

AttachmentInfo.isAllowedURL preserves a default remote-UNC block and allows a configured host exception. hasFile consumes that decision. The landing inserted host text directly into a RegExp; fixed code escapes each host with RegExp.escape before matching. This newer source difference matters for literal punctuation in a hostname. Invalid URLs, feed enclosures and other schemes follow separate checks. No network share or security test ran, and approval alone is not safety validation.

Scope: Attachment host matching.
