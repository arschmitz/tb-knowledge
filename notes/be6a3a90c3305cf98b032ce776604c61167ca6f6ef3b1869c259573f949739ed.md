# The same-account IMAP folder-copy regression checks both the copy and the surviving source

Same-server moves use the native MoveFolder branch; same-account copies retain false isMoveFolder and use the folder-copy state. The added test synchronizes a one-message IMAP source before copying it, then directly checks one message in the destination copy and one in the original source. The folder menu/drop wiring supports this production operation. These are static source and direct assertion scopes; message-byte identity, server interoperability and fresh test execution are not established.

Scope: IMAP folder-copy dispatch and xpcshell regression coverage.
