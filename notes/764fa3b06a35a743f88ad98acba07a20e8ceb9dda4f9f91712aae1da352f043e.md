# A large knowledge tree can exceed the buffered Git listing cap

The sync importer reads a complete NUL-delimited Git tree before checking every entry. On October31 the listing grew past its16MB command-output limit, so sync stopped with ERR_CHILD_PROCESS_STDIO_MAXBUFFER. Raising only that output cap to32MB allowed the same importer and publication checks to finish. Six existing repository tests and an actual standalone sync passed. The correction is local and uncommitted; existing console processes may still hold the old module. Larger repositories may eventually need streaming rather than another fixed cap. This repair does not establish a higher commit-audit rate.

Scope: Knowledge repository sync.
