# The send-button test skip names x86_64 architecture explicitly

The browser_sendButton.js manifest entry replaces the Windows debug bits ==64 check with arch == x86_64. The accepted entry retains this exact architecture predicate. A64-bit Windows debug input with another arch string would satisfy the old width condition but not the new one. This is a conditional source comparison, not a claim about actual harness values, ARM jobs, test execution or equivalent behavior. The other43 formatting/reorder paths were classified from metadata without source-body inspection.
