# Keep parent unread state separate from unread descendants

DB view unread/new counts include the parent. When the only unread message is the root, it must not receive hasUnread for children; analogous hasNew handling applies in row properties. The parent still has its own unread/new property. Tests separate root versus child mutations. Do not reuse a total count as a descendant badge without the parent adjustment.

Scope: view.
