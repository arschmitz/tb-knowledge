# The all-fields EWS sync optimization is a historical phase, not the accepted fetch contract

The original optimization puts metadata fields in SyncFolderItems and consumes its create/update payloads directly. At the fixed accepted revision, SyncFolderItems requests only IDs and a separate get_items call obtains explicit metadata fields. The accepted comment explains that SyncFolderItems can silently omit fields; this is source rationale, not an independently reproduced server result. This narrows the current applicability of provisional lesson a476975b9bb3e9ac8901859da3bd6b278c9af0ce8eeca2617c9dac10284ed84b: its numeric speed/request claim belongs to the historical proposal and is not a verified current benchmark. No later backout or reland receives a source audit from this correction.

Scope: EWS synchronization field completeness and source phases.
