# Name extension browser globals for the window they retain

The browser-test cleanup uses gDefaultTabmail, gDefaultAbout3Pane and gDefaultMessagePane for references obtained from the default test window. In messageDisplayScripts, checkMessageBody uses the default message pane only when no browser argument is supplied; message-tab and new-message-window cases pass their own browser explicitly. Preserve that receiver distinction when several windows or tabs are open. The selected fixed source retains this contract. This extends the existing scoped fixture-global naming note; it does not require g prefixes in unrelated code or make the default window the current window. Source and direct checks were read statically; no UI or accessibility test ran.

Scope: Extension browser default-window fixture identity.
