# The Graph mock DSN update does not model resetting a true value to false

GraphServer updates dsnRequested only for a truthy isDeliveryReceiptRequested value. A later PATCH with false leaves an existing true value unchanged. The send test checks only a newly created message with DSN true and one Bcc recipient, so it does not establish false/reset behavior. Keep this limited mock contract separate from the production request, which includes the actual Boolean.

Scope: Graph send mock update contract.
