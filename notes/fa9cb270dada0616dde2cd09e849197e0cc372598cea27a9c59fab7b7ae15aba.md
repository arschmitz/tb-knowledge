# Keep incoming and outgoing Account Hub captureState result shapes distinct

Incoming captureState returns {config, edited}; outgoing captureState returns an AccountConfig copy. The controller unwraps the incoming config field before passing it to the next step. Keep these exact state shapes at this boundary. The class-preserving copy contract already has a shared lesson. This is not a blanket no-alias invariant: setState stores the supplied config and other inspected edit paths share working data. Static source only; no test, build, live keyboard or accessibility session ran. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub configuration state boundaries.
