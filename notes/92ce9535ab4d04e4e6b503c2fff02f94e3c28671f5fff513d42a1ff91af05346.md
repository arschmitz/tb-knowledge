# The annotated legacy picker wrapper still waits for its callback through event processing

The patch annotates the ShowPicker definition without changing its body. That body calls Open, returns an opening failure, processes events until the callback sets its done flag, then copies the callback result. The annotation does not replace that existing asynchronous-callback/event-processing contract. Its exact Gecko macro/static-analysis pairing and native runtime behavior remain unverified.

Scope: Legacy native messenger picker boundary.
