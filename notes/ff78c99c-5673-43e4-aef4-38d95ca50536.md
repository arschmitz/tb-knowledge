# Grouped ingestion trial missed the throughput target

A trial selected 31 files from two connected JavaScript-heavy groups. Independent
source review accepted 20 complete file obligations, kept 6 partial, and rejected
5 records. Source review took 900.460085 seconds, or 79.959124 files/hour. Dispatch
through retrieval and confirmed publication took 1240.993782 seconds, or
58.018018 files/hour. The target was 524.471 files/hour, a 9.039795-fold shortfall.
Setup took another 606.030860 seconds. Final report work adds further overhead.
This is a sample result, not a representative whole-codebase forecast.

Existing maps and inventories were reused. A scoped search found 53 matching
notes with structural or narrow local facts, and no complete behavioral records
for the selected files. Literal path search cannot prove implicit mentions absent.
All 178 unit descriptions were source-compared; only 95 units belong to accepted
complete files. No product runtime tests ran. Preparation took 1227.316542
milliseconds with no selected-target failures. Five later dependency source reads
used incorrect paths; all five were corrected and retained in private receipts.

Five Thunderbird test records were withheld because file-wide reads and ownership
facts became false per-callback claims. Six Firefox records retain explicit gaps
in dependencies, protocol argument/results, or release paths. The 26 published
notes preserve complete or partial status and exact source evidence.

The notes contain 558 pinned source links and total 873268 bytes. All 26 named
record checks and six behavior queries passed in each of two checks: bounded exact
lookup in the existing local cache, and full lookup in a fresh contribution-only
standalone cache. These checks do not establish full-library ranking, semantic
retrieval, console UI, copy grouping or supersession behavior. A previous
full-library search ran out of memory.

Source preparation is fast. Interpretation, evidence writing and review remain
the observed limit. Shared family contracts with checked membership and caller
exceptions are a possible later experiment, not an implemented or measured
solution. The completed file census and this trial do not establish full codebase
understanding. These observations do not create new instructions.

The source window overran its 900-second cap by 0.460085 seconds; that time is
included. A metadata and formatting edit crossed dispatch. Source selection and
configuration stayed fixed; both adapter hashes remain in private receipts.
Exact active worker cost is unavailable because repair timers were incomplete.
A later export fix was checked independently after editing, but its required
pre-edit check was missed. That fix was outside source analysis and does not
change this run, which had no preparation failures.
