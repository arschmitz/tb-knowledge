# Choose the delivery mode before applying recipient validation

829 moves the no-recipient guard after the draft/template/autosave handling. Saving an encrypted draft can use the account own key without an address in the recipient list. Sending still needs recipient validation. In this compose path, put validation after the mode-specific branch that defines which inputs are required; do not reuse send-only prerequisites for a save operation.

Scope: OpenPGP compose delivery modes.
