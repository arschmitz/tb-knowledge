# Body search matches leftover quoted-printable text before leaving EOF

When a message ends on a quoted-printable soft break, MatchBody now matches its accumulated text before leaving EOF. The charset binding survives between iterations because the concrete GetNextLine returns EOF before assigning it. Two synthetic plain/HTML fixtures add one-hit Contains cases; the shared TestSearch completion callback directly checks the count but lacks an assertion message. No test ran. The accepted implementation also has a later buffer cap, which is a separate source phase. Earlier charset and decrypted-parser limits remain separate evidence.

Scope: Message body search EOF and charset.
