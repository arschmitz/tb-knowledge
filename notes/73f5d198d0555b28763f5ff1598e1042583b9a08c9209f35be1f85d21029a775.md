# The News input-container hidden selector is a separate historical style phase

This import-migration patch also changes .input-container to .input-container:not([hidden]), excluding a hidden node from that flex rule. The actual News server document has a hidefor="nntp" input container, loads am-server.js and am-prefs.js, and passes its server type to hideShowControls. That helper toggles the hidden attribute on matching nodes. The fixed comparison CSS again has the plain .input-container selector, so the owned predicate must remain a separate historical phase. This source trace does not establish current computed display, a reproduced News settings failure or a general hidden-element rule.

Scope: Account Settings hidden-control styling.
