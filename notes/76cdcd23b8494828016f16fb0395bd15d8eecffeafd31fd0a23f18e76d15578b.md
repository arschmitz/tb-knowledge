# A Boolean iterator result can collapse error and end-of-work

The historical offline NewsDownloader change checks EnumerateMessages and returns false on failure. Its DownloadNext caller also uses false for normal exhaustion and reports NS_OK. Recommend checking caller error semantics when adding a guard to a Boolean iterator. That native downloader was later replaced by NewsDownloader.sys.mjs at the fixed accepted revision; the old error behavior is historical, not a current implementation claim. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
