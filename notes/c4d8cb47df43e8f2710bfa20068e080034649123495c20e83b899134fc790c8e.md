# Space command scrolls before navigating and uses a remote actor when needed

Accepted cmd_space obtains the inner message content window or a MessageScroll actor when direct access is unavailable. Shift scrolls back while above the start, and unshifted Space scrolls forward while below scrollMaxY; only at the boundary and with the preference enabled does it select the previous/next unread message. Keep scroll extent, content access and unread navigation separate when changing this shortcut. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
