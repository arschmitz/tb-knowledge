# The first combined Account Hub test refreshes settings and stays in the manual form

In this landing the manual branch calls the configuration test without continuing account creation. The test fills returned settings, shows the review title and success notification for a complete field configuration, preserves existing passwords and reports errors in the same form. Stubbed browser tests directly check both-server inputs, updated field values, visible review state and retry readiness; they do not prove authenticated connectivity or account creation. The later conditional Continue policy is a separate source phase.

Scope: Account Hub manual configuration testing.
