# Keep actor protocol documentation tied to the actual numeric result

The accepted ScrollState typedef annotates scrollMaxY as boolean, but getSize returns contentWindow.scrollMaxY and cmd_space compares it numerically against Math.ceil(scrollY). Recommend correcting that field type when editing the scroll protocol, and keeping command name/data/return shapes explicit. The later typedef form is an observed syntax pattern; the boolean spelling is not a style rule to copy. These are fixed accepted source and test-code observations.
