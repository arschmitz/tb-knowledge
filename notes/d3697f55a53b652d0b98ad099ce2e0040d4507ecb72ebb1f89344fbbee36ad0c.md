# Remove an unused IMAP interface method at all three boundaries

1013 removes beginMessageUpload from the IDL, the BeginMessageUpload C++ stub that only returned NS_ERROR_FAILURE, and its synchronous runnable wrapper. The accepted IMAP source has no remaining reference to either spelling. A method cleanup must account for the declared interface, implementation and cross-thread wrapper; deleting only the stub would leave an inconsistent interface. No external ABI compatibility or build was tested.

Scope: IMAP interface implementation and wrapper cleanup.
