# The Calendar attachment list replaces connected rows from URI stubs

After connection creates its template, setAttachments replaces all child items with mapped AttachmentStub values. URI supplies both the label and URL, while a missing icon becomes empty. The test directly checks item attributes and clearing with an empty array. This component does not load an event or wire the overview expansion; those parent phases are separate. The documented connection precondition matters because the list element must exist.

Scope: Calendar attachment-list data and connection contract.
