# The PDF Space test checks downward scrolling after the content-tab guard

The owned change removes the global XUL Space key and lets non-mail tab modes return from the outer keypress handler before preventDefault. Its PDF task waits for textlayerrendered, focuses viewerContainer, checks an initial scrollTop of 10, then waits for scrollend and checks a value greater than 10. The task name says cmd_space is not called, but there is no direct command-call assertion. The test has no Shift-Space, other tab-mode or platform matrix in this landing. Binary PDF identity and historical Try claims do not establish fresh rendering or focus behavior.

Scope: mail keyboard and PDF content tabs.
