# Calendar task migration combines Fluent patterns with DTD tooltip sources

This task-string migration copies existing Fluent label/accesskey patterns into renamed toolbar IDs while copying their tooltips from different DTD IDs. The source roles differ: toolbar controls request label/accesskey/tooltiptext, detail fields opt into value, and the task filter supplies custom attributes used by JavaScript. The owned patch keeps five progress-level messages and adds the shared calendar resource to the summary dialog for Copy Link. Its shorter Current Tasks note omits the old selected-date/recurrence detail; current filter code still selects explicit statuses and a selected-or-now end date. The note is not a full behavior contract. The exact historical migration script is retained because it no longer exists at the fixed accepted revision. Source declarations do not prove rendered translations, access-key behavior or successful migration execution.

Scope: Calendar task Fluent migration and source roles.
