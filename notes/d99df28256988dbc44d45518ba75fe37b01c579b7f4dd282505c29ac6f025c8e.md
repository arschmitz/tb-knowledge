# The Spam properties reland separates synchronous validation from asynchronous tree labels

The reland lazily creates a synchronous Localization object for restart and account-save prompts. It separately makes account-tree _build asynchronous for the Spam panel label and awaits it inside initialization and server load/unload handlers. These are different completion contracts. The iframe window's __UIFontRegistered flag prevents repeating that window's font registration; it is not a tree-build serialization lock or proof every observer caller awaits the promise. No account dialog or test ran.

Scope: Account Manager localization completion.
