# Use a specific EWS item ID lookup for Exchange message sync

Bug 1895801 needed a way to find message headers while syncing Exchange Web Services (EWS). Existing database lookups use a message key, Message-ID, or Gmail ID. The bug discussion rejected a generic service-ID field because providers use incompatible ID forms under current constraints. The 2024 IDL adds getMsgHdrForEwsItemID(AUTF8String), backed by the header property ewsId. Current ExchangeMessageSync and ExchangeFolder call it for create/update/delete or folder operations. Keep provider ID meaning explicit when these IDs cannot be safely shared.

Scope: Message database and Exchange.
