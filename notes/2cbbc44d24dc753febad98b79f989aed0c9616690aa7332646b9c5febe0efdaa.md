# Current protocol headers use path-based uppercase include guards

The inspected OfflineStorage, ExchangeService and ExchangeMessageChannel headers use COMM_MAILNEWS_..._H_ guards derived from their directory and basename. The historical EWS channel used a different guard spelling. Scoped naming recommendation for new headers in these current directories: follow the accepted path-based form and update it when moving or renaming the file. This is an observed family convention, not a complete repository-wide header audit or a formatter rule. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Protocol header naming.
