# Account Hub footer availability combines action visibility with the busy state

The current footer keeps one click listener and dispatches custom-footer-action for the custom button. canCustom hides unavailable actions and disables them when hidden or when the footer is disabled. toggleForwardDisabled also ORs in the footer disabled state. Back has its own setter. When changing this widget, preserve those separate controls instead of letting form-validity updates enable an action during loading.
