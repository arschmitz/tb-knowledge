# The partial-inline OpenPGP test waits for processing separately from message display

The test starts an inserted-about:message-document observer before clicking the subset-processing control. It then waits separately for the new window, message display and that document’s openpgpprocessed event before checking the body and icon. The normal display helper observes load state, while the event producer marks decryption work before later signed-part notification handling. The observer predicate is not tied to the returned window or message URI. This is a bounded test synchronization contract, with restricted bug/review context and no reproduced race or crypto execution.

Scope: OpenPGP partial-inline message test synchronization.
