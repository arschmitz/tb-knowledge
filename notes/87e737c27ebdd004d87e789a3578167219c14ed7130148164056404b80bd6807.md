# MAPI listener completion and returned send status are different signals

MAPISendListener marks m_done in OnStopSending and routes OnSendNotPerformed through that same method, without preserving aStatus. The outer function returns the SendMsg call result after waiting, and shutdown can end the wait before m_done. Treat its return value as the inspected dispatch result rather than a reliable final delivery result. Proposed tests should cover OnSendNotPerformed and shutdown-before-callback separately. This is a static contract observation, not a changed API guarantee or runtime diagnosis. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mailnews / mapi.
