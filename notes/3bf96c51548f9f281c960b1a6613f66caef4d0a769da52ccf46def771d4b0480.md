# The inspected replacement-password branch still discards the cancellation outcome

The empty-password branch returns the matched Cancelled or NewPassword outcome. In the distinct New Password branch after an existing-password failure, the same match ends with a semicolon and is followed by an unconditional RETRY. The fixed accepted helper still has that structure. Its cancellation test starts with an empty password and directly asserts only eventual idle, so it does not establish cancellation handling in this replacement branch. Preserve this conflicting static evidence rather than treating the patch title as a universal cancellation guarantee. No replacement-password failure was reproduced.

Scope: Authentication prompt coverage limit.
