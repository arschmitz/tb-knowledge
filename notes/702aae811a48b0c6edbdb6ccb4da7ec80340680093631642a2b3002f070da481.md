# Two new Graph diagnostics still describe the wrong actor or value

QueuedGraphOperation's custom Debug formatter prints QueuedEwsOperation. ProtocolError::InvalidHeaderValue prints invalid header name, although the caller failed to convert a header value to text. Both mismatches are retained in accepted source. Use the actual Graph type and header value in these scoped diagnostics so logs identify the failed operation clearly. This is a manual naming finding, not a global naming rule or an authorized code change.

Scope: Graph and protocol error naming.
