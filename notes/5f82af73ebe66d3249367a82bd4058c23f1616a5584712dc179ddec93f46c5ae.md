# Keep an event UID separate from its CalDAV resource path

getItemLocationPath uses an existing cached locationPath for updates, and sanitizes the UID only when generating a new .ics resource name. The original event UID remains the calendar lookup identity. The special-character regression test retrieves by the original UID in cached and uncached providers. Replacing illegal path characters is not permission to rewrite an ICS UID. The mapping can collide (for example a/b and a_b); this study has not established collision handling.

Scope: calendar/providers/caldav.
