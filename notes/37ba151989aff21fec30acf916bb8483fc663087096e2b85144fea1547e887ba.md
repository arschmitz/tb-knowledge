# The accepted POP factory uses the query message key rather than the original base-URL interface

The original interface-removal patch queries aBaseURI as nsIMailboxUrl and gets a key through that object before recovering the account. Accepted source later parses number from the spec and uses that key for GetMessageHeader and folder scan state. Keep the original and later lookup phases separate. The current source proof supports this lookup boundary, not unchanged callers, a malformed-query result or a reproduced partial-message failure.

Scope: POP factory account lookup phases.
