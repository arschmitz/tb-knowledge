# Put LDAP port and security controls next to the host in a two-column dialog

Bug 1895826 removed an inactive Find button and the old three-column spacer layout. The accepted dialog uses grid-two-column, puts Port and Secure beside each other just after Hostname, and keeps the existing XUL widgets. The review says the same dialog opens from Address Book and Preferences, where extra Preferences CSS can change its appearance. When editing this dialog, inspect both entry points and check the label/input pairs after moving rows.

Scope: LDAP settings UI.
