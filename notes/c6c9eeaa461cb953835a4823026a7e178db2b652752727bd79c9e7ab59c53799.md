# Address Book copy support follows cards-table focus

The copy registration uses cards-table focus to decide whether the Address Book supports cmd_copy. Its separate enabled predicate requires selected non-mailing-list cards. A focused empty list therefore remains supported but disabled; leaving table focus declines support even if cards stay selected. CommandController stores those predicates separately. The checked comm lookup also tries a second controller set after a disabled first result, so the original native-routing report must not be generalized to every caller. Native command selection was not executed.

Scope: Address Book command routing.
