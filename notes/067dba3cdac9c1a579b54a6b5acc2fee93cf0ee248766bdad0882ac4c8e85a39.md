# Keep virtual-folder fixtures explicit about the field that must match

After the unused address-word helper is removed, make_person_with_word_in_name remains. It returns [aWord, generatedAddress], so the match word is in the display name, not injected into the mailbox address. The complex virtual-folder test builds subject-only, sender-only, both and neither fixtures, uses AND and verifies only the both fixture. Local test naming guidance: retain the field in this helper name so the fixture does not silently test address matching instead of name matching. No search test ran. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran.
