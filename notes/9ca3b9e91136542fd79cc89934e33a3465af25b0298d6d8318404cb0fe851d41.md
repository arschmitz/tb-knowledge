# OAuth removal invalidates live cached objects by origin and username

Removing an oauth:// login clears both token fields on live cached OAuth objects with the same origin and username, then removes their weak references. Realm/scope is not part of that match. Existing holders keep the cleared object; later initialization can create a new one. The two-user test checks failure/new identity for the removed user and continued reuse for the other user, then global removal. It does not establish cancellation of an in-flight token request or all same-user scope cases.

Scope: OAuth object lifetime and storage notifications.
