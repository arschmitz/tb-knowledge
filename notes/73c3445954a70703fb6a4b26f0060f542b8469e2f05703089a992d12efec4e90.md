# Register font-managed windows after the load path and only once

UIFontSize rejects a duplicate window. While the OS base size is still unset it rejects a loading document before reading computed font size. Search and Subscribe register in their load functions; the broad Calendar utility registration was removed. Preserve registration at the owning window load path instead of a reusable helper script top level. The readiness guard is conditional on osValue, so it is not a universal rejection of every early subsequent registration. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: UIFontSize registration phase.
