# Gate a superseded extension API by manifest version in its schema

Bug 1897377 kept messageDisplay.getDisplayedMessage() for Manifest V2 and set max_manifest_version to 2 in the schema; Manifest V3 uses getDisplayedMessages(), which handles zero or multiple displayed messages. The current schema still has that gate. This is a specific compatibility method: limit old entry points in schema while retaining their promised older-version behavior.

Scope: Extension message display API.
