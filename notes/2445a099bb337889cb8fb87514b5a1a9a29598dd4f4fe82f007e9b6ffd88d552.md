# Feed archives use the source account and default archive preferences rather than an unrelated identity

When a message has no identity or comes from RSS, MessageArchiver chooses Archives under the message root folder and reads default archive preferences. Other messages use their identity archive settings. The selected folder and options enter the archive batch for later processing. Accepted later source creates a missing Archives folder asynchronously; the historical fix used a deprecated detached-folder helper as a temporary bridge. The old helper is not a recommended new API. Static source only; no archive execution.

Scope: MessageArchiver RSS and missing-identity routing.
