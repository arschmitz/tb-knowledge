# MIME emitter creation preserves failed status while its null fallback changes later

The owned patch returns the actual failed emitter-creation status instead of replacing every failure with OUT_OF_MEMORY. Its successful-null fallback still uses OUT_OF_MEMORY. Fixed accepted source checks the failed status first and returns INVALID_POINTER for a null emitter after success. This distinguishes the historical fallback from the later branch; it does not diagnose an observed null or out-of-memory failure.

Scope: Thunderbird MIME stream converter initialization.
