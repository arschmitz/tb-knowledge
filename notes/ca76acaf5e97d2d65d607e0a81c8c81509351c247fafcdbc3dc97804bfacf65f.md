# Keep account order with the account manager rather than the retired type sorter

allAccountsSorted now filters accounts without an incomingServer and optionally removes IM accounts, then returns the account manager order. The retired GetSortOrder, compareAccounts and server-type ranking must not be recreated from this historical patch. ReorderAccounts preserves hidden accounts, requires all existing keys, swaps m_accounts, and writes the accounts preference. The helper name and its older sort description do not establish a current type-based ranking contract. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account ordering ownership.
