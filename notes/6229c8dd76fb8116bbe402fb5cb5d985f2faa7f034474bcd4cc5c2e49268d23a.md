# The shortcut close button needs a checked name in the actual dialog

The accepted close control is a native type="button" with decorative alt="" artwork and a Fluent message that supplies .title = Close. The template’s visible dialog heading is still hard-coded. For this scaffold, recommend checking the computed accessible name and providing a clear localized button label or aria-label where needed; do not infer that an empty image makes the button unnamed, because the localized title can provide a fallback. This is a scoped proposed accessibility and localization check, not a proved defect or reviewer-approved rule. No live name, screen-reader announcement, focus return or keyboard inspection was done. Full Bugzilla and Phabricator discussion remains pending.

Scope: Customizable shortcuts accessible naming.
