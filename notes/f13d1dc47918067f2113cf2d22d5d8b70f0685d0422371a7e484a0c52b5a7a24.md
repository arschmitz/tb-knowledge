# Confirm the exact scope before applying folder view settings

Appearance uses separate confirmation text for all accounts, one selected folder, and a folder with children. It returns on cancellation and rejects a folder-menu event with no _folder by showing an error. The descendant helper includes the parent because .descendants omits it. For this pane, preserve the chosen scope and parent inclusion when refactoring menu actions. Prompt behavior and actual controls were inspected statically, without keyboard or screen-reader validation. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / components.
