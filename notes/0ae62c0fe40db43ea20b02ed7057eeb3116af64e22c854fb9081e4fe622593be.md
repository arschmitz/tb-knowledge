# The IMAP subfolder scan keeps the summary file separate from the local folder name

The scan strips .msf only from a name copy and preserves the enumerated currentFile for cache lookup and unknown-delimiter cleanup. It saves the local base name before replacing display/URI names from the cache. A separate clone gets the local base name for child construction. The needed comm cache helper uses a persistent descriptor without changing that leaf. This supports the selected local source path, not a reproduced deletion or a guarantee for every native error.

Scope: Thunderbird IMAP local subfolder discovery.
