# MessagePane is a custom element with three distinct browser responsibilities

1363 moves the about3Pane message-pane object into MessagePane and clones messagePaneTemplate. Accepted source still owns webBrowser, messageBrowser for about:message and multiMessageBrowser for summary content; the message and multi-message setters disable DNS prefetch. Keep those browser roles and load targets separate when moving display code. Not all three browsers have the same document, remote behavior or findbar. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
