# Keep message-header flag masking in the shared patch helper

Both mbox and Maildir ChangeFlags call PatchXMozillaStatusHeaders with the requested flags. The helper removes RuntimeOnly before formatting the persisted headers and retains the existing Queued bit. Preserve this shared boundary instead of applying a mask in only one backend. This does not imply all metadata update policies are identical between stores. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mailnews/local/src.
