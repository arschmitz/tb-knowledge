# Close the calendar input stream after success or failure and retain the cause

CalendarFileImporter logs the failed filename and rethrows the original error. Its finally block closes the input stream. The decoder/parser error is therefore preserved for its caller and the file handle is closed on either outcome. Preserve this cleanup boundary when adding preprocessing steps. This static reading does not test corrupted files or failure injection.

Scope: mailnews/import/modules.
