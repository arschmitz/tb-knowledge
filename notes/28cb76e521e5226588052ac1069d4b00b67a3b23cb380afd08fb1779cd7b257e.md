# Account Hub scrolling forms keep their height limit when alignment changes

The constrained form rule changes vertical flex alignment from center to space-around while retaining its 40vh maximum, full block size, vertical scrolling and outline padding. Current address-book and Exchange-settings rules override alignment to start. Read the matching selector and overrides together; the shared group declaration does not establish final alignment for every form. This is static layout evidence, not a rendered scroll-reachability result.

Scope: Account Hub constrained form layout.
