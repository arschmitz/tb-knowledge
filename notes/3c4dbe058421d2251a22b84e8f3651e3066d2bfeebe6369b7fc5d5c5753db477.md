# IMAP folder defaults seed filter and Gmail state before header processing

The constructor explicitly sets m_msgMovedByFilter and m_isGmailServer false. Header processing later queries the server Gmail state and resets m_msgMovedByFilter before applying incoming filters; the flags determine header insertion and Gmail custom-property handling. The historical m_totalKeysToFetch initializer has no corresponding member in the checked accepted header/source. Favor the active fields and do not teach a removed counter as current.
