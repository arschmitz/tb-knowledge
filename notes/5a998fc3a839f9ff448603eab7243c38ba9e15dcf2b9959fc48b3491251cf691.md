# Unobtrusive signing preserves extra trailing CRLF outside the signed buffer

Before requesting the signature, finishCryptoEncapsulation makes the input end with exactly one CRLF. If several trailing CRLF sequences existed, it keeps the extras in cryptoIrrelevantMessageSuffix. After producing the folded Sig field, it emits the signed input and then that saved suffix. The output validator checks the expected armored framing and the code removes its declared prefix/checksum/footer positions. This is a bounded serialization algorithm, not evidence that arbitrary armor, all whitespace forms or cryptographic verification were tested.

Scope: OpenPGP unobtrusive signature serialization.
