# Restore calendar scroll state with a bounded rounding tolerance

The test helper restores each view, repeatedly calls scrollToMinute inside waitForCondition and compares against Math.round(0.5 / pixelsPerMinute). The comment explains the double rounding between minutes and physical pixels. Keep that unit-based tolerance rather than demanding exact equality. This is a repeatable setter in a bounded test wait; it is not a general recommendation for arbitrary side effects in polling predicates. The reported intermittent failure cause remains unverified. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar test scroll restoration.
