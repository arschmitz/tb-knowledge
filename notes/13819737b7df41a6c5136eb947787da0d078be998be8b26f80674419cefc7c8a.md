# Keep notification type styling separate from shared focus and contrast behavior

Shared notification CSS defines container layout, CTA focus-visible outline, close-button outline and the decorative icon’s pointer-events:none. Type selectors set colors and geometry; the current prefers-contrast:more block applies system colors across all four visible types. The template uses native anchor/button controls and a focusable container; focus methods forward through shadow roots. Preserve those actual control semantics when changing a type design. The source and axe-observer setup do not prove keyboard, screen-reader or visual contrast results in this study. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Notification controls and contrast styling.
