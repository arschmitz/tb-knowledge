# Keep cached preference observers until their values no longer need refresh

AddressFormatFunction initializes cached display preferences with StaticPrefs but still reads its own fields while formatting. Its observers update those fields when preferences change. The header comment says this will be unnecessary once static preferences exist, although the getters are already static. A scoped comment repair should describe the remaining cache ownership; do not remove observers merely because the getter is generated. SQL formatting tests also change the preferences, but no live observer or restart experiment was run. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama address preference cache.
