# Format flowed conversion uses 72 columns and changes inline markup

The flowed option sets wrapWidth to 72 and passes OutputFormatted with OutputFormatFlowed to the serializer. A debug assertion forced OutputFormatted after the initial patch used OutputWrap; that changed expected output so italic text became /flowed/. Current code and test retain this behavior. When changing serializer flags, check debug builds and exact plain text, including markup and trailing spaces on flowed lines. The workaround should not be silently treated as the originally desired presentation.

Scope: Extension text utilities.
