# Keep a cancellation route available while OAuth authorization is pending

The current footer stores its busy flag and disables forward/custom actions, but does not disable Back through the overall disabled setter. The current OAuth browser tests cancel either with Escape in the prompt or the footer Back button and assert no account, stopped loading and restored forward availability. This current cancellation contract is distinct from the original 1696-era footer that disabled Back as part of the busy state. The generic footer state-first rule is already recorded and is reused here. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/components/accountcreation.
