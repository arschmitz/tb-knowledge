# The folder-add regression test counts global row refresh calls

onFolderAdded sets the new folder sort order and adds it without calling updateFolderRowUIElements. The new regression task wraps that helper, creates a local folder and directly asserts that its row exists and the global helper was not called. This checks a narrow call contract, not rendering speed, all server modes or dynamic accessible-label correctness.

Scope: Folder pane incremental folder creation.
