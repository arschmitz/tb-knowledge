# Keep localized shortcut instructions aligned with the physical key code

The notification handler checks code KeyJ with Alt and Shift, rather than the produced key character. Fluent uses a term for the key's label and PLATFORM() for the Option/Alt instruction. The instruction span is visually clipped rather than display:none. Preserve the physical-key contract and the displayed/spoken instructions as two linked pieces; localization of the term does not change the handler's code. No layout, conflict or assistive-technology test was run.

Scope: Notification physical shortcut and localized instruction.
