# Exchange offline message storage does not enable offline operations

ExchangeFolder reports offline message-storage support for nonvirtual folders while ExchangeIncomingServer keeps offline-operation support at NONE. Account Manager uses an explicit EWS exception for the synchronization panel instead of raising that server capability. The generic offlineDownload preference controls new-folder flags; toggling the page checkbox separately changes existing descendants. The original and accepted current source both show this capability split. This source study proves no queued offline operations, persistent flags, completed download or clean original test run. The backout and later reland remain separate private audit context.

Scope: exchange-offline-policy.
