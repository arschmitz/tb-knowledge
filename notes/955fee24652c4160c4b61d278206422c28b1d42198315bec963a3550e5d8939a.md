# Thundermail setup field assertions need their own expected-result messages

Nearby comments and field values do not provide the assertion message. The fixed accepted test adds three identity checks in a later phase and those also lack messages. Scope a diagnostic to each expected field; do not infer that the missing messages make the checked values incorrect. No browser test was run.
