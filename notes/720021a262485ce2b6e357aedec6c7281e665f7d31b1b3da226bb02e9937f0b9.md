# Keep the autoconfig test resource name and HTTP metadata paired

The Account Hub test server uses an extensionless-looking domain resource xml/test.test with a matching test.test^headers^ file declaring Content-Type: text/xml. The original fixture requests OAuth2 for both servers; the current fixture also includes a POP3 alternative. Preserve the fixture URL and HTTP metadata pairing when adding sibling autoconfig cases. This is a local test-resource naming pattern, not a rule that XML files elsewhere omit .xml. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: Account Hub test fixtures.
