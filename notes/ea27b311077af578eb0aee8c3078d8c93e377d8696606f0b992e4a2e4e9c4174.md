# Keep the SMTP password label conditional on transport security

am-smtp describes passwordCleartext differently when socketType is SSL or alwaysSTARTTLS. The 731 alias cleanup preserves that condition. A cleartext authentication method name alone does not determine whether this settings UI should display the insecure label. This source finding does not validate a live TLS negotiation.

Scope: mailnews/base/prefs.
