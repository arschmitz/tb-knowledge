# Editing outgoing settings invalidates the prior successful test

The outgoing form emits config-updated with completed:false after refreshing its captured config and native validity. Filling required controls does not prove a working SMTP connection. Preserve this edit-to-retest transition when changing outgoing controls; the controller owns the later server probe. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.
