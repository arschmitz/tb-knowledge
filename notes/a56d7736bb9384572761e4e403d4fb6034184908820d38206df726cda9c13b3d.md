# Hovered URL display encodes five additional directional controls after UI unescaping

setOverLink first unescapes a nonempty URL for UI, then percent-encodes the matched directional controls. The patch adds U+061C and U+2066–U+2069 while preserving U+200E/U+200F and U+202A–U+202E. The result is written to the visible status bar or fallback status panel; the location-change caller clears it with an empty string. This is the exact display path, not navigation rewriting or a complete spoofing/security guarantee. The restricted primary keeps the source study at zero full-audit credit.

Scope: Mail status hovered URL rendering.
