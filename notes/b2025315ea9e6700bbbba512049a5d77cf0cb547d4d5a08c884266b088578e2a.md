# The connection-alert test waits for a mock signal before reading the alert

promiseShown resolves without an alert value. It returns an already-resolved promise if an alert is stored, or a deferred promise that showAlert resolves after storing the alert. The repaired test therefore awaits that signal and then reads MockAlertsService.alert. reset clears state and rejects unfinished deferred scenarios. This establishes test/mock completion, not session cleanup, native notification rendering or a measured intermittent-failure fix.

Scope: Get Messages mock alert completion.
