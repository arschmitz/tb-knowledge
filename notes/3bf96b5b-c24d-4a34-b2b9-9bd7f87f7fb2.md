# Let the IMAP server own the login lock

Concurrent IMAP protocol threads can try an obsolete saved password together and lock the account. The incoming server owns a logon monitor and runs the full login callback under it. The lock is explicit and scoped per server, avoiding a shared monitor key that previously caused shutdown deadlock.

Scope: IMAP login.
