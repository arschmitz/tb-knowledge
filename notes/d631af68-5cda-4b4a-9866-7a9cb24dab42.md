# Delegate nested message delete commands before prompting

The May front-end confirmation patch prompted in about:message and then delegated to the about:3pane parent, which prompted again when the message pane held focus. The later accepted fix delegates first, then confirms only in the controller that executes the delete. It added a focus-on-message-pane Shift+Delete test and was uplifted to beta and ESR 128. Use this later order when reviewing nested command handlers.

Scope: message deletion confirmations.
