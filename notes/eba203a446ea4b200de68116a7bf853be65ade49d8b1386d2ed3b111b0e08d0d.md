# Use ESR, beta and release URL suffixes explicitly

660 adds esr to the Flatpak ESR release-note URL. Current keyed configuration uses an esr suffix for comm-esr.*, a beta suffix for comm-beta and no suffix for the default release route. Stable/beta Flatpak branch selection is a separate keyed value. Build metadata and a packaging channel are not sufficient to derive a release-note URL by blindly appending beta. The static config was inspected; remote release-note pages and a Flatpak package were not checked.

Scope: Flatpak release-note routing.
