# Exchange advanced configuration captures selected settings before backend creation

The Exchange type subview emits advanced-config from the subview when its advanced configuration button is clicked. The parent captures the current state, fills AccountConfig variables, asks for confirmation and awaits backend account creation before opening Account Settings. The initial integration test selects EWS with passwordCleartext and checks the resulting stored fields. The accepted test later selects OAuth2; this does not turn the original case into a token-flow test. This is a static source and test-contract finding; no account or authentication operation ran.

Scope: Account Hub Exchange setup.
