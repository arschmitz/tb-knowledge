# Keep registered MV3 scripts across background termination, then clean up on extension shutdown

Bug 1896907 moved compose and message-display script registrations from a background context local Map to gExtensionScripts keyed by extension, with IDs built as type plus ID. Closing the background no longer unregisters scripts. Non-app extension shutdown destroys the scripts and deletes the map entry. This preserves injection when a Manifest V3 background wakes again, while avoiding registration leaks after an extension ends. Current code retains this map and shutdown cleanup.

Scope: Extension scripting API.
