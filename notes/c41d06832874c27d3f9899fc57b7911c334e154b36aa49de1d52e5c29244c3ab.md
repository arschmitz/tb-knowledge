# Audit enumerated Fluent-ID comments against real resource names

The accepted XMPP source lists dynamic Fluent variants in comments, which can help find generated IDs. It also retains a typo remove-non-member-you-actor and lists non-member IDs under the muc-shutdown branch. The actual resource has removed-non-member-you-actor and only the inspected unsuffixed muc-shutdown string. Proposed rule: compare listed IDs and supported suffixes with the resource during review. These retained mistakes are uncertainty to fix or test, not evidence that the misleading comment spelling is a convention.
