# Skip the audio probe for the package condition rather than all Windows diagnostics

about:support skips its round-trip latency probe when the platform is Windows and hasWinPackageId is true. macOS still requires authorized microphone access; other cases call the probe. Device information remains separate. Required Bug comment6 and review remain unavailable/unread in this specification, so this is source-only with zero full-audit credit. No native audio or MSIX test ran.

Scope: Package-aware audio diagnostics.
