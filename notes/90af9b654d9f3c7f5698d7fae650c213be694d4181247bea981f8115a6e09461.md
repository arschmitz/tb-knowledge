# Match runtime icon lookup with shipped resource paths

560 searches beside the installed executable in chrome/icons/default and prefers TB-symbolic.svg on GNOME-derived desktops. 569 adds SVG files to the Unix package manifest and allows the duplicate symbolic asset; its commit says Daily did not ship that asset and the tray icon was broken on GNOME. The current locator still canonicalizes the runtime path and can fall back to a theme name. A checked-in SVG is insufficient unless the packaging manifest installs it at the requested case-sensitive name. No installed Daily or GNOME environment was tested.

Scope: Tray packaging breakage.
