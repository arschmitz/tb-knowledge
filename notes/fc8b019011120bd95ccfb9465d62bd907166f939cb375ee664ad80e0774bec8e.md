# The attribute port has different later primary-selector and browser-flag phases

The owned port changes subject-column CSS from primary=true selectors to attribute-presence selectors and changes selected markup to primary=primary. Accepted CSS on all three platforms and the chat tree later use the literal true form, while the message browser still declares primary=primary with nodefaultsrc and forcemessagemanager name values. Keep those exact receiver/source phases separate. This comm evidence does not define an engine-wide Boolean rule or prove restored layout/accessibility.

Scope: Thunderbird primary and browser attribute port phases.
