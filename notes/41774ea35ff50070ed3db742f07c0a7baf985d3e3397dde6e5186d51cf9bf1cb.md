# The crypto header keeps its label and icons in one unwrapped row

The fixed message header applies white-space: nowrap to crypto-label and makes crypto-button a row flex container with nowrap, centered items and a 3px gap. The native HTML button contains the label span and signed/encrypted image children inside cryptoBox. This scopes the long-subject wrapping fix to that control. The historical XUL-era hidden-button display override is absent from the fixed CSS, so it is not current guidance. The review proposed both flex styling and a cryptoBox block change; the inspected landing applies the flex styling but does not apply the block suggestion. No visual, localization, zoom, contrast or accessibility-tree check ran.

Scope: Message security header layout.
