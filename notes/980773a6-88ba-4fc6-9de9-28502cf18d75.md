# Prefer an early return to an else branch after recovery in grouped-view code

D209662 requested “No else after return please” during the grouped-view crash fix. The accepted 2024 code returns immediately when the group is invalid, then handles the normal child-count cases without wrapping them in a recovery else branch. Apply this small control-flow convention when a guard fully exits, while preserving later else branches that select different live cases. The review also asked for the index proof after the base deletion call; style did not replace that correctness check.
