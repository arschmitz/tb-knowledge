# Local search separates callback deferral, adapter lifetime and timer reuse

The failure path queues OnStopRunningUrl with a strong listener reference. Search also holds its adapter alive until the invocation returns. StartTimer separately reuses the timer, reinitializes it and invokes its first callback directly. These are distinct protections, so deferring one callback does not replace the adapter reference or timer ownership. Parse completion can skip a failed scope before resuming. The native reinitialization guarantee is stated by a source comment, not independently tested here. No crash, timer or search run was performed.

Scope: Local folder search lifetime.
