# Format calendar ranges with the same timezone adjustment as single values

1116 adds timeZone: undefined for floating/date-only values and UTC for fixed timezone values after adjusting the JS Date by the calendar offset. That avoids applying the host timezone a second time when formatRange handles a fixed calendar value, including timezone IDs Gecko may not recognize. Both range APIs keep this policy in accepted source. Missing start/end cases use single-value formatting; the range option is based on the start date, so mixed endpoint timezone policy is not established by this change.

Scope: Calendar adjusted date range timezone policy.
