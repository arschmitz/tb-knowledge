# Current feedback service progress deduplication is separate from the UI truthy guard

Accepted reportProgress drops an unchanged percentage and a direct 0-to-100 step, then sends to the most recent window. The inspected UI consumer checks event.data.progress by truthiness, so zero does not pass that particular branch. Preserve this as an observed local boundary, not proof that all progress consumers ignore zero or that runtime progress is broken. This is static source and test-code inspection.
