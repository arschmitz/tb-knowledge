# The theme icon tests distinguish custom themes from built-in theme expectations

The shared helper tests custom dark/light themes separately from built-in dark/light and default. At this landing, light custom uses the dark icon, while built-in light and default use the default icon. Callers supply separate16/32 theme icon paths and the helper asserts actual computed listStyleImage. Accepted source later changes built-in/default expectations, so the historical matrix must not be described as unchanged current behavior. No theme or DPI test ran.

Scope: Extension theme icon test fixtures.
