# Ownership metadata keeps communication groups separate from review groups

The YAML stores group URLs and review_group names separately, and the Markdown export renders separate Group and Review Group rows. Import also uses the explicit nobody owner alias, producing a Nobody row instead of an absent-owner warning. These data fields describe scoped roles; the placeholder is not a newly assigned person and the stored review group is not proof of automatic enforcement.

Scope: Thunderbird MOTS metadata and generated docs.
