# Keep observer lifetime and lock cleanup visible in the folder-repair integration

The inspected about3Pane code registers and removes folder-needs-repair with its other observers. FolderCommands returns for a locked folder and uses a finally block to release the local-mbox repair semaphore. A scoped recommendation is to keep these lifetime and cleanup paths beside the repair operation. The sources do not prove that every error path or headless caller reaches an open about3Pane observer. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
