# Reset Calendar navigation once per route

The local Bug 2061760 update uses D338959's shared navigation row and subview.
Two lifecycle checks were needed when replacing the old Description controls.
These are observations for this dialog, not new shared instructions.

The subview manager sets its current view before it dispatches `subviewchanged`.
A listener can replace the event route during Back navigation. At that point,
the manager already reports the main view, but focus can still belong to the
old Description textarea or the subview's shadow Back host. The route-clear
hook must account for those controls when it restores focus.

The source mixin also clears the route on every `close()` and disconnect.
Existing CreateSave test cleanup calls `close()` again after closing the tab.
Replacing custom elements again at that point can run their constructors in a
document whose scripts are disabled. The update checks whether a navigation
route still needs cleanup, clears that callback, and replaces controls once.
A stale but present callback still needs cleanup, so its presence is checked
without calling it.

## Evidence

- D338959 diff 1428217 supplies the shared navigation and subview contracts.
- Local Description fixup `e6c27df2e36415f9c267fd57faa8ca7f5cd8ddbd` adds
  `this.#descriptionSubview.contains(document.activeElement)` and captures
  `const hadRoute = !!this.#isNavigationCurrent` before clearing that field.
- The Back route-replacement test failed before the containment check and
  passed after it. Fourteen teardown exceptions at the two `cloneNode` calls
  disappeared after navigation reset became idempotent.

## Validation and limits

An independent source check matched the changes to the source mixin, manager,
and test cleanup calls. Eight headless browser files produced 1,092 passing
checks and nine failed assertions. All navigation, focus, route replacement,
and first-open localization checks passed. Five remaining failures report the
shared Save button's macOS contrast; four report unchanged title-length checks.
The update does not claim a green related suite or a landed upstream fix.
