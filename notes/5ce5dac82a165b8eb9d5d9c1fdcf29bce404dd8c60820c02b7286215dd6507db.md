# Hide whole-folder mark-read for filtered virtual folders

The folder menu accepts real folders and virtual folders with searchString "" or "ALL". It hides Mark Folder Read for a filtered virtual folder because this command iterates the underlying searchFolders and marks whole folders read. The active view command is a different path. The temporary database wrapper is cleaned up in finally.

Scope: mail/base/content.
