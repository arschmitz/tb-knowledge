# Gate the Windows MAPI generated-code directory for compile environments

mapihook/moz.build adds build only when COMPILE_ENVIRONMENT is true. The build directory owns the MIDL GeneratedFile outputs and exports; public and src stay in the directory list. The landing reports that an upstream make/export change caused unnecessary msgMapi.idl compilation during localization repacks. Preserve the narrow build-directory guard rather than disabling all MAPI files. The reported cause comes from the commit message; no localization repack or failed build log was inspected. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: MAPI localization build graph.
