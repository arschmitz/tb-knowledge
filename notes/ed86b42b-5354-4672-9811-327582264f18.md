# Use DOM key names and assert prompt text in new browser tests

D208902 review asked new keyboard tests to use modern DOM key descriptors such as KEY_Delete instead of VK_* descriptors. It also required checking the displayed confirmation text; the accepted patch introduced a helper around promiseAlertDialog to check message content and then press the chosen button. The test names describe behavior, such as test_shift_delete_prompt and test_delete_from_trash_prompt. This is a reviewed syntax and test practice, not a formatter rule.
