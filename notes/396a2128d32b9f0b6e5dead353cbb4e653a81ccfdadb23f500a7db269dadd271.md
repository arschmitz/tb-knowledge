# The archive hierarchy preview mutates a visual HTML simulation and keeps identity persistence separate

The HTML archive example is a visual simulation. updateArchiveExample hides levels, toggles children classes and reparents sample Inbox/sibling/child nodes for keep/recreate choices. Loading and accepting separately transfer three settings to the supplied identity. Backend archiver tests do not instantiate this preview. Shared tree styles and role=tree do not by themselves prove keyboard or accessible-tree behavior; no dialog test ran.

Scope: Archive options preview state.
