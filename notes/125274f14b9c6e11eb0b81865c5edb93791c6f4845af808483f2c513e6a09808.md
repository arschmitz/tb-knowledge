# Message-channel handle setters reject parent-process storage

The base mail, IMAP mock and Exchange message channels store the handle in a RefPtr only when the setter is outside the parent process. Parent calls return NS_ERROR_NOT_AVAILABLE before assignment. Getters return an added reference to the stored value. These are checked source ownership/guard paths; paired Gecko callers, handle internals, native behavior and the stated leak rationale were not independently verified.

Scope: Mail message-channel process-handle ownership.
