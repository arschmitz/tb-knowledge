# Link actors derive source context separately from the destination mail window

The link parent uses its actor browsing context and top embedder browser to obtain source metadata for a new tab. It no longer resolves a context ID sent in the child payload. LinkHelper then chooses the most recent mail:3pane window and forwards those parameters into contentTab. Source context and destination-window selection are separate steps. Accepted later principal/CSP/phishing handling is distinct from the original ID-removal patch. No navigation or security test ran.

Scope: link-click-window-actors.
