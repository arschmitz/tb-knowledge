# The oversized-ZIP smoke test waits for a notification without checking the exact error

The importer rejects a selected non-directory whose fileSize exceeds 2147483647 before it calls _showItems. The large-ZIP test uses the sparse fixture but only waits until the error-notification box has a child. That checks a visible error path, not the exact oversized-ZIP error ID/text, the boundary at 2147483647, valid archive parsing or migrated profile data. No import or filesystem test ran.

Scope: Profile ZIP rejection test coverage.
