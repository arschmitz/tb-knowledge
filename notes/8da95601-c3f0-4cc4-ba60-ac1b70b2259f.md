# Test registered scripts through background sleep and wake

The compose and message-display MV3 tests register on runtime.onInstalled, wait for Installed and Ready, terminate the background, then open a new compose window or load a message. The registered script still injects, sends a runtime message, and wakes the background; tests wait for both ScriptLoaded and Ready before asserting content. Re-registering blindly on each wake throws because the script remains registered. This test covers lifecycle behavior that a simple registration test misses.

Scope: Extension scripting tests.
