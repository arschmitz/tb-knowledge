# Preserve manifest-specific raw output defaults and the generated decrypt limit

getRaw defaults to BinaryString in manifest version 2 and File in version 3. Its File conversion explicitly narrows the binary string into bytes and labels it message/rfc822. Numeric source IDs read the existing message; a MessagePart source reconstructs generated.eml. The generated branch still warns that decrypt is not supported, while the existing-message branch invokes the decryptor and maps its failure. Keep these source kinds separate when documenting errors and capabilities. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/raw-output-source-kinds.
