# The shared tray quit message moves from a Fluent attribute to a value

The new system-tray-menuitem-quit is a message value with platform-specific Exit/Quit text. Windows reads that value with LocalizeMessage, and the Linux tray reads message.value before formatting. The migration copies the old system-tray-menu-quit.label pattern to the new value; its archived body is identical. This is a coordinated consumer/resource change, not a global Fluent convention or an executed translation/native menu result.

Scope: Native and Rust tray quit localization.
