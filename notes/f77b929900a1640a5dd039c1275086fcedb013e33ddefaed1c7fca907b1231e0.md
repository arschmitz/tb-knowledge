# Describe cross-compilation by target, worker tools and artifacts separately

667 adds debug and opt Windows Arm64 jobs built with Linux-side Rust/Clang/Wine tools and architecture-specific mozconfig values. The opt job enables signing and full crash symbols; debug enables full crash symbols. Current jobs use a mozconfig object and fetch winappsdk-aarch64-pc-windows-msvc, rather than the historical extra-config mozconfig_platform field and UPX fetch entry. A Windows target label does not mean the worker executes natively on Windows. No graph generation, toolchain fetch or Arm64 artifact test was run.

Scope: Windows Arm64 task graph architecture.
