# Give unit-only menus and number-bearing labels different Fluent messages

The calendar duration menu messages use a count selector but return only the unit word. The count-bearing messages are separate. Label messages refer to the menu message .label through their own .value attribute. This avoids formatting a count-bearing string then stripping the number. Keep message names and attribute targets aligned with the DOM node type.

Scope: calendar/locales/en-US.
