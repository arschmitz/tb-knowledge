# Distinguish printable creation text from the signature timestamp

The producer records signature creation seconds in keyCreated and formats created using new Date(keyCreated * 1000). SigListView copies created and returns it for sig_created_col. A local documentation recommendation is to keep the timestamp unit and display-string type explicit when changing these fields. The displayed creation text is not a raw numeric timestamp, and this observation does not prescribe a new time-storage format. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: OpenPGP time data.
