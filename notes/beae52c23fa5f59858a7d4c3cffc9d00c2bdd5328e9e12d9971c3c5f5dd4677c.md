# The UID utility tests cover null-flag-state formatting, not clipping or key-storage separation

The patch changes helper signatures and locals to the ImapUid alias and adds five format/parse cases. Every formatter call in the new matrix passes nullptr, so it checks ordinary ranges, descending input and unchanged count without testing flag-state gap bridging or long-set clipping. Real protocol callers pass m_flagState and advance by the returned count. ImapUid remains an alias; this landing does not establish independent UID storage. The original second test targets the overlapping key formatter and leaves reverse input disabled. The accepted suite name and later UidSetFromUids cases are separate phases. All four original ASSERT_EQ sites lack messages, including the count check with only a nearby comment. No test ran.

Scope: IMAP UID string helpers and gtest contracts.
