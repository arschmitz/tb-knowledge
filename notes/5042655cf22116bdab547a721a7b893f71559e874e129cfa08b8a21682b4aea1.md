# A reproducible Thunderbird locale merge pins Gecko and comm strings separately

The current local helper reads the locale revision from Gecko browser/locales/l10n-changesets.json and comm mail/locales/l10n-changesets.json separately. It clones the Firefox and Thunderbird Git strings repositories, checks out each pinned revision, and merges only the declared Gecko and comm directory patterns. Missing project or locale revisions fail explicitly. checkout uses an argument list and appends ^0 to resolve the supplied revision as a commit. Manual maintenance proposal for this helper: preserve both pins and pattern sets when changing repository hosting; checking out the latest default branch for both repositories would change the requested snapshot. This does not claim that every release locale uses a distinct Git revision.

Scope: localization.
