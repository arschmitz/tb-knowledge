# The new grouped-date query helper omits an assertion message

Ten insertion cases call the new shared checkDateGroup helper, whose Assert.equal compares the actual SQL group with the expected group but has no message argument. The separate SQL-function helper already reports the input and expected group in a nonempty should message. Keep those diagnostics distinct from the actual added coverage: representative groups and grace-period cases are checked, not exact half-hour equality, DST or a fresh intermittent cure.

Scope: Panorama grouped-date test diagnostics.
