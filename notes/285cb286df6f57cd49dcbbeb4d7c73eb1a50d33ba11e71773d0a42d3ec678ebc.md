# Debian app and language-pack rules exclude XPI archives from nondeterminism stripping

Both current Debian rules files override dh_strip_nondeterminism and pass -Xxpi. The initial landing and reland include this exception in both package families. Preserve the exception when editing package rules; it is a functional packaging choice rather than whitespace style. The source does not state the exact failure it prevents or prove all XPI transformations are forbidden. Bugzilla and review context are still needed for that rationale. Manual review proposal for these make rules: check corresponding app and language-pack behavior together and explain an exception where evidence supplies its reason.

Scope: debian-xpi-rules.
