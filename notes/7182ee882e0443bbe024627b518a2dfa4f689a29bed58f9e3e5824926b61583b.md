# Unresolved button focus token

The AI review record for D336388 at revision 938178e96fcd54acd48300758465d6feb76b68c9 reports that an undefined --color-bolt-pressed token overrides the shared button focus outline. It reports a Thunderbird experiment in which replacing the declaration with outline: var(--focus-outline) restored a solid 2px outline in light and dark modes. When extending these shared button variants, check token definitions and keyboard focus. This is a reported experiment, not independently supplied test evidence; the record has no human feedback or landed outcome.

Scope: Shared button focus styling.
