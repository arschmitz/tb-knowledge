# Correct the documentation offset file without weakening the opaque token contract

The current storage document says the mbox storeToken is an offset from the database file. The pluggable-store interface instead says it is an offset in mbox, and the implementation uses the folder mbox file and commits its file position as the token. A scoped documentation correction should name the mbox file. Callers must still treat the token as opaque and folder-specific; the existing token-join lesson is reused. No parser or runtime defect is inferred from the prose error. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Folder storage documentation offset.
