Scope: production Gecko C++ and inline headers; Web Platform Tests (WPT).

Thunderbird boundary: calendar/base/src/CalReadableStreamFactory.sys.mjs:235–307
constructs ordinary ReadableStream with JavaScript source objects. Gecko constructor,
ReadableStream.cpp:165–248, converts actual underlying source dictionary, chooses
default controller unless type=bytes, and uses default highWaterMark=1 plus
default size=1 per queued chunk. Calendar enqueues array chunks, so native default

Setup493–585 connects stream/controller/algorithms, resets queue, marks not-started,
not-closing/not-pulling, saves strategy, runs source start with controller, and
resolves its return through a promise. Start fulfillment sets started and checks
pull demand; rejection errors the stream. The completion callback owns a RefPtr
to controller. Source start completion is distinct from all queued data consumed.

ShouldCallPull377–407 requires readable/non-closing and started, then pending
reader requests or desiredSize>0. CallPullIfNeeded432–490 starts one pull promise
and sets pulling. A second demand while pulling sets pullAgain instead of invoking
another overlapping pull. Fulfillment clears pulling and schedules the saved
demand; rejection errors stream. The callback algorithm is obtained from actual
controller field, not resolved by the name pull alone.

Enqueue252–350 directly fulfills a waiting default reader; otherwise calls actual
size callback or uses1, validates/enqueues and updates total. Size callback or
queue validation exception errors stream with the same JS error, then rethrows.

rejects NaN/negative/infinite chunk sizes, owns each value with an auto-clean list,
dequeues through a UniquePtr and clamps negative rounding residue to0. JS values
are traced by controller cycle collection; unlink/destruction clears queued nodes.

DesiredSize161–180 is null when errored,0 when closed, otherwise highWaterMark
minus queueTotalSize. Public Close234–243 throws for invalid state; internal close

only with empty queue. Remaining queued chunks drain before closing. PullSteps

drops size callback. ReleaseSteps655–657 itself does nothing. Reader release

not be confused with controller close or source cancellation.
