# Validate tag keys before exposing virtual tag folders to extensions

folders.getTagFolder accepts a registered tag key, rejects unknown keys distinctly from a missing virtual folder, and returns either the converted MailFolder or traversed subfolders. The first landed version used SmartServerUtils.getTagFolder and a minimal browser test, but virtual tag folders were then created only when the user enabled Tags folder mode. The immediately following SmartMailbox extraction removed that UI prerequisite. When implementing an extension API, verify its data exists before any view is opened; do not preserve the first patch’s UI dependency.

Scope: WebExtension folder API.

Paths:

- `mail/components/extensions/parent/ext-folders.js`
