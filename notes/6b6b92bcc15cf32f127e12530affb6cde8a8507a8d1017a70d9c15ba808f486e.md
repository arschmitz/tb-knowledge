# Propagate a Panorama message lookup error before reading its result

Historical MessageDatabase::GetMessageFlag in 2069/2070 calls GetMessage but ignores its nsresult before reading the returned fields or pointer. GetMessage returns an error for a missing row without filling the output, so callers cannot safely treat that result as an initialized header. This is a static error-contract risk; no crash was reproduced. The fixed accepted GetMessageFlag calls GetMessageFlags through MOZ_TRY before reading flags, and GetMessageFlags propagates EnsureCached failure. Preserve that newer error path. The compatibility tests check missing membership and cross-folder header retrieval, but do not test a missing-key flag getter in this landing. Proposed coverage is a missing or removed key and an injected lookup/storage failure. No native test or SQL failure experiment ran.

Scope: mailnews Panorama flag lookup error contract.
