# Distinguish ancestor state from same-element classes in nested CSS

The manual form rules use .stacked & for an ancestor state, &.responsive-row for the current row class and & .expanded for a descendant. Recommend retaining those distinct selector forms when extending this local nested stylesheet; adding or removing the space changes the matched relationship, not only formatting. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
