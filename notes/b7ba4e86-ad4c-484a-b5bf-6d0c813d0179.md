# Toolbar customization documents must load Fluent resources for their controls

Compose toolbar customization produced missing-message errors for text actions, signing, and receipt controls. Adding toolkit/global/textActions.ftl and messengercompose.ftl links in customizeToolbar.xhtml fixed the missing resource bundle; current document retains them alongside additional later links. When adding a localized control to a separate customization window, check that window loads the Fluent file and verify the console for missing-message errors.

Scope: Compose toolbar localization.
