# Match MIME line callback types instead of hiding mismatches with casts

Entry 826 replaces char*/unsigned-length/void* line callback casts with const char*, int32_t and MimeObject* signatures. Accepted mimebuf.h and mimebuf.cpp still agree on those exact types, and MimeObject passes its parse_line method directly. Preserve declaration, implementation and caller agreement together. The separate parse_buffer interface now takes MimeClosure; do not assume every MIME callback has the same closure type. No sanitizer or build ran.

Scope: mailnews/mime/src.
