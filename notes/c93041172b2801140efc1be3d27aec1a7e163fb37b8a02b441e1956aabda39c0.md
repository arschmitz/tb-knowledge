# Check QR accessibility beyond decorative image markup

The current QR template uses figure/figcaption and an empty img alt, while labels name the native controls and localization supplies step/count text. CSS uses logical spacing and a pixelated bitmap with a maximum inline size. Those static facts do not establish that changing a code is announced, that focus moves appropriately between hidden sections, or that a keyboard and screen-reader user can complete export. Require manual checks for step announcements, focus after Next/Done/Back/Restart, zoom, RTL, contrast and phone scanning. The remote checklist and live accessibility tree remain unread.

Scope: mail/components/preferences.
