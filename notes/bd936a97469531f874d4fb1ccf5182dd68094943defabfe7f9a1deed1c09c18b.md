# The filter dialog starts its own run state before accepting global feedback

FeedbackService broadcasts status and meteor messages to every window. The original filter-dialog fix starts gRunningFilters in runSelectedFilters and returns from the message handler while no local run is active. It also resets the progress-visible flag on stop. The accepted comparison later clears run state in the filter operation callback and recomputes button eligibility with updateButtons. The guard excludes idle feedback; it does not identify which operation sent a message during an active run.

Scope: Filter dialog run-state and feedback ownership.
