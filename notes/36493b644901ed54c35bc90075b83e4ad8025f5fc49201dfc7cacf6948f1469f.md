# Graph creation completes after create, optional move and flag update

The Graph helper first creates a message from base64 MIME content. If a folder is supplied, it moves that message and returns its replacement ID. DoCreateMessage then PATCHes draft/read flags before its success callback returns the ID. A failure can occur after an earlier remote stage changed state; the scoped operation has no compensating deletion. The shared listener forwards success status and ID, or failure status and an empty ID. This is source sequencing, not real-account creation or a failure-injection result.

Scope: Graph message-creation stages and callback.
