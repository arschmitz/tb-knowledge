# Keep version-specific MailFolder shapes explicit in the schema

The schema defines MailFolder choices with max_manifest_version 2 and min_manifest_version 3. Manifest V2 retains optional fields because its folder objects also served as partial input objects; Manifest V3 has more required result fields and uses MailFolderId inputs. accountId remains optional for unified and tag folders, and subFolders remains optional when not requested. The 715 commit explicitly calls this a schema/documentation cleanup, while 716 changes actual absence behavior. Do not infer a runtime change merely from fewer optional annotations.

Scope: mail/components/extensions.
