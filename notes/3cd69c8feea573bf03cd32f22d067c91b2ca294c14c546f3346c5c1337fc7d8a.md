# Use explicit values for forwarded validation options

The Bug 2084433 report records two command-line failures: commlint's optional -W argument consumed the first file path, and a separated --verify-max-time 90 argument caused 90 to be treated as a test path. The reported successful forms were -W soft and --verify-max-time=600. These are useful invocation details for the recorded mach wrappers; verify current parser behavior before treating them as universal command syntax.

Scope: Thunderbird validation commands.
