# Pending IMAP pseudo or offline work can defer compaction

Current CanCompactNow rejects folders with pseudo headers and folders whose offline-operation table has a row. HasPseudoActivity checks the pseudo map count; HasOfflineActivity checks whether its cursor obtains a row. These are separate forms of in-progress IMAP work. Preserve both checks before scheduling this compaction family; neither is a general folder semaphore or universal network-idle test. No pending-operation scenario was executed. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: IMAP compaction activity guards.
