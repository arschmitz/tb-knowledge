# Preserve missing-versus-reset semantics in spaces updates

Spaces Manifest V2 uses empty strings or arrays for resets, and the update implementation ignores null values produced for absent optional inputs. Manifest V3 uses omit-key-if-missing so absent keys preserve state and explicit null requests a reset. The update code clones the old properties before applying supplied entries. The 729 schema reorganization is cosmetic and preserves this contract. Do not replace it with a broad null-coalescing assignment that loses explicit reset requests.

Scope: mail/components/extensions.
