# Separate Account Hub DOM IDs from classes and localization IDs

D229061 requests camelCase DOM IDs, ID-first attribute order, native buttons and the shared link-button style in the success template. The fixed template uses accountHubEncryptionLink/accountHubSignatureLink while classes and Fluent IDs remain hyphen-separated. Treat these as the inspected Account Hub markup families; preserve stable localization/public identifiers and do not export one naming form to all languages or components. The review calls the hyphen-separated family snake-case; the actual checked spellings establish the form. No visual or accessibility test ran.

Scope: Account Hub markup naming example.
