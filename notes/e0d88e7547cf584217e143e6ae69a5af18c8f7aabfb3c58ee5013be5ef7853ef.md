# Enable Mark Read By Date from folder unread state

cmd_markReadByDate and cmd_markAllRead share folder-level availability: a real view folder with unread messages. They do not require a selected message. Keep command names and callers consistent across menu/context/keyboard surfaces. Current menu tests cover later read-only and synthetic view cases; historical mail-context review did not test empty selection because that popup cannot open without selected messages.

Scope: mail-commands.
