# Partial-message replacement matches Message-ID and transfers a strong reference

Accepted RetrieveHdrOfPartialMessage searches mDownloadPartialMessages for the first matching Message-ID, forgets that strong reference into the output and removes the matched array entry. The member is nsTArray<RefPtr<nsIMsgDBHdr>>. Preserve this ownership transfer and first-match behavior; Message-ID here is not the POP3 UIDL used to request the body.
