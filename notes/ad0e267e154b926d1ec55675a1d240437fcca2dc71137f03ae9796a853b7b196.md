# Opaque S/MIME display coverage checks rendered text rather than signature status

The added display test opens four opaque signed or signed-then-enveloped fixture names in sequence and checks for the Alice-to-Bob sentence in document text. It does not directly check HTML structure, exact line endings or signature validity. local-gen.sh adds copy steps for three missing browser fixtures, while the manifest packages data/**.
