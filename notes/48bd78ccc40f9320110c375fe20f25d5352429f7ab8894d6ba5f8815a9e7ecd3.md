# Account Hub footer fixtures use the widget’s central anchor handler

The fixture update removes inline openLinkExternally calls and adds the missing localized Privacy link to the address-book footer. Both fixture load paths register AccountHubFooter, whose click listener handles anchor targets centrally and prevents default navigation. This is fixture parity with the existing widget contract; the changed markup does not prove external launch, keyboard behavior or link accessibility.

Scope: Account Hub footer test fixtures.
