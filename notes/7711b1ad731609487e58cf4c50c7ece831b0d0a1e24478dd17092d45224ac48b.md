# The original generated navigation getters require object or array values despite nullable descriptions

The initial expansion landing adds map-backed navigation getters that return NotFound when the field is absent and UnexpectedResponse when its JSON value has the wrong object/array shape. User collection descriptions can say Nullable while the getter returns a required Vec; JSON null reaches the shape-error branch in that historical representation. Nested values borrow the map, while setters own inserted objects and explicitly disclaim Graph writability. No direct getter/null test is added. Later accepted owned-struct serialization is a separate phase; this does not establish server behavior.

Scope: Historical Graph navigation-property map access.
