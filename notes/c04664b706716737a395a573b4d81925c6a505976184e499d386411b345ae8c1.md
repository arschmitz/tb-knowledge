# Perform NNTP channel security checks before creating an unknown server

The constructor finds an existing server but does not create one for an unknown host. asyncOpen calls the content security manager, then rejects carriage return, line feed or NUL in the parsed message ID, group name or article number. Server creation is delayed until _readFromServer. Preserve this order when changing URI handling: creating server state in the constructor would move that side effect before the channel security check. The two URI forms and missing-port handling are part of the same boundary. Current source was read; no malicious-URI test or live server creation was run. This supplementary source check does not complete the later historical security patch or its review.

Scope: mailnews/news.
