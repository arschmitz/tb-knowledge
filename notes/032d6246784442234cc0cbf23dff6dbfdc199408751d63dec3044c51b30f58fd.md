# The OAuth test login helper waits for its dialog to close before resolving

handleOAuthDialog creates the close promise for the observed OAuth window before submitting the test login, then awaits it after the submit operation. Its callers therefore wait for that close boundary before later message checks. This is a test-lifecycle ordering change; window close does not prove authentication success, and the intermittent alert failure was not reproduced or diagnosed.

Scope: Thunderbird get-messages OAuth test dialog lifecycle.
