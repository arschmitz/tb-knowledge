# Match release-note rules to release types and update channels separately

A product-details condition uses release-types, while a show-url rule can also constrain update-channel. In 2024, the ESR release type was esr128 rather than esr. Current source lists esr128, esr140 and esr153 while the corresponding show-url update channel is still esr. Use the condition field that owns the decision and preserve the current release family. The linked bug includes beta follow-up history, so the first manual report alone was not proof for every channel. No update-service request was tested by this study.

Scope: Update release configuration.
