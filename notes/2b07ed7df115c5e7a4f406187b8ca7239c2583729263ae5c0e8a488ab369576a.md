# Preference telemetry keeps reporting-list names and metric labels in separate files

This change adds privacy.globalprivacycontrol.enabled to the labeled Boolean metric schema; the reporting list already names that preference. The accepted MailGlue code reads the tracked Boolean value with a false fallback and sets the Glean label keyed by its name, then updates tracked values on preference changes. The schema label and reporting list are separate configuration points. This patch does not enable the privacy setting or establish a collected ping, backend bucket, or fresh telemetry result.

Scope: telemetry.
