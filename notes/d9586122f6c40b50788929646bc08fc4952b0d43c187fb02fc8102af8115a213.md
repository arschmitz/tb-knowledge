# Use a single decorative updater image for the selected panel state

Current about dialog has one img with id="icons" with role=presentation and empty alt. selectPanel sets its className to the chosen panel ID; CSS selects the corresponding image or hides it. Preserve textual status in the deck and do not add duplicate accessible descriptions for decoration. No accessible-tree or screen-reader check was run.
