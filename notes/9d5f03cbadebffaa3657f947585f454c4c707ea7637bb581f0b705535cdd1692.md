# Store primitive selection identity to avoid keeping message objects alive for a session

Bug 1902549 rejected saving header objects because the selection Map can survive for the session and keep dependent objects reachable. Current URI arrays preserve identity without retained nsIMsgDBHdr references. The author revised the initial claim that headers uniquely avoid thread expansion, so do not teach that false association. Expansion remains an explicit restore option. No memory or performance measurements were run.

Scope: mail/base/content.
