# Yield large POP3 and NNTP line responses without nested event loops

For long multiline responses, LineReader yields to the event loop after 1000 lines. The older spinEventLoopUntilEmpty path could stall POP3 LIST or UIDL processing until a server timeout. Making read async also required callers to handle resulting promise failures.

Scope: protocol line reader.
