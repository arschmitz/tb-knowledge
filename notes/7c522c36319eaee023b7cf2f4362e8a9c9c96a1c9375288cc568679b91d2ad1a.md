# CalDAV scheduling responsibility follows the action owner

adaptScheduleAgent acts only on CalDAV calendars that support automatic scheduling. With forceEmailScheduling it marks attendees CLIENT for an organizer action, or the organizer CLIENT for an attendee action, while preserving explicit NONE. Without the force option it removes matching CLIENT properties to hand responsibility back to the server. The accepted helper lives in cal.itip and callers invoke it before save or modify.
