# Parse mbox tokens at the backend boundary and check conversion status

Current mbox ChangeKeywords obtains the typed token, parses it with ToInteger64 and checks rv before seeking. Maildir uses its token as a cur/ filename and rejects an empty token. This supports a scoped implementation rule: keep interpretation inside the backend and validate conversion before byte access. It is not a claim that every migrated native caller checks every return; the historical MAPI path did not add equivalent conversion-status handling, and its runtime behavior was not established.

Scope: mailnews/local/src.
