# Taskgraph test-packaging checks allow missing tests for explicitly partial selections

The local packaging check records test-to-build dependencies before finalizing the graph. Shippable builds and builds with test dependencies require MOZ_AUTOMATION_PACKAGE_TESTS=1. A nonshippable build that packages tests without dependent jobs is rejected only when missing tests are not allowed. Target-kind selection, a nondefault manifest loader and explicit test paths or tags permit missing tests. The check describes graph consistency, not tests passing or running.

Scope: comm-taskgraph-test-packaging-selection-contract.
