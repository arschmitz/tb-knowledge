# Preserve installed SAX resource URLs when moving the vendored source

The SAX wrapper imports resource:///modules/sax/sax.js and exposes SAX through sax.sys.mjs. The vendor moz.build installs the wrapper in EXTRA_JS_MODULES and the library in EXTRA_JS_MODULES.sax; XMPP still imports resource:///modules/sax.sys.mjs. The physical move to third_party/sax-js must not be confused with a resource URL rename. The imported library body is excluded from Thunderbird style evidence. This source establishes packaging relationships, not a completed package or parser test run. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: SAX vendoring resource identity.
