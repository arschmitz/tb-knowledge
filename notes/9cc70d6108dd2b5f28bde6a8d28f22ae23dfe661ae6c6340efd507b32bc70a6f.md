# Release the undo reparse listener before continuing the internal undo

When the destination database is absent, the local undo path adds and manually references mUndoFolderListener while waiting for a database reparse. UndoTransactionInternal removes that listener, releases it and clears the pointer before continuing. The constructor starts the pointer at null. Preserve this reparse-listener boundary; it is distinct from the transaction object's own message-added listener. No reparse or undo operation was run.

Scope: mailnews/local/src.
