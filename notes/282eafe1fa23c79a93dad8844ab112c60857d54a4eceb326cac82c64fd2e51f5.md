# Use the shared mail-account enumeration boundary across extension APIs

getMailAccounts is the shared filter used by account tracking, folder queries, identity lookup, and message queries. Centralizing the mail-account boundary prevents each API from inventing a different account set. Current code excludes im accounts there. The old source comment also mentions excluding EWS, but the actual current filter does not; trust the implementation and inspect callers when reviewing that comment.

Scope: mail/components/extensions.
