# Related MIME output restoration starts after its callback snapshot

The EOF handler returns a negative superclass result before saving or overriding output callbacks. It then saves output_fn and output_closure and registers a scope guard before installing the related-part output wrapper. Later exits pass that restoration guard. The old shared FAIL label also handled the earlier superclass-error branch, so the rewrite has a concrete ordering difference and should not be described as unconditional runtime equivalence. The real_write consumer uses the saved callback state. This is public-source inspection only; no parser or failure scenario ran.

Scope: related MIME EOF cleanup.
