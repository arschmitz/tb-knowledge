# Table account-color indicators use a hidden server-key result and clear dummy-row state

This landing adds a serverKeyCol result when the account text column is visible, then sets that cell's --account-color reference from the escaped server key. Dummy rows remove the per-cell property before continuing. Base CSS leaves the pseudo-element hidden; the unified-view non-dummy selector displays it and the color has an inbox-token fallback. The changed test checks default and custom account colors through actual table cells and their pseudo-element computed background. This is static source and assertion coverage, without a browser run or general rendering guarantee.

Scope: Thread table account-column color state.
