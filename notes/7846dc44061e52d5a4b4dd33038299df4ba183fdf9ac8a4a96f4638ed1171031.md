# Large radio-card selection groups by form while later change dispatch is separate

Large radio cards select among every same-tag card in their containing form. The checked setter synchronizes aria-checked/tabIndex and clears checked peers; horizontal keys follow document.dir and vertical keys keep their direction. The original landing changes selection without dispatching change. Fixed source later adds bubbling change events for user selection, separate from programmatic setter calls. Direct tests cover selection state and later event targets; the Space test still lacks an assertion message. No native focus, form-submission or accessibility result is established.

Scope: Account Hub large radio-card selection and event phases.
