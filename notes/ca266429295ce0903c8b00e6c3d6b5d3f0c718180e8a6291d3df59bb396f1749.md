# MIME part selection stops using abbreviated query-name matches

This landing replaces the display parser's name-length prefix comparison with a named part lookup and activates the odd-URI body test that uses a separate p query key. The converter also receives the URI directly for its own output selection. These are scoped source and written-assertion changes; they do not establish full URL parser equivalence, every malformed-query behavior or a native test result.

Scope: MIME URL option parsing.
