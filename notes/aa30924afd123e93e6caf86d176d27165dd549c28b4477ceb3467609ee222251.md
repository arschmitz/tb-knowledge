# Calendar export currently parses title properties from serialized lines

At the fixed accepted revision, exportToStream adds NAME and X-WR-CALNAME only when title is truthy. It interpolates title into serialized property lines and passes each line to createIcalPropertyFromString. The property factory trims and parses serialized ICS text. A property value setter accepts an unescaped text value under a separate contract. These are static implementation facts. Assigning title through the value setter and adding special-title tests are proposed changes, not accepted practice or executed fixes. No exporter, parser, file-picker or data-corruption test ran. This observation replaces an earlier proposal that was incorrectly labelled supported because its primary evidence was a historical code snapshot.

Scope: calendar/import-export.
