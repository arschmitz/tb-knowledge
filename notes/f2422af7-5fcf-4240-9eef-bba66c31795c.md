# Resolve an omitted message display tab ID from the active tab tracker

messageDisplay.getDisplayedMessage and getDisplayedMessages accept an omitted tabId, matching mailTabs.getSelectedMessages. getMessageDisplayTab wraps tabTracker.activeTab through tabManager when no ID is given, then keeps the same message-load and tab-type handling as explicit IDs. The browser test selects a message in about:3pane and compares both API forms, including the returned message header. A public optional parameter needs both schema and runtime behavior, plus a test that checks equivalence.

Scope: WebExtension message display API.

Paths:

- `mail/components/extensions/parent/ext-messageDisplay.js`
