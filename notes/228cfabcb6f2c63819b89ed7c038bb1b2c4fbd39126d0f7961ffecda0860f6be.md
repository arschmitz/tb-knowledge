# Use the target row center when testing a child-folder drop

The 1959025 test repair sends dragover and drop at the target row center. The owned folder pane interprets center and edge regions differently: the center moves a folder into the target, while edges can reorder it. The test directly checks B becomes a child of C; it does not cover all reordering or assert the final persistent selection. The author suspects font-size differences explain local versus CI results, but this study does not establish that cause. Fixed geometry has later border/RTL changes. No browser test ran here.

Scope: Folder operation contracts.
