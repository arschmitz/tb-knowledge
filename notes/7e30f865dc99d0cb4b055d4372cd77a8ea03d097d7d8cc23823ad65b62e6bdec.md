# Name the notification event module after its exported class

Accepted notification code keeps the standalone event class in InAppNotificationEvent.mjs and exports InAppNotificationEvent. Its payload member is notificationId. This scoped file-naming pattern pairs the PascalCase filename stem with the exported class and uses the ordinary .mjs module extension. Follow that pair when extending this event-class family. The custom-element modules keep their separately documented tag-based filename family. Shared event-ownership lessons already cover the notification ID and primary-button checks; their behavioral claims are reused rather than republished here.

Scope: Notification event module naming.
