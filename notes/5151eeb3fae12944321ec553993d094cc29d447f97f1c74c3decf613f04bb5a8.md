# The string-boundary port routes ASCII previews through the existing UTF-8 helper

The owned historical patch removes the ASCII-only SetLength shortcut, so every overlong UTF-8 preview uses nsMsgI18NShrinkUTF8Str. The unchanged helper remembers the previous character start before forming its substring; that bounds the historical off-by-one concern without a runtime reproduction. The accepted later phase instead returns nsMsgI18NTruncateUTF8Str's bounded value and is kept separate from this initial port.

Scope: Message preview truncation.
