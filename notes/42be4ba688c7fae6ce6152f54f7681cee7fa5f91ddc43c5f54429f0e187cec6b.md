# Use logical dimensions in the accepted Account Hub layout

The newer accepted layout uses max-block-size, block-size and inset-block-start where the assigned landing used max-height, height and top. Proposed scoped syntax convention for new Account Hub layout changes: follow those logical dimensions and offsets when they express the same intent. This follows current code in these two stylesheets and does not establish a repository-wide prohibition on physical dimensions. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub logical layout properties.
