# The original Graph setters consume local JSON values without promising server writability

This landing adds empty constructors and must-use setters that consume self and return Self for chaining. The generator preserves nullable and collection argument shapes. It merges inherited properties into the flat JSON map, nests named objects and converts custom collections to JSON arrays. The same generator emits setters for read-only documented properties and warns that Graph may not expose them as writable. These methods construct local data; they do not validate a server write. Fixed accepted code uses later public typed fields and nested options instead of this PropertyMap API.

Scope: ms_graph_tb historical type construction and generator.
