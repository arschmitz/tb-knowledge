# Keep provider event routing and public argument order separate

The internal provider-search-request-UID event receives query before searchString, while fire.async converts the book node and sends searchString before query according to the public schema. ExtSearchBook is remote, read-only and has no stored card map; results arrive through the search callback. Keep routing UID, query expression and user-entered text distinct. isSecure is provider metadata, not proof that this layer performs or verifies encryption. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension provider event boundary.
