# The cookie policy port changes the test stimulus and keeps ordered completion waits

fake_profile_change now uses testCloseCookieDB and testOpenCookieDB rather than dispatching profile observer topics. It registers a cookie-db-closed observer before closing, waits and removes it, then does the same for cookie-db-read before resolving. The caller checks persistence only after awaiting that ordered sequence. This comm patch adapts the test; it does not contain or independently verify the engine shutdown blocker named in its title. No cookie database or policy test was run.

Scope: Enterprise policy cookie test.
