# The comm toolchain handler passes a typed schema subclass to its existing registration

CommToolchainRunSchema inherits the imported ToolchainRunSchema, declares the exact comm-toolchain-script literal, and annotates script as Optional[str]. The docker-worker handler registration consumes that class with toolchain_defaults. The local annotation has no default; compatibility of omitted keys, defaults and validation errors requires the matching external schema implementation. This comm source does not establish unchanged voluptuous behavior.

Scope: Comm taskgraph toolchain run schema.
