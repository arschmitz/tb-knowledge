# Keep dynamic element names, module filenames and package entries paired

Account Hub loads widgets by templateId, first checks customElements.get and then imports content/widgets/${templateId}.mjs. The registered account-hub-step tag, account-hub-step.mjs filename and packaged chrome path use the same kebab-case stem. Class AccountHubStep uses PascalCase; template accountHubStepTemplate.inc.xhtml and its ID use lowerCamelCase. This is a justified local naming map, not a repository-wide demand that every module use dashes. A misspelled state-table tag can break lazy loading even if lint accepts the string.

Scope: Account Hub file, class and template naming.
