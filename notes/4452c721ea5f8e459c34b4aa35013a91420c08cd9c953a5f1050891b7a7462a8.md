# Treat a send server URI as nsIURI; guard optional mailnews interfaces

In the 2024 EWS send work, a server endpoint URI did not implement nsIMsgMailNewsUrl. Use instanceof when the mailnews interface is optional; it exposes the interface, so a second QueryInterface is redundant. Current send callbacks pass serverURI and secInfo separately. Preserve real security context at the transport boundary; the historical review accepted missing secInfo only with a follow-up, not as proof certificate overrides worked.

Scope: message-send.
