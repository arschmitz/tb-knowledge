# Load the localization resource used by the minimonth in each host document

1112 adds calendar/calendar.ftl to both the timezone dialog and the minimonth's insertFTLIfNeeded calls. The widget uses week-title-label with a title argument when week numbers are shown; loading only calendar-widgets.ftl did not supply that message. Preserve both document and component resource ownership when adding a localized widget to another dialog. The current document still declares the resource. No Fluent runtime error was reproduced.

Scope: Minimonth host Fluent resource dependency.
