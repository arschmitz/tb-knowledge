# Keep imported SDK provenance and deliberate compatibility edits explicit

564 updates the bulk MAPIStubLibrary headers and records the exact upstream Microsoft revision. Its README separately documents lowercase filenames for cross-compiling, the intentionally removed MAPI.h and quoted includes in MAPIx.h. That lowercase rule is an imported-SDK compatibility constraint, not a naming rule for every Thunderbird C++ file. The upstream bodies were not fully read; README and selected ARM ABI changes were inspected. Do not use the SDK uppercase macro style or tabs to define Thunderbird-owned style.

Scope: Imported MAPI naming scope.
