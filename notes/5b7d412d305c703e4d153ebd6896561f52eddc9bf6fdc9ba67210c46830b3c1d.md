# Virtual junk deletion scans base folders and returns a target count before completion

The deletion helper recurses through a virtual folder’s searchFolders and deletes spam-scored headers from each physical folder. It returns their target count, not a deletion-completion promise. The added ALL-search test waits for completion on both base folders and checks their remaining counts; the virtual cached-total assertion stays commented. This does not prove arbitrary search subsets or immediate virtual totals. The test wrapper must forward the new folder argument. No deletion test ran.

Scope: Virtual junk deletion scope and completion.
