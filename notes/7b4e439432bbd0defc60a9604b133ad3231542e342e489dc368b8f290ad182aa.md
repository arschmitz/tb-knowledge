# The native Dock menu is owned by the hidden Mac document

The dock menu and handler script move from an ordinary messenger document to hiddenWindowMac. The handler initializes a native menu and gives it to the dock service. Dock Options waits for the preferences callback before opening its subdialog; current code calls openPreferencesTab directly. The promise describes callback completion, with separate reuse/closure limits, and does not establish measured leak elimination.

Scope: Mac Dock menu ownership and preferences opening.
