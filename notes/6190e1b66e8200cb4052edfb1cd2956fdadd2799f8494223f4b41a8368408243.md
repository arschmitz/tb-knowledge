# Address-book contact lookup checks an already populated per-book cache

After a global contact-cache miss, findContactById populates a missing per-book contacts map and then checks that map outside the population guard. A map that already exists must still be searched. The owned change fixes this loop; it does not change the separate bookHint branch or prove an end-to-end extension test result.

Scope: extensions/address-book-cache.
