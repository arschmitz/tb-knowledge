# Follow the actual address display preference fallback order

AddressFormatFunction first tries an address-book display name when condensed addresses are enabled and an email exists. It then chooses full address, email-only, name-only or a fallback from mail.addressDisplayFormat. Preference observers refresh cached values. This retained helper is a local formatting contract, with explicit TODOs for legacy first-sender and zero-recipient parity; it is not proof that every message-list path currently calls it. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama address display formatting.
