# EWS attachment URL permission must match the channel scheme

Bug 1973062 changes only the non-feed attachment allowlist from ews to x-moz-ews. Fixed ExchangeService maps ews-message to x-moz-ews for channel URIs, and the protocol handler registers that scheme. AttachmentInfo and message-header consumers use isAllowedURL to reject fetches, filter actions and disable Save All. Keep this exact producer/permission join when changing EWS attachment commands. Earlier URL parse, UNC host and feed gates remain separate. The MIME attachment URL producer and attachment runtime are outside this source check. Complete D254406 discussion is reconciled in the private audit.

Scope: EWS attachment command gate.
