# The new hp checks pass their diagnostic to Array.some instead of Assert.ok

Both new hp checks place the message string inside lines.some. That argument is Array.some's thisArg, while Assert.ok receives only the Boolean. The assertions therefore lack failure messages. Move each message to Assert.ok's second argument; the signed-only message must describe hp=clear rather than cipher. The accepted source retains both call shapes. This is a static diagnostic finding with no executed failure.

Scope: OpenPGP composition assertion messages.
