# The Exchange service URL step gates continuation on syntax and preserves endpoint discovery as a separate phase

This landing combines form validity with sanitized URL parsing and an explicit HTTP(S) guard. It emits config-updated.completed, which the actual controller maps to the forward-button disabled state. captureState calls copy and replaces incoming.exchangeURL; continuation stores that state and moves to the Exchange type step. Component tests check focus/value/capture and completed cases without a real endpoint request or full Hub navigation. The original permits syntactically valid HTTP(S) locations without requiring an EWS path. Accepted later source separately suppresses initial visual errors and normalizes selected Graph version paths. No authentication, endpoint validity, runtime or native accessibility result is established.

Scope: Account Hub Exchange settings.
