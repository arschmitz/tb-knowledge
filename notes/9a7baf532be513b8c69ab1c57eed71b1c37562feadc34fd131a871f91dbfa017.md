# ADR filenames and supersession preserve decision history

The ADR readme names files NNNN-title-with-dashes.md, with a four-digit number increased for each new record. If simultaneous patches use the same number, the first landed record keeps it and the later accepted record is renumbered. Accepted, deprecated and superseded are distinct documented states; superseded records link to the replacing ADR. The template and readme spelling correction in entry 2038 changes no status meaning. Preserve the old decision and its replacement link when documenting a change; do not infer current policy solely from an old accepted status without checking supersession.
