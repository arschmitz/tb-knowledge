# Background sending joins the compose window's successful-send close branch

The original change adds Background beside Now and Later in CompleteGenericSendMessage's final close condition, after the awaited send path and its failure returns. The new fake-SMTP test awaits window closure, checks unsent queue state and no initial SMTP message, then checks a later received subject. These are inspected assertions, not an executed delivery result. The fixed accepted source later waits for progressListener.waitForStop() before closing; that copying-recovery phase is separate from the original condition change.

Scope: Compose background-send completion.
