# The first merged manual-config form is a state scaffold with isolated-template coverage

The initial element clones an empty form, stores the supplied configuration object and returns it unchanged. Its one test provides templates in an isolated fixture and asserts structural state equality. The historical production bundle lacks the new form-template include, and the bounded controller references add state metadata/binding without a transition into that state. This is initial scaffolding, not evidence that a merged input editor was integrated or tested. Accepted source later adds field updates, the include and protocol routing; those later phases have separate scope.

Scope: Account Hub merged IMAP/POP3 manual configuration.
