# Folder properties tests wait for dialog closure, inert removal, popup closure and focus

The folder-properties helper focuses and closes the dialog through its actual button, then waits for the window to close, about3Pane to lose inert, the context popup to hide and the main window to regain focus. Popup closure may be delayed while the dialog is open, so its promise is retained until after closure. Accept and cancel use the same helper. This test-specific lifecycle replaces a post-close animation-frame wait; it adds no new color assertion or fresh runtime result.

Scope: folder-pane/properties-tests.
