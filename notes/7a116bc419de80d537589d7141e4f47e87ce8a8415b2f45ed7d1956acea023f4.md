# The PluralForm copy preserves common calls while changing legacy helpers, locale rules and test coverage

The owned replacement lazily installs get(number, semicolonString) and numForms() functions for the primary locale language. It removes makeGetter/ruleNum and the broad legacy-rule matrix. The retained English/Irish tests cover those common calls and fallback behavior, not every changed locale branch. In particular, is/mk move from two to four forms and mt reaches the two-form default; these source deltas are not a linguistic correctness claim. The checked later news-menu caller uses Fluent, so the historical helper is not a current API recommendation.

Scope: Historical plural selection module.
