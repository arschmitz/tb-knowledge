# The initial Graph transport kept the configured API-version path, while the accepted client appends it

The first HTTP client starts with endpoint.path and appends the generated request URI; it does not insert a v1.0 literal. Its review settles on a manually configured versioned endpoint. At the fixed accepted revision, base_api_url reads the operation sender base URL and appends v1.0 because configuration is assumed to omit the API version. Keep those phases separate when interpreting setup instructions. The original slash concatenation and later generated path builder also differ; no live endpoint or normalization behavior was tested.

Scope: Graph endpoint version phases.
