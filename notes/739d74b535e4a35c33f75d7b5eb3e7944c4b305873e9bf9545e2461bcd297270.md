# Route Account Hub steps through the submitted button value

The address-book option form uses the same subview button name and puts the destination step in value. The handler checks validity before using event.submitter.value. Back uses the current step’s previousStep. The original local view is a shell; fixed source later adds name validation/reset/capture and state confirmation. Visibility tests follow navigation, but one old isHidden check has a says-visible message. No native keyboard or accessibility behavior was tested.

Scope: Account Hub step routing.
