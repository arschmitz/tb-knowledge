# Header-view callbacks compare the channel URI with the current message service URL

displayMessage replaces gMessageURI before starting a load. Header-view callbacks use the message service to map that URI to a channel URL and compare nsIURI identity before changing current state. The file case relies on a new-about:message assumption. This rejects a different message, not every earlier generation of the same URI. nsIChannel supplies URI access while nsIMailChannel supplies parsed mail data; neither interface inherits the other. Static inspection only.

Scope: message-load-callback-identity.
