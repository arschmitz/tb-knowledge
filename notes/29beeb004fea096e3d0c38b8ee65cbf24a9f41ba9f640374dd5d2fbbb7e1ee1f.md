# State what the encrypted draft test observes

The new browser test enters body text without a recipient, saves, waits for a message, and checks the encrypted icon in the opened draft. It does not inspect stored ciphertext bytes. Its 100 ms wait is explicitly an uncertain compose-readiness workaround, not evidence for a general UI delay rule. Cleanup awaits onStopCopy but does not check its status. No draft save or encryption run was performed here.

Scope: OpenPGP encrypted draft tests.
