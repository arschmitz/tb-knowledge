# Load updater modules only in builds that ship the updater

The 2024 upstream update port imported UpdateListener.sys.mjs at module load. Bug 1900357 found that builds without MOZ_UPDATER did not ship this module. Current general.js defines the UpdateListener module getter only when AppConstants.MOZ_UPDATER is true. Gate imports and update-service calls by the build feature, and test updater-disabled distributions when touching this path. A successful standard update test did not cover that configuration.

Scope: Application updates.
