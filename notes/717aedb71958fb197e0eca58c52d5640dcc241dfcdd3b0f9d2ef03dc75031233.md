# Renaming identity folder APIs does not rename stored preference keys

The API uses draftsFolderURI, archivesFolderURI and templatesFolderURI, while implementation still stores draft_folder, archive_folder and stationery_folder. templatesFolderPickerMode also retains tmpl_folder_picker_mode. The author explicitly avoids a preference migration in this landing. Preserve persisted names when applying a clearer API name in this family; the spelling of an old storage key does not establish the preferred new symbol name. Current resolver methods add Async because they return a Promise. This is the identity folder family, not a global renaming rule.

Scope: Identity special folder API.
