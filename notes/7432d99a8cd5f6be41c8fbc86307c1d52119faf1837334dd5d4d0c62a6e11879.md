# Permission prompts must rebuild controls in the owning mail window

The historical optional-permission callback used a tab document while its controls lived in top messenger.xhtml, allowing stale or missing permission text. It switches document ownership and rebuilds a semantic list plus required-permissions title even for one item. Fixed code handles null targets and selects documentGlobal or the top mail window; the old ownership expression is not the full current contract. Tests directly inspect displayed list/title content or visibility, not every grant effect or screen-reader announcement.

Scope: Extension permission prompt ownership.
