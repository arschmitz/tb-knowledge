# Search callers preserve change reasons when moving constants onto SearchService

The comm port moves search change-reason constants from Ci.nsISearchService onto the existing SearchService receiver. It preserves the caller roles: ENTERPRISE for policy defaults, ADDON_INSTALL or ADDON_UNINSTALL for extension setting changes, and USER for preference selection. The extension control and prompt branches remain separate decisions. This is exact caller evidence; it does not prove an uninspected upstream enum, ABI or runtime result.

Scope: Thunderbird search-service caller port.
