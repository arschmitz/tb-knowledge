# Windows MAPI maps file and sender failures through separate cases

Entries 2080/2081 remove retired file-open codes from the MAPI_E_ATTACHMENT_OPEN_FAILURE group. Entries 2084/2085 remove obsolete sender-address/identity cases that previously mapped to MAPI_E_FAILURE; the default still yields that generic failure after the landing. Fixed source keeps NS_ERROR_FILE_INVALID_PATH mapped to attachment-open, NS_ERROR_FILE_NOT_FOUND to attachment-not-found and other failures to MAPI_E_FAILURE. Preserve actual nsresult-to-HRESULT behavior when cleaning error identifiers; deleting a retired case does not establish new sender validation. No Windows build or MAPI operation ran.

Scope: mailnews Windows MAPI error conversion.
