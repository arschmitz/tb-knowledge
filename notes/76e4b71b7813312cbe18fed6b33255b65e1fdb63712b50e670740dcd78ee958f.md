# Describe requested QR correction strength without claiming a fixed level

QRExport requests ErrorCorrectionLevel.L. The selected current foreign generate boundary defaults optimizeEcc to true and can improve the error correction level after choosing a version. Therefore the owned call requests L but does not establish that every generated code uses exactly L. Keep the dependency option semantics separate from the concise module comment. This is a static boundary reading; the foreign algorithm and generated matrices were not executed or fully audited.

Scope: mail/modules/QRExport.sys.mjs.
