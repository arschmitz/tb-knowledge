# Non-SMTP outgoing settings can be displayed while editing remains disabled

The protocol-neutral settings view displays server type and generic serverURI fields. A missing localized type label falls back to the raw add-on type. Manual non-SMTP configuration was explicitly deferred, so both relevant Edit buttons are disabled for non-SMTP servers. Tests directly check SMTP/EWS labels, selection and enabled state, not delivery. Existing smtp-prefixed DOM and stored names remain compatibility details. Fixed code later handles a missing URI and adds certificate UI. Primary Bugzilla comment2 is absent; full public review retained separately. No complete-audit credit.

Scope: Outgoing server UI capabilities.
