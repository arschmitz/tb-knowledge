# The original Quick Look import precedes its platform availability check

The initial landing packages its manager only for cocoa and registers the native component only for Darwin, but its lazy getter attempts to import the resource inside try/catch before reaching the manager's isAvailable getter. The fixed accepted getter first tests nsIMacQuickLook in Ci, then imports. That source ordering is the supported platform boundary; the later reported broken-resource failure is attributed discussion, not a new build result. No cross-platform support, successful native build or global import rule is inferred.

Scope: Attachment preview platform boundary.
