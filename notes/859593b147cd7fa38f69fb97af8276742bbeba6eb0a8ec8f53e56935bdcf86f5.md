# The MIME recursion tests accept a broad error instead of asserting the exact cutoff

The new tests exercise depth 50 and 1000 in nested message/rfc822 and multipart fixtures. The shallow helper requires the decoded marker. The deep helper passes on any stream exception, or on marker absence after successful streaming. Its unconditional assertion in the catch branch does not identify the rejection cause. These cases do not directly assert depth 64 versus 65 or the fallback class. Those are static test limits, not observed failures.

Scope: MIME xpcshell recursion tests.
