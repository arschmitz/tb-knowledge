# Flatpak adds its DBus wildcard only for a nondefault application ID

The script collects options in build_args, then appends org.mozilla.thunderbird.* as an own-name only when APP_ID is not org.mozilla.thunderbird. It passes the array as individual build-finish arguments. This conditional describes the inspected package variants; it does not establish live DBus access or a general sandbox permission rule.

Scope: Flatpak build-finish arguments.
