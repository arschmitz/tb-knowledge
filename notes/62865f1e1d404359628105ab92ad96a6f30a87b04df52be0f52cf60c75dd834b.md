# Folder error styling depends on state selectors as well as semantic warning color

The folder palette defines folder-color-warning with the critical text token. Error icons and TLS status icons consume that alias. The feed currentColor override excludes rows with data-has-error, as well as busy and special folders, so the generic feed rule does not replace error styling. Keep selector state and token role together when changing this family. The original busy color choice differs from accepted selected-item-color, and the original group was backed out before a later reland. Source alone does not prove rendered contrast or successful theme tests.

Scope: Folder pane CSS state and palette consumers.
