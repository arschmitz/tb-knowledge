# Official branding configuration has a current automation exception

Entry 2007 moves legacy confvars settings toward moz.configure implications. The frozen accepted code computes official_branding_directory but leaves its MOZ_OFFICIAL_BRANDING_DIRECTORY implication commented because MSIX repack cannot read moz.configure; confvars.sh also explicitly leaves that variable unset for automation. Preserve this documented exception when reasoning about build-variable ownership. The source does not validate a repack or configure run. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran.
