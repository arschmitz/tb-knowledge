# Use one pane step switch and initialize through the named step methods

Current showStep toggles the hidden state of all known Intro/Codes/Summary sections. showCodes authorizes when needed, initializes the wizard, checks total zero, updates labels, displays Codes and populates the summary. Next chooses Done on the last QR code; clicking Done then shows Summary. Back from the first code and Restart return through showIntro, which repopulates accounts. Treat step initialization and section visibility as separate responsibilities; live focus movement and repeated rapid submissions were not verified.

Scope: mail/components/preferences.
