# The hidden-attribute migration also changes fifteen ARIA token values

The owned Boolean XUL migration also replaces15 aria-hidden="true" values with aria-hidden="hidden" across thread/card buttons, a search-bar placeholder and its fixture/Storybook copies, and the compose attachment-animation span. Selected fixed source retains these values. ThreadRow and SearchBar clone the affected templates; a comment still says the animation marker is excluded from the accessibility tree. These source substitutions are a separate ARIA contract concern and must not be copied as a proven Boolean-attribute accessibility pattern. No live accessible-tree or screen-reader outcome is established.

Scope: Boolean visibility migration scope boundaries.
