# Define shared header probes once after upstream configure changes

Mozilla-central began checking dlfcn.h in moz.configure. Thunderbird openpgp.configure still checked it, so HAVE_DLFCN_H was exported twice and mozbuild failed. Bug 1897114 removed dlfcn.h from the local list. D210633 records that Try could not run because of the related toolchain bustage, while the author built locally and confirmed this fix. When upstream takes ownership of a configure probe, remove the duplicate local export and state exactly which validation was possible.

Scope: OpenPGP build configuration.
