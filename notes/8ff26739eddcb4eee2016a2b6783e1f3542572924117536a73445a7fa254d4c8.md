# Keep an event UID separate from its CalDAV resource path

getItemLocationPath returns a cached locationPath for an existing item and sanitizes the UID only when generating a new .ics resource name. The original ICS UID remains the calendar lookup identity. Both retained special-character regression tasks retrieve by the original UID, but both pass false to createCalendar and disable caching; the cached filename does not prove cached-mode coverage. Do not rewrite the ICS UID as a path cleanup. The underscore mapping can collide, for example a/b and a_b; collision handling remains unestablished. Complete bug/review context and exact factory/test/source were read. No server test ran.

Scope: calendar/providers/caldav.
