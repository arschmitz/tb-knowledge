# The notification source-URI migration updates registration, entry points and test imports together

The migration registers notification content/modules with MOZ_SRC_FILES, removes the old jar/module packaging entries and changes the startup, lazy, static and fixture imports to matching moz-src:///comm paths. Messenger script-src adds that scheme while relative sibling content imports keep their roles. Static checks find all13 migrated targets at the historical and accepted source phases. These checks do not prove runtime resolution, successful import/CSP enforcement or a global migration rule for every chrome/resource URI. Lifecycle gating and rejection behavior stay distinct. No build, import, notification or test ran.

Scope: In-app notification source URI and packaging boundaries.
