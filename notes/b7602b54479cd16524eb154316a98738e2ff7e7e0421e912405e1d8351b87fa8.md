# Manual Account Hub error links use a keyed list and focus the internal field

Manual validation associates each invalid field with its input and Fluent label. The summary keeps the existing node when the field-ID list is unchanged and rejects stale localization results with a request counter. A link prevents fragment navigation, scrolls the field into view and schedules focus on the custom input, whose focus method forwards to its inner input. The header inserts the description node into an expanded notification and clears it on reset. Component tests directly check error labels/description, focus, coalesced config updates and unchanged list identity. These source assertions do not establish live screen-reader behavior or eliminate every race/flicker; no browser test was run. Later connection-testing/validation changes remain separate.

Scope: Account Hub manual field-error summary.
