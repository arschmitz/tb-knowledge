# Wait for the nested message pane before asserting its URI

A new mail tab has a chrome browser and a nested message pane. Waiting for the outer browser alone does not guarantee the inner message content is loaded. The intermittent browser_mailTabsAndWindows test added an explicit wait on secondOpenedMessagePane before checking currentURI.

Scope: message tab tests.
