# Folder repair preserves view state but must reset IMAP summary state

Current rebuildFolderSummary snapshots the IMAP property bag before closing/backing up the database, restores it afterwards, and then updates the folder. Preserve view settings while resetting numMsgs/numNewMsgs and UIDValidity so IMAP recognizes a rebuild. The original preservation fix also retained stale counters and caused later breakage. Local folder reparsing uses backend transfer support; do not blindly duplicate one protocol sequence for all folders. Current EWS/Graph repair resets the sync token instead.

Scope: folder-repair.
