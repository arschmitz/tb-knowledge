# ADR 0003 records document-scoped Redux stores and a gradual rollout

The accepted ADR chooses Redux Toolkit for front-end state and shares in-memory stores at document scope. Backend synchronization and helpers are described as work to refine. Its rollout names new front-end projects as the default starting point and existing components when useful. The global-store alternative, benefits, risks and security expectations remain the document’s stated reasoning, not measured implementation results or proof of adoption in every component. This lesson records the accepted project document and does not create or edit user instructions.

Scope: Front-end state-management ADR scope.
