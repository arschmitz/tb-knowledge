# The direct message-property cursor needs the later detached-database and cursor guards

The enumeration removal replaces a guarded, reference-holding adapter with direct row-cursor traversal. Its owned version accesses database/row members and uses the returned cursor without the later checks. Fixed accepted GetProperties clears the output, returns no properties for detached database state, checks cursor creation status and tolerates a null cursor. The existing live-header membership test does not cover database shutdown or cursor failure. Keep the refactor and these later safety boundaries separate; no lifetime failure was reproduced.

Scope: Legacy message header property collection.
