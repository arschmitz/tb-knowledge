# Smart-folder regeneration checks the initialized mailbox owner

The smart mode initializes this._smartMailbox with SmartMailboxUtils.getSmartMailbox. regenerateMode checks that same field before removeAll(true), then calls init. The old _smartServer typo skipped cleanup. Use the name for the actual mailbox wrapper, and use .server when the server is needed. This checked ownership pattern does not guarantee recovery if removal or initialization throws. This is static source and test-code inspection.
