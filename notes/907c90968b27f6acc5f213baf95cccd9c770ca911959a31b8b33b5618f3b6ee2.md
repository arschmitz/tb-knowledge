# Password forgetting can reject before the cache-clearing promise in its comment

The native loop ignored an individual removal failure and still cleared its cache. The JS port keeps the continue-and-clear comment but awaits each removeLoginAsync without a local catch. A rejection exits before the later cache clear. The accepted exact snapshot still has that ordering and comment, so settlement waiting does not implement the promised continuation. No failure or stored-password state was exercised.

Scope: Password module removal failure contract.
