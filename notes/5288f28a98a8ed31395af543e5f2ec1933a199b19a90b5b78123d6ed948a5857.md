# Match custom-element tag, module and class names

The accepted 2024 custom-element guide pairs my-element with my-element.mjs and MyElement, asks each element to register itself at the end of its module, and uses a named export when other elements extend it. Current lazy-findbar.mjs still demonstrates lazy-findbar, LazyFindbar and self-registration. Use the tag’s dash-separated spelling for the module and PascalCase for the class within this family. This is scoped to custom elements, not all JavaScript files or class prefixes. The old guide path has since been removed; preserve it as a historical source and prefer newer accepted examples where they differ.

Scope: Custom-element file and class naming.
