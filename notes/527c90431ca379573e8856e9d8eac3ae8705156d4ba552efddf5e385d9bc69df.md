# Guessed logins keep the local part as a per-method fallback slot

The guess helper starts incoming/outgoing usernames with the full email and retains a distinct local part in config.usernameSaved. The verifier uses a tried-both marker so a saved initial name is tried once for that auth method, then resets the marker when changing methods. The guessed test starts full then local for the first method, but local then full for the next method. This in-memory slot and simulated order are not password-manager lookup, SMTP verification or a real authentication result.

Scope: Account setup guessed username retry state.
