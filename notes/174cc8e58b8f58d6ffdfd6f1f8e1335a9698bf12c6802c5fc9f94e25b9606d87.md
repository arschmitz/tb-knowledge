# Folder-command extraction keeps page context and moves selection routing to commands

The new FolderCommands object is packaged at a chrome URL and loaded through an about3Pane getter with global:current. Its functions still use that page document/window/top; the view picker reaches the page export, while the compact toolbar uses cmd_compactFolder and the controller chooses current or selected folders. Quota markup is gated by MAIN_WINDOW and dispatches its own command. The reviewed direct-import proposal was rebutted, and the requested usage comment is absent from the checked module header. These are scoped context/caller facts, not a universal import rule or verified native-operation equivalence.

Scope: about3Pane FolderCommands module and dispatch.
