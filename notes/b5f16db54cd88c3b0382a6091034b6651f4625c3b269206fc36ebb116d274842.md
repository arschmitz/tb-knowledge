# The first read-dialog menu patch opens a popup but does not wire its three actions

The first menu phase adds duplicate, delete and print labels plus a more-actions button, then opens the popup after_end when that button is clicked. Its test checks hidden/shown popup state and closes it; no action handler is introduced. Accepted markup later hides duplicate/print and assigns delete an action identity. Keep the original popup capability separate from those later commands, and do not infer a toggle-close branch from the helper name.

Scope: Calendar read-dialog header menu.
