# Account-tree rows are staged through async work before one DOM replacement

The rebuild collects detached account rows while asynchronous account-panel work runs. It then replaces the live children once and colors those attached rows through the live-tree lookup. The SMTP row is appended afterward. This ordering prevents partially constructed rows from being appended during the awaited work; the inspected function does not serialize separate rebuild calls or prove every timing failure is fixed.

Scope: Account Settings tree rebuilding.
