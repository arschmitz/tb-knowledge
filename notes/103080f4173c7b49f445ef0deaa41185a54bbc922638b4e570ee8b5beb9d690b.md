# The async-folder removal leaves the Drafts prompt label sourced from the Sent folder URI

The landing replaces synchronous draft-folder creation in ComposeCanClose with a default Drafts name and an optional existing-folder lookup. That lookup uses fccFolderURI, which nsIMsgIdentity documents as Sent Mail, while draftsFolderURI is a separate attribute. The resulting name fills text that calls it the drafts folder, and the Save branch still initiates AutoSaveAsDraft. Thus a differently named existing Sent folder supplies the displayed Drafts label in this path. The mismatch remains in fixed accepted source, although localization later moved to Fluent; no native dialog, folder creation or data-loss result was exercised.

Scope: ComposeCanClose folder label.
