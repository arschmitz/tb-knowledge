# Refresh SMTP OAuth availability from the hostname being edited

The popupshowing handler queries OAuth2Providers with gSmtpHostname.value and protocol smtp immediately before showing the authentication menu. Initial setup instead derives the host from the stored server URI when one exists. Preserve the edited-host lookup at popup time, including the protocol argument, so adding or editing a server is not limited by its original value. This controls option visibility; it does not guarantee OAuth authorization succeeds.

Scope: mailnews/base/prefs.
