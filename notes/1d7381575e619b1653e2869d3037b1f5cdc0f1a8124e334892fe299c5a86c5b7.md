# Check header existence before obtaining a header for undo

Accepted local move undo calls ContainsKey and skips source headers that disappeared. Its source comment states that GetMsgHdrForKey can create a new header for a missing key. Use the explicit database existence check in this undo path before obtaining the header. A non-null returned header alone is not proof that the original message is still in the database. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/local/src.
