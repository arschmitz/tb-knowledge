# Keep OS search support file formats and locations distinct

SearchSupport shares indexing queues and folder event handling, while platform subclasses set their own preferences, header indexed property, file extension, and stream writer. Spotlight writes .mozeml support files under ~/Library/Caches/Metadata/Thunderbird because Spotlight does not index the profile directory. Windows uses .wdseml support files in per-folder .mozmsgs directories and Windows search registration. Preserve this split when changing common queue logic; test the relevant platform because the May review only reports manual macOS and Windows checks and later platform regressions were filed.

Scope: desktop search integration.
