# The typed langpack worker separates channel choices from task-reference values

LangpackWorkerSchema declares env as a mapping and command as a list using taskref_or_string_msgspec. Its channel is separately keyed by project and platform with listed/unlisted literals. The kind supplies a structured TASK_ID reference and channel maps; make_task_description resolves worker.channel from the project and dependency build platform before constructing worker metadata. These are local declarations and consumer calls, not proof of external schema validation or unchanged legacy acceptance.

Scope: Release langpack typed worker contract.
