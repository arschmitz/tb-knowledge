# Module URI ports update lazy consumers and the startup denylist together

This port changes the module URL at three actual consumers and changes the corresponding ContextualIdentityService and CrashSubmit names in the startup denylist. The test compares exact recorded module strings with includes, so an import-location port also needs the test's URI literals. The checked consumers retain their existing calls and lazy loading. This is a scoped source relationship; it does not prove upstream module equivalence, compatibility or a successful startup run.

Scope: Thunderbird moz-src imports and startup recording.
