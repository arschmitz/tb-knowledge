# The context-menu extraction retains an unresolved focusedthis.window access

The extraction changes document.commandDispatcher.focusedWindow into this.document.commandDispatcher.focusedthis.window inside isContentSelection. The latter spelling remains at the fixed accepted revision. A scoped Thunderbird symbol search did not identify an invoking caller for this module method; the IM implementation is a separate receiver. This records an exact member-chain difference for follow-up, not a reproduced reachable crash or evidence that every context menu fails. The selected browser menu tests do not directly invoke this helper, and no browser test ran.

Scope: Browser context-menu selection helper.
