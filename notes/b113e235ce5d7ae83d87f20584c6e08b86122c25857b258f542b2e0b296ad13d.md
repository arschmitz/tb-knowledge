# ProxyGetSubFolders checks its folder before dispatching the import runnable

Fresh complete subfolder-proxy null-guard hunk and runnable/callers read. ProxyGetSubFolders now checks the folder before scheduling GetSubFoldersRunnable, whose Run calls GetSubFolders to initialize the folder list. The dummy result list is not returned as a new API. Dispatch status and mResult remain distinct. The initial ImportMailThread initialization call ignores the result; the later depth-increase call checks NS_FAILED and continues. The guard therefore does not establish all callers handle every initialization failure. Reporter null-folder interpretation, approval and historical beta/ESR landings remain distinct from the explicit absence of automated/reproduction/verification evidence. Fixed source retains the narrow guard; no crash or import was run. This is a scoped receiver precondition; it does not add all-output validation or establish the upstream reason a folder became null.

Scope: Mail import main-thread proxy receiver guards.
