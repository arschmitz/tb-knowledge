# Address-book sync capture preserves selected provider objects and excludes disabled rows

AddressBookSync.captureState reads checked enabled inputs only from the account-row container, matches their dataset URLs and returns the original available-address-book objects. This preserves each object.create method for the later forward consumer, which awaits selected creates in sequence. Disabled pre-existing books can remain counted/checked without being returned for creation. Direct component tests compare returned objects and assert selected create-stub calls; the stubs return true, so these tests do not verify real CardDAV creation or directory metadata. The original selection-subview landing and the later fixed creation/tri-state code are separate stages. Provider callbacks and duplicate-URL discovery contracts were not inspected, and no test ran.

Scope: Account Hub address-book selection contract.
