# The message visibility receiver does not consume the child's URI payload

The child sends a visible-state notification with the document URI. The parent checks the current embedder window's gMessageURI and calls autoMarkAsRead, but does not read or compare message.data.uri. Keep the presence guard and payload identity check separate. No wrong-message, lifecycle race or native actor result was reproduced.

Scope: Mail message visibility actor contract.
