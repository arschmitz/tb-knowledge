# The Graph flag operation checks returned ID count before success

The original flag operation extracts IDs from batch response messages and returns an error if the returned count differs from the requested count. Success arguments use No for legacy fallback. The accepted operation keeps this count boundary with later generated-type handling. Equal counts do not establish identity or uniqueness of each returned ID, and bridge dispatch success is not remote completion. No request or callback execution was run.

Scope: Graph flag operation result boundary.
