# Separate common platform mozconfig from build-mode mozconfig

666 adds six Win64 Arm64 mozconfig files. common-win64 sets the aarch64-pc-windows-msvc target and sources clang-cl; common-opt sets update channel, official-build metadata and JavaScript shell packaging. nightly and release select distinct branding, debug enables debug, and l10n-mozconfig composes the localization common file. Current files keep that division, and USE_ARTIFACT disables MAPI in common-win64. The historical Linux UPX chmod workaround is no longer there. These are static configurations, not verified build modes.

Scope: Windows Arm64 mozconfig composition.
