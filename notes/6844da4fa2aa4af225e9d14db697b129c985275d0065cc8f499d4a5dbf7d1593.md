# Address import initializes its database-array pointer before the caller binds the array

AddressThreadData starts dBs at nullptr. The import caller later assigns &m_DBs before calling ImportAddressThread and deletes the state after that direct call. The consumer dereferences the array when a selected nonempty book is imported, so constructor initialization does not replace the binding requirement or grant ownership of the array. Keep the initial value, owner binding and consumer lifetime as separate parts of this local contract.

Scope: Legacy address-book import state.
