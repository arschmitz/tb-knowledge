# Test preference initialization and toggling through the actual checkbox

The privacy test uses testCheckboxes for GPC. The helper opens the pane with both initial states, checks the bound pref and native checked state, clicks twice and checks unaffected controls, then closes the tab. This is useful source coverage of binding/toggle behavior, not proof that the outgoing network signal or keyboard/accessibility behavior works. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Privacy checkbox harness contract.
