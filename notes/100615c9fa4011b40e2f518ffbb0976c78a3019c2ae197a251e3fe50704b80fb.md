# Collection updates an existing primary address across books but leaves non-primary matches alone

Without skipCheckExisting, accepted collection searches directories for a matching card, compares primaryEmail case-insensitively, and returns without editing a non-primary match. A writable matching card receives a displayName only when its current displayName is empty. The directory’s matching implementation can find more than two vCard addresses, so the old "secondary" comment is narrower than the actual lookup scope. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
