# Keep synchronous tree row access while Panorama fetches asynchronously

A tree view asks for rows synchronously, but Panorama fetches messages asynchronously. Place temporary rows in the requested range before starting the fetch, then replace them when selectMessages resolves. This prevents reentrant requests for the same empty range.
