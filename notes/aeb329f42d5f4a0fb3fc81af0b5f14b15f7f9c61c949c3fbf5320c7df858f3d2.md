# Reset the delayed-send header identity before parsing each queued message

BuildHeaders frees and clears m_messageId before parsing another queued message. Without that reset, its existing-header branch can append another value to retained content. The destructor separately releases the buffer. The new task calls the same header-bearing fixture helper twice and requires an end-anchored ENVID in each fake-SMTP MAIL FROM line. This checks per-message envelope state, not a delivered-header identity or a memory-leak diagnosis.

Scope: Delayed-send per-message header state.
