# Gloda telemetry removal keeps adaptive indexing timing

The patch removes two unused legacy histogram paths and their dedicated message counter. The accepted indexer still calculates time per token from _perfIndexStopwatch and uses it to adjust _indexTokens. The datastore still creates or opens global-messages-db.sqlite. Keep those behavioral consumers separate from the removed reporting code. The discussion chose removal instead of a Glean migration and required coordinated platform landing; no telemetry usage survey or benchmark ran here.

Scope: Gloda telemetry and indexing budget.
