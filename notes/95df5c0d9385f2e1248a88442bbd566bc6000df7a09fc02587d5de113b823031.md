# Flag mutation and notification are separate database steps

SetKeyFlag resolves the header, returns NS_MSG_MESSAGE_NOT_FOUND when absent, and sends NotifyHdrChangeAll only if SetHdrFlag reports a changed bit. A repeated assignment therefore does not emit a flag-change notification through this helper. MarkKilled now reuses that helper for Ignored. This describes the checked legacy database path, not every database implementation or notification source. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
