# The removed Calendar offline observer is separate from the manager's active observers

The deletion removes calendarOfflineManager's network-status observer registration, initialization guards and view/command refresh code. The accepted load/unload functions still add and remove the separate composite and calendar-list observers. These source roles are distinct; deleting this object does not establish that all Calendar offline behavior is gone or that runtime inactivity was measured.

Scope: Thunderbird Calendar manager observer lifecycle.
