# Use set for configuration snapshots and add for counted events

Account, address-book and calendar reports set a current aggregate; setup successes/failures and FileLink/send actions add events. Account reporting seeds common types with0 to reset removed accounts, skips none Local Folders, and names IM protocols im_<normalizedName>. Proposed manual metric rule: preserve population and sampling semantics when replacing a probe; changing set into add would accumulate repeated snapshots.

Scope: telemetry-reporting.
