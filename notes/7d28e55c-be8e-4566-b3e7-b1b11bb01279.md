# Give non-submit HTML controls an explicit button type

Use type="button" on an HTML button that is not meant to submit a form. D211687 requested this for account-color controls, and the restored address-book Import button also declares it. This communicates the action and prevents accidental submit behavior if the surrounding markup changes.

Scope: syntax HTML buttons.
