# Assert complete event argument shapes instead of only selected object keys

1966 replaces a per-field expected-key loop with assertDeepEqual(expectedArgs, actualArgs) and adds an event-type message. Current checkEvent consumes one queued event, checks type and compares the full expected argument tuple. Proposed scoped test guideline: compare the complete expected payload when the API shape is the subject of the test, so extra or missing fields are visible. This is stricter than a selected-key loop; no test was executed and no global assertion library rule is implied. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: extension event test assertions.
