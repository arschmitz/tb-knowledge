# Correct the test cleanup guidance

This correction supersedes the unsupported callback-count guidance in
[the original note](8f5d298f-8df3-4eaf-84d3-59a844728679.md) and
[the writing-only clarification](58165b80-803d-40c2-8d71-fd3e20468789.md).

The assistant added a requirement to use separate cleanup callbacks without
checking accepted local practice. That requirement was not a human instruction
and is withdrawn. The number and arrangement of cleanup callbacks must follow
the actual harness and supported local examples. No global callback-count rule
is established here.

The direct human writing instruction remains: When writing tests, do not add
`try/finally` blocks. Use the test harness setup and cleanup hooks. Register
cleanup before setup can fail. This is writing guidance, not a patch-review
criterion. It does not require rewriting unrelated tests or ban production
`try/finally`.

The human also requested evidence before edits and an independent check afterward,
with the knowledge repository usable standalone. [CODE-EVIDENCE.md](../CODE-EVIDENCE.md)
defines that workflow. Automatic learning must not change these instructions.

Scope: deliberate writing guidance requested in the D332509 verification and
test-fix discussion on 2026-10-13. This correction is not a claim that the earlier
run evaluated the quality of knowledge retrieval or its effect on code quality.
