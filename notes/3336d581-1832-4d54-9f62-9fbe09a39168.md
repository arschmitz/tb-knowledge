# Do not bump a Sync engine version for a routine record field

The accepted Sync extension guide warns that increasing MyEngine.prototype.version wipes users' server-stored data. Add or change normal fields through the record cleartext forwarding, store, tracker, tests, and record specification instead. Treat version changes as a data migration decision. This is the 2024 authored guide, which still exists in the current checkout; verify current engine semantics before a future change.

Scope: Sync engines.
