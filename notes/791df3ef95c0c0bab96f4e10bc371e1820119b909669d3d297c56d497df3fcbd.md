# Subject text does not need to grow with its surrounding header row

The subject row keeps a flex-growing parent while expandedsubjectBox has no flex declaration of its own. The child remains a SimpleHeaderRow with tabIndex 0. The assigned change removes only the child flex declaration; it retains the long-subject clamp and scrolling rules. This is a local layout change, not a rule to remove subject focusability.

Scope: message-header-layout.
