# The new EditorConfig Python-width comment does not match the local Ruff value

This landing adds max_line_length=88 for Python/build/configure files and comments that it matches Ruff. The local pyproject.toml declares line-length=99 both at this landing and at fixed accepted source, so that specific explanation does not match the inspected configuration. The source establishes the two declared values and the misleading match comment; it does not require a new width, prove editor/formatter behavior, or create a global style rule.

Scope: Editor and Python formatter configuration.
