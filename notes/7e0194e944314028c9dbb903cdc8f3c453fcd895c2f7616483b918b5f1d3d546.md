# Check the signed-part match before writing the extracted message

In the fixed accepted viewSignedPart implementation, an unmatched boundary regexp makes body undefined. The following hdr + body expression still creates a string and passes it to msgOpenMessageFromString, which writes it to a temporary EML file. A no-match path should stop or report failure before creating that file. This is a conditional static finding: the added test uses one matching forwarded fixture and does not cover missing boundary matches. It does not establish which real messages reach this case or claim a reproduced signature failure.

Scope: mail/OpenPGP/nested-message-display.
