# The selected-card export diagnostic says inclusion while asserting list exclusion

The selected-contact helper expects contents.includes("list") to be false, but says "export includes list". The message should say that the export should not include a mailing list. New default-filename checks also lack expected-behavior messages. The accepted helper retains these issues; no test failure was reproduced.

Scope: Address-book export test diagnostics.
