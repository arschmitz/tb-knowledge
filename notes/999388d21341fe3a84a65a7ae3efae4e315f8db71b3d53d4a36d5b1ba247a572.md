# The runtime sandbox lookup originally mutates its built-in issuer entry

This phase moves the sandbox preference into getIssuerDetails, but takes details directly from kIssuers and changes that object only when the preference is true. There is no false branch restoring production values and no clone in this owned implementation. Static true-then-false lookup tracing can therefore retain the sandbox mutation. Accepted code later clones and freezes the override; the existing focused lesson covers that later phase. No live toggle, cached-OAuth lifetime or successful authentication was tested.

Scope: OAuth provider lookup phase ownership.
