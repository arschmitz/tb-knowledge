# The incoming-server hostname rename spans interface callers and Account Manager bindings while keeping the stored key

This landing renames the incoming-server interface property to hostname and updates its native, JavaScript and Rust callers. The checked JS/native implementations still read and write the literal hostname preference. Account Manager also changes the input ID and label targets to server.hostname, and its helper reads the hostname property from the incoming server. The persistence preference string is unchanged. These are paired source contracts for this interface and UI; private helper names, Rust trait names and unrelated URI APIs are not covered by a general spelling rule. Generated bindings and runtime compatibility were not tested.

Scope: incoming server interfaces and Account Manager.
