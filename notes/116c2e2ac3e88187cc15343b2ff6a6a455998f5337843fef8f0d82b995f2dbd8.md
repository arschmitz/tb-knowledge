# Preserve explicit false when choosing the extension popup close default

929 passes allowScriptsToClose without boolean coercion and uses nullish coalescing in the popup. An omitted value defaults to true for a moz-extension URI and false for other schemes; explicit false overrides the extension default. Only the first configured tab supplies the URL for this popup path. Keep undefined and false distinct across the parent-to-window arguments. The changed test checks omitted permission for an extension page, not explicit false or an HTTP page.

Scope: Extension popup boolean defaults.
