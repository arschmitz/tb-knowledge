# Ubuntu test labels select an image separately from their build platform

The initial Ubuntu24.04 addition maps linux2404 test labels to existing Linux build-platform keys and test sets. A separate by-test-platform Docker selector chooses ubuntu2404-test, while its original default stays ubuntu1804-test. The Docker kind also imports the Ubuntu24.04 image family. Adding a test label is only one part of this configuration. The accepted phase retains the labels but later makes ubuntu2404-test the unconditional default. No generated graph or test execution was checked.

Scope: taskcluster.
