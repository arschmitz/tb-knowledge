# Recent destination labels separate duplicate names, display paths and account labels

Special folder menus cache the localized folder name, display path and server display name, then compute the label before sorting it. Duplicate names use the path; a server suffix is added when the same-name group has more than one server display-name value. Every item has a path/account tooltip. Display names are not stable account IDs, so this code does not prove uniqueness when distinct accounts share the same display name. The owned hyphen tooltip and accepted later en dash remain separate phases.

Scope: folder-menu-special-label-disambiguation.
