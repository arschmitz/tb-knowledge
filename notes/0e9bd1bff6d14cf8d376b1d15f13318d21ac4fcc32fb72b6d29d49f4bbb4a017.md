# Cloning a configured Graph NextPage resets its requested maximum

NextPage::clone copies next_uri but sets max_page_size to None, so it does not preserve a previously configured maximum. Its request builder adds Prefer only when that field is Some. The inspected Graph sync loop sets the maximum again before sending each NextLink. The clone behavior remains in accepted source; no production clone impact, server limit or runtime failure is inferred.

Scope: Graph pagination clone contract.
