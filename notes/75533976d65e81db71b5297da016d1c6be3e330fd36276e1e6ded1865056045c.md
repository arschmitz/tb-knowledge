# Pass explicit notification window, container and value identities in current tests

The deleted get_notification_bar_for_tab took no tab argument and read the selected tab from the shared mc window. Current get_notification takes win, container id and notification value separately, throws if the box ID is missing, and can return null when no stack exists. open_compose_from_draft calls it with its message window and draftMsgContent. Follow this explicit identity contract for this family; do not infer that a helper’s old name selected the passed tab. A notification lookup is not an assertion of visibility or an event waiter. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: mail test notification identity.
