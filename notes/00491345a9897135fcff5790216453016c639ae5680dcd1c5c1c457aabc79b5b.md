# Calendar row icon and truncation rules need their own rendering checks

The accepted Calendar row stylesheet gives slotted icons logical 16px dimensions and currentColor-derived paint. The truncated-content class clamps to five lines. Preserve these local icon and content rules when changing row styles, and test long localized text, inherited colors and expanded content separately. Existing notes cover hidden-host, host/slot, labelless and expansion-state behavior. Source layout rules alone do not prove correct rendering or accessible output. Static source and test-code inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and review discussion remains pending.

Scope: Calendar dialog row slot layout.
