# Handler display names may come from platform metadata rather than filenames

getDisplayNameForFile uses the Windows FileDescription field or the macOS bundleDisplayName, falling back to leafName if metadata access fails or the special interface is unavailable. chooseApp assigns that display value to handlerApp.name while keeping fp.file as executable. Preserve this distinction when changing labels: the displayed name is not the executable path or a filesystem naming convention. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: mail handler display names.
