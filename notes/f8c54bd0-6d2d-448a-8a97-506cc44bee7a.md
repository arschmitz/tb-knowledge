# Use shared dialog variables and include them in standalone consumers

themeableDialog.css duplicated button and selection variables already in variables.css. The accepted cleanup removes those definitions and adds variables.css to backupKeyPassword.xhtml, which had not imported it. It also removes the redundant colors.css import where preferences.css already supplies it. When deduplicating shared CSS variables, inspect every dialog consumer for the needed import and focus-state styling.
