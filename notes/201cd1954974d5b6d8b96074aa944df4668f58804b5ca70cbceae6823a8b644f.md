# Remove an unused initialization field instead of preserving a dead interface enum

Entry 909 removes m_contentModified and the corresponding contentModifiedType enum after finding the field unused. The accepted IMAP URL class and interface no longer carry those members. An uninitialized-field report can be resolved by deleting dead state when its interface has no active contract; blindly initializing it can preserve misleading API surface. Static report identifiers do not prove a user-visible crash. Current whole-repository consumer absence was not independently established beyond the removed patch and scoped accepted declarations.

Scope: mailnews/imap/public.
