# Preserve all character strings inside one DNS TXT record

TXTRecord exposes strings, an array for one DNS record. On Unix the parser advances through length-prefixed strings within the resource-data length; on Windows it reads dwStringCount pointers. Do not concatenate all strings in the shared DNS layer or silently take only the first. Consumers choose the interpretation. DAV treats each string as a key/value entry and finds path= within each record, then takes the first found path. This fixes providers whose path was not the first string. The accepted code’s TXTRecord JSDoc still says string rather than string[]; do not copy that stale type into a new interface.

Scope: DNS TXT representation and DAV discovery.
