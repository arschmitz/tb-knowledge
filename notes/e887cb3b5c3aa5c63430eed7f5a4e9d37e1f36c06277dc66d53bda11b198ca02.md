# Promise wrappers must reject failed send callbacks and expose completion counts

763 adds PromiseSendLaterListener. It rejects on a message error and on a non-NS_OK final status, then resolves with totalTried and successful counts. A callback firing is not equivalent to a successful send, and the caller can compare the counts rather than treating every resolved completion as one message. Current registration uses xpcshell.toml. This is source inspection of the listener contract; no queued-send test was run.

Scope: Delayed-send test listener.
