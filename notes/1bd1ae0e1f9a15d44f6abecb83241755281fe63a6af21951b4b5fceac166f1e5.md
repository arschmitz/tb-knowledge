# The Axe guide separates the scan context from the watched container

The guide uses context for the Axe scan and container for DOM observation. The actual content helper requires a selector container, while the window helper accepts an element or selector. When context is absent the explicit container becomes the scan context; the default observed node differs between content and chrome windows. These static contracts do not show an Axe engine or accessibility test passed.

Scope: Axe browser-test guide and helper receiver contracts.
