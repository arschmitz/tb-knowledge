# Graph hard deletion uses asynchronous per-message DELETE requests and shared completion

The bridge copies the IDs and starts a local async task; its immediate Ok is dispatch, not remote completion. The operation sends a typed Delete request for each ID and reports no new IDs or legacy fallback through the shared listener. The test waits for completion and checks one local message is gone for EWS and Graph. It does not establish real Graph permanent retention semantics or partial-failure behavior.

Scope: Graph message deletion operation.
