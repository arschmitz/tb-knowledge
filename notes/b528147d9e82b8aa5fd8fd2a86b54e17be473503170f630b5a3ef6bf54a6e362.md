# All Mail localization separates display text from the server folder name

The patch loads folder-name-all-mail into a cached localized string and uses it for All Mail display text. Its IMAP fixture expects the Fluent value while keeping the raw name All Mail and an empty database folder-name override. The original return is nested under Archive plus AllMail; accepted code later checks AllMail separately and has a remote-folder localization gate. The translator comment asks for the Gmail web UI wording in that language, without assuming the app and web account use the same locale. No server rename, localized UI or test execution is claimed.

Scope: folder-names.
