# The Yahoo/AOL notification indicator is removed by a versioned UI cleanup

The removal patch deletes the notification default and initializer write, then clears its user value for eligible profiles below UI version 58. New profiles skip these version blocks, and already-current profiles return early. This cleanup does not itself migrate account authentication or enable PKCE. Accepted source retains the pre58 cleanup and no OAuth write, while the old name remains in telemetry declarations. Keep removal of live preference writes separate from textual name retention or a successful auth/upgrade result.

Scope: Yahoo/AOL notification preference removal.
