# Align Nightly gates across an experimental preference and its tests

Conversation-view exposure is gated in the default preference, preference registration, markup, telemetry registration and browser test. Current General preferences also use offerExperimentalFeatures to control visibility when the Nightly element exists. Changing one layer alone can leave an absent element with a binding/test or expose a setting outside its intended build. The checkbox binding does not prove the conversation implementation is complete.

Scope: mail/app/profile.
