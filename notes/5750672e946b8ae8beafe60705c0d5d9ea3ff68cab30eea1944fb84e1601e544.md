# The initial Graph generator translates a selected schema subset

The first generator reads a local OpenAPI file, limits output to four named types, extracts supported properties and emits Rust tokens. Navigation/odata properties and unsupported refs can be skipped; nested arrays and binary conversion are explicit todo paths, with other unsupported schema/format cases able to panic. Sorted emitted names do not prove full-schema support or byte-for-byte reproducibility. Current source has later object/enum/path support files and typed output; keep that later pipeline separate.

Scope: ms_graph_tb initial generator pipeline.
