# Installer path defines now use the shared package variables

The Makefile gets BINPATH and FINDPATH from MOZ_PKG_BINPATH, RESPATH from MOZ_PKG_RESPATH, and Darwin APPNAME from MOZ_MACBUNDLE_NAME. The selected manifest and package-compare target consume these defines and paths. This replaces local platform guesses with a shared configuration boundary, but the upstream definitions and generated package results were not inspected or executed. No Mac installer/build result is claimed.

Scope: Thunderbird installer package-path configuration.
