# Legacy Exchange XML keeps ewsURL while the account model uses exchangeURL

For the legacy combined type="exchange" input, the fixed accepted parser reads external ewsURL and stores it as incoming.exchangeURL. Its regression test supplies <ewsURL> and checks the internal Exchange endpoint. The original Graph manual patch renamed that XML input key together with the model property. These are separate source contracts; an internal endpoint rename does not establish an external XML schema change.

Scope: accountcreation/external-xml-model-boundary.
