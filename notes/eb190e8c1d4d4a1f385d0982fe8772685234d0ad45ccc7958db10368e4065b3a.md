# Return the new draft message key through the copy listener

1108 reads the created local header's message key and calls SetMessageKey for draft saves so a later save can replace the earlier draft. Ordinary copies do not take this branch. The accepted current draft test exercises composing and saving one draft for EWS and Graph, then checks a count of one; that test alone does not cover replacing a previous draft or listener-key propagation. Keep the key handoff in a draft lifecycle review and record that coverage gap.

Scope: EWS historical draft replacement key handoff.
