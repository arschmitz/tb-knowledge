# Retain explicit history decisions at external-link callers

The 1171 migration replaces direct protocol-service calls across help links, calendar attachments, chat and other UI paths. Current representative callers pass addToHistory false, while ordinary LinkHelper calls default to history insertion. The IM context-menu path also supplies its source principal. Scoped recommendation: preserve the caller’s history and principal decisions when extracting a wrapper; do not infer that every URL opened by Thunderbird should or should not enter Places. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: calendar/base/content.
