# The address collector is a privileged module function rather than a native service

1551 removes the native address-collector IDL, registration and implementation, and registers AddressCollector.sys.mjs. Accepted send and Gloda callers use collectSingleAddress. Changes to this family must follow its module/resource integration instead of resurrecting the old service contract. Bounded accepted-source checks confirm the old collector IDL and C++ file are absent. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/compose/src.
