# The historical native NS_OK status sentinel carries already formatted text

1563 makes native OnStatus treat NS_OK as a preformatted status string, avoid FormatStatusMessage in that branch and reject a missing string. This is a dated sentinel contract where zero means a valid success status, not absent input. The native feedback file/IDL are absent at the accepted endpoint, which instead exposes explicit string reportStatus; do not teach the old method as current. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
