# Dataset deletion state needs a boolean value and a literal string comparison

The controllers convert IMAPDeleted bit tests to booleans and write dataset.imapDeleted. DOM dataset values are strings; the shift-click path checks == "false" before choosing permanent deletion. Scoped manual syntax recommendation in these handlers: keep the boolean conversion and literal dataset comparison. Testing dataset.imapDeleted for truthiness would treat the string "false" as true. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: message deletion bitmask and dataset representation.
