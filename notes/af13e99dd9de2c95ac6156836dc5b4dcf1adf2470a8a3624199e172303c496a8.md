# Read QR account eligibility from both protocol and identity contracts

Accepted QR export requires a default identity, IMAP or POP3 incoming server, supported authentication, a nonempty ASCII identity email and an SMTP outgoing server with supported authentication. It now uses the default outgoing server when smtpServerKey is empty, unlike the original landing. The current test expects that fallback account to be eligible and removes created account state afterwards. The source policy describes this export implementation; it is not independent evidence of every current mobile capability. Read the branches and tests rather than relying only on the shorter eligibility comment.

Scope: mail/qrexport/eligibility.
