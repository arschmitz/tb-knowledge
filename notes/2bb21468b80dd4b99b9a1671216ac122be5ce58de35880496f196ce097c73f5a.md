# Extension status preferences count active non-special buckets and refresh on enable changes

hasExtensionsInstalled counts successfully parsed active extensions that are not system, builtin or privileged. hasExperimentsInstalled adds the Experiment and not-allowlisted conditions. MailGlue refreshes these values on enable/disable as well as install/uninstall and startup. Experiment suppression remains a separate predicate and blocklist update. The existing install/uninstall test is not direct coverage of every added flag combination, and no telemetry result or callback race is inferred.

Scope: Extension status preferences.
