# The standalone attendee fixture uses a different element shape from the registered customized li

The component registration declares extends:li, and production constructs a li with is=calendar-dialog-attendee. The standalone fixture instead writes a calendar-dialog-attendee tag and its setup selects that tag before invoking setAttendee. This exact source-shape mismatch remains in accepted source. Fixture presence alone therefore does not establish that the selected element supplies the registered customized-li method. No runtime failure or engine-specific exception was tested.

Scope: Calendar attendee test fixture contract.
