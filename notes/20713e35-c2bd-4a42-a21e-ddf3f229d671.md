# Retest every action renderer after the unified toolbar split

The browser action moved to the unified toolbar, while compose and message-display actions kept the older toolbar implementation. Before Bug 1873455, title and label UI tests existed only for browser action because the buttons once shared an implementation. The patch adds live tooltip and label assertions to compose and message-display tests and verifies that setting label does not change tooltip. Shared API code no longer means shared rendering code; test each action surface. The matching test files use browser_ext_browserAction_properties.js, browser_ext_composeAction_properties.js, and browser_ext_messageDisplayAction_properties.js, preserving API camelCase in this component.

Scope: Extension action tests.
