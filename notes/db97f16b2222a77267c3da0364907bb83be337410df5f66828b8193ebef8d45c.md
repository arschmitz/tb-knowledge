# Verify offline download by consuming the message stream

Entry 1169 replaces an open/close-only stream check with service.streamMessage and an awaited PromiseStreamListener. Accepted verifyDownloaded checks the Offline flag and uses localOnly true for every message. The helper reads delivered chunks and rejects a non-NS_OK completion. This checks local readability through completion when run; the task does not compare the returned text with the original fixture or assert exact message size. This is source and test inspection only.
