# Wait for a Calendar item load before starting a replacement load

The read dialog can receive a new item while an earlier asynchronous load is still running. Track loading and reload state, let the current load finish, then load the replacement; concurrent loads can overwrite each other's UI.

Scope: calendar-dialog.
