# The AppUpdatePin port reads its direct telemetry oracle from the metrics ping

This test landing replaces legacy scalar access with Glean.update.versionPin.testGetValue("metrics"). It initializes the profile and FOG once, resets FOG after each awaited policy setup, and then checks the generated URL plus the pin value or null. The explicit test limit remains: it does not establish which update version the server serves or the client applies. The fixed accepted test matches the landing. Upstream policy/update-checker/FOG implementations and telemetry submission were not paired or executed; this is a scoped test-oracle fact, not a general Glean setup rule.

Scope: Enterprise policy xpcshell tests.
