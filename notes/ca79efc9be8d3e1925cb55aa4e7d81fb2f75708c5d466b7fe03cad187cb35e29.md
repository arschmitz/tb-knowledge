# Automation-only key-swap logging records tracker transitions without adding a new swap strategy

automationOnlyLog writes to console.warn only in automation. Its callers record replayed keys, current ID associations, remapping and decoupling. The added attachment-delete newId lookup uses the read-only _get helper; the branch still updates oldId and decouples its old identifier. Diagnostic arguments are evaluated outside the helper guard. This patch provides evidence for investigating a failure, not a reproduced failure or a new repair algorithm.

Scope: WebExtension message tracker diagnostics.
