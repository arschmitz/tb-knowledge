# Invitation calendar preselection uses the found holder before the live default property

This invitation chooser passes the found non-composite calendar's ID as preselectId. If no such holder exists, it reads the default property from the eligible calendars at prompt time. The dialog only overrides its existing initial selection when that ID matches a listed calendar. A single matching eligible calendar is selected without opening the dialog. Tests inspect chooser arguments through a stub and separately check memory-calendar writes; they do not prove native dialog focus or visible selection. Search ranking uses the configured sort-order preference, without establishing a universal manager/provider order.

Scope: calendar-itip.
