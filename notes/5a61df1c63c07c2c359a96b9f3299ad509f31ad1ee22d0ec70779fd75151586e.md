# The shared arrow icon replacement preserves platform-specific sort mappings

The inspected Linux selector maps ascending to the down token and descending to up. macOS and Windows map ascending to up and descending to down. The resource-to-token replacement preserves each mapping. Keep the platform/selector scope when using this evidence; it does not establish a universal arrow-direction convention or a rendered sorting result.

Scope: Platform tree sort icons.
