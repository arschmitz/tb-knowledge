# QR export resolves stored SMTP passwords before serializing accounts and initializing the wizard

getAccountData awaits the stored SMTP lookup before placing its result in the account array. getQRCodes waits for all selected accounts before JSON serialization, and the wizard waits for those codes before setting its first step. The regression test keeps a Login Manager password, clears the server cache, and checks the exported SMTP string. This establishes the specific fallback and completion chain. It does not prove Android import, per-account rejection recovery or cancellation, and no credential export or test ran.

Scope: QR export asynchronous password and wizard completion.
