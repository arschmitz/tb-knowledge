# The thread-row click precheck is optional and its native-role check depends on resetEnv's return

Without a supplied setEnv member, prepare_thread_row_descendant_click returns without checking row semantics. With that object, it waits for DOM treegrid/row roles, but only asserts native ROLE_ROW if resetEnv() returns undefined; it then suppresses the named accessible-target rule. A missing Accessible triggers two forced100ms refresh ticks before another query. These exact branches limit any claim that every migrated click received unconditional native validation; no upstream return contract or live accessibility run was established.

Scope: MailViewHelpers semantic precheck and one-rule synthetic-click exception.
