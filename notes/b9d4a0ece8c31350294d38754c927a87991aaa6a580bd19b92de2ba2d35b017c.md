# Setting a Panorama folder name does not perform a physical rename

The name setter persists a database name. The inspected direct test changes folderA.name to alpha while filePath.leafName and URI remain folderA and lookup by the new URL fails. Use the actual Rename operation when its filesystem/move contract is needed. Default mailbox startup also checks existing name and special flags before creation. Current FolderDatabase updates cached name only after SQL succeeds; full rollback and descendant path behavior remain separate gaps.

Scope: Folder name and storage identity.
