# MIME-generation failure rejects the send Promise before the compose success path

MessageSend.createAndSendMessage is async. Its MIME-generation catch notifies failure and throws the original error. The compose frontend awaits the send Promise and returns from its catch before the success close; it does not inspect a fulfilled null value. The added secondary-identity S/MIME task directly checks that the compose window stays open and the stored draft count remains. Its arbitrary one-second wait limits completion coverage; no runtime result or general XPCOM rule follows.

Scope: Thunderbird compose pre-delivery failure.
