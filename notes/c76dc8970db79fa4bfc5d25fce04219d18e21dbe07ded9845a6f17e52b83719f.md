# Return only a matching copy request, never the last candidate

FindRequest keeps matchingRequest null until a candidate passes source support identity and destination checks. The old loop variable could remain a nonmatching candidate at loop end. Accepted code also skips mPendingRemoval requests. Preserve the separate candidate/result names and explicit match assignment in this request-matching function.
