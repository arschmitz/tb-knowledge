# The Thundermail divider keeps text color separate from its line bars

The divider is a div with a localized text span whose English value is or. Its color property uses color-text-secondary, while the before/after line bars explicitly use color-surface-border as their background. The owned fix changes only the text token. Header visibility is separately gated by the Thundermail preference, and accepted markup has later form/title changes. Local light/dark token definitions support that scoped role; they do not prove measured contrast, custom-theme rendering or a global ban on icon color tokens.

Scope: Thunderbird Account Hub divider styling.
