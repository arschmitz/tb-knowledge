# Removing clicked-URL IMAP subscription keeps internal subscription commands and the external fetch guard

The removal deletes the prompt-and-subscribe branch from NewChannel, but AsyncOpen still limits externally marked URLs to message fetch and fetch-peek. Internal URL construction clears the external flag, and SubscribeFolder still queues a subscribe command. Keep these separate contracts when describing this removal. The author’s uncertainty about dead code is not a reachability proof; no clicked-URL, server or security test ran.

Scope: IMAP channel and subscription routing.
