# Account Hub captures initial identity before publishing form validity

The email widget stores realName/email before it emits config-updated and returns that object from captureState. Manual entry lets the controller build and fill an AccountConfig, then records the return step. The historical branch selected EWS or incoming manual forms; accepted source adds later preference-driven routing. Current widget assertions check the identity shape and completion, but do not assert a capture from inside the validity event callback. No account was created and no browser test ran.

Scope: Account Hub email form state ownership.
