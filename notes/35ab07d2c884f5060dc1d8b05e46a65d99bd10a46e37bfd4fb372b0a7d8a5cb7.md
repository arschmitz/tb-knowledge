# The initial Git ignore list and later vendored exceptions are separate phases

The initial ignore file combines root-anchored /obj*/ with explicit tool/build output paths and broad *.orig/*.rej patterns. Accepted later source adds negations for vendored Cargo.toml.orig and dotfiles, plus more root config/editor rules. Keep those phases separate. Ignore patterns do not establish deletion of tracked files or a new rule to exclude all generated source from study. No Git operation or build was executed.

Scope: Repository Git ignore configuration.
