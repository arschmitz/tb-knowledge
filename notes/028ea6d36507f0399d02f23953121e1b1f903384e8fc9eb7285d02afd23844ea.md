# Clear a stale offline flag when the header has no local store token

Entry 1003 and accepted GetMsgInputStream clear Offline and return NS_ERROR_FAILURE when storeToken is empty. The function does not fabricate a stream. Current IMAP HasMsgOffline initially uses offline-copy information, and opening a local stream can still fail. This repair makes later cache decisions able to see no local copy, but does not guarantee that every caller retries the network in the same operation. The protocol’s local-path helper returns false on a stream-open failure. Keep local state repair and request recovery as distinct claims.

Scope: mailnews/base/src.
