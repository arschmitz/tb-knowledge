# The tab popup gates moving by closability and defers persistence to the move command

Opening the tab popup sets the Move to New Window disabled attribute from !canClose. It no longer calls persistTab to decide attribute presence. The command still calls replaceTabWithWindow, which checks tab count, closability and a usable persistence result. persistTab returns an object or null; menu availability is not a successful-transfer result. This exact receiver is a window command despite the historical title saying New Tab.

Scope: Tab context menu and window transfer.
