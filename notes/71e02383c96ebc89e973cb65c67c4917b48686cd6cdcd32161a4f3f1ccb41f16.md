# Do not restart for an empty feed migration batch

Entry 907 initially calls Promise.all(migrations).then(restart) even when no feed account needs migration. Context-only entry 946 adds a migrations.length guard, retained by the fixed accepted code. An empty promise collection resolves too; reaching a version gate is not proof that work happened. Keep the guard when editing this migration. The exact regression discussion and runtime restart behavior remain pending.

Scope: mail/modules/MailMigrator.sys.mjs.
