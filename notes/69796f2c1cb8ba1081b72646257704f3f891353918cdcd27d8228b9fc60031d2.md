# Handle zero new messages before slicing the NEW-key list

_getNewMsgKeysNotNotified returns [] when getNumNewMessages(false) is zero, before using slice(-count). In JavaScript slice(-0) behaves like slice(0), which would otherwise keep the complete list. The inspected helper limits keys to the folder new-count tail and then applies its time watermark. Retain the zero guard when changing this sequence; the source does not establish database NEW-list ordering for every producer. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Mail notification zero-count boundary.
