# DeferredTask separates delayed requests, running work and final callback release

Each section is a checked body contract at Firefox revision `1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b`. These records describe source behavior. They do not promote source patterns into coding policy.

## DeferredTask.constructor

Trigger: BookmarkList.addListeners creates a delayed callback task.

Stores callback, delay and idle timeout; records caller/profiler marker. Detects the callback global. A window callback uses a weak reference to that window for window-specific timers/idle dispatch.

Result and completion: Returns inactive task. No callback is scheduled until arm.

Errors: No separate error handling in this body; caller receives thrown errors or promise rejection.

Ownership and cleanup: Task retains callback until finalize completion; callback closure can retain window. Window weak reference is kept after callback release.

## DeferredTask.#startTimer

Evidence: [DeferredTask.#startTimer:215-241](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/modules/DeferredTask.sys.mjs#L215-L241).

Trigger: arm starts idle task, or a completed task schedules a rearmed run.

Idle timeout zero calls task directly after delay. Otherwise timer dispatches an idle callback that checks original timer identity, suppressing callbacks after disarm/rearm/finalize. Uses window setTimeout when a window ref exists, otherwise nsITimer.

Result and completion: Stores timer handle; task begins only when its chosen callback fires.

Errors: A missing expected window reference throws instead of falling back to non-window scheduling.

Ownership and cleanup: Task owns timer handle; disarm clears/cancels it.

## DeferredTask.arm

Evidence: [DeferredTask.arm:277-290](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/modules/DeferredTask.sys.mjs#L277-L290).

Trigger: BookmarkList updates cache and requests its observer callback.

Throws after finalization. Marks armed. Starts one timer only when task is not running and no timer already exists. Repeated arms do not extend existing delay. Arm during execution requests a later run.

Result and completion: Synchronous undefined. Does not return the callback result or a completion promise.

Errors: Throws Unable to arm timer when finalized.

Ownership and cleanup: Timer and callback remain with task until disarm/finalize; running task is not re-entered.

Trigger: BookmarkList.removeListeners cancels a pending observer request.

Clears armed flag. Cancels native timer or clears window timeout and removes handle. Does not cancel a callback already executing.

Result and completion: Synchronous undefined. A running callback still finishes on its existing promise.

Errors: No separate error handling in this body; caller receives thrown errors or promise rejection.

Ownership and cleanup: Releases pending timer handle while retaining running work until completion.

## DeferredTask.finalize

Evidence: [DeferredTask.finalize:332-353](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/modules/DeferredTask.sys.mjs#L332-L353).

Trigger: BookmarkList removes listeners or another owner shuts down.

Throws on a second call. Marks finalized. If timer exists, disarms and runs callback immediately; if work is running, attaches callback release and returns its promise. Otherwise releases callback and returns resolved promise. Armed work during a running callback gets one final immediate run.

Result and completion: Resolves undefined after final callback execution. Task callback errors are logged by #runTask, not propagated as its result.

Errors: No separate error handling in this body; caller receives thrown errors or promise rejection.

Ownership and cleanup: Releases #taskFn after running promise settles; keeps the weak window-reference object.

Unresolved: BookmarkList calls disarm first and does not await finalize; it suppresses pending observer work but does not wait for a running observer.

## DeferredTask.#timerCallback

Evidence: [DeferredTask.#timerCallback:366-402](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/modules/DeferredTask.sys.mjs#L366-L402).

Trigger: Timer expiry or finalize starts execution.

Sets timer null, armed false and runningPromise before task starts. Awaits callback, then if rearmed schedules a new delay unless finalized; finalized rearm runs once immediately and clears armed. Sets runningPromise null on normal completion.

Result and completion: Running promise fulfills after this sequence. Outer catch logs unexpected scheduling errors.

Errors: Outer errors are catch-logged. If an unexpected error occurs before the normal assignment, _runningPromise can remain non-null; this branch was not reproduced.

Ownership and cleanup: Maintains one running promise so arm cannot overlap callback invocations.
