# Give the Mork EWS lookup the exact UTF-8 byte length

GetMsgHdrForEwsItemID converts the ewsId property name to a Mork token and makes an mdbYarn from the AUTF8String pointer with Fill and Size set to itemID.Length(). Its comment explains the pointer need not be NUL-terminated because the length is explicit. FindRow returns the row ID and row; a found row becomes a message header, while a missing row returns NS_OK with a null output. Current callers check the null header separately from nsresult failure. Do not use a C-string length assumption for this input.

Scope: Message database and Exchange.
