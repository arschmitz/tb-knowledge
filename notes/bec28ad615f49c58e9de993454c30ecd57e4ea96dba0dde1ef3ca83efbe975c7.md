# Outlook runnable success is separate from its import result

ImportMailboxRunnable records store/database/setup failures in mResult and returns NS_OK from Run. ProxyImportMailbox first checks synchronous dispatch, then returns the recorded import result. Changing Run to return the import error would change that named caller contract. The importer still leaves finish/token calls unchecked after counting an imported message; review explicitly defers that wider error overhaul. This preserves the distinction between a dispatch result and an import result without endorsing unchecked finalization. No Outlook or native dispatch test ran.

Scope: Outlook import result channels.
