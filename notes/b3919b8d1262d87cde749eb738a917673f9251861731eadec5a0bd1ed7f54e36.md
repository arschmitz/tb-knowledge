# New-mail batching is a trailing delay per folder

Pending arrays and DeferredTask instances are keyed by the folder object. Each accepted new message is pushed, then its task is disarmed and armed again with NOTIFICATION_COLLAPSE_TIME, currently 200. The callback emits one nonempty messages-received batch and deletes the pending array. This is a delay restarted by arrivals, not an immediate event per message or a fixed number of messages. No timing experiment was run. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: WebExtension per-folder batching.
