# Use the Mozilla ESLint package config export for the relevant harness

Entries 2060 and 2065 stop deep-importing eslint-plugin-mozilla/lib/configs and remove a redundant local static-test config. The legacy root override spread both the config and its rules so func-names could be changed without discarding inherited rules.
