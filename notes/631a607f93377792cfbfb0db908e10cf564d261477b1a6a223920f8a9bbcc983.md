# Server-settings test setup dismisses the existing Account Hub dialog before creating accounts

The server-settings setup first queries account-hub-container and calls close on its internal shadow-root dialog, then creates the test accounts. The container implementation supplies that dialog from its cloned template. An absent host short-circuits the call; the setup does not wait for later initialization, a close event or a closed-state assertion. This is a test setup phase separate from the earlier reopened-input keyboard receiver repair. It does not establish a native overlay/focus result or cure the separate reported CI failure. The related Account Hub lifecycle assertions remain a separate contract.

Scope: Account Manager browser-test startup state.
