# Generate and pass the message ID before entering a protocol server

483 removes SMTP fallback ID generation and updates callers/tests to provide it. Current SMTP passes the caller ID into the envelope, MDN creates its reply ID, and MessageSend passes compFields.messageId. Protocol implementations must not independently invent an identity that disagrees with the MIME message. Historical unit updates are caller-contract coverage; no unit run was made.

Scope: mailnews/compose/src.
