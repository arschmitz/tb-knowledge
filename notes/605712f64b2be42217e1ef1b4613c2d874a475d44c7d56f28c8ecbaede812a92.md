# Address Book creation checks guard a missing directory after finding its row

If the selected row exists but getDirectoryFromUID returns null, the new book && guards avoid reading readOnly and supportsMailingLists. They return falsy null on that path, rather than the literal Boolean described by the existing JSDoc. The checked command controller forwards callback results and tests falsiness before dispatch. This supports the narrow null-lookup boundary; it does not prove the suspected removal race occurred, fix every deletion path or set a global return-style rule.

Scope: Address-book command permission state.
