# Message-window XUL-store logging brackets completion rather than repairing resize state

The shared helper now dumps stored messageWindow.xhtml IDs/attributes/values before opening and after its document and MsgLoaded waits. openedMsgWindowCount increments only after those waits, so A/B describe a helper-opening sequence rather than the number of currently open windows. The added code reads and logs state; it does not clear the store, assert geometry or repair a resize. No message window or test ran.

Scope: WebExtension browser-test message window diagnostics.
