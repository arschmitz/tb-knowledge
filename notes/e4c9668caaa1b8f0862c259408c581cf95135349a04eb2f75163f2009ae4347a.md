# The secure-load landing compares each S/MIME event with the last reported URI

This landing skips a nonempty S/MIME status event when its signature-or-encryption URI equals the last reported URI. A different URI replaces the cache, and MsgLoading clears it. The scheduling helper uses a timeout with no explicit delay after MsgLoaded or later status callbacks. This guard controls repeated reporting of the cached URI; it does not count pending signature completions or promise one event across every load of an email. The later accepted signature-count implementation is a separate phase. The metric fields describe present signed/encrypted state, not cryptographic validity.

Scope: Secure-mail telemetry original load-cycle guard.
