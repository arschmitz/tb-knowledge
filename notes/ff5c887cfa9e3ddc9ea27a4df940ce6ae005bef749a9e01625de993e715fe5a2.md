# The Graph batch mock uses response data objects and assumes JSON item bodies

This landing moves normal and batch dispatch through HttpResponseData. Its initial batch handler parses every dispatched body as JSON and wraps statuses in an outer200 response, which does not establish support for empty or non-JSON endpoint bodies. The fixed mock later handles empty bodies, forwards item headers and converts UTF-8. Owned createFolder retains an unused response parameter, and sendMessage JSDoc claims a tuple although the method returns HttpResponseData. These are bounded mock interface/comment facts, not live Graph guarantees.

Scope: Graph fake-server batch dispatch.
