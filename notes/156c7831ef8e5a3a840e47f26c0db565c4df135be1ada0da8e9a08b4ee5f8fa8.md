# Open and Show normalizes the rebuilt signed-part prefix before appending multipart bytes

viewSignedPart removes a non-attached parent Content-Type including its trailing newline, trims the retained parent headers, then combines signed-part headers and preamble. It normalizes the assembled prefix to two CRLF sequences before adding the signed multipart bytes from the original message. The attached-message branch omits parent headers. This scoped separator fix is distinct from earlier boundary selection and later line wrapping; it does not promise complete header-byte preservation or all MIME layouts.

Scope: nested-signed-message-serialization.
