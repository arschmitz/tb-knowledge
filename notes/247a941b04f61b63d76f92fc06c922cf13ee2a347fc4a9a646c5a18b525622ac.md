# The tabs documentId port pairs schema options with child forwarding

This landing permits an optional string documentId in both tabs.connect and tabs.sendMessage options, and forwards the value through the existing child messenger calls. connect supplies null when omitted; sendMessage uses optional property access. The checked accepted code retains those local contracts. The related getContexts test checks document identity after navigation, rather than targeting messages or ports by that identity. The inherited Gecko messenger receiver is not paired here, and no targeted routing or live extension test was run.

Scope: MailExtension tabs API.
