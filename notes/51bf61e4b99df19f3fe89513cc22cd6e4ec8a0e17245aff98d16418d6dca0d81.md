# The new identity-folder test omits messages on sixteen scalar assertion sites

The unset, missing-folder, remote-error fallback and deferred-POP subtests each assert parent URI, name, special flag and folder URI without a message argument. These sixteen sites are in the newly added identity-folder test file, even where the assertion pattern came from its predecessor. Add nonempty messages that state which folder result should match; an info call or task name is separate from the assertion. The existing-target test also sets URI attributes before calling the getter, so its flag check includes setup effects. No unit test or native folder operation ran.

Scope: Identity special-folder unit tests.
