# Notification popup padding selects density-specific wide tokens

The notification popup overrides --button-padding with --button-padding-wide. The default pair is 6px 14px and compact density uses 3px 9px; ordinary button padding remains a separate token. The same patch adds 32px/30px minimum-height tokens. These declarations establish selector/density values, not computed popup layout or proof that every upstream button consumes each token.

Scope: Notification popup button CSS tokens.
