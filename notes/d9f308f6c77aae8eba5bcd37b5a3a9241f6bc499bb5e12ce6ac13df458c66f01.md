# The Calendar attachments overview count and hidden state are separate from list contents

For nonempty attachments, the parent sets the count metadata and list data, then shows the overview row. Empty input hides the row; reset separately clears the list and hides it. The expansion button switches subview, and tests directly check count metadata, visibility and switching. They do not validate rendered plural strings or keyboard/accessible behavior. Keep this overview phase separate from the earlier item/list and parent-mapping commits.

Scope: Calendar attachment overview and subview controls.
