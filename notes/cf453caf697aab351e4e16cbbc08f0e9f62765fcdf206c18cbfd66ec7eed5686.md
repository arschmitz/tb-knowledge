# The alarm ignore-list migration stays pending while missed alarms are enabled

The cleanup helper returns without setting legacyCleared while showmissed is true. When permitted, it removes no-ack-format entries from currently registered calendars, keeps ack-bearing entries and then sets the global completion flag. startup calls the helper; the patch adds no live preference-change callback that runs it immediately on a toggle. The tests call the helper directly and assert format retention/removal and the flag. These checks do not prove recovery of every unregistered calendar or a native restart.

Scope: Calendar alarm migration.
