# Calendar acceptance selectors use the production radio ID and label target

The acceptance stylesheet must target the production radio input and its label target. This patch changes both checked-state selectors from not-going to notGoing, matching the production template. The static story uses a different spelling and is a separate receiver; do not select an ID from that preview without checking the actual consumer. This is a local selector correction, not a repository-wide naming rule.

Scope: calendar-dialog-acceptance.
