# Return native IMAP transport failure before continuing setup

The historical change removes the trySTARTTLS retry as a plain transport. Current SetupWithUrlCallback creates ssl or starttls transport according to the named enum and immediately applies NS_ENSURE_SUCCESS to CreateTransport. Later STARTTLS failure closes the transport and sets failure status for required TLS. Preserve those failure boundaries when changing transport setup. The JS IMAP implementation modified in 2024 is absent from the fixed accepted source, so this current claim is scoped to native IMAP.

Scope: mailnews/imap/src.
