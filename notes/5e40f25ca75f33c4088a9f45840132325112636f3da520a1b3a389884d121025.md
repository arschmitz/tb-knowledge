# Use separate card-state tokens for focused and unfocused selection

The historical dark-theme fix changed the unfocused card mix colors. Current accepted CSS uses newer light-dark mixes with layout-background-3, so its old gray-50 percentages are not current constants. It retains distinct current, selected, selected-current and unfocused tokens, and selects the unfocused family under :not(:focus, :focus-within). Preserve state separation when changing card colors. Forced-colors has separate system-color tokens. No visual or contrast check ran.

Scope: mail/themes/shared.
