# Null-check optional Error causes in Account Hub notification fallbacks

The current header reads error.cause through optional chaining in its log and title fallback. Its component test explicitly supplies a plain Error with no cause and verifies the raw title takes error.message without Fluent attributes. Preserve this optional-cause path when adding structured errors. Error type annotations alone do not guarantee a cause object. The source test was inspected but not run.

Scope: mail/components/accountcreation.
