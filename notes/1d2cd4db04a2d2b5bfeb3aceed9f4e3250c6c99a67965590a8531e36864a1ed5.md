# Collect tab-load state inside the idle callback in the current helper

The 1906202 landing delays Promise.all and tab-property collection through requestIdleCallback, but still builds the content-tab load promises before that callback. Fixed get_tabs.js moves enumeration and listener registration inside idle too. It waits only for content tabs whose webProgress is absent or loading, ignores about:blank load events and removes each listener after another load. The command-line test reads the returned tab summaries through an asynchronous script. This is not a guarantee that non-content tabs, all future tab opens or every network action have completed. The old tabs.js path is absent, and Bug human comment6 is unavailable. No Marionette or runtime test ran.

Scope: Marionette tab collection timing.
