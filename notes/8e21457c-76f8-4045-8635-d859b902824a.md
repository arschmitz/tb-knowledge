# Moving a recurring series changes an exception ID but preserves its chosen start

An exception recurrenceId identifies the original series slot; its startDate is the independently moved event time. When onStartDateChange shifts the series, it shifts RDATE/EXDATE and the exception recurrenceId, but must not shift the exception startDate. Bug 1890975 reported a manually moved exception being moved again when the series start changed. The accepted fix removed shiftOffset(ex, timeDiff). Current code and test keep the slot at 14:45 after a three-hour series shift while the exception remains at 12:45. Test both values whenever changing recurrence shifting.

Scope: Calendar recurrence exceptions.
