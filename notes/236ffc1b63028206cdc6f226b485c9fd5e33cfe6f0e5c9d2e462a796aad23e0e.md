# The mozcheck task follow-up adds binary fetches and nests the shebang option

The follow-up adds linux64-mozcheck fetches to file-perm, file-whitespace, license and trojan-source tasks, adds its toolchain reference together with linux64-rust-static, and nests allow-shebang under check-config for the script permission variant. Fixed accepted configuration retains these inputs. The comm wrapper forwards the configuration to mozcheck; backend schema, artifact availability and actual lint execution remain unpaired. Historical missing-binary reports explain the change but do not prove a fresh successful lint run.

Scope: Thunderbird Rust-backed lint infrastructure.
