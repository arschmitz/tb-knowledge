# MailStream exposes header bytes while preserving the sequential message

MailStream buffers through the blank header separator, exposes that block as a borrowed Span and serves buffered bytes before continuing on the underlying stream. FirstLine includes CRLF/LF and returns an empty span for an incomplete line. The caller must keep the wrapper alive while using the header view. The tests directly compare header and full-message bytes before and after reading; they do not establish a fresh runtime result, general thread safety or failure recovery.

Scope: MailNews MailStream buffering contract.
