# Remote-content separator visibility now depends on URL origins alone

The menu subtracts its optional author-email principal from the URL-origin count. Allow All stays collapsed below two URL origins, but both separators now collapse only at zero URLs. The previous separator condition also used the address count, so email-only and one-URL-without-email states change with this localization patch. Display labels strip the email URI prefix while stored command values retain the original origin. These are scoped DOM-state conditions, not a tested visual defect or permission change.

Scope: Remote-content options menu state.
