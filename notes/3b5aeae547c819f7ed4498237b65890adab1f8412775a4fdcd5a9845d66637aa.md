# Exchange reapplies load flags and load group to the returned read request

Before an offline read request exists, ExchangeMessageChannel stores load flags and load group in its own fields. Once the request exists, their getters and setters delegate. StartMessageReadFromStore explicitly applies both saved values after AsyncReadMessageFromStore. The helper still carries a TODO about doing this automatically. Do not assume a pump receives the source channel load configuration merely because the channel was passed to the helper. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Exchange read request configuration.
