# Make regional date preference behavior explicit in the real controls

Entry 1065 defaults intl.regional_prefs.use_os_locales to false. Current general preferences compare the base app and regional languages and hide the radio fieldset when they match, except during automation. The comment says the regional locale is used in that case regardless of the preference. Labels and access keys are set on the real radio controls. Describe this UI rule as the accepted comm implementation/comment; the paired Gecko locale policy was not independently verified. Do not assume the raw preference value alone determines all displayed formatting. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/preferences/regional-formatting.
