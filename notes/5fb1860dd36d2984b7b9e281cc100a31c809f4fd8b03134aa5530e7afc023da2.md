# The deletion fixture avoids a batch boundary and retains a stale selection comment

The virtual-folder fixture deliberately uses 2 and 13 messages so tested selections avoid a physical-folder boundary while _doDelete asserts one select event. The later non-adjacent scenario expects message 11 and selected/current index 3, but its comment still describes selecting below the first selected row. Keep that stale comment separate from the actual changed expectations. These tests directly check bounded selection/message results; the fixture adjustment does not establish coverage of every multi-batch deletion or mixed IMAP delete model.

Scope: Thread-tree deletion test coverage.
