# The mark-all callback retains its folder and undo window while remote work is pending

The success lambda captures self and the optional message window as RefPtr values. The listener owns that lambda until the asynchronous work releases it. The normal branch uses the retained window to add the undo action after local commit. This source proves a scoped ownership choice; it does not establish a general strong-pointer policy or measure shutdown cost.

Scope: Exchange callback ownership.
