# Report leaked status-bar state before repairing test cleanup

The 727 helper asserts missing timers, stopped meteors, hidden determinate progress, zero start requests and no active processes before clearing broken state. Current clearStatusBar retains this diagnostic-before-repair pattern and uses FeedbackService stop-meteors. promiseServerIdle delegates to that shared helper after protocol idle. Preserve failed assertions while repairing leaked state so a cleanup fallback does not silently turn a test failure into success.

Scope: mail/test/browser.
