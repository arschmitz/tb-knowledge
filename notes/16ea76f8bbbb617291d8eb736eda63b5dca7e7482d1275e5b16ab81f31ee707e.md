# Compose Findbar replacement styling overrides inherited layout narrowly

1924 adds flex-direction:initial to #findbar-replaceButton. The current override also resets min-inline-size and block margin, and hides only its toolbarbutton-icon child. The compose FindToolbar is tied to messageEditor. Scoped manual CSS recommendation for this widget: inspect inherited button layout and override the affected selector locally; use the current logical size property when extending this rule. No computed-style, zoom, RTL, keyboard or screen-reader check was performed. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Compose Findbar inheritance.
