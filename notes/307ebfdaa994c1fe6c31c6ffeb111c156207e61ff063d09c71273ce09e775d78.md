# The plain-text renderers defer eligible blank lines until later content

This landing adds a per-object blank-line count behind a static preference. Eligible unquoted, non-signature empty lines return before normal rendering. Later content replays that count using the fixed or flowed renderer's own line markup; a count left at EOF is not replayed. The flowed guard checks both current and previous quote levels, preserving the quote-closing path. The tests inspect fixed/flowed output strings, preference-off behavior, interior gaps, a fixed quote close, and a synthetic Sig-bearing MIME shape. Their text-reader check strips tags and counts literal newlines rather than reading DOM textContent. This does not prove cryptographic canonicalization, all MIME modes, stored-body changes, or rendered UI spacing.

Scope: MIME fixed and flowed trailing blank-line rendering.
