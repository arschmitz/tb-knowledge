# Check native and JavaScript call contracts separately after an API change

Proposal for external protocol signature adaptations: identify the exact native caller and the meaning of each added argument. The historical FolderPrivileges call adds false for the new-window flag. The bug author describes JavaScript callers using defaults as a separate contract. Do not infer that every Thunderbird call has the same window behavior or that optional script arguments exempt native calls. The native method is retired at the accepted endpoint and current folder management opens its configured URL through another helper. Preserve this as historical caller evidence, not a permanent seven-argument rule. No paired Gecko build, external navigation or JavaScript-default test was run.

Scope: mailnews/imap/src.
