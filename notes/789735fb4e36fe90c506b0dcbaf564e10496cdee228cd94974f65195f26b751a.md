# Subscription-setter success does not establish rediscovery completion

The setter ignores the result of PerformExpand(nullptr) and returns NS_OK after requesting rediscovery. PerformExpand can return without work for an empty non-OAuth password and can return immediate errors; starting DiscoverAllFolders is also distinct from network completion. This caller therefore reports preference-update success rather than a verified refreshed folder pane. No error or server response was exercised, and required primary scope remains incomplete.

Scope: IMAP rediscovery return contract.
