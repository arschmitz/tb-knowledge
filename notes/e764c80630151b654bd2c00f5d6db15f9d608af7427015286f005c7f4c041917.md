# Treat the sideload telemetry port as an expectation change, not blocklist policy

1028 adds the string form of STATE_NOT_BLOCKED to expected sideload_prompt, enable and uninstall event extras. It changes a browser test only. That does not add a production blocklist decision or prove soft-blocking behavior. The accepted sideload test no longer contains this legacy event expectation; retain the 2024 schema adaptation as historical context and recheck the current telemetry API before extending it.

Scope: Historical sideload telemetry event extras.
