# Removing the unused root-folder registry preserves incoming-server notifications

Entry 1372 removes the account-manager add/removeRootFolderListener interface, registry and attachment helpers. The accepted interface still exposes add/removeIncomingServerListener, and its implementation still dispatches OnServerLoaded and OnServerUnloaded. Treat this as retirement of one account-manager API, not removal of ordinary folder listeners or server lifecycle notification. The commit says the replacement was unused and lacked tests; local symbol checks are bounded to comm and do not prove all downstream consumers were absent. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account-manager listener API retirement.
