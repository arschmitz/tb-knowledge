# NNTP POST saves its continuation before either authentication path

post stores the POST action before deciding whether to authenticate proactively or send immediately. A later server AUTH_REQUIRED response can then authenticate and invoke that same action, rather than resume a stale group operation. Normal client reset clears the continuation and message/article identifiers before reuse. The fake-server test checks POST/auth/POST and the received fixture bytes; it does not independently reproduce every cached-connection or error-alert case. No runtime test ran.

Scope: NNTP client action resumption.
