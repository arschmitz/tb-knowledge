# Search Messages owns the remaining legacy folder display and tree handlers

Entry 2033 deletes folderDisplay.js, threadPane.js and threadTree.inc.xhtml, removes their packaged scripts, and moves the used widget, handlers and markup into SearchDialog.js/.xhtml. The frozen tree keeps that ownership. DBViewWrapper is loaded through a lazy module getter; the widget handles UI state and callbacks while DBViewWrapper owns the view. gDBView is set before MsgCreateDBView observers run and cleared on view destruction. SearchDialog still uses script globals and providers loaded by its markup. Preserve this caller boundary when extracting code. Old shared-file names and comments about other message windows are historical context. Static source and test inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending-single-browser-reader.

Scope: Search Messages legacy UI ownership.
