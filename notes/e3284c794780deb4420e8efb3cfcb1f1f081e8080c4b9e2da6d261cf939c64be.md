# Advanced POP3 deferral now uses the selected server rather than a dead local-account getter

1937 removes getLocalFoldersAccount. The accepted POP3 UI excludes the current server from its picker, restores a deferred target when configured and disables further deferral for an account already used by another account. On acceptance, another-account selection resolves its server to an account key; returning to the current account stores an empty key. A new deferral prompts for confirmation and cancels dialog acceptance when rejected. These are the inspected current control/data boundaries, not proof of every cycle or migration case. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: POP3 deferral picker boundary.
