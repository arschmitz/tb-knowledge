# POP3 request and URL completion report the actual final status

Accepted Pop3Channel records the status before calling onStopRequest. Pop3Client passes final status to the URL listener, SetUrlState(false,status) and onDone before releasing the lock and marking the client free. State-file writing can replace the earlier status with NS_ERROR_FAILURE, so a stored request status must describe final completion rather than default NS_OK. The existing queue/lifecycle naming note is reused. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending.
