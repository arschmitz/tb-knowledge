# Bundled Botan configuration supplies compiler flags before mozbuild compiles its library

The owned Botan3 integration removes build-time Makefile/GENERATED_FILES wrapper generation and invokes Botan configure through mach python during configure. This route is gated by in-tree librnp, the Botan backend and absence of a found system Botan package. After the command, the integration reads build_config.json, shell-splits five compiler-flag fields and drops /Zc: entries. botan.mozbuild includes the shared RNP defaults first, then assigns BOTAN_CXXFLAGS as OS_CXXFLAGS and adds distinct public/internal generated include roots. Exported library name/file metadata is separate from the Library(botan) target; the inspected build consumers do not establish that those name/file exports choose the output. The owned ABI input is target-only and Windows MT is fixed; accepted compiler/sysroot preservation and ASan MD selection are later phases. Source ordering and inputs are verified; configure, generated outputs and cross-platform compatibility were not executed.

Scope: third-party/openpgp/botan-build.
