# The shared border token has an explicit forced-colors value

The port adds --border-color for roots and hosts, using a 46 percent currentColor mix by default and -moz-DialogText under forced-colors. Selected owned consumers replace older in-content border tokens while preserving selector roles, widths and the autocomplete fallback. The replacements are scoped; an unrelated old-token use remains in accepted account styling. Exact declarations and imports support this source contract, not computed-color, contrast or visual-equivalence guarantees.

Scope: Thunderbird shared CSS border token.
