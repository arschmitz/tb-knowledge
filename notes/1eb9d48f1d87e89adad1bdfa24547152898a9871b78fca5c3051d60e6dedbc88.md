# Initialize undo state before a fallible initialization path can inspect it

The nsLocalMoveCopyMsgTxn constructor initializes move/IMAP/undo flags, the copied-header counter and the folder listener pointer before Init can fail or undo callbacks can run. Current source retains these defaults, while the older m_canUndelete field is gone. Add new scalar or pointer state with its lifecycle-safe initial value in this constructor family. Do not copy obsolete members from the historical initializer list.

Scope: mailnews/local/src.
