# The Exchange unknown-host OAuth banner warns without invalidating the form

The Exchange form shows its warning when OAuth is selected and the parsed service hostname has no provider details. It still reports completion from the selected authentication value and form validity, so an unknown-host warning does not itself block continuation. The tests directly check warning visibility and config-updated.completed across authentication and account-type changes. They do not establish actual OAuth success, a native alert announcement or support-link launch. Keep this advisory Exchange contract separate from the manual IMAP/POP configuration-test guards.

Scope: Account Hub Exchange type form.
