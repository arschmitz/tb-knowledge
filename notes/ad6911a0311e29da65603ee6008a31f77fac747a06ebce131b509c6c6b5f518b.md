# Keep Cargo package spelling distinct from Rust crate identifiers

854 uses kvstore-gtest in Cargo metadata and kvstore_gtest in Rust source. Follow the language boundary: package names can contain hyphens while Rust identifiers use underscores. The current as _ form also documents link-only usage. This is a precise local naming convention, not a rule to rename all test files or project identifiers.

Scope: Cargo and Rust crate naming.
