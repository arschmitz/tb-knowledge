# Gloda count simplification preserves the two count roles while changing the Fluent ID

The display passes m=messages.length and n=FacetContext.activeSet.length to item-count-m-of-n. The en-US message directly formats those two values after the nested repeated-m selectors are removed. The consumer and resource use the same new ID. This does not change count computation or establish a pluralization rule for all locales; the reported translation-tool cause and rendered outcome were not independently tested.

Scope: Gloda facet count localization.
