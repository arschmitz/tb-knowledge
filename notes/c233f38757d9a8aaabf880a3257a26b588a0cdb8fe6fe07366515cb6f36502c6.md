# Folder deletion removes descendants but does not allow deleting a root

Historical DeleteFolder recursively deletes a copied child list because deletion mutates the parent collection. Current DeleteFolder collects descendant IDs plus the target, deletes those rows and evicts them from its cache; parent ID zero is rejected. Its TODO says message deletion/unlinking remains unresolved. Do not describe deleting folder rows as a complete message-store deletion guarantee. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama folder deletion.
