# MDN sending follows the identity outgoing server and request completion

Bug 1882574 changed the message disposition notification (MDN) generator from nsISmtpService and nsIUrlListener to the outgoing server selected for the identity and nsIRequestObserver. It sends the MDN file through that server, removes the temporary file in OnStopRequest, and uses the generic server display name in a failure message. The unit test now creates an outgoing server because processing can reach the send path. When changing outgoing sending, include automatic MDNs and their cleanup path; a compose-only test does not cover them.

Scope: Message disposition notifications.
