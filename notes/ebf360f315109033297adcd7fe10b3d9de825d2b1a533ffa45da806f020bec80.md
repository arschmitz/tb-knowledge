# Message pane names preserve file, tag, class, template and DOM selector roles

In this family message-pane.mjs and message-pane are dashed, MessagePane is the class, messagePaneTemplate/messageBrowser are lowerCamel DOM names, and the renamed findToolbar is shared by about:message and standalone-window command callers. Semantic request-count-update/show-single-message events are dashed. Keep those local mappings when refactoring callers; changing one selector requires its cross-window consumers, not a general naming sweep. This is static source and test-code inspection.
