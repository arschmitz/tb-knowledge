# Separate search adapter status from the completion output contract

The retained search IDL returns a Boolean, while the native signature returns nsresult and receives bool* for completion. The checked base Search implementation returns NS_OK without assigning that output. Treat operation status and completion as separate values, and read a concrete override and caller before claiming the output is written. This clarifies the existing adapter-retirement lesson wording; the selected base source alone does not establish every adapter implementation or runtime result. No test or generated wrapper was run.

Scope: Search adapter native output contract limit.
