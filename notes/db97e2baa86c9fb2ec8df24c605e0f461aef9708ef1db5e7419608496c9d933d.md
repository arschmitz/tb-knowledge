# Keep key-object record shapes and printable dates distinct from numeric time

Current keyObj documents UserId and SubkeyData records separately, then uses UserId[] and SubkeyData[] for their collections. Subkey expiry is printable text while expiryTime is seconds since the epoch. A scoped documentation pattern is to name reusable record shapes and state time units beside numeric fields instead of treating the formatted date string as the same value. This source pattern does not establish every keyCreated unit or every producer, which was not traced in this landing. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: OpenPGP key record documentation.
