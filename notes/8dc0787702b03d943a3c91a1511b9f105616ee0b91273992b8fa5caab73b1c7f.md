# The add-on locale test restores shared settings after its assertions

The normal task changes requestedLocales and the add-on URL preference, then explicitly restores them after its deep assertion. Its using resource owns the local server, whose disposer only invokes server.stop. An earlier thrown assertion skips the local preference/locale restoration; disposal does not replace those actions. Keep this separate from any outer harness behavior or completed asynchronous server shutdown. No failure injection or test ran, and this historical pattern does not change current harness-cleanup writing guidance.

Scope: Account-creation xpcshell shared-state cleanup.
