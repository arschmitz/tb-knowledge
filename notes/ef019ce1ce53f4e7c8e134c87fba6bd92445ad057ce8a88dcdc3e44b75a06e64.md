# Keep a solid Account Hub background while its image loads

The account dialog uses a surface background color beneath its light and dark WebP background. The adjacent comment gives the image-loading delay as the reason. Awaiting JavaScript view.ready does not establish that a CSS background image has decoded. In this dialog, retain the solid surface when replacing its background artwork. The cited >=100ms comment is an author observation, not a timing measurement performed here. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Account Hub first paint.
