# windows-rs is a fetch dependency in Thunderbird Windows tasks

The owned port moves windows-rs to fetches.fetch in Windows build defaults and Windows Searchfox, and removes it from the toolchain reference list. Fixed accepted comm source keeps that split. The fetch kind delegates to the upstream same-kind reference loader; when no reference-tasks filter exists, that loader returns all upstream inputs. This is dependency classification in comm configuration. It does not independently verify the upstream windows-rs task, bootstrap code, a generated task graph or a successful Windows build. Unrelated local toolchain entries retain their toolchain role.

Scope: Taskcluster Windows fetches.
