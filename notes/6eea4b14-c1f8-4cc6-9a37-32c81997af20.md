# Marionette command-line tests restart Thunderbird with each argument set and assert the opened UI

The first TestCommandLine suite replaced an empty test with real command-line cases. Its helper quits the app, assigns marionette.instance.app_args, starts a new session, checks the main window and exact tab modes/URLs, closes extra tabs, and clears app_args. A compose case also checks recipients and subject in the compose window. Current suite retains the restart helper and adds a --migration case. Use this pattern for startup flags because changing arguments inside an already-running session does not exercise command-line startup handling.
