# The comm release alias needs its own release_level import

The original follow-up only imports release_level into the comm attributes module, where an existing release lambda calls it. Copying that lambda into Gecko attributes does not provide a missing name in the comm module. The accepted comparison later imports from mozilla_taskgraph and passes PROJECT_RELEASE_BRANCHES with params. Keep the original missing binding separate from the later module and helper-signature phases. No graph or release result was tested.

Scope: Thunderbird Taskgraph release alias.
