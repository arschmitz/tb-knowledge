# Separate one-time element setup from reconnectable external listeners

A custom element can reconnect. Keep one-time DOM/shadow setup behind its existing-root or hasConnected guard, but register external listeners when connected and remove them when disconnected. Use the listener object this with the actual handleEvent method when this helps inherited handlers. The guide’s prose spells handleEvents, while its working example spells handleEvent; preserve the real API name. The example’s early return can skip localization-root reconnection and its attribute callback assumes a shadow root, so it is not a fully verified boilerplate to copy unchanged. Current LazyFindbar removes its browser listener and unregisters only while the real findbar has not taken ownership.

Scope: Custom-element lifecycle and event syntax.
