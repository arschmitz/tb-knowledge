# Forwarded-message header selection names the enum values and keeps the normal fallback

The migration replaces numeric header switch cases with nsMimeHeaderDisplayTypes names. MicroHeaders chooses micro headers, AllHeaders chooses all headers, and both NormalHeaders and the default branch choose normal headers. The static preference still defaults to 1. This is a local C++ enum clarification with the same fallback, not a rule that every integer preference is validated against an enum.

Scope: MIME forwarded-message headers.
