# Put default ICS display order in the importer

Part 1 moved the old dialog’s sort into CalendarFileImporter.parseIcsFile so the consolidated about:import wizard receives items in useful order: start date, then entry or due date for tasks, undated items last, with numeric-aware title collation as a tie breaker. Current importer keeps this ordering. This avoids relying on a removed dialog to make imported items intelligible.

Scope: Calendar ICS import.
