# Storage SQL formatting keeps the closing table parenthesis on its own line

The table formatter places a leading newline before each field and replaces the last comma with a newline plus the closing parenthesis. The patch changes SQL text layout without changing the inspected table field declarations or index construction. getAllSql uses the same strings for diagnostic output, while schema operations also execute them. This is a local formatting phase, not a tested database migration result.

Scope: Calendar storage schema SQL construction.
