# Preserve a failed NNTP request status when transport completion arrives later

cancel stores the request status and cancels the input pump when present. Once a failure is stored, a later cancel call returns without replacing it. The server data callback stops delivering after failure; a listener exception calls cancel with e.result or NS_ERROR_FAILURE when the result is absent. onDone then replaces its transport completion argument with the stored failed request status. Keep channel cancellation status, transport completion and URI.errorCode separate when tracing failures; an empty successful transfer uses URI.errorCode for its own failure signal. These are static callback contracts. No cancellation race, failed listener or protocol test was executed.

Scope: mailnews/news.
