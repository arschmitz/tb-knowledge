# The Graph mark-read reland gives created fake drafts a SyntheticMessage metadata object

The reland creates an empty SyntheticMessage when registering a new fake Graph draft. ItemInfo retains it, and the constructor supplies metaState with read false by default, so the existing PATCH handler has metadata to update. GraphMessage keeps the decoded body separately. This is fixture dataflow support, not a fresh saveDraft result or proof of message-content retrieval.

Scope: Thunderbird Graph fake-server created-message metadata.
