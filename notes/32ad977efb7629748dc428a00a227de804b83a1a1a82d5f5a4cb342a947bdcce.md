# Give parent and child custom elements a clear communication direction

The guide uses direct methods for information sent or requested by a parent from a child, and custom events for information emitted by a child to its parent. An explicit initialize method can serve both the parent request and initial connection. External attributes, slots, parts, CSS properties and events need JSDoc manifest tags. For a DOM-owned XPCOM observer, declare nsIObserver and nsISupportsWeakReference when registering weakly, then unregister on disconnect. Weak registration depends on ownership; it is not a blanket replacement for every observer.

Scope: Custom-element interfaces and ownership.
