# Assign a parsed header pointer and length on every valid branch

851 replaces header length computation with a signed local len and clears pointer/length for a negative result, but omits assigning header->length for the nonnegative path. 855 backs the entire change out. The fixed accepted parser now assigns both fields together on valid input and resets both for invalid bounds. This is exact source proof of an omitted assignment; it is not proof of the reported crash cause or why the backout was needed.

Scope: Mailbox parser header state pairs.
