# Increment each cross-folder child level from its own level

When a new root is inserted into a cross-folder thread, increase each existing row level from that row's own value. Using m_levels[1] for every row flattened nested children. The bug had existed earlier but became visible when an extra sort was removed.

Scope: cross-folder threading.

- `mailnews/base/src/nsMsgXFViewThread.cpp`
