# Load notification cache from the profile before showing messages

The notification controller stores cached messages in scheduled-notifications/notifications.json through JSONFile and loads it at init. The cache lets notifications remain available offline. Init returns when _jsonFile already exists, so callers do not create a second file store.

Scope: in-app notification storage.

Paths:

- `mail/components/inappnotifications/modules/InAppNotifications.sys.mjs`
