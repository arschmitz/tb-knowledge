# The shared Downloads icon rules keep the existing button as the nesting subject

Inside .downloadButton, the adopted platform rules use & > .button-box > .button-icon. Repeating .downloadButton there would select a descendant button instead of the current one. Folder and search-glass icons remain platform-specific. Other overrides move to media rules, while the old Linux sidebar font override is intentionally dropped, so wrapper deletion alone is not a proof of unchanged rendering. The current selector and declared platform heights are inspected; no CSS rendering or native visual test ran.

Scope: Theme CSS selector scope and platform behavior.
