# Question routing and strict scope filters

Question intent changes evidence ranking. Explicit filters exclude records. Keep these actions separate so an inferred intent does not silently remove other matching evidence.

## Evidence

The tb-tools working tree adds retrievalPlan, matchesScope, and evidencePreference in commands/knowledge/routing.mjs. searchKnowledge applies scope filters before candidate limits and again after copy grouping. beforeTurn passes request text separately from the search query. Missing Boolean metadata does not mean false. Review-feedback acceptance is used only when source.accepted is true and source.reverted is not true. Source-map titles are navigation hints, not scope metadata or proof of behavior.

## Validation and limits

A broader publication suite has a learning-queue order failure in a test that does not call search. The implementation remains uncommitted; the recorded revision is its base.
