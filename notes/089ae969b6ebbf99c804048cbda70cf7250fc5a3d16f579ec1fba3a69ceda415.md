# Mercurial decision metadata keeps the corresponding Git revision optional

The Mercurial-only decision branch sets the backing Git repository URL, then stores comm_head_git_rev only if get_hg_revision_info returns a truthy extras.git_commit value for comm_head_rev. Both schema fields default to None. The repository assignment itself does not wait for a Git extra, despite broader wording in the documentation. Comm uses the comm_ parameter prefix; actual upstream route generation and artifact lookup remain unpaired and unexecuted.

Scope: Comm taskgraph Git revision metadata.
