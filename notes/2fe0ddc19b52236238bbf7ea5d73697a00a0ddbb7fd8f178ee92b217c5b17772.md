# The Exchange protocol rename retains protocol-specific factories and URI schemes

The shared classes become ExchangeService and ExchangeProtocolHandler, while registered message-service aliases still cover ews, graph, their message schemes and their internal schemes. NS_CreateEwsProtocolHandler and NS_CreateGraphProtocolHandler remain distinct factory entry points and initialize x-moz-ews or x-moz-graph. GetUrlForUri maps each message scheme to the matching internal scheme. A class rename does not itself migrate these external identifiers; no compiled ABI or live protocol result is claimed.

Scope: Exchange service and protocol registration rename.
