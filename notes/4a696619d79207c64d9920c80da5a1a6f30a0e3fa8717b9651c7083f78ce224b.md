# Platform icon changes need matching mocked alert expectations

The imageURL follow-up repairs three get-messages tests after the native notification change. Each expects an empty URL on macOS and chrome://branding/content/icon48.png elsewhere. The fixed tests now live in the getMessages subdirectory. These direct mock assertions check the API value passed to the alert service; they do not establish whether the operating system draws one icon, two icons or the expected pixels.

Scope: Notification test contracts.
