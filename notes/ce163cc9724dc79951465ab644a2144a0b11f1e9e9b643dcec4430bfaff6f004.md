# Register settings across preference control, schema and permissions

The accepted settings implementation registers preference names with ExtensionPreferencesManager, exposes named settings objects through ExtensionPreferencesManager.getSettingsAPI and requires messengerSettings permission through API/schema wiring. ExtensionsUI includes the permission and Fluent provides its display text. Keep those layers aligned when adding a setting; changing one pref getter alone does not create a complete add-on API. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
