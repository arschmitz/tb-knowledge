# Check a standalone message folder before attachment policy methods

CanDetachAttachments checks !gFolder before calling isSpecialFolder, which supports messages loaded from a standalone .eml file. The regression test expects open/save actions to remain available and detach/delete actions to be disabled for that standalone message. Keep absence of a folder distinct from attachment existence and cryptographic restrictions. The fixture and menu assertions were inspected, not exercised in Thunderbird. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / base.
