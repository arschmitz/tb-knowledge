# Put native titlebar tint on its decorative pseudo-element

488 applies native titlebar appearance to the standalone-window toolbox pseudo-element so it does not suppress the chrome/content separator. Current macOS main/compose styles use transparent toolboxes and a positioned ::after decoration under the native-theme preference. The current preference syntax/name changed; do not restore the removed unified-toolbar appearance from474. Numeric z-index values belong to this stack, not a global style rule.

Scope: mail/themes/osx/mail.
