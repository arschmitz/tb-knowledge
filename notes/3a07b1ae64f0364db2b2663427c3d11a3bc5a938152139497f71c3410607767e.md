# Existing-account address-book discovery requires a usable hostname

The scan skips non-mail none/rss/nntp/im accounts. For eligible accounts, it takes the domain from the username, then the default identity email, and skips the account if neither supplies a hostname. Empty discovered-book lists are also omitted. This is a scoped discovery guard, not full email or hostname validation, and the default identity object remains required by this path.

Scope: Account Hub existing-account discovery.
