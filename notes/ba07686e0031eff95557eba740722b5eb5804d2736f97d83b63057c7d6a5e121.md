# Header tests explicitly request branding before their assertions

This landing adds showBrandingHeader before the existing ordinary and first-run header assertions. The checked method only clears the branding container's hidden property; separate first-run title code selects IDs and aria attributes. These test setup calls are not a production-step fix, and the original first-run close-button-hidden expectation remains its own phase. Two unchanged ordinary-task diagnostics say not to expose text while asserting that aria-hidden is absent; the actual attribute expectation needs a matching message, without claiming an accessible-tree result. No browser or screen-reader test ran.

Scope: Account Hub header tests.
