# A locked mbox getter returns an owned snapshot

The accepted EnvAddr getter acquires mLock and returns nsCString by value. EnvDate and MsgOffset return scalar snapshots under the same lock. Do not replace these with a borrowed parser pointer that outlives the lock without checking the ownership contract. This is a scoped getter/lock recommendation; the code was not run concurrently. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
