# The context-menu Reply button uses the protocol-aware reply command

Entry 1478 changes the navigation Reply action from cmd_replySender to cmd_reply. The accepted cmd_reply sends a newsgroup message to reply-to-group and ordinary mail to reply-to-sender; the explicit Reply All action remains a separate command. In this menu family, recommend selecting the command that owns protocol behavior instead of hard-coding one destination in the menu map. This does not establish a smart-reply preference policy. The actual menuitem and current compose test assertions were read. No mail/news reply, keyboard menu or compose test was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Context-menu reply command ownership.
