# Compose current Account Hub footer classes from shared button roles

The 2024 footer-primary and footer-secondary palette selectors have been replaced in current markup. Footer buttons now combine button, button-primary or secondary-button, and footer-button. The local footer-button rule controls footer sizing. Prefer that accepted composition in this component family instead of restoring the old footer-specific color classes.

Scope: mail/components/accountcreation.
