# Use the draft closure to reach the temporary output stream

931 changes dummy_file_write from a raw output-stream closure to a tagged mime_draft_data closure; the accepted callback extracts draft data before writing tmpFileStream. Decoder setup supplies that same tag and draft pointer. Preserve the state owner required by the callback instead of wrapping the inner stream with the draft tag. The callback reports bytesWritten but does not inspect the Write result in the inspected source; no claim of complete write-error handling is made.

Scope: MIME draft decoder output context.
