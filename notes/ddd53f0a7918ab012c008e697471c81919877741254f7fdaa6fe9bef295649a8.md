# Spaces tests check a target URL before accepting a complete tab

The address-book and settings helpers reacquire the selected panel/browser during polling and require both complete state and the matching about URL prefix. They then directly assert the content window location. A complete about:blank document alone is insufficient. The polling URI and final window location are distinct checks, and the prefix match is not exact full-URL equality. No navigation or timeout cure was measured.

Scope: spaces-toolbar/browser-tests.
