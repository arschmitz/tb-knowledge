# Give imported items without UIDs stable keys before building the list

about:import stores item DOM wrappers by item.id. The test ICS file had items with no ID, and review confirmed such files are plausible. The landed loop generates a UUID only when item.id is absent, before building _itemElements. Without this, multiple imported rows could share a missing object key. Current code retains the guard.

Scope: Calendar ICS import.
