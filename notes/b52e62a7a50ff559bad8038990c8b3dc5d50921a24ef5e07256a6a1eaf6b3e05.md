# Keep the harness prefix and component stem in split Edit menu filenames

A scoped source pattern for this menu family is browser_editMenu_delete_item.js, browser_editMenu_favorite_folder_item.js and browser_editMenu_properties_item.js, with head_editMenu.js as shared support. The browser_ and head_ prefixes identify harness roles; the editMenu stem keeps the family together; underscore suffixes identify behaviors. Accepted menus/browser.toml still lists those exact names after the directory move. This does not establish camel case or underscores for every test family. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/base/test.
