# Rename a Sync engine across both settings display and acceptance paths

568 changes services.sync.engine.accounts to services.sync.engine.servers in the settings display, dialog map and test engine data. Account-oriented DOM IDs such as configSyncAccount remain because they name the UI concept. The dialog writes preference values only on dialogaccept. The browser test changes checkboxes, cancels to confirm old values remain, then accepts to confirm new values apply. Keep the engine key and user-facing identity separate when renaming a service. Current product enablement was not inferred from this source change.

Scope: Sync settings naming and behavior.
