# Keep a timeout increase tied to a shared scenario suite

The certificate-error suite requests twice the timeout because most code is shared across several scenarios. Accepted tests still use that request and exercise domain mismatch, expired, not-yet-valid and self-signed certificates through a common helper. This is evidence for this suite’s timeout choice, not a general rule against splitting tests or a remedy for a missing wait. No timing, CI log or test run was inspected.

Scope: mail/base/test.
