# The ARM shippable build entries pair a nightly field with the release transform

The build kind selects Gecko run_on_releases before the build transforms and loads the Linux and Windows task files. Each named ARM shippable task pairs run-on-releases:[nightly] with run-on-projects:[comm-central]. The accepted source retains those fields; upstream filtering and actual task execution were not verified.

Scope: Thunderbird ARM shippable task configuration.
