# Keep required STARTTLS failures out of the plain SMTP fallback

SmtpClient distinguishes alwaysSTARTTLS from SSL. If EHLO is unsupported while STARTTLS is required, it reports smtp-starttls-failed and returns; it does not use the ordinary HELO fallback. If EHLO succeeds but does not advertise STARTTLS, it also fails. These current branches preserve the removal of opportunistic trySTARTTLS. No connection or authentication experiment ran.
