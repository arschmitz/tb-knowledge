# Treat generated Cargo.toml as output of the Rust workspace generator

Both gkrust/workspace templates and the accepted rust/Cargo.toml say DO NOT EDIT THIS FILE and name python/rocbuild/rocbuild/rust.py. Entry 718 changes the generator, target dependencies, Cargo output, lock data, and checksums together. Preserve generator/output consistency when changing this dependency synchronization. This human generator change is studied; its mechanical output does not justify manually styling every generated feature list.
