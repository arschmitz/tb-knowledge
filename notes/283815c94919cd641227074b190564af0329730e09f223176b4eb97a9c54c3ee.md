# Quick-search mark-all-read acts on visible hit keys

The accepted nsMsgQuickSearchDBView command loops over m_keys and stops on the first failed MarkRead. It disables and then re-enables folder count notifications around that loop. The checked path still calls SetSummaryValid(true) after the loop regardless of rv. Preserve the hit scope and inspect that failure policy before treating the command as an all-folder or fully transactional operation. This is source and test-code inspection.
