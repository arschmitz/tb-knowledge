# The Rust Exchange listener names share the existing IExchange callback interfaces

The shared Rust safe-listener aliases use SafeExchange names while retaining the existing IExchange callback interface targets. Both EWS and Graph bridges construct the renamed wrappers. Protocol-specific EWS operation/data names remain. The patch updates names and import layout; this source scope does not prove native ABI, thread safety, all-caller behavior or runtime equivalence.

Scope: Thunderbird Exchange Rust safe listener naming.
