# Unknown MIME disposition fallback is gated by text class and first-written state

The new fallback keeps the existing inline-text class for a disposition other than attachment only while options/state exist and no first part has been written. Explicit attachment remains outside this exception. The test covers a single text/plain part whose malformed disposition is quoted-printable and asserts visible body text. It does not prove every unknown disposition or later part renders inline. The older broad fallback/default-filename proposals and attributed RFC debate remain separate from this source condition.

Scope: MIME body visibility exception.
