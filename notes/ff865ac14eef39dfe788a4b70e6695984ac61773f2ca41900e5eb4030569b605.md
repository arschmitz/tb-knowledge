# Folder listener modules emit data while the pane owns UI updates and event cleanup

FolderReorderListener and UserFeedbackListener dispatch data on their explicit EventTarget members. The pane installs the reorder receiver before transfer and owns insertFolder; it also owns TLS row/icon updates and matches feedback event registration with removal. The reorder receiver is once-only after an event arrives, while no arrived folder means no event. Keep the custom target requirement distinct from a generic copy-listener interface and from a durable arrived-folder result. Current server lookup/icon changes are later phases, not part of this move.

Scope: folder-pane-listener-modules.
