# Filelink transmitted markup carries stable inline colors independent of the compose theme

1351 sets explicit root, link and detail text colors in generated Filelink markup, reduces padding and gives the HTML list a white background. Accepted source retains these inline styles. This is a scoped generated-message pattern: compose application theme variables do not automatically become a recipient’s rendering environment. It is not a rule to hard-code colors in ordinary application CSS, and cross-client/dark-theme appearance was not rendered. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/components/compose.
