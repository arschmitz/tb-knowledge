# The messages API trims language tags and respects Content-Language suppression

For a nonempty optional string array, the API trims each tag and joins with comma-space before setting Content-Language, unless mail.suppress_content_language is true. Draft tests check explicit tags, omitted absence and pref suppression. The field does not add detection or validation, and the “verbatim” wording does not describe arbitrary surrounding whitespace. No live sending or language-detection result is established.

Scope: Thunderbird messages API Content-Language header.
