# Pair a fixed warning background with an intentional text color

Current CardDAV error status keeps the fixed yellow background and dark ink token. A theme-dependent dialog text color can be unsuitable on that fixed background. Review foreground/background together; this is scoped to the status area, not a requirement for all errors to be yellow. No contrast measurement or forced-colors test was run.

Scope: mail/themes/shared/mail.
