# Restore notification focus to the last element outside the notification

1030 saves focusout targets unless the manager contains them, then restores that element on an accepted primary CTA click or when hiding the notification. The native container has tabindex="0", so it can receive focus without becoming the restoration target. The test covers no focus theft on open, restoration after close and moving focus inside the shadow-tree container before closing. This is an actual focus contract; pointer and programmatic-focus tests do not prove every keyboard or assistive-technology interaction.

Scope: In-app notification external focus restoration.
