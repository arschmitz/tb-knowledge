# Wait for the spell-check setup state before clicking Send in the compose test

The before-send test waits for the Close button to become hidden before clicking Send. The spellCheckStarted callback initializes language state and calls NextWord before swapping those controls, so this state is more specific than the existence of the Send element. The test then checks the fake SMTP subject, not corrected spelling or cancellation. Keep the literal attriubuteFilter typo visible: this source does not establish a correct hidden-only filter.
