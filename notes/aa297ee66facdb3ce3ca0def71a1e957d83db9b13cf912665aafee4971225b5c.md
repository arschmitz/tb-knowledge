# Await the injection helper’s folder updates before folder-tree assertions

Entry 2052 adds await to messageInjection.addSetsToFolders in setup. The accepted helper is async; its local path invokes filters then awaits updateFolderAndNotify for each target unless doNotForceUpdate requests an early return. Waiting covers these final folder-update notifications, not only adding message bytes. The frozen folder-tree test now uses addMessageBatch and markAllMessagesRead directly, so the old helper call is historical.
