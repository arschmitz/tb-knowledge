# Separate link insertion from copying advanced attributes

For new/replacement selection links, the workaround sets href, inserts the surrounding link and then clones the advanced attributes onto the selected anchor parent. Existing-link editing keeps its earlier clone step. Fixed source later adds an early clone for insertLinkAtCaret, so do not apply the historical exclusion to every insertion mode. The underlying editor behavior and selection internals were not traced, and no compose/undo test ran.

Scope: Separate link insertion from copying advanced attributes.
