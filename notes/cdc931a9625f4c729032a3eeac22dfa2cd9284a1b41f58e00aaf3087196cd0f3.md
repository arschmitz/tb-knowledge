# Distinguish an active Calendar ready promise from a completed refresh

Current filter tests around 740 distinguish cancellation, a replacement active refresh and an already completed refresh. Repeated access during the same work returns the same ready promise; a forced new refresh creates a new one. The tests also keep cancelled results out of the item list. A promise resolving once is not proof that a later refresh has completed. These assertions were inspected without executing the stream tests.

Scope: Calendar refresh promise contract.
