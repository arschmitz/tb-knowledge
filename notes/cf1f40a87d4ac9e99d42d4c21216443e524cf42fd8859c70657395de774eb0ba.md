# The Publish dialog uses an attribute message for its initial accept-button label

The load handler localizes the dialog with calendar-publish-publish-dialog-button, whose buttonlabelaccept attribute contains Publish. Markup explicitly permits that attribute. The migration copies the old Publish value into the new attribute. After acceptance, the existing handler separately localizes the accept button with the value message calendar-publish-close-button. Preserve each actual target and message shape; this static correction does not execute publication or prove a live accessibility result.

Scope: Calendar publishing dialog localization.
