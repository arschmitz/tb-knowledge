# Redo a local destination copy from the current source headers

Entry 1068 removes the special IMAP redo path that only toggled deletion flags. Accepted RedoTransaction clears the destination key list, resolves the current source headers and copies them through the destination folder with the stored move flag. Undoing an IMAP move can leave the local destination deleted, so redo must create the local copy again. This is the local destination transaction contract. A scoped case-insensitive content search found no redo references in the selected suites; no redo runtime was run. This note is based on source inspection. Tests were not run, and full review discussion remains pending.
