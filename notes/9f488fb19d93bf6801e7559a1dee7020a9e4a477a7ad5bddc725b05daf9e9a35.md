# Keep optional extension cleanup state available before later assignment

The commands-update browser test declares let gUpdatedExtension before its task registers cleanup. The task assigns that binding when it loads the replacement extension, and cleanup unloads it only when the binding is set. The comment names the incomplete-startup case. Preserve the declaration, later assignment and guarded cleanup together; changing only the name loses the failure-path reason. This is the optional replacement-extension slot, not proof that every setup failure or unload error is handled. The fixed source keeps the same code. No failure or cleanup path was executed here.

Scope: Extension browser command-update cleanup state.
