# Arm browser event waits before invoking the action that can finish quickly

The send tests arm popupshown before opening menus and popuphidden before activation. Newer password-send code also creates the compose-window-close promise before the final send action. Proposed scoped manual async-test rule: create the event promise before the stimulus, then await both event and asserted result. A timeout or arbitrary delay does not provide the same event ordering guarantee. The tests still skip the native macOS menu bar because the helper cannot operate it.

Scope: Compose test event ordering.
