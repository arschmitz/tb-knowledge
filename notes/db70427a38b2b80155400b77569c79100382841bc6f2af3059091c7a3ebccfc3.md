# Four scoped name comparators stop forcing base sensitivity

The owned patch removes sensitivity:base from the extension name sort, special-folder menu label sort, shared folder collator and Panorama text collator. Their consumers remain different: FolderUtils compares sortOrder first, and the adapter uses a Boolean compare-result predicate. Accepted FolderUtils later adds numeric:true while the adapter retains its default constructor. Preserve each local contract; no all-locale ordering or global style policy is established.

Scope: Folder and Panorama locale-aware ordering.
