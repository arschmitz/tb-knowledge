# Initialize the parent tabs API before a space opens a tab

The later 1541 follow-up explicitly loads the tabs module in both getAPI implementations. Its comment explains that synchronous child onCreated registration can return before the parent TabOpen listener is ready. Keep this dependency at the space-open boundary rather than assuming a registered child listener proves parent readiness. The reported test race was not reproduced, and D232068 remains unread. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces tabs startup ordering.
