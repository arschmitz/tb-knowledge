# Keep Account Hub severity classes separate from input state classes

The Account Hub styles distinguish notification severity classes error/warning/info/success, icon classes icon-danger/icon-warning/icon-info/icon-success and field state classes input-warning/input-success. These are composable roles, not alternate spellings for one boolean. Current showNotification documents the severity string union, and CSS selects the matching icon under each severity. Use the local hyphenated class families and the documented severity names when extending these forms; this is not a global ID/class case rule.

Scope: mail/components/accountcreation.
