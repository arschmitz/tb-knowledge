# Mask a deleted Sync record before async cache removal

When an account, address book, calendar, or identity is removed, mark its ID as deleted synchronously before clearing cached data asynchronously. Otherwise createRecord can still read the cached normal record instead of creating a tombstone with deleted: true.

Scope: Thunderbird Sync.

Paths:

- `mail/services/sync/modules/CachedStore.sys.mjs`
