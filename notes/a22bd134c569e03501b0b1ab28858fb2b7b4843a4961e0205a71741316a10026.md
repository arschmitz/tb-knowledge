# EWS request serialization now happens when the queued operation runs

The removed enqueue macro serialized XML and selected the server version before placing a request in the queue. QueuedEwsOperation instead owns the operation and options, then builds a borrowed SOAP envelope during perform. Serialization failure is sent to the typed response channel; enqueue_and_send waits for the result. Keep enqueue completion, execution-time version lookup and response completion separate. Accepted code later moves request construction into build_request without making these the same phase; no network execution is claimed.

Scope: EWS queued request construction.
