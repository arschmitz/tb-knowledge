# Test S/MIME algorithms through Thunderbird message rendering

NSS already tested ECDH and RSA-OAEP decryption, but Thunderbird needed application-level coverage. This patch adds encrypted message fixtures with ECDH and several RSA-OAEP options, imports matching private keys, and checks decrypted text in the rendered message. Review replaced a boolean check_text flag with expected text so old and new fixtures use one assertion path, and asked fixture subjects to describe each message. Bug 1893039 was needed when raw test data lacked an inner MIME header.

Scope: S/MIME decryption tests.
