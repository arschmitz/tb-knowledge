# Keep Maildir token conversion separate from token interpretation

The scanner converts the UTF-16 file leaf to the UTF-8 storeToken. Reading a Maildir message converts that token back to UTF-16 and appends it below cur. Preserve this filesystem round trip; the common opaque token API remains distinct from a message key or an mbox numeric offset. This narrows the existing typed-token lesson to Maildir encoding. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
