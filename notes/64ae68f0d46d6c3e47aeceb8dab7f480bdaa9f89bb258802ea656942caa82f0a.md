# Calendar's final logging migration replaces Boolean switches and rejects single-interface helper calls

Part 6 replaces calendar.debug.log and calendar.debug.log.verbose with the string preference calendar.loglevel, whose production default is Warn. Test setup chooses Debug or All separately. It also strengthens cal.generateQI's length-one branch from a warning plus ChromeUtils.generateQI delegation to an Error. The multi-interface wrapper remains; the inspected alarm-monitor caller supplies two interfaces. This is a scoped API change, not a claim that all callers were exercised.

Scope: Calendar logging migration part 6.
