# The test-helper document separates Firefox harness utilities from imported Thunderbird helpers

This landing adds a nonexhaustive helper list and registers the testing documentation tree. It distinguishes Firefox harness utilities from Thunderbird helpers that need explicit imports. The fixed mailnews build list packages the named resources, and Calendar browser head explicitly imports CalendarTestUtils from its listed URI. The accepted index later moves helpers into a Testing section and the page later adds AxeHelpers. This scoped documentation/packaging evidence does not verify every linked Firefox API or replace deliberate test-writing rules.

Scope: Thunderbird test-helper documentation.
