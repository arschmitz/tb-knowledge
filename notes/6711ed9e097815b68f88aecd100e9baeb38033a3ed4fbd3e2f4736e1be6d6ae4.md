# The message database chapter maps metadata roles to separate interfaces

The chapter maps message rows to nsIMsgDBHdr and nsIMsgDatabase, folder properties to nsIDBFolderInfo, notifications to nsIDBChangeAnnouncer, and database opening/caching to nsIMsgDBService. It separately describes threading and IMAP pending-operation tables. The checked IDL confirms the notification inheritance and folder-info attribute. Use this as a navigation map for the documented per-folder design; it does not prove every backend's storage or synchronization behavior. Panorama remains a separate documented direction in this chapter.

Scope: Message database architecture documentation.
