# Assert the actual grouped-view flag rather than the assertion message

The historical Appearance patch used grouped value 40 and an assertion that negated kGroupBySort even though its message said grouped. The fixed accepted UI uses value 64, and the descendant test positively checks viewFlags & kGroupBySort. Proposed manual rule for these tests: compare the actual enum or bit before trusting assertion prose. This is a source-backed test review lesson; it does not establish the review reason for the later correction or a runtime result. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
