# Separate a certificate-send test from a fake server TLS promise

753 tests certificate exceptions for several failures, checks the matching host/port exception and retries sending. Its test SMTPServer advertises STARTTLS specifically to exercise account setup without implementing that upgrade. Do not treat that fake capability as proof of real TLS support. The current certificate path awaits two alerts with Promise.allSettled; that call alone does not assert both settled successfully. The historical extra-alert FIXME and focus delay remain test limits rather than recommended synchronization patterns.

Scope: Compose certificate test limits.
