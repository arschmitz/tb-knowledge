# Keep browser OAuth test filenames, task names and registration linked

The added file is browser_oAuthGranularScopes.js; its scenarios use testNotGranted, testOnlyMailScope, testNotMailScope and testAllScopes. The historical browser.ini registration tags it oauth; current registration is in browser.toml with the same file and tag. Proposed scoped naming rule: new granular OAuth tasks use a test-prefixed lowerCamelCase scenario name, and the browser_ filename, manifest entry and helper imports must agree exactly. Other nearby legacy tests use underscores and mixed OAuth casing, so this is not a repository-wide rename directive.

Scope: OAuth file and test names.
