# Update preference UI after a Sync engine rename

Renaming the Sync accounts engine to servers also changes its preference key. The preferences UI kept the user-facing Accounts label but must read services.sync.engine.servers; the old key left the toggle out of sync. Update both UI and tests when an engine key changes.

Scope: Thunderbird Sync.
