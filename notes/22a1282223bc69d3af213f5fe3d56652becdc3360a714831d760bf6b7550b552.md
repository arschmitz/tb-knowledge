# Disabled Save clicks can trigger a footer accessibility check

For D332899 at revision 61fdeb24a40374feeb64fe1685f402200b2304c5, the AI verification record reports that synthesizing a pointer click at the disabled Save button reached the footer and caused the accessibility checker to flag that footer. The direct Save rejection and zero-transaction assertions reportedly passed. The scoped recommendation is to handle the expected checker result in this intentional disabled-control test while retaining those behavior assertions. The record does not support adding an interactive role to the footer. No applied fix or successful rerun is recorded; this is a reported harness issue in this specific test, not a general exemption from accessibility checks.

Scope: Calendar event edit disabled Save test.
