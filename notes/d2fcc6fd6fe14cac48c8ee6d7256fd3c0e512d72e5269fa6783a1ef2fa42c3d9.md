# IMAP store variants use dashed manifest filenames and shared tests

The current build runs xpcshell-maildir.toml and xpcshell-mbox.toml. Both include xpcshell-shared.toml, set cpp plus the storage tag, allow duplicate manifests and run sequentially. The maildir head sets mail.serverDefaultStoreContractID to maildirstore. Scoped naming recommendation for this suite: name manifest variants after the storage backend and reuse shared test filenames rather than cloning every test for a retired JS implementation. cpp remains a tag even though it is no longer a filename suffix. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP test manifest naming.
