# Promotion configuration rewrites the Phabricator callsign in .arcconfig

The main-to-beta promotion configuration replaces THUNDERBIRDDESKTOPMAIN with THUNDERBIRDDESKTOPBETA in .arcconfig; beta-to-release replaces BETA with THUNDERBIRDDESKTOPRELEASE. The main checkout itself declares the MAIN callsign. These are requested branch-specific configuration replacements; the transform/worker execution and an actual promotion were not run. Excluded product replacement tuples are outside this evidence.
