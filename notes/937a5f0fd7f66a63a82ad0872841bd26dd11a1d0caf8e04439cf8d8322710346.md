# Removing the generic Exception wrapper keeps typed cancellation and HTTP error fields

This phase removes the empty Exception wrapper and its export. It keeps NotReached, CancelledException and UserCancelledException as distinct Error subclasses, and ServerException still records cause, code, uri and url. The sanitizer test stops depending on the removed wrapper: it checks Error.isError while preserving the localized message-prefix test. Replacing the wrapper does not make cancellation equivalent to an ordinary lookup miss or remove HTTP failure metadata. The preceding modernization supplied the class/cause form; this entry changes its base, with later localization and module renames kept separate.

Scope: Thunderbird account-creation error contracts.
