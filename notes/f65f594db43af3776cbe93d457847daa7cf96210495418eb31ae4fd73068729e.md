# Use the shared channel URL conversion for all Exchange message operations

Entry 1087 extracts the channel URI helper. Accepted CopyMessage, LoadMessage and SaveMessageToDisk all call GetUrlForUri, while already-internal x-moz URLs pass through. The service supports EWS and Graph scheme conversion. The current fragment-to-path/local-key contract is already a shared lesson and must not be replaced with the historical remote EWS-ID URI format. These are source-derived API facts; no channel/display execution was run. This note is based on source inspection. Tests were not run, and full review discussion remains pending.
