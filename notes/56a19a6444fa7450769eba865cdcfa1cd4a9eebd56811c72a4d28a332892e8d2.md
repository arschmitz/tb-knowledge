# Add-on warning hooks retain a default delegate and explicitly refresh existing cards

After waiting for addon-card, Thunderbird installs its warning callback through setEmbedderHooks. Local cases return warning payloads; unmatched cases delegate to the imported default with the same selected context. The module explicitly updates existing cards after its update override. The re-enabled banner test checks warning state with local fixtures; it does not establish the imported component implementation or a fresh runtime result.

Scope: Thunderbird add-on card integration.
