# The MailGlue actor port changes five module addresses while retaining local registration roles

This landing changes FindBar and NetError parent/child module addresses to moz-src:///toolkit/actors and updates the startup-idle AutoCompleteParent import. The local declarations still feed JSWINDOWACTORS registration after the explicit unregister calls; the idle import retains its documented message-registration side effect. The fixed accepted local declarations and calls retain those addresses. This does not establish toolkit actor exports, URI resolution, packaged resources or successful native actor startup; those imported implementations and runtime were not paired or executed.

Scope: MailGlue actor registration.
