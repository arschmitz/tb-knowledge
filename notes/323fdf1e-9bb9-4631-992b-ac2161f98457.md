# HTML snippet conversion is a standalone messengerUtilities API

Bug 1898853 added convertToPlainText as a utility so extensions can convert arbitrary HTML snippets, including content not tied to a message. The schema exposes body plus optional flowed mode; implementation uses nsIParserUtils and trims leading and trailing whitespace. The API and test files were later renamed to messenger_utilities and ext-messengerUtilities, and current code retains the function. Do not require a message ID or listTextParts call for this conversion.

Scope: Extension text utilities.
