# Test omitted extension properties separately from null values

The accounts tests distinguish no default account (null), a Manifest V3 subFolders property not returned (undefined), and the legacy Manifest V2 folders property returned as null when excluded. The getDefault(false) result has a strict shape assertion; the default-call assertion separately checks the recursive arrays. When testing versioned payloads, cover omission, explicit null, explicit false and the omitted-argument default. A loose partial-object comparison alone cannot prove these distinctions. Tests were inspected, not executed.

Scope: Extension payload tests.
