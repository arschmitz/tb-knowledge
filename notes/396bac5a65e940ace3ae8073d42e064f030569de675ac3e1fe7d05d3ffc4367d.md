# CardDAV discovery carries readable-only privilege results into the new book

The writable list drops write-properties and adds bind. Discovery separately computes readable and writable from privilege element local names. A readable-only result remains available to the user, and its create callback sets readOnly on the new address book. Accepted source later refines successful propstat selection, so that response-parser phase remains separate. This source classification is not a full per-operation permission model or a live server result.

Scope: CardDAV discovery and persisted read-only state.
