# Use xpcshell add_task skip_if for conditional skips

Bug 1898449 found that xpcshell task .skip(condition) skips unconditionally even if condition is false. Three tests used it after a conversion from __skipMe and were silently disabled. The accepted fix puts skip_if: () => condition in the options object passed as the first add_task argument. Current grouped thread count and large offline store tests still use this form. Do not carry .skip(condition) syntax from another test harness into xpcshell; check the actual harness contract.

Scope: xpcshell tests.
