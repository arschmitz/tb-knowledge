# Scope FCC test discovery to its account and compose window

The current FCC test discovers folders with both accountId and name, waits for windows.onCreated before opening a composer, and queries its tab by the returned windowId. Native checks separately assert that exactly one compose window exists. These scopes prevent a global folder-name or tab search from choosing unrelated fixture state. The code takes the first account, folder, and tab by destructuring; it does not assert unique folder-query results or exercise several accounts with duplicate names. Supported test pattern: retain the account and window scope. Additional uniqueness or multi-account checks are proposals, not existing coverage.

Scope: mail/components/extensions.
