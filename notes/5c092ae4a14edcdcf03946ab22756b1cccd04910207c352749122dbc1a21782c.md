# Windows application libraries and sandbox-only libraries use distinct guards

The Windows application branch declares advapi32, shell32 and ntdll. The separate MOZ_SANDBOX-and-WINNT branch declares shlwapi, user32, version and winmm along with sandbox_s. The repair moves advapi32 out of the sandbox-only scope and consolidates the later ntdll declaration. Preserve those guards when checking link inputs; an upstream Chromium port title does not prove paired library requirements, ABI compatibility or a successful build.

Scope: Thunderbird Windows application link configuration.
