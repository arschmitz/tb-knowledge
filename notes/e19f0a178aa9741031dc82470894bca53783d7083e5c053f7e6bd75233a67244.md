# The key-encryption label describes the first recipient info, not a matched certificate

GetKeyEncAlgorithmName explicitly reads recipientInfos[0] and accepts no recipient certificate. MimeCMS_eof independently obtains certOfInterest through GetEncryptionCert and forwards it beside that label. The accepted source retains the first-recipient rule while moving the outermost envelope lookup into a helper. For a message whose recipient infos use different algorithms, this source does not establish that the label matches the certificate shown in the panel. No such message or cryptographic operation ran here; this is a display-scope limit, not a security-severity finding.

Scope: S/MIME algorithm details and recipient selection.
