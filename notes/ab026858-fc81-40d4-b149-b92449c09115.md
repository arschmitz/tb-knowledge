# Ignore MYRIGHTS when no IMAP mailbox is selected

An unsolicited IMAP MYRIGHTS response can arrive before selecting a mailbox. In that state there is no folder to update; consume the response and keep the connection usable instead of copying a null mailbox name.

Scope: imap.
