# Do not claim the IMAP login monitor skips duplicate authentication

In D211308 the reviewer asked whether a waiting thread could avoid logging in after the first succeeds. The accepted answer was that separate connections still must authenticate. The monitor serializes attempts so a prompt or updated credential can happen first; the review did not prove exactly how every server handles the second connection. Review test plans should use multiple simultaneous connections and wrong then corrected passwords, and should measure attempts and prompts.

Scope: IMAP authentication.
