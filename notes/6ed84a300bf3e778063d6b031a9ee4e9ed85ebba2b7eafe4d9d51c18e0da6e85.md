# Clang task commands must be derived before deleting their optimization data

Entry 1479 reports that removing optimization data before deriving changed file paths produced an invalid command that always succeeded. The exact historical transform order changes to derive clang paths before remove_optimization; the derivation reads optimization patterns and formats selected C++ paths into the command. The accepted source has since retired that clang-path transform, but retains optimization removal for code-review-enabled jobs on comm-central hg-push, after removing when; an always optimization remains exempt. Recommend respecting this producer/consumer order in this historical task family; no CI failure or successful formatting task was reproduced. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Clang source-test transform ordering.
