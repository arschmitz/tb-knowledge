# Exchange attachment conversion must precede the downstream format converter

Normal display lets docshell run the RFC822 converter. For part= or convert=true the protocol handler explicitly enables the Exchange converter, sets load info on the channel, and applies attachment disposition when needed. PDF attachments require the message/rfc822-to-application/pdf converter before PDF.js converts PDF to HTML. Current internal protocol configuration marks Exchange schemes dangerous to load and forbids relative URLs, cookies and automatic document replacement; it is not evidence that arbitrary web content may open them. Manual protocol review proposal: check conversion ordering, load info and content policy together when changing message/attachment channels. No PDF, attachment or security test was run.

Scope: exchange.
