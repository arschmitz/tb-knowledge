# Keep platform network errors through SMTP delivery and map them at presentation

Entries 2092–2095 stop translating unknown-host/proxy-host, refused/proxy-refused, interrupted, timeout and reset errors into SMTP-specific aliases. MessageSend instead recognizes the original Cr codes when adding the server hostname. MimeMessageUtils maps both host errors to the unknown-server message, both refusal errors to the refused message, interrupt to interrupted, and timeout/reset to timeout. These are coordinated branches: retaining a raw exit code alone would lose the intended message or hostname if the presentation tables still expected the old alias. The fixed accepted source preserves this mapping with Fluent IDs. Its local JavaScript form uses computed object keys for code-to-ID lookup and an array includes check for hostname formatting; this is scoped accepted source, not a tree-wide syntax rule. No network failure, displayed alert, screen-reader announcement, runtime, build or lint validation ran. Full discussion is pending.

Scope: Compose send error mapping.
