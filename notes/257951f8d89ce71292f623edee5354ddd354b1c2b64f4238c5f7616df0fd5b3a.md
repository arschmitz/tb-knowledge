# The historical Exchange URI branch checks finalization before reading the query

The original standard-URL branch checks the Finalize result before dereferencing uriResult to read its query. The assigned change adds the existing native success guard at that boundary. The accepted branch later constructs ExchangeUrl directly and checks SetSpecInternal instead; that separate factory proof is reused. The malformed-spec crash is an attributed report, not a fresh reproduction or a guarantee about native mutator internals.

Scope: Thunderbird Exchange URI creation result handling.
