# Gate message-ID context-menu data with messagesRead

The header builds onHeaderPaneLink context data, keeps the displayed bracketed Message-ID as linkText and strips brackets into a mid: linkUrl. ext-menus exposes those data fields only with messagesRead, while header_pane_link remains an available menu context. Tests cover with/without accountsRead and messagesRead across message panes. Preserve permission-gated data disclosure separately from menu presence. No extension menu was opened. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension message header menus.
