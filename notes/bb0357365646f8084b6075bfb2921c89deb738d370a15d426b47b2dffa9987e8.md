# Calendar sidebar focus styling follows both list selection and the focused button

The header hover rule excludes disabled headers and its focus-visible rule uses an inward outline offset. A separate list rule colors the menu-button outline only when the list contains focus, its row is selected and that button is focus-visible. The accepted file keeps the selector but uses a later sidebar-color fallback. These declarations and actual markup establish selector scope; they do not prove rendered contrast or keyboard behavior.

Scope: Calendar sidebar focus and hover states.
