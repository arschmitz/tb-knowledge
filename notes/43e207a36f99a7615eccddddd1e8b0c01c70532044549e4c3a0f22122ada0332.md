# Commands Thunderbird/Firefox desktop onboarding and guided setup

On Windows, invoke MozillaBuild as `start-shell.bat -no-start -defterm -c`; generated batch launch must preserve the runner exit status across pause. Request elevation through `Start-Process -Verb RunAs -Wait -PassThru`, supplying the installer through `TB_SETUP_INSTALLER` rather than interpolating it into PowerShell. Reject `%`, `!`, quotes, metacharacters, and control characters in relevant paths. [Task 1]

Scope: general.
