# Account Settings refresh reuses the tab but should not rebuild its tree listeners

MsgAccountManager finds an existing about:accountsettings tab, assigns server/selectPage and calls that page’s onLoad before switching to it. Current onLoad uses hasLoaded to register the outer font/density window only once, and gAccountTree.load returns early for an already loaded tab. onUnload clears the guard and unloads the tree. Preserve refresh-versus-first-load intent; the patch adds no test and no duplicate-load experiment ran. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: account settings lifecycle.
