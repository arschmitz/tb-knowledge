# The offline get-messages delay is a retained test workaround

The offline test marks an inbox read, waits250ms, then separately waits for the corresponding IMAP server to become idle. The fixed file has moved under getMessages and retains an explicit arbitrary-timeout lint exception. The sleep is not a verified completion contract or a new preference for test design. Its Bug discussion has missing numbered comments and later reported failures. Preserve the user-directed event/state wait rule for new tests; do not copy this workaround as a general recipe. No test or intermittent reproduction ran.

Scope: Offline retrieval test timing.
