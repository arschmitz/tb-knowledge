# Botan module configuration and mozbuild source lists are separate inputs

Botan module names are passed as a comma-separated --enable-modules argument during configure, while botan.mozbuild lists library translation units explicitly. Reading build_config.json for compiler flags does not automatically replace that source list. The owned base list changes168paths to 184; metadata checks establish path presence, not a successful build or crypto feature coverage. Its regeneration comment names .test_srcs, while accepted source names .lib_srcs[]. Accepted later nightly modules and their conditional source list explicitly cross-reference each other; they are not part of the original upgrade. Keep module selection, source-list maintenance and compiler-flag import distinct when checking this integration. No regeneration command, configure or test ran.

Scope: third-party/openpgp/botan-build.
