# Protocol default-server eligibility is checked before the account manager changes the default account

The historical EWS override enables a capability that defaults to false on nsMsgIncomingServer. The accepted renamed ExchangeIncomingServer also returns true. The account manager queries that virtual capability and rejects a failed or false result before changing the default account, writing its preference or notifying folders. Returning true permits selection; it does not itself select a default or establish transport readiness. No protocol/default-account test ran.

Scope: Exchange default account capability boundary.
