# Persistence tests should show check then transition then check again

For view-state persistence, explicitly assert the state before and after refresh/rebuild. Use a small assertion helper if multiple fields must stay equal. The secondary-sort regression test checks type/order for both primary and secondary sorts, refreshes once, and checks again. Review preferred this sequence over a loop because it exposes the state transition and avoids an extra refresh. Limit this recommendation to tests where a transition is the contract; it is not a ban on data-driven tests.
