# Calendar color coverage sets the input value without opening the picker

The existing properties test assigns colorElement.value, clicks Accept and checks the calendar list's computed color; reopening checks the retained input value. The field is an HTML color input, and the save handler writes its value to the calendar. These checks exercise value/save/display flow, but do not open the native picker or simulate a load event from another target. They therefore do not directly cover the reported picker-load regression.

Scope: Calendar properties browser-test scope.
