# OAuth authorization appends parameters to the configured URL object

The authorization builder constructs a URL from the configured endpoint and appends parameters through its searchParams. This preserves existing query input instead of adding a second question mark. append can retain duplicate keys, and the existing falsy-value guards still omit optional values. The const binding remains stable while the URL mutates; original string consumers call toString locally. Generated state and later request-specific redirects are separate phases, and no authentication result follows from this source inspection.

Scope: OAuth authorization query construction and local const use.
