# The redirect-rejection assertion describes an invalid email instead of the rejected redirect

The redirect test resumes discovery with acceptRedirect: false and expects a null configuration. Its assertion message says the email address is invalid, although the tested condition is refusal of a cross-domain HTTP redirect. The fixed accepted test retains this mismatch. A focused message correction should describe the rejected redirect and the expected null result. This finding concerns the assertion's explanation; it is not evidence of a discovery or network failure.

Scope: Thunderbird account-discovery test messages.
