# Scope extension icon visibility to both menu and menuitem

The icon hide rule matched menu and menuitem, but its extension exception matched only menuitem. Extension submenu/root icons therefore vanished. The accepted fix gives both selectors the same node-type scope; the current class hook changed to webextension-rootElement while that parity remains. When changing an exception to a broad CSS rule, compare every target type in the base and exception selectors. No reproducer extension was installed or run.

Scope: mail/themes.
