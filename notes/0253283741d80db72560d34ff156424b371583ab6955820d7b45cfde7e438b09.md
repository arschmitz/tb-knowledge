# EWS account creation leaves special-folder selection to the resolver

The EWS creation path skips the helper that seeds literal Sent/Drafts/Templates URIs. With no usable preseeded preference, the identity resolver can choose a folder by its special flag before trying a conventional name or creation. The new fixture deliberately uses sentItemsTest with distinguished sentitems identity, asserts the FCC URI starts unset and waits for one filed message after sending. Accepted later code also excludes Graph and uses async folder APIs; those are separate phases. This is scoped source/test code, not a guarantee about every locale or provider. No account or send test ran.

Scope: ews-account-special-folders.
