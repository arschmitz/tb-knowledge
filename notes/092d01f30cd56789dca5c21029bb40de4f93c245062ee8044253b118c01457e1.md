# A Search Messages delete-column click uses a single-row temporary selection

Entry 2066 fixes delete-column behavior for a clicked member of a multi-selection. If the clicked row is not the sole real selection, create a transient TreeSelection, suppress its events, log index adjustments and select only that row. Run cmd_delete so existing validations/prompts apply. Restore the real selection and replay adjustments so removed rows shift saved ranges. The fixed accepted handler keeps this sequence. Removed FolderDisplayWidget command-updater callbacks were described as unused after native storage became weak; do not use that author statement as a general interface rule. No tests changed or ran. Proposed regressions cover multi-selection, outside-row click, modifiers, cancelled deletion, index changes and focus restoration.

Scope: mail Search Messages delete column.
