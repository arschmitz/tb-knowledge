# Keep the first LiveView sparse adapter as historical architecture

The first adapter used LiveViewRowMap, a lazy .at accessor and buffered synchronous selections. The accepted adapter has retired that class and awaits countMessages/selectMessages, with rows delivered through onSelectedChunk. Retain the original caching design as project history; do not apply its offset-based select contract to the current Promise API. Current tree data can be incomplete until its invalidation arrives. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama adapter evolution.
