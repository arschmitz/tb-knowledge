# Failed IMAP URL setup terminates that protocol thread

Entry 1284 adds TellThreadToDie(true) when SetupWithUrl fails. The accepted LoadImapUrl first permits a local fulfillment path, then performs setup and requests thread shutdown on failure. This is a scoped failed-initialization cleanup boundary; it does not show that all IMAP errors should close a thread or that a successful local read starts a new connection. No thread shutdown or setup-failure test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP URL setup cleanup.
