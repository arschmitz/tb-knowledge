# An unmatched invited-attendee override falls through to calendar scheduling support

itip.getInvitedAttendee returns the explicit X-MOZ-INVITED-ATTENDEE match only when it resolves. If the override names no attendee, the helper continues through the calendar scheduling provider. The added memory-calendar test directly checks that calendarUserAddresses supplies the matching attendee. The result can still be null when no fallback resolves; this does not establish all callers or an actual invitation send.

Scope: calendar/base/modules/utils.
