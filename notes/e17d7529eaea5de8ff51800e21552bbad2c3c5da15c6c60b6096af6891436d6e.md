# Graph folder, message and channel schemes have separate native service roles

The Graph integration maps graph-message URIs to x-moz-graph channels and chooses the graph message service in AsyncOpen. Header lookup maps Graph message/channel forms back to a graph folder URI. These roles differ from a folder URI and from the remote Graph item ID. Accepted renamed ExchangeService/ExchangeMessageChannel retain the mappings; their later pass-through and security checks are separate phases. The comm code proves local selection, not paired Gecko protocol behavior or a successful displayed-message fetch.

Scope: Exchange Graph URI and channel routing.
