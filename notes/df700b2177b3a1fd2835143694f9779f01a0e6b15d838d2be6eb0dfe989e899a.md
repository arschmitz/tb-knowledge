# The Account Hub overflow cleanup removes form offsets while keeping scrolling

The overflow repair removes negative block margins and matching 18px block padding from the shared address-book form selector. It keeps start alignment, and the surrounding shared form rule still supplies a bounded height and vertical scrolling. LDAP and other address-book forms consume this class, so the change is broader than the reported advanced-LDAP field area. The source alone does not prove the final rendered overflow or keyboard behavior.

Scope: Account Hub address-book layout.
