# Cross-window pill moves carry addresses and clean up the source widget

A pill drag serializes the selected fullAddress strings into text/pills. Drop identifies the source recipients widget through mozSourceNode.ownerDocument and passes both addresses and source widget to createDNDPills. The target rebuild is separate from source cleanup; another source widget removes its own selected pills. The regression test directly checks target address/count and source emptiness. The original guarded JSON parsing differs from accepted direct JSON.parse, so validation behavior must be described by source phase. No native drag or accessibility result was run.

Scope: Thunderbird compose recipient pill drag and drop.
