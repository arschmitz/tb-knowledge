# Exercise persisted hostname rescue through account reload

test_accountMgr2 creates a valid server, writes a bad hostname into prefs, unloads and reloads accounts, then checks the resulting <key>.invalid hostname. That crosses the actual persisted-data boundary; passing a bad hostname only to CreateIncomingServer would exercise rejection instead. The test also accepts numeric hostname 2 and finds it through normalized 0.0.0.2, while rejecting invalid.192.168.1.2. Keep normalizable numeric input distinct from invalid numeric-ending names.

Scope: mailnews/base/test.
