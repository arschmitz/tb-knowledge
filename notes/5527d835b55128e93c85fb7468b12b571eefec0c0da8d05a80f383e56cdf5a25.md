# Exchange soft delete uses move transport with a separate delete undo type

The soft-delete callback moves messages to Trash through CopyItemsOnSameServer while requesting eDeleteMsg for the undo record. isMove, allowUndo and undoOperationType have distinct roles. Replay disables undo creation, so eUnknown is valid for its unused new-record type and avoids registering another undo entry. This does not add permanent-delete undo or make a transaction method wait for remote completion. No delete/undo/redo test ran.

Scope: Exchange soft delete undo registration and replay.
