# Keep SMTP delayed-QUIT recovery separate from terminal QUIT

The first Bug 1965690 landing reconnects from _sendCommand when the socket is closed or _isQuitSent is true. SmtpServer.onidle uses isRetry to rebuild the message envelope. The human backout restores the prior command path after a reported composition-test crash; the author later identifies recovery after any QUIT as too broad and narrows the reland to delayed QUIT. Fixed accepted source is later: the delay timer sets _reuseConnection false and connect replaces the socket. Keep terminal QUIT and message-recovery triggers distinct. The Bug supplies the crash diagnosis and later user report; no crash, race or SMTP send was reproduced, and reland3049 is not audited here.

Scope: SMTP connection retry lifecycle.
