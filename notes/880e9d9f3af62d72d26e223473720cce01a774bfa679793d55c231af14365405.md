# Calendar row visibility depends on the hidden-aware display rules as well as the row event

The dialog handles a component's visibility event by hiding its closest hideable-row. The description wrapper includes the expand control; the categories host is itself the row. Flex/grid selectors are scoped to elements without hidden so row state and layout rules agree. Keep the original :host&:not([hidden]) rule separate from accepted :host(:not([hidden])); no original selector parsing or computed layout was tested. Direct test assertions cover visible/hidden rows, without proving focus or accessible-tree behavior.

Scope: Calendar read-dialog row layout.
