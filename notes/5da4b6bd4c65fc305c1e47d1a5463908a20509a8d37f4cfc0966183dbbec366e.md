# Outlook composition can leave its wait when shutdown starts

nsOutlookCompose starts asynchronous RFC822 composition and waits for its listener. The repair adds account-manager shutdown as another reason to leave the spin, preventing that wait from holding shutdown indefinitely. After leaving, the code still requires a returned file for a successful result; ProcessMessage copies only on success. The author explicitly says this does not repair the hanging import itself. The reporter’s scanner theory was later withdrawn. No Outlook import, shutdown, crash reproduction or native Windows test ran.

Scope: Outlook import shutdown.
