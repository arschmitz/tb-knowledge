# Persist virtual-folder sort choices even when the view is empty

Quick filtering a unified folder can leave the search DB view empty while the user changes sort type. Sort previously returned early and lost that choice when the query changed or cleared. The fix stores m_sortType, m_sortOrder, and SaveSortInfo before returning on zero rows. A requested test closes and reopens an empty multi-folder virtual view and checks both sort type and direction.

Scope: message search DB view.

- `mailnews/base/src/nsMsgSearchDBView.cpp`
