# Quick-filter deferred search is a coalesced UI scheduling step

deferredUpdateSearch clears its previous timeout and schedules updateSearch after the current click handler, so the UI has a chance to paint. It does not return a search-completion promise. The current updateSearch checks for an active filterer and view search before changing user terms. The 2024 cleanup removes write-only activeElement plumbing and comments describing focus protection that the code did not implement. Manual comment proposal: describe the real scheduling and guard behavior; do not preserve stale parameter or focus claims merely because they appear in older code.
