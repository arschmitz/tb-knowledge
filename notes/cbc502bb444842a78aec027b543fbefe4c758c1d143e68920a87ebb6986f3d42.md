# Cross-folder thread identity includes the folder and message key

nsMsgXFViewThread stores parallel key, folder and level arrays. GetChildHdrAt opens the database of the folder at that index before looking up the corresponding key. A key by itself is not a global message identity in this view. Preserve the array alignment and folder context when changing insertion or hierarchy code.
