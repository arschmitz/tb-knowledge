# Filter-list close prompts keep Continue at button zero and resolve deletion strings before the preference guard

The filter-list dialog uses a synchronous Localization getter for prompts. During filtering, Continue is button 0; its result returns false and the window close handler prevents close. The other result stops navigation before close is allowed. For a valid deletion, both translated strings are resolved before the confirmation preference is checked, while the actual prompt stays guarded. Deletion then walks the shrinking selectedItems list backward. These are static control-flow and evaluation-order facts, not observed prompt results.

Scope: Filter-list dialog Fluent prompts.
