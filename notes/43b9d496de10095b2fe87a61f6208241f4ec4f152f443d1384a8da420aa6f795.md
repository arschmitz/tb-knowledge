# Reject new bad server hostnames while rescuing old account data

Current CreateIncomingServer rejects unusable hostnames before creating a server. Local Folders and smart mailboxes are special names only for type none, and their percent-encoded spellings are rejected. Ordinary names must pass domain-to-ASCII validation and standard URL construction; this is not an ASCII-only policy. Loading an existing configured server instead substitutes <key>.invalid on validation failure so the user retains access to the account. Tests exercise both rejection and pref-based rescue. Use test.localhost in generic local/POP fixtures rather than borrow the special Local Folders name for every protocol.

Scope: accounts.
