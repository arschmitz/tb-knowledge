# Preserve the macOS language-pack exception inside release routing

The language-pack task uses linux64 for the normal per-locale upload and macosx64 for ja-JP-Mac. Even on beta, release or ESR projects, the macOS branch is unlisted, while the default platform branch is listed. For this mapping, adding a release project must retain the nested platform exception. The comment and mapping are source evidence; actual add-on service publication was not run. This is static source evidence. No runtime, build or accessibility session was run.
