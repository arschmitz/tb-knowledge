# About-dialog architecture labels use explicit Fluent variants

The About dialog shows bitness for x86 and x86-64 and an architecture name for other architectures. A literal Map selects base, architecture and nightly Fluent IDs; nightly adds the build date. The four IDs include both aboutDialog-version and aboutdialog-version-arch spelling. The Fluent comments document the argument types and examples. Manual localization naming proposal here: preserve exact literal IDs and keep the selected message’s arguments aligned with its documented variant. A casing cleanup must not mechanically rename existing localization contracts. This is a local mapping pattern, not a repository-wide requirement to use a Map for every Fluent selection.

Scope: about-dialog-localization.
