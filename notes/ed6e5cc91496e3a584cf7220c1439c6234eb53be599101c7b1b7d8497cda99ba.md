# Account Hub finished-event counts describe discovery results before sync selection

The controller records account_hub_finished from returned discovery arrays before displaying optional sync choices. Calendar entries can include existing-calendar descriptors, so the count is not newly created or successfully synchronized resources. The catch emits zero/zero before distinguishing user skip from other errors; those extras alone cannot distinguish an empty result from fallback. Added tests assert one event and zero/zero or one/two extras in two normal IMAP scenarios. They do not prove every error path records once or that every account-creation route uses this event, and no telemetry/runtime execution was performed.

Scope: Account Hub completed-account discovery telemetry.
