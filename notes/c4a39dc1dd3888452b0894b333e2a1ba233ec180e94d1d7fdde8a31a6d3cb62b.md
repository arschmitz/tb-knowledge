# Folder copy preserves the selected copy action within the same server

The folder UI no longer turns same-server Copy To into a move or rejects same-server copy during drag-over. Context and drop callers pass the chosen isMove to the deferred copy-service call and retain that choice for Again preferences. The helper returns no completion result; backend queue/listener handling determines completion. Other target restrictions and the explicit multi-selection limitation remain. This is a UI action contract, not proof of every backend recursive-copy or move outcome. No runtime tests.

Scope: folder-pane-transfer-action.
