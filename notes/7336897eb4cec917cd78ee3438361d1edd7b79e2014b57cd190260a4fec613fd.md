# Message-header Star buttons expose pressed state and the multi-message test checks it directly

The single-message and multi-message Star controls are native buttons whose aria-pressed value follows existing flag state. The multi-message test directly checks pressed and unpressed states and verifies that checkbox state is absent. Recipient popup and website roles are separate source changes; these three assertions do not directly test their keyboard behavior or a native accessible tree.

Scope: Message header Star-button semantics and tests.
