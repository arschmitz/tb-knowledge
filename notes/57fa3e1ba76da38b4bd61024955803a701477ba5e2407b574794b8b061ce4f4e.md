# Allow the lock owner to write IMAP offline data and reject other writers

Current ParseAdoptedMsgLine checks the lock only when beginning a new offline message. It asks TestSemaphore(this) to distinguish its own OfflineDownloadAll lock from a compaction or other owner’s lock, and returns NS_MSG_FOLDER_BUSY before creating an offline header/stream when another owner holds it. The protocol checks that return and sets PseudoInterrupt. Self ownership is intentional; a blanket locked-folder rejection would also block the legitimate downloader.

Scope: mailnews/imap/src.
