# Remote context menus reconstruct pointer metadata and screen coordinates

The parent actor routes a remote contextmenu message to the receiving window. Two handlers construct a PointerEvent, scale screen device pixels by that window ratio, map the integer inputSource to pointerType and pass the event to openPopupAtScreen. The generic handler also rejects stale globals. This supplies popup trigger metadata, not a dispatch into the original page or proof every input/device path works. The upstream producer and native popup contract remain unpaired. No menu or input test ran.

Scope: ContextMenuParent popup trigger reconstruction.
