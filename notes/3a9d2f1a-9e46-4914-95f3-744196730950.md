# Route message MIME links before generic filename-extension handling

A news link embedded as a MIME part can become an imap/mailbox URL with filename=message.rfc822. MailLinkParent checks message/rfc822 before ordinary extension handling and calls AttachmentInfo.open with the target browsingContext. Entry313 and current source preserve that path. The explanatory comment is needed because an EML-only filename assumption would break this generated URL again.

Scope: message attachment link routing.
