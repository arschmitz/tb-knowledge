# The fallible LoadInfo port returns before protocol registration or channel opening

The five comm call sites replace direct construction with MOZ_TRY(LoadInfo::Create(...)) while preserving principal, flags and content type. IMAP protocol creation sets loadInfo before adding the connection to its cache; mailbox loading sets it before Initialize/LoadUrl, and stream branches create it before NewChannel. These are checked call-site error boundaries. Gecko factory internals and paired-build compatibility were not validated; no message load or build ran.

Scope: Mail protocol fallible channel setup.
