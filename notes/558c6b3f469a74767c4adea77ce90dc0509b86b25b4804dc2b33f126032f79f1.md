# Commands desktop alpha release, Mac signing, and GitHub binaries

Alpha.1 exposed different Team IDs in Electron Framework and the main executable. Applying `desktop/mac-entitlements.plist` with `com.apple.security.cs.allow-jit` and `com.apple.security.cs.disable-library-validation` to all signed Mac binaries fixed framework/native-addon loading while retaining hardened runtime.
