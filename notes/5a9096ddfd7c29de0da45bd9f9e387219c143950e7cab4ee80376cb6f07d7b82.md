# IMAP filter copies register before lookup and resume queued actions only after the count reaches zero

The IMAP filter registers a copy before destination lookup so a synchronous lookup failure is still tracked. Its call-site completion lambda ignores duplicate completion, while CopyServiceListener only forwards the status. Playback remembers a request and returns while any registered copies are pending; the final completion resumes it. This is a folder-wide pending-copy barrier with per-message retained headers, not a runtime proof that every native copy callback arrives. The checked tests cover command order, copied body data and failure recovery; no test ran here.

Scope: IMAP incoming filter copy ordering.
