# Message-ID lookup closes a database only after an owned unsuccessful search

findMsgIdInFolder records weOpenedDB before acquiring folder.msgDatabase. It returns a found header before the cleanup branch; after a miss it force-closes and clears the folder database only when that lookup opened it. Errors are logged and recursive subfolder search can continue. The folder databaseOpen attribute describes its current database reference. This contract does not promise closing on every return or exception path, and its recursive default remains true. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: MailUtils Message-ID database ownership.
