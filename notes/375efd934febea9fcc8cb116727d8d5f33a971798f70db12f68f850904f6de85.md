# Check both the saved session file and the restored application state

The session test quits in-app, checks session.json, restarts, then compares the restored tab descriptions. It treats the first mail3Pane tab separately from saved secondary tabs. assert_similar checks every expected dictionary key, but lists must have the same length and order. It only checks windows[0], so it is not a full multiwindow persistence test. Use this comparator only when ignored extra metadata is deliberate. Document its partial-object and strict-list semantics.

Scope: mail/test/marionette.
