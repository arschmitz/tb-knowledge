# Alarm write rejection shares the local fallback for an ineffective saved result

Snooze and dismiss return early only when modifyItem resolves with the requested saved property or acknowledgement. A rejected write now logs a warning and reaches the same local ignore path as a resolved write that did not preserve the requested state. This handles the awaited write failure, not every possible exception in the method. The original ignored the item without a cutoff; fixed accepted dismiss later stores an acknowledgement time to preserve future occurrences. Keep that later recurrence behavior separate from this error-catching phase.

Scope: calendar-alarms.
