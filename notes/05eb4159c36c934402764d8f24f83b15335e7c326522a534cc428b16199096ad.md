# Folder-pane mode headers use one Fluent ID family, including tags

The landing replaces the properties-bundle text assignment with setAttributes on the cloned .mode-name header. The ID is folder-pane-mode-header-${modeName}; tags no longer needs a separate lookup branch. Six Fluent values and six COPY transforms preserve the old English labels. The actual document loads about3Pane.ftl. Header visibility still depends on how many modes are active. Attribute assignment is a localization request, not proof that translation has completed before a detached window or test reads text. The accepted archived recipe has the original blob; no migration or browser test ran.

Scope: Folder pane mode header localization.
