# Keep the MDN reply ID distinct from the original message ID

483 gives m_messageId to the new MDN reply and m_originalMessageId to the message being acknowledged. Current generator puts the former in Message-ID and sendMailMessage, and the latter in References/Original-Message-ID. Mixing them can send an envelope ID different from the generated MIME header. This supports role-specific naming, not merely an m_ prefix rule.

Scope: mailnews/extensions/mdn.
