# Offline-read ownership clears references after handoff and after the final callback

The historical fix clears the channel’s stored stream listener after the offline helper accepts the asynchronous read. The wrapper releases its channel after forwarding OnStopRequest and applying failed-offline-message policy. These are different lifetime boundaries; the public channel remains the request object while callbacks need it. Breaking one cycle edge is sufficient for the reported pair, so clearing both is not a universal policy. Later accepted Exchange code passes a listener argument directly instead of keeping the historical member. No leak, destruction, cancellation or callback test was run.

Scope: Exchange channel and offline stream listener ownership.
