# Pane-layout is a customized body element, not an extra wrapper

The pane-layout module defines PaneLayout as an HTMLBodyElement and registers the dash-separated pane-layout name with extends: "body". about3Pane waits for its definition before using the paneLayout body. In this family, the module/tag use dash-separated names, the JavaScript class uses PascalCase, and the DOM instance ID uses paneLayout. Preserve those local forms and the customized built-in registration when extending this element. Source was inspected; browser custom-element upgrade and layout behavior were not tested. Full bug and review discussion remains pending.

Scope: Three-pane custom-element naming.
