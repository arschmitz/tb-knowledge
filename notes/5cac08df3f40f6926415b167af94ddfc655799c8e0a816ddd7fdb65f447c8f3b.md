# Name requested OAuth scopes separately from granted scopes

In OAuth test helpers, expectedScope describes the scope in the authorization URL; grantedScope describes the subset selected by the user. An omitted grant and an empty grant have different meanings. Proposed scoped naming practice: name these roles explicitly instead of using one ambiguous scope field across the request and response. The landed helper and frozen accepted JSDoc keep this distinction. The review explains the earlier confusion, but no global naming rule or new user instruction is inferred.

Scope: OAuth test helper naming.
