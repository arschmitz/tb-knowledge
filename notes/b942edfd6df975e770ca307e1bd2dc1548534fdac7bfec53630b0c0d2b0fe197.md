# Filter Log opens a dependent window and passes the current filter list to its log browser

FilterListDialog.viewLog opens FilterLog with chrome,dependent,titlebar,resizable,centerscreen and passes the current filterList. The log window reads that argument, sets its logging checkbox, disables JavaScript in the log browser and loads logURL. Clearing the log calls clearLog then reloads that browser. The historical change replaces modal as a workaround for a reported caught remoteness/sessionHistory exception; it does not establish a general dialog rule or a reproduced Gecko fix. No native window or logging test ran.

Scope: Filter log window contract.
