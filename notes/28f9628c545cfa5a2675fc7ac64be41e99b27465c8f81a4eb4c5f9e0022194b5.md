# Standalone message account setup routes to the main window

The standalone message document loads accountUtils so its menu can call openAccountSetup. The fixed function focuses the main mail window and invokes its Account Hub. MenuTestHelper takes the target document and dispatches through the menu element’s documentGlobal. The historical test directly checks menu states and main-window focus under account-hub/platform gates; it does not create a real account or prove native accessibility. Initial-setup branching changed later, so reuse the current entry point. No account setup ran.

Scope: Account setup window routing.
