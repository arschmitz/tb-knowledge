# Keep native checkbox labels and disabled existing accounts in sync selection

The current sync form creates a native checkbox inside a label with visible account-name text. Existing accounts are disabled, and Select All changes only enabled inputs. Preserve the native label relationship and existing-account exclusion when changing this selector. The numeric counters and keyboard/announcement behavior were not executed here. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/components/accountcreation.
