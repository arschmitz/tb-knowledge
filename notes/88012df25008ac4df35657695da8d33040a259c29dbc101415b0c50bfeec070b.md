# Original-request re-authentication returns the retry response and stops on other errors

The original re-authentication patch validates credentials with the queued operation request and returns the resulting response to the recovering operation. Its prompt loop refreshes credentials after prompting, retries an authentication failure and returns other errors. This avoids treating a connection or processing failure as another bad password in that original loop. The accepted source later uses a different provider and a unit-returning recovery path, so the original response-returning flow is historical. Neither phase proves a runtime cure or exactly-once delivery.

Scope: Thunderbird shared protocol sender authentication recovery.
