# Commands diff viewer navigation and conditional VS Code integration

Diff rows provide `data-old-line`/`data-new-line`. `handleDiffLineContextMenu` chooses the line for the locally resolved side, then falls back to the existing side; form is `vscode://file/<encoded-path>:<line>:1`. Remove the menu on Escape, outside pointer, scroll, and resize; omit it for files without a local editor link. [Task 1]

Scope: console.
