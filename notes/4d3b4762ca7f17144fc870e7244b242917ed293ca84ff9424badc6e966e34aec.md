# Name callback arguments for their different roles and update their documentation

1008 changes a context-menu helper argument from element to elementToClick and updates its @param text. The observerElement receives popupshown, while elementToClick is the click target and supplies its document global. Those may be different elements because the popup may be created during the click. Prefer role names when two arguments have the same type but different jobs; keep parameter documentation aligned with the signature.

Scope: Extension menu callback argument naming.
