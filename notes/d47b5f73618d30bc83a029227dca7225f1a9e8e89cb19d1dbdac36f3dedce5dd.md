# Account Hub text fields declare their shared radius token explicitly

Inside Account Hub forms, .input-field and .input-textarea set border-radius to --button-border-radius. The inspected shared token declaration is3px. Keep this component selector and explicit token dependency when tracing input appearance; an inherited generic input style can change independently. This is a scoped accepted pattern, not a requirement for every input or theme. No computed-style, visual, zoom or accessibility check ran.

Scope: account-hub.
