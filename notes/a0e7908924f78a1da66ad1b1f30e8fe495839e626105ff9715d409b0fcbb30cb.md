# Task context menus update referenced commands and commandless parent menus separately

The task popup maps direct child command names to command elements before writing disabled state. Calendar and Convert parent menus have no command attribute, so their disabled properties are set explicitly. Property menus separately clear referenced checked properties and retain zero as a valid selected value. This split follows actual menu ownership; it does not update every descendant or establish native popup behavior from a static read.

Scope: Calendar task context-menu command ownership.
