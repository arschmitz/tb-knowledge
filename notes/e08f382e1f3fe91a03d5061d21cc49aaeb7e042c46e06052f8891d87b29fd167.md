# Treat the built-in theme path as a complete resource location

925 removes a second resource://builtin-themes/ prefix. BuiltInThemeConfig stores complete resource URIs, and both the active-theme installer and the all-theme installer pass that value directly. The preview helper appends preview.svg to the same configured directory. Preserve the configured path representation across consumers instead of rebuilding a prefix in one caller.

Scope: Built-in theme configured paths.
