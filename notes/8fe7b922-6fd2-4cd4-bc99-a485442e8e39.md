# Use a promise request observer for asynchronous send tests and keep stream data behavior in the subclass

The accepted 2024 refactor added PromiseRequestObserver to wrap nsIRequestObserver and resolve on NS_OK or reject with the status on failure. PromiseStreamListener extends it, adds nsIStreamListener and data accumulation, and reuses the start/stop behavior. SMTP send tests changed from a URL listener to PromiseRequestObserver because server.sendMailMessage reports through request callbacks. Match the helper to the callback contract and preserve the status failure in the test; do not wait on a URL callback that the new server API no longer emits.

Scope: Mailnews test helpers.
