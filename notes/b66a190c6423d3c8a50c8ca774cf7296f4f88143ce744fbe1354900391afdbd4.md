# PositionedDialog height cap subtracts both margins before positioning

At the fixed revision, PositionedDialog.#update computes floor(containerRect.height - margin * 2), sets maxHeight and passes min(measured dialog height, maxHeight) to getIdealDialogPosition. The position calculation therefore receives the capped height. The shared CSS also sets a viewport maximum and border-box sizing. The current oversized-dialog test asserts lessOrEqual after flooring; it does not require exact equality. The original height-cap landing assigned the cap after calculating position, so current update ordering is a later refinement. No layout or test was run.

Scope: Calendar dialog container sizing.
