# Profile source admission is a heuristic that drives the whole item pane

Directory validation admits a source when prefs.js, ImapMail, Mail or News exists. The item pane then checks all supported import items. A rejected source clears the checks, hides item selection, shows localized text and disables Continue. This Boolean contract does not establish available data for each item or validate file contents. Missing prefs.js returns from preference loading after empty maps are initialized, so a mail-only source can avoid that read failure. Preserve admission, item availability and completed data import as separate facts. No importer or browser test ran.

Scope: Thunderbird profile import admission and UI.
