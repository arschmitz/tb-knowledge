# The ARM Mac build port wires separate opt and debug outputs through signing, repackage and tests

The landing adds distinct macosx64-aarch64/debug and /opt jobs, enables build signing, routes both platform names through Mac signing/repackage, and gives the macOS 15 test entries matching build and repackage signing labels. The accepted comm test loader ignores a test platform if its build platform is not loaded, then carries the configured labels into generated test descriptions. These are source-declared routing contracts; imported transforms, worker provisioning, signing artifacts and successful task execution were not verified.

Scope: macOS ARM build and test routing.
