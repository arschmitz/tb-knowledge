# Clear the displayed feed message before removing its test account

676 fixes a leak by clearing threadTree.selectedIndex after its feed display helper. Current code places the clear in each selectWebsite/selectSummary/selectFolder task before registered cleanup removes the RSS account. The menu-bar path is still skipped on macOS because the test cannot click the native menu bar. This is a test lifetime boundary, not a product change to RSS display or evidence of a general account leak. No leak checker, native menu test or browser test was run.

Scope: RSS browser-test lifetime.
