# A safe listener default failure callback depends on the native fallible interface

SafeListener.on_failure converts the error and queries IExchangeFallibleOperationListener. It calls OnOperationFailure only when that interface exists; otherwise it returns Ok without that native callback. handle_error logs the operation error and separately logs a failing callback result. A safe-wrapper name or Ok from this default method is not proof every listener received failure notification. The historical concrete sync listener declares the fallible interface, but the generic trait uses a conditional query. Static source only.

Scope: Shared protocol listener failure dispatch.
