# Folder reordering must keep explicit ordinals and cached order consistent

Panorama sorts explicit ordinals first; natural order then uses special-folder flags and name collation. The historical fix writes in-memory ordinals too and clears them before cross-parent insertion. resetChildOrder removes manual order. Direct tests reorder and reset mixed special/ordinary folders. Fixed ID-based code checks SQL success before updating cached ordinals. Do not infer that the older nsresult return type checked every Execute or that comparator equality edge cases were tested.

Scope: Panorama folder order state.
