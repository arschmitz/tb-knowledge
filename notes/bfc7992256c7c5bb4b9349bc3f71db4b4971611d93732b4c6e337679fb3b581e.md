# Address-book documentation names dirType constants for each provider family

The documentation maps SQLiteDirectory to JS_DIRECTORY_TYPE, CardDAVDirectory to CARDDAV_DIRECTORY_TYPE, LDAPDirectory to LDAP_DIRECTORY_TYPE, both native OSX/Outlook directories to MAPI_DIRECTORY_TYPE, and ExtSearchBook to ASYNC_DIRECTORY_TYPE. It tells callers to use the named nsIAbManager constants. This is documented API scope, not a verified numeric/getter implementation or a change to the earlier first-run URI checks.

Scope: Address-book directory documentation.
