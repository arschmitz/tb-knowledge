# The autosync test helper documents a folder type while callers supply an incoming server

runAutoSyncTest's new JSDoc names nsIMsgIncomingFolder and describes an incoming message. The inspected EWS/Graph setup helpers instead return incoming servers through LocalAccountUtils, and the account-manager factory declares nsIMsgIncomingServer. The test uses the parameter's type and rootFolder as server properties. This is a concrete documentation mismatch in that helper; no compiler or runtime failure was tested.

Scope: Exchange autosync helper JSDoc argument contract.
