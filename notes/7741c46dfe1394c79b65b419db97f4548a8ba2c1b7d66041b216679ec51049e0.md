# Chat test teardown arms a storage observer before deleting the account

This landing replaces one microtask wait in 19 chat task teardowns with an observer created before deleteAccount and awaited afterward. The inspected account receiver starts async password removal without waiting for it, while deleteAccount returns after account collection updates and account-removed notification. The test observer filters only by passwordmgr-storage-changed, so the inspected source does not prove that the received notification belongs to that account or that the store is empty. This is a scoped test synchronization change, not a general cleanup or login API rule.

Scope: Chat browser-test async password cleanup.
