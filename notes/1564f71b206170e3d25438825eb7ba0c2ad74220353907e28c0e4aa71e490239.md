# Keep compaction metric names aligned across YAML and C++ and JS

This Glean family defines snake_case metric names in mail/metrics.yaml, uses those names through mozilla::glean::mail in C++, and reads their generated lowerCamel names through Glean.mail in JS. compact_result uses the lowercase hexadecimal nsresult label, matching Cr.NS_OK.toString(16) in the test. Keep those generated-name and label relationships when extending this family. The source now references data review comment 7; merely reading that URL in YAML does not establish the approval discussion. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Folder compaction metric naming.
