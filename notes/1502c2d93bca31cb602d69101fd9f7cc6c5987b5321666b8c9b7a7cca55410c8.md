# Removing an old clang task also removes its runtime and engine-reference names

The owned cleanup removes local clang20 tasks, their versioned runtime fetches and 20/selected19 engine references, then updates the documentation example to 21. The fixed accepted definitions later use22; the old documentation path is gone. Preserve the exact version phase and inspect both local tasks and reference names. This static cleanup does not prove task generation, repacking or a successful build.

Scope: Taskcluster compiler cleanup.
