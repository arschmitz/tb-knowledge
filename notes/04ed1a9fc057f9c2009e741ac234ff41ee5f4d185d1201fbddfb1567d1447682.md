# Do not treat replacement of an optional config key as insertion

671 unconditionally reads GECKO_HEAD_REV while constructing a replacement. Cached Bug 1905941 gives that absent key as the cause of the later central-to-beta failure and backout. The later workaround uses a ###### placeholder for that transition; current main-to-beta retains the placeholder path and directly replaces GECKO_HEAD_REV for other transitions. This is distinct from the first July central-to-beta breakage, whose exact cause remains unproved. Source plus cached full bug context support the later diagnosis; D215538 file bodies were Loading, so inline feedback is still pending.

Scope: Merge automation breakage and workaround.
