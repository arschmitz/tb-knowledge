# Recurrence mutations normalize the JavaScript object before identity lookup

The direct replacement for unwrapInstance selects a truthy wrappedJSObject or the original input. Recurrence deletion applies that selection before indexOf; append, insert and exception mutation use it before storing or validating the object. Item cloning separately keeps the new-parent/original-parent fallback and assigns the cloned recurrence backlink after its wrapper check. Existing guards and ownership branches remain separate. No arbitrary getter equivalence, wrapper runtime or clone result was tested.

Scope: Calendar recurrence object identity.
