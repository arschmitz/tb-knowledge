# Split escaped folder URI components before unescaping names for storage

Folder URI conversion receives an escaped path and finds its hierarchy separators before unescaping each component for NS_MsgHashIfNecessary. Unescaping the full URI first would let a slash in a folder name change the component boundaries. Mbox and maildir separately pass raw aFolderName to AddSubfolder while using a safe filesystem name. Accepted later code changes the news conversion order and adds summary-name persistence; those additions are not credited to this patch. The creation fixture checks display names versus storage leaves, not a successful real restart. Required bug/review bodies are missing, so this is source-only knowledge with zero full-audit credit. No test ran.

Scope: folder-uri-storage-paths.
