# Certificate exception continuations wait for dialog closure and distinguish tab teardown

These dependent exception dialogs return before a user chooses. Continuations that inspect exceptionAdded wait for the matching domwindowclosed event and remove the observer. The address-book content adapter also handles unload for a closed tab; IM and feed windows use their real opener window-close notification to close the dependent dialog. Keep these lifetimes distinct when reviewing cleanup. Source establishes ordering and conditional retry, not a fresh certificate UI or network result.

Scope: Certificate exception dialog lifecycle.
