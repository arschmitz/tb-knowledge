# Resume a redirecting discovery generator with explicit user feedback

Accepted parallelAutoDiscovery is an async generator. It yields isRedirect, host and scheme, then expects the next call to carry acceptRedirect. Its test first refuses a redirect and expects null, then accepts a fresh redirect and obtains a config. A caller that only awaits a promise would not implement this contract. The view forwards feedback through discoveryStream.next. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/components/accountcreation.
