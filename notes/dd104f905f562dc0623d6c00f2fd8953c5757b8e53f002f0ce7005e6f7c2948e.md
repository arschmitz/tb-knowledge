# The initial Graph message sync pages create/delete callbacks before publishing its checkpoint

The initial Graph header-sync operation emits created or deleted item callbacks for each page, follows nextLink requests and publishes the sync-state token only at the final deltaLink. It returns start success through the bridge before async completion and does not roll back earlier callbacks on a later failure. That phase uses zero size/false flag placeholders and always creates present items. The accepted later operation attempts updates first and creates only when the listener reports NS_MSG_MESSAGE_NOT_FOUND; these phases remain separate.

Scope: Graph message header synchronization.
