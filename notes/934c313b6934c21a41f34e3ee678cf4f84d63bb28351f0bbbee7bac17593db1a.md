# Graph folder copy returns IDs before native hierarchy reconciliation

The bridge schedules a detached operation; its immediate Ok is not copy completion. The operation batches folder-copy POST requests, extracts returned IDs and selects UseLegacyFallback by the result count. The selected native same-server callback requires one ID and synchronizes the hierarchy for a copy; it deliberately leaves copied-message synchronization to later folder actions. These distinct completion stages do not prove that every batched folder or message was copied, and no copy was executed.

Scope: Graph folder copy completion.
