# Keep ES module startup measurement after legacy module tracking is removed

The port removes Cu.loadedJSModules tracking, but accepted StartupRecorder still records Cu.loadedESModules and instantiated services. The startup test waits for recorder.done and evaluates each phase. Do not describe the change as removing all startup module budgets or infer release-build behavior from the old component comment alone; the test separately gates its supported build types. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Startup module tracking evolution.
