# Read release blob switches through their keyed release-type mapping

The comm Balrog task sets update-no-wnp to false for nightly.* and release, and true for the default branch. The landing describes using -no-WNP release blobs; the switch name alone is not enough to infer what false does. When modifying this mapping, retain an explicit release-type case and check the upstream Balrog transform that consumes the value. That transform is outside the comm source inspected here, so actual release submission and blob naming are not validated. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Release Balrog configuration.
