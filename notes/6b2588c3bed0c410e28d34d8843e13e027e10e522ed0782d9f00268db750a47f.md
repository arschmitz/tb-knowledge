# The generic Calendar row exposes three named shadow slots

CalendarDialogRow attaches an open shadow root, clones calendarDialogRowTemplate and exposes icon, label and content slots. Current assignedElements tests compare each actual assigned element with its light-DOM slot attribute. Preserve that shadow slot boundary when composing sibling rows; appending similar light-DOM markup alone does not create the same slot contract. This is source/identity-test evidence, not a live rendered result. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: calendar row composition.
