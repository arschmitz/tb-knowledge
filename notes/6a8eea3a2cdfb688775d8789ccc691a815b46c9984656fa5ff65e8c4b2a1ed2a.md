# Keep queued folder-name serialization despite removing it from completion matching

m_dstFolderName still participates in queue conflict checks with destination identity, but FindRequest no longer uses it. The Init comment says the saved leaf name lets FindRequest find a folder request, which is stale. Recommend updating that comment to the current queue role; the correct cleanup is not deleting a field that another caller still uses. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
