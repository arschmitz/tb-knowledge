# DAV redirect verification no longer waits for a session redirect hook

The owned change removes CalDavSession.prepareRedirect and its ICS no-op counterpart. CalDavRequestBase now completes local redirect preparation and calls the verification callback directly, rather than waiting on that session promise. Its separate commit method still awaits prepareRequest before executing the initial request. Authorization copying is limited by matching prePath values in this phase; the fixed comparison source has a later cross-origin abort branch. Both required discussions are denied, so review rationale and runtime authentication behavior remain unavailable.

Scope: CalDAV and ICS request preparation.
