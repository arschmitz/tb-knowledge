# Grow MessageList options as named fields with explicit defaults

MessageList options now carry messagesPerPage and includeDeletedMessages, with nullish defaults at construction. Event callers set the inclusion flag while other list callers retain the default. Follow this local named-options shape when adding independent list policies, so page size and deletion visibility do not become ambiguous positional values. This is a scoped recommendation from current code, not an approved project-wide syntax rule. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension message lists.
