# Keep update release type separate from the URL channel slug

495 differentiates ESR update-channel/type from release/beta URLs. Current whats_new_page has explicit channel=esr for ESR families and channel=beta for beta, with major-version transition conditions; its release-types release list is now empty. Do not assume internal ESR product names are the user-facing URL channel. No update-service evaluation was executed.
