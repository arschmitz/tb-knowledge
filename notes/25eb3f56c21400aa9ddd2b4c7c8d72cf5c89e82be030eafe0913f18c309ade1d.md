# Assert caret behavior instead of an obsolete spacer node

The cloud-file test types two line breaks, adds real Filelink URL nodes, then types again. It now checks the typed text immediately before the attachment root rather than requiring a separate br spacer. The same subtest runs in HTML and plaintext composers. Keep assertions tied to insertion and caret behavior when an upstream editor changes markup. Markup that controls behavior still matters; this example does not justify removing all DOM checks. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/cloudfile/caret-test.
