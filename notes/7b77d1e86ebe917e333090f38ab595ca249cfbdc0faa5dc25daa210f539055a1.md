# Delete a moved source only after destination creation succeeds under its current contract

EndMove is deliberately a no-op; OnCreateFinished handles failure before deleting the source and starts the next message afterward. Current creation success requires remote creation and local DB AttachHdr/Commit success. Only the later offline-content write is tolerated/logged for normal sync recovery. Thus current success is not remote-only, and it is not proof that all destination offline bytes were written. Preserve that exact boundary when reviewing destructive move ordering. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Exchange copy destination success boundary.
