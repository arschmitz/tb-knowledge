# Test Sync records after encryption and decryption round trips

The accepted Sync extension guide requires roundTripRecord around createRecord assertions, so tests inspect what would reach the server after record encryption and decryption. Its file naming pattern is modules/engines/things.sys.mjs, test/unit/test_thing_store.js, and test_thing_tracker.js; the singular Thing names the record/store/tracker while plural Things names the engine. Also test unknown-field preservation, invalid updates, tombstone removal, and tracker positive and negative changes. This is component-specific guidance, not a repository-wide naming rule.
