# Persisted extension menus restore parents before children

initExtensionMenus reads stored menu properties in insertion order, constructs MenuItem objects, and removes entries that fail reconstruction. The code comment explains that parent records must precede children. This is why menu reparenting and update order matter to startup behavior. For a persistence change, test restart with nested menus, changed parentId and a malformed stored item, not only menus created in one session.

Scope: Extension menus.
