# Attachment rename tests supply prompt input before checking rename events

The attachment test arranges a prompt callback before cmd_renameAttachment, supplies loginTextbox text, clicks accept and awaits the returned result before checking rename events. The blank-name case separately expects no event. RenameSelectedAttachment returns for an accepted empty or unchanged name before updating the attachment. This preserves each caller's input and result checks without relying on the deleted mock's method-state field.

Scope: attachment-prompt-tests.
