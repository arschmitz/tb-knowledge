# The small OpenPGP button rule covers both HTML and XUL controls

The new max-content minimum applies to .button-small. The accepted Publish control is an HTML button, while expiry and external-key removal are XUL buttons with that same class. Publish shares an hbox with a description. The CSS comment's all-HTML wording must not replace these actual element roles, and the source constraint is separate from a rendered clipping or localization result.

Scope: Thunderbird account settings OpenPGP button sizing.
