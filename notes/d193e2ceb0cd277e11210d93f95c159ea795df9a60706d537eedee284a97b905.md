# Localization source signing derives its upstream task from the primary dependency

define_upstream_artifacts uses get_primary_dependency, copies the dependent job attributes and creates a task reference from dep_job.kind. The taskType is build except for a dependency kind containing notarization, where it is scriptworker. Entry 698 removes the separate upstream_artifact_task transform and its job override. Manual taskgraph proposal in this transform: derive reference and task type from the resolved dependency together; a syntactically valid task reference can still identify the wrong worker class. The current transform signs strings_all.tar.zst and l10n-changesets.json with gcp_prod_autograph_gpg. No taskgraph generation or signing task was run.

Scope: taskgraph-signing.
