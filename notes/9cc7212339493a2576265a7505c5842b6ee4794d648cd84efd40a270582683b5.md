# Category work checks route ownership and render identity

For Bug 2084433 at revision 24ae8c26d87e424b3f98e49153604460e4ede65b, the implementation report says category controls capture their owning route, while render completions check both route currency and render ID. The intended result is to ignore controls and delayed translation results from a previously opened event. Tests reportedly cover both cases. This is a scoped category-rendering design claim, not a general requirement to add generation checks to other Calendar controls.

Scope: Calendar event category asynchronous rendering.
