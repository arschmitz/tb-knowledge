# Calendar subviews lock the default view size until navigation returns

CalendarDialogSubviewManager contains initially hidden ID-addressed child views and a default-subview attribute. showSubview returns without an event for the current ID and throws for a missing target before hiding the old view. On the first departure from the default, it records the old view height/width. Other non-default views retain those limits. Returning to default clears the inline dimensions, then emits subviewchanged with the selected ID. The complete historical browser fixture/test covers size retention, massive content, events, errors and default helpers; it does not prove scrolling, zoom, focus transfer or accessible state. The fixed accepted manager retains the same implementation. Static source/test-code evidence only.

Scope: mail Calendar dialog subview manager.
