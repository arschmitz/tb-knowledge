# Expose Thunderbird compose and message scripts under the Manifest V3 scripting namespace

Thunderbird has two document types beyond web pages: the compose editor and displayed mail messages. Bug 1896522 adds scripting.compose and scripting.messageDisplay for Manifest V3 and restricts the old composeScripts and messageDisplayScripts namespaces to Manifest V2. The new schemas use file URLs rather than code strings and provide registerScripts, getRegisteredScripts, and unregisterScripts with script IDs and optional ID filters. The registered scripts apply to newly opened compose tabs or newly loaded messages; the schema tells extensions to use scripting.executeScript for already open targets. The implementation and schema are packaged in jar.mn and registered in ext-mail.json. Current schema retains these namespaces. D210241 was accepted after a secondary review.

Scope: Thunderbird extension API architecture.
