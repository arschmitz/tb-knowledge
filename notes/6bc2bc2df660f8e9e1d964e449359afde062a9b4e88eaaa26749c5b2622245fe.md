# The extension search-provider wrapper awaits the singular SearchService API

The comm wrapper now awaits SearchService.addEngineFromExtension(extension). Its existing catch logs the error and returns false; otherwise it returns true. The manifest consumer awaits the wrapper but does not read that Boolean, and its default-engine handling stays separate. This source check establishes the comm call site and local flow, not the unread upstream engine implementation or a fresh telemetry/search test result.

Scope: Extension search-provider API port.
