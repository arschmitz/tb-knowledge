# Body-search case tables reach a shared assertion without a message

The added HTML cases supply an expected hit count to TestSearch. Its onSearchDone checks that scalar count with Assert.equal(aHitCount, hitCount), without a message argument. The preceding print call is separate and does not satisfy the assertion-message requirement. A useful diagnostic should name the searched value and expected hit count; this study does not change the helper or execute the cases.

Scope: Body-search regression diagnostics.
