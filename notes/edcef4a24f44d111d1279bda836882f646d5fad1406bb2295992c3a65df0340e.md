# Test the focused Account Hub input and the Enter result together

The protocol/password form patch adds hidden submit controls and retains a submit receiver that prevents default, checks form validity, then runs the forward action. Review asks for both focus identity and Enter behavior. The added test compares the shadow root active element with the recommended POP3 input, sends Enter and waits for the password view; the password scenario also sends Enter. The producer calls focus on the recommended label, so test-code inspection is not proof that input focus or submission works live. No keyboard test ran.

Scope: Account Hub keyboard browser tests.
