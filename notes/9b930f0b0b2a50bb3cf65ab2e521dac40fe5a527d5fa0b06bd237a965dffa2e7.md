# A contact icon can omit its own tab stop only with a working equivalent keyboard route

The accepted internal icon has tabIndex -1/keyNav false because the first popup command exposes the same action. Its outer recipient item is role button, tabIndex 0 and aria-haspopup menu, and Enter/Space opens the popup with prevented default. Preserve that scoped equivalent route and combined accessible label if refactoring the icon. Source inspection is not keyboard, screen-reader or accessibility-tree validation. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
