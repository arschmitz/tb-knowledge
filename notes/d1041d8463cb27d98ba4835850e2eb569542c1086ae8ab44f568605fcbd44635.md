# Keep Mork JSON fixture expectations tied to the parser output version

The JSON regression patch adjusts the original Mork table regex and tests a flat row list by explicitly parsing columnStates as JSON, then checking the following message ID. It also routes a command-line .msf file to dumpFile. The fixed parser returns tables and automatically unpacks JSON-looking values, preserving the original string when parsing fails; its test finds table and row IDs before reading the object. Preserve the representation at each revision. This one fixture does not prove all Mork formats, and no parser or CLI test ran.

Scope: Mork JSON parser regression coverage.
