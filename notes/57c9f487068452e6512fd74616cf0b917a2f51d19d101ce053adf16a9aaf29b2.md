# Use an octal literal for a literal filesystem permission

Manual syntax proposal for new or changed calendar stream/file code: write a literal permission in 0o form, such as 0o0664, instead of parseInt("0664", 8). The accepted export change makes the numeric meaning explicit and avoids parsing a constant string at runtime. Keep the bitmask stream modes in their existing hexadecimal representation. This is a scoped preference supported by the landing and current code; nearby legacy test helpers still use parsed octal strings, so it does not justify an unrelated tree-wide rewrite.

Scope: calendar-export.
