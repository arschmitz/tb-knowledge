# The enabled Graph trash test directly checks a moved subfolder

The newly enabled Graph task runs the existing soft-delete helper. It checks the moved folder remote parent, waits for local Trash subfolders to disappear, syncs and asserts the moved folder is absent remotely. It adds no message fixture or direct assertion for message deletion, mixed failures or rollback. The null passed to emptyTrash is a URL-listener argument in this source phase. No test was run.

Scope: Graph EmptyTrash test coverage.
