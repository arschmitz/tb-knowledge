# Try-comm-central graph policy and root task expiry are separate configuration scopes

The port changes try-comm-central default, medium and long expiration policy values to 28days while keeping7day and 14day short policies. The root task template separately uses28days for its try-comm-central expires field. Those declarations serve different scopes; the root value alone does not establish that graph configuration passes validation. The inspected comm verifier resolves project try at level1 and checks each value against28days, so its exact selection also matters. No policy evaluator, decision graph or build was run.

Scope: Taskgraph expiration policy.
