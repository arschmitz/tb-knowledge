# Remove vCard backing properties before removing their editor rows

The organization editor owns associated title and role rows. Removing their DOM nodes alone left title/role in vCardProperties and Save restored them. Dispatch the existing bubbling vcard-remove-property event before removing each row, so the general handler updates the backing entries. The regression test checks title/role absence before saving. The current handler also moves focus to a valid neighbor or the fieldset add button. Preserve model cleanup and focus together; no live focus or screen-reader check was run.

Scope: mail/components/addrbook.
