# The Yahoo/AOL PKCE switch changes both OAuth inputs and the CardDAV veto

This patch enables PKCE for Yahoo and AOL, replaces client IDs, removes built-in client secrets and supplies HTTPS loopback redirects. The OAuth receiver creates an S256 challenge and later sends code_verifier for authorization-code exchange; null secrets are omitted. Expanded scope strings and the aol.com parent mapping are separate changes. Removing Yahoo's null CardDAV preset removes an early incompatibility rejection and allows ordinary discovery; it does not prove discovery, server authorization or service success. The current Yahoo scheme redirect is later work.

Scope: Yahoo and AOL OAuth provider integration.
