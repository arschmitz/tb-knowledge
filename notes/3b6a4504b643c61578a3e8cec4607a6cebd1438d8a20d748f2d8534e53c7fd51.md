# Replace All scans ordered document boundaries and ends its transaction in finally

Replace All scans the full editor document independently of the wrap option. Backward mode retreats the end boundary before replacing a match; forward mode advances from the editor selection after replacement. The finally block ends the transaction even on the early return or an exception. The normal compose command supplies a non-null editor. The added test directly checks only that lowercase apples is absent; it was not run here.

Scope: Thunderbird compose Find and Replace.
