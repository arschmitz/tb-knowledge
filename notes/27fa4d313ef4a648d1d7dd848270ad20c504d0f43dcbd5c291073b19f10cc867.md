# Manual folder sorting tests assert URI order after a complete simulated drag session

The manual-sort browser test resolves source and target rows, starts a test drag session, sends dragover and drop at target-relative coordinates, then ends the session. The sequential task directly compares the tree row URI array after each move. The fixed test also asserts drop-indicator geometry, visibility and cleared drag state. This proves the expected assertions exist; it is not a fresh native drag result. Keep per-drag result/dataTransfer local to the helper, while named folder fixtures remain shared with setup. Four expected-order messages were added after review. The original patch has fewer scenarios than the fixed test; later reset/alphabetic coverage is separate.

Scope: Manual folder sorting browser tests.
