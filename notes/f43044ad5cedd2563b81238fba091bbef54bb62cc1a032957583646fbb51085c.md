# The standalone Panorama document owns its selected live-view adapter

The first standalone Panorama document builds a folder/tag navigation list and creates a new LiveViewDataAdapter for the clicked target. Its initial unread-only radio is sampled during that click; changing the radio alone has no listener that refreshes an existing view. On unload the script assigns messageList.view=null. In exact accepted consumers, the base tree setter detaches the previous view with setTree(null), and LiveViewDataAdapter clears its registered live-view listener and references. The owned patch packages a diagnostic document, not a normal mail-tab integration. Current grouped/threaded/conversation controls and async counts are later phases. No UI, database or accessibility run establishes broader cleanup or user-flow guarantees.

Scope: Panorama diagnostic document.
