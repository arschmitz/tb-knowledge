# The shared sender preserves the queued URI while adding current authentication

The shared sender translates the already-built request's method, URI and headers, then sets a supplied authentication header. It does not rebuild the URI from an updated base URL. A nonempty body requires Content-Type; an empty body skips that body-specific requirement. Callers must distinguish configuration used to build a later request from the immutable URI already queued for retries. This is source inspection, not an authentication or configuration-change test.

Scope: Protocol HTTP request contract.
