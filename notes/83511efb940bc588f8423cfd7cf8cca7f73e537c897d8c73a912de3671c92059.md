# Separate folder identity names from localized display names

1976 migrates folder/server names to UTF-8. Accepted nsIMsgFolder now uses AUTF8String name and AString localizedName for user-facing text. The latter can localize special folder names. Preserve this identity/display distinction; the broad migration does not mean every native string or localized UI API uses the same encoding. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mailnews/base/public.
