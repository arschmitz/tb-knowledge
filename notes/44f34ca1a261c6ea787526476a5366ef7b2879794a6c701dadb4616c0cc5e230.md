# A compose encryption tooltip does not establish a usable action control

The subject warning icon has a localized .title, alt="", hidden state and onclick calling toggleEncryptedSubject. That function changes the encryption setting and records that the user touched it. The inspected image has no button element, role, tabindex or keyboard handler. Manual accessibility review proposal for this specific action: check the actual interactive control, keyboard activation and accessible name when adding or reviewing its tooltip; consider a named button if this icon is intended as an independently usable action. This is a proposal from a static concern, not a claim that the 2024 review requested a button or that the full encryption UI lacks another keyboard route. The historical misspelling subject-encription-icon is an existing Fluent ID, not a recommended spelling rule. No accessibility tree or runtime keyboard test was inspected here.

Scope: compose-accessibility.
