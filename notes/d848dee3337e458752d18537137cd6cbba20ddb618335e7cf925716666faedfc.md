# Leave room for dialog focus rings when changing viewport geometry

The Remove Account change removed an unneeded inline width/height from the inner viewport because the focused Cancel ring clipped on macOS and Linux. The current document retains its top-level dialog width and defaultButton=cancel; the change was not a ban on every inline size. Review focus at the actual child boundary when changing chrome dialog geometry. Historical review reported platform checks, while this study only inspected markup. Focus visibility, keyboard traversal, zoom and screen-reader announcements remain manual checks.

Scope: Dialog accessibility and layout.
