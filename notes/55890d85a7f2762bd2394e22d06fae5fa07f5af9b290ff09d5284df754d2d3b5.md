# Panorama priority accessors connect the IDL, SQL projection and cached message

This landing adds required priority input after tags, stores it as an integer and appends it at projection index13. PerFolderDatabase passes RawHdr.priority, and nsIMsgDBHdr priority accessors delegate to MessageDatabase. The setter updates SQL and an already cached entry; notification delivery remains TODO. The original changed test fixture adds the schema column but no direct priority assertion. A fresh-schema declaration is not proof of existing-profile migration, complete round-trip behavior or native execution.

Scope: Panorama message priority storage.
