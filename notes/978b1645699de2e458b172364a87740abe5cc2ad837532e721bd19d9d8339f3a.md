# OAuth issuer overrides handle empty strings and Boolean false differently

The accepted issuer override path clones provider details, applies only present nonempty string values, then assigns usePKCE and useExternalBrowser as Boolean options even when false. The original migration used a single truthy-value loop. Keep these phases separate: copying every option only when truthy would lose false Boolean configuration. The prior provider-default/cloning lesson remains linked; this adds the exact typed-option distinction. No login, invalid-input or mutation test ran.

Scope: OAuth issuer configuration.
