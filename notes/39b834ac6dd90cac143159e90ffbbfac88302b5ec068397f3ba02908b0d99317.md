# Loopback OAuth normalization removes one final slash from the request redirect

After assigning the socket port and serializing its base URL, loopback setup removes one final slash from request.redirectURI. The lexical callbackPrefix stays unchanged for incoming callback reconstruction. The request URI is sent in authorization and saved for token exchange. This is a single-suffix operation, not removal of all repeated slashes or proof of provider acceptance. No native socket, URL-boundary or login test was run.

Scope: OAuth external loopback redirect.
