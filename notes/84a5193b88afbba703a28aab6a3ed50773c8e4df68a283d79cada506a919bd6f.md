# Unread-child and new-message indicators are separate thread states

Entry 784 gives a thread with unread children a green dot and reserves the star for new messages. Current card CSS nests hasNew inside hasUnread and explicitly says hasNew should not affect styling otherwise. Collapsed threads have a contrast override. Summary unread rows also use the dot, while starred-message status retains its separate star selector. Manual CSS state proposal in this family: preserve the distinction between unread, new and starred and scope selectors to the full required state. The inspected row code also maintains localized expand/collapse names and aria-expanded on the real twisty button. The decorative glyph and contrast override do not prove that every unread-child state is announced to a screen reader.

Scope: thread-state-indicators.
