# The legacy Newsgroup XUL wizard uses a CSP processing instruction

AccountWizard.xhtml is a top-level XUL window used only for Newsgroups. Its policy must be declared through the csp processing instruction before the window, rather than an HTML meta child. The fixed document retains chrome resource sources and unsafe-inline for its legacy handlers/styles. This narrowly scoped compatibility repair does not endorse unsafe-inline for new HTML documents. The reporter reports patched debug verification; no new debug, security or native UI test ran.

Scope: Newsgroup wizard CSP.
