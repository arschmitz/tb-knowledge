# An IMAP subscription URL keeps its temporary folder through a registered listener capture

The URL's folder/message sinks are weak references, while subscribe cleanup can release temporary folders. SubscribeToFolder now captures a RefPtr folder in a no-op UrlListener and supplies that listener for subscribe and unsubscribe. URL creation registers it in the URL's strong listener array, which is cleared after stop notification. The capture therefore supplies ownership through the active URL notification boundary; it does not assert operation success or indefinite ownership after a finished URL remains referenced. The new test checks parent/child discovery but does not explicitly invoke subscribe cleanup or test unsubscribe. No native lifetime or IMAP test ran.

Scope: IMAP subscription folder lifetime.
