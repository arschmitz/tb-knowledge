# Graph continuation requests carry the full returned URI

Initial folder-delta operations build a URI from an endpoint and a path. Returned next-page and delta links instead become complete request URIs. NextPage parses @odata.nextLink during deserialization; GetDelta parses the supplied token, and both build requests from that URI directly. Matching the token to the correct operation path remains a caller contract. Current folder synchronization explicitly fetches NextLink responses and stores the terminal DeltaLink; that loop is separate from parsing and request construction. URI parsing does not itself prove origin or token-path validation, and no live synchronization was run.

Scope: Graph generated requests and pagination.
