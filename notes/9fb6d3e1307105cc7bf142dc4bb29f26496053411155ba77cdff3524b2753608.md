# The displayed-message listener reacts to the loss of Offline state

Entry 1286 installs its database listener before starting the load and reloads when the displayed message loses its Offline flag. The accepted FolderDBListener first checks that the changed header is gMessage, then detects the true-to-false flag transition. This joins store invalidation to a new download for the current message; it is not a reload on every header change. The source and browser test were read, but no live reload, focus or network test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message display offline-copy reload.
