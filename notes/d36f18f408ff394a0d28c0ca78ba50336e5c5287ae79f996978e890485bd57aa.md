# The compose lifetime regression test observes progress completion after a manual copy callback

The regression test substitutes a send object that captures the listener and resolves immediately. After awaiting that promise and an event turn, it drops its compose variable, forces collection, then manually calls onStopCopy(NS_OK). The direct final assertion checks the successful progress STATE_STOP status. The test does not inspect a rendered dialog or prove the compose object was collected, and it does not cover all error/cancellation branches. Both new assertions have nonempty expected-behavior messages. This is static coverage analysis; the test was not run.

Scope: Compose send-listener xpcshell test coverage.
