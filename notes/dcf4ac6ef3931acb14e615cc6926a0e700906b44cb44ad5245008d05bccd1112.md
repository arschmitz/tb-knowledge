# Edit Delete menu semantics follow focus, selected object and deletion model

The split delete test covers local roots, NNTP roots/newsgroups, folders, messages and text input. A selected message does not force a message action when the Quick Filter textbox has focus. The IMAP delete-model test also expects Delete to become Undelete when the message is marked deleted. These are command-context contracts; infer neither the label nor the action solely from thread selection. This is source and test inspection only.
