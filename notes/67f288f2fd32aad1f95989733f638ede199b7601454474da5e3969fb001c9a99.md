# The EWS script test initializes its cleanup callback after the awaited message open

The test's message listener can call cleanUp, but the const binding is initialized only after messageDisplay.open resolves. The open API waits for MsgLoaded; message-display script work starts from MsgLoading and has a separate async execution path. If the loaded notification callback runs before that binding is initialized, the callback reads an uninitialized binding. This is a conditional static ordering concern. Transport scheduling was not established, and no race or test failure was reproduced.

Scope: EWS extension browser-test ordering.
