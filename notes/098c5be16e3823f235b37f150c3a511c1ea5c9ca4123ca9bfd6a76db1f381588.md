# Distinguish a stored folder name from its physical filename and display label

The historical collector used cached folderName and an aliasFiles map so a hashed filename could be found through its folder name. That collector is retired. Current folder-discovery fixtures still distinguish the stored Unsent Messages name from presentation such as Outbox. Do not turn the historical Outbox database-name assertion into a current invariant, or assume a visible label can locate a file. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Folder identity representations.
