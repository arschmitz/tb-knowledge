# Clearing an Account Hub notification removes its Fluent title arguments

clearNotifications removes both the title localization ID and its argument data, then clears its text. showNotification clears prior state before applying the next notification. The focused browser test checks the full {id,args} state before and after clearing, including null arguments; checking only visibility or text would not prove stale argument metadata is gone. No translated output or live accessibility result is claimed.

Scope: Account Hub notification lifecycle.
