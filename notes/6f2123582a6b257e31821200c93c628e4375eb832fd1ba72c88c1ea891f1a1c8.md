# Attachment current focus and selection need separate visual states

The attachment list uses one richlistbox with option rows. Its current row can differ from the selected rows. Shared attachment CSS gives selected rows a background and gives the current row an outline when the multi-select list has focus. Keep those states separate when changing theme colors. A background alone does not show the keyboard current row independently of selection. The widget keeps list focus on primary-button mousedown, uses plain Space to select the current item and emit quicklook, and uses plain Enter to open an attachment. The reading-pane toggle test checks focus returns to the message pane when the list collapses. Static source supports these contracts; forced colors, computed accessibility state, and screen-reader behavior still need runtime checks.

Scope: accessibility/attachment-list.
