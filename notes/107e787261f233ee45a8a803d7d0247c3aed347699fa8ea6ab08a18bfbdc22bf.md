# Release notification prefixes are formatted and encoded for the tb-release command

The release-notify-started config selects prefix-message by project. release_started.add_notifications resolves that value, formats config and release_config placeholders, UTF8/base64 encodes the result, then supplies it to tb-release as --prefix-message. Check both the selected YAML value and this command producer when changing channel text. The fixed file uses explicit beta/release/esr and try branches with a default fallback. This is static configuration behavior; it does not prove taskgraph validation, email rendering or delivery passed.

Scope: Taskcluster release notifications.
