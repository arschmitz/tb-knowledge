# Arm MsgLoaded waits before changing the reader preference or theme

1127 moves the message-load promise before setting mail.dark-reader.enabled and before enabling the dark theme. The original test subscribed only after the action could have triggered loading. Current tests retain the wait-before-action ordering and use pushPrefEnv for preference restoration. This applies the existing event-order lesson to the exact dark-reader regression; it does not prove that this race was the sole reason for the earlier backout.

Scope: Dark-reader preference and theme event wait ordering.
