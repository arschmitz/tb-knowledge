# Reset tag-mode UI before repopulating a cleared filter

When tag state is not an object, reflectInDOM hides the tag container, removes none-mode-selected and resets the dropdown to index zero. That option is OR/Any of. When a new tag object has no stored mode, _populateTagBar takes the dropdown value, keeping the displayed choice aligned with the new state. A mode event with no filter value returns before mutation/search. Direct test source checks off/on reset to OR and tagged results; no live search or full-bar close/reopen run was performed.

Scope: Quick Filter Bar tag state.
