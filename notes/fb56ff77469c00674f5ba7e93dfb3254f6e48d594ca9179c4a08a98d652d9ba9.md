# Build package desktop files from the task graph localization artifact

Flatpak and Snap depend on shippable-l10n-pre and fetch strings_all.tar.zst. Their repack scripts activate the prepared Python environment, run fetch-content and point the desktop builder at the extracted l10n-central directory. The landing removes the older direct archive download with a fixed localization revision. The Docker recipes provide the virtual environment and zstandard dependency. Keep the artifact producer, fetch declarations and builder inputs connected. No Taskcluster graph or package was built. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: taskcluster/packaging/localization-inputs.
