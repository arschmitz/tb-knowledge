# Standalone shortcut routing keeps Search in its window while Spaces uses the recent three-pane window

The keydown handler resolves the recent mail:3pane window for each event and reads that window’s tabmail. Spaces commands use that recent window; search-messages keeps calling the current window’s searchAllMessages. The separate numbered-tab focusOnMail command also reads tabmail from the same topWindow that it focuses. The new standalone test arms a matching SearchDialog window watcher before synthesizing F with platform modifiers. Its final assertion reports completion; it does not directly verify Spaces focus or every window/folder fallback. The later accepted event.repeat guard is a separate phase. These are scoped source contracts, not a native shortcut or focus result.

Scope: mail/base/content.
