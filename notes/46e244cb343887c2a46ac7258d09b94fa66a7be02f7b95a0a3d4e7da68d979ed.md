# The first internal-key-token port retained an early unchecked native login

The first landing creates nsIPKCS11Token directly, returns true if creation fails, and calls Login(false) once with an ignored result before the later checked call. The original IMAP and local-folder callers stop when the helper returns false. The backout and corrected reland are separate phases; the fixed accepted helper later uses NSS slot APIs. These are source branches and ordering, not a reproduced failure.

Scope: Thunderbird local-folder primary-password gate.
