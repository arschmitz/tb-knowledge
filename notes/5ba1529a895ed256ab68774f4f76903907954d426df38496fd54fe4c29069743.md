# The username hint is a default help value, not a switch that disables change feedback

The username widgets now declare a static help message. Their actual input component stores that ID and restores it when custom help is cleared. Removing the per-field config-change ID does not disable the original change-help helper: it falls back to a default ID when the attribute is absent. The accepted later helper also manages the change-comment class explicitly. These are separate static-help, temporary-feedback and error-description contracts; no UI, localization or accessibility run was made.

Scope: Manual username attributes, fallback change-help receiver and AccountHubInput defaults.
