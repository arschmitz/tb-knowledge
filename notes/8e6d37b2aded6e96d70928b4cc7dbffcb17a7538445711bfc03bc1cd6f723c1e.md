# The first Graph next-page API represents another request without fetching it

At the pagination landing, Paginated::next_page parses an optional @odata.nextLink String and returns None for either no link or a URI parse failure. NextPage builds a GET from that stored URI; it does not send or combine pages. The historical client separately rebuilds its configured endpoint from request path/query, and the inspected production change is the connectivity request rather than a page-fetch loop. Present/absent-link unit tests do not establish that transport preserves the full next URL. Fixed accepted code later moves URI parsing into NextPage deserialization. Keep these API, transport and later-phase contracts separate.

Scope: Graph pagination API boundary.
