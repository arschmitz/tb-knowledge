# Thunderbird Rust version metadata comes from the generated workspace owner

At the fixed accepted comm revision, mach tb-rust sync calls run_tb_cargo_sync. That function regenerates manifests before copying the upstream lock. CargoFile reads the upstream workspace.package.rust-version; regen_toml_files passes that value into the Thunderbird package and workspace.package template. gkrust inherits it through rust-version.workspace. The historical patch emitted Rust 1.82.0 and edition 2021; current generated comm metadata is Rust 1.90.0 and edition 2024. The generated-file header identifies Python as the owner, so a metadata change must account for regeneration. This source establishes the propagation contract, not successful compiler, Cargo or continuous-integration execution. The upstream workspace value and engine Cargo implementation remain outside this paired-source audit.

Scope: build/rust.
