# Explain buffer invariants next to the unsafe stream call

The stream reader's SAFETY comment states buffer contiguity, char compatibility and that the returned length cannot exceed the available capacity. The accepted source uses read_ptr.cast::<c_char>() and raw mutable output pointers, then converts the returned length before slicing. Keep these concrete boundary invariants beside unsafe FFI calls instead of an empty safety assertion. The current cast spelling is a source-supported local example, not a repository-wide casting ban or a memory-safety test result.

Scope: Rust XPCOM stream safety comment.
