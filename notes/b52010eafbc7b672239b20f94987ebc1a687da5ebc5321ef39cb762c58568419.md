# The IMAP copy refresh tests check final counts without exercising front-end file drops

The copy/move test replaces count polling with updateFolderWithListener promises, then checks two messages in each destination and zero in the local source. The first update still has a 1000 ms delay with a lint exception, and the final count/null assertions have no messages. The attachment test replaces polling with a direct one-message assertion after detachAttachments, then checks the detached file and marker. The original uses UID 2; the fixed test later enumerates the remaining header. These tests exercise their own IMAP operations and do not directly test the new MailUtils wrappers or drop-event ordering. The delay is an observed local test technique, not a preferred waiting rule.

Scope: IMAP file-copy and attachment unit tests.
