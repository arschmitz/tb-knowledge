# The CMS classifier now adopts its allocated MIME parent address

mime_part_address returns allocated data from strdup or PR_MALLOC and releases only its recursive temporary. The original new classifier stores its parent address in a raw const char pointer without a visible release in that branch. Accepted code instead adopts the result into nsAutoCString. Preserve that local ownership change separately from the original classifier behavior; this is static allocation/lifetime evidence, not a measured leak or a general string-wrapper rule.

Scope: mime-part-address-ownership.
