# Graph supported-name files use a manifest-relative filtered set with fatal lazy initialization

The landing replaces fixed arrays with LazyLock<HashSet<String>> values populated from files relative to CARGO_MANIFEST_DIR. The parser trims each line, ignores blanks and leading-# comments, deduplicates strings and returns InvalidData if no values remain. The static initializers call expect, so this list-loading failure is not a normal main Result propagation path. The owned ten path memberships and fourteen unique type memberships are preserved; consumers query set membership and selected module/import/variant builders sort their own output. At the accepted endpoint the parser remains but object/enum lists replace the original type list. No generator or failure path was executed.

Scope: Microsoft Graph extraction supported-list loading.
