# Debian repack kind changes keep main and localized upload mappings separate

The release-deb-repackage directory rename is paired with tasktype/from and beetmover dependency changes to repackage-deb. Main target.deb inherits all_locales false and explicitly avoids Balrog-manifest updates; localized langpack.deb still requests all locales through repackage-deb-l10n. Nightly main destinations are distinct from localized ones. These are inspected manifest contracts, not a generated graph or completed upload. No packaging or service operation ran.

Scope: Taskcluster Debian repack and beetmover manifests.
