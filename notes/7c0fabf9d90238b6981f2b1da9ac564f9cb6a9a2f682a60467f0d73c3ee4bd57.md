# Expose dynamically constructed Fluent ID families in comments

The duration helper constructs event-duration-label-${aUnit} and lists the concrete minute, hour, day, and week IDs immediately above it. The agenda helper lists its count-week and count-day IDs as well. Keep those concrete comments when using these dynamic ID families so manual review and source search can connect the caller to the actual messages. This is a local manual style pattern; no global extraction requirement was established.

Scope: calendar/base/content.
