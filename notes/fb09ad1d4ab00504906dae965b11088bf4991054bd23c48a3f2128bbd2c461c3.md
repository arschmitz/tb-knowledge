# A successful nonlocal copy needs usable local message storage

The nonlocal-copy test waits for the copy listener, then checks both destination headers, nonempty storeToken attributes and openable input streams. A count alone would miss a destination header whose local file was never finished. The shared manifest runs the scenario for Maildir and mbox; this test uses copy, not move. Stream opening executes a storage path but does not compare message bytes, and the test does not assert source deletion. All scoped assertions lack expected-behavior messages; add nonempty messages containing should when repairing the test. This is source inspection only; no copy or regression test ran.

Scope: IMAP to local-store copy regression tests.
