# Create the Docker virtual environment with the explicit system Python

Entry 2078 changes only venv creation in make_venv.sh to /usr/bin/python3 -m venv --system-site-packages. After activation the script still uses python3 -m pip, which selects the activated environment. Keep those two interpreter roles distinct when changing image setup; a hardcoded interpreter for creation does not mean hardcoding the later pip command. Fixed accepted script retains the sequence and its VENV_DIR/VENV_NAME defaults. The diff and commit do not establish why a particular prior interpreter failed. No Docker image, virtual environment or dependency installation ran.

Scope: Taskcluster Docker virtual environment recipe.
