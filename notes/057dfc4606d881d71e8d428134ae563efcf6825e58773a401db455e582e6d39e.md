# Privileged PNG icon calls distinguish output options from the randomization key

The badge and extension window-icon calls pass an empty string for outputOptions and null for randomizationKey, with short inline labels. This follow-up replaces the badge first landing with two empty strings and also updates the extension caller. The two accepted callers support these exact argument roles, not a global null default or argument-comment rule. The unpaired upstream encoder body was not read, so this records caller adoption without an ABI, privacy, randomization or image-equivalence guarantee. No live Windows test ran.

Scope: windows-png-icon-callers.
