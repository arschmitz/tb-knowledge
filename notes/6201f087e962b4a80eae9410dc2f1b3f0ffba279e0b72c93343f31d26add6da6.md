# Give a MIME output type a named initial state

nsStreamConverter initializes mOutputType to nsMimeUnknown before Init seeds a local newType and optionally calls DetermineOutputFormat. Recommend the named enum state in this converter instead of leaving a scalar uninitialized or inventing a numeric default. The known-output override and downstream output behavior were read statically; no conversion was executed. This is source and test-code inspection.
