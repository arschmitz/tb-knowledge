# Removing forced message encoding is tested with one short ASCII draft

The extension wrapper stops forcing message encoding, leaving the fresh compose-fields default false. Its new draft test checks one short ASCII body: one saved message, a 7bit transfer-encoding header, no base64 header and readable raw body. The actual encoder still encodes for other content conditions such as long lines or null bytes, so removing the override is not a guarantee that all plain text stays 7bit. These are source and fixture assertions; no MIME, crypto or runtime test ran.

Scope: Extension message save encoding.
