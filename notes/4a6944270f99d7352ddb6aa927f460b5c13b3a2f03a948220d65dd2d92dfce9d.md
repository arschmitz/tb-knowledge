# Correct the Panorama startup return comment without restoring the old Promise contract

The accepted core IDL still says startup returns a Promise, but declares void startup and the native startup now returns synchronous nsresult. The existing shared startup-thread lesson records this design change. Recommend correcting the stale IDL comment, keeping actual Promise-returning migration methods distinct. This is a scoped documentation proposal, not evidence that callers must await startup. These observations are scoped to the cited accepted source and historical changes.
