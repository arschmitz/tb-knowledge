# Validate loaded servers after initialization but allow new-server setup

Current shared outgoing initialization sets a unique key and password-module key. newServer=true skips required-property validation until setup can supply fields; loading an existing server requires username/auth method/endpoint. Key and endpoint OnceCells protect one-time setup; this is not generic permission to swallow repeated initialization. Historical Part 7 predates this newServer distinction.

Scope: rust/protocol_shared/src.
