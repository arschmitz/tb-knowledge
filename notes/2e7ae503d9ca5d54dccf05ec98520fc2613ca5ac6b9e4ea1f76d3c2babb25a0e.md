# The first attachment URL port shadows its result and bypasses raw-input cleanup

In the owned normal-part branch, ProcessBodyAsAttachment introduces an inner nsresult rv while a separate outer rv is later tested. Successful inner construction leaves that outer value unassigned. Its new error returns also occur before the later input/data cleanup. GenerateAttachmentData retains a raw urlSpec allocation but removes its final free; the fixed accepted code frees it after NS_NewURI and uses a helper result assigned to the outer rv. These exact original/current source differences do not establish a runtime crash, leak count or the cause of the historical macOS test failure.

Scope: MIME attachment URI error paths.
