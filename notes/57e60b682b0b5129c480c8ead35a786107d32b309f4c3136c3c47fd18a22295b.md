# The summary description await has a narrower blank-document guard

updateItemDetails awaits description rendering, and the changed dialog/import callers await that method before their later setup. Inside updateDescription, the progress listener ignores about:blank stops, but it is installed only when the initial document is not complete. An already-complete blank document does not enter that wait. The listener settles on a nonblank STATE_STOP without an added target-URL or successful-status assertion. Preserve those limits instead of treating the method promise as proof that every loading case is covered. No blank-document failure or rendering result was reproduced.

Scope: Calendar summary readiness limit.
