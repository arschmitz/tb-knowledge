# Add image schemes to the image CSP directive

The compose fix adds img-src chrome: moz-icon:, leaving the default and other directive roles separate. Those image schemes remain in accepted messengercompose.xhtml even though script sources have evolved. When an icon needs a new scheme in this window, change the image directive explicitly; this pattern does not justify weakening every resource directive. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
