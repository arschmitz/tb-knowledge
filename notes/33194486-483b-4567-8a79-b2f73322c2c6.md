# Theme color migrations must include token consumers and default state

Before changing a theme custom property from a resolved color to light-dark(), inspect JS getPropertyValue consumers and input values. Test selecting, resetting, saving, reopening, and canceling in both themes. In2024 folderColors conversion was removed after reset stored black rather than removing override. Newer2025 accepted code restores light-dark and tracks isDefaultColor explicitly; current save uses that flag to clear stored override. Preserve semantic default state instead of relying only on color-string equality. This is a consumer contract rule, not a ban on light-dark. CSS parse test success alone cannot cover it.
