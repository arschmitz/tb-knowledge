# Publish destination new-mail counts at the POP3 batch boundary

EndMsgDownload applies the accumulated counts per destination URI, skips folders that no longer exist, and avoids setting new-mail state on Junk. It adds to existing destination new counts and sets HasNewMessages and BiffState_NewMail when the total is positive, then clears and releases the map. IMAP/coalesced moves use a different route. Current EndMsgDownload returns NS_OK, unlike the historical shared rv; do not infer its final return from the old diff.

Scope: mailnews/local/src.
