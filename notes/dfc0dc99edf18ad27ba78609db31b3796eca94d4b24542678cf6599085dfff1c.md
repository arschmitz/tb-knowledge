# The srcdoc test adaptation expects a blank frame and changes which harness branches run

This landing replaces a srcdoc load/image check with a delayed about:blank check and sets shouldBeBlocked to false. The actual message consumer then expects that predicate to succeed, and the main loop skips its blocked-context branch while continuing later allowed-context checks. The flag does not establish that content was allowed, and the source does not prove the upstream parent-process behavior. The old image-specific case name remains despite a reviewer’s narrower document-level wording proposal. No test ran; the explicit local timeout exception is not a general waiting convention.

Scope: Message content-policy browser test.
