# Gloda folder queue acceptance and a false activity flag do not prove successful indexing

indexFolder returns true after queuing an eligible folder and exposes an optional callback with success versus abort. The indexing getter reflects desired unsuppressed work, and its comment permits false while work still quiesces. The inspected search test asserts fixture count and queue acceptance, then waits for indexing false; its unconditional Assert.report(false,...) is a passing progress report, not a checked all-messages-indexed result. Later search match and tab assertions are distinct UI oracles. Preserve these completion limits when interpreting this timeout repair; no indexer, browser or intermittent scenario was run.

Scope: global search test indexing synchronization.
