# Match flag API verbs to the state they change

The current IDL uses markRead(key, read, instigator), markMarked(key, marked, instigator), markKilled(key, killed, instigator) and separate isRead/isMarked predicates. The historical native hdrMsgId variable became msgKey. Recommend maintaining those local state and identifier names when extending this interface; legacy bRead native parameters still exist, so this evidence does not establish a project-wide ban on Boolean prefixes. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/db/msgdb.
