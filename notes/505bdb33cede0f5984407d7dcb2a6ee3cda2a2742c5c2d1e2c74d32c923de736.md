# Transfer an owned C++ out-parameter once along each branch

FetchMessage calls GetMessageFromUrl without first transferring a reference into aURL. The docshell branch transfers url; the stream branch transfers mailnewsUrl; the fallback delegates the transfer to GetImapConnectionAndLoadUrl. The old early forget filled the same owned out-parameter again and leaked its previous reference. The review suggestion to add another fallback forget was rejected because the helper already owns that transfer. Trace the called helper before adding forget/getter_AddRefs calls, and check success branches separately. No leak detector or C++ runtime test was run.

Scope: IMAP ownership.
