# forgetSavedSelection clears durable view state rather than selecting a row

The rename from forgetSelection to forgetSavedSelection makes the target explicit: it deletes a key from _savedSelections. Omitted selectionKey uses _getSavedSelectionKey, which returns the folder URI for folder views and the special synthetic key for a synthetic view. It does not clear the current visible selection. Message navigation and the extension folder-switch path pass the destination URI before switching when they plan to set a new selection. Preserve that distinction and the destination-before-switch ordering when calling or renaming this helper. Static source and test inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending-single-browser-reader.

Scope: Thread tree saved-selection naming and caller contract.
