# Check allocation arithmetic at the allocator's width

In MIME and send-later buffer growth, validate size multiplication with CheckedInt before allocation. A 64-bit product truncated to the allocator's uint32_t size can leave a smaller buffer than the recorded capacity and cause an overrun.

Scope: mime.
