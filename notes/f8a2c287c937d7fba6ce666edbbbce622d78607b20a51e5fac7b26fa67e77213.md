# Test the same address group through the parser and public wrapper

The group follow-up adds internal fixtures for a mailbox before a colon, a quoted display name and whitespace/comment normalization, plus public nsIMsgHeaderParser extraction assertions. Keep both representations checked: the internal result can contain a named group while the public extraction returns the actual member mailbox. A wrapper-only assertion can miss the group structure; a parser-only assertion can miss the user-facing extraction. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Address header test layers.
