# The generic IMAP argument trait tests a pointer type before selecting pointer storage

The first patch gives two explicit XPCOM pointer argument types nsCOMPtr storage. The generic replacement computes is_base_of<nsISupports,T> before matching RefType<T*,true>. The actual CloseMockChannel alias supplies a pointer type as T, so the Boolean default is false and the primary T& storage remains. This persists in the inspected fixed revision. The comment and approval do not establish owning storage; a compiler/native lifetime/crash test was not run, and later spurious-wakeup work is separate.

Scope: IMAP synchronous proxy argument storage.
