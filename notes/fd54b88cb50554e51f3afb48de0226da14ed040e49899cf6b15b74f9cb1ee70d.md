# Exchange settings strip only the root Microsoft Graph v1.0 path during capture

The getter normalizes only /v1.0 or /v1.0/ on the exact https://graph.microsoft.com origin to the root pathname. captureState copies the configuration and stores the normalized URL; setState still restores the saved versioned textbox value. The changed test directly distinguishes restored display from normalized capture. Other paths/origins, live endpoint discovery and authentication are outside that proof. No test ran.

Scope: Account Hub Exchange URL normalization.
