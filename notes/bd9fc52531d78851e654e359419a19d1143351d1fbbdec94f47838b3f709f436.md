# Original EWS manual tests separate form visibility from advanced account creation

The original EWS manual task checks hidden protocol/security/port fields, visible EWS URL/label and discovered field values, then stops at the password step. A separate advanced task confirms account creation and waits for an account by identity email. The ordinary manual task checks the opposite field visibility.
