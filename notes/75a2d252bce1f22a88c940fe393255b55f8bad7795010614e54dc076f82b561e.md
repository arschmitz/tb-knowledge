# Shared search widgets and the saved-search dialog have distinct current localization getters

The historical saved-search document loads both searchWidgets.js and virtualFolderProperties.js as classic deferred scripts. Both define a property named l10n on this. Wrapping the widget declarations in a block does not rename that object property. The original dialog formatter includes both Fluent resources, while the fixed source separates searchWidgetsL10n from the dialog l10n getter and gives them different resource lists. This is an observed shared-window ownership boundary. The author could not recall the precise failure during review, so the source comparison does not establish which getter caused a reproduced failure or a general global-name policy.

Scope: shared classic-script localization ownership.
