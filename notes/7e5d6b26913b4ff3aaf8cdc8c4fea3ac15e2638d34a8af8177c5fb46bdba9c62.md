# Remove obsolete CSS-parser allowlist gates when the platform preference disappears

Entry 803 removes forced-colors and forced-color-adjust allowlist branches whose upstream features are always enabled. The accepted parser test still has narrow feature gates for other features and requires all supplied error criteria to match. Do not preserve a getBoolPref gate for a removed platform preference. This change concerns the parser test allowance, not a visual forced-colors certification.

Scope: mail/test/static.
