# Calendar's first log-removal part also changes duration and missing-label fallbacks

The task-postpone falsy-duration branch now throws instead of logging and returning. Its checked factory returns a new duration object on normal completion, so the branch rewrite alone does not establish a reachable new invalid-string failure. Separately, missing counterproposal labels now return null instead of implicit undefined. The checked display caller uses label && value, preserving its skip behavior for either missing value. These are exact local return/control-flow changes, not a runtime regression claim.

Scope: Calendar task and counterproposal fallback contracts.
