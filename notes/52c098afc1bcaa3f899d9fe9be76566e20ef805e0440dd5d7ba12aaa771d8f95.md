# Delete the image closure on URL allocation failure and retain string cleanup

mime_image_begin allocates MimeImageDisplayStreamData with new. If duplicating its URL fails, it now deletes the object before returning. The normal image end path frees the URL string with PR_FREEIF and deletes the object. Match the object and string allocation families rather than replacing all deallocators uniformly. The selected class and both exit paths were read, without fault injection or sanitizer execution. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
