# Target the AppMenu control image without changing nested button icons

The density and font-size containers each own a direct image and also contain toolbarbuttons. Their icon selectors use > .toolbarbutton-icon, so the container image receives the menu icon without applying that content to descendant controls. This is a specific markup/selector boundary, not a general CSS image API rule. The accepted review has no substantive inline rationale, and the suspected upstream regression remains unproved. No visual, keyboard or accessibility runtime test ran.

Scope: AppMenu control icon scope.
