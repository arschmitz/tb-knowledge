# The Rust connection-notification helper propagates observer failures

report_connection_success returns Result<(), nsresult>. Observer-service lookup and URI acquisition use ? before the unsafe call; NotifyObservers is converted with to_result. The current HTTP consumer also propagates that result after a successful HTTP-status check. Preserve this error path when changing the UI notification. The helper does not prove the later protocol operation succeeded. Current internal_uri and shared HTTP placement are later changes, separate from the original EWS client insertion. No Rust build or request ran.

Scope: Fallible Rust XPCOM observer call and unsafe scope.
