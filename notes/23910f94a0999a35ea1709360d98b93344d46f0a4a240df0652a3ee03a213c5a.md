# A copied component header must describe the component that owns the template

The accepted email-added-success source still says it is the AutoForm template, while it loads accountHubEmailAddedSuccessTemplate and handles created-account settings actions. This is a scoped documentation mismatch from a copied component header, not a reviewer-approved rule. Recommend checking the owning class/template and state meaning when copying a widget comment; a syntactically valid header can still describe another component. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Account success component comment accuracy.
