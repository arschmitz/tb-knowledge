# The subscription setter writes the preference before updating cached host state

SetUsingSubscription first calls SetBoolValue and returns on failure, then updates the available host session. It starts rediscovery only when the old effective read succeeded, the value changed, and both host service and server key exist. Source adopts the review's ordering request despite a Not Done label. The hadPref variable is getter success, not proof of a user-set preference. Required older primary context remains unread, so this source contribution has zero full-audit credit.

Scope: IMAP subscription preference ordering.
