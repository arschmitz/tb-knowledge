# The long-subject header groups its date above the security controls

The message header places dateLabelSubject above a buttonsBox row inside expandedButtonsBox beside the subject. The new column uses space-between, and the lower row aligns the security and dark-mode controls at its end. The button keeps its ID, native semantics, tooltip and inner label/icons; existing click and date-update consumers still use stable IDs. The owned patch resets min-width, while the fixed accepted CSS later expresses that reset as min-inline-size. Keep this surrounding layout change separate from the older nowrap/flex contract inside the crypto button. The unchanged security tests check text and icon states, not long-subject geometry. Screenshot pixels, responsive layout and accessibility behavior were not inspected at runtime.

Scope: mail/message-header/layout.
