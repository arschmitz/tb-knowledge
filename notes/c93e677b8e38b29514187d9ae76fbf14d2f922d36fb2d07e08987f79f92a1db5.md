# The BITS update preference follows the build feature flag

Entry 1200 enables app.update.BITS.enabled under MOZ_BITS_DOWNLOAD rather than using the operating-system macro alone. The accepted preference keeps that feature guard and documents fallback to the internal downloader. For this configuration boundary, gate the preference on the feature that provides it. This is a scoped source recommendation; the downloader implementation, fallback execution and Windows update behavior were not tested, and the upstream discussion remains pending.

Scope: Update download configuration.
