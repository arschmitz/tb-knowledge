# POP3 move and mbox validation read preferences when their branches run

The patch removes first-read static caches. The actual-delete move branch reads mail.pop3.deleteFromServerOnMove directly; the two Trash-marking branches read its inverse. Mbox summary validation reads mail.db_timestamp_leeway after metadata checks, then uses equality for zero or a bounded timestamp difference. The declared allowance is 4000; the former explicit 60 initializer does not establish the upstream API fallback. The removed getter still has a header declaration, with no remaining caller found. No preference-change, POP3 move or summary validation ran.

Scope: MailNews local folder preference lifetime.
