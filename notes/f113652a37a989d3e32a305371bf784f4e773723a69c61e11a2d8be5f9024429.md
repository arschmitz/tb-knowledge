# The large-attachment notification uses a new Fluent message value in both update and creation paths

The patch replaces the old .label-attribute message with the value message big-file-notification-text. Both document.l10n.setAttributes on an existing notification and appendNotification's label object use that same ID and count. The migration recipe requests copying the old label pattern into the new value, and its accepted archived script is byte-identical. This records the exact comm message shape and consumers, not a universal notification API rule or an executed migration/rendering result.

Scope: Compose FileLink notification localization.
