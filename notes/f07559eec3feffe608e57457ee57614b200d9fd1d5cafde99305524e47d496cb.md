# Graph CheckConnectivity returns a URI before detached verification completes

The initial bridge returns a SafeUri after detaching check_connectivity work. The client later reports its request outcome through OnStopRunningUrl; getting a URI back does not establish authentication or HTTP success. The original bridge and client each construct a URI. Fixed accepted code instead passes a clone of the bridge URI into the later operation handler and guards access to an uninitialized client. Those later identity and guard details must not be projected onto the first landing.

Scope: Graph bridge callback completion.
