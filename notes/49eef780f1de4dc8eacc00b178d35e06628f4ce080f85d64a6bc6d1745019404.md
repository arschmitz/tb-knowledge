# Check Unicode folder operations across files, summaries and child directories

The accepted Greek-name tests assert the folder name, file leaf, .msf summary and .sbd child location after create, rename and copy. Preserve this operation matrix when changing folder encoding; a passing in-memory name assertion alone would not establish on-disk naming. The source describes local copy as synchronous and does not use a completion listener for it. These observations are scoped to the cited accepted source and historical changes.
