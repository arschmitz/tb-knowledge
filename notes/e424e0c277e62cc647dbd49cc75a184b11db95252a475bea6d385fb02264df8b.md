# SMTP cancellation keeps an early status until the outgoing request exists

MessageSend retains the outgoing listener before onSendStart provides a cancelable request. The listener stores early cancellation and applies it at start. SmtpServer guards cancellation and terminal notification, releases a drain wait and ignores later callbacks after cancellation. Components.Exception carries the send result into comm native rejection handling, allowing the UI and native alert path to recognize NS_ERROR_ABORT. These static contracts do not prove every error path settles, nor establish EWS or Gecko helper behavior.

Scope: Thunderbird compose SMTP cancellation lifecycle.
