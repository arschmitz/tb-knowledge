# UI font size clamps the effective value

At revision fcc7266f76f1db04196baede3c02650665ed35df, UIFontSize.size selects the stored preference or, when it is zero, the OS value, then clamps the effective size to 9–30 to prevent unusable UI. This getter does not rewrite an out-of-range preference: the browser test sets mail.uifontsize to 7 and expects prefValue to remain 7. When reading or changing this component, distinguish the stored value from the effective size. These are static source and test-code observations; the evidence does not show a test run or establish limits for other font controls.

Scope: UI font size.
