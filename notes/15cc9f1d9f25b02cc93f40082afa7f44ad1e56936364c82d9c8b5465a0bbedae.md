# Explain intentional Taskgraph imports with a specific lint exception

comm_taskgraph.register imports dependencies to trigger group_by registration and taskgraph_attributes to patch Gecko Taskgraph. The latter module calls its patch functions at import time. These are behavior-owning imports, even when the imported local name is unused. In this registration module, retain an explanatory F401 exception instead of deleting the import as dead code or suppressing all lint. The earlier import-order-only cleanup is excluded as mechanical context. This does not establish every Taskgraph extension or prove a graph was generated. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Taskgraph registration import syntax.
