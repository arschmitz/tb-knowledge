# Use the open modal state as an Account Hub test assertion

The opening browser test awaits openAccountHub, then asserts both the dialog element and dialog.open. Finding a created dialog alone does not show that it has entered the modal open state. The same test registers the close-event waiter before sending Escape and then checks !dialog.open. Preserve those separate assertions in this test family. These synthetic checks are not a screen-reader or visual validation. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Account Hub browser test lifecycle.
