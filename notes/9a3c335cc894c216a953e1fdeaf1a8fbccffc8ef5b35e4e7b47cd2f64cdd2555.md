# Folder prettyPath supplies a display path separately from abbreviated labels

The thread-pane header keeps abbreviatedName as visible text and uses prettyPath for its title. Folder rows also keep the abbreviated and full-name inputs separately. The native prettyPath builds localized ancestor names, omits the server root and treats Gmail grouping parents specially. It is a display path, not a filesystem path or stable identity. Later full-path visibility settings and asynchronous row labels are separate behavior. No tooltip or Gmail UI test ran.

Scope: folder-name-display.
