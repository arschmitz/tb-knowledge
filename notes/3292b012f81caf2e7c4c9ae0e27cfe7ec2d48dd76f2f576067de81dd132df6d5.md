# Calendar slot assignment tests do not validate layout or accessible names

The row test asserts only assignedElements identity. Current production supplies localized Location and Join meeting icons/buttons through slots; the Location icon Fluent entry provides .alt=Location. Proposed focused UI coverage should check actual accessible names and focusable slotted controls as well as identity. Do not infer accessible output from data-l10n-id alone or treat the original fixture image as proof of live production behavior. No screen-reader or keyboard run occurred. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.
