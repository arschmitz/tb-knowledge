# Search table caching does not cache a message-membership boolean

The accepted HdrIsInCache caches a referenced nsIMdbTable but still calls HasOid for each header key. RefreshCache and UpdateHdrInCache mutate the table contents. For this search cache, recommend retaining the mutable table handle rather than memoizing a previous membership result that can become stale after updates. This is a scoped source pattern; no update-versus-search race or membership test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Search membership cache boundary.
