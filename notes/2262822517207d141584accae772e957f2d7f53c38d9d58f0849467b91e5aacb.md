# Replace account-option state without accumulating old buttons

AddressBookAccountSelect builds buttons for the new account state and uses replaceChildren after the loop. It sets the account username as the submitted value, keeps full-name/email text literal and passes count arguments to Fluent. Tests directly check button replacement, disabled state, literal values and localization arguments; they do not prove translated text or performance. The batching request was nonblocking and applied.

Scope: Account Hub account option state.
