# An early array-length failure bypassed the old manual statement reset

The historical synchronous LiveView::SelectMessages returns NS_ERROR_UNEXPECTED when SetArrayLength fails. That return occurs before assigning the result and before the later manual mSelectStmt->Reset. No failure injection or statement lifetime experiment ran. Fixed accepted SelectMessages is an asynchronous Promise/listener implementation, so this old synchronous branch is not a current API recipe. Preserve the failure and cleanup boundary as historical evidence; the newer listener cleanup needs its own source study.

Scope: Panorama query failure boundaries.
