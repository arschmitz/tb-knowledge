# Contact updates refresh the global cache before per-book enumeration

The contact-properties observer replaces the global _contacts node even if the parent's contacts map has not been populated. findContactById checks that global map first, while per-book enumeration can reload directory cards and mask the stale node. The regression test avoids an explicit creation UID and reads contacts.get before contacts.list to preserve that cold per-book state. The fixed accepted source retains the change; no test execution is claimed.

Scope: Thunderbird WebExtension address-book cache.
