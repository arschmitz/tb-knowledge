# The comm Flatpak transform formats worker inputs before it builds the desktop artifact reference

The kind invokes the comm Flatpak transform after release dependencies and before localization packaging. Its format pass resolves keyed environment values before formatting them with release_config, config_params and the current task. Its desktop-file pass inspects only selected repackage dependencies before adding a task-reference URL. The original copy uses older gecko_taskgraph imports and release_level(project); fixed accepted code uses mozilla_taskgraph and release_level(release-branches, params), and adds flatpak_name. Keep historical signatures separate from the checked current input contract. The absent-DESKTOP_FILE_URL assert has no message. No upstream helper body, taskgraph generation, artifact fetch or package execution was validated.

Scope: Flatpak taskgraph input flow.
