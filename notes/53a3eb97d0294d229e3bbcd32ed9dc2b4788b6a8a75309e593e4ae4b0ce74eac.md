# Prefer localized notification content and avoid rendering the same fallback twice

Current Account Hub notification code returns after assigning a Fluent description so raw content is not also shown. If there is no explicit title, it promotes available description/error text into the title and returns rather than duplicating it as a description. The title helper also returns after assigning localization attributes. Preserve these precedence and early-return paths when adding content sources. The existing shared clear/reset lesson already covers stale-state removal and is not duplicated here.

Scope: mail/components/accountcreation.
