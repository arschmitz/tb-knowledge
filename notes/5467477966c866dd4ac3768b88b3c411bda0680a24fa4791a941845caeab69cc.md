# Read virtual cached hits from each physical search database

getMessagesInFolder enumerates wildcard and explicit search folders, then asks each physical folder database for hits keyed by the virtual folder URI. The old implementation read the virtual folder parent database. Preserve both database owner and virtual URI in this extension listing path. Existing native cache-identity knowledge is reused; this source adds the extension consumer and its manual-search fallback. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension virtual-folder cached-hit owner.
