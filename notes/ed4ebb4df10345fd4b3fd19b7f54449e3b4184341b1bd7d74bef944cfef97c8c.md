# WebExtension schema choices retain their positions for generated compatibility history

The schema README says to append new choices and retain existing choices with deprecated or unsupported markers rather than deleting them. It ties stable positions to generated version_added/version_removed history. The inspected MV2 folders.create destination retains older MailFolder and MailAccount choices before the newer MailFolderId. The full patch repairs ordering across compose, folders, messages and spaces. This is documented schema-consumer guidance, not a rule that every JSON array is append-only. The external generator and generated output were not inspected or run, and the full assigned review remains pending.

Scope: WebExtension schema compatibility positions.
