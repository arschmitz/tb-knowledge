# Number-input spinner defaults live in the shared input stylesheet with local size overrides

The landing moves common native spinner appearance, icon variables and dimensions from themeableDialog into input-fields. Platform input wrappers import those defaults. Preferences keeps wider spinner buttons and applies one half-height formula to both halves; number fields and vCard special-date controls use full button height. The main window and preferences explicitly load input-fields. This does not establish the complete cascade of every dialog or identical platform rendering. No UI or native spinner test ran.

Scope: Mail number-input CSS and stylesheet consumers.
