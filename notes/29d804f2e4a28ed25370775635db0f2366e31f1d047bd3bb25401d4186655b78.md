# Statement cache names must identify a fixed SQL query

DatabaseCore caches statements by aName, returning the cached statement without comparing aSQL. Proposed rule for these table methods: use a stable operation name for one SQL shape and a different name when the query changes. Reusing a name across incompatible table statements can return the wrong prepared query. That consequence follows from the cache lookup; no collision was reproduced. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama statement naming.
