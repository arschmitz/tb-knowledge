# Document the actual empty-string result of a missing folder property

During D209933 review, the author found that nsIMsgFolder.getStringProperty returned an empty string when a property did not exist, despite IDL text claiming it threw. The landed IDL corrects that contract, and EwsFolder.UpdateFolder explicitly checks for an empty ewsId before making a network request. The code still tolerates an empty sync state token for initial sync. When calling older XPCOM APIs, verify observable missing-value behavior instead of relying on stale interface comments.

Scope: Mail folder property contract.
