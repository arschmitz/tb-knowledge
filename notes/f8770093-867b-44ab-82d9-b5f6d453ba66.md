# All-day tasks must save date-only values with optional endpoints

A task can have an entry date, due date, both, or neither. The all-day editor must set isDate on each present date when saving and leave duration null when one endpoint is absent. The all-day checkbox and disabled time picker must stay in sync when dates are toggled.
