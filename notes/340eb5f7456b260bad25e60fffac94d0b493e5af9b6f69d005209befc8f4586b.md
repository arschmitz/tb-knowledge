# Generate the RNP minimum version from the same vendored version source

The vendoring action runs thirdroc/rnp.py. Its parser reads and strips the version file, and main replaces the MIN_RNP_VERSION declaration with parsed major, minor and micro fields. RNPLib uses that array for its runtime minimum check and status text. Preserve this update action when changing RNP vendoring; hand-editing the runtime minimum independently can let the vendored library and loader requirement diverge. No vendoring command or library load ran.

Scope: third_party/rnp/moz.yaml.
