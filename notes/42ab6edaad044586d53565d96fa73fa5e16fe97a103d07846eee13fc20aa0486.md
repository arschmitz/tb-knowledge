# Unobtrusive signature buffering keeps initial signature headers separate from canonical payload

The top-level mixed parser captures consecutive initial Sig headers separately, buffers the first part with normalized CRLF and delays trailing empty body lines. EOF requires one child and uses the first captured signature. The original required a space after Sig:, while accepted code later recognizes Sig: without that space. Keep those phases and the remaining draft-detection/output TODOs explicit; the source does not establish full draft compliance.

Scope: MIME unobtrusive-signature state machine.
