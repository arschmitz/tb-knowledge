# Search-bar reset sends one empty autocomplete only when the value changes

The accepted reset contract clears a nonempty input, cancels its timer and sends an empty autocomplete event; resetting an already empty input sends nothing. Browser tests cover both and watch long enough to catch an unwanted delayed duplicate. Current reset still has the early return. When changing clear, Escape or reset paths, assert the empty event and the absence of a second event.
