# Threaded-header reconstruction keeps selection and notification cleanup scoped

OnNewHeader rebuilds an affected visible thread through collapse, base row removal, sorted root insertion and expansion. It saves selection by message key and uses a scope-exit guard to restore it. Notification suppression is released only if this invocation enabled it, preserving an outer owner. The guard is cleanup rather than rollback: it does not establish success for each row helper or prove that a UI lock cannot occur. The base removal mutates view arrays rather than deleting message storage.

Scope: Threaded DB view new-header reconstruction.
