# Preserve inherited Back spacing in wizard navigation

Entry 2110 removes the important zero inline-end margin on the Back button. It retains zero inline-start margin on Next and Finish. The fixed comm stylesheet has that same split, so Back can retain spacing from the imported/platform button styles instead of both adjacent edges being forced to zero. The selectors use the native dlgtype role and logical inline sides. The separate accepted Gecko wizard markup contains Back plus Next/Finish controls with different platform ordering. Its pairing with frozen comm is unverified. No exact gap, inherited margin value, rendered platform, RTL, long-label, zoom, keyboard or focus result was measured. No build or CSS lint ran. Full external context is pending.

Scope: Wizard button CSS spacing.
