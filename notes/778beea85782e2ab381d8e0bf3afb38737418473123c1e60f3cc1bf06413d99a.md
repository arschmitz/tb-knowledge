# EWS accepts an InternetMessageHeader with no text before later header normalization

InternetMessageHeader.value is Option<String> for serde's $text field. The self-closing X-Is-Empty fixture expects None and the shared helper compares the complete deserialized value. This directly checks missing text acceptance, without testing a live GetItem response or every empty/whitespace spelling. At the later accepted header-block route, extract_headers converts None to an empty String before duplicate comparison. That collector is a later phase; imported formatting and naming are outside Thunderbird style guidance.

Scope: EWS XML header deserialization.
