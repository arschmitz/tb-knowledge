# UIDVALIDITY uses unsigned folder storage while later sentinel repair stays separate

The type patch changes the Mork UID-validity read to the unsigned wrapper and ImapUid_None, while its setter already writes unsigned data. The owned Panorama methods still return not implemented. The later accepted loader uses zero and explicitly remaps stored 0xffffffff to zero. Keep that compatibility policy separate from this type migration; no database format, binding or full-range round trip was executed.

Scope: IMAP UID-validity storage phases.
