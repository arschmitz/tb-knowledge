# Check notification translation after reconnect, not only template reuse

Current close-control code translates its light DOM on every connection while guarding one-time template and click-listener setup. The existing close-button lesson already records that ownership. The notification container separately connects and disconnects its shadow localization root and reapplies attributes. Its comment warns that translation-affecting changes will not be reflected after reconnection. Proposed scoped check: change localized inputs while detached, reconnect and observe the actual labels, rather than treating successful reconnection or a registered root as proof of fresh translation. This study records the comment and current lifecycle, without reproducing a translation failure.

Scope: Notification element lifecycle.
