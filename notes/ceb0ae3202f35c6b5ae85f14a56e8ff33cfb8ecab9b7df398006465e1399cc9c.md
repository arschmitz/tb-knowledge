# Keep spaces focus handling before tab activation

Dynamic addon buttons start at tabIndex -1 and use _addButtonClickListener, which adjusts the roving focus state before the activation callback. The toolbar implements Enter/Space, arrows, Home and End; its tests assert activeElement and both old/new tabIndex values. Removing a focused button moves focus before detaching it. Preserve this actual composite-control path, not just a focusable attribute. No keyboard session or accessibility tree was inspected live. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces keyboard and focus.
