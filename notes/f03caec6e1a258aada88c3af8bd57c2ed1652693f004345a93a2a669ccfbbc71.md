# The disabled QR-export browser test checks Settings removal

The new browser test pushes mail.qrexport.enabled=false and directly checks that the Settings category and pane are absent. Separate policy data cases expect false-policy enabled/unlocked and true-policy disabled/locked through an existing shared runner. These checks are distinct from menu rendering and module-rejection coverage; imported policy-checker assertions and native execution were not inspected or run here.

Scope: QR export browser and policy tests.
