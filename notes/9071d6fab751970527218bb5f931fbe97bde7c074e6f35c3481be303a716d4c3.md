# Windows menu spacing combines icon margin with scoped label padding

The stylesheet gives menu icons 0.5rem end margin and uses calc(24px + 0.5rem) for its selected no-icon/gutter label groups. A separate scoped rule exposes unchecked checkbox/radio icon slots outside the excluded popup classes. Rem follows root sizing, so this source does not establish a universal six-pixel margin or measured alignment. Toolkit rendering and accessibility results were not tested.

Scope: Windows native-menu icon spacing selectors.
