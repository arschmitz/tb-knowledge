# Refresh the new-folder picker through its popup and keep its selection result

When the New Folder parent changes, onFolderSelect calls MsgNewFolderPopup.selectFolder and stores its Boolean result. Setting only the menulist label would leave the shared picker's tooltip and icon-driving folder/server attributes stale. The helper also checks whether an enabled matching child or ancestor accepts the requested folder; its return value feeds dialog enablement. Reuse the receiver's state update contract instead of forcing folderSelected true. This is checked source behavior, with no rendered icon, tooltip or accessibility result.

Scope: New Folder dialog and shared folder picker.
