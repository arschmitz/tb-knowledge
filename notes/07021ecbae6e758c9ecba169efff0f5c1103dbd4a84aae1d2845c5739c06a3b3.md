# Thunderbird debug mochitest chunk count is a scoped scheduling choice

The original change adds11 chunks for .*/debug in mochitest-thunderbird; default 7 and existing sanitizer/coverage counts remain separate. The fixed accepted map retains these values and explicitly enables mozharness chunking. This configures task partitioning without proving shorter wall time or a universal optimum. The comm loader assigns test-platform to copied descriptions; downstream Gecko expansion is a bounded dependency. Track original, backout and reland separately when scheduling changes expose test-order or isolation problems.

Scope: Taskcluster test scheduling.
