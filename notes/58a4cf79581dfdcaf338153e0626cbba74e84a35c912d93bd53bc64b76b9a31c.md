# EWS item accessors distinguish borrowed and owned message data

RealItem variants carry a shared Message representation. inner_message returns a reference; into_inner_message consumes the variant and returns the message. The inspected folder-sync code uses these accessors while retaining ID validation and deduplication. The historical change added meeting variants; the fixed enum has additional variants. This supports the shared-data boundary, not complete meeting actions or every EWS item consumer. No EWS server or schema test ran.

Scope: Scoped source study.
