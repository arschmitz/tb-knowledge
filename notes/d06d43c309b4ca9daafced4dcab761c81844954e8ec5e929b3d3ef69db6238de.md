# Body-only retention removal spans controls and data adapters while message retention remains

This removal drops the body-only age controls and their init/save/lock bindings, server setting mappings and database property plumbing. The remaining retention interface still provides header age/count and starred-message policy; database application still selects whole messages under those settings. The patch neither adds body deletion nor explicitly erases old stored preference/database keys. Removing the control from an EWS-hidden test list is not an assertion that it is absent.

Scope: message-retention-settings.
