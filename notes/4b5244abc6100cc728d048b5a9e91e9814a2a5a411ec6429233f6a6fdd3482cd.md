# Per-message Quick Look registration retains handlers on the attachment list

The selected landing registers a fresh anonymous quicklook handler each time attachments are built for a new message. The reused-message path clears header state and list children, while the header-start path resets the build flag; the same list element can keep earlier handlers. The inspected fixed accepted code retains that registration shape. After two attachment-bearing messages, a single event can reach more than one toggle handler: conditionally, an open panel can be closed by the first and another show started by a later handler. This is a scoped static caller/registration finding, not a native execution result or an explanation of the reported compiler backout.

Scope: Attachment preview event registration.
