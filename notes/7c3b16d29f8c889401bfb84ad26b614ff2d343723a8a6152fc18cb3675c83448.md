# The IMAP JavaScript implementation is retired while native registrations remain

1930 removes the experimental IMAP JavaScript modules, module-loader service, preferences and duplicate JS test variants. At the accepted endpoint, components.conf registers nsImapIncomingServer, nsImapService and native folder/channel types, and moz.build compiles their C++ sources. Do not use the deleted ImapClient/ImapResponse bodies as current protocol behavior or style. A bounded search still finds an old startup-test comment mentioning ImapModuleLoader and imap-js, so retirement does not mean every textual reference is gone. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP implementation retirement.
