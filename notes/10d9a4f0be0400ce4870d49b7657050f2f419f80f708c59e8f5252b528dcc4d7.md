# Infer mailto identity only from a database-backed message header

MailLinkParent starts with identity null. It calls getIdentityForHeader only when documentURI is an nsIMsgMessageUrl and has messageHeader. This permits mailto links from standalone EML files that lack a database header, while preserving message-derived identity for database-backed messages. Current OpenComposeWindowWithURI receives the resulting identity and the Shift-dependent format. The EML regression test asserts that compose opens, not the recipient value or which identity was chosen.

Scope: mail/actors/MailLinkParent.sys.mjs.
