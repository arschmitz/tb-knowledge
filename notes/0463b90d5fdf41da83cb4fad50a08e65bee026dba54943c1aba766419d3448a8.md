# Keep a selected thread root distinct from aggregate unread children

The current thread test asserts that selecting an expanded root clears its own new/unread properties while hasNew/hasUnread remain for children, then clears aggregate properties after those children are read. Preserve these separate DOM properties in tests or styling. A thread aggregate is not the read state of its root message. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
