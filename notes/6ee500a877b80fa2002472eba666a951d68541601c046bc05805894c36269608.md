# Load the DOM DarkReader helper in the consuming current global

D225298 review moved the DOM helper from a system module to packaged DarkReader.mjs. The aboutMessage consumer uses a separate lazy getter with global:"current", as requested in inline1259903. Keep this helper’s DOM global in mind when changing its import. Possible Calendar and task consumers were an author plan; those callers were not inspected. Bug context remains incomplete; no complete audit or new runtime result is claimed.
