# Treat the identity-dialog result as a close signal in this caller

The 1958255 patch reloads am-main when the identities dialog returns args.result. The actual dialog binds both dialogaccept and dialogcancel to onOk, and onOk sets result=true. Therefore this caller uses the flag for dialog closure; it does not prove that the user saved a particular edit. The caller saves the current identity before opening the list. The full-page reload refreshes possible changes but also reruns page listeners. This is the checked local contract, not a general rule that cancel saves edits or that every reload is free of side effects. No Account Settings UI was exercised.

Scope: Scoped completion and input contracts.
