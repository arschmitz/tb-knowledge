# RawHdr reference arrays and legacy reference strings meet at the database adapter

RawHdr.references contains a list of message IDs. The legacy ApplyRawHdrToDbHdr adapter surrounds each item with angle brackets and joins the items with spaces before SetReferences. An empty list skips that setter. DetachedMsgHdr::SetReferences takes the opposite direction and parses the incoming string into the list. Preserve this representation boundary when changing header parsing or either database adapter; do not pass a serialized References header as one array item. The detached indexed-reference getters in the inspected source remain unimplemented. Static source only; no parsing or database test ran.

Scope: message-database.
