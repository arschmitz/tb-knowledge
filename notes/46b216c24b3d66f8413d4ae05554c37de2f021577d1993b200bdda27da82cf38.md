# Keep duration mirrors its next keep value into aria-pressed

The markup defaults to keep=false and aria-pressed=false. Its command handler reads the previous keep value and writes the same next true/false string to both attributes, while preserving the stored keep attribute. Existing date arithmetic continues to read keep. The checked startup path synchronizes only the linked image and markup persists only keep, so restored-state pressed synchronization remains a bounded source/coverage limit. No screen-reader, persistence or dialog result was tested.

Scope: Calendar item editor toggle state.
