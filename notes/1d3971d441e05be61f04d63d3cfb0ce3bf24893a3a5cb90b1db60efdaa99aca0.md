# Validate manual port numbers and expose matching field errors

Incoming and outgoing configuration capture reads valueAsNumber and sanitizes ports to integers from 1 through 65535. Failure sets custom validity, aria-invalid and the matching error description; success clears them. The native inputs also carry min and max. Keep the source, visible error and description ID paired when extending these fields. Unknown or empty-port behavior in other forms must be checked separately; source markup is not a keyboard or screen-reader test. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub manual port validation.
