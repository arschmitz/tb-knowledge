# Storybook uses a dedicated development profile and does not hot-reload chrome URLs

The accepted running guide says tb-storybook starts a temporary Thunderbird profile at localhost:5703 and supports --no-open. It also says chrome URL dependencies need a hard refresh and describes context-properties preferences when previewing SVGs in a web browser. These are environment boundaries for this Storybook workflow; no Storybook command or browser preview was run, and the guide does not prove all platforms behave identically. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Storybook runtime environment.
