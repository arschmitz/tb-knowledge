# The highest-nondeleted UID type change keeps its zero no-result contract

The owned patch names the highest-nondeleted return value ImapUid and removes a redundant uint32_t cast in PeriodicBiff. The scan and comparison stay intact: the helper scans backward for a nonzero nondeleted UID and returns zero otherwise, while biff also checks whether the last message is unseen. This local zero result is separate from the historical alias sentinel. No new range validation, strong typing or runtime proof follows from the annotation.

Scope: IMAP highest UID and biff comparison.
