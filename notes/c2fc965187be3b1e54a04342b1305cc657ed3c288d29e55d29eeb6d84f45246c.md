# The accepted secure-auth mapping contains a different Fluent ID from encrypted password

The original landing maps secure authentication to encrypted-password. The accepted helper instead maps that enum to vencrypted-password, while the inspected Fluent file defines account-hub-result-authentication-encrypted-password. InputSanitizer.translate returns matched values unchanged, so the none default does not replace this literal. This is a static conditional ID mismatch. The source study does not establish that a real selected config supplies secure or reproduce a missing label.

Scope: Account Hub authentication localization mapping.
