# Keep SQL address-function input and statement cleanup explicit

ADDRESS_FORMAT accepts one argument; a non-text, non-null value is rejected, while null produces an empty formatted value. Its tests reset prepared statements and finalize them after use; test setup also triggers destruction to finalize even after failure. Preserve error and cleanup boundaries when adding a SQL helper. This does not establish complete invalid-input test coverage beyond the inspected fixtures. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama SQL helper lifecycle.
