# Stylesheet origin affects Calendar forced colors

The D333944 review record at b6552d05a12e27636d3af194b7f285a661f4c5ff reports that replacing an author-origin link stylesheet with AGENT_SHEET caused Calendar description and comment frames to ignore selected foreground and background colors in forced colors mode. Reported AUTHOR_SHEET controls respected those colors and retained normal dark mode. When changing stylesheet loading in these frames, verify both forced colors and normal themes; loader origin is part of the behavior. The production suggestion was unapplied, and the supplied evidence contains reported test and screenshot results rather than independent confirmation. This does not establish a blanket ban on agent sheets.

Scope: Calendar description and comment styling.
