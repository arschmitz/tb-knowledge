# Verify contact selection through keyboard command enablement and recipient insertion

The contact sidebar listens to select, updates addrbook-select commands, and toggles disabled on To/Cc/Bcc commands based on GetNumSelectedCards. Button markup binds those commands. The current test reaches the contacts table with Shift+Tab, changes selection with ArrowDown, waits for To enablement and button focus, sends Space, then asserts the exact recipient pill. This tests the user action through command state. It does not inspect screen-reader announcements or cover activation of all three recipient buttons.

Scope: mail/components/addrbook.
