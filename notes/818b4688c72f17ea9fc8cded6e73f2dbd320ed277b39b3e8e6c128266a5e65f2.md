# Preferences search includes surrounding text when every element child is an anchor

searchWithinNode admits a non-leaf parent when every element child satisfies the anchor predicate: prefix null or html, and localName a. Its existing text-node collector and per-node highlighting can then inspect surrounding paragraph text as well as link text. Child recursion and visibility guards remain separate. This does not establish phrase matching across text-node boundaries, arbitrary mixed-element support, or a strict namespaceURI test. The accepted source retains the change.

Scope: preferences-search.
