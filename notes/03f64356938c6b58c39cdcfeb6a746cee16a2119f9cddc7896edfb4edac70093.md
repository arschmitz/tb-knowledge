# offlineMessageSize describes an offline local copy

The nsIMsgHdr.idl documentation at revision 259df1000552ba1e7795b7360c1d13faaa9cac06 defines offlineMessageSize as the exact size of the local message-store copy for folders that support offline messages, such as IMAP and NNTP. It documents zero or unset when the message lacks the Offline flag and for Local folders. Do not treat this field as a general message-size value. This is the documented interface contract; the supplied excerpt does not verify implementation behavior.

Scope: message header interfaces.
