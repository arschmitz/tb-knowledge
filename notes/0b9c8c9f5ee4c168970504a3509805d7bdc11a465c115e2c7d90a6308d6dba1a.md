# OAuth telemetry describes why the interactive flow began and how it ended

Entry 1509 adds issuer, reason and result extras. Current connect sets no refresh token or refresh before authorization; invalid_grant sets invalid grant before one retry. Terminal authorization/token paths record a result separately. A successful background refresh with no window reason does not produce this window event. Preserve these separate meanings instead of using result as the prompt reason. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: OAuth window telemetry.
