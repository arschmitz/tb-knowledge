# Test palette filtering and item availability against their actual sources

The customization filter test registers autocomplete before typing and before Escape, then checks child visibility. The availability test iterates customizableItemDetails, selects each pane and checks the correct generic or space-specific palette or target. It explicitly skips global search because that feature is disabled in the test. This is a catalog-driven availability check, not proof that the skipped item works or that palette navigation after filtering is accessible. Preserve the test’s feature-gate limitation.

Scope: mail/components/unifiedtoolbar.
