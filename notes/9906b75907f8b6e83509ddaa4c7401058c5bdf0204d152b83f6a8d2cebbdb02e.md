# Keep the mail EventUtils namespace tied to its actual exported helpers

The import follow-up replaces an incorrect named EventUtils import from the generic testing resource with import * as EventUtils from the mail resource. Current ContentTabHelpers retains that namespace import, EventUtils exports individual functions, and TESTING_JS_MODULES.mail packages that file. A lint-driven import change still needs export and resource-path checks; syntax alone does not establish which helper module it loads.

Scope: mail/test/browser.
