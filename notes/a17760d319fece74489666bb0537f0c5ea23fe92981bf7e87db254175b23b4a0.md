# Read state updates also change new state and counts

The native read path changes folder unread counts before setting the read bit, removes the key from m_newSet, clears New, and then notifies. MarkHdrRead calls it only when IsHeaderRead differs and also updates thread read counts. Recommend using the existing read operation rather than replacing it with a raw Read bit assignment in this database scope. No count transition or database commit was executed.
