# Address-pill class, DOM tag and JavaScript property use separate local names

The accepted widget is MailAddressPill, registered as mail-address-pill. Its DOM class is pill-indicator and its JavaScript field is pillIndicator. Preserve these local namespaces when extending the widget; a dashed DOM class does not require a dashed property or a renamed class. This is a component naming pattern, not a new project-wide case rule. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
