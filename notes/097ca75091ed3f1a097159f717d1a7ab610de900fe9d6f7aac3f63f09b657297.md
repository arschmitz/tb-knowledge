# Folder URI replaces folderURL without becoming a universal file URL

Entry 2010 removes folderURL from the folder API and its implementations. Current URI documentation describes a unique folder identifier that loosely represents server/filesystem location. The properties UI uses the URI unchanged for IMAP/NNTP and decodeURI for other folders. Scoped API recommendation: preserve that protocol-specific handling; URI is not a promise of a local file:// URL. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: folder URI API retirement and display.
