# The mail-message group narrows message actors while preserving shared browser actors

The messagepane browser declares mail-message. MailMessage and MessageScroll are restricted to that group, while shared FindBar, LinkHandler, LoginManager and NetError lists explicitly include it and the strict link actor still serves both mail-message and single-page. The actual space command obtains MessageScroll from that same browser when no local content window is available. These are declared registration/caller boundaries, not an executed actor/process result or an interpretation of the retained empty-string group.

Scope: Message display browser group and JS window-actor registration.
