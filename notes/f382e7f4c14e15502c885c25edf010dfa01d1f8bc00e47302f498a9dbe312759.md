# Detached-window assertions inspect reported windows after closing and releasing test references

The second-window scenario explicitly closes the window and clears its window/promise locals before assertNoDetachedWindows. The helper minimizes memory, gathers top-window report paths and reports any path containing detached. A source assertion for that scenario does not prove every window reference is absent or establish a passing leak test. The scoped arbitrary-delay exception remains test uncertainty, not a general waiting rule.

Scope: Mail detached-window test proof limits.
