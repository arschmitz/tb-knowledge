# Release-note environment substitution precedes the job transform

The release-note kind runs comm env_subst before the job and task transforms. env_subst exposes release_config, config_params and task, resolves keyed environment values, and formats command elements and env strings. The kind supplies BRANCH from release_type and VERSION from release_config. That input contract is separate from whether the graph selects and runs the task.

Scope: release-task-environment.
