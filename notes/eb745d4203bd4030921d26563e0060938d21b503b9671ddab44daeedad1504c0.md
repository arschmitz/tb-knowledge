# Keep native control semantics when building notification controls

767 implements the CTA as a customized HTMLAnchorElement and the close control as a customized HTMLButtonElement. The template uses native a and button elements with is attributes, localized close text and an inner CTA label. The current container manages href, displayed text, title and hidden state. These choices preserve static link/button semantics, but the actual control names, keyboard activation, focus return and screen-reader behavior were not validated live. A class called Button does not itself decide the native role.

Scope: In-app notification control semantics.
