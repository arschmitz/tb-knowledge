# The current-day week-view test indexes its column mapping with the weekday

The fix replaces getUTCDate with getUTCDay when indexing the seven-column expected-highlight mapping. The views harness sets calendar.week.start=4, so the mapping is scoped to its Thursday-first week. The direct assertion compares the day-column-today class with the expected column. This corrects the inspected test expectation; it does not establish a production-view fix or timezone/midnight runtime coverage. No browser test ran.

Scope: Calendar week-view browser tests.
