# MIME named-service migration preserves converter receiver and returned-buffer ownership

The MIME converter is a named JS component behind the C++ interface. Database GetMimeConverter returns a raw pointer backed by its nsCOMPtr member; it does not transfer ownership. The UTF8 decode wrapper calls this.decodeMimeHeader, so its receiver matters. The MIME encoder checks conversion status and PL_strdup-copies local output for the caller; accepted later source also keeps a service-null guard. Service-access cleanup must preserve these distinct receiver, object and buffer lifetimes. No runtime test.

Scope: mime-converter-service-ownership.
