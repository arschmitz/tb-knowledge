# Keep manual Account Hub names consistent with their layer

This family pairs dashed widget file/tag names such as email-manual-incoming-form with UpperCamel EmailIncomingForm classes. Templates keep the lowerCamel accountHubEmailIncomingFormTemplate.inc.xhtml stem; native IDs such as incomingPort and incomingPortErrorMessage are lowerCamel, shared classes such as number-input are dashed, and Fluent IDs use dashed account-hub prefixes. Component browser tests keep the browser_accountHubEmailManualIncomingForm.js stem and describe behaviors in their task names. Follow these local role-specific names without imposing one dash or camel convention on all files or test tasks. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub manual form file and control naming.
