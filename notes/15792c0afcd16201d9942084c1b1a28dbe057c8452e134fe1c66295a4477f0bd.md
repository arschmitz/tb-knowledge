# Offline visibility assertion messages should name the checked newsgroups button

The offline settings test checks selectNewsgroupsButton but calls that node the select folders button in its NNTP visible and IMAP/EWS hidden messages. In the same IMAP/EWS tasks, selectFoldersButton is expected to be visible. A failure therefore reports the wrong target and can appear to contradict the preceding assertion. Use messages such as "The newsgroups button should be hidden for EWS accounts." Preserve the distinct folder and newsgroup controls. The new row-count, row-name, checkbox and saved-flag checks also often omit message arguments; those need nonempty expected-behavior messages when edited. This is a concrete target/message mismatch and missing-message review finding; should is already present in the wrong messages.

Scope: mail/account-settings/tests.
