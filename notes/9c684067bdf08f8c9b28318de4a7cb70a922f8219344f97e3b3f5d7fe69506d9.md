# The unified toolbar popup requests gutter spacing for its mixed menu items

The change adds gutter-popup to the actual unifiedToolbarMenu. Its markup includes a checkbox and ordinary actions; the current Windows stylesheet pads non-iconic ordinary items in that popup separately from checkbox/radio items when needsgutter is absent. The context handler opens this popup and changes menubar-item presence/state by platform. This is a scoped popup/receiver contract, not a rule to add gutters to every menu or proof of rendered alignment, keyboard or accessibility. No menu or UI test ran.

Scope: Unified toolbar context menu CSS class contract.
