# The Owl OAuth fix normalizes the account type before choosing scopes

This landing adds the owl-prefix to exchange mapping already described in the activity-alias lesson. The inspected review accepts that small compatibility change. Bug 1952303 discusses D240649 and D240650 as alternatives and requests abandoning the latter; that request is not an independent audit of D240650. Keep the chosen normalization separate from a general change to scope-return policy. Current Microsoft tests directly cover ews and exchange scopes, while the inspected region has no owl-specific assertion.
