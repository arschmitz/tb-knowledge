# The existing-account password guard can initialize the cached password

The non-OAuth scan checks passwordPromptRequired before reading password. The accepted incoming-server getter can retrieve a matching saved password and cache it, while the password getter itself only returns the cache. Keep this ordering when changing the discovery guard. The test clears the cache with a saved login, then removes that login and changes username to test the skipped result. This establishes a scoped source/test contract rather than a fresh no-prompt UI result.

Scope: Account Hub existing-account credentials.
