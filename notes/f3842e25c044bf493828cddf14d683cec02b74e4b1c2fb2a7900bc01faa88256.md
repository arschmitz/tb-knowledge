# The SQL date-group cache starts from a defined refresh threshold

GroupedByDateFunction now initializes all five cached PRTime boundaries to zero. OnFunctionCall checks now >= mTomorrow before computing local date boundaries, so the initial refresh check no longer reads an indeterminate member value. The fixed accepted source retains the defaults. The existing test directly asserts named groups and future-grace examples, but this source change does not establish that every intermittent failure or timezone-change issue is fixed.

Scope: Panorama SQL date grouping.
