# Folder conversion's account ID is a lookup shortcut

At revision 4ee1236e7d4268751bee94659b76acaf3adc60c2, FolderManager.convert documents its optional accountId as a way to avoid an account lookup and explicitly forbids using nsIMsgDBHdr.accountKey. Without a truthy accountId, the implementation finds the account from folder.server and uses that account's key. Callers supplying the shortcut must respect this folder-account contract. The excerpt does not explain why the message-header value is unsuitable or provide runtime validation.

Scope: WebExtension folder conversion.
