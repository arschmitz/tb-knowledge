# Credential-confirmation labels reflect discovery input rather than a certificate check

The confirmation widget displays the supplied host and username. It chooses SSL/TLS for scheme=https and a localized None label otherwise. The inspected discovery gate compares base domains and its explicit safe-domain list before asking for consent. These are presentation and routing contracts; the widget does not verify a certificate. Clearing its display fields does not itself cancel discovery. No account or network test ran.

Scope: Account Hub redirect confirmation presentation.
