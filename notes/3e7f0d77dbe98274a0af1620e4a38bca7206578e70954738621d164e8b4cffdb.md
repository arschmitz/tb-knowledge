# Account Hub Support links rebuild their query from the current subview

setCurrentSubview rebuilds the Support anchor URL from formatted app.support.baseURL and sets account-hub source/referral parameters plus the current subview. Email and address-book footer setup pass their current state. The direct widget test checks the base URL and replacement of utm_content without duplicates; it does not verify an external browser launch or analytics delivery.

Scope: Account Hub footer support URL and direct assertions.
