# Recent destination timestamps invalidate an already listed folder menu

When an initialized Recent submenu receives MRMTimeChanged, a folder already in the list can now trigger clearing too. The event handler schedules _clearMenu with a zero-delay timer; that helper tears down generated items and initialization state. Popup initialization rebuilds later. The change therefore invalidates stale order rather than sorting synchronously or restoring alphabetical order. Unbuilt-submenu guards still apply. No rendered menu test was run.

Scope: Folder destination menu lifecycle.
