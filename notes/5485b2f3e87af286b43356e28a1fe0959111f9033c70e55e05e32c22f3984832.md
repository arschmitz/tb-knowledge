# Validate EWS folder shape and ID presence at the owned boundary

GetFolder validation requires exactly one entry, requires the ordinary Folder variant, and converts a missing FolderId option into MissingIdInResponse. It does not check that the ID string is nonempty. Preserve the distinction between a typed entry, optional ID presence, and any further string validation when documenting this boundary. The imported EWS model is dependency context; its internal style is not Thunderbird guidance. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: EWS GetFolder payload validation.
