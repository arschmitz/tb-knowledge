# Calendar attachment activation is asserted in the full dialog integration test

The integration test opens the real Calendar dialog/subview, arms the external-protocol mock and clicks the attachment anchor before asserting its observed URL. The isolated content-tab item tests do not cover that action because their link handler interferes. This proves the intended assertion boundary in test source, not an actual OS launch or download. Cleanup clicks Close before awaiting event deletion, without its own close-event barrier.

Scope: Calendar attachment external-request integration coverage.
