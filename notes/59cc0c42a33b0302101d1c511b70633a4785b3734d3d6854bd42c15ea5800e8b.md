# Explain numeric repair sentinels by the backend constant they represent

Current UIDValidity reset keeps the comment // == kUidUnknown beside the string "-1". The comment also explains that IMAP must recognize a repair. Proposed manual comment rule: when an API requires a string or literal for a backend sentinel, name its meaning and the consumer condition. Do not silently convert the representation or quote a constant unavailable to JS.

Scope: folder-repair.
