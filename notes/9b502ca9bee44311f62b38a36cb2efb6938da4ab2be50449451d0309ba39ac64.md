# Make menu expectation tables detect extra and missing items

The restored mail-context expectations caught Forward As Inline showing for multiple selected messages. Current MenuTestHelper.iterate waits for the popup, opens visible enabled submenus, and checks each item against data; the all-items path reports an item absent from the table and leftover expected entries. Keep a complete mode-specific expectation table when the test claims to cover the whole menu. Check nested popups after shown/hidden events. The data should describe intended behavior, so do not regenerate it mechanically from the implementation. This source check is not a keyboard-menu test.

Scope: Context menu tests.
