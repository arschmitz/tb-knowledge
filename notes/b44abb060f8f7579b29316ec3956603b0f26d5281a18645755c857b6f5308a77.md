# OpenPGP encrypted MIME keeps the original subject inside protected headers

The protected writer emits a truthy originalSubject through the structured header emitter for encrypted and outer-encrypted/inner-signed structures. The compose path preserves that subject before optional compFields clearing. An outer protected placeholder is a separate output under ENCRYPT_SUBJECT. Fixed source adds a prepared-header guard and a separate unobtrusive-signature route; those are later phases. Source placement does not prove an encryption roundtrip or all subject consumers. No crypto or UI test ran.

Scope: OpenPGP protected subject writer.
