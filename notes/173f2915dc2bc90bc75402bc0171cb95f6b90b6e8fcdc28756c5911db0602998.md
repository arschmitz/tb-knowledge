# The body-search text fallback is scoped to two sniffers and two simple fixtures

Both body-search sniffers keep a part searchable as text when the lowercased Content-Type line contains text/ or content-type: text. The implementation uses substring checks, not a complete token validator. The added bare-text and missing-header fixtures use the standalone word waldo, and the test expects two aggregate Contains hits. This does not establish general MIME-parser equivalence, all malformed spacing/token cases, or a direct bare-header test of decrypted-buffer parsing. Fixture wording keeps this repair separate from expanding substring-search expectations.

Scope: Message body-search content-type handling.
