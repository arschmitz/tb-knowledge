# Read forget as a transfer of the output reference

749 removes a check of aFolder after msgFolder.forget(aFolder). aFolder is the output slot, while msgFolder is the local smart pointer whose reference is transferred. The accepted function returns NS_OK after the transfer. This patch does not add validation of a null output-slot argument and does not prove the transferred folder is always non-null. Proposed manual C++ review rule: distinguish the output slot, its pointed-to value and the local owner before diagnosing a null check.

Scope: IMAP folder output parameters.
