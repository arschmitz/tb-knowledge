# Remote IMAP keyword writes use the database change-notification wrapper

HandleCustomFlags stores both its merged keywords and supported server keywords through SetStringPropertyByHdr. That wrapper returns for an equal old value, conditionally calls registered listeners before the header write and calls them after a successful write. SyncFlags invokes the helper after fetching custom flags but does not check its result. This is the inspected storage/notification contract; no live IMAP event or UI refresh was verified.

Scope: IMAP keyword database notifications.
