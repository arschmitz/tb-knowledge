# LiveView converts nullable database text with UTF-8 APIs at the native-to-JavaScript seam

The owned fix copies messageId, sender, recipients, subject and tags through JS_NewStringCopyUTF8Z into rooted JS strings, with JS_GetEmptyString for a null pointer. The same producer serves selected rows and message notifications; fixed source retains it after later async/context changes. LiveViewDataRow passes those fields into display text. The fixture adds accented sender/subject values, but that does not establish invalid-byte handling, allocation-failure behavior or coverage of every nullable/non-ASCII field. Keep address formatting and locale comparison separate from text encoding. This is static source evidence; no runtime validation ran.

Scope: Panorama native message object encoding.
