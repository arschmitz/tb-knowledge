# Build Thunderbird docs from the comm docs root

The docs command repair sets DOC_ROOT under topcommdir and reads config.yml there instead of the Gecko docs root. Accepted docs/config.yml maps topic names to component docs trees without a comm/ prefix. Keep this checkout boundary in Thunderbird documentation tooling; changing topsrcdir or copying a Gecko command can silently select the wrong config. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Thunderbird docs root boundary.
