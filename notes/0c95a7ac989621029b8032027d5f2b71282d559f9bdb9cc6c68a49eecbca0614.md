# Graph creation task and request comments still name other actions

The creation bridge spawns client.create_message under the task label sync_folder_hierarchy. The creation helper also calls its initial request a message move request, though the code creates the message first and only optionally moves it afterward. Both mismatches remain in the fixed accepted source. For this flow, the label and comment should name the actual creation action so a reader can trace it. This does not change behavior or define a global task-naming rule.

Scope: Graph creation diagnostic naming and comments.
