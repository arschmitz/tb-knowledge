# Rename a shared theme preference with all platform consumers

The landing changes mail.theme.macos.native-theme to mail.theme.native-theme in the default and three macOS consumers. Accepted code keeps the shared name with a macOS-and-Nightly true default and false elsewhere. Nearby maintenance should update each consumer/default together. This preference is not proof that Windows Mica is enabled; Windows styles instead depend on the platform mica media condition. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Native theme preference naming and scope.
