# Await cleanup navigation in content-policy browser tests

simplePageLoad installs browserLoaded for the expected page URL before loadURI and returns that promise. Both the remote-page load and about:blank cleanup are awaited. In this test family, an unawaited cleanup can overlap the next load and consume a later load event. Retain the expected URL and registration-before-action order when extending the test. The landing reports a --verify run without a timeout; that is author-reported testing, not a run performed in this study. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Content-policy navigation test lifecycle.
