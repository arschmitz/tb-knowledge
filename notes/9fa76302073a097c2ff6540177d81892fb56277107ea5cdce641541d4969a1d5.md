# Test the documented notification ID type if a string contract is required

InAppNotificationEvent documents notificationId as a string, but its constructor assigns the supplied value and the unit test passes the number 7. The source proves that the current wrapper preserves a value, not that it enforces a string type. For this wrapper, make a required type contract explicit in validation or test input. This is a narrow proposal, not a claim that all JavaScript annotations require runtime checks.

Scope: Notification event ID type contract.
