# Account Hub distinguishes known CardDAV incompatibility from connection failure

A null CardDAV host preset throws NS_ERROR_NOT_AVAILABLE. The Account Hub initializer maps that result to a specific notification and supplies the submitted server hostname through the Fluent url argument. It returns before the generic error while finally still restores busy and navigation state. This is a scoped error mapping; the browser scenario checks the localization ID rather than the final interpolated text.

Scope: Account Hub CardDAV errors.
