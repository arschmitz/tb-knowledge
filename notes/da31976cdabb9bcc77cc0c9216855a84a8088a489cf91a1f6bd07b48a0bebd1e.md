# Exchange fetch callback names are distinct from stream-listener callbacks

1926 renames the fetch data callback to onFetchedDataAvailable. Current IDL, the C++ fetcher and Rust caller use onFetchedDataAvailable, OnFetchedDataAvailable and on_fetched_data_available respectively. The IDL explains why this listener does not use nsIStreamListener: downloading does not always provide a request/channel argument. Scoped interop naming recommendation: update every binding spelling when renaming a callback and keep its fetch-specific semantics clear. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Exchange callback interop naming.
