# Choose the explicit-path database type from the owning server

OpenDBFromFile uses the folder server's localDatabaseType to construct the msgDB contract and create the matching database implementation. The 1848 rename removes the old implication that this method always creates nsMailDatabase. Preserve the type lookup and factory failure boundary when editing this path. A cache hit returns the existing object before this factory runs. These observations are scoped to the cited accepted source and historical changes.
