# The legacy alert no longer consumes main-window geometry from a fourth argument

This landing removes the manager fourth geometry argument, keeps the folder/message-keys/observer contract and adds left=0,top=0 as window features. The alert queries the primary-screen service or falls back to its own screen, sizes to content before its initial snap and divides captured edges by the live window devicePixelRatio on later snaps. Its target metrics remain captured once. Exact prior accepted geometry evidence is reused. Source comments state intended device/CSS units, but paired native units and cross-monitor origin behavior were not checked; this is the implemented calculation and argument flow, not an all-DPI placement guarantee. No tests change and no native display/accessibility run was performed.

Scope: Legacy new-mail alert placement.
