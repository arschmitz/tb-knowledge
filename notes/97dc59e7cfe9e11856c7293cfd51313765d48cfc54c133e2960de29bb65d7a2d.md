# The lifecycle reland changes constructor cleanup and test observation timing

The reland installs Gloda unload cleanup in its constructor and removes the observer only after hasConnected. It also adds a 500 ms wait after closing the second window before clearing local references and inspecting memory reports. Those are the two changed result blobs relative to the first landing. The accepted test later waits for mail-startup-done; that event change is a separate phase. No Mac failure cause or passing runtime result is established.

Scope: Mail window lifecycle reland phases.
