# Identity encryption capabilities reflect configured credentials and are read only

A WebExtension MailIdentity exposes OpenPGP and S/MIME canEncrypt/canSign booleans. OpenPGP uses the configured key ID for both; S/MIME uses separate encryption and signing certificate names, so one can be available without the other. convertMailIdentity reads these attributes from both live and cached identities. The API protects encryptionCapabilities from create/update writes. Current code retains the fields. D211823 approved the functional code; the reviewer said two tests were trusted but not reviewed.

Scope: WebExtension identity encryption API.
