# The parent-folder menu passes accessKey through its attribute dictionary

When a parent-folder item has fileHereLabel, its attribute dictionary receives that label and fileHereAccessKey under the key accessKey. _buildMenuItem forwards the dictionary to generateElement, which calls setAttribute for each entry. Without the configured label, a different branch uses the folder name and CSS attributes. Keep this attribute-dictionary route separate from a direct element.accessKey assignment. The comm source does not by itself prove the toolkit cause of the reported NULL label or a live keyboard result.

Scope: Folder menu parent-item construction.
