# Date-only calendar values use localized All Day text

formatDateTime checks aDate.isDate before applying date/time Intl options. It returns the formatted date and the localized AllDay string; timed values still include a short time. formatTime also treats date-only values as All Day. Preserve the date-only versus midnight distinction in this formatter scope, and use cal.dtz.formatter for full display strings rather than assembling date parts in callers.
