# Clear the window reason after recording a terminal OAuth event

recordTelemetry requires issuer and reason, records the terminal result, then deletes reason. The reason gate prevents the same object’s normal token reuse/background refresh from being recorded as another window event. The shared prototype storage concern is separate and means this is not a proven isolation guarantee across OAuth objects. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: OAuth telemetry settlement.
