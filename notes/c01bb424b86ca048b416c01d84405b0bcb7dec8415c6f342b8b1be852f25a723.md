# Coalesce expensive tree selection processing during key repeats

Newer accepted TreeListboxMixin updates selection highlights and scrolling for every repeated navigation key but defers select callbacks until keyup or blur. Its test expects2events for repeated ArrowDown: first press and release, with final index4. A single press remains immediate. Preserve blur cleanup so deferred downstream folder loading is not lost when focus changes. Tests were read, not run; this later accepted behavior must not be attributed to the2024 reland.

Scope: tree performance and lifecycle.
