# The related-PDF draft regression checks attachment presence and name

The original regression imports a synthetic multipart/related draft with HTML before an inline PDF, opens compose, and asserts one attachment named pdf-sample_0.pdf. Its messages describe the expected result. It does not save and reopen, forward, compare decoded bytes or inject allocation/output failures. Keep those untested paths separate from the normal decomposition implementation.

Scope: MIME related-part browser regression coverage.
