# Hidden related MIME parts use a decoded-size sink without emitting content

The added related-child path feeds suppressed leaf data through MimeLeaf_parse_buffer_for_size. It uses the shared decoder with a discard sink, and sizeSoFar advances by decoded output where decoding applies. The caller normalizes line endings before feeding each line. The regression task checks one unreferenced inline PNG has size 67 and is not empty. The accepted ordinary suppressed-output raw-byte fallback is a later source difference; the test does not establish all encoding/mode or save-byte behavior.

Scope: MIME attachment size accounting.
