# Validate the primary sort only when grouping a message view

For DBViewWrapper grouped-by-sort, groups already sort their messages by date. Validate the primary sort type and replace an invalid primary with byDate. Do not reject a valid primary just because a saved secondary sort is bySize. The May 2024 fix also rejects byUnread and byJunkStatus, and byLocation for a single-folder view.

Scope: message view sorting.

- `mail/modules/DBViewWrapper.sys.mjs`
