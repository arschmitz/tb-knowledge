# Calendar dialog bottom spacing belongs to the subview rather than category presence

This landing moves the bottom-space contribution from a populated categories list to the visible subview's logical block-end padding. Category visibility is still controlled by its widget. The original rule covers every visible direct child; accepted code later narrows padding to the main subview and uses --calendar-dialog-gap. Preserve that phase distinction when reusing the spacing example. No rendered size, RTL or accessibility test was run.

Scope: Calendar dialog layout.
