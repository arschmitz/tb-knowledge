# Shortcut row file, class, tag and template names follow distinct local roles

The accepted component uses shortcut-row.mjs for its file, ShortcutRow for its class, shortcut-row for its custom-element tag and shortcutRowTemplate.inc.xhtml for its template. The package mapping preserves those exact resource names. This adds row-specific evidence to existing shortcut-container naming guidance. Recommend matching each local role for a sibling widget instead of imposing one case style on all four. This is a scoped source pattern, not a reviewer-approved project-wide naming rule. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Shortcut row naming roles.
