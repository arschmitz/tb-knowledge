# Treat icon size suffixes as family names rather than universal dimensions

856 registers --icon-nav-down-xs and --icon-nav-up-xs under a stylesheet group commented XS - 12x12px, but these SVGs have an 8 by 8 viewBox and dimensions. Use the matching registered family names and check actual geometry when sizing a control. The naming label alone does not guarantee all XS assets have identical dimensions. The dual context-fill/context-stroke paths accommodate different toolkit paint inputs.

Scope: Icon naming and paint conventions.
