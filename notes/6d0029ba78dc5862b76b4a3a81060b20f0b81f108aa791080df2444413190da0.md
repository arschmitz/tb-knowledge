# Expand a collapsed selected thread through one shared message-header helper

944 extracts getMsgHdrsForIndex into ExtensionMailTabs.sys.mjs and uses flatMap so a selected closed container can contribute every thread child. The helper returns a single header for an ordinary or open row. The mailTabs getter/event path and messageDisplay three-pane getter reuse the same actual-selection helper. Keep the expansion rule in this shared boundary instead of duplicating it across APIs. The previously published real-selection versus context-target lesson remains the broader contract.

Scope: Extension collapsed-thread header expansion.
