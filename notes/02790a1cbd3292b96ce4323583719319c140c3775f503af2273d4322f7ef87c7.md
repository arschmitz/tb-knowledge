# Keep stored expansion state keyed by both folder and folder-pane mode

FolderTreeProperties stores expanded URI lists under open[mode]. The getter returns false when that mode has no valid array; the setter adds only absent URIs and removes by index>=0, preserving index0. Different folder-pane modes can therefore hold different expansion states for the same URI. Preserve both identity dimensions when changing persistence. This comes from current related code, not a new292 migration.

Scope: folder pane persistence.
