# Panorama flag notifications follow state mutation and stay within the matching folder

The flag patch returns early for equal flags, updates SQL, updates the message state, then sends old/new flags to listeners. PerFolderDatabase forwards only messages in its own folder; changed tests assert folder isolation and the Read transition. Fixed accepted code keeps that order with a later cache representation. The added LiveView callback was empty. The original count adapter had a separate pointer-cast defect repaired in 2679; review acceptance does not erase that sequence. No test ran.

Scope: Panorama flag notification boundary.
