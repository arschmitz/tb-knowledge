# The extension browser lookup returns native tabs before ID or wrapper conversion

The new hook gets a tab from the actual tabmail receiver, otherwise returns a supported secondary window or null. Browser data then converts that native object to an ID, while the status listener directly asks for its wrapper. The old browser-ID cache/helper is removed. The new test asserts two content-tab results. Secondary-window linkedBrowser compatibility is unverified in this scope; the review status alone does not establish a defect or a resolution. Paired Gecko behavior and runtime success are outside this comm-only proof.

Scope: Thunderbird extension TabTracker native browser lookup.
