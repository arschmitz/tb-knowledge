# Initialize copy-request state before applying the caller policy

The copy-request constructor initializes m_allowUndo to false. Init then overwrites it from allowUndo and acquires the transaction manager only when that policy is true. A scoped manual recommendation is to give scalar request fields a defined construction state while preserving the later caller-controlled setting. The default does not mean all message copies disable undo. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Copy request initialization contract.
