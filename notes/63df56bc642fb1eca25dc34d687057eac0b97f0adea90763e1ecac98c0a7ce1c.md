# Rust vendor cleanup removes listed files and checksum entries together

The owned cleanup helper removes each listed path from both the package checksum map and disk, tolerating an absent key or target file. The historical version targets Cargo.toml.orig in source-backed lockfile packages. Accepted code later iterates package directories and targets other excluded metadata paths; the old target list is not current guidance. Vendor calls cleanup after its policy check, and a separate cleanup subcommand is available. This is not an atomic repair or a verified vendor run. Imported manifest and checksum bodies are excluded.

Scope: tooling/rust-vendor.
