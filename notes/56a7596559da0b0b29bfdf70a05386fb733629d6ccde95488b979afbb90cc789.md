# Distinguish a selected mail tab from the first mail tab

switchToMailTab compares the selected tab mode with mail3PaneTab. It switches to tab 0 only when the selected mode differs; it leaves a second mail3Pane tab selected. D215708 reviewer asks about privacy/other tabs after account setup. The author explains startup ordering and later session restoration, without reporting a test run. Fixed accepted callers still use this helper at normal startup and account-setup closure, and restoreTabs can later select the saved tab. Proposed comment and review practice for this exact helper: describe the mode check and target index explicitly, rather than promising that every call selects the first mail tab. Minimum test coverage: selected content/privacy tab, selected second mail3Pane tab, account-setup closure, and restored secondary selection. These are proposed checks, not reported results.

Scope: mail/base/content.
