# Thunderbird Calendar D332509 route-generation explanation

Generation identifies which event request a rendered calendar control belongs to. The listener captures its control's generation, and `changeCalendar` ignores it when `selection?.generation !== generation`, so an old control cannot modify the new event's draft. [Task 1]

Scope: calendar.
