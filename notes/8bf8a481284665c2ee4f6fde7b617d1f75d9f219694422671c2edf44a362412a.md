# Treat a shared CSS token port as a consumer migration

Entry 986 changes ten owned styles from --in-content-box-background to --background-color-box. The accepted select option rule in widgets.css still uses the new token, alongside newer semantic text tokens. This supports using the shared token expected by the imported platform stylesheet in that consumer. It does not prove that all in-content tokens are forbidden or that this one variable is defined by comm. The exact paired Gecko theme revision and rendered palette were not established.

Scope: mail/themes/shared.
