# Keep native Windows backdrop styling conditional on accent theme and contrast states

Accepted Windows code applies transparent Mica only with customtitlebar, no lightweight theme and accent-color-in-titlebar disabled. Acrylic adds a translucent light/dark tint, and prefers-contrast separately uses ActiveCaption/CaptionText. The border uses ActiveBorder/InactiveBorder under accent or mica conditions. Preserve these platform/state exceptions instead of replacing every titlebar surface with transparency. No Windows rendering, contrast or activation test was run. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Windows native backdrop style scope.
