# A missing loading-state receiver must not count as an observed false loading state

The fixed message-header promise helper waits when webProgress is missing, is loading, or has the wrong URI. FolderDisplayHelpers completion polling instead requires webProgress?.isLoadingDocument === false and the required URI state. Missing optional state produces undefined; negating undefined is true, while undefined is not strictly false. The historical summary incorrectly equates false with undefined. Keep the actual predicate and absence contract, rather than banning optional chaining. Navigation and Gloda waits use separate expected-URI contracts. The bug later reopened, so this accepted guard repair did not prove the intermittent deletion failure fixed. No browser tests ran.

Scope: Browser test loading predicates.
