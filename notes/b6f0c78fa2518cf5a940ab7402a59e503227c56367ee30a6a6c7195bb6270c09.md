# Exercise the actual OAuth token cache for send failures

753 creates send cases for saved refresh tokens, expired or invalid access tokens and a bad refresh token. It changes the actual OAuth module cache for those scenarios instead of only changing a local variable. The bad-access-token task explicitly retains a FIXME about retries using the same bad token; that limitation is not a desired behavior rule. Later accepted tests add more cases, but those later landings are not counted as studied here. No OAuth request was made during this study.

Scope: Compose OAuth recovery tests.
