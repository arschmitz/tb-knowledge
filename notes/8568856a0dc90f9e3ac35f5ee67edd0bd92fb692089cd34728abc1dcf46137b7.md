# Xpcshell timeout annotations need the intended manifest scope

This change places requesttimeoutfactor under individual slow-test sections, except xpcshell-local.toml where it is under DEFAULT. A manifest default has a wider declared scope than one named test. The CardDAV offline factor 6 has a Windows reason comment but no platform condition. The test_over4GBMailboxes.js request moves from 2 to 4 in this phase and later reaches 12. Platform defaults and worker runtime caps are separate settings. These declarations do not establish an optimal factor, exact timeout seconds or a passing test run.

Scope: Xpcshell test configuration.
