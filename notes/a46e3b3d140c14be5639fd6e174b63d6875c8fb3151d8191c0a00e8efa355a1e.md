# Treat colon and whitespace according to address-token context

Group names are cleaned and whitespace is collapsed; quoted display tokens containing a colon remain names rather than group delimiters. Empty group names flatten their mailboxes into the main result, and the parser tolerates a missing final semicolon. Test those distinct branches instead of globally stripping colon characters or whitespace from the input. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Address header token normalization.
