# Additional FCC copying is gated by delivery mode while each copy keeps its selected mode

The additional File Carbon Copy field fcc2 is handled only once and only when the overall delivery mode is send-now or queue-for-later. The second copy is requested with an explicit deliver-now mode, and the copy helper passes its local deliverMode argument to the native startCopyOperation call. Saving drafts or templates therefore does not enter this additional-copy branch. The current method is asynchronous and has later retry/filter work outside this historical change. Its written unit scenarios check the copied subject for sending and queueing, but the added assertion has no message. No send, copy, folder flag or draft-replacement test was executed.

Scope: Compose sent-copy versus save behavior.
