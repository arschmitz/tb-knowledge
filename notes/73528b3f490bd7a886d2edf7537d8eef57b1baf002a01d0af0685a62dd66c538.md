# Three release merge actions explicitly set update-clobber-file to false

The selected kind configuration adds update-clobber-file:false to main-to-beta, beta-to-release and release-to-ESR actions. Accepted source retains the values after a later uplift-to-merge-day action rename. The imported transform and Lando consumer remain bounded dependencies, so this is a configuration finding rather than proof of a successful release operation or all clobber behavior. Unrelated Suite sections stay excluded.

Scope: Thunderbird merge-automation release action configuration.
