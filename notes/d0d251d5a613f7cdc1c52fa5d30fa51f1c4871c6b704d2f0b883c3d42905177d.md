# The seven headless Linux condition rewrites are a historical manifest phase

The four-file condition port changes seven skip-if strings from headless && os == linux to the same two terms with OS first. It does not change an operand or add a test assertion. The fixed accepted manifests later use separate run-if strings for OS and headless state; the menus entry puts !headless first while the other six put OS first. Keep these exact phases separate and do not infer a repository-wide ordering rule or test execution from this metadata port. The upstream condition evaluator remains outside this source study.

Scope: browser-test manifest conditions.
