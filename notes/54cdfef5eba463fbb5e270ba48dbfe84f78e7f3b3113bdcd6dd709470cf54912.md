# Ignored category actions must restore checkbox state

For Bug 2084433 at revision 24ae8c26d87e424b3f98e49153604460e4ede65b, the AI report says an ignored category change could leave a checkbox inconsistent with the draft. The reported repair restores the checked state from observed categories after an ignored change. This applies to these category controls when the UI changes before the draft accepts the action. The record names a regression test but provides no independent confirmation of the implementation.
