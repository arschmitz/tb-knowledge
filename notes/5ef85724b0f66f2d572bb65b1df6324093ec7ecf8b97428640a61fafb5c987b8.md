# Commands rebase conflict dialog session-state ownership

`server.mjs` returns `status: "applying"` when `session.resolutionBusy || session.continueBusy`; restored dialogs derive Resolve, Continue, and Close disabled state from the selected session. `ai-task-tray.js` invokes `adapter.onUpdate?.(session)`, which must refresh restored dialogs when server work completes.
