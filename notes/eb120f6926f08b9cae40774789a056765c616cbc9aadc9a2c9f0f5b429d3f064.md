# Account Hub separates default and Exchange field capture before common account fields

getIncomingUserConfig chooses a protocol-specific capture helper before setting common authentication and username fields. The reviewed original landing splits default fields from EWS URL handling; current code names the latter #getExchangeConfigValues and chooses it through isExchangeConfig. The separate helpers keep hostname/port/security fields apart from endpoint URL validation. These are concrete local names and responsibilities, not a global method-splitting rule. The primary historical Bug has missing human1, so this source-supported style lesson grants no full-audit credit. No UI or test run occurred.
