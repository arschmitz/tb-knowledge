# Distinguish a clock-boundary wait from an unexplained readiness sleep

844 waits 2000 ms because the stored timestamp can be truncated to seconds and the test must detect a wrong replacement with a later current time. That purpose is concrete. The 829 compose test instead documents an uncertain 100 ms readiness workaround. State the clock or event condition a wait protects; do not promote either delay as a general test style or claim a focus wait removes unrelated readiness needs.

Scope: Time-sensitive test documentation.
