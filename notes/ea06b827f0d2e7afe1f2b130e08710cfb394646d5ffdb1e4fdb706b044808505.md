# The Try decision command adds parameter override after the cron branch

The decision-task configuration keeps cron arguments as the first branch. For other decision tasks, try-comm-central receives --allow-parameter-override beside the existing try_task_config.json argument. Other projects receive no extra argument, and the action-callback command does not use this interpolation. The comm source establishes argument selection; the Gecko parser and a live Try push were not validated.

Scope: Taskcluster decision command arguments.
