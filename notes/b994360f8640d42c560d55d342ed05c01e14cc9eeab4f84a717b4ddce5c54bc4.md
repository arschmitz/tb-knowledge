# Local virtual-folder transfer guards the source and removes it only for a move

LocalCopyVirtualFolder rejects a source without the Virtual flag, copies its summary/name/flags into the destination and removes the old folder only when isMoveFolder is true. Exchange delegates virtual sources before remote handling; the IMAP caller uses it within a same-server move branch. The new EWS/Graph tests pass true and directly check source disappearance and destination presence. They do not directly test a non-moving copy, guard failure, duplicate name or IMAP. No transfer was executed.

Scope: Shared virtual-folder transfer.
