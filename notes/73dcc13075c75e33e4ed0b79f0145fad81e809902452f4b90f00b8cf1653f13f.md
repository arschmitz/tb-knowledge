# Route notification activation through its custom event and manager

767 suppresses the original link click with preventDefault and stopPropagation and dispatches ctaclick. Current code uses InAppNotificationEvent to include the notification ID, and the manager handles primary-button CTA activation. This prevents independent link handling from competing with notification bookkeeping. The newer event class and manager behavior are current comparisons, not attributed entirely to 767. Mouse-button and composed-event assertions exist; keyboard and external-navigation behavior were not run.

Scope: In-app notification event ownership.
