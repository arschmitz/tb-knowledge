# The deleted customizeMode include is separate from Thunderbird's live toolbar command route

The removed include supplied gCustomizeMode handlers for palette, titlebar, theme, density and reset/done controls. Bounded historical tracked-mail searches found no external include or handler references. The actual toolbar-context item instead invokes cmd_CustomizeMailToolbar, whose receiver uses unified-toolbar.showCustomization for the tabmail case or the separately registered customizeToolbar.xhtml resource for its sheet/dialog path. Keep these routes distinct; deleting the unused include does not establish that toolbar customization was removed or that this file was never used in every historical or dynamic environment.

Scope: mail toolbar customization resource ownership.
