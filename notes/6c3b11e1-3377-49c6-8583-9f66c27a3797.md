# Bound a DNS TXT string read to its declared length

A DNS answer can contain several TXT records. ctypes readString has no length parameter, so reading directly from the answer buffer can run into following records and fail with malformed UTF-8. The May 2024 fix copies the length-prefixed string into a bounded buffer. A July 2024 follow-up handles several strings within one TXT record; do not treat this first fix as complete for that case.

Scope: DNS TXT parsing.

Paths:

- `mail/modules/DNS.worker.mjs`
