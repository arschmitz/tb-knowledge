# Attachment fallback names decode file leaves while other URL names remain raw

When no name is supplied, AddAttachments and inline-drop link text decode the last component only for an exact file:// prefix. Other URLs keep the full string, including http:// and percent escapes. The attachment URL itself stays separate from its name. The browser event test directly expects gött.txt and the original encoded file URL. AddAttachments also applies separate protocol safety naming; this does not prove arbitrary URI handling, real file I/O or inline-drop runtime.

Scope: Compose attachment names and event contracts.
