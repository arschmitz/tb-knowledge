# The folder-color rename test checks cache and row state without reloading its JSON file

The rename listener updates JSONFile data and schedules saveSoon. Its shared assertColor helper checks getColor under the new and old URI keys and the row icon inline --icon-color value. Those assertions cover the loaded cache and row refresh; the test does not flush and reopen folderTree.json or restart the store. Keep this direct coverage separate from durable disk-persistence validation or computed visual-color/accessibility results. No browser test or file reload ran.

Scope: Folder-color persistence test scope.
