# Calendar removal menu comments keep complete Fluent IDs beside the dynamic ID

setupDeleteMenuitem builds one of three near-identical Fluent IDs from the checked removal mode. The adjacent comment lists each complete ID, keeping those names visible to text search. This is an adopted local convention for this small ID family, supported by the exact code; it is not a rule to construct every localization ID dynamically. The existing mode logic and command remain separate from label delivery. No translation or removal action ran.

Scope: Scoped Calendar localization naming and source comments.
