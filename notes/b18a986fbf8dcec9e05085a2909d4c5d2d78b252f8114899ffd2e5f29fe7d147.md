# URI hash wrappers read their visible spec before calling the shared helper

The port adds URIHasher inheritance and SpecHash to LDAP, mailnews and the historical Mailto wrapper. Each SpecHash calls its own GetSpec before CachedSpecHash, and explicitly ignores GetSpec’s status. The mailnews getter normalizes the visible news/snews form first. Fixed accepted LDAP and mailnews retain these calls; the old compose files are absent. This source establishes the wrapper input and call order, not the upstream cache algorithm, invalidation, caller equivalence or an avoided string read. No hash or build test ran.

Scope: Mailnews URI spec-hash port.
