# New folder rows initialize their new-message indicator from existing folder state

setFolder now initializes new-messages when a row is created. A collapsed row includes subfolder new-message state; an expanded row checks only its folder. This happens before message counts and avoids depending on a later update callback for already-existing state. The updateNewMessages path separately accepts a notified-but-not-downloaded flag, which initial setup does not add. The selected CSS consumes the class for bold and new-folder-color text. No folder/view or rendering test ran.

Scope: Folder-tree initial new-message state.
