# Migrate the signing format and the matching signing permission together

The port changes localization signing to gcp_prod_autograph_gpg and changes Widevine removal to its gcp_prod_autograph_widevine format and matching project scope. Current remove_widevine removes both the permission scope and every matching artifact format. Scoped configuration naming check: use the service’s complete format spelling consistently in payloads and scopes; changing one string alone can leave an unintended signing request or permission. No task graph or signing job was generated. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: taskgraph signing names.
