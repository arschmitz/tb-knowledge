# The UPX migration changes fetched dependency categories before later path fixes

The owned kinds replace upx-3.95-win fetch inputs with linux64-upx toolchain inputs for the changed Windows builds and localization/Searchfox tasks. Searchfox retains windows-rs as a different fetch. Selected accepted declarations keep this category split. Executable paths, bootstrap behavior and the later mozconfig corrections need their own source phases; this YAML change does not establish a successful build.

Scope: Windows UPX taskchain inputs.
