# The XUL CSS cleanup keeps the public folderPane resource while removing platform wrappers

This cleanup deletes the three platform folderPane.css wrappers and maps the existing public messenger skin URL directly to the shared file. The owned shared file still retains legacy XUL icon and twisty rules. Its server rules still reference --primary-fill and --primary-stroke after their local root definitions are removed. This records the exact packaging and declaration/use boundary; it does not prove a complete cascade, rendered regression or removal of all XUL consumers. The accepted revision's later file deletion is a separate phase.

Scope: Folder tree stylesheet packaging and retained legacy rules.
