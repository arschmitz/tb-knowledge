# The temporary Gloda list tab leaves its query callback attached when closed

The adapter installs a collection listener whose completion callback opens the result tab. Its closeTab hook is empty, while the framework marks the temporary tab closed and invokes that hook. The callback does not check that closed state or detach the listener. If completion later arrives, this callback contains no suppression of the result-tab opening. This is a bounded static lifetime finding, not a reproduced race, an assertion about datastore timing, or a general listener policy.

Scope: Gloda list-tab query completion lifetime.
