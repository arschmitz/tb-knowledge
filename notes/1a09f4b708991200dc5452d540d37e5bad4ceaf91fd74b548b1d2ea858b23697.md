# POP body-download URLs carry folder and key data into a channel-owned sink

The removed nsIPop3URL held a sink and message URI. Its replacement factory carries uidl, an optional number and the canonical folder URI in a plain mailnews URL. Pop3Channel resolves that folder, creates/configures a sink and passes it to fetchBodyForUidl, whose actual receiver retains it. uidl is decoded while folderURI is deliberately kept in its canonical escaped form. This bounded data/receiver contract does not prove cross-process serialization, arbitrary delimiter handling or a successful download.

Scope: POP partial-message download ownership.
