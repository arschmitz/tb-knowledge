# The read dialog waits for its held data promise before measuring its position

The initial change makes show await the held load promise before invoking base show, and resolves successful loading only after reload checks and description work. The positioning fixture awaits show before checking target/container tolerance in its own document; the shared event opener waits for the open attribute. Accepted code later prepares the promise during connection, coalesces attribute updates, changes missing-ID handling to rejection and replaces the promise on close. Those phases matter: promise completion is not a rendered-frame, test-execution or all-error-path guarantee.

Scope: Calendar dialog async show contract.
