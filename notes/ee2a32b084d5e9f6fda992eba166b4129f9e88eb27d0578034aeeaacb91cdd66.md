# The aggregate Star display and command use different flag predicates

The inspected ThreadSummarizer initialization computes the Star display by checking every summarized message's flag. Its click handler requests cmd_markAsFlagged, whose matching common handler chooses flag or unflag from the first selected header. For a mixed selection with a flagged first message, the display can be unpressed while the command chooses unflag. The handler's enable guard separately requires a selected non-dummy message. These are exact source predicates, not a reproduced interaction, a live controller-routing trace or a new command-policy rule. The added mouse tests cover uniform thread toggles rather than this mixed first-header case.

Scope: Multimessage Star command routing and mixed selections.
