# Keep notification event constants strings and test names in their local namespaces

NotificationManager event constants use upper snake case, while dispatched event strings are lowercase undashed words. The nearby test_notification_manager.js file uses a lower snake case stem, and some test functions use lowerCamel words after test_. Keep these separate local naming families for related code. Existing knowledge covers the service module and custom-element filename distinction. These are scoped accepted source patterns, not an approved repository-wide casing policy. Static source/test inspection only; no runtime, build, lint or live accessibility validation. Full Bugzilla and Phabricator discussion remains pending.

Scope: In-app notification naming.
