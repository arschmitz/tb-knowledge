# Search sort indicators use DOM column identity rather than the sort enum

Entry 1465 passes primarySortColumnId instead of primarySortType to the indicator updater. The old folderDisplay.js owner is retired; the accepted SearchDialog passes the column ID and order, and DBViewWrapper resolves built-in and registered custom columns to DOM IDs with a date-column fallback. UpdateSortIndicators clears old directions before setting the chosen column. Preserve the enum-versus-DOM-ID boundary in this Search Messages UI, including custom columns. No sort, custom-column, accessibility-tree or Search Messages UI test was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Search Messages sort column identity.
