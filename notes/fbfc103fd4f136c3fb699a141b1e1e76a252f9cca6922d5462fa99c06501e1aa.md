# Scope destination-recency updates to user-initiated non-special folder actions

UpdateTimestamps skips Trash and Junk. It sets MRU for other folders, then sets MRM only for a user-initiated action and when the folder is not an archive or a child of one. Preserve that narrower destination history when adding callers; last viewed and last used as a destination are different properties. No folder move or new-mail operation was run. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: folder timestamps.
