# The import page replaces its account-setup stylesheet dependency with scoped local rules

The owned patch removes the packaged accountSetup.css and its aboutImport link, then loads common and preferences styles directly. The import stylesheet keeps the selected root/body layout, description line height and result-indent rules. The actual import code assigns result-indent to its profile-details dl, and description paragraphs already have a local margin reset. Review-questioned margin/padding additions are absent from the owned final source; the requested blank-line grouping is present. The connector uses the border token for its normal state. This bounded source migration does not establish visual or accessibility equivalence for every removed account-setup rule.

Scope: Standalone import-page styles.
