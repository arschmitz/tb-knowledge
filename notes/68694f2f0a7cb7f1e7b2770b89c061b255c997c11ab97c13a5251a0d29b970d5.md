# Specify only the MIME options that affect the selected header parser

1032 removes RFC 2231 decoding flags from address and unstructured header calls and replaces HEADER_OPTION_ALL_I18N with ALLOW_RAW plus DECODE_2047 where appropriate. parseHeaderField only uses DECODE_2231 in HEADER_PARAMETER; address and unstructured branches ignore it. Keep the effective flags explicit so the call does not imply support it lacks. This is a readability rule beyond formatting, and the checked behavior supports the commit's no-functional-change description.

Scope: MIME effective parser-option syntax.
