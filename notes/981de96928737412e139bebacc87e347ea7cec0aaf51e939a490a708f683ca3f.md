# Graph folder emptying sequences subfolder deletion before message deletion

The operation first batches deletion of the supplied subfolder IDs and checks successful-response count. It then awaits the shared message-deletion operation for supplied message IDs. The outer DoOperation wrapper delivers the final result, including the no-work case, with no legacy fallback. These are separate request phases with no added atomicity or rollback. Recursive remote semantics and network execution were not verified; the delegated message-batch result limitation is linked separately.

Scope: Graph EmptyFolder operation phases.
