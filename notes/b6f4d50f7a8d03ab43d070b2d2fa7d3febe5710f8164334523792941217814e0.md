# The zoom-event rename preserves the concrete browser targets and scroll-step methods

The comm port renames six event strings to DoZoomEnlarge and DoZoomReduce. Mail passes event.target; source view and compose retain their known browser element and capture-phase listeners. The actual comm ZoomManager defines both called methods, including scrollReduceEnlarge, which subtracts 0.1 and clamps fullZoom at the minimum preference. Both the owned and fixed accepted method ranges retain the 0.1 step. This verifies consumer and receiver scope, not the unread engine event producer or a live zoom result.

Scope: Thunderbird scroll-zoom event consumers.
