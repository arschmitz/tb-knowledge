# Test constructed telemetry labels against the declared set

Historical 1173 chooses the label prefix from username before sessionId, but chooses a session token if no username token matches. If both preferences existed and that session-token branch matched, it would construct username_sessionToken, which is absent from its ten declared labels. The read tests do not combine both preferences. Scoped recommendation for a similar future classifier: test mixed-state branches against the declared label set. This is a conditional static gap in a removed probe, not an observed profile failure or a diagnosed backout cause. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
