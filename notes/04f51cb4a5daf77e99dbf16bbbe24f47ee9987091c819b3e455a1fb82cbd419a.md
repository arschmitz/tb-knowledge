# Recheck future notification candidates when their start time arrives

Current _updateNotificationManager also schedules the nearest future start time, clears an old timer, sorts parsed start times and calls the helper when the candidate becomes available. Locale-change debounce can postpone the update. These are later refinements beyond 587, checked only as current accepted source. A filtered list that is correct now does not by itself prove future items will become visible without another trigger. This batch did not fake time, run locale-change tests or fully study the later revisions.

Scope: Notification temporal behavior.
