## Remaining limits

The complete census is not a complete manual code review. AST traversal covers
standalone JavaScript only. Embedded markup scripts, preprocessed source, and the
22 parser failures are not covered by the syntax traversal. C++, Rust, Python,
CSS, markup, localization, IDL, shell, and build-file guidance uses checked
configuration or existing scoped review guidance; it is not an exhaustive syntax
study of those languages.

Path roles, configured ownership lists, generated-marker detection, and enclosing
method labels help retrieval but need manual context checks. The scan does not
resolve types, custom receivers, caller intent, all fixtures, or runtime behavior.
Effective configurations were evaluated with the installed paired Gecko plugins;
plugin versions and future configuration changes can alter results. No complete
Bugzilla or Phabricator discussion study was done. The provisional earlier review
lesson is preserved with its original uncertainty.

No unrelated source comments or code were rewritten. Raw manifests, scripts,
occurrences, configuration results, public checks, and checkpoints remain private
under the console knowledge directory. Shared guidance contains only reusable
source observations, deliberate rules, and explicit limits.
