# The folder owns lazy AutoSync state while the state keeps a weak owner

The generalized state constructor accepts nsIMsgFolder and stores do_GetWeakReference(folder). ExchangeFolder keeps the state in a RefPtr and creates it on first AutoSyncState access; GetAutoSyncStateObj returns an added reference. This avoids a direct strong backedge through that owner field. Call the lazy accessor when state is required rather than assuming the member exists. These selected edges do not prove full leak freedom, thread safety or that queue/download integration is already present. No lifetime or leak test ran.

Scope: AutoSync state constructor and Exchange folder lazy accessor.
