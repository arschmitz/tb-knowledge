# Single-server account types hide outgoing-only configuration fields

The accepted Account Hub configuration display hides the outgoing section for no outgoing server and for EWS, Graph or Exchange configurations. These single-server types also hide port details in this UI. That extends the historical Exchange/no-outgoing branch in entries 1197–1198. For this view, use the configuration model to decide which labeled groups are relevant. This is a limited current comparison, not a complete study of later Graph or EWS changes; live hidden-state accessibility and protocol creation were not tested. Full bug and review discussion remains pending.

Scope: Account Hub server-specific fields.
