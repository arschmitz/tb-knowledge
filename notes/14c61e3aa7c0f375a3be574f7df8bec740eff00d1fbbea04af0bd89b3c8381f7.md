# Clear tag state before rendering the next recycled card value

Current ThreadCardTags first hides all tag images and the overflow counter and clears its title. It then filters valid tag keys, shows at most three icons and uses cached Intl formatters for the title list and extra count. Empty or invalid keys return after clearing. Preserve the reset-before-return order when changing recycled card rendering. The older inline ThreadCard implementation was extracted into this component; do not teach its old field names as current.

Scope: mail/base/content.
