# Scope duplicate-import lookup to the destination and preserve caller-owned files

Import rejects a duplicate Message-ID in the exact destination folder by passing recursively=false to MailUtils.findMsgIdInFolder. Other callers retain the helper default of recursive search. The accepted import code removes a generated temporary file after the operation, but keeps a DOM File already linked to a real file through mozFullPath. Early read and duplicate errors occur before that final cleanup block. This batch has not established the temp-file ownership or shutdown behavior on every early error; preserve that question instead of claiming all paths clean up immediately. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/import-resource-scope.
