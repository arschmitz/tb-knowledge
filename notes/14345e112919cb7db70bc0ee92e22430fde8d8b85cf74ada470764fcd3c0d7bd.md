# Keep remote-content override state distinct from notification decoration

At accepted revision0b93f0f7a926ed94c8a0646f18b6734ec7cc0f6d, MsgHdrViewObserver computes canOverride from the negation of gEncryptedURIService.isEncryptedWithoutIntegrity(browser.currentURI.spec), then passes it to setRemoteContentMsg. The notification method supplies an empty button array when that value is false and decorates firstElementChild only if a button exists. The optional child guard does not grant permission to load remote content or make notification/buttonContainer optional. This is the inspected caller-to-notification boundary; the encryption service implementation, other callers and live policy outcomes were not audited. Source inspection only; no runtime or security test ran.

Scope: mail/base/content/msgHdrView.js.
