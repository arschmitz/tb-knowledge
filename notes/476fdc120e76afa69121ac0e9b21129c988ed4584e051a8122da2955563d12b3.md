# Keep backup database listener ownership explicit

OpenBackupMsgDatabase uses OpenDBFromFile and adds its listener itself so the folder can close the backup during OnAnnouncerGoingAway. This is an explicit caller responsibility, distinct from the normal FinishDBOpen pending-listener hook. Preserve that manual listener step when changing the backup opener. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
