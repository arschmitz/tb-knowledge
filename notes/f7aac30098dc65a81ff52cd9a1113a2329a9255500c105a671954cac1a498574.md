# The OAuth custom-scheme test delivers a generated callback directly to the observer

The helper generates the final authorization URL and calls the OAuth observer directly for net.thunderbird. It does not perform the operating system's custom-scheme redirect delivery. The success test checks resulting tokens, saved login fields and transport telemetry; the accepted test also replaces the OS capability query. The extracted redirect producer does not keep the removed fake-server username/password comparison. These are exact fixture boundaries, not a rule for all mocks or proof of real-provider behavior.

Scope: Thunderbird OAuth custom-scheme test boundary.
