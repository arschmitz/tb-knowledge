# A storage Calendar can still receive a read after `profile-change-teardown`

A storage Calendar can still receive a read after `profile-change-teardown`. Reading `params` on a finalized SQLite statement can assert or crash. Guard the statement's state before parameter access; a stream may swallow only the known shutdown error, not arbitrary failures. The regression test deliberately avoids first use before teardown. [commit](https://github.com/thunderbird/thunderbird-desktop/commit/42a5262682fdc8c60bc5232dfd959eb8401af632), [D317485](https://phabricator.services.mozilla.com/D317485).
