# The async extension factory is awaited despite a synchronous callback return annotation

CreateExtensionFn documents an Extension return value, while the actual factory declarations are async and its test handlers await createExtensionFn(manifest) before startup. The Promise return is absent from the callback annotation. Keep the function-valued factory, its Promise and the resolved extension object distinct in this harness. The local createExtensionFn name is accepted source usage, not a global suffix rule. This is static documentation/caller inspection; no test was executed.

Scope: Content-script test factory JSDoc.
