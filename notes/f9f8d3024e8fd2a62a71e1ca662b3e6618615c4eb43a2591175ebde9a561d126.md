# Keep the autosave-in-progress guard across awaited send preparation

CompleteGenericSendMessage distinguishes the AutoSaveAsDraft mode from an autosave already in progress. It sets the in-progress flag before awaited OpenPGP preparation and clears the flag in finally, including early failure exits. Draft-mode preparation still runs for the first autosave. The method then performs optional Autocrypt work and dispatches the retained cancelable compose-send-message event before sendMsg; cloud attachment ID cleanup still uses that event. Removing the old OpenPGP listener does not remove the event contract. These source facts do not prove all-mode concurrency safety or successful delivery. No autosave/send test was run.

Scope: mail/components/compose/content.
