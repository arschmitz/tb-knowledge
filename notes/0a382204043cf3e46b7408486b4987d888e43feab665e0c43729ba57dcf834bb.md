# Keep the flat Any Number search fallback scoped

Advanced address-book search enables Any Number for both Match-any and Match-all validity tables, then expands it into five phone fields. The dialog uses one flat query operator and only replaces a trailing and with or before appending the phone terms. This is an explicit compromise for the flat query format, not nested Boolean support: after other terms have already been serialized, and is no longer the URI suffix. The Bug corrects the earlier never-shown premise to Match-any-only. Preserve that limitation when reasoning about combined criteria. No search or provider test ran, and no new test was part of the patch.

Scope: Advanced address-book Boolean query construction.
