# EWS logging correlates retries with one queued-operation ID

The operation gets a UUID before enqueue, and request attempts reuse it rather than creating an ID for every send. Enqueue and receiver-completion logs carry the same ID, but completed is printed before result propagation and does not mean success. Enqueue failure returns earlier. This correlates log phases without adding elapsed-duration measurements or wire identity; the accepted shared sender architecture is a later phase.

Scope: EWS operation tracing and result boundaries.
