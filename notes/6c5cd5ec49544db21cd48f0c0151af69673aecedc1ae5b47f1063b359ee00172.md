# The experimental Calendar checkbox enables the event-view branch, not the edit dialog

The checkbox binds to the Boolean calendar.dialogs.new.enabled preference. Its adopted copy says to view events in the new dialog. The consumer also requires an event in view mode after the in-tab branch, so this setting is not an edit-dialog or all-item switch. The default remains false. Later ESR and experimental-settings visibility restrictions are separate changes; no rendered accessibility result was checked.

Scope: Calendar read-dialog preference UI.
