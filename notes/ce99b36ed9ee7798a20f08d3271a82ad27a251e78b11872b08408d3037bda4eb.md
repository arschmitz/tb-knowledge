# Package symbolic icon names match the installed application identity

Entry 778 installs a symbolic SVG alongside the existing sized PNG icons in the Flatpak hicolor tree. Current repack.sh uses ${APP_ID}-symbolic.svg in the symbolic/apps directory and ${APP_ID}.png in each size directory. Linux tray code separately tries bundled TB-symbolic.svg and default 256.png, then falls back to a desktop icon name. Manual asset naming proposal for these packaging paths: keep application IDs, symbolic suffixes, icon-theme directories and bundled file names distinct and preserve exact case. Adding an SVG to the source tree alone is not proof it reaches the package. The actual built package and desktop theme lookup were not exercised.

Scope: linux-icon-packaging.
