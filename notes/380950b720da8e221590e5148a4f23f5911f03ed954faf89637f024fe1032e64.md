# Today Pane changes its menu access key to P while keeping a separate F11 toggle binding

The historical localization fix changes the Today Pane submenu accesskey from T to P. Its parent menu consumes that localization, while the child visibility item has a separate todaypanekey command binding. Accepted current source retains P in a later Fluent entry and F11 in the key definition; Toolbars retains T in en-US. This is a scoped menu-mnemonic change, not a shortcut reassignment or a universal requirement that every menu access key be unique. Other locales, all menu conflicts and live cycling/expansion were not checked. Later Fluent migration is a separate phase. No keyboard, localization build or UI test ran.

Scope: Calendar en-US menu localization and shortcut distinction.
