# Save All completes the batch after per-file replacement choices

AttachmentInfo.saveAttachments confirms each existing destination. A declined replacement skips that attachment and continues later saves. After the loop, the helper dispatches attachmentsSaved with the directory path and returns that path, including a batch with skipped items. A canceled directory picker or the caught error path returns null before that event. Consumers need this completion meaning: the event marks the completed loop, while the user choices determine which files were written. Current filename deduplication and Fluent strings are later context. No filesystem, prompt or browser test ran.

Scope: attachments.
