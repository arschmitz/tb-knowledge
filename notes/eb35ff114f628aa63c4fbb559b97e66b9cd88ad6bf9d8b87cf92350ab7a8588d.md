# Wait for the document and image before measuring image layout

Historical OnMsgParsed waits for a document load promise and for an unfinished image before comparing widths. Current messageProgressListener still waits for document readiness, checks that the message is still displayed, and registers a once-only image load handler if necessary. Image-loaded and stylesheet/document-ready are separate conditions. Avoid a fixed timeout as a substitute for the actual readiness condition. The historical browser test waits for all images to complete; it was read, not run.

Scope: Message image readiness.
