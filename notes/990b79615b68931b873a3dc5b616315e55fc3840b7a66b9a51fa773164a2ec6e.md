# Release a paused discovery generator when cancelling the wizard

The email view aborts the controller before resuming a paused discovery stream with acceptRedirect false, catches the resulting rejection and clears the stream. It retains the abortable until the discovery path can inspect its aborted state. Merely hiding the loading view would not cancel work or release a yielded generator. The current unit cancellation task aborts before its first next call, so it does not prove every in-flight wizard cancellation race. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/components/accountcreation.
