# Use explicit seconds when testing folder recentness

The folder cutoff converts the 31-day millisecond window to integer seconds. Folder MRUTime fixtures explicitly use startTimeSeconds plus different offsets instead of relying on actions completing in different seconds. Current tests distinguish recent ordering, result limits and a separate name-sort request. MRUTime is last use; MRMTime is user move or copy activity or manual folder creation. Keep those properties and units distinct when naming fixture values. No sleep-based timing guarantee or tie policy is inferred. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Folder time units and fixture naming.
