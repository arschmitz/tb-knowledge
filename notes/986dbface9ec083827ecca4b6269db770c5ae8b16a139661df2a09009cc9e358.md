# Deletion enumeration and header lookup are separate database contracts

The added test verifies that deleteMessages removes the chosen keys from listAllKeys. Its getMsgHdrForKey failure assertion is commented out because legacy lookup may still return a deleted header. The fixed test retains that limit, and legacy lookup still tries its cache before a store lookup whose condition ignores hasOid. Review speculation about dependent callers was not traced. The assigned historical Panorama DeleteMessages is unimplemented; its later accepted removal loop is not proof that this exact historical test passed on both backends. No test ran.

Scope: Legacy and Panorama message database deletion tests.
