# Tag command ownership and folder keyword batching are separate changes

The relocation puts tag actions in commandController while context-menu checkbox events still pass their key and checked state to that controller. The original helpers batch only consecutive same-folder messages; fixed code later groups by folder with Maps and limits removal to known keys. Do not attribute that later batching algorithm or complete menu decoupling to the method move. The new-tag callback still updates stylesheet state before applying the tag. No tag UI, keyword write, test or build ran.

Scope: Message tag controller and context menu.
