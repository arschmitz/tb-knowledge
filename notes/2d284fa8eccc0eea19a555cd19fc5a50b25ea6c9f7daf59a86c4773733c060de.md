# readerDisplayAttachmentsInline exposes a global read-only reader preference

readerDisplayAttachmentsInline is a messengerSettings-permission protected types.Setting backed by mail.inline_attachments. Its getCallback reads that Boolean preference and its API options explicitly set readOnly:true. The schema documents supported attachments displayed inline. Current MIME setup passes the value into show_attachment_inline_p and has separate text-inline and quote-inline preferences. The new test checks true then false and levelOfControl:not_controllable via .get({}); it does not attempt extension writes or exercise rendered attachment visibility. Treat the returned value as the global preference, with actual MIME type/rendering conditions handled elsewhere. Keep this read-only property distinct from the later writable composeInlineSpellCheckEnabled setting.

Scope: mail/extensions/messengerSettings.
