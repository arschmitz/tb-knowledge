# News credential prompts keep server and newsgroup as distinct Fluent arguments

The original native migration chooses server-only or group/server credential text according to single-signon and passes named server/newsgroup arguments. Native formatting uses UTF8 buffers, checks its localization results and converts for the UTF16 prompt interface. Accepted later code formats the same named roles asynchronously in NntpClient and uses folder.localizedName for the group. Keep those phases and argument meanings separate; no authentication, credential-storage or prompt rendering result was run.

Scope: nntp-credential-fluent-argument-phases.
