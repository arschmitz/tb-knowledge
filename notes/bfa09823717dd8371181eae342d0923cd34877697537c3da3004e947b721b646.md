# Keep abort listener cleanup independent from install success

_installDirect attaches an abort listener using the stable cancel arrow field, then removes the listener and deletes _installer in finally. By contrast, email.mjs clears this.abortable only after installer.install resolves; a rejection bypasses that assignment. Scoped manual recommendation: use a completion-independent cleanup boundary for the view controller too if it must clear the abortable on failure. This is a source concern, not a reproduced cancellation defect. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: Account Hub add-on abort cleanup.
