# Standalone message reload handles view recreation separately from thread-pane setup

onCreatedView resets its loaded marker. When the normal threadTree/view path is unavailable, the about:message branch reloads a loading or loaded message in the fixed source, then returns. The landing checked only msgLoading; msgLoaded is a later refinement. Normal thread-pane column/sort/scroll restoration is a separate branch. The bug distinguishes own-folder stale-view repair from later parent-folder compaction behavior. Do not infer coverage for every compaction path. No message window or compaction ran.

Scope: Standalone message view lifecycle.
