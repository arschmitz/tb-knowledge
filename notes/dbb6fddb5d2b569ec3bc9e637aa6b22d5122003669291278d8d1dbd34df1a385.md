# The 2026 bundled notification change is shared data rather than a new fallback trigger

The landing adds the same four scheduled donation_tab objects to three branding resources, with identical post-state blobs. The fixed comparison contains only ESR 26 and the two end-of-year objects, so original Spring data and later removals remain separate phases. The actual loader reads the branding JSON; the accepted initializer has explicit cache, automation/force and updater-readiness gates. This data addition does not introduce those gates or prove a scheduled notification was shown. Date filtering, URL expansion and delivery remain bounded dependencies.

Scope: Bundled in-app notification data phases.
