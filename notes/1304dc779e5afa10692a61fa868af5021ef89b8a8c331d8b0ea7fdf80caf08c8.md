# Notification version targeting treats stars as anchored string wildcards

No-star values use exact string equality. Star values escape regex operators, expand each star to dot-star and anchor the whole string. checkProfile accepts any matching version alternative; an empty version array fails. Five added assertions check current-major matching and literal regex characters. This is not semantic-version ordering, malformed-payload validation or live notification delivery. No test ran.

Scope: In-app notification targeting.
