# Fetch host tools for macOS update verification through the toolchain dependency

The update-verify kind adds toolchain as a dependency and fetches linux64-libdmg for the macOS task. The current default worker is Linux and the task build_platform is macosx64-shippable. Keep execution host and verified target platform separate when selecting tools; the task name does not imply it runs on a macOS worker. No taskgraph generation or LZMA DMG validation ran here. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Update verification host-tool dependency.
