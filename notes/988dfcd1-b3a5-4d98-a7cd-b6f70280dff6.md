# Register cleanup last in setup

When writing or updating Thunderbird tests, make `registerCleanupFunction` the
last statement in the setup function. Keep one combined cleanup callback per
test file. Preserve the required order of cleanup actions.

This is a deliberate human instruction. It replaces the earlier instruction to
register cleanup before setup can fail. Automatic learning must not change it.

## Evidence

The human requested:

> register cleanup should also always be the last thing in the setup function

The request corrected the cleanup registration near the start of `add_setup` in
`mail/components/calendar/test/browser/browser_calendarEventCategoryRow.js` at
revision `c3eda32b4c44299da87bc5c015aad8b42e4bd6bb`.

## Validation and limits

The current test and active guidance were inspected. This note records the direct
human instruction. Validation of the source change is reported separately.
The instruction applies to future test changes and the current category-row test.
It does not require unrelated test edits.
