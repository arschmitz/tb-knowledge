# The Basic-header test workaround is separate from the later Necko-auth provider

The selected request path keeps AuthIdentity setup and independently adds an optional Authorization header; its credential helper constructs Basic from username:password. Fixed accepted send_request instead calls the server auth-header API, whose provider defers Basic and NTLM to Necko. This is a historical workaround and later disposition contrast, not proof of native realm correctness, a leak cure or a rule to always bypass challenges.

Scope: Protocol-shared Basic authentication phase boundary.
