# Apply folder-label visibility even when the stored value is unchanged

FolderTreeRow setters update their count/size text only when the value changes, but always apply persisted visibility afterward. Newly created rows and freshly populated Favorite rows can start with default values while still needing the current column preference. Value equality must not skip initialization of independent UI state. Accepted tests check empty new folder badges, changed contents and a Favorite row’s visible columns. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/base/content.
