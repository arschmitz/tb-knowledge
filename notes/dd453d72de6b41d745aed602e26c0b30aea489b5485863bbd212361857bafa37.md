# The generic Exchange client interface remains separate from its concrete transport

Both EWS and Graph bridges implement IExchangeClient, while distinct component contract strings select their concrete constructors. The owned MailGlue code retains the EWS contract and variable while requesting the renamed interface; the accepted endpoint later uses a dedicated telemetry recorder. The rename does not establish identical operation support: the owned Graph create-folder implementation still returns NOT_IMPLEMENTED. Keep interface identity, concrete transport choice and later refactors separate.

Scope: Exchange client interface and concrete component boundary.
