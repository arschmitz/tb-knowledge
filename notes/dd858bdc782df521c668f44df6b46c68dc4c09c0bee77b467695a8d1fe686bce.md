# Account Hub OAuth completion watches the hidden attribute before inspecting the account

The OAuth creation task replaces polling with a mutation wait on configFoundTemplate. It observes only the hidden attribute and resolves through the existing isHidden predicate before looking up the account. The task then directly asserts that the account exists and uses OAuth2; it separately waits for the success view. The patch adds no arbitrary delay and does not establish that timeout duration caused the intermittent failure. This is the local test contract, not a rule for every asynchronous wait.

Scope: Account Hub OAuth browser test.
