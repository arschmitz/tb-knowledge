# Guard optional text before normalizing calendar search values

833 excludes an untitled event from a nonempty title search instead of calling normalize on a missing title. Clearing the search still clears filtering. The newer accepted implementation searches SUMMARY, DESCRIPTION, LOCATION and URL and guards each value before normalization. Apply the null guard to each optional field, not only to the search input. This current widening is not counted as a later fully reviewed landing.

Scope: Calendar unifinder nullable text.
