# The yearly every-day recurrence branch discards its formatted rule string

The YEARLY branch for BYMONTH plus every weekday calls recurrence-yearly-every-day-of but does not assign the returned string. ruleString begins unset and is later passed into the detail formatter. This remains in fixed accepted code. The changed dialog assertion uses the same formatter for its expected text, and the focused unit file explicitly lists that formatter's coverage as missing. They do not independently verify this branch. No Calendar or localization runtime was exercised, so exact visible failure behavior remains unverified.

Scope: Calendar recurrence formatter result flow.
