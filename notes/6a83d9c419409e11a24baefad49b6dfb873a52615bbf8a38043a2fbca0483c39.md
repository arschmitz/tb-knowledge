# Wait past the intermediate about:blank load before resolving a tab

The Marionette tab collector registers a named capture listener and leaves it active for about:blank. It removes that same listener and resolves only after a different document loads. once:true would consume the intermediate event. Promise.withResolvers exposes the promise and resolver without nesting this ownership in an executor, and Promise.all waits for every loading content tab. Current code lives in scripts/get_tabs.js, not the historical tabs.js path. No Marionette run or load-race reproduction was made here.

Scope: Marionette loading and promise syntax.
