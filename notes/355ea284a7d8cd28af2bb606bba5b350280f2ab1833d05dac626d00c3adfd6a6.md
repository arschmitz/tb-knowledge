# The Windows helper includes local initialization before callback macro expansion

The installer port packages uninstaller_helpers.nsh, includes it after shared.nsh, then expands the UI callback helpers. helper.exe .onInit calls UninstallOnInitCommon. Its PostUpdate branch first checks the uninstall log and leaves required elevation to the launcher. PostUpdate itself is an exact move from the shared header. The local include, caller and package inputs support this integration; they do not establish behavior of the unpaired Gecko headers or a successful Windows build.

Scope: Thunderbird Windows installer integration.
