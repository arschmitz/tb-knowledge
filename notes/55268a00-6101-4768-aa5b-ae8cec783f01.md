# Distinguish missing script filters from an empty ID array

For compose and message-display scripting, getRegisteredScripts() with no ids filter lists all scripts; ids: [] returns none, and unknown IDs are ignored. unregisterScripts() with no filter removes all; ids: [] removes none. Unknown IDs make unregisterScripts reject before any selected script is removed, including when an existing and a missing ID are mixed. Bug 1896870 matched the established content-script behavior and tests all three script types. This distinction is still present in current ext-scripting-tb.js.

Scope: Extension scripting API.
