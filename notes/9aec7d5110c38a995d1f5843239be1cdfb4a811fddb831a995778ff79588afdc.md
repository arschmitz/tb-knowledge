# Match mobile icon names to the size directory and consumer

The owned mobile icon integration uses mobile-export.svg and mobile-import.svg under sm and lg directories, with 16- and 24-pixel size families. Current packaging still lists both sizes. The app menu uses --icon-mobile-export-sm, while the preferences category loads the lg path and has an empty decorative alt. Scoped naming pattern for this icon family: dash-separated asset names, lowercase size directories and --icon-name-size CSS variables. Historical duplicated export variable declarations are not a style rule; current declarations have one export variable per size. Imported SVG geometry is excluded from style conclusions.

Scope: mail/themes/shared.
