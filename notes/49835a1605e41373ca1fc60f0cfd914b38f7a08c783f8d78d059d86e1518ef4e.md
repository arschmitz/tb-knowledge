# Treat deleted-folder close differently from an ordinary folder switch

Current DBViewWrapper.close takes an options object, not the historical boolean argument. leavingFolder false skips onLeavingFolder callbacks and avoids EndFolderLoading calling back into deleted storage. _folderDeleted uses that mode for its displayed folder. It also ignores Trash-folder deletion notifications used during empty-trash. Preserve these exceptions when adjusting deletion cleanup; they are separate from clearing visible message selection.

Scope: mail/modules/DBViewWrapper.sys.mjs.
