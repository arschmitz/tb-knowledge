# The initial run-task Docker directive change leaves the repack fetch path unchanged

The initial two-Dockerfile fix replaces an explicit missing fetch-content source include/ADD with include-run-task. Its historical repack scripts still invoke /scripts/fetch-content. The fixed source retains the directive, adds COPY globs that exclude the injected run-task directory and uses /builds/worker/bin/fetch-content in both consumers. Keep those later path/glob changes separate from the initial D-task fix. The directive comment does not prove its upstream expansion, image contents or a successful package task.

Scope: Flatpak and Snap image/repack tool paths.
