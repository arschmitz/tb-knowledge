# The about:support moz-src migration keeps script consumers and packaging aligned

The Thunderbird about:support migration registers six content scripts in MOZ_SRC_FILES, updates the document to their exact comm moz-src URLs and imports the selected Windows/Mac/Unix module from the same source-resource scheme. The JAR keeps the Thunderbird document and global-document override while dropping the individual script entries. The unit test loader follows accounts.js to its new URL; its existing account/privacy assertions are unchanged and are not a full-page or cross-platform packaging test. These are exact source contracts without a fresh build, unit test or UI run.

Scope: about-support.
