# The new CMS key-size assertion has no diagnostic message

The new GetContentEncKeySizeBits method checks that the NSS key-size value is nonnegative with a one-argument MOZ_ASSERT. It supplies no message stating that expected behavior. The accepted source retains that exact assertion. A diagnostic stating that the content-encryption key size should be nonnegative would satisfy the deliberate assertion-message rule without changing this condition. No assertion failure or native execution occurred, and no unrelated assertion was changed.

Scope: S/MIME native assertion diagnostics.
