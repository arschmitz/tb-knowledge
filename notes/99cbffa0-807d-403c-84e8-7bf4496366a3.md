# Wait for message reload after display preference changes

Changing mail.addressDisplayFormat reloads the displayed message. The browser_preferDisplayName test must await messagePaneBrowser after each change before checking rows or finishing. The Bugzilla issue was missing code coverage from windows that had not completed loading; this patch addressed one test path but the bug had already needed another listener cleanup.

Scope: message browser tests.
