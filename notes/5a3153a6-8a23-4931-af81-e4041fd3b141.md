# Manifest V3 folder APIs omit nested subfolders unless requested

The 2024 change set includeFolders/includeSubFolders false by default for Manifest V3 because recursive folder trees can be large. Manifest V2 retains true defaults for compatibility. Tests use explicit true where they still assert full trees and separately assert the new omitted subFolders default. Current accounts schema calls the option includeSubFolders and covers getDefault too; use the current name and check the specific method and manifest version before assuming a default.

Scope: WebExtension folder API payloads.
