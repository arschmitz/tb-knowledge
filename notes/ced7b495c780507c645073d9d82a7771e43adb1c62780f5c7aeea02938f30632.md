# Address Book Hub rollout and legacy test overrides have separate preference scopes

The initial rollout enables mail.accounthub.addressbook.enabled under EARLY_BETA_OR_EARLIER and keeps false otherwise. Two legacy test manifests explicitly override it false, preserving their legacy menu/setup expectations rather than adding enabled-Hub assertions. At the accepted later revision, the profile default is true while those harness overrides remain. Production rollout, test setup and later TODO work are different scopes. The menu harness moved later, and no fresh account-creation, UI or browser test was run.

Scope: account-hub-addressbook-rollout.
