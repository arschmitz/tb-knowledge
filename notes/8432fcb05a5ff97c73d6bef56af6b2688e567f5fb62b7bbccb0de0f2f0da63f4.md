# Server URI migration keeps a synchronous caller around asynchronous password changes

migrateServerUris attaches catch and finally to migratePassword, then calls spinEventLoopUntilOrQuit with a finished predicate before continuing URI migrations. onUserOrHostNameChanged calls that wrapper synchronously. This describes the inspected bridge and logged-error continuation, not an atomic transaction, general safe nested-loop pattern or proved shutdown/reentrancy behavior.

Scope: Incoming-server migration completion.
