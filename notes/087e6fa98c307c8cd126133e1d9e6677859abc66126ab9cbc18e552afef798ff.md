# The local NSIS registry preference helper depends on definition order

Thunderbird supplies GetInstallerRegistryPref locally after the upstream helper was removed. Its scripts include shared.nsh before inserting the function and keep InitHashAppModelId earlier because the function uses AppUserModelID. The reader uses the HKCU Installer/model-ID subkey and returns string true for a successful nonzero DWORD read, otherwise false. Keep the NSIS stack wrappers and definition order distinct from runtime preference consumers. The exact upstream caller/removal and native build remain unchecked; no installer or registry test ran.

Scope: windows-installer-nsis.
