# LDAP prompt callers consume the returned password object without adding a cancellation exit

Both callers select rv.password from the awaited result when rv.ok is true and otherwise return null. The inout object remains an argument but is no longer read for the password. Their actual initialization paths still call simpleBind with that result; the port adds no cancellation early return. LDAPListenerBase also initializes its operation before awaiting the prompt and preserves its separate GSSAPI branch. The async helper's documentation should name the Promise and distinguish a false status from rejection, which is not caught here. No native prompt or LDAP behavior was executed.

Scope: LDAP password prompt result port.
