# Update the CTA tooltip when its visible text changes

Entry 1514 sets the notification button title from the cta attribute. Current attribute handling updates visible text, visibility and title, while test_cta_title checks two successive values. Proposed rule for this CTA: update derived tooltip text on replacement, not only creation. A title tooltip is not a substitute for visible text or a verified accessible name; optional CTA visibility has a separate existing contract. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: In-app notification CTA tooltip.
