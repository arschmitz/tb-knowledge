# The new listed-message sorting task checks the folder API rather than the mail-tab override

test_listed_messages_as_sorted constructs sort options but passes them to browser.messages.list(folder.id, sortOptions). Its expected orders exercise the shared sorting helper through the folder API. The older as-viewed task calls mailTabs.getListedMessages without options. These tests do not directly establish the new mail-tab override branch, unchanged UI order after an override or sorted pagination.

Scope: WebExtension message-list browser tests.
