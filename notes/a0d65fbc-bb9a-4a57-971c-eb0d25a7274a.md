# Truncate UTF-8 at a complete character within the byte limit

A mail header byte limit can fall inside a multibyte UTF-8 character. Advance one character at a time and return the prefix before the character that exceeds maxBytes or is invalid; never emit a partial character.

Scope: mail-headers.
