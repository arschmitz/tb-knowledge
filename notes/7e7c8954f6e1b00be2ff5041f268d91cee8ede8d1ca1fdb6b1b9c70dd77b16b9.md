# Keep the mailbox offset origin explicit when reusing the stream

Current MsgOffset documentation states that the offset is relative to the underlying stream position at construction. It is an absolute file offset only if the underlying stream starts at the beginning. Preserve that origin contract for callers that seek before creating the parser. The inspected large-file test checks download, database size, and separate message keys; it is not a direct assertion of this relative-offset API.

Scope: mailnews/base/src.
