# Header borrowing reduces intermediate ownership without removing native string conversion

1266 changes header-trait strings to Option<impl AsRef<str>> and recipient collections to iterators over borrowed Mailbox values. Accepted protocol_shared retains that shape, while safe XPCOM setters still convert values into nsCString before native calls and lists still serialize/join. A scoped Rust API pattern is to borrow at the adapter boundary and allocate where the destination actually needs ownership. This is not a zero-allocation or measured-performance claim; current populate_from_message_headers callers were not found by the bounded Rust search. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
