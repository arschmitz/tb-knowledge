# URL completion finalizes MIME work that still has its message header

OnStopRunningUrl finalizes with null after a failed URL exit or while _msgHdr is still present. This covers a pending MIME callback even when the URL status is successful. Normal successful request finalization clears that header after callbacks, so a later successful URL completion skips. This is a specific pending-state fallback; callback exceptions and failed later URL exits are separate conditions, and no general exactly-once or runtime cure is established.

Scope: Gloda MIME listener completion.
