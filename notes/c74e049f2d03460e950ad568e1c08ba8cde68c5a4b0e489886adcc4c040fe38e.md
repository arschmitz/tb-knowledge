# Linux titlebar and spaces-toolbar corner rules share the transparency feature gate

The patch scopes custom-titlebar drawing and spaces-toolbar corners to -moz-gtk-csd-transparency-available. Normal non-tiled window drawing and the rounded-bottom preference remain additional conditions. The spaces toolbar uses a logical border-end-start-radius, replacing separate directional bottom-corner branches. The checked current files retain the media gate but use the later tiled attribute and additional logical radii. Keep the feature, window state and preference conditions together in this component; no general CSS rule or live GTK/Wayland/X11, RTL, theme or accessibility result follows from static selectors.

Scope: Linux client-side window-decoration CSS.
