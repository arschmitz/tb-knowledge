# Canonical timezone IDs are a picker list, not a validation whitelist

TimezoneDatabase requests canonical ICU IDs to avoid redundant choices in user-facing lists. Its IDL explicitly says that this list is not restrictive. CalTimezoneService can separately resolve an ID that is not already in its cache. Do not reject an imported timezone only because it is absent from the canonical picker list. The current Windows-to-IANA conversion is later comparison context, not another fully studied chronological landing. These paths were inspected statically. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
