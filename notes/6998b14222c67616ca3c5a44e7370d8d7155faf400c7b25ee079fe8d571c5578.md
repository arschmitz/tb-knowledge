# CSS parser allowlist objects need a source or error predicate, with multiple predicates combined

Accepted ignoredError fails a catch-all item when neither sourceName nor errorMessage is present; it permits a source-only entry such as imported CodeMirror and combines both predicates when both are supplied. For a known upstream parse exception such as 1457, retain the bounded source regex and specific error regex. This is a scoped manual test-maintenance recommendation, not a blanket requirement that every imported stylesheet exception contain both fields. This is source/test-code inspection only.
