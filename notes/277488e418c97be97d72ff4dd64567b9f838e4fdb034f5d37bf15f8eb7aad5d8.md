# Retiring NNTP posting wrappers does not remove the file-based posting service

1933 removes nsINNTPNewsgroupPost, the URL messageToPost member, its binding/build entries and the unused create_post test helper. The accepted nsINntpService still declares postMessage with nsIFile, and NntpService reads that file line by line, dot-stuffs lines beginning with a dot, sends CRLF and ends with a single-dot line. Treat the removed object wrapper as historical; do not claim NNTP posting itself was removed. The current groupNames parameter is not used in the inspected body, so no new routing guarantee is inferred from that argument. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: NNTP posting API retirement.
