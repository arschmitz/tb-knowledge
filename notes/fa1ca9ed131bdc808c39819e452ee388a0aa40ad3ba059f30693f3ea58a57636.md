# Preserve scroll position and focus when the dark toggle reloads a message

The click handler stores the current scrollTop before changing the dark-reader preference. MsgLoaded restores a nonzero saved position with instant scrolling and resets the saved value. The current test waits for the reload, then checks scroll position and focus on the message browser. Keep that completion check when changing the toggle; zero is handled by the existing falsy guard, not a separate restore call. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.
