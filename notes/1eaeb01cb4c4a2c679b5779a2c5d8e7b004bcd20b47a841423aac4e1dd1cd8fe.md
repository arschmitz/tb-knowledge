# Mailbox cache lookup still requires a database associated with its real folder

Accepted GetMsgHdrForKey first obtains a cached database for the file path, then checks its folder. A missing database or folder association triggers an account-folder search using nsIFile.Equals and OpenFolderDB. CachedDBForFilePath is an already-open lookup, not permission to create a summary for any arbitrary file. The inspection does not benchmark folder enumeration or exercise failed databases. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/local/src.
