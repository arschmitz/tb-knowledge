# The initial related-item removal test omits messages from 55 assertions

The new 485-line test contains 59 Assert calls. Those assertions need nonempty messages that state the expected behavior so a failure identifies its intended result. Four checkLoginsCheckbox assertions already supply messages. This is the original test's diagnostic gap; the source was parsed and read, not executed, and the finding is not based on a missing should word alone.
