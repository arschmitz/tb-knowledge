# Untagged-only quick filtering bypasses selected tag criteria

The public none mode maps to internal NONE. That branch adds a Keywords IsEmpty term and returns before selected-tag inclusion/exclusion logic, selecting messages without any tags rather than messages that merely lack chosen tags. The public schema explicitly says supplied filters are ignored. The new extension fixture uses an empty criteria map, so that case does not directly assert ignoring a conflicting nonempty map. No search was run.

Scope: Quick Filter Bar untagged-only search.
