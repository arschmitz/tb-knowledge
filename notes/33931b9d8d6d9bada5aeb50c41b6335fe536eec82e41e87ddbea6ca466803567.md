# Operation Debug logging can bypass the separate network-payload output gate

The removed enum Debug hid serialized content unless the network-payload environment variable was present. The replacement QueuedEwsOperation Debug prints inner directly, and both the original runner and accepted shared runner log that Debug output at info level. CreateItem and its message item types derive Debug and include message-data fields. Therefore a gate around serialized request/response logging does not also gate this structured operation path. This is a static path finding; no user payload, enabled deployment logger or runtime disclosure was observed.

Scope: EWS queue structured logging.
