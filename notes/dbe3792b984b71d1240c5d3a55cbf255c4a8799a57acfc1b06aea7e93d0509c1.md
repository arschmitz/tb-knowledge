# The localization schema port updates both validation checkpoints

The comm localization port imports L10nDescriptionSchema and supplies that symbol to both ValidateSchema calls in the transform sequence. One checkpoint remains before dependency/keyed/chunk processing and the second remains after chunk_locales. Both ordinary and shippable localization kinds select this module. The next import-order correction is a separate landing, as are later signing and signoff changes. This proves the comm call sites and selected module, not the unpaired Gecko schema export, validator implementation or a successful generated task graph.

Scope: Taskcluster comm localization transform integration.
