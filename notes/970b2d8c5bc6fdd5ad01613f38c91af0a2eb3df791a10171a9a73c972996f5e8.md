# Calendar subscription rows refresh after the properties window closes

The properties opener returns its dialog window. The subscription caller matches that exact window in domwindowclosed, removes its observer and then rereads the calendar name and color for the row. A separate opener-close branch closes the properties window and relies on the child-close notification for observer removal. This records the local ownership and refresh conditions; no native closure-order or focus result was tested.

Scope: Calendar subscription properties-window ownership.
