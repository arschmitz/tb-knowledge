# Treat dark-toggle visibility as a CSS condition rather than a reload event

At the accepted endpoint the toggle is shown only in dark color scheme with mail.dark-reader.show-toggle, and prefers-contrast hides it. The current visibility test waits for CSS visibility and explains why high-contrast theme switching may not reload the message or fire MsgLoaded. Keep preference visibility, color scheme and conversion enabled state as separate inputs. This does not validate rendered contrast or accessible naming. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending.
