# Wait for Calendar delayed startup

A recorded `browser_viewTelemetry.js` setup timeout was attributed to default-calendar mutation racing Calendar delayed startup. The repair awaited `window.delayedStartupPromise` before telemetry checks or Calendar state changes because delayed startup loads the Calendar component and initializes `calendarDeactivator`. Check that the current timeout has this startup signature before reusing the fix; a focused pass alone does not prove an intermittent is gone.

Scope: Calendar browser tests.
