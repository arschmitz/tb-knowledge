# Closing a menu stack is an awaited operation that consumes the array

close_popup_sequence pops each popup from the supplied array, hides it and awaits the popup helper before taking the next item. Callers must await this asynchronous stack closure before later operations. click_menus_in_sequence also awaits it before returning an empty array when it does not keep menus open. Preserve the destructive reverse order; the patch does not remove every fixed delay or prove that removing focus is harmless on every platform.

Scope: browser shared menu test helpers.
