# Test favorite unified folders through mode removal and rebuilding

The accepted browser test marks a smart Inbox favorite, checks its synthetic-server parent and row, removes and re-adds the modes, then clears the flag and repeats mode changes. This distinguishes live updates from initialization persistence. The assertion helper waits for idle, expands rows, waits for frames, and compares URI order. It does not test process restart or on-disk preference persistence. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
