# Use the shared popup-event API after retiring the local wrapper

Entry 1608 removes wait_for_popup_to_open and changes its test callers to BrowserTestUtils.waitForPopupEvent(popup, "shown"). Current account-actions coverage keeps that explicit popup/event call, and the bounded current query finds no old helper in mail/test/browser. A scoped test-maintenance recommendation is to use this shared helper and name the expected event directly. Some inspected calls still wait after the click, so this landing does not prove every waiter is armed before its action. This is static source and test-code inspection.
