# Include the rejected space URL in its boundary error

D229975 review accepts while asking the URL validator to include the invalid URL for easier diagnosis. The actual historical and fixed getNativeTabProperties code distinguish a missing URL from an invalid resolved URL and include the latter value in the thrown error. Keep this narrow API-boundary diagnostic when changing the converter. This is not permission to log message bodies or arbitrary sensitive inputs, and no invalid-URL runtime was executed.

Scope: Spaces API conversion diagnostics.
