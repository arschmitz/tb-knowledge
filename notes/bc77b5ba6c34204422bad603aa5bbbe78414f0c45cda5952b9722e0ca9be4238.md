# Archive tests reset identity granularity and choose the expected year folder explicitly

The archive file cleanup sets all identities back to per-year archive folders. The recent-menu task derives the year from its selected message and opens that named archive child rather than the first descendant. This prevents the test from assuming another file left archive settings and folder order unchanged. Cleanup restores a known value, not each identity’s prior value. Direct assertions check recent-menu count and label; no reordered suite ran.

Scope: Archive and recent-menu test isolation.
