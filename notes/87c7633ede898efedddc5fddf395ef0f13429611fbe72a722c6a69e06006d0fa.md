# Document the nullable semantic link node used by canNavigate

D232156 requests documenting a possibly missing link node and questions removal of conditional chaining. The actual landing and fixed canNavigate declare {?DOMNode} linkNode and use linkNode?.getAttribute("target"). With no target, the function permits default navigation; otherwise it checks for an existing named browsing context. Preserve this scoped nullable caller contract when changing the semantic-link helper integration. Done flags alone did not establish adoption, and no navigation runtime ran.

Scope: Link click actor nullable node contract.
