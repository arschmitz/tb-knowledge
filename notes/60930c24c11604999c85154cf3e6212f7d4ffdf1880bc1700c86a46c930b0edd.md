# Thunderbird packaging includes moz-src resources beside ordinary modules

Entry 2067 ports an upstream package-manifest entry for @RESPATH@/moz-src/* beside modules and actors. The fixed accepted Thunderbird installer manifest retains it. A moz-src import may need source-resource packaging as well as source/module registration; inspect the actual build output before calling a missing-resource issue fixed. This is one Thunderbird manifest observation, not proof of all platform packages or an upstream behavior check. No package/build/runtime test ran.
