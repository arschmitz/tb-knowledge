# Thunderbird selects the upstream password-manager metrics file as interesting

The selected configure change adds toolkit/components/passwordmgr/metrics.yaml to MOZ_GLEAN_INTERESTING_METRICS_FILES. The accepted configuration retains it. This differs from registering comm-owned definitions in MOZ_GLEAN_EXTRA_METRICS_FILES; it does not by itself establish metric fields, retention, recording conditions or a successful migration.

Scope: Thunderbird password manager telemetry build selection.
