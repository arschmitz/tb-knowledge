# MSIX association arguments distinguish news from direct file and calendar input

The owned manifest passes a quoted EML/ICS file, mid URI or webcal/webcals URI directly, while nntp/news/snews receive -osint -mail. Its unchanged mailto uses -osint -compose. The inspected Win32 mappings support the direct-open versus news/compose distinction, but do not list snews separately. These are declared dispatch arguments; no Windows package registration or launch was verified.

Scope: Windows MSIX association dispatch.
