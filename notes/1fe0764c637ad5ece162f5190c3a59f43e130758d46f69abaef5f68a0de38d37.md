# Release a temporary message selection without invoking the scrolling setter

threadPane.releaseSelection restores with notify false. restoreSelection then sets the underlying selection currentIndex and updates its classes instead of calling threadTree.currentIndex. The widget setter always scrolls a valid row into view. Preserve this difference between bookkeeping and visible navigation: disabling smooth scrolling still scrolls, while the direct path avoids it. The historical test changed sort setup but added no direct scroll-position assertion.

Scope: mail/base/content.
