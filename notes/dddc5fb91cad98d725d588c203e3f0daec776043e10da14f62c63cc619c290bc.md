# The send-report contract instantiates a packaged JavaScript class

Part 3 keeps messengercompose/sendreport's contract ID while replacing its native type/header registration with MessageSend.sys.mjs and constructor MessageSendReport. The build packages that module and component manifest, and the actual message-send caller creates the contract, resets it and assigns delivery state. Native source removal and registration are one integration change; they do not prove a successful build or live component activation.

Scope: Thunderbird send-report component migration.
