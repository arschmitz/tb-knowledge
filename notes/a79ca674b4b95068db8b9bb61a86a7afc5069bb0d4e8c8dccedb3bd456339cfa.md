# Preserve chrome font and collapse behavior after upstream stylesheet movement

The owned common.css port restores -moz-box-collapse: legacy on :root and applies font: message-box only outside .system-font-size. It still imports the Gecko shared stylesheet and Thunderbird layout stylesheet. Check these explicit local rules when an upstream stylesheet moves behavior; do not assume importing the upstream file supplies the prior chrome contract. The upstream change and rendering are unverified. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Thunderbird common CSS integration.
