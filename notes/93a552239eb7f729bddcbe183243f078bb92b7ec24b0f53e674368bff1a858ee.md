# Sort recent folders before applying the result limit

getMostRecentFolders collects every folder newer than the cutoff, sorts descending with b.time - a.time, then slices to aMaxHits. This also sorts results when fewer than the limit exist. The initial 1231 landing used a Boolean comparator; the fixed accepted source uses a numeric difference. Copy the current numeric comparator in this function family, not the historical Boolean form. Equal-time ordering and unusual negative limits were not independently tested here. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Recent-folder ordering.
