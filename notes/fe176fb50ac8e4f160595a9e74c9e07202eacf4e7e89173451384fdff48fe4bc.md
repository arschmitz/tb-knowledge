# Folder type definitions are shallow-copied

At revision d15c88407bf2ebb1363d33567fefa9ca43643178, SmartMailboxUtils.getFolderTypes returns a new array with a shallow copy of each folder-type object. Changing the returned array or assigning properties on a returned object therefore does not change the module's definitions. This does not establish deep copying of any nested values. This is static source evidence for this helper, not a general style rule or runtime validation.

Scope: Smart mailbox folder types.
