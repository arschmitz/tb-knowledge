# The Add-ons menu skin targets the button part

The change styles panel-list separately and moves item styling to panel-item::part(button), with the trash image on the remove-action button part. Thunderbird's actual Add-ons loader injects this stylesheet. Accepted CSS retains the receiver selectors but later changes border and hover/active tokens. The paired engine widget/part implementation and live keyboard, focus, contrast and accessible-tree behavior are not established by these local selectors.

Scope: Add-ons Manager menu selector scope.
