# Missing detached MIME signature data is an explicit bad-signature outcome

In the inspected pgp-signature completion branch, empty mimeSignatureData sets exitCode=-1, creates a DecryptVerifyResult, sets BAD_SIGNATURE with Signature data missing, sends status if a sink is available and returns before RNP.verifyDetached. Earlier guards can return for raw/incomplete/disallowed/background contexts. Preserve this explicit missing-part outcome without calling it a verified signature, and do not generalize it to all MIME or inline-signature handling. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: OpenPGP missing signature.
