# Do not rely on the removed extensions.legacy.enabled default

Bug 1852699 removed the Thunderbird default pref extensions.legacy.enabled and its comment that said it allowed legacy XUL/XPCOM extensions. D210020 accepted this specific dead-code removal. The old pref is absent from the current checkout search. Treat the 2024 default as historical; new extension work should use current extension APIs and should not assume this switch enables legacy add-ons. The broad Bug 1852699 has many unrelated cleanup patches, so this claim applies only to this preference.

Scope: Extension preferences.
