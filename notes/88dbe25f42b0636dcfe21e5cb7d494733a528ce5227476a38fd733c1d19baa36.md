# The Flatpak channel reland omits an empty desktop VERSION_FLAG argument

The reland builds desktop_args as a shell array, appends VERSION_FLAG only when nonempty and forwards the quoted array to build_desktop_file.py. The earlier addition passed the empty flag as a positional argument. The checked accepted repack retains this conditional array construction. Existing identity lessons cover why project-selected flags differ from APP_ID and stable/beta branches; this lesson adds the exact reland phase and optional-argument boundary. No parser execution, package build or launch was tested.

Scope: Flatpak optional desktop generator arguments.
