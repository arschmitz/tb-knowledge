# Wait for subscription row identities rather than a transient row count

1104 replaces a three-row wait with the intended final identities: Baz absent, Foo present and Foo/Subfoo present. A remove/add update can temporarily have the expected count with the wrong rows. The test then checks both server subscription flags and visible folder rows. Use the final domain objects in this wait instead of a count that can match halfway through updating. The reported ordering was not replayed here.

Scope: IMAP subscription final-state wait.
