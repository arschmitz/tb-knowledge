# Recipient lookup checks effective expiry only in recipient mode

findKeyByEmail builds key information and rejects keyTrust r/e in either mode. Recipient mode additionally checks effectiveExpiryTime, whose existing producer accounts for encryption-capable subkeys and primary expiry. Zero is non-expiring in isExpiredTime. The new verified-fixture test expects recipient lookup to fail while unrestricted lookup still finds a handle; it does not execute encryption or prove every native expiry case.

Scope: OpenPGP recipient key candidate filtering.
