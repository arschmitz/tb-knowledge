# Live thread repositioning adds Received mode and respects the root-sort preference

On new headers, normal and search views allow thread movement for Date or Received only when mailnews.sort_threads_by_root is false. The existing equality compares the incoming Date accessor with GetNewestMsgDate; the patch does not add a separate incoming dateReceived lookup. The actual sort-key consumer also distinguishes aggregate-thread and per-message Received modes. Keep live movement, full sort values and root anchoring separate; the mode name alone does not prove every timestamp-ordering case. No native test ran.

Scope: Native threaded DB view live-update ordering.
