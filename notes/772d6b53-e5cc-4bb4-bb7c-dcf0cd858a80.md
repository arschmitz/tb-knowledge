# Notify folder listeners on both delete success and failure

Exchange delete or move operations finish asynchronously. Emit kDeleteOrMoveMsgCompleted after local deletion succeeds and kDeleteOrMoveMsgFailed on either failure path so folder listeners can leave their pending state.

Scope: exchange.
