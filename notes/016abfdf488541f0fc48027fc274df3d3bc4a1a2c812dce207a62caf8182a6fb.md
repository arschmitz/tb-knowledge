# Attachment File construction requests a byte-valued parser string before copying bytes

MsgHdrProcessor defaults strFormat to unicode, while getAttachmentFile copies each body character code into one Uint8Array byte. This caller therefore requests binarystring explicitly. The added non-IMAP fixture directly checks returned UTF8 XML text containing ö through File.text; it does not assert exact byte length or every attachment/protocol combination. Keep decoded text, byte-valued strings and the File consumer contract distinct.

Scope: extensions-get-attachment-file-binary-string-contract.
