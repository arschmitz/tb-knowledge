# Keep zero-based locale arrays separate from one-based recurrence and DOM values

Formatter weekday arrays start at Sunday=0 and month arrays start at January=0. Recurrence pickers display those names but store weekday/month values one higher; BYMONTH conversion subtracts one. The minimonth month attribute is zero-based, while month-view date cells store month+1. CalendarTestUtils documents its public month argument as one-based and converts it when scrolling. The later print correction removes an accidental +1 before indexing shortWeekdayNames. State the index base at each boundary and test it instead of inferring it from the label. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: calendar/index-base-contracts.
