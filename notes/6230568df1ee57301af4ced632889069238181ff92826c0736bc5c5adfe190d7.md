# Preserve distinct test and fixture names within each test family

The inspected work uses test_qrExport.js for unit coverage and browser_qrExport.js for the browser pane. The message regression uses test_ext_messages_bug_1918925.js for issue traceability, while the binary key fixture encodes the key ID and failure property in its filename. The drag task names the rejected input and action as test_directory_drag_and_drop. Manual naming proposal: follow the local runner prefix and add a useful behavior, component or bug identifier. These accepted mixed patterns do not establish one repository-wide dash or camel rule, and bug-number filenames do not replace assertions of behavior.

Scope: thunderbird/test-file-naming.
