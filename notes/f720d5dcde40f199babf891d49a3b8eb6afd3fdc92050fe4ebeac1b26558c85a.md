# Calendar sidebar header buttons explicitly route state through their modeboxes

Task and calendar header buttons forward click events to their matching modeboxes. togglePane toggles checked on event.target; the shared header class excludes children from pointer targeting. setVisible applies mode/collapsed state, persists per-mode choices and updates refcontrol checked/disabled. The inspected controls do not set aria-expanded, and both images retain the same toggleCalendarIcon ID; the inspected code uses class/event-target contracts instead of that ID. These are static control boundaries, not a live accessibility or rendering result.

Scope: Calendar sidebar header control and state flow.
