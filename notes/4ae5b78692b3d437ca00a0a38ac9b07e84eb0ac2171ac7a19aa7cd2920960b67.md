# The original Calendar reload check clears its loading flag before the lookup

The original helper sets #loading to false before testing #reload and is called before awaiting calendar.getItem. That ordering leaves the flag clear during the lookup even when no reload was requested. Accepted code first returns false when no reload is pending and clears the flag at rendering completion instead. The first-load regression test warms the cache and drains the event queue before asserting reminder metadata; it does not prove every overlap, rejection or cancellation path.

Scope: Calendar event-loading invalidation.
