# Changing an identity folder URI still updates shared special-folder flags

The fixed URI setter calls setFolderPref. It clears the old folder flag only when no other identity still uses that URI, sets the new existing folder flag, and clears the temporary return-receipt filter for Sent. testOldFolderFlagIsReset directly checks that a shared Drafts flag remains until the last identity leaves. The original refactor removed setter side effects, but that historical intent is not the current contract. The IDL summary that URI attributes just get or set preferences is incomplete for these side effects. No test or account migration ran.

Scope: Identity special folder API.
