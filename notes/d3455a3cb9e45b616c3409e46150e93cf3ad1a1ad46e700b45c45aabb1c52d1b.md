# An OAuth-only test must check the object configured by its new scenario

The historical test creates configIncomingHandlesOutgoing, sets its incoming auth to OAuth2 and type to ews, then mistakenly asserts config.isOauthOnly() on the earlier object whose incoming and outgoing auth were already OAuth2. That assertion repeats the earlier positive scenario and does not check the new Exchange shortcut. Accepted current source calls configIncomingHandlesOutgoing.isOauthOnly() instead. Match each assertion receiver to its scenario setup; a correct expected-behavior message does not establish that the intended object was checked. This is a historical coverage gap, not an unverified current regression.

Scope: AccountConfig OAuth test coverage.
