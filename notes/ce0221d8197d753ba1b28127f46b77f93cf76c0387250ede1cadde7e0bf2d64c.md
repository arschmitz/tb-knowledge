# Calendar detection diagnostics move to warn while selected failure callbacks stay explicit

The detection handler now warns with the error object instead of building a filename/line/stack string at error level. Its existing status and password-prompt branches remain. The ICS worker path still calls the parsing listener with NS_ERROR_FAILURE and null after logging an error. Log level and receiver do not establish operation success or replace the completion callback. No detection, worker or console execution ran.

Scope: Calendar diagnostic severity and completion.
