# Import tests bind the file picker to the address-book window and await format selection

The import test initializes MockFilePicker with abWindow.browsingContext, where the import action starts. Format selection is async: it clicks the radio, waits a tick and directly checks the checked state; each format task awaits that helper before Next. startImport separately checks pane visibility and yields to an idle callback. These are scoped harness steps, not proof that a tick or idle callback establishes every readiness condition or cures an intermittent failure.

Scope: address-book/import-tests.
