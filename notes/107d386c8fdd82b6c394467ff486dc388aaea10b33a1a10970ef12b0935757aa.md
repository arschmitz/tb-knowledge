# Conversation messages replace one open browser rather than expanding every article

The experimental preference and one selected thread choose the conversation element. It queries Gloda asynchronously, drops duplicate Message-IDs and unresolved folder headers, builds collapsed entries and opens the last returned message. Clicking another entry replaces the existing browser article with a collapsed entry before inserting one new browser article. This preserves a single expanded browser in the selected path. Source does not establish keyboard activation, stale-query cancellation, an indexed message for every header, or implemented find continuation. Later load-callback and localization cleanup changes are separate. No UI or test run was performed.

Scope: Experimental Gloda conversation UI state.
