# Match the CardDAV credential realm

A review of D318997 reported that updating a saved login by origin and username alone could overwrite a credential for another HTTP realm. For that revision, credential selection and writes needed to account for `httpRealm`; the review also noted that selection occurs before the challenge reveals the realm. This is a review finding, with no product edit recorded. Recheck the current authentication flow before using the proposed fix.

Scope: CardDAV authentication.
