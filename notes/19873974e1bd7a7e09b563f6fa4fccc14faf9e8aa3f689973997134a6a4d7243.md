# Match every declared compose label to the emitted string

The current compose_type declaration includes ReplyToSenderGroup, while the C++ ReplyToSenderAndGroup branch emits ReplyToSenderAndGroup. Read unit tests cover New, Draft and EditTemplate, so they do not prove this branch. Proposed manual review rule: compare every enum-to-label mapping against the schema and test representative/exception branches; do not treat a passing common case or accepted casing nit as proof of the full map. This mismatch is static evidence; its runtime outcome was not reproduced.
