# The header cache releases the object stored in the keyed entry

This landing changes cache reference handling to follow the stored entry object. Replacement retains a different new header before releasing oldHdr; removal saves cachedHdr before the hash-table ClearEntry callback nulls the slot, then releases that saved object instead of an arbitrary same-key input. The new test keeps stale and fresh header objects across a database reopen and checks the fresh lookup after stale deletion. Its two added assertions lack messages. The code and direct expectations do not establish a reproduced crash, complete reference-count correctness or performance result; required primary comment7 is unavailable and full-audit credit remains zero.

Scope: Message database header cache.
