# Keep mbox helper file boundaries separate from higher-level folder state

Entry 1812 extracts MboxScanner/MboxCompactor from the store implementation without a reported behavior change. Current AsyncCompact obtains a file path and passes it with the listener to the compactor; the compactor retains that listener and starts a scanner, which retains the scan listener. Folder/database commit work belongs to the higher-level caller. The later current compaction strategy is separate chronology and does not follow merely from the file split. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mbox helper boundaries.
