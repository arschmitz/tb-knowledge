# A valid zero dialog margin must not trigger a missing-value reload

PositionedDialog tests Number.isInteger(this.margin) before loading the margin attribute. Review identifies that !this.margin would treat a valid zero as absent and reread it on every show. This is the exact local integer-margin contract, not a rule to replace every truth check with Number.isInteger. The position calculation permits a separate negative-margin possibility; those calculations and native geometry were not executed.

Scope: Dialog margin validity.
