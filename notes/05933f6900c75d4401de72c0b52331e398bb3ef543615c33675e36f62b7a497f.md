# Account Hub notification title arguments flow from the caller into the selected Fluent message

showNotification forwards fluentTitleArguments when it has an explicit localized/raw title path. The private title setter defaults arguments to {} and passes them with the chosen Fluent ID to document.l10n.setAttributes. In the checked CardDAV caller, the url argument is the configured server hostname, and the selected Fluent message references $url. This traces data producer, forwarding and message consumer; it does not establish that fallback description titles receive the same arguments or that rendered localization and announcements were tested. Existing notification clearing, description references and error logging are separate contracts. No new test or UI run was part of this patch.

Scope: Account Hub localized notification data.
