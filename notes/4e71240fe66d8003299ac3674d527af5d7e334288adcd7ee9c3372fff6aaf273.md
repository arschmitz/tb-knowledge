# Use labels for actual controls and plain text for fixed SMTP protocol

Incoming fields link label for values to matching input IDs. The outgoing protocol display is a span with the fixed SMTP name, rather than a label pointing to a nonexistent outgoingProtocol control. When maintaining this form family, use label for only when it identifies an actual labelable control. The custom account-hub-select provides its own internal select ID and label link; do not infer native labeling from the host ID alone. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub label and control relationships.
