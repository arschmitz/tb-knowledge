# Check the signed filter-name search result before splitting its buffer

When LoadTextFilters already has a current filter, it checks whether RFind("name") returned a negative offset before slicing/truncating the unparsed buffer. The negative case marks that filter unparseable/disabled and skips the split. Its switch break is not a guaranteed function exit, since later iteration can assign err again. Preserve the offset guard and its exact recovery scope; no malformed-file or OOM test ran.

Scope: Filter-file malformed-name parsing.
