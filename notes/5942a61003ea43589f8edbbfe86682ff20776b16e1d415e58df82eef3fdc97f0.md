# Preserve the selected output file across decrypted-save branch cleanup

The decrypted-attachment review catches an intermediate removal of else: the later temporary-file assignment would overwrite the file selected by Save As. The next update and the assigned landed source retain exclusive saveAttachment, revealName and open branches; fixed source still assigns fp.file only in the save branch and a temporary file in the open branch. The author also identifies writing a string to the complex directory preference as the original exception; existing knowledge already covers the nsIFile repair and overwrite-picker result. This is a control-flow constraint for this callback, not a general rule to retain or remove else. Partial historical evidence: Bug 1952823 comment 7 unavailable; no new runtime validation.
