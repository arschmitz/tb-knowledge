# The accepted Graph README retains the old type-list filename after the lists split

The original landing's README names supported_types.txt and supported_paths.txt, matching its new files. At the fixed accepted endpoint supported_types.txt is absent, the code loads supported_objects.txt and supported_enums.txt, and those files contain the respective names. The accepted README still directs maintainers to supported_types.txt. This is an exact documentation/code mismatch in a later source phase; it does not prove a failed command, lost generated data or a runtime issue.

Scope: Microsoft Graph extraction documentation and supported-list phases.
