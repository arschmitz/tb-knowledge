# Thunderbird Calendar transaction-manager failed-move recovery

`pendingMoveCopies` records failed destination copies by source calendar/item ID. Cleanup deletes only a current copy that still matches the recorded immutable copy, retains externally changed copies, and keeps failed cleanup records for a later edit retry. [Task 1]

Scope: calendar.
