# The Clang 21 transition moves default aliases while retaining Clang 20 jobs

The owned change adds Linux and Windows Clang 21 repacks and their runtime/reference names. It removes default toolchain aliases from the retained Clang 20 jobs and places those aliases on the new jobs; the toolchains project keeps null aliases. Old version 20 jobs and references are still declared in this phase. The fixed accepted configuration has since moved to 22. These declarations do not prove upstream pairing, artifact contents or a successful build.

Scope: Thunderbird Taskcluster compiler repacks.
