# Undelete applies only when every selected message has IMAPDeleted

Context-menu, multi-message and unified-toolbar state use every selected header, rather than only the first selected header, to choose the undelete policy. The single-message header button uses its displayed header flag. Mixed selections therefore remain on the delete path. These selected-message controls also have separate enabled/count guards, so every([]) alone is not evidence that an empty selection is an active undelete operation. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: message deletion multi-selection policy.
