# EWS message fetching validates response shape and decodes only the outer transport layer

GetMessage requests MIME content for one server ID, rejects a response count other than one, and rejects a missing MIME payload. EWS base64-wraps the entire Internet Message Format content; the Rust client decodes that outer wrapper and passes the resulting bytes to the listener. Encodings inside the message remain for MIME consumers. The current unit test fetches from both EWS and Graph mocks and compares the full returned message string. Manual Rust review proposal in this scope: put the shape check before unwrap and explain the established invariant. The 608 follow-up replaces an irrefutable if let with match historically; current code uses inner_message(), so that old match spelling is not a current universal rule. Malformed-response paths were read but not executed.

Scope: exchange.
