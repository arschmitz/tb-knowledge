# Exchange junk moves wait for the empty-URI classification batch marker

OnMessageClassified accumulates eligible junk message keys and treats an empty URI as the end of the batch. At that point it skips messages already marked for a filter move, dispatches one copy-service move, updates the new count and clears the accumulated keys. Dispatch does not prove remote move completion, and the absent-junk-folder branch still lacks a completion listener to queue the message. Keep per-message classification and batch completion separate when extending this path. Static source only; no classifier or move ran.

Scope: Exchange junk classification batch state.
