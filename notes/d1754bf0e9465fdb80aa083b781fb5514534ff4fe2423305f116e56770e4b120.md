# Folder-sync updates exclude IDs deleted in the same response batch

The accepted EWS hierarchy handler collects update and delete IDs in sets, then subtracts delete_ids from update_ids before local reconciliation. The consumer fetches details for remaining updates before emitting deletion callbacks and the sync-state token. This prevents that batch from fetching an updated folder already deleted on the server. The filter does not cover create_ids or prove conflict handling across sync batches. No collision test or live server run was performed.

Scope: EWS / folder hierarchy sync.
