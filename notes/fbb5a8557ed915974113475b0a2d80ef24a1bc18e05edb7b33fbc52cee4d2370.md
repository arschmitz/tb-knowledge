# Global-search shortcut comments must be read against the distinct quick-filter consumer

The factored search-bar-placeholder-search-shortcut belongs to the unified toolbar global-search-bar and its Control+K placeholder. The separate quick-filter control uses quick-filter-bar-search-placeholder-with-key and Control+Shift+K. The unifiedToolbar.ftl comments call the first control a quick filter, but the markup, QuickSearchFocus selector and quickSearchCmd.key comment identify global message search. Preserve the actual consumer when reading or writing localization comments. The visual placeholder is separate from SearchBar input aria-label; no live accessibility result follows from the source.

Scope: search placeholder localization.
