# The header migration keeps EWS-specific adapters outside the shared header module

At this historical migration, MessageHeaders, the mail_parser implementation and Mailbox move into protocol_shared. Their remaining source bytes match after the EWS-only sections are removed and trait visibility is widened. EWS keeps a local Message wrapper and convert_mailbox helper, and the shared manifest does not add an ews dependency. This is a checked migration boundary; the historical EWS wrapper is not presented as the current EWS API.

Scope: Rust message-header migration and protocol adapters.
