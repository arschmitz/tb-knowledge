# Use current schema notation for values, references and header mentions

This is a scoped manual syntax proposal for new or changed WebExtension schema descriptions. Use <var> for variables/literal values, $(ref:qualifiedName) for API references, and <em> to mention header names such as From. The 346 commit actually emitted <val> although its subject said <var>;1903248 corrected that after generating documentation. Follow actual newer accepted source. Some current descriptions contain reintroduced <value> or :ref: notation, so this is an intended interoperable convention rather than a claim that the tree is uniform. A formatter cannot prove these consumer semantics.

Scope: mail/components/extensions/schemas.
