# The libotr SDK directory and deployment-version argument are separate inputs

The historical update changes both macOS task SDK directories and the shell fallback from26.1 to 26.2, while retaining target-version values10.15 and 11.0. The script turns the fetched SDK directory into CROSS_SYSROOT for compiler/linker sysroot arguments and passes MACOS_TARGET_SDK separately as the minimum-version argument. The fixed accepted directory is later26.5. Keep these source phases and inputs separate; changing the directory alone does not establish a raised deployment target, a fetched SDK or a successful cross-build.

Scope: macOS libotr cross-build.
