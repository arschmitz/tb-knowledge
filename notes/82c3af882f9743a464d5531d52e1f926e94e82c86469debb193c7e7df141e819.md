# EWS client running state includes idle queue workers

The original queue counts pending, waiting and active runners as running. Closing submissions drains queued work before the last runner stops, so running is not a network-activity indicator. Accepted client code exposes a separate idle query and later starts five runners instead of one. Keep these lifecycle and concurrency phases separate; declarations and cleanup waits are not a throughput or cancellation test.

Scope: ews/queue-running-state.
