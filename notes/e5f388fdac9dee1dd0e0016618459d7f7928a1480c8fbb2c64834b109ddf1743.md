# The autocomplete test cleanup leaves its shared Drafts special folder intact

The follow-up removes deletion of the Drafts folder from browser_addressPillsAutocomplete cleanup while retaining deletion of its newly created address book. The concrete get_special_folder helper obtains the special folder under Local Folders by flag, creates it only if missing and empties it by default; create-if-missing does not give this test private ownership. The fixed cleanup therefore leaves that shared folder in place. No test, folder deletion or complete test-isolation behavior was run.

Scope: Compose autocomplete test cleanup ownership.
