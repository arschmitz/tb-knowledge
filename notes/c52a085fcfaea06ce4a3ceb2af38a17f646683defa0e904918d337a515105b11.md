# Import source links through the shared mail library after its wrapper is removed

The patch deletes the import/build wrapper and traversal entry and changes import/src FINAL_LIBRARY from import to mail. Current metadata defines Library(mail) with FINAL_LIBRARY xul and retains import/src targeting mail. This records build composition, not a successful configure/link or proof every old wrapper flag is redundant on every platform. It does not remove the importer source or define a general library-layout rule. No build or importer test ran.

Scope: MailNews import build ownership.
