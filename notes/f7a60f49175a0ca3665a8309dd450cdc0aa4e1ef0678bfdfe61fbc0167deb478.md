# The remote address-book form gives an explicit server URL precedence over an email-derived domain

On form input, the checked widget stores the original username and chooses server from the URL field, then the lowercased email domain, then an empty string. It updates ariaInvalid and emits config-updated with the combined validity result. The added deepEqual directly expects the typed unrelated URL to override the email domain. That is a written assertion of captured state, not a discovery or login result. The historical onwerGlobal typo is gone from fixed source. Its event wait still receives an evaluated Boolean argument rather than a callback, so that call is not evidence of a dynamic value predicate. No widget test or URL request ran.

Scope: Account Hub remote address-book form capture.
