# The preferences help-link port pairs plain anchors with a message-value migration

This landing replaces the remote-content text-link label with an HTML anchor and changes its Fluent label from remote-content-info.value to a new remote-content-privacy-info message value. The authored recipe requests COPY_PATTERN of the old .value into the new message value. Other help anchors lose moz-support-link customization and receive explicit support URLs while retaining the shared label resource. The descriptive ID and Bug-specific migration text implement the reviewed requests; fixed source later renames the remote-content ID and wording again. No localization migration, native link event or external page was run.

Scope: Preferences support anchors and Fluent message roles.
