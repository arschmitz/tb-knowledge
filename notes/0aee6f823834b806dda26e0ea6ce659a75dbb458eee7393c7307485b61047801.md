# Assert shared status-bar leaks before resetting the test helper

The account test helper first waits for start and stop timers and spinning to cease. On failure it asserts those conditions before forcibly clearing timers. It also asserts the progress-bar state and request/process counts before resetting counters. Keep assertions before recovery in this helper so cleanup does not hide a leak. The Account Hub test calls it before closing the tab and removing accounts. The helper can recover after a failure; its resets are not proof that the operation cleaned itself up. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Account browser test leak detection.
