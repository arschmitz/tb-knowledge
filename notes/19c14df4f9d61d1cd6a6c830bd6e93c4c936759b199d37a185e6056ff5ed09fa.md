# The two spaces icon fixtures use different expected-key matrices

The legacy Manifest V2 spacesToolbar test selects its dark expected key for built-in light and default themes, while the newer spaces API fixture selects light for those cases and also runs Manifest V3. Both helpers select expected data and compare actual computed image/menu icon properties. The inputs and expected fields differ, so the selectedTheme string alone cannot define a global icon-color rule or prove that the other fixture is wrong. These exact test matrices are retained at the fixed accepted revision; no rendering or DPI test ran.

Scope: Spaces and legacy toolbar icon test contracts.
