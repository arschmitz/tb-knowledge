# Name Account Hub colors by semantic role and control state

The historical Hub conversion adopts shared color roles. Newer accepted names use surface and critical rather than the older neutral and danger families. Hub-specific properties map roles to normal, hover, active and focus states; shared role tokens select light and dark values. Manual CSS proposal for this family: use role and state names such as --hub-account-primary-button-background-hover and --color-primary-hover when those tokens fit the control. This does not ban every raw color or require a mechanical rename of all old tokens. Static token inspection does not prove measured contrast.

Scope: mail/account-hub/color-names.
