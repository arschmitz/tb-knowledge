# Import telemetry records the stage that completed or failed

Profile import builds importer metadata with zip, profile or directory and records unzipFailed separately from failed. It records succeeded after the backend startImport resolves and then updates the finish UI. Address-book and calendar imports also record their own importer/result values after awaiting backend work. Preserve these result stages when extending this event. The schema and success-test metadata were inspected; data review, failure events and remote telemetry were not validated. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
