# The comm update-verify workaround selects both its launcher and vendored hglib

The vendored metadata identifies2.4. Preserve the launcher and import-path pairing when maintaining this workaround; adding a vendor folder alone does not make the other script import it. The task supplies comm/. as local_repo. This establishes selected source/command routing, not an independently reproduced2.6.2 bug or a passed release job.
