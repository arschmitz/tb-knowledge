# Mirror the search-integration preference without equating it to registration state

The 553048 repair initializes the platform-independent Settings preference from SearchIntegration.prefEnabled, then forwards changes from that Settings preference to the platform-specific setter. The setter reads/writes the platform enable preference; the implementation warns that this preference can be on while enabled is false. Its observer attempts OS registration/deregistration and can roll the preference back after registration failure. This is an initial mirror and a forward handler, not a general proof of bidirectional live synchronization or working OS registration. The version 48 migration copies the platform preference; later migration reruns are separate scope. Bug comment12 is unavailable, so this is source-only knowledge with zero full-audit credit. No OS integration test ran.

Scope: Search integration preference state.
