# Exchange read flags follow acknowledged item IDs and can update before an aggregated error

The local read-state update moves into the server-success listener. A same-count shortcut assumes all returned IDs are the requested ones; a smaller result is matched by ID. Rust delivers successful IDs before returning aggregated item errors, so partial local success is not rolled back. The native commit return is unchecked. Fixed shared-operation code avoids a second success callback and handles failure separately, unlike the original outer log-only phase. No mixed-result or DB test ran.

Scope: Exchange MarkMessagesRead acknowledgement.
