# Preserve length-bounded charset data when handing it to the message header

The parser builds charset strings from explicit header spans. Current code passes either the assigned nsAutoCString or nsCString(charset, end - charset) to SetCharset. Preserve the known span length instead of treating a header substring as a null-terminated value. This recommendation is scoped to the parser’s string boundary, not a blanket requirement to copy all C++ strings. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mail header parsing.
