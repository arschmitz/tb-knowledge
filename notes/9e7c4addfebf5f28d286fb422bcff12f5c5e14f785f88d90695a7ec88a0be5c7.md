# Initial folder selection waits for message-list layout work

Current about3Pane installs the folder select listener after restoring state, waits one event-loop turn for the message-list resize observer, then dispatches the initial select event. The comment reports preventing wrong list scrolling. Preserve the specific initialization order when changing this path; the source does not prove every resize observer has completed in all environments, and a zero-delay turn is not a general readiness rule for all UI operations. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Three-pane initial selection layout.
