# New-mail deduplication uses the header Message-ID and resets on clearing New

_knownNewMessages is a tracker-wide Set of msgHdr.messageId values, rather than folder/key pairs or numeric WebExtension IDs. Repeated values are skipped before queuing. A Status notification that changes New to false removes that Message-ID. Preserve the key and reset condition when modifying this logic. The inspected tests do not cover duplicate Message-IDs across folders or empty Message-IDs, so uniqueness in those cases is not established. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: WebExtension new-mail deduplication.
