# Message-loaded notification is earlier than final image adjustment

Entry 1297 moves image scaling into async onEndMsgDownload. At the accepted revision, MsgMsgDisplayed is sent before waiting for the document load and before image adjustment. Tests or extensions that need image geometry cannot treat that notification alone as image readiness. This is a scoped event-order contract, not a claim that the message body is absent at notification time. No image load, browser test or extension listener was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message image readiness phases.
