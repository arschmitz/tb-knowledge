# Pass the dragged destination file path to attachment initialization

The attachment drag callback reads the file-promise destination, queries it to nsIFile, and passes destDirectory.path to the new local file initWithPath call. The object and its path are different inputs. Current source also contains later macOS duplicate-save handling and an explicit background save call; those later behaviors are not caused by this one-line repair. The author reports a macOS correction but explicitly requests Windows/Linux testing; this study does not establish a common platform path or native result. Bug comments2/11/15 are unavailable, so zero full-audit credit.

Scope: Attachment drag destination type.
