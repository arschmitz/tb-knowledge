# The CSS parse port renames a conditional error exception rather than enabling a feature

The owned port updates a disabled-feature preference and the matching html.css/ua.css unknown-property expressions to text-decoration-inset. It leaves shipping CSS untouched. Current ignoredError requires all supplied source/message regexes to match and records use; it does not test isFromDevTools. The separate unused-rule check applies to thunderbirdIgnoreList. The test asserts zero unmatched CSS errors, but no parser run was performed for this study.

Scope: Static CSS parse test exceptions.
