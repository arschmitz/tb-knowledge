# CloseMockChannel rejects null before closing without proving channel lifetime

The callback adds a null check before aChannel->Close(). Its original and fixed accepted caller already test the channel member, route close through the folder sink when available, then release that member under a monitor. The guard is a local precondition check. It does not retain the argument across the proxy call or establish why a crash occurred; the primary later reopens the report and treats ownership as a separate theory.

Scope: IMAP URL teardown.
