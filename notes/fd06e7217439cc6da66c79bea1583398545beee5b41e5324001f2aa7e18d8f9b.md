# Filtered virtual-folder menu checks explicitly release the temporary database

Corrects shared lesson 5ce5dac82a165b8eb9d5d9c1fdcf29bce404dd8c60820c02b7286215dd6507db, which claimed that this helper uses finally. hasNoSearchTerms returns true for a nonvirtual folder. For a virtual folder, it reads searchString, accepts "" or "ALL", explicitly calls cleanUpMessageDatabase(), then returns the result. The helper contains no finally block. This is the current scoped cleanup path; it does not prove exception-safe cleanup or a leak in other wrapper users. The mail-folder command is also gated by server and smart-tag conditions. Reviewer1214146 proposed investigating other users; the request remains Not Done and supplies no wider defect proof.
