# The GPGME candidate loop adds version 45 without giving it first priority

The list first tries libgpgme6-11 and libgpgme-11. It adds Windows -45 names later, while common candidates try unversioned gpgme before the dotted 45 variants. The loop stores the first returned handle and stops. Optional-version names therefore do not override the two initial 11 candidates, and automatic 45 support is not a guarantee that 45 will be selected. Actual library naming, loading and crypto compatibility were not run. Required primary comment 3 is missing, so this is zero-credit source knowledge.

Scope: External GPGME library candidate ordering.
