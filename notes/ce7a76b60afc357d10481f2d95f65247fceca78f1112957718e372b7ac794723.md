# Join-link extraction follows pattern order and returns one matched string

extractJoinLink tries each declared provider pattern and returns immediately on a match. It therefore selects by pattern order and then that pattern's first match, rather than finding the earliest supported URL across the whole description. The original unit task checks exact provider fixture strings and one nonmatch, but has no mixed-provider precedence case. It does not implement CONFERENCE-property precedence, multiple join options or URL opening. Later provider patterns and the UI caller are separate phases.

Scope: Calendar meeting-link parser.
