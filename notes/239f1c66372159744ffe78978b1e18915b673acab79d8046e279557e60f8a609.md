# Name saved-search eligibility after the collection-wide predicate

includesOnlineServers names an any-folder predicate in the accepted saved-search code. For nearby code, use a name that states this meaning and a collection operator such as some. Do not name it as a single selected server or substitute the first array entry. This is a scoped naming and algorithm recommendation, not a project-wide Boolean prefix rule.
