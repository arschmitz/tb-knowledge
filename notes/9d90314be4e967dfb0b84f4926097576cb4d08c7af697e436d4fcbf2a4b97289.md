# Update attachment encoding comments with the migrated interface

The accepted name attribute is AUTF8String and its native getter/setter use nsACString. The implementation still labels this attribute wstring in a comment. Recommend updating the comment when touching the migrated interface, so native callers do not copy an obsolete UTF-16 ownership assumption. The actual function signature already uses the new contract. These observations are scoped to the cited accepted source and historical changes.
