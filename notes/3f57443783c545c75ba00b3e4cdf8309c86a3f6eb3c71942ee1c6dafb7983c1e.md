# Move native tray actions to the Gecko main thread before XPCOM calls

The tray menu callback captures a Copy action value and dispatches it through moz_task onto the main thread. handle_action then obtains nsIAppStartup and calls Quit with eAttemptQuit. The menu service thread should not invoke that XPCOM action directly. Keep the thread requirement beside the handler and preserve cancellation-aware application shutdown. These exact thread and shutdown contracts are manual semantics, not spacing rules. No D-Bus or shutdown run was performed.

Scope: Linux tray thread ownership.
