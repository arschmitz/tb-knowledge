# Test selected-message events across repeated pane visibility changes

The selectedMessagesChanged test repeats visible and hidden states, single selection, multiple selection, empty selection and a twelve-message selection. It checks the first ten-message page and the final two messages through continueList, then repeats the getter pagination. Preserve both event and getter cases when changing this list family; testing only a visible loaded message misses the original failure. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: MailTabs selection test matrix.
