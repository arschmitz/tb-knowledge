# Test the notification shortcut through its focus host

The shortcut test dispatches a composed, bubbling KeyJ event with Alt and Shift on the manager. It asserts document.activeElement is the in-app-notification host because the actual focused container is inside its shadow root. This tests the handler and document-level focus report, not native OS shortcut delivery or the exact descendant in a screen reader. Keep the event code, modifiers and shadow-root focus scope explicit in tests of this shortcut. The close-button automation skip is separate from this keyboard test. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: In-app notification shortcut focus.
