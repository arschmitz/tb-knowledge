# Log the CardDAV fallback response while retaining the full-fetch fallback

924 adds the server URL and HTTP status/statusText to the warning when a sync REPORT returns 400. The accepted path still awaits fetchAllFromServer and returns; the warning does not itself repair the server or change the fallback algorithm. Keep diagnostic context and recovery behavior separate when reviewing this path. No server response was exercised.

Scope: CardDAV sync fallback diagnostics.
