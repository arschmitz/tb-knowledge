# Calendar dialog theme background overrides

At revision d3725c0feed22918f20609ca8db70be87d095943, calendar-event-dialog.css forces the inner event and task dialogs to use `background: -moz-Dialog !important`; the comment says this overrides lightweight-theme background images. The same file gives #calendar-item-panel-iframe a -moz-Dialog background only when the root has lwtheme and lacks lwt-tree. These are observed CSS rules for these dialog elements, not a general theme convention. The supplied evidence contains no visual or runtime validation.

Scope: Calendar dialog themes.
