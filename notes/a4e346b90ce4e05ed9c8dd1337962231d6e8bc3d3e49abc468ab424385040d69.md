# The C++ compose replacement checks document-setting errors before resetting editor state

The non-quoted HTML branch chooses the conditional-CSS-cleaned or original body, obtains the editor document and calls SetInnerHTMLTrusted on documentElement with its principal. It checks the document result and setter error before BeginningOfDocument and ClearUndoRedo. Later embedded-object tagging/signature work remains separate. This does not establish complete HTML sanitization, fresh editor fidelity or cleanup on every failure; the normal tail reenables undo only if reached. The extension-JavaScript replacement is an earlier separate change. No compose, error-injection or test ran.

Scope: Non-quoted compose HTML load and failure boundary.
