# Preserve checkbox gutter in address book context menus

The address book column menu consists of checkbox options and needs the leading gutter even when items are unchecked. The fix marks bookContext with needsgutter and adds Windows-specific padding for unchecked checkbox and radio icons. Review separated the cross-platform address book gap from a Windows-only sort popup alignment issue.
