# Clear the NNTP response action when resetting a reusable client

The assigned patch adds this._nextAction = null to NntpClient._reset. Fixed response dispatch calls this._nextAction?.(res), while _actionDone completes callbacks, resets the request state, then calls onIdle. Clearing the saved response action therefore belongs to the reusable-client reset boundary. Later reset fields are comparison only. Available Bug reports distinguish FIN during a pending response from idle close and RST cleanup; they do not prove every reconnect path. Bug comment27 is unavailable and review is deferred. No new socket or automated test ran.

Scope: NNTP request reset and response dispatch.
