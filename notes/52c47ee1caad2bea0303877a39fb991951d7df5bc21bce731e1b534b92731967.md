# Reconcile deletion examples before teaching compaction timing

The current storage document general paragraph says deletion removes the database entry and issues a server delete, while its older IMAP examples defer both until compaction. The inspected compactor builds a keep map from current headers and retains tokens by map membership. Do not teach those older examples as the current timing contract. The scoped recommendation is to update the examples against actual protocol deletion callers; those callers and runtime effects have not been validated in this batch. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
