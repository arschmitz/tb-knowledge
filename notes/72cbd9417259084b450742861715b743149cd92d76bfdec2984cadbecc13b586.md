# The specified-socket test loops pass array keys instead of the listed socket values

The POP and IMAP loops use for (ssl in [ ... ]) around explicit nsMsgSocketType values. That loop supplies array property keys to getIncomingTryOrder, then expects the same key in the result. It does not repeat the intended listed-value cases with the custom port. Explicit tests above still check actual socket values, so the gap is limited to these loops. When correcting this test, iterate the listed values and keep protocol, socket and port expectations separate. No test was run.

Scope: Thunderbird account-creation probe tests.
