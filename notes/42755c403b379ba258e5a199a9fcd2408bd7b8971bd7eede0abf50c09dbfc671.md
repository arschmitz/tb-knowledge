# Filter action Fluent labels leave machine values and action-order lookup separate

The migration changes visible labels to Fluent while retaining the action menu's machine values. showActionsOrder captures each row's label and target argument, then maps each execution-order action back through gTempFilter.getActionIndex before passing named number, action and argument values to Fluent. It still inserts its own blank lines and item newlines, and preserves the truthy label-or-value fallback. Separate remove-button IDs use a Unicode minus label. These source contracts do not establish translated rendering or execution results.

Scope: Filter Editor Fluent action consumers.
