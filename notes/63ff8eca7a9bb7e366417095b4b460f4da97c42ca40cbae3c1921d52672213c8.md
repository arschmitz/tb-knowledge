# Permission-prompt tests exercise four target modes across three host surfaces

The external-handler test runs links with no target, _self, _blank and _other from a content tab, an extension popup and the three-pane message surface. Each expects the registered ext+test handler in a new tab and verifies its URL. This tests routing across hosts under mail.external_protocol_requires_permission=true. It does not establish every external scheme’s behavior or a native application handoff. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/extensions.
