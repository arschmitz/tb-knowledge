# Do not claim missing-task validation still runs after introducing patterns

The reference loader returns the matched tasks before the former missing-reference assertion, which is now commented out. Thus current pattern selection does not retain that strict literal-name guard. A typo or unexpected alias may silently select fewer tasks. Proposed review rule: validate the resulting task set for a changed pattern, including intended exclusions, instead of relying on the disabled assertion. No taskgraph or matcher runtime test was run.

Scope: Taskgraph validation gap.
