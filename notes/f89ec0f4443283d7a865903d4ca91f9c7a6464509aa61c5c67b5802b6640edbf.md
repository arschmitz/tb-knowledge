# Offline and partial flags filter different stages of Get Selected Messages

The accepted view filters out Offline headers, then the local folder filters that result to Partial headers before marking their POP3 UIDLs FETCH_BODY. Keep the selectedMessages, messages and mDownloadPartialMessages roles separate. A scoped manual recommendation is to build derived collections with copy_if instead of mutate the selected collection while iterating. The landing adds no direct regression test for every selection/view combination. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
