# VCardProperties selects the first card block and can return null

fromVCard returns null when the input has no bounded vCard block. If several blocks match, it warns and parses only the first. The Google CardDAV PUT caller checks for null before adding N. The regression test checks the first card and manually appends the trailing empty block for its final comparison; it does not prove that serialization preserves several cards. Other callers and native file-opening behavior need their own checks.

Scope: address-book vCard parser and callers.
