# Account Hub stores a separate AutoDiscover username for retries and clears it on reset

After an AutoDiscover authentication error, Account Hub captures an optional username with the password, stores it in #exchangeUsername and passes it to discovery retries. A whole-view reset clears that state. The value overrides the email fallback for AutoDiscover authentication; it can also populate a discovered configuration, so it is not universally separate from the final account username. The original patch uses Promise discovery and rejects a401 before selecting results. Accepted later generator code can return a valid priority configuration despite AutoDiscover error. The owned tests assert synthetic authentication/configuration and back-navigation state, not successful account login. No test ran.

Scope: account-hub-exchange-authentication.
