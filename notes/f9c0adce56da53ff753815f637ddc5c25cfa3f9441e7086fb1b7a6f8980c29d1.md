# The optional GnuPG test skips its tasks after external-tool discovery

The manifest limits this test file to Linux. Its setup initializes RNP and imports local fixtures before checking for gpg and a usable GPGME initializer result. Only after those checks does externalGnuPGReady become true, and each signing task has a skip_if predicate for that flag. This is optional external-tool task gating, not a promise that missing optional tools skip mandatory RNP setup or that the native tests passed.

Scope: OpenPGP optional native integration-test gates.
