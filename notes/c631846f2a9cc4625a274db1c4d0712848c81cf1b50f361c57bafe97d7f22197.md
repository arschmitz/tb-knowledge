# Restore newsgroup headers without parsing them as email addresses

670 passes false for the Followup-To row when converting draft compose fields. setAddressRowFromCompField parses an encoded address header only when multi is true; otherwise it preserves the raw header value before creating pills. Current Newsgroups and Followup-To both use false, while To/Cc/Bcc/Reply-To use true. Proposed manual call-site rule: document what a boolean switches and check the header grammar before copying a nearby call. No draft round-trip with multiple groups or poster was run.

Scope: Compose draft header restoration.
