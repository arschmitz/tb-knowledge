# Thunderbird a11y task variants select a matching mozharness suite key

The test task maps a11y-checks to mochitest-browser-chrome-thunderbird-a11y and retains the ordinary try-name. Thunderbird extra config defines that exact suite key with browser flavor, Thunderbird subsuite and leak threshold options. The entry has no explicit file list. Accepted config separately limits scheduling to Linux opt; imported variant transforms, generated flags and executed accessibility checks are not established by this local mapping.

Scope: Thunderbird browser-test CI configuration.
