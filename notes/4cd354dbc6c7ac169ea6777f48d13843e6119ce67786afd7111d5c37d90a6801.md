# Use singular lowercase dash names for Gloda noun definitions

Gloda.defineNoun documents its canonical noun name as a nonlocalized debug/lookup name and suggests lowercase names separated by dashes, in singular form. The implementation indexes that name and can use it for table and localization roots. This is an explicit suggestion in the checked Gloda API documentation, not a general rule for every Thunderbird class, module or DOM ID. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/db/gloda.
