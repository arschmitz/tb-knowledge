# Optional notification CTA state includes absent and stringified absent values

Entry 1471 hides the complete CTA button when its text is empty or literally undefined/null. The accepted parent writes notification values through setAttribute, so actual nullish values can arrive as strings. The container observes changes, initializes the current value on connection, and the browser test covers absent attributes, literal nullish strings, actual nullish values and restoration. Preserve this serialization boundary in this notification family. Hiding the actual anchor avoids an empty visible action; live focus and accessible-name behavior remain untested. No notification UI, keyboard or screen-reader test was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Notification optional CTA serialization.
