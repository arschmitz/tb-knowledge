# Special-build light-style tests add an idle turn before their result assertions

assert_light_style waits one aboutMessage animation frame and, for DEBUG/ASAN/TSAN only, an idle callback followed by another frame. It then checks the nested message document explicitly. This conditional scheduling addition does not itself prove style readiness or an intermittent cure; the actual style assertions remain the result checks.

Scope: Message reader style-test scheduling.
