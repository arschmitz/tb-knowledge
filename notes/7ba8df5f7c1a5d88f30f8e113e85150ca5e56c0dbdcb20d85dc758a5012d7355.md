# IMAP progress formatting requires a server before localized folder lookup

ProgressStatusString now checks the retained server pointer before continuing to the existing mailbox-folder lookup and GetRootFolder dereference. The inherited GetServer returns success for a non-null output and failure for null. The pointer guard stops that missing-server path; it does not establish that every later interface query is non-null. The original fix and its separate unused-rv return follow-up remain distinct. No crash or status-display result was reproduced.

Scope: IMAP progress status lifetime.
