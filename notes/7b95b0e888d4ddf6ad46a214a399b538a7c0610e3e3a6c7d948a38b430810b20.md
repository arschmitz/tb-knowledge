# Choose shipped notification defaults using cache validity and startup gates

NotificationUpdater.init returns loadFromCache and hasCache. hasCache is meaningful only when loading from cache: a scheduled valid cache returns true/true, while a failed initial fetch returns true/false. InAppNotifications loads shipped defaults when stored notifications are empty or the network cache is invalid, subject to automation and readyToUpdate gates. Keep network validity separate from whether the local JSON contains any notifications. These are fixed accepted source and test-code observations.
