# Use the MimeMessage tag for the partial-message footer callback

The 2024 regression fix changes html_closure from isMimeObject to isMimeMessage when the Partial flag schedules MimeMessage_partial_message_html. The callback obtains AsMimeMessage and returns null if conversion fails. Current MimeClosure::AsMimeMessage asserts its tag in debug and returns null on a mismatch. Keep the producer tag aligned with the consumer conversion; the tag identifies the expected callback type and does not establish ownership or pointer lifetime. This concrete partial-message fix augments the existing generic tagged-closure lessons. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: MIME partial-message callback tag.
