# Name compaction retry constants by unit and bound

Current BatchCompactor uses kRetryDelayMs for the timer delay and kMaxAttempts for its attempt bound, while mQueue, mRetry, mComplete and mFailed name their distinct states. Proposed local naming rule: keep the time unit in the delay name and distinguish attempts from queued folders. This is a source pattern in this scheduler; it is not a project-wide mandate for every constant or container. This is static source and test-code inspection.
