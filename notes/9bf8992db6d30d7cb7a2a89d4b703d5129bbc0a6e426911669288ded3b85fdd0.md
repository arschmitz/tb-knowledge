# The compose image-error listener belongs to the document that survives body replacement

InitEditor installs the capturing image-error listener on editor.document before calling gMsgCompose.initEditor. SetComposeDetails can replace documentElement.innerHTML, which replaces the body that previously owned the listener. The regression setup calls that setter before the existing pasted-file-image scenario. Existing waits and queued-message assertions cover data/cid conversion and blocked content, rather than listener identity. Keep this preserved-listener phase separate from the abandoned earlier conversion/readiness proposals. No browser test or remote image load ran.

Scope: compose/editor-image-error-listener-lifetime.
