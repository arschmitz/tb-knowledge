# Account-preference telemetry is a typed array of whitelisted protocol objects

Entry 1282 collects only imap, nntp and pop3 servers. The accepted collector builds a new array of explicit basic preference fields and sets the object metric once. It does not serialize the whole server object or include account hostnames and credentials in these inspected fields. The schema declares number, boolean and string property types. This is the contract of this metric, not proof that all account telemetry has the same fields or that a data reviewer approved them; the linked data-review discussion is pending and no telemetry collection was run.

Scope: Account preference telemetry payload.
