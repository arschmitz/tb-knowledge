# Exchange star tests separate outbound waits from inbound sync assertions

The original outbound star task asserts setup but calls both remote-state waits without awaiting or returning them. The current shared task explicitly awaits each wait. The changed inbound sync tests instead await callback or folder sync and directly assert the fetched/stored flag. These checks cover different directions; inbound flag hydration does not prove outbound star completion, local callback filtering or mixed-response behavior. No test was run.
