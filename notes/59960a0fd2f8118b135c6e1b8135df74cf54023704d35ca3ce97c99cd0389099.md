# IMAP copy completion and folder refresh have different completion points

The append callback completes the copy through OnCopyCompleted before requesting a folder refresh. OnCopyCompleted clears copy state and notifies the copy service; UpdateFolderWithListener can then start a SELECT URL whose header updates finish later. Do not use the copy callback or a successful refresh-start return as proof that refreshed headers are visible. The original patch broadens refresh to both append URL types, while fixed accepted source again limits that backend refresh to draft append and the extension import caller explicitly updates its destination. Preserve these phases rather than teach a lasting all-append policy. No IMAP, filter or import test ran.

Scope: IMAP append copy and folder-refresh callbacks.
