# Keep toolkit button compatibility variables behind the current palette names

Entry 894 replaces old accent bgcolor aliases with color-accent-primary and its hover/active variants. Current variables.css maps those palette values into the toolkit button variables, and popupPanel.css uses the button-primary text/background/hover/active family. Prefer the current consumer family for these buttons. This does not justify a general ban on every variable ending in bgcolor; the evidence is scoped to these renamed accent aliases and their consumers.

Scope: mail/themes/shared.
