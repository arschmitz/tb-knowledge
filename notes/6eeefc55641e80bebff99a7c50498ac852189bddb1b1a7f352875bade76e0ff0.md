# Name color tokens for the semantic foreground they supply

847 ports --button-color to --button-text-color across its definition and consumers, including icon stroke. The accepted high-contrast definition pairs ButtonText with ButtonFace. Use the existing semantic text token when the color is foreground; update every owned consumer with the definition. This is a scoped token naming and state rule beyond formatter output, not a new global color palette.

Scope: Button theme token naming.
