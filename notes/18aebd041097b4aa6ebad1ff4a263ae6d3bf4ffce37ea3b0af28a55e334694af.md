# Clear both pane modes when an empty selection can follow either display

1017's refactor routes zero selection through displayMessage() but its historical empty-URI branch only clears the single-message view. The accepted MessagePane now explicitly clears both single and multi-message modes for an empty URI or empty message array. Preserve the accepted two-mode clearing contract when changing selection flow. The source proves this later refinement; no original stale-pane failure or later repair cause was reproduced.

Scope: Message pane empty-selection mode clearing.
