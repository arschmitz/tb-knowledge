# Return a list of replacements that callers can extend

mk_gecko_rev_replacement returns an empty list for an unchanged value and a one-item list containing the file/old/new replacement when changed. Its callers use extend, not append, so the worker receives one flat replacement list. Keep the helper’s return shape and caller operation paired, including the no-op branch. The current helper targets scriptworker-lando; the historical Treescript wording is retired. This small shape rule follows actual Python data flow rather than formatting.

Scope: Merge automation helper shape and syntax.
