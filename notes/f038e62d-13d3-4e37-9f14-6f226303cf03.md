# Keep tree selection identities stable while rows are removed or collapsed

The reland checks whether a removed row belonged to the current selection before deleting it, so sequential selected-folder deletion does not repeatedly rebuild an unstable range. Current TreeListboxMixin stores selected DOM rows in a Set and builds index mappings from current visible rows at its public getter. Check row identity or explicit null, not !selectedIndex, because index0 is valid. This supersedes the historical private Map implementation.

Scope: tree-listbox deletion and identity.
