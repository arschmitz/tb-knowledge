# Calendar dialog title tooltips are populated and cleared with event state

Loading a Calendar event sets the heading title property to calendar name plus event title. Clearing the dialog clears that property along with the visible title/name, so a reused dialog does not retain the previous event tooltip. The test directly asserts the composed property and its empty value after reset; the reset closes the dialog and close calls clearData. These assertions do not establish hover rendering or accessible-description behavior.

Scope: calendar-dialog-title.
