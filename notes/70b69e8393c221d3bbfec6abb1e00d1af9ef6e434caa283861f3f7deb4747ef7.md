# The protocol card lets its native radio receive a moved click

The protocol card keeps a native radio inside its label and overlays that radio across the card with opacity0, while the content has pointer-events:none and the card disables text selection. The regression waits for click/change and asserts selection after an eight-pixel moved click. The checked value is the form state used for manual protocol configuration. This is a scoped source/test contract; no live pointer, keyboard, accessibility-tree or layout result was measured.

Scope: Account Hub protocol-card pointer interaction.
