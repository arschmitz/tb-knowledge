# Hide the smart account root from the public folder API

Unified and tag folders are stored under a hidden smart account, but that account is an internal choice. The refactor makes getParentFolders return an empty array for unified folders instead of exposing the common smart-account root. Extensions reach these folders through getUnifiedFolder and getTagFolder, and unified-folder queries use SmartMailboxUtils.getFolderTypes rather than the broader special-use map, which also contains Outbox. Tests changed to assert the public tree without the implementation root. Preserve this API boundary if internal storage changes.

Scope: WebExtension folder API.
