# Combine test cleanup in one callback

When writing or updating Thunderbird tests, use one `registerCleanupFunction`
callback per test file. Combine all cleanup actions in that callback. Keep the
required cleanup order and register cleanup before setup can fail.

This is a deliberate human instruction. It applies to future test changes and
the category-row test in Bug 2062007. It does not require unrelated test edits.
Automatic learning must not change this instruction.

## Evidence

The human requested:

> there should only be one register cleanup function they should always be combined remember this

The request corrected two cleanup callbacks in
`mail/components/calendar/test/browser/browser_calendarEventCategoryRow.js` at
revision `017cc984aeadb070df44e77787588b9d7be66fdf`. The first callback finished
axe. The second callback closed the dialog and tab. The human requested one
combined callback and asked to retain that requirement.

## Validation and limits

The current test and the shared guidance were inspected. This note records the
direct human request. Validation of the source change is reported separately.
The notification example supports the cleanup order; the human request is the
authority for the callback-count rule.

## Correction

The [earlier cleanup correction](f706938f-ead2-4a9c-ad82-59db1d738286.md) withdrew
an assistant-authored requirement to use separate cleanup callbacks. It did not
establish a global callback-count rule. Preserve that historical note unchanged.
This later direct human instruction now requires one combined cleanup callback.
