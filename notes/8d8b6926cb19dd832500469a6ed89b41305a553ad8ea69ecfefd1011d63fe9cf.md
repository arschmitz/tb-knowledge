# Folder popup Fluent labels and saved-search legacy names keep different localization receivers

The folder popup formats labels synchronously with its dedicated folderWidgets Fluent Localization, so getDisplayName still returns a string immediately. The saved-search properties dialog instead reads verboseFolderFormat from its existing messenger.properties bundle. Removing folderWidgets.properties therefore does not mean that every consumer switched to Fluent. The current popup later adds path-mode and localized tooltip behavior; those are separate from this initial resource/receiver migration.

Scope: folder-widgets-localization.
