# Test folder count refresh and the absent-view state separately

Proposal for threadPaneHeader tests: start with multiple selected messages in one folder, then select a different folder with no selection. Check that the selected-count indicator is hidden. Also cover no gDBView, one selected message, multiple selected messages, and revealing a hidden header. Current onFolderSelected() refreshes selected count, while updateSelectedCount() hides the indicator for undefined or fewer than two selections before setting the numeric Fluent argument. The original fix added refresh; its follow-up added the absent-view guard. These are separate state contracts. Suggested assertion messages include “The selected count should be hidden after changing to a folder with no selected messages.” and “The selected count should show the current folder selection.” The historical reviews allowed whole-header tests in a follow-up. No test was added or run by this study.

Scope: mail/base/content.
