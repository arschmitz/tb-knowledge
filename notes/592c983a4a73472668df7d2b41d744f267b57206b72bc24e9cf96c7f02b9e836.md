# Keep aggregate header storage alive while its pointer is used

The historical GetAggregateHeader used an allocated buffer with raw pointer/length handling. The newer accepted parser builds aggregate To and Cc values in caller-owned nsCString buffers and returns a HeaderData view into them. Those buffers remain alive for the subsequent use. In this representation, preserve owner lifetime and use the string length for the view; do not revive the backed-out malloc patch as the preferred current design.

Scope: Mailbox parser aggregate ownership.
