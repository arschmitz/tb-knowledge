# Distinguish message-update UI tests from the API-only unit suite

The regression is placed in browser_ext_messages_update_ui.js, while test_ext_messages_update.js checks extension event payloads and stored message properties. Proposed scoped filename convention: retain the UI qualifier for the browser test that asserts rendered tags, and use a scenario name that states the combined junk/tag update. This mapping is useful for this test family, not a requirement to add a UI suffix to every browser test. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message update test filename scope.
