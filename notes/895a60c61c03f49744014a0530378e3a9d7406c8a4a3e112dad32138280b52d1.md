# Test a message drag through transfer flavors and its completed effect

The drag test checks URI and URL flavors, the file promise provider, exported message content and the destination folder notification. It waits for message-saved before reading a file and msgsMoveCopyCompleted before checking moved message IDs. Current coverage also checks that a second file export leaves the first file intact and creates a numbered file. This distinguishes correct drag metadata from a completed move or export. The filename regular expression is not adopted as a syntax rule; escaping and platform filename details were not independently validated.

Scope: mail/base/test.
