# The local Appearance initializer only sets accent-control disabled state on contrast changes

The local init registers event listeners but does not apply prefersContrast.matches to the accent menu immediately. The disabled assignment appears inside the change listener, and the markup supplies no initial disabled attribute. Keep initial state separate from later change handling and from CSS that ignores custom tokens in contrast mode. This bounded source finding does not prove a rendered startup failure or replace a high-contrast test.

Scope: Appearance contrast-state initialization.
