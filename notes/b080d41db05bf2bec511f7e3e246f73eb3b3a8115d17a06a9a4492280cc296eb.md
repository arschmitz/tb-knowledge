# Compare normalized mbox size while preserving database keys

The compaction test normalizes only the variable From separator, compares the normalized string length with a size calculated from the message headers and checks surviving message keys remain stable. Its fixtures are ASCII, so the readUTF8 string length comparison is not a general byte-size test for non-ASCII data. These assertions cover stored size and database key identity. They do not compare the complete message bodies, so do not describe this test as exact content preservation. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/base/test.
