# Handled compose send failures return before the outer completion event

CompleteGenericSendMessage catches a sendMsg failure, unlocks and returns. GenericSendMessage then emits compose-prepare-message-completed without an exception detail. Errors that escape other preparation code still use the outer exception event. The accepted source retains this handled-return boundary and separately treats user abort. Callers must not infer successful send or final copy completion solely from that ordinary event. This is static producer/consumer flow, not an exercised event or UI failure. The owned file-creation helper can also handle an error and return null normally, so a fulfilled chain is not independently a sent-message signal.

Scope: Compose send preparation completion events.
