# Release an encoded search term on the success and error paths

750 deletes the temporary search-term array before breaking on AddSearchTerm failure. The accepted code also deletes it after success and separately releases the accumulated expression. EncodeImapTerm initializes its output pointer before allocating data. Proposed manual C++ rule: match array allocation with delete[] on every path after the callee has consumed the data, and keep the output ownership contract explicit. No allocation failure was injected.

Scope: IMAP search expression ownership.
