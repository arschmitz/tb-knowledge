# Keep fixed protocol namespace URIs with narrow lint exceptions

The upstream SJS/test ESLint port made a URL rule flag CalDAV and CardDAV namespace constants that are defined with http:// by the protocol. The accepted patch puts a one-line no-insecure-url exception beside each fixed URI rather than changing its value or disabling lint for the file. Current code retains the constants but the rule name changed to sdl/no-insecure-url. Treat a protocol URI as an exact identifier and use the current configured rule name.
