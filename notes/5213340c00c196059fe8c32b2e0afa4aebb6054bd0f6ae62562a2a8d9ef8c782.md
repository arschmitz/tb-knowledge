# Document awaited Account Hub dialog parameters as elements rather than promises

The open helper returns Promise<HTMLDialogElement>, but its awaited result is passed into close/fill helpers that use dialog.querySelector and shadowRoot immediately. Those parameter comments still say Promise<HTMLDialogElement>. Recommend correcting the two local parameter types while keeping the async return type. This is a scoped manual documentation rule about actual values, not a formatter decision or runtime failure. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: Account Hub test documentation.
