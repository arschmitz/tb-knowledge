# Account Hub component tests use real modules with templates supplied by the fixture document

The fixture imports the real AccountHubStep module but defines local header/step templates and separate ID/raw-text instances. Both components clone templates from their owning document, so these assertions check the fixture scaffold through the real component code. They do not by themselves verify production include markup or all combinations. The step assertions compare Fluent IDs and raw text with attributes; every original assertion message is explicit. This is a scoped harness contract, not a reason to copy every production template into tests. No browser/localization or accessibility test ran.

Scope: Account Hub standalone component test harness scope.
