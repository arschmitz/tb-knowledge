# Splitter fixtures need production geometry styles

For D332225 at f4fe2265884d0096b7b05986f86fcd604a678412, the review reports that replacing fixture geometry rules with color rules left the pane splitter using default hr styles because neither the fixture nor pane-splitter.mjs loaded splitter.css. The reported baseline had cursor auto, missing drag resize events, and failures; adding chrome://messenger/skin/splitter.css reportedly produced 3187 passing assertions. When removing local geometry from this fixture, retain the production stylesheet dependency. These are recorded local experiment results, not independent confirmation or proof of landing. The correction remained uncommitted; this does not establish a general stylesheet convention.

Scope: Pane splitter test fixture.
