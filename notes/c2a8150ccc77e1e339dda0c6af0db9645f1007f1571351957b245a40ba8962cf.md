# S/MIME tests call their owning utility module directly

The inspected tests import SmimeUtils from its mailnews testing module and call its namespace methods, instead of using re-exports through FolderDisplayHelpers. The removed wrappers discarded return values; the changed call sites do not consume them. This supports clearer dependency ownership in this test family, not a global ban on helpers or permission to use testing modules in production. Fixed certificate setup and cleanup were inspected; no NSS or signature test ran.

Scope: S/MIME test imports.
