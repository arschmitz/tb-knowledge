# State the complete QR unsupported-authentication set in its eligibility comment

The accepted unsupported set includes GSSAPI, NTLM and External, plus old, secure and anything because they have no export mapping. The shorter eligibility comment lists only the first three and misspells the protocol descriptions. Proposed scoped documentation repair: describe unsupported and unmapped values separately and match the actual set. The presence of a numeric map entry is not proof that eligibility accepts that authentication method. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: QR export eligibility documentation.
