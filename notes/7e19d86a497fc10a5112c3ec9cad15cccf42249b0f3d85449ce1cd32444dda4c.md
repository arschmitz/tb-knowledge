# A From-and-To fixture does not test every recipient form

The accessor-removal patch changes three assertions from hasRecipients to fields.to. This fixture creates an empty object, a From-only object and then a To header, so To presence covers those states. The removed accessor instead checked trimmed To, Cc, Bcc and Newsgroups through a helper. Do not reuse fields.to as a general equivalent or claim that Cc/Bcc-only and newsgroup cases are now tested. D244790 then removes the helper after this last consumer goes away. No compose test or send path was run.

Scope: Compose recipient test scope.
