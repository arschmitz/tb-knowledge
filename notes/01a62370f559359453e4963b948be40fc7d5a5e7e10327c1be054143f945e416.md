# The comm readable-search port uses named case-insensitive helpers

The seven eligible mailnews files replace sixteen forward searches with CaseInsensitiveFindInReadable and one iterator-based reverse search with CaseInsensitiveRFindInReadable, removing the explicit comparator argument from those calls. Existing branch, append and iterator-offset consumers remain visible in comm. Other comparator-based Equals and StringBeginsWith calls are still present. The external helper implementation is unpaired, so this is a comm call-site port rather than proof of build or runtime equivalence.

Scope: Thunderbird shared readable-string API port.
