# Name the two row geometry paths for the view they control

The accepted address-book sizing code separates cardMinHeight, cardRowHeight and rowMinHeight. These names identify the card and table calculations and their different density minimums. Prefer equally specific names when adding another branch in this code. This is a local readability pattern, not a repository-wide rule that every height variable must carry a view prefix.

Scope: mail/components/addrbook.
