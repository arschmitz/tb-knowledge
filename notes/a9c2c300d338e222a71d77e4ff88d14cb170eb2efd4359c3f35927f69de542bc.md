# The EWS sender leaves sent-folder copying to MessageSend and forwards transport failures silently to its listener

Accepted DoSendMessage builds CreateItem with SendOnly and no saved folder ID because MessageSend handles FCC, including headers such as Bcc that are not in the uploaded MIME content. It uses TransportSecFailureBehavior::Silent here so the outgoing listener reports the security failure through the compose path. Preserve those ownership boundaries to avoid duplicate sent copies or duplicate user alerts; the EWS server was not exercised. This is static source and test-code inspection.
