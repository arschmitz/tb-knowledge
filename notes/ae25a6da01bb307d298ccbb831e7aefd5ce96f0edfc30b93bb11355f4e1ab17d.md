# Saved message selection uses stable URIs and keeps current row separate

This adds the implementation and regression tests behind the existing URI-selection lesson. A cross-folder view needs message URIs rather than folder-local keys. Save the current URI separately from selected URIs; the current keyboard row can be unselected. Filter grouped-by-sort dummy headers before saving, since they can point at a member that the user did not select. Restoring surviving URIs after insertion or deletion naturally follows the messages to their new row indices. The current code updates currentIndex even when it is outside the selected set. Tests check both model state and selected/current DOM classes after context-menu overrides.

Scope: message-list.
