# A summary-file suffix is not the database-open validity contract

1959 deletes the nsMailDatabase::Open override whose debug-only check required a .msf filename. The accepted subclass inherits Open; the base implementation opens and validates the database contents through OpenMDB/CheckForErrors. FolderCompactor currently opens a copied .msf.compacting file with OpenDBFromFile. This concrete caller explains why a valid summary need not end at .msf; it does not permit arbitrary formats or remove normal summary naming. No database-open or compaction test ran. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: mail summary file opening.
