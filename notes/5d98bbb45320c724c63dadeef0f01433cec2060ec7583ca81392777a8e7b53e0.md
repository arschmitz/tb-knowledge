# Use the CalDAV OAuth sentinel and origin check as separate guards

Accepted CalDavSession uses presence of _oAuth to distinguish uninitialized state from a cached null decision. A matching saved password disables OAuth; an unsupported provider also sets null. An initialized token is attached only when the request prePath matches _oAuthOrigin. Scoped recommendation: preserve both the presence test and origin check in this family. A truthiness-only cache guard would retry the null cases; a host-only check would discard part of the origin boundary. This is source and test inspection only.
