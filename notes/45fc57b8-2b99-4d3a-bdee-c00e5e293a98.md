# Rebuild multi-folder views when entering grouped-by-sort

In the May 2024 view wrapper, changing a multi-folder search view to grouped-by-sort must use beginViewUpdate and endViewUpdate so the view is rebuilt. Changing view flags in place could leave an invalid sort such as bySize and destroy or empty the view. Check current code before applying this to another view implementation.

Scope: message view sorting.

- `mail/base/content/about3Pane.js`
