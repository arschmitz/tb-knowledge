# Address Book header keys bypass contact actions while handled row keys consume their own event

The Address Book card-list keydown receiver returns when the target is inside thead. Header controls can then use the shared header behavior instead of activating the current contact. The pane prevents and stops an unmodified Enter only after currentIndex identifies a row to activate; it leaves Enter unconsumed when there is no current row. The shared header separately stops an Alt+arrow key event and emits a new bubbling shift-column event. These are scoped ownership and consumption rules, not a general requirement to stop every event. No live keyboard or accessible-tree result was measured.

Scope: Address Book tree-header keyboard routing.
