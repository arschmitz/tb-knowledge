# Hidden Exchange OAuth inputs retain their required-field role

OAuth controls are shown for OAuth2, while the default-settings checkbox controls the custom fields. The controller clears required while custom fields are hidden and records wasRequired so the role can be restored when shown. It also sets expansion state on the actual native select and checkbox inputs. Tests directly check visibility, ARIA metadata and the first custom input required flag; a separate helper opens and activates a native select popup item. These source/test contracts do not establish native accessibility or a successful account flow.

Scope: Account Hub Exchange custom OAuth controls.
