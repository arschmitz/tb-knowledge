# Map a negative selection index to the named no-index sentinel

ViewNavigate receives a signed current index from the tree selection and explicitly maps a negative result to nsMsgViewIndex_None. Preserve that conversion at the signed-to-view-index boundary rather than assigning a negative constant through an unsigned type. The inspected fix changes representation; no navigation failure or analyzer diagnostic was reproduced. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message view index sentinel conversion.
