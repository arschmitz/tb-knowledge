# Retain the full QR summary label when visual text is truncated

The pane puts the account name in both textContent and title. Current summary CSS uses grid with hidden overflow and ellipsis. The original two-column grid and display:block ruby are no longer present in this section, so they are not current layout rules. The browser test checks the tooltip equals the full account name. A title is not proof that keyboard users or a screen reader can obtain truncated text. Check the real label and control behavior when changing overflow. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/qrexport/summary-overflow.
