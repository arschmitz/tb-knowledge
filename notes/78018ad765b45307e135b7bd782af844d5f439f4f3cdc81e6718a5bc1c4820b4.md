# Mail news URLs remove internal authority-less slashes when returning their spec

nsMsgMailNewsUrl removes internal triple slashes from authority-less news: and snews: URLs after the base URL returns its spec or display spec. The accepted helper checks the exact news:/// and snews:/// prefixes before cutting those slashes. Accepted test_nntpUrl.js directly asserts spec round trips for message IDs, groups, wildcards and uppercase schemes, plus host/port/query preservation for authority URLs. That inspected test does not directly assert displaySpec. The historical Bug tracker has a scoped context gap, so this is source evidence only. No NNTP or UI runtime test ran.

Scope: Mailnews URI serialization.
