# Treat tabs.create completion as tab creation rather than page load

Current tabs.create opens a contentTab, marks non-blank URLs as initializing and returns tabManager.convert without waiting for page load. The schema explicitly says the result may still have loading title and about:blank URL. Register tabs.onUpdated before create when a consumer needs to observe load completion. The separate initializingTabs set makes executeScript wait for the requested URL; it does not change the create Promise contract.

Scope: mail/components/extensions.
