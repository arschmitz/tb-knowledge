# Use a named request wrapper for shared logging metadata

OperationRequest carries operation_id, operation_name and the borrowed request together, and documents why they travel as one argument. send_request destructures those fields locally. For this shared transport boundary, preserve the named roles and borrowing lifetime instead of passing an unlabelled tuple of similar values. This is a local Rust API/documentation pattern; the source does not establish a repository-wide ban on tuples or an approved new naming policy. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Shared Rust request metadata syntax.
