# The fixed SMTP value is a div and its Protocol heading is a span

Additive correction to the tag description in lesson 4e71240fe66d8003299ac3674d527af5d7e334288adcd7ee9c3372fff6aaf273: the Protocol heading is a span with account-hub-protocol-label, while the fixed SMTP value is inside div.selected-option. A div wraps both elements. The earlier lesson calls the SMTP display a span; that wording confuses the heading with the value. Its broader distinction between labels for actual controls and plain fixed protocol text remains valid. This corrects the concrete markup description only. No rendered UI or accessibility test ran.
