# Keep attachment content type and parameters separate

SetContentType copies the input then truncates at the first semicolon. SetContentTypeParam strips leading semicolons and spaces from a nonempty input into the separate field. Preserve this local split when constructing attachment MIME values; the setter does not parse arbitrary MIME parameter syntax or quoted values. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
