# Commands diff viewer navigation and conditional VS Code integration

`renderLocalDiff` in `commands/graph/data.mjs` runs `git worktree list --porcelain -z`, checks regular files, and supplies resolved paths. `getDiffFilePathsForLocalLookup` provides new and old rename paths. Generate `vscode://file/<URL-encoded-absolute-path>` and encode spaces and `#`; `desktop/main.cjs` must send `vscode:` to `shell.openExternal`. [Task 1]

Scope: console.
