# Attach backend notification listeners for each connected lifetime

The manager element listens for both newnotification and clearnotification on connection, and removes both on disconnection or window unload. Local click/close handlers are installed once through hasConnected. Backend listeners are attached each connection. Do not place both kinds under one permanent initialization guard or a reconnected element will stop following backend events. Historical tests cover disconnected and unload behavior; current browser tests no longer contain those same tasks.

Scope: mail/components/inappnotifications.
