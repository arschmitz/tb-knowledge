# Correlate tab load completion with the expected tab and non-blank URL

The prompt test creates its tab-created and tab-updated promises before creating/navigating or clicking. UpdateTabPromise remembers a non-about:blank URL and accepts complete only after a URL is seen. verify checks one updated tab, the exact expected ID and URL; popup setup can key updates by windowId. A scoped extension-test recommendation is to keep that identity check so an unrelated completion cannot satisfy the test. This collector is test code, not a general navigation state machine. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
