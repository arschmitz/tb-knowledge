# Treat taskgraph parameter fixture filenames as dispatch inputs

update.sh splits a fixture basename into repository and action. Release actions must include the -thunderbird suffix so the script can select the Shipit product and phase. Keep that suffix when adding release fixtures; it is functional naming. The script also accepts cron-* and nightly-desktop, skips Try and merge-automation, and rejects unknown repositories or actions.

Scope: taskcluster/test/params.
