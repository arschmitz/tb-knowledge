# Constrain theme background overrides to calendar dialog content

Lightweight theme background images reached the event and task dialog content through its iframe and obscured the lower event form. The accepted patch sets -moz-Dialog background on the two inner content elements, rather than broad extra elements. Review first removed unneeded targets and tested Windows 11. Check event and task dialog inner content with a theme background when editing inherited dialog styles.

Scope: calendar event dialog theme.
