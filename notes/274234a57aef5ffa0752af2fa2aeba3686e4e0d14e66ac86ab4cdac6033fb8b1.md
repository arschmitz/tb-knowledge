# QoS values are clamped before narrowing to a byte

Entry 1281 replaces mozilla::clamped with std::clamp while retaining the 0..255 bounds before conversion to uint8_t. The accepted protocol still reads the per-protocol integer preference and applies that order. For this preference boundary, recommend checking bounds in the wider type before narrowing. The single replacement supports this local use of the standard helper; it does not establish a universal C++ helper policy. No build, preference test or socket traffic was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Mail protocol QoS preferences.
