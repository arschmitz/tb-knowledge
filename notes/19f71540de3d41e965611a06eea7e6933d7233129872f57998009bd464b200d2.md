# The stream-converter test feeds MIME callbacks through an opt-in byte listener

The new converter test supplies encoded MIME input through start/data/stop callbacks and awaits a PromiseStreamListener created with byte reading enabled. That listener keeps the existing default read path and selects readBytes only for the new option. The original test directly checks headers, attachment metadata and selected output bytes/DOM, but skips IMAP and unknown-URI tasks and leaves several output assertions disabled. It is a framework with explicit gaps, not full converter coverage or a passing run.

Scope: MIME converter test framework and byte listener.
