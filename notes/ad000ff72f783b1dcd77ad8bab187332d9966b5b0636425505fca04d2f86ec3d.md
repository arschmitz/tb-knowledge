# Keep callback and folder method sections with their own C++ classes

In D227880 review requests grouping DeleteFolderCallbacks implementation with its class, then corrects an update that also moved EwsFolder methods into that section. The landing places the callback class and OnRemoteDeleteFolderSuccessful together while folder methods remain with EwsFolder. A separate alphabetical-order preference is explicitly nonblocking and does not authorize reordering unrelated methods. This is the inspected multi-class EWS file organization, not a formatter guarantee or global fixed ordering rule.

Scope: EWS C++ method ownership grouping.
