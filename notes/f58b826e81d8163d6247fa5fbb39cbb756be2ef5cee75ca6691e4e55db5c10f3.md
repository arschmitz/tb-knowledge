# The original detached-virtual-folder guard was narrower than all parentless eviction

The original lookup change checks cached objects in both creation entry points and discards only a parentless virtual folder outside Panorama. It preserves parentless non-virtual reuse and uses GetFlag rather than the database-reading GetFlags. The fixed accepted phase no longer contains that helper: deletion explicitly evicts the current object, with a real local Trash exception. Tests directly assert fresh identity and Virtual non-inheritance, but no runtime or universal folder-deletion guarantee is established.

Scope: Historical folder lookup cache reuse and deletion phases.
