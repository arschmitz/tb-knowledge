# Return EWS response bodies when the current caller needs them

The author proposed retaining UpdateItem response messages for a possible future use. Review rejected that reason for the current read-status API and distinguished CreateItem, whose caller actually extracts the new EWS ID. The final read-status request returns Result<(), XpComEwsError>. In this operation, add a response return when an actual caller needs it; do not copy another operation's return contract without its consumer. Later change-key work was a possible future need, not implemented here.
