# Locally configured Windows Botan selects MD for ASan and MT otherwise

The patch passes the ASan dependency into configure_botan as is_asan and uses it for the Windows --msvc-runtime flag: MD for ASan and MT otherwise. The local Botan configuration is skipped when a system Botan package is present, and the OpenSSL backend is separate. Accepted source retains the selection and forwards the flag to Botan configuration. This is an argument-selection contract, not proof of compiler/linker/runtime compatibility or a successful ASan build.

Scope: openpgp-botan-build.
