# Chat account sizing uses actual logical minima and a separate scrolling middle area

The landed CSS uses min-inline-size:27em and min-block-size:14em, although the commit explanation cites the older 41em by 27em defaults. The accountManager body is a flex column. Its imAccountsMain middle area can shrink and hides overflow, while accountlist scrolls vertically and the bottom buttons remain a separate sibling. The opener creates a resizable chrome window. These are exact layout declarations and consumers, not proof of unclipped rendering, keyboard access or accessibility.

Scope: Chat Accounts window layout.
