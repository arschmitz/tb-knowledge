# The Account Hub OAuth warning messages land before their UI consumer

The landing adds two Fluent messages and translator context only. It references the brand term and a named help link but leaves Advanced Configuration and Account Settings as literal wording rather than interpolated message references. A later accepted warning banner uses those IDs, and later widget code controls its visibility. That consumer and policy are separate from the preparatory string phase. No translation/rendering, support-link, OAuth, account or accessibility result was tested.

Scope: Account Hub OAuth warning localization phase.
