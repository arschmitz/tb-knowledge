# Disabled extension-action tests reset their accessibility override immediately after the click

The disabled-action mouse test temporarily allows disabled input checks, and relaxes the accessible-rule check only for the unified-toolbar target. It resets that environment immediately after the synthetic click, before the existing observation delay and listener checks. The disabled background handler fails if onClicked occurs. This is a test-only negative-input scenario, not a production accessibility exception or an observed native result.

Scope: Extension action negative-input browser test.
