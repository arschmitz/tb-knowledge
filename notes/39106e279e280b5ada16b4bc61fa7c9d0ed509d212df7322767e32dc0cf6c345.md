# Graph delta sync distinguishes removed items before reading present-folder properties

DeltaItem places Removed before the permissive Present variant. A removed item carries its ID and optional reason, so hierarchy sync sends that ID to the deletion callback without requiring a display name or parent ID. The reason is logged; this branch does not restore folders. The mock test asserts live-folder callbacks, the removed callback ID and a state token, while its listener only records IDs. These are source and direct assertion contracts, not proof of real database deletion, remote restore semantics or live Graph behavior.

Scope: Graph folder hierarchy delta representation and callbacks.
