# The link actors carry the destination and visible text to a mail-specific phishing decision

This landing moves message-link handling into the link actors. The strict child sends href and gathered visible linkText; the shared parent applies the phishing decision only for the mail-message group. Decision1 blocks,0 dispatches linkText, and the normal path dispatches href through the concrete external-link helper. The single-site, relaxed and strict child policies remain separate, and actor registration selects them by browser group. These are static source contracts; no native event, external browser, network or full security behavior was tested.

Scope: Message click actor routing.
