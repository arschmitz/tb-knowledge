# Current Exchange copy task wrappers do not await their asynchronous subtests

subtestCopyItem awaits fixture setup and the copy operation before asserting source/destination counts and subjects. The current async testCopyItemEws and testCopyItemGraph task wrappers call that helper without await or return, so their own promises do not carry its completion or rejection to the task runner. The original historical direct copy test did await its work; this is a later source gap. A focused correction can return or await each helper call. No harness failure or out-of-order execution was reproduced.

Scope: Exchange copy-item test task completion.
