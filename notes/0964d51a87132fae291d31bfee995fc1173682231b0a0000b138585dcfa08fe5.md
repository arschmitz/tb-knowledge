# The extension-test UUID fix restores a captured string rather than an empty map

The original shared head captures extensions.webextensions.uuids at script load and writes that saved string in cleanup instead of {}. This preserves the value, not the prior user-pref/default origin. In the accepted phase, setup places the current UUID string in pushPrefEnv and shared cleanup no longer contains that setter; the legacy capture/comment remain. The two mechanisms are separate phases. No direct restoration assertion or fresh execution was added.

Scope: extension-tests.
