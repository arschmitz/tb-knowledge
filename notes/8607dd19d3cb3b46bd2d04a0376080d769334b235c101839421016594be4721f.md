# Wait for NNTP cancel success before removing the local article

NntpService sends the cancel control body from onReadyToPost, but removes the local article only when onDone receives a successful nsresult. A server error reaches _actionDone as NS_ERROR_FAILURE, so the success-only removal and completed-folder event are skipped. removeMessage itself notifies deletion and removes the database row. This keeps local state tied to operation outcome rather than transmission readiness. No server-denial regression test or NNTP session ran here.

Scope: NNTP cancellation outcome.
