# Direct NNTP expiry cleanup is separate from URL loading and error status

The error-page button calls the incoming-server expiry method instead of loading a special ?list-ids URL. The method removes server-returned IDs from a local-key Set, then removes the remaining keys and resolves when onDone runs. The client passes a status to onDone even on error, but this callback ignores it. The UI does not await the promise. The new test checks only the command sequence through a helper whose assertion lacks a message; it does not prove successful enumeration, deletion correctness or exploit prevention.

Scope: NNTP expired-article cleanup API.
