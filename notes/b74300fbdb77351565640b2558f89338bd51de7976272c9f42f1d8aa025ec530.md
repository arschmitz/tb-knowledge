# Make protocol fakes enforce the new permission condition

The OAuth2TestUtils server stores granted scopes with access tokens and returns a scope response. IMAP_OAUTH2_extension checks the token through validateToken before authenticating. Without this change, the granular account-setup test could pass with an ungranted mail scope. Current validateToken returns false for absent granted scope before token membership; the historical helper checked the token variable instead, so an unknown non-empty token could reach split on undefined. That historical guard weakness is a static observation, and the fixed accepted source has the safer guard. No fake-server runtime probe was run.

Scope: OAuth fake-server fidelity.
