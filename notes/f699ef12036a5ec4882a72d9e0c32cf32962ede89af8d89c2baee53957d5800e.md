# Set the dark-message preference before loading the message fixture

The release-channel test fix moved the disabled dark-reader baseline into setup before opening the fixture. Current setup uses pushPrefEnv to disable dark mode, enable its toggle and turn off the accessibility theme for this test. Current production defaults enable dark reader unconditionally, so the old nightly-only default should not be taught as current behavior. The test waits for MsgLoaded when toggling conversion and separates light-theme behavior from dark-theme conversion. No contrast result follows from the test intentionally disabling the accessibility theme. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Dark message test baseline.
