# Standalone message minimum dimensions flow through all three platform skin imports

The standalone document loads the platform messageWindow.css, and each Linux, macOS and Windows skin imports shared/messageWindow.css. The shared jar entry maps that URL to the shared source file. That sheet imports the common messenger and primary-toolbar styles and sets the html root's minimum inline size to 45rem and block size to 35rem. The minimums remain at the fixed revision, while the original shared pane-layout rules are removed later. This source chain does not prove exact native window dimensions at every font, scale or platform.

Scope: mail standalone message window shared and platform CSS.
