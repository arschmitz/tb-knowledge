# The identity-color test supplies its local identity before opening compose

The test now creates and adds a local identity only when defaultIdentity is absent, before opening compose. The picker skips accounts with no identities, and the existing blue-color assertion queries a menuitem by the local account key. Supplying that state removes this setup dependency on another test's MessageInjection helper. It does not prove an isolated run passed or make the test restore all state: cleanup removes the POP account but leaves the added local identity.

Scope: Compose identity color browser-test setup.
