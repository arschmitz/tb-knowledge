# Name fakeserver inputs by the object actually passed

The small documentation follow-up changes the EWS request document parameter name to reqDoc; accepted #generateCreateFolderResponse agrees with its @param XMLDocument reqDoc. Binaryd.isClosed returns whether its transport is null, and POP3 setMessages documents filename strings versus fileData objects. Keep types, result names and parameter names aligned with these actual harness values rather than deriving a new formatter rule. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
