# Stop an EWS send when its start listener fails

The historical EWS review asked whether observer errors were intentionally ignored. The author said they were not and changed the send path to return when OnStartRequest fails. Current EWS DoSendMessage::do_operation calls self.listener.on_send_start()? before building CreateItem. SafeMsgOutgoingListener::on_send_start forwards OnSendStart and converts its result, so a start failure stops that operation before the request is built. Preserve this operation boundary when changing the caller or safe listener. The current completion framework differs from the historical observer implementation; do not copy its retired method signatures. Cancellation is a separate contract and remains stubbed in the cited current CancellableRequest. This is source/review evidence only. No send, callback-failure, build, lint or live accessibility test was run.

Scope: rust/ews_xpcom/src/client.
