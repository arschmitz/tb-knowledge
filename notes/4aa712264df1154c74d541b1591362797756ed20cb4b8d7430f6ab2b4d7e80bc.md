# Account listing follows folder pane order

At revision a5701b14a54abf2d51b510b1e4e7c3af77bf93ab, both manifest-version signatures of accounts.list document folder pane order. Preserve that declared ordering when changing account enumeration. The MV3 test expects a newly created default account first in its fixture, but this does not establish that default accounts always come first under every folder pane configuration. The supplied evidence contains source and test expectations, with no test execution result.

Scope: WebExtension account ordering.
