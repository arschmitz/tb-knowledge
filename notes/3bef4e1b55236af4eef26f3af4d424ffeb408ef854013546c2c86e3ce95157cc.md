# Exchange host lookup uses its endpoint without a hostname fallback

For an AccountConfig recognized as Exchange, getConfiguredHost returns the parsed exchangeURL hostname. It does not fall back to incoming.hostname when that URL fails to parse. Other types return incoming.hostname. The reland's OAuth visibility consumer guards the returned host before provider lookup. The accepted helper retains this priority, while the accepted visibility consumer later reads sanitized live inputs directly to avoid stale configuration. Keep those method and caller phases separate; this is static source behavior, not an OAuth result.

Scope: Account creation Exchange host lookup.
