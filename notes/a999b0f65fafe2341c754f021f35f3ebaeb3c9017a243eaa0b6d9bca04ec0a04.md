# Keep parameters used by serialized extension background functions

1008 removes background(testCases)'s parameter while its body still reads testCases. The harness serializes that function and passes JSON data in a new extension context; the outer test binding is not a closure there. 1016 restores the parameter and names the host fixture TEST_CASES. Current code keeps both. When renaming such fixtures, check the serialized invocation and the background parameter together. This is a proved source repair; the full bug discussion and original failure output are unread.

Scope: Serialized extension background parameter boundary.
