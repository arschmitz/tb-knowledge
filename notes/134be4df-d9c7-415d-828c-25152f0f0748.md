# Bridge EWS folder refresh through a typed callback into the folder database

Bug 1895317 makes EwsFolder.UpdateFolder obtain its IEwsClient, validate the folder ewsId, read the folder syncStateToken, and call SyncMessagesForFolder. MessageSyncListener lets Rust request a new nsIMsgDBHdr from the target folder database, commit it to that database, and save the new opaque sync token on the folder. The Rust bridge detaches the async operation so it survives the immediate XPCOM call. This is the 2024 path from folder refresh to visible message-list metadata; current EWS files have since moved, so use current source before implementing against it.

Scope: EWS message sync architecture.
