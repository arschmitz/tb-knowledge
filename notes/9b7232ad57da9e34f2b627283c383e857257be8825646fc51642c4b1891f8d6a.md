# Distinguish a copied theme Map from copied theme entries

getBuiltInThemesDataMap returns new Map(this.builtInThemeMap). This clones the map container but preserves references to its entry objects. Treat it as protection against changing the internal key set, not as a deep immutable snapshot of version and path objects. The method comment should keep that distinction if expanded. This is an observed local ownership limit, not evidence that any caller currently mutates those objects. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Built-in theme map ownership.
