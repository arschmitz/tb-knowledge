# The three-pane and message host CSP add data only to image sources

Both host documents append data: to img-src while preserving the other directives. Keep that image-source exception separate from permissions for scripts, styles and the embedded message body. The report concerns a contact photo blocked as data:image, but the patch author says they could not test that input. These declarations remain in accepted source; avatar output and native enforcement were not run.

Scope: message header image CSP declarations.
