# Current Exchange tests separate scheme conversion, raw fetch and attachment detachment

The current scheme test checks ews-message/x-moz-ews and Graph equivalents. test_getMessage compares full synthetic message content and uses IExchangeMessageFetchListener callbacks. test_ewsAttachmentSaves waits for MIME discovery, detaches a text attachment, asserts the file exists and checks AttachmentDetached in the replacement message. These are distinct contracts; none of the inspected tests exercises PDF rendering, cancellation during download or malformed query handling. The 1926/1927 diffs add no tests; these later tests are comparison context only. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
