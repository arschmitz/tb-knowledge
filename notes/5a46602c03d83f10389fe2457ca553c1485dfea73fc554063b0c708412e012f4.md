# Calendar sound URL checks add eight assertions without failure messages

The added test waits for the automation-ended topic and checks built-in and selected file source URLs. Seven added assertions in testSounds omit messages, and the provider head's new Audio URL assertion also omits its message. These assertion APIs accept a message argument; each changed assertion needs a non-empty expected-behavior message. The provider count checks do have messages. The fixture is registered through files/** and chosen through MockFilePicker. This is a static diagnostic finding, with no browser run or claim that the sound was heard.

Scope: Calendar preference and provider browser-test diagnostics.
