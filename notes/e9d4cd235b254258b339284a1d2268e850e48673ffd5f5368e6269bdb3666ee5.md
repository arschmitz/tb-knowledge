# OAuth provider details separate all supported scopes from required activity scopes

Entries 1476 and 1477 require an activity type and replace the positional return tuple with issuer, allScopes and requiredScopes properties. The accepted function returns all scopes for a provider with a single string, or the mapped activity scope plus extra for a protocol map; it returns undefined for an unsupported mapped type. requiredScopes controls token reuse, while allScopes is the provider authorization set. Keep those meanings separate in this OAuth API; this is a scoped implementation contract. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: OAuth provider details object.
