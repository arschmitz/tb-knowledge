# Register a shipped Remote Settings dump and its collection name together

1121 adds the URL-parser intervention JSON dump and registers its exact filename under Thunderbird defaults.settings. The separately checked Gecko observer reads the same collection, verifies signatures through Remote Settings, and feeds scheme values to setSimpleURIUnknownRemoteSchemes. This is a parser-selection bypass list, not a general link-permission list. Keep the collection/filename/registration spelling paired. The Gecko/Comm pair was not built, and no live Remote Settings update was made.

Scope: Thunderbird URL parser intervention dump integration.
