# Return zero local storage size for a virtual folder before asking the store

GetSizeOnDisk gives root folders and Virtual folders a safe cached zero. Only a still-unknown real-folder size calls EstimateFolderSize. A virtual search folder represents other folders and may have no Maildir file; its local storage size is not the sum of its search scope. The current code preserves kSizeUnknown on estimation failure by using a temporary value. No filesystem/backend runtime was run. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/local/src.
