# The UPX path correction is an intermediate mozconfig phase

This landing changes the UPX export in all three common Windows mozconfigs to MOZ_FETCHES_DIR/upx/bin/upx.exe while retaining the Linux-host guard and conditional chmod. Fixed accepted files contain no UPX setup block; its later removal is a separate source phase. Preserve that sequence when interpreting a bootstrapped-toolchain port. The comm files establish path/configuration ownership, not successful toolchain bootstrap or an executed Windows build.

Scope: Windows build mozconfigs.
