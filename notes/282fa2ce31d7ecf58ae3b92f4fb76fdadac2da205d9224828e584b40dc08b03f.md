# An IMAP BYE greeting fails the connection while preserving scoped diagnostics

The initial greeting branch recognizes a case-insensitive * BYE prefix and sets connection failure even when no server sink exists. The BYE alert flag keeps the complete trimmed response and puts it on a new line; ordinary command alerts still remove their leading tag/status words. Accepted current code adds a STARTTLS exception: because the greeting precedes TLS, it uses a generic disconnect alert rather than presenting potentially injected server text. That security refinement is later than this original landing. No server simulation, hang reproduction or alert test ran.

Scope: IMAP initial greeting and server-alert formatting.
