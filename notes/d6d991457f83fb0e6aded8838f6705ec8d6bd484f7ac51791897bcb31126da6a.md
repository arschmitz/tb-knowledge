# Choose the task filter from the control that originated the command

Entry 1193 reads the value attribute of explicitOriginalTarget because the historical XUL command can retarget event.target to the command element instead of the radio or menu control that owns the value. The fixed accepted code instead uses direct task-view handlers, verifies the target control type, and then reads the value attribute of event.target. For these handlers, choose the target according to the event route; do not apply explicitOriginalTarget as a universal style rule. The originating controls and both source versions were inspected, but menu and keyboard behavior were not run. Full bug and review discussion remains pending.

Scope: Calendar task-filter event routing.
