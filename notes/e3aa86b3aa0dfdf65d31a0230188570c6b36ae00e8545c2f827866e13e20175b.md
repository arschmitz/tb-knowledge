# Context-menu icon groups are not nested submenus

Entry 1517 changes the compose-test helper so an item inside mailContext-navigation does not trigger ancestor-menu opening. Current helper treats the top-level popup and navigation group as direct activation cases, and only opens an actual submenu for other parents. This tests real native control ownership, not just dispatching the backing command; the command-routing lesson already exists separately. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Message context menu tests.
