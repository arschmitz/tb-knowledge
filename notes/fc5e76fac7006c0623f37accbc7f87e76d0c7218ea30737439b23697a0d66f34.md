# Keep message identity documentation consistent with the runtime representation

The current MsgIdentifier typedef still labels folderURI as boolean, but getIdentifier stores msgHdr.folder.URI and getHash embeds it in the folder hash. That comment is not reliable evidence of the runtime type. The source also distinguishes a dummy URL plus modification time for external file messages. Manual documentation proposal: state the actual representation and lookup lifetime of each identity field. This batch records the stale type without changing source or claiming a type-check run. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/message-identifier-docs.
