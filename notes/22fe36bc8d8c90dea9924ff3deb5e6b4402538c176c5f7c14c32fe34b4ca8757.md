# Verify advanced setup in the native account and clean it up even after an assertion fails

The shared Account Hub verifier waits for currentAccount, then checks native server usernames, hostnames, ports and identity values. Its try/finally removes the account and related outgoing server, and clears Account Manager state. These assertions are stronger than checking the form values only. A scoped testing recommendation is to keep backend assertions and cleanup together when extending advanced-setup tests; no test execution occurred in this study. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
