# Website header decoding must be read with its encode-and-open consumer

The content-base Website header is decoded for display with decodeURIComponent, then UrlHeaderRow applies encodeURI to its displayed text for click or Enter before opening it. The regression fixture contains object=tx%2C1234.5: the direct mock assertion expects a literal comma in the external URI, while embedded web-mode navigation expects the encoded comma. Check both producer and consumer before changing this field; the reason comment is scoped to that pair. This is not a universal URL-decoding rule or proof of every reserved-character/malformed-input case. The custom assertion wrapper supplies its own nonempty messages and checks one matching dispatched URL. No external browser, keyboard or test run occurred.

Scope: message Website header and RSS external URL.
