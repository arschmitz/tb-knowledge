# Silent macOS startup initializes notification state through the guarded singleton

MailGlue calls MailNotificationManager.init only for macOS silent startup. The normal mail-window path also calls init; the manager's first-call guard prevents duplicate listener/count setup. The selected implementation uses the silent-start gate rather than idle dispatch. The comm command-line handler uses that flag at initial launch to avoid opening a window. This source pairing does not prove native badge rendering or initialization retry after an exception.

Scope: MailGlue windowless macOS notification startup.
