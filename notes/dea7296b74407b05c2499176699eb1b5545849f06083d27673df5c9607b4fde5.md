# Do not infer the database storage encoding from the public string type

Accepted nsDBFolderInfo converts its UTF-8 mailbox name to UTF-16 for the token property helper and converts back on read. Its folderName uses GetCharProperty/SetCharProperty directly. Preserve each field adapter rather than treating the AUTF8String interface migration as proof of one physical encoding for all Mork properties. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mailnews/db/msgdb.
