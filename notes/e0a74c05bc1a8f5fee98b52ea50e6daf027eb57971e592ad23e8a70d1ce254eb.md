# Split custom elements need registration readiness at their actual consumers

Removing the common mailWidgets bundle means its elements are supplied by each using document or script. The split therefore adds module load sites and waits: aboutMessageLoaded is dispatched after attachment-list is defined, OpenPGP waits before using the attachment widget, and the editable-menulist test waits before reading its constructor. Preserving moved class bodies alone would not preserve this readiness contract. Registration completion does not mean all widget connection callbacks, message data or layout are ready. SearchDialog retains an explicit current-global JS import as a scoped workaround whose underlying HTML-loading cause was not established. No browser or test run was performed.

Scope: Widget module loading and aboutMessage readiness.
