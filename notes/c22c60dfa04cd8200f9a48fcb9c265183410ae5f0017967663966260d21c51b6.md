# The tree collapse scenario checks row identity after visible indices shift

The added browser scenario clicks row content through firstElementChild, registers its select promise before the click, and waits for select delivery. It then checks the active index, selected-class row and visible-row order while a preceding branch collapses and expands. Multi-select mode is enabled, but the scenario expects one selected row at each step. The event promise does not establish completion of all listeners, rendering or every multi-row selection path.

Scope: Tree-listbox browser-test action and assertion scope.
