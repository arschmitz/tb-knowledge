# Current SMTP stop reporting is one terminal event and awaits listener cleanup

Accepted SmtpServer guards stopNotified and cancellation, awaits listener.onSendStop before resolving its returned completion promise, and reports failure through the listener rather than rejecting that server promise. MessageSend’s listener interprets the exit code separately. Preserve those two promise/result channels and single terminal notification when changing cancellation or retries; the historical 1367 listener conversion alone did not establish this later behavior.
