# Shortcuts initialization guards the shadow root and connects its own localization root

The accepted connectedCallback returns when a shadowRoot already exists, then attaches an open root, loads a local stylesheet/template and connects DOMLocalization to that root. For this component, preserve the initialization guard and the explicit localization root when adding content. The inspected class has no disconnectedCallback, so this source does not establish a general reconnect or localization-cleanup policy. It remains a small initial shortcut scaffold; no custom-element reconnect, translation or UI test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Customizable shortcuts component initialization.
