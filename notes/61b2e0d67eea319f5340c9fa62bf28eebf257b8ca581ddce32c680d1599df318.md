# Named filter-service access keeps custom action and custom term lookup outcomes separate

GetCustomAction checks an empty ID and lookup failure before caching and AddRef-returning the action. GetCustomTerm uses NS_OK for a missing registration, so MatchCustom also checks the returned pointer and reports false plus failure when missing. Service availability is therefore separate from extension registration and evaluation. Existing registry miss-path aResult assignment is not a verified caller-output initialization. No runtime test.

Scope: mailnews-custom-filter-lookup.
