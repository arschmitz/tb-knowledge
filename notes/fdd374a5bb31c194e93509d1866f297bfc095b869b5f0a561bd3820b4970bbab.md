# The temporary EML name is part of the later save filename contract

An opened message attachment is saved to a temporary EML file before MailUtils.openEMLFile receives its URI. Current AttachmentInfo sanitizes the attachment name, uses message.eml when it becomes empty, adds .eml only when needed, and creates a unique file in a private process-specific temporary directory. This name reaches the later file picker. Keep URL identity, safe local filename and user-facing attachment name separate. The current browser tests check the direct file default name and the attached message name. Runtime filenames are content, so their punctuation does not establish a repository filename convention.

Scope: eml-attachment-identity.
