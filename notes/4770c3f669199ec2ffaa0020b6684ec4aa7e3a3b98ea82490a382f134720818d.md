# Folder repair takes the target folder explicitly across UI entry points

The extracted repair function accepts folder, and accepted folder properties passes gMsgFolder to its rebuildSummaryCallback. about3Pane observes folder-needs-repair and delegates the queried subject to FolderCommands. Keep the target explicit instead of recovering it from a currently selected row; notification and properties-dialog entry points can refer to different UI state.
