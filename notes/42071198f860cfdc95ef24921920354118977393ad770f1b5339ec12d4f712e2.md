# New IMAP folders seed optimistic support bits before upload keyword filtering

CreateClientSubfolderInfo preserves existing imapFlags and ORs the user, forwarded and MDN-sent support bits into folder info. The later getter can load that persisted value, and move/copy keyword assembly checks the user-support bit. A mailbox specification can replace the support value through its setter. These are local source contracts; they do not prove server support, RFC behavior or a reproduced folder-copy cure.

Scope: Thunderbird IMAP new-folder keyword capability initialization.
