# Use link-role tokens without assuming AccentColor is a link color

The 2025 historical change adds LinkText and ActiveText values for link tokens in its unthemed branch. The fixed accepted variables now choose blue palette tokens in a not-prefers-contrast branch, while high-contrast button-link tokens use LinkText/ActiveText. Favor the newer accepted scope rather than prescribing the historical override everywhere. Recommend naming and choosing colors by semantic role; no contrast ratio or rendered theme validation was done. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
