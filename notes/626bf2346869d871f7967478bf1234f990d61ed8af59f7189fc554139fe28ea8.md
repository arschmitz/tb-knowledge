# Keep linked message images out of the click-to-zoom behavior

1021 skips images with an ancestor matching [href] in both the historical parsed-message pass and resize pass. The accepted parsed-message path still skips them before adding shrinktofit/overflowing state. The link keeps ownership of the click. The regression fixture includes a linked image and checks attribute state separately from fit width. The accepted resize logic now lives in MailMessageChild and retains the same ancestor guard; its primary-image click handler prevents default only for an overflowing image. No live link activation is inferred.

Scope: Linked message image interaction ownership.
