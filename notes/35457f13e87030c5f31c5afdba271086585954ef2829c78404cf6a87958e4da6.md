# Generated S/MIME error pages need a packaged theme stylesheet

The S/MIME error page is generated as a data URI, so its head explicitly links error-pages.css. Entry 1188 also packages that resource. At the fixed accepted revision, the stylesheet applies its dark colors only when the operating-system dark preference and mail.dark-reader.enabled both match. For this generated-page family, keep the HTML link, packaged resource and preference condition together. This is a scoped source pattern; contrast, layout and live error-page behavior were not tested, and review discussion remains pending.

Scope: S/MIME error-page theming.
