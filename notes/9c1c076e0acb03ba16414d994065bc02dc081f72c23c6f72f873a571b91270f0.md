# Use the folder system URI rather than a generic string encoder for tag folders

The 2024 special-character tag fix used ESCAPE_URL_PATH because encodeURIComponent and folder URL escaping differed. Newer accepted SmartMailboxUtils now records folder.URI when it finds or creates a tag folder, keyed by tag.key. Prefer that known URI in current code. Keep a special-character creation/deletion test so a display label, key and URL cannot produce duplicate folders. The getter may return an unknown URI if no mapping exists; do not promise that it creates a folder.

Scope: mail/modules.
