# Local move completion keeps its move flag while source streaming uses copy mode

The local destination still gives isMove to CopyMessageStreamListener but passes false to the source message service. The listener delegates move completion after checking EndCopy, and local EndMove returns on failed copy or m_writeFailed before reaching source deletion. The added test waits for empty source parent/child message counts after a successful move; it does not directly test source retention under a failed write. No disk-full/IMAP/native result is reproduced. Required primary comments 6 and 7 remain unavailable, so full-audit credit is zero.

Scope: IMAP-to-local cross-server move completion.
