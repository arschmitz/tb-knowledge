# Keep X-Priority parsing separate from numeric enum casting

The MIME adapter takes the first trimmed X-Priority character and maps 1 through 5 explicitly to highest through lowest; its comment says nsMsgPriority indices do not match header values. The current shared adapter preserves the mapping and falls back to Default for other characters. Use this protocol mapping instead of casting a header digit to the enum. This checked source path has no current outside population caller established here.

Scope: Parsed MIME priority mapping.
