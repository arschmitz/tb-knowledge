# Limit the remember-password label region with the actual layout container

The password form uses a native checkbox inside its localized label. The human fix adds align-self: start to the remember-password container so it does not stretch across the available area. Keep the native label association while adjusting the layout. The fixed accepted stylesheet retains that alignment, but its nearby spacing calculation differs from the original. Source inspection supports the layout intent, not a measured click region or screen-reader result. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / themes.
