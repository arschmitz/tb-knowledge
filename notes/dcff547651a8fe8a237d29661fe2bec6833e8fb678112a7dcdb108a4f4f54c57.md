# The content-script matrix excludes about:blank updates of the mail tab

The matrix tests web content in four target modes but excludes updateMailTabBrowser from the about:blank modes. The production update path constructs a triggering principal only after its content/protocol URL gate, which does not include about:. Principal support for about: targets therefore does not by itself establish that tabs.update can load about:blank into the mail-tab browser. This is a scoped source and coverage boundary, not a tested browser capability or universal injection policy.

Scope: Extension tab principal and target coverage.
