# Tokenizer reinitialization keeps an offset only when it retokenizes the same line

When the tokenizer buffer is absent, AdvanceTokenizerStartingPoint records whether AdvanceToNextToken will fetch a new line. It then returns if the buffer is still absent or the line had to advance, so an offset derived for the old line is not applied to the new line in that path. The exact called helper uses the same current-line/end-of-line condition. Later accepted bounds and caller guards are separate phases; this static inspection is not a crash reproduction or a general memory-safety proof.

Scope: IMAP generic-parser tokenizer state.
