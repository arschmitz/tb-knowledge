# Keep Account Hub DOM IDs, style classes and Fluent IDs in their local forms

The sync template uses lowerCamelCase IDs such as selectedAddressBooks/selectAllCalendars, kebab-case classes such as sync-type-container/select-all, and account-hub-* Fluent keys. Preserve these local names and the explicit selectors when adding sibling controls. This is an observed scoped naming pattern, not proof that every existing Thunderbird DOM ID or class follows it. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: Account Hub naming.
