# Linux sort glyphs use the shared ascending and descending images

The owned patch removes Linux-only image reversals, leaving the shared up image for sorting and down image for descending. Accepted CSS later reads aria-sort, which message and Address Book controllers write from their sort state. The checked generic test helper asserts header/persisted state, not glyph pixels, and has ten inherited assertions without messages. This is source proof of the mapping, not a Linux visual result.

Scope: Shared tree sort glyph state.
