# The Thunderbird gtest filter adds XREAppDir while platform routing stays separate

The Thunderbird gtest environment filter adds *XREAppDir* beside TestMail* and TestMsg*. Compiled test configuration loads that file for its platform configs, but the gtest project gate remains separate and still excludes macOS by default. This is an explicit selection/configuration change, not proof of native test execution or adoption of the upstream XDG path implementation.

Scope: Thunderbird compiled gtest selection configuration.
