# Remove collapsed tree children from layout only after their transition

TreeListboxMixin sets a collapsed child list height to zero, but hidden is added only when neither animating-collapse nor animating-expand is present. Expansion clears hidden before measuring scrollHeight. This makes completed collapse leave layout while allowing the transition to render. The fixture CSS uses overflow hidden and auto height rather than permanently display:none on collapsed rows. Existing selection/active-descendant rules are separate reused knowledge. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending.
