# Panorama per-folder databases are scoped adapters over one message store

Entry 2069 implements nsIMsgDBService in DatabaseCore. It resolves a folder ID, reuses a live weak-cached PerFolderDatabase for that ID, or constructs one over the shared MessageDatabase. ContainsKey and getMsgHdrForKey enforce folder ownership; listAllKeys and markAllRead filter folder ID. Message keys use nsMsgKey while folder IDs remain 64-bit. Many database/service methods remain stubs, so implementing the interface does not establish complete compatibility. Fixed source uses folder.id directly instead of recursive server-key/name resolution. Check exact method support, missing keys and cross-folder keys before using the adapter. No native build/runtime test ran.

Scope: mailnews Panorama legacy per-folder adapter.
