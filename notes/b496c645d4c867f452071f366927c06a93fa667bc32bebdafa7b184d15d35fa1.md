# Extend OpenPGP wizard names according to their local role

The keyWizard.js, keyWizard.xhtml and keyWizard.css family keeps the lowerCamel file stem. In this dialog, control IDs such as passwordConfirm are lowerCamel, reusable classes such as wizard-section and input-container are dashed, and Fluent IDs use the openpgp- prefix with dashes. Follow the existing role-specific names for additions to this family. Historical in-subdialog was a temporary sizing class and is absent from the current stylesheet. This is a scoped naming recommendation, not a rule for all Thunderbird dialogs. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: OpenPGP wizard names.
