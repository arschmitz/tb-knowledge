# QR image format is part of the renderer, tests and UI contract

Entry 1195 switches QRExport.renderQR from SVG to a BMP data URI, updates its return documentation and snapshots, and makes the image render with pixelated scaling. The fixed accepted renderer still returns bmp-uri. For this export surface, keep the documented MIME format, test expectations and image consumer consistent. The renderer, test and CSS changes were fully read; two huge encoded snapshot bodies were excluded from detailed inspection. No BMP decode, scan-quality measurement or export UI test was performed. Full bug and review discussion remains pending.

Scope: Mobile QR image rendering.
