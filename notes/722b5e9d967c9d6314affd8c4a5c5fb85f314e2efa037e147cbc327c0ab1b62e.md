# Storybook dependencies must be supplied by the story markup

The accepted create_story guide tells authors to include the relevant template and styles in rendered markup, rather than assuming the normal Thunderbird window has already loaded them. It uses a component-tag story filename, a slash-separated title and named stories; those naming rules already have a focused shared note. In this isolated Storybook environment, recommend making the dependencies visible in the story body so component appearance can be inspected without its application window. This is documented local guidance, not a test that every existing story is self-contained. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Storybook standalone markup dependencies.
