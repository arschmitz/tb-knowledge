# Bind Rust field expressions to named formatting arguments at this boundary

The adjusted 860 reland formats {id} and {ir} with explicit id = item_id.id and ir = is_read arguments. The original attempted {item_id.id} inside the format string. Manual syntax proposal for similar log calls: bind a field expression as a named argument and use that name in the format string. This gives the argument a clear local role and follows the accepted reland. The backout reports build bustage but contains no compiler diagnostic, so the specific build failure is not established. The current implementation no longer uses these unsupported-operation log calls; this is a historical syntax example, not an instruction to restore them.

Scope: rust-log-field-format.
