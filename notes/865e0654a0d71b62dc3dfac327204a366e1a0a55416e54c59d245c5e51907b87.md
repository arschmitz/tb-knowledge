# Publish useful private-source project claims as separate provisional lessons

For enabled project identities, publishProjectLessons creates new shared summary evidence and a provisional shared lesson. It keeps original lesson and private evidence IDs for audit. Raw private evidence and its exact private quotes stay local. A published summary is not independent verification. This is the console publication behavior, not a claim that the original interpretation is correct.

Scope: knowledge.
