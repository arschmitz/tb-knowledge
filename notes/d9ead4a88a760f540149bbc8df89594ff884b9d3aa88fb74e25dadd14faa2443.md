# Unchecked-row assertions do not separately check model and input state

The isSelected predicate combines the model checked flag with the input checked property using &&. A positive assertion proves both are true. A negative assertion only proves they are not both true, so it can pass when one state disagrees with the other. The tests therefore do not independently establish both unchecked states. This is a static coverage limit, not an observed synchronization failure.

Scope: Folder checkbox browser-test assertion scope.
