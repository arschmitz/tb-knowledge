# Message-body completion skips automatic-read setup when its mailnews URL has an error

After rejecting a stale channel, onBodyComplete checks the mailnews URL errorCode and returns before autoMarkAsRead when it is nonzero. NNTP puts failed-status or no-payload failure on that URL; listener completion status is a separate value. This prevents this body-completion path from setting up automatic read, while other preference, active-page, timer and manual routes keep their own contracts. It is not an NNTP-name-only check or a global read prohibition. No transfer or test ran.

Scope: NNTP error marker and displayed-message read boundary.
