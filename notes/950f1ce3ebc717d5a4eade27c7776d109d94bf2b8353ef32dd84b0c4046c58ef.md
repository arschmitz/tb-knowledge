# Outgoing security errors retain both status and transport security information

Accepted moz_http recognizes NSS transport failures and wraps the original nsresult together with TransportSecurityInfo; conversion back to nsresult returns that stored status. The safe outgoing listener forwards both to MessageSend, which checks NSS classification and overrides before notifying the compose security handler. Keep payload and numeric status together; an ordinary localized SMTP error string alone cannot supply the certificate context. This is static source and test-code inspection.
