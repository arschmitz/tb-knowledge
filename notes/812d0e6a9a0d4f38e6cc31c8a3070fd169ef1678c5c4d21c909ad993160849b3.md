# Mail protocol AsyncOpen marks replacement before the content security check

1354 sets LOAD_REPLACE before doContentSecurityCheck in both nsMsgProtocol::AsyncOpen and nsImapMockChannel::AsyncOpen, and accepted source retains that ordering. This is a specific channel/security integration contract. The paired triggering Gecko change and its runtime behavior were not established, so do not broaden it to every channel or claim that a security regression was reproduced. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/base/src.
