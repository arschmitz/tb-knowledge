# Treat a Taskgraph loader port as a schema and configuration migration

Moving to taskgraph.loader.transform changed the accepted field vocabulary from jobs to tasks across kind files, defaults, from keys and comm reference/merge loaders. The merge loader yields upstream references before local tasks. Update the interfaces together and inspect release consumers, not only the Python import. The historical missing-reference validation is not a current guarantee: the endpoint reference loader uses pathspec matching and comments out that older check. The original fix landed for bustage without prior acceptance; no graph or release pipeline was run here.

Scope: taskcluster.
