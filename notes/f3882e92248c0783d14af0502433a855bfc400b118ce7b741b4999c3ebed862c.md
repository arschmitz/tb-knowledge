# The Nova follow-up excludes category lists and connects button token families

The preferences override now applies to richlistbox except the actual categories navigation list, with shared inline-start padding and retained hover/selection/focus branches. Common popup item geometry uses explicit padding. Shared button hover/active names alias the existing state token family; input radius and toolkit primary-disabled background also receive aliases. These are selected CSS/markup relationships, not rendered dimensions, contrast or all-dialog correctness.

Scope: Thunderbird shared preferences control styles.
