# Spaces extension menu icons use the popup variable while toolbar and sidebar icons keep their own receivers

The follow-up separates .spaces-addon-menuitem from .webextension-action. Spaces popup entries set --menuitem-icon from normal/theme/dark icon variables, while toolbar action still uses list-style-image and sidebar img still uses content. Construction creates an iconic menuitem and forwards supported icon variables to it and the toolbar image. This records a specific receiver boundary, not a global property replacement. Primary Bug context has known gaps, so source publication has zero full-audit credit. No rendering, theme, accessibility or extension test ran.

Scope: WebExtension spaces popup icon styling.
