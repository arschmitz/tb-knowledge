# Header actions use the displayed message and actual window capabilities

The message-header include exposes the real Other Actions items and passes the displayed gMessage, plus gViewWrapper for a new window. Popup handling checks top-window tabmail, Gloda indexing and the about:3pane parent before showing the appropriate actions. The top-window command functions receive the message explicitly and own window/tab creation. Existing labels and access keys remain; the test checks menu visibility and tab mode rather than opened message identity. No fresh UI or accessibility result is established, and the missing numbered Bug comment keeps required context incomplete.

Scope: Message header Other Actions menu.
