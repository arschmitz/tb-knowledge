# A failed watched virtual-folder DB lookup stops folder-added scope updates

When a listener watches the added folder parent, OnFolderAdded now checks the virtual folder DB lookup result before reading searchFolderFlag. Failure returns the callback error immediately, so later listener/scope work does not run on that path. This guards a failed status, not every possible successful call with absent output, and does not recreate the database or prove the crash fixed at runtime. The legacy source-classification and saved-search tail remain separate. No crash test or build ran.

Scope: Legacy account-manager failure guard before folder-info access.
