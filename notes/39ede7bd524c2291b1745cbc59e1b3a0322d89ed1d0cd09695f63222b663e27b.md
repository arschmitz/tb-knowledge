# S/MIME header starts clear displayed algorithm text and localization state

The registered header-start listener resets the S/MIME algorithm globals and calls clearCryptoDetails. That helper also clears displayed text and cipher Fluent attributes, collapses the signature/encryption groups and hides/closes the disclosure. Global-state reset and DOM-state reset are separate actions. No new test directly checks this message-switch behavior, and no native UI or asynchronous-localization race was reproduced.

Scope: S/MIME security panel lifecycle.
