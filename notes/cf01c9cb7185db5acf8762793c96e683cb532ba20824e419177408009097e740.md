# A negative junk-shortcut check observes a finite wait window

The background-command test sends j while Account Hub is open, waits one second under an explicit lint exception, and checks that the spam icon is still hidden. This is a bounded negative observation. It does not prove that no delayed action can occur afterward. The close event listener is registered before each close action, and j/J checks before and after closure cover command restoration. Keep this local delay rationale separate from a general recommendation to use fixed waits.

Scope: Account Hub background-command tests.
