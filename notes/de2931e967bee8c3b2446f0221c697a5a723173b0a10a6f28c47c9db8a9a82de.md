# Compaction refusal diagnostics preserve the retry decision

The patch raises three IMAP compaction-refusal messages from Debug to Warning. CanCompactNow still returns false for pending pseudo/offline activity and a relevant offline-state query failure; StartNext queues that folder for retry. Unsupported offline operations remain a different case. This improves visibility of the reason without changing when compaction proceeds or proving that a later retry succeeds. No compaction ran.

Scope: Scoped source study.
