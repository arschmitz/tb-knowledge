# Wait for loaded message, flag notification and row rendering separately

selectNewMessage first checks new/unread preconditions, registers a folder flag listener and messageLoaded promise, changes selection, then waits for both completions and the row to lose new/unread properties. Preserve all three completion boundaries. A loaded message alone is not proof that the folder notification or row rendering finished. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
