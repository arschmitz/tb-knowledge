# Saved-search online eligibility is existential over all selected folders

The accepted saved-search properties code splits gSearchFolderURIs and uses some to find any server with offlineSupportLevel. It disables and unchecks Search Online only when no such server exists. A valid set preserves its checked state; selection order must not decide eligibility. The inspected browser regression test checks an existing online selection across repeated dialog openings, not every mixed-server ordering. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
