# The category-list margin was conditional on actual list items and is absent later

The original Calendar category patch applies margin-block-end only when the category ul contains li descendants. The component fills that list from categories, so an empty list avoids this added spacing. Fixed accepted CSS no longer has the conditional rule, and the component later reports zero-category row visibility. Keep the initial spacing fix separate from that later state; no rendered outcome or global CSS rule follows.

Scope: calendar-dialog-categories.
