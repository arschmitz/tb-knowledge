# Preserve the Calendar dialog name mapping across code, template and tests

The local mapping is calendar-dialog.mjs and calendar-dialog custom-element tag, CalendarDialog class, calendarDialogTemplate, calendarDialog.ftl, browser_calendarDialog.js and the matching calendarDialog.xhtml fixture. Proposed scoped naming convention: preserve the roles of dashed component names and camel resource/template/test names in this family, rather than changing every name to one case. No project-wide approval of that mapping is claimed. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
