# Graph expansion options are formatted before one outer query encoding step

ExpansionList replaces or appends an ordered vector of expansion properties and omits an empty pair. It joins properties with commas and uses literal expand without a dollar for all generated requests; the source comment gives an unverified delta-workaround rationale. ExpandOptions formats nested selection/filter clauses with semicolons inside property parentheses, then request construction applies the outer form serializer. Generated variants do not prove endpoint support. The initial tests check populated formatting/URIs, not replacement, empty queries or real requests. No new execution occurred.

Scope: Graph expansion query representation.
