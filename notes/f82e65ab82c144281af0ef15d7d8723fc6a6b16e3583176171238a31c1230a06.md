# Append the message body outside an optional attachment warning

The first inline OpenPGP landing appended plainText inside the unencrypted-attachment warning branch. A normal message without that warning could therefore lose its body. The backout is the exact inverse of the first landing. The reland’s functional correction moves msgContent += plainText outside the condition, then converts and displays it. Review acceptance alone did not ensure the first landing contained the requested change. Check a warning-free path as well as the path that adds a prefix. The exact failing harness case in the linked Treeherder run was not fetched.

Scope: OpenPGP backout and reland.
