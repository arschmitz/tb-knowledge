# Search shortcut tests changed key case at reland; the accepted matcher later normalizes case

The Search Messages reland changes open_search_window from lowercase f to uppercase F with shift and accel. At that landing, ShortcutsManager.matches compared event.key and shortcut.key directly. The fixed accepted matcher later lowercases both sides while keeping context and modifier checks. Test helpers must match the matcher at the inspected revision; source identity or an old case example does not prove the current contract. The backout says a test broke, but the exact failing log was not read. No keyboard test ran here.

Scope: Shortcut matching and search test helpers.
