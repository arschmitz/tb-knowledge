# The new folder-operation tasks drop their async helper completion

The new EWS and Graph move tasks call an async helper without await or return; the refactored EWS copy task does the same. The helpers await folder setup and copying before their placement assertions, but the task callbacks do not adopt those promises. Accepted tasks later await each helper. Keep the intended direct folder assertions separate from a claim that the original task runner waited for them.

Scope: Exchange move/copy unit-test task lifetime.
