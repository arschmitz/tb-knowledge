# Dispatch desktop search integration through platform modules

The ESM migration left SearchIntegration null in a folder-listener callback after a failed send. The accepted May patch makes SearchIntegration.sys.mjs a small dispatcher: Windows imports and constructs its module only when the Windows search helper contract exists, macOS imports its Spotlight module, and unsupported systems export null. SearchSupport.sys.mjs holds shared indexing behavior; moz.build packages only the matching platform module. This avoids runtime subscript globals. D208875 specifically requested a helper-contract check before construction. The patch had cross-platform builds and manual log checks, but no focused search test was added.

Scope: desktop search integration.
