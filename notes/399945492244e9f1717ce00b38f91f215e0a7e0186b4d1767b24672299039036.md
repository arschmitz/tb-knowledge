# Live-view mutations distinguish reserved children from loaded rows

The mutation landing treats a conversation count, a thread's reserved sparse child slots and loaded child rows as different states. Closed never-loaded rows adjust reserved length; expanded rows also clear the flattened cache and notify visible count changes. Final thread/group removal deletes its lookup entry. Adapter detachment passes its identity to clearListener so it cannot clear a different replacement listener. The original change appends new children and explicitly leaves ordering for a later phase. Accepted child sorting and native JSContext changes are comparison evidence, not part of this landing. Mock assertions exercise state/count paths when run; no runtime result or complete edge-case coverage is claimed.

Scope: Panorama live adapter add/remove state.
