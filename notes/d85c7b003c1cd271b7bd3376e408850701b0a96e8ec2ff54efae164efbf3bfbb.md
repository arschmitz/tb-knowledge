# Write native file permission modes as octal values

All three MAPI temporary-directory creation sites now pass 0777 rather than decimal 777. In this native file-mode scope, preserve octal notation so the literal represents the intended permission bits. The JavaScript attachment helper separately uses 0o700 and 0o600. This recommendation concerns numeric meaning; it does not justify copying the same permission policy between temporary directories. No Windows or file-permission test was run. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mailnews MAPI.
