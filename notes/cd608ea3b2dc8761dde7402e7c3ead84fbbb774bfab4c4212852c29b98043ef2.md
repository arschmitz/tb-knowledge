# Attachment-detach tests keep one logical scenario in one async task

The paired IMAP and EWS attachment-detach tests keep message setup, MIME discovery, detach and result checks in one async task. Local messageGenerator names differ from the shared gCallbackObject, and the callback uses a class with a deferred Promise. This makes one logical scenario readable and selectable for focused debugging; it is a local test organization pattern, not a claim that tasks normally run out of order or a global naming/class rule. Direct checks cover file existence, a single replacement message and AttachmentDetached text, not saved bytes or every attachment type. No test ran.

Scope: IMAP and EWS xpcshell attachment tests.
