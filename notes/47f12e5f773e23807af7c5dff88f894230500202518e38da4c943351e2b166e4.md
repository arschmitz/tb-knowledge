# Native account enum documentation preserves the Manifest V2 and V3 local-account names

The new account annotations describe none only through Manifest V2 and local from Manifest V3, matching the existing NativeMailAccountType schema choices. Other labels use protocol names, with Feed for rss. This adds documentation without renaming enum values or changing runtime account handling. External generated output was not inspected.

Scope: extension account enum documentation.
