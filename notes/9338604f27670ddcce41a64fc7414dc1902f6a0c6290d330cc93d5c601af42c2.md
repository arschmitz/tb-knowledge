# Initialize the folder-search shutdown state before querying it

The timer callback initializes isShuttingDown before passing it to GetShuttingDown and then branching on it. Review asked for this initializer because static analysis could otherwise report an uninitialized value. The checked historical and accepted source include it, although the review row remains marked Not Done. Preserve this local initialized output-parameter pattern when editing the callback. No static-analysis or runtime result was inspected.

Scope: Folder search shutdown query initialization.
