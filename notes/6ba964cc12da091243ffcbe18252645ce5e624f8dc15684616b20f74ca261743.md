# Use the COPYUID destination set in the Trash mailbox

After COPY to Trash, the parser saves the destination UID set from COPYUID. The deletion path parses it, builds compact UID ranges, selects Trash and marks/expunges those destination UIDs before reselecting the original mailbox. Preserve the mailbox ownership of each UID set; source message identifiers cannot be substituted for destination UIDs. No COPYUID malformed/missing response test or server execution was included in this landing. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Gmail destination UID ownership.
