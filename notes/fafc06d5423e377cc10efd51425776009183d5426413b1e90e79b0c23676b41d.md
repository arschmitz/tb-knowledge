# The Panorama count repair converts an output value instead of reinterpreting its storage

FolderInfo exposes32-bit count outputs while MessageDatabase writes uint64 counts. The repair gives the database a uint64 local, then casts that value into the legacy output. It removes the earlier cast of an int32 pointer to a uint64 pointer. Added assertions exercise public folder getters as well as FolderInfo properties; fixed source retains the adapter. The cast has no overflow check, and this does not establish all query-error paths as safe. No test or sanitizer ran.

Scope: Panorama legacy count storage width.
