# Route the legacy Exchange username state after discovery completes

The checked legacy account setup patch turns an Autodiscover401 failure into ExchangeUsernameException and stores it through the discovery error callback. Its all-finished observer exposes the username state only when priority discovery also failed; a successful priority result still wins. The username branch returns before configuration guessing. This landing updates legacy accountSetup.js, and its review explicitly leaves AccountHub for a separate update. At the fixed revision the old path is absent; selected newer FindConfig and AccountHub form/view use an error cause and username state instead. The current module test directly checks missing-versus-separate username authentication, without proving the old parallel UI race or the new view transition. No runtime test ran.

Scope: Account discovery authentication state.
