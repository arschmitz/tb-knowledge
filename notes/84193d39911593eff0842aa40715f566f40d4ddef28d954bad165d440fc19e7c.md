# Keep historical header chunking separate from the accepted UID handoff

The openFolder removal expanded historical header chunking to folders that were not displayed and revised the chunking test. That test is absent at the accepted endpoint. Accepted GetMsgHdrsToDownload now moves the entire pending UID array and resets it. Do not describe the old chunk-size preference branch as current behavior of this method. Its retired test is not runtime coverage for the current handoff. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP header handoff evolution.
