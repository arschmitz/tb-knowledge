# Cards View tag checks distinguish the shadow icon from the host title

The re-enabled task finds .tag-icon inside each tag host’s open shadow root, waits for visibility and compares the host title with tag-service display names. The actual component formats that title from valid tag keys rather than assigning a Fluent attributes object. After table/card switching the task reacquires row hosts and checks both titles, covering same-session view reconstruction rather than disk persistence, every locale or native accessible naming. No browser test was run.

Scope: Cards View tags regression and ThreadCardTags rendering contract.
