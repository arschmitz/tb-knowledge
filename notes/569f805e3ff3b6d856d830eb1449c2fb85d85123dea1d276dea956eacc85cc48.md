# Customization keyboard selection has no visibility guard for retained Chat nodes

The CSS leaves hidden Chat tiles in the DOM. The listbox key handler selects first, last or sibling elements; selectItem accepts a nonnull node and sets aria-selected and aria-activedescendant without checking visibility. Those complete helper bodies are unchanged between this landing and the accepted comparison. A hidden entry can therefore reach this unchecked selection path. No live keyboard, focus or accessible-tree result was observed, and other event paths were not exhaustively traced.

Scope: Unified toolbar customization keyboard selection.
