# Treat current, selected and focus as separate legacy tree states

The shared XUL tree CSS gives current+focus an outline even when the row is not selected. Selection without focus uses a muted background; selection with focus uses selected-item tokens. Calendar task text and untagged search results also distinguish selected from selected+focus. Inspect all of those states when editing this old tree family. These pseudo-element rules do not define styling for the newer tree-listbox controls, and static CSS is not a contrast or keyboard test. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/legacy-tree/state-style.
