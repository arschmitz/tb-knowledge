# Check accessibility after theme changes settle

In Bug 2061760 at revision 120631be1a28113287187f4b5bfc554a1fbc885f, the implementation report attributes earlier calendar-selector contrast failures to asynchronous theme transitions. It reports retaining mutation checks for earlier interactions and adding explicit axe scans after each theme, density, direction, and forced-color state settled, without disabling axe rules. For these dialog tests, distinguish transition timing from the accessibility of the final state and retain checks for both relevant interaction mutations and settled states. This is a reported local test repair, not proof that other contrast failures are timing issues or that live screen-reader output works.

Scope: Calendar dialog accessibility tests.
