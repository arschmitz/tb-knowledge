# Single-folder database closure differs from recursive ForceDBClosed

The historical CloseDatabase implementation closes this folder database, or asks the database service to close this folder, while ForceDBClosed iterates subfolders. FolderCompactor switches to the single-folder call; the fixed consumer still calls CloseDatabase after its start notification. Similar names do not imply the same recursion scope. Required Bug comments remain unavailable; this is source-only, not a proven compaction fix or an exhaustive current-native implementation review. No database test ran.

Scope: Compaction database scope.
