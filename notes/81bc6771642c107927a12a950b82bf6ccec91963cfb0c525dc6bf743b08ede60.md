# Virtual-folder query filtering and incremental matching have different coverage

The original virtual-filter landing only restricts messages to source folders and explicitly defers saved-search subsets. At the fixed accepted revision, Refresh builds supported saved-search SQL, but Matches still only checks source-folder IDs and retains a search-term TODO. LiveView uses SQL for queries and Matches before message-added listener callbacks. The current fixture asserts query subsets and creates a new view after changing terms; it does not establish automatic refresh or equivalent incremental term filtering. Preserve this distinction when evaluating coverage. No incorrect callback or runtime failure was reproduced.

Scope: Panorama LiveView virtual-folder filters.
