# Finish verifier cleanup before Account Hub sync discovery

The historical OAuth-only and password account-creation paths run verifier cleanup in finally around validation/completion, before fetching address books or calendars. Cleanup no longer depends on successful sync discovery. Current #createAccount keeps cleanup in finally and also clears verifier/abortable references; ConfigVerifier removes its temporary incoming server and listener. This is the production verification-resource boundary, not a requirement to add try/finally to tests or proof that all account creation/recovery paths succeed. No account setup or network test ran. The reviewer explicitly leaves page closure during the operation as a question; this source does not settle unload coverage.

Scope: Account Hub verification resource boundary.
