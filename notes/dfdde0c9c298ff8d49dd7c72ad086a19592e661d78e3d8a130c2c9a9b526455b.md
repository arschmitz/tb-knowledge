# Put an optional suffix quantifier on the intended character

The accepted address-book expression is http?s, which matches https and htts but does not match http. The mock exposed-protocol expression uses https?, so under that mock policy a valid http website would become plain text. The changed fixture covers https, xmpp and data, not http. Recommend an explicit scheme table covering both intended spellings when changing this helper. The separate Node expression check confirms only regex matching, not a Thunderbird failure or a full security assessment. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
