# Escape tag keys where they are inserted into CSS variable references

The accepted tag component builds var(--tag-${CSS.escape(key)}-backcolor), while the pane creates the corresponding tag color properties. Keep identity keys separate from localized names and escape the identifier when building this CSS reference. This is a current consumer pattern for tag variables, not a claim that every stylesheet value or every setProperty argument should be passed through CSS.escape.
