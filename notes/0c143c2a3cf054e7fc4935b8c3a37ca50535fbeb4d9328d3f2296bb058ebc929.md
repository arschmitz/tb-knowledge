# Panorama FolderInfo starts with a narrow flags-and-name contract

Entry 2074 adapts nsIDBFolderInfo through shared FolderDatabase and nsIFolder. The implemented surface is folderName and flags; most count, size, property and transfer methods start as NOT_IMPLEMENTED. Its test checks name and flag set/AND/OR values. Fixed source rereads flags by folder ID, propagates backend errors, persists the mask result, and then returns it; current selected tests also cover counts/properties. Do not infer unsupported metadata behavior from the interface name or treat a transfer property bag as a live FolderInfo. Check each method and current caller. Static source/test-code inspection only; no runtime test.

Scope: mailnews Panorama folder metadata adapter.
