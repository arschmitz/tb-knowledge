# Search-bar label and placeholder are separate accessibility inputs

The shared search-bar uses label for the shadow input aria-label and placeholder for the visible fallback slot. Changing one attribute updates only its own target. The 2024 change separated them, and tests cover initial and later updates plus fallback when a slotted span is removed. Current code keeps the split. An accessible search label should state the action without visual ellipsis or colon; a placeholder can show the ellipsis. D211135 review raised the spoken punctuation problem and the author made D211948 as the prerequisite.

Scope: Shared search bar accessibility and localization.
