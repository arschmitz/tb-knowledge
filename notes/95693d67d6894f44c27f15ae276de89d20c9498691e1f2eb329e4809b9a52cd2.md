# IMAP copy state carries the unread delta into pending folder counts

The copy-state constructor now initializes m_unreadCount to zero. The inspected producer fills it from message read flags, using a whole batch for same-server work or the current message for cross-server work. UpdatePendingCounts consumes the stored value to adjust server unseen and pending unread counts, then calls SummaryChanged. This ties the initialization to a real downstream delta rather than treating it as an isolated style change. No copy or count test ran.

Scope: IMAP copy unread state.
