# Debian 13 Docker reference additions select images without changing worker consumers

The Docker-image kind adds three upstream reference names: debian13-raw, debian13-base and debian13-amd64-build. The comm merge loader yields selected upstream tasks before local tasks; this config edit does not add recipes or change every worker image. The reference selector does not enforce that all requested names were found. Upstream image bodies remain unpaired, and no generated graph or container build validates them here.

Scope: Taskcluster Docker image imports.
