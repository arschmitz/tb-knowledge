# The OAuth token debug message interpolates the complete request form

requestAccessToken adds an authorization code or refresh token, an optional configured client secret and, for the PKCE authorization branch, its verifier to URLSearchParams. The added debug call interpolates that form immediately before fetch receives the same body. Accepted code retains it. This establishes the static logging input; it does not show that debug output was enabled, any real value was emitted, or any account was compromised. No credentials, request or logging flow was executed.

Scope: OAuth token-request diagnostics.
