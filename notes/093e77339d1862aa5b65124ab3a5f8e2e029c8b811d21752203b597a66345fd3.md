# Test shortcut tab reuse separately from shortcut view targeting

The shortcut test checks a fresh tab, the same reused tab after changing selection, and a new tab after removing the old one. A separate two-extension task checks only the requested extension is focused. These assertions cover different contracts; a correct about:addons URL alone does not prove tab reuse or extension targeting. The current test body matches the landing apart from its license header. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
