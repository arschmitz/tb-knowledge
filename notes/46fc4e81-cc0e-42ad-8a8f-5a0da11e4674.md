# Keep old and new Windows maintenance signing issuers during rotation

The installer records both current and previous certificate issuers during a signing certificate rotation. The May 2024 upstream port moved the former current issuer to CERTIFICATE_ISSUER_PREVIOUS while setting the new current issuer. The nearby code comment says both must coexist in the registry temporarily. This is a historical example, not a source for present certificate values. The patch was uplifted to ESR 115 to keep signing working.

Scope: Windows maintenance service installer.
