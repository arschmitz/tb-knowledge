# Account Hub password state uses checkbox properties and the remember-signons policy

Accepted EmailPasswordForm reads signon.rememberSignons through a lazy preference getter and updates defaultChecked, checked and disabled together. captureState returns password value and the checkbox checked boolean; setState resets the form and restores password focus. Preserve these distinct properties so a later form reset and a live preference change agree. Do not substitute the presence of a checked attribute for the current checkbox state.
