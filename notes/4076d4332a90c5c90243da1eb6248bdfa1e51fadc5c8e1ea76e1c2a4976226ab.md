# Cookie behavior fields select a separate branch from deprecated settings

If Behavior or BehaviorPrivateBrowsing is present, Cookies uses the modern mapping branch and keeps the default value of either omitted counterpart. It processes Default, AcceptThirdParty and RejectTracker only in the legacy branch, which copies regular behavior to private browsing. It then calls setDefaultPref for both preferences even for a lock-only configuration. These are call-site semantics; the schema and imported Gecko helpers remain separate validation boundaries.

Scope: Enterprise policy Cookies callback.
