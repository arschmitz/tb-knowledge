# Clear localized text as well as Fluent attributes when notification sources change

account-hub-header.showNotification first clears the previous notification. Accepted clearing removes the title Fluent ID/arguments and text, removes description Fluent ID/text, clears raw title/content and resets notification state. That prevents already-rendered localized text from remaining when the next notification uses a raw source. The tests separately check Fluent attribute reset and DOM description preservation; a full localized-to-raw transition with accessibility announcements was not run. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.

Scope: mail/components/accountcreation.
