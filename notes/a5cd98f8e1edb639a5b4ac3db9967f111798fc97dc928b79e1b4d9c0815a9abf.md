# The menu test waits for the URL that its extension will query

This landing passes https://example.com/?SomeTab to awaitBrowserLoaded before starting the extensions. The same test extension queries that exact URL and uses the first result as a tab. The shared helper adds a currentURI.spec equality predicate to its document/load-state checks. This establishes the local setup ordering; it does not reproduce a timeout or prove a browser-swap mechanism.
