# Use the installed update for the post-update page at startup

The 2024 port changed startup showWhatsNewPage to await getReadyUpdate. Bug 1906983 showed that this returned null after the update was installed, so the What's New page failed on the first post-update start. The later fix queried the installed update and added a browser test for this startup flow. Current code calls lastUpdateInstalled. Keep ready/downloading/installed update states distinct; test the first restart after a real update, not only the update button in preferences. The suggested missing import was investigated and discarded.

Scope: Application updates.
