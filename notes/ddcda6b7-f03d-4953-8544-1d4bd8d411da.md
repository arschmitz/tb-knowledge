# Delete obsolete capability flags through every caller and interface

The D210022 patch removed osVersionTooLow from the shared SearchSupport class and Windows implementation, and removed its checks from messenger startup, the integration dialog, and Preferences. The remaining osComponentsNotRunning flag has a different meaning: a supported integration whose required service is stopped. This is a scoped cleanup lesson: when retiring a capability gate, remove its definition and every consumer, then preserve other gates that still represent a real state. No dedicated test was added in this commit; existing browser preferences tests cover the remaining states in the current checkout.

Scope: Desktop search integration.
