# Test persisted folder settings by leaving and returning

650 changes the repair test to wait for allMessagesLoaded, then display another folder and return. That checks settings restored from the rebuilt database rather than only a repaint of the existing view. The current test checks sort type, sort order and grouped state. Its assert_visible_columns helper checks membership in both directions, even though its documentation mentions order; it does not compare column positions. Proposed manual test rule: name and document the property actually asserted, and use an order comparison when order is the intended contract. These assertions were inspected, not executed.

Scope: Folder repair test contracts.
