# Outgoing address collection runs before mail delivery and failure is advisory

Accepted _deliverAsMail combines parsed To/Cc and Bcc addresses, then calls collection before creating the outgoing listener/server path. Collection failures are caught and logged as nonfatal for sending. This describes a send-stage address-book side effect, not proof that a successful SMTP delivery is required before a card can be collected. This is static source and test-code inspection.
