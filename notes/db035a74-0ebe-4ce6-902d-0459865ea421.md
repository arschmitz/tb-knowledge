# Give search listeners an explicit owner and keep cleanup active in backoff mode

The shared search support class owns an nsIMsgFolderListener object that stores its SearchSupport instance in _searchIntegration; StreamListenerBase also receives its parent instance. This preserves access to indexing state when callback this refers to a listener rather than the module. When integration is disabled, SearchSupport still listens for moves, deletes, and renames so stale support files can be removed. Active mode additionally watches new messages and display events. The migration review identified listener scope as the hard part of replacing the old subscripts. A current-source copy guard still reads this.enabled on the listener object, so do not infer that copy behavior was fully verified from this patch.

Scope: desktop search integration.
