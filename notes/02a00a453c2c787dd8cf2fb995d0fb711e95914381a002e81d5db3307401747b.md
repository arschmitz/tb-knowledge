# Guard reparenting against roots, self-cycles and cross-server moves

The accepted moveFolderTo rejects a root child, rejects moving a folder into itself or its descendants, and rejects a different root. Moving to the current parent is a no-op. The code notes the cross-server restriction could belong in the nsIMsgFolder layer, but it still enforces it here. Preserve the present guards until an intentional change updates the callers and tests; a TODO is not authorization to remove a live guard. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama folder move guards.
