# The manual URL guard defers normalization while the host is being typed

The original input listener skips updates while the typed URL has a host but no following slash, to avoid writing a normalized slash into the middle of that host. Accepted current code keeps the guard in Exchange field capture and clears the derived hostname before returning. A validated value is written back to the input from the generic URI representation. The production placeholder gains a slash, while the isolated fixture still has the older hint. This is an editing-state constraint, not a general URL syntax or server-authentication rule; the tests do not cover every partial input.

Scope: account-hub-endpoint-editing.
