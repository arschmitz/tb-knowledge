# Free the attachment URL on the no-attachment early return

GenerateAttachmentData allocates urlSpec through several helpers. If body display detects that it equals the base message URL, the repaired path frees it before returning NS_OK. The later NS_NewURI path also frees it before checking that result. Recommend inspecting every return after acquisition in this function; one added free is not proof that all MIME resource paths are correct. This is source and test-code inspection.
