# Disable sync-account actions for discovery; delay only the spinner

startLoading disables the active subview and footer before awaiting address-book and calendar discovery. Both success and caught error stop loading; the three-second timeout only displays a spinner. Requests remain sequential and setState receives the completed arrays. Fixed source later adds centralized cancellation/empty-result routing. The initial patch has no new automated test; no account discovery ran.

Scope: Account Hub discovery UI completion.
