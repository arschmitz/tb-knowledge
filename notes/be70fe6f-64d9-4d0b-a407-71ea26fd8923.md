# Use graph parameters for the taskgraph diff base revision

The tgdiff source-test transform previously fetched hg json-automationrelevance and used the first changeset parent as base_rev. This patch uses config.params.get("comm_base_rev") for only the taskgraph-diff job, under MOZ_AUTOMATION and outside taskgraph.fast. It removes a network fetch whose revision may not exist in a local repository and follows the upstream migration to a minimal changed-files endpoint. The current source still uses this parameter. When inspecting a taskgraph diff, distinguish the configured comm base revision from a head revision or an ad hoc first parent.

Scope: Taskcluster taskgraph.

- `taskcluster/comm_taskgraph/transforms/source_test.py`
