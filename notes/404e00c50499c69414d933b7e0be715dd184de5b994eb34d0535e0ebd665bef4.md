# Embedding requests can return no vector

At TB Tools revision e1ebf2bf42e2d2530ad120fdcc7c5322e87ff4a0, the local embedding wrapper returns null when the worker is not ready or a request times out. It sends only the first 2,000 characters of each input to the worker. Callers must therefore handle missing vectors, and text beyond that limit does not contribute to the embedding. Worker-reported errors reject the request instead of returning null. This describes the supplied implementation on the unmerged codex/standalone-knowledge branch; the evidence does not show dedicated tests for these limits.

Scope: knowledge.
