# ClientClosed has different direct and EWS-wrapped native status mappings

The accepted shared ProtocolError conversion specializes XPCOM and HTTP errors and otherwise returns NS_ERROR_UNEXPECTED. The EWS wrapper separately maps ProtocolError::ClientClosed to NS_BASE_STREAM_CLOSED. Choose the actual conversion receiver before predicting the native result. A shared variant name does not establish a universal mapping or a reproduced failure.

Scope: Shared protocol error and EWS nsresult conversion.
