# Maildir scanning skips file-open failures before starting the message listener

NextFile loops past known directories and file-open failures, and opens the stream before OnStartMessage initializes the parser. Enumeration, listener, pump and read-completion failures still stop the scan. The final patch leaves EstimateFolderSize failure propagation intact; StoreIndexer checks that estimate before starting AsyncScan. No hidden-name or extension filter is adopted, and no runtime repair result is established.

Scope: Thunderbird Maildir folder scanning.
