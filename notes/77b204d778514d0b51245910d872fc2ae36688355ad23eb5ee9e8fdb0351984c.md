# Array contact conversion can return partial results

At revision 5bc47cc15bfa2aa6abfd4d6f4eff817b9503ac81, address-book node conversion uses Promise.allSettled for arrays and retains only truthy result values. A rejected child conversion therefore does not reject the whole array conversion, and null results are also omitted. Callers must not assume that output length matches input length or that successful array conversion proves every child converted. This applies to this convert implementation; individual node conversion can still reject. No runtime test is supplied.

Scope: WebExtension address book conversion.
