# Calendar certificate-dialog suppression is per host and time bounded

BadCertHandler shares a Map keyed by requestURI.asciiHostPort. It records the time before deferred dialog opening and skips another report only while that record is less than 5000ms old. Normal dialog completion deletes the key. A long-lived dialog can outlast the time gate, and exceptional continuation does not have a finally release. Treat this as a short suppression window, not a lock proving exactly one dialog for the whole user interaction. No certificate or UI test ran.

Scope: Calendar discovery certificate report throttling.
