# Rich-description clicks forward the anchor and event through the Calendar launch helper

The document listener finds the clicked anchor, returns early without one, and calls launchBrowser with href and the original event. Current launchBrowser handles button/protocol guards and cancels default handling on its ordinary external-open path. The integration test stubs that global, checks the forwarded HTTPS/mailto URI and cancels the event itself, so the test's hook assertions do not establish a real external launch or MailLink result. Conversion/sanitization remains a separate contract.

Scope: Calendar description link dispatch.
