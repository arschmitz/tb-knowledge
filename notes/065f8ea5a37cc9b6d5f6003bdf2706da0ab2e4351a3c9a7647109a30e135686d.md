# Graph operation request construction is separate from transport

The initial me::Get builds a relative GET /me request with a unit body and URL-encoded selection; its selected-request test checks the URI, not a network result. Current connectivity instead supplies an endpoint to a later builder, then sends the operation separately. The client calls build_request before passing the request to queued transport. Keep request shape, transport completion and Graph authorization distinct when interpreting builder tests.

Scope: Graph operation builder and client boundary.
