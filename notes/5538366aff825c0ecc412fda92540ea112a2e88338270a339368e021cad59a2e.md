# Give identifier mapping tests distinct domains and mixed edge cases

The historical database test chooses local message keys and deliberately different UIDs starting at 5000. It tests empty inputs, unset UIDs, sentinels, missing real keys and mixtures that preserve array positions. Local folders isolate the mapping contract from IMAP networking. The removed task is a useful test-design example, not a current integration test. Its array argument to the scalar getMsgHdrForUID API is not a syntax pattern to copy; binding conversion was not verified.

Scope: mailnews/db/msgdb.
