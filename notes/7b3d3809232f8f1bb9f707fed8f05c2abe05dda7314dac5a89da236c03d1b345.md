# DNS fixed-width and payload bounds checks have separate limits

The Unix DNS parser checks two- and four-byte reads against the reported answer length before calling native functions. It also checks the RDATA extent before mapping an answer. A bounds violation throws an explanatory Error through the worker promise, whereas failed search or name skipping can return an empty result. These guards do not validate every TXT sub-string, native ABI, or reported-length/allocation relationship. Later shared-worker serialization is separate. No crash cure or runtime result is claimed.

Scope: Unix DNS parser bounds.
