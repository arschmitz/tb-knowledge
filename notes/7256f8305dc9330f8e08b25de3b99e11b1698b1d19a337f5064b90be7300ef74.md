# Capture an OTR username before awaiting notification creation

notifyVerification copies context.username into cachedUsername before its await. It closes matching unverified notifications and later sets the user attribute using that string. Native context storage can change while appendNotification runs. Preserve the stable value across the await rather than dereferencing the old Context afterward. This patch does not prove all non-null native pointer lifetimes safe.

Scope: chat/modules/OTRUI.sys.mjs.
