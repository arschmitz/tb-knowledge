# Missing AppStartup guards have different callback and state effects

The AppStartup guards prevent dereferencing an absent service, but their outcomes differ. IMAP returns failure before its positive-shutdown listener notification. The search timer returns before InterruptSearch or normal completion cleanup. The compactor observer constructor can return before assigning its bare mIsShuttingDown member, which the accessor later reads. This source-level state risk is not proof of a reproduced crash or completed shutdown. Keep service absence, confirmed shutdown and callback/state completion distinct in these exact paths. No native test ran.

Scope: IMAP playback, search timer and compactor shutdown guards.
