# Keep the temporary and permanent RNP import policies aligned

The accepted _importKeyBlockWithAutoAccept derives permissive from !seckey, uses importToFFI for the temporary store, and adds RNP_LOAD_SAVE_PERMISSIVE to permanent-store flags only for public import. A scoped maintenance recommendation is to change these two import stages together if policy changes. The code proves the present policy; it does not prove a wider cryptographic rule or native-library safety. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/extensions/openpgp.
