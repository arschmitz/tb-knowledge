# Account Hub's initial-icon test selects validation images rather than provider-button images

This landing changes the initial hidden-image query from all img elements to img.form-icon. The inspected template puts form-icon on validation images and uses a separate class for the Thundermail button image. Later test steps still use the selected validation collection for success/danger checks. The hidden assertion's condition and icon.src message remain unchanged; the earlier proposed computed-style diagnostic is a separate suggestion. This is test scope, not a new production visibility guarantee or a rendered test result.

Scope: Account Hub browser-test image scope.
