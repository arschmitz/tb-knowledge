# Distinguish native return codes from caught errors and unused callback parameters

The OTR key-generation callback names its native result rv, turns a nonzero result into an Error, cancels an allocated newkey when the Promise fails and rethrows the caught error. InteractiveBrowser uses underscored positional parameters for callback values it does not use. These names communicate different roles. Preserve failure cleanup and callback arity while renaming for clarity. This is a manual proposal for these callback families, not a new rule duplicating no-shadow or no-redeclare lint, and no OTR worker or browser-auth runtime was executed.

Scope: chat/callback-role-naming.
