# Shared Graph hard-delete tests still assert the EWS deletion log

The common helper sets up the supplied mock server and waits for local folder disappearance. Its hard-delete and delete-from-trash callers still assert ewsServer.deletedFolders even when called with graphServer. These assertions therefore do not directly prove Graph remote deletion. The original Graph soft-delete task is disabled; it is enabled in the accepted comparison. No pass, false pass or failure was reproduced.

Scope: Exchange and Graph folder deletion assertion scope.
