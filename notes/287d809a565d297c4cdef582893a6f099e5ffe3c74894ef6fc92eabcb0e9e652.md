# Documentation staging now uses a literal root index without generated category validation

The reorganization removes categories and root-index placeholder formatting. Component trees remain explicitly mapped in doc_trees, while the root index names literal pages. The manager stages those trees and directly links or copies index.rst; the Sphinx extension then uses that staging directory. The former uncategorized-tree completeness check is also removed, so explicit mapping alone does not prove every topic is linked from the root. No documentation build or live reload ran.
