# Historical NTLM setup splits domain and username once before module initialization

In the owned historical NTLM implementation, a domain\\username credential is split at its first backslash. Without a backslash, the domain stays empty and the original username remains. Both values are converted to nsString and passed to Init. The reviewed split_once(...).unwrap_or(...) form is actually landed. This is a historical input-adaptation change; the accepted shared provider later delegates NTLM to Necko, so it is not a claim about the current wire authentication flow or a reproduced login fix.

Scope: Exchange NTLM credential validation.
