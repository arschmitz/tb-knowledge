# Gloda indexing tests distinguish recovery from cleanup

The current helper tracks recovered, failed-to-recover, cleaned-up and no-cleanup counts separately, and compares only expectations that are non-null. Recovery and cleanup are different outcomes; zero is a valid expected count. Keep these counters distinct when adding error-path assertions.
