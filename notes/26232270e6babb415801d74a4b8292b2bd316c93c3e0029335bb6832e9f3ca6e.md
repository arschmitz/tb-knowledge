# The JavaScript send report marks display before formatting and prompting

The removed native display method sets mAlreadyDisplayReport after its prompt work. The new JavaScript method sets #alreadyDisplayed immediately after its guard, before formatting and alerting, and reset clears it. A synchronous formatting or prompt exception leaves that flag set until reset. This is a static ordering difference, not an injected failure or reproduced missing/repeated dialog. The JavaScript method also appends any truthy error detail without the old equality-based text de-duplication.

Scope: Thunderbird send-report duplicate display state.
