# Await both asynchronous image checks before continuing the EML scenario

In the historical722 test, check_image_size is async and waits for image.complete. The first caller awaits it, but the following cidImageOrigin caller does not. Proposed improvement for this exact test: await the second returned promise before continuing the copy and teardown scenario, so its image checks remain part of the ordered test. This omission predates the new copied-message state wait. The filed intermittent failure concerns an empty destination folder; no evidence here establishes the unawaited helper as its cause. No race or runtime failure was reproduced. The exact historical source is primary evidence; this is a scoped provisional test proposal, not a new user rule.
