# Put architecture in the Treeherder group, not a duplicate child suffix

758 adds architecture-specific toolchain groups such as TLA64 and TMA64, then assigns libotr tasks to those groups with the child label libotr. Current group definitions and libotr references retain that organization. Proposed scoped naming rule: keep the target architecture in the declared group and match references to it rather than repeating the architecture in each child symbol. The displayed name is not evidence that a task is currently scheduled or that chat functionality is supported on every platform.

Scope: Toolchain display naming.
