# The initial HTTP-auth port used empty realms and a request-level cache identity

This landing sends Basic and NTLM credentials to nsIHttpAuthManager before each request. The provider constructs the lowercase AuthType variant and splits a backslash-qualified NTLM username, but sets realm and path to None; the mock challenges temporarily remove realm=test and name a follow-up. OAuth continues to supply its own bearer header. Fixed accepted code later moves cache handling to a provider-backed manager and restores realm-bearing mock challenges. Those later changes do not extend this original landing's coverage. Necko cache matching, copying, connection affinity and native authentication were not independently exercised or established from the Rust comments.

Scope: Exchange HTTP authentication.
