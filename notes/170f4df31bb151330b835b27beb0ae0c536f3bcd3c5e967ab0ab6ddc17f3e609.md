# The EML performance fix moves the discriminator before expensive header lookup

The 1953 diff reads the message key before GetMessageHeader and takes OpenFileSocket for key zero. Its comment explains that header lookup otherwise walks folders looking for a database matching the external file path. That is a reported mechanism tied to this protocol path and matches the accepted early branch. Proposed performance regression check: open an external EML with many folders and verify that the header-lookup path is bypassed; no timing or folder-walk trace was collected here. Folder-backed nonzero lookup and its failures remain separate. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.
