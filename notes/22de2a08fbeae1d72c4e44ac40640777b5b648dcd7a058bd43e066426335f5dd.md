# Known-fingerprint key refresh bypasses the HKP search branch but keeps the existing import-result checks

The key-details refresh now passes its existing key fingerprint to downloadDirectlyByFingerprint. That entry point sets skipSearch=true, selecting downloadNoImport instead of the ordinary HKP/HKPS search-and-download branch. The shared parser/import path still decides keyImported and handles unchanged or collected keys, and the UI updates only for a true imported result. The local direct-download wrapper delegates to its selected backend with import=false. This is a dispatch and caller contract, not a guarantee about a server response, key validity or successful import. No keyserver or crypto test ran.

Scope: OpenPGP key refresh.
