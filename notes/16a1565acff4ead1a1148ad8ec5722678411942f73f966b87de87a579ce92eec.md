# Keep public cookieStoreId values separate from native userContextId

A space tab converts public cookieStoreId through the framework helper, or uses DEFAULT_USER_CONTEXT_ID. The accepted test checks firefox-default and firefox-container-1 after opening/querying real space tabs. Preserve these compatibility strings even in Thunderbird. The added popup tests also require cookies permission and reject invalid/private IDs; this is not proof that the entire framework permission implementation was read or that every space permutation was tested. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces cookie context.
