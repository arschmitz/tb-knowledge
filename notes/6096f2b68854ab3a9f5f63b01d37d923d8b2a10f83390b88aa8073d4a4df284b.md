# A returned Gloda collection can still be empty until query completion

getMessageCollectionForHeader and getMessageCollectionForHeaders return collections populated asynchronously. A header may also have no indexed Gloda message at all. The multi-header implementation groups by folder and unions folder/message-key clauses. Consumers need completion-listener logic and cannot infer a one-to-one indexed result merely because the API returned a collection. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/db/gloda.
