# Folder-ID path tests keep literal percent-name roundtrips deferred

The migration derives paths from current parent/name rows and percent-encodes slash characters in each name. Lookup performs general percent decoding before NFC-aware name lookup. Active direct tests distinguish slash separators from escaped slashes and check case sensitivity and equivalent Unicode names. The examples for a literal I%2FO name remain commented out with a TODO, so they establish no executable or passing roundtrip coverage. The same deferred block remains in the fixed accepted source. Keep literal percent-name behavior separate from verified slash/NFC examples. This is static inspection; no test or path roundtrip was run.

Scope: Panorama folder path escaping and direct-test limits.
