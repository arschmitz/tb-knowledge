# The tag overflow test computes its expected count with the locale formatter

The tag-overflow test constructs Intl.NumberFormat with the default locale and signDisplay always, then compares the counter with format(2). It does not hard-code an en-US +2 string. Separate assertions require the tooltip to contain each displayed tag name. These checks adopt the scoped review requests for this component; they do not establish exact tooltip punctuation, all locales or a general rule to duplicate implementation logic. No browser or locale test was run.

Scope: Tag component browser-test expected values.
