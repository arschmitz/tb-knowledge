# Unobtrusive main-part encoding relaxes a force flag while the encoder keeps its own checks

For signed-only unobtrusive mode, the main-part helper clears the force-encoding request for TAB/CR/LF and printable ASCII content. The same helper serves HTML, direct plain text and derived plain text. MimePart still asks MimeEncoder to select encoding, and the encoder retains independent long-line, null and content checks. The new flowed text/plain unit cases compare CTE strings only; they do not establish HTML, signing, canonicalization or sent-message behavior.

Scope: Signed-only MIME main-part transfer encoding.
