# Address Book table rows avoid the card-list block padding

The #cards rule supplies the top border in both layouts. Only rows=ab-card-row receives 2 px block padding. The actual layout toggle selects ab-table-card-row for table mode, so that padding rule is limited to list rows. The same patch supplies explicit sidebar color defaults before their aliases. These are selector and token contracts; no visual or contrast result was measured.

Scope: Thunderbird Address Book list and table layout.
