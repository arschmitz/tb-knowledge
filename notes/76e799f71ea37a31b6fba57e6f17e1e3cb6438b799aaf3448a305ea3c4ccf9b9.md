# Keep Panorama C++ file and interface names in their current family

The component pairs FolderDatabase.cpp/FolderDatabase.h and FolderComparator.cpp/FolderComparator.h with their PascalCase classes, while its exposed interface file is nsIFolderDatabase.idl and implementation metadata names mozilla::mailnews::FolderDatabase. Accepted headers use full COMM_MAILNEWS_DB_PANORAMA_SRC_ guards instead of the initial short FolderDatabase_h__ form. Use the current family when adding related files. Parameter names are mixed during migration, so this evidence does not justify a blanket a-prefix rule. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama C++ file and interface naming.
