# Guard the specific observer removal on repeated server shutdown

MsgIncomingServer.shutdown removes its password-manager observer only while _stoppedObserving is false, then sets the flag after successful removal. Other connection/log cleanup remains outside that guard. This prevents that selected duplicate-removal call; it does not prove every shutdown side effect is idempotent or cover re-registering an already shut-down object. No shutdown test ran.

Scope: Guard the specific observer removal on repeated server shutdown.
