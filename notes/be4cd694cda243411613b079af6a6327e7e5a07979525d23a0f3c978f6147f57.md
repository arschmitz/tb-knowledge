# The checked-command follow-up and accepted menu targets are different phases

The original follow-up centralizes checks on cmd_* elements and changes the direct visibility helpers to assert those command attributes. At the fixed accepted revision, View initialization writes pane menu/appmenu items directly and the folder-pane helper asserts menu_showFolderPane again. Preserve both source phases; original approval or command-only assertions do not prove native menu propagation or survival of that implementation.

Scope: Mail menu state synchronization.
