# The date-row removal assertion message reverses its hidden-state expectation

The historical entry 2131 test removes repeats and asserts BrowserTestUtils.isHidden(repeatsIcon), but its message says Repeats shouldn't be hidden again. The fixed0b93 test retains this contradiction. A focused proposed wording is: The repeats icon should be hidden again. This is an assertion-diagnostic correction supported by the direct predicate and preceding action; it is not a reproduced product visibility defect or an applied code change. No test ran.
