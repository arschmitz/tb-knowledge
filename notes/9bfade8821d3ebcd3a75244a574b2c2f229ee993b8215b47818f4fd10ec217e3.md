# Apply all three folder view fields and release the opened database reference

The Appearance commitViewState callback skips server roots, copies viewFlags, sortType and sortOrder into dBFolderInfo, then sets folder.msgDatabase to null. Keep the three persisted fields together; updating only a visible tree would not update stored folder settings. Releasing the reference is explicitly documented to avoid memory bloat. This is an observed local persistence and lifetime contract, not proof that every database is closed or every write is flushed immediately. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
