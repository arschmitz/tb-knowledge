# Do not overwrite extension startup data with dynamic theme state

The current Theme constructor saves startupData only for extensions whose type is theme; extensions with theme permission take a separate path. Startup data supplies early fallback styling before this API loads. Preserve owner-specific cached data when dynamic theme.update changes the current theme. Current storage contains lwtData only, unlike the older multi-field cache. Upstream review context remains pending.

Scope: mail/components/extensions/parent.
