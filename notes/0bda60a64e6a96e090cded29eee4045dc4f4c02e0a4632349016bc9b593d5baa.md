# Clone Exchange alternatives before changing their protocol-specific settings

Accepted ewsifyConfig clones the Exchange incoming server, changes the copy to ews, clears add-on-dependent fields and disables global preferred-server reuse. The includeExchangeAddon argument decides whether to retain the add-on config and append native alternatives or replace Exchange primaries and alternatives. That boolean describes coexistence, not general server eligibility. The older OAuth scope lost write is already a separate shared lesson; this current function no longer contains that assignment sequence. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/components/accountcreation.
