# Merge notifications declare the same Matrix room for both level branches

Both level 3 and default branches declare pending and resolved notification routes to the same room. The task adds the Matrix route scope and a message containing task name, state and URL; its dry-run suffix is conditional on the payload property. Accepted code retains the envelope with a later worker. The configuration alone does not prove delivery, imported template expansion or a separate staging room.

Scope: Release merge task notification configuration.
