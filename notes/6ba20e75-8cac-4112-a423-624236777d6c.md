# Cross-folder rebuilds must preserve sort metadata and persistence

In threaded/grouped cross-folder views, RebuildView can bypass normal Sort. UpdateSortInfo and SaveSortInfo must run before rebuild so the prior primary column/order survives as secondary, including custom column details. UpdateSortInfo does not update primary sort type/order. Keep metadata update and persistence calls separate where that makes save sites visible; a review suggestion to merge them was considered and rejected, and the accepted/current code keeps both calls.

Scope: mailnews/views.
