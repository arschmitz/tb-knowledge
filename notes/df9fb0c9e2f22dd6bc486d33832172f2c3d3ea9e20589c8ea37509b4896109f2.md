# The key-expiry test helper adds one minute only for nonzero day offsets

changeKeyExpire uses local setDate to add the requested days, then adds60000ms before converting to the key-relative expiration value. That branch runs for nonzero day offsets, including negative values; zero maps to no expiry without the margin. The soon-expiry test sets10days before opening compose and checking the 10day message. The margin provides comparison time but does not freeze the clock or prove every boundary/stall safe. No key-expiry or notification test ran.

Scope: OpenPGP test wall-clock expiry setup.
