# Graph OAuth customization carries the server type into its preference branch

The original change uses the incoming or outgoing server type to choose mail.<type>.server.details.<hostname>. and extends the existing Exchange advanced-settings path to Graph. The advanced panel keeps the existing feature-pref gate. At the accepted revision, the type is still passed through the Rust factory call, while a later username component and ForAccount lookup distinguish accounts. This describes the preference/caller boundary, not successful provider authorization or a runtime test.

Scope: Exchange and Graph custom OAuth preference lookup.
