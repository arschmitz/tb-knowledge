# Check tracker return types against Map iterators and missing lookups

SpaceTracker.getAll returns Map.values(), although JSDoc says SpaceData[]. Callers deliberately iterate it or spread it into an array. fromSpaceButtonId returns null for missing data despite a non-null JSDoc type. Document the iterator and nullable lookup results when maintaining this module; a written type is not proof of the runtime shape. No generator/type-check failure was run. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces return documentation.
