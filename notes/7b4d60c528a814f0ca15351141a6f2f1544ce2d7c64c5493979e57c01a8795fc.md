# Mork row access guards remain separate from the non-arena cleanup branch

GetOid and GetRowCellCursor reject a missing wrapped row. GetProperties clears its output, returns empty success for absent database state or a successful null cursor, and propagates cursor-acquisition failure. CutAllRows severs row/store links only in its non-arena branch; the fixed config enables zone arenas, whose branch returns zero. These conditional and null-state checks are source contracts, not proof of complete teardown safety or eliminated crashes.

Scope: Mork detached row and header property access.
