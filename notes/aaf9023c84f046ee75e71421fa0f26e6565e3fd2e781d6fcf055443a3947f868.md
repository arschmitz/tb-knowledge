# The Exchange type heading test checks its Fluent ID

Both the production subview and isolated fixture provide account-hub-exchange-type-title. The actual AccountHubStep receiver applies that ID to the slotted title. The new test reads the nested title's localization attributes and asserts the ID; it does not directly assert translated text or an accessible name. Keep that direct assertion scope separate from the header's live presentation.

Scope: Account Hub Exchange type heading and component test.
