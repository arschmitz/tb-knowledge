# Graph sending originally created and sent a draft before later DSN and Bcc support

The original landing creates a base64 MIME draft and then sends its returned ID. Its DSN and Bcc inputs are deliberately unused. Fixed accepted code inserts a property-update request for those values between creation and send. Each await can fail after earlier server state already changed; the inspected operation contains no compensating cleanup request. Success follows the final request, not proof of recipient delivery. Keep the original two-request implementation separate from the later three-stage path. No Graph or failure-injection test ran.

Scope: Graph outgoing request phases and callback boundary.
