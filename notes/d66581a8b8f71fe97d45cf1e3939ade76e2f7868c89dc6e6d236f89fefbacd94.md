# Reused AutoTreeView checkboxes replace their row-bound handler

The cached row fragment gives recycled rows persistent checkbox nodes. Each fill sets checked state and replaces checkbox.onchange with a closure for the current viewRow, then refreshes the row's properties after a toggle. Visible cells also clear ariaLabel/title before new content is applied, and reset discards the layout fragment. Preserve state and callback replacement when reusing the structure; a clone or cached fragment alone does not reset data from the previous row. No live checkbox or recycling test was run.

Scope: AutoTreeView recycled cell state.
