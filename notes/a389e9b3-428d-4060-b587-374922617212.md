# Keep compose and message display registration return values aligned with the scripting contract

Bug 1897920 corrected Thunderbird scripting.compose.registerScripts and scripting.messageDisplay.registerScripts after Bug 1896870 and upstream behavior showed the MDN return-value description was wrong. Registration now resolves without a scripts array. The schema callbacks have no parameters, and browser tests verify registered details through getRegisteredScripts instead. When changing an extension API, update implementation, schema, and tests together, and confirm the upstream contract rather than relying on a single documentation page.

Scope: Extensions API.
