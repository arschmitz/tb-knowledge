# Filter action maintenance points to the checked C++ log-message array

The action-constant comment points maintainers to kActionLogIds[] in nsMsgFilter::LogRuleHitGeneric. The actual logger indexes that array only after checking a nonnegative action type, array bounds and a nonempty entry. The source requires these two manually maintained representations to stay aligned; the comment does not enforce synchronization. The Fluent migration's removal of filter.properties does not remove the C++ mapping.

Scope: Filter action IDL and log localization.
