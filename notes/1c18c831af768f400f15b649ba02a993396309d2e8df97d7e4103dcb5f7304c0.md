# Retain local test names without turning legacy snake_case into a global rule

The legacy shared-module helpers use verb-oriented snake_case names such as focus_message_pane, set_mail_view and delete_all_existing, while the extension command test file preserves the public lowerCamel API suffix openShortcutSettings. Recommend matching the neighboring test family and naming the state actually checked. These examples justify local consistency, not a project-wide requirement that all new tests use one casing. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/test/browser.
