# Remove hidden protocol fields from native form validity

When incoming protocol groups become hidden, the form remembers required fields with data-was-required, toggles required, clears custom validity and resets aria-invalid. Completion combines AccountConfig completeness with the form check. For this protocol switch, hiding a field alone must not leave a required invalid control blocking the visible form. The inspected source does not clear every possible description attribute in that loop, and no assistive technology result is claimed. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub protocol visibility and validity.
