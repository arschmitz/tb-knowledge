# Close a backup database even when the main database is absent

Current Shutdown separately closes and nulls mDatabase and mBackupDatabase; the destructor calls Shutdown(false). The backup can exist without the main database, so nesting its cleanup inside the main guard can leave it open. Cleanup conditions should track each owned resource. No runtime lifetime/leak test was run and no broader listener-cycle fix is asserted.

Scope: mailnews/base/src.
