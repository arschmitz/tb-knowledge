# Preserve notification wire names separately from markup names

The story passes CTA and URL exactly as payload keys; the component maps them to cta and url attributes. The widget tag and CSS classes are dashed, while template IDs are lowerCamelCase and the exported story/class use UpperCamelCase. Follow this local mapping rather than renaming wire fields to match HTML attributes. This is a scoped naming recommendation, not a global casing rule. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: In-app notification namespace naming.
