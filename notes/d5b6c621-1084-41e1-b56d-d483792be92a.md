# Renaming a folder cache key invalidates old element handles

Folder cache elements use a message database path as their key. The key can be renamed to preserve cached data when a folder moves, but setting it invalidates other outstanding nsMsgFolderCacheElement handles. The May 2024 patch added the setter and a collision test; it did not itself update every folder move call site.

Scope: folder cache.

- `mailnews/base/public/nsIMsgFolderCacheElement.idl`
