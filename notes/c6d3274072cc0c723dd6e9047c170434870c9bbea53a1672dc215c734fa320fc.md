# The token API port narrows the primary-password helper's direct assertion targets

The port removes checkPassword assertions that directly checked the old/new password values. The QR helper instead calls changePassword and asserts whether hasPassword matches the presence of a new password; the privacy test retains password-present and checkbox-state assertions after removing its direct value check. Accepted QR source later awaits changePassword. Keep presence/state assertions separate from a direct chosen-password-value assertion. This is inspected test code, not a new token or browser-test result.

Scope: QR export and privacy browser tests.
