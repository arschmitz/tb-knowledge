# Keep Storybook import exceptions within their actual flat-config scope

The accepted config enables import/no-unassigned-import for .mjs modules, then turns it off for *.stories.mjs because stories import element registration and CSS for side effects. The same story block also disables unresolved-import checks, and a separate .storybook module block handles unavailable Node dependencies. These are separate file-role exceptions, not permission to omit imports or disable checks in privileged production modules. The original port removes matching inline suppressions from stories. Resolved plugin configuration and Storybook/lint execution were not evaluated.

Scope: Flat-config Storybook import boundaries.
