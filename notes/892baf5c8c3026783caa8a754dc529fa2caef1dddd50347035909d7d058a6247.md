# The Tasks View menu refreshes its checks from pane and tree state when opened

The menu’s popupshowing listener reads actual pane visibility and selects tree filterValue, then radiogroup value, then all. Menu and sidebar commands call taskViewUpdate, which synchronizes checks and the selected radio before updating the custom task tree filter. This replaces the old shared-command wiring in the five owned paths. It is a source-level state contract; no task-data, keyboard, persistence or accessibility test ran.

Scope: Calendar task filter menu state.
