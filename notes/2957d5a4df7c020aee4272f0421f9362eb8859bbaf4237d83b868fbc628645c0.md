# The STARTTLS failure check also accepts its own unexpected-success error

The test throws an Error if the URL listener unexpectedly fulfills, then catches any error and merely checks that it is truthy. That same catch accepts the synthetic error from the success branch, so this check alone does not establish that the URL listener rejected. The exact chain persists in the accepted source. A rejection-specific assertion outside a catch for the success sentinel would preserve the intended distinction. This conclusion follows from the source; no STARTTLS experiment ran.

Scope: IMAP STARTTLS failure test promise chain.
