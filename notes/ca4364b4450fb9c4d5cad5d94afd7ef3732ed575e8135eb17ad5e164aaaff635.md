# The search-policy port calls direct module and engine objects in its tests

The Thunderbird port removes wrappedJSObject from the imported SearchService reset and from engine icon, charset and POST-method assertions. setupPolicyEngineWithJsonWithSearch resets, installs policy, registers the settings-write notification, awaits initialization and returns that notification promise. Its callers still await policy setup before reading engines. This is a test receiver/API migration; the unpaired upstream engine body was not inspected and no search-policy run was performed.

Scope: Enterprise search policy tests.
