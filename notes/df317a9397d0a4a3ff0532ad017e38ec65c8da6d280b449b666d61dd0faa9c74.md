# Match Windows toast icon registration to the packaged Thunderbird path

1012 removes the inherited browser directory from IconUri. The accepted installer registers $INSTDIR\VisualElements\VisualElements_70.png, and Thunderbird's package manifest places that asset under VisualElements beside the executable. Compare installer paths to package paths before porting browser registration code. This is a source packaging check; no Windows install or toast display was run.

Scope: Windows toast icon packaging path.
