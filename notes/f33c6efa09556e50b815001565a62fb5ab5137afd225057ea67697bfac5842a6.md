# Forget saved folder selections before deleting the test account

The thread-tree test cleanup clears saved selections for its three folder URIs before removing the account. The fixed accepted implementation names this operation forgetSavedSelection and deletes the appropriate key from its internal saved-selection Map. Retain that cleanup ordering when adding folders to the test. Static inspection supports test-state isolation; it does not prove an observed memory leak or cross-test failure.
