# Reject invalid notification dates and preserve inclusive endpoints

NotificationFilter rejects NaN start/end values and start>now/end<now. The endpoints are inclusive. Comparison alone against an invalid Date NaN would not reject it. Preserve explicit invalid-data handling when shortening these guards. No time-boundary runtime test was run by this study.

Scope: notifications.
