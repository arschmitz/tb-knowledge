# The charset widget awaits Fluent labels while keeping encoding values

The picker derives 17 lowercase charset-* message IDs from its encoding values, requests its own Fluent resource and awaits formatValues before appending labels with the original encoding values. Existing UTF-8 precedence remains in its sort. The recipe targets the same 17 IDs from old properties keys, and its accepted archive body is identical. This describes the component data/resource boundary, not a localization run, build result, reentry guarantee or global Fluent import rule.

Scope: Charset picker Fluent initialization.
