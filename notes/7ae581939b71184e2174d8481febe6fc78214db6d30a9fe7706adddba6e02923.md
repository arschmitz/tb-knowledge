# Keep image zoom and resize transitions in the message actor

Current MailMessageChild receives click and resize events in the message document. A valid left-click image with overflowing toggles shrinktofit; broken image requests do nothing. Resize recomputes overflow for fit-mode images and restores fit mode when an enlarged image no longer overflows. HTTP content and images in links are excluded. The historical parent aboutMessage.js resize function is gone, so new work should follow the actor rather than recreate that retired handler. Pointer, keyboard and platform behavior were not exercised.

Scope: Message actor ownership.
