# TagTracker emits one lifecycle event at the native preference boundary

The native AddTagForKey writes tag, then ordinal, then color. TagTracker waits for the final color notification before emitting tag-created and uses only removal of the tag property for tag-deleted. It caches previous values and emits tag-updated with only the changed property and its old value; normalized color changes that compare equal do not emit. Keep this write order and observer contract together when changing tag storage. Static tests and source were inspected; event counts were not executed. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mailnews / base.
