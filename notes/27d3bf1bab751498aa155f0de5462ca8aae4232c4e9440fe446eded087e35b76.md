# Folder context eligibility uses OR inside the accumulated selection predicate

For each evaluated selected folder, context-command eligibility allows an online application or a server without offline support. The outer online &&= preserves the combined selection condition. Using AND inside that predicate rejects offline-capable folders even while online. cmd_deleteFolder separately requires deletable. This change concerns command availability, not the protocol deletion operation or a successful live multi-folder action.

Scope: folder-context-multi-selection-online-predicate.
