# Pass the authentication argument object into AutoDiscover retries

In the Basic authentication retry path, startFetchWithAuth adds username and password to args, then calls setUpAndStart with that single object. Passing an extra leading call argument loses the credentials; the request has no Authorization header and account setup falls back to manual configuration.

Scope: Exchange account discovery.
