# A missing selected UIDL is an error rather than a cleanup request

fetchBodyForUidl requires the stored UIDL status to be UIDL_TOO_BIG. A missing map entry or another status calls _actionDone(NS_ERROR_FAILURE) and returns. The historical fallback that began delivery to delete stale partials was removed. Keep selected-body fetch failure separate from the successful full-session cleanup contract; no UI error-page execution was performed. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
