# Promise test helpers reject Error objects while combined send/copy settlement remains first-callback driven

The changed test helpers reject Error(status), so affected tests read error.message instead of the raw status. PromiseCopySendListener inherits copy settlement and adds send-stop/not-performed/security settlement against the same promise; one fulfillment does not prove both phases completed. The migrated send-later test checks outbox data and eventual failed send/remaining-unsent state, while dropping the earlier exact status/count/error-callback checks. Its four state/data calls omit assertion messages. No callback or test ran.

Scope: Mailnews promise test listener errors and completion.
