# Three browser-test waits explicitly name their expected initial document

Three scoped fixes pass options.wantLoad to BrowserTestUtils.browserLoaded: about:blank for redirect and Calendar initial documents, options.url for a policy content tab before its task callback. Redirect then starts completion navigation, policy helper closes after its callback, and Calendar retains an event-loop tick before returning the panel ID. These exact caller phases are the shared claim; the separately retained auxiliary Firefox API check is private context and supplies no additional shared rule or accepted comm/Gecko pairing claim. No timeout reproduction, rejection-safe cleanup guarantee or test execution is claimed.

Scope: IM redirect, policy tabs and Calendar edit-tab load contracts.
