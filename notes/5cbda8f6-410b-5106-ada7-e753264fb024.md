# RunnableBuilder::dispatch_local behavior in xpcom/rust/moz_task/src/dispatcher.rs

Consumes the builder, allocates an atomic XPCOM runnable containing the callback in Some under a mutex, and submits it to the current XPCOM thread. Obtains the current thread before allocation; non-Send callbacks are allowed.

```text
    pub fn dispatch_local(self) -> Result<(), nsresult> {
        let target = get_current_thread()?;
        let runnable = RunnableFunction::allocate(InitRunnableFunction {
            name: self.name,
            priority: self.priority,
            function: Mutex::new(Some(self.function)),
        });
        unsafe { dispatch_runnable(runnable.coerce(), target.coerce(), self.options) }
    }
```
