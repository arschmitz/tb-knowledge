# Manual identity changes retain compose modification history

The identity dropdown calls LoadIdentity(false), which no longer resets editor modification count or disables undo for ordinary identity changes. Those operations remain around the initial body-ready identity correction after the body and signature are assembled. Native bodyModified reads the editor document-modified state, and the close prompt checks that state alongside other changes. Keeping the manual path from resetting it preserves an existing reason to prompt; it does not establish autosave or recovery. The enabled reply test checks initial Delivered-To identity, not the full edited-draft/reselection sequence. No compose test ran.

Scope: Compose identity selection and close-state contract.
