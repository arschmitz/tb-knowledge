# Notification action objects use l10nId, isValidFor and runAction for separate roles

The reviewed action objects use l10nId for the Fluent key, isValidFor(message) for eligibility and runAction(message) for dispatch. The reviewer requested l10nId/runAction; actual landed source adopts them even though the rows remain NotDone. Archive eligibility delegates canArchive([message], true), which checks the single message identity archiveEnabled path. Starting archiveMessages is not proof of completion; the browser test waits for the folder event before checking the moved message. This is a local action-object convention, not a global method-name rule. No runtime test ran.

Scope: Notification action object naming and archive dispatch.
