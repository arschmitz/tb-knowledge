# HTTP response errors reach connection alerts before ordinary response parsing

Response.error_from_status turns400–599 into a StatusCode error. Its nsresult conversion maps to NS_ERROR_NET_ERROR_RESPONSE, which the alert glue formats with the server hostname. The owned original EWS client notified and returned before success/SOAP parsing. Selected current shared sender first hands recognized error statuses to the response processor; EWS recognizes500 so protocol errors/backoff can still be parsed. Keep connection failure, HTTP status error and parsed protocol response distinct. No HTTP or notification test ran.

Scope: EWS HTTP response and connection alerts.
