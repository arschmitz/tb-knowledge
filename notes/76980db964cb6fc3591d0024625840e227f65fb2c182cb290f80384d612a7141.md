# Under-threshold auto-compaction commits the triggering folder database

The owned change adds a guarded mDatabase commit in the else for the total-expunged-byte threshold, inside the nonempty-server branch. It targets the triggering folder database, not every scanned folder. Original type is kLargeCommit; fixed later code uses kCompressCommit. AutoCompact dispatch remains conditional on invocation, the global one-hour gate and prompt setting, so this is not an unconditional per-folder timer. The call ignores its commit result. Keep exact branch/type/phase distinctions when maintaining this fallback. No database or compaction run was performed.

Scope: Folder database maintenance.
