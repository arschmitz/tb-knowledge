# Retention callers guard full-disable state before selection-based numeric updates

setDisabledStates applies either an explicit force value or the Folder Properties account-default checkbox. Folder initialization returns when that helper fully disables controls. Account-dialog initialization likewise returns immediately after a locked retainBy preference forces all controls disabled. Only the remaining path calls updateStates, which combines individual numeric locks with policy values 2 and 3. updateStates itself does not remember a prior global disable; preserve the caller guards and call order rather than treating it as an independent all-state reconciler. This is static source adoption, not a locked-preference UI test. Required discussion gaps keep full-audit credit at zero.

Scope: Retention policy locks and initialization order.
