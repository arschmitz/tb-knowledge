# RNP backend version inputs come from distinct configured producers

The RNP 0.18 build integration forwards -b from moz.build to the header generator. Botan reads BOTAN_VERSION, exported from bundled configure's build_config.json version field; OpenSSL reads MZLA_LIBRNP_OPENSSL_VERSION. The inspected system-Botan route returns before the bundled namespace and gated export, so these selected paths do not establish an equivalent version input for that route. Preserve this source limitation rather than claiming system-build success or failure. The backend version is part of generated identity; the numeric upstream/runtime minimum remains separate.

Scope: OpenPGP RNP generated build identity.
