# Remove the summary suffix only when it is actually present

StripSummarySuffix clones the input, checks StringEndsWith using the case-insensitive comparator and then truncates by the known suffix length. It leaves other names unchanged and returns the clone. Preserve that guarded conversion for IMAP summary filenames; unconditional removal of a fixed character count belongs to the retired implementation and can misclassify a path. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP summary-suffix conversion.
