# Name a default-server test for the fallback it exercises

The QR unit fixture still calls its account noOutgoingServerAccount, although its comment and assertion say it uses the default SMTP server. Proposed manual naming rule for this test family: use a name such as defaultOutgoingServerAccount for that fixture. Keep an absent-server fixture distinct from an empty-key fallback fixture; the current source establishes the behavior, not an approved project-wide naming rule. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: QR export fallback fixture names.
