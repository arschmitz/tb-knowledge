# Loaded event edit tests must include More in tab order

For D332899 at revision 61fdeb24a40374feeb64fe1685f402200b2304c5, the AI verification record reports that a loaded edit draft shows More between the calendar selector and Close. The edit Save test omitted More in both directions, so its later Enter action activated Close instead of Save and undermined storage and Redo checks. The reported production check reached calendarEventCreateEditDialogMenuButton after Tab from the selector. For this loaded-edit state, the proposed sequence is Calendar → More → Close → Save in both directions. Do not extend it to states where More is hidden. Local test edits and static checks are reported, but the edited test was not run and acceptance is not recorded.

Scope: Calendar event edit keyboard tests.
