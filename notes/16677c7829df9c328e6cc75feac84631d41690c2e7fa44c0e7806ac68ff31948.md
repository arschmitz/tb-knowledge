# OAuth cache-removal assertions need messages for each user and phase

The new cache-removal task adds 17 equal/notEqual assertions without a message argument. The scenario comments explain the setup but are not failure messages. Each assertion should state the expected user, token/object state and removal phase, so a failure distinguishes single-login invalidation, unaffected-user reuse and global invalidation. No helper or test was changed or run.

Scope: OAuth unit-test diagnostics.
