# Mailbox move-copy indices are array positions, not message keys

Accepted SetMoveCopyMsgKeys clones the key list and may initialize m_messageKey from its first key. GetMoveCopyMsgHdrForIndex bounds-checks the index, extracts the corresponding nsMsgKey and delegates lookup; out-of-range returns NS_MSG_MESSAGE_NOT_FOUND. Preserve the index/key distinction in names and callers rather than pass an array position to database lookup. This is static source and test-code inspection.
