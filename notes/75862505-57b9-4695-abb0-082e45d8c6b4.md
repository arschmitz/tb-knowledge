Evidence: [DefineTransaction:688-720](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/components/places/PlacesTransactions.sys.mjs#L688-L720).

Trigger: Each PT constructor definition declares required/optional property names.

Rejects unknown schema names. Generated constructor supports function and new syntax, normalizes declared inputs, binds them to raw execute, and returns a frozen proxy. Unknown extra input properties are not copied into fixedInput.

Result and completion: Public constructors return transaction facades. Bound fixedInput becomes execute input.

Ownership and cleanup: Input object is copied at its top level. Array members can retain caller objects; child validation returns the original child object.
