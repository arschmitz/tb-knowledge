# Materialize calendar timestamps after re-inserting an attendee

The summary dialog clones the input item, clones the invited attendee, removes and re-adds it, then calls ensureNotDirty. CalItemBase uses its dirty flag to update LAST-MODIFIED and DTSTAMP. Some timestamp getters call ensureNotDirty too, so delaying the call can make the old and new comparison observe the update at an unintended read boundary. Entry 897 adds the explicit call after attendee mutation. Current source retains it. No outgoing invitation was sent during this study.

Scope: calendar/base/content.
