# Guard a database getter with the side-effect-free open flag

The view-release path first checks databaseOpen, then reads msgDatabase.databaseSize. The databaseOpen implementation tests the existing mDatabase pointer, while msgDatabase can load a database. Preserve that order in nearby cleanup code. Reading the getter to ask whether a database is open can change the state being measured. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message database getter boundary.
