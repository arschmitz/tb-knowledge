# Assert archive and delete destinations after the folder notification

The navigation tests register msgsMoveCopyCompleted before activating the native archive/delete item, await popup closure and the folder notification, then check move status, source message and destination. Archive expects the year folder under Archives; delete expects Trash. Proposed pattern in this menu family: assert the completed side effect and destination instead of only a menu click or hidden popup. The notification and pointer paths were read, not run. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Message context menu outcomes.
