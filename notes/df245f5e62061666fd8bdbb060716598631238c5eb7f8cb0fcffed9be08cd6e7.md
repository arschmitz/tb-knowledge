# Run local post-download plugins for filtered destination folders

EndMsgDownload processes each recorded filter destination except Inbox and Trash, calls filter plugins and clears its database reference when no filters ran. A separate moved-message map adjusts destination new-message counts and skips marking Junk as new. Preserve those destination-folder and notification conditions together when changing delivery cleanup. This is the current local parser path; plugin return errors and UI delivery were not exercised. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
