# Follow parent build declarations before treating a removed moz.build as a feature removal

Entry 905 removes an unused mailnews/db/moz.build aggregate. Current mailnews/moz.build names db/gloda, db/mork and db/msgdb directly, with Panorama conditional on MOZ_PANORAMA. Removing the unused parent file does not remove those database subtrees from the build. Trace actual DIRS reachability before drawing a feature-removal conclusion from a deleted build file.
