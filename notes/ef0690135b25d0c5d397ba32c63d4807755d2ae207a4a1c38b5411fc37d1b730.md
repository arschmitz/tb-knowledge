# Use a docs directory and the tree mapping for component documentation

The accepted docs/config.yml says tree paths omit comm/ and must include a docs directory for CI to notice changes. The source-docs task uses comm/**/docs/**. Add a component tree with the correct relative path and retain that directory convention; placing source documentation elsewhere without changing the task filter can miss rebuilds. Rust markdown filenames retain underscores in their existing family. This is a scoped documentation layout rule, not a global filename case rule.

Scope: Component documentation path and CI naming.
