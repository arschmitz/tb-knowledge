# The Exchange type step overrides the footer label while large-card rows keep a minimum size

This landing supplies the Connect Fluent ID for the Exchange type step. The checked controller passes that ID to the footer receiver, which otherwise defaults to Continue. The separate grid change uses minmax(125px, auto) and resets the fieldset's inline and block-end padding while retaining top focus-ring space. These declarations do not prove a fixed card height, measured design spacing or native focus behavior.

Scope: Account Hub Exchange type step / shared footer and large-card group.
