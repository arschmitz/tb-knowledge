# Account Hub open-dialog waits and address-book step readiness are different checks

The original1960750 helper checks dialog creation/open, but its address-book branch is only a TODO. The new tests therefore do not assert that the address-book view is ready, despite the helper summary saying fully opened. Fixed head.js maps ADDRESS_BOOK to address-book-option-select, then waits for that element and its visible state. Keep the actual completion boundary separate from a test helper name. This later code does not prove the earlier placeholder had a complete creation flow. No Account Hub, UI, keyboard or test runtime ran.

Scope: Account Hub subtype test completion.
