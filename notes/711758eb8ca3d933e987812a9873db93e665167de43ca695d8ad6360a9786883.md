# The identity initializer can replace an empty SMTP key with the account key

The new initializer uses identity?.smtpServerKey || account.defaultIdentity.smtpServerKey before applying the final empty-string fallback. For an existing non-default identity with an empty or null SMTP key and an account default with an explicit key, that selects the account's explicit key. The actual use-default menu item stores an empty value, and saving copies the menu value back to the identity. The added catch-all visibility test does not assert this fallback case; no profile was changed.

Scope: Identity SMTP default selection.
