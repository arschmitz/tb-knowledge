# Axe skip metadata is separate from a completed accessibility check

The helper skips engine work on debug, ASAN, TSAN and coverage builds by returning empty result arrays with skipped metadata. Its watcher assertion compares the number of errors plus unique violations with zero. These local branches do not call a harness skip-reporting API, and an empty skipped report is not evidence that Axe checked the DOM. No engine or harness run was executed.

Scope: AxeHelpers build gates and report assertion.
