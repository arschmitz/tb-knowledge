# Generated tag keys keep a separate display label and their case-folded encoding is not an exact label round trip

The generator hex-escapes selected UTF-8 bytes but then lowercases the whole key. Its comment correctly treats hex-digit case as irrelevant to an escaped byte, yet that does not make the original display label recoverable from the key: unescaped ASCII letters also lose case. The direct test maps Auto Tag to auto=20tag. AddTagForKey stores the display string separately, and GetKeyForTag retrieves the mapping. Keep the case-folded identity distinct from the stored label; do not use the comment as proof of a lossless label round trip, complete Unicode coverage or server compatibility.

Scope: Tag key generation and label storage.
