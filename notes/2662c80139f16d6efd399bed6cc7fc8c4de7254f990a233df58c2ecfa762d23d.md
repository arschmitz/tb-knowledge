# Panorama enumerators keep statement finalization when destructors move out of headers

The include-reduction patch leaves the storage statement forward declaration and nsCOMPtr member in the header and moves destructor definitions into the implementation file, where the full statement type is included. Both destructors still finalize the held statement. EnumerateMessages clones the named cached statement and passes the clone to its enumerator, so this cleanup is for the owned enumerator statement rather than the cached original. This is an exact local header/implementation pattern and a preservation of existing cleanup, not new behavior or a universal include rule. No compiler or lifetime test ran.

Scope: Panorama C++ enumerator storage lifetime.
