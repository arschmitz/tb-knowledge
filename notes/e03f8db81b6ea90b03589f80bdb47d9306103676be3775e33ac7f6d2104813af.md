# Commands patch-review conflict recovery, single-patch fallback, and capacity status

`moz-phab --apply-to base` can fail when a Thunderbird `comm` patch's recorded base is unavailable because fallback searches mozilla-central landing history. Export exact raw stack metadata, replay parents first on pinned Review main through `TB_TOOLS_MOZPHAB_REVIEW_MAIN`, and send the exact incoming patch plus affected files to the existing resolver; retain one resolver session through repeated conflicts. [Task 1]
