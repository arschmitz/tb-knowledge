# Use the accepted -moz-pref function form in preference-controlled chrome CSS

The syntax port replaces (-moz-bool-pref: "name") with -moz-pref("name"), retaining not and and combinations. Current Account Manager and tree-table styles use that function form with scoped stylelint exemptions. Follow this current syntax when changing those chrome preference queries; this is an engine-port requirement observed in source, not a new manual naming rule or proof of support outside this chrome CSS context. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Chrome CSS preference query syntax.
