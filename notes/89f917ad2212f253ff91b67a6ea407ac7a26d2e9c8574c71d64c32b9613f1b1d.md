# Certificate-check tests separate pointer preparation, a tick and final-state waits

The test scrolls the fetch button before synthesizing its click and waits one tick before checking fetching. It then uses a separate status predicate for completion. Returning from a TLS server to plain SMTP scrolls the server list and waits until certificate-check is absent. Removing an exception uses a tick before direct override and localized-status checks. These are distinct preparation and state checks; a tick or scroll call is not proof of final asynchronous completion or live visibility. The patch changes test timing, not certificate validation or account authentication.

Scope: certificate-check browser-test timing.
