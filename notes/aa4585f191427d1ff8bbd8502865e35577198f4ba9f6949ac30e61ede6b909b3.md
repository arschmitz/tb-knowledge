# The shared Exchange rename preserves protocol factories, stored state and log-channel strings

This owned C++ pass renames shared fetch, copy/move and sync files/helpers and updates their build/includes/callers together. It keeps the stored ewsSyncStateToken value and ews_xpcom log channel while renaming local symbols. EWS and Graph factories retain protocol-specific names under Exchange-path include guards. The title Final does not mean every Ews spelling or later Rust listener was changed. Preserve persisted/interop names unless their own contract changes; this source is not a state migration, ABI build result or implemented JMAP feature.

Scope: Exchange C++ naming and integration.
