# Shared Account Hub details require matching incoming and outgoing values

The original authentication-display landing placed incoming username, connection security and authentication under All servers without comparing outgoing values. The accepted code compares all three values. It shows shared details only when all match, and otherwise fills per-server values with CSS selecting the corresponding sections. Keep the original display and this later repair separate. Source and Fluent-ID assertions do not establish successful authentication or live accessibility.

Scope: Account Hub configuration detail display.
