# Account Hub service discovery identity follows endpoint URLs

Historical 1375 marks address books existing by carddav.url and calendars existing by uri.spec. The accepted address-book helper keeps a URL set and invalidates it on directory create/delete observer topics; calendar discovery still compares URI strings. This is a scoped later-source refinement, not full chronological coverage of the helper extraction. Preserve resource identity rather than treating the visible name as an existing-resource key. No observer or remote discovery test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub discovered-resource deduplication.
