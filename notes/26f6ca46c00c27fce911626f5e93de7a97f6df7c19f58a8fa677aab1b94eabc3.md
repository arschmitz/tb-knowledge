# The RawHdr database adapter skips empty fields while always applying flags

ApplyRawHdrToDbHdr conditionally writes nonempty strings, nonzero dates and a set priority, but always passes raw.flags to SetFlags. An empty RawHdr field therefore does not clear the matching value of an existing database header. AddMsgHdr uses this helper while its new header is detached and attaches the header only after the helper succeeds. The initial extraction preserved these field conditions; fixed accepted source later protects encoded-looking subjects and changes header key allocation. Do not treat those later changes as part of this refactor.

Scope: message-database.
