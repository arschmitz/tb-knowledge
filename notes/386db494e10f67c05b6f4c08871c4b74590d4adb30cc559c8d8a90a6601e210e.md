# The nsMsgIdentity follow-up moves unchanged accessor macro definitions into its implementation file

This landing removes five accessor-generating macro definitions from nsMsgIdentity.h and places the same text in nsMsgIdentity.cpp before the implementation invocations. The definitions keep the string, wide-string, Boolean, integer and folder-accessor forwarding roles and stored preference keys. The fixed header retains the class declarations without these implementation macros. This is a scoped source fact and a separate follow-up to an earlier deferred review request; no C++ build or general macro-placement rule is established.

Scope: nsMsgIdentity accessor macro placement.
