# Reset the ZIP import marker before a new profile selection

The importer clears _importingFromZip when it shows the profiles pane again. Only a selected archive sets the marker; choosing a directory does not. The marker later controls archive extraction, progress weighting and cleanup of the extracted profile directory. Its value belongs to the current selection, so a prior ZIP choice must not route a later profile/directory choice through those branches. This is the inspected controller state contract, not proof of every reset path or archive validation. No import or filesystem operation ran.

Scope: Profile importer selection state.
