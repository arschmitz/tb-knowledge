# Removing unlimited stream slices preserves the caller’s actual range contract

Entry 1194 removes m_readCount and slices that were configured to read the complete stream. The accepted .eml path opens the local file directly; mailbox messages still obtain their stream through folder.GetMsgInputStream. This change is scoped to redundant unlimited slices, not to every SlicedInputStream or every message-size check. The full diff and both stream callers were read. No message stream, large mailbox or attachment test was executed. Full bug and review discussion remains pending.

Scope: Mail protocol input streams.
