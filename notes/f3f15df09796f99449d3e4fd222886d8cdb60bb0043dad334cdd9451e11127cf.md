# Offline-manager completion clears the poll flag before this test's delayed offline-flag checks

The terminal downloading-for-offline state now assigns eDone and calls StopRunning, which clears inProgress. The test sets the flag itself, polls until it is false, then waits100ms before checking the Offline flag of each enumerated message. It does not assert the injected count or body contents, so neither the poll nor those assertions prove complete storage readiness for every requested message. The timer is an explicit historical workaround, not a condition-based completion contract; no test was run.

Scope: Offline-manager terminal state and IMAP test completion boundary.
