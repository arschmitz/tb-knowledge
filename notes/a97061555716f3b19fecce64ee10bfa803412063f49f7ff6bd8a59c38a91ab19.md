# The new splitter disabled-state task checks coercion on a widget fixture

testIsDisabled checks attribute presence for nine true/false/truthy/falsy inputs and checks the getter for Boolean values. Its document is the dedicated paneSplitter.xhtml fixture opened as a content tab. The task does not itself open a second about3pane tab or check dragging, keyboard resizing, focus or an accessible tree. All assertion messages are nonempty; no widget or browser test ran.

Scope: Pane splitter state test coverage.
