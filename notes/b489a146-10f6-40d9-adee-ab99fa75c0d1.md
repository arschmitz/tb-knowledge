# Test the import UI across file formats with a shared outcome check

The browser_import.js suite uses separate testImportCSV, testImportLDIF, testImportVCard, testImportSQLite, and testImportMAB tasks under the browser_import.js file. Each drives the real wizard with MockFilePicker, checks type-specific file filters, pane changes, destination choices, and imported contact data; formats that support lists also check list metadata and membership. CSV explicitly maps unrecognized columns. The shared checkImported helper cleans imported cards and lists, and setup cleans MockFilePicker and the address-book window. This is a scoped file/test naming example and a test pattern for this importer, not a repository-wide naming rule.

Scope: Address-book import tests.
