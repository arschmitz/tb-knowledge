# Prompt acceptance tests bypass the security delay explicitly

The permission dialog callback checks the dialog URI, sets the accept button disabled=false and clicks it. Its comment explicitly bypasses the security delay. These tests exercise acceptance and resulting routing, but cannot prove the delay works, keyboard focus is correct or the prompt is accessible to a screen reader. Preserve this boundary when reusing the test as validation evidence. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/extensions.
