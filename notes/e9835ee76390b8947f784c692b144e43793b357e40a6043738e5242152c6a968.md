# Keep schema enum lists ordered within the native account type family

651 inserts rss while changing the NativeMailAccountType enums into lexical order. Current enums retain that order after adding ews. Proposed scoped manual JSON style: keep these native type lists alphabetized and update both version choices together, while preserving the version-specific none/local spelling. This is supported by this schema family, not a rule that all enum order is arbitrary or that a formatter enforces it.

Scope: WebExtension schema naming and list style.
