# Preserve the array shape of decoded header values

Current convertHeaders returns an array for every header, including a single value. It inserts ["text/plain"] only when addMissingContentType is true and the part lacks content-type. Mailbox decoding maps each original value to its comma-joined parsed mailbox strings; it does not flatten the header-value array. Component-local API rule: document both container shape and decoding behavior, and keep fixture comparisons sensitive to arrays even when most messages have one value.

Scope: mail/components/extensions.
