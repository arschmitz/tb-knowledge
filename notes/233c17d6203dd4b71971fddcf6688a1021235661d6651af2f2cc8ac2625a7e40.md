# The contact-icon regression checks ownership and negative state after deletion

Accepted browser coverage chooses a configured add directory, checks directoryUID on the resulting card and tests that later lookup/deletion does not produce duplicate contacts. Current add behavior uses AddrBookUtils.getDefaultAddDirectory rather than always assuming Personal Address Book. Preserve book ownership and absent-state checks in this regression family. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
