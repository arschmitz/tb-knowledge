# Use a mailbox-header type name when a value may include a display name

MessageHeader author and recipient lists reference MailBoxHeaderString. Its description permits either a bare address or an RFC 5322 mailbox string and points to parseMailboxString for extracting parts. Preserve that distinction in schema documentation and consumers; treating author as a plain email address loses valid display-name data.

Scope: mail/components/extensions.
