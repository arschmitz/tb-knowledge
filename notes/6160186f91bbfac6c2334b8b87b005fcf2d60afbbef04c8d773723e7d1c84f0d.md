# Removing legacy add-on telemetry assertions preserves the extension interaction tests

The four-file change removes legacy AddonTestUtils telemetry hooks and event assertions. It retains sideload and update interaction tests, their version or badge checks, and cleanup. The retained UI checks do not test the deleted event sequences or extra fields, and this patch does not establish that production telemetry is disabled. Static inspection only; no browser test or paired Gecko telemetry implementation was run or inspected.

Scope: Mail extension browser tests.
