# Exceptions Site column passes the model origin property to sorting

The Site treecol names origin in data-field-name, matching Permission.origin. Its click handler forwards that field name to onPermissionSort, which supplies it to gTreeUtils along with the permission rows and comparator. The Site renderer also reads origin but can strip the mail-URI prefix for display. Keep markup sort fields aligned with the real model, while preserving DOM/localization IDs. This comm mapping is not a guarantee of engine helper behavior or every visible-label order. No permission or UI test ran.

Scope: Preferences Exceptions table.
