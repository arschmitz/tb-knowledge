# Folder cache getter error and null contracts

At revision d2c3c9e6808277e9b753c78a0bb07b8a7f66b381, nsIMsgFolderCacheElement documents that getCached... accessors fail for missing properties: JavaScript gets an exception and C++ gets an NS_ERROR_* result. Stored null values instead return an empty string or numeric zero to handle possible panacea.dat migration data. The comments also identify legacy C++ callers that rely on the output value staying unchanged on failure. Preserve these distinct cases when changing the accessors. This is a documented interface contract from a verified source snapshot; no implementation or runtime validation is supplied.
