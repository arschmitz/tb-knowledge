# Compaction precomputes fallible file names before the critical handoff

In D238551 the author explicitly rejects recomputing redundant-looking leaf names at each use: nsIFile leaf-name access can fail, so setup performs it before the critical OnCompactionComplete phase. The selected fixed source gets SourceName with an rv check, derives the staged names, then reuses those names in rename operations. This is an accepted local reliability constraint, not a global ban on helpers or redundant state. No failure injection or runtime test ran.

Scope: mailnews folder compaction DB lifecycle.
