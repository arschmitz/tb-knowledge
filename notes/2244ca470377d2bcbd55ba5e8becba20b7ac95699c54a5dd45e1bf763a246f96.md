# MSIX release routing keeps push channels, branding channels and package identities separate

The owned MSIX configuration enables beta, release and ESR 140 push releases with Manual publication. It gives ESR repacks the esr branding channel and release Store packages the MozillaThunderbirdRelease identity. Push channel, branding channel and identity are distinct settings; non-store release/ESR identities remain shared. Accepted source keeps the repack distinction but later uses ESR 153 and Immediate publication. The localized path separately fetches unsigned Thunderbird langpacks. These declarations do not prove Store submission or generated task success.

Scope: Thunderbird MSIX release configuration.
