# The time-zone overlay's six-digit selectors differ from its explicit UTC value

The overlay CSS now hides the highlighter by default and reveals explicit six-digit offset selectors. The accepted UTC branch and initial markup still use +0000, which differs from the +000000 selector. The comm offset serializer permits values with or without seconds, so six digits cannot be assumed for every producer. This is a static producer/selector mismatch, not an observed rendering failure or a diagnosis of all time-zone data.

Scope: Calendar time-zone dialog overlay selector contract.
