# Require an EWS item ID at operations that need message identity

The owned EWS adapter now treats message.item_id as optional input. Sync collection maps IDs into Result and collects with ?; create_message returns MissingIdInResponse when the created message lacks an ID. Do not silently default a missing server ID when it becomes a local lookup key or the result of creation. The current code is split into operation modules and the error maps to NS_ERROR_UNEXPECTED through the general conversion. These sources do not prove a malformed-response runtime test passed. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: EWS optional identity boundary.
