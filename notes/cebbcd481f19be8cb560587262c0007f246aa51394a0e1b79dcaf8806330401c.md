# The periodic-filter Fluent binding carries the server interval and the checkbox accesskey

setType reads periodicFilterRateMinutes from the selected server and supplies it as minutes to run-periodically. The checkbox's markup value of 10 is only a placeholder; the same control still dispatches cmd_updateFilterType. Fluent owns both its plural label and accesskey. The recipe maps the legacy #1 placeholder to minutes and preserves the accesskey in a separate attribute transform. Its completed blob is identical to the authored recipe. This source inspection does not establish all-locale output or live keyboard behavior.

Scope: Filter editor periodic option.
