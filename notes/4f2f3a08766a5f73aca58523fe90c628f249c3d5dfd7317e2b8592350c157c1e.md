# Zoom personal-room recognition keeps a nonempty suffix after /my/

This landing adds a Zoom /my/ route to the existing ordered join-link patterns. The expression accepts http or https, an optional subdomain and a nonempty suffix up to whitespace or an angle bracket. Its one added fixture expects the exact personal-room URL from a text description. It adds no URL validation or network guarantee, and does not test empty routes, delimiter edges or mixed-link precedence. The existing parser-order lesson and actual dialog consumer retain their separate scope; no meeting or test was run.

Scope: Calendar join-link Zoom personal rooms.
