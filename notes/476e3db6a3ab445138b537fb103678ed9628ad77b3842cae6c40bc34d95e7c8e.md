# The Star-state update reads the modified batch rather than the full selection

The normal initial thread-summary path checks every summarized message, but _processItems rebuilds its state only from the Gloda items supplied in that callback. The actual collection manager forwards a modified subset. A batch containing one starred item can therefore make every known batch node starred while other selected messages remain unstarred. Per-node OR aggregation can also represent any starred child rather than all messages. Accepted source retains this calculation. A focused regression test should keep multiple messages selected, modify only one and wait for the actual update before checking the aggregate pressed state. This is static source reasoning, not an observed UI failure or an executed test.

Scope: Multimessage Star state and Gloda notifications.
