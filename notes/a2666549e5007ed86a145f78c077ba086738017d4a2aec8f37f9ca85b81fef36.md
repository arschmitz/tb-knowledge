# Await localization before asserting localized calendar labels

The day-view test waits document.l10n.translateRoots before reading the week heading. DOM creation or view readiness alone did not guarantee translated text, producing intermittent failures. Proposed manual test rule: use the localization completion barrier before localized text/accessible-name assertions, rather than a fixed delay. The read test also documents week-start assumptions; no live assistive-technology check was done.

Scope: calendar-tests.
