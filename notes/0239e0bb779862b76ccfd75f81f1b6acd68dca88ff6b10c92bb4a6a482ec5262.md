# Copy and move results name the resync decision before listener conversion

The copy/move result uses RequiresResync::Yes or ::No instead of a Boolean. The explicit conversion maps those values to the listener-facing UseLegacyFallback enum. The names keep the ID-resync decision and its API conversion visible. This is the local copy/move contract, not a rule that every Boolean must become an enum or that every folder copy avoids resynchronization.

Scope: ews/copy-move-result-types.
