# Command support and command enabled state have different effects

672 changes the callback annotation to Function. The surrounding current controller accepts boolean or function values for enabled and supported separately. Its documentation states that unsupported commands can fall through to another controller, while merely disabled commands do not provide that routing. doCommand forwards rest arguments only after enabled-state checking. Proposed manual API review rule: document routing and callback input contracts, not only a broad Function type. This file is CommandController.mjs, distinct from system module filenames; the annotation cleanup did not rename it.

Scope: Tab command-controller behavior.
