# Keep group-header counts in the visible text and row accessibility label

A dummy row is a Group By Sort header. Table layout now appends (unread/total), or only (total) when all messages are read, to its subject text. The same enriched text feeds the localized cell title and row aria-label aggregation. Dummy header images clear their alternative text. The previous frontend move covered cards layout but omitted table layout, causing this regression. Test both layouts when moving shared display data. This patch’s table test exists; its cards test is still a TODO. No computed accessibility tree or speech output was checked.

Scope: Grouped message rows and accessibility.
