# Thunderbird decision defaults name the Firefox Git checkout repository explicitly

FIREFOX_GIT_REPOSITORY names https://github.com/mozilla-firefox/firefox and supplies COMM_DEFAULTS.head_git_repository. get_decision_parameters applies COMM_DEFAULTS to the parameter dictionary before project-specific values. The nightly and on-push fixtures use the same Git repository URL; their separate Git/Hg revision and repository fields are unchanged by this patch. These are exact configuration facts, not proof that a revision is fetchable or that a CI job passed.

Scope: Thunderbird CI decision parameters.
