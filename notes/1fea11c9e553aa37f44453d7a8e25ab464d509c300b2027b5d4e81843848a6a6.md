# The Gloda sort select uses both the shared select rule and its icon-token stylesheet

The sort control remains a native select with the stable sortby ID and adds the select class. Removing its old ID-specific styles relies on the imported widgets.css select rules, while the new icons.css import supplies the icon-nav-down-sm token used by the single-select chevron rule. The checked shared rule also provides focus-visible and RTL positioning states. This is a scoped selector/token/receiver relationship, not a global CSS-import rule or a rendered layout/accessibility guarantee. No UI test ran.

Scope: Gloda results sort-control styling.
