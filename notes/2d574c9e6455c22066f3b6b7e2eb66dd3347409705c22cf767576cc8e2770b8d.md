# Resolve DAV authorization before opening the network channel

CardDAV awaits getAccessToken before creating the channel and applies Bearer through the header map. CalDAV commit awaits session.prepareRequest before calling asyncOpen. The centralized OAuth module replaces the old per-provider authentication adapter. Preserve these awaited boundaries when adding a DAV request path; scheduling token retrieval alone does not make an authorized request ready. The shared session’s cached-null and origin rules are already covered by existing knowledge. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: DAV asynchronous authentication boundary.
