# MailTab conversion omits folderMode when no folder row is selected

convertMailTab reads selectedRow?.modeName and adds folderMode only when the mapped mode is truthy. The local mapper passes undefined through, and the schema declares the property optional. The mode-update and message-selection paths also tolerate a missing selected row at lookup, with the latter retaining a fallback to other enabled modes. Keep this extension guard separate from the earlier New Message view-wrapper repair. No extension runtime result is claimed.

Scope: mailTabs extension object conversion and folder selection.
