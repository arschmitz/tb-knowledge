# Chat Fluent lookups must use a key present in the loaded locale file

Bug 1899240 reported a missing Fluent message for the idle-away default in imCore.sys.mjs. The accepted fix changed the lookup to messenger-status-default-idle-away-message, and current chat/locales/en-US/status.ftl defines that exact key. When changing a chat status lookup, compare the key with its loaded FTL file and check for missing-message errors.

Scope: Chat localization.
