# Decision changed-file discovery replaces the list with comm repository results

The owned change replaces the helper-based append with repo.get_changed_files at comm head/base revisions. A try hg-push adds outgoing files to that comm set; other cases use the base delta. Both branches assign files_changed rather than combining its incoming value. The initial phase omits the path prefix; the later prefix restoration is a separate change. This records the exact data-flow boundary, without claiming complete Gecko-file preservation, task-selection success or zero network use by every repository backend.

Scope: Thunderbird decision-task changed-file discovery.
