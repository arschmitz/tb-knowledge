# Keep a reported compiler pin synchronized but temporary

The historical ccov change selects Rust 1.83 in Linux, Windows and toolchain references, citing another bug as the reason. Accepted configs now use rust-dev. When applying a similar temporary pin, inspect both consumers and referenced toolchain tasks and record why the pin can be removed. This landing does not justify a permanent Rust version policy, and the exact compiler failure was not inspected. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Coverage build toolchain coordination.
