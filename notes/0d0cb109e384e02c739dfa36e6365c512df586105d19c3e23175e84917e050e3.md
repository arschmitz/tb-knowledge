# Account Hub form validity drives the forward button in both directions

The Account Hub auto form combines native name and email checkValidity results and emits config-updated with detail.completed. The controller uses the inverse of that value for the forward button’s disabled state. The current footer also explicitly applies the inverse of each state’s forwardEnabled flag, including false states. For this state machine, restore disabled state as well as enabled state when a user edits data or moves between steps. This is a scoped source pattern; no validation, keyboard or live dialog test was run. Full bug and review discussion remains pending.

Scope: Account Hub form state.
