# Search-table references are cleared before database teardown

Entry 1370 explicitly clears the new map in nsMsgDatabase destruction before releasing the Mork store and environment. The accepted destructor retains that order. These are referenced native table objects, so the new cache has a lifetime obligation as well as a lookup benefit. Preserve this teardown ordering in this database family; no leak or lifetime test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Search-table cache destruction.
