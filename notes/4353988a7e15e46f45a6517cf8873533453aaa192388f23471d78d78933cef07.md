# Stored Exchange folder discovery bypasses new-folder defaults

CreateChildrenFromStore creates stored children through nsMsgDBFolder::AddSubfolder, then recursively discovers descendants. It avoids the Exchange override that applies server defaults such as Offline to new folders. The loaded flag is set before child creation to prevent recursive GetSubFolders lookup from starting discovery again. That ordering does not provide transactional rollback or remote freshness. No restart or persisted-state test ran.

Scope: Exchange local folder initialization and Offline state.
