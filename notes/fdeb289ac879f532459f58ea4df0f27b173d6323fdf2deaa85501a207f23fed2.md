# Correct copied test documentation to match its actual operation

The password-send helper documentation says it tests getting messages although its implementation sends a composed message. The fixed accepted source still has this copied description. Proposed manual documentation rule: check the action, arguments and assertions after copying a helper from a related test. A function named subtest and an otherwise passing transport assertion do not make the copied contract accurate. This study records the mismatch without editing the test.

Scope: Compose helper documentation.
