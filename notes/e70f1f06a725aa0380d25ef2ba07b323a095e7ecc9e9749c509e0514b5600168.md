# Host detection awaits the localized completion check before cancelling probes

The model migration makes _checkFinished async and awaits it before cancellation in the ordered result loop. Probes overlap; a rejected check is caught so the loop can try later results. The final caller returns the promise after its abort guard. The new localized-failure condition also covers unfinished work when not aborted, so its all-failed wording is broader than the condition actually proves. Separate XML boundaries now throw Error objects instead of strings, while synchronous model consumers retain formatValueSync. No probe/authentication run or final-failure cure is established.

Scope: Account-creation model localization and host-probe completion.
