# Disabled optional rows retain draft values

The Bug 2061214 implementation report says shared Save preparation omits disabled optional rows from saved events without changing their draft values. Disabled-row validation is also ignored. When extending this create Save path, preserve values for later re-enabling while excluding them from the saved event. The report says an intentional mutation that included disabled rows caused two exclusion assertions to fail. These are AI-reported results, not independent confirmation; the later verification could not confirm matching binaries for the earlier runtime tests.

Scope: Calendar event optional-row Save preparation.
