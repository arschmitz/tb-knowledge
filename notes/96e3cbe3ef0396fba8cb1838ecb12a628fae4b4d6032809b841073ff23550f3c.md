# Chat preference type metadata and persistence assertions have different scope

The change replaces wstring with string for the inspected chat account controls and dynamic preference metadata while keeping Boolean and integer mappings separate. The new browser task checks protocol controls and directly changes/resets auto-login state. It loads string controls but does not directly assert password, alias, autojoin or general string persistence. Keep those assertion limits when reusing the test as evidence. Missing bug comments remain an explicit gap. No account settings or protocol test ran.

Scope: Chat account preference control types.
