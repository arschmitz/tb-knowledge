# The downloader extraction loses a phase flag's inherited initialization before a later repair

The old nsImapOfflineSync constructor sets m_mailboxupdatesFinished=false. The extracted downloader stops calling that base constructor, declares its own plain bool without an initializer and initializes only window/listener in its constructor. ProcessNextOperation reads the flag before reaching the assignment at the end of mailbox updates. The accepted header later adds {false}; that later repair must not be credited to the original extraction. This is an exact static initialization finding, without a fresh sanitizer, build or crash result.

Scope: nsImapOfflineDownloader construction and phase guard.
