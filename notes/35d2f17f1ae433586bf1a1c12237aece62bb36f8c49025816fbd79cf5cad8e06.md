# Follow the compose browser test family naming instead of forcing one case everywhere

753 uses browser_sendMessage.js with scenario suffixes such as _badPassword, _certError and _oAuth2. Task names use test followed by a lower camel case scenario, while system-module files use .sys.mjs. These browser_ prefixes and underscores are part of the established compose test family; the in-app custom element family uses dashed module filenames. Proposed scoped naming rule: name a test by its behavior and nearby family, and keep its manifest entry synchronized. Current registrations use browser.toml, not the old .ini convention.

Scope: Compose test file and task naming.
