# The Exchange account reporter retains a truthiness guard after filtering

The reporter maps and filters the account array, then uses if(!servers). Filtering produces an array even when it is empty, so this condition does not check the account count. Recorder creation is still reached, while the loop records no accounts. The reviewed empty-list proposal was different. This is a static control-flow finding, not a live failure or a new global style rule.

Scope: Exchange telemetry empty-account branch.
