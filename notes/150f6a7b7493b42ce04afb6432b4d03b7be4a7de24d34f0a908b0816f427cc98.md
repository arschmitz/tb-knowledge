# Assert ownership visibility separately for extension-created spaces

The multiple-extension test distinguishes owner-visible and other-extension space records and checks isSelfOwned. management permission exposes extensionId in the checked expectations; similarly named spaces may coexist. Preserve the actor/permission distinction in this API test instead of treating a space name as one global identity. This is the test contract inspected here, not a complete security audit of every spaces consumer. These observations are scoped to the cited accepted source and historical changes.
