# Task date checkboxes update date presence separately from picker attributes

The task-date handler returns when updates are ignored or the item is not a task. Entry/due wrappers map checkbox state to gStartTime/gEndTime: checking initializes an absent date, unchecking clears it, and duration requires both dates. Its custom datetimepicker inherits disabled state to date/time children. The owned patch explicitly sets true or removes disabled; fixed source later uses toggleAttribute and reapplies all-day time disabling. Keep those phases separate and inspect the actual receiver before changing attribute operations. No focus or date behavior was executed.

Scope: Calendar task editor.
