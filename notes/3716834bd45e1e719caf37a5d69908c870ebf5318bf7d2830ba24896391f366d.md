# Host property assertions do not directly verify the Account Hub internal select

The disabled test assigns and reads select.disabled on the custom component. The inspected class has no matching property accessor; its attribute callback writes this.select.disabled when the disabled attribute changes. The test does not directly assert the internal native control state. Keep the host property, host attribute and internal select receiver separate. No native disabled-state or popup failure was reproduced.

Scope: Account Hub select test targets.
