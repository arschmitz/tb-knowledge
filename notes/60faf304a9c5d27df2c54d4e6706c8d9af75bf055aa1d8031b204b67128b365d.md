# Keep modifier semantics when replacing a row-click test action

1100's headless fallback calls row.click when elementFromPoint finds no row, instead of synthesizing the original pointer action with modifiers. That fallback cannot validate the same shift/accel click path merely from a matching selection result. The accepted test now targets the actual row with synthesizeMouseAtCenter(rows[index], modifiers, content) and keeps the selection-event checks. Favor that current action contract. The historical commit explicitly says the cause was unknown; no headless failure or repair was reproduced.

Scope: Tree-view row click modifier test contract.
