# The renamed Exchange channel passes an explicit conversion flag to the store reader

StreamMessage appends convert=true to the URI query when requested. NewChannel tests the full URI spec for part= or convert=true and passes that Boolean into ExchangeMessageChannel. The channel forwards mConvert to AsyncReadMessageFromStore, which installs the message/rfc822 to wildcard converter only when the flag is true. The rename adds constructor documentation for conversion examples; those examples do not prove actual HTML, text, attachment or raw output. No MIME or browser execution ran.

Scope: Exchange message channel conversion consumer contract.
