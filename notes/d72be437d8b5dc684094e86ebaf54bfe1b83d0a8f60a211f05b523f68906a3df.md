# firstNewMessage normalizes unavailable headers to a nullable result

After guarding the output pointer, GetFirstNewMessage clears it and returns NS_OK when the database or key/header lookup is unavailable. A null result is not proof that the folder has no new messages. onMessagesLoaded now checks that nullable header and clears its scroll flag. Explicit message selection calls displayFolder and then clears the flag for a later asynchronous callback, while keeping its own message scroll. No notification/database/scroll or test execution established a runtime result.

Scope: Mail folder first-new-message and selection scroll contract.
