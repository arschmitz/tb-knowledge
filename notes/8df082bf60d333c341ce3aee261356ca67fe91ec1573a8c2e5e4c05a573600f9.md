# Attachment predicates describe availability, not only attachment category

668 adds boolean return types to attachment predicates. Current isDeleted checks text/x-moz-deleted; external file and HTTP predicates additionally require isExternalAttachment. hasFile rejects a resolved size of -1 and a disallowed URL. Do not read a boolean type annotation as proof that a file exists, was loaded successfully or may be opened; the open method still awaits isEmpty and can show a missing/empty prompt. These implementation checks were read, but no external attachment or picker interaction was run.

Scope: Attachment state and availability.
