# Make the QR pane searchable only after its content is initialized

Entry 992 adds a category-bearing groupbox and a normally hidden search header. Current init removes dataset.hiddenFromSearch only after setting up the pane. findInPage excludes elements with the data-hidden-from-search attribute at the pane root and refuses descendants of a node whose value is true; when a result matches, it shows the nearest groupbox search header. Preserve the search metadata and initialization order when moving this pane. No preferences-search runtime was executed.

Scope: mail/components/preferences.
