# The current child-loading hook runs after open is set despite two before-open comments

The actual toggle caller sets row.open=true and then calls ensureChildren without awaiting it. The current thread and grouped-row hook comments both say the call occurs before open is set. Their implementations load sparse children asynchronously and clear/invalidate the cache only if the row is still open. Keep the documented order aligned with the actual caller. This is a static comment mismatch; it does not establish a broken fetch, rejection or displayed-row failure.

Scope: Panorama child-loading callback documentation.
