# The packaged auth refresh shares one operation and classifies three failure codes

The v2.0.2 emitted auth module routes checkAuthStatus, getAccessToken and refreshToken through one in-flight refresh operation. Success updates currentUser and can persist it for extension context. Only the three listed string error codes clear the local login state and request sign-out; other refresh failures return null without that branch. This is a scoped predicate, not proof that every other error is transient or all callers preserve state. Other direct signinSilent calls and checkAuthStatus outer cleanup remain. Accepted code includes later recovery changes, so those are a separate phase.

Scope: Thundermail system-addon v2.0.2 auth refresh.
