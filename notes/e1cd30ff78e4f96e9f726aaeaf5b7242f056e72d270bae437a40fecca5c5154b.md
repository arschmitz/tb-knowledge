# The Calendar parser's stack cleanup removes a local conversion catch

When no VCALENDAR is found, processIcalComponent now interpolates rootComp directly in its error message. The old local catch around that conversion and manual stack construction is gone. A conversion exception would therefore leave this branch. The inspected synchronous parseString call still sits inside its outer catch, while the async callback calls processIcalComponent without the same local catch. This is a conditional static distinction; no conversion failure or callback failure was reproduced.

Scope: Calendar ICS parser diagnostic control flow.
