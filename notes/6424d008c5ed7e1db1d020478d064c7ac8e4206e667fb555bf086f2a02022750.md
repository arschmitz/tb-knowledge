# Give test names the behavior and layout they actually cover

browser_importTabChange.js names pane switching and profile restoration separately. browser_dummyRow.js explains that a dummy row is a Group By Sort header and names the table-layout task explicitly. Follow these local families: browser_*.js for browser files and named tasks for distinct scenarios; use the layout in the task name when it changes the expected behavior. Task names here mix snake_case and lowerCamelCase after test_, so this evidence does not justify a repository-wide dash-versus-camel task rule. Add a short file comment when an internal term would hide the test’s purpose.

Scope: Browser test naming and comments.
