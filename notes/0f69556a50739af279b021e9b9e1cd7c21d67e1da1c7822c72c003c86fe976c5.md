# Removing the message-window stopped flag needs separate caller contracts

The initial change, its backout and the read reland remove nsIMsgWindow stopped/StopUrls while moving each caller to its own contract. The filter dialog disables Run during work, prompts on close and uses window navigation STOP_ALL. Search sessions own m_searchRunning and stop scheduling another URL after interruption. Offline synchronization shutdown checks are separate. The changed dialog test simulates running state, so it is not proof that a real filter operation cancels. Fixed source also avoids touching the dialog DOM after closure. No stop-button, filter, network or shutdown run occurred.

Scope: Message stop and search state.
