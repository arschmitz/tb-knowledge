# The mail message-body stylesheet deliberately overrides hidden root overflow

Entries 2054–2055 add :root { overflow:auto !important; } and remove only the comment’s trailing whitespace. The MIME HTML emitter links chrome://messagebody/skin/messageBody.css as an important stylesheet for rendered messages. The rule is scoped to the message document root, where message-supplied hidden overflow can prevent scrolling. Keep the importance and document scope together when changing it; this is a concrete content override, not a rule that every app stylesheet should use !important. The frozen source retains the rule. No crafted hidden-overflow message, scroll extent, keyboard reachability or accessible content was tested. Static source and test inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending-single-browser-reader.

Scope: Rendered mail body root overflow override.
