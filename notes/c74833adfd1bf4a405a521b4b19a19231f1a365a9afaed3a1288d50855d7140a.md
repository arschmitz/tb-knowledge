# Account Manager restores background focus only after its last subdialog closes

The lazy subdialog manager listens on dialogStack. Opening a dialog marks the account sidebar and settings-frame body inert and gives the frame tabIndex -1. Closing restores false/0/false only when the manager reports no remaining dialogs. This handles the separate sidebar/frame background rather than assuming the toolkit made the whole page modal. The source sets fixed normal values; it does not capture arbitrary prior inert/tabIndex state. The root cause of the Settings/Account Manager difference remains unresolved in review. No keyboard, nested-dialog or accessibility runtime check ran.

Scope: Account Manager subdialog background and keyboard state.
