# Apply valid tag deltas without deleting unrelated message keywords

The update path filters both requested and current keywords through isValidKey, computes obsolete and missing sets, and batches each mutation as a space-separated string. This preserves unrelated keywords such as IMAP Junk/NonJunk. Keep tag identity separate from the full keyword property when changing this API; an input tags array is not a replacement for every keyword on the message. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension message tag delta.
