# Normalize both sides of the selected phone-field search

Address-book search applies the same punctuation normalization to the query and stored value for five named phone fields before the existing comparison operator. It retains leading plus and selected dialing/letter characters. The added browser cases cover spaced and dotted WorkPhone inputs. This is not E164 conversion, arbitrary-field normalization or complete multiple-number/provider coverage. No search test ran.

Scope: Address-book phone comparison.
