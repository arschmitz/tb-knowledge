# Browser context-menu module state is handed off by window-owned popup glue

Window glue places browser, actor, selection and principal data on nsContextMenu.contentData before opening the popup. The module constructor captures the popup’s document and window; setContext consumes the static handoff into the instance and clears it. The window keeps gContextMenu until hiding triggers cleanup. Module globals such as the spellchecker remain a separate lifetime concern. Keep these owners and completion points explicit when changing popup reuse. No concurrent-window, actor or browser test ran.

Scope: Browser context-menu module ownership.
