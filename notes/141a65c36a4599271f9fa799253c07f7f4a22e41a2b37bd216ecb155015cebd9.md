# Keep one updater timer and clear state before its callback fetches

The newer accepted _schedule rejects a second pending timer, clears the handle before starting the fetch, and _clearStateForTests resets history, failure count and the outstanding handle. The 836 interval implementation has evolved into this one-shot scheduler. Timer state and test cleanup are part of the updater contract. The fixed-source comparison does not mark the later scheduler change fully reviewed.

Scope: Notification updater timer state.
