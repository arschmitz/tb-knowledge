# A locale change re-filters notification candidates rather than downloading new data

Entry 781 observes intl:app-locales-changed and refreshes the manager’s filtered notification list. Current code debounces that refresh for 5 seconds, cancels a prior timeout and blocks other manager refreshes until the debounce expires. getNotifications filters the existing JSON data using NotificationFilter, the per-ID seed and prior interactions. The unit test sets different locale include and exclude rules, waits for a different notification ID, and restores requested and available locales. Manual state API proposal: distinguish updateNotifications, which updates stored data, from _updateNotificationManager, which re-evaluates candidates. Preserve an explicit event predicate when an old notification event would otherwise satisfy the wait. The test’s restoration is at its end, not an inspected finally cleanup.

Scope: notification-locale-targeting.
