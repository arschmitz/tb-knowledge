# The OAuth cooldown test clears tokens and checks a generic abort before retrying

The test clears access and refresh tokens before the blocked attempt, checks NS_ERROR_ABORT, then waits3500ms and completes another flow. The abort assertion has no message and does not assert a cooldown-specific reason; the accepted wrapper maps general rejections to that status. Original _forgetObjects calls clearCooldowns, while accepted code later uses clearState to clear both maps. This separates test assertions from reset and UI-transport contracts. No test or boundary-clock experiment ran.

Scope: OAuth cooldown regression and reset API scope.
