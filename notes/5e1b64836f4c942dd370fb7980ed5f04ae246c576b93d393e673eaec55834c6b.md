# Validate default sort types against the accepted enum range

GetDefaultSortType accepts values from byDate through byCorrespondent but excludes byCustom, falling back to byDate otherwise. The enum includes byNone below the accepted range, and byReceived after byCustom. Preserve the explicit custom-sort exception rather than assuming every numeric enum is a useful default. Sort order separately accepts descending and otherwise normalizes to ascending. These are fixed accepted source and test-code observations.
