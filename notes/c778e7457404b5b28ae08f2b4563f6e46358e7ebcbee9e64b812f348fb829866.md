# The UID wrapper removal changes the intermediate combined helper's empty-result status

This landing removes the wrapper that rejected an empty key list. The still-present BuildIdsAndKeyArray keeps only successful GetMessageKey results, formats that list directly, and returns NS_OK even when the list is empty. Its earlier empty result reached NS_ERROR_INVALID_ARG through the wrapper. This is a historical intermediate status contract; the next landing removes the combined helper, and the fixed source uses separate producers. No runtime reachability, unintended regression or new empty-result test is established.

Scope: IMAP UID helper migration phases.
