# Keep handler executable validation tied to platform-specific self names

The accepted validator requires an existing executable and rejects the application’s own expected leaf name: MOZ_APP_NAME + ".exe" on Windows, MOZ_MACBUNDLE_NAME on macOS, and MOZ_APP_NAME + "-bin" elsewhere. Its comment admits that this is not a comparison with the running executable identity. Keep those platform spellings when editing this validator; do not describe the leaf-name check as canonical-path or same-file protection. No alternate executable, renamed application or platform picker test ran. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: mail handler executable validation.
