# Removing MSGApopMD5 does not remove APOP authentication

Entry 1215 removes the unused public C++ MSGApopMD5 declaration and implementation. Exact-symbol searches of its parent revision find only those two definitions, and the accepted revision has no occurrence. The current POP3 JavaScript client still computes and sends APOP authentication. Keep removal of the obsolete helper separate from removal of the protocol feature. This is source-backed call-site evidence, not an assessment of APOP security or proof of a successful server exchange; no POP3 test or build was run. Full bug and review discussion remains pending.

Scope: POP3 legacy helper removal.
