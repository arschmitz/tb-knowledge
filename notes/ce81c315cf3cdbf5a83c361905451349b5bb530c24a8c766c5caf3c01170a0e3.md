# Changing SCHEDULE-AGENT also clears old scheduling result parameters

In the forced-client branches of adaptScheduleAgent, setting SCHEDULE-AGENT to CLIENT also deletes SCHEDULE-STATUS and SCHEDULE-FORCE-SEND. Explicit NONE is preserved. Recommend updating related protocol parameters as one operation in this helper so stale server results do not describe the new responsibility. This is scoped protocol-source behavior, not a claim of complete RFC validation. This is static source and test-code inspection.
