# Use the sync template’s no-resource spans as visible state, not selection inputs

1956 changes noAddressBooks/noCalendars from p to span. Current setState hides select-all for an empty array and shows the matching no-resource span; it populates input containers only for resources. Preserve their IDs and sync-option class when adjusting layout. The source supports a text-state boundary, not an independently verified spacing or screen-reader result. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.
