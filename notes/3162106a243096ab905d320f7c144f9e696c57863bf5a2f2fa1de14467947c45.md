# Use a named listener when a one-shot callback removes itself

The compose attachment tests register function listen directly and pass that same function to removeListener before resolving. A function name inside its own body gives each registration its own removal identity without an outer redeclaration. Retain the exact callback identity when writing one-shot extension event waits; a new arrow function would not remove the registered listener. This is scoped to self-removing callbacks, not a rule that every callback must be named.

Scope: Extension one-shot listener identity.
