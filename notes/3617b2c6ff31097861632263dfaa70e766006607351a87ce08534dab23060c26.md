# Panorama new-message lists are separate from unread flags

Entry 2073 adds an in-memory mNewList to each PerFolderDatabase. AddToNewList suppresses duplicates; GetFirstNew returns its first key or nsMsgKey_None; GetNewList returns a clone. MarkNotNew removes a listed key and separately clears the New bit in the message store. ClearNewList only clears this list. The historical test adds already-read keys after markAllRead, showing that list membership is not unread state. Its sorting method is initially a stub; fixed source implements sorting. Proposed checks cover clone independence, clear behavior and sorting after reverse insertion. No runtime or notification test ran.

Scope: mailnews Panorama new-message list.
