# Adapt the tray Fluent bundle before adding and formatting its resource

923 replaces the bare Fluent bundle with FluentBundleRc, calls adapt_bundle_for_gecko and adds the resource through Rc. The checked Gecko adapter configures number formatting, PLATFORM, NUMBER and DATETIME functions, pseudo-localization and bidirectional isolation preferences. The Linux tray then formats its quit label and logs formatting errors. Preserve the adapter call before resource use. No localized tray or Rust build was run. Exact comm-to-Gecko revision pairing was not established.

Scope: Linux tray Fluent integration.
