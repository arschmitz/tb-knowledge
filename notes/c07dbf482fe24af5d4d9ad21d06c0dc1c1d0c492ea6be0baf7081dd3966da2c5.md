# Contact conversion adds local photos to a cloned vCard

At revision 5bc47cc15bfa2aa6abfd4d6f4eff817b9503ac81, WebExtension contact conversion clones the card's vCard properties before adding export data. If there is no photo entry but PhotoName exists, it reads the profile Photos file and adds a photo entry to that clone. The source explains that local address-book photos are omitted from the stored _vCard to reduce database size. A photo-read failure is logged and conversion continues. Preserve the distinction between exported photo data and stored card data. This is static source evidence; no runtime validation is supplied.

Scope: WebExtension address book contact photos.
