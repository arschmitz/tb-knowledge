# Choose callback method syntax for the receiver the callback needs

The OAuth prompt listener deliberately uses a plain method for onPromptStartAsync so this refers to the listener object, and an arrow for onPromptAuthAvailable so this refers to OAuth2Module. The comment documents the difference. For this callback object, preserve the chosen receiver when converting methods or extracting functions. This is a scoped JavaScript syntax recommendation, not a rule that all callbacks should use arrows. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: OAuth callback receiver syntax.
