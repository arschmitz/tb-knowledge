# The EWS rename mock uses XML collections as elements

The added UpdateFolder handler gets collections from getElementsByTagName, then uses element-only operations without selecting a node: getAttribute for the folder ID, textContent for the display name and appendChild for the response folder container. The parser is a DOMParser and the accepted source retains these accesses. Select and validate the intended element before those operations. This is a static contract finding, not an executed test failure; the historical reviewer report does not resolve it.

Scope: EWS fake-server receiver contracts.
