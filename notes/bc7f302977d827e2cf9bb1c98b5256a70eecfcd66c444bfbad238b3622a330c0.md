# Storybook suppresses startup prompts only in its temporary-profile preference branch

The launcher adds suppress_dialog_on_startup=true and checkDefaultClient=false only when it chooses a temporary profile. storybook.openTab=true is still supplied in either profile mode. The account startup and first-run helpers honor the suppression preference; Mach receives both setpref and temp_profile arguments. Native default-client behavior and a launched Storybook/profile result remain untested.

Scope: Storybook development launch preferences.
