# Use explicit resort when data changed but sort keys did not

sortBy returns early if the requested column and direction match the current ones, unless resort is true. D208447 review requested the optional argument default in the signature to match its documented default. Address Book later uses sortBy(..., true) after a name-format preference change. This avoids redundant sorts in ordinary UI events while allowing a data change to update the current order.

Scope: Tree sorting.
