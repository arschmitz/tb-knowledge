# Content-policy checks assert minimum window geometry before judging remote content

The test clears persisted compose/message documents and then asserts a standalone window's inner width of at least 700 and inner height of at least 600 after load, MsgLoaded and focus. Those direct checks expose an undersized test window before the content verdict. The original reset occurs once per scenario; accepted code later also clears message-window state inside the helper before each open. These are test baseline phases, not production default changes or proof that the intermittent failure is fixed. No test was run.

Scope: Content-policy browser test baseline.
