# The Graph generator carries paging metadata into the operation response type

The parser marks an operation pageable when x-ms-pageable is present. Generation wraps its success type in Paginated and emits it as the Operation response type, so the client no longer asks the caller for an unrelated generic response type. The original response lifetime is nominally present but constrained by DeserializeOwned; later accepted Operation removes that lifetime parameter. This is generated request/response type wiring, not proof of remote paging, structured metadata validation or automatic iteration.

Scope: Graph generator response contract.
