# Compose closure moves to JavaScript while native cleanup moves to destruction

The landing removes nsIMsgCompose.CloseWindow and moves docshell unregistration plus send/editor release into the initialized native destructor, retaining the attachment-lifetime guard. Successful Now/Later sends close in JavaScript after awaiting sendMsg; saves stay open. Awaiting the original delivery chain does not prove sent-copy completion. Accepted code later waits for progress-stop before closing and includes Background. Native cleanup ordering is not a measured leak or collection result.

Scope: Compose window close and native cleanup phases.
