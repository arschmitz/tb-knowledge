# AppMenu update banners stop forcing flex-start alignment

The banner CSS removes its align-items: flex-start override. The actual consumer is a toolbarbutton; PanelUI sets its localized label and notificationid before showing it. Update icons retain their16px dimensions, trailing order and centered background image. This verifies the scoped override removal and consumer, not a measured layout or accessibility result.

Scope: AppMenu update notification banner styling.
