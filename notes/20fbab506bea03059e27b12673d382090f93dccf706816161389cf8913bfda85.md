# Static MIME preferences keep the consumer lifetime of copied header and stream state

The message-display migration declares always-mirrored preferences, but callers still choose when to read them. The base emitter copies mail_show_headers at construction and later filters headers through mHeaderDisplayType. The HTML emitter reads mail_show_headers for each BroadcastHeaders call. Display-stream setup copies attachment, charset and HTML options into stream state. An always-mirrored declaration alone does not refresh those already-copied fields.

Scope: MIME preference reads and emitter state.
