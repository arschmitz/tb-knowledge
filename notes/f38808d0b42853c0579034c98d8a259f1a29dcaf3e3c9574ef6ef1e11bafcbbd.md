# CID substitution preserves named text parts as attachment candidates

During accepted related-part URL substitution, hide_related_part_p declines to set dontShowAsAttachment for a part with a nonnull header-derived name and a text/ content type. The name helper checks filename/name headers and fallbacks; the flag consumer skips attachment-data generation when hiding is set. This exemption does not clear other hidden state or cover every named MIME type. Viewer and draft tests assert attachment count and names, not content bytes or opening behavior. No parser, UI or test ran.

Scope: MIME related-part attachment visibility.
