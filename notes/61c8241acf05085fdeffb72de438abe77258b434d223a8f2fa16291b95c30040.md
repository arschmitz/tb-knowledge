# Clear the search timer before calling interruption listeners

The historical interrupt path canceled the timer, called NotifyListenersDone, and then cleared m_backgroundTimer. The change clears the timer first. Current source preserves that order and keeps a self-reference across the callback. This leaves observers seeing the timer as stopped and avoids writing that field after a callback that can release external references. Preserve both state ordering and the existing lifetime guard when editing this callback path. The exact reported crash was not reproduced. Static source and test inspection only.
