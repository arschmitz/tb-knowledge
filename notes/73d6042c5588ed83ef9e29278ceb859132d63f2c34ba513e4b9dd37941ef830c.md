# TreeView readiness, row-frame filling and localized labels have separate completion points

At fixed0b93, TreeView.isReady checks connection, view/height and its idle-buffer handle. It does not inspect each row animation-frame token. The row index setter schedules later fill, and ThreadRow/ThreadCard set their composed aria-label after a separate Promise.allSettled chain. Treat those as separate completion points when extending tests or callers. Existing sorting tests explicitly distinguish scroll and fill frames; that is not a universal two-frame guarantee for every localized label. Static source/assertion reading only; no timing or accessibility run.

Scope: Virtual message-list row completion.
