# Perform Exchange local deletion after remote operation success

Current hard deletion supplies an ExchangeSimpleFallibleMessageListener. Its success callback invokes LocalDeleteMessages and reports the local result through the copy-service guard and folder event. The failure callback reports the folder failure and stops activity feedback. LocalDeleteMessages deletes cached bodies only for offline messages, deletes all selected database keys, then emits the deleted-message notification. This is ordered cleanup, not a cross-server/database atomic transaction. Remote failure or partial remote success was not exercised here. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Exchange remote/local deletion ordering.
