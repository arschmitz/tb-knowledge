# Measure recovered compaction space from the actual file-size delta

Current compact_space_recovered accumulates oldSize - newSize only for a successful final status. It is a memory_distribution with memory_unit: byte; the initial compact_bytes_recovered custom_distribution is historical. The test expects expungedBytes plus removed separator overhead, rather than equating the metric with expungedBytes alone. Those tests cover local mbox storage and explicitly leave IMAP offline and maildir coverage as TODOs. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Folder compaction recovered-space metrics.
