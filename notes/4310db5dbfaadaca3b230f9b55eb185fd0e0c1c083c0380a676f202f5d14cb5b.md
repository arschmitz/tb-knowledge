# Freeze the passphrase tab decision for an open key-details dialog

The historical fix removes tab and panel visibility changes from reloadData. Current onLoad computes gShowPassphraseTab once from a personal key and either the enabled preference or existing user-passphrase protection, then applies the same hidden value to passphraseTab and passphrasePanel. The preference does not change existing secret-key protection. A key already protected by a passphrase must remain manageable even with the preference disabled. Current source also releases tracked keys when the dialog offers no passphrase management; this is not a complete secret-key lifetime audit. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: OpenPGP key-details tab lifecycle.
