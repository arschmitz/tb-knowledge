# Check self-signatures and live user IDs before deciding a key advertises unsupported features

The feature check collects flags from primary-key self-signatures and user-ID self-signatures, skips revoked user IDs and photo user IDs, then removes Thunderbird-supported flags from the bitmask. The landed supported mask held MDC only; AEAD and v5 bits were defined but unsupported. The code also checks a newly imported key object before the import UI warns. This is a feature-advertisement test, not proof that the key material itself is unusable. Current RNP.sys.mjs retains the same structure.

Scope: OpenPGP feature detection.
