# Custom Thunderbird link registration has a separate flag and a later checkbox-default phase

NET_THUNDERBIRD is a separate app-type bit, so callers can request custom-link registration without choosing MAIL. Startup checks both bits. The original dialog checks and disables the box only when already default; accepted later code checks it outside preferences even when registration is missing. Keep that later default-selection follow-up separate from the original registration split. No operating-system or profile-routing result was executed.

Scope: System integration app types.
