# ProfileCreator distinguishes summary, mail storage and child-directory paths

ProfileMailFolder.path is the .sbd child directory, summaryFilePath is the .msf file, and mailFilePath is the mbox file or maildir directory. addMailFolder copies a supplied summary, creates a maildir directory or copies/creates mbox content, then returns its folder through an async promise. A later landing restores consumer test changes lost across helper ordering. The inspected @returns annotation omits Promise and should not be copied as accurate async documentation. No profile test ran.

Scope: Profile fixture filesystem contracts.
