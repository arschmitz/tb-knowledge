# Flatpak repacking returns lint failure after packaging the artifacts

The repack script captures the linter status instead of letting set -e stop at lint failure, then creates and moves the tar and Flatpak bundle before returning that status. Packaging errors can still stop earlier. The image copies the application-specific exception map beside the script; the accepted image later supplies the linter and clears its inherited entry point. This is static source evidence, not a successful release or lint run.

Scope: Thunderbird Flatpak release repacking.
