# The message-theme test synchronizes on theme update and computed color

The message-theme test installs its windowlwthemeupdate waiter before allowing the extension to update the theme. It then waits for a frame and the expected computed border color. The assigned patch removes a setup-only prefersReducedMotion override and its matching cleanup. These scoped waits remain the synchronization contract; the source does not establish a general animation-preference rule or reproduce the reported cross-test interaction.

Scope: Extension message theme test synchronization.
