# The Move and Copy submenu migration copies label patterns into new IDs

The Recent Destinations and Favorites migration creates new no-accesskey IDs by copying only each old .label pattern. It does not request the old .accesskey or copy the whole entry. The archived accepted recipe is identical to the original. This preserves a narrow source-level translation boundary; it does not prove that a locale migration ran, remove every old localized entry or establish native keyboard behavior.

Scope: folder menu Fluent migration.
