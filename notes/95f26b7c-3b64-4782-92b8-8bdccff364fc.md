# Size Calendar summary dialogs after localized content settles

The toolkit flexbox migration left event summary dialogs too short on Windows and Linux, hiding controls until users resized the window. The May fix removes a 100vh inner-dialog height and the load-time sizeToContent call. It adds a temporary resize class so CSS :has() gives the outer dialog height:auto during setup, then removes that class after item details and translated text are ready. The notification transition still calls sizeToContent separately. D207656 questioned the selector; the author said the dialog could not grow or resize correctly without it, and review accepted it as a temporary workaround. Do not generalize the workaround to new dialogs; inspect the current dialog and platform behavior before changing it.

Scope: Calendar summary dialog layout.
