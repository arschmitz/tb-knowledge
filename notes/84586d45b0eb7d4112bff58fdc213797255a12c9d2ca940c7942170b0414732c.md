# Send-later resolves its queue preference in the folder-cache miss path

GetUnsentMessagesFolder reads mail.default_sendlater_uri only when its weak folder cache does not resolve. A failed or empty preference selects ANY_SERVER. A literal space in a configured URI becomes %20 and the corrected value is saved before LocateMessageFolder resolves the queue-for-later folder. The caller then stores a weak reference. HasUnsentMessages treats a missing queue as no unsent messages. This is the surviving queue-specific contract from the removed GetFolderURIFromUserPrefs helper, not a general preference or URI escaping rule. The historical patch changes no tests; these facts come from exact source, without a fresh send or build.

Scope: mailnews-compose.
