# Check both Mork row IDs before changing the duplicate lookup

D209891 was mostly a lint and dead-code cleanup. The author identified its main intentional check: after FindRow returns an out row ID, older code calls GetOid on the row to fetch the same ID. The patch adds MOZ_ASSERT that both IDs agree at several lookup sites rather than immediately replacing the old path. This limits behavior change while exposing a broken assumption during debug runs. The current message database retains the equality assertion.

Scope: Message database internals.
