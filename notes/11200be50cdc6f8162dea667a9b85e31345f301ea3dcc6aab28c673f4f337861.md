# Append a UID integer directly when building the IMAP zero-length UID list

1360 removes a temporary sprintf buffer and long cast from zero-length UID collection, retaining comma separation and using fZeroLengthMessageUidString.AppendInt(CurrentResponseUID()). Accepted code keeps that form. For this native string-building path, prefer the string API’s integer append over a manually sized buffer when the output is only the integer representation; this is a scoped recommendation beyond layout formatting.
