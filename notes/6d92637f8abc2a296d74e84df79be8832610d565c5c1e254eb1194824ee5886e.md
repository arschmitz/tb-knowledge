# The add-ons category test reads the categories-box state property

The test now queries categories-box and directly asserts currentViewId equals the requested Themes view URI. Its existing helper waits for the tab and browser load, and openAddonsMgr routes the URI to the actual manager. The assertion checks the state property, not the rendered reusable navigation component, focus or accessibility. The upstream component and a fresh test run remain unverified.

Scope: Add-ons manager browser-test port.
