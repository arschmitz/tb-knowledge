# DisableBuiltinPDFViewer now requests MIME-handler actions instead of only locking a pref

The callback defers to an explicit PDF Handlers policy. With false it clears the pdfjs.disabled user pref and requests internal handling through a run-once helper; with true it requests the system default. The old simple-pref lock case is removed. This source inspection does not establish native handler persistence, PDF opening or a passing replacement regression test.

Scope: Enterprise policy callback and source comparison.
