# Thunderbird Calendar event-row validation location and Save gating

`setSectionValidity()` in `calendarEventDraftSlice.mjs` stores a structured clone in `draft.validation`; it does not inspect field values. `selectCanSave()` requires stored active-section results to be valid, ignores disabled rows, and permits missing results. `saveCalendarEventEdits()` calls it before saving.
