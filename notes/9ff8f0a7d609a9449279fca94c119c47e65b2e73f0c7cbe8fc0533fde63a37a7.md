# Share UI listeners by reference count and remove state at the last subscriber

The UI event emitter installs folderURIChanged and select listeners only when listenerCount reaches one. The last decrement removes both and replaces the WeakMap used for folder deduplication. Persistent event unregister handlers remove their emitter listener and decrement the same count. Preserve this shared ownership when adding another event in this API; do not install one global window listener per extension subscriber. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: MailTabs listener lifetime.
