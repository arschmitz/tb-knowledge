# Roll back a newly persisted outgoing server when saving its settings fails

SmtpServerEdit creates and persists an outgoing server before saveSmtpSettings completes. Previously a save error was logged but the dialog still reported success and left a half-configured server. Bug 2069949 tracks the new server, clears its values and deletes it on failure, clears the returned key, reports result=false, and prevents the dialog from closing as a success. Sync also checks record.location before createServer. Validate inputs before persistent creation where possible, and undo persisted creation when later configuration fails.

Scope: SMTP account settings.
