# The non-Exchange add-on assertion checks identity rather than mutation

Without an Exchange incoming alternative, getAddonsList returns the original config before fetching or adding addons. The new test asserts strict object identity and an absent addons field. Its identity assertion message says the config should be modified, which does not describe this path or what strictEqual proves. A future test message should state that the original config is returned. This is a scoped assertion-meaning finding, not a claim that the test was run or failed.

Scope: Account-creation add-on discovery test expectations.
