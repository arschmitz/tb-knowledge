# Treat an installed add-on as active and matching rather than merely present

AddonInstaller.isInstalled checks a returned add-on, its required identity/version match and isActive. isDisabled checks presence with inactive state, and install skips work when the active matching test succeeds. The helper can return a falsey non-boolean value when no add-on exists despite its boolean JSDoc. Do not reduce this gate to an ID lookup alone or use the annotation as proof of the runtime type. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account creation add-on status contract.
