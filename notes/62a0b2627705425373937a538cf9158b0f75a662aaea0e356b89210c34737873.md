# Certificate alert callbacks keep their context after debounce expiry

In the inspected alert hook, activeAlerts tracks duplicate suppression only. The certificate error context stays in the showExceptionDialog closure and the notification click calls that function directly. Resolving the five-second debounce removes the cookie from the Set; it does not look up or delete the captured certificate context. This keeps the dialog input separate from duplicate-alert state. It does not prove a native backend delivers a later click or that an override is safe or automatic. The owned observer API and later accepted callback API are separate phases. No native notification or certificate UI ran.

Scope: Connection and certificate alert callback lifetime.
