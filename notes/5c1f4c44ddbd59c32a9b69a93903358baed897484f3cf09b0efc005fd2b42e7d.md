# The legacy database clears a present New bit but still notifies every found listed header

On the notify=true, nonempty path, ClearNewList swaps the stored new-key list out before callbacks. It tests flags & New and clears that bit only when present, then notifies every listed header it could resolve, using old flags with New set and the current flags. NotifyHdrChangeAll separately checks that the header remains in the database. The folder caller explicitly uses ClearNewList(true) and clears its own new-message state. This is the legacy receiver, separate from Panorama's list behavior.

Scope: Legacy message database new-list clearing.
