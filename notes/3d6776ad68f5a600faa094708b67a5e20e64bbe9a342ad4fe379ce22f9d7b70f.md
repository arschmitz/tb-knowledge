# Set translated headings before measuring their layout

Current multi-day labels use synchronous formatValueSync/textContent before readjustView measures the short and long headings. Asynchronous document.l10n.setAttributes is unsuitable at this measurement boundary without an explicit completion wait. This is a scoped timing requirement, not a rule that all localization must be synchronous. Resource availability and localized long labels still need runtime checks.

Scope: calendar/base/content.
