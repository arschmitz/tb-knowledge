# Folder-row ARIA serials reject older localization runs after a newer run starts

FolderTreeRow caches row values, debounces updates for 50ms and assigns a serial when localization work starts. A completed older run cannot replace aria-label/title after a newer run has started. A setter only schedules the next run, so an older result may still apply before that next timer fires. The guard does not cancel Fluent work or prove immediate invalidation on every property change. Existing Text nodes are updated without child-list replacement; fallback textContent still may notify the actual child-list observer. No race or performance measurement ran.

Scope: Folder pane localized accessible-name scheduling.
