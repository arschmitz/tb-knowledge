# CSS Prettier support separates the two per-tool ignore lists

The root Prettier list admits CSS. The ESLint-specific list ignores CSS, and the Stylelint-specific list ignores the listed non-CSS formats. The permission-check configuration also starts selecting .css files. This is a scoped configuration change; the external formatter invocation and all 163 bulk CSS bodies remain unverified. No lint/autofix or visual result is claimed.

Scope: lint/prettier-css-config-scope.
