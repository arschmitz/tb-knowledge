# Rewrite feed folder authorities before changing the feed server hostname

For affected old RSS profiles, MailMigrator reads the subscriptions JSON, chooses an available Feeds or Feeds-N hostname, replaces the mailbox authority in each destFolder, writes the JSON and only then assigns server.hostname. Restart is scheduled after the collected promises resolve. Preserve the path suffix when changing the authority. Source order was checked; concurrent collision selection, write failures and restart recovery were not tested, so this is not an atomic migration guarantee.

Scope: mail/modules/MailMigrator.sys.mjs.
