# The Graph notnull macro supports both values and patterns

notnull! expands to Some(Some(...)) and is used to construct an outgoing present value and to match a present non-null extended-property value. A generic constructor function would cover the value expression but would not replace the let-pattern use. Keep that concrete pattern consumer when assessing the macro rationale. The extended-property guard returns None for an absent/null value; parsing a present string remains a separate fallible step.

Scope: Graph nullable field helpers.
