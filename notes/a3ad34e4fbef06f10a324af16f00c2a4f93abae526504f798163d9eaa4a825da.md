# Windows App SDK port connects target fetches with package library declarations

The port adds target-matched App SDK toolchain fetches to 13Windows build variants and references the x86, x86_64 and aarch64 toolchain names. It separately lists eight libraries inside the Windows package-manifest branch. Accepted source retains these declarations. Build dependencies and package payload are separate integration steps; these static declarations prove no artifact availability, SDK/DLL ABI compatibility, completed package or runtime load.

Scope: windows-build-packaging.
