# Mailbox-size test early returns limit coverage and retain separate diagnostic mistakes

The low-space setup return occurs before near-limit fixture growth and listener registration; individual task guards can return before download/compaction assertions. Those branches are not executed boundary coverage or proof that all later tasks are skipped. The guards use diskSpaceAvailable, but three diagnostic strings use diskSpaceAvailabl. A new Download successfully failed log also precedes the onDone promise wait, and the retargeted compactUnder size assertion lacks a message. Keep guard state, diagnostics, direct assertions and actual completion separate.

Scope: Over-4-GiB mailbox test diagnostics.
