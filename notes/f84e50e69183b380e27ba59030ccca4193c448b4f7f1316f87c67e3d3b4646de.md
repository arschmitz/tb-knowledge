# Copy compose encryption flags into the fields returned to callers

930 adds requireEncryptMessage and signMessage assignments in GetComposeDetails. The accepted function updates recipients, subject, attachments and these security fields before returning the same compFields object; GenericSendMessage calls it. The C++ S/MIME state extractor reads its stored flags. Keep the JavaScript UI state synchronized at this handoff rather than relying on whichever toggle last wrote the native object. No send, encryption or C++ runtime test was performed.

Scope: Compose UI to native security state.
