# Attachment sizing moved from a height attribute to CSS and later separated its preferred size from the pane cap

The historical patch writes a pixel-valued style.height instead of the height attribute and clears it when collapsing. The checked current expansion path calculates --preferred-height from the list and bar, while list-expanded CSS caps max-block-size at min(preferred height, 25%). Collapse still clears inline height left by the splitter. Current source also updates aria-expanded and translated labels, and its key handler passes focus intent for Space/Enter. The existing collapse focus TODO remains; these are source contracts, not rendered sizing or keyboard/accessibility proof. No test is changed by the historical patch.

Scope: Message attachment expansion sizing.
