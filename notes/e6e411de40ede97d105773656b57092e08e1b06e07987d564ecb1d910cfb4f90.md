# The Owl offer is independent of incoming and outgoing configuration columns

The layout change moves owlExchangeDescription outside the incoming/outgoing selection grid and reduces its own padding. The information link and install button keep their IDs and separate actions; showing the offer is independent of either configuration column. The accepted template also has a later enterprise guard. Preserve layout ownership separately from installation completion or control presence; this patch performs no JS action-handler change. No UI, install or accessibility test ran.

Scope: Account Hub configuration-found layout.
