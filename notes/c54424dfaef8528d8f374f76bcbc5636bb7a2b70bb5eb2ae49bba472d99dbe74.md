# Let the extension account helper own fake IMAP server startup

createAccount("imap") already starts and configures the fake server. The account-list tests removed a second open call and duplicate port/credential setup in both MV2 and MV3. The fixed helper is async and each fixed caller awaits it before publishing the account to the extension. These tests assert account listing and folder shapes; they do not directly assert the number of server starts. Apply this ownership rule only to callers of this helper, and check other harnesses before removing explicit startup.

Scope: Extension xpcshell account setup.
