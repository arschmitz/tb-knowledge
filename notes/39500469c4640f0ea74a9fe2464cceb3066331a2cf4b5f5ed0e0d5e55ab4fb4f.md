# The selected-color token port keeps definitions, guarded consumers and focus states together

The owned port renames selected background, selected text and selected-unfocused variables while retaining their values and selectors. Its selected, disabled, keyboard-focus and focus-within consumers keep distinct conditions. Accepted code later uses Thunderbird selected-item foreground/background tokens directly in these consumers, while richlists retain a separate unfocused background alias. Match the concrete definition and selector state when describing this change; token names alone do not establish current DOM matching, OS color output or contrast.

Scope: Account and Preferences selection token dependency.
