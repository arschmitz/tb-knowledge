# Ingestion reuse population: cross-repository byte matches and generator families

The 2026-10-14 audit reused the existing file census and added cross-repository and family breakdowns. The [earlier calibration](acf9ed87-1c83-4bcf-b603-b9c3b483d2f6.md) already recorded 524,471 included origins, 476,461 distinct Git blobs and 48,010 redundant copies. These totals are reused, not new behavioral coverage. An origin means one repository-relative path at its pinned revision.

Of the 23,428 same-path pairs, 23,424 have the census's imported primary role, three have its other role, and one has its test role. Equal bytes support reuse of body reading. They do not establish equal callers, build features, runtime, ownership or test assertions. Each origin retains those context obligations.

The same-path count uses the exact join `a.path=b.path AND a.oid=b.oid`, with `a.label='thunderbird'`, `b.label='firefox'`, and both `scope='included'`. Redundant copies are `count(*) - count(DISTINCT oid)` across included rows. Repeated bytes are the sum of `(group size - 1) * blob bytes`, grouped by Git object ID.

## Limits

Primary roles are ordered path/list heuristics, not a complete semantic partition. Imported files can contain tests or generated code. WebGL wrappers are classified as tests and the generated Test262 helpers as imported. The generated-role total therefore does not count every generated file. Fixture path matches also miss many real test fixtures. Language is largely inferred from suffix; runtime remains unresolved in the census.

No corpus-wide reusable-behavior total, full behavior-unit denominator or end-to-end speed gain follows from these counts. Even making all exact redundant copies free saves only 9.15% under an equal-cost-per-origin assumption, about 1.10 times faster. Actual semantic costs vary. No tests or generators ran in this population audit. These findings guide later work; they do not change instructions or remove imported/generated code from scope.
