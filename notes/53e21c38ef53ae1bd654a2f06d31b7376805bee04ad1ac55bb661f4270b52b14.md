# Wait for popup state and the actual mutation in browser tests

The repair review requested the state-aware popup helper and waitForMutationCondition rather than a generic event wait/poll. Current tests use BrowserTestUtils.waitForPopupEvent and waitForMutationCondition. Proposed manual test rule: use the current state-aware helper where an event may already have occurred, and wait on the actual changed property. Preserve the current API name instead of copying the 2024 waitForPopup spelling.

Scope: browser-tests.
