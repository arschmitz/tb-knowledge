# Move the single saved EWS message out only after validating response cardinality

The historical 1266 client checks that response_message.items.inner contains one item before moving it with into_iter().next().unwrap(), replacing clones/temporary collection. This is a scoped historical ownership change justified by an explicit size guard, not permission to use unchecked unwrap generally. Accepted EWS client code has since been split into operation modules; this study does not claim the old send/save path remains unchanged. This is source and test inspection only.
