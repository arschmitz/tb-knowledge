# The local-store regression task is registered for each pluggable store

test_ensureLocalStore removes the inbox store and directly checks its recreated path and type, including tmp and cur for maildir. The add_task(withStore(...)) registration is essential: a declared test function alone would not exercise this path. These assertions cover store creation, not the full frontend repair or restart discovery sequence.

Scope: Folder store xpcshell coverage.
