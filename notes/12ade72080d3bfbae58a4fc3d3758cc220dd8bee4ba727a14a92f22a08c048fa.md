# Treat raw MessagePart serialization as reconstruction that can mutate its input

messagePartToRaw unwraps the synthetic RFC822 envelope, merges its headers into parts[0].rawHeaders and may add a multipart preamble. It rejects missing rawHeaders and a truthy decoded body, then rebuilds headers, body and parts. Its checks are not a complete structural validator. Callers editing a raw tree should expect reconstruction and these mutations; the result is not promised to retain original header case, preamble or byte identity. The fixture test checks the reconstructed lines and filters protocol status headers. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/raw-tree-reconstruction.
