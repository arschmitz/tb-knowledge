# The inherited IMAP filePath getter returns a clone of cached path state

The deleted IMAP overrides only forwarded to nsMsgDBFolder. Its fixed GetFilePath initializes mPath through parseURI when needed, checks it and returns Clone, while SetFilePath stores the supplied reference. Removing those forwarding overrides preserves this specific inherited behavior; it does not establish that every accessor wrapper is redundant. The actual base relationship and implementation were checked. No filesystem/build test ran.

Scope: IMAP inherited folder paths.
