# Optional component features use defined rather than required-key lookup

The Windows address-book and import component declarations test defined("MOZ_MAPI_SUPPORT") because an explicitly disabled optional feature can leave no substitution key. Required OS_ARCH remains a direct lookup. Manual build-syntax proposal: use the component-declaration defined helper for optional feature presence in these files, and preserve the Windows guard. This fixes a disabled-configuration path; it is not a rule to replace every buildconfig.substs lookup with a default. No --disable-mapi build was run.

Scope: component-registration.
