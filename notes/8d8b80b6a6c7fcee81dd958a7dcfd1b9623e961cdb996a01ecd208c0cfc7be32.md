# Rust outgoing password lookup delegates to the shared module after checking the cache

The outgoing getter first returns a nonempty module cache. Otherwise it passes username, endpoint hostname and protocol to QueryPasswordFromManagerAndCache and propagates the XPCOM status. The same landing repairs the JS wrapper to return its cachedPassword after synchronous settlement waiting. The fixed getter retains delegation with later server-type/raw-pointer forms and the JS cache later becomes private. This getter does not itself prompt. No test changes or live login/no-prompt result are established; the separate cache-versus-current-lookup-result limits remain in the existing module lesson.

Scope: Rust outgoing password lookup delegation.
