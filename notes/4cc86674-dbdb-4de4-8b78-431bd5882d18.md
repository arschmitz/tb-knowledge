# Address book file import tests exercise AddrBookFileImporter instead of old XPCOM modules

The user-facing about:import flow uses AddrBookFileImporter for contacts. This revision removed redundant XPCOM address book importer tests and kept one test_AddrBookFileImporter.js suite that constructs that class, imports a file into a temporary book, and compares resulting cards. Current test keeps that path. When changing CSV, LDIF, or vCard import, use the live importer path rather than reviving dead nsIImportModule address book tests.
