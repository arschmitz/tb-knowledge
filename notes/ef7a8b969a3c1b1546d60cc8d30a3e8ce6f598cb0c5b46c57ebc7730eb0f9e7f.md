# Graph ISPDB support separates URL parsing, protocol choice and browser-test coverage

The owned patch allows a Graph incoming entry only when mail.graph.enabled is true. It derives hostname and socket type from the URL, keeps the generic URL and the internal exchangeURL endpoint, and adds Graph to the discovered configuration options. Local URL catches do not bypass the later socket, authentication and incoming-hostname checks. The parser assertions cover normalized fields. The accompanying browser change exposes Graph while still selecting EWS, so it adds no direct Graph-creation result. Later fixture and UI changes remain distinct from this original phase.

Scope: Account Hub Graph autoconfiguration.
