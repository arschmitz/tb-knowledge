# Derive the Account Hub cancel control from the active operation

The email abortable setter stores an AbortController and changes the directional button text between Cancel and Back. It passes the active controller or previous step to canBack. Changes to the busy UI should preserve this operation-dependent cancellation control. The historical setter also changed Forward disabled state; that specific old implementation is not the accepted setter and should not be copied as the current contract. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Account Hub cancel control.
