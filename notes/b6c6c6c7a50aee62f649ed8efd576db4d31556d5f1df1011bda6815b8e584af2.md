# Acquire an OTR conversation only when notification actions need it

notifyVerification calls getUIConvFromContext only for cancelable or verifiable notifications and returns if that action owner is absent. Non-actionable error notifications can still be created without a live conversation. Cancel and ignore callbacks obtain a fresh Context from cachedUiConv.target when activated. Preserve that lookup timing instead of closing over the original native Context. No runtime teardown race was reproduced.

Scope: chat/modules/OTRUI.sys.mjs.
