# New-folder minimum declarations and the geometry test floor remain different contracts

The owned patch replaces a fixed 200px height with a 12.5rem minimum and changes the width minimum to 20rem. Its test separately lowers only the width floor to 235 pixels and leaves the 120-pixel height floor. Accepted markup later uses 22rem by 18rem while those broad test floors remain. The actual command opens a non-resizable modal dialog. Source declarations and assertion thresholds do not prove font-scaling, resizing or a cure for the reported intermittent failure.

Scope: New-folder dialog geometry phases.
