# Keep migration reference paths and generated commit checks explicit

The migration test rejects a non-normalized reference path and resolves it through the project's l10n.toml mapping. It derives the migration module from the l10n subfolder and recipe basename. The 2024 checks require a bug number in that basename and part numbers in oldest-to-newest commit order by reversing RepoClient.log's newest-first list. These are tool-specific recipe constraints beyond formatting. Current reporting has since been expanded, so preserve the exact historical check separately from newer report behavior.

Scope: Fluent migration recipe and reference contracts.
