# Release the parser temporary even when its value is not stored

738 frees mailboxName after parsing XMAILBOXINFO. CreateAstring returns an allocated temporary, and the loop may use it without retaining it. The added release covers the end of the whole parse scope. xmailboxinfo_data is absent from the fixed accepted source, so this is a historical ownership lesson rather than a recommendation to call that parser API now. No allocation-failure or leak-checker run was performed.

Scope: Historical IMAP parser ownership.
