# Quick Filter hides the global-search submit control through host CSS properties

When the global indexer preference is false, QFB sets two custom properties on its search-bar host: hide the shadow submit button and replace its reserved end space with ordinary padding. Shared host defaults otherwise show the button and reserve 28px. The input, form and search-event handler remain; the actual search consumer still contains the Gloda-tab route. This is a presentation change, not a new backend or keyboard-submission gate. The separate upsell logic has its own indexer check. No test in this patch measures computed visibility or padding, and no live preference, input or accessibility check ran.

Scope: mail/quick-filter/search-control.
