# Bound the WKD padding claim to the quantity the expression measures

The WKD request uses x.repeat((512 - (url.length % 512)) % 512). It adds zero characters at an exact multiple and otherwise fills the remainder so URL character count plus padding is divisible by 512. The nearby comment refers to total packet size, but this expression does not measure HTTP headers, encoded bytes or transport framing. Preserve the arithmetic correction while treating the wire-size privacy claim as unverified. These are fixed accepted source and test-code observations.
