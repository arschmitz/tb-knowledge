# Thundermail sign-in learns the username before saving the refresh token

When the refresh token or granted scope changes, the OAuth module can fill a strictly null username from preferred_username for the explicit Thundermail or external.test origins. It updates both wrapper and inner OAuth objects before saving the refresh token. The added unit test uses a fabricated URL-safe token and directly checks saved login fields, reuse for the learned username and non-reuse for another null username. This is a scoped identity and persistence contract; the test does not establish JWT cryptographic validity or support for arbitrary providers.

Scope: OAuth username discovery and object reuse.
