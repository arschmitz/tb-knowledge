# isGmailFolder identifies an IMAP grouping node, not every Gmail folder

The read-only isGmailFolder attribute is on the IMAP-specific folder interface. Its native getter requires a server parent, a Gmail incoming server and NoSelect state, rather than a literal name comparison. The generic JavaScript caller first checks nsIMsgImapMailFolder. This is a grouping-node predicate, not a Gmail-account predicate or measured optimization; the changed test setups add interface queries rather than new getter assertions.

Scope: Gmail folder identity and interface boundary.
