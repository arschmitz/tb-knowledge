# Give icon consumers semantic tokens and vary the token by density

Read-state consumers use --icon-dot. icons.css selects the normal small asset and overrides this semantic token to --icon-dot-xs for compact density. This fixed a dot that was too small in normal and relaxed density. In this icon family, name CSS custom properties with lower-case dash-separated words, use --icon-* for the semantic icon and a size suffix for an asset variant. Change the shared token instead of teaching every consumer its density choice. This is a scoped code pattern; visual size, forced colors and zoom were not measured here.

Scope: Icon syntax and density.
