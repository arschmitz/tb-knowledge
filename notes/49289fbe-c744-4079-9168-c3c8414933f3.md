# Scope selected-row icon styling to each icon state

Bug 1894761 found that the old combined :not([data-properties~=flagged],[data-properties~=junk]) rule tied the inactive spam icon appearance to the star state. The accepted CSS uses separate selectors for the flag icon and spam icon, each with its own data-properties condition. The reviewer also removed a needless nested child rule. This is a concrete selector rule: when styling independent row actions, pair each state with its own cell. Current CSS has since changed, so inspect the current selectors before applying this old snippet.

Scope: Message list CSS.
