# Current nodefaultsrc and remote flags use attribute presence explicitly

The accepted browser creation paths use toggleAttribute("nodefaultsrc", true) and toggleAttribute("remote", true), while other XUL attributes still use string values. For these presence flags, follow the explicit presence operation instead of assuming all XUL attributes share one boolean syntax. This is a scoped DOM style pattern supported by current code, not reviewer-approved global policy. It does not replace value-based checks for attributes such as open="true" in the older menu family. No browser initialization or syntax/lint test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Content browser presence-attribute style.
