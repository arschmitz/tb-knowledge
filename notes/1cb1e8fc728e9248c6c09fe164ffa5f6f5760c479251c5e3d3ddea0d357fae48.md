# The phantom-twisty regression observes a collapsed background tab

The regression task opens two folder tabs from one browser window. It collapses the second view, deletes a child from the expanded first view, then checks that the second view still has one row and is no longer a container. The landed task name says tab. Its assertions cover row count and container state; the later accepted sort-after-delete task adds separate root-identity and sort-direction checks. Static assertions and historical review reports do not establish native multi-window or IMAP timing results.

Scope: Thread deletion browser-test coverage.
