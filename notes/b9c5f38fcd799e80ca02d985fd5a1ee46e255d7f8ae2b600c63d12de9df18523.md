# Keep escaped configuration names and TOML values valid in the generator

The target-dependency writer escapes embedded double quotes in the configuration name before writing [target."...".dependencies.<crate>]. inline_encoded_toml lowercases Python booleans and emits lists across lines, keeping dependency options and feature lists readable. These are scoped serialization rules retained in accepted code, beyond ordinary source formatting. The helper is not a general TOML serializer; no round-trip or platform regeneration test ran.

Scope: python/rocbuild/rocbuild.
