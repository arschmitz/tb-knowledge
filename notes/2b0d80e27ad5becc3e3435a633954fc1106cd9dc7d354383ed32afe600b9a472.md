# The virtual-tree click override is an explicit test-helper argument

The changed browser tests explicitly pass their AccessibilityUtils object to mailTestUtils.treeClick. The helper optionally calls setEnv with mustHaveAccessibleRule:false, synthesizes the click and calls resetEnv on normal return; callers that omit the object retain the existing path. Its comment explains the virtual row/cell versus shared DOM-node mismatch. The native checker and actual accessibility behavior are unpaired here, so these calls do not establish that every check is disabled or that an accessible click succeeded. Later accepted coordinate/target changes are a separate source phase.

Scope: MailTestUtils virtual-tree click and browser-test callers.
