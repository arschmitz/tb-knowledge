# Dark quote sanitization also visits unquoted HTML style sheets

The dark-mode inline selector is limited to quoted descendants, but the separate stylesheet loop selects every HTML style element in the document and calls the recursive rule sanitizer on its sheet. There is no quote-ownership check in that loop. The outside-style preservation case runs with false, while the dark outside-content case checks an inline div, so neither directly asserts preservation of an unquoted stylesheet under the dark walk. This is a source/test boundary, not a reproduced visual failure.

Scope: Quote sanitizer stylesheet scope and test boundary.
