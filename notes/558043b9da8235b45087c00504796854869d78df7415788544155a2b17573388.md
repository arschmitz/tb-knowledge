# The colored folder-icon story is a static token preview

The Colored story imports the icon and palette styles and maps fourteen image classes to icon/color variables. Its shared style draws a 20 percent fill and a currentColor stroke with 64px size limits. This previews token combinations for developers. It adds no interaction or assertion and does not establish production accessible names, rendered contrast or tested dark-mode behavior. The first file addition was deleted by its backout; accepted presence comes from a later phase. No Storybook build or preview ran.

Scope: Storybook folder icon palette examples.
