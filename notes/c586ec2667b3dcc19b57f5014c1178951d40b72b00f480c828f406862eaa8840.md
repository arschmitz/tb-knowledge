# Use a known failure directly inside a copy failure branch

The EWS repair replaces aCopySucceeded ? NS_OK : NS_ERROR_FAILURE inside if(!aCopySucceeded) with NS_ERROR_FAILURE. The fixed accepted ExchangeMessageCopyHandler retains the direct failure completion. Recommend this local branch simplification when a predicate already determines the status. It removes redundant logic; it is not evidence that the whole copy operation became safe or transactional. This is source and test-code inspection.
