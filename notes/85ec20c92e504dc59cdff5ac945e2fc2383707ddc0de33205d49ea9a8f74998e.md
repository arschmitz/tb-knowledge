# Thundermail backup completion ignores the save response

The backup helper awaits its save request and then writes the Backup complete label without checking the returned value. The API wrapper can resolve null for a network or HTTP failure. Thus this completion path records a settled request call rather than a verified successful backup response. Folder creation also awaits that backup helper before storing and exposing a new folder, so a null save response does not enter its thrown-error rollback branch by itself.

Scope: Thundermail generated backup and API completion.
