# Keep visual separation when dark-theme tabs are hidden

Bug 1819232 reduced mismatched dark-theme toolbar, field, sidebar, and list-header colors. D211018 reviewer requested keeping the top toolbar separation color because without tabs the toolbar otherwise blends into content. The accepted patch retains toolbar_bottom_separator while darkening toolbar and field and using toolbar-bgcolor for the list header. This is a behavior constraint for future dark-theme changes: check both normal tabs and all-tabs-hidden layouts before removing a separating edge. Exact 2024 colors may have changed.

Scope: Dark theme.
