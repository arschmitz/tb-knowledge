# Two touched S/MIME sink helpers have message-free comparisons

In the inspected encryptionStatus methods, the message-number comparison and nesting-level comparison omit the assertion message. A focused repair should state the expected message identity and level in nonempty messages containing should. These four inspected sites predate the new empty start hook. This finding does not depend on missing should alone and does not authorize unrelated rewrites.
