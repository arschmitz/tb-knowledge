# The mail-header move exports raw-span and IHeaderBlock entry points from the base module

The relocation moves the metadata parser out of nsParseMailbox into MailHeaderParsing, exports its header, compiles the implementation from mailnews/base and updates AddMessageBatch2 to ParseRawMailHeaders. Its three moved functions retain executable tokens after the parser rename; the IHeaderBlock wrapper still serializes through AsRaw. The header's direct-interface design is a future plan, not completed protocol decoupling. Caller timestamp policy and later subject/flag changes remain separate. No build, parser or database run was performed.

Scope: Shared mail-header parsing API ownership.
