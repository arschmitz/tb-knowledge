# A message key or Message-ID alone does not establish view membership

DBViewWrapper checks the header folder before native lookup in a single-folder view, because native findIndexOfMsgHdr checks the message key. A same-number key in another folder must not select a row. getMsgHdrForMessageID instead searches backing databases, returns the first matching header or null, and documents duplicate Message-IDs and filtered-out results. Manual naming and documentation proposal for these lookup methods: keep database-header lookup distinct from visible-row lookup and state the not-found value. A returned header is not proof of unique identity or visibility. No new production caller or direct lookup regression test was established in this bounded source pass.

Scope: message-view-identity.
