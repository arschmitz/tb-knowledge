# The address-book menu reland updates expected item data and window filtering

The reland keeps the initial four implementation blobs and adds expected-data entries for the legacy Address Book submenu/children and hidden Account Hub item. It excludes all five from the non-main-window table. MenuTestHelper.testAllItems checks menu state and rejects unknown or leftover item IDs, so these additions update its inventory; they do not exercise creation commands or both Hub preference states. Current relocated menu tests retain these expectations. Keep this test-data addition separate from the initial landing and explicit backout. Static source only; no menu or browser test ran.

Scope: File menu browser test inventory.
