# Keep compiler exception flags scoped to the affected target and source

664 addresses clang-cl compilation by applying /EHa only to aarch64 CLI builds and the stream-dump.cpp source, while x86 and x86_64 retain /EHs. These Thunderbird integration changes under third_party are human-authored build logic and were read in full; their path does not make them bulk vendor churn. Current RNP build files no longer contain these exception flags. Proposed manual build-review rule: document the target/compiler/source constraint and check current defaults before carrying a historical workaround forward. No compiler run was performed.

Scope: RNP architecture-specific build workaround.
