# EWS updated-message tests compare stable Message-ID, changed content and store-token replacement

The patch gives the fake server Update changes and InternetMessageId. Direct listener tests record header/store-deletion callbacks, while the real-folder task retrieves the same Message-ID after sync and checks changed subject/body plus a different store token. A moved message is checked by Message-ID rather than subject. These predicates establish fixture expectations, not actual filesystem deletion, every stream-error path or fresh server success. getMessageText resolves read stream content without status checking/rejection. Later current Graph/flag/six-message cases are separate. No test ran.

Scope: EWS sync update test boundaries.
