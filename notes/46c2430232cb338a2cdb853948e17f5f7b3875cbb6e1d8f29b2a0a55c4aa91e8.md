# The Calendar dialog activation fallback requests focus without confirming activation

The helper races an activate event against a 5000 ms timeout. The timeout calls win.focus and resolves immediately, so winning that branch does not prove the window became active. The edit mode then has separate iframe load/focus waits; the timeout is not a total operation bound. Accepted code retains this source boundary. Historical verify reports and diagnostic pass records are separate from a fresh focus result.

Scope: Calendar browser-test event-dialog completion.
