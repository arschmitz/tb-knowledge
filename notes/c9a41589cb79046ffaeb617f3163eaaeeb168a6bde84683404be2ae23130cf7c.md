# The LDAP cleanup removes old C++ mappings while keeping protocol errors

The historical cleanup deletes obsolete NS_ERROR_LDAP_* C++ mappings but keeps nsILDAPErrors protocol constants. IDL exception documentation changes to the remaining names. This is not evidence that every JavaScript method throws those documented values or that protocol result codes equal generated nsresult values. The exact runtime implementation remains a source-ingestion gap. Other entries remove unused mail constants and a never-set filter-specific overflow branch; the separate historical generic overflow text and invalid-header behavior do not establish removal of a user-facing header limit. Required Bug comment14 remains unavailable and reviews are deferred. No LDAP/filter test ran.

Scope: LDAP error interfaces.
