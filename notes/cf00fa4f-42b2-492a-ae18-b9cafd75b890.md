# Keep notification launch alive through the asynchronous message lookup

A Windows native notification can start Thunderbird without a normal window. Enter the last-window survival area before asynchronous tag lookup and leave it in finally after success or fallback opens a window. Entry307 prevents shutdown while the callback still needs services; current MessengerContentHandler keeps that structure. Installation-level cleanup spans profiles and an absent native alert service needs a guarded call. No Windows runtime was run in this study.

Scope: Windows notification lifetime.
