# Target-element tests exercise onShown lookups rather than menu-item clicks

The four tasks check element lookup in popup, message-display and content-script documents, plus null for an arbitrary background identifier. The popup and message scenarios also check replacement of a previous target after another context-menu event. Although the popup setup registers onClicked, no task clicks an item or consumes that event; lookup IDs come from onShown. Keep that setup separate from direct coverage. The tests do not force timestamp collisions or prove that every ID is null in background.

Scope: WebExtension target-element browser-test coverage.
