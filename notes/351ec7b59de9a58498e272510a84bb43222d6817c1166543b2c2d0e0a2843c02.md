# Test Calendar close behavior through both its button and native cancel event

The current dialog test sets an item, awaits show, clicks the close button and checks open is false. It reopens, registers a cancel-event wait before Escape and checks closure. The current close override also clears loading/data and resets its show promise. Preserve those current close paths when extending the skeleton test; checking DOM structure alone does not cover close behavior or loading lifecycle. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar dialog open and close test boundary.
