# Use the real ARIA attribute spelling for the notification status region

The historical 834 root uses aria-role="status", which is not the role attribute. The fixed accepted messenger markup uses role="status". Source presence does not prove a screen reader announces the region, especially as content changes. Review actual attribute spelling and live-region placement; do not infer semantics from a test that only counts elements.

Scope: Notification status-region attributes.
