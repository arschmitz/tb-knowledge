# Missing MIME headers skip receipt handling without ending the rest of message completion

The completion handler sets message-loaded state, then handles junk notification for a folder. It calls HandleMDNResponse only when channel.mimeHeaders is present; onEndMsgDownload remains after that branch. The receipt handler reads actual MIME fields. Keep its optional input guard separate from overall message completion. The named feed test checks format/preferences, without a direct null-header or MDN assertion; no failure or receipt run was reproduced.

Scope: Message completion and MDN headers.
