# The CSS import migration keeps explicit toolkit and shared-dialog exceptions

The owned migration moves shared style dependencies into actual XHTML loaders, but it retains CSS import paths where a shared integration still needs them. aboutExtra.css imports icons, colors and variables; the existing injected about-page link supplies that stylesheet. Shared preferences/dialog.css imports colors, while the comm SubDialogManager options supply that dialog stylesheet, preferences.css and variables.css. The same patch changes in-content dialog defaults to base text/surface tokens. These are scoped loader and token facts, not a ban on @import or proof of one runtime load, equivalent cascade, toolkit rendering or performance.

Scope: Document and shared stylesheet loading.
