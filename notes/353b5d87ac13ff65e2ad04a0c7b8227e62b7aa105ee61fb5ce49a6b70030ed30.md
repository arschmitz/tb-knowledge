# A single-message thread root keeps its sort-boundary flag after child deletion

The two deletion paths clear Elided and HASCHILDREN for a surviving single-message root but keep ISTHREAD. ReverseThreads uses ISTHREAD to copy whole thread runs, while the inspected IsContainer branch uses HASCHILDREN for threaded row containers. The added visible/hidden deletion tests check root identity and row count across both sort directions. They do not prove SearchDBView behavior or a fresh native result.

Scope: Threaded message views.
