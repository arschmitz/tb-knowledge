# The EWS lint patch clones its credential snapshot before awaiting token lookup

The patch binds an owned Credentials clone before awaiting to_auth_header_value, so the temporary RefCell borrow ends at the preceding statement. Basic clones its username/password strings; OAuth2 retains the same module through RefPtr. This changes borrow lifetime without proving a particular reentrant panic, fresh token or successful retry. It is separate from earlier snapshot refresh after auth failure, and the old credentials module is absent in accepted current code. This is a historical scoped pattern, not a rule to clone every value before await. No auth, borrow or network test ran.

Scope: Historical EWS RefCell credential borrow lifetime.
