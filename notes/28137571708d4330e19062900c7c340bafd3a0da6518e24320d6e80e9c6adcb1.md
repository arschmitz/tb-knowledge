# Keep read-only settings scoped to each preference API

messagePlainTextFlowedOutputEnabled, messageLineLengthLimit and readerDisplayAttachmentsInline are exposed with readOnly:true at the accepted endpoint. composeInlineSpellCheckEnabled uses the same settings wrapper with the default readOnly:false and normalizes values with !!value. The 1859 landing introduced only the first two read-only settings. Do not call the whole messengerSettings namespace read-only now. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
