# Special message-content context menus exclude unrelated message actions

A right-click on a link, image, mailto link, or input must show only actions for that content context. The second patch gates delete, navigation, forwarding, tags, and calendar conversion with onSpecialItem and avoids building tags there. The browser test uses exclusiveMenu to compare the complete visible top-level menu. Current implementation and relocated test retain this contract.

Scope: Mail context menus.
