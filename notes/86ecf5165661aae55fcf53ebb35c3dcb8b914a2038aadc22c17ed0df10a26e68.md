# AutoTreeView checkboxes bind a named row property while their test only checks structure

A checkbox column names a TreeDataRow property. The renderer initializes input.checked from hasProperty and writes the actual checked Boolean through toggleProperty, which adds or removes that property. Accepted code also refreshes row styling data in the change handler. This is independent of the widget's selected row indexes and of a dialog's later persistence action. The owned test adds a visible checkbox column but checks its DOM shape, column order and empty text only; it does not click the checkbox or assert model changes. No interaction or accessibility test ran.

Scope: AutoTreeView checkbox model binding.
