# Check date-only inputs and explicit locale variants in formatter tests

The interval matrix now creates genuine ICAL DATE strings for all-day cases and separate date-times for timed cases. Expected outputs allow named Intl punctuation/hour-clock variants, rather than silently treating one platform form as universal. The helper uses en-US under xpcshell to remove machine-locale dependence. These tests are useful behavior evidence, but were not run and do not cover every locale or option combination. Keep real input types and the accepted variant list visible in a test change. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: calendar/formatter/test-inputs.
