# The tag scanner can accept a longer token after its needle prefix matches

TagsMatchFunction increments n while the needle matches, but a later non-space mismatch only clears matchingStart. At a space or end it tests n == needleLength without that flag. A static trace with haystack foo and needle fo therefore reaches found=true; exclude applies the opposite Boolean. The inspected tests check whole tags and suffix/nonmatches, but not this shorter-prefix case. This is an original and accepted-source limit, not a runtime reproduction or a proposed accepted pattern.

Scope: panorama-sql-tags.
