# Keep the persisted preference namespace stable across an API rename

Current OutgoingServer calls the public value endpoint_url/exchangeUrl while PrefName::EwsUrl still maps to persisted ews_url. PascalCase enum variant names and snake_case wire keys serve different namespaces. Preserve data compatibility when generalizing EWS into shared Graph/EWS code; do not mechanically rename stored keys to follow a new identifier name.

Scope: rust/protocol_shared/src.
