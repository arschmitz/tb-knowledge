# Reset password and connection state when testing a second send attempt

753 covers missing and wrong saved SMTP passwords. It observes the entered password, successful sending and whether the login manager saved the replacement. The historical test forgets the password and closes cached connections between attempts so authenticated connection reuse does not hide the credential change. Current helpers also clear HTTP authentication state for additional protocols and register account, login and server cleanup. This is a test isolation contract, not a live password-dialog result.

Scope: Compose password test isolation.
