# Track the later throughput cost of serial POP3 checks

Bug 1847137 targeted freezes when many POP3 accounts checked in parallel, especially with delivery to one Inbox. Later Bug 1943854 is marked as regressed by it and records users with many accounts waiting minutes for the last serial check. Maintainers noted that parallel delivery to the same file had caused problems and were seeking safer performance improvements. The later report is still open in the checked Bugzilla page. This is an observed tradeoff and open investigation, not proof that the original hang was fully fixed or that the later delay has one cause. Preserve both safety and latency when considering queue changes.

Scope: POP3 connection lifecycle.
