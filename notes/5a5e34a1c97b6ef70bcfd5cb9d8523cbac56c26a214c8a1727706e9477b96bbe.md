# Release aliases and transform callers use different branch maps

At the fixed accepted revision, the release alias passes PROJECT_RELEASE_BRANCHES and params to release_level. That constant contains central, beta, release and ESR 153. The graph release-branches map also contains ESR 140 and enterprise-thunderbird with enterprise-main, enterprise-beta and enterprise-release, and the env_subst transform passes that graph map instead. The local comment explains why aliases duplicate a map, but its mirror description does not mean the two maps are identical. Check the intended project coverage when changing either input. This is a static comm configuration difference; the unpaired helper implementation and actual target-task reachability were not evaluated, so no runtime misclassification is claimed.

Scope: Taskgraph release-alias map comparison.
