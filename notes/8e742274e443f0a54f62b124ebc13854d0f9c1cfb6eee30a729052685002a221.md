# Related MIME root selection normalizes bracketed start values before comparison

MimeThisIsStartPart compares a bracket-normalized start parameter with the similarly normalized child Content-ID using strcmp, while retaining the original allocation pointers for freeing. Its related-child caller consumes that result only when start exists or a root is already loaded. Two converted-stream tests assert that the designated HTML marker appears with the root first and second. They do not establish full output or malformed-ID behavior.
