# Mork diagnostic summaries do not define the landed dump and flag representation

The refactor summary describes a diagnostics wrapper and human-readable flags arrays. The landed source instead serializes the table array, logs warnings separately and emits flags as padded hexadecimal text. getFlagsArray is a separate utility with no invocation in this module. Preserve those differences when reading the historical summary. The dump and trigger analysis already exists in linked knowledge; this adds the exact summary-versus-source correction, without runtime output proof.

Scope: Mork diagnostic output contract.
