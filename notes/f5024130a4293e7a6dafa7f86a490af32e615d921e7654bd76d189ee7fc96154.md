# The adblock sync workaround preserves only dashed default-features

The adblock workaround belongs in regen_toml_files as well as its generated manifest. Its first branch still removes default_features. Only the following dashed default-features branch exempts the exact adblock key. The original generated entry therefore keeps default-features = false and explicit feature names, while the owned lock delta drops addr, psl and psl-types. Preserve this spelling- and crate-specific scope; it is a temporary local exception, not a policy for all crates or proof of successful dependency resolution.

Scope: Thunderbird Rust manifest generation.
