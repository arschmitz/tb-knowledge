# Name browser tests by feature and keep fixture filenames easy to use

The accepted test is browser_imageOverflow.js with task names test_imageOverflow and test_imageUnderflow. Its current fixture is data/image_sizing_test.eml; the original fixture had spaces in Image sizing test.eml. Proposed local convention: keep the browser_ prefix, use a feature name rather than adding another bug-number filename, and use simple lowercase fixture stems with the directory’s separator convention. The component already mixes snake_case and camelCase suffixes, so this evidence does not justify a global suffix rule. Check the registration and fixture path when renaming.

Scope: Browser test and fixture naming.
