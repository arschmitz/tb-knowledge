# Rejected OpenPGP user ID logs include the key and rejection reason

The key-info loop reads the UID string before validity filtering so debug diagnostics can name rejected IDs and their key fingerprint. It records revocation, native invalidity and missing good self-signature reasons, and logs the existing no-description fallback. The signature helper accepts an optional UID string for diagnostics. Earlier retrieval also exposes its API failure before filtering; this is not a claim of unchanged failure behavior or validated key handling.

Scope: OpenPGP RNP key-list diagnostics.
