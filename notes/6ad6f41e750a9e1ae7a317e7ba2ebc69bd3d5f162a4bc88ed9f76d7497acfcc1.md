# AddressBookSync keeps its selection update synchronous without requiring every caller to await it

The owned patch removes async from updateSelectAll, whose body only updates checkbox properties and localization attributes. Its event/setState callers do not await its return. Accepted current code keeps the helper synchronous, with later checkbox-state details separate. Async on a test task is a different harness choice; the review discussion does not establish a global rule requiring every browser test to be async. This local helper correction is not evidence that all localization work completes synchronously or that the first intermittent fix succeeded. No harness or browser test ran.

Scope: Scoped async function contract and browser-test choice.
