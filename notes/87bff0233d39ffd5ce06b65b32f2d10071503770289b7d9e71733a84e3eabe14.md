# Mailnews URLs expose attachment filename query values through GetFileName

nsMsgMailNewsUrl stores a filename query value while setting the spec and returns that value from GetFileName before falling back to its base URL. The historical Exchange fix selected that type only when the query contained filename=. Accepted construction later uses ExchangeUrl for all six Exchange schemes and inherits the mailnews filename behavior. This is source-level filename and type handling; the paired rendering/download result was not executed or inspected here.

Scope: Thunderbird Exchange attachment URL filename contract.
