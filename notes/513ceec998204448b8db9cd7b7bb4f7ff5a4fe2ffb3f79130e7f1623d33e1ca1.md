# The fake IMAP mailbox default UIDNEXT is5000 while explicit state still wins

The mailbox constructor defaults uidnext to 5000 to expose tests that assume a first UID of1. Supplied state is copied before setDefault, whose property-existence check preserves an explicit value. APPEND allocates with uidnext++, addMessage can raise the next value, and SELECT advertises it. This changes the default test-server state; no protocol or test execution was performed.

Scope: IMAP fake-server UID allocation.
