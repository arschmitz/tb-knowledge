# EWS Mailbox routing type preserves server values as a string

The vendor update replaces the Mailbox routing-type SMTP/EX enum with Option<String> because a server also returns SYSTEM. Accepted source keeps this field as a string and explains the observed value in its reason comment. The change removes a closed-value restriction at this mailbox field; it does not establish a protocol-wide rule for enums or prove successful synchronization.

Scope: ews-mailbox-routing-type.
