# EWS serialization must preserve the types namespace below CreateItem

673 is a substantive fix inside a vendor update: it adds the t namespace to Item variants and the outgoing Message fields mime_content, is_delivery_receipt_requested, internet_message_id and bcc_recipients. CreateItem itself uses the messages namespace. Current code moves Message into common.rs but preserves explicit t prefixes on the fields; current sending constructs that Message and a SendOnly CreateItem. Namespace annotations are protocol behavior, not formatter style. The current CreateItem test checked response deserialization, not outgoing serialization or sending. No XML round-trip or EWS send was run.

Scope: EWS outgoing XML namespace.
