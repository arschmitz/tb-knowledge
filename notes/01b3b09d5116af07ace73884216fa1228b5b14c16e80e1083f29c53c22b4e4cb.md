# The digest test checks selected icon source states

The multiple-signatures test negates signed mismatch and encrypted ok source-state checks. Those helpers query src substrings, while separate helpers query the hidden attribute. The messages claim that the icons are not displayed, which is stronger than the checked predicates. Use messages that state the checked source state, or use the hidden-state helpers if invisibility is the intended assertion. The original test checks a digest text marker; later accepted source adds two nested body markers. This is a static assertion-scope finding, not a crypto, rendering or reload-loop result.

Scope: OpenPGP digest test assertion scope.
