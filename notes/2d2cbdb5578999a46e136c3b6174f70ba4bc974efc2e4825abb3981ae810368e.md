# Publish late-startup signals after startup component loading

messenger._delayedStartup sets delayedStartupFinished, resolves its startup promise and sends browser-delayed-startup-finished/extensions-late-startup only in the _loadComponentsAtStartup completion callback. Calendar loading precedes restoration, and the no-mail-account branch restores tabs separately. Preserve that ordering for background extensions. The selected callback has no rejection handler, so successful ordering does not establish recovery if startup loading rejects. These are fixed accepted source and test-code observations.
