# Return drag promise data before the asynchronous save finishes

FlavorDataProvider creates a unique destination file and assigns data.value synchronously, then starts saveToFile in the background. The native transferable callback therefore does not wait for the async method. Preserve this boundary if adding error handling; the shown call does not attach a rejection handler. Recommend a focused failure-path test rather than assuming the callback can be made async safely. No drag operation was executed. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mail attachment drag.
