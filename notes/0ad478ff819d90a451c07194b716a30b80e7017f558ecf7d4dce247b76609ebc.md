# CloudFile management pages receive the selected account ID in their URL

The historical schema documents reading accountId from new URL(location.href).searchParams. Fixed schema text is shorter, but preferences still appends the selected accountKey to the management URL and an existing browser test checks that query. The documentation patch also removes test from an API list; that edit alone does not prove a runtime API access change. No management page or test ran.

Scope: CloudFile account management URL contract.
