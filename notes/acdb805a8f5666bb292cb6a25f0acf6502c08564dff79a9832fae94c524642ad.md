# Account Hub select styling shares its border state with local form controls

Entry 1466 gives the Hub dropdown the form-control background and border tokens, a hover/open accent border and a focus-visible outline. The accepted forms stylesheet uses the local menulist class on HTML select controls, while the historical change targeted XUL menulist. For this form family, recommend keeping hover, open and keyboard-focus states in the shared token model; do not describe the historical element type as the current owner or turn one outline rule into a global instruction to suppress focus. No computed styles, live keyboard focus, contrast, high-contrast or open-menu check was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Account Hub select control states.
