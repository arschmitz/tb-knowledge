# Format invitation panels through the item interval API

InvitationInterval assigns its text from cal.dtz.formatter.formatItemInterval(value). That API obtains the item dates and preserves the formatter’s missing-start/due task messages and all-day display rules. Scoped UI recommendation: pass the item through this whole-interval boundary when changing the invitation display. General whole-range formatting and adjusted range timezones already have separate notes. Static source inspection only; no calendar runtime or locale test ran, and full bug/review discussion remains pending.

Scope: Calendar invitation item interval display.
