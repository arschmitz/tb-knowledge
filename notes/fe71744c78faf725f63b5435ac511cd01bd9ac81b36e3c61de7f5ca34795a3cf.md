# Alarm write warnings keep the exception separate from item and outcome text

The snooze and dismiss catches use logger.warn, identify the item and say the alarm will be ignored, then pass the caught exception as a separate argument. Keep the outcome text and the actual exception distinct in this local diagnostic pattern. The source does not establish which stack details a logger renders.
