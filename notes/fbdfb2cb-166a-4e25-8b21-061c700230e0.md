# Keep Address Book view changes behind SetAbView and CloseAbView

The contacts sidebar and search dialog migration removed the old XUL tree implementation and reused AddrBookDataAdapter through abResultsPane.js. SetAbView reads persisted sort state using a query-free document URL and attaches the new adapter; CloseAbView clears it. Both windows set default columns and react to rowcountchange, select, or viewchange. Existing callers can keep the shared view functions while the widget changes. Current code still uses the adapter path.

Scope: Address Book architecture.
