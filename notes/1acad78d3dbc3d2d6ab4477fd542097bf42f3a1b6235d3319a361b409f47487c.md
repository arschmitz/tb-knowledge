# Keep the Mork debug trigger and its output mode explicit

Entry2179 adds a folder-properties diagnostic click that passes the folder summary path, the inverse of Shift, and the folder URI to MorkParser.dumpFile. A normal click requests readable message-header data; Shift requests the parser data without that formatting. The reviewer accepts this hidden route for rare developer/triager use; a visible clipboard button and saved-search access remain proposals. The fixed source retains the trigger but now groups results by table and chooses native dump or console.info according to the dump preference. The original fixture test checks an array and one message ID, not this UI. No diagnostic UI or parser test ran.

Scope: Mork diagnostic integration.
