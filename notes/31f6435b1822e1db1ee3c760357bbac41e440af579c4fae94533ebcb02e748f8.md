# Virtual-folder source selection is checked through the properties dialog round trip

The added test starts with a virtual folder searching first and second under condition ALL. It changes the picker to second, third and nested fourth, checks the chosen-folder count from 2 to 3, accepts both dialogs, and asserts the resulting URI list while ALL stays unchanged. Historical XUL row-range/space handling is separate from the accepted checkbox-row implementation. The accepted adapter collects folders from checked rows. The picker passes selected URIs to the properties callback; final acceptance writes wrapper.searchFolders and saves virtual folders. These direct state assertions cover more than opening the dialogs, but they do not establish actual search matches, cancel behavior or restart persistence. Keyboard actions are present in test source, not a live accessibility result.

Scope: mail/virtual-folder/tests.
