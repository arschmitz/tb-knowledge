# Attachment URL policy depends on message kind and the action consumer

Fixed policy has since changed: after URL parsing and an explicit allowed-hostname branch for nonlocal file paths, FeedMsg enclosures permit HTTP/HTTPS; other messages use a separate non-HTTP protocol list. Fixed MIME external URL classification is a separate literal http/https/file check and falls back to an internal part marked deleted for disallowed external schemes. The browser fixture explicitly marks feed cases to exercise the enclosure contract. Do not copy the historical protocol list into current code. Unavailable Bug/review context keeps this public source-only work at zero full-audit credit. No runtime or test ran.

Scope: Attachment classification, fetch and UI gates.
