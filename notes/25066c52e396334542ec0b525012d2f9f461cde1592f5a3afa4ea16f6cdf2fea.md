# Materialize forwarded mailbox attachments before replacing their URL

The composition caller sanitizes the name, creates a unique temporary path, wraps nsIMsgAttachment data in AttachmentInfo and awaits saveToFile. It preserves the old mailbox URL in contentLocation before assigning the new file URI. Preserve that distinction between the original message attachment and the materialized file when changing forwarding. Current code does not pass isTmp=true here, so do not assume every temporary path is hidden from the download list. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mail composition attachments.
