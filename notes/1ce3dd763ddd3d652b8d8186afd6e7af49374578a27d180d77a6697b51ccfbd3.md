# The deletion plural test shares the producers string-valued count

The renamed deleting-message pattern selects on number with one/other variants. The native producer constructs number as UTF8String, and the one-message test formats expected status with string1 too. Matching those two formatted results does not independently assert singular wording or the selected plural branch. The FTL Number comment and actual argument types should remain visible; resolver coercion and locale behavior were not tested. No localization or deletion scenario ran.

Scope: Exchange deletion status Fluent arguments.
