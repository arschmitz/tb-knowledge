# Keep notification service filenames distinct from element module filenames

This notification family uses NotificationManager.sys.mjs and NotificationUpdater.sys.mjs for service modules, while the element module and its custom tag use in-app-notification-container. Keep these local filename and registration roles when adding related modules. Existing notes cover the separate CSS and template-ID namespaces. This is a scoped accepted-source naming pattern, not one filename casing rule for Thunderbird. Full Bugzilla and Phabricator timeline and inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/components/inappnotifications.
