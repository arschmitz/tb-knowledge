# Avoid entering a local folder twice during its initial update

A local folder can finish updateFolderAndNotifyOnLoad synchronously and enter its view before DBViewWrapper.open reaches the immediate-display path. Check folderLoading before entering again. IMAP can still load once from cache and again after the server update; this May 2024 fix did not remove that path.

Scope: message list loading.

Paths:

- `mail/modules/DBViewWrapper.sys.mjs`
