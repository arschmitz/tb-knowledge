# Keep the legacy misspelled compaction key separate from the active key

The 2024 threshold used mail.purge_threshhold_mb. Accepted mailnews defaults and GetPurgeThreshold use mail.purge_threshold_mb, while UI migration still probes the old misspelling. Scoped recommendation: preserve exact historical keys in migration code, and use the current active key for new readers and defaults. A spelling cleanup that changes only one side can stop migration from finding the old value. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mailnews/base/src.
