# File-menu initialization resets Calendar Save visibility from the editor tab mode

file_init updates commands, then assigns both Calendar Save menu items hidden unless the current tab mode is calendarEvent or calendarTask. Assignment on every initialization also re-shows them when returning to an editor tab. The File popup and application-menu initializer call this function; actual menu commands and tab-switch label handling remain separate. No menu rendering, save action, shortcut or accessibility result was run.

Scope: Calendar File-menu visibility.
