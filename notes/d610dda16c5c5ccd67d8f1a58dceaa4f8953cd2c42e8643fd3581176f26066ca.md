# The GTK symbolic-icon port keeps the lint rule with a named function exception

The port replaces four titlebar background image expressions with -moz-symbolic-icon and adds that exact function to function-no-unknown.ignoreFunctions. The rule remains true, and its inline note names GTK icons. D252939 explicitly requested the matching lint configuration after the simpler port replaced an earlier toolbar/brighttext approach. This is a scoped platform-function exception, not a general reason to disable the rule. No GTK, theme or lint test ran.

Scope: Linux caption icons and CSS lint configuration.
