# RNP derives permissive import from public versus secret material

In the RNP import boundary, public-key import uses permissive parsing and secret-key import uses strict parsing. The caller no longer controls this through mail.openpgp.allow_permissive_import or a retry confirmation. importToFFI rejects usePublic && useSecret, but its guard does not reject both false. Describe that exact guard rather than claiming it requires exactly one true flag. This is static source and test-code inspection.
