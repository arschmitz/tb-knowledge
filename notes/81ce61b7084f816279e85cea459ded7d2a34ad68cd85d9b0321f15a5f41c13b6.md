# Record the final compaction result at the final summary boundary

The 2024 metric was recorded in OnCompactionComplete before a following database commit could alter status. The accepted staged compactor records compact_result in OnFinalSummary, which receives the final result after lower-level store work. Interpret this metric at that boundary. An earlier successful callback is not proof that the complete compaction succeeded. Existing staged-file and recovery lessons remain separate. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Folder compaction result metrics.
