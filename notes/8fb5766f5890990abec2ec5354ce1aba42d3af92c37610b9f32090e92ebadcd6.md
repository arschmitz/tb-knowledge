# Pass the folder context target into filter commands

The folder context menu exposes Message Filters only for server roots and hides it in multi-selection. Its action passes the right-clicked folder to MsgFilters instead of relying on the open inbox/current folder. Keep context identity explicit across windows.

Scope: mail/base/content.
