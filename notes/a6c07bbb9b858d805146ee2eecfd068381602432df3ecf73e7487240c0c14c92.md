# A failed Exchange message creation completes before the optional header is used

OnCreateFinished now routes failed status to OnCopyCompleted before reading the destination key or marking a sent-file message read. Success requires a non-null header before those actions, and move deletion remains later. The real file/folder callback lambdas discard the inner return, so this local failure fix must not be broadened into a guarantee that every unexpected header or MarkRead error reaches copy-service completion. No message creation, failure injection, queue or move operation was run.

Scope: Sent-file and folder copy completion guard.
