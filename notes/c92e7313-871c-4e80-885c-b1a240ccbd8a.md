# POP message parsing must not treat message bodies as mbox envelopes

nsPop3Sink supplies one message at a time and publishes it on IncorporateComplete. The new-mail parser must treat body lines beginning From as message content instead of restarting envelope/header parsing. Storage separators belong to a different boundary; deleting old envelope detection fixed database subject corruption even when stored mbox data could be repaired. The landed regression fixture and independent database subject check exercise this failure. Current source keeps the parser state guard.
