# Current bulk sync selection changes only enabled checkboxes

The 1375 implementation changes every checkbox, including disabled existing resources, and sets a counter from the total available length. The accepted implementation filters disabled inputs before changing checked and recomputes the count from checked inputs; its toggle button is disabled when every input is disabled. Prefer that later local pattern for bulk actions in this sync form. Counts still include existing checked items, so they do not mean the number of newly registered resources. No all-existing or mixed-existing interaction was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub bulk-selection permissions.
