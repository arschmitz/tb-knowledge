# Optional AutoSync state needs an actual output-pointer write

The folder IDL describes AutoSync state as optional and says nonparticipants return null. The checked base implementation assigns autoSyncStateObj = nullptr, which changes its local pointer variable rather than the caller output. The manager passes a local nsCOMPtr through getter_AddRefs and skips a null result; that selected caller does not establish the default output contract for every caller. The Exchange override separately writes through the output pointer. Preserve this implementation-versus-documentation mismatch and check caller initialization before drawing a failure conclusion. No runtime failure or ABI test was reproduced.

Scope: Base folder AutoSync capability and manager receiver.
