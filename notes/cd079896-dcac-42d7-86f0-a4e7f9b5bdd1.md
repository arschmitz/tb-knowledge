# Native new-mail notifications default on Linux and Windows but macOS has no switch

The 2024 pref change sets mail.biff.use_system_alert true by default on Windows and Linux, and removes a browser-test override. macOS uses native notifications unconditionally, so the pref is deliberately excluded there. D211957 reviewer raised and then withdrew a request to remove the platform guard after recognizing that distinction. Current mailnews.js retains the guard. When changing new-mail notification defaults, check platform-specific behavior and tests; do not infer background mail checking or message activation from this preference alone.

Scope: New-mail notification defaults.
