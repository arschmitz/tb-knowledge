# Use the tooltip interval formatter in the Calendar tooltip assertion

The historical test stopped requiring a comma between date and time because an event crossing midnight used a different separator. The accepted test now builds start and end occurrence dates and compares against cal.dtz.formatter.formatInterval, the formatter used by the tooltip, to account for OS date patterns. This validates that the tooltip selected the expected interval, not the formatter independently; formatter unit tests remain necessary for formatting behavior. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Calendar event tooltip assertions.
