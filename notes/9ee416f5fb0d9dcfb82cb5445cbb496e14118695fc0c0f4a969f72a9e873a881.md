# The original ARM Mac test exceptions differ from the later Marionette selector

The original landing adds fail-if to test_otrlib.js and skip-if to browser_accountCentral.js for the exact macOS 15.30 ARM64 condition. It does not add a test assertion or make the two manifest fields interchangeable. Both exceptions are absent in the fixed accepted manifests. Separately, accepted Marionette defaults assign no run-on-projects to macosx1500-aarch64.* while those platform entries still list marionette-tests. Keep the initial exceptions, later selector and historical failure reports separate; the manifest/taskgraph engines and a native run were not verified.

Scope: macOS ARM test coverage phases.
