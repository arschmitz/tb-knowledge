# Keep custom splitter attributes in kebab case and JavaScript properties in camel case

PaneSplitter exposes resize-with-window and resize-lock-ids as markup attributes, with resizeWithWindow and resizeDirection as JavaScript properties. Boolean resize-with-window is read by attribute presence, rather than a string comparison with "true". Private fields in the newer implementation use # names and explicit types where state is not obvious, including ?Window and ?string. Manual naming proposal for this custom element: retain these attribute/property pairs and document nullable state at its declaration. CSS lock target IDs are existing IDs passed as a comma-separated list; this does not justify converting all Thunderbird DOM IDs or class names to one case.

Scope: style.
