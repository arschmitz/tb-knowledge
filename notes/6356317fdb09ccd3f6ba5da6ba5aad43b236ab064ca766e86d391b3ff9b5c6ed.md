# The task filter keeps its accessible name separate from the shortcut placeholder

The renamed task-filter message supplies a plain aria-label while retaining the placeholder's #1 shortcut marker and both platform key labels. The migration removes #1 and adjacent whitespace only for the accessible-name TextElements and copies the other attributes. The actual startup consumer waits for localization readiness before replacing the placeholder marker with the platform shortcut. This preserves separate name and hint contracts; no locale migration or live accessibility output was executed.

Scope: Task search Fluent binding, migration and startup consumer.
