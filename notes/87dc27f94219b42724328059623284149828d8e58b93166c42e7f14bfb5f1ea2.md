# The form-picker helper awaits browser focus after its non-blank load guard

checkABrowser first waits for a non-about:blank load when its readiness guard requires it, then awaits SimpleTest.promiseFocus(browser) before obtaining document contexts. Both ordinary and WebExtension tests explicitly load that shared head; selected callers await it with their actual browser element. The single added wait changes setup ordering, while the existing date-popup checks and older delay are separate. The reviewer said it had not been tested, and the linked engine patch remains unpaired. No runtime focus or intermittent-cure result is established.

Scope: Shared browser form-picker setup.
