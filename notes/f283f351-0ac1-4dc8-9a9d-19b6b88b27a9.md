# Populate message-list flags and fields with optional EWS values

The landed 2024 helper maps optional EWS IsRead, HasAttachments, sent date, sender, reply-to, recipients, subject, and importance into nsIMsgDBHdr. It checks multiplication when converting seconds to PRTime microseconds and leaves absent optional fields unset. The review called out uncertain attachment hints for encrypted messages; the author treated that as a low-priority UI hint pending body-fetch work. Do not claim EWS attachment flags are accurate for encrypted messages from this patch. The commit added no focused test and none was run in this study.

Scope: EWS message metadata.
