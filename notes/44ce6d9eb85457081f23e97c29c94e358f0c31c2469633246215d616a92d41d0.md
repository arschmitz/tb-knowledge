# Choose CSS sibling selectors from the actual password-control markup

Entry 1511 changes adjacent sibling selectors to general siblings because a label sits between the password input and the reveal button. Proposed rule for this historical form: use a selector that matches the real intervening elements and verify its state target after markup changes. The reveal control is absent in fixed accepted markup, so its old selector is not a current implementation recipe. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Account Hub historical password CSS.
