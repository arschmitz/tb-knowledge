# The tentative acceptance indicator adds one pixel without changing response state

The #maybe checked-state rule moves its sibling .toggle from button-space + 2px to button-space + 3px, matching the local 3px constant in the separate declined-state formula. The accepted stylesheet retains that change. This is a logical inline-position adjustment; no radio value, response event or border-width change is part of the patch. It does not prove rendered hover, RTL or scaling alignment, and it supplies no global spacing rule.

Scope: Calendar acceptance indicator layout.
