# Panorama test branches need a separately enabled manifest variant

The original change places two base folder-name tests and two local/POP3 account tests in shared manifests, then includes those tests from ordinary and Panorama variants. The Panorama variants set mail.panorama.enabled and a panorama tag; declaring a preference-specific branch in a test alone does not select that branch. Original build registration is unconditional. Accepted source later gates the Panorama manifest on MOZ_PANORAMA, which is a separate compile-time selection phase. This is static manifest/source inspection, not a test-run result.

Scope: Panorama xpcshell manifest routing.
