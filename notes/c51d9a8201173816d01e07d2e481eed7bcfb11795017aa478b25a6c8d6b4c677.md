# Check custom-property names at definition and consumption sites

The historical notification CSS uses --background and misspells --contianer-border in its contrast override, while the consumer reads --container-background and --container-border. The current contrast rule uses the correct container tokens. CSS custom-property spelling is an API contract; matching a color value is not enough if the name is wrong. This is a static historical defect and current refinement, not a rendered contrast result.

Scope: Notification CSS custom-property contracts.
