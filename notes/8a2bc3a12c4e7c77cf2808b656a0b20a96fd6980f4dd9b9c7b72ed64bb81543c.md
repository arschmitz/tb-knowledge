# The toolbar migration test waits for compose readiness before reading attributes

The toolbar reader moves its DOM lookups into a callback and the runner changes to execute_async_script. An already-ready compose window resolves immediately; otherwise a once-only compose-editor-ready listener resolves the two collapsed values. A neighboring accepted Marionette script uses the same flag/event pattern. This is a local script/caller contract, not a proved event-producer or native-startup guarantee. The six existing migration cases remain separate, and no test or profile restart ran.

Scope: Marionette toolbar migration test.
