# Compose command registration belongs to the editor window that owns focus

The first JS-controller port attaches its cached controller to the compose chrome window. The follow-up and fixed accepted code instead get the current editor contentWindow, return null when it is absent, and insert the controller into that window. The source comment ties this owner to focus-dependent enabling. Current parameterized methods forward to registered commands, whereas the original port threw not-implemented errors. Keep those phases and command contracts separate. No compose focus or command test ran.

Scope: Compose JS command controller registration and follow-up repair.
