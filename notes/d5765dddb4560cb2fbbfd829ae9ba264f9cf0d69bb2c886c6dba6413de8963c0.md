# External-link dispatch adds a principal only after the existing permission branches

This landing supplies a system principal only when the existing external-link wrapper reaches loadURI with a null or undefined principal. A caller principal or the no-prompt branch's constructed permission-bearing principal survives the final nullish assignment. Protocol prompt decisions and history insertion remain separate. The checked test and mock assert URI/history behavior, not the triggering principal or native permission outcome. No native protocol launch or security-isolation result was executed.

Scope: External link handling.
