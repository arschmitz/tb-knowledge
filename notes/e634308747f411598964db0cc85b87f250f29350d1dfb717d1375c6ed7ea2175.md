# Account, incoming-server and identity keys belong to separate configuration objects

The account guide separates accountX, serverY, idZ and smtpA preference namespaces. Its incoming-server section explicitly says the account and server integer suffixes need not match. The account interface exposes incomingServer and identities as separate references. Resolve those relationships through the actual references and stored keys; the source does not establish a shared-number contract or execute preference migration.

Scope: Mail account configuration foundations.
