# Do not reject every nonattachment drag in the compose envelope handler

1271 removes the else that set dropEffect="none" whenever the dragged type was not an attachment flavor. Current onDragOver still rejects an invalid attachment-bucket self-drop, skips message-body drags and shows the overlay only for valid supported attachments; other input can fall through without that global rejection. The landing message calls this a regression fix, but its failure mechanism and original bug discussion were not independently read or reproduced. A scoped recommendation is to reject only the invalid case the handler owns. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/compose.
