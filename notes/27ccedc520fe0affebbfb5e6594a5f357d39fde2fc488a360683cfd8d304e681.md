# Identify child processes before the shared fork-server and runtime setup

Current nsMailApp consumes process type and child ID arguments and sets SetGeckoProcessType before fork-server handling. The startup sequence then registers crash reporting and dispatches child or parent initialization. Keep that order when porting Gecko startup changes. Current XREChildData uses GeckoServices and differs from the 2024 data fields, so a port must match the actual Gecko interface rather than copying the old child block.

Scope: mail/app/nsMailApp.cpp.
