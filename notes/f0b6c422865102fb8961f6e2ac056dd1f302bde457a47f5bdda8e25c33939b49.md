# Image zoom has a pointer path whose keyboard access still needs a real-control check

The inspected accepted actor toggles image zoom on a left click, and CSS exposes zoom-in and zoom-out cursors. Its event switch has click, resize and visibilitychange but no keyboard zoom branch. For this image interaction, recommend a focused keyboard-access check and an explicit keyboard control if the feature has no usable equivalent. This is a scoped proposed accessibility check, not proof that all application keyboard routes are missing. No trusted keyboard, focus, accessible-name or screen-reader run was performed, and the 1297 discussion is pending.

Scope: Message image zoom accessibility.
