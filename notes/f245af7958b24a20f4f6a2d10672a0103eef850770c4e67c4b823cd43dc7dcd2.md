# Use the shared message header parser for OpenPGP address lists

stripEmail delegates to parseEmails with decoded input, then maps address objects to email and joins with commas. This replaced incomplete regular expressions that failed on quoted display names and bracket/comment combinations. parseEmails uses nsIMsgHeaderParser for encoded or decoded input and returns an empty array when parsing throws; callers must not assume the old bracket error will still throw. A short map/join pipeline expresses these three simple steps clearly. This is a scoped example, not a ban on loops or reduce elsewhere.

Scope: OpenPGP address parser and expression style.
