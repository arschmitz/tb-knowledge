# Graph junk commands use the caller-selected move destination

The Graph bridge ignores is_junk and dispatches a move to legacy_destination_folder_id. The native view-command caller selects Junk for junk and Inbox for unjunk, so the folder ID carries the distinction. DoMarkAsJunk requests legacy resync when returned ID count differs from input count. This is source-level routing and completion behavior; it does not establish spam training, blocked-sender changes, ID uniqueness or live server results.

Scope: Graph junk and unjunk operations.
