# Mailing-list animation-frame focus scheduling does not return focus completion

awSetFocusTo captures its element in requestAnimationFrame but does not await or return that callback. Its async promise therefore does not mean that focus has completed. The new-list path requests name focus separately from optional blank-row insertion. This is a local helper contract, not a verified native-focus outcome or a general timer replacement rule.

Scope: Mailing-list dialog focus helper.
