# Extension MailFolder.name uses the localized display name

FolderManager converts a non-root native folder to an extension MailFolder with name set to folder.localizedName. A root instead gets the literal Root. The converter derives id and path from folderURIToPath separately. A native folder name or special-use flag alone therefore does not determine the extension result name. This explains why the drafts-flagged compose fixture named something is selected as something after the localized-name restriction.

Scope: mail extensions folder conversion.
