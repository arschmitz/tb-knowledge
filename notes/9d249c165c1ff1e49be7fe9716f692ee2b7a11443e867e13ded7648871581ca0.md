# Keep Account Hub cancellation distinct from an empty discovery result

Accepted discovery code rethrows UserCancelledException and UserSkippedError while allowing ordinary guess failures to leave no configuration. The abort handler cancels the controller, stops loading, and lets the discovery generator process a rejected redirect before dropping it. Keep these terminal paths distinct when editing account discovery so cancellation does not trigger another discovery route as if nothing was found. The current controller and generator contract evolved beyond the original callback abortable. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Account Hub discovery cancellation.
