# Commands rebase conflict dialog session-state ownership

`rebase-dialog.js` should retain per-session snapshots and pending operations; capture the original `uiState.rebaseDialogState` across awaits. `commit-actions.js` passes that captured state into `finishRebaseDialog`, `setRebaseDialogError`, and conflict transitions so a late response cannot update a different conflict. Complete conflict metadata, including `rebaseConflict`, must remain in generated snapshots. [Task 1]

Scope: console.
