# FCC save regression tests keep configured input independent of expected output

The follow-up separates config.config from config.expected, so an extra FCC folder remains configured while a save expects one default copy. It directly checks saved return counts, stored-message content and destination paths. Separate send-now and send-later tests still expect two copies and compare return values with onAfterSend folder/message identities. The API annotation dates the save behavior to Thunderbird 142; the current saved-event schema states one saved message when the messages property is included and requires messagesRead for that property. These are exact fixtures, assertion targets and documentation, not new browser/native test results. An expectation change must not silently remove the triggering input.

Scope: Compose save and send regression fixtures.
