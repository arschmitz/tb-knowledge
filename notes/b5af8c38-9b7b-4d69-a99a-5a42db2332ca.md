# Give Today Pane toolbar controls keyboard focus and a visible focus state

Bug 1898199 found the Today Pane mode buttons absent from the tab cycle. The accepted change sets -moz-user-focus: normal on cyclers, close button, and status button, and draws a focus-visible outline for each. Current CSS keeps those rules. When changing toolbar controls in this pane, check that keyboard users can reach each control and see focus. This patch added no automated test; Bug 458074 still requests a separate View menu selector.

Scope: Calendar Today Pane accessibility.
