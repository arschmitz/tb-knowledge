# The CSR save picker uses the top chrome browsing context before key generation

The Generate CSR button calls smimeGenCSR, which initializes the save picker with the top chrome window browsing context. It awaits the picker callback and returns on cancellation or a missing file before proceeding to algorithm and confirmation prompts. Key generation and the awaited UTF-8 write happen later. The owned patch also replaces an OK/Replace allowlist with this cancellation guard; do not assume equivalence for other result codes without inspecting the picker contract. No native dialog, key generation or file write ran.

Scope: S/MIME CSR wizard file picker ownership.
