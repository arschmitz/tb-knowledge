# Check inherited repackaging configuration before copying platform files

Proposal for release-deb-repackage reviews: list the Gecko transform and configuration search paths before adding Thunderbird copies. The indexed Debian kind uses gecko_taskgraph.transforms.repackage and references signed-platform configurations while adding the comm configuration directory. The historical review asked to remove duplicate signed configurations; the indexed comm copies are absent, although those requests still display Not Done. Keep the Thunderbird base configuration and product metadata when they supply actual differences. Verify the resolved search path and caller before removing a file; a matching filename alone is insufficient. This is a scoped review proposal, not proof that a task executed or a rule for every build file.
