# Folder lookup initializes the created component before inserting its weak cache entry

CreateDangling uses the URL scheme to select a folder-factory component, then calls Init(url) and checks that result before caching a weak reference. It transfers the created strong reference to the caller only after initialization. GetOrCreateFolderForURL propagates creation failure when it cannot reuse a live cached folder. The helper replacement removes the explicit nsIFactory object; it does not remove these separate initialization and cache steps. This is static source and caller inspection, with no component-manager, constructor, lifetime or failure-injection execution.

Scope: legacy folder URL lookup.
