# Use presence semantics for XUL boolean attributes

For a XUL menuitem checked attribute in this patch, hasAttribute('checked') reflects its boolean state. Reading getAttribute('checked') as a string made the attachment-bar start-expanded preference persist incorrectly. Other disabled controls in the same patch use boolean properties where supported; check the exact element API.

Scope: mail-ui.
