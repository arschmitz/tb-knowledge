# LDIF and MAB import own returned card and list interfaces with nsCOMPtr

The LDIF and MAB importers hold returned AddCard and AddMailList interfaces in nsCOMPtr and pass getter_AddRefs as the output argument. This gives those local returned references a release scope, including list-member loops. It does not establish that all Mork objects are released. The accompanying browser-test change fixes message spacing and adds no reference-lifetime assertion.

Scope: address-book/import-ownership.
