# UI migration 57 rewrites six persisted checked values

For an existing profile below UI version 57, the migration rewrites existing checked values at six explicit URL/id pairs. The exact string false becomes -moz-missing plus a newline; other present values become empty string. hasValue prevents creation of missing entries. This preserves document/id identity and makes the conversion narrower than all checked state. The comm code proves these writes and startup/version guards; native restoration semantics and runtime persistence were not verified.

Scope: UI persistence migration.
