# MIME header allocations must be released when no cache array accepts them

AddHeaderField allocates a zeroed header structure before checking the selected outer or embedded header array. The landed alternate branch releases that structure when it cannot be appended. When append succeeds, CleanupHeaderArray later frees the stored name, value and structure. The return remains NS_OK, and strdup failures are not newly handled. This is the exact allocation-to-owner boundary, not a reproduced leak or a complete out-of-memory guarantee.

Scope: MIME emitter header ownership.
