# Keep shared tree CSS generic and mail state CSS in thread styles

The landed patch moved common card backgrounds, border, focus, selection, hover, high contrast, and reduced motion behavior into tree-listbox.css. Review then asked to keep mail-specific junk and tag behavior in threadCard.css or threadPane.css. The final patch and current code retain the split. Shared tree CSS should cover behavior both message and address book rows need; message-only properties belong in the thread styles. Check focus and selected states in high contrast mode on both surfaces when changing common selectors.
