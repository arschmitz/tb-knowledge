# The hdrParser removal leaves the internal IMAP header-parsing path in place

This landing removes nsIMsgImapMailFolder.hdrParser and the getter that returned an addref of m_msgParser. At the fixed accepted revision, ParseMsgHdrs still sets up that member, parses header lines and finishes the header stream. The scoped accessor removal does not implement the wider parser replacement described by its author. A bounded mail/mailnews search finds no remaining accessor name; external callers, generated bindings and runtime compatibility were not verified.

Scope: IMAP header parser interface.
