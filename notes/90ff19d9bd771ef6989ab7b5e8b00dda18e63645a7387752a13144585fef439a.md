# Separate per-folder metadata, raw bodies and protocol-specific sinks

The storage documentation describes per-folder .msf metadata, raw local mbox/maildir content and protocol-specific server sinks. The inspected Panorama SQLite work is a separate global-database direction, not proof that the documented default storage has already switched. When explaining a folder operation, name which layer owns the data and whether only headers or full bodies are present. There is no universal sink abstraction established by this document. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Folder storage architecture.
