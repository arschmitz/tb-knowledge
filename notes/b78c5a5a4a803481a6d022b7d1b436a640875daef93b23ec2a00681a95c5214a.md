# The URI size hooks return zero as placeholders rather than measuring allocation

The historical nsLDAPURL, nsMsgMailNewsUrl and nsMailtoUrl SizeOfIncludingThis methods return zero without using the supplied allocator-size callback. Zero is a stub accounting result, not proof that the URI object or buffers use no memory. Accepted LDAP and mailnews code retain the stub through a later separate nsIURIWithSizeOf interface; the historical nsMailtoUrl source is later removed. No memory-reporting test, caller accounting result or build was verified.

Scope: mailnews/uri-size-accounting-stubs.
