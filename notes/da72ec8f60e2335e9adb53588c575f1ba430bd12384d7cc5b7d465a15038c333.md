# Addressless Gloda identities use the parsed name instead of one shared empty key

Gloda uses a lowercase address as an identity key when present, otherwise the parsed name. This stops every correspondent without an address from sharing one empty-string contact and the first displayed name. The changed tests query two addressless identities and their common message. Equal names or other malformed inputs are not proved unique, and name fallback is not an email-normalization rule. No indexing run occurred.

Scope: Gloda addressless identities.
