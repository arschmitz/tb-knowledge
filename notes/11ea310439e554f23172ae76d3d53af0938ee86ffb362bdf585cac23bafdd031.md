# Sort partial messages using the same size role shown in the view

In byte mode, current FetchSize prefers onlineSize for Partial messages and falls back to messageSize when zero. GetLongField now similarly uses onlineSize for Partial messages, falling back on query failure or zero; the line-count branch remains separate. Preserve this display/sort agreement. onlineSize, messageSize and offlineMessageSize are different roles; the existing offline-size lessons should not be used to replace this sort key. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Message size display and sorting.
