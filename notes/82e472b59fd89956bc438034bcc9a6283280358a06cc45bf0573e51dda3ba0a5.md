# Panorama thread sorting mutates message metadata while returning preorder

sortThread links messages to present parents, treats missing parents as roots and sorts each sibling set by ascending date before preorder traversal. It writes level on the original objects and removes temporary childMessages after visiting them. The direct tests check returned IDs and message levels for rooted fixtures. They do not prove cycle handling, arbitrary preexisting child metadata or immutability.

Scope: Panorama threaded message ordering.
