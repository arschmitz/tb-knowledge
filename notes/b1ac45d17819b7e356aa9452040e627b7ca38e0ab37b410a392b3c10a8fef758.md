# Borrowed XML serialization must forward the underlying element override

The SOAP envelope calls serialize_as_element on its operation body. The new XmlSerialize implementation for &T forwards that method as well as child serialization; forwarding only children would use the default element wrapper and lose metadata supplied by a derived element implementation, such as default_ns. The Operation and sealed envelope-name borrow implementations also forward response/name contracts. This is shared imported behavior evidence, not a Thunderbird formatting rule, and no serializer test was run.

Scope: EWS and XML shared serialization.
