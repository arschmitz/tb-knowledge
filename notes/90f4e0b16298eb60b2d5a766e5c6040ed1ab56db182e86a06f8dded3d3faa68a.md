# Folder creation validates destination support

At revision d15c88407bf2ebb1363d33567fefa9ca43643178, WebExtension folders.create rejects unified mailbox folders, virtual search folders, and folders whose canCreateSubfolders is false, with a distinct error for each condition. Resolving a destination ID therefore does not establish that it supports child creation. Preserve these distinctions when reviewing this API's validation or error handling. This is scoped static source evidence, not a rule for every native folder operation; no execution result is supplied.

Scope: WebExtension folder API.
