# Check the concrete store stream before replacing SyncCopyStream

In D229190 WriteFrom was proposed and briefly used, then reverted after review pointed out the message-store output implementation lacked it. The actual landing retains SyncCopyStream. A method on the interface and cleaner-looking syntax do not establish support by the returned object. This is the historical file-to-EWS store boundary; no general claim about every output stream or current performance is made, and no stream test ran.

Scope: EWS file copy stream capability.
