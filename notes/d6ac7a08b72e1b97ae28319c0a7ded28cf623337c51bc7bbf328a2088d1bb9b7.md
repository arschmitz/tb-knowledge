# Panorama's temporary normalization bypass also removes specific Unicode checks

The temporary landing returns input bytes from DatabaseUtils::Normalize and comments out selected decomposed Unicode lookups, duplicate-name checks and message-value expectations. It does not establish a new normalization contract or pass those disabled cases. Fixed accepted code later normalizes through nfc_normalize with error propagation, and the inspected decomposed lookup/sender cases are active again. Keep the temporary bypass and later restoration separate; no Unicode/storage test was run.

Scope: Panorama normalization and test phases.
