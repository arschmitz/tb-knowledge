# CardDAV existing-book marking returns a new array while preserving found-book objects

The shared module builds a lazy set of configured carddav.url values and invalidates that set on directory-created/deleted notifications. markExistingAddressBooks maps to a new array but retains each found-book object, setting existing true when its URL is in the set. It does not clear an already true flag on a nonmatching object. The written test directly checks new-array and same-object identity, names, URLs and existing flags. Its create check only asserts a function type; no creation callback or observer invalidation path was executed. URL preference edits and deletion of already marked results remain separate freshness cases.

Scope: Account Hub CardDAV existing-address-book cache.
