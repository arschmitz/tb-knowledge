# EWS draft completion leaves OnStopCopy to the tracked copy request owner

The historical EWS handler called the copy listener directly and then called NotifyCompletion, whose tracked-request clearing path also calls OnStopCopy. The patch removes the direct call and documents that owner. Current Exchange handler retains NotifyCompletion; copy service only clears matching processed/failed original requests and excludes newly reentrant requests. The added draft task awaits a stop-state promise and asserts empty-to-one folder count. Its promise ignores status, and it does not test callback count, the rendered Save button, repeated replacement or full saved content. No save or test ran.

Scope: Exchange draft-save copy completion ownership.
