# Use visible row lookup rather than assuming the backing map index

The original TreeDataAdapter change routed access through .at so a lazy row map could supply entries. Accepted code routes cells through rowAt and a flattened visible-row cache, while the backing map contains top-level rows. Use that lookup boundary for new cell access. A displayed index is not automatically a top-level map index when rows have open children. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Tree adapter index boundary.
