# Task date-checkbox updates must address the custom picker element rather than its ID string

The owned change resolves the date-picker ID once before assigning value and disabled state. The receiver is a custom datetimepicker with child attribute mapping and a value getter/setter, so its self-assignment is not a plain field operation; the retained FIXME does not establish that the write is necessary. Accepted source later switches to toggleAttribute and reapplies all-day timepicker disabling. Entry/due closures update distinct date state. No live widget result is claimed.

Scope: Calendar task date control state.
