# Protocol-selection entry clears only IMAP and POP3 hostnames on a copied config

#initManualConfig copies the current config and clears its incoming/outgoing hostnames only when clearHostnames is true for IMAP or POP3. Protocol selection opts in; config-found entry only supplies its previous step and leaves that option false. The added helper directly checks both hostname controls for IMAP and POP3. The owned change does not clear usernames or directly test preserved controller state.

Scope: Account Hub manual-config entry state.
