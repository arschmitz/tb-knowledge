# Sort explicit folder ordinals before natural order

The initial comparator sorted non-null ordinals first and used raw names for the rest. Current FolderComparator retains ordinal priority, then orders non-ordinal folders by special flags and AppCollator::CompareBase. GetFolderChildren sorts each returned child list. The current code explicitly notes numeric comparison is still missing. Do not describe the raw 2024 alphabetical comparison as the present policy or claim numeric natural sorting is implemented. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Panorama folder display ordering.
