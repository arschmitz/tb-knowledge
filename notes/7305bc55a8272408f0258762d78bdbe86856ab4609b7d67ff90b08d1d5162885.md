# The Linux tiling port changes two selector guards and preserves their different scopes

This landing replaces the old gtktiledwindow exclusion with tiled in two Linux decoration selectors. The messenger branch still requires normal size, GTK transparency and a custom titlebar, while the visible spaces toolbar has its own GTK/custom-titlebar guard and bottom-corner preference. Both styles are mapped through the Linux theme manifest and loaded by the main messenger document. The port title does not prove native attribute production, computed rendering or cross-platform behavior, and no native test ran.

Scope: Linux window and spaces-toolbar decoration CSS.
