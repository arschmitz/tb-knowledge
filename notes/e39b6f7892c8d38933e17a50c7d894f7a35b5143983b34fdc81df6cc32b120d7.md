# Name MIME closure conversions and predicates for their result

The accepted wrapper uses AsMimeDraftData for a nullable pointer conversion and IsMimeDraftData for a tag predicate; closure enum values use isMime... and default to isUndefined. Follow those names when extending this wrapper so a call reveals whether it returns a pointer or checks a tag. The class and its files retain their local MimeClosure/mime_closure naming. These examples do not justify renaming unrelated C++ families.

Scope: MIME closure API and file naming.
