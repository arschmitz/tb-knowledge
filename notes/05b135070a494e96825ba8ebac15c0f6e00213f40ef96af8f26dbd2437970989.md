# The shift-click target window is not forwarded into its index normalizer

The overload chooses a target win for the row and mouse event, then calls _normalize_view_index(aViewIndex, win). That actual normalizer accepts only aViewIndex and reads get_db_view() with its default mc. Negative indices and message sets can therefore be resolved from a different view than the requested target when those contexts differ. The ignored extra argument predates this overload; the inspected current code retains it, and no explicit-window regression test or multiwindow execution was added.

Scope: FolderDisplayHelpers overloaded shift-click and actual default-view receiver.
