# Accept LF and CRLF state files independently of the writer platform

The POP3 state reader now splits with /\r?\n/ and skips empty lines. The writer still uses a platform-specific separator. This permits LF, CRLF and mixed files without redefining native write output; it does not split a bare CR-only file. Keep reader compatibility and writer formatting separate when changing persisted text. No state-file runtime or new line-ending test was run. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: POP3 state line ending contract.
