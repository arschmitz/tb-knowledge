# Calendar summary Fluent patterns keep XUL attributes separate from HTML text

The summary widget maps XUL section labels to .value, reminder menuitems to .label and HTML table/status nodes to message text. Its date labels use explicit task/event Fluent IDs. The connected callback inserts the widget resource, and the summary dialog waits for item details and root translation. The recipe preserves those target roles while copying DTD strings. This exact receiver mapping is scoped to this widget; required discussion has a deleted-comment gap and no migration, layout or accessibility run was performed.

Scope: Calendar item summary widget localization.
