# Declare UTF-8 at the thread-subject interface boundary

947 changes the historical nsIMsgThread.subject IDL type from ACString to AUTF8String while retaining the C++ nsACString setter/getter and byte storage. The interface declaration supplies an encoding contract for crossing the XPCOM boundary; it is not a database schema change or proof that every stored subject is decoded human text. The accepted interface and implementation no longer expose these methods. Keep this as a historical encoding lesson and verify the current API before copying it. No Unicode boundary test was added or run here.

Scope: Historical thread-subject string encoding.
