# Keep FolderDisplayHelpers inside its legacy browser-test harness

The patch removes FolderDisplayHelpers imports from Calendar, extension and preferences browser tests. Its new stack guard rejects detectable browser_ callers outside comm/mail/test/browser/ because importing the historical module acquires a window and initializes MessageInjection/inbox state. The replacements use test-owned accounts and each harness own helpers; createSubfolder arms and awaits the folder-added notification. The fixed guard remains, but current import-time state differs from the original. This does not prove every external importer is detected, and the historical late cleanup registration does not change deliberate cleanup guidance. Static inspection only.

Scope: Browser-test harness ownership.
