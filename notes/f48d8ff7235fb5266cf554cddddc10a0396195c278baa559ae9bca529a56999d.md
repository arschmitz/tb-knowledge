# The Linux ASan fuzzing target has distinct build, package and task identifiers

The fuzzing task selects nightly-fuzzing-asan, declares the linux64-fuzzing-asan-opt index name and uses the Bof Treeherder symbol. Its mozconfig sets package suffix asan to avoid normal-nightly naming conflicts and enables fuzzing with sanitizer configuration. Project/backstop metadata and packaging flags are separate controls. This source configures a target; it does not prove a build, fuzz run or Fuzzfetch integration.

Scope: Thunderbird Linux fuzzing build configuration.
