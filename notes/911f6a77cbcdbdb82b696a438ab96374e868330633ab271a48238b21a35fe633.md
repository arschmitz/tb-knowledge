# EWS operation names come from typed request and response constants

The EWS Operation trait supplies NAME as a static string constant. The macro generates the request constant from the request type name and the response envelope constant from the response type name. SOAP serialization uses the body type name; deserialization rejects a body element that differs from the expected response type name. Thunderbird uses the request operation constant for operation handling instead of repeating protocol-name strings. This patch changes how the names are supplied, not success/warning/error policy. The adapted generic-envelope test asserts text deserialization; it does not newly cover every operation name or live server. Later queued-client and borrow implementations are separate accepted context. No fresh build, cargo test or EWS run.

Scope: ews-rust-protocol.
