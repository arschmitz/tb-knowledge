# Mork map allocation checks report through the environment before bulk operations

The unsigned slot-size helper rejects multiplication overflow, new_assocs rejects zero size, and grow rejects doubling overflow before new_arrays and copying. new_arrays frees partial allocations and sets an environment error when required arrays are missing. In the inspected error receiver, OutOfMemoryError calls NewError, which records NS_ERROR_FAILURE; the diagnostic name is not proof of a distinct result code. No build, fault injection, benchmark or crash-cure test ran.

Scope: Mork map slot allocation and error propagation.
