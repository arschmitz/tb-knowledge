# A discard guard does not check an ignored message-write result

The inspected legacy AddMessageBatch calls SyncWriteAll without assigning its nsresult, then assigns rv from parser operations. SyncWriteAll itself returns a destination Write failure. The nearby Panorama path explicitly checks the write result and discards on failure. A scope guard only runs when control leaves its scope; it does not make an ignored error cause that exit. A scoped proposed test should inject a write failure and inspect parser publication, returned headers and stored bytes. No failure or runtime corruption was reproduced, and no global error-handling exemption is inferred.

Scope: Local message batch failure boundary.
