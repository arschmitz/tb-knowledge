# MSIX package publisher must match the current signing certificate in both repackage kinds

The 2024 MSIX patch changed publisher DN city from Mountain View to San Francisco in both regular and localized shippable repackage kinds to match a new signing certificate. An earlier landing was backed out after build bustage when the upstream change was backed out, then relanded. Current configuration still uses San Francisco. When signing certificates or upstream packaging rules change, update both task kinds together and verify the actual certificate DN; do not treat this historical DN as a permanent value.

Scope: Taskcluster MSIX packaging.
