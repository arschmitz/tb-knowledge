# Separate an app-store identifier from its encoded referral payload

The QR export link changed from the Android beta package to net.thunderbird.android and puts attribution inside a percent-encoded referrer query parameter. The XHTML source additionally escapes the outer ampersand. Keep the package ID, outer query escaping and inner referral encoding distinct when editing this exact link. This is the accepted source target; no live Play Store navigation or analytics result was checked. Existing QR control naming lessons are reused rather than repeated. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: QR export app link.
