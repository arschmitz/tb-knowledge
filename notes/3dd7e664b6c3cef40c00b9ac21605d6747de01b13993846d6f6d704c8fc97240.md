# Distinguish an empty commands manifest from no commands declaration

commands.openShortcutSettings is available when the manifest declares commands:{}, but the no-commands task asserts the method is absent. The commands API registration is gated by the manifest key, not by a nonzero command count. Preserve this edge case when changing schema/manifest wiring. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
