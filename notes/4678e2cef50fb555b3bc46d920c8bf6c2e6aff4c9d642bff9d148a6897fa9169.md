# Mail security call sites consume the explicit NSS initialization result

The S/MIME Init methods return NS_OK only when EnsureNSSInitializedChromeOrContent reports true, otherwise NS_ERROR_NOT_AVAILABLE. The selected IMAP authentication modes reject the same false result before protocol initialization. This is the comm caller/error contract. Paired Gecko helper internals and the reported debug/compiler cause remain unproved; no security or build runtime ran.

Scope: S/MIME and IMAP initialization.
