# Name notification browser tests and fixture pages after their component family

The current test is browser_inAppNotificationCloseButton.js and its fixture is files/inAppNotificationCloseButton.xhtml. The test waits for that exact fixture URL before using the content window and checks the close event in test_closeButtonEvent. Follow these local filename forms when adding adjacent component tests. Task names elsewhere in Thunderbird vary, so this evidence does not establish a global camelCase or snake_case task rule.
