# Mailing-list expansion is opt-in and recognizes the equal-name mailbox form

parseMailboxString preserves legacy Boolean preserveGroups input and defaults mailing-list expansion to false. When expansion is enabled, the backend requires addressBooks permission and only looks up an entry when its name equals its email. A found list returns member mailboxes or one named group; a missing list stays unchanged. The accepted source therefore does not expand the unequal ListName <ListDescription> form through this path. The compose schema documents ListName <ListName>. This is a static local contract, not a runtime result or a claim about recursive lists or every schema permission path.

Scope: Messenger utilities recipient parsing.
