# Keep the account test cleanup helper name tied to its actual shared state

The shared account helper is named subtest_clear_status_bar and the Account Hub caller uses that exact identifier. Its assertions cover status feedback timers, progress, active processes and request counts. For helpers in this existing family, use a descriptive subtest_ name that states the state being checked or reset, and place shared helpers in the account head file. This is a local naming pattern; it does not establish a project-wide rule for all test functions. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Account browser helper naming.
