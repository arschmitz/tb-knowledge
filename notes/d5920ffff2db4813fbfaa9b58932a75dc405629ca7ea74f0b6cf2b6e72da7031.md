# The iframe font-registration guard differs from the outer tab guard

1960 gated inner font registration with the global hasLoaded flag inside the existing iframe load listener. Accepted code still listens for iframe load but records __UIFontRegistered on that iframe window, while hasLoaded guards the outer window/tree. Keep these two object lifetimes separate. The current comment reports asynchronous sub-page loads can overlap; this is a bounded current refinement, not full study of the later migration or proof that every listener is registered once. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: account settings window lifetimes.
