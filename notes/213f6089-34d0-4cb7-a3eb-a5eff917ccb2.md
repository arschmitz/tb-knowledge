# Resolve relative Exchange message URLs against their base

Exchange message URI creation must resolve anchor and relative references against a supplied base URI before setting the spec. Treating a relative reference as a full URI could crash GetScheme. The test covers EWS and Graph message schemes.

Scope: exchange.
