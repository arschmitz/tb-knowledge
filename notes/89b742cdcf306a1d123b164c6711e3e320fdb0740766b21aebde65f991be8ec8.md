# The offline search loop rechecks its iterator before each next-message read

Search now requires both !*aDone and m_listContext before another GetNext call. CleanUpScope can clear that member, and successful matches are delivered through the search session to OnSearchHit listeners. The new condition avoids another read when the iterator is absent; it does not itself mark the search done or establish thread safety. The exact reported clearing/crash path was not reproduced, and the accepted entry's strong self reference is separate context.

Scope: Offline mail search iterator lifetime guard.
