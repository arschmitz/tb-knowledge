# Check feed-toggle callers before replacing obsolete selection helpers

The feed cleanup removes GetNumSelectedMessages from setContent and keeps the toggle plus window.gDBView guard before ReloadMessage. Its inspected open-message caller already requires one selected feed and separately checks window type and open preference before requesting the toggle. The message-header caller uses the webpage branch instead. Read those actual callers before adding or replacing a selection-count helper; the shared callee’s name alone does not establish a selection contract or prove a search-window route is reachable. This patch adds no regression test, and no toggle or search-window run was performed.

Scope: Feed content toggle and search caller.
