# Search-result table cache identity includes the virtual-folder URI and database owner

Entry 1370 adds a URI-keyed table map to each nsMsgDatabase. The accepted HdrIsInCache uses aSearchFolderUri to retrieve that table, and the virtual-folder view passes m_viewFolder URI while obtaining the database from the physical hit folder. The effective identity is therefore physical database plus virtual-search folder, not message key alone. Preserve both dimensions in this cache family; this is a scoped implementation contract. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Message database search-table identity.
