# The imported process-status repair makes supplementary group IDs unsigned

The imported Status.groups field changes from Vec<i32> to Vec<u32>, while the inspected parser still fills it from the Groups text through parse_list. Adjacent real/effective/saved/filesystem GIDs are also unsigned. This is the checked dependency type change, not a measured compiler fix, kernel-range validation or proof of crash collection. Generated checksum metadata separately adds the empty cargo-ok file. No build or parser test was run.

Scope: Shared Rust procfs status type.
