# Free the copied Content-Type value independently of MIME headers

MimeHeaders_get allocates the returned header value. In multipart/alternative flushing, ct is used to choose which cached children can display and is then freed after each child, including children created with output disabled. Freeing the header container and part buffer does not release this copied value. Preserve allocation, last use and matching cleanup together when changing this loop. The full state chart and allocation branch were inspected; the reported Coverity leak was not reproduced.

Scope: mailnews/mime/alternative-ownership.
