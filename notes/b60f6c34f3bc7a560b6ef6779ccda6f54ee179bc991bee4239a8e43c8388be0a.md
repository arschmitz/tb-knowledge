# Preserve an early non-text MIME body candidate when promoting a later text body

The original fix handles a multipart/mixed message whose first part is a PDF and whose later part supplies the body. Before selecting a later text or multipart/alternative candidate, it moves the earlier unusable messageBody into attachments, clears the body pointer and refreshes attachment count. The browser test directly checks visible body text, one attachment and its filename; it does not certify PDF bytes or all forwarding formats. Accepted native code later adds disposition and appended-text handling, while the original test/fixture remain unchanged. No MIME or compose runtime test was run.

Scope: MIME draft decomposition and forwarding.
