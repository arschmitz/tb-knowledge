# Record the initial tray capability limit before inferring notification behavior

The 2024 tray landing provides a Quit action and a service handle, but UpdateUnreadCount is a no-op. Current JS still excludes Linux from the unread-count listener because there is no Linux count indicator. Current Rust additionally reads show_tray_icon_always and shuts the service down on exit; those later refinements do not turn the original feature into hide-to-tray or unread-badge support. Verify product capability through handlers, not the presence of a crate or menu icon.

Scope: Linux tray behavior and lifecycle.
