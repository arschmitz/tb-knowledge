# Describe the actual source of an automatically found account configuration

The current configuration-success description selects strings for Exchange, guessing, disk XML, provider XML or Mozilla ISPDB based on source and subSource. The generic historical ISPDB message is not valid for every source. In this notification family, keep visible success text consistent with the configuration metadata, and preserve an unknown-source fallback policy explicitly if adding a source. The inspected map can leave the ID undefined for an unmapped source; no universal fallback is inferred. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub source-aware notification wording.
