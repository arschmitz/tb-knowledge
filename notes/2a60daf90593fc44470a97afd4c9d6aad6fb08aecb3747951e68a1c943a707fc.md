# The row-local tree inverse lookup omits a skipped descendant offset

TreeDataRow.rowAt counts an open child's descendants before a later sibling, but indexOf uses rowIndex + childRow.rowCount without assigning the result after a failed child search. A static A(open with G), B trace therefore gives rowAt(2)=B and indexOf(B)=1. The added single-child test misses that shape. The same line remains in accepted source, while current TreeDataAdapter.indexOf uses its flat cache and avoids this row-local recursion. This is a bounded source mismatch; no production failure or runtime test is claimed.

Scope: TreeDataRow nested index contract.
