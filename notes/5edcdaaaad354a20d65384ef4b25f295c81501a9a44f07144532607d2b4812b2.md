# The shared icon helper separates custom theme teardown from the next startup

The shared helper awaits the dark custom theme unload and its window update before starting the light custom theme. The separate unified-toolbar test still puts dark unload, one event wait and light startup in a single Promise.all, so it has a different ordering contract. The helper has explicit success-path unloads and no added failure-cleanup hook. Harness failure cleanup remains unverified here. This source comparison does not prove a race or a passing test.

Scope: Extension theme test completion.
