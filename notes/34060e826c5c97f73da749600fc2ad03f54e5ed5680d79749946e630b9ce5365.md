# Keep normal folder opening distinct from temporary file opening

OpenFolderDB repairs a cached database with no m_folder and calls FinishDBOpen for newly opened folder databases. FinishDBOpen hooks pending listeners and synchronizes counts. OpenDBFromFile returns a cached object directly and does not call that hook; its historical/current comment explicitly leaves the listener intent uncertain. Temporary compaction or backup work must not be described as having normal UI listener side effects. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mailnews/db/msgdb.
