# Let panel CSS constrain the app menu height

The May 2024 PanelMultiView port removed JavaScript screen geometry and the popuppositioned handler, then constrained the panel container with flex and max-height CSS. Reviewers tested the low-resolution menu with a scrollbar on Windows, macOS, X11, and Wayland. When changing shared popup sizing, check those host and display conditions rather than relying on a single desktop screenshot.

Scope: app menu layout.
