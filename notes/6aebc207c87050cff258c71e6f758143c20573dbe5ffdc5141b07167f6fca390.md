# Attachment count localization leaves the filename colon in separate markup

The old single-attachment count included a localized colon. The new count message has no colon, and attachmentNameSep supplies a literal colon and space in markup. Source hides both that span and the filename unless exactly one attachment exists, while retaining the sanitized filename and its single-item context menu. This describes the inspected English/source phase and is not a recommendation to move translated punctuation into markup. No layout, locale or accessibility run occurred.

Scope: Message attachment header localization.
