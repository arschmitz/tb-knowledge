# Unexpected MIME data errors must not assume every request is a channel

CallbackStreamListener.onDataAvailable remains an intentional error because the converter should consume message data. It reads URI.spec only when the request implements nsIChannel; otherwise it formats the request itself. This preserves the intended diagnostic instead of masking it with an undefined URI property error. Normal stop/finalization methods keep separate channel contracts, and this does not prove a channel with a missing URI is handled. No stream or indexing test ran.

Scope: Gloda MIME callback diagnostic.
