# Folder picker labels, tooltips and stored URIs follow separate contracts

The original change adds a full prettyPath/account tooltip and opts the filter target into path labels. The fixed picker now formats labels through Fluent and resets the tooltip before setting it; its stored value remains the folder URI. The fixed filter target uses verbose labels again while keeping the full-path tooltip. Move/Copy Again still builds an en-dash tooltip directly. Keep these separate states and do not use the original separator or path-label choice as a global UI convention.

Scope: Folder picker and filter target display.
