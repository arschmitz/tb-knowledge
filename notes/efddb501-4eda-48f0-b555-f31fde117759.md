# Initialize the EWS endpoint once and return specific XPCOM errors

D210200 reviewer replaced a mutable EWS URL field with OnceCell<Url> and an initialize method, because the endpoint should not change after setup. The landed 2024 code returned NS_ERROR_NOT_INITIALIZED when ServerURI was requested early and NS_ERROR_ALREADY_INITIALIZED on a second initialization. This review also kept the public nsIEwsServer interface limited to the needed initialize operation. These are accepted design choices for that historical EWS outgoing server; current Rust code has since evolved.
