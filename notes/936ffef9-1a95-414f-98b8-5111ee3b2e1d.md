# Report smart-folder capabilities through the same guards used by mutations

The native smart-account folder can report deletable or renameable even though add-ons must not destroy unified or tag folders. FolderManager.canBeDeleted and canBeRenamed force false for the smart server. The folder API uses these helpers both for capability reporting/query filters and for rename, delete, and move guards; create rejects a virtual tag destination. Tests check those failures. Copying a virtual tag folder is still allowed but produces an empty nonvirtual folder, so copy is not a way to duplicate the search definition.

Scope: WebExtension folder API.
