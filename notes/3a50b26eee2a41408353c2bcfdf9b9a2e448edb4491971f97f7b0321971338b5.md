# AutoSync group size is a suggested byte target, not a message cap

The default target is2000*1024 bytes. GetNextGroupOfMessages admits a first message at least as large as the target into an otherwise empty group, then stops. Later messages are limited by the summed target, and zero-size messages are skipped. Do not read the approximate2MB comment as an exact2MiB cap or a maximum message size. Removing the unused public setter does not remove private grouping. No performance test ran.

Scope: AutoSync grouping target and oversized first-message branch.
