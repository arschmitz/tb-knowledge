# Menubar value migration is gated by the old profile UI version

The version 54 repair converts only exact stored autohide="false" to "-moz-missing\n" when currentUIVersion<54. The earlier pre47 default migration can supply that false value; new profiles skip old migrations. A test fixture already at 54 bypasses this branch even if it expects the converted value. The original false_no_update case did that; selected current source uses52 in a separate second-update case. Check both starting version and stored representation, then assert DOM state and persisted value separately. No migration test ran; shared existing assertions lack messages.

Scope: Profile menubar persistence migration.
