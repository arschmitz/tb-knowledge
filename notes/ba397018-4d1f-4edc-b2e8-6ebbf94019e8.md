# Normalize both sides of an OpenPGP email-address lookup

Bug 1896876 found that EnigmailKeyObj.getUserIdWithEmail lowercased each key user ID but compared it to the configured email address without normalizing the argument. An uppercase character in the configured address prevented the key lookup and suppressed the outgoing Autocrypt header. The landed fix lowercases the argument before comparing, and current code retains it. For case-insensitive address matching, normalize both sides at one boundary. This is a scoped OpenPGP lookup rule; it does not establish a rule that stored display addresses should lose their original case. No test was added in this commit or run here.

Scope: OpenPGP Autocrypt address lookup.
