# Calendar attachment wiring reads the URI before choosing its icon

The parent converts event attachments to URI/icon stubs and clears the list on reset. It dereferences attachment.uri.spec before calling getAttachmentIcon, so the utility’s empty-URI return does not guard this caller read. The new test supplies a URI and checks exact child metadata, not rendering or absent/binary input. Accepted later reset/re-show assertions remain a separate test phase.

Scope: Calendar attachment event-to-list contract.
