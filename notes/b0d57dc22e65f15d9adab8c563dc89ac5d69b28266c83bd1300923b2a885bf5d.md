# EWS sync passes header blocks while C++ owns message persistence and recovery status

The decoupled sync callback carries IHeaderBlock and non-header metadata into C++; it no longer returns a detached database header to Rust. Creation parses and inserts there, while update invalidates offline content before applying metadata. NS_MSG_MESSAGE_NOT_FOUND is the explicit missing-update signal; Rust uses only that result for creation fallback and propagates other errors. Original creation cleared every parsed flag before server Read/Marked bits; fixed accepted code later preserves HasRe and marks unread creates New. Keep those phases separate, including later update notifications. Conditional size/preview writes do not clear zero/empty values.

Scope: Exchange message sync boundary.
