# ICS offline restoration awaits item values and their flag writes before playback

The full-sync offline collector stores item objects by hashId. The old custom cal.iterate.forEach converts that object to entries and does not await returned promises; the landing instead iterates Object.values and awaits each offline restoration before playback. Its cache helpers complete both the item change and offline-flag write before resolving. Modified replay supplies a null base version under the checked interface and memory-calendar contract, and ICS takes and clears the per-operation callback before queueing. This is a scoped ordering/data-shape finding; no calendar test, conflict dialog, live server or all-provider behavior was executed.

Scope: Cached ICS full synchronization and offline replay.
