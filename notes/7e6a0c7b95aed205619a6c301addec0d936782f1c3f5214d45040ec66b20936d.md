# Allow optional chaining only for a valid missing structure in the insertion guard

Filelink checks three successive nextElementSibling values with optional chaining because missing following BR nodes are valid. If any shape test fails it skips removal; it still restores the editor selection. This supports a narrowly justified absence guard. It does not justify optional chaining on required initialized controls, and it does not establish a global syntax rule.

Scope: syntax optional chaining.
