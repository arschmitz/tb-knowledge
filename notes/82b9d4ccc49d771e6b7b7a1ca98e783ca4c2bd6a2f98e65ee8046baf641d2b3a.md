# The simple Exchange success callbacks borrow their identifier arrays

The success methods receive newIds by const array reference, and the stored callback signatures accept the same const reference. This landing removes std::move from those callback arguments. The message listener's separate header Clone and the constructor's move of its owned callable are unchanged. Exact original and renamed accepted signatures support the borrowed-array contract; diagnostic use-after-move wording is not a reproduced ownership failure or measured copy count. Earlier broad first-pass lessons stay provisional.

Scope: Exchange listener callback reference contract.
