# Version-gate optional subFolders results to protect Manifest V2 add-ons

The preceding schema cleanup still allowed MailFolder.subFolders to be null. D209203 fixes this for Manifest V3: when folders were not requested, AccountManager leaves rootFolder.subFolders absent, the schema permits null only through max_manifest_version 2, and the Manifest V3 xpcshell test expects undefined. Manifest V2 continues receiving null because changing its established result risks breaking add-ons. This accepted follow-up is the newer rule for this property.

Scope: WebExtension account folder contracts.

- `mail/components/extensions/ExtensionAccounts.sys.mjs`
