# Spellcheck Enter dispatch follows the current default action rather than dialog acceptance

Entry 1473 replaces dialogaccept handling with a keydown Enter check. The accepted doDefault chooses Replace, Ignore or Close from the dialog's default-action state and prevents the event default. The markup has only a cancel dialog button and exposes separately labeled controls with access keys. For this spellcheck dialog, recommend preserving the action dispatcher when the platform event changes; Enter must not become an unconditional Close or Replace action. The change references Bug 1878701, but that upstream discussion is still pending. No keyboard, composition-input, repeat-key or screen-reader check was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Spellcheck default keyboard action.
