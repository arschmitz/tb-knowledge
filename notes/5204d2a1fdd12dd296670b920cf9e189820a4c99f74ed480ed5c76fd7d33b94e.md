# Only show release notes when the configured product build has them

The hub footer skips release notes for NIGHTLY_BUILD, a missing app.releaseNotesURL preference or an about:blank result. It formats the configured URL, assigns the anchor and unhides its list item only after these checks. This is a product/channel condition, not a generic rule that every build has release notes. Current source retains it. No Daily, beta or release footer was opened.

Scope: Account Hub channel-specific links.
