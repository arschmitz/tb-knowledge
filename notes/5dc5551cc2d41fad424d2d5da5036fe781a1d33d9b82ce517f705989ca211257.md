# Check icon-button accessible names during calendar localization migrations

Entry 644 removes both reminder-snooze-ok-a11y and the setAttributes call that supplied it. At the fixed accepted source, the snooze OK button has a command and a CSS checkmark image, with no explicit name in the inspected template or updateUIText path. A live accessibility-tree check is still needed. Proposed manual review rule: check the computed accessible name of icon buttons when removing or moving Fluent attributes, including labels that depended on dynamic duration values.

Scope: calendar/base/content.
