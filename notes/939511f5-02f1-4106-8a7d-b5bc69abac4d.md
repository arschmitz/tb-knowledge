# Use a Boolean name that states the decision or state

Prefer a name that reads as a Boolean question or decision, such as shouldEmbed for an embedding predicate or isAttachment for a part state. D211759 renamed acceptObject to shouldEmbed in compose; D210790 explicitly requested indicative Boolean names. Keep meaning specific rather than adding is mechanically to every flag. This is supported naming guidance beyond lint.
