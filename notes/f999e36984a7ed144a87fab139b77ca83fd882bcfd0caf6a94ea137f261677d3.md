# Tree-listbox registration and selection storage are separate contracts

The dashed tree-listbox.mjs module registers tree-listbox as a customized ul using TreeListboxMixin(HTMLUListElement). Current selection storage is a private Set exposed by the selection getter, rather than the older Map described in the 2001 report. Scoped naming and architecture recommendation: keep the registered tag, module and mixin relationship explicit, and inspect the actual storage when documenting selection. A historical error report is not a type declaration for current code. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.
