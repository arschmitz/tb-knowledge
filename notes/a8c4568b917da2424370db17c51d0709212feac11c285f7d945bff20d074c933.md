# MimePgpeData transfers one retained reference into its MIME closure

MimePgpe_init retains the new nsISupports object in a RefPtr while setting up the proxy. Zero-closure error returns release local ownership; nonzero closure returns use forget().take() to hand the reference to MIME. Finalizing MIME cleanup calls crypto_free, which removes the proxy callback and releases MimePgpeData, then clears its closure. This is the inspected ownership chain, not a fresh leak result or proof about every parser error path.

Scope: mime/pgpmime.
