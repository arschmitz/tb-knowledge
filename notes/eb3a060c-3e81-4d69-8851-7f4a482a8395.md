# Validate nested message attachments as messages and as files

For decrypted message/rfc822 attachments, test list metadata, assigned message IDs, getRaw content and getAttachmentFile content together. Their decoded-content size and serialized EML file size are different quantities; tests must use the correct one. Entry300 adds nested-message assertions and current test_ext_messages_encrypted.js preserves that coverage with more crypto/protocol cases. The accompanying historic recursive equality helper does not establish reliable Date timestamp equality, so do not use it as a general date comparator.

Scope: extensions nested MIME tests.
