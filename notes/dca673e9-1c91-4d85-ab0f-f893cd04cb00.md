# Keep the no-PIE linker flag after the default PIE flag

The Clang 18 follow-up replaced the old Clang-only -nopie spelling with -no-pie. The existing comment states why the setting uses OS_LIBS instead of LDFLAGS: it must appear after -pie from MOZ_PROGRAM_LDFLAGS so it wins. The Clang upgrade and this flag were backed out together when upstream rolled back. When porting a compiler change, preserve linker flag ordering and check the upstream state before relanding.

Scope: Build toolchain.
