# Wait for destination headers before emitting cross-server move and copy events

An IMAP operation can report an empty destination-header array. The tracker creates deferred results keyed by destination URI and header Message-ID before updating the folder, resolves them from msgAdded, then emits the full event. Removed source headers may come from the temporary cache and must be tracked before purging their old mapping. The cross-account test registers one-time event listeners before each operation and verifies source IDs/subjects plus destination folders/subjects and message counts. The inspected code has no timeout on _headerPromises and no duplicate-Message-ID matrix; those limits remain explicit. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/move-copy-event-completion.
