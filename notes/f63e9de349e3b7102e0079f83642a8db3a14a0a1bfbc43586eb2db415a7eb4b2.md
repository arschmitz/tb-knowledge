# Preserve Thunderbird dependency features during manifest regeneration

Current rocbuild preserves the mailnews feature from local Gecko dependencies while rebuilding gkrust.toml. Current idna_glue retains features=[mailnews]. Regenerating from upstream dependencies must preserve Thunderbird behavior switches, not only dependency versions and paths. The preserved-feature list scopes the exception; do not keep arbitrary obsolete features. Generator and build were not executed.

Scope: python/rocbuild/rocbuild.
