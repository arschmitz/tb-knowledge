# Calendar attachment items replay initial attributes after connection

The item clones its template once, then reapplies existing label, URL and icon attributes. Pre-connection callbacks return early, so that replay supplies the initial anchor and image state. Later changes update textContent/href and clear whichever src/srcset representation is unused. Clicking delegates to LinkHelper without adding history. Attribute tests do not establish link activation or accessible output; integration is a separate phase.

Scope: Calendar attachment item lifecycle and link delegation.
