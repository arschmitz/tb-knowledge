# Keep state tokens that mirror public panel IDs consistent

Updater states such as checkingForUpdates and noUpdatesFound are CSS classes because controller className mirrors the existing deck ID. Proposed naming guidance: preserve the shared state token across producer, panel and selector; treat it as an explicit exception when drafting a general kebab-case CSS-class recommendation. New unrelated CSS names do not inherit this camelCase contract.

Scope: mail/base/content.
