# Document the mouse retry helper actual inputs and bounded attempts

The accepted helper recognizes a Function, a stringified arrow starting with "() => ", or a selector; it registers content-event observation before sending the synthetic mouse query and races a 500 ms fallback. Current JSDoc lists string inputs and says more than three tries, while the loop permits two attempts. A scoped manual proposal is to document the actual accepted input union and exact bound. This mismatch is static; the fire-and-forget query/error route was not reproduced. This is static source evidence. No runtime, build, lint or live accessibility check was run.
