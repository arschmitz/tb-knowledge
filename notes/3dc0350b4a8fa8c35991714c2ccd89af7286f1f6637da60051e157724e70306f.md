# Use encoding variants in test and fixture names without inventing a global filename rule

The current calendar importer suite has test_importIcsFileUTF8 and test_importIcsFileLatin1 tasks, paired with import.ics and importLatin1.ics fixtures. These local names communicate the encoding variant and common import scenario. Follow that suite when adding another encoding case. The observed mix of test_ prefix, underscores and camelCase does not justify a repository-wide dash-versus-camel rule.

Scope: calendar/test/unit.
