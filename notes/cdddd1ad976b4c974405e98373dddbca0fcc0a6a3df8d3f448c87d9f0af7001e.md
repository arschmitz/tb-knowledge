# Malformed news URI handling has separate direct-call and command-line guards

MailUtils returns before new URL when URL.canParse fails. The command handler dispatches parsed news/snews protocols, then reports a malformed raw news/snews prefix rather than falling through to the generic URI resolver. The added xpcshell tests use fake NNTP and UI/prompt stubs; the negative message-ID case checks after a fixed delay. This establishes scoped source and test assertions, not every malformed URL case or an executed network/crash result.

Scope: MailUtils and command-line news URI handling.
