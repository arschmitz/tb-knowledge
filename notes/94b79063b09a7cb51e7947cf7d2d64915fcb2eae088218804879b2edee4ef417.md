# Calendar reloads can repeat stylesheet installation

The D333944 review record at b6552d05a12e27636d3af194b7f285a661f4c5ff reports that eventDialogCalendarObserver.onModifyItem() re-enters loadDialog() after an external update. A second load of the same stylesheet and origin reportedly throws NS_ERROR_ILLEGAL_VALUE before the description updates. A title-only conflict test missed this because the title changed first; an added description assertion reportedly failed. For this document lifecycle, the proposed fix installs the sheet once or checks whether it is already installed. This remains a review claim supported by reported local experiments, not a confirmed landed fix or a general rule for all stylesheet APIs.

Scope: Calendar event editor reload.
