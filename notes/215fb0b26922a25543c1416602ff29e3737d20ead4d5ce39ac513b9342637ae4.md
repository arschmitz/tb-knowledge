# Account Hub error notifications can use a plain Error message without a cause

The header fallback can turn error.message into a raw notification title when no explicit or localized title is available. Optional cause lookup prevents a plain Error from throwing during fallback selection. The regression task leaves cause unset and directly checks visibility, the raw message, absent localization attributes and clearing. It does not cover every cause-only localized-description path or a live account setup error.

Scope: account-hub/notifications.
