# Avatar names distinguish the custom element, stylesheet and row state

This component uses ContactAvatar with tag/contact-avatar.mjs, while its packaged stylesheet is contactAvatar.css. Caller mail-list-row and mail-list-card markers differ from the avatar host is-mail-list state used by CSS. These accepted local names identify different roles; keep their registrations, consumers and selectors aligned when editing this family. They do not establish a universal dash/camel convention or a global class-prefix rule. No runtime style test ran.

Scope: Address-book avatar local naming.
