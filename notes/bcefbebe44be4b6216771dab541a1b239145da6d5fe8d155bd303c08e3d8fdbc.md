# The Microsoft https localhost restoration is a historical provider phase

The historical patch restores redirectionEndpoint https://localhost only in the Microsoft issuer entry. Fixed accepted source later removes that explicit field and selects the external-browser flow; the constructor otherwise defaults to http://127.0.0.1. Issuer extensions and the sandbox clone are separate paths. Preserve the phase and exact selected provider rather than treating the old literal as current universal configuration. No account or OAuth flow was tested.

Scope: OAuth Microsoft provider redirects.
