# Preserve the notification Fluent resource filename at its consumers

The accepted notification container loads messenger/inAppNotifications.ftl. This localization resource keeps its lowerCamelCase filename, while the custom-element modules use their separately documented dashed family. Preserve the exact chrome resource spelling at localization consumers and packaging references when adding or renaming a resource. Existing notes already cover template IDs, .inc.xhtml filenames and payload-to-DOM mappings. These names belong to different contracts; this example does not justify renaming all Thunderbird localization files to one casing style.

Scope: Notification localization resource filenames.
