# The cookie button's plural count is separate from its selection enablement

onCookieSelected passes the existing selectedCookieCount to the new Fluent label. That value includes an artificial addition of two for one selected expanded host, so it is not a precise cookie total in every tree state. The button's enabled state still comes independently from seln.count, and the concrete control keeps its deleteCookie action. Preserve those producer and command contracts when changing the label. Identical English plural wording is not a reason to remove the count needed by other locales. No UI or locale test was run.

Scope: Cookie preferences selection label.
