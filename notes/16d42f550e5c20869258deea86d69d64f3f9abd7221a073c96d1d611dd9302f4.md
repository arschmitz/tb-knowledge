# Check the selected message again before replacing its displayed body

Inline crypto work can finish after the user selects another message. Immediately before replacing the body, the current code compares the processed message URI with the displayed URI and returns when both exist and differ. This guard applies to final body replacement; it is not proof that every earlier status update is guarded. When processing has no plaintext to show, the original message text remains the fallback. Keep asynchronous result ownership tied to the selected message. No rapid-selection race was reproduced.

Scope: OpenPGP asynchronous display ownership.
