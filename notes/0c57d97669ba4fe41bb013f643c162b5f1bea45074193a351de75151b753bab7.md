# A short final IMAP chunk aborts the offline write before it is marked complete

The final-chunk guard applies to chunked non-header downloads with a positive announced total. If origin plus the current literal size is still below that total, the parser aborts the write. The abort reaches EndNewOfflineMessage with failure, which clears Offline and asks the store to discard a pending stream. The new positive and truncated-message tests directly check the Offline bit. They do not assert a later re-fetch, content integrity or attachment recovery, and this audit did not execute them.

Scope: Chunked IMAP message finalization.
