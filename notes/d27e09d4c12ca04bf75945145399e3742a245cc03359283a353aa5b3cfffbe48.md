# Initialize the account web channel before opening the reauthentication URI

568 replaces the force-signin fallback chain with EnsureFxAccountsWebChannel followed by promiseConnectAccountURI and opening the returned content tab. The lazy import alone does not initialize the channel. Keep the callback channel setup before navigation so the page has the intended account communication path. Current source retains this order. The real Firefox Accounts flow and remote login callbacks were not exercised.

Scope: Account reauthentication order.
