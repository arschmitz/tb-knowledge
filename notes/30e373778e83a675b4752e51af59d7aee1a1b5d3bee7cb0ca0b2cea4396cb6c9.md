# Parser value arrays remove heap-owned header nodes without owning the header bytes

Accepted m_toList and m_ccList store HeaderData values in AutoTArray with inline capacity one. Each HeaderData still holds a borrowed pointer into m_headers; replacing individually allocated structs does not copy their text or make capacity one a maximum. Keep container ownership and byte ownership distinct in this parser. The existing bounded-slice note is reused rather than duplicated. This is static source and test-code inspection.
