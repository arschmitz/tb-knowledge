# Keep a connection-security label linked to the surviving control

Entry 799 removes an obsolete security option and accidentally changes the historical label target to server. while the control remains server.socketType. The fixed accepted markup again targets server.socketType and uses that exact ID on the HTML select. Proposed review check: after removing an option or replacing a widget, verify the actual label-to-control reference, including names that contain dots. A matching static reference does not prove the final accessible name or access-key behavior.

Scope: mailnews/base/prefs.
