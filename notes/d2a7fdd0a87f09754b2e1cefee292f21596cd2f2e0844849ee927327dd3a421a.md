# Toolbar template correctness checks command support without proving command execution

1273 adds a per-space test over template-backed customizable items. It accepts a controller that supportsCommand or an existing command element. The real UnifiedToolbarButton uses an enabled controller or command.doCommand at click time. Thus this test proves structural support in each tested space, not current enablement, successful command side effects or keyboard operation. Keep these distinct when adding a toolbar command or citing test coverage. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/unifiedtoolbar.
