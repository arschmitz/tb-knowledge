# The 2024 password-reveal button is a historical control, not the current template

Entry 1511 adds a native type=button reveal control, a decorative image, aria-pressed state and localized show/hide names. Its handler updates input type and pressed state together. The fixed accepted password widget/template no longer contain that control. Preserve the useful state/name/type relationship as a historical accessibility example, not a claim that the current Account Hub exposes password reveal. The later removal rationale and keyboard/screen-reader behavior are unverified. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Account Hub historical password reveal.
