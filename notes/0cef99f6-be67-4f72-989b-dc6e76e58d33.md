# Implement upstream extension context hooks in Thunderbird TabTracker

Mozilla toolkit began calling tabTracker.getBrowserDataForContext for runtime.getContexts, but Thunderbird provides its own TabTracker rather than Firefox ext-browser.js. This missing hook caused a comm-central xpcshell failure. The landed Thunderbird hook sends background, tab, and popup contexts through getBrowserData and returns tabId/windowId -1 for other view types. getBrowserData returns -1 for windowless dummy extension documents and validates window IDs instead of trusting an outerWindowID alone. An options page embedded in about:addons needs one extra browser-owner level to find the Thunderbird tab. Keep these cases explicit when adapting upstream extension APIs.

Scope: WebExtension runtime contexts.
