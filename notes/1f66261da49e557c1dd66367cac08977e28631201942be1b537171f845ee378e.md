# Dialog richlist selection colors depend on focus

At revision f77e5d1246a1856b67369ec44594b2f59fc15311, themeableDialog.css gives selected richlist items --tab-selected-background and inherited text color. When the parent richlistbox has focus, selected items use --selected-item-color and --selected-item-text-color. A separate rule sets the current item's outline color in a focused multi-select list. Preserve these separate selectors when changing dialog list colors because selection and current-item styling have different conditions. This is observed CSS behavior in this file, not a global style rule. The excerpt does not establish whether an outline is visible without other CSS, and no runtime or accessibility validation is supplied.

Scope: Themeable dialog richlists.
