# Use TreeDataAdapter as the data side of a TreeView

Bug 1890731 added TreeDataAdapter and TreeDataRow to hold row data and respond to the TreeView contract, while existing nsITreeView users migrated in stages. The adapter owns row count, cell text/value/properties, parent and level, expansion, selection callbacks, and tree notifications. New code should inspect current TreeDataAdapter before implementing a separate tree model. The current class still exists but now uses a flat-row cache rather than the first commit’s fully flat storage.

Scope: Tree view architecture.
