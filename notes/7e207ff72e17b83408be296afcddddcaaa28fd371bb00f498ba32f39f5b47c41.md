# Address Book command module imports MailServices but borrows document globals

aboutAddressBookCommands.mjs imports MailServices into its module scope but uses explicitly listed globals supplied by the Address Book document script. The globals comment is a lint declaration, not runtime initialization. The document loads the classic script and command module as separate script roles. Keep this scoped workaround separate from normal import choices; its comment says import-globals-from is intended but the linter rejects it. No linter or document runtime test ran.

Scope: Address Book content module dependency declarations.
