# Check Hub styling at the real dialog scope and invalid states

The accepted Hub CSS explicitly says :root supports tests but does not style all application elements within shadow DOM; dialog is the real application scope in the inspected rule. Contrast preferences override Hub button colors, and forms contain separate focus and invalid-state rules. A passing root-based test or the presence of semantic tokens alone does not prove application scope, focus visibility or contrast. Preserve the real scope and inspect user-invalid, aria-invalid and warning behavior when changing form styles. No live accessibility or contrast measurement was done.

Scope: mail/account-hub/form-style-scope.
