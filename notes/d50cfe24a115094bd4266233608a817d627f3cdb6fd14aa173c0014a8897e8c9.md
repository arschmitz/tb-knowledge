# Reject negative file sizes before allocating the EML read buffer

The adjusted reland checks fileSize < 0 and returns NS_ERROR_FAILURE before constructing mozilla::Buffer. Preserve that guard when changing header parsing. A failed GetFileSize call is checked separately; a successful call with a negative result must not become an allocation size.

Scope: mailnews/local/src.
