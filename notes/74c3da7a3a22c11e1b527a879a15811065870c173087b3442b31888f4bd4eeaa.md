# A new recurrence date wrapper can still retain a cached inner value

The cached rule pushes new CalDateTime(next) wrappers into its result. CalDateTime stores a supplied inner object directly; clone is the method that clones that object. A new wrapper alone therefore does not establish detached inner-date ownership. This is a source identity boundary. Caller mutation and observable cache effects were not exercised or followed through every consumer.

Scope: Calendar recurrence date ownership.
