# Copy-move fixture prefixes name test data while isMove selects the operation

The original helper documents prefix as the naming prefix for two folders and two source items. It does not choose copy versus move; callers pass that operation choice separately as isMove. The accepted refactored copy test still requests a copy-prefixed fixture and then sets isMove=false. This is a scoped distinction between fixture identity and operation behavior, not a naming rule for every test helper. The historical four-element tuple docs describe the original helper; later return-shape changes need their own contract check. No fixture or test ran.
