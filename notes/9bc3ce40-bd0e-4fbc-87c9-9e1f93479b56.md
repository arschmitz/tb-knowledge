# Load OTR key generation as a registered module worker

Bug 1897627 moved the OTR worker from chat/content/otrWorker.js to chat/modules/OTR.worker.mjs. The caller sets type: "module" on BasePromiseWorker, the worker imports PromiseWorker.mjs, and chat/modules/moz.build registers the module. The worker still handles generateKey through the PromiseWorker dispatch bridge. This was a module/runtime change made after the chrome-worker ESLint rule disappeared; current code keeps the same module path. No new test was added in this commit.
