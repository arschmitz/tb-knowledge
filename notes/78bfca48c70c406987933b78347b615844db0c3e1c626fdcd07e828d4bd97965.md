# The no-format signing cleanup preserves scoped entitlement inputs rather than treating them as release outputs

The build declares public/build/security XML inputs and the signing configuration references those artifact names. In the final cleanup, entries whose paths all use that prefix are kept before the explicit empty-formats removal branch; other empty-formats entries also lose their release-artifact paths. The loop uses a list copy while mutating the original. This is a precise prefix-scoped input/output distinction, not XML validation, a universal unsigned-artifact exception or a successful signing result.

Scope: macOS artifact producer/configuration and final signing cleanup.
