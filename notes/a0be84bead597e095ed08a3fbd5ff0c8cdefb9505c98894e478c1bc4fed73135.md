# Attachment URL type metadata feeds channel selection, while tests compare decoded parameters

This landing adds declared type metadata to internal attachment URLs, with a message/rfc822 exception in GenerateAttachmentData, and appends encoded type metadata in GlodaAttachment.url. The converter’s local part/type selector supplies channel content type. Tests expect text/plain and image/svg+xml and compare Gloda protocol/pathname plus decoded parameter values instead of raw URL prefixes. That comparison does not establish authority, fragment or duplicate-parameter equality. The fixed accepted local contracts were checked; URI-engine semantics, protocol rendering and test execution were not proved.

Scope: MIME attachment URL and channel metadata.
