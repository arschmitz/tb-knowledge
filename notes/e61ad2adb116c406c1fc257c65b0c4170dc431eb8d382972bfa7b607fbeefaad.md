# Calendar discovery returns arrays grouped by provider and the Hub flattens them

The provider detector returns a Map whose successful entries associate a provider with its calendar array. Account Hub iterates the map values and each array, preserving new calendar objects while replacing existing ones with disabled placeholders. Treat Map size as provider-group count, not calendar count. This is a scoped caller/result contract; the 1375 change in the detector file itself is only a removed blank line, so no new detection algorithm is attributed to that commit. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub calendar discovery result shape.
