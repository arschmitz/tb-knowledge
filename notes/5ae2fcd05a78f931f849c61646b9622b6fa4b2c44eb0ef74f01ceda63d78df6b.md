# Name a path character set for the forbidden values it matches

D215445 requested FORBIDDEN_PATH_CHARACTERS, and current source retains that name for the negated ASCII whitelist regex. The constant describes the matched forbidden set and path role. Proposed broader manual naming guidance: name a regular-expression character set for the values matched and the data boundary, not a vague clean or bad label. This single accepted rename does not establish that every regex constant must use this suffix.
