# The version55 mail migration requests login re-encryption through a preference

For an existing UI migration version below55, MailMigrator sets signon.reencryptionNeeded=true. Already-current profiles return, and new profiles skip historical migration branches. This source requests later login-storage work; it does not perform encryption or prove completion. The exact paired storage consumer and cipher implementation remain a source-ingestion gap. No migration or login test ran.

Scope: Mail profile and login migration.
