# Old-selector tests did not establish a user failure

For D331224 at revision 7b68cf9db1c67fa4736d0125914e3d799d300d0c, the AI source inspection reported that calendar selection dispatched immediately and that only tests retained old selection actions or removed selectors across operations. Those tests demonstrated rejection of artificial stale input, but did not establish a normal user path requiring extra selector generation checks. When assessing similar protection in this component, distinguish a test-created condition from a reachable user failure. This limitation concerns selector actions; it does not invalidate the separate checks for pending asynchronous event loads. No live reproduction was reported.

Scope: Calendar event calendar selector.
