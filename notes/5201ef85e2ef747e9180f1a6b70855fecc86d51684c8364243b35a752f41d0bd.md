# The IMAP discovery test checks selected database cache entries

After looking up discovered folders and awaiting an Inbox update, test_listClosesDB asserts that five selected folders have no cached database. cachedDBForFolder resolves the summary-file path and calls FindInCache. This is a direct cache-membership assertion for those folders, not proof that every production owner releases every database. Discovery setup still uses a fixed delay, and the test was not run in this study.

Scope: IMAP discovery database lifetime test.
