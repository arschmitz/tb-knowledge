# CSS console errors are correlated to test loads by a unique URI suffix

The accepted test resets the console before loading CSS and appends a random ?always-parse-css- suffix to each stylesheet URI. messageIsCSSError accepts nsIScriptError entries with CSS category and that suffix, strips it before allowlist matching and fails on unmatched errors. Preserve this correlation when changing the loader; an arbitrary console message or previous-test error is not evidence about the current stylesheet load. This is source/test-code inspection only.
