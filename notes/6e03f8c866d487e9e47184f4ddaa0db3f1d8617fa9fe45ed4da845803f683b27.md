# The rebuilt key-import info dialog uses HTML key cards inside a XUL modal

This landing replaces the old manually sized key list with HTML cards in a XUL dialog, a dedicated scroll layout and UIFontSize registration. Cards show the created date and formatted fingerprint, omit Bits, and provide an href-bearing details link that opens the captured key ID. The Close button receives initial focus. These checked source contracts do not prove native keyboard behavior, every screen/locale layout or a crash fix.

Scope: OpenPGP import-info dialog.
