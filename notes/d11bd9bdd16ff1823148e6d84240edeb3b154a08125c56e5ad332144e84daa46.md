# Map preference, DOM, JavaScript and Fluent names in their own local forms

For horizontal thread scrolling, the persisted preference is mail.threadpane.table.horizontal_scroll, the JavaScript property is isHorizontalScroll and the Appearance element ID is tableHorizontalScroll. Fluent message names use the existing hyphenated preference family. Keep these mappings explicit instead of mechanically forcing one case style across every layer. This is a verified local convention, not a claim that all Thunderbird DOM IDs use camelCase.

Scope: mail/components/preferences.
