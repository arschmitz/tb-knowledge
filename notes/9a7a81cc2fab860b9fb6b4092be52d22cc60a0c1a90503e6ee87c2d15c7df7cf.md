# AutoSync periodic updates use protocol-specific listener APIs

The timer keeps IMAP InitiateAutoSync and sends other supported owners through state.UpdateFolder. That method uses IMAP UpdateFolderWithListener or EWS GetNewMessages with the same manager listener; unsupported types fail. Successful initiation marks stUpdateIssued and the manager update flag. The manager stop callback clears that flag and removes the queue head while returning the exit status. The account gate still permits only IMAP/EWS and has a scoped EWS password-precheck exception; it does not prove logged-in state or establish a general auth-check rule. No timer or protocol test ran.

Scope: EWS and IMAP AutoSync update lifecycle.
