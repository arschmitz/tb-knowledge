# Honor the asyncCompact callback order

asyncCompact returns before work finishes. A start failure invokes no listener callbacks; successful start invokes begin, per-message retention and retained-message callbacks, then completion. No callback fires before the initial call returns. Higher-level folder and database work must follow that contract.

Scope: message store compaction.
