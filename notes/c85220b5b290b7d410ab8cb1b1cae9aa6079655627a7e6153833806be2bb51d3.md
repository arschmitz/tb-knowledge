# Saved-search accept labels target the button rather than the dialog

The saved-search properties code gets the actual accept button and assigns its create or update Fluent ID with document.l10n.setAttributes. Those messages define .label and .accesskey. This differs from New Folder’s dialog-level buttonlabelaccept field. The edit-title message receives folderName separately. Keep each message’s attributes matched to its actual receiver; declarations alone do not prove live translation or accessible naming.

Scope: Saved-search Fluent receiver roles.
