# The S/MIME body-handler count describes decrypted MIME rather than its returned text buffer

The S/MIME branch replaces buf with GetRelevantTextParts output, then returns decrypted.Length rather than buf.Length. The header promises the length of buf, and MatchBody adds the returned n to its seen counter. The full decrypted MIME string and filtered text buffer need not have the same length. Preserve this static count-contract limit without claiming a reproduced search failure or memory error.

Scope: Encrypted body-search return-count contract.
