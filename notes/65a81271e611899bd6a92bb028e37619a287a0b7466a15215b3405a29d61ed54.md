# OAuth state is consumed before the mismatch branch and uses an explicit byte count

The request asks generateRandomURLToken for 32 bytes, separately from the 64-byte PKCE verifier. The response copies and clears _authorizationState before checking a mismatch when the saved value is truthy. The negative external-flow test directly checks the state string shape, abort result, empty tokens and no saved login. OAuth2Module maps promise rejection to NS_ERROR_ABORT. These bounded source/test contracts do not establish general callback replay prevention or a security guarantee.

Scope: OAuth authorization request correlation.
