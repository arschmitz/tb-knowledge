# Use the newer logical edge properties in the Windows titlebar family

The 2024 titlebar patches use physical top properties. Newer accepted CSS uses border-block-start and margin-block-start for these related edges. Proposed scoped manual CSS style: use the logical block edge in new changes in this family, while retaining platform, theme and Mica conditions. This is a newer-code preference, not proof that every physical property is forbidden. Zoom, writing mode and native layout were not exercised.

Scope: Windows titlebar CSS syntax.
