# Test the actual result and keep assertion comments honest

The current repair helper says it checks column order, but it only checks mutual membership. The folder-mode telemetry test compares actual length, then checks each expected mode against expectedModes itself. Proposed manual review rule: compare observed values to expected values and decide whether order matters; make the comment match the checks. These are static test gaps, not proof the runtime feature is broken.
