# The first Account Hub OAuth hostname gate resets the choice, while the later phase warns

The original hostname gate hides unsupported OAuth and, if it was selected, writes Normal Password into the matching form control and config-side auth value. Its new tests assert that reset for IMAP/POP3 and SMTP. Accepted source later retains the OAuth choice, shows an unsupported-host banner and rejects validate while that combination remains unsupported; its tests assert the retained choice and warning. Keep these source/test phases distinct when reusing the direct-input hostname lookup contract. Neither option visibility nor a passing static lookup establishes an OAuth authentication result.

Scope: Account Hub manual OAuth hostname phases.
