# Document repeated headers as arrays even when an input accepts a scalar

The raw and decoded header converters normalize each header value to an array. The encode/decode utilities accept a string or array but return arrays. MessagePart schema descriptions state the key/value representation and link the option controlling presence. Manual representation proposal: keep plural header values and option-dependent body fields explicit in JSDoc and schema, and use the named cross-reference syntax already present in extension docs. A scalar example does not change the return shape. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/header-array-docs.
