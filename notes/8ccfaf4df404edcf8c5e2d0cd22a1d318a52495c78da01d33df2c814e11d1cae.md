# Force-all IMAP polling includes Junk only in the non-Inbox traversal

The owned change removes Junk from the forceAllFolders mask in GetNewMessagesForNonInboxFolders while retaining Inbox/Trash/Virtual, non-root and can-open conditions. CheckNew remains a separate route. GetNewMessages handles Inbox separately, resolves legacy/server force-all settings and starts traversal. The separate IDLE biff filter still excludes Junk unless explicitly marked. Keep these caller paths distinct; this is not a global statement about Junk notifications. STATUS work completes through the URL-listener queue after traversal returns. No network or notification test ran.

Scope: IMAP new-mail polling.
