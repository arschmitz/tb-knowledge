# The Calendar helper re-fetches the visible event box after scrolling

This landing replaces the scrollend/timeout/frame wait in showEvent with a poll that re-fetches the current week-view event box and checks BrowserTestUtils.isVisible. The initial waitForEventBoxAt only checks existence. The returned refreshed node reaches openEvent and the positionTest tolerance measurements. The new condition does not directly assert a nonzero rectangle or final dialog position; those measurements are separate downstream assertions. The required historical primary later reports the failure still present and reopens it. No layout or test was run here, and BrowserTestUtils visibility internals remain outside this bounded source check.

Scope: Calendar dialog browser-test helpers.
