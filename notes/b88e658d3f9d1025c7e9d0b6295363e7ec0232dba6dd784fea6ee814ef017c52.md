# Preserve the favicon channel security contract during fetching

MailUtils creates its favicon channel with the system principal, inherited CORS context, chrome allowance, script disallowance and internal favicon content policy. It checks fetch status before reading and converting the image. Those flags and the principal are part of the existing privileged fetch boundary; they are not incidental syntax to remove while shortening the port. The local clean NetUtil dependency returns an ArrayBuffer, so Uint8ClampedArray(data) is not evidence of byte-string corruption. Its Gecko revision was not established as paired to the accepted comm endpoint. No network request or security runtime test was run.

Scope: mail/favicons/channel-contract.
