# Calendar checkbox title meaning comes from Fluent values rather than ID names

The calendar list selects show-calendar-title when the displayed checkbox is checked. In the inspected English resource that ID has title Hide; hide-calendar-title has title Show. Initial setup, checkbox changes and the Space-key path use this mapping. The identifiers alone therefore do not describe the displayed action. The property observer updates checked separately; no new observer ordering, live tooltip or accessibility result was measured.

Scope: calendar/calendar-list.
