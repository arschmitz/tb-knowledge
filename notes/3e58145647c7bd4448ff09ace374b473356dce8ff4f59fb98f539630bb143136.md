# Name account-configuration diagnostics after the actual source

The historical setup log is corrected from installation to the Mozilla ISP database around FetchConfig.fromDB. That old controller is absent from the accepted tree. The current database helper sanitizes the domain, builds the configured ISP DB URL, passes timeout and AbortSignal to fetching, and tags the parsed result as db. Current Fluent messages distinguish installation files, the ISP database and domain guessing. Manual diagnostic proposal: name the actual branch or source so parallel setup work can be traced; do not copy the retired controller or imply a successful database network request from this log-only landing.

Scope: mail/accountcreation/source-diagnostics.
