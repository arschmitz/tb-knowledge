# Preserve tag-list traversal limits when describing merge pinning

671 replaces a first-ten-tags limit with traversal of the downloaded tag list. For each tag, it checks the release/build regex first and then the base regex, returning the first matching item in list order. This is not a two-pass global search that always prefers any release tag over every base tag. Current code keeps that traversal. No assumption about remote list ordering or exhaustive repository tag history was tested.

Scope: Merge upstream tag selection.
