# State exactly what a cleanup test fixture proves

test_nstmpCleanup awaits offline-download listeners but explicitly creates stand-in mbox files if the real files do not yet exist. It then proves that protected paths remain, orphan paths are removed and a second call is suppressed by the latch. It does not prove downloaded-message readiness or content preservation inside every kept file. Keep the fixture limitation beside the lesson; passing path-existence assertions cannot establish an asynchronous download contract. The retired historical test was read in full and was not run.

Scope: Cleanup regression test bounds.
