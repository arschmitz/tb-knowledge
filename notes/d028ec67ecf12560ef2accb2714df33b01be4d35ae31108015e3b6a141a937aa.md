# Store an explicit messageKey even when the offline row OID uses the same key

GetOfflineOpForKey uses msgKey as rowObjectId.mOid_Id and separately calls SetMessageKey(msgKey) on the live offline-operation object. SetMessageKey persists PROP_MESSAGE_KEY. Preserve both representations when changing row creation; identical current values do not prove the explicit field is redundant. The 733 comments explain this otherwise easy-to-miss persistence boundary.

Scope: mailnews/db/msgdb.
