# Show the top-level OAuth page address, not an iframe address

654 gates reporterListener.onLocationChange on aWebProgress.isTopLevel. The browser-request URL field must follow the actual login page, while subframe navigation must not replace it. The current regression test first checks top-level navigation, then proves the iframe loaded the expected different URL before asserting that the field stayed unchanged. A negative test needs proof that the rejected stimulus occurred. This is source/test inspection; no OAuth browser or security UI run was performed.

Scope: OAuth request window navigation.
