# Commands Electron desktop shell, branding, and build-capable worktrees

Artifact builds suit frontend/resource-only changes. Native code, WebIDL, build-system/configuration, Gecko/shared changes, or uncertain files require normal builds. A fresh artifact checkout needs one complete configure/build before `mach build faster`; copied binaries with overlaid resources are not runtime proof. [Task 2]
