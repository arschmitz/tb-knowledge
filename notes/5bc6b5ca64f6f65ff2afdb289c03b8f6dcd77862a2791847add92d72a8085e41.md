# Pass a named scroll flag instead of relying on Boolean coercion

Entry 1081 and accepted compose consumers pass SCROLL_SYNCHRONOUS to scrollSelectionIntoView in both JavaScript and C++. A true value does not describe the flags contract even when conversion compiles. Proposed manual syntax rule for these editor APIs: use the named enum/flag required by the interface. The commit discusses historical numeric values; this study did not pair or execute the Gecko interface and does not infer a user-visible timing difference. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/components/compose.
