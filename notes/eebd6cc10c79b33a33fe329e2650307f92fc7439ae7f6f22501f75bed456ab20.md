# Sync dispatch failure is a stop callback after start rather than a setup return failure

ExchangeMessageSyncHandler::Go can return a setup failure before starting callbacks. Once setup succeeds, it calls mOnStart before client dispatch because callbacks could occur during dispatch. If dispatch immediately fails, it calls mOnStop and changes the return to NS_OK. Keep this two-channel result contract separate from a guarantee that the remote operation started. General callback timing policy remains unresolved; the source does not establish exactly-once completion under reentrancy.

Scope: exchange-message-sync.
