# Keep recovery files when compaction reaches its commit phase

When compaction has reported success from onCompactionComplete, preserve recovery files if the later mbox or database install fails. The two files cannot be renamed atomically as a pair; .compacting, .compacted, and .original files show which stage was reached and allow later recovery. This revision did not yet add automatic recovery.
