# Distinguish required persisted fields from optional defaults

485 uses FieldType::Required/Optional at pref getter sites and preserves errors other than a missing-pref result. Current shared OutgoingServer retains it: required missing properties return NOT_INITIALIZED, optional fields return empty/zero, and Some cached values are returned even if empty. This does not establish a nonempty-string invariant. The named enum makes the decision visible at each call, a supported scoped manual API pattern beyond formatting.

Scope: rust/protocol_shared/src.
