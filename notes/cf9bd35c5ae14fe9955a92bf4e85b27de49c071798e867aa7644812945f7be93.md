# Offline news search scope depends on junk and body availability

At revision 0d8ec7dee44a3d9cc02b742c1d76ffc553fbc9b5, SearchDialog.js selects one of four offline news search scopes. It checks the folder's Offline flag for body availability and compares the inherited dob ayes setting (exact identifier: dobayes.mailnews@mozilla.org#junk) with "true" for junk availability. Both select localNewsJunkBody; junk alone selects localNewsJunk; body alone selects localNewsBody; neither selects localNews. Preserve these separate cases when changing news search scope selection. This is static source evidence for the news branch, not a rule for IMAP or proof of runtime behavior.

Scope: Search Messages offline news scope.
