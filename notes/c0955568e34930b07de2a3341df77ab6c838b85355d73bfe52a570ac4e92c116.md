# Mail-only profile copying must carry local-target mode through recursion

The mail-only importer passes isTargetLocal = true when copying into Local Folders, and recursive calls preserve that flag. Every level copies mail files but skips .msf summaries, which prevents imported special-folder state from following the messages. The added test uses fake root and nested mail/summary files and checks existence versus omission at both levels. It does not parse messages or prove real-folder deletion behavior. Preserve the mode argument when refactoring recursion. No test or copy ran.

Scope: Thunderbird profile mail-only recursive copy.
