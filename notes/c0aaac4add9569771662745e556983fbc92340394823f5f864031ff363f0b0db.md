# Return null for a missing legacy child without treating invalid input as missing

Current GetChildNamed sets its output to nullptr and returns success when no child matches. It still rejects an empty name or missing output pointer. The compose helper can therefore use lookup || createLocalSubfolder for Drafts. Keep absence, invalid input and folder creation distinct when converting an old exception-based caller. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Legacy child lookup absence contract.
