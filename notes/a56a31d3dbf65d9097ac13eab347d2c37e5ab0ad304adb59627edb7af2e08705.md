# Delete the source only after the destination move completes

The local copy caller creates a move-aware destination listener but passes false to the source message service so it cannot delete independently. Local EndMove checks both the passed success value and m_writeFailed before deleting source messages. The stream listener calls EndMove only for moves and non-IMAP destinations; the IMAP destination owns that action. Copy operation intent and source-service deletion intent are separate booleans in this path. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/local/src.
