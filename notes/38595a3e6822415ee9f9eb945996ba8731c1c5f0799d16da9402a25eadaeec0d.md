# Account creation and service discovery have separate success outcomes

The email forward path validates/creates the account before fetching sync accounts. Current #fetchSyncAccounts can show account-added success with an informational discovery failure, while a user skip shows success. This differs from the initial inline OAuth discovery branch. Preserve account creation success separately from optional address-book/calendar discovery when reviewing this flow; no discovery server or error path ran. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
