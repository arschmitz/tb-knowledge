# Correct the old Reply mapping and test the actual menu action

Actual1478 source changes navContext-reply from cmd_replyall to cmd_reply. Lesson461d68eb98d2fa724c3cfe52a2a024d567082912ea1310179b66d368c72e6de5 incorrectly called the old mapping cmd_replySender. The accepted generic command chooses group reply for newsgroup state and sender reply otherwise; explicit Reply All stays separate. D231485 accepts the fix and asks for a separate test follow-up because old-menu tests missed the wiring regression. Current selected tests expect compose type and recipients for these actual items, but they are later source context and were not run. Do not infer a smart-reply preference policy or a completed follow-up from this review.
