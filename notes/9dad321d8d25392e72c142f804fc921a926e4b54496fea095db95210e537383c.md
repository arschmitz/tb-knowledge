# Name recursive API options after the data they expand

The current accounts.getDefault option is includeSubFolders. It expands the rootFolder.subFolders tree, including nested descendants; includeFolders was too vague. Keep the public lowerCamelCase spelling and state the affected object property in the description. Manifest V3 defaults false; Manifest V2 defaults true and also affects the deprecated folders property. This adds the getDefault gap and naming rationale to the earlier folder-default lesson. Do not change established public criteria such as accountId merely because they accept arrays.

Scope: Extension API naming and compatibility.
