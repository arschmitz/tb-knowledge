# Gloda folder indexing jobs use Gloda IDs rather than the new nsIMsgFolder Panorama ID

The new native folder.id is a mode-limited Panorama identifier. Gloda maps that native folder to glodaFolder and creates folder indexing jobs with glodaFolder.id; its compaction/reindex purge must compare job.id with that same Gloda value. The purge helper actually calls the predicate on queued jobs and removes selected entries. The shared property name id does not establish a shared identifier namespace. Current Panorama tests separately compare native folder IDs with numeric FolderDB lookups, but no Gloda, ID or build-mode test ran here.

Scope: Folder identifier receiver boundaries.
