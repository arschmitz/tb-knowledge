# The compose global guard has a file-specific baseline and lazy-object alternative

The ESLint override enables mozilla/no-more-globals as an error for MsgComposeCommands.js only. Its companion .globals array records the baseline, and the lint wrapper includes that extension. The source comment asks contributors to consider separated code and to attach lazy getters to the existing lazy object rather than this. Accepted config later treats .globals as strict JSON and names the allowlist path for necessary changes. Keep this scoped guard separate from a global JavaScript rule; the plugin implementation and actual lint result were not checked.

Scope: compose ESLint global restriction.
