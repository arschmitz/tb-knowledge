# Local message moves can write bytes before a destination database is rebuilt

The local copy setup creates a header only when a destination database exists, while obtaining its store stream separately. Completion attaches the returned token only to an available header. The inspected test deletes the destination summary database, moves a message, checks that the database remains absent, then reparses and checks the moved text after trim. That is direct coverage of the named move/rebuild scenario, not every copy operation or exact trailing-newline preservation. Current additional truncated-source handling is a later refinement. No test ran.

Scope: Local copy without summary database.
