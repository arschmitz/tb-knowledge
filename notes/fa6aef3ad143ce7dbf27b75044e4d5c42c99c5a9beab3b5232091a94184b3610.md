# The CalDAV offline-playback regression checks the neighboring cache rows after delivery and flag reset

The regression first changes A online and B offline. It waits until server B contains the change and the cached offline flag is cleared, then checks A's existence and title plus one row for each UID. The actual playback resets the flag after the direct uncached operation succeeds. These are direct test-code checks of neighboring-row preservation, not a cached-B-title assertion or an executed network/test result.

Scope: CalDAV cached offline modification regression.
