# The English Empty Spam access-key change preserves the existing menu identity

This patch changes only folder-context-empty-spam.accesskey from S to E in en-US. The Empty Spam label, Fluent ID, emptyJunk DOM item and FolderCommands.emptyJunk call remain. The controller still shows that item under its junk-folder condition. The scoped intent is to remove an English menu collision; no all-locale ID policy or collision-free result for every dynamic menu is established. No keyboard or accessibility test ran.

Scope: Folder context menu en-US localization.
