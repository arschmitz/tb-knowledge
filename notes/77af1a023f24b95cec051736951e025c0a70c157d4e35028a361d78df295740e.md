# Distinguish unsupported offline activity from a failed status query

Current CanCompactNow permits NS_ERROR_NOT_IMPLEMENTED from HasOfflineActivity but defers compaction for another failure of that query. Earlier failures to obtain a database/interface and failures of HasPseudoActivity can fall through to allow, so do not describe the whole helper as fail-closed. A scoped review recommendation is to preserve the unsupported-versus-failed distinction and test the actual error branch being changed. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Compaction status-query policy.
