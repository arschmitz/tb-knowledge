# Give reused branch predicates a decision name

476 uses isTotalCol/isSubjectCol instead of assigning comparison results within if conditions. The names preserve the column role across routing and rendering; the final unreachable assertion documents the two surviving cases. Proposed scoped syntax rule: name a predicate used in multiple decisions before those branches. One refactor is not evidence for banning all assignment expressions.

Scope: mailnews/base/src.
