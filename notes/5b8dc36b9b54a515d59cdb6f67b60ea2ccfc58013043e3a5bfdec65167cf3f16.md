# Check observers separately from preference metric lifetime metadata

Current mail boolean and integer probes use application lifetime and register an observer to update changed values. Current calendar preference reporting runs in reportPreferences, but registerPrefObservers checks only the mail boolean and integer arrays. Do not claim every calendar preference updates live merely because metadata lists it. The integer probe stores current getIntPref values via labeled string set, not event increments.

Scope: preference-telemetry.
