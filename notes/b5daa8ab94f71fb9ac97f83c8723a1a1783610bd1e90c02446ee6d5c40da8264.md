# Persist changed OAuth scopes even when the refresh token string stays the same

The prompt success path saves credentials if the token changed or the granted scope changed. setRefreshToken uses oauth.scope ?? this._scope for the login realm and preserves origin and username matching. Scope-only changes therefore reach persistent login state. Keep both conditions when refactoring credential updates; saving only rotated token strings can leave stale permissions.

Scope: mailnews/base/src.
