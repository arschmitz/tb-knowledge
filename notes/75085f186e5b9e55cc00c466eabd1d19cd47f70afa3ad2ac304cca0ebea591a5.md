# Name a logging constant as the environment-variable name it stores

D231690 review notes that ENV_LOG_NETWORK_PAYLOADS could be read as the actual environment-variable spelling and suggests LOG_NETWORK_PAYLOADS_ENV_VAR. The separate D231805 landing and fixed shared sender use that name for the string THUNDERBIRD_LOG_NETWORK_PAYLOADS, with a comment that no specific value is required. The actual gate is env::var(...).is_ok(), not a true/false parser. This is a scoped naming and reason-comment example; the separate preference for fully qualified std::env was rebutted and not applied. No logging runtime was executed.

Scope: Exchange protocol logging constant naming.
