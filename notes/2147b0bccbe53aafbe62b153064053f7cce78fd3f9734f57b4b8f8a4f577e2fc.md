# Cloud attachment names are serialized separately and can replace the listed placeholder name

The producer writes the real cloud attachment name as an RFC2231 header parameter beside its URL. The listing helper decodes that parameter and adds name only when it is nonempty. convertAttachment spreads those entries after the MIME placeholder name, so the real name wins when available and the placeholder remains otherwise. The test asserts the decoded checkmark filename. This is a metadata round-trip contract, not proof of remote-file fetching, header safety for every input or a live API run.

Scope: Cloud attachment name header and API consumer.
