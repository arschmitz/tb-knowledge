# Count real messages rather than group header rows

nsMsgGroupView routes totalCol for grouped-by-sort through the group and NumRealChildren. nsMsgGroupThread subtracts a synthetic dummy root from m_keys.Length. A dummy header represents a grouping bucket, not an extra message; non-dummy group roots still need the group total.

Scope: mailnews/base/src.
