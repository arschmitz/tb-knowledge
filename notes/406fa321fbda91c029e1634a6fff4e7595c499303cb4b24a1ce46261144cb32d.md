# Graph copy dispatch returns before the asynchronous copy result

The bridge now owns copy arguments and the listener, spawns a detached copy_messages task and returns Ok for dispatch. The operation builds one copy POST per source message, extracts returned IDs and reports legacy fallback when returned count differs from input count. Shared numeric ordering and native indexed mapping are covered by the reused batching lesson. Dispatch success is not server-copy completion or full response-ID validation. The helper's Moves/message-move doc remains stale beside the actual copy endpoint.

Scope: Graph native bridge and message copy operation.
