# Header sync completion and offline-body completion are separate Exchange events

New-header sync schedules filtering and notifies AutoSync state of local keys before its FolderLoaded/caller completion. Background body downloads finish later through the offline fetch callback, which releases the folder semaphore and notifies the manager. Keep these completion boundaries distinct. Fixed code adds later Graph and filtering hooks; they are not evidence that this first integration waited for all filters or downloaded every body. No sync or download ran.

Scope: Exchange new-header AutoSync queue and offline dispatch.
