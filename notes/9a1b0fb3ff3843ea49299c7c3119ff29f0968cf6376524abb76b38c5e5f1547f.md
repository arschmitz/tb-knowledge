# Silent key refresh does not accept a new email identity

The explicit unverified-import test accepts a newly added identity on the same key. The separate silent-refresh test starts with rejected, unverified or verified acceptance, imports updated bytes non-interactively, and asserts that the new email remains undecided. These are different user-intent boundaries. A successful import or finding the key without the acceptance filter does not establish recipient-key acceptance. The existing import/acceptance lesson supplies the base policy; these direct tests add the refresh boundary. Public key fixture text was read but not cryptographically decoded or executed.

Scope: OpenPGP identity acceptance.
