# Mbox scanning retains itself until the final stop callback and owns each pump stream

The scanner retains a self reference for a nonempty scan, uses RefPtr for the mbox input stream passed to the next pump, propagates a pump/start-next failure into final status and clears the self reference only after OnStopScan. Scoped C++ lifetime recommendation in this asynchronous scanner: retain objects across callback-driven progress and release them at the actual final callback boundary, not merely at the commit notification. This is static ownership inspection. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: mbox scanner asynchronous lifetime.
