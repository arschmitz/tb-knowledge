# Check both output length and consumed input in IMAP UTF-7 conversion

An IMAP UTF-7 conversion loop must reject invalid output length and calls that consume no input. Without the consumed-input check, conversion can stop making progress while input remains, causing a hang or bad output.

Scope: imap.
