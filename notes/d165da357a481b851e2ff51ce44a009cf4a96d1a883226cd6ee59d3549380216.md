# The Graph generator keeps concrete operations while building nested module exports

Supported Graph API paths become nested Rust modules. The hierarchy records concrete nodes, walks their ancestors and deduplicates/sorts child exports. Concrete path modules retain their operations and gain child exports; unsupported ancestors receive export-only files. Type generation separately combines direct schema modules and namespace children. The fixed hierarchy file has the owned blob. Four new unit tests assert paths and export structure, but their 12 assertions omit expected-behavior messages. No generator or Rust test ran; later enum/type-generation changes remain separate.

Scope: Graph Rust extraction module hierarchy.
