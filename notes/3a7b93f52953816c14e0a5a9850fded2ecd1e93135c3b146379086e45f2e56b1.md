# Use the value from a for-of loop as the backend contract

Both historical and accepted test_virtualFolders4 iterate the storage contract strings with for-of but index pluggableStores[store] when setting the preference. That lookup is undefined because store is already the contract string. The test intent is both mbox and Maildir, but this source does not establish that the two intended stores are selected. Proposed manual syntax rule for this test family: name value loops clearly and use the value directly; an indexed loop must explicitly provide an index. Gecko preference conversion and actual test execution remain unverified. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/base/test.
