# Composer toolbar colors belong to the shared app theme

The accepted shared composer stylesheet gives MsgHeadersToolbar and FormatToolbox the same layout background/text tokens and color-scheme: light-dark. The Linux calendar toolbar inherits its parent colors, with background inheritance scoped to a root without a theme image. Preserve theme-image and root theme overrides when consolidating platform CSS. This landing supports a manual preference for shared semantic tokens in these toolbars; it does not justify a project-wide ban on system colors. Contrast, forced colors and native controls still need runtime checks.

Scope: compose-theme.
