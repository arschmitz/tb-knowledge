# Shared Move and Copy menus own their Fluent resources and dynamic folder argument

Move Again chooses its Fluent ID from the stored move/copy preference and supplies the destination's localizedName as folderName. Its tooltip still uses the folder path and account name. Recent/Favorites submenu IDs are supplied by folder-menupopup rather than caller label attributes, so filter target pickers add messenger.ftl to the owning document before creating the popup. The original IDs carried access keys; fixed accepted source has later no-accesskey variants. No keyboard or rendered localization result was tested.

Scope: Folder menu localization.
