# The S/MIME PKCS12 test helper fails setup on a nonzero import result

SmimeUtils.loadCertificateAndKey takes a File and password, calls importPKCS12File synchronously and throws Error with the code on a nonzero result. The separate PEM helper does not add this check. This is a test setup failure boundary, not verified NSS internals or production password-logging guidance. The original was backed out; accepted code contains the check again.

Scope: S/MIME fixture setup.
