# Separate imported module bindings from mutable fixtures in extension xpcshell tests

The 2126 patch uses var for system-module imports and let gServer/gSubFolders for host fixture state assigned during setup. The toolbar file registers XPI files and update JSON on that same gServer. It also changes a local FileReader binding to const and keeps named test tasks. These are different roles within this harness, not a production-wide var or naming rule. The review summary alternates between global functions and variables; the actual declarations establish the narrower practice. Current script/test configuration and source retain these distinctions, but no lint result is claimed.

Scope: Extension xpcshell test lifecycle and binding roles.
