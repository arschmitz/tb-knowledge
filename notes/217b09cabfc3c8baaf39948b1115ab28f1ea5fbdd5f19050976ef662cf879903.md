# Layout color tokens describe surface and text roles

Use the shared layout token family according to its documented role. layout-background-0 is the main page surface; background-1 is for center panes and secondary sidebars; background-2 is for primary sidebars. Higher levels cover content blocks and elements. layout-color levels vary text emphasis. layout-border-0 separates main layout sections, while border-1 separates parts of an element. These semantic roles are a manual style convention beyond formatting. Keep widget-specific colors in the widget token family. Inspect the current contrast override before copying a normal theme value: some background levels become transparent and text values become system colors or currentColor. This is a convention for mail/themes/shared/mail/layout.css and its consumers, not a universal color-number policy.

Scope: style/semantic-theme-tokens.
