# storeObserver needs explicit initial application and disposal, and compares selected results

The mixin receives selectors in its constructor, subscribes immediately and leaves initial application to the subclass after setup. It compares each selected result with the cached result using strict equality; it does not notify on every dispatch or deeply watch a retained object. dispose releases the subscription. The inspected selectValue method computes the selector directly because !args does not detect an empty rest array. The test checks initial/later values but does not assert behavior after disposal.

Scope: state/store-observer.
