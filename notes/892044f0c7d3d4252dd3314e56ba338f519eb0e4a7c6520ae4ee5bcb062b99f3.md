# EWS create completion has different local owners in the migration and accepted code

The owned DoCreateMessage migration still populates the local header and sends its new key before returning operation success. Accepted code instead returns the remote ID to OnRemoteCreateFinished, where MessageCreateHandler performs local parse, database attachment and storage work. A local create error leaves the server copy in place. Failure to save the offline copy after database commit is logged while the database message remains successful. Keep remote creation, database creation, offline storage and success-callback errors separate. No save or failure test ran.

Scope: EWS remote and local message creation.
