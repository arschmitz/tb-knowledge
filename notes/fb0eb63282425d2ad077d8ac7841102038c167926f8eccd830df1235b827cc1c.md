# Shared mail browser setup clears persisted compose and message-window state

The shared browser head removes both compose and message-window documents from xulStore during add_setup. Its reason comment names leaked position and size from earlier tests. The fixed accepted setup retains both calls. This resets persisted window state for tests using the head; it is not a production-window change or proof that the reported intermittent timeout is fixed.

Scope: mail/base/test/browser.
