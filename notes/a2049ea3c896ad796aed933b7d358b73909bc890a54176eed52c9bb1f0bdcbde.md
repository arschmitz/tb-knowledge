# Use message store prose when no actual symbol is being named

D228378 discusses ambiguity in the word store. The reviewer suggests msgStore; the author chooses message store for human-readable documentation, reserving identifier-like spelling for real symbols. The actual channel comment names the message store and explains the listener/request roles. This is a scoped terminology example, not a ban on exact interface or variable names when needed. No runtime validation accompanies the comment choice.
