# Graph transparent fields move validation to decoding and explicit required checks

This landing replaces raw JSON-map getters with owned public fields generated from schema flags. Serde decodes the associated response type before the bridge reads those fields, and the new Required helper turns an absent or null required value into a Processing error. These are separate boundaries: invalid typed input can fail decoding, while a successfully decoded object can still omit an id. The folder-creation consumer requires that id; Required does not reject a present empty string. This is scoped source behavior, not a guarantee that every Graph endpoint or provider succeeds.

Scope: Graph typed response and bridge contracts.
