# The fake EWS folder-move response discards its filter result

The filter callback catches reparenting failures and returns false, but its result is not assigned. The response builder still receives the original folderIds array. The same narrow behavior remains in the fixed accepted source. This is a concrete lost-result and readability finding in a mock action loop, not a general prohibition on array filter or a claim about the response body for every failure.

Scope: EWS mock response filtering and action loops.
