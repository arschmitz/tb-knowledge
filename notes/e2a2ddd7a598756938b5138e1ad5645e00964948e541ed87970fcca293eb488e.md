# Calendar descriptions pass converted text or HTML through the shared fragment sanitizer

A truthy HTML description bypasses plain-text scanning; otherwise the converter scans phrases, glyphs and URLs and replaces newlines with br. Both paths reach parseFragment with flags that drop forms and media, using the target document base URI. The row replaces the browser body with that fragment. The original direct test expects a p element to remain and a button to be removed. These exact flags and one test assertion do not establish complete HTML or navigation safety, and later current tests differ. No parser or browser test ran.

Scope: Calendar description parsing and direct test boundary.
