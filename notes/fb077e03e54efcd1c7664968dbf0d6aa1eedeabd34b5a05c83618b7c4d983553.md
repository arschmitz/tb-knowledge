# Keep online-search charset selection with the encoded command

Online Encode determines whether string terms need a nonASCII charset, constructs local charsetParam and omits CHARSET for a UTF8-enabled folder. It passes the selected conversion charset to EncodeImap, then appends SEARCH, optional charset and terms after success. The historical cleanup inlines the old allocated helper into this caller. This is the selected encoder contract, not complete capability negotiation or an externally verified IMAP rule. No server/search test ran.

Scope: Online IMAP search charset construction.
