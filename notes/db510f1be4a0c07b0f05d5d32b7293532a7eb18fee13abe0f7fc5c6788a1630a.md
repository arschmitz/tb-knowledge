# Keep the NNTP generic-failure mapping separate from abort

The news callback changes every non-success result except NS_ERROR_ABORT to NS_ERROR_FAILURE with postFailed text. Fixed source retains that mapping using send-error-post-failed. The callback then enters the shared delivery presentation path. Abort bypasses this conversion. This is a deliberate result translation in the checked implementation, not proof that original news-specific failure results are preserved or that an NNTP send succeeded. Source only: Bug 783526 comment 14 is unavailable; reviews are unread. No runtime validation.

Scope: News-delivery result mapping.
