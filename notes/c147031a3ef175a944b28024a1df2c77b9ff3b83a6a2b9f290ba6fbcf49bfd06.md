# Provider alias matching preserves ordered attendee fallbacks

Scheduling support builds one map keyed by lowercase attendee ID and keeps the first attendee for duplicate keys. isInvitation rejects a matching organizer alias and accepts a matching attendee alias before its existing non-ACL/owner-identity checks. getInvitedAttendee preserves a resolved organizerId first, then ACL owner identities, then calendarUserAddresses in list order, and returns null on no match. The new memory-calendar test checks matching, absent, empty and organizer cases. It does not exercise CalDAV discovery or sending, whose first-address behavior remains separate.

Scope: Calendar scheduling support.
