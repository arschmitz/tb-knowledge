# Use template quotes for query selector strings in Calendar code

For new Calendar querySelector and querySelectorAll calls, use a backtick-delimited selector string. This keeps double quotes available for attribute values in the selector and makes literal selectors easier to find with global search. This is a newer local style request, so migrate related lines when touched.
