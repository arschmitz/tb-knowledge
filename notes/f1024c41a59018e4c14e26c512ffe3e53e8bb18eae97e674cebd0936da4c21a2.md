# Messenger session restoration and address-book document readiness are separate barriers

The async helper waits for mail-tabs-session-restored when it opens a new window whose document is incomplete or still the initial uncommitted document. Its producer explicitly reports restoration before all tabs finish loading. A caller or test that needs the address-book document must also wait for that specific tab's about-addressbook-ready event. Register the TabOpen waiter before the action and use its browser for the second event. Existing messenger windows do not pass through this new-window wait; no native initialization or close-path runtime guarantee is established.

Scope: Messenger window and address-book readiness.
