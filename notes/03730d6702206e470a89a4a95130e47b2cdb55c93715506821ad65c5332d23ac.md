# First-run detection gets visible accounts from the account-manager getter

The first-run predicate enumerates MailServices.accounts.accounts. Its actual getter excludes accounts whose server is hidden, so the unified-folder test can keep first-run true without an extra hidden check in the predicate. The account predicate also requires a valid server and either no identities or at least one valid identity. This is a static receiver contract, not a startup test result.

Scope: Account Hub first-run profile detection.
