# Graph move modules use plain file names and raw Rust identifiers

ModuleName stores a plain snake-case file segment and creates its Rust identifier separately. The move path uses move.rs on disk and r#move in exports and the actual Graph client. The generated request still targets /me/messages/{message_id}/move. Direct tests assert this file/identifier split; they do not prove every Rust keyword or arbitrary input works. This is a generator and caller contract, not a reason to hand-edit generated output or a general naming rule. No HTTP request or compiler was run.

Scope: Graph Rust module naming and move request consumer.
