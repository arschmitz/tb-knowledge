# Match the adapter class, module and test stem within Panorama

LiveViewDataAdapter is exported from LiveViewDataAdapter.mjs, with test_liveViewDataAdapter.js registered in xpcshell.toml and the module registered through jar.mn. This local pattern uses a class-case implementation filename and a lowerCamel test stem after test_. Follow that family for nearby adapters and include its packaging seam. It is not a mandate that all Thunderbird modules use this casing or the .mjs rather than .sys.mjs suffix. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama file and test naming.
