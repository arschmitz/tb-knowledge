# Shortcut menu accesskey support used a new Fluent ID and matching consumer variables

In the reviewed Search Messages migration, menuitem-shortcut-string becomes menuitem-shortcut-attributes when .accesskey is added. The consumer supplies label, accesskey and shortcut variables. The author questioned whether a variable-only addition required a rename; the reviewer explained older locale messages would lack the new attribute. The landed rename and consumer show the adopted decision. This is historical scoped evidence, not a check of every current locale or a general localization rewrite rule.

Scope: Shortcut menu localization.
