# Saved-search synchronous alerts follow the initialized count formatter

The saved-search dialog creates a lazy Localization for virtualFolderProperties.ftl with synchronous mode true. Its normal onLoad path calls updateFoldersCount, which uses formatValueSync, before the user can accept the initialized dialog. onOK uses the same instance for the no-source alert, prevents acceptance and returns. This is the checked local ordering behind the author’s qualified earlier-call rationale. It does not establish arbitrary-call safety, engine cache behavior or a general synchronous-localization rule.

Scope: Saved-search properties localization ordering.
