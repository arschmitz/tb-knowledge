# Separate notification integration assertions from external-browser execution

The in-app notification end-to-end test serves a local fixture and checks banner content, a content-tab URL and an external-browser dispatch in one ordered sequence. External opening is intercepted by MockExternalProtocolService, so its awaited URL assertion proves the requested dispatch in the test, not launch of a real external browser. Distinct severities exercise one ordering case; start-time and probability tie-breaks remain separate. The current opener can fall back from a requested tab to an external browser when no tabmail is available. The source was read, but no test or native browser launch ran in this study.

Scope: In-app notification integration-test boundaries.
