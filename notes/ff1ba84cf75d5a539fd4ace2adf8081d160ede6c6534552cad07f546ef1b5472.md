# The folder-name preference leaves Inbox and local-folder exceptions

At the fixed accepted revision, mail.useLocalizedFolderNames defaults to true and is mirrored once. The remote getter localizes a folder with the Inbox flag and native name inbox before checking that startup value. When the value is false, other remote names fall back to the native name. With the value true, most special folders need a recognized name and matching flag; AllMail uses its flag alone. The local override ignores this preference and checks a narrower canonical-name map. These are specific getter boundaries, not a general rule for every folder or a collision policy.

Scope: mailnews folder names.
