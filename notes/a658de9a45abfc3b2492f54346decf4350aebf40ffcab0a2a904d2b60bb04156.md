# The Calendar date row formats attributes; its parent supplies event dates and clears recurrence

Entry2131 introduces a display row that formats start-date/end-date attributes using Intl.DateTimeFormat with short time and medium date. The repeats attribute supplies the recurrence tooltip and controls its visibility. The landing itself does not read calIItemBase. Fixed0b93 parent dialog converts event dates to ISO attributes and removes repeats when switching to a nonrepeating event. The added standalone test uses the same formatter/options and checks recurrence visibility/title; it does not prove locale, all-day or timezone correctness. No runtime or accessibility test ran.

Scope: Calendar read-dialog date row.
