# The recurrence test helper owns closing after its callback completes

For custom recurrence, the shared helper waits for the recurrence window, awaits data.repeat(recurrenceWindow), then clicks Accept. Callbacks edit recurrence state without independently closing the dialog. menulistSelect separately verifies active-window, enabled/popup state and the selected value. The retained500ms delay is a reported workaround, not evidence all asynchronous work completed. The tracker was reopened after later failures, and no test ran here.
