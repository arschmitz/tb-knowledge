# Omit absent extension output fields instead of filling them with null

The implementation follows optional schema fields by adding them only when they have a value. ext-folders.getFolderInfo omits quota when no quota exists; ext-compose omits unavailable deliveryFormat and relatedMessageId; ext-mailTabs omits unavailable sortType and sortOrder. Browser tests changed expectations from null to undefined. This makes runtime results match the public schema and generated types. The later D209203 follow-up specifically corrects subFolders for Manifest V3; do not infer that every old null can change in Manifest V2.

Scope: WebExtension output objects.
