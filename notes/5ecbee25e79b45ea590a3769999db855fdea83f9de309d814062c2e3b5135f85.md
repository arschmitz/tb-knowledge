# about:support add-on table columns must change in both renderer and markup

Entry 2076 adds addon.locationName immediately before addon.id in aboutSupport.js and adds support-addons-location-name at the same position in the table header. The fixed accepted source retains the pair. Keep emitted cell order and localized header order aligned; otherwise troubleshooting data would appear under the wrong name. Native table elements provide the structural starting point, but source alignment does not prove computed screen-reader associations, long localized labels or copy/export layout. No tests changed or ran. The deleted commented features formatter was explicitly unused Thunderbird code, not a lost active output.
