# When an upstream CSS utility disappears, keep dependent Thunderbird UI working and track its removal

An upstream toolkit change removed .plain from global-shared.css, but Thunderbird still used it for several buttons and panels. The 2024 fix defined the class in messenger.css and adjusted the OpenPGP key-details button spacing. In D210267 the author warned that some .plain users might not import messenger.css; reviewer asked for a TODO to remove the temporary utility, and the landed change added it. The current messenger.css still has .plain and the TODO, while current markup and scripts still use the class. A moved shared style must be checked against each document that imports it; a local bridge should state the intended cleanup.
