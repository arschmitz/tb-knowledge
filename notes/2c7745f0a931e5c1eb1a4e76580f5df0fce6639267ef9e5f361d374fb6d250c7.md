# Keep refresh interval zero distinct from an unset interval

Current properties dialog uses null to choose the default 30 minutes, zero to select Manual, standard values for generated items, and an extra item for a custom configured value. Do not use a falsy default that turns zero into 30. This is a syntax/behavior contract for this preference, not a rule that every unset number uses null.

Scope: calendar/base/content/dialogs.
