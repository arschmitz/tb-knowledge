# Guard Save results against session replacement

The Bug 2061214 implementation report describes separate checks for create mode, draft identity, and request identity so Save affects only its originating session. It also reports guards against delayed success or failure changing a replacement create or edit session. When extending this controller, retain both duplicate-write protection and stale-result protection; disabling the Save button alone does not establish either guarantee. Minimum test coverage: replace the session while Save is pending, then deliver both success and failure results and check that the replacement remains unchanged. This is reported behavior, not independently confirmed runtime validation.

Scope: Calendar event create Save session ownership.
