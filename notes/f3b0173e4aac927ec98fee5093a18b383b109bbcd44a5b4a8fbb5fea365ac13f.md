# Wait for the scheduled notification event and clean up the timer

The notification unit test installs NEW_NOTIFICATION_EVENT waiting before updating the async cache, checks that a timer exists, waits for the selected payload, checks the elapsed lower bound, and clears notifications. Test cleanup also clears the timer. Keep the action-to-event and cleanup order when adding scheduled-notification cases. The inspected case has one future notification; it does not independently cover timer replacement, several equal start times, large delays or an expiring current notice. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Scheduled notification test lifecycle.
