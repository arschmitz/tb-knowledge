# The compactor’s error-code type boundary can justify if chains rather than switch

Accepted BatchCompactor uses equality-based if/else handling and comments that NS_MSG_ codes are not actually nsresult constants suitable for the switch here. Preserve this local type constraint if refactoring status handling. This is an explanation of the component’s accepted code and comment, not a project-wide syntax preference; the referenced Bug 1927029 discussion was not read.
