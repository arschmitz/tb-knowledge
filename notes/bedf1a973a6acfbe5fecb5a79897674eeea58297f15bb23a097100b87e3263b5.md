# Manifest extension scripts use extension shutdown rather than parent-context cleanup

Dynamic ExtensionScriptParent registrations retain the parent context and close hooks. Manifest entries instead create a minimal context from the Extension and register an extension-close callback that deletes their entries from the shared scripts Set. That callback does not call destroy. Injection awaits CSS then JavaScript before its completion event. New tests cover injection, not shutdown or rejected/in-flight work.

Scope: extension-script lifecycle.
