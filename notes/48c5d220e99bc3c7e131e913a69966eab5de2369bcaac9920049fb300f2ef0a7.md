# Keep mailnews PromiseTestUtils separate from the harness namespace

The 2125 review explains that mailnews and Gecko export different PromiseTestUtils modules with different methods. The landed import alias is MailPromiseTestUtils; promiseFolderAdded and PromiseUrlListener call that alias. A reviewer suggests renaming the module file, but the selected fixed path remains mailnews/PromiseTestUtils.sys.mjs. Preserve the actual module and receiver contract instead of inferring a file rename from acceptance. PromiseUrlListener resolves only on NS_OK and rejects otherwise; the local FolderLoaded helper has a different completion boundary. This is a scoped test namespace distinction. No runtime or rejection test ran.

Scope: Extension test promise utility namespace.
