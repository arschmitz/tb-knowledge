# Name an account-setup action independently of its display container

The rename in 1170 removes Tab from the entry-point name as the action can use a hub dialog. Accepted menu, Account Settings and Account Central calls still use openAccountSetup. Scoped naming recommendation: name this shared action by the user task, and update every script and markup caller when its name changes. Do not assume that Tab-named helpers elsewhere are wrong when their actual contract requires a tab. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mailnews/base/prefs.
