# Use readable date fixtures while keeping their storage units explicit

Panorama fixtures use human-readable date strings and SQL UNIXEPOCH expressions instead of opaque precomputed timestamps. The JavaScript helper multiplies milliseconds by 1000; SQL multiplies seconds by 1000000. Timed SQL fixtures include an explicit Z. Follow this local fixture pattern so reviewers can see the date and unit conversion together; the older microsecond-to-JavaScript display conversion lesson remains separate. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama date fixture notation.
