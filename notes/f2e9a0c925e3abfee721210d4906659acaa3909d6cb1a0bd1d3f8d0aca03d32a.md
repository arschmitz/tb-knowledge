# A Graph component contract ID is distinct from the constructor interface ID

The Graph component entry maps @mozilla.org/messenger/graph-client;1 to NS_CreateGraphClient. The exported constructor takes REFNSIID aIID and void** aResult; the Rust export likewise accepts an interface ID and result pointer. Keep the lookup contract string separate from those constructor arguments. The historical review reply about passing a contract ID does not describe the checked signature. No direct constructor call or component runtime was executed.

Scope: Graph XPCOM component lookup and constructor boundary.
