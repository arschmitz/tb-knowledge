# TreeSelection returns a tuple with a nullable slot rather than a nullable array

_findRangeContainingRow always returns a two-entry array. Its first slot is the containing-range index or null, and its second slot is the insertion index. adjustSelection destructures both and checks iContain != null, so index0 remains valid. The accepted ?number[] annotation does not precisely state the nullable-slot contract. Check the actual result and caller when refining this JSDoc; do not infer that the function returns null. Static inspection only; no selection test ran.

Scope: Mail tree selection range adjustment.
