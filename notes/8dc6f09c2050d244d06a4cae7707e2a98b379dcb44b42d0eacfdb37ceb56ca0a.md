# The policy-free credential test message names the opposite setup

testNoPrimaryPasswordPolicyRememberPasswordSaves and its comment identify a case without the PrimaryPassword policy. Its first assertion checks that removeMasterPassword is allowed but the message says with PrimaryPassword policy. Change that condition to without so a failure describes the actual setup and expected permission. The test source separately installs the policy in its second task and expects removal to be disallowed. This is a scoped diagnostic defect, not a missing-should-only style report or an executed test failure.

Scope: Account-creation policy assertion diagnostics.
