# Show Full Path refreshes compact-mode availability when the folder menu opens

Show Full Path is available only when compact display is enabled and an active mode supports compact rows. Mode changes and compact commands update availability; opening the menu also refreshes its checked and enabled state. The command persists the visibility option and recalculates rows. Only both-style visible folder-and-server names use that choice; fullName keeps the full path for the separate accessible-label path. This is a scoped source contract, not a UI or screen-reader test result.

Scope: Compact folder-pane full-path option.
