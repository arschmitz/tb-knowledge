# Plain Enter adds a filter criterion and cancels default dialog acceptance

The search-value widget forwards Return keypress to Filter Editor. Modified Enter accepts the dialog, while plain Enter calls onMore to insert a criterion and then prevents the default dialog action. This repairs unintended dialog closure; it does not validate empty starts-with or ends-with values. The original test executes the sequence without a new direct assertion, while later source adds remove-button state checks. No keyboard or filter test ran.

Scope: Filter Editor keyboard event contract.
