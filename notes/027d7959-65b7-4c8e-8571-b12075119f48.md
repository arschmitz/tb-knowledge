# Protect the active quick-filter text field from extension writes

At the May 2024 quick-filter API revision, overrideSearchTerm refuses to replace a nonempty search input while the user is typing in the shadow DOM field. Callers must honor its boolean result and preserve the old search term when it returns false.

Scope: quick filter bar.
