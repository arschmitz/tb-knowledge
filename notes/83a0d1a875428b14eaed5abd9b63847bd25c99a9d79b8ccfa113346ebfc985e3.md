# The chunked IMAP test uses the UID returned by its inserted fake message

This landing returns msg.uid from the fake insertion helper and uses that UID in the direct-stream URI instead of #1. The concrete fake message stores its allocated UID and the mailbox preserves it. The message service parses the URI fragment and builds fetch>UID, while still using folder metadata/cache; the new comment about bypassing the folder entirely is broader than that actual receiver path. Direct assertions compare normalized streamed text and length, not channel.contentLength or attachment parts. No assertion changes or runtime test is claimed, and fixture identity does not grant an unrelated MIME or key-mapping audit.

Scope: IMAP chunked-stream unit tests.
