# Keep temporary database filenames tied to the owning compaction phase

Current FolderCompactor appends .compacting, .compacted and .original to the source summary name inside its temp directory. Proposed scoped naming recommendation: preserve these distinct phase suffixes and their associated paths when changing the temporary database flow; they are not file extensions for different database formats. This note concerns naming and the OpenDBFromFile caller only, with no new atomic-pair or crash-recovery guarantee. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: compaction file naming.
