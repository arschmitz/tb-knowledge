# Account Hub widget filenames and element tags use hyphens while classes use PascalCase

Three inspected widget pairs use matching hyphenated module basenames and custom-element tags: address-book-local-form, address-book-remote-account-form and address-book-option-select. Their JavaScript classes are AddressBookLocalForm, AddressBookRemoteAccountForm and AddressBookOptionSelect. Keep those roles distinct when following this component family. LocalAddressBookConfig is a type name; addressBookName and localAddressBookForm are selector names, not module basenames. This is supported local naming practice from exact accepted source, not a rule for every Thunderbird module, DOM ID or CSS class. Full assigned review remains pending; no external names were changed.

Scope: Account Hub address-book widget naming.
