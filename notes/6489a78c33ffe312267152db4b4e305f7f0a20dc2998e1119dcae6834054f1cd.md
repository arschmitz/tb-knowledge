# Keep privacy search keywords distinct from the localized control label

The Fluent GPC search message includes the platform name and abbreviation and has an explicit do-not-translate comment. The checkbox label describes the user action and exposes an access key; markup supplies search-l10n-ids separately. Preserve this intentional untranslated technical search term instead of showing an acronym-only label. Current text says Ask websites, not the original Tell websites; no legal or network guarantee is inferred. This is static source evidence. No runtime, build, lint or live accessibility check was run.
