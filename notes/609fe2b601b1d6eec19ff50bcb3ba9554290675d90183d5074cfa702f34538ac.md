# Message-command read tests wait for idle after the context menu closes

Entry 2064 replaces two TestUtils.waitForTick calls in mark_read_via_menu with an awaited window.requestIdleCallback. The helper first waits for menu shown, selects the read/unread action and waits for menu hidden. The fixed accepted source retains the idle wait. The commit title describes a third attempt to resolve an intermittent unread assertion; the diff does not establish its cause or prove the attempt succeeded. For new tests, prefer an observable expected state where available. An idle callback is this helper’s accepted scheduling boundary, not a guarantee that arbitrary asynchronous work finished. No local browser run; external context remains pending.

Scope: mail folder-display browser message commands.
