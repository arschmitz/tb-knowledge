# Card line height and virtual row geometry must change together

Entry 696 changes both CSS line-height and the JavaScript card-height coefficient to 1.5. Current CSS keeps 1.5 for fixed and dynamic card rows. Current densityChange multiplies that coefficient by this.rowCount and font size, then adds density-specific gaps and padding. The generic tree uses ROW_HEIGHT for spacers, row styles and scrolling, so a CSS-only line-height change can leave virtual geometry inconsistent. Manual layout proposal for this path: update and test the paired CSS and virtual-row calculation across supported row counts, font sizes and densities. The historical fixed three-row formula is no longer the full current formula. No pixel, overlap or scrolling measurement was executed.

Scope: thread-card-geometry.
