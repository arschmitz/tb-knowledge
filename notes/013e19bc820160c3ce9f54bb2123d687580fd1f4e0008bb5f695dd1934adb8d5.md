# Folder reconciliation consumes a complete expected child-name list

Reconcile deletes existing children absent from childNames and inserts missing names. Passing a partial update list would remove other real children and their descendants. Current code additionally preserves virtual folders; its actual caller passes the discovered child list from the store. Treat this input as a snapshot, not a notification delta. The current source also contains a TODO questioning this deletion policy, so the observed algorithm is not a permanent architecture recommendation. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama folder reconciliation.
