# Attach copy and folder-notification waits before starting the copy

The quarantine filter test registers both its copy listener and msgsMoveCopyCompleted promise before calling copyMessages, then awaits both. These are different completion signals. Use that order for nearby asynchronous folder tests so an early notification cannot be missed; a copy callback alone is not automatically proof of the folder notification or readable destination content. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Folder copy test listener ordering.
