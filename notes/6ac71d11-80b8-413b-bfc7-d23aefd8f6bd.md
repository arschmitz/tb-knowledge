# Recheck upstream state before relanding a ported toolchain change

Bug 1891452 and D210554 show the accepted Clang 18 port was backed out after a mozilla-central regression caused build failure. It was relanded, then backed out again when upstream reverted the source patch, and finally landed again with the upstream state aligned. Thunderbird Taskcluster toolchain jobs reference upstream compiler jobs. Before relanding a port after a failure, check the matching mozilla-central revision and actual build result; an earlier accepted review is not proof that the upstream dependency still exists. This is a history lesson from the 2024 port, not a claim that Clang 18 is current.

Scope: Taskcluster toolchains.
