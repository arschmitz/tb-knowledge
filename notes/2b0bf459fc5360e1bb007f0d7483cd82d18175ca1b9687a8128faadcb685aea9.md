# The OAuth close script hash is repeated in template and response policies

The result template calls window.close and both CSP locations name the hash of that exact inline body. Static source hashing matches at the owned and fixed revisions, including whitespace. The generator uses the same template for success and error pages. Matching literals do not prove DOM serialization, browser permission to close a tab or a successful external OAuth flow.

Scope: OAuth result-page inline script.
