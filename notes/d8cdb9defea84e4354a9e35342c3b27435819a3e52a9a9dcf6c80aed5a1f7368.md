# The Ubuntu test migration updates aliases, mappings and the default image together

Ubuntu and x64 Try aliases retain linux64 names and replace linux1804 test prefixes with linux2404. The parser expands those prefixes; the direct test expects four gtest platform names. Test-platform YAML still maps linux2404 variants to linux64 build platforms, while the test-kind image becomes ubuntu2404-test. These names serve different roles. The changed parser test does not prove that a VM, container or whole task graph ran.

Scope: Taskgraph Linux platform selection.
