# No-password EWS send tests reset the outgoing cache separately from saved logins

The owned test repair clears the login manager and then assigns an empty password to the EWS outgoing server in both no-credential helpers. The outgoing setter writes the password-auth module cache, so clearing saved logins and clearing this cache are distinct test actions. The fixed accepted tests later centralize the reset and also clear HTTP authentication state. Their assertions check prompt completion, saved-login state and the sent subject; they do not directly assert a leak or shutdown cure.

Scope: Compose outgoing-password test isolation.
