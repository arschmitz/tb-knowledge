# List-reply display-name suppression applies to the collected recipient set

Accepted _collectAddressesToAddressBook blanks displayName for every collected address when the composition type is ReplyToList, or for an address whose name includes the case-sensitive literal " via ". It still collects the email address. The test sends through its SMTP mock and checks a blank collected displayName; the code is a heuristic and does not recognize every possible mailing-list label. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/compose/src.
