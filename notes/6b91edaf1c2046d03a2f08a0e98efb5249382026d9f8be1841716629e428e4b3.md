# Document precedence when adding a test-generator option

Manual documentation proposal: an optional fixture argument must say when an existing argument overrides it. MessageGenerator documents that date is ignored when age is given, and the implementation evaluates age first. Selection tests use explicit dates to place new messages relative to old ones. Preserve that precedence when extending this generator; do not infer that all optional Date fields in Thunderbird behave the same way. The nearby age JSDoc calls a dictionary number, so its type annotation is not reliable proof of the value shape.

Scope: test-support.
