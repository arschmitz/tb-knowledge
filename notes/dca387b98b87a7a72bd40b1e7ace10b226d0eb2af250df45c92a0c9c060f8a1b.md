# EWS header reconstruction supplements InternetMessageHeaders with structured fields

extract_headers synthesizes core fields from structured EWS data because InternetMessageHeaders can omit addresses or be absent. It discards an internet entry only when the core map has the exact same name and value; case variants and differing values remain, and missing text becomes empty. The original collector is preparatory and unused. Accepted source later calls it during sync and shares HeaderBlock, which is a separate phase. Wishlist comments do not establish tests.

Scope: ews-header-block.
