# Inspect initializers before treating a const global as constant initialization

In the accepted Windows search helper, sRegKeys is a const array of const RegKey pointers but its elements use new RegKey and the declaration retains MOZ_RUNINIT. Its consumer writes these registry values. Scoped review recommendation: inspect the actual initializer and platform build, rather than deciding from const alone whether runtime initialization can be removed. No compiler or registry operation was run. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/search.
