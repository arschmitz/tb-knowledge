# A folder flag change refreshes every matching row name as well as its type

FolderFlag notifications update active folder modes, then update folder type and names for every row with the folder URI. Names include abbreviated/localized folder text and full path; special remote-folder flags can affect localization. Row name style also updates fullName for the scheduled ARIA label. Local-folder naming has its own override. This is a scoped UI synchronization contract, not a generic rename rule or live accessibility proof. No runtime tests.

Scope: folder-pane-row-state.
