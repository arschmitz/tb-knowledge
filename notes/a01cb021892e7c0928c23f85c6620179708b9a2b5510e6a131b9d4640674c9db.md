# Keep message date units separate from display text

The database fixture helper supplies microseconds with a millisecond Date value multiplied by 1000. Native message conversion divides PRTime by PR_USEC_PER_MSEC to make a JavaScript Date. The row keeps formatted date text separately from message.date.valueOf numeric sort data. Preserve those unit boundaries; a localized date string is not the stored timestamp or a safe numeric sorting key. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama date representation.
