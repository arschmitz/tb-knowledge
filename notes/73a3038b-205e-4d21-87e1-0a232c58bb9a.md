# Complex OpenPGP expiry changes one chosen key component

Treat a primary key and its subkeys as components with independent expiry when the key structure is complex. A user may intentionally leave a retired subkey expired; changing all components could revive it. Simple mode may change the primary and its single similarly-expiring subkey together. Complex mode changes the selected component. Thunderbird keyring changes are separate from external GnuPG edits. The current dialog delegates modification to RNP.changeKeyExpiration. Do not reproduce the old dialog-local fingerprint implementation. Commit 262 added no automated test; manual checks were reported in review.

Scope: OpenPGP expiry.
