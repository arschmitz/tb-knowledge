# Calendar fixture dates and timeout budgets need separate evidence

The date follow-up hardcodes a fixture base and derives start/end and offsets from it. The longer timeout is deliberately left out of that landing, then added in a separate follow-up after more failures. Later fixed source uses new Date() again. These are different changes with different evidence; neither a historical fixed date nor a larger budget proves a timezone or intermittent cure. Preserve current Calendar UTC guidance and inspect the actual harness date contract. No test ran.

Scope: Scoped source study.
