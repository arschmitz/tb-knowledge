# The Linux CCov timeout mapping preserves both platform-name forms

The xpcshell timeout mapping keeps factor 4 for linux1804-64-ccov-qr/opt and adds factor 4 for linux.*64-ccov/opt. The accepted Linux 24.04 CCov platform is named without -qr and includes xpcshell tests. These exact keys explain the intended selection repair. The source does not establish a resolved task graph, test duration or a general timeout policy.

Scope: taskcluster/xpcshell-platform-timeout-config.
