# Use narrow weekday text with full accessible names and stable date attributes

The minimonth uses narrowWeekdayNames for its short header text and weekdayNames for aria-label. It stores numeric year/month attributes separately from formatted visible values; CalendarTestUtils reads those attributes. Month-view day cells use formatDateOnly or a date without year and set a full date aria-label. Keep the concise display, full accessible name and machine date representation distinct. Static attributes do not prove screen-reader output, keyboard movement or translated layout. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: calendar/minimonth/label-state-contracts.
