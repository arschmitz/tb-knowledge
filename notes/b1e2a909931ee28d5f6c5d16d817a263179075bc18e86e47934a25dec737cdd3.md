# The attachment reminder close control requests focus in the message area

A newly created attachment reminder attaches a click listener to its own shadow-root close control after appendNotification resolves. The listener calls focusMsgBody, whose actual implementation advances focus into messageArea. Other removal/update/toggle branches remain separate. The helper returns true without asserting activeElement or caret state, so this is a checked focus request rather than proof every cancellation or keyboard path succeeds. No compose or accessibility test ran.

Scope: Compose attachment-reminder dismissal focus.
