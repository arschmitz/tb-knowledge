# Choose a valid draft alternative before asserting a display closure

931 and 934 preserve MIME paths that may carry either display or draft data. In the accepted S/MIME UI-sink lookup, IsMimeDraftData selects nullptr instead of calling AsMimeStreamData on a valid draft closure. The display branch suppresses UI feedback for header=filter and header=attach. Do not make a debug assertion fire for a supported alternative type merely to reuse a display-only accessor. Background crypto processing is not automatically a UI transaction.

Scope: S/MIME closure variants and UI feedback.
