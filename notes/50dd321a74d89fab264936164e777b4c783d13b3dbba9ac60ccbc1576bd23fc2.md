# Erase the vacated bytes after unfolding message headers

ParseHeaders replaces folded line endings and whitespace with a single space and shifts subsequent bytes. It fills the vacated tail with NUL bytes. This prevents the old fragments from appearing as more filter headers when the parser walks the NUL-delimited buffer. This is a framing repair alongside bounded scanning, not evidence that every residual byte is required by every consumer. The review explicitly requested an explanation of why the tail is purged. No malformed-message parser test was added in this patch or executed by this study.

Scope: Header unfolding and filter breakage.
