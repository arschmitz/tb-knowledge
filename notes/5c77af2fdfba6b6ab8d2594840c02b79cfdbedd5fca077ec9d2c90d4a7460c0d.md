# Account Central telemetry classifies a query-free document and its containing widget

The listener removes the document query before matching its allowlist and maps the accountCentral root to account-central. Anchors join the shared interactive-tag list, so that tag change applies across eligible documents. Existing event guards still apply, and recording requires both widget id and source. Five fixture tasks assert ordered id arrays; they do not prove delivery or every source value.

Scope: Account Central UI interaction telemetry.
