# Graph enum generation replaces the importance object wrapper with wire strings

The enum landing splits supported objects from enums and generates a concrete Importance enum for low, normal and high. The original Message accessor parses a JSON string into that enum and the setter stores its displayed string, replacing the old object wrapper and string member. Generated variants use camelCase serde/display names. Later accepted Message fields expose Option<Importance> and no longer use that accessor or EnumString. Extraction-test equality does not establish wire round trips or an unknown-value fallback.

Scope: Thunderbird Microsoft Graph enum extraction and generated importance representation.
