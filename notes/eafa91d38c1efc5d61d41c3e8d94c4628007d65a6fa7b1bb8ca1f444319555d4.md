# Keep notification focus styling and decorative content separate

The template uses a native close button, a native CTA anchor, and an empty alt for its decorative icon. The accepted CSS supplies focus-visible styling for action controls and pointer-events:none for the icon; visually hidden instructions remain in the DOM with clipping instead of display:none. These are distinct semantic and visual roles. No accessible-name, focus order, announcement or axe run was performed.

Scope: Notification control accessibility source.
