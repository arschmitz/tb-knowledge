# Wait for virtualized-row layout before invoking its context menu

The changed mail-context test waits a frame after proving that the current row is outside the rendered tree. Current code also waits until an old row is detached, then checks that showing the context menu brings the selected index back into the viewport. One animation frame is a layout boundary, not a general asynchronous-completion guarantee. The present manifest excludes macOS; no intermittent was reproduced. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
