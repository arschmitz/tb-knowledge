# Notification action tests wait for the folder operation after an explicit click

The delete-action test waits for the alert, registers DeleteOrMoveMsgCompleted, explicitly invokes clickAlert(delete), and then checks that the source loses one message, Trash gains one, and the moved message has the expected ID and read state. The action marks the message read before calling deleteMessages. These assertions test the completed folder effect instead of treating a click or telemetry increment as success. The mock bypasses native notification UI. Historical Windows11 history checks are separate reports; no browser or IMAP test ran here.

Scope: Notification action tests.
