# Focusing a message window does not retarget the selection assertion

The message-window deletion task focuses msgc, but assert_selected_and_displayed(curMessage) supplies no Window. The helper contract requires a Window first to override default mc, and its argument processing resolves a lone message in that default view. This precondition assertion therefore does not directly check msgc. Later all-display checks remain separate; no deletion failure was reproduced.

Scope: Virtual-folder deletion tests.
