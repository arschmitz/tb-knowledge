# Removing a child must not remove a parent that still matches its pane mode

A moved child can lose its parent link before the folder notification runs. The unread-mode caller then revisits the old parent with childAlreadyGone=true. _removeFolderAndAncestors checks whether that parent still matches the mode before compact-mode removal. The regression scenario moves folderC out and back, checking both expanded and compact unread/favorite lists through an ordered URI deep-equality helper. Keep the matching parent distinct from a merely displayed ancestor. No folder UI test was executed.

Scope: Folder pane filtered ancestors.
