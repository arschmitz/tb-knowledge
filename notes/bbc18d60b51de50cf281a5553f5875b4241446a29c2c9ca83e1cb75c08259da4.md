# Split escaped URI path pieces before decoding their names

The current folder-path helper separates pieces before unescaping each one, so an escaped slash in a folder name cannot become a hierarchy separator before hashing. It adds .sbd only between folder levels and retains a news-specific modified UTF-7 conversion. The existing parseURI test explicitly skips test%2Ftest, so that test must not be cited as proof of the escaped-slash case. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
