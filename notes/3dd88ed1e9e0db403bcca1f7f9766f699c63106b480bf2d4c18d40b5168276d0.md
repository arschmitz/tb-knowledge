# Name templates and CSS according to their different roles

The custom-element guide uses Template ID: #myElementTemplate, myElementTemplate.inc.xhtml for included markup, and my-element.css matching the module/tag family. These different spellings identify a DOM ID, include file and stylesheet. Document the required template ID, import dependent custom elements in the owning module, and load the element’s stylesheet into its shadow root when it has one. Do not convert established DOM IDs to dash spelling merely to match CSS filenames. This is a historical documented convention; the guide was retired and no global naming consistency was proved.

Scope: Custom-element template and CSS naming.
