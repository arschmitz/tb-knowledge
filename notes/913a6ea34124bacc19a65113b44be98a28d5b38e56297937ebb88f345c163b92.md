# Panorama uses MOZ_TRY values in typed initializers and existing outputs

Accepted Panorama callers use MOZ_TRY as a value expression for typed local initialization and assignment to existing fields, references, pointers or traversal IDs. The port replaces separate declarations/MOZ_TRY_VAR calls, and some nsAutoCString locals become nsCString. The current flag modifier still reads flags, applies a mask, updates storage and then assigns its output. This is a scoped C++ call-site pattern, not proof of macro expansion, constructor counts, allocation cost or runtime equivalence. Upstream implementation remains unstudied; no compiler or test ran.

Scope: panorama-result-call-sites.
