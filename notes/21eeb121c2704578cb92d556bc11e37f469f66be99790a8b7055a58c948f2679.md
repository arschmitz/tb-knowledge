# MailGlue creates the IMAP service before normal UI startup to register its handler

MailGlue requests the IMAP protocol service during final-ui-startup, before folder/view string initialization and _beforeUIStartup. The component contract resolves to nsImapService, whose first construction registers the IMAP protocol handler with the IO service and initializes autosync. Thus the eager service call has a registration side effect. Session-restore motivation is retained from commit context; no restored PDF/tab or network behavior was executed.

Scope: imap-protocol-startup.
