# Folder notification failure can follow successful local callbacks

The nine nsMsgDBFolder notification methods call folder-local listeners before obtaining the global MailSession service. The crash guard returns NS_ERROR_FAILURE if that service is missing, so local callbacks may already have run while global callbacks do not run. The inspected folder-load caller does not check this result. Preserve that ordering when changing error handling; the guard does not make delivery atomic or prove a shutdown cause. Static inspection only.

Scope: Mailnews folder notification ownership.
