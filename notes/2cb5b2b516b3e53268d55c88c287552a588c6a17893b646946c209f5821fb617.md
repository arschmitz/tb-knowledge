# Keep QR wire data positional and versioned

The export module serializes a version number, a one-based [part,count] pair and flattened account data. Numeric protocol/socket/auth mappings encode the Android data format, not JavaScript enum values. Current getQRData still returns [QR_DATA_FORMAT_VERSION, [part, count], ...data], and its unit test checks that exact nested shape. Do not change field order or numeric mappings from a desktop refactor alone. The linked Android revision and format document remain unread while browser access is stopped, so cross-device protocol compatibility is not independently verified.

Scope: mail/modules/QRExport.sys.mjs.
