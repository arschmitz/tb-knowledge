# Calendar activation does not recreate a dismissed disabled-calendar notice

This landing adds the disabled-state condition to the missing-notification branch. When a notice was dismissed and a calendar becomes enabled, no new disabled-calendar notice is appended. An existing notice is still removed on enable, and a missing notice is still appended while disabled. The inspected observer/state callers supply the enabled-calendar Boolean. No regression test was added, and this static branch analysis does not establish native UI timing or rendering.

Scope: Calendar deactivation notification state.
