# Account creation renames its validator export and resource together

The rename changes the exported binding to InputSanitizer, installs InputSanitizer.sys.mjs, and updates direct/lazy consumers and dynamic test calls together. Exact byte comparison proves the moved module implementation changes only its export name; the fixed accepted module retains those bytes. Method calls keep the validator object as receiver. This establishes the component's resource/binding migration, not a global name ban, stronger validation or runtime compatibility result.

Scope: Thunderbird account-creation input validator module.
