# Search unifinder text across the four restored fields with Unicode normalization

Current unifinder normalizes the query and each nonempty SUMMARY, DESCRIPTION, LOCATION and URL value before a lowercase includes comparison. The browser test puts decomposed Amélie in DESCRIPTION and searches with the precomposed spelling, reducing eight rows to one. This avoids a raw code-unit mismatch. This is row filtering of already-fetched items, not a change to calendar-provider queries. Locale-sensitive case folding and every field’s runtime cases were not independently exercised.

Scope: calendar/base/content.
