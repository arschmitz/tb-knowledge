# Card lookup uses cheap address properties before full vCard matching

Accepted AddrBookDirectory.cardForEmailAddress first probes PrimaryEmail and SecondEmail. It then uses a case-folded vCard substring check to avoid unnecessary parsing and confirms an exact case-insensitive emailAddresses match on the card. The substring is a prefilter, not the final matching rule. Keep both checks if extending this path. This is static source and test-code inspection.
