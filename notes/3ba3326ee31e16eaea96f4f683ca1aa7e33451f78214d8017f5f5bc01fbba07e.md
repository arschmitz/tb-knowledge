# Test midnight state without waiting for the real clock transition

The accepted midnight test sets up stale selection intent/markers, emits CalMetronome's day event, and asserts markers, selection, agenda interval and hidden-view invalidation separately. Its dedicated TOML manifest sets TZ=UTC, and the test skips near real midnight because the real metronome can race the simulated transition. Follow these explicit clock assumptions for this family; this current test was not added in 1098 and was read only as accepted regression coverage.

Scope: Calendar midnight regression clock assumptions.
