# Document async notification accessors as promises with their resolved value

Both shipped-data accessors are async, but their accepted JSDoc return annotations are object[] and Set<string>. Their callers await the resolved values. When editing this module, recommend Promise<object[]> and Promise<Set<string>> or the repository equivalent so the annotation describes the call result rather than only its awaited value. This local semantic type recommendation is useful even when JSDoc syntax lint accepts the current spelling. These are fixed accepted source and test-code observations.
