# Short OAuth result-page success logs still follow a full source comparison

The helper first compares the actual callback page string with the generated expected page. If they match, it emits matching short marker strings to avoid logging a large success body. If they differ, it passes the two actual strings to Assert.equal. The constant success assertion therefore follows a real comparison; it is not the only check. This source observation does not establish a successful live OAuth flow.

Scope: OAuth2TestUtils result-page assertions.
