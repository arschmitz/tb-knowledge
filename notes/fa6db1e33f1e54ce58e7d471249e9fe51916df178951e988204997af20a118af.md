# An absent password must not skip incoming configuration verification

The old condition could resolve a password-auth guess without a password, even when discovery had misidentified an OAuth-only account. The change always starts verifyLogon after server setup. The accepted helper delegates to server.verifyLogon with the verifier as URL listener; success resolves the stored configuration from OnStopRunningUrl after cleanup. Returning from the initiating method is not completion, and this incoming check does not establish SMTP validation. Review records manual OAuth/password checks and defers broader refactoring. No logon was executed here.

Scope: Account configuration verification.
