# Context-menu tests should identify the mode in failed visibility assertions

The message-list browser test adds the mode to Assert.deepEqual output when comparing visible menu items. The special-context test can compare the entire menu, not just items before the normal message-action boundary. This makes a failure identify the mode and catch leaked unrelated actions. Prefer these observable menu assertions when a change affects context visibility.

Scope: Mail context menu tests.
