# Composite Calendar's explicit failure guard rejects self delegation

The removed assertion's success condition was that the item's calendar differed from the composite. The explicit failure branch must therefore test calendar == this. The owned and accepted methods use that condition, reject a missing calendar and otherwise return the concrete calendar's modify/delete operation. Review caught the intermediate opposite guard. This is the local delegation contract, with no reproduced recursion or runtime result.

Scope: Composite Calendar modify and delete routing.
