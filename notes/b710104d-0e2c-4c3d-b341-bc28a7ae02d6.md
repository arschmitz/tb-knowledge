# Preserve sync and async boundaries when bypassing OpenPGP wrappers

Removing CryptoAPI moved the old cApi.sync helper to EnigmailFuncs.sync where synchronous decryption still needed a result. Direct MIME verification still passes an RNP promise through that sync helper. Other call sites await RNP directly. Review suggested awaiting attachment verification inside an async function, but the author deferred that risky cleanup. When replacing OpenPGP indirection, inspect each caller’s timing contract rather than changing every call to await by pattern.

Scope: OpenPGP architecture.
