# Count only successful unread local filter moves as destination new mail

The local non-coalescer move branch captures the header flags before moving. Only a successful move of a previously unread message increments the folder-URI map and clears msgIsNew, causing the inbox new count to decrease later. Failed moves and already-read messages do not enter that counter. Delete marks the message read before reaching the move branch. Preserve these conditions when changing filter actions; a physical move alone is not enough to mark destination mail new.

Scope: mailnews/local/src.
