# Normalize both lookup and candidate server hostnames

Current findServerInternal uses ConvertToDisplayIDN followed by MsgNewStandardURL/GetHost for both requested and candidate hostnames, then compares normalized strings without case sensitivity. Percent escaping happens before URL parsing. Keep thisHostname distinct from normalizedHostname so local fake hostnames, numeric normalization and ordinary DNS input are not compared at different stages. Current URL helper replaces historical NS_MutateURI; do not copy the obsolete helper call.

Scope: mailnews/base/src.
