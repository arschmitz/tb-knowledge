# The certificate probe close timer exists to reach its stop callback

When the protocol command queue is empty, the probe schedules a 500ms transport close because a server may not hang up after quit. The adjacent comment states that otherwise onStopRequest waits for the connection timeout. Accepted current code retains the reason and captures the local transport. This is a specific completion fallback, not a recommendation to replace event/state waits with arbitrary sleeps or proof every error/cancellation path completes. No socket or timing test ran.

Scope: Scoped production timer reason and completion comment.
