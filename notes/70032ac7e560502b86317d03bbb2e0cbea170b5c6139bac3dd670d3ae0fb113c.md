# Preserve borrowed input lifetimes while reading the current HTTP builder API

The lifetime cleanup named the old mutable-builder return lifetime explicitly. Current RequestBuilder still borrows URL, method, headers and body data under its named lifetime, but header and body now consume self and return a builder value. Body borrows byte data or the bytes of a string. When changing this module, state which data is borrowed and follow the current ownership signature. Do not teach the historical mutable-reference return as current fluent syntax. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Rust HTTP request ownership syntax.
