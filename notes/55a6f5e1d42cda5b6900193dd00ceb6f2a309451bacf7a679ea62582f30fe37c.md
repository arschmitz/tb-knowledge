# Keep font registration membership owned by each window

UIFontSize.registerWindow rejects a window already in registeredWindows. On successful registration it adds that exact window, attaches a one-time unload listener that removes it, and applies the current font size. This manager membership is separate from the AccountManager iframe __UIFontRegistered guard, which reuses an earlier note. Preserve cleanup for the registered window; the source does not prove a navigation or unload sequence was exercised. Static source and test-code inspection only. Full Bugzilla and review discussion remains pending. No runtime, build, lint or live accessibility check ran.
