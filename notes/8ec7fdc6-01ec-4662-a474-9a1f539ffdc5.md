# Apply saved column state only to columns that were present in it

AutoTreeView stores column order, width, and hidden state in xulStore. During restore it clones defaults, parses the saved value in a try/catch because profile text can be malformed, and only overrides hidden/width for IDs found in that value. D207127 review caught that forcing a hidden value for missing IDs would wrongly make newly added default columns visible in old profiles. Keep new column defaults meaningful for existing users. Current code keeps the conditional.

Scope: Tree column persistence.
