# Keep synthetic drag cancellation distinct from native Escape behavior

The new drag/drop test checks expansion timing and cancel/drop outcomes, but its cancellation helper sends Escape and then explicitly sets dropEffect="none" and synthesizes dragend. This constrains the handler response to that event state; it does not prove Escape alone produces it on each platform. The new test does not cover thread/message drags or every dragleave timer path. Keep that observation boundary in reviews.

Scope: Folder pane drag test scope.
