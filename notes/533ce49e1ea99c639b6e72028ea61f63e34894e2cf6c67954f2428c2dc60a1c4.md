# GTK window-decoration selectors move from a true value to attribute presence

The original Thunderbird port changes both normal-window and spaces-toolbar negations to test whether gtktiledwindow is present. The surrounding GTK/custom-titlebar and visibility conditions still apply. Accepted CSS later calls that attribute tiled. Preserve the two source phases without claiming the engine setter was paired or making a global attribute or decoration rule.

Scope: linux-window-decoration-css.
