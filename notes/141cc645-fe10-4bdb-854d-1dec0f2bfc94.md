# Hide a mail context submenu when it has no visible actions

The mail context menu computes visibility after its child items are set. _ensureSubmenuVisibility hides a top-level submenu when every child is hidden or is only a separator. Generated tags, move, and copy menus are excluded because they have their own setup. Current code retains this logic. When adding a submenu, check that it disappears in contexts with no valid actions and does not leave an empty heading.

Scope: Mail context menus.
