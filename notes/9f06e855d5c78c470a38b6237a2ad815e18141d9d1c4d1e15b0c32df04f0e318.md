# Calendar spacing migration changes density values and keeps category spacing fixed

The Calendar token migration changes compact and touch row dimensions. With a 3 px step and base values of 3/6/9 px, row padding is 9/12/15 px, column gap is 6/9/12 px and content gap is fixed at 3 px. Category gaps remain 9 px, with fixed pill padding/radius. The row CSS consumes these properties for its grid and expanded state. The owned titlebar offset change and the later accepted header layout are separate phases; replacing pixel literals with tokens does not imply visual equivalence.

Scope: Calendar dialog spacing.
