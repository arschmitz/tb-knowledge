# Parse outgoing recipients at the common compose boundary

484 changes sendMailMessage from a comma string to separate msgIAddressObject arrays. Current MessageSend parses To/Cc and Bcc before protocol dispatch; SMTP combines email addresses for its envelope while EWS consumes Bcc separately. Preserve semantic structure across the shared API instead of repeating parser policy in each server. Current collection into address book is nonfatal if database access fails, a later accepted behavior beyond this historical patch.

Scope: mailnews/compose/src.
