# Invitation location value and tooltip share the renamed Fluent binding

The producer and resource both use calendar-invitation-location. One locationProperty argument supplies the prefixed value and the unprefixed tooltiptext, with a localized None fallback when LOCATION is empty. The owned patch changes the ID as well as adding the attribute. This checks the concrete producer/resource pair without establishing a global localization rule or a rendered-tooltip result.

Scope: Calendar location localization binding.
