# The tree column picker separates per-cell buttons from one outer popup

Every ordinary header cell has a picker button, while #updateView marks the last visible column and CSS shows only its button outside drag transitions. The header owns one popup under the outer tree-view container and rebuilds its items when it opens. setColumns can replace all header cells while that popup remains outside the row. This replaces the old extra picker-cell layout; button-label and tab-index follow-ups are separate phases.

Scope: Tree-view table header layout and popup ownership.
