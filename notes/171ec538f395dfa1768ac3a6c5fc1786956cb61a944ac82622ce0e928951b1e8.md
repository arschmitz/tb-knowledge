# The special-folder account picker uses a flagged folder’s full URI before its suffix fallback

In account mode, SaveFolderSettings obtains the root for the account currently selected in the picker. It searches by the supplied special-folder flag and uses the matching folder’s full URI, which preserves nested and alternate names. Only a missing match falls back to the selected account URI plus /Sent, /Archives, /Drafts or /Templates. Explicit folder mode keeps its selected URI. This lookup neither creates a missing folder nor locks flags, so later Exchange flag-loss reports remain a separate contract.

Scope: Copies and Folders destination selection.
