# Tag row selectors use their own T-prefixed byte encoding and flow through row-property tokens

GetSelectorForKey produces a separate row-style token: T followed by ASCII alphanumerics or underscore-hex byte escapes. The port visits the explicit string extent and converts a non-alphanumeric byte to unsigned before formatting, rather than using the old NUL-terminated scan. The DB view appends the selector as a row property, ThreadRow transfers the property list to data-properties, and the pane color rule matches that token with ~=. Traditional tree rules also consume this service selector. Keep this representation distinct from the stored =xx-generated key and from CSS custom-property references. The helper does not validate protocol keys; neither its comment nor this refactor proves universal IMAP safety, allocator performance or rendered styling.

Scope: Tag selector generation and row styling.
