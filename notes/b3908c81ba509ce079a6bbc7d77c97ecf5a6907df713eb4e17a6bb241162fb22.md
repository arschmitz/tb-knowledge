# Message copy prompts and local fallback names use the folder's localized name

The patch changes the copy-failure prompt, copy-start status and local fallback name component to localizedName. The property supplies a special-folder translation when applicable and otherwise returns the stored name; local folders use their own recognized-name mapping. Accepted code keeps those roles, with Fluent arguments for UI and an encoded component for the new local fallback URI. This concerns display/fallback construction and does not rename the original remote destination.

Scope: Message copy destination naming.
