# Keep metric definitions, generated field names and build registration together

1031 adds the inappnotifications event definitions to mail/moz.configure and records notification_id and active_this_session extras with the same declared spelling. The accepted schema identifies quantity extras in seconds and links data_reviews to the specific #c4 comment instead of the historical incomplete #c fragment. These source references do not establish that the data review was approved; its human context is still unread. Check the exact schema and registration before adding a producer field.

Scope: Notification metric definition and producer naming.
