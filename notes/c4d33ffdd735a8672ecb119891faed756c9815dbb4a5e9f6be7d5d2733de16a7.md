# Today-pane task-only sizing depends on the hidden splitter's adjacent sibling

The task panel normally requests40% block size. The nested#today-pane-splitter[hidden]+& selector instead requests100%!important when that immediately preceding splitter is hidden. The actual markup preserves this adjacency, and updateDisplay hides the splitter whenever the task and agenda panels are not both visible. In tasks-only mode this connects the chosen view to the full-size rule. This is a scoped CSS/state contract, not a measured layout result or a general recommendation to use!important; native height persistence and live accessibility were not exercised.

Scope: Calendar Today-pane CSS and view state.
