# Group address book importer cases by format with named tasks and explicit fixtures

The consolidated xpcshell suite uses named test_importCsvFile, test_importVCardFile, and test_importLdifFile tasks. Within each, it awaits test_importAbFile for representative fixtures: CSV separators, missing headers, quoted and non-UTF8 files; vCards with extra newlines or DOS line breaks; and LDIF labeledURI behavior. Each case compares imported card data with addressbook.json. This is a scoped test organization pattern that preserves edge cases while removing one-file-per-case legacy tests.

Scope: Address book import tests.
