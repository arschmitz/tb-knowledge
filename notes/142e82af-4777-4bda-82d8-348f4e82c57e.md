# WebExtension decryption disables UI prompts and reports failure

MimeTreeDecrypter normally prompts when user input is needed. ExtensionMessages constructs it with disablePrompts true because a WebExtension call has no Thunderbird UI interaction. Prompt branches instead log the message and fail decryption; MimeTreeEmitter explicitly passes false for its UI path. Current code retains both caller choices. Adding a new prompt inside the decrypter must honor disablePrompts and return a failure the extension API can report.

Scope: OpenPGP extension decryption.

Paths:

- `mail/extensions/openpgp/content/modules/MimeTree.sys.mjs`
