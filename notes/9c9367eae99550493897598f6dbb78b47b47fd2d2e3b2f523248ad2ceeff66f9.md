# Release transforms move one config provider while retaining their local consumers

The four transforms import get_release_config from mozilla_taskgraph.worker_types and still call it with config. Their local consumers remain command/env formatting, Flatpak metadata, notification prefix formatting and update-verify partial_versions arguments. Other Gecko imports and keyed release policies remain separate. This supports the comm integration change, not the unseen provider implementation or a successful release graph. No changed tests or taskgraph execution occurred.

Scope: Thunderbird release taskgraph configuration imports.
