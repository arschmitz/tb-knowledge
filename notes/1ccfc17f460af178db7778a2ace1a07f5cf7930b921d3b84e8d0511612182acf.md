# Unobtrusive signature UI verification has explicit message and sink eligibility gates

The mixed parser checks top-level/single-child/signature eligibility, display context and a parseable message date before invoking the sink. The sink requires t=p and signature data b before awaiting detached verification and updating security status. The added test assertions check signed and encrypted icon states separately; they do not validate malformed-header, date or asynchronous-error paths. Native Promise completion/rejection handling is not established by this handoff.

Scope: OpenPGP display sink and MIME handoff.
