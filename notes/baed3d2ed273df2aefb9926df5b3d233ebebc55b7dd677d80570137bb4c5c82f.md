# Unbound Gloda test hooks use the explicit test-state owner

IndexMessageState assigns its hook methods to GlodaIndexer as plain function references. The hook documentation warns that this is lost, and the implementations update the module indexMessageState singleton. Preserve that explicit owner or bind deliberately when changing these hooks. This is a checked callback-receiver pattern, not a recommendation to replace all method callbacks with globals. This is static source and test-code inspection.
