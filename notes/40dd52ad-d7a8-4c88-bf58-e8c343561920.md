# Sync servers before identities that refer to them

The rebuild replaces the old accounts engine with a servers engine covering incoming IMAP/POP3 and outgoing SMTP. MailGlue registers ServersEngine before IdentitiesEngine; server syncPriority is 3 and identity priority is 4, with address books and calendars at 6. Identity records name incoming and outgoing server UIDs, and IdentityStore.create resolves those UIDs to local account and SMTP objects. This order gives dependent identities a chance to find their servers. The server engine also adds SMTP deletion notifications to OutgoingServerService for tracking.

Scope: Thunderbird Sync engine order.
