# Complete an EWS folder move through the remote listener and checked local reparent

3036 introduces same-server MoveFolder, with cross-server operations left to FolderCopyHandler. The original callback ignores local reparent and ID-write results, and some scheduling/direct-return paths do not update the exit guard value. The accepted ExchangeFolder code checks LocalRenameOrReparentFolder before completing the move and checks MoveFolders scheduling. The local helper checks name conflicts and recursive movement before notifications. Current tests assert local child absence/presence, not replacement IDs, descendant stability or failure notifications. Treat the source comment about stable descendant IDs as an observation, not a protocol guarantee.

Scope: mailnews/protocols Exchange folder move.
