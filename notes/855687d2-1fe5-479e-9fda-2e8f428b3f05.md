# Reject an empty IMAP NTLM challenge before decoding

An IMAP server may answer an NTLM/GSSAPI authentication step with no usable challenge or only base64 padding. Check the remaining length before indexing or decoding; fail login without crashing. The regression test checks that the connection stops after AUTHENTICATE NTLM.

Scope: imap.
