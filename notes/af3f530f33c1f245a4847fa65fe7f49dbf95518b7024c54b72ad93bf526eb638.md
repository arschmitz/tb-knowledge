# Graph folder creation fallback follows the typed missing-folder result

Graph now creates after an update only when the callback returns NS_MSG_ERROR_FOLDER_MISSING; other errors propagate. FindFolderWithId uses that status for a nominal miss but preserves encountered lookup failures. The update chain queries both target and parent, so the status does not itself identify which folder was missing. Accepted source retains this contract under the renamed ExchangeIncomingServer path. The folder test supplies the correct typed error, although its new comment incorrectly says messages and NS_MSG_MESSAGE_NOT_FOUND; that wording remains and should name folders and the actual status. No explicit generic-error propagation assertion was added.

Scope: Graph folder delta callback classification.
