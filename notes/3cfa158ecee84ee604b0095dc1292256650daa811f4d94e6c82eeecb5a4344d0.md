# Resolve the file-picker title in its actual Fluent bundle

openLocalCalendar uses calendar-open from calendar/calendar.ftl. The old generic open ID was missing in that bundle, producing an empty native picker title. Keep the localized ID and the Localization bundle paired; similar English text does not make an ID interchangeable. The .ics filter uses a separately localized description with the wildmat argument. This fixes the static title lookup; a native picker’s accessible name and announcements still need a runtime check.

Scope: Calendar localization and file-picker accessibility.
