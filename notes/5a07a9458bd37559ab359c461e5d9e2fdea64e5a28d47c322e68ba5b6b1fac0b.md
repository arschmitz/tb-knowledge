# Keep the unifinder sort indicator tied to the view’s sort event

The unifinder view sorts first, then emits sort-changed with the selected column and direction. The UI clears every existing sortDirection attribute before setting the new one. The initial start-date column declares ascending; the tree no longer persists a separate sort-active/sort-direction pair. Preserve this local model-to-header contract when changing the event list. A visible indicator check has not run. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: calendar unifinder.
