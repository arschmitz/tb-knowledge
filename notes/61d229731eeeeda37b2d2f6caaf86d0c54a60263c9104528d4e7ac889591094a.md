# Compose List- custom headers share the normalized read, write and removal gate

The custom-header name gate lowercases and trims names, accepts List- alongside permitted X- names and explicit exceptions, and still rejects X-Mozilla-. Both getComposeDetails and the update/removal path use that gate. A supplied customHeaders array replaces accepted names, so a later array or empty array can remove List-Id. The test checks its name/value round-trip through the real API helper. This is the local prefix contract, not unrestricted header or RFC validation, and the test was not run.

Scope: Compose extension custom headers.
