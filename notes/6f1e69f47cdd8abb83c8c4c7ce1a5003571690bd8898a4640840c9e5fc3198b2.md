# Preserve query parameters and locale choice when updating a canonical product link

The 2024 donation link change updates several UI and package metadata consumers together, removes the fixed en-US path and preserves UTM/other query parameters. XML consumers keep &amp; escaping. When changing a shared product URL, inspect all source forms and retain their context parameters; do not treat all strings as interchangeable text. The cited Flatpak metadata path is historical and no longer exists at the fixed endpoint. The destination page was not visited, so this study confirms historical source linkage only, not current destination routing.
