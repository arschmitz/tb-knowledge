# Normalize both filter query and every searched property

Find Events uses str.normalize().toLowerCase for both query and values. Current search covers SUMMARY,DESCRIPTION,LOCATION,URL and guards missing values. Normalize the query once, rather than once per item/property. Default NFC normalization handles canonical equivalence; this does not claim locale-specific case folding or accent stripping.

Scope: calendar.
