# The granular-scope test retains the OAuth dialog promise before starting verification

This landing stores expectOAuthDialog(grantedScope) before verifyConfig and awaits that dialog promise after the verification branch, before telemetry checks. The concrete helper submits the requested scope through the test login page. The selected sequence joins dialog handling when it reaches that await; it does not attach an immediate rejection handler or prove that every earlier failure reaches the join. Accepted later code catches dialog errors immediately and retries the full flow, which is a separate phase. No assertions change and no browser/OAuth test was run.

Scope: OAuth account-creation browser tests.
