# Surface role names do not replace every numbered neutral color token

Shared colors.css defines surface base, subtle, lower and border roles with light/dark aliases, while --color-neutral-200 remains a separate valid numbered token. The toggle uses surface roles for its default surface/knob and still uses neutral200 for its hover border. Match a token to its actual role and producer when migrating names; do not mechanically invent a surface equivalent for every neutral prefix. The selected toggle state uses separate selected-item colors. Static source only; no contrast or theme-rendering result.

Scope: Shared mail semantic color roles.
