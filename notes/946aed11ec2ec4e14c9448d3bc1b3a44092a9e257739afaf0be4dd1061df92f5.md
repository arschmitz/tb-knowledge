# Do not deduplicate CardDAV discovery by URL alone

Entry 1801 removes the triedURLs guard. Current discovery changes the PROPFIND body while resolving a principal and an addressbook-home-set; the final listing also changes Depth to 1. The same URL can therefore represent a different discovery request. Preserve phase/request differences if adding a retry cache. The reported Radicale case has not been reproduced and its discussion remains unread. Static source and test inspection only. No runtime, build, lint or live accessibility check ran.
