# The attachment-opening test sets Always Ask handler state before waiting for its dialog

The test stores text/plain/txt handler metadata with preferredAction=alwaysAsk and alwaysAskBeforeHandling=true before opening compose. It registers a watcher for the unknown-content-type dialog before double-clicking the attachment, then awaits the dialog. Cleanup removes the test entry rather than restoring a snapshot of a prior handler. This is explicit local test state; the source and historical Good Try report do not prove the intermittent timeout is cured on native platforms.

Scope: Compose attachment dialog test setup.
