# Use the Account Hub widget naming family without flattening its namespaces

The email-config-found custom element and implementation filename are dashed, its EmailConfigFound class is class case, and the accountHubEmailConfigFoundTemplate.inc.xhtml template uses the existing lowerCamel stem. The template uses lowerCamel IDs such as addonInstall, dashed classes and dashed Fluent message IDs. Preserve each local namespace for nearby controls. These accepted examples support a scoped convention, not a project-wide rename rule. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub config widget naming.
