# The historical MIME switch gate limits allowed part positions

The historical gate allows MIME part 1, allows part 1.1 under a signed top part, and allows a signed part 1.1 under an encrypted top part. Deeper parts cannot trigger this handler switch. The PGP check considers the top part and its first child; switching reloads and returns false so the actual decrypt caller stops that pass. The S/MIME sink also keeps its status and current-message guards. Fixed accepted JavaScript and IDL no longer expose this switch method, so preserve this as the historical implementation phase. No MIME parser, cryptographic result or loop termination was executed.

Scope: OpenPGP historical handler-switch positions.
