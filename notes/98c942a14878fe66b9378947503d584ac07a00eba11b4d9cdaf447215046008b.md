# macOS mail toolbar button classes explicitly opt out of native appearance

The patch adds appearance:none to .toolbarbutton-menubutton-button and .toolbarbutton-1 in the macOS mail stylesheet. Current source retains both declarations beside the existing dropmarker opt-out and local checked/open/inactive styles. This is a scoped rendering choice for these button classes, not a global styling or accessibility rule. It changes no labels, roles or commands. No native hover, focus, screenshot or accessibility test was run.

Scope: macOS mail toolbar CSS rendering.
