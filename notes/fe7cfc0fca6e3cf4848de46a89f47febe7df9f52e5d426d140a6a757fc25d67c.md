# Put the Calendar close action name on the button in the accepted control

The original skeleton placed localized alt text on a child image and had different close-image/close-button IDs across template, fixture and resource. Current markup uses a native type=button with calendar-dialog-close-button, and Fluent supplies aria-label and title on that button. Preserve this accepted control-owned naming when building related icon controls. No computed name or assistive-technology session was checked. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar close button localization owner.
