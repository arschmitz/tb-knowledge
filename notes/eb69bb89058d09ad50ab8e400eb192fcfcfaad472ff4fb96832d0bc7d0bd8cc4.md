# Thunderbird explicitly registers the shared contextual identities extension API

ext-mail.json names the Gecko parent implementation and schema, addon_parent scope, startup event, settings flag, contextualIdentities permission and namespace path. Thunderbird’s extension category manifest points to ext-mail.json and jar.mn packages that file. The frozen browser cookieStoreId test starts with privacy.userContext.enabled=false and requests contextualIdentities, then expects container windows/tabs to work. That test expectation is source evidence only. The shared Gecko implementation and the D238525 dependency were not fully inspected, so this establishes the Thunderbird registration boundary, not a verified runtime permission or isolation guarantee. Static source and test inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending-single-browser-reader.

Scope: Thunderbird shared extension API registration.
