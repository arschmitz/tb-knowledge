# The CSP compatibility port gives each owned dialog its specific missing resource permission

Fresh entry 2151 changes four owned CSP declarations: both Calendar dialogs permit img-src chrome: moz-icon:, multimessageview permits inline chrome styles, and EdImageProps permits img-src chrome: data:. The last addition follows the explicit review request for data-URL images. Fixed selected policies retain these permissions and contain separate later additions, including moz-src scripts and HTTP/HTTPS image sources in EdImageProps. These are page-specific compatibility exceptions, not a general CSP relaxation rule or a reproduced debug-crash fix. Main Bug 1954414 comment2 is missing, so source/full review findings have zero audit credit. No image-preview implementation, upstream debug assertion, native CSP, network or accessibility behavior was run; the external editor-script consumer remains uninspected.

Scope: Owned dialog CSP compatibility.
