# The grouped insertion sort receives a Boolean date predicate

The grouped row passes _compareMessages directly into children.sort. That method returns comparators.date, whose result is a Boolean less-than predicate. The resulting false/true values do not supply a negative comparator result. Keep this source-level mismatch separate from SQL ordering and expected-order tests; no runtime sorting failure was reproduced. The inspected accepted revision still contains the same call and predicate.

Scope: Panorama grouped message comparator contract.
