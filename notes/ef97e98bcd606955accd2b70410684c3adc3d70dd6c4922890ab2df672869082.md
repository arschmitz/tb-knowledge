# Keep real number-input controls when styling their spin buttons

The manual port fields remain native type=number controls with numeric bounds. CSS styles Gecko number-spin parts with logical borders, context stroke and navigation icons rather than implementing a second JavaScript stepper. For these fields, keep the control semantics while changing its appearance. Native markup and logical properties support the intended behavior but do not prove keyboard increments, high-contrast visibility, pointer target size or right-to-left layout at runtime. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub native numeric controls.
