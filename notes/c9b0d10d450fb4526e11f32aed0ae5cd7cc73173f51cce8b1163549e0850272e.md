# Keep QR auth test skips aligned with the branch being tested

Accepted test_osAuthRefused skips unless the harness can test OS-keystore login, OS authentication is enabled, and the keystore can reauthenticate. The password prompt helper checks those OS conditions only when there is no primary password. Primary-password tests use the native alert dialog instead. Scoped test recommendation: gate each platform scenario by its actual capabilities; a skipped OS test is not evidence that the denial path passed. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
