# Update horizontal-scroll state even without a selected folder

In [D222886](https://phabricator.services.mozilla.com/D222886), the reviewer rejected using a second lazy preference observer and skipping changes when no folder exists. The author agreed. The accepted threadPane.observe reads the changed preference and updates treeTable.isHorizontalScroll before checking gFolder. Only the column refresh is skipped. This preserves the state for the next folder selection. The observer-order concern is the reviewer’s stated reason; no ordering experiment ran. This is a scoped message-list lifecycle lesson, not a ban on lazy preference getters. Existing widget/CSS and geometry lessons remain linked by the audit.

Scope: Message list preference observers.
