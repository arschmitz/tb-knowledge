# Load menu styling in the document or shadow-tree context that uses it

The two-file 1959667 follow-up links chrome://global/skin/menu.css from the unified-toolbar test document and imports it into Account Hub styling. The actual AccountHubStep puts that stylesheet link inside its shadow root. These are explicit consumers of menu styles after the menu-DOM port, not proof all documents inherit those rules. The existing popup test opens a submenu and checks popup/ariaPressed state, but this commit changes no test assertions. The shared Bug is missing comments2/7/8, so no full-audit credit is claimed. No menu, native platform or browser test ran.

Scope: Menu stylesheet consumers.
