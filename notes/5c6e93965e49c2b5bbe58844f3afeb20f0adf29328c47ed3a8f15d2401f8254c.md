# Treat documentation source filters as scoped tooling behavior

The JSDoc follow-up excludes browser_/test_ and underscore-matched paths through its excludePattern, while keeping .mjs/.js/.jsdoc inclusion and recursive traversal. This supports the established harness filename prefixes but is not a new manual test-name rule or proof that every test file is excluded. Account Hub accessor docs still need to be useful in production files even when tests are outside generation. This is static source evidence.
