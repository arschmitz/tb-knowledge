# Keep a persistent search book alive across background termination

The provider registers a persistent book during the starting phase, retains it when its listener is unregistered during suspending and reuses the same queued directory while stopped. Other unregister paths delete the directory. Extension background lifetime therefore differs from search-book lifetime. Preserve the UID/directory through priming and wake-up, and delete it on true removal or unload. The test verifies the original object still returns results after termination and that unload removes it; it does not assert every address-book notification. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension search-book lifetime.
