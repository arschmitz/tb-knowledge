# Related-account discovery returns the first nonempty host result and later centralizes host selection

The original discovery change tries the email domain then incoming mail hostname in an ordered Set and stops at the first nonempty address-book list or calendar map. It does not merge results across hosts. Accepted source later builds candidates in the caller with a same-site check and a separate Graph case, then passes that list to both detectors. The caller still sequences address books and calendars around cancellation/skip work. Helper redirects, credential handling and server behavior remain unverified; required discussion gaps give this source lesson zero full-audit credit.

Scope: Account Hub calendar and address-book discovery candidates.
