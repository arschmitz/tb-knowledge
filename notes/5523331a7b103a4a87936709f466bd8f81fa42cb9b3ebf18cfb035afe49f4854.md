# Arm the event promise before input and await the correct window focus

The notification button test registers ctaclick before synthesizing the click. 837 and 846 add an awaited SimpleTest.promiseFocus for the actual browser or filter dialog. In these asynchronous UI tests, wait for the action target to be focused and arm expected event observation before input. The close-button test still has an additional documented 1000 ms workaround; focus waiting does not prove all readiness races were solved. No keyboard or focus test ran.

Scope: Browser UI event and focus synchronization.
