# Single-locale repacks select artifact producers by task kind and platform

The single-locale kinds replace explicit en-US package names and URLs with MOZ_ARTIFACT_TASK task references. Ordinary l10n selects build for Linux/macOS and build-signing for Windows. Shippable l10n selects build-signing for Linux/Windows and repackage for macOS. Fixed0b93 retains those choices, with ordinary Linux restricted to linux64.*. Preserve the distinction between the ordinary and shippable kind when changing artifact producers. These strings do not establish a universal signing policy or prove a download/build passed. The upstream artifact-fetch implementation was not inspected.

Scope: Taskcluster single-locale repack inputs.
