# Remove list members without deleting the contact

deleteSelectedCards groups selected cards by their owning directory UID. If the active directory is a mailing list, it removes cards from that list instead of deleting the underlying contacts. It handles selected mailing-list cards through deleteAddressBook separately. Current code should be checked before edits because deletion details may have evolved, but the distinction between list membership and contact deletion is the behavior to preserve.

Scope: Address Book deletion.
