# Trace derived installer values through the registry writes

Bug 1898366 fixed an NSIS build error by defining UpdateChannel. Its SetAppKeys and SetUninstallKeys macros then computed an ESR suffix in $3, but the landed 2024 registry writes did not use $3. The short review accepted this. Bug 1895080 reopened in 2025 because ESR 140 still had ordinary release registry identity. The later fix inserted $3 into Mozilla and Windows Uninstall key names and display values, and added an ESR DWORD. Current code retains those writes. In installer reviews, follow a computed value to its externally visible key or value; a calculation and an accepted patch do not prove the effect. Validate the installed registry on Windows when changing installer identity. No automated test covered this fix.

Scope: Windows installer.
