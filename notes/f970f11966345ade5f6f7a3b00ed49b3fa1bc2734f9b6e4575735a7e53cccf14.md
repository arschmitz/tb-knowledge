# The native offline-read wrapper applies recovery to the stream status

The accepted ImapOfflineMsgStreamListener returns the underlying OnStopRequest result but decides whether to discard from the incoming stream status and mail.discard_offline_msg_on_failure. A listener returning an error after a successful stream is a different condition. Keep those result sources separate when reviewing this wrapper. This is scoped source behavior, not proof that every error response causes discard. No listener-error or preference-disabled run was performed; the historical 1285 version had no preference gate. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP offline stream result handling.
