# ConfigVerifier reports failure when launching an alternative logon throws

After a failed logon, tryNextLogon can throw while starting an alternative. OnStopRunningUrl catches that synchronous call and invokes _failed(url), which cleans up and calls the error callback that rejects verifyConfig. The error shown comes from normal URL/backend/abort handling, not necessarily the caught exception text. This reports failure instead of leaving verification pending; it does not repair credentials or guarantee the next logon succeeds. The catch excludes the preceding closeCachedConnections call and does not replace later asynchronous status handling. No setup or test ran.

Scope: Account configuration retry failure path.
