# Treat trashFolderName as a folder path in IMAP

GetTrashFolderName explicitly returns a path such as INBOX/Trash. Setting it clears the previous Trash flag, sets the new one when MoveToTrash is active, converts paths to the negotiated wire encoding and stores the UTF-8 preference. Preserve that path meaning despite the inherited method name; taking only the leaf name changes which folder is selected. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
