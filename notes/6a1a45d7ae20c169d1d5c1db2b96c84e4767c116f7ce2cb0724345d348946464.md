# Exchange display-name persistence and lookup-cache invalidation serve different roles

Classic Exchange metadata caching stores and restores mName under folderName only when the folder does not use a localized name. These overrides reject Panorama mode. FolderLookupService.invalidateCache separately clears its in-memory folder-object map. The test uses that invalidation and another incoming server to simulate restart, then asserts the active fixture names before and after the second load. It does not restart Thunderbird, independently assert disk flush or run its two commented-out Unicode cases. The mock preview sanitizer is a separate serialization path. No test or restart ran.

Scope: exchange-folder-display-names.
