# Allow only the configured IMAP cleanup actions to authenticate during shutdown

AuthLogin ordinarily aborts when the account manager is shutting down. Its accepted exception is limited to expunging a folder, deleting all messages or deleting a folder; failure to obtain the action also aborts. The account manager starts cleanup only for the configured trash/inbox options, avoids offline cleanup and checks available credentials or OAuth before starting. This is not permission for arbitrary network work after shutdown starts. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/imap/src.
