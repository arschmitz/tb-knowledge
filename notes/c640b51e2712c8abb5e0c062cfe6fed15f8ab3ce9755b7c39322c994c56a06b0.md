# Attachment activation goes through a host command with host-specific selection gates

The shared attachment widget calls cmd_openAttachment from Enter and item double-click instead of opening from generic command events. Reader enablement checks all current attachments, then the action collects and filters selected attachments. Compose requires exactly one selected attachment. The accepted Enter listener later excludes modifiers, unlike the initial landing. Availability and command dispatch are not successful-open completion; reader opens can be scheduled and AttachmentInfo.open still performs async checks. No activation or OS-handler test ran.

Scope: Reader and compose attachment activation.
