# The old send interface cleanup removed exposure rather than all delivery inputs

Three landings remove the unused nsIMsgSend deliveryMode attribute and deliverAsNewsExit/deliverAsMailExit declarations. The retained sendDeliveryCallback and its explicit news-delivery flag have a separate role. A removed readonly property does not prove every deliveryMode argument or internal delivery action disappeared. The common Bug tracker lacks a Thunderbird discussion selection; reviews remain deferred, so these are scoped source facts only. Legacy spelling is not a current naming recommendation.

Scope: Compose send interface cleanup.
