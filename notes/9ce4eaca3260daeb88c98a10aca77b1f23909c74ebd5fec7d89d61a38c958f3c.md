# SOAP Body attributes must consume their values before the operation payload

The imported EWS SOAP visitor treats XML attributes as map entries and consumes each value before the next key. It then accepts one expected operation response or Fault and rejects another body element. The GetFolder regression fixture places namespace attributes on Body. This is a specific ews-rs wire contract, not a style rule for owned Rust or a claim of arbitrary SOAP support. No tests were run.

Scope: ews-rust-wire-deserialization.
