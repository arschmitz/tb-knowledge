# The alert geometry handoff uses the most recent main window before a later primary-screen change

This landing passes the most recent mail:3pane window’s available screen geometry as the fourth alert argument. The alert uses that snapshot or falls back to its own screen and retains live window dimensions in the corner calculation. The accepted code later removes that handoff and queries primary-screen device coordinates with a devicePixelRatio conversion. Keep the main-window handoff and later primary-screen phase separate; neither source inspection nor historical placement reports establish a new native mixed-DPI result.

Scope: Custom new-mail alert coordinate phases.
