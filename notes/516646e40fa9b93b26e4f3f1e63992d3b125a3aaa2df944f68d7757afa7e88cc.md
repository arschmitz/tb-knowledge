# Use fixture-specific invitation test names instead of repeated generic names

1954 renames repeated test_event_from_eml functions to names for a Teams invite, another meeting invite, and an event message, and names the non-invite publish case. Current names retain those distinctions. Scoped manual test naming recommendation: use test_ plus the fixture or behavioral case in this invitations directory so logs identify the case. This is not a new universal camelCase-versus-snake_case rule; other Thunderbird test families use different names. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: calendar test naming.
