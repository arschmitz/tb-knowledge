# Delivery-file Bcc pruning matches the literal field delimiter

The helper removes a line beginning with Bcc:, then space-prefixed continuation lines while inBcc is true. Adding the colon preserves other field names beginning with Bcc. Matching remains case-sensitive and space-specific; the change does not add a general header parser. The helper runs only when compFields.bcc is nonempty, and Bcc recipient parsing is separate. No regression test was added or run by this study.

Scope: Outgoing message-file header filtering.
