# NNTP reads prefer offline storage, then memory cache, and normalize cache keys

NntpChannel.asyncOpen first tries an article in the folder offline store. If that succeeds, it returns before the memory-cache path. Otherwise it opens the memory cache, and a new entry or cache failure falls back to the server. Before opening the cache, it removes query strings; the constructor also supplies a missing port from the known server or the NNTP/NNTPS defaults. Keep the article lookup URI and normalized cache URI roles distinct. A test of only the network path misses offline and cached delivery. This is a static architecture observation at the fixed accepted revision. Those paths were not exercised, and later commits implementing them were not marked historically covered.

Scope: mailnews/news.
