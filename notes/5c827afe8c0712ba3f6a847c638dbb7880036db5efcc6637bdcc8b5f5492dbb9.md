# Match XMPP part-message placeholders to the selected Fluent family

For an ordinary room departure, xmpp-base reads the status element into reasonMessage, clears the item reason, uses affectedNick as participant and omits actor suffixes. The Fluent parted family expects participant and message, not affectedNick and reason. Removed-non-member suppresses reasons unsupported by its strings. Preserve branch-specific suffixes and argument names when building messageID; an argument object containing all names does not repair a wrongly chosen Fluent ID.

Scope: chat/protocols/xmpp.
