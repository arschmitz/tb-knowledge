# Original mock pagination mixes filtered pages with global offsets

The original helper limits folder-filtered changes but marks truncation using offset + maxItems < the global log length minus one. For two matching changes at offset 0 with maxItems 1, that comparison is false even though one matching change remains. Its consumers advance truncated cursors by the limit rather than by the selected changes original positions. Fixed accepted code tracks original indices, flattens before pagination and returns nextOffset. This is a static boundary finding; no mock request or regression test ran.

Scope: Mock Exchange pagination cursor.
