# Message error-page redirects clear the captured browser sandbox before loading seeOtherURI

displayMessage first assigns the normal message sandbox flags. If its URL listener receives nsIMsgMailNewsUrl with seeOtherURI, it hides the header, clears the captured browser sandbox flags and loads that error URI. The reset is scoped to that branch; the next displayMessage call sets message restrictions again. The historical report is an offline NNTP blank pane. Review acceptance is not a new security or runtime test, and there is no changed direct regression test in the assigned patch.

Scope: Message error-page navigation.
