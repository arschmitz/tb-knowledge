# AutoTreeView density handling skips work until a row class exists

The owned change guards uidensitychange with _rowElementClass before assigning ROW_HEIGHT or resetting the tree. Accepted code keeps that guard. This gives the event handler a bounded readiness check; it does not replay the skipped event or establish that all callers initialize density correctly. Row-class resolution and current template static height are separate setup paths. No startup or density test ran.

Scope: AutoTreeView density event readiness.
