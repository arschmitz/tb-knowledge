# The mixed MIME parser documents its one backward state transition

This parser keeps ordered interval comparisons for header phases and documents the one transition from Sig continuation back to accepting another Sig header. The reviewer offered explicit equality comparisons as a nonblocking alternative; the source retains the ordered model and its exception comment. Preserve this exact state contract when reading the comparisons. It is a local accepted choice, not a general rule for all state machines.

Scope: MIME parser local state comparisons.
