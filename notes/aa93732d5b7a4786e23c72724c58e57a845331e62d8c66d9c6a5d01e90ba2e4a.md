# Clean up a test server through the service that owns its preferences and cache

The SMTP default-type regression test writes mail.smtpservers=smtp1 without the type preference, loads it through MailServices.outgoingServer and calls deleteServer. Deleting through that service clears the preference list and cached server. A reviewer corrected the assumption that xpcshell automatically reset this preference between tasks. This augments the existing pre-migration SMTP lesson with the test-owner cleanup contract. The fallback is only for a missing type; it does not change an explicit other protocol. No migration profile or xpcshell test was executed.

Scope: Outgoing server tests and cleanup.
