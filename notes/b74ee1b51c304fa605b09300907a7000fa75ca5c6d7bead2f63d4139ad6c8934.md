# Preserve native MouseEvent fields without object spread

[D222639](https://phabricator.services.mozilla.com/D222639) rejected spreading the native MouseEvent because needed fields were lost. The author reported that own-property enumeration showed only isTrusted. The accepted wrapper passes the original event to the MouseEvent constructor and then assigns notificationId. The unit test directly checks mouse fields and ID; no test was run by this study. Check the actual native property contract before cloning an event. This is a scoped wrapper lesson, not a ban on ordinary object spread.

Scope: In-app notification event wrapper.
