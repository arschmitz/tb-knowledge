# Advertise only supported optional extension permissions

Thunderbird does not implement hiding tabs, so Bug 1896595 removes tabHide from the OptionalPermission enum in tabs.json. This schema also feeds public extension documentation; listing an unsupported permission would mislead add-on authors even if runtime behavior is absent. D210282 was accepted without an inline change request. This is distinct from the action.default_area compatibility key in Bug 1896288: that harmless known manifest property is parsed and ignored to avoid install failure, while an optional permission for an unavailable API is removed from the advertised set. Current tabs.json still lists only tabs here. Later unrelated RegExp attachments were posted to the same Bugzilla bug by mistake; they are not context for this Thunderbird change.
