# Offline message completion separates unconditional cleanup from successful metadata

StartNewOfflineMessage prepares the stream and byte counters for News/IMAP. EndNewOfflineMessage always releases its semaphore and clears the stream/header through a scope guard. Failed input status discards the write and clears Offline; successful storage finish and token assignment precede setting Offline, byte size and line count. The guard guarantees the named cleanup actions, not successful storage or database work. The removed historical seek-based sanity check does not establish a general rule for other writers. No offline download or failure test ran.

Scope: Offline message lifecycle.
