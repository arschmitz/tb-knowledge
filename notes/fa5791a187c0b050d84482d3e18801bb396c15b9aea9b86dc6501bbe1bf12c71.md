# Resolve inherited folder strings through parents and server defaults

GetInheritedStringProperty uses a nonempty local value, otherwise asks the parent; a server folder delegates to GetStringValue, which supplies its server/default preference chain. Preserve this hierarchy and the empty-string inheritance trigger. A missing value is not a distinct null result in this current API. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
