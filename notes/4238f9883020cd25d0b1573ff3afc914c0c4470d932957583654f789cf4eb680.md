# Attachment detachment selects the remaining header instead of a fixed numeric key

The attachment test snapshots inbox.messages after detachment, asserts that exactly one header remains, and reads that header instead of GetMessageHeader(2). The actual folder enumerator reads its database and getUriForMsg uses the selected header messageKey. The test directly checks the saved file and detached marker; it does not prove arbitrary enumeration order, a specific new UID or independent UID storage. No test ran.

Scope: IMAP attachment-detachment test header selection.
