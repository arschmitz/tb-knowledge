# Lazily load only the one-tag legacy scripts in the loader table

The legacy table pairs folder-summary and menulist-addrbooks with their scripts and gives scripts defining multiple elements or commonly used elements an empty tag. The empty-tag branch loads immediately; the tagged branch waits for element creation. Keep that distinction when adding a script rather than making the whole table lazy. The dummy extension document is still excluded. Current code keeps this table contract.

Scope: Legacy custom-element loader eager and lazy rows.
