# Flat-row expansion reserves sparse descendant slots while collapse splices the cached range

toggleOpenState removes a collapsed descendant span with splice. Expansion instead reserves rowCount slots between head and tail, replaces the array with head.concat(tail), then fills present child rows and notifies the tree. rowCount includes sparse holes, while #addChildren's array forEach skips them and assigns hierarchy metadata to real rows. This preserves placeholder positions; it does not promise stable array identity. A mechanical for...of rewrite needs a hole guard. The retained tests check visible rows and metadata, not speed or array identity.

Scope: TreeDataAdapter incremental visible-row cache.
