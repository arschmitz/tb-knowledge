# Carry the MIME tag and pointer together across the OpenPGP callback boundary

933 adds outputClosureType beside outputClosure in the noscript proxy interface and callback typedef. The proxy reconstructs a MimeClosure and sends both members to each output call; RemoveMimeCallback resets the callback and wrapper together. The receiving callback rejects an unexpected tag before casting. Preserve this pair across interface declarations, setters and invocations. The integer-to-enum cast itself does not validate arbitrary enum values.

Scope: OpenPGP MIME callback tag transport.
