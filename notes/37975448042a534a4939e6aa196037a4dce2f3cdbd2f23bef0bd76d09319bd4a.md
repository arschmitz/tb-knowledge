# The outer Space handler drops the event used by cmd_space for Shift direction

The original key element passed event to goDoCommand. The new outer keypress path, retained at the fixed endpoint, calls goDoCommand("cmd_space") without it. goDoCommand and the JS controller forward only supplied arguments; cmd_space uses event?.shiftKey to select reverse scrolling or previous unread navigation. On that route a missing event selects the forward branch. The separate message-body keydown listener still passes ev and can prevent the later keypress path. This is a bounded argument-contract discrepancy, not proof that every focused Shift-Space reaches the outer path or that a native failure was reproduced. The new PDF task exercises plain Space only.

Scope: mail keyboard command arguments.
