# LiveView populates thread identity in both selected and native-message objects

The LiveView scalar builder exposes enumerable threadId and threadParent properties. SQL selection reads those columns, and the native Message conversion reads the corresponding getters before using the same builder. Direct fixtures assert roots and a nested parent, including out-of-order arrival; they do not directly test live notifications or large IDs. Native values are converted to JS doubles, so the small-ID assertions do not establish exactness for every64-bit value. The added scalar assertions lack messages. No database or test run occurred.

Scope: Panorama LiveView JS message fields.
