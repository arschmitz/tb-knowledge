# Document lookup sentinels and failure separately for each direction

The historical UID mapping API has asymmetric contracts. UID-to-key lookup returns a slot for each input, with zero or a missing UID mapped to nsMsgKey_None. Key-to-UID lookup maps nsMsgKey_None to zero, and a valid header with an unset UID also yields zero. A missing real key fails the call. A generic statement that missing values return zero would hide a caller-visible failure. These methods were later removed; preserve the lesson about exact API contracts without teaching the old API as current.

Scope: mailnews/db/msgdb.
