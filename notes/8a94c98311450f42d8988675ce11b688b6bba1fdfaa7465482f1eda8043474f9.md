# The reminder row renders caller order and creates delete controls without deleting alarms

setReminders sets the localized count and maps the supplied alarms in input order. Each item uses alarm.toString and creates a type-button delete image, but the row has no delete handler or alarm mutation. The owned UI patch imports/inserts the row without a production setReminders call. A later accepted parent sorts copied alarm values with calculated-date b.compare(a), renders them and clears the row when replacing an event. Sorting and event integration are caller phases, not behavior provided by the row or proved by its direct test.

Scope: Calendar event reminder row rendering and integration phases.
