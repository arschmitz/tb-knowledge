# Describe both array levels in the signature-view input contract

1888 adds explicit object[] and nested signatures[].sigList[] property annotations. The accepted producer returns a list of user-ID objects, each with its own signature list. Some current top-level property annotations still omit []; uidLabel is documented but is not assigned by the inspected producer. Scoped documentation proposal: use a consistent nested-array property path, document the actual producer fields, and distinguish accepted input from fields the view copies. This is proposed clarification, not a reviewer-approved project-wide JSDoc rule. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.
