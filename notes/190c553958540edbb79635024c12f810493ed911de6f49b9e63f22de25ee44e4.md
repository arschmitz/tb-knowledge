# Outgoing credential removal returns the native ForgetPassword status

The historical EWS method called ForgetPassword and then returned Ok regardless of its status. This landing returns the status through to_result. Fixed accepted shared outgoing code retains this conversion after resolving username, server type and endpoint host. This scoped fact does not prove successful password removal, caller failure handling or unchanged behavior in every protocol after the code moved.

Scope: Rust outgoing-server password removal.
