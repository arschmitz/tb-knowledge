# Keep custom OAuth configuration ahead of provider lookup

The newer accepted updateOAuthUI returns after a custom OAuth override, clears provider extension information, and makes the OAuth option visible. hasCustomOAuth uses different UI settings for IMAP/POP and EWS/Graph. This is a current refinement checked alongside 828, not a claim that the later customization landing was fully studied. A hostname-only whitelist would lose this precedence.

Scope: Account settings OAuth capabilities.
