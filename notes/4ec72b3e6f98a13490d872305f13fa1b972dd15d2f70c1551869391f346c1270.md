# VCardTime exposes its selected constructor type through a getter

The update stores the selected constructor type in _icaltype and returns it through the icaltype getter. clone passes that type to the new object and toICALString uses it to select a converter. Thunderbird's dateProperty consumer constructs VCardTime with type date and assigns nullable date components explicitly. This is a static source contract; no runtime regression result is claimed.

Scope: Thunderbird bundled Ical vCard date conversion.
