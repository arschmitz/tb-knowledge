# Extension popup background setters and teardown remove matching custom properties

BasePopup routes the background-change message to setBackground. Falsy input becomes white. It skips the background assignment for widget-overflow, and white gets a default border. After browser readiness, destroy removes the background and border properties from non-remote panels. The port changes both setter and removal names together and keeps the public popup_border theme key. Later shared CSS names differ, so compatibility with the unread Gecko consumer remains bounded rather than inferred.

Scope: Extension popup inline color lifecycle.
