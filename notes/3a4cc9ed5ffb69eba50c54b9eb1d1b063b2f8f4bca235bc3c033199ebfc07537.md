# Use the intended private configuration field instead of a lookalike property

The manual forms use #currentConfig. A current outgoing port-adjustment assignment still writes this.currentConifg, which creates a different public property. Record this as a source concern and check its effect before changing it; getConfig also rereads the controls, so the typo alone does not prove lost port data. In these classes, preserve the exact private-field name when carrying state and avoid copying the historical misspelling. The general lowerCamel private-field pattern already has shared evidence. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub private configuration naming.
