# Use logical image sizes and preserve the two zoom states in CSS

Current messageBody.css uses max-inline-size for fitted images and block-size/inline-size/max-inline-size for zoomed images. Fitted overflowing images use object-fit: scale-down; enlarged images clear the size limits. These supersede the 2024 physical width/height rules. Attribute names shrinktofit and overflowing are an existing behavior contract and should not be renamed just to match CSS class spelling. This is a scoped newer CSS pattern beyond formatter enforcement; no RTL, zoom or printing test was run.

Scope: Message image CSS syntax.
