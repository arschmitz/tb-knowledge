# Convert numeric DOM values before passing the shared duration count

updateUnitLabelPlural and updateMenuLabelsPlural convert the input field value with Number before passing count to document.l10n. The agenda list also converts menu values before converting days into weeks. Preserve numeric arguments for these shared helpers. Other inspected widget paths still pass their input value directly, so this is an accepted helper pattern and a proposed consistency rule, not a claim that every caller is already uniform.

Scope: calendar/base/content.
