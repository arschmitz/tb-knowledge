# Keep add-on Exchange and native EWS configurations distinct

FindConfig stores add-on Exchange configurations as exchange and creates a structured clone with type ews for the native implementation. It sets useGlobalPreferredServer to false on the native clone because its sending path differs from the add-on. With add-ons allowed, it appends the native alternative; otherwise it replaces the add-on configuration wherever it occurs. This is the current configuration contract; the historical tests and selected current tests were read, not executed. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.
