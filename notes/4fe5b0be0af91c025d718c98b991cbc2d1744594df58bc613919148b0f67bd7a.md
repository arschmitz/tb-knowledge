# The Unifinder splitter toggle writes the concrete menu checkbox state

Passing calShowUnifinder as the second goToggleToolbar target makes the splitter toggle update that menu item’s checked attribute to the inverse hidden state and persist it. The bottom-events-box toggle still targets the Calendar command separately. The menu item dispatches that command to toggleUnifinder. This is the direct comm helper/control path, not a rendered menu or native accessibility result.

Scope: Calendar Unifinder menu synchronization.
