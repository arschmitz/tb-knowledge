# Flatpak ESR metadata is selected separately from the stable branch name

The job selects an ESR application name and channel paragraph separately from FLATPAK_BRANCH, where release and ESR share stable. The script substitutes the actual metainfo template, requires MANIFEST_URL and allows its custom AppStream key. This connects declarations to script/template consumers; it does not prove resolved environment values, generated XML validity, remote manifest correctness or a successful package/upload.

Scope: Flatpak channel branding and metadata.
