# Commit the message summary database before creating its compaction snapshot

1033 adds a checked kLargeCommit before locating and backing up the .msf file. This writes the current logical database state before taking the file copy. The accepted compactor still commits the live database before getting the summary-file location; its later staging design compacts a separate copy. Preserve this ordering when preparing the copy. A failed commit returns before the snapshot is prepared. The existing staged-copy and recovery lessons remain separate. This source inspection does not establish an atomic pair of files or a crash-recovery result. No compaction run was made.

Scope: Folder compaction database commit boundary.
