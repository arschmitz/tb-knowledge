# The app-menu helper checks the matched node before synthesizing a click

The app-menu script exposes the local PanelView class through its shared-script lazy getter. The shared test helper skips mouse synthesis when its directly matched subview child has disabled set, while keeping the existing ViewShown continuation and final-subview result. This does not establish traversal through disabled navigation targets or a general disabled-descendant rule.

Scope: App-menu shared test helper and PanelView binding.
