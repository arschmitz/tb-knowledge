# Keep text-column and icon-column minimum sizes separate

Current tree header text cells use min-inline-size:5ch; icon cells override with their icon minimum token. Entry 507 reduces the historical 7ch floor. This allows smaller useful columns while preserving a separate icon layout contract. The exact numeric value is component-specific, not a global sizing rule.

Scope: mail/themes/shared/mail.
