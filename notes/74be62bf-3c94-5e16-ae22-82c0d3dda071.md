# TaskBuilder::spawn behavior in xpcom/rust/moz_task/src/executor.rs

Allocates shared spawn configuration with background target and fallible dispatch enabled. Gives owned future and scheduling closure to async_task, schedules initial runnable, then wraps the handle.

## State read

- self name/priority/options/future

## State changed

- new Arc<TaskSpawnConfig>; async_task task; initial queued runnable

## Calls and triggers

- async_task::spawn creates runnable/handle; callback calls schedule(config.clone(), runnable); runnable.schedule triggers initial work.

## Result and consumers

AsyncTask<F::Output>; it resolves to the future output when polled successfully. Does not return a Result for dispatch failure.

## Errors

Dispatch errors are logged inside schedule. Cancelled underlying handle is exposed as Pending by AsyncTask::poll.

## Async completion

Initial runnable is scheduled immediately. Future is polled on target, wakes schedule more runnables. Dropping wrapper cancels by documented dependency contract; detach retains execution; cancel waits.

## Ownership and cleanup

Arc config is retained by scheduler and each runnable closure; explicit/current target has a RefPtr. Future is moved into async_task. Future and output must be Send.

```text
    pub fn spawn(self) -> AsyncTask<F::Output> {
        let config = Arc::new(TaskSpawnConfig {
            name: self.name,
            priority: self.priority,
            options: self.options.fallible(true),
            target: SpawnTarget::BackgroundTask,
        });
        let (runnable, task) = async_task::spawn(self.future, move |runnable| {
            schedule(config.clone(), runnable)
        });
        runnable.schedule();
        AsyncTask::new(task)
    }
```
