# The reminder focus test uses mouse activation

The component moves focus to the select when opening and back to Add after submit or cancel. test_focus checks those targets, but every activation in that task uses synthesizeMouseAtCenter. It establishes source assertions for focus transfer, not a keyboard activation or traversal test. No keyboard, browser or accessibility test ran.

Scope: Calendar reminder form focus coverage.
