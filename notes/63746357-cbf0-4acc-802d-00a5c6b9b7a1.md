# Select outgoing-server implementations by a lower-case contract type and keep existing profile keys

The service constructs @mozilla.org/messenger/outgoing/server;1?type=$type, rejects an unknown contract with NS_ERROR_INVALID_ARG, creates keys like smtp1, and records mail.smtpserver.${key}.type. Existing mail.smtpserver.* preferences were deliberately not renamed: D203799 explains that changing them in the first Thunderbird 128 release would make an older version unable to find SMTP settings after rollback. The historical IDL says type is lower-case, while final createServer validates whether its contract exists rather than modifying input or separately rejecting case. Treat the type string as a contract identifier, not display text.

Scope: Outgoing server architecture.
