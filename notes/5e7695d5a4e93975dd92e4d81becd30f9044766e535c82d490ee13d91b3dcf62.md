# The month-view touch handlers keep initialized private state outside view initialization

The patch moves touch bookkeeping into initialized private class fields and separate private start/end/move methods. ensureInitialized registers those method identities. The field JSDoc uses Map<number, number>, matching the reviewed local type syntax; only the move method has its own event JSDoc. These are accepted local organization and naming facts, not a global private-method, prefix or documentation mandate, and they do not claim implemented listener teardown.

Scope: Calendar month-view local handler organization.
