# UpdateItem namespace annotations are part of the wire structure

The 1279 and 1293 upstream changes add explicit XML namespace and flattening annotations to UpdateItem fields and Message variants. The accepted source still uses the messages default namespace for the operation and t-prefixed item-change fields. In this integration, inspect the serialization boundaries when updating the vendored schema; matching Rust field names alone does not establish XML compatibility. This is a scoped wire-structure observation, not a rule to copy third-party syntax into Thunderbird code. Generated checksum hashes were not audited; no serialized request or server exchange was tested. Full Bugzilla and Phabricator discussion remains pending.

Scope: EWS vendored wire-schema integration.
