# The flat Address Book depth override avoids repeated historical row walks

AddrBookDataAdapter returns 0 directly from getLevel because its rows are flat. At this landing, the inherited method called rowAt(index).level and rowAt walked rows. The tree-view accessibility calculation repeatedly queried neighbor levels when accessibility or automation was enabled. The override removes row resolution from those depth queries, while the neighbor loops remain. Later accepted code adds a flattened row cache and a rowAt metadata fast path; those are separate changes. No benchmark or live accessibility result is established.

Scope: Thunderbird address-book tree depth and accessibility metadata.
