# The quoted-printable allocation failure does not match the draft writer's size guard

The new combined-buffer allocation branch returns MIME_OUT_OF_MEMORY (-1000) before setting the output size. The actual draft writer initializes no outsize value, checks only ret == -1, and then adds outsize to the attachment size. The same bounded writer code exists in the historical landing and fixed accepted source. This is a static mismatch on that allocation-failure path, not a reproduced crash or a claim that all decoder callers fail. The leaf caller separately initializes its size to zero and propagates the status. The new tests do not force allocation failure.

Scope: MIME draft decoder error contract.
