# The global-search list option opens a completed message collection in a 3-pane tab

This landing adds a false-by-default preference that routes selected search entry points through glodaTableList. The adapter opens a folder-pane-hidden mail3PaneTab with an explicit message collection, immediately for supplied items or after query completion. It handles message results, not the optional IMSearcher argument supplied by the toolbar. The new tests check mode, synthetic-view state, and the preference checkbox; they do not establish result content, indexing, chat parity, or native UI behavior. The original new adapter and these tests remain unchanged at the fixed accepted revision.

Scope: Gloda search preference routing and synthetic views.
