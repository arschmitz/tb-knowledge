# The mailto interface retirement moves test observations to compose fields

This landing removes the mailto wrapper interfaces and parses selected fields in the compose service. The rewritten unit test calls getParamsForMailto and reads compose fields, so its HTML and address expectations include that later layer instead of raw wrapper output. Dropping private from, followup-to, organization, reply-to and priority storage does not by itself establish a new security fix: the old GetMessageContents path did not pass those fields to production compose fields. Preserve this observation boundary when comparing the old and new tests; no complete URI, sanitization or RFC guarantee was tested here.

Scope: Mailto parsing and compose parameter construction.
