# Keep telemetry snapshots distinct from accumulating counters

calendar_count and read_only_calendar_count use labeled_string and set the current quantity. uploaded_size uses labeled_counter and accumulates bytes. Moving definitions in 558 preserves that difference. A schema category or filename is not permission to replace snapshot set operations with counter add operations. Cached Bug 1899602 discussion describes this choice, but only a curated record is available here; it does not complete the whole discussion pass. The current schema and callers independently support the code contract.

Scope: Telemetry data meaning.
