# SafeUri string conversion reports GetSpec failures

The cleanup replaces SafeUri Display with TryFrom<SafeUri> for String. The conversion checks GetSpec.to_result before formatting its output, so a native failure is returned as nsresult instead of ignored. The Graph connectivity log uses its endpoint rather than the former Display path. Fixed accepted conversion keeps this fallible boundary; native GetSpec behavior and failures were not exercised.

Scope: Rust native URI conversion boundary.
