# The leak guide's threshold and detached-window examples have distinct source scopes

The leak guide points to a 50 kB threshold and a detached-window test. The checked comm configuration sets 51200-byte options for two named Thunderbird browser/a11y command lists; this is not every harness's threshold. The selected compose scenario closes its window and clears references before a helper gathers memory-reporter window paths and reports detached entries. This links documentation to concrete configured/test controls without proving leak-free execution, native reporter behavior or all-window coverage.

Scope: Thunderbird leak-detection document and selected harness controls.
