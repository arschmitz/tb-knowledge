# EWS and IMAP restore count notifications before returning a mark-all database error

Both paths disable count notifications, call MarkAllRead, restore notifications and then test both saved results. This manual pairing restores notification state even when MarkAllRead fails. Later commit or undo errors remain separate failures. The code does not roll back a server update or an earlier local read-state change.

Scope: Folder count notification restoration.
