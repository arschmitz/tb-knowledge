# Give Account Hub forms a scroll boundary while preserving header and footer rows

Accepted Account Hub separates a header/body/footer grid from account-hub-step content. Forms have max-block-size 40vh and overflow-y auto inside a view capped at 90vh. The original landing used a simpler flex step and height-based limits. Preserve the current container boundaries when adjusting font scaling; assigning overflow only to the dialog can lose the intended form scroll area. This static layout does not prove keyboard reachability or large-font usability. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub font-aware scroll layout.
