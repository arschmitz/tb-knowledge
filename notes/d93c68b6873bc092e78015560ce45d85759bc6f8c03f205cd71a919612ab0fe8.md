# Reject a directory signature with a generic file-load failure

Entry 2088 changes LoadDataFromFile so a directory returns NS_ERROR_FAILURE. It removes NS_MSG_ERROR_READING_FILE from the C++ definition, C++ and JavaScript message maps, and the compose properties file in the same change. At the fixed accepted revision, ConvertHTMLToText and ConvertTextToHTML propagate failed file loading before conversion, and the directory guard still returns NS_ERROR_FAILURE. Keep the guard and its callers distinct from SMTP delivery errors; this is signature-file loading. No directory-signature test, send operation, runtime, build, lint or live accessibility check ran. External discussion remains pending.

Scope: Compose signature loading.
