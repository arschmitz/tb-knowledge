# Serialize the release prefix before the shell command boundary

The task transform base64-encodes UTF-8 prefix text, then shell-quotes each command argument; the Mach subcommand decodes it back into the email body. This preserves multiline task text across the command-line boundary. The command also passes the Comm revision/repository and declares Comm checkout access. Keep producer/consumer encoding and shell quoting paired; no task graph or actual mail dispatch ran.

Scope: Release email command serialization boundary.
