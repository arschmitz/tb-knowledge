# The context-menu reply test waits for compose editor body text after the window loads

The reply scenario opens a compose window, then polls editor body?.textContent because window-load completion can precede editor-body creation. Only after nonempty body text does it assert that the right-clicked message is quoted and the selected message is not. The null body is a temporary setup state; the test retains the expected quote checks. Static test inspection only, no intermittent test execution.

Scope: thread-tree-compose-test-readiness.
