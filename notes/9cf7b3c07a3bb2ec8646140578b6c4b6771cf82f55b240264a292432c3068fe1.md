# Reset per-message envelope state before parsing the next message

840 resets mEnvAddr and mEnvDate in Kick when leaving a completed message. Getter documentation guarantees the From-line parse is ready when data is available. This reset is part of the next-message lifecycle and prevents metadata from leaking between messages. An empty string and zero mean unknown; they do not prove that the next separator is valid.

Scope: Mbox input per-message lifecycle.
