# The AutoSync logging test checks queue drain after account removal, not the later retained-folder fix

The logging patch guards missing folder owners in timer discovery/update paths and adds timerIsRunning as a non-null-handle probe. Its MOZ_LOG=IMAPAutoSync:4 fixture removes an IMAP account, waits for the timer handle to clear and asserts empty queues. It does not keep deleted folder objects alive or assert a stop deadline. The later accepted DiscardGoneFolders logic and stronger retained-folder/deadline test are distinct behavior and test phases.

Scope: AutoSync logging and timer regression tests.
