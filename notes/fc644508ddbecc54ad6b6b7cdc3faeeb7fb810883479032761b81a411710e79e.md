# Let the contact-picker button grow beyond its minimum height

The address-book context button changes from a fixed height to a minimum height. Current CSS retains a 24px inline size and a 24px minimum block size, with inherited icon color. Preserve the distinction between fixed width and minimum height in this control; the landing does not make every dimension scalable. Font/density changes also require row-geometry updates in the address-book list, which are covered by an existing separate lesson. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Address-book contact-picker sizing.
