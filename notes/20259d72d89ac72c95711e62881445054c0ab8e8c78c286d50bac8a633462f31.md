# Attendance heading messages use value rather than menu label attributes

The accepted agenda heading points to calendar-context-attendance-occurrence-label, whose Fluent attribute is .value. The containing attendance menu uses .label and .accesskey. The all-series heading follows the same value pattern. Keep the message attribute matched to the actual receiver when editing this local menu family. The initial migration used heading .label messages; the later accepted value/ID form is separate and does not prove that initial rendering worked. No locale, heading or accessibility test ran.

Scope: Calendar attendance Fluent receiver mapping.
