# Prefer the documented key-value form for new EventUtils tests

The accepted synthesizeKey documentation recommends key values with KEY_ for non-printable keys and retains VK_ only for legacy compatibility. The implementation strips those prefixes and builds a keyboard event dictionary. Recommend this helper-specific syntax for new tests while preserving existing callers; the documentation cleanup does not authorize a project-wide key-name rewrite. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending.
