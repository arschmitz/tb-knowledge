# The encrypted-body test cases omit the operation field read by their runner

The two encrypted case literals have a shorthand Contains property. The runner reads test.op, and TestSearch assigns its aOp argument directly to searchTerm.op without a JavaScript fallback. Thus these descriptors do not explicitly supply the operation field used by this actual runner. Do not infer the underlying XPCOM conversion or a test failure from that source mismatch alone. The shared hit-count assertion also has no nonempty message; a nearby test comment does not supply it. No test was executed.
