# Use the platform accelerator for tree multiselection

TreeListboxMixin uses metaKey on macOS and ctrlKey elsewhere for additive selection. The tests use accelKey so the harness follows the platform. Shift adds the visible range; Escape keeps the last interacted selected row. Do not substitute one platform-specific modifier in shared tests or claim Ctrl is the only supported interaction from a historic commit description. Source/test assertions are checked; no native keyboard or screen reader run.

Scope: tree keyboard behavior.
