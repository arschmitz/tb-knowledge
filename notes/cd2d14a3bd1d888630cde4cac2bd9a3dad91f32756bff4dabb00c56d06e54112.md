# Preference telemetry snapshots calendar values but observes only tracked mail preferences

This landing reports the tracked mail Boolean, calendar Boolean and mail integer preferences, then registers an observer that updates only names in the mail Boolean/integer lists. The fixed accepted caller retains that order inside a best-effort idle task, whose comment permits it never running. Mail metric declarations explicitly use application lifetime; the inspected calendar declaration has no lifetime field. These source facts do not establish an SDK default, delivered ping value, or a calendar defect. The snapshot-only test export does not exercise observer registration.

Scope: MailGlue preference telemetry update boundary.
