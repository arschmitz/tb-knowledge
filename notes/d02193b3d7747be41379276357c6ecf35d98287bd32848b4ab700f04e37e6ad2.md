# Tree-view defaults cover missing rows and nullish row results

The range-checked _getRow returns null for an index outside the current map. Selected getters use optional chaining and method-specific defaults, including empty strings, zero, minus one and Boolean values. The ?? defaults also apply when an existing row method or property produces null or undefined; they do not only cover absent rows. This is the inspected local return-value contract, not proof of native accessibility queries or a blanket guard for every row-map method. No tree or accessibility test was executed.

Scope: Selected PROTO_TREE_VIEW row accessor contracts.
