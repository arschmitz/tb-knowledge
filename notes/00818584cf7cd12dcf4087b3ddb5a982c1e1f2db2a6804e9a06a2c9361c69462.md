# Thunderbird Account Hub D320328 radio-card accessibility patch updates

`aria-describedby` adds a description; it cannot replace the required accessible name on the `role="radio"` host. `aria-labelledby` could name the host but needs stable IDs for all slotted light-DOM content and robust dynamic-update handling. Existing `#updateAccessibleName()` normalizes full `this.textContent` on every `slotchange`, retaining title, tags, and description together. [Task 1] [ad-hoc note]

Scope: general.
