# OpenPGP preparation must not be gated by the optional Autocrypt header

The original async send migration returns before prepareSendMsg when sendAutocryptHeaders is false. Later review explicitly identifies that skipped preparation as the source of an S/MIME-object error and records a partial backout. Fixed code awaits preparation independently, then handles the optional Autocrypt header separately. The retained compose-send-message event still has a cloudfile consumer. Tests were reported to miss the failing configuration; no send or crypto test ran.

Scope: OpenPGP send preparation boundary.
