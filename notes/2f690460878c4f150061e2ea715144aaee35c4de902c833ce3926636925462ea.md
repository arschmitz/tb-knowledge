# Historical async folder loading does not propagate the worker result to its promise

In entry 1214, the background task calls InternalLoadFolders without checking its nsresult and then resolves the promise with undefined. The dispatch results are also not checked in that source. For comparable asynchronous database wrappers, recommend propagating worker and dispatch failures to rejection rather than treating task completion as successful loading. This is a static historical concern and a scoped proposed rule; the old API is absent from the fixed accepted interface, and no failure was reproduced or reviewer disposition established. Full bug and review discussion remains pending.

Scope: Historical Panorama asynchronous errors.
