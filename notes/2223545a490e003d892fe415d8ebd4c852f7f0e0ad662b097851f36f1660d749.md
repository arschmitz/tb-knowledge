# The Calendar Join Meeting row lands before its action wiring

The original patch supplies a localized native type-button and icon inside the row slots, without a Join Meeting action in the dialog handler map. The accepted later source adds the click handler and a description-derived meeting URL with row visibility control. The mirrored browser fixture is markup, not activation or accessibility coverage. Keep this UI landing separate from the later parser and action phase.

Scope: Calendar meeting-row UI and later behavior.
