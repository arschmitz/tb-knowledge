# Historical EWS silent connectivity still performs the NTLM handshake

The historical connectivity operation passes Silent, but the sender first attempts the NTLM cookie handshake. Success returns Continue so the request can retry; only a failed handshake reaches the Silent guard and returns Break before a password prompt. Silent therefore limits user prompting in this scoped implementation; it does not skip the required first handshake. The later fixed sender has moved to protocol_shared and uses a different error/realm flow, so the old explicit cookie path is historical evidence. No network or cookie test ran.

Scope: Historical EWS authentication.
