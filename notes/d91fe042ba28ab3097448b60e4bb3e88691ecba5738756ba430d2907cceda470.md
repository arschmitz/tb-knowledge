# UI migration52 seeds NNTP user order from immediate subfolder enumeration

For existing profiles below UI52, the migration filters NNTP accounts, resolves each root by serverURI and writes immediate subFolders userSortOrder=i+1 in returned order. New profiles skip legacy blocks. Current code retains block52 under a later UI version; stored user order feeds effective sorting. This is neither recursive reordering nor a physical move. Folder setter metadata lookup can fail while returning NS_OK, so the later version preference does not prove every write persisted or make migration atomic. No migration/database/restart test ran.

Scope: NNTP folder-order migration phase.
