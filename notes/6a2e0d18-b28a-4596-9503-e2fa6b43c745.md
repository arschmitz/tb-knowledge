# Search-bar sends pending autocomplete before a submitted search

The shared search-bar waits 250 ms after input before autocomplete to avoid a quick-filter database view for every keystroke. D210985 requested a change because submit could cancel the pending autocomplete event while consumers still depended on it. Accepted code fires that pending event immediately, then dispatches the cancelable search event. Current code keeps the order. A search consumer must handle autocomplete for the last typed value even when the user submits immediately.

Scope: Search bar.
