# Handle an external import hash only when it differs from the current pane

External import and export commands reuse the about:import entrypoint with a fragment. Current hashchange compares the requested fragment to currentTab before resetting the wizard, so an internal showTab hash assignment does not reset its own flow. A new external pane request resets previous choices and shows that pane. The 2024 patch used a tab- prefix; current source takes a plain paneId union and keeps existing mixed-case IDs such as tabPane-addressBook. Treat fragment spelling and DOM IDs as contracts. No open-tab or navigation run was made here.

Scope: Import navigation and DOM naming.
