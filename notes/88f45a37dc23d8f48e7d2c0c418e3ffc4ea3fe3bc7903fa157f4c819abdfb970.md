# Calendar interface-name strings are not Ci property expressions

Memory-calendar interface declarations use bare names such as calICalendar. cal.generateQI tests those names against keys in Ci, and cal.generateCI indexes Ci by each declared entry. Numeric filter expressions separately read Ci.calICalendar constants. The backed-out cleanup changed quoted names as well as expressions; accepted current source retains bare strings while qualifying the numeric masks. Preserve the distinction when removing abbreviations. Historical alarm-test failure is reported, not reproduced or localized to a fresh assertion here. No Calendar test ran.

Scope: Memory calendar QI/classInfo registry and filter constants.
