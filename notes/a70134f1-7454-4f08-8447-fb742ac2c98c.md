# Message deletion ignores held-key repeats on every message surface

For Delete and macOS Backspace message commands, ignore event.repeat before dispatch so holding one key cannot delete successive messages. Cover three-pane and loaded about:message documents, including standalone windows. D212650 review found the initial three-pane-only fix incomplete. Later bug 1911946 confirms protection is intended; bulk deletion uses explicit selection. Do not suppress navigation or all repeated keys. Commits 272/274 added no automated test; current source retains both guards.
