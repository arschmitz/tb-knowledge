# Use delete wording in the delete API’s user-action description

The current delete schema describes isUserAction as applying to a "copy operation". The implementation uses it for deleteMessages and the surrounding field is deletePermanently. Recommend correcting this local copy-paste description. It is a documentation concern beyond automatic formatting; the source does not prove a deletion bug. Static source and test inspection only.
