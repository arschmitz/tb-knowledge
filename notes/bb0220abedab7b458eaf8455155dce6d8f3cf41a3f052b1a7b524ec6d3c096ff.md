# Keep Fluent assertion metadata separate from rendered text and accessible-name contracts

D214347 chose TodayPane metadata assertions to avoid async propagation across tests, but the author expressly had reservations about treating this as best practice. Other tests wait translateRoots and compare expected literals. Proposed manual review rule: choose metadata only when assignment is the contract; await rendering for text/name/geometry contracts. A passing localization metadata assertion cannot prove user-visible strings or accessible names.

Scope: calendar/test/browser.
