# Transfer folder metadata in a real property bag instead of a fake database object

GetTransferInfo returns nsIPropertyBag2 containing a snapshot of folder properties. The old fake nsIDBFolderInfo lacked a real database row, so its other methods could crash. A property bag states the actual transfer contract and lets summary rebuild and Empty Trash paths retain values without depending on a live database object. InitFromTransferInfo restores properties, then LoadMemberVariables refreshes cached fields. The IDL and folder callers changed together. This is metadata transfer, not a live folder object or a guaranteed complete rollback. No rebuild or Empty Trash run was done.

Scope: Folder metadata transfer architecture.
