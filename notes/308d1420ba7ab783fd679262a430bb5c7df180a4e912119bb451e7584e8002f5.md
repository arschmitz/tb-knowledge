# Outgoing address collection avoids storing list display names as people

The collector uses the outgoing collection preference for createCard and clears the display name for ReplyToList or a name containing " via ". It still passes the address to collectSingleAddress. This is the source policy for display-name collection, not a rule for hiding recipients from the delivery envelope. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: outgoing list address collection.
