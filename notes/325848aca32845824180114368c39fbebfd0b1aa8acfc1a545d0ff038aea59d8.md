# Notification position tests bypass startup delay and check the opener result separately

The position fixture resolves the scheduler startup promise, awaits it and waits a tick before using the idle service. Its non-Linux offscreen test checks that no browser opened, restores the window, then checks the mock opener URL. These checks exercise fixture state and the destination result; they do not measure the real two-minute startup gate. Fixed waitASecond calls remain test limits rather than a general waiting rule.

Scope: In-app notification browser position tests.
