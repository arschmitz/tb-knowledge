# Debian manpage templates retain generated names and external helper limits

Entry 787 adds a manpage.1.in plus a manpages.in packaging list. Current manpage metadata uses ${DISPLAY_NAME}, ${MANPAGE_DATE} and ${PKG_NAME}, and its synopsis states optional OPTIONS and URL. Manual documentation proposal for these templates: preserve substitutions and keep executable names consistent with the package links; escape literal command dashes in the manpage source. This source was inspected as human product documentation. Its list of legacy command-line flags and external helpers was not validated against every current command handler, so it is not proof that all documented options still work.

Scope: debian-manpage-template.
