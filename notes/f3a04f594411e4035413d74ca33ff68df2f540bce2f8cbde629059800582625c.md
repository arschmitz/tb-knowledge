# Popup ID uniqueness coverage must compare the stored IDs

The popup test pushes popupTabId numbers into tabs, then checks popupTabId != otherTab.id for each earlier entry. That reads an id property from a stored ID rather than comparing the IDs, so the assertion does not detect a repeated popup tab ID. The neighboring tab test stores full tab objects, where .id is appropriate. This mismatch persists in the inspected accepted source; it is a static assertion-coverage finding, without a reproduced duplicate ID or CI failure.

Scope: WebExtension content-page popup tests.
