# Thread table background selection and shared header colors have different selector scopes

The table body override uses layout-background-0 only under the thread tree with rows=thread-row. The actual view switch sets that row type for table mode and thread-card for cards. The header change applies layout-background-1 to the shared tree-view-table-header-cell selector, which has a broader scope than the thread-pane override. The manual light/dark test plan does not prove computed colors or contrast.

Scope: Message-list table styling.
