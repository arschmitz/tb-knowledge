# Handle the immediate notification replay for object listeners

The manager overrides addEventListener to send the current UI notification immediately to a newly added newnotification listener. Current code supports both a function listener and an object with handleEvent. The unit test checks that the object receives the current notification and preserves this. The original 805 element uses an object listener, so checking only later dispatched events misses this registration-time path. Non-UI types are deliberately excluded from replay.

Scope: mail/components/inappnotifications.
