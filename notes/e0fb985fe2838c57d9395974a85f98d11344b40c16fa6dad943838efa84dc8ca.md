# New-mail events snapshot headers without eagerly allocating extension IDs

msgAdded creates CachedMsgHeader with addToMessageTracker:false. The snapshot copies author, decoded subject, flags, date, folder and message key immediately. Its id getter registers lazily when an ID is requested. The event consumer starts its list with includeDeletedMessages:true before waking the background page. This supports delayed event conversion without requiring the original database header to remain usable; it does not prove all deletion or move races are covered. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: WebExtension cached new-mail headers.
