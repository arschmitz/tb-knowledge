# The thread-depth fix widens stored levels, temporary arrays and quick-search counters

The original insertion/setter parameters already carry uint32 levels, but the old persistent arrays and several temporary arrays/locals used uint8. This patch widens those stored and intermediate levels together, including cached threaded levels and the quick-search minimum sentinel. The accepted selected producers and storage retain the wider types. GetLevel still writes to an int32 output, so wider storage is not an unlimited-depth or native-rendering guarantee. No test is changed by this commit; the inspected existing cases assert small levels rather than a 256-level boundary.

Scope: Thunderbird native message-view thread depth.
