# Keep Account Hub action event names separate from element and Fluent IDs

In the Account Hub forms, action events use dashed strings such as advanced-config and custom-footer-action. The DOM button ID advancedConfigurationIncoming uses lowerCamelCase, and its Fluent ID account-hub-advanced-setup-button uses dashes. Keep each action string consistent between dispatch and controller handling; match DOM and localization references in their own namespaces. This is a scoped accepted pattern for these forms, not one naming rule for Thunderbird. Source and test inspection only. Full Bugzilla and Phabricator timeline and inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/accountcreation.
