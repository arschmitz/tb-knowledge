# Alias a selected icon to distinguish it from the outer fallback icon

1016 uses { icon: preferredIcon } inside getIcon instead of another icon binding. The outer icon selects legacy size handling; the inner preferredIcon selects a size/theme image and substitutes the Thunderbird default icon. Use a role-bearing alias when both values are needed in the same helper. The fallback substitutions and escaping are behavior to preserve, not just a lint rename.

Scope: Toolbar icon value roles.
