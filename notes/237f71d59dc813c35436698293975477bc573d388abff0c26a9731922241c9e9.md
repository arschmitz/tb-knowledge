# The EWS store migration applies the local failure propagation requested in review

The earlier completion analysis identified a local error that could leave the network status unchanged. This migration supplies the historical repair: its landed OnFetchStop assigns status=rv after the checked storage/header/database chain before notifying OnDownloadFinished. Review explicitly requests that behavior and the source applies it. On an already failed fetch, cleanup does not replace the primary error. The separate fixed Exchange implementation keeps its own queue/completion contract. This augments the earlier source-only finding with applied review context; no fetch or injected disk failure ran.
