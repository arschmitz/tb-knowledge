# Inlining the dialog focus helper preserves receiver dispatch but removes its null fallback

SetTextboxFocus formerly called input.focus only when input existed. Inlining that call removes the fallback unless the caller guards the receiver, as ValidateNumber and link-text validation do. The actual HTML-name control is an editable menulist whose focus override forwards to an internal input. Preserve the receiver and its absence contract when removing a wrapper; this local change does not justify deleting null guards or treating every focus call as a built-in API.

Scope: compose-dialog-focus.
