# Copy known cache fields instead of assigning the whole cached object

The historical theme fix removes Object.assign(this,startupData); current source explicitly copies lwtData and its experiment. Proposed manual boundary rule: restore the fields that belong to the cache rather than let persisted object keys overwrite unrelated constructor state. This is supported in the Theme cache and is not a repository-wide ban on Object.assign.

Scope: mail/components/extensions/parent.
