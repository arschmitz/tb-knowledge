# The compose command-line handler consumes a parameterless compose flag

When handleFlagWithParam throws NS_ERROR_INVALID_ARG in the compose branch, the handler consumes -compose with handleFlag and keeps an empty parameter string. Other error results are rethrown as a Components.Exception with the original result. It then uses the existing main-window and default-account checks before opening compose. This repairs the parameterless path without changing separate osint validation or proving every argument combination. No command-line test ran.

Scope: mail/compose/command-line-arguments.
