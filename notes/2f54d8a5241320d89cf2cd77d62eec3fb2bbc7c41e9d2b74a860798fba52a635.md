# Messenger attachment URL drops fetch ICS before opening an event dialog

The messenger policy adds literal connect-src * for the document. Today-pane agenda delegates drops to the calendar observer. Its URL handler matches filename=.*\.ics within the query, removes URL user information, fetches text and sends it to the ICS parser; the observer opens event dialogs for parsed items. The directive is not an attachment-extension or sender allowlist. Dialog creation is separate from saving an event, and exact network/CSP behavior was not executed.

Scope: Calendar attachment drop and page connection scope.
