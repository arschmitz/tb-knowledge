# Telemetry event-extra keys keep their schema spelling

656 corrects event data keys to is_signed and is_encrypted to match mail/metrics.yaml. The historical generated metric member is mailsReadSecure, while record payload keys keep their exact snake case spelling. Current code uses lowerCamelCase locals isSigned/isEncrypted and explicit object mappings to those snake case keys under the later secureMailLoaded metric. Proposed scoped naming rule: distinguish generated metric members, JavaScript locals and event-extra keys. The formatter cannot establish that the payload matches the schema. The later metric/timing change is only a current comparison here, not a fully studied later landing.

Scope: Telemetry schema and JavaScript names.
