# Follow the calendar locale test filename and shared-task family

The nearby locale files use browser_language_REGION.js such as browser_ar_QA.js, browser_de_DE.js and browser_ja_JP.js. Each named testPrint task passes locale-specific expected output to subtestPrint in head.js. Preserve the underscore/case locale spelling and reuse the shared behavioral helper for this family. Other Thunderbird browser tests use different stems and task casing. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar locale file and test naming.
