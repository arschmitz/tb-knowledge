# A removed special card field can still be an arbitrary property

The current card API uses case-sensitive property names, and AddrBookCard retains a generic _properties map with a separate banished vCard-property list. Phonetic-name identifiers are absent from that banished list and active specialized generation/query APIs are removed. Do not infer that the historical cleanup erased persisted custom data; persistence/import migration was not executed. Preserve exact legacy PascalCase keys when dealing with generic properties. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/addrbook/public.
