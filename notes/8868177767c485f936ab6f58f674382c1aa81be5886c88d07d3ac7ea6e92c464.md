# Offline header streaming takes its URI from an enumerated message header

The offline header test derives the URI from the first header in inbox.messages instead of assuming numeric key 1. Its setup inserts one fixture, waits for folder update and downloads it for offline use. The direct assertion checks only that streamed data includes Content-Type; it has no explicit header-count check and does not exercise unsupported online streaming or prove general enumeration order. No test ran.

Scope: IMAP offline header-streaming test selection.
