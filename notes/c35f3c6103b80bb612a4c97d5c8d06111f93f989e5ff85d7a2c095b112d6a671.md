# Name chat defaults and string parsing as separate operations

The chat account interface separates getChatRoomDefaultFieldValues() for the Join Chat form from getChatRoomFieldValuesFromString(aString) for autojoin and /join. IRC, Matrix and XMPP implement protocol-specific parsing; XMPP defaults can add a discovered service while an empty parsed string supplies only the nick. The UI obtains defaults and mutates those values before joining; command and invitation callers use the parser. Manual API naming proposal in this scope: use FromString for parsing an input string and Default for initial form values; do not overload one method with both meanings. Migrations must update the interface, forwarding account wrapper, protocol implementations, and all command/autojoin/UI callers together.

Scope: chat.
