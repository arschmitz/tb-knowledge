# Use the public parser wrapper when internal stages become protected

The indexer now calls ParseAFolderLine while four parsing stages become protected in nsParseMailMessageState. The fixed indexer still documents its deliberate choice to continue after a parser result, and treats oversized incomplete lines separately. This supports the exact interface boundary and this caller tolerance; it does not support ignoring every parser failure. No malformed-line or indexing runtime test ran.

Scope: Mail parser interface boundaries.
