# The notification DND browser test substitutes the native service on every platform

The shared notification test head registers MockOSIntegration for the osintegration service on every platform and restores registration at cleanup. Its DND getter returns a static test Boolean. testNoSoundOnBiffWithDND sets that value true, injects new mail with sounds enabled, and uses the one-second no-sound helper before resetting it. This checks the manager sound gate with a mock; it does not exercise Windows WNF, Linux GSettings or macOS schedule detection. The current task comment still says Windows although the test is no longer Windows-only. No test was run here.

Scope: notification browser test OS integration.
