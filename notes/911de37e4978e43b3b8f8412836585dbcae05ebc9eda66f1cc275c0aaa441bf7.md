# Narrow getArrivedFolder to the folder type its caller supplies

Fresh full two-file43-line IDL/C++ patch read. getArrivedFolder now accepts nsIMsgFolder aSrcFolder instead of generic nsISupports aSupport, with matching native signature, identity comparison operand and parameter documentation. It does not change the request matching algorithm, result ownership or lifetime; narrowing this named contract does not prohibit nsISupports everywhere. Fixed IDL and C++ retain the narrower type and null result when no processed matching request is found. FolderReorderListener supplies its actual sourceFolder during onStopCopy, returns when no moved folder is found and otherwise dispatches insert-folder. Existing focused arrived-folder callback lifetime knowledge is reused; no durable post-callback query, new copy test, native build or folder move was executed.
