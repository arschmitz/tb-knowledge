# Calendar mode changes close the current dialog before updating the Today Pane

changeMode closes an existing calendarDialog before TodayPane.onModeModified. The tab monitor selects the relevant mode helper; those helpers avoid changeMode when their mode already matches. This bounds the patch to mode changes. The accepted dialog receiver also resets its loading and show-promise state when it closes. The regression test registers a close wait before switching to mail, checks closed/hidden state, then checks that returning to Calendar does not reopen the dialog. The test source is coverage, not fresh execution.

Scope: Calendar dialog mode lifecycle.
