# The CalDAV multi-user fixture isolates authentication and item paths

CalDAVServer authenticates a user from its map and checks that the requested path belongs to that user. Query/sync responses filter by the request path. The multi-user test saves Alice/Bob logins, registers separate calendars on one origin, and directly checks each can read its own UID and cannot read the other. Internal fixture writes now take full per-user paths. This models the inspected client scenario, not a complete real-server access-control implementation or every same-URL configuration. No CalDAV test ran.

Scope: CalDAV multi-user test contracts.
