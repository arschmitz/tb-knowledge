# The compose icon wait checks readiness before an exact path assertion

The compose task checks the default icon and two active setIcon updates. The new wait only requires listStyleImage to differ from none; it does not wait for the requested expected path, so a previous non-none icon can satisfy the wait. The subsequent equality assertion still checks the exact image-set. Keep that condition limit separate from an observed intermittent failure or a claimed cure; no test was run.

Scope: Compose action icon test.
