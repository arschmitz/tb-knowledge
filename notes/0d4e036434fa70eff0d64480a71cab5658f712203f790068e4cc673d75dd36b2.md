# Graph schema names separate borrowed type names from owned module names

SchemaName stores the original schema name and its PascalCase type name. as_pascal_case returns a borrow of stored text, while as_snake_case creates the module name as an owned String. The source comment ties stored PascalCase to the downstream ownership constraint. This preserves the review's accepted local explanation; it does not make caching or repeated conversion a general Rust naming rule or establish a performance result.

Scope: Microsoft Graph Rust generator naming.
