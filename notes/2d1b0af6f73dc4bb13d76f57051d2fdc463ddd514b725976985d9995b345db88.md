# IMAP cache storage ownership belongs to the service rather than a raw static channel pointer

1340 removes the static gCache2Storage from nsImapMockChannel and obtains the storage through a local nsCOMPtr/getter_AddRefs. Accepted nsImapService caches mCacheStorage and returns an added reference. This changes the channel’s ownership and shutdown lifetime, not creation of a new backing cache for every request. Keep service sharing and request-local strong ownership separate when touching this path. This is static source and test-code inspection.
