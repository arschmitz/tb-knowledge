# Navigation shadow-style overrides require both resource redirects and scoped button-state rules

The owned theme manifest redirects both global moz-page-nav stylesheet URLs and packages the matching Thunderbird files. Local Add-ons initialization separately injects aboutExtra.css, which imports the document theme inputs. Within the button override, a[href]:hover and button:hover:not([selected]) share hover styling; selected buttons and focus-visible outlines have separate rules. Exact icon-src selectors choose Thunderbird Add-ons icon variables. The nav sheet gives primary and secondary groups different dimensions and pushes the secondary group down with margin-block-start:auto. This is a scoped resource/selector contract. It does not prove the upstream shadow markup, accessible names, native focus or a restored visual appearance.

Scope: mail/themes/shared/mail.
