# Calendar part 1 moves module diagnostics to per-module debug methods without making arguments lazy

The owned module calls change from cal.LOG/LOGverbose to lazy.log.debug on module-owned console instances with Warn default and calendar.loglevel. Old shared logging definitions and Boolean preferences still coexist in this phase. Retained message expressions, including JSON.stringify, are evaluated before the debug method call; the selected level does not defer them. Plain-script diagnostic removal can remove that work entirely, as with the extraction payload/timer logs. Later accepted prefix changes and part 6's API/pref deletion are separate phases. No logging output was executed.

Scope: Calendar logging migration part 1.
