# Fetch Exchange sync fields in the SyncFolderItems request

Fetching only item IDs during EWS folder sync required many extra GetItem requests. The measured result was more requests and worse overall time despite a faster individual request. Ask for the fields needed for create, read, update, and delete work in SyncFolderItems, then handle items from that response.

Scope: exchange.
