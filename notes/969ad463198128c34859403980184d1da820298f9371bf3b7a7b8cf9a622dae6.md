# Notification URL expansion includes feature-specific and platform placeholders

The 2024 updater changed from reading the raw preference string to formatURLPref. Accepted _getUrl now first replaces %IAN_SCHEMA_VERSION% and then calls Services.urlFormatter.formatURL, so locale, operating-system and channel placeholders are still expanded. For this updater, preserve both stages and test the resulting local request/payload rather than treating the preference as an already resolved URL. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
