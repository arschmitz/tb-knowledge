# The About dialog removes fixed root dimensions while retaining local content limits

The sizing change removes the fixed 670x400px html/body dimensions but retains a 100% block-size container, left-box minimum sizes and a 440px right-box cap. Its actual content receivers include XUL hbox/vbox elements inside an HTML root/container. The opening caller also uses different native-window feature strings per platform. Keep those scoped constraints separate from a claim that every content state grows correctly or that the same CSS works in a different dialog. No native dialog or resize test ran.

Scope: About dialog content layout.
