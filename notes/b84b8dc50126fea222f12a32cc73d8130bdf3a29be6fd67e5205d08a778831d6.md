# Compaction completion uses a base-folder event with local bookkeeping before it

The base folder emits the CompactCompleted event. Its separate CloseDB method leaves Inbox/Trash database references open. The local override clears new-message and processing state, refreshes size and calls CloseDB before the base completion notification. Entry 2005 removes the separate IMAP completion override. Scoped architecture recommendation: keep provider bookkeeping before the shared completion notification rather than treating the event as local-folder-only. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: folder compaction completion dispatch.
