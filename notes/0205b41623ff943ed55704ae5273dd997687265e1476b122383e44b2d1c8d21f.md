# Update the fire closure when a primed provider wakes

The provider callback awaits fire.wakeup when present, then invokes fire.async. convert replaces the captured fire object while keeping the extension and directory ownership. Follow the framework conversion contract when retaining a listener across background restart. Existing onContactUpdated conversion guidance has a different context capture, so it is reused only for the persistence concept, not copied as an identical implementation. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension provider callback conversion.
