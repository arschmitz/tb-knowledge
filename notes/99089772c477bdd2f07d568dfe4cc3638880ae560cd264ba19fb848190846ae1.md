# Window unload complements component-specific observer cleanup

The owned change adds window-unload removal for several process-service observers and calls PanelUI.uninit from messenger unload. Calendar retains explicit deactivate cleanup. The tab strip moves preference removal out of disconnectedCallback while keeping timer cleanup there; its connection body does not add a once-only guard. The current Gloda constructor has a later hasConnected guard. These are scoped lifetime paths, not proof that any reconnect pattern or every window reference is safe.

Scope: Mail window observer lifetime.
