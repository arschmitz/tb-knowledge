# Await the asynchronous history side effect separately from external link dispatch

LinkHelper inserts Places history without awaiting it, but observes rejection. Unit tests register a mock external load promise before action, then await PlacesTestUtils.promiseAsyncUpdates before checking recorded visits. Dispatch to the external protocol service and history completion are separate observable results. Current reusable MockExternalProtocolService replaces the initial inline generator.

Scope: testhelpers.
