# Initialize parser state before any command-specific reset can run

The response parser constructor now sets command flags, UID counters, chunk counters and owned pointer fields to defined initial states. First use must not depend on a later command reset. fSavedFlagInfo is a flag value in the header, even though this constructor assigns false; do not describe every false assignment as a boolean field. The labels parsing branch creates, copies and frees fLabels locally. The commit reports Coverity context, but no analyzer or parser runtime was run here. This supports an initialization review check, not one repository-wide choice between initializer lists and constructor body assignments.

Scope: mailnews/imap/parser-state.
