# Shared container styling must preserve hidden, focus and motion states

Extracting reusable sidebar-panel-header CSS changed display values and made hidden header/remove controls visible. The accepted fix restores explicit [hidden] display:none in the shared/custom scope. Current widgets also preserve focus-visible and reduced-motion guarded transitions; shared header spacing comes from density tokens. Inspect visibility, keyboard focus, RTL logical spacing and reduced-motion behavior with every such extraction. The old header z-index is not a permanent rule; current scroll shadow layers live in sidebar-panel-scroll. These checks here are static only.

Scope: mail/themes.
