# Keep IMAP UID, source database key and destination database key distinct

The undo header says m_idsAreUids distinguishes IMAP UIDs from sequence numbers. Offline operations separately store messageKey as their own row key and srcMessageKey as the source-database key; the current interface also has srcUid. A destination offline move uses a fake destination key and stores the original source key in srcMessageKey. Preserve those identities in names and comments; a generic message ID name would hide which database or protocol value is required.

Scope: mailnews/imap/src.
