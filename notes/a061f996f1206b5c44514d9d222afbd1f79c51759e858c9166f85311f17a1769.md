# The added EWS sync test checks real folder counts and opaque token transitions

The historical task syncs five fake EWS messages through real folder objects, then asserts total/unread counts, a changed saved sync token, the moved message subject and empty folders after permanent-delete cleanup. The fake DeleteItem response now emits one success response per requested ID. These checks add a folder-state layer beyond direct client callbacks; they do not assert every stored body or restart/server/error behavior. Current six-message shared EWS/Graph coverage is a later expansion. No sync or test ran during this study.

Scope: EWS folder sync test coverage.
