# Account Hub schedules system integration only after an allowed close

The request-close path closes the hub only when it is not minimized and reset succeeds. It then schedules showSystemIntegrationDialog through requestIdleCallback with timeout100, so the check does not block the close event. The comment ties ordering to temporary-account cleanup, but the selected helper does not prove every delegated cleanup is complete. The test waits for actual close and conditionally cancels an alert; no OS integration or browser run occurred.

Scope: Account Hub close and system integration.
