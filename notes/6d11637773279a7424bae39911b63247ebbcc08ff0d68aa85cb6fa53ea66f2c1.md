# Pass the mailto identity before choosing the compose format

composeEmailTo delegates to OpenComposeWindowWithURI with the identity. GetParamsForMailto passes that identity to DetermineComposeHTML before constructing the parameters. Setting identity only after parsing would leave the format decision based on another identity. Current source also accepts a preferred format, while URL HTML fields override the default-format path and HTML sanitization can fall back to plain text. Preserve this ordering and those exceptions. The browser test covers different identities, opposite default formats, Shift clicks and an html-body URL; no live composition was run. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Mailto compose identity and format.
