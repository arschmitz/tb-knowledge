# IDL method spelling and native implementation spelling are separate boundaries

The search adapter interface uses lowerCamelCase methods such as addResultElement and a lowerCamelCase read-only searchCharset attribute. Native implementations use AddResultElement, GetSearchCharset and Search with generated interface conventions. The 1462 removal does not change these retained mappings. In this interface family, recommend matching the declared script API and generated native signatures separately instead of applying one casing rule to both. This is a scoped naming pattern, not a project-wide convention. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Search adapter interface/native naming.
