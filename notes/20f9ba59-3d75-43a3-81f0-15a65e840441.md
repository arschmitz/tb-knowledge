# Cover scripting injection by target and permission in Manifest V2

Bug 1896217 established that the scripting API, introduced for Manifest V3, also works in Manifest V2. The added browser tests exercise inline function and file injection, CSS insert/remove, missing permissions, and the messenger alias in compose, web content, and message display. The target needs its own access permission in addition to scripting: compose for compose editors, host access for web content, and historically messagesModify for displayed messages. Bug 1896522 later changed the Manifest V3 message case to messagesRead plus scripting; do not copy the older permission set into MV3. In D210102 the author caught an existing test error: tabs.query returns an array; the accepted code uses const [tab]. Current tests still use this destructuring pattern. No tests were run in this study.

Scope: Extension scripting tests.
