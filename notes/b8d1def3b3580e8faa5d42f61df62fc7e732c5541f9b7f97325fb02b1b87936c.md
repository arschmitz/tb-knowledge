# Omit unrequested rootFolder.subFolders in both manifest versions

This replaces the older lesson that Manifest V2 must keep rootFolder.subFolders null. Entry 716 removes that compatibility branch. Accepted AccountManager.convert adds rootFolder.subFolders only when folders are requested, for both Manifest V2 and V3. Manifest V2 still returns null in the separate deprecated account.folders property. The strict Manifest V2 getDefault(false) test expects a rootFolder without subFolders and folders: null. Do not confuse these two object properties.

Scope: WebExtension account folder contracts.
