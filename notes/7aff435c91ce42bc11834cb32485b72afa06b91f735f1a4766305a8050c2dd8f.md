# Name the IMAP undo predicate for its actual local-mailbox source

The transaction sets m_srcIsLocal when the source URI protocol is mailbox. The old m_srcIsPop3 name described a narrower transport and was replaced throughout Undo/Redo and mailbox-delete paths. Current code retains the new name and clones source headers without adding them to the database for move undo. Use a predicate name that matches the tested source domain. This is a scoped boolean naming example; changing the name did not introduce new undo behavior.

Scope: mailnews/imap/src.
