# Card styles keep current and selected state after removing the selection pill

The owned CSS removes the selection-pill pseudo-elements and represents card/list interaction with container backgrounds and borders. Current and selected remain separate state inputs: TreeView updates the current class/active descendant independently, while the selected setter updates the class and aria-selected. The actual mail and Address Book row constructors supply card-layout/card-container markup used by the shared selectors. Hover, active press and focused/unfocused selection have distinct branches; forced-color outlines remain. This source does not establish rendered contrast, keyboard visibility or screen-reader output.

Scope: Mail and Address Book shared card interaction styles.
