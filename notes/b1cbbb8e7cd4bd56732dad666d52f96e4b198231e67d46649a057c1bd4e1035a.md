# Thunderbird Calendar create/edit attribute-driven source loader

D326596 must retain `setCalendarEventRoute()` before `await dialog.show(event)`; the method comes from D320964's `calendar-event-dialog-source-mixin.mjs`. In the routing test, each task sets `calendar.event.createEditDialog.enabled`, so a per-test `browser.toml` `prefs` line is redundant and invalid; non-xpcshell `prefs` belong in `[DEFAULT]`. Use `@param {Event} [event]` when the trigger can be omitted, and use `itemToEdit` when Calendar Prettier collapses a suggested multiline route call. [Task 14]

Scope: calendar.
