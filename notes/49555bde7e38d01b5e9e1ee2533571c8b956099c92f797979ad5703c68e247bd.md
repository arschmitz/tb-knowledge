# The invitation file-link test separates link routing from dialog arrival

The public invitation attachment caller prevents default link navigation and calls openLinkExternally. The existing helper policy makes its file-scheme permission path independent of the false default preference; that policy is linked to the earlier source lesson. The added test checks the file-URI prefix and waits for an expected permission dialog before canceling it. Its callback Assert.ok(true) marks arrival; it does not assert a native file launch or a security result. Source and fixture identities are checked, but no test, dialog, file or accessibility execution occurred. This finding uses public Git code only.

Scope: Calendar invitation external attachment routing.
