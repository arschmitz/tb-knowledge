# Current OAuth token updates and token clearing have separate APIs

Entry 879 historically removes strict-subset logins and adds or updates a token with the granted scope. Current setRefreshToken first updates the inner OAuth object, modifies matching subset logins to the new password or realm only when changed, and creates a new login only if no matching login was handled and the token is truthy. clearTokens separately clears the inner access and refresh tokens and removes matching stored logins. An external add-on caller is explicitly supported. Manual API naming proposal: distinguish setting refresh credentials, clearing only an access token and removing both kinds of token; do not infer deletion from passing an empty token to the setter. Current storage differs from the historical removal-and-add algorithm.

Scope: oauth-set-versus-clear.
