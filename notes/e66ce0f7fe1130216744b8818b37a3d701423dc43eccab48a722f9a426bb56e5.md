# The folder-copy entry point is on nsIMsgCopyService

The folder-copy paragraph names nsIMsgMessageService::CopyFolder. The checked public copyFolder declaration belongs to nsIMsgCopyService, and its selected request dispatcher calls CopyFolder on the destination nsIMsgFolder. Use that concrete service-to-folder path when reading this paragraph. The owner mismatch remains in the accepted document; this is a static API/document correction, not a new folder-copy runtime guarantee.

Scope: Copy/move document folder API receiver.
