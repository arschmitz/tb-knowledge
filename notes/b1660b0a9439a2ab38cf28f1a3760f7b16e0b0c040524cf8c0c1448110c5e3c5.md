# Windows acrylic styling stays inside its chrome gates

The backdrop 2 background is added only inside the Mica and disabled-titlebar-accent condition, on the custom-titlebar window without a lightweight theme. Fixed accepted source expresses it in messenger.css under not(prefers-contrast) and #messengerWindow. Keep the enclosing gates when copying the preference-specific rule; it is not general content CSS or a claim that all Windows themes need translucent backgrounds. No native Windows rendering or contrast check ran.

Scope: Windows chrome backdrop scope.
