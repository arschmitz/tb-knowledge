# Address-book row changes call densityChange before resetting the list

Correction for lesson250ed638674b74c95dc835e087ee8e7b7486099feb295c4adbece6fe6251fee9: at 0b93f0f7a926ed94c8a0646f18b6734ec7cc0f6d, the address-book font and density events call cardsPane.densityChange, not updateRowHeight. The method assigns both row classes ROW_HEIGHT values and calls cardsList.reset. The virtual list then uses those values for its spacer and row style heights. The original lesson’s observation that CSS spacing and virtual geometry need to stay coordinated remains valid. These are the exact source symbols for the current path.
