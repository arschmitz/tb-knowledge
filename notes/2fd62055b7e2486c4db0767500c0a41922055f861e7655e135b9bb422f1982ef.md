# The legacy account-setup CSP fix permits data images without changing installation code

This historical patch adds img-src chrome: data: to the legacy accountSetup.xhtml policy. It leaves the script, style, connect and default directives unchanged. The source change therefore covers image loading; it does not alter the add-on installer or establish that the separate reported TypeError is fixed. Required Bug comment 3 remains missing, so this is a source-only finding with zero full-audit credit.
