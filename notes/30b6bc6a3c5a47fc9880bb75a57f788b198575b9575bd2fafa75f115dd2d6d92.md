# Preserve incoming configuration when capturing outgoing edits

The outgoing form starts from #currentConfig, updates outgoing values and returns config.copy(). Replacing it with a new AccountConfig containing only outgoing values would lose incoming and identity data. The incoming component test also changes protocol through the visible control and checks that the original AccountConfig remains IMAP while the captured config is EWS. Keep the boundary test distinct from claims that no intermediate object can be shared. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub manual configuration preservation.
