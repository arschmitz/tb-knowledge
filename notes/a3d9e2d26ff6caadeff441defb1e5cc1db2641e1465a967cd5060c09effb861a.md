# Clear unread-only flags before installing an unread-thread special view

Current _setSpecialView starts a view update, forces threading, clears showUnreadOnly, installs the special view enum and clears the search before ending the update. An unread-only message flag and a view of threads that contain unread messages are different filters. The former must not leak into the latter. The showUnreadOnly setter also clears an active special view even when assigned false, and virtual folders reject these special views. Current mutual-exclusion tests inspect wrapper state; they do not demonstrate every visible message combination.

Scope: mail/modules/DBViewWrapper.sys.mjs.
