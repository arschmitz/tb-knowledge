# Successful CMS decoder completion does not establish a non-null content object

MimeCMS_eof handles Finish failure through status, but its layer-classification block also needs the returned content_info object. This follow-up explicitly guards that pointer before GetContentIsEncrypted/GetContentIsSigned and leaves thisPartIsAllowed false if it is absent. Preserve output-object existence as a separate condition from the status code. The source comment records the scenario; no crash, cryptographic result or decoder run was reproduced.

Scope: MIME CMS end-of-file classification.
