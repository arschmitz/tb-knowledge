# A bad mbox start offset becomes a terminal parser error

Entry 1202 stops treating bytes at a missing initial From separator as message headers. The malformed parser state is terminal for feeding and completion, and PumpData returns NS_MSG_ERROR_MBOX_MALFORMED to the stream consumer. The changed gtests cover several chunk sizes, while local and offline-IMAP tests corrupt storeToken offsets. This is the parser’s initial-message boundary, not a ban on all unescaped body lines or a recovery algorithm. All changed tests were read; malformed reads were not executed and review discussion is pending.

Scope: Mbox parser error boundary.
