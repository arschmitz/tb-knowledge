# ICS conflict tests check both answers through a prompt stub and server/cache assertions

This test landing replaces cal.provider.promptOverwrite with a file-wide recorder that returns a configured Boolean. It adds both-answer cases for offline modification against server edit, offline deletion against server edit, and offline modification against server deletion. The checked production branches pass the offline item to the prompt and compare Calendar lastModifiedTime values when a server copy exists. Tests assert concrete server/cache outcomes after a load-and-lock readiness wait; that wait alone is not a success result because the synchronization wrapper catches/logs rejection. The real modal dialog, native mutations, parser and network were not exercised by this source study.

Scope: calendar-offline-tests.
