# Match the folder tree item when increasing drop-target selector specificity

The drop-target rule uses li[role="treeitem"].drop-target > .container, alongside the focused selected-current rule. This keeps its priority tied to the row and role in this tree. Preserve that local structural selector when adjusting drag styling. This example does not justify broad !important use or repository-wide selector specificity rules.

Scope: mail/themes/shared.
