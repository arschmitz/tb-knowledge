# Calendar date-row alignment leaves recurrence visibility with its attribute receiver

The date-row CSS makes its descendant div a flex container with a token gap, aligning the existing date label and recurrence image. The repeats attribute receiver separately sets the image tooltip and hidden state. Keep layout and recurrence state responsibilities distinct; the alignment patch does not compute repetition or prove visual or accessible-name output.

Scope: calendar-dialog-date-row.
