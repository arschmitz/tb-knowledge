# Click a rendered subscription checkbox after scrolling and layout

The historical test waited for a populated tree and a useful row height before computing XUL cell coordinates. Accepted clickTreeRow first scrolls the new tree, waits two frames in its documentGlobal, clicks the actual checkbox and yields for row data to update. Preserve this UI-specific sequencing when changing tree implementations. A frame wait is not a replacement for the separate row-count population condition. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/base/test.
