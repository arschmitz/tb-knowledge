# Alternative MIME candidates and explicit part requests use separate output gates

The follow-up makes non-text/non-multipart children display candidates, while retaining the outer do_display && display_part gate. Separately, an explicit part_to_load bypasses the hidden-part no-op callback; suppress_output also controls saved-state restoration. The earlier failure-exit restoration limitation remains unchanged and is linked. These are bounded static gates, not proof of every attachment operation. Required primary comment5 is unavailable, so full-audit credit is zero.

Scope: MIME alternative output and requested-part streams.
