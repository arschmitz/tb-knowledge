# POP3 checks a failed greeting before starting authentication

After the socket connects, the next initial response opens POP3 processing only when res.success is true. A -ERR greeting goes through pop3ServerError and NS_ERROR_FAILURE instead. The new fake-server test expects retrieval failure and zero messages; its transaction helper permits an excluded trailing QUIT. The fixed accepted guard remains, while its test later checks reason.message instead of the original bare nsresult. No live socket or test run is claimed.

Scope: mailnews/local.
