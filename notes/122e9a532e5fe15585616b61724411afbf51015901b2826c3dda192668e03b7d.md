# The POP transaction helper still compares command lists without an assertion message

The touched partial-download test uses do_check_transaction for TOP and RETR/DELE sequences. That existing helper calls Assert.equal without a message after normalizing optional QUIT and AUTH entries. A focused repair should supply a nonempty message that names the expected POP command sequence and contains should. The test’s new direct assertions do have messages; the helper omission predates this patch.

Scope: POP test transaction diagnostics.
