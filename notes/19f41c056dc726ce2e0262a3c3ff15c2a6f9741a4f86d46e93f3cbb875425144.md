# Resolve merge behavior data before selecting the source repository

671 moves source/upstream/tag/base policy into worker.gecko-rev keyed by behavior. Historical release-to-ESR and ESR bumps read to-repo, while central-to-beta and beta-to-release read from-repo. The fixed accepted code uses branch names and worker actions instead of the old merge-info object, skips bump-only behaviors, and reads version/config from the production source branch. Do not assume every transition has from-repo or every bump needs Gecko pinning. No live branch transition or network-backed transform run was performed.

Scope: Merge automation configuration boundaries.
