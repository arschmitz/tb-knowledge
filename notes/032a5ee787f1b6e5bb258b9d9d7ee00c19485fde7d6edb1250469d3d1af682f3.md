# The forked URL lint rule is configured separately for general tests and xpcshell

The config imports eslint-plugin-sdl and registers its sdl alias. General-test rules name sdl/no-insecure-url with error-level URL/name exceptions, while a separate xpcshell object sets it off. Both then spread inherited Mozilla rules, and the actual path/extension matcher selects each harness scope. This is static configuration evidence, not an evaluated final rule result or permission for production HTTP URLs.

Scope: Thunderbird ESLint test configuration.
