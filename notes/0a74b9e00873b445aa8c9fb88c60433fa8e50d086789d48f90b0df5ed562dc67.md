# Tabmail separates tab buttons from its content panel container

Entry 4641 documents panelContainer as the toolbar containing tab elements. The actual bindings and messenger markup identify tabContainer with tabmail-tabs and panelContainer with the tabpanelcontainer tabpanels element. The latter contains tab content rather than tab buttons. The accepted documentation still has this mismatch. Keep these named element roles separate when using the overview. This is a scoped source/documentation finding, not a UI execution result. Available discussion stays private; the required primary comment 14 remains missing.

Scope: Tabmail documentation and element roles.
