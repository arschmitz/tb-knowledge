# Mailbox-header descriptions keep From and Sender separate

The adopted MailboxHeaders annotations describe From as who the message is from and Sender as the actual sender, which may differ. Bcc/Cc and resent fields name their recipients; receipt headers name the address to send receipts to, with return-receipt-to marked deprecated. These are scoped documentation distinctions, not validation of header parsing or a global naming rule.

Scope: extension mailbox-header documentation.
