# Coalesce preference-triggered message reloads and remove observers at unload

aboutMessage uses one reloadTimeout to combine changes in the current event queue. The callback clears the handle before ReloadMessage, so later changes can schedule again. Preference, color-scheme and forced-color observers feed this route; unload removes those listeners and preference observers. Preserve the scheduling and teardown relationship; the selected source does not show an explicit unload cancellation for an already scheduled reload timer.
