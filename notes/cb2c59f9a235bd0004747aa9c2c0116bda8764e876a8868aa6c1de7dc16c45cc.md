# The Today Pane active-event test skips its first-minute fixture overlap

This landing adds an early return only for hour 0 and minute 0 in testActive, before fixture creation. The test's nominal past event spans the captured day from 00:00 to 00:01; for a same-day setup, the checked agenda predicate start<=now<end makes that event active during the first minute. The test and agenda compare Calendar date-time objects in the default timezone, rather than raw timestamp units. The accepted later test also excludes a margin from 23:58 through the end of the day, which is not part of this original guard. This static pairing does not simulate clock transitions, prove setup and assertions always stay on one day, or establish every intermittent failure is cured.

Scope: calendar-test-boundaries.
