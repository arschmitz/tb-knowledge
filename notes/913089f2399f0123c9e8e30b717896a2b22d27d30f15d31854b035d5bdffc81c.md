# Separate folder drag targets from persistent folder selection

When the dragged row is outside the selected rows, the payload contains only that folder. When it is inside, the payload contains the selected folders. Keep later current guards for server mixtures and offline cases. The regression test verifies moving folderB while folderA was selected, but does not explicitly assert that folderA remains selected after the drop. State this coverage limit rather than treating the review summary as a test.

Scope: folder-pane.
