# Selecting starred rows needs a repaint and a selection signal

The accepted native selectFlagged command suppresses selection events while clearing/toggling Marked rows, then unsuppresses events and invalidates either tree interface. The about3Pane command also dispatches its select event. Keep these separate steps when changing the selection contract: updating selected indices does not itself prove that row styles or message-pane consumers refreshed. No live selection or accessible-state check ran. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
