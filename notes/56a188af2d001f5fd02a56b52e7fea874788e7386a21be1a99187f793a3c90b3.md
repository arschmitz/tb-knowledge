# Register a message completion event before invoking the Edit menu action

The local-message delete test registers DeleteOrMoveMsgCompleted in the first Promise.all argument before activating delete and awaits both afterward. The properties tests verify the dialog URI and its actual folder URI, then cancel and restore focus. In these menu tests, waiting for the result and checking its target is stronger evidence than checking a menu item label. The retained 1200 ms IMAP flag wait remains a test limitation; this study does not claim every action uses a completion event. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/base/test.
