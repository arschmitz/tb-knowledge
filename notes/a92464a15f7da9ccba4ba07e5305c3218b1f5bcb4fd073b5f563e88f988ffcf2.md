# Extension folder matching distinguishes stored names from localized labels

Move/copy child lookup and create conflict checks use folder.name in this reland and accepted code. Rename conflict checks accept either name or localizedName. The native receiver stores one name and may produce a translated display name for known special folders. Preserve the role of each comparison; replacing every localizedName use would change user-facing labels or rename conflicts. These source checks do not establish a complete multilingual migration or a runtime copy result.

Scope: Extension folder identity and conflict checks.
