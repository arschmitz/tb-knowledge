# The RNP minimum version is a runtime library compatibility gate

Entry 180 raised MIN_RNP_VERSION to 0.17.1 with the RNP vendoring work. RNPLibLoader uses the tuple in check_required_version to reject too-old loaded libraries, and the current source says mach vendor updates the tuple during upstream vendoring; the current value is newer. For future RNP updates, coordinate vendored library, exported symbols, build configuration and the runtime minimum rather than changing one number in isolation.

Scope: OpenPGP library loading.
