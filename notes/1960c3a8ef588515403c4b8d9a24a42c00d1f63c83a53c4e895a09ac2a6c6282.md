# Google mail base-domain entries use the existing label-by-label provider fallback

The mapping replaces six exact protocol host entries with gmail.com and googlemail.com, retaining the Google issuer/type-indexed scopes. The existing fallback tries the full host then removes one complete leftmost label, so additional subdomains can use those entries without literal star patterns or substring matching. DAV endpoints remain separate and the requested activity still selects its required scope. Current lowercase/extension-override behavior is later. A recognized provider is not a successful token or connection result. No DNS, OAuth, SMTP or test ran.

Scope: OAuth2 hostname matching and activity scope boundary.
