# Use lower camel case for new script-addressed UI IDs and stable role names

Prefer lower camel case for new IDs addressed by Thunderbird UI scripts in these components. D213166 explicitly changed supernova-logo to codenameLogo and made the name independent of the release. The same ID survives the newer meadow asset. Account colors use serverColor and the address-book Import button uses booksPaneImport. This evidence supports a new-ID convention; legacy dashed IDs and class names have other local families and do not require a blanket rename.
