# Preserve envelope metadata while compacting retained messages

843 passes the scanned envelope fields into the output stream before writing each retained message. The accepted MboxCompactor still does so after its retention query and per-message reset. This keeps a known timestamp available for a later repair, rather than regenerating the separator with the current time. Unknown zero time is subject to the writer default, so it is not preserved as a literal zero.

Scope: Mbox compaction metadata preservation.
