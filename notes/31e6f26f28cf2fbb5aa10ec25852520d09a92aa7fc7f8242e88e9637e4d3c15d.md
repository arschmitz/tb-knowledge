# Cargo regeneration strips serialized feature edges because the template owns section spacing

The generator reads the existing features table and inserts tomlkit.dumps(features).strip() into a template that already separates features from workspace. The historical artifact drops accumulated empty lines, and accepted current code retains the boundary and explanatory reason comment. strip affects edge whitespace of this serialized block; it is not a rule to trim every TOML value or proof of full regeneration idempotence. The suspected upstream library change remains unverified. No generator, parser, Cargo or build ran.

Scope: Python Cargo generator serialization boundary.
