# The forwarded-message signature assertion still targets the parent window

testOpenForwardedSigned creates aboutMessage2 for the opened attachment, but the signature assertion under the attachment-window comment calls hasNoSignedIconState with aboutMessage.document, the parent. The original owned change introduced this receiver replacement, and the fixed accepted comparison retains it. That assertion therefore does not establish the attachment window’s signature-icon state. This is a source coverage gap, not a reproduced failure or an authorized test fix.

Scope: OpenPGP forwarded-message test coverage.
