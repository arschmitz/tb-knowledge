# SyntheticMessage clone separates headers and metadata while sharing its body

The fake Graph copy handler calls syntheticMessage.clone and adds the result under a new _copy ID. clone creates independent structured clones of headers and metaState, but supplies the existing bodyPart to the constructor, which retains that object. Its comment accurately names this shared-body limit. The fake response contains only id; it does not validate a complete external Graph response or repeated-copy identity behavior.

Scope: MessageGenerator and fake Graph copy fixtures.
