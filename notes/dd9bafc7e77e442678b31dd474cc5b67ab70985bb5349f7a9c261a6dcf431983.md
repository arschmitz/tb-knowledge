# An empty mbox is a successful empty scan

The current MboxScanner checks an existing file size of zero and schedules onStartScan and onStopScan(NS_OK) on the main thread. It does not invent message callbacks. A nonempty input stream that parses as a null message still fails as malformed. Keep valid empty storage separate from malformed storage and database repair; the earlier corruption lessons cover different failure boundaries. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
