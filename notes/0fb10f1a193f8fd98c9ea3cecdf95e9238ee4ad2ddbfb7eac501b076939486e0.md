# Document the navigation callback as required when every caller supplies it

The accepted CrossFolderNavigation docs mark navigateFunction optional, but both branches call it unconditionally. A fixed-revision callsite search finds one caller, which supplies this._navigate. Treat the optional marker as a documentation concern, not a demonstrated current crash. For this function, align the signature docs with the required callback or define omission behavior explicitly.

Scope: Cross-folder callback documentation.
