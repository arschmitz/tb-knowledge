# Collapsed recipient labels route cross-window drops through the source widget

The disclosure handler uses the dragged node to distinguish another compose window from a local move. A different source passes its widget and parsed addresses to createDNDPills; local or missing sources use moveSelectedPills. Cc and Bcc share this binding, but the new regression task directly exercises collapsed Cc only. It checks target row/address/count and source removal. Native drag, keyboard, focus and malformed-data behavior were not run.

Scope: Compose recipient disclosure drop routing.
