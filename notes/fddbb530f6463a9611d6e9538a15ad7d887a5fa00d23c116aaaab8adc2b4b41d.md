# Close-to-tray cancels the qualifying window close before hiding

The Windows listener acts only when close-to-tray is enabled and no other three-pane window remains. It cancels the close event and hides the base window. Titlebar and last-tab callers request a cancelable close, and window.close runs only if that request is not canceled. The original minimizes before hiding; accepted code removes that step and later native activation restores only iconic windows. These source phases and mocked hide counters do not establish native window-state behavior or application-Quit behavior.

Scope: Windows three-pane close-to-tray control.
