# Header wrapper state describes an adapter update rather than complete native initialization

The historical Unpopulated/Populated wrappers represent completion of the Rust population method even for an existing database header. Most fields are optional and writes fail in order, so the type transition does not establish complete message data or rollback of earlier native writes. Accepted source uses Stale/Updated names for this utility. Current EWS sync separately passes a header block to the native listener, so do not describe the old wrapper path as the current sync implementation. The proposal and explicit backout are separate phases; no database or memory test ran.

Scope: Scoped Rust message-header state naming and error boundary.
