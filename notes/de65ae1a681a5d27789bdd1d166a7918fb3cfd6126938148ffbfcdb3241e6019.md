# Account Settings localization uses a named action anchor with a separate focus contract

The paragraph and Fluent message share account-settings-url so the localized text retains the Account Settings click action. Accepted source later changes the message ID while keeping that anchor name. The inspected anchor has onclick but no href or explicit tabindex; matching the localization name alone does not establish keyboard focus or native link behavior. Those remain separate source/runtime checks.

Scope: Privacy encryption guidance localization.
