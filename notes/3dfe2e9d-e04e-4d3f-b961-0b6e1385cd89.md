# Capitalize shared system module file names

For a new shared Sync system module, use a PascalCase stem such as CachedStore.sys.mjs. D205784 requested the capital C and the landed file follows it. Keep this scoped to shared module names; engine files in this same area use lowercase plural names.

Scope: Thunderbird file naming.
