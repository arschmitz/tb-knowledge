# Startup system integration uses a profile gate and a dependent dialog

Non-first-run mail-window startup schedules the existing integration check. The prompt opens as dependent rather than modal, and the old immediate post-open default check and mail:setAsDefault notification are removed. First-run classification depends on configured profile data and suppression, while the prompt keeps account/default and search-integration branches. The new Marionette fixture checks a non-default configured account environment; no native startup or OS-default behavior was executed.

Scope: Thunderbird startup system integration.
