# RunAt assertion captions read fields removed from the phase table

The two verifyResult helpers move document/body expectations into documentStates and compare against expectedState. Their captions still read runAtPhases[i].document and .body, but those fields are no longer in that table. The ordinary absent-field false branch therefore says should not exist even where the comparison expects a document or body. Use the corresponding expectedState field for the caption so a failed assertion describes its actual expected value. Both accepted helpers retain this mismatch. This is a static diagnostic finding; no extension injection or test ran.

Scope: Message display script test diagnostics.
