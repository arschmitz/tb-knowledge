# Unified toolbar hidden toggles still pass strings as the force argument

The accepted palette and target handlers pass Boolean.toString() to toggleAttribute("hidden", force). Both "true" and "false" are nonempty strings, so Boolean conversion makes either force true and adds hidden. Pass the Boolean value itself when deliberately repairing these scoped calls, then check all-spaces and per-space actions in their actual menus. The inspected ordinary-target insertion test does not directly assert every add/remove-everywhere visibility case. This is a static source concern, not a reproduced UI failure or an automatic rewrite rule.

Scope: Unified toolbar customization context menus.
