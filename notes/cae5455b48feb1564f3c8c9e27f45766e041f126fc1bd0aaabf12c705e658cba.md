# Stop timer-driven folder search before another shutdown time slice

TimerCallback asks AppStartup whether shutdown has begun, calls InterruptSearch, and returns before TimeSlice. The interrupt path cancels a background timer and notifies listeners of NS_MSG_SEARCH_INTERRUPTED. Keep this early boundary for timer-driven search. It does not establish that every direct search entry is blocked during shutdown or prove the commit-reported shutdown hangs were reproduced. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Folder search shutdown boundary.
