# The delayed AutoTreeView fixture covers blank row objects rather than a missing row

Before resolving its delayed child data, the hierarchy fixture installs two new TreeDataRow objects. Its empty-text assertions therefore exercise truthy placeholders. AutoTreeViewTableRow.fillRow separately returns immediately when rowAt has no row; that branch does not clear or refill the old cell state. The added scenario does not directly cover that missing-row path. This is a bounded coverage distinction, not evidence of an active UI failure or a fresh test result.

Scope: AutoTreeView async test coverage.
