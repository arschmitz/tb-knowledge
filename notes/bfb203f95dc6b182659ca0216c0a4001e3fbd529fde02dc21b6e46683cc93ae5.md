# The tab groupId compatibility value does not implement tab grouping

The inspected tab wrapper returns -1 for groupId. Its schema accepts an optional integer with minimum -1. This supplies a compatibility value without creating tab groups. Review removes a redundant assignment attributed to the superclass, but the paired Gecko constructor was not inspected in this audit. Keep that reported rationale separate from the directly read getter and schema. No extension or native tab-group test ran.

Scope: Extension tab compatibility.
