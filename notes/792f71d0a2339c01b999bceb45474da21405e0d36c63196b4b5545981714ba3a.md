# Thundermail legacy logout adds a second api prefix

The accepted useAuth.logOutAuth calls the OIDC logout helper and then ApiConnection.removeAuthToken. The legacy helper supplies api/auth/oidc/logout to call. buildApiUrl removes leading slashes but adds /api/ before that relative path. The legacy attempt therefore constructs /api/api/auth/oidc/logout and leaves the method at its GET default. The separate OIDC helper uses auth/oidc/logout with an explicit POST. No server response or logout outcome was observed.

Scope: Thundermail generated UI API and auth caller.
