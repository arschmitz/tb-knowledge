# A cached Calendar reset must await `calICalendarProvider.deleteCalendar()` before it reuses storage

A cached Calendar reset must await `calICalendarProvider.deleteCalendar()` before it reuses storage. The later fix also clears item and recurrence caches after deletion, keeps offline flag caches that have no refill path, and checks whether the calendar was unregistered during the await. The provider API now returns a promise for completed deletion. https://github.com/thunderbird/thunderbird-desktop/commit/368ff70f6e02355be7948e50d985be71f3c62509 and https://github.com/thunderbird/thunderbird-desktop/commit/186e2142b778af3fcbfe09f911bc7a8b26da72c1
