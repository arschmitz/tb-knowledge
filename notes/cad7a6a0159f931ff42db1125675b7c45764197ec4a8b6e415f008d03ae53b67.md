# The organizer-object fallback does not cover a missing organizer ID

The alias patch changes the earlier ACL fallback condition from a missing organizer object or ID to organizer || parentItem?.organizer followed by an ID guard. If an item has a truthy organizer object with no ID, the parent organizer is not selected and isInvitation returns false. CalAttendee allows a null ID and CalItemBase's organizer setter does not validate it. This is a bounded static change in preconditions, not a reproduced invitation regression; no added assertion covers this case.

Scope: Calendar invitation classification.
