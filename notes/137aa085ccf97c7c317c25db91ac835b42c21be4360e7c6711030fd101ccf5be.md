# Sparse Panorama child slots must count as rows before messages load

A threaded or grouped Panorama row reserves sparse child-array slots from the aggregate message count before fetching each message. Its rowCount loop must count those empty slots. The selected for...of loop does this; Array.prototype.reduce skips holes and would undercount these placeholders. Tree expansion starts the child loader without awaiting it, then later completion fills and redraws visible rows. This is a sparse-array contract, not a mechanical loop-style rule. No live tree was exercised.

Scope: Panorama/tree-row placeholders.
