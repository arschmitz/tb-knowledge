# EWS folder repair clears sync state before rebuilding the message list

The owned EWS repair branch clears ewsSyncStateToken before backing up and closing the message database, then starts updateFolder. The sync consumer reads this opaque folder token; clearing it allows the message list to be fetched without the previous sync state. IMAP transfer-info handling remains separate. The changed test corrupts local IDs, consumes an initial FolderLoaded event, then registers a new event promise before Repair and awaits it after closing the dialog. Its entries loops pair each message with the saved expected ID. The final loop has no direct final-count assertion, so it alone does not prove all three original messages were returned. Exact accepted source retains these contracts after the repair/test paths move; Graph handling and local-store recreation are later changes. Shared-test var imports and the documented Exchange2013 fake-server default are local harness facts. No runtime result is claimed.

Scope: EWS folder repair and browser-test event ordering.
