# Keep manual account fields aligned with the protocol data they need

The 2024 EWS patch removed its manual incoming-protocol option and the separate outgoing row. The author and reviewers concluded that the IMAP/POP3 form asked for host, port, and connection security, while EWS needs a full endpoint URL with a path and scheme-linked security. Native EWS reused incoming configuration for outgoing; the add-on Exchange path had different sending behavior. D210200 records the decision to remove the EWS manual option for that version. This is historical UI context; check current setup UI before applying it.

Scope: Exchange account setup UI.
