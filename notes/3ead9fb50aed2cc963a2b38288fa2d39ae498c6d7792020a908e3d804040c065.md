# Store notification data before connection and apply it after the shadow template exists

setNotificationData stores the payload even before the custom element has a shadow root. connectedCallback clones the template, finds the container and reapplies the stored data. Current mapping includes CTA, id, title, URL and type, translated to lower-case attributes and data-id. Preserve this explicit mapping; blindly lowercasing payload keys would map title to title rather than heading and id to id rather than data-id.

Scope: mail/components/inappnotifications.
