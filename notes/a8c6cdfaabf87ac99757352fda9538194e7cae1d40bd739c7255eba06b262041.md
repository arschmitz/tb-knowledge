# Treat a component stylesheet as packaging plus host loading

The 1864 landing creates an initially empty calendarDialog.css, packages it and injects a link from CalendarDialog. Accepted CalendarDialog no longer injects that link; messenger.xhtml and isolated test fixtures load the stylesheet. Keep the current resource mapping and host/test loading together. The historical empty file establishes wiring, not a visual design or an executed layout result. These observations are scoped to the cited accepted source and historical changes.
