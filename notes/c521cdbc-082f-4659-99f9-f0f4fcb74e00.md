# Set table header visibility through TreeView.headerHidden

The old table header was hidden by body.layout-table, a page-specific CSS class. Bug 1890731 gives TreeView a headerHidden property and uses it when computing visible body height, then about:3pane and Address Book set the property as their layout changes. D207127 review specifically requested a stable entry point instead of walking child DOM nodes. Current TreeView still exposes headerHidden and about3Pane uses it.

Scope: Tree view layout.
