# Report tree rows within their sibling set

Tree rows report a 1-based hierarchy level and position within the sibling set, rather than treating the flattened row index and total visible count as the group. The original helper scans same-level rows in both directions until a shallower row bounds the group. Fixed accepted source can obtain the same properties from TreeDataAdapter row metadata before using the fallback scan, and updates them during row fill. The collapse/expand test directly checks the ARIA properties and visible row counts. Automation bypasses the accessibility-enabled optimization guard, so these assertions do not prove late production activation or screen-reader announcements.

Scope: TreeView accessibility.
