# Keep the Calendar row labelless layout class separate from expansion state

The accepted :host(.labelless) rule hides the label slot, aligns the row at the start and places slotted content on the first grid row. labelless is a CSS class. expanding and expanded are separate boolean host attributes covered by an earlier note. These selectors do not establish keyboard behavior or an accessible name for an unlabeled control. Static source and test-code inspection only. Full Bugzilla and review discussion remains pending. No runtime, build, lint or live accessibility check ran.

Scope: mail/components/calendar.
