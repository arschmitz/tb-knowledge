# The CardDAV request awaits authentication saving before returning its response

This one-line change awaits the concrete NotificationCallbacks.saveAuth promise before _makeRequest returns its response. The helper awaits login-manager work, but may return early when primary-password enforcement declines and catches/logs operation failures, so completion does not guarantee a saved login. Request-end still fires before this save branch and HTTP-status validation remains earlier. No test assertion changes or fresh login/network/test execution establish the intermittent failure as cured.

Scope: CardDAV request completion and saved authentication.
