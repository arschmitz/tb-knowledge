# Keep EWS mail-class matching separate from classless-folder compatibility

The 1958548 patch creates mail folders with FolderClass IPF.Note and accepts the exact class or a dotted IPF.Note. prefix. A case-insensitive alternative was proposed and declined, so matching stays case-sensitive. The original patch skipped folders with no class. Fixed accepted code later retains those folders for compatibility while still skipping unsupported explicit classes. Do not reuse the old missing-class warning as the current contract. The inspected creation test checks existence, count and parent, not the full class/case matrix. No EWS request or test ran here.

Scope: Scoped EWS and mail filter contracts.
