# Assert locale defaults before calendar views can overwrite them

The shared i18n week, multiweek and month subtests assert their weekday labels and days-off properties before loading dates that could force updates. Per-locale setup checks the week start, weekends, timezone and winter/summer offsets. Same-language en_NZ exercises regional and southern-hemisphere settings separately from language translation. These are inspected test expectations, not independently validated timezone data or executed Linux results. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: calendar/test/browser.
