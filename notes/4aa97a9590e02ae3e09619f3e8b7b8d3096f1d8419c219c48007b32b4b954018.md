# Use local value records for one POP3 partial-message scan

DiscardStalePartialMessages collects PartialRecord values in nsTArray. Each value holds a strong nsCOMPtr header and an owning nsCString UIDL. The old raw-pointer array and manual record deletion are gone. For this one-operation scan, a local value container states ownership and lifetime more clearly than member state carried through callbacks; this is a scoped source pattern and maintenance recommendation. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
