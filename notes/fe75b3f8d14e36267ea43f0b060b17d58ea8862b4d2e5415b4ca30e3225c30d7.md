# Account Hub command blocking follows the modal lifecycle

DefaultController returns false from isCommandEnabled while tabmail.globalOverlay is true. The accepted Account Hub sets that flag when it shows the loaded modal and clears it on close. The address-book transition also clears the flag before opening its tab. The original patch set the flag before awaiting the view and was backed out; that ordering is not the accepted current contract. This evidence covers the named command controller and modal transitions, not every shortcut implementation.

Scope: account-hub-command-overlay.
