# Restoring incoming settings must not reset the edited flag

Incoming setState updates fields and checks completion. resetState alone clears #edited, while actual configuration changes set it. This separation lets revisiting or repopulating a manual form retain whether the user edited it. It describes the incoming form state contract, not all Account Hub components. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Account Hub manual state.
