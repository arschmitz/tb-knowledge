# Email Details needs the calendar owner window

At inspected revision 2135bbdeb7dd3feafb298c0220b412a66cc41826, editable email events with calendar.item.editInTab=true require a document containing tabmail. Calling modifyEventWithDialog from about:message can reach a null tabmail lookup and fail at openTab. Scheduling invitations and read-only items may instead use the summary dialog, so an emailed event is not necessarily an invitation. Bug 2048214 routes X-SHOWDETAILS through the main calendar window in view mode. Its fix is specific to Details; counterproposal rescheduling still uses the caller window. The supplied note reports source inspection and a stubbed Node experiment, not release-binary verification.

Scope: Calendar email Details routing.
