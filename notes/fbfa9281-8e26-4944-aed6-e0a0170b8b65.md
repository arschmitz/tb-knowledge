# Clear Calendar dialog state even when it does not reload

The dialog's checkReloadAndReturn clears data only on the reload path. When the dialog stays open, call #clearData explicitly before reusing it; otherwise stale item state can affect its next position or content.

Scope: calendar-dialog.
