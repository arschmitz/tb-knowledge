# Resume archive year and month creation from the matching folder event

The checked archive patch records the destination parent and child name before asynchronously creating a year or month archive folder. Its folderAdded callback resumes only when both values match, clears them, and continues the batch. The old URL-listener callbacks are removed. The new local/fake-IMAP test waits for oncomplete and directly checks year/month folder names and message counts. Fixed source later awaits createSubfolderAsync instead of using this callback matcher. Keep these historical and fixed implementations separate, and do not infer cancellation, failed-create recovery or all archive branches from this change. Bug 1971248 comment5 is unavailable, so this is source-only knowledge with zero full-audit credit; no archive test ran.

Scope: Archive folder creation completion.
