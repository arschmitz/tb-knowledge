# Small link-button outline space ties margin to minimum block size

The small link-button rule uses --margin-for-outline for its vertical margins and subtracts twice that value from the minimum block-size expression. The Account Hub form rule keeps scrolling and adds literal block-end padding. The button values share a variable, while the container padding remains a separate literal. Review alternatives are retained in the linked audit. This is a scoped source relationship, not verified focus-ring geometry across platforms or a global spacing rule.

Scope: Account Hub link-button focus outline spacing.
