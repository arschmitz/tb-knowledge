# Bracket CardDAV authentication resolution with request notifications

The directory sends addrbook-directory-request-start before searching stored credentials or resolving OAuth and sends request-end in finally, including authentication failures. This marks the directory busy during login-manager access as well as the network request. Preserve the balance when adding new awaited authentication work. The source is a notification lifecycle contract; it does not establish rendered busy-state behavior. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: CardDAV authentication request lifecycle.
