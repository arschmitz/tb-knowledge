# Deletion completion for one folder is separate from verifying every message display

The deletion test arms a DeleteOrMoveMsgCompleted promise on the intended header folder before issuing deletion and logs the header subject around that wait. The event helper matches folder identity and event name, not the deleted header. The following display checks therefore remain meaningful: folder, foreground tab and message window check displayed message state, while the background tab path checks only its title. The original key-based helper has no explicit focus or local timeout; the fixed helper later focuses, issues cmd_delete and races five seconds. These source phases do not establish a cured intermittent failure or successful failure/cleanup behavior.

Scope: multiple-display deletion browser tests.
