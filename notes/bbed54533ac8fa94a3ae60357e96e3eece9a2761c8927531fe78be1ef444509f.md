# The Gecko pin verifier checks tag shape rather than freshness

verify-pin.sh rejects an empty/default GECKO_HEAD_REF, a12–40digit hexadecimal commit reference, and a value without FIREFOX_ prefix. It does not verify that a tag exists or is the latest upstream tag. The task description therefore promises more than this script checks. Preserve this limit when using a passing task as release evidence. Static source only; no task or upstream lookup ran.

Scope: Thunderbird release pin verification.
