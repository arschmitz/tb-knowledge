# Remove both the disabled Chat settings pane and its category

When mail.chat.enabled is false during Preferences initialization, the 1671747 repair removes paneChat to exclude its contents from search and removes category-chat to remove the unusable navigation entry. The same init block removes both Calendar nodes when Calendar is inactive; current code also gives QR export its own later preference gate. This is initialization behavior in this Settings page, not proof of live preference toggling or a policy to disable Chat by default. No search, keyboard or Settings runtime test ran.

Scope: Scoped state and notification contracts.
