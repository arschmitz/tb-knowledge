# The historical MIME switch gate admits an inner signed part under S/MIME encryption

The owned gate adds application/(x-)?pkcs7-mime to the top-level encryption forms allowed to switch for part 1.1 when that part is multipart/signed. Existing position guards and current-message checks remain in the actual historical caller before unregistering and reloading. The two tests cover opposite starting handlers, with different direct assertions: PGP checks final handler/icons after waiting for body text; S/MIME checks body text. Both test files and the dynamic handler API are absent from the fixed accepted source, so this is historical behavior evidence. No MIME, crypto or browser execution proved it.

Scope: Historical OpenPGP and S/MIME handler switching.
