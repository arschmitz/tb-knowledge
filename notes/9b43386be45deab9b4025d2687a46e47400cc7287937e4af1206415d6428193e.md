# Related-account cleanup consumes a mapped dependency set for each login

The async discovery helper returns login GUIDs mapped to Sets of associated account/resources, alongside Sets of related resources. The actual removal dialog awaits that result, records the items it removes and only removes a mapped login when every item in its recorded dependency Set is in itemsRemoved. Outgoing-server discovery separately excludes server keys used by other account identities. This is the inspected map/consumer contract; it does not prove every other account or external use of the credential is tracked, and no cleanup was executed. The helper's arrays/RelatedItems return documentation also does not describe its Promise and Set result accurately.

Scope: Account-related item discovery and login-removal consumer.
