# The Graph copy mock checks the source ID under a destination-move error

The copy handler reads parsedReq.DestinationId into newParentFolderId, then tests !folderId, the source ID taken from the URL. The thrown text describes a missing destination ID for move. The accepted source keeps the same mismatch. Check the intended value and name the copy operation in the error; do not infer destination validation from that message. This is a static source finding, not a malformed-request run.

Scope: Graph fake-server diagnostic accuracy.
