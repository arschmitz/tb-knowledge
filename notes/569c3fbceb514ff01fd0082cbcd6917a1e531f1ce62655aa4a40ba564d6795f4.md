# Exchange streaming appends conversion and header parameters without dropping existing queries

StreamMessage obtains the channel URI, reads its query, appends header= only when requested, inserts & when needed and appends convert=true for converted output. GetUrlForUri separately preserves the original query while changing the scheme and message-key path. Scoped test recommendation: include existing attachment/query parameters when testing either transformation. The inspected service unit tests check schemes only, so they do not establish query preservation at runtime. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Exchange stream query composition.
