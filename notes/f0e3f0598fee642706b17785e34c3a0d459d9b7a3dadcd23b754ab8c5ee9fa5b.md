# Mail popup context colors target the icon receiver while address-book menulists retain their host rule

The patch moves the mail and Get Messages context-paint declarations onto descendant .menu-icon selectors. The address-book footer instead groups the visible menulist and its icons, so the host keeps its declaration too. Values remain a 20% currentColor fill mix and currentColor stroke, with both context properties requested. The popup IDs and iconic menuitem consumers match the selectors. This is the declared receiver scope, not a measured color, platform-rendering or toolkit-construction result.

Scope: Mail menu icon context painting.
