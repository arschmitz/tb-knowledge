# Create the local Exchange folder after remote completion, then notify consumers

Entry 1497 sends the remote CreateFolder request and its callback creates the local folder and records the returned server ID. Current ExchangeFolder preserves that ordering: its success listener checks one ID, calls CreateNewLocalExchangeFolder, stores the Exchange ID and sends folder-added notifications. The local store operation can still fail after remote creation; this is not an atomic local/remote transaction guarantee. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Exchange folder creation.
