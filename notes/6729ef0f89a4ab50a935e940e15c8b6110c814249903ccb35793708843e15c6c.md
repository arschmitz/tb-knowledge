# Use native fullscreen for the macOS top strip

The imported desktop Task 4 summary reports that a macOS standard-fullscreen window started 39 pixels below the display top. Because the gap was outside web content, HTML or CSS could not fix it. The reported solution adds Window → Fill Entire Display (`Control-Command-Shift-F`) using Electron simple fullscreen, which stays on the current desktop; standard fullscreen uses a separate macOS Space. This finding is scoped to the reported macOS/Electron setup. Check current native bounds and Electron version before reuse.

Scope: console Electron desktop.
