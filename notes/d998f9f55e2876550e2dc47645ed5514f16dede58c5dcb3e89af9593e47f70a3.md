# The multipart-alternative test checks attachment listing and body separation, with a missing filename message

The fixture's application/octet-stream attachment carries a small base64 text payload beside the displayed plain body. The test directly checks one listed attachment, its filename, displayed body text and absence of the decoded attachment text. It does not validate attachment retrieval bytes or every binary type. Its filename Assert.equal supplies no message, while the surrounding assertions do. This is a concrete assertion-diagnostic gap in the changed test; no MIME test ran.

Scope: MIME attachment browser regression-test coverage.
