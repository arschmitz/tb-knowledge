# Checked disabled sync rows keep their checkmark and use muted colors

The ce4b5917170a360e04fb2f6fa3278a91ebe5533a patch removes :enabled from the common form checked-checkbox selector, so disabled checked inputs also receive the check SVG. A nested disabled rule supplies neutral border/background and muted fill. A sync-option row containing a disabled input also has pointer-events:none and muted name text. The widget creates a native checked checkbox, disables it for an existing address book, and wraps it with its name in a label. This separates native disabled state from CSS presentation. Historical select-all still assigns checked to disabled inputs; the later fixed version skips them. This CSS patch does not own that later behavior. The inspected initial-state test checks disabled and checked state but adds no color or hit-testing assertion. No visual, keyboard, accessibility or runtime test ran.

Scope: Account Hub checked disabled checkbox presentation.
