# Distinguish file-copy requirements from folder-copy requirements

The accepted file path requires both source file and copy listener, represents a single copy rather than a move and creates sent messages as read versus drafts as unread. The file test waits on PromiseCopyListener, checks message ID/remote ID/storeToken and server membership, but leaves the keyword assertion as a TODO. Do not claim newMsgFlags or requested keyword persistence is covered by this test. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Exchange file copy and test limits.
