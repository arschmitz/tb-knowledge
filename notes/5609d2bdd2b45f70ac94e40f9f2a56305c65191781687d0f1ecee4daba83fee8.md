# Awaited public-key extraction keeps a temporary RNP context alive until finally cleanup

mergePublicKeyBlocks returns await getPublicKey inside try/finally, so its temporary FFI survives the asynchronous handle lookup and text extraction before destruction. The caller awaits the resulting public-key text. Other new finally blocks also destroy tempFFI, but separate key/input/output cleanup remains in normal-path code. This is a scoped JavaScript call-order guarantee, not proof that every native allocation is freed on every exception or that all historical leak signatures disappear.

Scope: OpenPGP temporary native context lifetime.
