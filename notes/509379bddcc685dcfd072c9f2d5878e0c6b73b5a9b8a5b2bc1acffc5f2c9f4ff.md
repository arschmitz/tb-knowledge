# EWS read-flag tests separate local counts, fake-server state and callback identities

This test/fake-server patch adds three different checks: the shared browser scenario observes local message.isRead across background/foreground and preference states; the operation unit test checks local unread counts and synthetic server flags while toggling selected messages; the direct sync test records exact id/readStatus callback pairs for ReadFlagChange. Fake UpdateItem mutates synthetic state and appends readflag, while GetItem reads that state. These do not alone prove every production UpdateItem field, change-key conflict or UI-to-server path. Current code separates token updates from final sync completion and still uses state waits in browser setup. Three initial server-state assertions lack required messages. No test, display or server operation ran.

Scope: EWS read/unread test contracts.
