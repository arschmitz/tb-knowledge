# Remove an obsolete composite predicate with its now-unused leaf helpers

1895 deletes PageIsEmptyAndUntouched, which combined IsDocumentEmpty, IsDocumentModified and IsHTMLSourceChanged. 1904–1906 remove those three unused helpers. The fixed mail-tree query has no remaining reference to the named helpers. The accepted compose close path instead checks compose state flags, and SetContentAndBodyAsUnmodified clears the body/content pair. This is a verified cleanup chain and current-state distinction; it does not prove that an empty message is always unmodified or that the removal repaired a draft-saving failure. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: compose state cleanup.
