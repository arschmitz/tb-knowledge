# Incoming-server preferences separate account overrides from shared defaults

SetKey creates the account-specific mail.server.KEY. branch and a separate mail.server.default. fallback branch. The checked Boolean and integer getters try the fallback when the account read fails, after initializing false or zero. The Boolean setter clears a user value when it matches a successfully read default. These exact selected contracts explain the member comments; the comment-only change does not add fallback behavior or establish identical error handling for every getter. No preference test ran.

Scope: nsMsgIncomingServer preference branch members and selected typed accessors.
