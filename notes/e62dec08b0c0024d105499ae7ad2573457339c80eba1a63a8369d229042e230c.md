# Account Hub success art varies by density and color scheme through separate variables

Entry2133 selects success-page assets and image dimensions through hub-success variables, while the host chooses the light/dark illustration variable. Base uses243x167; compact uses197x130 with separate compact light/dark SVGs. Touch changes link margins and inherits base illustration values. Fixed0b93 retains the mapping and has later shared scroll bounds/logical dimensions; those later changes are separate source context. The new SVG source, registration and CSS/template consumers were read, but no pixels, contrast, font-size or density UI were tested.

Scope: Account Hub success density resources.
