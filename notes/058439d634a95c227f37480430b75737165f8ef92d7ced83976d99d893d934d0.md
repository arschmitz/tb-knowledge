# Use native appearance radios while preserving preference values

The appearance change replaced a menu with a radiogroup bound to mailnews.default_view_flags. Accepted radios carry values 0, 1 and 64; those match no flags, threaded and group-by-sort constants. The group label uses control=defaultViewFlags, and tests click the actual radio and check the preference. Preserve values and native group semantics when altering icons or layout; artwork does not own the persisted view flags. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.
