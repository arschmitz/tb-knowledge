# Account Hub styles distinguish CSS tokens from DOM IDs and module filenames

In this Account Hub family, CSS classes use readable dash-separated tokens such as config-option and link-button-sm, while controller-addressed DOM IDs use names such as editConfiguration and incomingSocketType. Widget modules use names such as email-config-found.mjs. Follow those local forms when extending the same components, and keep each identifier aligned with its selectors and controller calls. These are observed source patterns and scoped recommendations; the evidence does not justify one naming form for all Thunderbird IDs or files. Full bug and review discussion remains pending.

Scope: Account Hub local naming.
