# Calendar dialog outer padding is separate from its internal layout

The new Calendar dialog sets padding to 0 on [is="calendar-dialog"]. Its fixed titlebar owns logical padding and the colored strip sits at block-start0. This preserves a flush outer surface while the title, rows and footer control their own spacing. The original patch used a negative top offset that later changed, so do not copy that historical pixel value as the current pattern. This is the Calendar dialog scope, not a general rule for every dialog. No rendered layout, density or contrast check ran.

Scope: Calendar dialog layout scope.
