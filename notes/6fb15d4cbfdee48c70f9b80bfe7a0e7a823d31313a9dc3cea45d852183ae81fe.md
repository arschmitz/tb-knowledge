# Autodiscover SRV destinations share the HTTP redirect authentication consent boundary

Autodiscover derives an HTTPS URL from SRV data, then routes it through the same base-domain consent helper used for an HTTP redirect. Same-base-domain and the explicit Microsoft base domains bypass that prompt; another domain requires confirmation before authenticated fetching. The accepted async helper checks cancellation after confirmation and FindConfig passes the destination to its UI resolver. DNS discovery alone is not consent. This patch also sorts by ascending numeric weight and chooses the first host; the nearby probabilistic weighting comment is not an implemented selection guarantee. Static source only.

Scope: accountcreation-autodiscover.
