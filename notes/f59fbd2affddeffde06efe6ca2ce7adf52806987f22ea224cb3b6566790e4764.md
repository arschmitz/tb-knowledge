# The search scope weakly owns the search session and closes its stream

The parameterized search-scope constructor stores the folder strongly but uses do_GetWeakReference for the search session. GetSearchSession uses do_QueryReferent, and both destructor and CloseInputStream close the stored stream. Those distinct lifetime contracts remain after the initializer repair. TimeSlice assumes an adapter exists, so constructing a scope alone is not proof it is ready to search. This is source and test-code inspection.
