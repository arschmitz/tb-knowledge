# Certificate-test Fluent IDs describe the action and result

The adopted family uses certificate-check-test-button, certificate-checking and certificate-test-success for connection-testing text. The IDs describe their message roles while existing internal fetch names remain. The historical patch also introduced a failure ID that a later classification removed. This scoped naming outcome does not require renaming every implementation symbol when UI wording changes.

Scope: certificate-check-localization.
