# Retain browsing context and security identity when opening actor-requested tabs

LinkClickHandlerParent opens a new tab with the originating browser group, initial browsing-context group, userContextId, document principal and browser CSP. Extension tab creation similarly passes the principal and extension browsing-context group. Keep navigation policy separate from security identity and container selection; a relaxed policy does not justify dropping those fields. No native or remote navigation ran. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.
