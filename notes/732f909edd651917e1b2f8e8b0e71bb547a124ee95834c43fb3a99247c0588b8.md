# Load the extension API before an isolated selection-event test

The selected-message test first calls mailTabs.query so the extension API is loaded before event-listener setup. Its local helper registers the selection-event promise before telling the parent test to select rows. Preserve both ordering steps when isolating this test. The arbitrary final task-turn yield is not proof that API initialization or selection completed. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: MailTabs isolated test setup.
