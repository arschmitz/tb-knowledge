# Compare both calendar identity and organizer addresses in the same case

The current CalDAV schedule-agent helper lowercases the configured identity email and organizer ID before comparing mailto addresses. The outgoing-message helper likewise lowercases owner email and each attendee address after removing mailto. This fixes the stated case mismatch in this calendar identity scope; it does not establish a general normalization rule for all identifiers or all email systems. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
