# Fall back when X-MOZ-INVITED-ATTENDEE does not identify an attendee

The X-MOZ-INVITED-ATTENDEE property can name an address that is not in the event's attendee list. Check whether it resolves to an attendee before returning it, then continue to calendarUserAddresses to find the invited attendee.
