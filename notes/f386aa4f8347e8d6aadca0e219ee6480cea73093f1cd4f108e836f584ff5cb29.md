# Match OAuth scopes by complete tokens and set inclusion

655 stops requiring the same scope-string order when selecting a stored refresh token. 659 also changes granted-scope comparison from substring matching to token membership. The current module turns scope strings into a Set and accepts a login whose realm is a superset of requiredScopes; it preserves the wider stored scope. This later contract separates wanted allScopes from requiredScopes. Current test excerpts cover the same stored scopes in another order and protocol-specific required scopes. Do not infer that a substring such as part of a URI grants that scope.

Scope: OAuth scope matching.
