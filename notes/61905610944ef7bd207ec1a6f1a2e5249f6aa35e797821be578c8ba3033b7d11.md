# The form-picker checks read the nested autocomplete row label

This landing changes four form-picker assertions from the outer item's title attribute to the nested autocomplete-row-item label. Expected values and the later outer-item click stay unchanged. Each changed Assert.equal still lacks its message argument, so the four sites need a nonempty expected-result message under the current review guidance. The shared fixture and caller checks establish the intended source scenario; they do not verify Gecko's label getter, suggestion matching, native focus or intermittent-failure cause. No browser test was run.

Scope: Browser widget tests.
