# Autocrypt gossip generation has encryption, PGP/MIME and identity gates

Compose requests gossip only when gSendEncrypted, sendPgpMime and the identity's sendAutocryptHeaders are all true; it supplies an empty string otherwise. The generator separately excludes the sender and requires at least two distinct recipient addresses before emitting available keys. The MIME writer consumes the supplied string, so it does not replace that compose gate. The signed-only regression test enables the preference and supplies two recipients whose public keys were imported before asserting that Autocrypt-Gossip: is absent. A one-recipient case could return empty gossip without exercising the new condition.

Scope: OpenPGP compose gossip generation.
