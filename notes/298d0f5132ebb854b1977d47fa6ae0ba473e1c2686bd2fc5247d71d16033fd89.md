# The 115-document CSP patch adds moz-src only to existing script lists

This historical patch appends moz-src: to script-src in 115 owned documents while retaining their other directives and existing inline-script allowance. A script-source addition is separate from each page's image, style and object permissions; it does not register source files or migrate imports. Current selected policies retain that distinction. The title does not prove every CSP was covered, and later missed-policy follow-ups are separate phases. No protocol resolution, CSP enforcement or dialog test was run.

Scope: Owned privileged-document Content Security Policy declarations.
