# Document and free each owned ICU object without freeing borrowed enumeration strings

TimezoneDatabase copies each ICU enumeration string into nsCString; the comment says the returned pointer belongs to ICU and must not be freed. It deletes the enumeration object after the loop, deletes the temporary TimeZone used for identity lookup, and deletes VTimeZone on rejection and after serialization. For this code, review allocation ownership and early-return cleanup together. This is a scoped manual ownership rule and leak-fix mechanism, without allocator instrumentation or an ICU failure test. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: calendar / base.
