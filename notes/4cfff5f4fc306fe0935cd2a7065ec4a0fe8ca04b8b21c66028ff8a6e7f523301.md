# Retain explicit spaces.update argument disambiguation

The accepted update schema makes the second argument required and accepts a URL string, SpaceTabProperties or SpaceButtonProperties. The implementation uses hasOwnProperty("url") to move a second object without url into the button branch. This is a documented workaround for the historical schema parser ambiguity. Avoid simplifying it into two optional objects without parser and caller tests. Current schema/runtime also expose a separate limitation: a tab object without url, such as cookieStoreId alone, is not recognized as tab data here. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces argument compatibility.
