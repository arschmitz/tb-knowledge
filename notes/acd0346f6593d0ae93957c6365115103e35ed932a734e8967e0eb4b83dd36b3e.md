# URI restoration handles missing messages and collapsed threads in the view layer

findIndexForMsgURI resolves the header and returns nsMsgViewIndex_None with NS_OK when the URI cannot resolve. If a threaded message is collapsed, expand=true expands its containing thread and returns the member; otherwise it returns the thread root. The caller filters absent indices and stores the restored indices in a Set, since several members can map to the same collapsed root. Keep expansion and row lookup in this native view helper rather than duplicate key-based restoration assumptions in UI code.

Scope: message-view.
