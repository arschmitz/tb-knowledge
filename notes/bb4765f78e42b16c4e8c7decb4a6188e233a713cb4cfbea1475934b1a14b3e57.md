# The conversion test checks Today pane state rather than More-button geometry

Setup toggles the Today pane, yields and asserts its collapsed attribute before using the More button. Cleanup later toggles and asserts that the pane is visible. These directly checked states do not assert the button rectangle or focus. The fixture assumes an initially visible pane and registers its own restoration callback only after the setup check; it does not preserve arbitrary prior visibility. No native key, viewport or intermittent-failure run was performed.

Scope: Message conversion test viewport fixture.
