# An Option collection and a filtered recipient iterator have different failure policies

Current reply_to_recipients maps conversions and collects Option<Vec<Mailbox>>, so one failed conversion makes the entire optional reply list absent. To/Cc/Bcc instead use address_to_mailboxes, which filter_map skips addressless entries while retaining others. These are distinct source policies; do not replace one form with the other as a shorter Rust expression without checking the intended malformed-address behavior. No parser/runtime experiment was run.
