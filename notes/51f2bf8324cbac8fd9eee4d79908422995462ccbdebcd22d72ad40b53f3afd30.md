# Folder compaction menus share a command while labels follow the selected or overridden target

The File and folder context menus separate ordinary folder compaction from account-wide compaction labels while sharing cmd_compactFolder. The label count follows the selection unless a context override targets another folder; that single override uses singular wording, and a server target uses Compact All Folders. The command dispatches by target type, including selected rows when no current folder exists. Its loop does not await completion. Capability/protocol predicates still decide enablement. The changed test tables check menu states, not compaction results or rendered plural text. The count represents a quantity; the All operation uses its own Fluent ID rather than a count = 0 sentinel.

Scope: folder-pane/compaction-menus.
