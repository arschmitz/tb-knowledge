# End the copied-message listener after the expected message IDs arrive

The accepted OnMessageAdded path counts messages whose IDs appear in m_copiedMsgIds. It appends their keys to the source or destination array according to m_undoing, then removes this transaction as a folder listener when the count equals the expected ID list length. The constructor starts the counter at zero. This is a separate completion contract from the manually referenced database-reparse listener. No notification ordering or undo runtime test was run.

Scope: mailnews/local/src.
