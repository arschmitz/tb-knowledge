# The Linux tray passes FluentResource from fluent_ffi into its Gecko-adapted bundle

The owned compatibility repair changes only FluentResource’s import to fluent_ffi. The resource provider parses built-in menubar/branding strings, and the Linux constructor adds that value to a FluentBundleRc from the same FFI layer after Gecko adaptation. Both fluent and fluent-ffi remain declared dependencies. This is a scoped resource/bundle integration fact; it does not certify the upstream lockfile update, remove fluent or define a project-wide import rule. No Rust build or localized tray execution ran.

Scope: Rust system-tray localization type boundary.
