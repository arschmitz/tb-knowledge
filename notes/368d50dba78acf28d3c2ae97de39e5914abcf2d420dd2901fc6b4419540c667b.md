# Initialize IMAP move notification state before an empty playback

nsImapMoveCoalescer initializes m_doNewMailNotification to false and m_outstandingMoves to zero. PlaybackMoves returns early when there are no destination folders, so relying on that method to initialize them is insufficient. Recommend seeding these scalar fields in construction and preserving that empty-work branch. This is a scoped constructor rule; no copy callback or notification run occurred.
