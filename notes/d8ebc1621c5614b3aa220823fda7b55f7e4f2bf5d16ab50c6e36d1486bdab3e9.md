# The main-window FirstRun binding is supplied to the shared Hub script

The integration imports isFirstRun with var in messenger.js and removes the Hub script's separate const import, declaring that consumed global instead. The accepted import uses the packaged accountcreation namespace. This exact shared-window binding arrangement keeps the two script roles visible; it does not require var in ES modules, tests or unrelated scripts.

Scope: Account Hub main-window script binding.
