# Use the landed destination-recency API name and expose only stored dates

The commit message’s proposed name lastAdded did not become the landed API name. The accepted schema and callers use lastUsedAsDestination. getFolderInfo exposes a recency date only when the stored numeric timestamp is nonzero. Preserve the exact landed API spelling and optional-value contract in code and docs. The separate MRUTime/MRMTime viewing-versus-destination distinction is already shared. A missing timestamp does not mean a recent event was observed. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension folder recency.
