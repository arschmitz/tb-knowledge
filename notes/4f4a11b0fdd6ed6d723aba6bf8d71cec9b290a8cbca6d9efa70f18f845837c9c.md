# NNTP cancellation permits the null listener already passed by the mail command

The mail command passes a null URL listener with its selected header and message window. The repair removes the native listener requirement while keeping the required header check and forwarding the listener/window. The checked NNTP start helper optionally calls OnStartRunningUrl. A separate prompt change uses no parent window; request-window forwarding remains. These are bounded source contracts, not a live cancellation result.
