# A lazy logging object must be called through a logging method

Entry 789 fixes a call of lazy.log as if it were a function in the PGP key attachment path. Current decryption.sys.mjs creates lazy.log with console.createInstance and calls lazy.log.debug for that diagnostic; warnings use their own method elsewhere. Manual JavaScript API proposal for this module: distinguish lazy service or logger objects from lazy callable functions and select the appropriate level method. Formatter success cannot establish a dynamic object is callable. The commit changes no key-import policy, and the current inspected branch also chooses Open or Save according to browser.download.forbid_open_with. No direct regression test was added for this logging path.

Scope: openpgp-logging.
