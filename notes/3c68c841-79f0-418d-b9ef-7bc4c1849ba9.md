# Do not add an a prefix to new JavaScript method parameters

In D208902, a reviewer explicitly asked new methods to avoid the a prefix on parameters. The landed MailUtils.confirmDelete method uses deleteStorage, dbView, and folder. This supports a naming rule for new JavaScript methods, while older code and interface-required names may still use the prefix. Favor this newer accepted form when choosing new parameter names.

Scope: JavaScript naming.

Paths:

- `mail/modules/MailUtils.sys.mjs`
