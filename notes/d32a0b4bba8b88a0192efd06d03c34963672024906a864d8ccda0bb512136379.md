# Use local fixture I/O separately from browser navigation

The CSP test updates replace fetch of packaged HTML, EML, JSON and helper code with IOUtils read APIs. The current menu test still navigates to an HTTP fixture, while its extension files use readUTF8 and its PNG helper returns an ArrayBuffer. Preserve the distinction between loading a fixture document and reading fixture bytes into a test. Do not remove the browser-navigation URL merely because direct fixture reads no longer use fetch. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Browser fixture I/O boundary.
