# Carry the attachment object with the mapped fetch error

MimePart maps a failed attachment fetch to NS_ERROR_FILE_NOT_FOUND and stores the body attachment as exception data. MessageSend recognizes that result and formats the attachment name, falling back to its URL. The mapping deliberately groups fetch failures; the selected source does not prove that each failure is a missing local file. cloudFileAccounts.constants.uploadErr moves to the same platform value. The constants getter stays on the cloudFileAccounts manager; the result-value change does not transfer that getter to an individual account. Fixed MAPI maps this platform result to attachment-not-found while invalid-path remains attachment-open-failure. Source only: Bug 783526 comment 14 is unavailable; reviews are unread. No runtime validation.

Scope: Attachment error data and consumers.
