# Commands Patch Update task lifecycle and resume contract

Recovery differs by mode: Review can rebuild after checkout changes, Verify can refresh newer local copies, and freeform Update rejects a changed checkout. Unfinished state is inferred from competing fields including `status`, `interrupted`, `freeformRequest`, `pendingChange`, `codexTurnId`, item flags, and sometimes message text. Patch operations use process-local maps/status checks whereas implementation recovery uses persistent locks/phases; there is no common recovery contract. [Task 1]

Scope: console.
