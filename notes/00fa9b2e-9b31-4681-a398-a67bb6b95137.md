# Delete absent optional Sync fields to stop cached values returning

The Sync guide says createRecord starts with cached server data to preserve unknown fields, then overwrites known fields. If an optional known field is absent locally, delete record.foo; otherwise an old cached value can reappear as a zombie property. Validate create and update input before mutating objects, and reject changes to immutable fields early. This supplements the code behavior studied in the Sync engine rebuild.

Scope: Sync record cache.
