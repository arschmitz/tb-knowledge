# An identity folder URI is not a usable folder object

Identity FolderURI attributes store references that may not name an existing folder. Code that needs a real special folder uses getOrCreate*FolderAsync and awaits its Promise; the fixed compose caller does so before returning folder.URI. The historical landing used synchronous resolvers and local fallback, but the accepted implementation later calls CreateSubfolderWithListener and completes through its listener. The old synchronous-only IDL sentence does not describe that later implementation. Keep stored references, usable objects and async completion separate. No folder or IMAP operation ran.

Scope: Identity special folder resolution.
