# A historical sentinel initializer does not prove a current sentinel contract

The virtual-folder view constructor sets m_curFolderStartKeyIndex to -1, but its header declares uint32_t. The bounded accepted source search finds assignments during construction, search hits and search reset, with no read of that field in this class. Recommend checking type and live consumers before teaching -1 as a general index convention. This is a narrow static observation, not a reproduced unsigned-index defect or a global sentinel rule. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/base/src.
