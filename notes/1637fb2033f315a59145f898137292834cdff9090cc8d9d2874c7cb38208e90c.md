# Check tag deletion and recreation through message keyword behavior

The current test tags a message, deletes the tag, observes no exposed tag, recreates the same key and sees the message tag again. That scenario checks the persistent keyword relationship as well as folder lookup. Keep the key stable within this test while allowing the visible tag label and generated folder URI to differ. It does not establish that deleting a tag removes the keyword bytes from every message. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Tag recreation test contract.
