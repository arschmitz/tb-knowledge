# Config Found notifications share a title and help link while selecting discovery text

Known discovery source/subSource values select a message for the first description span, while the success title and read-more span are common. The view header uses the new connect-settings ID. The discovery test checks the common content and conditionally checks the mapped ID; its unknown-source case does not assert the first span or localized output. The map can return undefined outside its known cases. This is a scoped producer/test fact, not a runtime localization failure or the earlier requested protocol-count behavior.

Scope: Thunderbird Account Hub configuration discovery messages.
