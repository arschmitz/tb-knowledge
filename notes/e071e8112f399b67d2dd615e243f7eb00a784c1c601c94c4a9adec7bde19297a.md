# Use explicit null choices when null is a valid account result

The accounts schema represents the missing-default-account result as choices of accounts.MailAccount and type null. The old optional return declaration could suggest undefined. Keep the declared value shape and function description aligned. This is an extension-schema contract, not a rule to use null for every missing value.

Scope: mail/components/extensions.
