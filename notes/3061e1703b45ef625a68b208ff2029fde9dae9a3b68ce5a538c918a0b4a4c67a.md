# Each EWS request supplies a processor with the shared server-version handler

The first phase moves SOAP response and version-header processing out of OperationSender. QueuedEwsOperation reads the shared version handler when building its request and supplies a new EwsResponseProcessor when sending. The processor can return a parsed response or request backoff; the sender owns the retry loop. Accepted code later uses a shared sender with associated result/error types, mutable processing and Duration. These are separate interface phases. No build, request or retry test ran.

Scope: EWS response processing and shared transport boundaries.
