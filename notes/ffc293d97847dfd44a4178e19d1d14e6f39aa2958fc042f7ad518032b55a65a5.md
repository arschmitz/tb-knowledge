# Give extension callbacks the actual result schema

The badge text color getter uses async: callback and declares a ColorArray result. The historical change applied the same correction to browserAction, composeAction and messageDisplayAction; a string result did not describe the returned color array. An optional typed callback also lets debug schema checks validate the return value and permits callback-based callers. Check the parent implementation and callback result together. This does not require callbacks for every ordinary JavaScript function.

Scope: Extension schema syntax.
