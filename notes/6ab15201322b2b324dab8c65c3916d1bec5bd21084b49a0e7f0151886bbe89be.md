# Reflect a current UI state directly instead of delayed obsolete attributes

584 replaces delayed filterActive attributes with the searching class driven by gViewWrapper.searching. The no-gDBView early return remains, because the view may still be created. The comment names the same class that the code toggles. Proposed local manual style: choose one named state and keep its producer, consumer and comment aligned; do not leave an obsolete attribute and timeout in place after the styling contract changes. No search state or spinner UI test was run.

Scope: Quick filter state naming.
