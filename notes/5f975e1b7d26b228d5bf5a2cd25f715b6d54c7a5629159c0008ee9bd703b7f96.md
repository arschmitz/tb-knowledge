# Account Hub tests wait for the requested address book after page readiness

The Account Hub sync and local-book tests wait until booksList.selectedIndex matches the created directory UID, then check search focus and clean up. Address Book page readiness can precede the requested selection: the tab handler defers its onLoad callback so initial selection completes before the supplied command runs. Current tests use TestUtils.waitForCondition; the owned patch first used BrowserTestUtils. This distinguishes ready from the requested selected state without claiming remote sync, focus or race execution. The expected index is captured once and assumes the row exists.

Scope: Account Hub address-book test synchronization.
