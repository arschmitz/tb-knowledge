# Calendar chrome mid links use MailUtils while content links defer to MailLink

In the inspected fixed launchBrowser helper, content mid/mailto/news/snews links return before a second dispatch. The MailLinkChild handler sends these protocols to its parent actor. Chrome mid links instead pass url.slice(4) to MailUtils.openMessageForMessageId and return before the external-browser path. MailUtils looks up a header and displays a found message. The optional event and task attachment caller need separate checking; this evidence does not prove every caller is safe or that every Calendar surface registers the actor. Static inspection only.

Scope: Calendar link handling.
