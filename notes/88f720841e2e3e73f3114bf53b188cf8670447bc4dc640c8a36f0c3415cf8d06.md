# Shared notes require corrections instead of edits

At TB Tools revision f2bd7b158ee4d3386e20389d99d7c19fee54eda6, importing a shared note compares its text fingerprint with the previously stored fingerprint. If they differ, import fails and asks for a correction. This protects previously imported evidence from silent changes. The check applies when a prior fingerprint exists; it does not establish that every first import detects historical edits.
