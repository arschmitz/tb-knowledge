# Track replacement coverage when a refactor moves header ownership

Proposal for Account Hub refactors: when header nodes move from the dialog to a widget, remove obsolete dialog selectors only with a named replacement test scope. Entry 602 deliberately removes default/welcome-header assertions after the header split. The author promises header-template tests later; that promise does not show those tests landed. Preserve the opening/closing contract separately from header state. Check the actual shadow root and current widget owner before restoring selectors. The same patch corrects a malformed nested hover/active selector, which is a separate CSS change. This scoped proposal does not make test deletion a default and does not claim a browser test or accessibility pass.

Scope: mail/components/accountcreation.
