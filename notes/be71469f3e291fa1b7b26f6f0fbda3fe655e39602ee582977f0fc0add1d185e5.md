# Windows AArch64 debug and opt tasks opt into comm-central explicitly

This patch changes the existing win64-aarch64 debug and opt task lists from no run-on projects to comm-central. The accepted entries keep that explicit selection. It does not alter their toolchain or worker definitions, enable every project, or prove that an ARM build or test passed. Keep this task-selection phase separate from the preceding RNP flag refactor and earlier disablement.

Scope: taskcluster-build.
