# Commands console reliability, task recovery, storage retention, and patch identity

Footer/status markup is in `commands/graph/templates.mjs`; `startGraphMachAction()` renders “starting...” and waits for `/api/mach-action`, so preparation can defer a session. Output/Cancel stay hidden until that session exists, and `renderMachStatus()` can suppress later updates while the initial busy state remains. [Task 2]
