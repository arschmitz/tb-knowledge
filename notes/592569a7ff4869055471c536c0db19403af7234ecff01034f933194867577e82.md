# Distinguish a toolchain target from its worker architecture

The 757/760 task changes add an arm64 macOS worker while retaining x64-target toolchain references. A worker architecture and the architecture of the output are different configuration roles. Current code retains the arm64 worker definition while toolchain versions and references have changed. This human-authored infrastructure work remains in scope; it is not excluded as an automated bulk commit. No cross-compiler or worker job was executed.

Scope: Toolchain worker and target configuration.
