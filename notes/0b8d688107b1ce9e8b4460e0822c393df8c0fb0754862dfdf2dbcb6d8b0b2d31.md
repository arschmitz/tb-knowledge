# Test a context command with a different current folder

testPropertiesSettingsFilters deliberately opens inboxFolder while acting on another folder/root. It registers dialog completion before the action, awaits focus, checks the target URI, and closes with Escape. Using the same current and context folder would hide a wrong-target bug.

Scope: mail/base/test/browser/menus.
