# Saved-search compaction tests need completion and a direct view assertion

The test deletes the first local message so compaction invalidates the next key, then opens a saved search and compacts its underlying folder. Entry2178 added a nonempty-row wait and a real header assertion. Follow-up2201 replaced the manual completion flag with PromiseUrlListener and removed that intermediate row wait; the fixed test directly checks the header at row0 after URL completion and one event-queue turn. The bug records failures after early attempts, so neither acceptance nor a completed test task establishes that intermittents were eliminated. The explicit header assertion is stronger evidence of the intended view contract than the old unconditional completion report.

Scope: Saved-search compaction browser tests.
