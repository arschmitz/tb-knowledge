# Offer the opposite junk action for one message and one bulk action for many

1018/1022 add navContext-markAsNotJunk. fillMailContextMenu compares junkscore with IS_SPAM_SCORE; one selected message exposes the opposite action, while multiple selections expose Mark as Junk and hide Mark as Not Junk. The command map, native menu item, shared spam icon and disabled-state CSS must stay aligned. Current Fluent IDs use spam wording, but the DOM/command IDs retain Junk. These are separate naming contracts.

Scope: Mail context navigation junk toggle.
