# Keep RNP compatibility flags under the actual ABI condition

The owned rnpdefs configuration ties the pre-GCC-5 string ABI setting, -fno-sized-deallocation and -fno-aligned-new to MOZ_STDCXX_COMPAT. The surrounding clang-cl branch is separate. Read the actual guard when modifying these flags; the historical subject’s reference to Clang is not an extra compiler-only condition in accepted code. The small lint follow-up changes formatting and supplies no new manual syntax rule. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: RNP standard-library compatibility.
