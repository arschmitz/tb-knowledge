# Update the thread preference state even when no folder is selected

The thread preference observer assigns the table horizontal-scroll property before the gFolder guard and refreshes columns only with an active folder. Startup installs the observer and teardown removes it. This lets future folder views use the latest state without calling folder-dependent work on an empty view. Keep state synchronization separate from work that requires a folder. No live observer lifecycle test ran.

Scope: mail/base/content.
