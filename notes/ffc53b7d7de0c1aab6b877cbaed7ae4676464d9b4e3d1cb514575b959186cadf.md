# Apply dark-reader changes after message load and reload to restore the original content

1113 listens for MsgLoaded and applies adaptation only when the dark media query matches; the adapter itself checks mail.dark-reader.enabled. Theme changes trigger one deferred reload, and that pref is observed for reload as well. Disabling the feature therefore reloads message source instead of trying to invert previous DOM mutations. Current source keeps this contract and coalesces preference changes through timeoutReload. Its later focus/scroll toggle behavior is accepted context, not part of the original landing.

Scope: Dark-reader load and restoration lifecycle.
