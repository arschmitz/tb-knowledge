# Account Settings requests main-window focus before its tab is reused or opened

MsgAccountManager requests win.focus after it finds an existing main window and before it searches for an Account Settings tab. The existing-tab branch updates the server and page, calls onLoad and switches tabs; the new-tab branch retains its account-tree focus callback. The no-main-window path remains a separate openTab window fallback. This is source-supported routing and a focus request, not a cross-platform native foreground result.

Scope: Account Settings foreground routing.
