# Document the chat log filename parser return shape and timezone limit

getDateFromFilename parses YYYY-MM-DD.HHmmSS+ZZzz.format, returns [] for a mismatch and otherwise returns a Date plus format string. The implementation explicitly ignores the parsed timezone offset. Current callers destructure the pair and check missing date/format. When extending the parser, preserve the invalid-name outcome and document the timezone limitation; do not treat a generic any[] annotation as a precise timestamp contract. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending.
