# The historical compose argument join checks emptiness before reading First

The older C++ compose handler stops joining at a nonempty hyphen-leading argument. It now checks IsEmpty before First, so an empty following argument is appended as a space and the loop still advances. Preserve that consumption behavior if repairing this historical branch; simply skipping or stopping on empty input would differ. Accepted current compose handling moved to JavaScript and is not proof the old loop still runs. No crash or command-line test was executed.

Scope: C++ command-line fragment and option boundary.
