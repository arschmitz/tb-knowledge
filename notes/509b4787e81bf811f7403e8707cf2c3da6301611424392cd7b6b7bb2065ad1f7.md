# Dark-reader toggle tests wait for CSS state rather than message reload

The accepted toggle-visibility test waits for prefers-contrast or the toggle visibility after simulated accessibility-theme changes. Its source explanation says Windows forced-colors can cause a default-theme substitution, so a theme switch need not reload the message or fire MsgLoaded. Wait for the state this test checks; the separate theme helper still waits for windowlwthemeupdate. This is a scoped harness contract, not proof of native contrast, accessibility or a fresh test pass.

Scope: Message-reader dark-toggle test completion.
