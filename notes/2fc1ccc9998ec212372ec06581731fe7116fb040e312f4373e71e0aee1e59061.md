# Use the feed dialog own shared folder-property imports

The Thunderbird feed subscription dialog imports FolderUtils directly and combines its getFolderProperties result with FeedUtils properties for the selected folder or feed parent. The actual shared helper supplies folderNameCol and common folder state; the feed helper supplies feed/error/busy/paused state. This avoids reading FolderUtils through another window global. The checked production entrypoint opens from the top Chrome window, but this study does not prove all dialog lifetimes require that window to remain open. The review reports a combined test fix while explicitly leaving broader removed checks unconfirmed. Removed non-Thunderbird behavior is excluded from this lesson.

Scope: Thunderbird feed subscription tree properties.
