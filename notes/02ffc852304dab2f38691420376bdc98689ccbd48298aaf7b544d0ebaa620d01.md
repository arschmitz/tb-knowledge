# Register view wrappers for teardown when adding test helpers

The removed clone helper registered its returned wrapper in active_view_wrappers. Accepted make_view_wrapper still registers a new wrapper, and postTest closes registered views, checks notification listeners and clears folder databases. Recommend preserving that teardown ownership when introducing another factory or clone helper; the deletion does not make registry cleanup optional. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
