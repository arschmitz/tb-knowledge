# MIME display completion and abort use the already validated data pointer

In mime_display_stream_complete and mime_display_stream_abort, conversion to mime_stream_data is followed by an immediate return when msd is null. The 10924e4996b79aac2e60a5dcdcfbd739070fa576 change therefore reads msd->obj directly instead of testing msd a second time. The object check and the distinct completion/abort cleanup remain. This invariant applies only after those local guards; it is not a rule to remove null checks from unrelated callers.

Scope: MIME display stream completion and abort.
