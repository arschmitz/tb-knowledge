# Flatpak metainfo renaming must follow the template through packaging

The template input, substituted APP_ID.metainfo.xml output and share/metainfo installation use the same filename family. AppStream compose writes metadata/icons/media under the application tree, and the screenshot ostree commit consumes that media path. This source connection is narrower than a successful lint, build or deployment.

Scope: Flatpak metadata pipeline.
