# Sort tree values with a numeric locale collator

TreeDataAdapter sorts by getValue(column) first, then getText(column) as a tie breaker, using an Intl.Collator with numeric:true. This lets a column have a semantic sort value separate from its display text, and orders digit strings numerically. The xpcshell test covers 11 versus 2, Roman numeral text backed by numeric values, equal groups, and both directions. Current code retains the comparator. Do not assume visible text is the sort key.

Scope: Tree sorting.
