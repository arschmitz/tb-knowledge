# Message-reader fixture names and browser test names follow different local conventions

Entry 1297 renames Image sizing test.eml to image_sizing_test.eml while retaining browser_imageOverflow.js. The accepted test uses that exact underscore-separated fixture basename. Neighboring fixtures include both underscore names and older camel-style names, so consistency supports a scoped recommendation for new descriptive fixtures in this family rather than mass renaming. Keep the browser_ harness prefix and the local test suffix style. This is naming guidance beyond formatting, not an established project-wide rule; no file-loading test was run. Full Bugzilla and Phabricator discussion remains pending.
