# Keep file-backed EML saving separate from database-backed message naming

Entry 768 adds direct saving for an opened EML file and disables Save as Template for a dummy message. Current SaveAsFile checks a single file-scheme URI, decodes the nsIFileURL filename, and delegates to MessageSaver.saveAs with the window browsing context. Other messages still use message headers to generate names, and multiple messages use saveMessages. The historical URL suffix regex and top.saveURL call are no longer the current implementation. A message display does not prove a database header or template operation is available. Manual review proposal for these commands: name file-backed and database-backed inputs explicitly and test both command availability and the resulting filename.

Scope: eml-save.
