# Flatpak runtime, SDK and BaseApp versions are consumed separately from the builder image

The original upgrade aligns runtime and BaseApp variables at 25.08 and changes the builder image to Freedesktop 25.08. Repack uses those variables for BaseApp installation and runtime/SDK/base metadata. Accepted source retains the package versions but later chooses a pinned linter container. Keep the package environment separate from the image that builds it; source values do not prove external compatibility or a successful package.

Scope: flatpak-packaging.
