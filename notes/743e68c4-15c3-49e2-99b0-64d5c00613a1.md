# Convert local message keys to UIDs for IMAP fetch URLs

When streaming an IMAP message, the offline database lookup needs nsMsgKey, while the server fetch URL needs ImapUid. Convert in both directions at that boundary and handle a missing mapping instead of assuming the values are identical.
