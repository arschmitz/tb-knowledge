# The Graph extractor validates pinned input before replacing generated directories

The command accepts cached OpenAPI bytes only when their digest matches the configured value. Otherwise it fetches pinned bytes and checks them before writing. Only after that helper returns does it replace src/paths and src/types. A checksum failure therefore precedes output removal in this caller. A later extractor failure has no caller rollback and may leave incomplete output. This is static ordering, not a fetch or failure-injection result.

Scope: Graph source-generation input boundary.
