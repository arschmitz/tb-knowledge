# Treat the OpenPGP draft delay as a bounded test workaround

The draft test waits 100 ms because saving immediately could open the Save dropdown or reach encryption before recipients were available. The comment states uncertainty, and the bug reports more failures with a related parser change without proving that cause. Review replaced an unavailable xpcshell delay helper with a browser-compatible Promise. Current code retains the delay with an explicit arbitrary-timeout lint exception. Do not turn this into a general preferred waiting rule or a product fix. Use a readiness event or condition if one is available and validated. No intermittent reproduction was run here.

Scope: Draft test readiness limits.
