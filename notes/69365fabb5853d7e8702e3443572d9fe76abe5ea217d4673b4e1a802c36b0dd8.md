# Put Glean definitions with the component and register every file

558 replaces the historical tb category with component categories: mail, addrbook, filelink, compose and calendar. It adds component-relative metrics.yaml files, updates MOZ_GLEAN_EXTRA_METRICS_FILES, changes producers in JavaScript and C++, and changes test lookups. Current configuration retains this placement and adds notifications and Exchange files. A directory move without build registration will not create the expected generated API. Older prose that requires a tb prefix is superseded by these accepted source names. No Glean generation or build was run.

Scope: Glean component boundaries.
