# The noreply warning matches the address local part and lets the user continue

Accepted reply handling tests the first parsed email from replyTo or author with an anchored noreply expression. The plus sign is allowed after reply in the suffix group, not anywhere in an address. A warning offers cancel or continue; it is not a send prohibition, nor a domain-substring match. No regex experiment or actual warning UI was run. This is static source and test-code inspection.
