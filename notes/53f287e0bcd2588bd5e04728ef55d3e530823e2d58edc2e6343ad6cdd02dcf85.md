# Track the remaining raw IMAP path allocation after smart-string conversion

The checked ReplaceCharsInCopiedString patch replaces the duplicated path buffer with nsCString and changes ConvertToCanonicalFormat to return a string value used by its callers. A separate allocation remains: AddOnlineDirectoryIfNecessary uses PR_Malloc and returns newOnlineName through directory. The fixed AllocateServerPath copies the returned onlineNameAdded into aAllocatedPath and shows no release before return. Treat that directory-prefix branch as a separate ownership concern when checking the refactor. No sanitizer reproduction ran, and this observation does not say every path leaks or that the original report was unchanged. The existing arbitrary hierarchy-delimiter ambiguity is explicitly outside this fix.

Scope: IMAP path conversion ownership.
