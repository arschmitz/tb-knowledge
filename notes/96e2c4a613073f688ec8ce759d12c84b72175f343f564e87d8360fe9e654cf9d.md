# A regression test that catches service lookup failure does not prove conversion ran

The removed test_bug387403 called the old msgvcardservice inside an empty catch. D212660 explains that the service was dead and the test did not exercise its intended parser. The public removed code confirms lookup, conversion and all errors were swallowed together. Check that a regression reaches the current implementation and asserts its result before treating a pass as protection. Current test_nsIAbCard calls fullCard.toVCard and checks raw BEGIN/END boundaries, field lines and UID. Those basic assertions do not by themselves prove malformed-vCard crash recovery or URI escaping. Scope: address-book conversion tests. Only source was read; no tests ran.

Scope: address book test validity.
