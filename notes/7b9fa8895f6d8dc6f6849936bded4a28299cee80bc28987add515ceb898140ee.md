# Graph delta response generation passes the collection element type to DeltaResponse

The extractor requires a collection response body, clones its property and clears the collection flag to generate the element type. DeltaResponse itself owns Vec<DeltaItem<T>>, so generated folder-delta operations use DeltaResponse<MailFolder>. The related types and imports move into a pagination module; the generated files reflect that local module contract. Do not infer remote schema validation, borrowing guarantees or a global wildcard-import rule from these generated examples.

Scope: Graph extractor delta response type wiring.
