# Exchange recommendation and stored protocol selection have separate roles

The initial code compares the service URL origin with the Graph origin to choose a recommended card, but a recognized stored protocol still chooses the selected card. Recommendation class/description and scoped CSS control badge and legacy-tag visibility independently of selection. The selected capture keeps the supplied endpoint instead of substituting a protocol default. Accepted source later uses URL.parse tolerance. Tests assert the Graph-recommended/stored-EWS distinction and passed endpoints; no service compatibility or UI/runtime result is proved.
