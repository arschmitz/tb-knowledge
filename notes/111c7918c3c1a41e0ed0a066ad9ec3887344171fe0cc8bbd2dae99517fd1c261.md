# OpenPGP test key import waits before consuming imported IDs

The inspected OpenPGPTestUtils.importKey helper awaits EnigmailKeyRing.importKeyAsync before reading the imported IDs. A nonzero status returns an empty array; success returns a copy of fingerPrintObj.value. importKeyAsync itself updates key/cache state after awaiting its implementation. These are asynchronous completion contracts even where old JSDoc still describes an integer. The harness-tag and headless-skip edits do not directly assert this ordering. No key import, XHR or UI workflow ran.

Scope: Scoped source study.
