# Folder picker construction flattens one Gmail grouping node before filtering

When enumerating a server parent, the picker replaces the first matching Gmail grouping-folder entry with that entry’s children and then applies its normal filters. The native IMAP getter delegates to a base getter that copies references into the output array. This is a presentation-array transformation; it does not alter the native folder hierarchy. The menu tests compare labels/structure across configured modes, while recent/favorite destination population remains TODO coverage.

Scope: Folder picker hierarchy and local array ownership.
