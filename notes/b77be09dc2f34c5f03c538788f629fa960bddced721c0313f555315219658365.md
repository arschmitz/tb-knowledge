# Replacing an open Calendar event closes the dialog before changing its route

setCalendarEvent validates the input, closes an open dialog, and only then changes event-route attributes. Callers that want the replacement visible must show it again; the changed location/visibility tests adopt that order. This is a presentation/lifecycle ordering change, not proof that every outstanding load is cancelled. Later callback, recurrence and readiness handling remain separate accepted phases.

Scope: Calendar dialog event replacement ordering.
