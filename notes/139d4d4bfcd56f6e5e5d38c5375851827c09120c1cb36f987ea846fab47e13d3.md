# The original Gloda recipient cap is separate from the list passed to Intl

The original rewrite builds a capped list but formats another full array, and checks an impossible > 3 length after slicing to at most two. It also reads name directly from identity values. Accepted code later reads contact?.name, caps three named recipients, counts every omitted recipient, formats that same list and uses Intl part.type for classes. Later fixture tests directly check overflow and unnamed recipients. Keep the original mistakes and later repair/test phase separate; no indexed-message or locale run was performed.

Scope: Gloda result recipient rendering.
