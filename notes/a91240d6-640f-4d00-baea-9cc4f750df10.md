# Gate system OpenPGP dependency options with pkg-config availability

Bug 1898715 fixed build bustage after an upstream configure change. System JSON-C, bzip2, Botan and OpenSSL option handling now uses when=use_pkg_config where pkg_check_modules dependencies require it; JSON-C has a separate dependent choice for in-tree builds. The same structure remains in current openpgp.configure. When changing a system dependency option, check whether the option, depends function and pkg_check_modules run under compatible conditions. Validate Linux system-library configurations, which the review called out as affected.

Scope: OpenPGP build configuration.

- `third_party/openpgp.configure`
