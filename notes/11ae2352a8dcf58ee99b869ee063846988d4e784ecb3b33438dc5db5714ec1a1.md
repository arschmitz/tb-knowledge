# The import-info wrapper retains result documentation after the result writer is removed

The deleted dialogaccept callback wrote the result object when Close was accepted. The rebuilt complete dialog script no longer writes that object, while keyImportDlg still initializes value=-1, returns it and documents button numbers0–2/-1. The eight checked current comm callers discard the return, so this is bounded source/documentation drift, not a reproduced caller failure. Native dialog behavior and uninspected external callers are not asserted.

Scope: OpenPGP dialog return contract.
