# Tree row properties expose an Iterable that consumers materialize

TreeDataRow stores property tokens in a Set and exposes them as an Iterable. The base getter returns a fresh iterator; fixture subclasses can return Arrays. The constructor does not parse a string into tokens. TreeDataAdapter joins the Iterable for its string API. The checked checkbox handler separately refreshes data-properties after changing the collection, so the mutation method alone does not establish a rendered update. Tests directly check unique ordered tokens, toggles, removals and joined strings. No runtime execution is claimed.

Scope: TreeDataRow properties and tree consumers.
