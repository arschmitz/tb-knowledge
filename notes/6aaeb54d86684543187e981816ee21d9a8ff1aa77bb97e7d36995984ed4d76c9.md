# Commands Review Update dialog, patch-review style pass, and task restart recovery

`restorePatchUpdateTask()` must open the owner modal, clear `uiState.lastUpdateRebaseId`, then `renderSession(value)`. Normal polling preserves the ID after a dismissed conflict, but explicit restore must reopen it. [Task 1]
