# Primary-password save guards do not replace authentication results

The new policy helper returns whether saving may proceed after any needed primary-password dialog. MsgAuthPrompt still returns the original authentication prompt result when that save guard declines. OAuth token persistence applies the guard only when adding a new login; matching existing-token updates occur earlier. Keep save permission, prompt acceptance and existing-login updates separate. The inspected code does not establish encryption guarantees or runtime behavior for every credential caller.

Scope: Credential save policy and caller results.
