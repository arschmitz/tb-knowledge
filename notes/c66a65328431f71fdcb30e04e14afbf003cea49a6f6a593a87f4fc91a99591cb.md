# Account removal clears folder-cache entries before removing server lookup

Folder paths can query their server through the account manager, so RemoveIncomingServer clears root/descendant cache entries before invalidating FindServer and removing the server map. Deletion notifications follow removal because listeners use FindServer to distinguish account deletion from folder deletion. Root cache keys use filePath, children use summaryFile. Synthetic accounts can return success with a null path and have no disk cache entry. The direct test asserts root and child entries disappear; it does not establish crash persistence or eliminate the admitted residual empty Inbox entry. Fixed source has a Panorama gate and logs cache-flush failures. No account/cache test ran.

Scope: Account folder-cache lifetime.
