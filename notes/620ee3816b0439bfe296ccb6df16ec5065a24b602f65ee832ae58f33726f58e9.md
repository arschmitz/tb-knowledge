# Compose attribute strings keep single-quoted values raw while decoding double-quoted values

GetArgs strips both surrounding quote styles, but only the double-quoted and unquoted branches call decodeURIComponent. The single-quoted branch preserves embedded percent escapes. Failed decoding falls back to the already stripped value. ComposeStartup uses this parser only for its legacy string-attribute fallback; mailto and nsIMsgComposeParams take other routes. No shell compatibility or live compose result was tested.

Scope: Compose GetArgs quote contract.
