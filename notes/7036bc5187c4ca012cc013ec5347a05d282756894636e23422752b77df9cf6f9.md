# The protocol copy tasks discard the async shared-test Promise

The extracted subtestCopyItem awaits setup and copyItems, then checks both folder counts and expected subjects. The new async EWS and Graph tasks invoke it without await or return. Their returned task Promises therefore do not wait for the shared helper's completion. The fixed accepted source retains those calls. This is a source-level test completion gap; no late failure or runtime race was reproduced.

Scope: Exchange EWS and Graph xpcshell copy tests.
