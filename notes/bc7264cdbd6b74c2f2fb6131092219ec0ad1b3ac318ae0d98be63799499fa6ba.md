# Own the filter completion listener before fallible dispatch

The folder puts MsgOperationListener in a local RefPtr before calling ApplyFilters. That reference covers service guards that can return before an executor owns the callback. The executor later retains the callback through its nsCOMPtr member for completion. Keep this concrete caller/service ownership path explicit; a raw-pointer parameter alone does not transfer ownership. This is checked source flow, not a reproduced leak or a global allocation rule.

Scope: Exchange filtering callback ownership.
