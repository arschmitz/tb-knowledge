# Keep the picker node alive while rebuilding table headers

TreeViewTableHeader.setColumns removes old ordinary header cells but retains the picker cell and inserts replacement cells before it. The comment explains that removing the picker during an event from its descendant breaks the event flow. The column picker menu is rebuilt when it opens so its order matches the current columns after reordering. Preserve live event targets when rebuilding a table header or popup.

Scope: Tree column picker.
