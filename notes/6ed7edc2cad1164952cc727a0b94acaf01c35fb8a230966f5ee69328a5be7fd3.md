# Account settings reset the protocol destination before each interface lookup

saveAccount iterates typed settings groups. A function-scoped var declaration did not reset dest between groups, so a throwing QueryInterface could leave an earlier destination. The patch uses per-iteration let dest=null, clears it in the catch and skips a missing target before slot writes. Current code retains this boundary and keeps later shared spam-settings work outside that skip. Added IMAP/EWS settings tasks check supported delete-model changes; they do not exercise every failure/order combination or establish atomic save. Scope this binding/early-continue pattern to the actual target lifetime. No settings or test operation ran.

Scope: AccountManager mixed-protocol settings save.
