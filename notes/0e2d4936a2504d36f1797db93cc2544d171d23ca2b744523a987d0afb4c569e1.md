# The card-layout color port uses layout roles with separate motion and spacing scopes

The owned port replaces selected local background values with numbered layout.css roles; those definitions use gray/light-dark and contrast system colors. It does not establish Bolt-token adoption. The shared transition duration becomes 200 ms, while density padding and logical overlay-scrollbar space have separate selectors and the avatar's two-sided margin applies beyond cards. At the accepted revision the spaces toolbar uses color-surface-lower and card color mixtures have evolved further, so keep the original layout-token port separate from later theme changes. No geometry, animation or contrast test ran.

Scope: Shared card layout tokens and later theme phases.
