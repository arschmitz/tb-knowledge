# Set NNTP read state before inserting and notifying about a header

NntpNewsGroup creates the read-key set from the folder newsrc line before processing headers. After the filters finish, it sets the Read bit from that set before adding the header to the database. Consumers should see the correct unread status when the new-header notification is emitted. Current filter tests also deliberately combine read and unread actions. These sources establish ordering, not a reproduced failure diagnosis. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/news/src.
