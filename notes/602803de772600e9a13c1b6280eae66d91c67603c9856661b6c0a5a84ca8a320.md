# Distinguish a browser owner document from the document loaded inside it

1255 replaces contentDocument null checks with browser.ownerDocument.readyState in five test families. Those current predicates still test the owner document, which alone does not prove the inner page has completed loading. A scoped recommendation when editing these waits is to check the inner load state or webProgress and the expected non-blank URL, as the extension awaitBrowserLoaded helper does. This static distinction is not an observed race reproduction or a diagnosis of the original intermittent failure. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
