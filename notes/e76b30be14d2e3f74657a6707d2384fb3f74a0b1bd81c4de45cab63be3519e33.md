# Keep about-blank origin and container expectations tied to accepted popup behavior

The 2024 popup test changed about:blank expectations from null origin to the extension origin. Accepted tests again expect about:blank - null while separately asserting firefox-container-1 or firefox-container-2. The current shared principal helper creates an about: target principal with those origin attributes. Do not reuse the older extension-origin expectation or conflate a cookieStoreId with the page origin. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/extensions.
