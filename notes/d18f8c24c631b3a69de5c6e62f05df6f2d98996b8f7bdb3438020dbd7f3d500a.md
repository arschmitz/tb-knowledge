# Associate spaces by stored identity rather than shared URL

The native extension-space opener forces duplicate:true because another space can use the same URL. It sets the space button ID on the new tab; the shared module stores that ID under tabInfo._ext.extensionSpaces.id. openSpace reuses the earliest primary tab only when appropriate and otherwise leaves the current tab alone. Do not identify a space only by its URL. The source retains a TODO about setting the ID during load rather than after opening. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces tab membership.
