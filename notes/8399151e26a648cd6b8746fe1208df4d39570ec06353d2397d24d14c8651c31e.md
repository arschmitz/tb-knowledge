# Folder size delegates to the store, while the new regression task tests the estimator directly

GetSizeOnDisk now delegates to EstimateFolderSize and preserves an unknown cached size if estimation fails. Maildir starts its output at zero, treats missing cur as zero and sums direct file sizes while skipping subdirectories; mbox uses its file size or zero if absent. The new cross-store task asserts the estimator's empty/nonempty and exact store-specific totals. It does not directly call the repaired folder getter or distinguish a missing cur directory from an empty one. No filesystem/backend execution or completed primary context is claimed.

Scope: Local folder storage-size accounting.
