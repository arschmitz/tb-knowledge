# Removing the stored message window changes prompt parents but keeps local deletion guards

The owned removal replaces docshell-derived prompts with the most recent DOM window. Local ConfirmFolderDeletion still requires aMsgWindow, and CopyFolderLocal only asks for confirmation when that argument exists. MessageSend has a different fallback: the most recent msgcompose window. These exact scopes do not define one universal prompt-parent or background-prompt rule. No prompt ran.

Scope: Mail prompt parent selection.
