# Exchange search capability controls picker eligibility without proving search results

ExchangeIncomingServer::GetCanSearchMessages returns true. The search dialog uses a folder-menupopup in search mode; that filter rejects servers without the capability and rejects virtual folders. The regression test syncs the root and directly checks for one account menu entry. Preserve this boundary: account eligibility and presence do not establish child-folder coverage or correct results for every search criterion. The historical owned path used EwsIncomingServer; the inspected current path is protocols/exchange. No query, browser test or accessibility run occurred.

Scope: exchange-search.
