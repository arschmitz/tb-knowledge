# Check decrypted content as well as nested signature status

The S/MIME cases with a bad outer signature and an inner encryption layer carry check_text in test_smime_decrypt. The outer signature is ignored under Bug 1806161; an inner signature can still be valid. Both the signed and unsigned inner cases must produce the message body, because the regression concerned content visibility. Keep enc, sig, sig_good and check_text as distinct fixture expectations; status flags alone do not prove readable content. The fixture-table snake_case fields are a local test-data contract, not a global JavaScript naming rule. These tests were not run.

Scope: Nested S/MIME behavior and tests.
