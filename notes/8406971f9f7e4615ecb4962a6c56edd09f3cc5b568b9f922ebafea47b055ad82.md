# Preserve Manifest V2 and V3 reset meanings in space updates

Accepted code clones old button/tab data. For button fields, Manifest V2 null means ignore and empty string resets; Manifest V3 omitted keys are absent and explicit null is allowed to reset. Keep the intentional != null condition and manifest-version branch. A generic truthiness check would discard valid values or change reset semantics. This is this schema/adapter contract, not a repository-wide equality rule. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces optional values.
