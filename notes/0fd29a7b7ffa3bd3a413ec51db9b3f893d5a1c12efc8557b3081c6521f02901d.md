# The folder picker excludes IM accounts only during default server discovery

This one-line landing passes true to the existing account-list helper only in the adapter's falsy/default server-discovery branch. The helper filters incomingServer.type im when that flag is truthy, after removing accounts without a server. Explicit single-server and array branches bypass this new filter. The accepted virtual-folder picker uses the default path, while the offline picker supplies its own filtered array or one server. No IM-account test is added; the inspected existing unit fixture has local/POP3 accounts. This does not prove arbitrary explicit IM inputs work or change folder identity/selection semantics.

Scope: FolderSelectionDataAdapter default account discovery.
