# Keep pill action names tied to their DOM and localization namespaces

The compose popup uses the custom element name mail-address-pill, dashed pill-action CSS selectors and lowerCamel editAddressPill ID, while the select-siblings ID retains its legacy menu_ prefix and the Fluent message uses pill-action-select-all-sibling-pills. Preserve each namespace when adding a sibling action. These are scoped patterns in this popup, not one casing rule for all DOM IDs or an instruction to rename existing IDs. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Compose pill action naming.
