# Review accessible row text when changing a card data key

The accepted card KEYS array contains tagKeys but no tags property. Its aria-label assembly still pushes data.tags, while visual tags are rendered through threadCardTags and a formatted title. Proposed review check: when replacing a display-name field with identity keys, update and inspect the accessible-name path too. Static inspection cannot establish the final screen-reader result or whether a child tooltip supplies equivalent context; live accessible-tree and keyboard checks remain required.

Scope: mail/base/content.
