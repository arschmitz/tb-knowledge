# Attachment deletion combines message policy with attachment state

The single-attachment menu combines CanDetachAttachments with not-deleted and not-detached state. The action handler also checks CanDetachAttachments and filters external attachments before detach/delete. Preserve these separate message and attachment checks when changing .eml handling; a toolbar disabled state alone is not the action guard. This is an observed caller contract, without runtime menu or attachment modification tests. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / base.
