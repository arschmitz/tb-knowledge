# Keep themed-icon fallback deliberate when converting spaces buttons

getNativeButtonProperties suppresses manifest icon fallback when themeIcons exist, matching the action-button behavior described in its comment. It deliberately bypasses the icon cache with _normalize and returns icon/badge Map objects for the native whitelist. Preserve these conversion choices when changing shared icon code; the underscore call is a specific documented cache exception, not a preference to bypass caches generally. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces icon conversion.
