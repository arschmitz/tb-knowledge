# Storage filtering keeps change-log constant ownership visible

CalStorageItemModel replaces the cICL abbreviation with Ci.calIChangeLog.OFFLINE_FLAG_* in event and todo offline filtering. The owning interface is visible where the requested journal value is chosen and where cached recurring flags are compared. Current accepted sections retain that spelling. This is a local naming example; it does not change filter precedence or prohibit useful aliases elsewhere. The umbrella includes a different cleanup backout, so its title or closure does not prove every style edit behaviorally harmless. No Calendar, SQL or stream test ran.

Scope: Calendar storage offline-filter names.
