# Calendar view switching copies Go-menu labels before exposing the items

switchToView copies label and access-key values from the selected view's attribute family before exposing the calendar items and before returning for an already active view. The actual markup defines four families; multiweek uses Week. The existing commands move the current view forward or backward. New tests directly check the four menu label/access-key pairs and subsequent displayed dates, but skip menu scenarios on macOS and omit messages on 16 new scalar assertions. None of these source checks is an executed UI or accessibility result.

Scope: Calendar Go-menu view labels and navigation tests.
