# Name parsed MIME header variables for the header they hold

In D211649 the reviewer asked to rename a generic header variable to contentDisposition while working on attachment classification. The accepted patch and current getAttachmentName code use contentDisposition for the Content-Disposition value. This is a scoped naming convention: a parsed header variable should name the header, so its role stays clear beside Content-Type and MIME parameters.

Scope: WebExtension MIME naming.
