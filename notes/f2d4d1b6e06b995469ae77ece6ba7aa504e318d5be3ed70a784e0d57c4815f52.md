# Stylelint expands directory-like exclusions separately from its ignore-path file

The config reads ThirdPartyPaths.txt and Generated.txt into ignoreFiles. It strips comm/ and appends ** only when the basename has no dot and the string has no asterisk. This heuristic makes directory-like entries recursive while preserving the selected exact files and globs. The wrapper independently passes .stylelintignore through --ignore-path and runs from comm_root. These are distinct exclusion routes; the patch and accepted source show the inputs, without a new Stylelint or CI execution result.

Scope: Thunderbird Stylelint configuration.
