# Keep compatibility names while modernizing local allowlist prose

In this family, legacy file names, preference keys and control IDs are compatibility exceptions to the newer wording. The unchanged file stem does not establish a preferred name for a new unrelated test. These conclusions come from static source inspection. No runtime test or accessibility session was run.
