# Storybook args must match the HTML attribute or JavaScript property boundary

The accepted create_story guide distinguishes HTML attributes from JavaScript properties and provides controls and actions for the exposed values and events. In these stories, recommend deciding whether an arg is an attribute, a Boolean attribute or a property before writing its Lit binding; a matching JavaScript variable name alone does not determine the DOM operation. This is component-story guidance from the documentation, not a repository-wide syntax mandate. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Storybook argument binding boundary.
