# Use geometry and splitter assertions for the horizontal-scroll preference round trip

The current horizontal-thread test checks default width and disabled final splitter, enables the preference, expands columns, waits for table width to exceed the container, then disables scrolling and waits for widths to match. Its event promises are created before popup actions. The Appearance preference test also checks checkbox state and the thread widget property. These assertions cover layout and binding. They do not drag a splitter or prove keyboard horizontal navigation.

Scope: mail/base/test.
