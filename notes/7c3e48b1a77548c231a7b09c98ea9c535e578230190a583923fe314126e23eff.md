# Batch stale saved-search removals within the successful search-completion path

Entry 995 brackets UpdateCacheAndViewForPrevSearchedFolders with JS-tree Begin/EndUpdateBatch in the successful, non-quick, non-interrupted search path. Current code retains that guard. The cache refresh yields bad hits and removes each header through OnHdrDeleted; batching avoids a tree update for every stale result. The separate new-search batch is ended before this completion cleanup begins. This is a static event-batching observation, not a measured speed result. Interrupted searches must not be treated as a completed cache refresh.

Scope: mailnews/base/src.
