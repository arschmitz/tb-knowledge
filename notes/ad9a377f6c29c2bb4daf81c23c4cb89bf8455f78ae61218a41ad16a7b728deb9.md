# Keep shared skill instructions separate from learned evidence

The shared knowledge sync accepts committed regular Markdown skill entrypoints and references as reviewed instructions. importFile skips these instruction files instead of creating evidence or learning jobs from their text. Automatic sync does not stage or install skills. Executable files, scripts and symlinks remain unsupported. This preserves standalone agent workflows without turning policy instructions into source evidence. Tests covered reader sync, pending instruction edits, unchanged remote state, and rejected file modes.

Scope: knowledge.
