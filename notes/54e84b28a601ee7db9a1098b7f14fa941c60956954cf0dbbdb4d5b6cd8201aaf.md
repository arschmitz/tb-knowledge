# The total-count-only path can bypass a direct ARIA-label request

With the total-count badge visibility already correct, the totalCount setter can update its cached count and text, then return through the unchanged-visibility guard without requesting an ARIA-label update. The checked TotalMessages path calls updateTotalMessageCount, whose size update schedules only when the folder-size column is visible. With that column hidden and no other pending or property-triggered label run, this direct path has no checked scheduling call even though the label includes total count. This supports a conditional source path only. No screen-reader defect was reproduced, and other notifications or pending work may refresh the label.

Scope: Folder row total count and accessible-label scheduling.
