# Outgoing-server popup waits target the menulist child popup

The account-settings test resolves identity.smtpServerKey as a menulist whose child is smtpPopup. This patch directs shown/hidden waits to menu.menupopup. The original still clicks menuitems; accepted source later uses activateItem, so popup-target repair and activation repair are distinct phases. Direct assertions check the selected server and edit-button state, but no fresh run or lasting intermittent cure is established.

Scope: Account-settings browser test event receiver.
