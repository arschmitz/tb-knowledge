# The decrypted-copy command keeps ordered per-message work and reports aggregate failures

The context ID mailContext-decryptToFolder maps to cmd_copyDecryptedTo. That command returns for no headers, awaits cryptMessage for each selected header with move=false, counts individual rejections and shows one failures/total alert. The removed Enigmail helper accepted a move argument; the accepted replacement route is specifically a copy operation. Keep that caller contract when changing the handler. This proves the inspected static flow, not crypto correctness, successful copies or all external consumers.

Scope: OpenPGP decrypted-copy command.
