# New-folder dialog geometry checks and saved-state cleanup have separate phases

The original menus test fix adds local setup that removes compose, message and new-folder saved window state, then directly checks a focused new-folder dialog is at least 300 by 120 pixels. The fixed accepted callback uses 235 by 120, while its menus setup removes only compose and message state. Preserve these phases when reusing the earlier provisional geometry note; neither the assertions nor the cleanup establish the cause of the reported timeout.

Scope: menus browser tests/dialog geometry.
