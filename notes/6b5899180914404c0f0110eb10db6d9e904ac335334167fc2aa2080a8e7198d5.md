# Unified folder creation excludes virtual and other special descendants

When getSmartFolder creates a missing unified folder, its recursive search-scope builder excludes descendants with SpecialUse or Virtual flags and does not descend through those children. SpecialUse also includes Queue, beyond the active unified folder-type list. Direct matching roots are still added separately, and an existing smart-folder URI returns before this creation path. No new test or live folder operation proves automatic cleanup of every existing scope.

Scope: folder-pane/unified-search-scope.
