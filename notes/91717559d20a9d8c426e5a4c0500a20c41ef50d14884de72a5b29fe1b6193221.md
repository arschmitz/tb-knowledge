# Commands amend working-tree diff recovery

The client formerly aborted `/api/graph/<index>/diff/uncommitted-changes` at 5 seconds. It now allows 60 seconds; amend-session working-tree requests use normal 20-line context rather than full-file context, and failure offers `Retry loading diff`. Focused browser tests, ESLint, and `git diff --check` passed. [Task 1]
