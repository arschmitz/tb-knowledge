# Apply-view tests wait for menu closure and descendant propagation separately

The apply-view test waits for popup closure and confirmation, and arms msg-folder-views-propagated only when descendants are included. The actual production update emits that topic after the descendant action promise completes; a single-folder update returns after writing its database fields. The final tick is an extra scheduling step, while direct assertions check the intended view fields. Do not treat the tick alone as proof of state convergence or an intermittent-failure cure.

Scope: Mail folder-view browser tests.
