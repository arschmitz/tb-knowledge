# Account-creation localization preserves synchronous validation and awaited error tests

The utility migration keeps sanitizer calls synchronous: its Localization is synchronous and MalformedException formats before throwing, retains a debug suffix and adds fluentTitleId. The async test helper first awaits the expected Fluent text, then uses Assert.throws with an Error/message-prefix predicate; its tasks await each helper call. FetchHTTP instead awaits its own fallback text inside an existing async wrapper while preserving numeric status, URI and cause. The later InputSanitizer rename is a separate phase. The matrix comment's old stringbundle wording remains stale; no runtime or translation migration was run.

Scope: Account-creation utility Fluent migration.
