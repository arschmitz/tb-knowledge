# Incomplete Account Hub configuration returns to the previous form with a warning notification

In the checked incomplete-config branch, EmailView stops loading, reinitializes the previous step and calls showNotification with account-hub-find-account-settings-failed and type warning. The nearby comment still says error, so the call is the source of severity behavior. The header applies the supplied severity through its options contract. This is a handled configuration-retry path, not a blanket definition of warnings or a claim that every account failure is recoverable. No configuration, rendered style, notification or accessibility test ran.

Scope: Account Hub configuration recovery severity.
