# Mock addMessages mutates IDs before the raw-message expectation is serialized

The helper rewrites each SyntheticMessage.messageId and stores the object under that derived ID. The raw fetch test serializes its expected message after addMessages, so the expected bytes include the mutated ID just like the fake server content. Do not keep using btoa(original ID) in callers after this mutation. The helper uses non-global replace calls for + and /, so those calls normalize only the first occurrence; no repeated-character fixture or production ID conversion was validated.

Scope: Exchange shared mock message identity.
