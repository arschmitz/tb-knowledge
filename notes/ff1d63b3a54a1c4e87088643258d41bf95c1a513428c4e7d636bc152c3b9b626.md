# The address-book tree receives its own Fluent accessible name

The books ul keeps role=tree and binds address-book-list, whose aria-label is List of address books. This names the tree itself; it is separate from the All Address Books row. The unchanged insertion-order test exercises the surrounding UI without a direct accessible-name assertion. No screen-reader or rendered accessibility run was performed.

Scope: Address-book tree labeling.
