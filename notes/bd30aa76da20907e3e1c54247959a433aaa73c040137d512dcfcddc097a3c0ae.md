# The Microsoft365 EWS marker records a suffix-matching initialization hint

The profile marker starts false and can be set true after successful EWS client initialization for a host ending in a configured suffix. The helper has no false/reset branch. The three suffixes without a leading dot do not enforce a DNS-label boundary. The test directly checks a non-M365 case and example.office365.com, not authentication, account removal or suffix-boundary rejection. This is a stored initialization hint, not provider identity or a live connection result.

Scope: EWS account migration marker.
