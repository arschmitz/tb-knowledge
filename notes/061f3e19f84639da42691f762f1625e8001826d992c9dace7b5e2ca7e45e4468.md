# Use shared surface tokens and retain focus space in subdialogs

Manual style proposal for these themed subdialogs: use the current shared surface/text tokens rather than add a new hard-coded light background. Offline selection uses --color-surface-base and loads colors.css and themeableDialog.css. It keeps a 50ch minimum width and a full viewport-sized body; the shared stylesheet reserves padding so a focus ring can remain visible when scrolling. These are current scoped examples, not a rule banning system colors or fixed heights throughout Thunderbird. No dark-theme, high-contrast, zoom or focus-ring rendering was tested.

Scope: dialogs.
