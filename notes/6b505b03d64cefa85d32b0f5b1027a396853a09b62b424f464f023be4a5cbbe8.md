# Clear previous notification text and accessibility state before reusing a header

Current clearNotifications removes Fluent IDs/arguments and old raw text, clears the open state and aria-describedby, removes severity classes, and hides the notification and disclosure toggle. This is more complete than merely hiding the historical bar. When a shared header is reused, stale localization text and accessibility relationships are state too. Preserve the exact root and reset contract. Static ARIA and source checks were made; the accessibility tree, keyboard disclosure and screen-reader output were not tested.

Scope: Account Hub notification reuse and accessibility.
