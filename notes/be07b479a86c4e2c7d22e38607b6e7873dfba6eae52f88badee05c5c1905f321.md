# The Windows tray Exit command consults Quit observers before attempting shutdown

The native context menu receives a command ID from TrackPopupMenuEx. For Exit, it sends quit-application-requested with a cancellation value and attempts application Quit only if not canceled. It does not call the close-to-tray requestWindowClose helper. Current event decoding and activation contain later changes, so this source path is not proof of native menu, keyboard or shutdown execution.

Scope: Windows native tray context menu.
