# The replacement URI port delegates through explicit serialization interfaces

The replacement port adds nsIIPCSerializableURI and nsIURIWithSizeOf inheritance, declarations and interface-map entries for nsLDAPURL, nsMsgMailNewsUrl and nsMailtoUrl. Each void Serialize method queries its initialized base URL and delegates through a local nsCOMPtr, which retains the interface through that call. The query result is used without a guard; the local standard/simple-URI construction paths do not establish the unpaired Gecko capability contract. Mailnews serialization still omits protocol-specific state, and its size hooks still return placeholder zero values. This evolved replacement is distinct from the original deletion and its exact backout. Its Needs Review landing and author-reported tests do not establish fresh runtime or ABI validation.

Scope: LDAP, mailnews and mailto URI interfaces.
