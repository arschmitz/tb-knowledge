# Notification fallback test runs last

At revision a4f840419d9d789b301716966485a472fb030132, browser_notification.js documents that test_revert_to_newmailalert must run last because one failed nsIAlertsService.showAlertNotification call leaves later notifications using newmailalert.xhtml. Preserve this ordering when maintaining that historical test setup, or verify that fallback state is reset before changing it. The test forces the mock service to fail and waits for the fallback window to close. It returns early on macOS because the source comment says the fallback window does not work there. This is a documented test constraint; the underlying persistent fallback behavior and current applicability were not independently verified.

Scope: Notification browser tests.
