# The first attendee row waits describe an optional label instead of their actual conditions

The original summary wait checks the four status counts, and the list wait checks three li elements, but both failure strings describe an optional participant label. These messages name the wrong expected behavior. Accepted source changes them to a correct summary and a three-item condition. The discrepancy concerns diagnostic accuracy; it does not show an executed timeout.

Scope: Calendar attendee row test diagnostics.
