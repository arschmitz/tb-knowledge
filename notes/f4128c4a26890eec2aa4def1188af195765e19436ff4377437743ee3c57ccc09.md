# Scope platform test exclusions to the interaction that cannot run

The 2024 menu-hang changes added macOS debug exclusions for two tests. Their current relocated manifest has different scopes: mailContext and menubar exclude macOS, while tagsMenusAndKeys includes opt/asan/tsan or a non-macOS OS. Body-mode tests skip only the macOS native menubar tasks and retain message-header tests. Read the current manifest and per-task skips together; a historical exclusion is not proof that the whole feature is untestable on that OS. Keep the issue or capability explanation beside the exception. No hang reproduction was run.

Scope: test-manifests.
