# Keyserver tests check serialized preference state and concrete DOM output separately

Checkbox changes serialize selected servers while leaving the visible row in place. Reset clears the user preference and rebuilds. The browser task separately checks added-server count, checked input and label text, then default preference state and removal of the extra row after reset. Its initial child count includes a retained template, so children length is not always a server count. No test was executed here, and the primary bug discussion is incomplete.

Scope: Privacy keyserver test coverage.
