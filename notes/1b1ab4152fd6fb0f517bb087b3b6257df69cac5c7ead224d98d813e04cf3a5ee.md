# Discard in-memory OAuth objects when testing stored token state

658 clears OAuth objects before checking the saved login and creating the account. The test utility also clears server tokens and cached OAuth objects on teardown. Current _forgetObjects clears both token fields on live cached objects, empties their weak-reference set and clears OAuth state. This separates persisted-token checks from accidental reuse of an in-memory token. The current granular browser test retries a known authorization/verification race and asserts succeeded telemetry; that retry logic is later source, not proof that the original 658 test covered the race deterministically.

Scope: OAuth test cache and cleanup.
