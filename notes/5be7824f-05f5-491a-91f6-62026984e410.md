# Compute multiselection capabilities with one lookup per folder

Collect selected folder objects once and intersect command capabilities. The accepted folder-pane implementation uses logical AND assignment, such as isServer &&= folder.isServer, and can stop when every useful capability is false. D203232 rejected repeated folder lookups across six separate scans. Current code keeps the intersection. Use this syntax when accumulating Boolean capabilities; it does not replace assignments with unrelated side effects.
