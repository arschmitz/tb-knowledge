# Keep UI font size session state separate in safe mode

The font size race fix makes isDefault derive from the preference or rounded OS size, updates isEdited after all registered windows, and keeps safe-mode changes in memory instead of writing a preference that would need rollback. registerWindow removes each window once on unload. The test waits for L10nMutationsFinished before checking the translated app-menu label. When changing global UI size, account for several windows, safe mode, and localization completion.

Scope: UI font size.
