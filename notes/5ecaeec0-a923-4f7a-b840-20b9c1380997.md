# Load the context menu sheet after contacts sidebar styles

D210978 removed three OS-specific abContactsPanel.css files and uses the shared sheet. Review found macOS menupopups rendered incorrectly when contextMenu.css was loaded before sidebar styles. The accepted XHTML moves contextMenu.css after tree-listbox.css and the shared sidebar sheet; the author observed a Linux fix too. Current markup keeps this order. CSS link order is part of the rendered behavior for this window, so inspect it during style changes.

Scope: Address Book CSS.
