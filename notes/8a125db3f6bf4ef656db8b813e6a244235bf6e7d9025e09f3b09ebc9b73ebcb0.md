# A nonnegative message-view index can still be the not-found sentinel

selectMessage checks both an absent lookup result and nsMsgViewIndex_None. Review rejects replacing those checks with >=0 because the sentinel is 4294967295 in JavaScript. The helper also assigns index for its caller. When lookup fails, the function resets the same-folder Quick Filter or changes folder and then resets a sticky filter before retrying; it returns if the message is still absent. Keep the sentinel, side effect and retry contract together. No filtered-view runtime was tested.

Scope: Quick Filter selection.
