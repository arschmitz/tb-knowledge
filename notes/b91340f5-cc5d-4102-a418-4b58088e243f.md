# Contact update events must restore extension context after a persistent background wakes

The version-specific onContactUpdated listener awaits fire.wakeup, then uses context.extension. Its convert(newFire, extContext) callback replaces both values after a Manifest V3 background restart. Manifest V3 reports the old vCard string as the second event argument; Manifest V2 reports changed flat properties. A listener that retains the old context can use the wrong version or a shut-down background.

Scope: WebExtension address book events.

Paths:

- `mail/components/extensions/parent/ext-addressBook.js`
- `mail/components/extensions/schemas/addressBook.json`
