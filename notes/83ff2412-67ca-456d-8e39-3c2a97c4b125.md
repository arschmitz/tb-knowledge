# Name C++ enum types used across translation units

Bug 1891306 found GCC rejected an alias for an unnamed enum in the nsImapNamespace constructor declaration because the type lacked linkage; Clang had allowed the old form. The landed fix added explicit enum tags for EIMAPNamespaceType and IMAP_ContentModifiedType, and current code retains them. When an enum appears in a C++ declaration used across files, give the underlying enum a name and check GCC as well as Clang. The reviewer raised possible removal of older IMAP definitions, but that was not part of this accepted fix.

Scope: IMAP C++ syntax.
