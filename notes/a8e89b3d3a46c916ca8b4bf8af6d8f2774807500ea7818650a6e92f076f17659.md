# Check accountsRead before folder conversion and FCC exposure

Current compose getter checks accountsRead before extension.folderManager conversion, then gates FCC fields and identityId; the setter gates FCC mutation. Without the permission, the folder manager may not exist. Preserve both capability access and output omission; guarding only a setter or only final serialization misses the other boundary. Existing read FCC tests grant accountsRead, so they do not prove the negative permission case.

Scope: mail/components/extensions/parent.
