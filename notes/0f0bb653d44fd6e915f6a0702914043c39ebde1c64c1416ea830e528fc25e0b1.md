# Preserve shipped notification dismissal and seed state across network refresh

updateNotifications unions fetched IDs with shipped default IDs before pruning interactedWith and seeds. This retains state for defaults omitted by a network response, so a dismissed built-in message need not reappear with new targeting state. The skipCleanup option deliberately preserves all state while installing offline data; the current unit test checks both interaction history and the same seed after an empty update with this option. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending.
