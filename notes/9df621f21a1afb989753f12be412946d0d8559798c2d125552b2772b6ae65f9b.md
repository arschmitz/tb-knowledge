# Move lint runtime and module dependencies together

Entries 892 and 899 move lint jobs from image-installed Node and node_modules to fetched artifacts. Current mozlint tasks fetch both the Node toolchain and node-modules reference artifact, use MOZ_FETCHES_DIR for module setup and link the upstream lint plugins from that fetched tree. Changing only the executable or only the module path can split the runtime and plugin environment. The CI task source was inspected; these jobs were not executed.

Scope: taskcluster/kinds/source-test.
