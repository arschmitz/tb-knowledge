# nsMsgProgress::RegisterListener behavior in mailnews/base/src/nsMsgProgress.cpp

Null listener is a successful no-op, contradicting the IDL's null-error description. Rejects self-reference, lack of weak-reference support, and duplicate weak reference. Adds listener before immediate replay. Closed/canceled state replays only STOP/NS_OK; otherwise replays cached status with NS_OK, then cached state if its sentinel is not -1. Replay callbacks can run before registration returns.
