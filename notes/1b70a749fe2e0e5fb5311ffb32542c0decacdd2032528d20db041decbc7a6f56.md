# The compose-context test selects the menus head rather than its parent

At the owned revision, browser_mailContext_compose.js is listed in menus/browser.toml, whose DEFAULT selects head.js in that directory. The complete selected menus head has no explicit parent-head import, script-loader call or persisted-window reset. The intermittent-fix patch changes the parent browser/head.js instead. Check the actual selected setup and its imports before attributing a test fix to a shared head. This is a bounded historical loader observation; transitive modules and the browser harness were not run or fully audited.

Scope: Mail browser test directory and setup ownership.
