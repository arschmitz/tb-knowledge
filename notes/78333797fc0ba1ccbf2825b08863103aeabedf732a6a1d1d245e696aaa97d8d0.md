# Calendar task attachment calls omit the event that launchBrowser reads

At the fixed inspected revision, launchBrowser documents event as optional but reads event.target.documentGlobal in its protocol guard. The task attachment onclick invokes launchBrowser(this.value) without that argument. These exact caller and implementation sources disagree in their event argument contract. This lesson supports only that static relation. It does not claim a reproduced Thunderbird failure, validate link activation, or require a particular fix. The historical accepted mid-link change does not establish that this separate caller path was tested.

Scope: Calendar task attachment links.
