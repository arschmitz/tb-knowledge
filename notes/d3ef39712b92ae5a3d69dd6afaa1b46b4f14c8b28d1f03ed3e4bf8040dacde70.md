# The EML action timeout increase is a separate phase from later window fixes

This patch adds an unconditional file-wide requestLongerTimeout(2) and changes no scenario wait or assertion. Fixed accepted source later uses factor four for coverage and three otherwise. The full Bug separately records later focus/mock-context and further timeout attempts; those are not behavior supplied by this first budget increase. A larger harness budget does not identify the failure cause or prove a successful test.

Scope: EML action test budget and follow-up phases.
