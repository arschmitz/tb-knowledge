# Keep footer sizing in logical CSS properties in current Account Hub code

The historical footer size used min-width. Current .footer-button uses min-inline-size, and nearby layout uses margin-block and margin-inline properties. Follow those current forms for new footer dimensions and margins so the property names describe the inline and block axes. This is a scoped accepted style pattern; no visual check of right-to-left layout ran.

Scope: mail/themes/shared.
