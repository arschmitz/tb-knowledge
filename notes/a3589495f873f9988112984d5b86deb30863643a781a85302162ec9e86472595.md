# The MIME lint repair also renames the forceCharset option contract

The repair changes the parser default, documentation, charset branch and test caller from force-charset to forceCharset. Options are copied as supplied, while the selection branch reads only forceCharset; the old spelling is not normalized by this constructor. The test passes options directly and compares declared Shift-JIS with the forced effective ISO-8859-1 value. External callers and compatibility need their own checks.

Scope: JSMime parser option and forced-charset test.
