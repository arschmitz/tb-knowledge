# Clone a caller-owned file before constructing a sibling path

Entry 1505 replaces SetLeafName on the input file with a clone used to find its .sbd directory. It also checks GetDirectoryEntries before enumeration. Proposed rule for this historical filesystem helper: derive the sibling path in a cloned nsIFile, preserving the caller’s original path for its later summary lookup. The Windows failure is reported by the commit, not reproduced, and the collector is retired in accepted source. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama historical filesystem paths.
