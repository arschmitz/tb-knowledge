# Use the already-locked close helper from Finish

Current Close takes the mutex and calls InternalClose, while Finish holds the same mutex and calls InternalClose directly. Calling the public Close from Finish would reacquire the nonrecursive lock. Keep the public locking boundary and private already-locked helper distinct, and document similar helper preconditions such as Emit. Existing lessons cover commit versus rollback behavior; this landing supplies the locking/lifetime boundary rather than a new rollback contract. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Mbox output private lock helper.
