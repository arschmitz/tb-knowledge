# Use two physical folders to test virtual-list aggregation and broad-query deduplication

The virtual-folder extension test creates two physical folders with six messages each, then checks each physical list/query, the twelve-message virtual list/query and the broad query still returning twelve. It also checks virtual flags and that search folders are not exposed as subfolders. Preserve that matrix when changing the aggregation path. The fixture does not explicitly force mixed cached/uncached states or overlapping wildcard and explicit folders; duplicate physical scopes remain unverified here. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Virtual folder extension test matrix.
