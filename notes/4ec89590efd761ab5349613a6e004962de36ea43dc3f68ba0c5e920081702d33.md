# Use an explicit local-address-book label when other provider actions coexist

489 changes New Address Book to Add Local Address Book and gives it a new Fluent message ID. Current resource keeps the Local/CardDAV/LDAP distinction while toolbar titles have a generic Add address book entry. Match text and ID to the action scope; preserve the local hyphenated Fluent message family. The rename alone does not establish a global create-versus-add policy.

Scope: mail/locales/en-US/messenger/addressbook.
