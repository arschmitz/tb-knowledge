# The Account Hub title migration copies old values into both renamed message values and titles

This landing renames seven authentication IDs and three connection-security IDs, updating their widget maps and test expectations. For each new ID, the migration copies the old value into both the message value and its title attribute. The title attributes were introduced in the earlier display landing; this separate recipe addresses translations after the stated ESR timing deferral. Changed assertions compare localization IDs, so they do not directly verify migrated locale output or resolved title text. The fixed completed recipe has the same blob; no migration execution is claimed.

Scope: Account Hub Fluent migration and localization IDs.
