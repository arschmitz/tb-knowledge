# Notification visibility documentation needs the scheduler platform limits

The scheduler checks active state, document visibility, focused window and screen bounds for the explicit currentWindow or the active window. _checkScreen returns true on Linux because positions are unreliable; elsewhere it compares the window rectangle with available screen bounds and a120px allowance. It does not detect another window covering Thunderbird. Startup active-state initialization uses idleTime<5000, separately from the 30-second idle observer. These checked limits qualify documentation about visibility; they do not establish user exposure, attribution, full multiwindow dismissal behavior or native results. No notification ran.

Scope: Notification visibility limits.
