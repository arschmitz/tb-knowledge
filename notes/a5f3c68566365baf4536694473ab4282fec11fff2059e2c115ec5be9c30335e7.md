# Outgoing-server lookup tests optional metadata only for supplied filters

findServer normalizes optional lookup filters and compares a candidate only when the corresponding filter is truthy. Optional chaining makes absent username, serverURI.host or type compare as missing rather than throwing. A supplied filter rejects that candidate; an absent filter leaves that property unchecked. This does not validate every server or establish its protocol capability.

Scope: mailnews/outgoing-server-lookup.
