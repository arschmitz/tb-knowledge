# The hierarchy transition-count test explicitly selects motion-enabled setup

testHierarchy sets ui.prefersReducedMotion to 0 before opening its fixture. The fixture loads tree-listbox.css, whose twisty transition only exists under prefers-reduced-motion:no-preference. That matches the helper's contract of counting the clicked row's transitionend while rejecting checkbox changes. The patch sets up an animation-specific test; it does not change the product default or establish behavior with reduced motion enabled.

Scope: Auto-tree-view animation test setup.
