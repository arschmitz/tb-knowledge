# The ICS discovery test validates prompt controls and discovery rows before cancelling

The new ICS test uses a direct /test.ics URL with authenticated fixture data. Its shared wizard helper handles the password dialog, checks visible and checked remember-password controls, then checks discovered row count, URI and name. It cancels the wizard rather than registering a calendar and does not assert the event contents. The extracted helper makes color comparison optional for an expectation without color. Fifteen Assert calls in the new shared head have no message, including focus, status, row and password-control checks. Those are scoped source findings; neither the test's name nor these assertions prove .well-known discovery, subscription or fresh execution.

Scope: Calendar ICS discovery browser fixture.
