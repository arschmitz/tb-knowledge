# SMTP action comments name the button beside its numeric case

The SMTP failure branch labels action 0 as Retry beside the access-token clear. Adjacent cases name Cancel and New Password, and the prompt implementation supplies those button positions explicitly. These local comments explain the UI meaning of numeric return values at the point of action. This is scoped source practice, not a new repository-wide comment template. The exact source, rather than a handled-review label, establishes the adoption.

Scope: smtp-oauth.
