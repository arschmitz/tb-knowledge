# Separate AddonInstaller status checks from installation cancellation

Current Account Hub setAddon constructs AddonInstaller without a signal and only runs status methods. The installation path in email.mjs creates an AbortController and passes its signal. _installDirect attaches cancellation, waits for installation and removes its listener in finally. Scoped API recommendation: preserve this split when reusing the helper; omitting a signal for read-only status checks does not establish that install can run without one. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/accountcreation.
