# Let the recommended protocol badge wrap with its title

The found-config option wraps its flex title row and gives config-title-text flex:1. Its native radio remains inside the label beside the badge. Current markup uses badge and recommended-protocol rather than the original recommended class. Preserve the separate text span when changing label layout so long text and larger fonts can wrap. No actual font/zoom, focus or accessibility-tree check was run. This is static source evidence. No runtime, build, lint or live accessibility check was run.
