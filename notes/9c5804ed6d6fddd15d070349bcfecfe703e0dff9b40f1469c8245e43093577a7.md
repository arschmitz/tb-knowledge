# Immediate offline-pump setup failures are distinct from failed OnStopRequest recovery

The accepted local-cache path returns false if opening the message stream, creating the pump or starting AsyncRead fails. The discard call is in the later wrapper’s failed OnStopRequest path. Do not read the broad setup comment as proof that every early return clears the copy. For this code, scope recovery claims to the actual callback boundary or add an explicit early-failure policy when changing it. This is a static source limit, not a reproduced missed recovery; no setup-failure test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP offline pump setup.
