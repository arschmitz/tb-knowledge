# Reminder-row assertions check generated metadata without exercising the rendered controls

The test creates start-related duration alarms and directly supplies an array. It checks Fluent ID/count, element count, first alarm text, classes, button type and image localization ID. It does not click Delete, check every alarm's order, await translated text or exercise the production date-sort caller. The original fixture misspells link as linkr for CSS/localization references; the accepted fixture corrects those elements. Keep metadata assertions, resource loading and functional behavior separate. The message 'First reminder should be unordered' does not name the exact first-input expectation.

Scope: Calendar reminder component fixture and test scope.
