# Keep Windows button appearance metadata for snap layouts

Thunderbird draws its own titlebar images, yet Windows 11 needs -moz-default-appearance on minimize, maximize, restore, and close controls to recognize native button behavior. Without it, hovering over maximize did not show snap layouts. Do not remove platform integration properties simply because appearance is otherwise set to none.

Scope: Windows titlebar controls.

Paths:

- `mail/themes/windows/mail/mailWindow1.css`
