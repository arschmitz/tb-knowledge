# ExtensionMenus is the persistence authority for menu changes

The port removes gStartupCache and uses ExtensionMenus to merge properties, add, update and delete persisted menus. Removing a parent collects its descendantIds before deleting the subtree from persistence; otherwise deleted children could reappear at restart. Current code retains descendant deletion. When changing menu tree operations, update the live tree and the ExtensionMenus record together.

Scope: Extension menus.
