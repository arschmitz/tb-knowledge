# Exchange folder lookup strips channel-only query and message-key information

MsgKeyStringFromChannelURI trims trailing slashes before extracting the final path segment as the local key. MsgHdrFromUri selects the folder scheme, converts that key and removes query and ref before GetExistingFolder. These local lookup rules differ from preserving the query on the stream channel. The inspected path does not establish complete rejection of malformed or overflowing key strings; no malformed-URI tests were run. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Exchange local header lookup.
