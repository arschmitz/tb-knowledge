# Address-book command predicates tolerate a missing creation receiver

Entry 4639 adds optional lookup and optional method calls to the cmd_newCard and cmd_createList enabled predicates. If books or the relevant method is absent, the predicate returns a falsey value and skips noOverlays. CommandController returns the callback result and prevents doCommand from executing on a falsey result; registration also requests an immediate command update. When the receiver exists, its capability method and overlay state still control creation. This is a scoped command-readiness contract, not a general reason to hide a required receiver. Static source only; no command or test execution.

Scope: Address-book command registration.
