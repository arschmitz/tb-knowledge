# Select Gloda facet groups by size, then order the selected result for display

makeTopGroups clones the input tuple list, sorts the copy by item count, slices the requested number, and finally sorts only the chosen groups by their attribute comparator. Thus rank selection and display order are separate decisions, and the original array is not directly sorted. Preserve that separation when adjusting facets. The source comment says the old other aggregation is gone; this function does not return such a bucket. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Gloda top facet selection.
