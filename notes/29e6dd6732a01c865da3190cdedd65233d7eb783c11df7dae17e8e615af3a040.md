# Destination toolbar popups opt into the shared Favorites menu

The standalone File and unified toolbar Move To popups use the existing filing-mode folder menu and set showFavorites=true alongside showRecent=true. Main Message Move/Copy menus use the same special-menu configuration. The shared widget filters destinations, selects Favorite-flagged folders and stores the actual folder object on each menu item; the caller still chooses cmd_moveMessage or cmd_copyMessage. Current localization comes from the widget's Fluent identifiers, while the original patch supplied DTD label/accesskey attributes. The generic widget test covers empty special submenus and does not prove populated Favorites or these toolbar commands.

Scope: Message move/copy destination popups.
