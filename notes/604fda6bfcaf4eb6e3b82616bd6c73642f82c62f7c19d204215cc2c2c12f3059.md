# Use the local EWS header receiver for server-originated read changes

The EWS review rejects folder MarkMessagesRead for a server ReadFlagChange because that method sends ChangeReadStatus back to the server. The patch instead looks up the local header and calls its MarkRead method. Review keeps a targeted branch because the general Update route fetches extra metadata/content. This intended local-only boundary is source-supported, but the landed callback uses rv without declaring it and adds no explicit CommitChanges call. Earlier approval does not prove final compilation or persistence. The current shared listener has later missing-header race handling. No server or build test ran.

Scope: EWS inbound versus outbound read state.
