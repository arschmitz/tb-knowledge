# Compose progress recorder tests do not establish native taskbar receiver lifetime

The current progress test replaces Windows, macOS and GTK taskbar contracts with MockRegistrar objects that record setProgressState calls. Its save case checks recorded first/last states and event count while the compose window stays open. These assertions can check publication of progress state, but cannot establish whether a native Windows taskbar receiver keeps the real icon present after garbage collection.

Scope: Compose taskbar test proof limits.
