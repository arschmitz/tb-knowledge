# Thundermail backup fields share their generated key and IV input

One backup operation generates one key and salt, then passes that same pair to encryption of every stored container-key string and the public/private key strings. Backup.encryptBackup passes the salt as the AES-GCM iv. Both original and accepted source retain that relationship. The scoped finding is equality of the supplied inputs across fields; it does not infer exploitability, severity, provider behavior or successful decryption.

Scope: Thundermail generated backup encryption inputs.
