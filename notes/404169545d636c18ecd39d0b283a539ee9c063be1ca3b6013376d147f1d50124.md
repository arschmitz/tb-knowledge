# The reference task loader selects matching upstream tasks without checking every requested name

In the checked comm reference loader, reference-tasks becomes a pathspec applied to each upstream task name and toolchain aliases. The loader returns the matching upstream tasks. The subsequent missing-reference-name comparison is commented out, so this source does not validate that every requested name exists upstream. The toolchain merge loader then yields those imports and local transformed tasks separately. Removing an obsolete runtime requires checking both an imported reference list and each repack consumer fetch; the owned repair removes the Linux x86 compiler-rt19 name from both Clang jobs and the reference list. Accepted later Clang22 names are a separate phase. This is a scoped static contract, not a generated-graph result or proof that unresolved dependencies are accepted by later graph stages. No graph, repack or test ran.

Scope: taskcluster/comm-taskgraph/reference-loader.
