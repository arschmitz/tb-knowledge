# Contacts sidebar selects an unselected drag origin before producing transfer data

The sidebar dragstart handler selects the origin row only when it is outside selectedIndices, then calls abResultsPaneObserver. That observer builds transferable rows and addresses from the current selection. Preserve this order, and retain an existing selection when the origin is already selected. The browser test asserts the added recipient and selectedIndex after a simulated unselected-row drag; it does not prove native drag behavior or all multiselection cases. Static inspection only.

Scope: Compose address book sidebar drag.
