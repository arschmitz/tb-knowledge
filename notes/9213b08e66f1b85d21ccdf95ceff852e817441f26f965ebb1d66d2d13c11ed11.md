# Keep folder timestamp units explicit at the extension boundary

Native MRU/MRM properties store seconds as strings. getFolderTime converts the chosen property to a number and returns milliseconds by default, or seconds when inSeconds is true. Date objects use the millisecond form; the sort helper uses seconds consistently. Preserve explicit units in names such as startTimeSeconds and in helper options. This is scoped naming/behavior guidance, not a requirement to use one global timestamp format. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension folder timestamps.
