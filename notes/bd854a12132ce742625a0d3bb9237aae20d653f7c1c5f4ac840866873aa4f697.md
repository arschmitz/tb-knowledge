# Folder Properties separates localized unknown values from loaded folder data

The migrated count and size labels carry Fluent IDs for unknown values. The existing loader separately assigns a nonnegative message count and a formatted disk size to those same .value properties. These are separate localization and data-loading roles. Source inspection alone does not establish retranslation timing or the final rendered value; preserve both consumers when changing these fields.

Scope: Folder Properties Fluent placeholders and runtime values.
