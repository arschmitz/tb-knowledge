# Decode address headers with their mailbox structure intact

An encoded comma in a display name becomes an address separator if a generic decoder drops quoting. MAILBOX_HEADERS identifies address-like headers; parseEncodedAddrHeader retains the mailbox structure. The utility lowercases the header name before classification and allows an explicit mailbox override. It returns an array even for a scalar input. The TO tests prove the correctly quoted output and intentionally show the wrong forced generic result. Use the address parser for this representation instead of assuming every RFC 2047 header can use the same decode path. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/mime-mailbox-decoding.
