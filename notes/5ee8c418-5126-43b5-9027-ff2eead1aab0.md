# Ship a Fluent migration recipe with new migrated strings

When a patch migrates existing Thunderbird UI text into Fluent .ftl files, include its migration recipe in that same patch. The documented workflow stores recipes in python/l10n/tb_fluent_migrations and runs them across locales after landing. This is about migrating existing strings, not adding a wholly new string.
