# Test message-display script timing across each document and window type

The Manifest V3 message-display test registers scripts at document_start, document_end, and document_idle. At start, readyState is loading and the body is absent; at end, the body exists and readyState is interactive; at idle, readyState is complete. It repeats this after selecting different messages, opening a message tab, and opening a message window, and checks that a web content tab does not receive the message scripts. The current test still covers these lifecycle states. A single successful inject call would not prove timing or target isolation.

Scope: Extension scripting tests.
