# Pass a message URL and destination filename in separate drag flavors

The current thread-pane drag sets canonical msgUrlSpec as both text/x-moz-url and file-promise-url, and supplies the filename through file-promise-dest-filename. Search Messages uses the same destination-name and directory flavors in its provider. Keep message URI, fetch URL and filesystem name separate in this drag family; do not append a display filename to the canonical message URL to carry save metadata. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message drag transfer representations.
