# Password prompt cancellation is a successful native status that must keep its identity

NS_MSG_PASSWORD_PROMPT_CANCELLED is a successful native result with meaningful identity. The incoming base method returns the original status, the outgoing Rust implementation bypasses xpcom_method! for this method, and the prompt adapter explicitly compares the status after error checking. It returns Cancelled separately from NewPassword, allowing the empty-password caller to abort on cancellation while still retrying an explicitly submitted empty value. This is a scoped cross-language result contract; the macro implementation itself and live prompts were not executed.

Scope: EWS password prompt boundary.
