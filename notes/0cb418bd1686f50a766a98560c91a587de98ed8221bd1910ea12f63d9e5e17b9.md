# The legacy Japanese locale is normalized before plural-function initialization

The patch rewrites only ja-JP-mac to ja-JP-macos before constructing Intl.Locale, so the existing Japanese one-form rule can be selected. In that historical module, init removes its lazy get/numForms properties before obtaining the rule; if rule creation throws, replacement functions are not installed. FilterEditor reaches this helper while building its periodic label. This is a bounded static initialization dependency, not evidence of lost saved filters or a reproduced locale failure. The accepted FilterEditor now uses Fluent and the module is absent.

Scope: Historical filter localization.
