# Message-display manifest scripts expose run_at while compose scripts expose only files

ComposeScript declares js and css arrays. MessageDisplayScript additionally declares run_at, defaults to document_idle and permits start/end/idle values. The original MV2 test expects exact loading/interactive/complete states and body absence/presence; accepted tests later permit later start/end states. MV3 covers injection without the three-state test. These are schema and written-assertion scopes, not fresh timing results.

Scope: extension-script manifest options.
