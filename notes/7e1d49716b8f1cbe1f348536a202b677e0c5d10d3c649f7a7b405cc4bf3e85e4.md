# Initial Graph calendar discovery requires an existing Graph mail server

The initial lazy provider map adds Graph only when calendar.graph.enabled is true; its default is false. Graph discovery then looks up a matching Graph incoming mail server and returns an empty list when none exists. The original client initialization constructs an HTTPS URI from the location. Accepted source later reads the mail server stored endpoint and builds manager-backed calendars, while retaining that incoming-server dependency. The initial placeholder calendar and name-only results are separate from later ID/readonly, persistence and event support. No account, network or runtime result was tested.

Scope: Graph calendar discovery integration.
