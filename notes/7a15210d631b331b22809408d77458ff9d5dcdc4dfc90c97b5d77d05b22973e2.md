# Preference slices keep transformed Redux values separate from raw typed preference writes

The preference slice transforms values for Redux while its set effect writes the raw action payload using the existing preference type. External pref changes dispatch sync; reset clears the user value. Extra reducers do not automatically gain persistence effects. The integration task checks that baz changes Redux without changing the raw pref, and distinguishes a BAR pref-change wait from the lower-case Redux result. A fallback does not create a typed preference; the effect has an explicit invalid-type branch.

Scope: state/preference-slices.
