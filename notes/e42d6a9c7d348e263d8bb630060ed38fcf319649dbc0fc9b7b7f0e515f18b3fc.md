# Calendar acceptance production markup and its static Storybook preview exercise different receivers

The production Calendar acceptance custom element clones its template into an open shadow root and connects that root to document localization. Its native radio inputs use matching labels and decorative images. The Storybook template instead returns a plain attendance-widget div with icon spans; naming the component in story metadata does not instantiate the custom element. This initial patch supplies the visual widget, not response persistence or the later status/change contract visible in fixed accepted source. Treat a preview of the plain wrapper separately from component lifecycle and state coverage.

Scope: calendar-dialog-acceptance.
