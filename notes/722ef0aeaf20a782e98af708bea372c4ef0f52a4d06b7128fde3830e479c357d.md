# The About dialog resize port moves logo geometry into shared CSS while keeping branding images separate

This landing centralizes client/left-box geometry in the shared About-dialog sheet and removes duplicate geometry from three branding sheets, which retain their logo images. The document loads the shared sheet before branding. Its initial670×400 minimum and 220px/1fr grid are historical declarations; accepted later flex/minimum rules differ. Neither the source nor a historical screenshot proves that every locale, font or native dialog size fits. No rendering test ran, and this is not a global grid or branding rule.

Scope: About dialog shared and branded layout.
