# The tree refactor exposes a protected count hook and keeps buffer methods private

The visible-row calculation becomes _calculateVisibleRowCount with @protected so the derived navigation code can call it. Buffer refill/add/remove methods use JavaScript #private names. The underscore and documentation mark the intended subclass interface; the # syntax enforces private access. This is the affected widget contract, not a global naming rule.

Scope: Tree widget subclass and private member naming.
