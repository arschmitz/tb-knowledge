# Reject a DAV redirect that would carry authorization across origins

Current CalDavRequest copies Authorization only when old and new channel prePath match. If a cross-origin redirect has an Authorization header, it rejects the redirect through NS_ERROR_ABORT. Preserve that current check when changing request preparation. The old unconditional header-copy path must not be taught as accepted behavior. This is a source-supported boundary; redirect behavior was not executed. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: CalDAV redirect authorization boundary.
