# Use a boolean value when toggling an HTML disabled attribute

An HTML disabled attribute is present or absent. When updating Move to New Tab availability, pass the inverse of canClose to toggleAttribute so the menu item works again after XUL-to-HTML attribute migration.

Scope: mail-tabs.

Paths:

- `mail/base/content/tabmail.js`
