# Calendar interface checks keep provider capabilities separate from recurrence objects

The patch uses guarded QueryInterface for the cached provider's changelog capability, with false on absence or error because an implementation may come from an add-on compartment. The same patch deliberately uses implementation-or-interface instanceof checks for a recurrence rule in the editor. CalDAV redirects separately catch upload extraction and then require HTTP channel interfaces. These distinct source forms follow their receiver and caller contracts; they do not establish one global interface-check style or a successful add-on/redirect runtime result.

Scope: Calendar provider and editor interface checks.
