# The footer link loop checks discovered requests, not privacy-link presence

The test discovers anchors under list items without hidden attributes, installs a mock URL promise before each mouse click, and compares the resolved URL with that anchor href. The mock resolves on loadURI, so the assertion checks a request rather than a real external browser launch. The loop has no explicit privacy-anchor or expected-link-count assertion and does not test keyboard or default-navigation behavior. The actual template contains the locale-free privacy anchor. Available discussion stays private; required Bug comment 1 remains absent with unknown author/type and zero full-audit credit.

Scope: Account Hub footer link test scope.
