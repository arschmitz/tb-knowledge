# Friendly-date localization changes the yesterday formatter while keeping its time thresholds

makeFriendlyDateAgo keeps a synchronous Date-to-string contract. The removed yesterday property is replaced with RelativeTimeFormat.format(-1, day) using numeric auto and the application locale. The existing local-midnight, fixed 24-hour/six-day and same-year branches remain. Actual callers construct Date objects in milliseconds; activity display keeps an exact datetime/title separately. Do not infer civil-day, DST or all-locale correctness from this formatter replacement. No boundary or locale test was run.

Scope: TemplateUtils friendly dates.
