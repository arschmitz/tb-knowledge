# Use the relanded address-book row formulas with density-specific minimums

The initial address-book sizing change was backed out, and entry 895 relanded a revised formula. Current cards round the combined font and density spacing once, then apply the card minimum. Table rows use font size times 1.2 with density-specific minimums of 18, 22 and 32. The original table formula used 1.4 and a fixed minimum of 18. The backout reports test failures, but the exact failure cause remains unverified. Do not copy the original formula when extending current row layouts.

Scope: mail/components/addrbook.
