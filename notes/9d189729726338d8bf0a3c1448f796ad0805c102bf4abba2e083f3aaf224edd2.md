# Rename Fluent identifiers at both definition and call sites

The loading landing spelled account-hub-config-test-scucess the same way in JavaScript and Fluent. The follow-up renames both to account-hub-config-test-success. This was a spelling cleanup of a matched pair, not evidence that the original lookup was missing. In this Account Hub resource, use meaningful correctly spelled dashed words and change every producer/consumer together. Current notification code and Fluent definition agree. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Account Hub Fluent identifier syntax.
