# Custom Headers migration copies locale punctuation rather than forcing English quotes

The final Custom Headers recipe copies the old alert strings. It contains no explicit typography replacement, while the new English Fluent strings use curly quotes. The review questions applying English punctuation to other locales; final recipe behavior supports that local outcome despite the unchanged summary claiming typography fixes. This is a scoped migration fact, not a new localization policy.

Scope: custom-headers-localization.
