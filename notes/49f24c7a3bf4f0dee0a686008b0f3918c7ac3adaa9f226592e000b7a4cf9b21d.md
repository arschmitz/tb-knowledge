# Keep startup allowlists useful by checking missing and unused entries

The accepted phase test removes matched allowlist entries, asserts no unexpected modules remain and also asserts the allowlist is empty. This catches stale exemptions as well as new startup cost. Preserve both sides when updating a startup budget; adding an allowlist entry without exercising it is not an accepted passing contract. No startup test or performance measurement was run here. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Startup budget test maintenance.
