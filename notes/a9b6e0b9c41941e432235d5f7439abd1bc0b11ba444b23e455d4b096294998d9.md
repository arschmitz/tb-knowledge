# Keep expected LDAP form errors separate from unexpected exceptions

1020 removes the blanket try/catch around LDAP directory acceptance. The accepted code still detects a missing or duplicate name, illegal host, non-numeric port and invalid result limit, shows a localized alert and prevents acceptance for those expected validation errors. It constructs the URL and creates or updates the directory in the valid branch. Unexpected service exceptions are no longer swallowed by the old generic log-only catch. This is the actual behavior difference inside a logging patch; no dialog failure or error presentation was exercised.

Scope: LDAP directory acceptance error boundaries.
