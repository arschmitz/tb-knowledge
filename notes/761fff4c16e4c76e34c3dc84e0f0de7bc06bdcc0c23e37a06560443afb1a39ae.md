# The Calendar title correction copies legacy title attributes into message values

The three document title targets use new Fluent IDs with scalar values. The migration recipe uses COPY_PATTERN to take the old calendar-server-dialog-title-edit.title, calendar-publish-dialog-title.title and calendar-error-title.title patterns into those values. This keeps the exact old attribute source and new HTML title target together; it does not establish a rendered title or a successful migration in every locale. The accepted recipe is in completed/ with later LF formatting. No migration runner, dialog or translation check ran here.

Scope: Calendar dialog localization.
