# MailSession keeps its separate shutdown-service initializer after removing no-op Shutdown

The removed MailSession Shutdown implementation only returned NS_OK, and the destructor only called that method. The cleanup removes both the scriptable declaration and no-op call. Component creation still invokes Init, which obtains the separate message shutdown service. These are distinct lifecycle paths. No runtime shutdown or external consumer compatibility was tested.

Scope: MailSession component lifecycle.
