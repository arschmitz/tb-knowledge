# Preserve Microsoft offline_access through token scope normalization

659 temporarily removes offline_access from MICROSOFT_SCOPES. 674 restores it and adds it to returnedScopes when Microsoft omits it from the token response. Current normalization accepts Microsoft tenant token endpoints through startsWith("https://login.microsoftonline.com/"); current provider definitions include offline_access for Microsoft mail and EWS. Its EWS comment explains that this requests a refresh token for reuse after restart. Treat 659 as an intermediate approach, not the current policy. The restart symptom is patch intent; no provider login or restart reproduction was run.

Scope: Microsoft OAuth refresh-token scope.
