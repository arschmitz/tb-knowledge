# Schema acceptance is separate from a private-browsing feature implementation

Entry 1625 adds private_browsing as a boolean in the per-extension ExtensionSettings schema. Fixed accepted schema keeps it alongside existing snake_case policy fields, and the policy handler forwards the validated parameter object to manager.setExtensionSettings. The inspected comm code does not itself prove a Thunderbird private-browsing UI or all manager-side effects. Preserve the schema/consumer boundary when describing this compatibility change. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Enterprise extension settings schema.
