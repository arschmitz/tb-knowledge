# Schema object references are a readability suggestion while compatibility versions describe prior support

The schema README suggests a dedicated named type for an object among choices, and says to consider one for an object with more than five properties. These are suggestions, not a global five-property limit or a formatter rule. The inspected menus command annotation marks the explicit enum as supported since66 even though that enum spelling was added in 124, because the strings were already accepted. A newer type declaration date does not alone establish the first supported runtime behavior. The annotation and full schema patch were read; external generator/runtime proof and full review remain gaps.

Scope: WebExtension schema documentation and support notes.
