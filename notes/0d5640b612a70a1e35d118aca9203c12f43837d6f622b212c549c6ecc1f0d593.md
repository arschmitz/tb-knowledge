# The accepted tokenizer translates the sliced iterator result before using it as a whole-buffer index

The original segmenter port constructs a word iterator from a slice beginning at pos, copies its break result directly into next, then exposes that value to a whole-buffer consumer. Fixed accepted code adds pos before using the result, and the consumer has separate later bounds and progress checks. Keep these phases distinct when reusing the port. This comparison establishes the local index arithmetic, not an independently checked native segmenter contract or a reproduced failure.

Scope: Bayesian tokenizer segmenter migration.
