# Scope unread-card emphasis to both descendant labels

The corrected selector is .card-container :is(.sender, .subject), nested under the unread card state. The descendant space is necessary: sender and subject are inside the container, rather than classes on the container itself. Current source preserves the selector and also has separate new-message color rules. Manual CSS review proposal for this component: compare the selector with the actual ownership of state and descendants, and cover both sender and subject when the visual state applies to both. Syntax validity does not establish that the selector matches the intended nodes. This augments the existing generic-tree versus mail-state style scope; it does not require all state styling to use this exact selector.

Scope: thread-card-selectors.
