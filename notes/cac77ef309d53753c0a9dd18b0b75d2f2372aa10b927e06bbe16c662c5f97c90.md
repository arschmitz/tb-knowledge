# New Folder Fluent messages keep button attributes separate from control labels

The migrated dialog requests new-folder-dialog-accept-button and explicitly allows buttonlabelaccept. Its Fluent message supplies buttonlabelaccept and buttonaccesskeyaccept; ordinary name/parent labels use message values plus accesskey, while the folder-kind radios use .label. Keep these actual receiver roles separate when editing this dialog. The existing control and aria-labelledby associations remain. This is the inspected source contract, not a claim that every Fluent attribute is allowed by the paired engine or that localization/accessibility was run.

Scope: New Folder dialog Fluent migration.
