# net.thunderbird routing resolves a host-named observer service

The handler parses the URL, resolves its host in the net-thunderbird-url category, gets the service as nsIObserver and passes the full href with that topic. The original starts window opening separately; accepted code later places dispatch after the window promise. This is category-based routing, not an enforced central consumer allowlist or proof of OS registration. No OAuth flow or protocol launch was executed.

Scope: Custom protocol command-line routing.
