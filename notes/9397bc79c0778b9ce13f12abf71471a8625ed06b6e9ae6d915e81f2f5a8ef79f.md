# Keep the old account-setup password-toggle workaround historical

Entry 723 hides the toolkit password visibility toggle with appearance: textfield !important on the old accountSetup.css password input. That stylesheet is absent at the fixed accepted revision. The current Account Hub password template still has an input type password and an associated label, but its toggle behavior was not traced. Do not carry the retired CSS workaround forward as a current password-input style rule.

Scope: mail/themes/shared.
