# Exchange server settings hide the POP advanced control through server-type metadata

The owned patch adds ews to the POP advanced control hidefor list. Account Settings passes the selected type to its local hideShowControls helper, which changes hidden from exact comma-separated membership. A separate EWS advanced control remains. The child hidden-data hbox change is redundant with the containing POP vbox and was described as consistency cleanup. This is a visibility contract, not removal of a backend capability or a rendered-dialog result.

Scope: Thunderbird Account Settings advanced-control visibility.
