# Fetch tag identities separately from their localized display names

Cards request tagKeysCol; nsMsgDBView returns space-separated keyword keys through FetchTagKeys. The current ThreadCardTags filters valid keys and resolves display names through the tag service. This replaces historical matching of tag-name substrings against a formatted text column. Keep the positional KEYS mapping aligned with getDefaultColumnsForCardsView when adding fields. Current cards also fetch account and serverKey. No performance benchmark ran.

Scope: mail/base/content.
