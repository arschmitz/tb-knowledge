# Queue extension permission prompts by their selected mail window

showPermissionsPrompt can receive no browser in an empty mail3pane state. It selects the browser's window or the most recent mail window, then uses that window as the pendingNotifications key until the prompt promise settles. This matches the window-oriented notification use in this path. The popup regression test requests and grants notifications from an action popup; it does not prove every multiwindow or reentrant routing case. Keep the selected window key and nullable-browser path together when changing this flow. No popup or permission test ran.

Scope: Extension permission prompt ownership.
