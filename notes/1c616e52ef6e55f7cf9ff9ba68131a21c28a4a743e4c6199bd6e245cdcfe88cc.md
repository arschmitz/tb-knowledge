# Historical subscribe icon rules cover both normal and search tree columns

The historical XUL-tree patch applies folder and NNTP icon rules to both nameColumn and nameColumn2. It uses a mixed fill plus currentColor stroke, then switches both to the focused-selection text color for selected rows. That state override is separate from choosing the icon variable. These exact legacy selectors were later removed: the accepted dedicated stylesheet has only layout rules and the dialog now uses base-tree-view. This is historical scope, not a current selector recommendation or tested contrast result.

Scope: subscribe-dialog.
