# Xpcshell timeout factors depend on the actual platform key

The timeoutfactor map has explicit platform branches and default 1. The original sanitizer keys lacked the later qr suffix; accepted code uses qr-aware patterns and updated platform names. A configured larger factor helps only when its selector matches the task platform. Chunk count and worker max-run-time remain separate settings, and the exact downstream timeout expansion was not read.

Scope: Thunderbird xpcshell task configuration.
