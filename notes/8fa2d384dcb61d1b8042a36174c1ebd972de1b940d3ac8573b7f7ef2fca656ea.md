# Suspend the enable observer during registration rollback

At revision 49408c8d1213df012e461f97a727957bb43c8442, SearchSupport._handleRegisterFailure removes its enable-preference observer, assigns prefEnabled, then adds the observer again. This keeps the observer detached during the corrective preference write. Preserve this ordering when changing this failure handler. This is an observed source pattern for desktop search registration failure, not a general preference-handling convention or proof that OS registration succeeds. The evidence contains no runtime validation.

Scope: desktop search integration.
