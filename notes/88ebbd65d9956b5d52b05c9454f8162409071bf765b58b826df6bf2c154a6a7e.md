# Unread thread sorting aggregates children only in the non-root threaded mode

For byUnread, an unread message supplies an unread key directly. A read root can use its thread unread-child count only in threaded display when group-by-sort is off and sort_threads_by_root is false. Search or cross-folder views fall back to the header database thread, not a guaranteed complete combined thread. The changed single-folder test checks root-only and default aggregate ordering in both directions through helpers with built-in expected-result diagnostics. Keep the mode conditions and fallback limit when changing the key. No sorting test or UI ran.

Scope: nsMsgDBView unread numeric sort key.
