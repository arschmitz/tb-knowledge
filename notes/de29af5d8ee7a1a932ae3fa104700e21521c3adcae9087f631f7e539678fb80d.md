# Legacy manual account security uses an unmatched-value fallback without rewriting explicit None

The historical form keeps allowed socket types0–3 and changes only the unmatched fallback to-1, whose option is Autodetect. Explicit0 still selects no encryption. Sanitizer.enum returns an allowed match using loose equality or the supplied fallback; it does not force all configurations to autodetect. The old form is absent at fixed source, so this is historical UI evidence, not proof of the newer form or actual security negotiation. No setup or connection test ran.

Scope: Historical manual account setup security controls.
