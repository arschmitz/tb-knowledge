# Graph body construction preserves supplied bytes and content type before transport

The original patch consumes each operation into a fallible HTTP byte request. JSON bodies are serialized with application/json; Other bodies carry caller-supplied bytes and a content type. The original Graph bridge forwards the operation method and only attaches nonempty bodies after checking their Content-Type. The generator and emitted POST operations must agree on that contract. This avoids the previous builder-level body clone, but native upload still copies bytes for stream lifetime. Accepted Graph dispatch later queues the built request, so construction, queue completion and a successful server operation remain separate.

Scope: Graph Rust operation and HTTP request bridge.
