# Attachment saving now crosses an asynchronous file-picker boundary

The checked AttachmentInfo.saveAttachments validates each attachment, opens a folder picker through a Promise, returns null on cancellation, then saves chosen paths asynchronously. The old unused native wrapper is not the current place to implement that behavior. Its JSDoc still says {?string} on an async method; recommend documenting the promised result when updating it.
