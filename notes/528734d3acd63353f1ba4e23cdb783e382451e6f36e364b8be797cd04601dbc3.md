# Follow a localized label rename through tests and later source

The original Recent Destinations label was exactly backed out for reported test failures. A later selected reland applies the label and updates two tests that locate it by visible text. Current menus use the destination-specific Fluent ID, and those tests expect Recent Destinations. Review both localization identity and label-driven test consumers when renaming UI. The reland test delta does not prove the exact earlier failure diagnosis, and later context does not complete future chronology. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.
