# Unified special rows choose folder-plus-server text by comparing display names

When inserting a searched special folder, the smart mode compares its localizedName with the matching smart folder’s localizedName. Equal strings select server-only style; unequal strings select both folder and server. This preserves custom local archive names that server-only Local Folders labels would hide. The predicate is string equality, not proof of how a name was translated. Direct tests add/clear an Archive flag and check the visible nameLabel text and hierarchy. Full-path and accessible fullName behavior are separate row-consumer contracts. No dialog, flag transition or accessibility runtime check ran.

Scope: Unified-folder row label selection.
