# Creating the CardDAV directory returns before its first server fetch finishes

The accepted discovered-address-book create callback schedules authPromise.then(() => dir.fetchAllFromServer()).catch(console.error) and returns the directory. Account Hub does not await that fetch in #addSyncAccounts. Its synchronous try/catch therefore does not mean all initial remote synchronization errors are reported in the setup form. This is a scoped completion boundary, not proof of failed synchronization or a request to redesign the callback. The historical 1382 browser test explicitly waits for addrbook-directory-synced instead of treating Continue as completion. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub CardDAV completion boundary.
