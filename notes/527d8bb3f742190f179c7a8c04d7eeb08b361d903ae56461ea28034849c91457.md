# The send/save header test gets Organization from the selected identity

The fixture sets an organization on its default sending identity, and the shared verifier directly checks that raw messages carry it. Accepted SendMsgToServer assigns identity organization to the compose fields when both fields and identity are present. The landing adds that header test; it does not add an API organization option or directly test a competing override. No runtime send/save result is claimed.

Scope: Thunderbird messages API Organization header coverage.
