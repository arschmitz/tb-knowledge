# Account Hub success icons use placeholder state to exclude empty inputs

The success icon is hidden by default. A user-valid sibling excludes optional placeholder-shown inputs, and a valid sibling excludes placeholder-shown inputs. The LDAP template adds empty placeholders while retaining permanent labels and decorative icon alt text. Placeholder presence is part of this local CSS contract; it is not a general value-empty check or runtime guarantee for every input type. No assertion changes.

Scope: Account Hub input-success CSS.
