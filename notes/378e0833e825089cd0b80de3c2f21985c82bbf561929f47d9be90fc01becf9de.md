# Keep folder lookup and detached folder creation contracts explicit

MailUtils.getExistingFolder only looks up an existing folder and can return null. getOrCreateFolder may create a detached representation and can return null for a nonfolder URI. getFolderForFileInProfile searches account folders by filePath.equals for desktop search integration. Choose the helper according to whether creation is allowed, and state nullable behavior in documentation. The 2024 JSDoc patch documents existing contracts; it did not change them or prove all callers handle null. These helper names and legacy a-prefixed parameters are existing API conventions, not a rule for every new parameter.

Scope: mail/modules.
