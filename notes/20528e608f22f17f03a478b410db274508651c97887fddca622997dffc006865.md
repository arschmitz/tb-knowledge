# The cloudfile test suppresses late built-in registration and restores only its provider

The test removes one built-in provider type immediately and whenever providerRegistered fires. Cleanup detaches the listener, then restores the captured provider only if the type is still absent. The registry inserts before registration notification and emits a different event on removal. Removal also deletes matching entries from the in-memory account map; cleanup restores the provider object only. This map operation does not establish persistent account-preference loss. These are test and registry source contracts, not a runtime result or a rule for production add-on handling.

Scope: Cloudfile preferences test registry isolation.
