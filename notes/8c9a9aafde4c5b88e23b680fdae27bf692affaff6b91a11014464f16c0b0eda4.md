# Skipping a folder update still performs the IMAP SELECT

Current SelectMailbox(noUpdate=true) sends SELECT, parses the response and updates the selected folder sink before returning early from the folder-update path. Gmail deletion uses it for the temporary Trash selection and return to the source mailbox to avoid temporary UI count updates. Preserve that protocol/UI distinction: noUpdate does not mean no server selection or no parser state change. No transient badge behavior was inspected live. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: IMAP selection without UI update.
