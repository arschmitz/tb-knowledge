# Check background creation and event-page waking separately from foreground activation

The accepted event test creates the second message tab in the background and expects onCreated(active=false) then page-load events with active=false. It separately launches a terminated-background event-page extension for a single expected event and gates forwarding to the first event after wake-up. Those are distinct consumers and states. A correct foreground onActivated test alone does not cover background creation or persistent-event wake-up. No extension lifecycle ran. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: extension tab test coverage.
