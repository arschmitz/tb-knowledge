# Commands Electron desktop shell, branding, and build-capable worktrees

`desktop/main.cjs` provides single-instance Electron lifecycle, tray/background persistence, secure `WebContentsView` pages, reusable same-origin windows, navigation controls, and console-server persistence. Package with `npm run desktop:package`; smoke-test with `npm run desktop:smoke -- [local path]`. [Task 1]
