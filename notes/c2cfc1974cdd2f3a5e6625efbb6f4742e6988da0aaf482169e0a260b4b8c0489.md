# Offline search hoists charset conversion to one time slice

Entry 1370 moves folder charset retrieval and UTF-16 to UTF-8 conversion out of the per-header loop. The accepted Search retrieves GetSearchCharset and constructs NS_ConvertUTF16toUTF8 once per invocation before its approximately 50 millisecond loop. It can run again for a later time slice; this is not a process-wide charset cache. For this loop, recommend hoisting values that remain fixed during the slice while preserving the next-call boundary. No benchmark or search test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Offline-search per-slice values.
