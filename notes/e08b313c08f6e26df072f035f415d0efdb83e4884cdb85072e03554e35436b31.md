# Encrypted compose roundtrip tests assert display results in six signed and unsigned cases

Three auto-enable/disable combinations run with and without signing; notify-on-disable stays false. Each scenario waits for encrypted-icon state and asserts displayed subject, then the selected signature-icon state. The attachment-count assertion is only in the unsigned branch. Icon helpers inspect DOM src/hidden attributes; the test does not directly assert protected MIME bytes. Keep direct expectations separate from code merely executed. No test or crypto run was performed.

Scope: OpenPGP composition browser test coverage.
