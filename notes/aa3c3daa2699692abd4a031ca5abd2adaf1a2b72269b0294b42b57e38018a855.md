# Keep news server encoding distinct from UTF-8 display identity

GetRawName converts the UTF-8 folder name through UTF-16 into the configured news charset, with lossy ASCII fallback on conversion failure. This server wire cache differs from localized or abbreviated display text. Preserve that boundary; the UTF-8 folder migration does not remove the server charset or make every NNTP wire name UTF-8. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
