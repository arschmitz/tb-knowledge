# The old existing-window helper did not wait for document loading

wait_for_existing_window claimed to wait for loading, but its entire body immediately returned Services.wm.getMostRecentWindow. Replacing that wrapper with the direct lookup does not remove a real load wait from that implementation. It also does not make direct lookup sufficient when a caller needs a newly opened, loaded or focused window. The filter test relies on a window opened by an earlier task; new-window promises keep a separate contract. Read the implementation before trusting synchronization implied by a name or comment. No window test ran.

Scope: Mail browser window helpers.
