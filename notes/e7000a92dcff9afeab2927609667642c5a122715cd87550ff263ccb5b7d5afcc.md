# Account settings crops the displayed title while preserving the complete account name

The account title shares a row with a flexible spacer and default/delete buttons. The CSS gives the content a600px minimum, hides title overflow and applies pseudo-element ellipsis while keeping direct-button rules scoped to that row. setAccountTitle still assigns the full account name to label value and document.title. The change clips presentation rather than stored account text. Accepted source uses later logical sizing properties; no live layout or accessibility verification.

Scope: account-settings-title-layout.
