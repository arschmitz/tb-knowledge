# Live-view recipient text currently bypasses the retained address formatter

The recipient landing selected ADDRESS_FORMAT(recipients), but fixed LiveView::SelectMessages explicitly disables address formatting and aliases raw recipients as formattedRecipients. The async row producer reads that text and CreateJSMessage emits a UTF-8 string; the adapter maps recipient sorting to the named native column and locale text comparator. Do not infer formatted display names from the alias or the existence of AddressFormatFunction. The formatter still has first-sender/zero-recipient TODOs. This is a static producer/consumer distinction, not a locale-sort, address-book or runtime result.

Scope: Panorama recipient query and object output.
