# Share the localization source cache but clone a separate recipe work directory

prepare_directories maintains one state-directory Git checkout and a two-day pull marker per Mach invocation. Each test_migration recreates its own recipe work directory, clones the source into en-US, runs a dry migration and then removes --dry-run for the real migration. Keep shared download cache state separate from the recipe checkout that receives generated commits. This source contract does not verify network freshness or a successful recipe.

Scope: Fluent migration source cache and recipe isolation.
