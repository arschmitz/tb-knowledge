# WebExtension attachment classification uses a nullable filename sentinel

In WebExtMimeTreeEmitter, null means a part is not an attachment. An empty string can still identify an unnamed binary attachment. MimeTreeEmitter.startPart therefore checks attachmentName != null before setting isAttachment and name. Scoped manual recommendation for this emitter family: preserve the nullable return contract and document it; replacing that comparison with a truthiness check loses unnamed attachments. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: WebExtension MIME attachment sentinel.
