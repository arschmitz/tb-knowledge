# Resume cross-folder navigation after the final message load

927 replaces immediate repeated navigation with a one-shot allMessagesLoaded listener registered before displayFolder. The load listener emits that event only for all=true, after restoring thread/selection state and resetting the tree. Intermediate loads keep the list responsive but are not this completion boundary. Keep the subscription before the operation that can emit the event. No cross-folder navigation was run, and the event contains no folder identity check.

Scope: Cross-folder navigation completion.
