# Subscription changes pass one server and an explicit Boolean record

The dialog now calls its completion callback with gServerURI and one plain changes record. Its producer writes only explicit true/false values from checked versus wasChecked tree state. The extracted module iterates that record's own entries, attempts each subscribe/unsubscribe action and then attempts one commit for the server, retaining per-action and commit error reporting. This is a specific producer/consumer contract, not a multi-server payload, all-or-nothing transaction or generic permission to change truth checks. No live subscription or failure test ran.

Scope: Subscription dialog callback.
