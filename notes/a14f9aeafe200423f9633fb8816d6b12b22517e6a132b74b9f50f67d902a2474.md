# Store token and flag arrays must be filtered together

nsIMsgPluggableStore.changeFlags requires token and new-flag arrays of the same size. The folder adapter updates DB flags, collects each token with its flags, and skips both values when a token is empty. Filtering only one array would break their correspondence. This boundary is not an atomic database/store update. Deletion also varies by backend: mbox marks Expunged, while Maildir attempts removal without checking its return. Do not treat a shared success code as proof of physical deletion. The named status tests were read statically; no I/O failure ran.
