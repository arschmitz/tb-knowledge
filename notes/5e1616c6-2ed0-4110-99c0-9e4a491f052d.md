# Update RNP build inputs when a vendored library moves or adds sources

Bug 1885353 updated RNP to v0.17.1. Its dependency renamed libsexp to libsexpp and added sexp-depth-manager.cpp. The reviewed moz.build patch updates both the include path and explicit SOURCES list. This is a scoped build rule: a vendor directory rename needs matching build path changes and any new source files listed where the build requires explicit sources. D204667 was accepted without inline requests. The vendored source commit itself is bulk and not a Thunderbird style sample.
