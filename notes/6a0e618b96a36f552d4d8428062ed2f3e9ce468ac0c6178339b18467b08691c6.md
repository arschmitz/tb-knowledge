# The remove-account helper keeps result and close waits around two dialog accept calls

The helper invokes dialog.acceptDialog() to start removal, retains its result-label and enabled-button checks, then registers dialogclose before invoking acceptance again. The second call is followed by awaiting that event. This source change selects the dialog API while keeping the two completion phases; it does not establish mouse-event behavior, native dialog success or an executed removal.

Scope: Account-removal browser-test activation.
