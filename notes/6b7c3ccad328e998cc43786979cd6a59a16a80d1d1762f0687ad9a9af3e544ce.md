# Shared in-content sidebar rules cover documents that do not import Preferences CSS

The Nova theme patch keeps narrow-window footer/category rules in shared common.css because Add-ons does not import preferences.css. It removes conflicting Preferences padding/collapse rules, preserves the 18em sidebar/grid and uses Thunderbird surface/sidebar tokens. Review requests become scoped source changes: sidebar-border replaces the removed splitter token, hover rows are excluded from the about:config stripe override and cards use the existing3px radius token. A proposed4px literal and acknowledged alphabetical ordering are not automatically adopted. Current aboutExtra has later imports/control overrides. This is static cascade/consumer evidence, not rendered or contrast validation.

Scope: In-content theme and narrow-window sidebar scope.
