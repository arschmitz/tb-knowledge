# The optional GPGME version adds guarded filename candidates without enabling external GnuPG

The original preference accepts an ASCII alphanumeric version suffix and adds guarded platform filename attempts before falling back to existing names. Invalid input is ignored locally. The preference remains empty by default and external GnuPG remains disabled by default. The original helper mutates a shared library handle, while the fixed accepted loader later returns handles and uses a candidate loop including automatic version 45 names. Startup readiness still requires the wrapper's library init; no library or cryptographic compatibility result was tested.

Scope: OpenPGP external GPGME loading.
