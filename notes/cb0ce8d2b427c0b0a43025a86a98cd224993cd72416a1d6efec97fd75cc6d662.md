# Auto-config loading disables both buttons and the delegated sign-in path

This landing extends the auto-form disabled setter to its manual-config and Thundermail buttons as well as inputs. The view disables that form when navigating away, while start/stop-loading toggles the active form. A delegated Thundermail click also requires the initial state and an enabled matching button. Twelve property assertions and five dialog navigation/cancel assertions check those disabled states with explicit should messages. They do not execute a disabled programmatic click, establish every failure path or prove OAuth/native accessibility behavior; no test ran.

Scope: Account Hub auto-config state.
