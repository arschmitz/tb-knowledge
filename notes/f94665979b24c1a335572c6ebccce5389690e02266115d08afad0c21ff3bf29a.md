# Keep console browser work hidden

The recorded user request requires hidden browser work during console AI tasks, including follow-up turns. Do not open or alter visible browser tabs. If hidden access or interactive sign-in prevents a required read, report the missing information and continue independent work. This is an explicit user preference for console tasks, not a verified browser capability or a Thunderbird-wide rule.

Scope: TB Tools console browser access.
