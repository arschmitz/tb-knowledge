# Empty folder submenus show a disabled explanatory child while keeping the parent enabled

When no recent/favorite folders remain, the folder popup creates a localized stub with disabled and aria-disabled attributes, adds stub-menuitem and leaves the parent enabled. The stub has a null folder and uses the info-icon custom property; it is explanatory content, not a real folder entry. The tests check parent state and the single child, but do not directly check ARIA output or screen-reader focus. No accessibility or performance run was made.

Scope: Recent and Favorites empty-state menu.
