# Measure window updates against outer geometry and await a real size change

updateGeometry compares requested width/height with outerWidth/outerHeight, registers a one-shot resize listener before resizeBy, and only waits when either difference is nonzero. Creation waits for focus before applying geometry and then waits for the already-registered load promise. Preserve these ordering and outer-size contracts. The Linux decoration cause is reported in the commit; no platform geometry failure was reproduced. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension window geometry.
