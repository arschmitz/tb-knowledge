# Tokenizer bounds checks precede conversion while its progress check follows insertion

ScannerNext adds pos to the boundary returned for its text+pos slice. The non-ASCII token loop checks begin/end against the string length before constructing a substring. It converts and adds the unit, then breaks if end did not advance. Preserve that order when assessing the guard: it does not prove that insertion or recursive scanning never sees a nonadvancing case. No regression test or crash reproduction ran.

Scope: Bayesian tokenizer scanner boundaries.
