# Mix full and partial POP downloads in the size-sort regression

The test downloads four messages fully and the same four as headers-only, then checks eight displayed size values for monotonic order on initial descending and later ascending/descending sorts. Current test code also normalizes a comma decimal separator before numeric comparison and is registered in xpcshell.toml. This verifies the intended UI size role more directly than checking storage bytes alone. Error and zero onlineSize fallbacks are visible in source but are not separate asserted cases in this test. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Partial message size regression tests.
