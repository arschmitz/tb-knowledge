# Keep the upstream RNP version separate from the Thunderbird build identity

rnp_version_defines returns the upstream version separately from version_full. Current version_full adds MZLA, Thunderbird version, optional variant, crypto backend and backend version. The commit timestamp is explicitly zero when upstream commit information is unavailable. These fields serve different build identities; the 2024 full-version string is shorter than the accepted current form. The two formatting follow-ups do not justify a manual line-length rule beyond the formatter.

Scope: python/thirdroc/thirdroc.
