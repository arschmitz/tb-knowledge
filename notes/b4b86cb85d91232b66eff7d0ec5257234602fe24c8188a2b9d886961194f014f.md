# The documentGlobal test port preserves distinct preference, drag and document-event receiver roles

The test port does not make every window role interchangeable. openNewPrefsTab directly compares the returned preference window with its content document documentGlobal. moveAttachments keeps the dragged element window and destination bucket window separate when calling the drag synthesizer, then directly checks destination attachment URL form. openpgpProcessed filters a newly inserted document by its optional global location, then waits for the processing event on that document. Fixed accepted source retains these bounded contracts. They support receiver and test-review checks; they do not prove paired native documentGlobal semantics, native drag success or cryptographic validity.

Scope: Browser-test document and window contracts.
