# Keep shared scroll decoration below modal backdrops and out of hit testing

sidebar-panel-scroll adds normal-contrast pseudo-element shadow/cover using --sidebar-background, z-index1 and pointer-events:none. Historical389 used higher z layers,396 lowered them so address-book dialogs were not covered. Check every consumer and modal stack when changing shared decoration. Prefer the current role class and semantic variable; no project-wide numeric z-index rule is established.

Scope: styles.
