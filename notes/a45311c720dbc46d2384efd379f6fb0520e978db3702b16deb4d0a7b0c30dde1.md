# MIME HTML closes after attachment output rather than body completion

The HTML display emitter writes closing body/html tags in EndAllAttachments rather than EndBody, retaining the filter-sniffer exception. EndBody still notifies body completion before attachment output finishes. The normal non-null attachment-list path calls end-all even when its per-attachment loop is empty. Added regression assertions check the exact output suffix, including a message without attachments; this is static source/test evidence, not an executed conversion or a guarantee for every failure path.

Scope: MIME HTML emitter lifecycle.
