# The secret-key email cache requires personal acceptance and valid user IDs

Current cache population skips keys without secret material, awaits personal-key acceptance and skips non-uid or invalid user IDs before storing lowercased email addresses. The attachment-import consumer lowercases candidate addresses before hasSecretKeyForEmail and avoids offering a public key for an address whose accepted personal secret key is present. Do not equate secretAvailable alone with membership in this cache. No key import or SQLite execution ran. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/extensions/openpgp.
