# Distinguish the retired settings importer from unimplemented mail import

The deleted Windows Live Mail module exposed a settings importer with real registry/XML account conversion; its mail interface returned NS_ERROR_NOT_IMPLEMENTED. The removed fixtures include IMAP, POP3 and NNTP accounts with encoded ports and identity settings. Preserve this historical distinction when describing why a component was removed. It is not a current recommended account schema, and the author statement that it was not connected to anything was not dynamically verified. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Windows Live Mail historical import scope.
