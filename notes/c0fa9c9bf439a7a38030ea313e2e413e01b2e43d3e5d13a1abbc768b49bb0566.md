# Shared link colors leave the theme guard while keeping the contrast guard

The original blue light/dark link variables sit inside not-prefers-contrast but outside the nested not-lwtheme block. Hover and visited reuse the normal link value, while active has another blue value. This broadens the local definition to themed normal-contrast hosts/roots; it does not assign those values in the contrast branch or prove a rendered palette. The unrelated removed field/button defaults stay separate.

Scope: Shared theme variable and link-state scope.
