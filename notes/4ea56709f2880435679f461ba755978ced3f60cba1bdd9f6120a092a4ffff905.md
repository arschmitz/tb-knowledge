# Let new pane buttons follow visual keyboard order

For the address-book pane header, keep navigation in visual order instead of assigning custom tabindex values to reorder actions. Review requested this and the accepted markup retains it. HTML buttons listen for click; XUL menu items still use command. The original NewBook click opened its menu. Current accepted source opens Account Hub when mail.accounthub.addressbook.enabled is true and otherwise opens the legacy popup. Check both routes when changing this control. Scope: these controls and matching component patterns. Purposeful roving-focus widgets can require different navigation. Keyboard operation was not run in this study. Correction to earlier lesson b1c1ff958ebe8d1d959c18a3a9764bc9bd860aea91c17d23488af349631df780: the newer accepted source above narrows or replaces that claim.
