# Parse every string within one DNS TXT record

One TXT record can contain several length-prefixed strings. The July 2024 follow-up walks all strings using the record data length and returns a TXTRecord holding the string array; Windows uses a cast based on dwStringCount. This corrects the May 2024 single-string assumption. The review caught that ctypes arrays lack map(), and Windows validation led to the landed Array.from form.

Scope: DNS TXT parsing.
