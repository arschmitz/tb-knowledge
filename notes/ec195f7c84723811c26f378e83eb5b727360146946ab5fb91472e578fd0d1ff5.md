# View-source popup cleanup waits for hidden before closing its window

The view-source encoding subtest waits for its context menu to be shown, checks the visible menu IDs, calls hidePopup and waits for hidden before closing the source window. The patch also replaces pre-registered popupshown waits with waitForPopupEvent calls after the opening actions. This records the accepted test sequence; the unpaired Gecko helper and historical reliability report do not prove a general timing guarantee. The ordinary menu branch is skipped on macOS. No test ran.

Scope: browser-view-source-tests.
