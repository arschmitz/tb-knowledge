# The signed-header test passes its diagnostic to Array.some instead of Assert.ok

In the signed-message task, the string "header-protection cipher line should have been found" is the second argument to lines.some. That argument is Array.some thisArg; it is not the Assert.ok message. Assert.ok therefore receives only the Boolean result. The original landing and fixed accepted test retain this unchanged neighboring issue. The newly added Bcc assertion has a correct nonempty expected-result message. A correction would move the existing diagnostic to the outer Assert.ok call; no implementation change or runtime test was made.

Scope: Thunderbird OpenPGP browser-test assertion review.
