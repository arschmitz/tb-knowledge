# Awaiting the AccountHub token lookup does not await the native server-loaded notification

The repaired AccountHub handler awaits getRefreshToken before its empty-token guard and event dispatch. The actual listener interface declares onServerLoaded as void, and the native account manager invokes listeners then returns NS_OK. The await orders this JavaScript handler; it does not make the native notification wait for token lookup or downstream add-on processing. No account-creation or login result was executed. Generated source gaps remain separate from this bounded callback contract.

Scope: AccountHub token notification completion.
