# Shortcut placeholder styling belongs to the kbd container and its real style loaders

The shortcut patch moves flex spacing from a toolbar-only placeholder selector into .kbd-container. Its kbd descendants inherit text color, use a lighter mixed-color border and have no own background or box shadow. The fixed rule keeps separate Mac gap/font sizing. The Storybook text still claims background variants, so that prose is not proof of the rule. Removing the direct about3Pane.css widgets import does not remove the current messenger.css import chain; SearchBar also loads widgets through its shadow stylesheet. These are local component and loader facts, not general CSS rules.

Scope: search-bar shortcut presentation.
