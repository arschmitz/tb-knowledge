# S/MIME completion counts a result before ignoring its status value

The MIME producers notify signatureProcessingStarted before requesting verification. The sink rejects nested or non-current-message callbacks before counting. For a selected top-level result, it increments the received count before ignoring a MIME part or retaining an earlier bad status, then checks completion. This keeps result accounting separate from whether the result updates the display. The existing completion-gate lesson supplies the MsgLoaded/count/latch behavior. No native callback-delivery guarantee or runtime race result was established.

Scope: S/MIME signature completion accounting.
