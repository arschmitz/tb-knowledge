# Auto-compaction diagnostics expose the throttle and byte threshold

AutoCompact schedules an event only when the global one-hour interval and prompt setting permit it. The event aggregates local and offline expunged bytes and compares bytes against the KiB preference multiplied by 1024. Current logs name the triggering folder, current and next allowed times, aggregate threshold values and user permission to compact. Current code additionally guards reentrancy because the modal compact dialog can spin the event loop and another auto-compaction can modify the same database. A scope-exit guard clears the flag on early returns. The 2024 logging landing did not itself add that newer guard.

Scope: compaction.
