# Commands Patch Update task lifecycle and resume contract

Sessions are keyed by checkout path, revision, and mode rather than a stable task ID, coupling a conversation to a checkout that other actions can move. Startup recovery effectively selects managed-worktree sessions while manual Resume can find main-checkout sessions. [Task 1]
