# The shared alerts mock permits teardown during application shutdown

The MockAlertsService reland adds a Services.startup.shuttingDown condition around the unexpected teardown assertion. The fixed accepted mock retains that condition: teardown during shutdown is allowed, while an earlier call still fails the assertion. Other unexpected mock methods retain their own failures. This is a scoped test-helper lifecycle exception. The original failure cause, successful shutdown behavior, and native notification behavior were not tested in this study. Exact original/backout/reland comparisons and retained discussions remain separate audit evidence.

Scope: Mock alerts test service lifecycle.
