# Specify the simulated drag effect independently of modifier input

The address-book drag helper accepts expectedEffect and supplies it to synthesizeDragOver, then asserts the returned effectAllowed and dropEffect. The modifier object is a separate input. This lets tests describe platform intent without assuming ctrlKey always means copy. Preserve the distinct parameter names and exact expected result when extending the helper. The browser test source was inspected; no simulated or native drag test was run.

Scope: Drag test API and naming.
