# Keep compose-security return documentation nullable

The human MIME construction follow-up documents _getComposeSecure as returning a nullable nsIMsgComposeSecure. The fixed accepted implementation returns null when no secure object exists, draft auto-encryption is disabled, or encapsulation is unnecessary. For this method, keep JSDoc and callers compatible with those early returns. This is a manual contract documentation pattern beyond whitespace formatting, not a repository-wide preference for one nullable type syntax. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mailnews / compose.
