# Keep translated scanning instructions linked to the other app’s labels

Entry 998 changes the fourth instruction to Scan QR code and gives the changed message a -revision ID. Current Fluent comments link the Import settings and Scan QR code labels to exact Weblate translations, and markup uses the revised ID. Scoped manual localization rule: preserve a source link when a translated instruction must match another product’s label, and update the message identity and consumer when its meaning changes. Those remote Android labels were not read or tested here; the claim is about the desktop source contract.

Scope: mail/components/preferences.
