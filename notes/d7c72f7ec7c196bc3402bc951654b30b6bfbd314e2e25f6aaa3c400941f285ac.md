# Use the class-wide lazy preference getter for the chat textbox setting

1567 removes imTextboxUtils and installs defineLazyPreferenceGetter on MozChatConversation.autoResize. Accepted textbox input/resize paths read that class property and keep a splitter-drag guard. A scoped recommendation is to reuse the existing preference helper for this shared class state instead of a bespoke observer singleton. The helper’s paired Gecko implementation and live preference updates were not executed. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
