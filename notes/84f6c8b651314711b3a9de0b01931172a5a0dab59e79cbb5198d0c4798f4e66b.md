# Recreate a JavaScript context at each native notification

Current LiveView notification callbacks create AutoJSAPI in PrivilegedJunkScope, obtain the active context and root the new message object before calling the listener. The historical notification landing stored a raw JSContext; that detail is no longer accepted source. Follow the current callback boundary when extending native notifications. This static reading does not prove garbage-collection safety of every caller. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama native notification lifetime.
