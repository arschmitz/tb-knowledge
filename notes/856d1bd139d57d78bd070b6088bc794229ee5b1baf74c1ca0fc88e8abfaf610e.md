# Tree listbox tests wait for layout before interaction

At commit c5cabe3cba61247482ce2f79f0b608d058a074cf, browser_treeListbox.js added a requestAnimationFrame wait after browserLoaded and before focus and mouse interaction. This change addressed a selection failure where loading the document did not ensure item layout was ready. Use this as a scoped example when investigating layout-dependent widget tests, not as a rule to add frame waits to every browser test. The review described the fix tentatively. The supplied study ran no tests or runtime experiments.

Scope: tree listbox tests.
