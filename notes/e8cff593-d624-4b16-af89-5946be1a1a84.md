# menus preserves Manifest V2 account and folder event shapes

For Manifest V2, an account root selection exposes selectedAccount, while a child folder exposes selectedFolder with subFolders; Manifest V3 uses selectedFolders, including the root folder for an account, and omits those legacy fields. displayedFolder also avoids nested subFolders in Manifest V3. Tests assert both versions and the permission boundary. Current implementation retains these branches.

Scope: WebExtension menu compatibility.
