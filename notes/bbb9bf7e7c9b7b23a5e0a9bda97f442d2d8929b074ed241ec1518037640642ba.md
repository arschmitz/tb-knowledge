# Invalidate cached Calendar formatters when the application locale changes

The fixed current formatter caches by serialized format options. It clears that cache on intl:app-locales-changed, including the startup locale initialization notification, so a formatter created with a fallback locale is discarded. This observer is later accepted context, not a change introduced by 1065. The standalone month/weekday arrays are lazy getters and are not explicitly cleared in this block; this batch does not establish their behavior after a live locale switch. Keep cache scope and invalidation scope separate. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: calendar/formatter/locale-cache.
