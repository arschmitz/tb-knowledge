# OpenPGP key indexes store aliases in Maps and check primary-index emptiness

The primary Map stores key ID, fingerprint and short-ID aliases; the subkey Map returns each subkey parent key. Lookup checks primary first, and cache emptiness uses primary Map size. Clearing/rebuilding resets both Maps. Map size here is an alias-entry count, not a distinct-key total. This is the accepted component contract and the follow-up to its array/string-key problem, not a general Map or iteration rule.

Scope: OpenPGP key and subkey index ownership.
