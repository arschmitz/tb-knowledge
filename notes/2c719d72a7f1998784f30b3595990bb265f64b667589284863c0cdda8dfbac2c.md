# EWS message scripts use the existing message-scheme permission branch

Adding x-moz-ews to MESSAGE_PROTOCOLS routes EWS message documents through the content-script matcher's existing message permission check. That check requires messagesModify, or messagesRead together with scripting. It does not grant a new permission or register every protocol globally. The direct test registers a message-display script, opens an EWS message and waits for its notification; it was not run.

Scope: Extension message-display script matching.
