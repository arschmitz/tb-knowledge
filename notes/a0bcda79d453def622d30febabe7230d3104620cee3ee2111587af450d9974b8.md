# Documentation code-link styling targets descendants of anchors

This landing adds an underline and a 0.125rem underline offset for code and docutils.literal descendants of anchors. It changes no link target and does not directly select plain text links or standalone code. The fixed documentation setup registers the stylesheet with Sphinx. The supplied review screenshots were inspected, but no documentation build or rendered-cascade test ran; theme/generated HTML behavior and every markup variant remain outside the proof.

Scope: Source documentation CSS.
