# Lando revision selection declarations change in two separate phases

The follow-up adds repo-param-prefix: comm_ to both Lando workers and changes the version-bump source selector key to try-comm-central. The early-tagging and version-bump actions keep their separate promote/ship roles. Fixed accepted code later replaces per-worker prefix declarations with task-context head_rev from comm_head_rev and an explicit tag revision. These are configuration phases, not proof of a generated worker task or successful remote action.

Scope: Thunderbird release task configuration.
