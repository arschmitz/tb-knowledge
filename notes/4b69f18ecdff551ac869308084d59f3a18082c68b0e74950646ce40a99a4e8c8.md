# Name parallel drag tests as a feature family

Use browser_dragDropFolders.js alongside browser_dragDropMessages.js in this browser-test directory. The accepted review explicitly renamed browser_folderTreeDragAndDrop.js to match the existing message test. Proposed manual naming rule: prefer the adjacent feature family over a new synonym/order when adding a parallel test. This is evidence for this family, not a universal ban on snake_case helper names or other directories.

Scope: browser-tests.
