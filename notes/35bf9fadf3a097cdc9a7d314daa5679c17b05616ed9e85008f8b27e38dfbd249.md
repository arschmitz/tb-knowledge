# Resolve CardDAV relative paths from the final redirected URL

On a successful 207 response with a DOM, tryURL replaces the working URL with response.url. Later principal and address-book home paths are resolved against that base. Preserve this explicit redirected base when changing request deduplication or phase handling. This is a current discovery contract; no redirecting server was contacted.
