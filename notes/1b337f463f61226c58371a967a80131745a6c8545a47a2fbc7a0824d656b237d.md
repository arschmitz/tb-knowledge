# Test a tag needle that prefixes a longer token

The original splitter-based matcher tests whole space-separated tag tokens. The current character loop can leave n equal to needleLength after a later nonmatching character sets matchingStart false, then accept at a space or end of string without checking matchingStart. Inspected tests reject suffix oo and cross-token oo ba, but do not reject a prefix such as fo in foo. Proposed focused include/exclude test: use a needle that is a proper prefix of a longer token at both a token boundary and end of string. This is a static concern, not an executed failing case or completed repair. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Panorama tag token static test concern.
