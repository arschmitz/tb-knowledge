# Multi-message Fluent migration changes count text while preserving distinct count and size argument roles

Summary counts are now numeric Fluent arguments, while numBytes remains gMessenger.formatFileSize output. Limited-scan lower bounds and total/shown display-limit notices have different meanings. The subject-bearing row no longer wraps its count/unread text in parentheses; the actual .count span and inspected style do not supply that wrapper. Do not call the migration text-equivalent. The max-thread-count-exceeded comment says all threads were summarized even though its caller enters only after the display limit; the message itself says the first shown subset. No all-locale or rendered result was checked.

Scope: Multi-message summary localization.
