# Folder color defaults use flags while stored overrides and RSS remain separate

The dialog chooses its default color from folder flags instead of the folder name. RSS has a separate branch. A stored override still wins for the input value; reset previews the computed default and saving a default clears the override. Keep folder identity, computed default and stored custom choice separate. No rendered color or native-dialog behavior was tested.

Scope: Folder properties default color and reset state.
