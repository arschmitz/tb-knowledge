# Await custom element definitions needed by pane initialization

The about3Pane startup handler waits for its element definitions, including tree-view, before initializing the folder, thread and message panes. 1983 adds that missing dependency to the earlier readiness work. Keep the registry wait scoped to components initialization actually uses. A layout tick still exists during state restoration; this does not establish that all delayed layout work can be removed. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
