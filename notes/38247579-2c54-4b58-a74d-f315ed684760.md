# Keep SMTP settings on the SMTP-specific interface

The outgoing server refactor makes nsIMsgOutgoingServer the common sending interface and keeps hostname, port, and client ID on nsISmtpServer. Code that needs SMTP-specific fields explicitly queries that interface. This prepares for EWS sending without assuming every outgoing server is SMTP.

Scope: outgoing server architecture.
