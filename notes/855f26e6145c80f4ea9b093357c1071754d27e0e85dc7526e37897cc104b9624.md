# Smart-folder URI membership uses delimiter boundaries rather than substring identity

In the accepted special-folder scope branch, searchURI and folderURI are wrapped with pipe delimiters before Find, so a similar URI substring does not count as the same source token. This recommendation is scoped to that serialized URI list branch; not every later branch uses the same exact wrapping. Preserve the token grammar if replacing this search with a collection representation. This is static source and test-code inspection.
