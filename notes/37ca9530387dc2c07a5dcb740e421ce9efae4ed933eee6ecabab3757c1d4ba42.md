# Treat subscription checkboxes as the subscription action

Entry 1079 removes the extra subscribe/unsubscribe buttons and tests checkbox actions. Accepted UI now uses real checkbox inputs within checkbox-tree-table-row, associated labels and a search input with aria-controls. The row changes data on checkbox change and supports Up/Down focus movement. The old XUL tree hitbox helper has been replaced by a rendered checkbox helper. This is a current control contract; native checkbox Space behavior and assistive-technology output were not run. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/base/content.
