# Attachment Copy To uses an all-selection gate and a separate refresh completion

Copy To requires all selected attachments to be message/rfc822 or match the .eml URL-parameter fallback, with allowed URLs. The command guards its custom _folder target and awaits each import, but starts the IMAP refresh without awaiting it. This phase adds finally removal around temp write/copy; initial fetching and file setup occur before that try. The import test replaces production importing, so menu/dispatch assertions do not establish rejected-copy cleanup or refresh completion.

Scope: Attached-message Copy To eligibility and cleanup.
