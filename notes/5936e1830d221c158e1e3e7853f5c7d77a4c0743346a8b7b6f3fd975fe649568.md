# The compose focus patch changes Settings handlers while the old wrapper already forwards

The two changed compose entries are menu_preferences, not the cmd_account Account Settings command. They switch from openOptionsDialog('paneCompose') to openPreferencesTab('paneCompose'). The old mailCore helper already returns openPreferencesTab with those same arguments, while utilityOverlay.openTab owns the existing main-window focus and new-window fallback. This establishes the exact handler/owner route; the patch title alone does not prove a changed focus result or identify a wrapper failure.

Scope: Compose Settings command routing.
