# New identity catch-all visibility comes from the account server type

The dialog now supplies the account when initializing identity fields. Both existing and new identity paths hide catch-all only for an NNTP account, so a new POP identity can expose the checkbox before it has an email address. The hint remains labelled by the checkbox. The added test directly checks visible catch-all in a POP dialog; it does not establish the NNTP branch, saving, keyboard behavior or encryption-tab changes.

Scope: Account identity dialog controls.
