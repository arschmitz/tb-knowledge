# Account Hub DOM notification descriptions use the raw container and a delegated help link

A Node description is inserted with replaceChildren into the raw notification description and returns before text handling. The Config Found caller supplies a fragment with localized spans and delegates help-link clicks from their parent to the named anchor. The header test directly checks raw text and the link href, then clears the notification. Existing notification state/cleanup is reused; the test does not activate the link, validate localization cloning or establish accessibility announcements.

Scope: Thunderbird Account Hub DOM notification descriptions.
