# The fixed-width preference is inverted only for the MIME variable-width stream option

Display-stream setup reads mail_fixed_width_messages into MIME_VariableWidthPlaintext and then negates it before the variable-width option is consumed. Flowed-text setup uses the same preference directly as fixedwidthfont. Plain-text rendering checks the negated variable-width stream option before choosing -moz-fixed. Preserve the target Boolean meaning; the similarly named stored and local values do not have the same polarity.

Scope: MIME plain-text font state.
