# finishTest appends the WebGL postlude without waiting for script loading

Firefox repository `git:314d8065c5ad68c7e5c5f92d`, revision `1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b`. Scope: DOM Canvas WebGL conformance tests and the shared Mochitest harness. Languages in the cited files: JavaScript. File roles are listed in the metadata. No production WebGL implementation is claimed.

finishTest sets successfullyParsed=true, creates a script element, scans script URLs for one ending exactly in js-test-pre.js, derives its directory or keeps an empty base path, then appends js-test-post.js to the body. It returns without waiting for that script to load.

```javascript
function finishTest() {
  successfullyParsed = true;
  var epilogue = document.createElement("script");
  var basePath = "";
  var expectedBase = "js-test-pre.js";
  var scripts = document.getElementsByTagName('script');
  for (var script, i = 0; script = scripts[i]; i++) {
    var src = script.src;
    var l = src.length;
    if (src.substr(l - expectedBase.length) == expectedBase) {
      basePath = src.substr(0, l - expectedBase.length);
      break;
    }
  }
  epilogue.src = basePath + "js-test-post.js";
  document.body.appendChild(epilogue);
}
```
