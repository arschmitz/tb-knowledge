# The retired FilterEditor help bridge is not a current dialog action

1935 removes doHelpButton and its old Suite openHelp comment from the shared FilterEditor script. The accepted dialog exposes accept and cancel, and its script registers dialogaccept to onAccept. This is a narrow retirement of an unused bridge; it does not establish a project-wide ban on help or authorize removing unrelated help controls. Retain exact current control wiring when assessing whether a deleted helper had a user-facing action. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: FilterEditor help retirement.
