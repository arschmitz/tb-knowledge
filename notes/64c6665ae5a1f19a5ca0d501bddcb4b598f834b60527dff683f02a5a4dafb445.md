# Do not claim that a successful stub Cancel stopped the network request

482 introduces a CancellableRequest whose Cancel logs that cancellation is stubbed and returns Ok. The same stub remains in protocol_shared at the fixed current revision; other request methods return NS_ERROR_NOT_IMPLEMENTED. A successful API result is not proof that the outgoing HTTP operation was aborted. Current listener/caller orchestration changed, so this is a scoped implementation limitation, not an allegation that every cancellation path fails.

Scope: rust/protocol_shared/src.
