# Cache2 waits for the first validated segment before forwarding request start

The inspected IMAP cache listener keeps mStarting true until it handles the first cache2 data segment. It peeks for a usable cached message header before calling the downstream OnStartRequest, and falls back to the IMAP connection when cache2 data is rejected. Keep that phase behavior separate from simple constructor initialization. The class retains its channel and listener; no stale cache, concurrency or network fallback was executed. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mailnews / imap.
