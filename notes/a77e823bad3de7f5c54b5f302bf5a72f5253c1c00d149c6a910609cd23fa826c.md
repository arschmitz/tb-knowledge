# Searched folders can be absent from the smart-mode tree

At revision d15c88407bf2ebb1363d33567fefa9ca43643178, smart mode's _addSearchedFolder returns without adding a row when neither the searched folder nor an ancestor has the relevant folder-type flag. The source comment says this case has no suitable display representation. When investigating a missing row, distinguish tree rendering from virtual-folder search membership: this return does not remove the folder from the search scope. This is static source evidence for this renderer, not a runtime result or a rule for other folder modes.

Scope: Smart folder tree rendering.
