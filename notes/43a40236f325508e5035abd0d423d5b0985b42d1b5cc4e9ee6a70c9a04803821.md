# Do not confuse a hex assertion with rejecting malformed input

MsgUnhex accumulates hex digits and stops on the first nonhex character. The Status2 caller asserts MsgIsHex, but does not branch on its result in release code. Recommend describing this as bounded conversion with a debug expectation, not full strict input validation. The same helper has other callers outside the studied path; their policies were not audited. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
