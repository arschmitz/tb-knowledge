# The original week-highlight test uses a day-of-month index where a weekday is required

The new original highlight assertion indexes a seven-entry weekday-to-column map with getUTCDate(). That value is 1–31, so dates 8–31 select no entry and expect every column to lack today's highlight. The accepted assertion uses getUTCDay(), matching the weekday map. Preserve the original expectation and later correction separately; this static comparison does not establish a reproduced failure or its historical timing.

Scope: Calendar week-view expected values.
