# A shared folder-completion event does not alone prove message deletion

The attachment task registers promiseFolderEvent on the actual folder before clicking a Delete button. The fixed task notes that attachment removal can emit the same completion event, then directly asserts that the thread row count fell by one. It checks both message-header and unified-toolbar buttons. The junk helper separately avoids waiting for a deletion event when zero deletes are expected and observes the returned delete count. Preserve event identity and the direct expected result as separate checks. No browser task ran.

Scope: Folder event test oracles.
