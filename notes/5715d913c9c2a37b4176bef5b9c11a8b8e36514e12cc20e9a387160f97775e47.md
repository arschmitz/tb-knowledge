# The native view folder getter borrows its result while owning callers retain it locally

GetFolderForViewIndex now returns a borrowed raw pointer through the native virtual method. The search override returns nullptr for an invalid folder-array index. Local nsCOMPtr consumers still retain the result, while raw sorting-entry assignments no longer use the former AddRef then immediate Release workaround. The owning cross-folder array and raw IdKey field are distinct contracts. This change does not remove all reference operations, validate every reentrant lifetime or establish a measured speedup.

Scope: Native message view folder ownership.
