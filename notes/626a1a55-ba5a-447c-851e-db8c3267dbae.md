# Gecko stream callback adapters preserve the source receiver and native release contract

Production Gecko C++ and inline headers. Full source callback helper implementation
602 lines and header344 were read. This distinguishes actual JavaScript-source
algorithms from native input-stream algorithms. [Default controller](1a19fcd7-38db-4964-871e-e9c78917e65d.md)
owns one base interface and calls its actual override.

UnderlyingSourceAlgorithms header81–133 owns global, original JS source object,
optional start/pull/cancel callback objects, and traced JS references. Constructor
copies callbacks only when dictionary members were supplied. IsNative returns
false; destructor drops held JS references and cycle collection unlinks them.
The base type's IsNative default=true does not make every subclass native.

CPP42–117 invokes start/pull/cancel with original source as this. Controller
argument is a union selected by actual default/byte controller. Missing start
returns undefined; missing pull/cancel creates resolved undefined promise.
Pull/cancel returns callback promise; exceptions use the explicit rethrow mode.
Source ownership thus preserves listener identity and method receiver, including
Calendar bounded controller object supplied by its factory. It does not call
a same-named method on an unrelated calendar/provider.

UnderlyingSourceAlgorithmsWrapper CPP123–159 is for native subclasses. Start is
no-op undefined; pull uses controller's parent global and calls PullCallbackImpl;
cancel uses current native global and CancelCallbackImpl. StreamUtils.h27–55
PromisifyAlgorithm returns actual promise, turns catchable error into rejected
promise, or resolves undefined for absent result. Uncatchable error returns null.
Base native implementations can return null normally; that alone is not a failure.

ReleaseObjects is a separate virtual cleanup hook, empty by default. Controller
ClearAlgorithms calls it before dropping algorithms. Native input subclasses
override it to close owned input; JS callback class relies on cycle-collected
fields after references are dropped. Cancel callback, resource release, reader
lock release and pending-read settlement are separate mechanisms.

StreamUtils.cpp high-water-mark extraction returns provided nonnegative non-NaN
value (including Infinity) or default. Default chunk size validation rejects
Infinity separately in QueueWithSizes. These two checks are not interchangeable.
Build dom/streams/moz.build exports helper/controller/queue headers, compiles
the corresponding CPP in unified sources and links xul. The file's commented
mochitest/browser manifests are not active test registrations.

start/pull/cancel and call counts.129–165 checks start promise behavior;
194–225 checks rejected pull's exact error identity. They test JS adapters through
public API; no direct native subclass ReleaseObjects test was established by
