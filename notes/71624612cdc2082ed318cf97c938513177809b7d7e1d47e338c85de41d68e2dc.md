# Try Ubuntu alias removal does not turn literal parser test platforms into production tasks

The owned change removes linux32 from UNITTEST_PLATFORM_PRETTY_NAMES[Ubuntu], removes its matching expected value and the Ubuntu,-x64 special test, and changes the chunk/platform case to win32-only chunk1. Bracketed test selectors still expand known aliases and pass unknown names through literally. The separate -p path validates requested platforms against the supplied graph, while task_matches applies parsed restrictions to existing task attributes and the Try target method filters existing labels. Synthetic unit-test tasks still use literal linux values, which do not prove a production Linux32 task exists. The direct assertions check parsed dictionaries rather than build/test execution. The two changed assertEqual calls have no message arguments, and the pretty-platform test description still names linux although its expected list excludes it. Those scoped message/comment gaps remain in the accepted source; no missing-should-only defect or new global style rule is inferred. Accepted linux2404 aliases are a later replacement of the owned linux1804 family. No parser test or taskgraph generation was executed.

Scope: taskcluster/try-option-syntax.
