# Folder cache key renaming is supported but folder moves still need integration

The folder cache entry key is the message DB path. This accepted patch makes nsIMsgFolderCacheElement.key writable as AUTF8String, rejects a duplicate key, and invalidates other element objects holding the old key; its unit test covers each case. Reviewer requested the UTF-8 type and made the legacy migration file optional. Bug 1870463 remains open because folder copy and move routines were not changed to use the new setter. Do not describe the end-to-end moved-folder cache problem as fixed.

Scope: folder cache.
