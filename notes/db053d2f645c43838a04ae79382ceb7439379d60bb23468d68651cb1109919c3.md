# Keep encrypted strings and typed byte arrays at separate OpenPGP boundaries

559 introduces decryptArray and keeps decrypt as a compatibility wrapper that copies each byte-string character into a ctypes uint8_t array. GPGME receives the same array representation. RNP sizing and input use the array length. The wrapper is for a byte string, not arbitrary Unicode text; message charset conversion remains a separate caller responsibility. A helper name should describe its representation when two entry points coexist. No crypto fixture was decrypted in this batch.

Scope: OpenPGP byte representation.
