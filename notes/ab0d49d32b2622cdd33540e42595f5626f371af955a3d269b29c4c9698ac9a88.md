# Account Hub background-test cleanup also clears local Trash

The background Account Hub test captures the local root, creates a message folder, and later deletes that folder during cleanup. It then calls emptyTrash on that root’s Trash. The commit reports that leftover messages affected the telemetry test when run next. Keep the explicit Trash cleanup separate from deleting the test folder; no combined test run or completion assertion was performed here. The bug discussion has two unavailable comments, so this remains source-only evidence.
