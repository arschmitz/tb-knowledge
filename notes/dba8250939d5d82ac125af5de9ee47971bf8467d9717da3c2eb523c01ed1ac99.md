# The mark-read test's shared idle helper has no explicit EWS predicate

The test compares EWS fake-server read state after awaiting promiseServerIdle. That actual helper has explicit IMAP, POP3 and NNTP branches, followed by common status-bar cleanup; it has no explicit EWS branch. The UI cleanup is a separate contract, so the helper name alone does not establish EWS server-write completion. No backend timing or test failure was reproduced.

Scope: Message read-state test completion.
