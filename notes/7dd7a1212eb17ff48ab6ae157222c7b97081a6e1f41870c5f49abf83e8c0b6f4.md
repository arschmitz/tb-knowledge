# Popup state tests expect normal for a minimized window on Wayland

The popup state test keeps the requested minimized state separate from the reported expectation. On Wayland it expects normal, while maximized and fullscreen retain their own expectations. The annotation says clients cannot detect minimization there. This patch also removes the popup dimension case and retry helper; it does not establish replacement dimension coverage or a fresh Wayland result.

Scope: extensions/windows-tests.
