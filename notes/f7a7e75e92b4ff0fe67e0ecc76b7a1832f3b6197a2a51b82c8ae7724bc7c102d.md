# The ExchangeFolder implementation rename preserves its stored ID and sync keys

The implementation and helper names change to ExchangeFolder, GetExchangeId and kExchangeIdProperty, while the stored property remains ewsId. The renamed sync-state constant retains ewsSyncStateToken. Local folder creation and ID reads use those exact strings. Both ews and graph folder factories map to ExchangeFolder, and the actual legacy lookup service selects the factory from the URI scheme. The rename does not establish a profile migration, compiled ABI result or remote behavior guarantee.

Scope: Exchange folder implementation rename and profile properties.
