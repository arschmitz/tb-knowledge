# Address book form control spacing must preserve select text and visible focus

The 2024 address book fix aligned vCard select controls with inputs and adjusted focus outline offsets. Removing line-height: 1 stopped clipping glyph descenders, but review found select text moved down on Windows. The accepted local choice was padding-block: 0, after discussion of 0 1px. Current vcard.css still uses padding-block: 0 for this control group. When changing these controls, inspect select text, descenders and focus outlines on relevant platforms and font sizes; do not turn one pixel value into a global style rule.

Scope: Address book vCard form styling.
