# External signing tests check both the selected key and the verified signer

The detached tests inspect args.externalSenderSigningKeyID and then verify both the signature status and returned signer ID. A third task combines external signing with RNP encryption, decrypts the result and checks the plaintext plus signer ID. These are direct intended assertions for the primary and signing-subkey fixtures; source inspection does not establish a successful native roundtrip, library compatibility or coverage of every error path.

Scope: OpenPGP external signing-test assertions.
