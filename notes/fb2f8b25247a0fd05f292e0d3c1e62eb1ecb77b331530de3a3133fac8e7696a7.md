# Keep buffered-row tests distinct from full-query sort tests

The historical adapter tests exercised insertion and removal before, between and after cached rows and across uncached gaps. Separate native sort tests checked ascending and descending expected arrays. The accepted adapter test now waits for async loading and repeats notifications across supported sort directions. Test the changed representation boundary as well as final order; old sparse-hole expectations are historical and should not be copied into the current implementation. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama test scope.
