# EWS retry delay comes from typed ServerBusy u32 data

The accepted owned response parser converts typed ServerBusy delays into Duration for both a response message and a SOAP Fault. The imported type parses BackOffMilliseconds as u32; Other is the last untagged enum variant. This differs from the historical owned usize clamp. No broader oversized-value fallback guarantee or live server behavior was established.

Scope: ews-rust-throttling.
