# Request OAuth permissions for the actual protocol account

756 removes EWS permissions from the common Microsoft scope set. Newer accepted OAuth2Providers separates EWS_SCOPES and selects it for ews/exchange protocol types, while FindConfig clones an Exchange configuration into the built-in ews alternative without changing the original add-on configuration. Permissions belong to the account protocol, not every account at the provider. The current provider source is a refinement, not proof that the complete later authentication changes were studied or tested.

Scope: Microsoft account protocol permissions.
