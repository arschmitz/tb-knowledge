# Loopback OAuth connections keep separate streams until one claims the listener

This landing gives each accepted connection its own streams and request buffer. A stream-availability failure closes that connection; one completed or rejected request can claim the listener, close the others and retain its response output. The new test holds an idle connection open before the normal mock callback; it does not directly cover the empty-connection close described in the report. Oversized partial input can reject before CRLF. Tests and native sockets were not run.

Scope: External OAuth loopback listener.
