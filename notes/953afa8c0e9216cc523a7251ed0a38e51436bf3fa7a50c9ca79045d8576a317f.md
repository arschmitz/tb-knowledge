# Derive telemetry expectations from fixture payload and storage overhead

845 calculates expected message payload size from the synthetic fixtures and uses a bound for disk space that includes mbox separator overhead. Counts remain exact; storage bytes need not equal payload bytes. The fixed accepted test converts Glean BigInt values before comparing. JavaScript string length is appropriate to these inspected fixtures, not a general byte-count rule for arbitrary Unicode messages. No disk measurement ran.

Scope: Account storage telemetry test bounds.
