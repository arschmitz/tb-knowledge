## createItemsFromBookmarksTree

Evidence: [createItemsFromBookmarksTree:986-1052](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/components/places/PlacesTransactions.sys.mjs#L986-L1052).

Trigger: Remove.undo restores a captured tree; Copy executes/restores copied tree.

Recursively inserts bookmark/folder/separator in child order. Restore mode supplies original GUIDs/dates. Copies keyword/tag data for leaf bookmarks. Root index is honored; child indices append. Restored folder lastModified is reset after its children update it. Unknown type reaches return without insertion only after any restore-mode date validation succeeds.

Result and completion: Resolves to created root GUID, or undefined for an unsupported tree type. Remove/Copy use it to rebuild items.

Errors: A storage/keyword/tagging/child failure rejects after any previous insertions. There is no cleanup or transaction wrapper in this helper.

Ownership and cleanup: Recursive closures hold each current tree item until completion. Caller transaction owns the retained tree.

## PT.Remove.prototype.execute

Evidence: [PT.Remove.prototype.execute:1457-1498](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/components/places/PlacesTransactions.sys.mjs#L1457-L1498).

Trigger: Remove facade transacts; controller builds a grouped removal.

Captures each GUID tree before deleting. Invalid-URL errors become GUID-only fallback records; other capture failures abort. Removes GUID list. Undo attempts each tree independently, logs failure, and narrows removedItems to entries whose helper call fulfilled. Redo removes that updated list.

Result and completion: Resolves undefined. Undo can complete after only some items restore; it is not a guarantee that the entire original tree is restored.

Errors: Undo catches per-tree restore errors. A GUID-only fallback has no date fields, so actual PlacesUtils.toDate validation throws before type dispatch. It is caught/logged and omitted from createdItems.

Ownership and cleanup: History raw transaction retains removed trees until history/caller release.

## PT.Copy.prototype.execute

Evidence: [PT.Copy.prototype.execute:1724-1752](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/components/places/PlacesTransactions.sys.mjs#L1724-L1752).

Trigger: Copy facade transacts.

Captures source tree, replaces parent/index, creates items without restoring GUIDs/dates. On first undo captures copied tree then removes it. Redo recreates that snapshot in restore mode.

Result and completion: Resolves copied root GUID to callers. Tree capture on first undo preserves then-current copied data.

Errors: Capture error is wrapped with source GUID. Recursive creation failure has no automatic cleanup.

Ownership and cleanup: Owns source tree and lazily captured copied tree through undo/redo closures.

## PlacesUtils.promiseBookmarksTree

Evidence: [PlacesUtils.promiseBookmarksTree:1736-1941](https://github.com/mozilla-firefox/firefox/blob/1a097ed8d31f6b307a5d0ebc34a82ceaf7f3727b/toolkit/components/places/PlacesUtils.sys.mjs#L1736-L1941).

Trigger: Remove captures undo data or Copy captures source/copied tree.

Runs a recursive descendant query that skips the tags root during recursive descent, returns parents before children, and obtains tags/charset/icon data. An explicitly selected root is not filtered by that predicate. Copies fields with non-null values, validates bookmark URLs, and fetches keyword data. Invalid root errors are rethrown; invalid children are logged and skipped. Optional exclude callback skips a folder subtree. Yields to main thread every50 retained rows.

Result and completion: Resolves root tree or null for no rows. Root includes parentGuid and nonenumerable itemsCount; descendants omit parentGuid and retain child order. Dates stay Places numeric time values for restoration helper conversion.

Errors: DB/root conversion errors reject. Child conversion or parent-map errors log and continue, so a fulfilled tree can omit bad children.

Ownership and cleanup: Local parentsMap and rows live through traversal; caller transaction retains returned tree.
