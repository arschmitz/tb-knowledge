# Round splitter size before writing column width state

Bug 1890731 rounds the PaneSplitter requested size to an integer before setting height or width. The author noted a fraction of a pixel cannot be used by this element, and AutoTreeView persists integer column widths. This keeps saved widths stable across resize and restore. Current pane-splitter.js should still be checked before using the old line as a code template.

Scope: Pane splitter sizing.
