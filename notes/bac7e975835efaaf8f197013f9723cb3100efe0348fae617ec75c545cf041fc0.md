# Keep envelope fallback metadata outside raw message headers

842 replaces unused envelope buffer fields with explicit sender/date state and a SetEnvDetails API. StoreIndexer initializes that state before parsing the message, and FinalizeHeaders uses it when Date is missing. Preserve the distinction between the store separator and the RFC message header when rebuilding an index. Later current parser representation was inspected only in the listed windows.

Scope: Message parser external envelope metadata.
