# The disabled port aligns command writers, readers and selectors

The comm port changes disabled representation across file roles. Existing XUL commands start disabled with an empty attribute. goSetCommandEnabled forces presence with the inverse enabled Boolean and still emits commandstate for an absent command. The HTML toolbar button reads command presence into its disabled property. Menu CSS uses presence for disabled styling and hover exclusion. This is scoped comm source support, not independent upstream engine verification or permission to convert unrelated checked/state/ARIA attributes.

Scope: Thunderbird command and control state.
