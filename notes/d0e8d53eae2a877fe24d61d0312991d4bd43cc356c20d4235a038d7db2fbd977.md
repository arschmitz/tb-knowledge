# Thunderbird a11y scheduling filters its platform set separately from chunks

The a11y-checks run-on-projects branch selects built-projects for linux.*64/opt and an empty project set otherwise. Ordinary and msix variants retain their own branches. Chunk counts are configured separately, so this does not make the accessibility run a single task. The exact accepted local mapping is checked; no graph or CI scheduling run was performed.

Scope: Thunderbird browser-test task scheduling.
