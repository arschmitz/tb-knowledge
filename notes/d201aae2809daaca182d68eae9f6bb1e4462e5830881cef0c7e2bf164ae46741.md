# Release-level ports change the full family of comm transform inputs

The 4298 port changes seven comm transform callers from a project string to the full params object. The values feed environment and localization selection, hardened-signing configuration, the production langpack gate and updater-verification arguments. Keep those consumers aligned when changing the helper boundary; checking one call does not cover the other outputs. The accepted surviving callers have since moved to a two-argument form with graph_config release-branches and params, while signing has become a local shim after upstream work. These are separate source phases. This lesson establishes only the comm caller contract; the imported helper's GitHub classification logic is an unpaired dependency, and no graph or release ran.

Scope: Taskgraph release-level caller contract.
