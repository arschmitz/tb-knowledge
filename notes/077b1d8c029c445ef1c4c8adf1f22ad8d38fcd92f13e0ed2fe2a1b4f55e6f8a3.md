# Panorama normalization propagates Rust errors before database execution

DatabaseUtils wraps the Rust normalization result in Result<nsCString, nsresult>. Its changed callers use MOZ_TRY before binding each normalized value, so a failure returns before that path executes the affected statement. The Rust destination can contain a normalized prefix before a write error, but the C++ wrapper returns Err instead of exposing its local output as success. This is not a whole-migration rollback guarantee. The exact backout and later reland remain separate phases.

Scope: Panorama NFC normalization and Rust/C++ error boundaries.
