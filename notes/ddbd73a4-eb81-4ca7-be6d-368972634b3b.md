# Choose address book import targets by write capability

The address book importer formerly allowed only JS_DIRECTORY_TYPE targets, which excluded writable CardDAV books. The May 2024 fix filters directories by !readOnly instead. This includes every writable directory type and excludes read-only sources, so future import targets should use capability rather than a concrete implementation type.

Scope: address book import.
