# The accepted Exchange OAuth lookup adds a username input

The native property accessors used by the new JS helper resolve custom details through GetDetailsForHostname. In the owned phase that helper passes type and hostname to ForTypeAndHostname. The accepted phase also reads username and passes all three values to ForAccount, despite retaining the old helper name. This is an exact caller-input difference, not proof of per-account isolation, a privacy defect or a successful migration. The new one-account property tests do not directly compare independent accounts.

Scope: Exchange native OAuth accessor lookup phase comparison.
