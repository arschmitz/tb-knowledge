# The initial signoff port removes one localization transform registration

This landing removes gather_required_signoffs from the comm localization module's import and transform tuple. The accepted module retains the other schema and job-description stages. Both ordinary and shippable localization kinds include that module, so the removed registration affects those declared pipelines. The two-line patch does not establish that every signoff, parameter or release gate was removed. Upstream helper behavior and task-graph execution remain outside this static scope.

Scope: Thunderbird localization task-graph pipeline.
