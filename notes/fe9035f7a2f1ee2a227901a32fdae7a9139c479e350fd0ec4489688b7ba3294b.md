# The offline IMAP downloader starts its mailbox-update phase with a defined false flag

This landing initializes m_mailboxupdatesFinished to false in the class declaration. The constructor does not assign it, and the service immediately calls ProcessNextOperation after constructing the downloader. That method reads the flag before the server-update pass and sets it true when that pass finishes. The inspected existing fake-IMAP test checks downloaded-message flags; it is not newly added coverage or an executed sanitizer/native result. This is a scoped initialization contract, not a repository-wide C++ style rule.

Scope: IMAP offline downloader initialization.
