# Graph documentation markup applies narrow string transformations

markup_doc_comment formats recognized description patterns rather than parsing general Markdown. It wraps selected examples, lists and query keywords in backticks, then adds a summary paragraph when none exists. In-place escaping inserts the end delimiter first to preserve the saved start/end positions. The example loop searches an unchanged lowercase copy with a slice-relative index while mutating the original; repeated-match offsets are a static concern outside the one-example test's direct assertion. No repeated-match failure or documentation build was executed.

Scope: Graph API documentation generation.
