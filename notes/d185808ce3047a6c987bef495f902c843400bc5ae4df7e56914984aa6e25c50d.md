# An OAuth success-callback decode failure has no local listener-failure route

The OAuth module passes an async success callback and a sibling rejection callback to connect().then. A new payload decode or JSON parse can throw inside the success callback. The promise returned by then is not returned or caught in this scoped callback, so its sibling rejection handler does not route that failure to listener.onFailure. The Account Hub waits on that listener through a deferred promise. The fixed accepted code retains this structure. This is a static completion gap, not a reproduced hang, malformed-token test result or claim that all cleanup is missing.

Scope: OAuth promise and callback completion.
