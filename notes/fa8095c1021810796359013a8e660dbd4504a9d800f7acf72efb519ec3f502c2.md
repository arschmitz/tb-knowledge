# A decorative severity icon does not supply the notification text

The header template gives each severity image an empty alt, keeps localized and raw title text, and uses a native details/summary control whose summary has role=alert. The widget adds aria-describedby only with a description and marks details aria-disabled otherwise. These checked semantics need to remain consistent with title/description visibility. CSS pointer-events: none is not proof that keyboard activation is blocked, and no assistive-technology behavior was tested. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/components/accountcreation.
