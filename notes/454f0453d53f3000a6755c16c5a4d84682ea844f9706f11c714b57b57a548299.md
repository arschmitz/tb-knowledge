# Account-creation class conversion updates dependent error constructors and cause metadata

This modernization turns the old Exception prototype into an Error subclass before a later patch removes that wrapper. Dependent CancelOthersException and MalformedException construction changes from parent .call(...) to class inheritance with super(...). ServerException also starts forwarding cause while retaining code, uri and url. Keep constructor compatibility and error metadata with the parent-class change; the later generic-wrapper removal is a separate source phase. These local changes do not require class conversion for unrelated functions.

Scope: Thunderbird account-creation exception construction.
