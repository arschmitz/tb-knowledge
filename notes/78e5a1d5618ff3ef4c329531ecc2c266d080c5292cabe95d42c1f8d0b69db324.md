# The DoOperation reland completes the outgoing failure-context migration

The original DoOperation patch changes OnSendStopArg to a two-item URI/message tuple and passes the error separately, but leaves send_message using the prior three-item tuple and Rc. After its exact backout, the reland changes that caller to pass &err and construct (server_uri, None::<String>). All other reland post-blobs in the seven-path group match the original. This supplies the concrete repair phase for the existing constructor-migration lesson. Check every caller of an associated failure-context type when a patch must build independently. This does not impose a general Rc rule or prove the sole historical build-failure cause. Current operation/completion code was checked separately; no compiler or connectivity test ran.

Scope: EWS DoOperation original-backout-reland.
