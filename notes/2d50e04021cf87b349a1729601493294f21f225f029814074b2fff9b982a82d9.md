# Remove old localization ownership before showing a raw config value

For native ews and graph names, the widget sets a Fluent message. For other protocol names it removes data-l10n-id before setting textContent and title together. Preserve that ownership change when reusing an element for a localized label and a dynamic raw value. The helper uses plain text rather than constructing HTML; this local pattern does not establish sanitization of every config field. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub result text ownership.
