# Treat appended count-column order as a cross-language data contract

The C++ cell-data provider makes unread and total count columns available to a dummy row, and the JavaScript renderer reads the last two values with at(-2) and at(-1). The comment calls out the assumption. Keep the producer order, renderer and regression assertions together; default-column tests alone do not prove every column permutation. A proposed enum/set redesign and EnsureColumnNames method were deferred to keep the uplift small and readable. They were not adopted architecture. Do not infer that Array.at is a rule for all array indexing.

Scope: Message list model and renderer contract.
