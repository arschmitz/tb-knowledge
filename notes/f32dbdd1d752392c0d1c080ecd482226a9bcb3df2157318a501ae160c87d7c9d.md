# Include platform-only translation units in build recovery checks

The 2024 recovery includes Windows search, Outlook import, Windows hidden windows and macOS address-book property mapping. Accepted source still has runtime annotations for the macOS mapping and Outlook globals, while hidden-window storage now uses constinit. A Linux-only source or test pass cannot establish that these changes compile on Windows or macOS. Scoped verification recommendation: check the platform gates and compile the affected native sources on their supported platform. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
