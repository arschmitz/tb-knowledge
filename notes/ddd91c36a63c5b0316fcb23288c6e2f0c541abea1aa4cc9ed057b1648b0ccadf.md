# Cloud-file upload still passes a File object after the old ArrayBuffer reader is removed

promiseFileRead was an unused FileReader wrapper returning an ArrayBuffer. The accepted uploadFile creates a File with File.createFromNsIFile and passes it as data in the uploadFile event. The persistent listener wakes the background context before converting the tab/account and forwarding {id,name,data}. Keep the actual File payload when reading or changing this upload path. This source comparison does not imply that the removed helper was on the active upload path. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: cloud-file payload contract.
