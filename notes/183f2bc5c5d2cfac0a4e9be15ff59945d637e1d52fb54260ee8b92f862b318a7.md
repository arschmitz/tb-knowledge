# Linux desktop-file generation accepts resources independently of the package

The Debian packaging backout removes the packaging templates and task at that historical point, but also changes the desktop-file generator to accept locale and Fluent resource inputs. The fixed current generator takes locales and fluent_resources explicitly, excludes missing translations, and adds en-US when rendering. Later 611 restores deb-templates and deb-l10n-templates in repackage config; current templates exist again. Do not infer that Debian support is permanently removed from a backout or teach its reason beyond the visible "by request" message. The useful current boundary is reusable desktop-file rendering versus packaging-specific paths. No package or translated desktop file was generated.

Scope: packaging.
