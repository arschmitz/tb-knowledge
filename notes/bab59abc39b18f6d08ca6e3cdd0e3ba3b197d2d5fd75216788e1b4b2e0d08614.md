# Removing MD2 changes the signed MIME class allowlist rather than proving verifier behavior

mime_find_class checks multipart/signed protocol and micalg parameters before choosing the CMS signed class. This patch removes the MD2 name from that allowlist. A failed match leaves no signed class; a non-exact request can subsequently fall back to mimeMultipartOtherClass. Keep this parser/class choice separate from cryptographic verification or a broader digest policy. The upstream port is unpaired and no signed-message test ran.

Scope: mime-smime.
