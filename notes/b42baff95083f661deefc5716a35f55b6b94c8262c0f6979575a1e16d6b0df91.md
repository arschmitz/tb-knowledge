# Password autocomplete styling depends on the toolkit row structure

Thunderbird hosts PopupAutoComplete as an autocomplete-richlistbox-popup panel. Its stylesheet targets toolkit-produced richlist rows and child classes such as ac-login-item, two-line-wrapper and labels-wrapper. The login secondary action is hidden, while separate selectors control empty icons and possible-username icon visibility. Preserve those element/type scopes when changing this styling; the selectors alone do not establish which toolkit features are exposed or whether login actions work. The exact paired renderer and computed layout remain unchecked. No UI test ran.

Scope: autocomplete-popup-theme.
