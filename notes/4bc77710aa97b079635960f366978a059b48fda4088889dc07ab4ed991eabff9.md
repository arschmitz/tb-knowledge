# Capture the attachment receiver for helper-app callback methods

The helper-app launcher object has its own this. The surrounding code captures const attachment = this and saveDestinationAvailable calls attachment.saveToFile(file.path). When editing this callback object, keep the attachment receiver explicit rather than calling the method on the launcher. This is a scoped JavaScript receiver rule supported by current code, not a reviewer-approved project-wide alias convention. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mail attachment callbacks.
