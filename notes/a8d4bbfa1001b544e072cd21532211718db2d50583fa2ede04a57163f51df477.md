# Calendar titlebar offsets share the component spacing and button-padding variables

The Calendar titlebar reads its inline padding from the row-padding variable, and its control container computes the end offset from --button-padding. Close and Back set --button-padding from --space-step and clear their margins. Keep those dependent box values aligned when changing this component. The original and current row arrangements differ, so this local relationship does not establish fixed pixel dimensions, a universal spacing rule or a general nav-button class.

Scope: calendar-dialog-css.
