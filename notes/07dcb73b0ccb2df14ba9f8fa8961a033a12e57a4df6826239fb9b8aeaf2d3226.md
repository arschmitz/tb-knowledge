# Legacy folder UI attribute removal spans interface, native owner and final caller

After the Search Messages consolidation, entries 2040–2041 remove lastMessageLoaded, showDeletedMessages, displayRecipients and manyHeadersToDownload from nsIMsgFolder. The changes remove the last UI assignment, backing member/constructor initialization, native methods and local-folder override. Bounded checks at the frozen revision find none of these identifiers in the six named owner/caller paths. This proves only those paths, not every external extension or project-wide absence. The old manyHeadersToDownload behavior was a load/notification heuristic and the old lastMessageLoaded value was session-local; do not recreate them as current folder contracts from historical comments. Static source and test inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending-single-browser-reader.

Scope: Legacy nsIMsgFolder UI attribute retirement.
