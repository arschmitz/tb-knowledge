# ServerType groups common server bounds while narrower helpers stay separate

The historical EWS-local ServerType groups AuthenticationProvider, UserInteractiveServer and RefCounted with a blanket implementation. The client writes its static lifetime bound separately. Copy/move construct_request helpers retain RefCounted-only bounds, so the shorthand does not replace every server constraint. The accepted shared trait later adds PrefBasedServer and public visibility; keep that later capability set separate from the original three-bound helper.

Scope: ews-rust-generic-bounds.
