# CryptoUtils URI migration has three Thunderbird auth consumers and a packaging edit

The owned port switches XMPP auth, OAuth2 and POP3 CryptoUtils imports to moz-src:///services/crypto/modules/utils.sys.mjs and removes the explicit cryptoComponents.manifest installer entry. Accepted code keeps that import for OAuth random tokens and PKCE, POP3 APOP digests and XMPP nonces. These are import and package-source facts. They do not establish upstream crypto behavior, package contents, a passing lint run or a successful build. Check resource registration and actual package output separately when diagnosing resolution.

Scope: Thunderbird CryptoUtils import and packaging boundary.
