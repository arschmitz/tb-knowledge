# Gloda removed unused default hook variables but kept named no-op tasks

1934 removes pre_setup_populate_hook and post_setup_populate_hook plus wrappers that called them. Current base_query_messages_tests still contains named empty pre_setup_populate and post_setup_populate functions around setup_populate. The current online, offline and online-to-offline drivers simply add each task, and a bounded search finds no other uses of those two task names. This cleanup does not establish a general rule to remove all empty functions or prove those names are active extension hooks. Preserve that distinction when explaining the historical change. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Gloda cleanup scope.
