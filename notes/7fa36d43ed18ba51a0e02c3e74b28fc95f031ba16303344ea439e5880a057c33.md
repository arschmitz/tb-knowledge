# Keep localized meaning-specific IDs with their feature rather than reuse a generic no-value string

Calendar review supported no-categories as a dedicated label rather than borrowing an unrelated NoWhatever string. IDs should follow semantic scope and group related messages. The reviewer explicitly was not a language expert; this is supported manual design guidance for that feature, not proof that translators approved every grammatical case.
