# Keep Panorama compatibility stubs separate from implemented behavior

The 1949120 compatibility patch deliberately returned success for pending-listener registration and supplied placeholder database size and summary-valid values so legacy tests could proceed. Its new Thread class still returned NS_ERROR_NOT_IMPLEMENTED, and the original enumerator created one object per message. The selected fixed source later groups by threadId and implements several Thread methods; it does not retroactively make the original stubs functional. Current pending registration adds a listener, while unregister remains a no-op. Preserve these source states when describing completion. The accepted review also leaves news/server-ID compatibility unresolved. No tests or runtime behavior were executed here.

Scope: Panorama compatibility database contracts.
