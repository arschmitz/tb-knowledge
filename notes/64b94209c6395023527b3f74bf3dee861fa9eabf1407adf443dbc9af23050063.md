# The release-source task selects the Thunderbird source upload configuration

The release-source task runs package-source through mozharness/scripts/fx_desktop_build.py and explicitly selects builds/thunderbird_source.py from the comm config path. That config supplies upload_env.UPLOAD_PATH as /builds/worker/artifacts. Keep the selected task config and its nested key together when changing source-package output paths. This is a static configuration join, not proof that a build or upload passed. The Gecko script implementation was not inspected.

Scope: Taskcluster source packaging.
