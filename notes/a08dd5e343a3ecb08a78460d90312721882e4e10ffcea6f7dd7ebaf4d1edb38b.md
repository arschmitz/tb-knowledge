# Notification type selects a destination as well as whether a banner appears

The notification manager treats donation_browser and donation_tab as notifications without banner UI. The accepted opener routes donation_tab to a foreground contentTab with the single-page handler when a mail window has tabmail, and falls back to the external browser otherwise. Keep those two type values distinct from the donation banner type; renaming the enum is a routing change, not only wording. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
