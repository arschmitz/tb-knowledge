# Add wording changes Fluent labels while keeping address-book toolbar identity and commands

The Add wording patch updates visible labels and titles without renaming the create-address-book item, its template or its module. The item labelId and template data-l10n-id identify the button message; label-id identifies the separate inner-label message. UnifiedToolbarButton localizes that inner label, and the concrete control still dispatches the popup data-command. Check both resource consumers when making this scoped wording change. This does not prohibit New in traditional submenus or prove rendered names, shortcut behavior or locale completeness.

Scope: Account and address-book creation labels.
