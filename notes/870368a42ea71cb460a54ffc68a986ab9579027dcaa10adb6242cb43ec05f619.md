# CardDAV discovery updates its base from the completed response URL

makeRequest exposes a URL made from the completed HTTP channel. When tryURL receives a 207 response with a parsed document, it stores response.url before resolving discovery hrefs. The principal, home-set and book consumers use that url binding. The later book loop also mutates the binding, so this scoped update is not a claim that every relative href uses an immutable document base. No redirect was executed here.

Scope: Thunderbird CardDAV address-book discovery redirects.
