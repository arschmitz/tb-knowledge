# Filename encoding has a reserved-name case limit despite its round-trip comment

EncodeFilename matches reserved Windows stems case-insensitively, then percent-encodes the uppercase table literal. Direct static evaluation of con therefore decodes as CON. The tests cover uppercase reserved stems and Unicode pass-through, but do not cover that lowercase case; the supposed multibyte encode-everything test repeats foo. Fixed source keeps these limits. Do not teach the broad header comment as an arbitrary-input exact-reversal guarantee. No GTest or filesystem operation ran.

Scope: Filename encoding contract and oracle limits.
