# Update licensing and third-party lint boundaries when relocating SAX

The SAX cleanup removes the obsolete XMPP-local lint configuration and old license-body path. Current SAX packaging declares LICENSES["sax"] metadata and assigns LICENSED_UNDER to sax, and ThirdPartyPaths names comm/third_party/sax-js/. Keep packaging, license registration and lint exclusion paths aligned with the actual vendor location. This is a dependency-integration recommendation; it does not authorize treating the owned wrapper as imported coding-style guidance or claim a lint/license build passed. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.
