# Invitation rows crop text while keeping action controls outside the overflow box

The row builds icon, content-box and action vbox as siblings. Only content-box gets overflow:hidden, while labels retain crop=end; the row also reserves logical overlay-scrollbar space. The dialog loads the matching stylesheet, and its stream-created rows hydrate from calendar items. This source structure does not prove that buttons remain visible at every width or zoom.

Scope: Calendar invitation dialog layout.
