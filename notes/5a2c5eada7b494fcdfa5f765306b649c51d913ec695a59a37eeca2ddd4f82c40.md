# Compare message identity across URI representations before accepting status

EnigmailFuncs.isCurrentMessage compares the host and decoded folder/message number. A file: message and its mailbox: display URL can identify the same message with different raw spec strings. S/MIME status callbacks use the shared helper before updating the selected message. Current code resolves the current URI through getUrlForUri; the historical getUrlFromUriSpec helper name should not be copied. Trace semantic identity and stale callbacks for file-opened messages instead of assuming a selected database header or equal strings. This URI behavior was inspected, not exercised with live callbacks.

Scope: Message identity and crypto status callbacks.
