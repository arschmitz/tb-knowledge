# The IMAP mapping helpers centralize casts before database key separation

This landing changes offline flag replay to pass message keys and centralizes the conversion before the IMAP service receives a UID set. Its helpers still ignore the database argument and clone or cast numeric values; accepted later names retain that boundary. Header promises about missing messages and omitted UIDs are not implemented by those casts. SyncFlags and NotifyMessageFlags replace ContainsKey checks with helper results and sentinel checks, so the helper is not proof of database membership. Lower storage-engine behavior and runtime effects remain unverified. The two added single-condition MOZ_ASSERT calls also provide no diagnostic message.

Scope: IMAP UID and message-key mapping.
