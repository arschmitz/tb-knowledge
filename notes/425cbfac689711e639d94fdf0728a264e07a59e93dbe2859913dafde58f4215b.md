# Arrowscrollbox ports must reconcile host events and state attributes across consumers

Entry 694 moves overflow/underflow listeners to the arrowscrollbox host and filters event.target against that host. It updates platform CSS to presence-based scrolledtostart/scrolledtoend selectors and the shared scrollbox part; markup uses clicktoscroll="". Current host listener and event-target checks remain. Some current cleanup and Linux selectors still use older contracts, recorded as static concerns rather than runtime failures. Manual component-port proposal: check registration, target filtering, removal and platform selectors as one consumer set when an upstream component changes its event or attribute contract. Do not apply a blanket presence-selector rule to attributes whose values are meaningful, such as overflow="true".

Scope: tab-scrollbox-integration.
