# The large-mailbox timeout request is scoped to one test manifest entry

The owned patch raises test_over4GBMailboxes.js requesttimeoutfactor from 4 to 6. Accepted source later uses 12 and names CCov, ASAN and TSAN in the reason comment. This per-test request is separate from platform defaults and the worker runtime cap. It supplies more allowance without proving the mailbox scenario or every coverage platform passed.

Scope: Large mailbox xpcshell timing.
