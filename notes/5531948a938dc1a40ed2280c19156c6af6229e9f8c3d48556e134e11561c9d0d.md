# The Graph size mock preserves expansion queries across delta links

The new fake continuation links copy the incoming query and replace prior skip/delta tokens, retaining the requested extended-property expansion on later pages. The mock recognizes a particular expansion substring and reports toMessageString().length. The new size assertions use that same string-length measure, so their direct result is mock size-array equality, not UTF-8 byte accuracy for non-ASCII messages or support for every valid OData expression.

Scope: Graph fake-server continuation and size assertions.
