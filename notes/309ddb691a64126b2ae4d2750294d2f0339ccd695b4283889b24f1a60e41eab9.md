# Wait for both extension menu data and the actual popup state

The mailTabs context-click test uses two completion signals: an extension menus.onShown listener verifies the target payload, and the browser harness waits for mailContext to be shown and state open before replying. The extension awaits the harness reply and onShown promise before checking selection or closing the menu. A data event alone does not establish that popup animation and state are complete. This static ordering does not establish that the original intermittent failure is gone. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Extension context-menu synchronization.
