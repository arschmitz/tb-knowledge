# Thunderbird Calendar create/edit attribute-driven source loader

Bug 2061188 routing calls `dialog.setCalendarEventRoute({ calendarId, eventId, recurrenceId })` for edit or `dialog.setCalendarEventRoute()` for create, then `await dialog.show(event)`. Create routes have no identity attributes; edit adds `calendar-id`/`event-id` and `recurrence-id` only for occurrence edits. Do not pass a raw Calendar event as dialog state. [Task 11]

Scope: calendar.
