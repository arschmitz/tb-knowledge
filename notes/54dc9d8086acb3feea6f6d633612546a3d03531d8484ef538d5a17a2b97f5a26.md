# Lazy-findbar visibility tests inspect the child while wrapper handling changes later

The original hidden setter also toggles the wrapper attribute, and the initial message-pane template stamps hidden on the wrappers. The changed tests accept either an absent child or a hidden child. Fixed accepted code later stops toggling the wrapper and removes those template attributes, explaining that a hidden display:contents wrapper would hide its findbar. Keep that later adjustment separate from the original visibility assertions. No rendered failure or native layout result was reproduced.

Scope: LazyFindbar hidden-state and test phases.
