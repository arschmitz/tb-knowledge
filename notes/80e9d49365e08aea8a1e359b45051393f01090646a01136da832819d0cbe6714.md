# Calendar menu migration preserves label and accesskey roles and gives the delete button its own tooltip

The migration binds context-menu items to calendar-context action/type messages with label/accesskey attributes while retaining command/key behavior in markup. The task delete toolbar button instead uses calendar-taskview-delete, whose label is Delete and tooltip is Delete Task. The migration copies those two values from different old entities. A static check matches all22 literal en-US attribute copies; the completed script keeps the historical blob. This is scoped attribute/consumer naming, not a rule to copy one string everywhere, a full Calendar conversion, or a successful migration/UI result. The earlier Today Pane P change remains a separate phase. No localization or test ran.

Scope: Calendar Fluent migration attribute contracts.
