# Calendar resize tests wait for dialog fit after the window helper completes

resizeWindow completes after a debounced resize or its fallback and an animation frame. The Calendar integration test then separately waits until the dialog height fits the container before checking final geometry. Keep these completion conditions distinct: finishing the window helper does not itself establish the dialog height condition. The test reuses the measured rectangles for its following scalar assertion and checks position separately.

Scope: calendar-browser-tests.
