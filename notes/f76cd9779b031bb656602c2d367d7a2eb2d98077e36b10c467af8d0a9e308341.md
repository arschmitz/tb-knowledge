# Return structured expected and actual response counts

The shared validator returns UnexpectedResponseMessageCount with expected and actual usize values. The error enum supplies the diagnostic text, keeping count data available to callers. Proposed pattern within the EWS response helpers: use a typed count mismatch instead of repeated formatted Processing messages, while preserving the caller’s expected cardinality. This does not imply every Exchange operation requires strict equality. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: EWS diagnostic structure.
