# Keep display-based sender sorting historical until its current path is restored

The sender landing selected ADDRESS_FORMAT(sender) so SQLite sorted the displayed address with locale collation. Accepted SQL instead selects raw sender AS formattedSender, and both adapter and native sender assertions are disabled with FIXME comments. The retained AddressFormatFunction alone does not prove sender rows currently use it. Do not describe the old display-based SQL sort as current behavior or claim that its reported parsing cost was benchmarked. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama sender formatting status.
