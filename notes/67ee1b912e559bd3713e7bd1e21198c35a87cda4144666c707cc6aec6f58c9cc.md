# The shared response processor chooses its result and error types through associated types

ResponseProcessor exposes ReturnValue and Error, with Error requiring From<ProtocolError>. The sender converts lower-level failures through ProtocolError before returning the processor’s error type. The reviewed alternative would add several direct From requirements; the author declines it and the actual trait keeps the single conversion boundary. This is a scoped interface decision. It does not define conversion rules for every Rust trait or establish runtime error behavior.

Scope: Shared Exchange response-processor error contract.
