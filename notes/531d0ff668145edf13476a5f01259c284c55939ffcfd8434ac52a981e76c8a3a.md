# Infobar split buttons share their base layout while platform inner geometry stays distinct

The historical fix centralizes row/stretch split-toolbarbutton layout in shared CSS, removes specific important overrides and adjusts notification outer/inner padding, compact height and close flex layout. Platform rules still differ: Linux/Windows use calc(1.8em-2px) inner minimum, macOS1.8em, with distinct padding. Current logical sizes and narrowed moz-button.close are later source forms. This is a scoped cascade/receiver pattern, not a global important ban or proven equal geometry, focus/contrast or accessibility. No visual, CSS or test run occurred.

Scope: Infobar notification toolbarbutton appearance.
