# Protocol choices use native grouped radios and their containing labels

The Account Hub protocol template places native radio inputs with the same config-type name inside labeled option cards and a fieldset. IMAP and POP3 therefore share one selection group in the markup. For this choice surface, preserve the native controls and label relationship while styling the cards. The markup is useful evidence, but it does not prove keyboard, announcement, group-name or focus behavior. Those runtime accessibility checks and the review discussion remain pending.

Scope: Account Hub protocol controls.
