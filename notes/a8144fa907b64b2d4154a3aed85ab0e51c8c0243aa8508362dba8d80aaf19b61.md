# Fixed filter-dialog reset code mixes a native search receiver with inputEl access

At fixed revision 0b93, searchBox is declared as a native HTML input and onLoad assigns that element to gSearchBox. resetSearchBox still writes gSearchBox.inputEl.value when the search keyword is nonempty and no filter is supplied or the supplied filter does not match. refresh calls it without a filter; selectFilter calls it before selecting a different filter. This records the exact receiver/property combination for a scoped follow-up check. No runtime exception was reproduced or native-input property behavior instrumented. The original entry 2907 landing used moz-input-search, so this observation does not establish that the original landing introduced the later native-receiver mismatch. A direct reset-path assertion was not inspected.

Scope: Message filter dialog search reset.
