# Attachment deletion tests must preserve the message-selection state that triggers the bug

The Bug 1910483 browser test displays the IMAP folder, asserts zero displayed messages, and deletes an attachment by the message ID returned from a query. It directly checks the original attachment metadata and the text/x-moz-deleted placeholder after awaiting deletion. The fixed accepted test keeps this scenario and explicitly enables RFC4315. An earlier review summary described a different selected message, but that summary was replaced; it is not direct coverage of the landed test. Current API input is a message ID, not a requirement for a selected message. Native rewriting behavior and unsupported-input branches are outside this regression test's direct assertions.

Scope: Extension attachment browser regression tests.
