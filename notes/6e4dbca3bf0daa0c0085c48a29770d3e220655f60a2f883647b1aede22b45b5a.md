# Coordinate sort glyph size with header width and semantic state

856 adds 8 by 8 chevrons, skin registration and variables, and adjusts table-header spacing. The current stylesheet selects the glyph from aria-sort and uses direction-aware left/right offsets. Later padding is larger than the historical patch. Keep glyph, available label width and state selector coordinated rather than changing the asset alone. No narrow-header rendering, RTL or zoom was tested.

Scope: Table sort glyph integration.
