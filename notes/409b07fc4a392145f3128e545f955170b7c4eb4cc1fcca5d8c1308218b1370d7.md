# Look up unified folders through canonical URIs when names are localized

Smart mailbox URIs use the canonical folderTypes names, while actual folder names may be translated. Accepted lookup therefore uses getChildWithURI rather than a child-name lookup. Keep the canonical type name, localized name and stored URI distinct when adding a unified folder. This is the smart-mailbox boundary, not a rule that all folders have untranslated names. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Unified folder localization boundary.
