# The Spam toolbar control keeps label state and command state together

SpamButton reads the current tab message’s junk score, selects the Spam or Not Spam label/title and stores isSpam in its dataset. Clicking chooses the opposite junk command from that stored string and reevaluates the control immediately. MailTabButton triggers updates for relevant folder, selection and message-load events and removes its listeners on disconnection. The direct toolbar test checks scores and label IDs; it does not prove rendered localization, every controller or all mixed-selection behavior. No browser or accessibility test ran.

Scope: Unified toolbar Spam action.
