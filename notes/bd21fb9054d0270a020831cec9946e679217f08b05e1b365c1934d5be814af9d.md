# Flatpak AppStream input and composition paths change together

The port installs the application XML under share/metainfo and replaces two old AppStream commands with appstreamcli compose. Explicit result and media paths connect the installed input to the generated package metadata. Fixed accepted code retains this shape but has later application-ID and output-layout changes, so the original constants are not current defaults.
