# Update both menu routes and the exhaustive menu fixture

The app-menu toolbarbutton and native Tools menuitem now route to openPreferencesTab with paneQrExport. Their Fluent labels and access keys are separate resources; the native label has an ellipsis while the app-menu label does not. The 973 follow-up adds menu_exportmobile to the expected Tools menu map. MenuTestHelper checks actual IDs missing from data and data IDs left over after iteration, so adding a real item also changes that fixture contract. This coverage is about menu structure and state; it is not proof that the export command ran or that access keys have no collisions.

Scope: mail/menus/export-mobile.
