# The missing EWS folder test separates local cleanup from remote deletion

The owned regression test creates and syncs a fake remote folder, then replaces its local ewsId with unknown ID foo. Deletion must remove the local child even though the fake server records zero known-folder deletions. This checks local recovery from ErrorItemNotFound; it does not prove the originally created remote folder was removed or that both trees agree. The fake DeleteFolder branch emits ErrorItemNotFound even though its nearby comment says ErrorFolderNotFound. The landed test uses the existing setupBasicEwsTestServer helper for server/configuration cleanup. Current setup has later shutdown waiting, and current test paths have moved from ews to exchange. These are static test assertions and fixture contracts, not an executed EWS result.

Scope: Exchange folder deletion tests.
