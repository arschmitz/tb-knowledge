# Separate appearance selection styling from illustration resource identity

The checked appearance CSS styles native selected radios and their .radio-icon using theme colors/context fill and stroke. Individual camelCase control IDs select dashed illustration custom properties. Recommend dashed shared classes/resource properties and existing camelCase IDs within this pane, while preserving native focus behavior. All six SVG bodies were read and are byte-identical at the accepted endpoint. Their dimensions, path structure and context fill/stroke relationships were checked, and local standalone renders distinguish grouped, threaded and flat rows. This does not validate every coordinate or themed in-app rendering, zoom, keyboard focus or forced colors. These are fixed accepted source and test-code observations.
