# The event description editor host uses the shared field background

The change adds field-background-color to #item-description while retaining the existing border and spacing. The actual receiver is the event-editing iframe's HTML editor host. Accepted source keeps this declaration. The source establishes the local host styling change, not a content-editing, theme-contrast or accessibility result.

Scope: Calendar event editor description styling.
