# Propagate the MIME listener result before retrying a blocked pipe write

1025 stores OnDataAvailable's result when the MIME pipe is full and returns it on failure before retrying the write. Complete also returns the final listener result instead of always NS_OK. The accepted emitter keeps both changes. A failed downstream data callback must not be replaced by the success of a later write or unconditional completion. These are local return contracts; no stalled-pipe test or error callback execution was run.

Scope: MIME emitter listener result propagation.
