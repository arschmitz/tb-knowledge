# Sample random seed diversity without requiring two IDs to differ

The historical test asserted two random seed values differed, even though collisions were legal. The current test takes up to100samples until10distinct values and requires at least2, while checking all sampled seeds are integers0..100 and same-ID retrieval stable. Prefer a deterministic injected seed for targeting tests. Bounded sampling greatly reduces collision flakiness but is still probabilistic.

Scope: notifications.
