# IHeaderBlock separates unfolded field values from a delimited raw block

IHeaderBlock.value(index) returns an unfolded field value without field-specific interpretation or RFC2047 decoding. Its asRaw() method instead returns the complete RFC5322-style block and requires a trailing blank line so a parser can distinguish a complete last field from a clipped continuation. These are separate consumer contracts. Adding the IDL and XPIDL registration alone does not implement a protocol adapter or test its serialization.

Scope: message-headers.
