# The direct week-title module returns a number despite its string annotation

The direct getWeekTitle implementation computes weekNumber with Math.ceil and returns that number. Its JSDoc and older interface declaration describe a string, but current module callers receive the direct JS value and pass it into label arguments. Keep the implementation result, interface declaration and displayed output separate when updating this documentation. No formatting or UI failure was reproduced.

Scope: Calendar week-info module.
