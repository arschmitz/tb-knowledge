# Fake-server test completion and reader transport cleanup are separate events

In the current fake-mail server, stopTest only clears the test flag. The async reader _realCloseSocket clears running state and calls stopTest before its delayed transport cleanup. Server stop awaits each reader cleanup promise, while the inspected stop-listener and command-processing paths start cleanup without awaiting it. Use the actual caller completion contract when interpreting shutdown; a stopped test flag does not mean transport references are already released. The historical3801 reland used a timer callback and an immediate branch; that parameter is absent from the current helper. No leak checker, socket-drain measurement or runtime test ran.

Scope: mail-test-fakeserver.
