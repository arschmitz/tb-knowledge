# Manual Graph setup shares Exchange endpoint fields under the Graph preference

isExchangeConfig recognizes EWS and adds Graph when mail.graph.enabled is true. Manual capture then uses the shared Exchange endpoint path, and CSS hides the Graph option when the preference is false. The assigned tests use the historical false default; the fixed accepted declaration defaults true. This form/configuration contract does not establish authentication or every protocol-registration gate.

Scope: account-hub/graph-manual-configuration.
