# Removing staged UID database methods leaves the storage and helper phases distinct

The patch removes the staged public uidOnServer attribute and database UID-query methods with their wrappers and tests. The accepted interfaces retain those removals, while database setup still resolves the UID column token. Existing conversion helpers remain identity placeholders with real lookup deferred. This is a preparatory public-API removal, not proof that all UID storage is gone or that independent key mapping is complete.

Scope: Staged IMAP UID database API removal.
