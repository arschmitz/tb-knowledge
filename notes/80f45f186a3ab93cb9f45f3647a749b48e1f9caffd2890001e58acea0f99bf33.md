# A successful outgoing-server lookup still needs a non-null result check

Entry 774 replaces a debug assertion with a release-time guard before sending a message disposition notification, or MDN. Current SendMdnMsg checks the nsresult and then the outgoingServer pointer before calling SendMailMessage. Current OutgoingServerService.getServerByIdentity falls back to defaultServer, which can return null when no server exists. Manual native-call proposal for this family: check status and an optional object result separately; an assertion is not a runtime error path. This lesson concerns server availability, not retry policy or the outcome of the asynchronous send. No new missing-server MDN test was found in this patch.

Scope: mdn-outgoing-server.
