# Folder picker checkbox spacing explicitly reserves overlay-scrollbar width

The owned two-column picker keeps table layout, unsets column maximum widths and gives the name column width100%. Under overlay-scrollbar mode, its checkbox column adds6px plus scrollbar-inline-size at the inline end. Accepted source later uses a flex label and reserves scrollbar-inline-size there without the 6px addition. These exact selector/layout phases describe source spacing; they do not prove a rendered width, checkbox hit area, RTL result or accessibility outcome. The proposed grid/subgrid rewrite is not treated as adopted.

Scope: Folder picker table and label layout.
