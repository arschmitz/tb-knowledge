# Preserve the output contract of a shared plural unit string

561 changes shared unit strings to omit the numeric count and updates their IDs. CalAlarm still builds human-readable relative reminders from the returned unit text, and unitPluralForm historically supports count-bearing output. 566 is an exact changed-line inverse of 561 and says it was backed out for test failures. Current CalAlarm retains count-bearing unit-minutes, unit-hours and unit-days. Before changing a localized unit from count-plus-unit to unit-only, inspect all consumers and test the final phrase, not only plural selection. The exact failing test report remains unread.

Scope: Calendar localization breakage.
