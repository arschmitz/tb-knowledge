# Keep platform events outside Calendar Redux state

The Bug 2061214 implementation report describes keeping platform event objects outside Redux and rendering Save operation state through the store observer. For extensions to this create Save controller, retain serializable state, actions, and results so the store can represent pending, failure, and success states without holding platform objects. This is the reported design of this patch, not a proven convention for all Thunderbird Redux code. The report claims unit and browser coverage, but later verification could not confirm matching binaries for those runtime results.

Scope: Calendar event create Save state.
