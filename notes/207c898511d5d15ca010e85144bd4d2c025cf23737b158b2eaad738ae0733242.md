# Preserve pill selection when the global click follows a context menu

The Linux fix returns for button 2 before the compose window can call deselectAllPills. The comment reports a contextmenu on a pill followed by a click on the body. Accepted code also ignores pill, toolbarbutton, menu and menuitem targets. The popup handler then collects selected pills for its actions. Review global click handlers together with the control that owns selection; the reported Linux event sequence was not reproduced. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Compose pill context actions.
