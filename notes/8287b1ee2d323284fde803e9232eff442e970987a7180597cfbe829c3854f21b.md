# Delegate notification focus through each shadow root to a tabbable container

1111 implements focus() on in-app-notification and its container so the shortcut reaches the inner tabindex=0 div. The document activeElement is the outer host because the focused div is inside nested shadow roots. The accepted keyboard test checks that host after dispatching a composed KeyJ event; it does not inspect each inner activeElement or run a trusted key/screen-reader interaction. Keep the delegation and focus target together when changing the template.

Scope: Notification shadow-root focus delegation.
