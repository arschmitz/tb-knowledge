# Generated fallback message IDs now use the owning output string directly

1573 replaces a raw generated-ID buffer with an owned string. Accepted code goes further: when rawMsgId is empty it assigns md5: and appends a Base64 hash of the headers, with dummy.message.id as the failure fallback, then writes rawMsgId to the header. Preserve ownership through that write; do not describe a generated HeaderData pointer as the current implementation. This is static source and test-code inspection.
