# Rust vendor previous-artifact lookup has an explicit repository boundary

The historical workaround skips the previous tb-rust-vendor task lookup and its dependency/environment updates on try-comm-central. Accepted code later performs that lookup only on comm-central. The worker treats an absent PREVIOUS_TASK_ID as no prior metadata and returns an empty mapping. This boundary concerns previous artifacts, not whether the current vendor task or Try build succeeds.

Scope: rust-vendor-task-previous-artifacts.
