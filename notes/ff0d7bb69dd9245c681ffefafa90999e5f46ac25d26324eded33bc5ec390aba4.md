# Keep the LDAP basic form patch separate from later state capture and error description coverage

3048 adds the initial name, hostname and port UI and bubbles a completed flag. It does not yet add the state capture or directory-creation flow. The accepted widget later captures SSL/baseDN/bindDN and advanced data; its parent enables the footer from detail.completed and calls captureState on forward. The name failure branch still sets aria-described, while the markup supplies nameErrorMessage and the success branch removes aria-describedby. Current selected tests check ariaInvalid and completion, not the error-description association. The port result is numeric even though the LDAPCredentials typedef says string. This is a scoped source finding; no form creation or accessible-tree behavior was run.

Scope: mail/components/accountcreation LDAP form.
