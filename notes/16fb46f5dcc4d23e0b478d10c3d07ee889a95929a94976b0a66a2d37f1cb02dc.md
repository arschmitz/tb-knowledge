# The OAuth result-page test checks local content-tab closure and request counts

The test serves generated success/error pages locally, waits for TabClose on the shared tab container and checks one matching request plus one remaining tab. The wait is not bound to a returned tab object. This exercises local content-tab page outcomes; it does not establish system-browser closure, socket-header CSP, token completion or native focus. The exact accepted test proof is reused with its original timestamp.

Scope: OAuth result-page browser-test boundary.
