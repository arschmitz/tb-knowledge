# Send Later test completion waits for a window lifecycle before checking message content

send_later registers domWindowOpened before issuing cmd_sendLater, then awaits closure of the observed window. The helper is intended to cover the send progress dialog, but it has no URI predicate or success-status assertion. The command handler does not return the async SendMessageLater promise. Callers therefore use this window lifecycle as one completion step and separately inspect Outbox message content. Awaiting the helper does not by itself prove compose-window closure, delivery success or leak cleanup.

Scope: Compose browser test completion.
