# Account Hub cachedValue separates stored selection from the live value accessor

The original observer patch names stored selection #cachedValue while value remains the getter/setter interface to the internal select. The setter updates both fields and the change handler records user selection. This adopted local name distinguishes two roles; it is not a global cache naming rule or a claim that every restoration edge case is correct.

Scope: Account Hub select naming.
