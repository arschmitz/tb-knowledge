# Give Compact folder a distinct icon across toolbar surfaces

Bug 1846323 found the Compact folder toolbar action used the same compressed icon as compact UI density, confusing users with customized toolbars inherited from older profiles. The new folder-compact.svg is packaged in jar.inc.mn, exposed as --icon-folder-compact-sm, and used in both the customization list/preview and placed toolbar button. D210977 review explicitly tested both surfaces. Current code keeps the icon variable and uses. When changing toolbar icons, cover both customization and live toolbar, including upgrade profiles.

Scope: Toolbar icons.
