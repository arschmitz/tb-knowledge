# Calendar properties initialization accepts only its own document load

The window keeps its DOMContentLoaded listener, but onLoad now returns when event.target is not the dialog document. The guard runs before reading window arguments, assigning gCalendar or resetting color, focus and notification state. It filters other targets rather than making initialization one-shot. The historical picker/duplicate-UI report is not a reproduced engine-event diagnosis.

Scope: Calendar properties event target boundary.
