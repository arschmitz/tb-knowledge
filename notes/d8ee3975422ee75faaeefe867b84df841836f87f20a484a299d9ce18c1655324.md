# Exchange folder-copy completion does not include syncing copied messages

A same-server folder copy syncs the complete hierarchy before finding the destination child and notifying copy completion. The callback explicitly leaves copied-message synchronization to later folder expansion or selection. A resolved copy listener or visible copied folder therefore does not establish that its messages have been downloaded. Moves use a different local-reparent path; this contract is scoped to this folder-copy implementation. Static source only; no operation ran.

Scope: Exchange same-server folder copy completion.
