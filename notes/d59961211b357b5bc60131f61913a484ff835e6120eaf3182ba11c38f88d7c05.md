# The EWS archive fallback handles per-folder response errors after the request succeeds

get_well_known_folder_map propagates errors from enqueue_and_send before processing response messages. For nonroot messages it skips ResponseError values ErrorFolderNotFound and ErrorSchemaValidation; root retrieval remains fatal. The missing-archive test uses a mock per-folder GetFolderResponseMessage and asserts six remaining folders plus a token. It does not model or prove a cure for a whole-request RequestFault/HTTP500. Required discussion has an exact numbered-body gap; this source-only claim has zero full-audit credit.

Scope: Exchange well-known-folder mapping.
