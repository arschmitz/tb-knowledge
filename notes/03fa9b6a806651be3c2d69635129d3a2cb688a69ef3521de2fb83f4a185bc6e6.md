# Calendar autodiscovery receives the account's remember-password choice

The Account Hub calendar-discovery call now passes currentConfig.rememberPassword ?? false rather than a hardcoded false. Its helper forwards that Boolean as the fourth detector argument, and the detector passes aSavePassword to each candidate provider. This preserves an explicit false while allowing a stored true to reach discovery. The source check ends at that provider API: it does not establish that a particular provider saved credentials or that a password-manager operation succeeded. No account, discovery or test was run.

Scope: Account Hub calendar discovery authentication state.
