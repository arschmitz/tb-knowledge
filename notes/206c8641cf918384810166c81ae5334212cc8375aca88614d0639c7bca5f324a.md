# The search-dialog color follow-up narrows Windows styles to the main window

The patch adds explicit colors.css links to three search dialogs and separately narrows five Windows :root selectors to #messengerWindow. The accepted main document has that root ID and the Windows selectors retain it. This avoids treating the patch as only a dependency import change. Later themed values and actual dialog/window rendering remain separate scopes.

Scope: Thunderbird search dialogs and Windows main-window styling.
