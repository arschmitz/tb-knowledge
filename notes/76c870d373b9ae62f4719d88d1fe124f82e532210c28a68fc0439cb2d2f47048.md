# The security-module helper has separate developer and production entitlements

The local developer and production plists both enable the library-validation and smart-card keys. Only the developer plist also enables dyld environment variables and debugger attachment. The package manifest includes the helper only for macOS Nightly builds with smart-card support, while its signing entries carry the nightly marker. Preserve the selected entitlement profile and packaging predicate when tracing this port. These source keys and comments are not proof of OS enforcement, launch success or a passed PKCS#11 test. Required Bug 2025042 numbered comment 2 is unavailable, so this source lesson does not complete that audit.

Scope: macOS security-module-helper packaging and signing.
