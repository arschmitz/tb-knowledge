# Password forgetting shortens usernames even when no at sign exists

The JS alternative match uses username.slice(0, username.indexOf("@")) without testing whether @ exists. With no @, the -1 end index drops the final code unit, so a distinct stored username equal to that shortened value can match. The accepted snapshot retains the expression. This is a scoped static candidate-selection fact; it does not prove equivalence to native StringHead or an executed account-isolation result.

Scope: Password module username matching.
