# Track every folder expanded by a drag operation

850 replaces a single auto-expanded folder with an array, waits 1000 ms before expansion, collapses recorded rows when the drag leaves or is cancelled, and cancels pending collapse when the drag re-enters a row. A committed drop clears the recorded list so the expanded route remains open. Folder and thread drag-end handlers share cancellation cleanup. The plural _autoExpandedRows name reflects the collection; no native drag was run.

Scope: Folder pane drag expansion lifecycle.
