# Keep null-hidden checks distinct from zero-value content assertions

assertColumns treats content == null as hidden but then uses if (!content) to skip checking text. Numeric zero therefore still exercises the visibility assertion while bypassing the content assertion. Its visible/hidden diagnostic strings are also reversed relative to that condition. Proposed manual test rule in this helper: check the intended sentinel explicitly and make the diagnostic agree with the asserted predicate. No current failing UI state is inferred. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mail/test/browser.
