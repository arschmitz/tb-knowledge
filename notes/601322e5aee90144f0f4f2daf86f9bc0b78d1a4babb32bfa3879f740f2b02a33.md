# Pass the MIME session to its session completion and abort callbacks

932 changes nested draft completion/abort calls from data_object to the nsMIMESession itself. MKSessionCompleteFunc and MKSessionAbortFunc both declare a session pointer; its data_object now contains a separately tagged closure. The accepted callers pass mdd->stream before freeing that session. Preserve the distinction between callback session and callback payload. This is a source-level argument repair, not a reproduced crash.

Scope: MIME session callback argument contract.
