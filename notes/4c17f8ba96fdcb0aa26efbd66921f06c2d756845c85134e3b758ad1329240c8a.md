# The queue update makes line acquisition async without making queue runners cross-thread

Operation-queue 1.1.0 puts Line's release channel behind an async Mutex and makes try_acquire_token awaitable. Both shared sender callers add await before or_token. The returned token still spans error handling and releases on Drop through a blocking lock acquisition. Crate documentation distinguishes thread-safe line helpers from queue runners that remain non-Send. Current-thread tests and a documentation Send+Sync check do not establish a multithread execution result. Accepted later 1.2.0 and Line::status are separate phases.

Scope: Exchange queue synchronization boundary.
