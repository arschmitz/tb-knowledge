# The new-folder follow-up suppresses the rights notice in menu tests

The follow-up adds mail.rights.override=true to the menu suite while changing the dialog width minimum. The actual notification predicate negates this preference, so true suppresses the about:rights bar before its version fallback. This isolates test setup from the dialog geometry change; neither the preference nor the width declaration proves the reported intermittent size failure is cured.

Scope: Menu browser-test environment and rights notification.
