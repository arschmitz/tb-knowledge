# An invalid-grant external OAuth retry asks before reopening authorization

The invalid-grant retry sets requestAuthorization(true). In the external-browser branch, that flag produces a confirmation containing the provider authorization hostname and login-hint username. Rejecting it cleans up the authorization request, reports user_cancel and returns before external request construction. The tests intercept browser launch and check prompt text plus accepted/rejected module outcomes; they do not exercise a real provider or prove every reauthentication path prompts. The module maps any connect rejection to its abort status.

Scope: OAuth reauthentication prompt and cancellation.
