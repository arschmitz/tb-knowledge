# S/MIME error reasons use UTF-8 parameters and a scoped message fallback

The error reason is converted from UTF-16 to UTF-8 at the self-cert callers and decoded with CopyUTF8toUTF16 by the parameter formatter. Distinct signing and encryption messages receive that reason. The reason helper tries localized NSS text, warns on a missing service and falls back to the error name; the reason can remain empty if those sources are absent. The review proposal to fail on a missing service is not the implemented disposition. No live text rendering or native verification was tested.

Scope: Thunderbird S/MIME send-time error text.
