# Make native-resource cleanup survive throws in asynchronous import helpers

The current RNP merge helper wraps work in try/finally and destroys tempFFI in finally. importToFFI and several other checked helpers destroy their native buffers on the normal path instead. Recommend using explicit exception-safe cleanup when changing an asynchronous native-resource helper, and check the full acquisition path. A possible cleanup gap is static evidence here; no exception leak was reproduced. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
