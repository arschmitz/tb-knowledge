# Virtual-folder live notification matching still omits the saved search terms

The virtual-folder SQL query includes saved terms, but current VirtualFolderFilter::Matches only checks whether the message belongs to a searched folder. LiveView uses that native matcher before added, removed and flag-change callbacks. The inspected virtual-folder tests check initial counts and selected IDs, then create new views after search changes. They do not verify term-filtered notifications or refresh of an existing view. A focused follow-up can attach a listener to a subject-filtered virtual folder and compare matching and nonmatching events. This is a source-level mismatch and test gap, not a reproduced UI failure.

Scope: Panorama initial query versus notification matching.
