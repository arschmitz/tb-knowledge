# Do not describe the inclusive seed threshold as an exact percentage

The current seed is an integer0..100 and eligibility rejects percent_chance<seed except chance100. Chance0 can admit seed0; this historical policy also appears in tests. Document the actual threshold and valid values rather than claiming mathematically exact p/100 probability. Whether to change that policy is unresolved, not an established syntax rule.

Scope: notifications.
