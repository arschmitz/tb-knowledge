# Treat schema migration metadata and intermediate build names as part of the change

This Glean stack carried migration bug links and data_reviews links. Review found missing IDs caused by find/replace, and warned that a partial landing with prefix collisions could fail the generator. Proposed manual review rule: inspect the resulting schema and dependent landing sequence, not just the mechanical conversion. The old-probe group had a historical shared data review; this does not grant a new policy exception or justify changing generated tags by hand.

Scope: telemetry-migration.
