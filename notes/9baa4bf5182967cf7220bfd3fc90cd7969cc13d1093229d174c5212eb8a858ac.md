# Flatpak runtime permissions and dictionary paths are packaging contracts

The accepted Flatpak repack declares both Wayland and fallback-x11 and sets DICPATH=/usr/share/hunspell. These values form the packaged runtime environment. Keep them in the repack metadata when replacing old launch steps; a source migration can lose behavior even when the application code is unchanged. The TMPDIR change was later backed out and remains absent here. Its reason is still unknown without Bug 1885794 context. No installed Flatpak, display backend or dictionary lookup was exercised.

Scope: packaging.
