# The panel token port treats native popups and the Gloda popup as different receivers

The original port assigns shared panel defaults to descendant menupopup and panel elements. Gloda uses a facet-popup-menu custom element with the popup-menu class, so its CSS sets surface and text tokens directly. Its hover/focus state pairs the selected background with selected text. The fixed accepted native selector later excludes autoscroller and uses longer background-color/text-color names. These are local receiver and phase facts; no rendered contrast or accessibility result is established.

Scope: Theme token receiver scope.
