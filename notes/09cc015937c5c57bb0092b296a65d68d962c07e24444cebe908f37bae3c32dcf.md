# Match email recipients with the generated Taskcluster notification scopes

1109's transform uses the resolved recipients both for --address arguments and notify:email scopes. The subcommand then calls the shared notify utility, which uses the task proxy when available and otherwise configured environment options. Keep task authority and recipients aligned so adding a recipient is not only a body or argument edit. This is the checked implementation contract; no credentials were loaded and no external email was sent.

Scope: Release recipient and notification scope alignment.
