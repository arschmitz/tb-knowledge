# The vCard import filter is tested separately from .vcard file import

The vcard source type supplies *.vcf; *.vcard to the picker and keeps the all-files filter. The browser test directly checks those accumulated MockFilePicker filter strings through doImport, but the selected fixture is still import.vcf. Preserve the filter assertion while keeping native picker behavior and an actual .vcard import as separate coverage.

Scope: address-book import file picker.
