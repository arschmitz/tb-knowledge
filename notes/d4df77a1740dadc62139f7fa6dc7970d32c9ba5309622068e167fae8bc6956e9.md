# Use phase readiness and useful context in folder-tree assertions

The accepted folder-tree helper waits for an idle callback before expanding rows and an animation frame after each expansion. Its optional context is included in the failure message. The historical intermittent fix used a zero-delay timeout; that is not the final readiness pattern. For nearby helpers, name the phase being awaited and include the mode and action in diagnostics.
