# Refresh zoom command state when about:3pane loads and its view changes

Ctrl++ failed on an opened message until the Zoom menu had been used. The accepted fix calls updateZoomCommands after DOMContentLoaded and after thread-view changes, using top.goUpdateCommand on reduce, enlarge, reset, and toggle commands. Current code retains those calls and also handles a collapsed message pane. A controller that changes target browser with the view needs an explicit state refresh when content attaches, not only when a later selection occurs.

Scope: 3-pane zoom commands.
