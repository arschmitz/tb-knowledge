# Publish dialog Close labeling follows submission rather than upload completion

The localization migration preserves the submission order: invoke the supplied publish callback, assign the Close localization ID and prevent the first accept default. The real whole-calendar callback is async and awaits items before starting the item upload, while the dialog handler does not await that promise. The label transition therefore records submission, not completed upload. The current initial Publish localization target differs from the first migration; no network, error-path or dialog test ran.

Scope: calendar-publish-dialog.
