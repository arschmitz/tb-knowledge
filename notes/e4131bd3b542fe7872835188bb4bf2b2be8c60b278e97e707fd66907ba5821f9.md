# The compose color picker refreshes its color text and swatch on input

The native color input now invokes SelectColor for input events. That existing handler reads a nonempty picker value and SetCurrentColor normalizes it, updates ColorInput and refreshes the swatch. The owned change replaces only the change-event attribute; it does not add validation, change acceptance, or establish a rule to replace onchange on all controls. No native color picker or UI test ran.

Scope: Scoped native color input event to existing dialog state.
