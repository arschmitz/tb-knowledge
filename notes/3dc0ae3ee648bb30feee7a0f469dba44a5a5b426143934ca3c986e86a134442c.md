# The credentials Fluent ID is shared by the error producer and authentication branch

The string migration updates both FindConfig’s error cause and the email view’s comparison to account-hub-credentials-wrong. The view uses that value to choose AuthenticationRequiredError, and the rejection test checks the same ID. Keep both sides and their tests together when changing this scoped identifier; it is not only display text. No discovery, credentials or network operation ran.

Scope: Account Hub Exchange error contract.
