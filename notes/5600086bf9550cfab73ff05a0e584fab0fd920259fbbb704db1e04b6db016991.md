# aboutExtra scopes its Nova button overrides to the sticky, search and heading containers

This landing groups sticky-container, main-search and main-heading for local Nova button background, ghost-state, border and icon-color overrides. It separately removes the page-options more-options-button image/size block, sets theme-enable-button's border property to none and uses color-surface-border for panel-list. Thunderbird injects this stylesheet into the Add-ons page. These are scoped declarations and override removals; the paired engine widget defaults, rendered gear/overflow appearance, focus and contrast are not established here.

Scope: Add-ons Manager local Nova CSS scope.
