# Destructure the identity result at header link call sites

MailUtils.getIdentityForHeader returns [identity, matchingHint], not a single identity. The list URL and header-field link handlers destructure the first item before calling composeEmailTo. Keep the tuple boundary visible with const [identity] in these call sites. The helper can return [identity, null], so the JSDoc string description for matchingHint is not a non-null runtime guarantee. This is a local destructuring recommendation, not a ban on indexed array access elsewhere. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Header identity result syntax.
