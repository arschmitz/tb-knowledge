# The EWS forwarding test directly checks subject and body after message loading

The browser test registers folder and message-load waits before the corresponding actions, then opens the shared forward helper. It directly checks that the forwarded header table contains the original subject and the editor body contains the original message text. Those two assertions do not establish Graph forwarding, redirect/send behavior, whole-URI identity or emitter-failure handling. Cleanup removes the test account and logins. This is static test coverage; the retained reports are historical.

Scope: Exchange compose browser-test coverage.
