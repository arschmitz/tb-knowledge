# Invalidate both the row cache and cached SQL when sorting changes

Accepted sortBy normalizes the column and direction, stores the comparator, updates native sort properties, clears rows and reloads asynchronously. Native sort setters call ResetStatements, which finalizes cached statements. A sort change crosses the JavaScript cache and SQL-query boundary. Review both rather than changing only the visible comparator. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama sort invalidation.
