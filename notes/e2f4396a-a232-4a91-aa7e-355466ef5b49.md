# Keep selected tree rows and the current row across sorting

sortBy records selection and current-row identity on row objects before it changes order. It restores selected indexes with selection events suppressed, restores currentIndex after selection changes, then resets the tree. The accepted sort test checks selection through ascending and descending sorts. Current code keeps this contract, so a new sort path must preserve the selected objects, not just their old numeric indexes.

Scope: Tree sorting.
