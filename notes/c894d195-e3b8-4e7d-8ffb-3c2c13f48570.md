# Regression test expected values must remain independent of results

A test can pass while its main equality assertion compares the result to itself. In test_pop3Download.js the landed/current expectBody assignment uses gotBody.replaceAll, then gotBody is normalized the same way. Therefore its body-equality assertion does not prove preservation. Header and database subject assertions remain meaningful. Normalize the fixture-derived expectBody independently in future tests. Also distinguish a RegExp from a string that looks like a regex in replace. This study reports the existing gap and made no code change or runtime test.

Scope: test/expectations.
