# Local-file construction must preserve initialization, encoding and failure checks

The 1350/1355 changes replace factories or interface creation with concrete nsLocalFile initialization, using InitWithFile, InitWithPath or InitWithNativePath according to the source value. Accepted IMAP/filter/Maildir paths still create a concrete file and check the initialization result before mutating it. The MAPI hook explicitly separates native paths from UTF-8 converted paths. For these callers, preserve that encoding and error boundary during API cleanup; the old Part 1 factory names are historical. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/base/src.
