### ZydisGetInstructionSegments (34–178)

Builds an ordered description of byte ranges from decoded instruction metadata. Rejects either null pointer before writing. Zeroes the output, separates an effective REX prefix from preceding legacy prefixes, appends an encoding prefix, then opcode, ModRM, SIB, displacement and up to two immediate ranges. For3DNow, also appends the final-byte opcode. Output offsets and sizes describe existing instruction bytes; this function does not decode or copy instruction bytes.

- Reads: instruction.raw.prefix_count; instruction.attributes; instruction.encoding; instruction.opcode_map; instruction.raw xop/vex/evex/mvex offsets; instruction.raw.modrm/sib offsets; instruction.raw.disp/imm offsets and sizes; instruction.length
- Changes: Zeroes entire caller-owned segments struct; segments.count; segments.segments[].type/offset/size
- Conditions: Null instruction or segments -> INVALID_ARGUMENT, without resetting output.; Legacy prefix count emits one range unless it consists only of effective REX; effective REX emits a separate one-byte range.; XOP size3; VEX uses reported size; EVEX/MVEX size4; other encoding adds no encoding-prefix segment.; Opcode is one byte except legacy/3DNow map0F or0F0F=>2, map0F38 or0F3A=>3; unexpected map is unreachable.; Opcode begins at end of last emitted prefix, else offset0.; HAS_MODRM and HAS_SIB independently append one byte at reported offsets.; Nonzero displacement/immediate bit sizes append size/8 byte ranges; exactly two immediate slots are visited.; 3DNow appends one opcode byte at instruction.length-1.
- Result: ZYAN_STATUS_SUCCESS after count/type/offset/size output is populated.
- Errors: Only explicit returned error is ZYAN_STATUS_INVALID_ARGUMENT. Invalid opcode map reaches platform-dependent unreachable macro. Other metadata is trusted; values are not checked against instruction length.
- Async completion: Synchronous calculation. Completion means output is populated; no promise, cancellation or deferred consumer.
- Ownership and release: Borrows instruction and caller-owned output for the call. No allocation, retained reference, listener, or release action.
