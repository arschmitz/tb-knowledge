# Account Hub banners select scheme-specific text and matching icon strokes

The Account Hub banner fix keeps light-mode pressed colors but selects different dark-mode foregrounds: base text for errors, success text for success, and the primary default for info. Success also uses its text token for the dark border. The matching visible severity icon sets stroke:currentColor over the shared context-stroke rule, so its stroke follows the banner foreground; its existing fill remains separate. Warning colors are unchanged. Accepted source retains these choices. This source contract does not prove a contrast ratio, forced-colors result or rendered icon appearance.

Scope: account-hub/notification-colors.
