# The calExtract logger prefix applies to its instance, while pattern errors still use the global console

The calExtract cleanup sets the lazy logger prefix to calendar.calExtract and keeps Warn plus calendar.loglevel. Debug messages no longer repeat the [calExtract] label. Pattern validation and missing-parameter errors still use console.error, so the instance prefix does not prove those global calls carry the same label. Check the actual receiver before treating a prefix cleanup as uniform output behavior.

Scope: Calendar text extraction logging.
