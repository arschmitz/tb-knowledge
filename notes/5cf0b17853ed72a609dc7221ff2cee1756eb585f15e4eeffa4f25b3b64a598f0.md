# Calendar checked toggles pass Boolean results to view state

The checked port takes toggleAttribute's return value as the next state. Calendar view toggles assign that Boolean to rotated, workdaysOnly, tasksInView or showCompleted; modebox togglePane passes it to setVisible. The timezone test helper separately compares presence with a documented Boolean input whose callers supply true/false. These concrete consumers explain the type change from true/false strings; they do not establish a rule for all attributes or native command propagation.

Scope: Calendar checked-state consumers.
