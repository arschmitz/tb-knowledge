# Preserve event snapshot IDs while invalidating removed live messages

CachedMsgHeader saves the extension ID and the properties needed for conversion. Delete and move handlers obtain cached headers before removing live tracker mappings. Events can still identify the source message, but get/update of its old ID fails; relocation creates a fresh destination ID. Copy keeps the source ID. The current identifier test covers these outcomes, and the attachment-removal test preserves the ID while changing content. That attachment test skips the IMAP test server, so it is not proof of every IMAP key-swap sequence. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/message-snapshot-lifetime.
