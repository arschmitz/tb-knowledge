# The source-packaging cleanup removes two comm Make forwarding targets

The change removes source-package and source-upload forwarding from the comm Make include while preserving upload and other package targets. The source-stamp fallback separately changes log.warn to log.warning and still returns when the file has the wrong line count. These are exact local changes; the author reports mach-based packaging, but the upstream implementation, generated package and uplift outcome remain unverified.

Scope: Thunderbird source package build integration.
