# Format printed month ranges through the locale formatter

formatMonthInterval uses Intl formatRange with numeric year/long month and the fifteenth as a representative day. Month-grid titles use this helper rather than join DOM heading strings with a fixed dash. The current German, Japanese and Arabic assertions demonstrate different separators and digit forms. Keep the complete formatted range as the unit of localization; no live print run was performed. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar print locale ranges.
