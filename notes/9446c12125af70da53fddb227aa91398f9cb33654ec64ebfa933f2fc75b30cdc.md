# Calendar test scrolling accounts for sticky headers and writing direction

CalendarTestUtils.scrollViewToTarget uses the calendar scroll-area rectangle and target rectangle for day/week views because sticky headers limit ordinary scrollIntoView. The inline difference reverses with document.dir, and alignStart chooses start versus end for both paths. When changing this helper, retain these geometry and direction decisions rather than only replacing a scroll API. No rendered left-to-right or right-to-left check ran here.
