# Calendar scheduling tests vary role, case and capability

The current test_adaptScheduleAgent deliberately uses a mixed-case identity. It covers organizer and attendee actions, force on and off, explicit NONE versus SERVER, and non-CalDAV or unsupported auto-scheduling calendars. These stand-ins test helper decisions rather than an actual CalDAV server, invitation delivery count or transport failure. The named test and file are registered in the calendar xpcshell manifest.
