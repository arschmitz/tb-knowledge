# Calendar import search uses widget autocomplete and Escape-to-clear behavior

The calendar import filter moved from a raw input and its own 250 ms timer to the shared search-bar autocomplete event; the handler reads event.detail and rerenders filtered items. The browser test changed its clear action from Delete to Escape, matching the widget behavior, and waits for visible item titles. Current import code and test retain this flow. Review discussed a possible widget attribute to avoid per-consumer submit prevention, but the accepted code handles search locally; do not assume that proposal landed.
