# MessagePane events carry view indices and extension observers accept either target shape

Accepted show-single-message bubbles with detail.messages obtained from gDBView header indices, filtering nsMsgViewIndex_None. MsgsLoaded can now originate from MessagePane as well as an about:message window; ext-messageDisplay resolves tabOrWindow through the target or documentGlobal and returns MV2 messages or an MV3 tracked page. Preserve the event payload and both target shapes during this extraction, rather than equate a DOM element with the old window emitter. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
