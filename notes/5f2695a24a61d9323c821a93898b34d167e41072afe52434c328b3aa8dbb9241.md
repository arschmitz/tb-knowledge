# Reuse one click-policy subtest across API and target variants

browser_ext_clickHandler uses shared test files and subtest_clickInBrowser for balanced/relaxed/strict tabs, spaces and popup windows. It resolves click targets inside a shadow root and asserts mocked external-protocol calls alongside in-app navigation. Recommend descriptive test_<api>_<policy> tasks for this matrix and shared helpers for common cases. Existing tests were read as code, not run against a default browser. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.

Scope: mail/components/extensions.
