# Opaque security Debug output is deliberate, but the error format retains a literal status placeholder

The accepted TransportSecurityInfo Debug implementation emits only an opaque tuple because the XPCOM object has no Debug trait. Separately, the TransportSecurityFailure thiserror attribute still uses doubled braces {{status}}, unlike the StatusCode attribute {status}; the stored status remains available for conversion. Preserve the opaque-wrapper rationale, but do not present the doubled-brace string as proven useful status output or a privacy policy. No Rust formatting/runtime test was run.
