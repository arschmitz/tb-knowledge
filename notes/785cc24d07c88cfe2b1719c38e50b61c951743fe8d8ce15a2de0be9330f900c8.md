# Programmatic folder visibility finishes non-CSS animations within the tree subtree

After expanding collapsed ancestors, the visibility helper finishes tree-subtree animations except CSSAnimation and CSSTransition. This scope includes non-CSS script animations, not just a named expansion. The mixin separately avoids animation under a collapsed ancestor or reduced motion and performs child-list cleanup directly. displayFolder updates selection afterward. No runtime race cure or whole-UI synchrony is established.

Scope: Folder-tree expansion and animation scope.
