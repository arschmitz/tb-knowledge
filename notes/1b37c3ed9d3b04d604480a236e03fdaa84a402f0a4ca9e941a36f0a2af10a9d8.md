# Header copying uses model values only when there is no active text selection

This landing preserves a noncollapsed global selection verbatim. With no selection, the Copy command resolves data-header-name from its target or ancestor, uses currentHeaderData when present and otherwise uses DOM text; that collapsed result is trimmed. The subject markup and popup command are paired. The added test mocks clipboard.writeText and covers the collapsed subject/model branch only. It does not prove native clipboard behavior, all fallback/selection cases or literal raw MIME preservation. The review removes a separate Select All change from scope. Required primary numbered comment 3 remains absent with unknown author/type, so this focused source finding carries zero full-audit credit.

Scope: Message-header Copy command.
