# Iterate Map.values when the key is unused

This is a proposed manual syntax rule. When only map values are needed, use values() instead of destructuring entries and discarding the key. D212688 requested this at both folder-selection call sites, and the current extracted helper retains [...folderTree.selection.values()].map(...). Keep entries() or [key,value] when the key participates in behavior. This is not a claim about every historic Map loop.

Scope: mail/components/extensions.
