# Each tree-header picker starts outside the tab order before roving focus is assigned

The header-cell constructor sets each picker button to tabIndex = -1. The header then selects visible ordinary buttons and the last-column picker for its roving focus set, clears that set to -1 and sets the first button to 0. Arrow handling transfers the tab stop and wraps according to direction. This one-line follow-up supplies a deterministic initial tab index; no new test or live keyboard result accompanies it.

Scope: Tree-view table header keyboard focus.
