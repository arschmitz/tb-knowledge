# Limit the test cleanup rule to writing

This is a deliberate user-directed clarification of the
[test cleanup rule](8f5d298f-8df3-4eaf-84d3-59a844728679.md).

When writing tests, do not add `try/finally` blocks. Use the test harness setup
and cleanup hooks. Register cleanup before setup can fail. Use separate cleanup
callbacks when one failed action must not prevent another cleanup action.

This is writing guidance, not a patch-review criterion. An existing
`try/finally` block alone is not a review finding under this guidance.
Review actual behavior, resource cleanup, and failures on their own evidence.

## Scope and limits

This clarification governs how the cleanup preference is applied. It does not
ban `try/finally` in production code or require rewriting unrelated tests.
Automatic learning must not change this deliberate guidance. The original
style study and its coverage limits remain unchanged.
