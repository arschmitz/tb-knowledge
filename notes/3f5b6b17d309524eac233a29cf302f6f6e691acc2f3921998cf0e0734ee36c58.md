# Address Book option order keeps the LDAP and local subview contracts together

The wording update puts LDAP before the local Address Book option and moves each option’s ID, icon and subview value together. The remote description uses CardDAV, and the new remote/LDAP Fluent IDs match their production consumers. Accepted subview definitions still distinguish ldapAccountSubview from localAddressBookSubview. This is scoped markup/localization wiring, not a rendered label, focus order or creation result.

Scope: Account Hub Address Book option localization and routing.
