# Missed-alarm handling can use either optional item date bound

For past writable unacknowledged DISPLAY alarms, showMissed fires and continues to the next alarm. With that preference off, the accepted code converts optional start/end bounds and fires when either is at or after now. Events use startDate/endDate; tasks use entryDate/dueDate. One missing bound does not discard the other, and the branch is broader than an ongoing-event test. Preserve per-alarm continuation and the later notification work. Current acknowledgment additions are separate later source. No date, alarm or UI test ran.

Scope: Calendar alarms.
