# macOS notification customization needs UI and packaging coverage

The macOS landing removes guards from the customization button, notifications.xhtml packaging and the browser task together. Current General preferences opens the shared subdialog through gSubDialog. The historical test only opens and cancels the dialog; the inspected current test also checks initial action order and checkbox state. Neither proves native notification delivery or every macOS setting. Keep the UI entry point, packaged document and test availability aligned when changing platform guards.

Scope: Notification preferences.
