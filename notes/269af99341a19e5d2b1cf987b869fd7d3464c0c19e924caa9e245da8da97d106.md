# Attachment summary updates distinguish formatted size from pane visibility

updateAttachmentPane always formats the summed attachment size, including zero. It separately toggles the empty-area class from item count. Without an action argument it updates the summary and returns; explicit show or hide changes the pane open state. The changed test helpers compare the formatted total directly instead of expecting an empty string for zero. These are separate source contracts, not a live rendering or attachment result.

Scope: compose/attachments.
