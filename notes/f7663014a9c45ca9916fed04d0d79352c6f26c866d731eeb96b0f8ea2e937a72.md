# The Graph mail-permission addition preceded its exact provider-test expectation

The original landing adds Mail.ReadWrite and Mail.Send to both members of GRAPH_SCOPES. Its enabled Graph getter combines those scopes, but the unchanged exact-object test still expects the previous list. The retained primary reports the same difference; no test was run here. The fixed accepted test later includes both permissions. This is an expected-metadata mismatch, not proof of token grants, revoked consent or live Graph access. The inspected existing Graph assertions also have no message argument; that is unchanged test context rather than an assertion introduced by this landing.

Scope: Graph OAuth scope literals and metadata test phases.
