# Remove package entries when their upstream binary is retired

Bug 1897593 removed the conditional breakpadinjector.dll entry from Thunderbird package-manifest.in after upstream Bug 1896636 retired the crash reporter injector. Upstream says this DLL had injected Breakpad into Flash processes and was unused after Flash support ended. The neighboring crash reporter and minidump-analyzer entries remained; the port removed only the obsolete injector. D210867 accepted the one-file port without inline requests. Current Thunderbird manifest has no breakpadinjector.dll entry.

Scope: Windows package manifest.

- `mail/installer/package-manifest.in`
