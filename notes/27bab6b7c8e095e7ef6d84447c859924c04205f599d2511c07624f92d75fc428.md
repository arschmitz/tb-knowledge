# The Calendar dialog background and date row use separate surface tokens

The customized Calendar dialog explicitly uses --color-surface-base for its background. The nested date-row rule keeps --color-surface-subtle. This patch changes the parent surface only. Token names and reviewer approval do not establish measured contrast, OS rendering or a universal dialog-style rule.

Scope: Calendar dialog surface styling.
