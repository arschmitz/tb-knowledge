# HTML preformatted selection quoting checks source ancestry and exact quoted text separately

The owned C++ patch checks whether the selection focus node has a pre ancestor before adding the moz-quote-pre wrapper; wrapped plain-text remains a separate fallback. Its HTML test asserts the direct wrapper, class and exact newline-preserving text. Accepted extraction later moves to an actor with a different closest-based traversal. Keep source membership, exact quoted text and visual wrapping as separate contracts; this test does not prove arbitrary cross-block selections or all encodings.
