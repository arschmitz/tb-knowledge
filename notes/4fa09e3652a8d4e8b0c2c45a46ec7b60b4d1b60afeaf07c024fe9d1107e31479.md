# Account Hub error outlines cover native validity and explicit ARIA invalid state in current CSS

Entry 1305 adds an outline to :user-invalid. The accepted stylesheet now groups :user-invalid, [aria-invalid="true"] and .warning and exposes the adjacent input-error-message for them. For this form family, preserve the visual and explicit invalid-state selectors when changing error presentation. The CSS also keeps a separate focus-visible rule for menus; this does not prove the error text is announced or focus stays visible in every state. No screen reader, trusted keyboard, axe or contrast check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub form error presentation.
