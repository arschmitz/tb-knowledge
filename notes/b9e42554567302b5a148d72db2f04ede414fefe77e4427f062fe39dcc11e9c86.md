# The bulk attachment save directory result does not identify which files were saved

The checked saveAttachments loop continues after a declined per-file overwrite and can still return the selected directory. Its result is therefore not a list or guarantee that every requested attachment was written. The non-silent detach caller receives that directory and constructs the complete URL-to-file map before confirming modification. Preserve this distinction when reasoning about save completion versus detach readiness; no overwrite-refusal flow, attachment loss, picker or file operation was tested.

Scope: Attachment save and detach caller result contract.
