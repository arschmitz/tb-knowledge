# The RFC822 attachment test accepts both known line-ending sizes without selecting a platform

The follow-up accepts size160 or166 unconditionally and prints the actual value with LF/CRLF labels. The same test also checks attachment type, subject-derived name, file presence and nonempty content. It does not compare all decoded bytes or establish which size each platform must produce. Reviewer Windows success is a historical report, and no test ran here. Required primary comments5/24 remain unavailable, so this source finding does not complete the audit.
