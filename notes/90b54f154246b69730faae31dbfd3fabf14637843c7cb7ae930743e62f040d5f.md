# The nested decrypted-MIME parser clears its QP flag before the text consumer checks it

The outer body parser asks MatchBody to reset QP after decoding its returned buffer. The nested parser has a different boundary: it clears m_partIsQP immediately before returning the accumulated part, while GetRelevantTextParts decides whether to decode by calling IsQP afterward. That caller sees false for this boundary result, so a returned part that still needs QP decoding skips that decoder branch. Accepted source retains the mismatch. This is a static condition/order finding, with no reproduced encrypted search or tested fix.

Scope: Encrypted MIME quoted-printable completion.
