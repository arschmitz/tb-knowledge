# Moved mailTabs scalar checks still need expected-behavior assertion messages

The dedicated selection test retains ten scalar browser.test assertions with no message: nine assertEq calls and one assertTrue call. They check tab counts, account/folder identity, foreground activity and empty selection. Add nonempty messages that identify the expected result and contain should, such as "There should be three mail tabs." and "The foreground mail tab should be active." The shared window.assertDeepEqual helper is a different API with a default description; its two-argument calls are not part of this count. The new threaded case already gives its assertions expected-behavior messages. This is a source review finding, not a test result.

Scope: extensions/tests.
