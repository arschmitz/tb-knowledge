# Folder-copy failure cleanup checks queue membership after the callback boundary

This landing adds a queue-membership condition before ClearRequest when CopyFolder returns failure. The checked local no-message folder path can synchronously return through OnCopyCompleted and NotifyCompletion; the service may remove/delete the request before CopyFolder returns. A failed return therefore does not itself establish that the original request is still queued. Existing listener/original-request safeguards are separate. This is a bounded callback-lifetime check, not a complete reentrancy/thread-safety proof or a reproduced crash. No copy test ran.

Scope: Copy service request lifetime.
