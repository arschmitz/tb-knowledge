# Keep the Calendar printing policy separate from chrome UI policy

The printing template permits no default resource source and permits inline styles. It includes its own style block rather than the general chrome-script policy applied to UI windows. Preserve this document-specific policy when updating printing output; copying a chrome window meta tag would broaden a different resource contract. No print rendering or policy enforcement test ran here. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar printing resource policy.
