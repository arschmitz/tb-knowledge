# Toolbar token output names change while theme input names remain distinct

The port renames CSS outputs to --toolbar-background-color and --toolbar-text-color while keeping the map's lwtProperty inputs toolbarColor and toolbar_text. The hover/active output variables also retain their existing --lwt-toolbarbutton-* fallback inputs. Focused field text/background change names while the focus border and outline stay separate. Preserve these actual mapping and state roles; this local migration does not authorize a blanket rename of theme API keys or prove engine/visual compatibility. No theme test ran.

Scope: ThemeVariableMap and toolbar CSS naming contracts.
