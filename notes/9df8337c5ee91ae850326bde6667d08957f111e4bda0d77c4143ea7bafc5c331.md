# Bind notification-tab waits and URI assertions to the tab returned by TabOpen

The donation-tab integration task registers TabOpen before triggering the notification, obtains tabInfo from that event, then waits for example.com/ and checks that same tabInfo.browser.currentURI.spec. This ties the assertion to the opened tab rather than whichever tab is currently selected. Preserve URL normalization in the awaited/asserted value. The landing adds a separate unit fallback task for missing tabmail; this browser assertion does not cover that branch. Source and historical review reconciliation only; no test ran.

Scope: mail/components/inappnotifications browser integration test.
