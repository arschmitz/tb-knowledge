# Keep the standalone EML header window bounded and distinct from mailbox parsing

nsMsgFileHdr reads up to the smaller of the file size and 500 KiB, replacing the historical 8 KiB stack buffer. nsMailboxService constructs this header object for file URIs and the converted mailbox-message URI used for an opened EML file. This is a local EML header read policy. It does not establish a limit for every Thunderbird parser or a current provider limit. Neither landing adds a focused large-header regression test.

Scope: mailnews/local/src.
