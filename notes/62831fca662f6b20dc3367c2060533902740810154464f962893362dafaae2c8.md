# tb-doc validates Node through nodeutil while retaining setup_helper

build_docs imports mozbuild.nodeutil as nodeutil and returns 1 when nodeutil.check_node_executables_valid() is false. It still uses setup_helper to set the project root and prepare ESLint dependencies before constructing the Sphinx PATH. The patch changes the receiver for one validation call; it does not replace the whole setup helper or prove a successful documentation build.

Scope: Documentation build command.
