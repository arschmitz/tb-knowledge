# Document Gloda generator results through their callback mechanism

getOrCreateMailIdentities is a generator with rest address-group arguments. It builds nested resultLists and yields doneWithResult(resultLists), rather than returning a flat synchronous GlodaIdentity array. The current JSDoc still types the result as GlodaIdentity[] and describes callback delivery. Recommend retaining delivery timing and nested shape when correcting documentation in this API; the annotation alone is not a runtime type check. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
