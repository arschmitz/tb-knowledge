# Pass the selected identity into archive-options ownership

The identity edit dialog passes the selected identity into Copies & Folders initialization. ChangeArchiveHierarchy uses that stored identity, with an account-default fallback only when no identity was supplied. The new test directly checks that secondary archive settings change while the default identity remains unchanged. Required Bug comments9/10 and the review remain unavailable/unread in this specification; no full audit or UI execution is claimed.

Scope: Archive settings identity ownership.
