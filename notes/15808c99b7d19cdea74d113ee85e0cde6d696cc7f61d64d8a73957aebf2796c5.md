# Folder badge assertion messages invert their hidden-state expectation

checkLabel compares label.hidden with content==null, but its message says visible for null and hidden otherwise. The comparison remains the intended check; the diagnostic labels are reversed in both the historical landing and inspected fixed source. A correction should swap the wording to match the expected hidden flag. This is a static expected-behavior mismatch, not a reported runtime failure or a defect based only on the word should. The broader popup update was still reported to fail --verify. No test ran.

Scope: Mail test assertion messages.
