# Gate language-pack uploads by release version shape

661 adds a transform that drops non-production staging tasks, always permits beta, permits release only for major bumps, and permits ESR major/minor updates without patch bumps. It removes release-push-langpacks from Balrog scheduling dependencies because the upload task is now conditional. The historical ESR first branch tests major_number == 0, which does not match the documented 128.0esr example; current code tests minor_number == 0. Proposed manual review rule: compare every numeric version predicate with the examples in its docstring. This is a visible historical condition defect, not a reproduced ATN upload failure.

Scope: Language-pack release eligibility.
