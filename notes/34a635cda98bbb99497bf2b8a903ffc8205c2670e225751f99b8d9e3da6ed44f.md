# The stylelint configuration declares CSS and SCSS extensions for the comm wrapper

This landing changes the stylelint extension declaration from CSS plus an empty value to CSS and SCSS. The checked commlint command converts outgoing commits into file paths before passing its configuration to mozlint. The comm stylelint wrapper adds the ignore-file argument and delegates to the configured external payload. This is an observed configuration and dispatch contract; upstream path filtering, the stylelint engine and actual CI file coverage were not verified or executed. It does not establish a repository-wide style rule.

Scope: lint-integration.
