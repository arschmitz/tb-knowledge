# The global-search test waits for popup display after finding matches

The task registers its PopupGlodaAutocomplete shown-event watcher before typing. It waits for controller matches and then awaits the shown event before selecting and clicking a result. Match count alone is therefore not the test's displayed-popup condition. The separately explained post-click delay still observes extra-tab behavior; this scoped ordering does not prove native timing, successful indexing or an intermittent-test cure, and no test ran.

Scope: Gloda autocomplete browser-test ordering.
