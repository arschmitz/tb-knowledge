# Use a typed last-directory preference and accept overwrite results for decrypted saves

Entry 2104 replaces lastSaveDir, initialized as a string, with the shared messenger.save.dir preference read as nsIFile. An unset preference is allowed. After the picker returns, the code rejects returnCancel or a missing file, so an overwrite result can proceed where the old returnOK-only guard returned early. It stores fp.file.parent and decrypts into the selected output file. The fixed accepted callback keeps this contract. Save-as picker results and typed directory state are separate requirements; test both on this action. The commit reports that decrypt and save as failed, but its exact runtime failure and reviewer reasoning were not reproduced. No picker, overwrite, decryption, keyboard, focus, screen-reader, build or lint test ran. Full external context is pending.

Scope: OpenPGP attachment save picker.
