# Preserve persisted dotted DOM IDs and escape them in CSS

identity.smtpServerKey is a pref-bound XUL menulist ID. Its CSS selector escapes the dot, and current inline-size:0 with flex1 permits shrinkage when a long SMTP label would force page width. Do not rename the persisted/bound ID merely to match a new lowerCamelCase convention. The geometry is source-backed; long-label,zoom and RTL rendering were not run.

Scope: styles.
