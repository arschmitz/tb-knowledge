# OAuth credential replacement uses modification so it stays separate from removal

For a nonempty token whose granted scopes cover a stored login, setRefreshToken modifies password and/or httpRealm instead of removing and replacing the login. It changes the timestamp only when values change. This prerequisite keeps replacement separate from the later observer's removeLogin/removeAllLogins invalidation path. Explicit clearTokens remains the deletion path. Engine notifications and races were not executed; the later cache child is a separate historical phase.

Scope: OAuth stored-login and cache events.
