# Removing the manual-config settings section leaves its preference and Fluent messages

The removal deletes the whole manual-config settings block, including its checkbox, legend, experimental badge and description. It does not remove the preference or Fluent messages: the accepted default remains true and the retained AccountHubEmail fallback branch still reads it. The selected landing changes markup only, so the review's localization-removal proposal is not proof that the messages were deleted.

Scope: Account Hub manual-config settings removal.
