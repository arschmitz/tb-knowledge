# Use own-property checks for dynamic cell-text cache keys

D208448 review changed the cache check to Object.hasOwn. A column ID such as a name inherited from Object.prototype could make an ordinary truthy or in check return a prototype member instead of computed cell text. The accepted adapter caches even empty strings and trims the computed result. Current code keeps Object.hasOwn. Apply this rule to plain-object caches keyed by external or dynamic names; do not generalize it to every property access.

Scope: Address Book syntax.
