# The CSP follow-up adds moz-src to explicit script directives in23 documents

The owned23-document follow-up appends moz-src: to existing script-src directives. It leaves each document’s other directives distinct: compose still has worker-src resource: and its HTTP/HTTPS connection sources, while preferences keeps its own wildcard connection and separate image/style/object sources. Exact accepted downloads markup later loads its script from moz-src beside that explicit script policy. This is a bounded declaration/consumer check, not proof every CSP was found, all resource types admit moz-src or runtime compatibility/security was tested. The primary Bug has another later missed-CSP follow-up, so title wording is not exhaustive coverage evidence.

Scope: Scoped document CSP declarations.
