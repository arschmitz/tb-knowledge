# Explain the local proof when an EWS response unwrap is safe

The root-first iterator unwrap follows a nonempty static folder list, a root-order assertion, and a checked response count. The single-folder unwrap follows a length-equals-one check. In these helpers, keep the check next to the unwrap and state the specific invariant in the comment. This is a scoped Rust recommendation, not a claim that every unwrap is safe or a rule that protocol data may be trusted without validation. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: EWS checked unwrap syntax.
