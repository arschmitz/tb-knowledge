# The text/plain MIME naming shortcut still follows the unnamed-part guards

ValidateRealName only supplies a generated name after null, existing-name, empty-type and multipart guards. It strips content-type parameters and uses txt for exact text/plain instead of calling GetPrimaryExtension; MIME service retrieval still happens first. Other types retain their lookup path. This is production code despite the performance report coming from tests. The changed test setups do not directly assert the .txt fallback or elapsed speed. No MIME, OS or browser runtime ran.

Scope: MIME attachment fallback naming.
