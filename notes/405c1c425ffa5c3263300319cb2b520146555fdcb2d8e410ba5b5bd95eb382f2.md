# The initial merged Account Hub form adds fields before wiring their state

The first merged IMAP/POP3 form landing supplies both server field groups and registers the template and input element. Its controller still only stores the supplied configuration and returns it. Production port fields have bounds but no supplied default; the fixture placeholders do not establish defaults. Checkbox, smart-default and error-state behavior were deferred, and later accepted state synchronization is a separate phase.

Scope: Thunderbird Account Hub merged manual configuration phase.
