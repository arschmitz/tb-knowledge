# Smart mailbox removal handles a server without an account

At revision d15c88407bf2ebb1363d33567fefa9ca43643178, SmartMailboxUtils.removeAll removes the associated account when one exists and otherwise removes the incoming server directly. It returns without action when the smart server is absent. This gives cleanup an explicit path for a server that has no associated account. The removeFiles argument defaults to false and is passed to either removal operation; its documentation identifies it as controlling removal of the local data directory. Apply this contract to this helper at the cited revision. The excerpt does not establish singleton reset behavior or runtime cleanup results.

Scope: Smart mailbox lifecycle.
