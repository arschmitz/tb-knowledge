# Hide smart-account storage behind folder API identities

WebExtensions identify virtual tag folders as tag://<key> with /tag/<key> paths, and unified folders as unified://<type> with /unified/<type> paths. They do not expose the smart account root that stores both. This keeps extension identity separate from the internal account layout.

Scope: WebExtension folder API.
