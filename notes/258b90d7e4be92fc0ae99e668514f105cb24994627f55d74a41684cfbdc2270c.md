# Unobtrusive signature generation is an opt-in signed-only MIME mode

The clear_signature_format default is multipart. Compose adds SEND_SIG_UNOBTRUSIVE only inside its PGP/MIME signed-only branch when the preference equals unobtrusive. It also exposes the selected transport through the shared signFormat string property consumed during MIME construction. The S/MIME class's accessors satisfy that shared interface; they do not by themselves implement this OpenPGP transport. Encrypted output keeps its separate mode path.

Scope: OpenPGP signature transport selection.
