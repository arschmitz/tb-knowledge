# Calendar description rows keep pending data until their rich document is ready

The fixed full description row waits for eventDescription.html to finish loading before it accepts rich content. setDescription stores its arguments while the row is not connected; connectBrowser later flushes that data. The plain summary row has its own visibility event. This behavior is later than the original description-subview landing, where the expanded loader and call were still commented out. Existing summary/full/reset knowledge remains valid; the new detail is the asynchronous initialization and pending-data boundary. The HTML-conversion helper internals and runtime behavior were not independently tested.

Scope: Calendar description asynchronous initialization.
