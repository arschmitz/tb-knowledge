# Popup notification presence flags follow active focus and displayed persistence state

The attribute port keeps the notification manager's existing conditions while expressing panel flags through toggleAttribute. In an active window, noautofocus is present unless a non-dismissed notification requests autofocus; the hidden-panel path restores that default. Both already-open and changed-anchor paths set noautohide when any displayed notification is persistent. The actual receiver is a checked XULPopupElement. These scoped flag updates do not prove native focus or popup behavior and do not replace other value-based attributes.

Scope: Global popup notification panel flags.
