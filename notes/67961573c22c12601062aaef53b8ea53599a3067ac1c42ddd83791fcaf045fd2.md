# State database timestamp and size units at the policy boundary

The idle policy converts Date.now and the millisecond idle preference to microseconds before comparing lastUseTime. The keep-open preference is a byte threshold. Preserve explicit unit comments or unit-bearing names near these calculations; multiplying a time value and comparing a size value solve separate policy decisions. This recommendation is scoped to the cache policy. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message database policy units.
