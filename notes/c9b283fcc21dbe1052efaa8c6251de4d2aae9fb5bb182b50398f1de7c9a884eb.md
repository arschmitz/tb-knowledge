# The original mock change flattener checks created instead of create

The original producers emit create, but the new createdInRange scan tests created. That set does not record these creations, so a creation followed by deletion can lose its create record while retaining its delete record. The fixed accepted helper tests create and has a later pagination design. This is a source trace of the initial helper, not a fresh sync failure or a statement that the accepted tag check is still wrong.

Scope: Mock Exchange change-log tags.
