# Keep execution-environment scopes when updating the lint configuration

The historical port adjusts language support and browser-global exclusions. Accepted code now uses eslint.config.mjs, with separate script, browser, privileged, xpcshell, Node and Storybook scopes. sys.mjs, workers and xpcshell paths are excluded from the general browser-global rule, with an explicit extension-test exception. This is a configuration and execution-context lesson, not a new manual shadowing or formatter rule. The two broad shadow/redeclare sweeps in this batch are excluded, and no lint run was performed. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: tools/lint/execution-environments.
