# AutoDiscover scope selection is separate from the final Exchange account capability

AutoDiscover initializes OAuth with the imap activity to avoid requesting an unnecessary EWS grant. This is a specific discovery request choice, not an instruction to use IMAP permissions for EWS runtime operations. Current later code additionally checks exchange provider support separately; Microsoft EWS/exchange requests select EWS_SCOPES and both maps retain offline_access. The historical comment attributes the choice to restricted tenant grants and says scope-independent configuration seems to hold; no endpoint or tenant policy was verified here. Authentication and cloned Bearer request arguments remain; token failure can fall back to Basic unless cancelled. No OAuth, server discovery or account-creation test ran.

Scope: Exchange AutoDiscover OAuth scope selection.
