# The outgoing OAuth visibility test message reverses its hidden-state expectation

The outgoing test computes hide from expected popup membership and compares that Boolean with item.hidden. Its message inserts NOT when hide is true and omits it when hide is false. The text therefore states the opposite of the comparison. Preserve the Boolean predicate when correcting the diagnostic text. This is a static message mismatch; no test failure or native popup value-mapping defect was reproduced.

Scope: Account Hub outgoing manual-form test diagnostics.
