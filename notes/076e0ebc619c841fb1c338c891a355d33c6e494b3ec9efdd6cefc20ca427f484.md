# Keep notification rendering behind the backend event interface

Entry 806 makes show/hide methods private and changes tests to dispatch the backend clear event. Entry 822 removes optional method invocation once the real component is packaged. Accepted manager code calls setNotificationData before inserting or replacing its single active element. Use the backend event interface for display integration; do not restore a permissive optional call that silently hides a missing component implementation.

Scope: mail/components/inappnotifications.
