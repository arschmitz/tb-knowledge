# Pass a string to the Fluent error variable even when import produced no message

The import wizard passes errorMsgObj.value to a Fluent message on failed key import. Bug 1874715 made this value an empty string when absent because an undefined error variable caused a Rust Fluent crash. keyRing also fills errorMsgObj on failure. The landed and current wizard preserve the empty-string fallback for this message. This is a boundary contract between import result and localization, not a general instruction to hide errors.

Scope: OpenPGP import errors.
