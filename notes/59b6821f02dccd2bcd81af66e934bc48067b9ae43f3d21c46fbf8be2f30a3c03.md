# Keep standalone message navigation on its separate view setup path

In accepted CrossFolderNavigation, about:3pane waits for allMessagesLoaded. The standalone about:message branch closes the old wrapper, opens the destination, installs a TreeSelection and invokes the callback directly. Preserve these different setup boundaries when changing navigation. The direct callback is not evidence that every asynchronous folder/server condition is complete, and no standalone navigation was exercised.

Scope: Standalone cross-folder navigation view setup.
