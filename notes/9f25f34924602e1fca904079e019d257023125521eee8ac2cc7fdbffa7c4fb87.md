# Global search uses the inherited input keydown listener once

SearchBar installs the actual subclass instance as a keydown listener on its internal input. GlobalSearchBar calls that initializer and overrides handleEvent to route keydown to result selection. Its separate host capture listener caused another delivery, so the patch removes that registration while keeping inherited input handling. Arrow navigation prevents the input default action but does not stop propagation. This is a static target/phase relationship, not a fresh keyboard or accessibility result. No test ran.

Scope: Unified toolbar global-search keyboard events.
