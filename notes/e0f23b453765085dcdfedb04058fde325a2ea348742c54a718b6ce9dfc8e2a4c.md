# The generic extension root icon preserves checkbox semantics

When forceManifestIcons is enabled, current root construction uses manifest icons or the generic chrome extension icon for non-checkbox roots and marks them webextension-rootElement. Checkbox roots have their extension icon removed; Linux also keeps a single checkbox in a submenu to avoid overlap. Preserve these type-specific branches instead of applying a generic extension icon to every menu item. The existing class contains mixed camel casing and must match its CSS consumers exactly; it is not a reason to invent a universal class renaming rule. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: WebExtension root icon behavior.
