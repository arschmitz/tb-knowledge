# Account Hub native action buttons can retain delegated clicks

D229061 changes the success actions to native buttons with the shared link-button style. A reviewer initially objects to the parent click listener because keyboard activation might fail, then explicitly withdraws that concern after the author response. The historical landing keeps event delegation. Preserve native control semantics and inspect the actual event contract; this review does not establish a general ban on delegated listeners or a measured performance benefit. The linked demo and trusted keyboard behavior were not tested here.

Scope: Account Hub native controls and event delegation.
