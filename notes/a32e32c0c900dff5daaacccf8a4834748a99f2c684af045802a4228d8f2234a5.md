# Document toolbar space as an attribute

CustomizationTarget documents @fires space, but setItems reads getAttribute("space"). The actual itemchange dispatch is a bubbles/composed Event so it crosses the pane shadow root. Recommend labeling space as an attribute and reserving @fires for the event contract. This is a scoped correction proposal; no historical review approval or generated manifest result was read. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
