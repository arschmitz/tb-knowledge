# Removing the Linux UPX block also removes x86 host-PATH mutations

The later UPX bootstrap follow-up removes whole Linux-host setup blocks. In Win32 and Win64 this includes the VC_PATH hostx64/x86 or x64 PATH export and unset VC_PATH, as well as the UPX export and chmod. Arm64 removes only its UPX block and keeps the separate artifact MAPI condition. Fixed accepted common files retain the target and clang-cl include without those blocks. These are exact comm configuration effects; the upstream bootstrap implementation and resulting environment were not executed.

Scope: Windows mozconfig setup removal.
