# Register subdialog event waits before each action and await focus

promiseSubDialog prepares the open promise before clicking the trigger, waits actual focusedWindow, awaits its async callback, then prepares dialogclose before activating the close button. It supports either XUL dialog.getButton or an explicit HTML ID. Current helper scrolls the trigger into view first. Preserve close/focus ordering; registering after a synchronous action can miss the event. Tests were read; native focus not run.

Scope: testhelpers.
