# Graph update tests preserve known message IDs while clearing each sync round

The update phase enables client, real-folder and recipient scenarios for Graph. reset clears observed arrays, token and completion promise but keeps the created-ID set used to classify later update callbacks. The mock presents create, update and readflag events alike, excludes updates whose last state is deletion and advances the final token to its global change-stream end. Real-folder assertions cover counts, a changed token, Subject/body/store replacement and a moved message. Graph size/flag assertions remain skipped; normalized To/Cc checks do not validate general quoting. Current generic pagination is a later phase. The separate existing lesson records the unchanged deleted-count assertion limitation.

Scope: Graph and EWS update sync test state.
