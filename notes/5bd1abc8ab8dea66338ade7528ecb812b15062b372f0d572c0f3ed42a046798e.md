# Folder notifier migration preserves shutdown cleanup and synchronous compaction start

Named FolderNotification access removes normal-path availability wrappers while keeping event payloads and operation conditions. RSS registers on first instance and checks service existence when the last instance unregisters during possible shutdown collection. Compactor still sends folderCompactStart before BeginCompacting returns; the selected existing fixture expects start then finish and tracks return separately. This is a synchronous ordering/lifetime contract, not test execution or a global guarantee that services cannot disappear.

Scope: folder-notification-service-lifetime.
