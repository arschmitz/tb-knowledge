# Thunderbird RFC 7986 CONFERENCE read/write scope

The direct ICAL check preserved the URI but parsed `FEATURE=PHONE,MODERATOR` as one string and serialized it as `FEATURE="PHONE,MODERATOR"`; feature-list semantics need parser/design support. `FEATURE=MODERATOR` URIs must not be sent to attendees. [Task 1]
