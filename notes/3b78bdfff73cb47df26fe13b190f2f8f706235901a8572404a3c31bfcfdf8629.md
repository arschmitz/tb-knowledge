# Copied claims do not provide independent evidence

At TB Tools revision c4b5b8fb8c80bafd44a62cffbb119234008f5efa, claimGroups groups duplicate lessons and linked summaries, Markdown mirrors, original lessons and portable copies. This prevents copies from counting as independent sources. Duplicate claim keys include repository, component, sorted paths and normalized text. Explicit provenance links can also join records; those joins check repository identity, not component or text equality. Grouping does not resolve conflicting interpretations. This snapshot is from an implementation branch that was not merged into the default branch.
