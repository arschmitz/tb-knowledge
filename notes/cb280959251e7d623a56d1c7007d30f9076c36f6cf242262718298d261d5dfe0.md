# Keep remote tab icons inside the tab icon conversion and fallback path

setIcon converts an http-prefixed source into moz-icon before assigning it. With a fallback it installs error and load listeners, removes both on the first event and substitutes the fallback only on error. Null sources remove the icon or use the fallback. Preserve this method as the owner of conversion and fallback; caller-provided raw remote icon URLs and final image URLs are different values. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Tab icon conversion and fallback.
