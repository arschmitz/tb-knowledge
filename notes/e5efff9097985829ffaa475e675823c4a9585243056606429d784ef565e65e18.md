# The folder-creation mock servers preserve Unicode traffic and reject sibling-name conflicts

The changed mock servers decode request bytes and encode response strings as UTF8, including Graph batch messages. Duplicate display names under the same parent get an EWS ErrorFolderExists response or Graph409Conflict. The added tasks exercise Unicode folder names and compare resulting names/URIs and protocol-specific rejection codes; documented legacy-error and nested-Trash cases remain skipped. This is source and assertion coverage, not a new server, network or test result.

Scope: EWS and Graph folder creation test transport.
