# Filter completion recalculates Run Now eligibility from the current dialog state

The operation callback clears the dialog's running flag and recomputes Run Now eligibility instead of enabling the button unconditionally. Eligibility depends on selected filters, a run folder and the server's after-the-fact capability. The selected picker path clears an unresolved folder and the last-filter deletion path updates selection/buttons. Browser tests check flag completion and news-folder create/delete button states; they do not test every mid-run state change, failure or close/cancellation path.

Scope: Manual filter dialog completion, target folder and button state.
