# Initialize shadow templates once and localize the shadow root explicitly

AccountHubStep guards connectedCallback using shadowRoot, creates its own stylesheet link and cloned template, then connects DOMLocalization to that shadow root. Forms in light DOM extend that shared step. The header has its own root and localization setup. DOM IDs and CSS selectors must be read in the correct root; document-level lookup is not proof that a nested widget exists. The one-time guard prevents duplicate templates on reconnection. No reconnect, translation or accessibility-tree test was run.

Scope: Account Hub shadow ownership.
