# The S/MIME browser test removes certificates by common name during cleanup

This landing adds a cleanup callback after importing the CA, Bob, and Alice fixtures. The callback deletes every enumerated certificate with one of those common names; it does not track exact imported object identities. If an import fails before registration, this callback is not yet installed. The later accepted test awaits SmimeUtils.removeCertificates, whose helper awaits enumeration and keeps the same name-based selection. That later helper is a separate phase. This source does not establish native private-key or trust cleanup, nor a cryptographic or runtime result.

Scope: S/MIME browser-test fixture cleanup.
