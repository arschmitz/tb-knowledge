# Removing dead DB-view APIs also removes tests of the retired surface

Entry 1495 deletes unused selection and tree-row insertion/removal methods from nsIMsgDBView and their native implementations; it removes the unit task that exercised those methods. Entry 1512 separately deletes displayed-message bookkeeping and the corresponding updater hook. This is source-surface retirement, not a formatter rule or evidence that the remaining selection/navigation behavior needs fewer tests. Current selection behavior is checked separately in this batch. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Message view API retirement.
