# The URL placeholder map also contains raw relative schema aliases

Seven imported relative or fragment schema URL strings are explicit keys in url-placeholders.json, including manifest/version, #type-DownloadItem and extension.html#property-lastError. Their values point to MDN pages. This is separate from the README's normal $(url:...) authoring syntax. The consumer is an external schema generator; this audit did not inspect its substitution code, generate documentation or test HTTP targets, so mapping presence does not prove rendered links work.

Scope: WebExtension documentation relative-link repair.
