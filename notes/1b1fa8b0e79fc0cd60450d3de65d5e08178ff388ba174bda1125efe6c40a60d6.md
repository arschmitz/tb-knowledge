# CalDAV identity preference falls back through a resolver and can still yield to ACL ownership

fillACLProperties first uses getEmailIdentityOfCalendar, whose missing-key path may select the default account identity and whose empty key means None. Server addresses and an ACL-owner fallback follow. A separate hasAccessControl block then replaces organizer fields with the first ACL owner. The new four-task test only covers hasAccessControl false and reads cache fields directly; it does not establish invitation UI behavior, RSVP delivery or refresh after a populated identity changes.

Scope: CalDAV organizer identity precedence.
