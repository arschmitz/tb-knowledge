# Pair schema names with their generated metric members

558 renames calendar_count_read_only and its JavaScript caller calendarCountReadOnly together to read_only_calendar_count and readOnlyCalendarCount. Both pairs keep the same word order across schema snake_case and JavaScript lowerCamelCase. FileLink uploaded_size is used as Glean.filelink.uploadedSize, while compose C++ producers use mozilla::glean::compose::compose_format. Review names at the schema, generated-language boundary, producer and test. This is a coordinated schema/caller naming convention; ordinary identifiers need their own component rules. No generated API or build was run.

Scope: Telemetry syntax and naming.
