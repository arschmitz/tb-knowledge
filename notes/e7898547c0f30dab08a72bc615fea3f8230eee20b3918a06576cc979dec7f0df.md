# OAuth dialog closure and Inbox completion use separate test waits

handleOAuthDialog resolves after the OAuth window closes. The bad-refresh-token test separately calls waitForMessages after awaiting that dialog promise; the latter checks unread/pending counts and waits for server idle before marking messages read. The changed polling budget widens the message wait. It does not prove that window closure alone means token exchange, saved login and mail synchronization have completed, or that the reported intermittent failure was cured.

Scope: OAuth get-messages browser-test completion.
