# Keep filter-run UI state scoped to a filter run

FeedbackService broadcasts progress start and stop to all windows. The filter dialog must ignore those messages unless its own filter run is active, and manage Run Now enabled state in runSelectedFilters; unrelated background operations otherwise leave the button disabled.

Scope: filters.
