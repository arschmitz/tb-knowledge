# Refresh Windows file size after replacing an mbox

On Windows, nsIFile can retain a stale fileSize after an mbox is replaced. Clone the nsIFile before reading final size, then use the fresh size for onCompactionComplete. The test checks reported old and new sizes against IOUtils.stat rather than the same cached nsIFile.

Scope: message store compaction.
