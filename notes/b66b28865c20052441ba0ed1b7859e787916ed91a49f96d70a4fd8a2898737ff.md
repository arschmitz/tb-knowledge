# The shared listener migration removes the interim URL-listener unsafe accessor

This migration replaces the separate SafeUrlListener struct with the common SafeListenerWrapper alias and removes its temporary unsafe_listener accessor and EWS compatibility implementation. UnsafeListener stays private inside the shared module. Graph passes the bridge URI into its connectivity operation, and the shared success/failure callbacks finish that URI. The common RefPtr ownership contract is existing knowledge; the new fact is completion of the earlier interim adapter phase.

Scope: Rust shared URL-listener migration phase.
