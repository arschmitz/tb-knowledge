# Compose attendee summaries from four localized count entries

The summary maps ACCEPTED, TENTATIVE, DECLINED and NEEDS-ACTION into four Fluent IDs, each with a $count argument and plural branches. It formats all four counts, including zeros, and passes the translated strings to Intl.ListFormat with narrow style before writing textContent. The original landing uses the default locale argument; accepted source later passes the application locales explicitly. The IDs still use going/maybe/declined/pending, so the requested direct participation-status naming was not adopted. The mixed-count English test is a bounded expected result, not proof of every locale, plural or punctuation case.

Scope: New Calendar dialog attendee localization.
