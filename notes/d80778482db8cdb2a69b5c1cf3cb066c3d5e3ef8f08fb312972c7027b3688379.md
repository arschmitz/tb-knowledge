# Retain the incoming edited flag across state updates and clear it during reset

1258 introduces incoming edited tracking. Accepted setState keeps the existing edited flag, captureState includes it, and resetState clears it. The controller reset walks subviews and invokes their resetState methods. A scoped recommendation is to preserve the distinction between revisiting a form and starting a fresh Hub flow; clearing edited merely because fields are restored can re-enable a continuation that still requires retesting.
