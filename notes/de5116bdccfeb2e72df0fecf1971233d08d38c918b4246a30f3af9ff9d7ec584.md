# The MDN bar restores a previous focus target after its actions

The MDN prompt captures the parent document's active element, then remembers the element that lost focus during later focusin events. Send and Ignore forward the MDN response and focus that remembered target; the close button uses the same helper. When no later target was captured, the helper uses the parent target. This is more specific than always moving focus to the thread pane. The accepted source retains the callbacks. The document listener is created per prompt without local removal, while notification cleanup only removes the bar; this scoped observation is not a reproduced lifetime defect. Existing return-receipt tests check the bar and its text rather than focus restoration.

Scope: MDN notification focus.
