# Separate toolbar selection, preview edits and saved customization

Current plain arrow/Home/End navigation selects items and leaves stored state unchanged. Alt-modified movement changes the target order and hasChanges enables Save; returning to the saved order disables it again. Cancel hides customization without storeState, while Save constructs overrides only for panes that differ from their defaults. Tests compare selection, preview order, Save state and persisted state separately. Keep these contracts distinct when changing keyboard handling. No live keyboard or accessible tree check was run.

Scope: mail/components/unifiedtoolbar.
