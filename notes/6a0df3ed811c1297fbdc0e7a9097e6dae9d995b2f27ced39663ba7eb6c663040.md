# OAuth test cleanup awaits login removal before clearing cached authorization state

Calendar and CardDAV checkAndClearLogins are async, and their task callers await them. The helper checks login count/fields, awaits removeAllLoginsAsync, then forgets OAuth objects and resets grantedScope. Each helper still has five message-less assertion sites. These source assertions describe pre-cleanup login contents; they do not directly test API rejection or storage completion semantics. No tests ran.

Scope: OAuth browser-test cleanup ordering.
