# Removing an experimental preference label does not change the bound default

Fresh full markup/Fluent patch removes the experimental span and changes the description text with a matching new Fluent ID. The preference bindings for dark-reader enabled/show-toggle are unchanged. The Bug says the default had already been enabled since136; this patch itself does not change defaults or establish all rendering defects solved. The shared label-experiment message still exists for other UI; removing one span is not a global deletion of experimental labeling. Brief review acceptance has no render/platform test report. No tests changed and no dark/light message rendering or preference interaction ran.
