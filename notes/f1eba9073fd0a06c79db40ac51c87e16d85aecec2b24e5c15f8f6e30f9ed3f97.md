# Legacy OAuth lookups now gate migration instead of returning their errors

The follow-up runs the legacy transfer only when GetBranch succeeds with a branch and GetBoolPref succeeds with useCustomDetails true. Failed legacy lookups now reach NS_OK without running the transfer; failures inside the transfer still use early error returns. ForAccount separately ignores that migration result, so this guard change does not make the transfer atomic or prove completion. No preference service, console warning or migration was executed.

Scope: Exchange OAuth settings.
