# The dark critical text value and the semantic color role are separate source facts

The original landing changes only color-text-critical-dark from #ef4444 to #f05252. At the fixed accepted revision, that text token is #f87171 and #f05252 is the separate critical-pressed-dark value. The semantic color-text-critical alias selects light/dark text inputs, and actual folder TLS-error text and icon consumers use the alias. Preserve the historical literal, current literal and semantic role separately; static CSS does not prove rendered contrast or accessibility.

Scope: Thunderbird shared semantic color palette.
