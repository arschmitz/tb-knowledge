# The initial APT push kind delegates publication through the repackage dependency

The initial kind consumes beetmover-repackage through from_deps and the upstream beetmover_apt transform, with explicit platform and release filters; the companion config adds BM-apt. Its backout exactly restores both prior blobs. Accepted configuration later adds different grouping, shipping and worker inputs, so current presence does not establish uninterrupted survival or identify the reported build failure.

Scope: Taskcluster APT package push phases.
