# Use the available Fluent sync formatter for default away text

Bug 1897768 reports a runtime TypeError because the default away-message branch called nonexistent lazy.l10n.getValueSync. The fix calls formatValueSync for the Fluent message. The error appeared only when the user had no explicit away-message preference, because the other branch read that preference. This is a breakage lesson: verify the imported localization object’s real API and exercise fallback branches, not only configured ones. The current chat code may have moved since this 2024 commit.

Scope: Chat localization.
