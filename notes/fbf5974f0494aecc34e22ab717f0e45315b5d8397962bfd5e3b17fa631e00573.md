# Message thread levels are separate from TreeDataAdapter row levels

The threaded helper tests assert message.level, but ensureChildren creates one flat child-row array. LiveViewDataRow retains the message without copying that field into row.level. The shared tree cache instead assigns row depth from structural parent/children nesting. Reuse helper level tests as helper coverage only; they do not directly establish rendered indentation or accessible row hierarchy. No live tree run occurred.

Scope: Panorama thread row-depth consumers.
