# Commands console reliability, hidden browser, and review-queue workflows

`iab` is session-scoped: console-created app-server sessions cannot inherit the current chat's in-app browser. Register the running interactive console's local URL/token and expose only authenticated `GET /api/ai/browser/phabricator`, which calls the console-owned hidden `phabWebSession.getReview`; inject connection values into child app-server environments without exposing them. `readConsolePhabricatorReview()` accepts only local HTTP console URLs and `D####` revisions, uses an abort timeout, and tasks must use the supplied snapshot first and never retry iab after bridge failure. [Task 13]

Scope: console.
