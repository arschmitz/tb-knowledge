# Separate an obsolete MIME feature from leftover declarations and names

Entry 951 removes the operational ROT13 URL option, display flag, dispatch assignment, lookup table and mutator. It also removes a branch that copied from a pointer initialized to null; runtime reachability of that branch was not established. The accepted parser still has a rotate-named charset conversion helper, and mimetext.h still declares an unused rot13_line class member. These names do not establish that ROT13 remains operational. Review feature removal across input options, dispatch and data state, and distinguish unused remnants from working behavior. This augments the prior ROT13 removal study without contradicting its operational scope.

Scope: mailnews/mime/obsolete-rot13.
