# ADR 0004 records the folder-name preference and its display risks

Accepted ADR 0004 records localized display names for special folders with matching flags and specific English names, plus mail.useLocalizedFolderNames as an opt-out. It explicitly preserves duplicate-looking folders and differences from server labels as risks. The fixed accepted document retains this decision. This is scoped architecture-document evidence; the separate getter-boundary lesson records Inbox, AllMail and local-folder exceptions, and the ADR does not prove all providers' behavior or a running release.

Scope: Server-folder naming architecture decision.
