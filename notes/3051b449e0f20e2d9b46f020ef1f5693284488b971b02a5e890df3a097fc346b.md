# Build the address-to-card map once per invalidation cycle

AddrBookManager changes from per-address timed lookups to a lazily created map containing the available address-book cards. Current cardForEmailAddress normalizes the requested address and populates the whole map on the first lookup after invalidation. Later lookups reuse it until the display-name version observer clears it. This shifts work to cache rebuilding; it is not evidence of a measured speedup or a permanent cache. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Address-book lookup cache.
