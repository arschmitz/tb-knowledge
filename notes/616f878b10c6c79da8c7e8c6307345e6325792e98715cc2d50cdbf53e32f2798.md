# Generic TLS failures have separate text and category-controlled exception actions

The error switches recognize untrusted certificates explicitly and give other TLS failures separate generic text. Notification clickability and its modal fallback use canMakeException; the widget's generic failure hides view/add-exception controls. The alert-click callback itself is not guarded, so this is a source mapping, not a native backend/security guarantee. The nonexistent-server test directly checks the failure message and no visible buttons, through helpers; it was not run here.

Scope: Thunderbird TLS error notification and certificate-check UI.
