# Give documentation snippets their real extension and Markdown instructions a .md name

This is a scoped manual file naming rule from the newer accepted annotation review. Use README.md for Markdown instructions. Use .js, .json and .css for corresponding example files so editor support works; do not rename JavaScript to _js just to evade lint. The accepted code adds narrow configured exclusions for the includes directory. The binary/text base64Image fixture remains extensionless, and existing snake_case versus camelCase snippet names are mixed; this evidence does not justify a global file-case rule. Keep any required source licensing separate from a file-name workaround.

Scope: mail/components/extensions/annotations.
