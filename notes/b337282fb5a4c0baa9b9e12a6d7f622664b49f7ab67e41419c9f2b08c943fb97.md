# Selected-card export separates card membership from the suggested filename

The export API takes cards plus a suggested filename. A single selected mailing list supplies its members; selected contacts pass directly, with one display name or a localized multi-contact name. The picker uses that separate name. The completion topic follows output writing and carries no directory UID. Clipboard copying and format round-trip guarantees remain separate.

Scope: Address-book selected-card export.
