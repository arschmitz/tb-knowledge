# Graph hierarchy creation falls back only on a missing-folder error in accepted code

The first Graph hierarchy implementation falls back from any on_folder_updated error to on_folder_created. Accepted code narrows this to NS_MSG_ERROR_FOLDER_MISSING and propagates other errors, while separately handling removed delta items. Preserve the callback status distinction when changing folder synchronization; an arbitrary callback failure is not proof the folder is absent. First-sync root mapping and later token paging are separate steps. The exact source establishes these phases, with no live sync, failure injection or persistence result.

Scope: Graph folder hierarchy callback contract.
