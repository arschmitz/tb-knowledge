# Create and verify unified and tag virtual folders outside the UI

The SmartMailbox refactor moved unified folder and virtual tag folder creation from about3Pane.js into a shared module. getSmartMailbox keeps one instance but calls verify on each access, preserving the old getSmartServer behavior of creating the hidden server/account and updating missing folders. The class creates tag search folders with AND (tag,contains,key) across all folders, while unified folders search the relevant flagged folder trees. Add-ons can now access virtual tag folders before the user opens Tags mode. Review specifically kept verify on each call while changing to a single instance; it also asked for a dedicated module test, but this stack relied on extension tests.

Scope: smart mailbox architecture.
