# Name the expected property and row in subscription test failures

checkTreeRow includes both the expected row property and nameCellText in assertion messages. The accepted tree uses uncheckable and checked properties; the historical subscribable-true and subscribed-true values are not the current flags. In this test family, use template interpolation to identify the row and failed expectation instead of a generic message. This is useful manual diagnostic style, not a request to replace every concatenation or copy obsolete property names. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Subscription test diagnostics.
