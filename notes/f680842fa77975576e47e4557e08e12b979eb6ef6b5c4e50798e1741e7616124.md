# Correction: the historical EWS scope overwrite affects ewsIncoming

At f2dcbd6a1a261352a6ec0a2c006f962d2c54bcf7, _ewsifyConfig appends EWS.AccessAsUser.All to ewsIncoming.oauthSettings.scope. The next destructuring assignment overwrites that same property with the provider scope. The earlier lesson incorrectly named config.incoming as the receiver; the quote already showed ewsIncoming. This correction concerns the cloned EWS option. It does not establish an authentication failure, and D220925 did not diagnose this lost write. The fixed accepted FindConfig later uses a different protocol-specific design. Keep historical static inspection separate from the reviewer's reported AutoDiscover test.
