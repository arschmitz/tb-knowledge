# Do not delete an editor placeholder after the editor already removed it

Plaintext inline forward uses a placeholder line break to keep its container alive. The editor can remove that break while inserting forwarded text. Check whether the node is still attached before deleting it, or the remaining compose setup, including signature insertion, can fail.

Scope: compose.
