# The worker fixed field is a byte count rather than the documented boolean

mac2unix documents whether repair was needed, but returns offset after counting all bytes read. The worker sends that result in the fixed field. Thus a nonempty already-valid input also returns a nonzero value; fixed does not mean changed. Scoped manual naming/documentation recommendation: use a byte-count name and number return type, or explicitly return changed when a boolean is intended. The current wrapper does not expose the object to its caller. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: mbox repair worker result naming.
