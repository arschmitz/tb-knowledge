# Store message selection with an identity that survives multifolder views

Historic387 saved msgKey values and excluded multifolder views because keys were not globally unique. Current saved state records full message URIs and finds them with findIndexForMsgURI; the earlier multifolder exclusion is gone. Synthetic views keep a dedicated key because they own their about3pane. Keep current URI identities and do not reintroduce local keys from old tests.

Scope: view.
