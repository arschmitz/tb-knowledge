# Gate saved-login OS authentication by capability and primary-password state

The port removes a Nightly-specific signon.management.page.os-auth.enabled default and uses LoginHelper. The privacy pane hides the OS-auth checkbox when OSKeyStore.canReauth() is false. The primary-password change path uses OS authentication only when no primary password is set and OS auth is enabled. D210126 reviewer asked whether removing explicit Linux exclusions was safe; author answered that Linux cannot reauthenticate, so the option is hidden and OS auth is disabled. The password manager keeps a confirmation dialog path when OS authentication is unavailable. Current privacy tests branch on LoginHelper.getOSAuthEnabled() and OSKeyStore.canReauth(). Do not infer platform support from the checkbox alone.

Scope: Saved logins and privacy.
