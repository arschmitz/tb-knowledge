# The Today Pane test refreshes the expected hour only for its past-date case

The New Event command computes a default time from now on each invocation. This patch refreshes expectedDate immediately before the historical September 2018 case, then uses that current hour on the fixed UTC date. Earlier test cases still reuse the first expected-time snapshot. The helper adds an hour only below 23, while the task already skips registration-time UTC hour 23. The source change narrows one stale-expectation window; it is not a fresh timing or sanitizer cure.

Scope: Calendar default-time test phases.
