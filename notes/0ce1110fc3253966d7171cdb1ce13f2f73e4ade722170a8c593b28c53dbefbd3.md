# The attendee duplicate test checks the dialog callback separately from calendar persistence

The reliability change passes event data directly to openAttendeesWindow and captures onOk's attendee array. Accepting the dialog directly checks one case-insensitive existing attendee and preserves its DECLINED status and CHAIR role. It removes this scenario's calendar add/get, modification-time wait and full editor save. The actual helper and dialogaccept receiver support that narrower callback contract; the test no longer proves persistence in this task. No browser test or accessibility interaction ran.

Scope: Calendar attendee browser-test scope.
