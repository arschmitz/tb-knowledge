# Use a deliberate message date to isolate archive-year fixtures

The navigation fixture sets MessageGenerator._clock to a date in 2001 so its archive folder differs from other tests, then asserts the expected year destination. After a move it refreshes testMessages from the folder. Keep the clock/destination expectation and mutable fixture state together. This isolates this test’s artifact names; it is not a rule that all test clocks must use 2001. Static source and test-code inspection only.
