# Omit previousTabId when the old tab has already closed

The accepted emitActivated sets previousTabId only if previousTabInfo exists and is not closed. The browser test expects activation after closing foreground tabs and eventually expects undefined for the previously removed last tab. Keep object lifetime separate from historical numeric ID presence; a closed tab should not be reported merely because its old object is available. This is a source/test contract, not a universal onActivated serialization guarantee for every event-page mode. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: extension tab identity.
