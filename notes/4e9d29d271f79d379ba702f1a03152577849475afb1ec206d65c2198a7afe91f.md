# Archiving Fluent recipes preserves body identity but changes their explicit module path

The four-recipe archive is four 100-percent renames with identical parent, destination and fixed accepted blobs. The original recipe analyses are reused; this entry adds no new script-body study or migration execution proof. The local tb-fluent-migration-test command accepts explicit test_paths, and its test wrapper derives the Python module name from path components below l10n. An archived recipe path therefore includes completed in that module name. These inspected functions do not establish every external discovery path or prove the recipes ran merely because their directory is named completed.

Scope: Fluent migration archival and local test harness.
