# Calendar password retry awaits its Fluent label before opening the prompt

The async password-retry function awaits a Fluent label with the location argument before opening the prompt. onDetectionError invokes it without adopting its promise. A confirmed prompt starts provider detection, whose callbacks deliver the results separately. The dialog registers the creation Fluent resource. This establishes the inspected completion boundaries; no native prompt, localization rejection or discovery test was run.

Scope: Calendar creation authentication and Fluent completion.
