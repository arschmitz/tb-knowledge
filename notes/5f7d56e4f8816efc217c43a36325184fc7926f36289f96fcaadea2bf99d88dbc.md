# Refresh interested DB views when a folder is reindexed

650 moves repair refresh coordination into FolderNotificationHelper. Its folderReindexTriggered handler skips IMAP, prepares all wrappers registered under the folder URI, and removes a temporary listener before refreshing them after the matching FolderLoaded event. _aboutToCompactFolder itself acts only for the displayed folder with a live dbView, preserving flags and notifying the listener before closing the view. The repair caller now lives in FolderCommands.mjs and sends the notification before invalidating the database. Do not infer that every wrapper is closed or that IMAP takes this same event path.

Scope: Folder repair and view lifecycle.
