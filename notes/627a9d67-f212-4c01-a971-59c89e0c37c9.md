# Derive EWS outgoing setup from its incoming configuration

The 2024 EWS outgoing-server patch reused the incoming Exchange Web Services settings to create an outgoing server, instead of treating EWS as SMTP. It looked up and created outgoing servers by config.outgoing.type and set the EWS endpoint through nsIEwsServer. D210200 reviewer asked for a capability on the config instead of EWS-only branching; the landed form used handlesOutgoing. Newer accepted code replaces that flag with AccountConfig.configureOutgoingFromIncoming(), which currently delegates to isExchangeConfig(). Use the current method when changing account creation. The initial server was a dummy and did not send mail.

Scope: Exchange account creation.
