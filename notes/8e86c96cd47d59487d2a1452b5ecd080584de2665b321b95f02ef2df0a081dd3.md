# The contact-move cache test waits for both move events and checks the new ID

This edit-contact test registers contacts.onCreated and contacts.onDeleted before moving the card. It waits for both events, checks the old ID and parent plus the destination parent, and compares contacts.get(newId) with the created event object in strict mode. Four create/move/delete runs must yield eight unique IDs. The test does not require event order or query the old ID after the move. These are source assertions, not a recorded test run.

Scope: WebExtension address-book browser tests.
