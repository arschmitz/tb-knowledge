# Fresh incoming-server root creation is separate from its cached root getter

The legacy CreateRootFolder path calls CreateRootFolderAndCache, which creates a new folder rather than reusing the cache object. It invalidates literal-prefix cache keys only when a live existing root resolves. GetRootFolder still returns the per-server m_rootFolder once present, with a caller reference. The service cache is weak; removing entries does not destroy old objects retained elsewhere. Panorama follows a separate database path. Static source only; no recreation, expired-root or prefix-boundary test ran.

Scope: Mail folder lookup and incoming-server lifetime.
