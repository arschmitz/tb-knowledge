# The Calendar telemetry setup waits for startup before enabling its calendar

The setup awaits the window delayed-startup promise before checking telemetry and enabling the test calendar. Messenger resolves that promise after its component loader; that loader awaits Calendar startup, which registers the deactivator. This pairs the test's readiness condition with the actual producer. It does not establish an executed intermittent-test cure, all lazy views being initialized or telemetry delivery.

Scope: Calendar telemetry browser-test setup.
