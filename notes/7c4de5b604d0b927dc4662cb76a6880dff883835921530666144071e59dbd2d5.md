# Only stop a compaction timer that actually started

Current OnCompactionBegin returns NS_ERROR_ABORT during shutdown before starting the Glean timer or profiler interval. OnFinalSummary always counts the result, but only accumulates duration and emits the interval end when mTimerId exists. The local mbox test aborts before releasing the event loop and expects an abort result with no duration or recovered-space sample. This distinction separates a pre-start abort from an operation that began and later failed. Other failure stages were not exercised. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Folder compaction timing lifecycle.
