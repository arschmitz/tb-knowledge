# Taskgraph helper substitution keeps distinct attribute merge and replacement callers

Both comm transforms import copy_attributes_from_dependent_job from mozilla_taskgraph after the provider substitution. Signing merges its result into existing attributes; langpack pushing replaces the attributes and then supplies chunk_locales with an en-US fallback. The import change preserves those visible caller steps. The upstream helper implementation, copied field set and task-graph behavior remain unpaired.

Scope: Langpack/signing dependent-job attribute helper provider.
