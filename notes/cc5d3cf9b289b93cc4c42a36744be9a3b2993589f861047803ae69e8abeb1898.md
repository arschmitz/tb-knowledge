# Thunderbird keyboard-shortcut source documentation

Inventory all mechanisms, not just menu accelerators: XUL `<key>` declarations, JavaScript handlers, access keys, customizable shortcuts, and native/editor bindings. Start with `mainKeySet.inc.xhtml`, `ShortcutsManager.sys.mjs`, `ShortcutsOverlay.mjs`, compose/calendar/address-book/chat keysets, then shared Firefox `dom/events/ShortcutKeyDefinitions.cpp`.
