# The initial Lando version-bump port declares release tagging before version updates

The initial port selects the lando worker and declares a release-tag action before the version-bump action in the ship phase. It replaces treescript bump/push fields with Lando repository and action configuration. Its Try project keys differ between lando-repo and the hg URL selector; accepted source later uses try-comm-central consistently and adds explicit revision/task-context fields. These are source configuration phases, not a generated graph or executed release.
