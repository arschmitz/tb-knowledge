# Compaction size tests use fresh IOUtils stat data instead of nsIFile cached size

The size test captures IOUtils.stat before and after compaction and compares those fresh sizes with final-summary values. Its comment explicitly avoids inbox.filePath.fileSize due to Windows nsIFile stat caching. Scoped test recommendation: keep the fresh filesystem observation when checking output size; a cached object value is a different observation. The linked older Windows bug is comment evidence, not a newly read diagnosis. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: mbox compaction test file-size freshness.
