# Filesystem import was an experimental mbox collector, not a general storage engine

Entry 1500 adds FolderCollector for mbox layout, mapping .sbd directories, mailbox files and orphan .msf summaries to logical children, then loading flags from the folder cache. That collector is absent at the fixed accepted revision. Current store discovery feeds Reconcile, and the current filesystem test sets up both mbox and Maildir through ProfileCreator. Keep the 2024 importer scope separate from later store integration; no filesystem import was run. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama historical filesystem import.
