# Stage documentation with the platform-aware copy or link helper

943 assembles trees into an output staging directory and redirects app.srcdir there. The accepted helper copies on Windows or for an existing symbolic link, and otherwise creates a symbolic link; the manager clears the old staging location before rebuilding it. Preserve the platform and existing-link branches when changing staging. No Windows permission behavior, live reload or rendered documentation was tested.

Scope: Source documentation staging lifecycle.
