# Keep snooze label counts separate from action minutes

Calendar snooze presets pass the displayed unit count to Fluent while their value remains minutes. The 2Hours preset uses count2 and value120; its handler forwards that value through event.detail to the minute-based duration consumer. Keep these two contracts separate when changing labels or presets. The minutes, hours and days messages each define plural branches and document the unit of count. Static source only; the existing popup test selects a preset but does not assert its translated text or duration.

Scope: Calendar alarm snooze localization and commands.
