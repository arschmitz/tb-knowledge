# The first-run Hub class scopes the darker backdrop to the modal

The first-run patch assigns a black 0.75-alpha background to the dialog's backdrop only when account-hub-first-run is present. The fixed accepted rule keeps that state selector under .account-hub-dialog. The controller sets the class from isFirstRun when opening the modal; it does not apply opacity to the whole dialog or continuously recompute first-run state. Source establishes the selector and value, not a rendered or measured contrast result.

Scope: Account Hub first-run backdrop.
