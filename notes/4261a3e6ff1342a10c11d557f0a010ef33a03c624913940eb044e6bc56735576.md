# Release-note checks read prod YAML and count beta groups

verify-notes.py builds a prod-branch YAML URL from BRANCH and VERSION and fails when the variables or parsed notes are missing. For beta it also requires at least the requested beta number of release groups. The check does not validate the release text or rendered notes page. Its version-prefix regex and expected mapping shape are narrower than a general version or YAML-schema validator.

Scope: release-notes-verification.
