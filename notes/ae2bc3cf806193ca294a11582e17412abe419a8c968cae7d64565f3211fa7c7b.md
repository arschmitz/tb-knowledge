# Folder-time comparisons convert units at the consumer boundary

The accepted FolderUtils helper converts Date.now milliseconds to seconds before comparing stored MRUTime or MRMTime strings. The current extension helper instead exposes milliseconds by default and its query compares against millisecond Date values. Keep the helper’s units explicit when crossing between these two callers; do not copy a seconds threshold into the newer extension query. This is scoped time-unit guidance from source, not proof of every stored timestamp’s validity. No boundary-date or clock test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Recent folder timestamp units.
