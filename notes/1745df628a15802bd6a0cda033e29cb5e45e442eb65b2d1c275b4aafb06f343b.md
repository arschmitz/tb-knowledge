# Check lazy global declarations after deleting the only direct reader use

The accepted ext-cloudFile still declares lazy File and FileReader globals. File is used by uploadFile, while the scoped full-file identifier query finds FileReader only in that declaration after promiseFileRead is removed. Proposed local cleanup check: confirm that no indirect consumer requires the declaration before removing the unused FileReader getter. This is a static unused-declaration observation, not a runtime allocation or startup-cost measurement and not a general rule to remove every lazy getter. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: cloud-file lazy globals.
