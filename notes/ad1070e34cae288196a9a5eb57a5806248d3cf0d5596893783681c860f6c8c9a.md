# Keep filter eligibility separate from direct notification-manager test inputs

The donations_old historical manager test feeds about:blank directly into NotificationManager. It does not pass through NotificationFilter and therefore does not contradict the HTTPS filter test. Current InAppNotifications.getNotifications applies filtering before manager selection. Existing shared lesson 8fad843ed7c07ca691d48a3cff7f3506255d8cf974ab0249c6b04c425ab91e07 already states that pipeline; reuse it. Proposed review check: establish which layer a mock exercises before claiming production validation accepts the mock value.

Scope: mail/components/inappnotifications.
