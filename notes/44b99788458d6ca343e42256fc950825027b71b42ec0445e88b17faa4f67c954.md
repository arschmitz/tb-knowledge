# Graph autosync uses the shared keyed offline download branch

The patch adds Graph to the existing EWS offline-download branch, which converts message headers to keys and calls the shared helper. The helper gets the server client through IExchangeIncomingServer and fetches each stored message ID. Its start result is distinct from later completion and store status; the autosync caller retains separate semaphore cleanup for those paths. Current client selection is reused from its earlier exact proof. No network/store execution or wire-equivalence result is claimed.

Scope: Thunderbird Graph autosync offline downloads.
