# The IMAP copy fix derives its UID set from source-folder headers

This landing replaces a destination-database UID lookup with UidsFromHdrs(sortedMsgs). MessagesInKeyOrder loads those headers from srcFolder, and the same-server online copy passes the resulting UID set with that source folder. At the fixed accepted revision, UidsFromHdrs still casts GetMessageKey to ImapUid and UidsFromMsgKeys ignores its database argument. This removes a prospective wrong-database dependency before UID separation; it does not demonstrate a current copy failure, completed UID separation or a network/undo result.

Scope: IMAP same-server online copy source identity.
