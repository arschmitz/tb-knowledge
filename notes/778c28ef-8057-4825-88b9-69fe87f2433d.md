# Put the misleading content tab before the mail tab in folder-event tests

The regression depended on tab order: a content tab before a mail tab produced the false null match. The new browser test creates that order, then selects folders both by UI state and mailTabs.update and checks event tab ID, account ID, and path for each transition. This is stronger than testing only one active mail tab. The descriptive test name states the exact context. Current test remains in browser_ext_mailTabs.js.
