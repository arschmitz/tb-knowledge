# The original alarm-widget wait polls a saved query result rather than querying again

The original runTestAlarms callback obtains a querySelectorAll result before waitForCondition and polls that saved result’s length. The accepted later callback runs querySelectorAll inside the condition and checks the returned count. Keep the original static query boundary separate from the later repair and from the test’s fixed delays. No dialog timing or test execution was reproduced.

Scope: Calendar provider alarm test.
