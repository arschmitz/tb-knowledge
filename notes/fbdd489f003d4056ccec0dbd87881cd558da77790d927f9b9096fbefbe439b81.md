# BuiltInThemes exposes a shallow map copy and separate installation completion

The instance uses the imported theme map directly. getBuiltInThemesDataMap returns a new Map with the same value objects, so the map container is copied but theme records are not deeply cloned. previewForBuiltInThemeId returns null when absent despite its string-only JSDoc type. ensureBuiltInThemes awaits delegated install promises, while MailGlue starts it without awaiting. The direct body has no expired-theme removal call; downstream add-on effects were not studied. No install or startup was run.

Scope: Built-in theme data and async consumers.
