# Give importer capability metadata stable names distinct from display labels

AppleMailProfileImporter and OutlookProfileImporter supply NAME beside uppercase USE_FILE_PICKER and SUPPORTED_ITEMS instance fields. The import controller reads NAME for Glean importer data and adds source-kind suffixes before recording success or failure. Treat these values as stable telemetry identifiers in this importer family; changing a display label does not justify renaming the telemetry value. The uppercase fields are a local metadata pattern, not proof of a universal field-case rule. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Profile importer metadata naming.
