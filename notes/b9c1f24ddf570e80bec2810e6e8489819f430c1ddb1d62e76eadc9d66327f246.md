# Suppress compaction error dialogs during shutdown while still notifying the caller

BatchCompactor records per-folder completion/failure and starts the next item. At final completion it skips error alerts when shutdown is in progress but still calls the final listener, reports totals and releases its self-reference. Avoid leaving the caller waiting merely because a shutdown cancellation must not display UI. This does not prove every prompt elsewhere is suppressed. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/base/src.
