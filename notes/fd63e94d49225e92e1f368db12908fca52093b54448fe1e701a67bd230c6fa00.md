# Agenda row helpers also maintain date-header structure

The accepted agenda insertListItem and removeListItem helpers update the adjacent date headers as they insert or remove a row. Their comments explicitly direct callers to these helpers rather than raw DOM methods. In this agenda family, use the helper when changing individual item rows so the grouped date presentation stays consistent. This is local guidance supported by source, not a rule for every list component. The 1283 edit/selection path was traced through these helpers; no date-header layout or keyboard test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar agenda row structure.
