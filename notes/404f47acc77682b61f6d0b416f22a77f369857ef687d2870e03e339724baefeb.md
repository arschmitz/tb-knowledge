# Tag popup tests wait for the owner document to translate before checking labels

After popup-shown, each of five tag-popup helpers awaits its actual owner document l10n.translateFragment(tagsPopup) before returning the popup. This replaces a single event-loop tick and lets later label/accesskey checks depend on explicit translation completion. The thread-pane, message-pane, header, toolbar and menubar paths use their own document receiver. This is the scoped follow-up to the Fluent tag migration, not a production wait rule or a fresh test result.

Scope: Message tag menu browser tests.
