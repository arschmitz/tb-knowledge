# Keep the security result shape usable by the status sink

displayStatus consumes signature, key, recipient and optional packet fields from returnStatus. The shared result class supplies the standard recipient object even for verification-only or missing-input paths. Preserve that consumer shape when simplifying initialization. This source does not require every operation-specific optional property on every instance. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
