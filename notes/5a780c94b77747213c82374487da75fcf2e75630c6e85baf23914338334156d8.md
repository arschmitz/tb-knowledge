# Carry notification identity in the close event and preserve mouse data

InAppNotificationEvent extends MouseEvent and stores notificationId. The close button supplies dataset.id, the container propagates its data-id to that button, and the manager listens in capture mode and dismisses only event.button === 0. Keep this event contract when refactoring close handling. The focused browser test checks the emitted ID and constructor name; it uses a synthesized click and does not prove all keyboard activation paths.

Scope: mail/components/inappnotifications.
