# Check real native notification behavior when a browser test can pass on fallback

Bug 1893349 reports that browser_notification.js passed locally even while the native alert path logged NS_ERROR_FAILURE and the user saw no notification. The fallback test deliberately makes gMockAlertsService fail and expects newmailalert.xhtml, so a green result does not prove Windows native notifications work. For fixes in this path, check the native notification is shown, clicked, dismissed, and brings the intended message and window forward. Keep fallback and native behavior as distinct checks; do not infer native integration from this fallback test.

Scope: Windows notification test design.
