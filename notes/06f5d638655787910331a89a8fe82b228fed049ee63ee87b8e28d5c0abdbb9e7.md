# Drop-indicator production coordinates stay fractional while tests round comparisons

DropIndicator.show subtracts its fixed orientation correction and writes the fractional logical inset values directly. Its comment explains that rounding those values can shift the indicator with font size, density and theme. The folder browser test instead rounds measured/expected rectangle coordinates to avoid subdecimal assertion differences. Keep production positioning separate from test comparison tolerance; the 6px correction depends on the fixed12px SVG short dimension. No rendered geometry or native drag test ran.

Scope: Drop indicator geometry and assertion tolerance.
