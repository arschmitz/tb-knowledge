# Network status localization uses semantic IDs and a named host argument

Entry 1210 replaces the numeric network-properties lookup with an explicit status-code-to-Fluent-ID map. The shared C++ formatter supplies the named host argument to netwerk/necko.ftl; NNTP uses the same status meanings in JavaScript. C++ converts the host to UTF-8 for localization and the result back to UTF-16 for its caller. For these status consumers, preserve the named argument and status mapping when porting localization. This is a scoped source pattern; translation rendering and non-ASCII host display were not tested. Full bug and review discussion remains pending.

Scope: Mail network-status localization.
