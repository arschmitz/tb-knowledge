# Use an unfiltered and filtered virtual-folder pair in folder menu tests

The browser test makes an ALL virtual folder and an AND date-filtered virtual folder over the same real folder. The visibility matrix hides Mark Folder Read only for virtualFiltered. testShownItems checks both folders and also tests context clicks on a folder other than the selection. Preserve that pair when extending this menu contract; a single virtual-folder fixture cannot cover it.

Scope: mail/base/test.
