# Use the ARIA multiselect attribute as the widget state source

TreeListboxMixin reads its multiselection mode from aria-multiselectable. D203232 requested this instead of maintaining a second redundant flag attribute in markup. Keep behavior and accessibility state aligned so the widget cannot advertise single selection while acting as multiple selection. Verify keyboard, pointer, current row and aria-activedescendant together.

Scope: tree-listbox accessibility state.
