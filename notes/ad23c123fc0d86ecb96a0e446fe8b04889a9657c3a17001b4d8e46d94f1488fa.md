# Make certificate-error tests assert the meaningful error text

838 changes expired and hostname-mismatch tests to match their NSS diagnostics rather than accepting a generic rejection. Those assertions constrain the error surfaced to callers. They do not test all TLS failures, live certificate UI or server recovery. Keep the observed diagnostic in an error-path test when callers depend on it; no TLS test was run here.

Scope: Account discovery certificate tests.
