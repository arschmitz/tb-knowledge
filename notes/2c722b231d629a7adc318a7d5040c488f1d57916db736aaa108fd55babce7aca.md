# Keep the POP fallback regression case distinct from capability-only tests

test_pop3AuthMethods exercises advertised method combinations, plain-password fallback candidates and encrypted-auth failure. Its inspected cases do not independently reproduce a server that advertises PLAIN, rejects AUTH PLAIN and then accepts USER/PASS. For this regression, require a focused rejected-command transition case before claiming that the capability matrix alone proves the fix. A small cached Bug 1928026 summary describes that server behavior and a reporter confirmation, but it is not complete rendered discussion and is not used as a public quote here. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: POP authentication regression test scope.
