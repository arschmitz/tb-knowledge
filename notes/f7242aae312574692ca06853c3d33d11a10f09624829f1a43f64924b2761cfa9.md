# The calendar conflict dialog inserts a separator before both warning continuations

The conflict paragraph starts with the item-modified-on-server message. Both the modify and delete branches then append one literal space and their separate warning message through textContent. The modal caller and overwrite result remain separate from this text change. The inspected English strings need that separator; no all-locale typography or runtime behavior was tested.

Scope: Calendar server-conflict dialog.
