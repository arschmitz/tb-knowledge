# The migrator explicit old-database close runs at enumeration exhaustion rather than in Complete

The added ClearCachedHdrs and Close(false) calls are in Run after its final enumeration slice, before async message insertion. SetupAndRun has an earlier no-elements-or-enumerator-error branch that calls Complete(true) before dispatch. Complete resolves or rejects the promise and handles the savepoint; it does not perform that explicit cleanup pair. This narrows the existing migration-close lesson to its actual branch and timing. It is static source evidence, not a reproduced empty-database leak, a destructor claim or proof of cleanup on every error.

Scope: Panorama legacy migration cleanup boundary.
