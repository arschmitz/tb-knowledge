## PT.EditUrl.prototype.execute

Trigger: EditUrl facade transacts.

Requires an existing bookmark item. Captures old URI/tags. Updates bookmark URI; removes old tags only when no bookmarks remain on old URI; adds only tags missing from new URI. Undo restores old info and old tags, removing only added new-URI tags when no bookmark remains there. Redo recomputes additional tags before updating.

Result and completion: Resolves undefined after URI and tag work. Consumers of bookmark-url-changed and tagging state observe changes.

Errors: No separate error handling in this body; caller receives thrown errors or promise rejection.

Ownership and cleanup: Raw transaction retains old info, URIs, original tags and latest additional-tag set.
