# Logical chat spacing retains physical transition and bitmap names

The migrated status container uses margin-block-start when hidden but keeps margin-top in transition-property. displayStatusText sets the value and toggles that hidden attribute. Alternating bubble indicators also use logical margins and padding beside center left/right bitmap positions. These retained physical names and coordinates limit any claim that the migration converts every direction-sensitive consumer. This is an exact static source observation, not a reproduced animation or RTL defect.

Scope: chat-theme.
