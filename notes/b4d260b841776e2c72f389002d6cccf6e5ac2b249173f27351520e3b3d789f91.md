# Connect Fluent to a notification shadow root before inserting translatable content

1111 inserts its Fluent resource on first construction, connects the shadow root to document localization, then appends the cloned template; disconnect disconnects the root. The current container retains a warning that translation-affecting changes may not be reflected on reconnect. Keep this component's localization resource, root and insertion order together. The existing reconnection/lifecycle lessons remain separate; the warning is not proof that reconnect fully re-translates content.

Scope: Notification shadow-root Fluent insertion order.
