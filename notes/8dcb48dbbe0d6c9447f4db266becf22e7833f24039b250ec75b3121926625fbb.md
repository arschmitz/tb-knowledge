# The typed alert mock leaves reset and close on the legacy callback path

showAlertWithCallbacks adds a callbacks registration, but reset does not clear it and closeAlert only forwards the old observer finish topic. clickAlert can invoke both registrations. A later legacy alert after reset can therefore still reach an earlier typed callback in the mock API, and closing a typed alert does not itself call its onAlertFinished method. The changed tests call finish directly, so their source does not verify those lifecycle paths. Activity alerts use finish to resolve per-alert deferreds, with an existing certificate-alert timeout fallback. This is static local source inspection, not a demonstrated native alert or test hang.

Scope: Notification mock registration and completion.
