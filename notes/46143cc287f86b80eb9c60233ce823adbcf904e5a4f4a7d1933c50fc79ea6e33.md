# Manual configuration titles follow the incoming type and clear for other types

The manual form selects an IMAP or POP3 Fluent title from configData.incoming?.type. Other values pass no ID, so setTitle removes title-id. The observed-attribute path clears the old title’s localization ID, arguments and text before applying a replacement. Direct tests check both protocol IDs and title clearing; they do not establish rendered localization or screen-reader output.

Scope: Account Hub manual configuration title updates.
