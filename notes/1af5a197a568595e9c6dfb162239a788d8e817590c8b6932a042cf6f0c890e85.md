# The initial account-setup migration removes the legacy fallback before enabling first-run Hub

This original phase removes the legacy setup-tab fallback while retaining a !isInitialSetup and Hub-preference gate. The startup caller passes true, so that call focuses the main window without opening either setup UI. Three legacy tests are disabled. Accepted code later opens Hub unconditionally; the temporary original gate is not current first-run policy.

Scope: Account setup startup transition.
