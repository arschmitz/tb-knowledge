# Use one CSS property as the identity color value and a class as state

Identity menu items store their color in --icon-color. LoadIdentity reads that same property, and has-custom-color records whether a color decoration should exist. The accepted review avoided a duplicate color attribute and the test checks pseudo-element content=none when no decoration is expected. In this picker, lower-case dash-separated CSS property/class names describe their role, while the existing identitykey/accountkey DOM attribute contracts keep their exact spelling. Do not treat attribute, class and CSS variable spellings as interchangeable. The pseudo-element check is source-level, not a computed accessibility-tree check.

Scope: Compose CSS syntax and state naming.
