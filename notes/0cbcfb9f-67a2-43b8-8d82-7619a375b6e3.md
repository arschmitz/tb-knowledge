# Replay the active notification to late listeners

The display manager creates an immediately available event target so UI listeners can register before storage initialization. If a listener registers after a notification became active, addEventListener sends that current notification to the new listener. Preserve this behavior when moving UI setup or splitting notification modules.

Scope: in-app notification manager.

Paths:

- `mail/components/inappnotifications/modules/NotificationManager.sys.mjs`
