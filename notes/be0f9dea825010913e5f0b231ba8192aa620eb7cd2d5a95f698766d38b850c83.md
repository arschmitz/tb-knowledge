# Preserve state and contrast conditions when flattening CSS selectors

The historical flattening retains prefers-contrast and :root:not([lwtheme]) while moving replies-icon and thread-replies descendants out of an extra nesting level. Current source instead scopes the twisty border to collapsed hasUnread cards, uses SelectedItemText under prefers-contrast and lets replies text/icon color inherit; it no longer has that old theme guard in this branch. Review actual state, ancestor and media conditions when moving selectors rather than copying the old guard. This is a scoped source recommendation, with no forced-colors or contrast measurement. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Thread card selector semantics.
