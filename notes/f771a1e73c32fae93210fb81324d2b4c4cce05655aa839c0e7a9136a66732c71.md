# Linux pool selection includes task defaults and explicit transform overrides

The 33-file worker-pool migration replaces GCP-suffixed requests and updates their alias mappings. Removing a child worker-type makes that job inherit its file default; it does not remove the pool choice. The fixed macOS, Windows cross-build and clang defaults later request b-linux-docker-amd, while the langpack transform still explicitly requests b-linux. The alias config declares docker-worker and Linux separately from the pool name. A Windows target name or the migration title does not prove a native Windows host, a generic-worker backend or live pool availability.

Scope: Taskcluster worker aliases.
