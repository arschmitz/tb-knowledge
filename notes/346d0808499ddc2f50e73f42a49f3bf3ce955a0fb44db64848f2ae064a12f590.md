# Preserve local extension API and test filename mappings

In this extension family, public lowerCamel messengerSettings/messengerUtilities names map to ext-messengerSettings.js/ext-messengerUtilities.js, underscored messenger_settings.json/messenger_utilities.json schema resources, and test_ext_messenger_settings.js/test_ext_messenger_utilities.js unit files. Jar and test manifests register those exact names. Recommend retaining this local mapping rather than forcing one casing across all layers. All three utilities rename pairs were byte-identical at the landing. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/components/extensions.
