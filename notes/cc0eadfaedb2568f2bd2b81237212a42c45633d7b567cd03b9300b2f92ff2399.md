# Quote YAML wildcard and exclusion patterns and include the universe first

583 makes reference-tasks use pathspec gitwildmatch against task aliases. The package kind starts with quoted "*", then quoted negations such as "!ub22-arm64*" and the newer "!ub24-arm64*". Quoting keeps YAML from treating these as syntax; starting with inclusion gives the exclusions an actual set to subtract from. Match aliases, not an assumed single task label. This is a manual pattern-order and configuration syntax contract beyond whitespace formatting.

Scope: Taskgraph syntax and matching.
