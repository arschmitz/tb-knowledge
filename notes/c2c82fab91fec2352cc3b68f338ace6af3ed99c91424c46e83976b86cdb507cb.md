# Distinguish sort-state assertions from message-order assertions

The changed wrapper tests verify primary and implicit secondary state and its persistence after refresh, including a multi-source virtual folder. Grouped tests use actual messages because the native sort state is not saved in that real-folder test without them. These assertions demonstrate state persistence; they do not prove every resulting message order or a performance improvement. Keep row-order checks as a separate test requirement for comparator changes.

Scope: mail/base/test.
