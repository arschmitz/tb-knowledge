# The Graph move test passes an object to a zero-argument setup helper

The move-test setup calls setupBasicGraphTestServer({}), but the actual helper has no parameters and never reads arguments. The object therefore configures nothing in this phase. The reviewer questions the mismatch and the author acknowledges it; future argument support is only speculation. Accepted source keeps the same call and signature. Scope the call to the real helper contract rather than infer an options API from a neighboring EWS setup helper. No test was run.

Scope: Exchange test setup caller contract.
