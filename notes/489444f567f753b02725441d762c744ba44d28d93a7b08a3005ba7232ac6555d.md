# Remove the notification key listener from the same event target

The manager adds the keydown listener on document and removes it from document when hiding the notification, but disconnectedCallback removes it from window. This target mismatch exists both in 1111 and the fixed accepted source. It is an unresolved static cleanup concern for disconnection while displayed; normal hiding has the matching removal. No stale-listener or null-focus exception was reproduced, and the keyboard test does not cover this disconnection case. Check the actual event target when reviewing listener cleanup.

Scope: Notification document keydown disconnection target.
