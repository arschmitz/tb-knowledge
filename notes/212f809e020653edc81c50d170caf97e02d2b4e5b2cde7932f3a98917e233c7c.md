# Keep the minimal MAILNEWS error input separate from the later migration

The checked1927029 landing adds an empty MAILNEWS module with code16 and passes mail/errors.json through MOZ_EXTRA_ERROR_DEFINITIONS. It does not migrate the error members in that change. The fixed table contains later named members, so do not attribute that populated state to the original seven-line file. The Bug first proposed landing comm alone, then corrected that advice after the unknown configure-option failure and required the paired Gecko mechanism before comm landed. Configuration caching remained an author hypothesis. This study verifies the comm source and historical discussion, without newly inspecting the paired Gecko generator or running a build.

Scope: Thunderbird extra error definitions.
