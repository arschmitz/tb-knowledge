# Commands console reliability, Commit UI, task recovery, storage retention, and patch identity

Electron remains near a 4,192 MB V8 heap limit even with `--max-old-space-size=8192`; `desktop/backend-client.cjs` must launch standalone Node. `TB_DESKTOP_HEAP_MB` accepts 256–65536 MB and defaults to 8192; packaged apps use `Contents/Resources/node-runtime/node`. Verify with `v8.getHeapStatistics().heap_size_limit`, `npm run desktop:backend:smoke -- [local path]`, and `node desktop/layout-smoke.mjs [local path]`. [Task 6]

Scope: console.
