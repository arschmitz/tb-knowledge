# Do not mistake an unused preference getter for a write

754 removes getStringPref expressions whose results were ignored. Those calls only read the preference with a default and did not install that default into preferences. The patch is therefore not evidence that it removed a required preference assignment. Proposed scoped manual test rule: trace whether setup writes state, returns a consumed value or only performs an unused read before copying it. The same landing also unregisters its fake alert service during cleanup.

Scope: Mail test setup semantics.
