# Mailbox UNC host extraction searches after the leading slash prefix

The assigned mailbox patch changes FindChar from offset2 to 3 after decoding and slash normalization. For the documented triple-leading-slash form, that avoids selecting the third leading slash as the end of the host. The extracted host still passes through profile and allowed-host exceptions before qualified-host rejection. This adds the exact historical index correction to the existing scoped UNC lesson; it is not a complete path/parser/security proof. Bug context is denied and review deferred; no file or network test ran.

Scope: Scoped mailbox path extraction.
