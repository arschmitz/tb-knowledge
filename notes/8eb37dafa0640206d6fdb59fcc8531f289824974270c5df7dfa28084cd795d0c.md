# Scope shared tree styles to the root element and top-level labels

Account Manager adopts the shared tree-listbox/list-container styles and the row .container structure. list-container.css uses :is(ul, ol)[role=tree] so descendant li treeitems do not become root style owners. Account-specific bold text is limited to direct top-level labels. Collapsed twisties use :dir(rtl) with the opposite rotation; current source also keeps focus-within, forced-colors and reduced-motion branches. Reuse this structure and preserve those states when changing the tree. Shared kebab-case list-container.css and legacy camelCase accountManager.css coexist; this does not justify renaming the whole directory. Runtime keyboard, RTL, contrast and computed roles were not verified.

Scope: Tree CSS scope, naming and accessibility.
