# S/MIME local certificate checks keep result status separate from certificate usability

CheckUsageOk initializes aCanBeUsed=false, reads DER bytes, maps only signing/encryption usages and returns NS_ERROR_UNEXPECTED for an unknown usage. A failed certificate verification yields false but the method returns NS_OK; failures to obtain required bytes or verifier remain nsresult failures. The public signing and encryption methods select EmailSigner and EmailRecipient respectively. Do not treat NS_OK from this API as proof that the certificate is usable. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: S/MIME usability result semantics.
