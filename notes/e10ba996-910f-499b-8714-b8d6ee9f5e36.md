# Keep safe-mode font changes out of saved preferences

At the May 2024 UIFontSize revision, changing the font size in safe mode updated an in-memory value and registered windows, without writing mail.uifontsize. Keep temporary safe-mode state separate from a persistent preference. Bug 1893107 arose from a race in this area.

Scope: mail UI font size.

Paths:

- `mail/modules/UIFontSize.sys.mjs`
