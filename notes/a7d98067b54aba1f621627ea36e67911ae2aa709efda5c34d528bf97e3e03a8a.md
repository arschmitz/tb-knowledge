# Bulk address-book creation notifies with a directory UID and preserves other books' rows

bulkAddCards commits its batch and emits addrbook-contacts-created with a null subject and the directory UID as data. The adapter resolves that UID, skips events for an unrelated selected directory, gathers existing UIDs for that directory only and appends missing rows before a forced sort/reset. This lets All Address Books retain other books' rows. The added test directly checks cumulative rows, one reset per affected view and no per-card rowCountChanged calls; it does not measure rendering speed or force a stored-UID collision.

Scope: Thunderbird address-book bulk insertion and view updates.
