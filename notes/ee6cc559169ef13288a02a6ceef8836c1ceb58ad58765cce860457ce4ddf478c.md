# Key-wizard input validity handlers remain after the unused toggleSaveButton callback is removed

The cleanup deletes the unused toggleSaveButton callback, which called reportValidity. The existing external-key input handler still sets the accept button from checkValidity when external GnuPG support is enabled. Entering the external-key section also checks a loaded key and otherwise disables accept. These active handlers predate the deletion; the patch does not introduce a replacement validation flow or prove rendered validation behavior.

Scope: OpenPGP key wizard control validity.
