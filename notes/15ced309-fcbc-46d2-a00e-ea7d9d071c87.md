# Localize icon-button tooltip text through Fluent

D210947 first tried to add a visible search icon tooltip without a Fluent resource; review requested a Fluent ID on the button and a searchbar.ftl entry. The landed button uses data-l10n-id="search-bar-search-button" with localized Search title text. Current code keeps this path. A later post-landing review comment questioned the .alt attribute on a button, so this case does not establish .alt as the preferred accessible naming method. Check the rendered accessible name and tooltip when making a similar change.
