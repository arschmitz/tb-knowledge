# Removing the old DoH dialog controls is separate from migrating stored preferences

The removal deletes legacy TRR controls, preference bindings and custom-URL acceptance from the connection dialog. It contains no explicit stored-preference migration or reset. The replacement privacy pane binds the same mode, URI and custom-URI keys and adds default-provider/rollout state. Later mode handling can write those preferences, so UI removal alone does not prove unchanged profile values or resolver behavior. SOCKS proxy DNS remains a separate control. No dialog, profile or DNS test ran.

Scope: DNS-over-HTTPS preferences UI ownership.
