# Apply the custom-element tb- fallback only when the tag has no hyphen

The accepted custom-element guide requires a hyphen. It says to prepend tb- when the proposed name has no natural hyphen, such as banner becoming tb-banner. It does not require every naturally hyphenated tag to start with tb-. The guide also pairs the module filename with the tag and the JavaScript class with its PascalCase form. Proposed scoped review rule: apply that fallback condition and keep the tag, filename and class aligned. Existing notification and Storybook spelling is covered by separate component lessons; do not rename those families merely to add a prefix. The documented Template ID example uses a # selector prefix. That example alone does not define a new repository-wide DOM-ID casing rule.

Scope: Custom element file, class and template naming.
