# Set-message-flags replaces the flag set and does not forbid Deleted

The patch removes an assertion that the set-flags action could not contain Deleted. Current nsImapSetMsgFlags issues one positive StoreFlags call for msgFlags and one negative call for its complement. A proposed local assertion-review check is to align invariants with actual supported operation semantics and callers, rather than infer an exclusion from historical comments. This describes the set-flags action only, not all IMAP delete/expunge policy. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: IMAP flag semantics.
