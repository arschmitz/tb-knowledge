# The messages API separates saved format intent from HTML send downgrade flags

The wrapper always assigns a concrete deliveryFormat, which the draft-info serializer records. Pure plaintext forces plain flags; HTML sending resolves Auto to plain or both, while HTML saving leaves the two MIME flags at their false defaults. Tests directly inspect content type/body and deliveryformat headers, not editor reopening. The broad save-operations comment should be scoped to HTML saves. No conversion or send/save runtime result is established.

Scope: Thunderbird messages send/save format handling.
