# Commands Thunderbird/Firefox desktop onboarding and guided setup

`desktop/setup-runner.cjs` uses fixed executable/argument arrays, checks Git/Python, clones Firefox plus Thunderbird, writes `ac_add_options --enable-project=comm/mail`, and runs `mach bootstrap --application-choice browser`. Artifact mode only adds `ac_add_options --enable-artifact-builds`; it must not select an artifact-only bootstrap. Preserve existing non-generated `.mozconfig`, completed clones/configuration, setup locks, and interrupted-run recovery. [Task 3]

Scope: general.
