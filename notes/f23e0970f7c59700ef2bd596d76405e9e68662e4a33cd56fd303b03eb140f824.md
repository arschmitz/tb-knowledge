# Allow resizing the last visible resizable column only when scrolling permits it

Without horizontal scrolling, the final visible resizable thread column absorbs layout width and its splitter is disabled. With scrolling, the final visible resizable column can resize. Columns explicitly marked non-resizable remain excluded. The accepted #updateView code distinguishes the last visible column class from the last visible resizable column splitter; hidden columns are excluded. Preserve those two conditions when changing column setup.

Scope: mail/base/content.
