# The hidden-recipient display test covers the Alice fixture rather than distinct key passwords

The added task opens the Alice hidden-recipient fixture and asserts its body text, no signed icon and an encrypted-ok icon. The source does not explicitly create several differently protected keys or assert the per-fingerprint password choice, cancellation, failure cleanup or used-recipient key-ID display. Those are separate coverage limits even though the implementation loops over candidates. Static fixture identity and test assertions do not establish a successful crypto run.

Scope: OpenPGP hidden-recipient browser-test scope.
