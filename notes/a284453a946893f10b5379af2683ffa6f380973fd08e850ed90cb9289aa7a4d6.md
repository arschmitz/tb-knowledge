# Rust constructor visibility and native registration are separate source contracts

The outgoing constructors become crate-visible while retaining unsafe(no_mangle) and extern C. The inspected native header and component registration still name the EWS and Graph constructors. These separate declarations support a bounded name/receiver check. They do not establish successful linking, a compiled ABI guarantee or that every caller is unchanged.

Scope: Exchange Rust native constructors.
