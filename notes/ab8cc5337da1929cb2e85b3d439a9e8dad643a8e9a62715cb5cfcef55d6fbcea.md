# Default-handler setup finishes selected associations before returning

The NSIS helper records that it can return, then still processes subsequent requested associations before the final return check. This preserves combined requests such as mail/calendar and the new custom-link type. GNOME separately loops URI schemes and performs optional MIME/extension registration once afterward. These are exact per-platform ordering contracts, not evidence that registration succeeded or a general loop/return style rule.

Scope: Native shell registration ordering.
