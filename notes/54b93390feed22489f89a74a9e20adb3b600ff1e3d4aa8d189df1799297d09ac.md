# Native search-input migration must carry receiver, event and clear-control contracts together

The historical change replaces custom moz-input-search instances with native type=search inputs and removes the shared search-bar clear-button slot and DOM button. Native clear appearance is styled through ::-moz-search-clear-button. Downloads moves search dispatch to an input listener, and subscription code switches to the native value property. The current shared widget still has its own reset/Escape and autocomplete behavior, so native markup does not replace every wrapper contract. Removed DOM-button tests and Fluent labels are not proof of native control focus or labeling. Static source, CSS and written reset/Escape assertions were inspected; no UI, platform, keyboard or accessibility test ran.

Scope: Thunderbird native search control migration.
