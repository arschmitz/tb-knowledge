# The shared banner template overrides the messenger body's XUL default namespace

The messenger body uses a XUL default namespace and includes the Account Hub template chain, which includes tb-banner.inc.xhtml. The banner include uses html:template and an explicit XHTML default namespace for its descendants. TbBanner.connectedCallback then clones template.content. Keep both the actual include context and the receiver's HTML-template contract in scope when changing this shared markup. The isolated Exchange fixture supplies a separate template under an XHTML root; this patch adds no direct production-include namespace assertion. This is static source inspection, with no browser or accessibility run.

Scope: mail/base/content/widgets.
