# RSS row status updates precede the deferred favicon assignment

setFolderPropertiesFromFolder applies RSS status datasets before waiting for document load. Only the single-feed page-icon assignment is deferred when readyState is not complete. Existing setServer/setFolder callers do not await the helper, so their return does not promise favicon completion; even the helper's completion means style assignment, not image loading. The source comment records the load-group rationale. No isolated failure or cure was reproduced.

Scope: Folder-tree RSS initialization.
