# Thundermail upload steps request a close control that the template does not render

FileUploadTemplate declares showCloseButton and the close event, but its inspected render function does not use them to create a close control. PasswordStep and ExpirationStep pass show-close-button=true and bind onClose. Those declarations and bindings do not provide the requested control. SuccessStep has a separate primary Close action, so this finding is limited to the missing template close control. No live keyboard or accessibility result is claimed.

Scope: Thundermail generated upload template and step callers.
