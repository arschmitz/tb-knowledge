# The database commit marker records the requested mode before compression promotion

The database profiler patch adds filename and requested commit mode to a scope-bounded marker after review asks for that context. Commit creates markerDetail before ShouldCompress may change a large/session request into a compression commit, so the text does not necessarily name the final storage operation. OpenMDB similarly marks its function scope, including its asynchronous setup path, rather than proving all later asynchronous work finished. No profile or performance run was made.

Scope: Message database profiler scope.
