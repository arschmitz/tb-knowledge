# StringFields uses five explicit ASCII delimiter bytes

The delimiter predicate contains SPACE, TAB, LF, FF and CR. It skips runs of those bytes and returns nonempty nsCString fields. Vertical tab and non-ASCII whitespace are not delimiters in this implementation, despite the broad ASCII-whitespace wording in the declaration comment. The new test directly compares eight literal input/output cases, including multibyte words, and its one assertion omits an explicit behavior message. No delimiter or GTest execution was performed; this is a scoped implementation/test limit, not a new global whitespace rule.

Scope: MailNews StringFields and exclusion preference parsing.
