# additional_properties.readOnly annotates Settings documentation without changing runtime access

The annotation README defines additional_properties.readOnly as metadata for documenting types.Setting: show get(), omit set() and clear(). It is not the JSON Schema additionalProperties keyword. The owned patch adds this metadata for selected browser, messenger and privacy setting names while keeping compatibility annotations separate. In the actual comm messengerSettings consumer, the original three settings already pass readOnly:true to imported getSettingsAPI; their production schema already describes them as read-only. No runtime API or permission code changes here. The accepted source also has a separate later writable composeInlineSpellCheckEnabled setting. The external generator and Gecko helper/type bodies were not read or run, so generated output and enforcement are not independently verified.

Scope: WebExtension Settings annotation data and comm API consumer.
