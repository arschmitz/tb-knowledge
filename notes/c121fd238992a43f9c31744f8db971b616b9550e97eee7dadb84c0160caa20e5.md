# Make the OAuth scope assertion prove the claim in its message

The accepted Exchange-config test says the EWS.AccessAsUser.All scope should be present, but its assertion checks for the outlook.office365.com origin substring. That assertion does not distinguish the EWS grant from other scopes at the same origin. Proposed manual test rule: check complete scope tokens when claiming a protocol permission, and make the assertion message describe the predicate actually used. This narrow mismatch does not establish a failing login or invalidate the separate provider implementation.

Scope: Account scope test precision.
