# Declare a write status where its checked lifetime begins

The flowed-text patch removes an unused outer status and declares int status at the first MimeObject_write whose result is checked. The same local value is then reused for the output write and returned. Recommend that narrow lifetime in this function instead of unrelated initialization far above its first use. This is a scoped manual variable-lifetime pattern, not a rule to remove every existing shared status variable. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mailnews/mime/src.
