# Thunderbird Calendar create/edit attribute-driven source loader

In D321284 draft state, `updateSection` computes dirty status from supplied patch keys. Its callers must supply every property for the section: omitting a changed property can leave `dirtySections` falsely empty. Preserve that current contract, document it, and cover a start/end value that stays dirty until both values return to baseline. [ad-hoc note]

Scope: calendar.
