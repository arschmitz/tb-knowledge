# Remove a temporary store bridge across its interface and both native stores

469 removes the temporary JS sliceStream bridge from nsIMsgPluggableStore.idl, nsMsgBrkMBoxStore and nsMsgMaildirStore together. It also removes the obsolete substring/EOF unit case and registration for each store while retaining asyncScan tests. Fixed accepted public IDL, both native store files and the store interface test have no sliceStream/SliceStream identifiers. Current getMsgInputStream takes a store-dependent storeToken and aMaxAllowedSize, with zero streaming all available data. Preserve those active reader contracts when editing the stores. The old bug describes the bridge as a step during mbox encapsulation; its linked dependencies were not read. No xpcshell or stream-runtime check ran.

Scope: mailnews/local.
