# Keep comm and Gecko source identities distinct

Current gecko_source.configure sets MOZ_COMM_SOURCE_REPO/CHANGESET from comm_source_repo and MOZ_GECKO_SOURCE_REPO/CHANGESET from gecko_source_repo. The generic MOZ_SOURCE_REPO/CHANGESET options are implied from the comm values. Keep repository and revision paired, and do not swap comm and Gecko identity when porting configure code. The Python names use the local snake_case family; the external MOZ_* option names remain uppercase contract names. The 2024 packaging failure motivated this boundary, but no build validation was run here.

Scope: Source identity and configure naming.
