# Attach warning accessibility state to the native select inside the host

The historical forms used XUL menulists; the accepted control wraps a native select in a shadow root. AccountHubSelect sets aria-invalid and aria-describedby on that internal select, while the warning paragraph has role=alert. Tests inspect the shadow warning and native label association. Preserve that internal target when editing the host component. Live announcements and screen-reader behavior were not checked. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/components/accountcreation.
