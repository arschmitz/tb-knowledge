# MIME service guards retain different failure and output contracts

The missing-MimeConverter fix uses each caller return contract. The encoder returns nullptr, search matching returns NS_ERROR_FAILURE before assigning its Boolean output, and the void MIME_DecodeMimeHeader wrapper clears its output reference. The historical mailbox parser returns a partly collected RawHdr before later recipient merges. These are different failure values and state effects, not universal empty-string recovery or atomic rollback. Newer source has replaced some old helper APIs; keep their phases distinct. No shutdown crash or MIME test ran.

Scope: Native MIME converter caller failure boundaries.
