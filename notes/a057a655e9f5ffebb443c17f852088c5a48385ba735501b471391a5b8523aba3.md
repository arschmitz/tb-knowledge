# Reserve terminator slack after MIME newline conversion

The accepted line-buffer code reserves two bytes because terminator conversion can grow a line by one and still needs a trailing NUL. convert_and_send_buffer then re-terminates after conversion before calling the typed line callback. Preserve both the allocation slack and the post-conversion terminator when changing this buffer path. This is later accepted source context for 826, not evidence that the 2024 sanitizer patch introduced those bounds fixes or that they were executed here.

Scope: mailnews/mime/src.
