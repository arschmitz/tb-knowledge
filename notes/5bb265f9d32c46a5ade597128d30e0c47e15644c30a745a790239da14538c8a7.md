# Tab selection presence selectors follow the comm widget attribute mapping

The tab port replaces selected/visuallyselected="true" comparisons with presence selectors in its tab-specific styles. Comm maps .tab-line selected from the tab’s visuallyselected attribute, so the appearance test now queries .tab-line[selected]. Other control attributes keep their own contracts. The upstream tab producer and inheritance engine are unpaired; this is a local consumer/mapping observation, not a global boolean-attribute or rendered behavior guarantee.

Scope: Tabmail selected-state CSS and child attribute mapping.
