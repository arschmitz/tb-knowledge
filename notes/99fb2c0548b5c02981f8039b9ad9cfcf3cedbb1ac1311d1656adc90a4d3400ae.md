# Current aggregate headers skip empty values before inserting separators

Accepted aggregation continues past zero-length entries and adds a comma only when the buffer already contains data. This differs from a delimiter based only on the original array index. Preserve the empty-entry behavior when changing malformed-recipient handling; the crash fixture does not assert the final To/Cc semantic values. This is static source and test-code inspection.
