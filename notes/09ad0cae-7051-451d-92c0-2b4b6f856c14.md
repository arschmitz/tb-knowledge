# Keep extension quick filter state aligned with the visible search input

After the Quick Filter Bar changed from a XUL textbox to an HTML input in shadow DOM, mailTabs.setQuickFilter could filter messages while the search box stayed empty. The accepted fix uses SearchBar.overrideSearchTerm and reflects filter buttons and visibility, then updates the search. overrideSearchTerm refuses to replace a nonempty focused input while the user types; the extension path retains the prior term in that case. Review explicitly kept this restriction and deferred a possible follow-up.

Scope: Quick Filter Bar extension API.
