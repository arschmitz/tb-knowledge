# Remove dead weak references while searching the OAuth2 object cache

The accepted in-memory OAuth2 cache stores WeakRef objects. Lookup calls deref and removes dead references before checking live objects. Preserve this cleanup when changing cache traversal; a dead wrapper is different from a live object that fails the identity or scope checks. Those live reuse conditions already have a focused note. This is the existing cache lifecycle and a scoped manual recommendation, not a policy for all authentication caches. This is static source inspection only. No runtime, build, lint or live accessibility validation ran. Full Bugzilla and Phabricator discussion remains pending.

Scope: OAuth object cache identity.
