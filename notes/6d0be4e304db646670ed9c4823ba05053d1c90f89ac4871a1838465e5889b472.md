# Matrix package names, resource paths and index modules form a loader contract

The Thunderbird Matrix loader translates SDK package paths with hyphens into packaged resource paths with underscores. crypto-api maps to matrix_sdk/crypto_api, its index path is listed in KNOWN_INDEX_JS, and moz.build packages crypto-api/index.js into that resource namespace. The SDK update changed all three integration points. The custom require hook retries index.js only on the first require failure; rethrown prevents nested failures from becoming unrelated fallback attempts. Manual naming proposal for this integration: update upstream import spelling, destination resource namespace, packaged files and index resolution together. This is a Matrix loader constraint, not a Thunderbird-wide preference for underscores. Bulk SDK code does not establish Thunderbird syntax style.

Scope: matrix-loader.
