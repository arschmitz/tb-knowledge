# About-dialog spacing applies to the conditional update-notes link

The CSS adds updateNotes to the releasenotes group with margin-inline-start:0.5em. The checked markup places updateNotes after downloadAndInstallButton, while updateButton is in a different panel. The updater assigns and unhides the link only in the selected download panel’s non-a-number version branch. This is scoped logical link spacing, not a global button or row-gap change. No rendered, RTL or accessibility check ran.

Scope: About dialog update layout.
