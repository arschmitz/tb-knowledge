# Keep notification launch alive through the asynchronous message lookup

A Windows native notification can start Thunderbird without a normal window. Enter the last-window survival area before asynchronous tag lookup and leave it in finally when the lookup settles. Current success with tagWasHandled=false opens the fallback3pane; a rejected lookup logs the error and still releases the survival guard, without proving a window opens. Entry307 prevents shutdown while the pending callback needs services. Installation-level cleanup spans profiles. The notification-launch path checks native alert service availability. No Windows runtime was run. Correction to earlier lesson 5dff69919ed2f9971c13c254e2bb5c6480aa8040f30761b0d6d3bd000795a941: the newer accepted source above narrows or replaces that claim.

Scope: Windows notification lifetime.
