# TreeView owns selection lifecycle while BaseTreeView owns display rows

The display-only base attaches a view and creates buffered rows without creating TreeSelection. TreeView clears prior view/selection links, allocates the selection model and decorates returned base rows. Its row-count handler adjusts selection, while the base handler invalidates display rows. The renamed row-creation hook returns a node for the subclass. Checkbox rows use native input controls without needing row selection. These are local source contracts; no selection/focus or accessibility run was performed.

Scope: Display-only and selectable tree ownership.
