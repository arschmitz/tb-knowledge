# Tree selection mutates the Set exposed by its getter

The Map-to-Set change stores row elements and mutates the same private Set through add, delete and clear. Shift selection finds both row positions in the current visible array before adding its slice. The selection getter returns that live Set; the checked folder-command consumer takes an array snapshot of its values. Preserve collection identity when reasoning about other getter consumers, and distinguish that contract from index lookup. Pruning and collapse promotion update selection without replacing the Set. No benchmark or executed interaction was performed.

Scope: Tree-listbox selection identity.
