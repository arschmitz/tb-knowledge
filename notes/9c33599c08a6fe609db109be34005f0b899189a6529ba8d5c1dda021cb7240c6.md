# Pass the S/MIME fixture password to the import helper rather than the File constructor

The small browser-test fix moves nss from new FileUtils.File(...) into the second argument of SmimeUtils.loadCertificateAndKey. That helper forwards file,pw to importPKCS12File; the old one-argument helper call supplied undefined as pw. This is argument placement, not a JavaScript grammar correction. Its exact backout restores the old call; later merged setup again passes both arguments separately. No import was executed.

Scope: S/MIME setup argument ownership.
