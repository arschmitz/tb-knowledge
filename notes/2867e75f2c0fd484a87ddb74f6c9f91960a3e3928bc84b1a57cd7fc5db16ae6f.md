# Initialize aggregate header outputs before the allocation can fail

Entry865 sets outHeader length to zero and value to nullptr before attempting PR_CALLOC. Successful allocation fills both fields. This makes empty input and allocation failure produce a coherent empty result. Its header parser also assigns both pointer and length on the valid branch. The earlier851 attempt omitted that length assignment and 855 backed it out; the exact failure discussion remains unread. The accepted aggregate representation now uses caller-owned strings, documented in an existing lesson. Preserve related output fields on failure when refactoring this code; this historical allocation example does not recommend restoring the obsolete allocator or prove a crash was fixed.

Scope: Aggregate header failure outputs.
