# Keep Mach diagnostics on stderr when command output is useful data

1109 adds setup_logging, which replaces the terminal handler with stderr while preserving the old formatter's interval/timestamps and enabling unstructured log messages. The release subcommand prints its composed body separately. Follow this helper's output split for commands whose stdout can be redirected. No logging run was performed.

Scope: Mach logging output-stream convention.
