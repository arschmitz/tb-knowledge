# The Graph filter API stores one bounded expression before URL encoding

Filter-capable requests store one FilterExpression; setting another replaces it. The expression grammar is Eq with boxed And/Or, using null/string/Boolean/i64 operands. Identifiers accept only a bounded ASCII subset; string Display doubles apostrophes before request serialization encodes the query pair. Four source tests make five assertions for selection, nesting and request URIs, all without expected-behavior messages; invalid identifiers, apostrophes and replacement are not directly tested. The macro calls a const-capable validator but does not itself force const evaluation. This is neither full OData nor real-endpoint property validation. Current generated requests retain the filter and add later options.

Scope: Graph OData filter construction and limits.
