# gDBView reads the current wrapper through a shared getter

mailCommon installs an enumerable, non-configurable gDBView getter that returns the current gViewWrapper?.dbView. Owned consumers remove manually maintained gDBView assignments and use that live accessor. Some changed optional guards also handle an absent dbView, so the patch is more than a spelling alias. The scoped ESLint restriction has a getter exception and a separate Calendar-test override. No setter, native-transition or future Panorama behavior was verified by execution.

Scope: Mail privileged-script current DB view accessor.
