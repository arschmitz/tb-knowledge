# Compose menu shortcuts must match their platform-specific key definition

key_renameAttachment is defined only in the non-macOS key branch. The menu item therefore excludes its key reference on macOS while retaining cmd_renameAttachment. Action availability and shortcut metadata are separate. The matching declaration and consumer guards support this local markup contract; they do not establish a universal shortcut naming rule or prove native keyboard accessibility. No attachment or platform test ran.

Scope: Compose key references.
