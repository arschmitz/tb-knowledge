# The modified UTF7 converter uses a per-call scratch buffer

CopyUTF16toMUTF7 changes its 100-byte scratch array from static storage to a per-call local array. Its converter is also local, while aDest remains caller-owned and receives appended output. This removes that one shared writable buffer, not every possible shared state or caller race. Accepted later progress and output-length guards are a separate phase. No TSAN or conversion test was run; primary comment 2 is unavailable.

Scope: Mail folder-name conversion shared state.
