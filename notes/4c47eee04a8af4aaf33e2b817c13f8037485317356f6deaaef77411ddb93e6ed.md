# MIME line buffering uses the signed cursor type declared by its caller

The implementation includes its own header and changes the cursor pointer to int32_t*. The existing declaration and MimeObject input cursor use that type, and the real parse-buffer caller passes the field address. The patch also removes unsigned casts in two boundary comparisons. Accepted source retains this agreement but has later CheckedInt growth and two-byte slack. Type agreement alone proves no negative-input validation, overflow safety, native ABI or runtime result.

Scope: MailNews MIME line-buffer type contract.
