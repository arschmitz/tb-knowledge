# Exchange star completion ignores the successful remote ID subset

Rust calls the star success listener with IDs from successful responses, then returns an aggregate error if other responses failed. ExchangeFolder's callback ignores that ID argument and marks every captured requested header. A partial success can therefore update failed requested headers locally, with no rollback in this path. After an all-success return, generic DoOperation also calls success with an empty ID payload, while the same callback still visits the captured headers. The one-message command test does not cover either boundary. These are static paths at the fixed revision, not reproduced failures.

Scope: Exchange star callback selection.
