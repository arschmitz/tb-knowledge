# The key-trust predicate JSDoc differs from its match-result return value

isExpiredOrRevoked is documented as returning Boolean, but it returns the result of one String.match call or another. The actual value is a match Array or null. Preserve that distinction when documenting or changing the helper; this study makes no implementation change or global Boolean-style rule.

Scope: OpenPGP trust helper return documentation.
