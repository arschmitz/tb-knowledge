# Draft and template actions survive through the common command map

The four removed header wrappers forwarded to _composeMsgByType. Current mainCommandSet sends the same command IDs to goDoCommand, while mailCommon maps them to Draft, Template, EditTemplate and EditAsNew. doCommand first checks isCommandEnabled and then uses the mapping. The draft and template gates require selected messages and the relevant special folder. Keep the command ID, type and gate together; wrapper removal is not feature removal. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: mail compose command dispatch.
