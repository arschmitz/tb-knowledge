# JavaScript token awaits and native folder authentication keep different completion contracts

The JS authorization functions await logout then login before returning token.isLoggedIn. Native folder authentication remains a synchronous Boolean routine that directly checks/authenticates an NSS slot, and its folder callers stop on false. The commit prose describes a Promise/spin-loop bridge that the final source does not contain. Keep those actual receiver/completion paths separate; no native callback, responsiveness, OS-auth or crypto result was executed or paired.

Scope: Primary-password async token API port.
