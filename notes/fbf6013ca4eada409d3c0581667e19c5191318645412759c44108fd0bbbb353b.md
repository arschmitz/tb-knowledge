# IMAP folder-move completion clears copy state before starting the next move

The folder-move completion branch keeps the source and arrival folder alive, clears m_copyState, then calls NotifyCompletion. That method directly calls DoNextCopy, which can enter CopyFolder and InitCopyState for the next queued move. InitCopyState requires the old state to be absent. The regression test queues three same-server moves before awaiting them and checks both destination presence and source absence. This is static ordering and assertion coverage, not a runtime result.

Scope: Thunderbird IMAP queued folder moves.
