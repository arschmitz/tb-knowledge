# SetComposeDetails replaces document-element HTML and resets caret and undo state

For an HTML body string, the compose-window setter assigns editor.document.documentElement.innerHTML, moves to the beginning of the editable document and clears undo/redo before setting bodyModified. It rejects HTML for a non-HTML editor and rejects simultaneous HTML/plain-text strings. The extension caller preserves the current editor format before using this setter. This is a specific full-document replacement and local lint exception, not general innerHTML permission, sanitization proof, or a caret/undo test result. The later C++ editor removal and test delay are separate changes. No compose or test ran.

Scope: Compose HTML replacement contract.
