# External OAuth returns focus before releasing its weak source-window reference

Success and failure callbacks request focus before cleanup clears the weak source-window reference. The helper preserves any active app window, otherwise uses the weak target or most recent window and calls restore/focus. Local tests check minimized and retained-focus scenarios, not a real provider/system browser or all OS focus policies. Missing messages and end-of-task-only restoration remain test limits.

Scope: OAuth external request focus lifecycle.
