# The folder interface distinguishes local deletion from requesting deletion

propagateDelete and recursiveDelete explicitly document local deletion without a server request. Their checked base implementation walks child links and can delete local storage. deleteSelf has a different documented contract that can involve Trash, confirmation or deferred completion. Callers must choose the required operation; this source study does not audit every backend override or prove remote deletion.

Scope: Folder deletion interface contracts.
