# Match the spam visibility wait to the ancestor row state

The junk-controls test follow-up polls whether the spam button is visible instead of observing attributes only on that button. Current CSS derives display from the parent row data-properties junk/notjunk state, so changing that CSS input need not mutate the button attributes. The selected current task retains the visibility predicate and classification assertions. This is a scoped receiver/state mismatch, not a rule against mutation waits. The earlier reviewer suggestion and later correction remain separate; no runtime failure or BrowserTestUtils implementation was independently tested.

Scope: Junk-controls test visibility receiver.
