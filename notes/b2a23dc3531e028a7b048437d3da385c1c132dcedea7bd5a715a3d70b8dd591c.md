# The Account Hub selection comment still describes the old full observer rebuild

The patch changes the mutation callback to updateElement for each record, while slotchange still calls observeAssignedNodes and rebuilds cloned options. Its new reconciliation comment nevertheless says the observer replaces all options. The accepted code keeps that stale description. Scope the reason to the actual rebuild path and keep it separate from incremental attribute copying; the four-case prose does not by itself prove native selection behavior.

Scope: AccountHubSelect comment and control-flow agreement.
