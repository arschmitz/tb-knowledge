# Tree row index changes are coalesced until the next animation frame

1353 changes row filling from synchronous index assignment to one scheduled animation frame. Accepted index setters retain only the latest _index and avoid scheduling another frame while one is pending; the callback skips detached rows. fillRow cancels a pending frame when forced immediately. Preserve the separation between index assignment and rendered content, rather than assume an index setter has finished all DOM/label work. This is static source and test-code inspection.
