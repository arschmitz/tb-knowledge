# Account Hub option synchronization must preserve attribute removal as absence

The original incremental handler sends target.getAttribute directly to clone.setAttribute. When the source attribute is absent, this does not remove the clone attribute; the null value is converted to text. Fixed accepted code instead checks hasAttribute and calls removeAttribute for that case. This distinction matters for presence-based attributes such as selected. The source trace identifies the later repair; no selection or discovery failure was reproduced.

Scope: AccountHubSelect incremental mutation phases.
