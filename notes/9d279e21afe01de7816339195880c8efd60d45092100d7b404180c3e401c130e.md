# Treat granted OAuth scopes as token state, using exact scope tokens

The token response can contain scopes different from those requested. OAuth2 splits and stores the returned scope list and compares exact entries; its Microsoft endpoint compatibility adjustment adds offline_access when the returned list omits it. Keep granted scope state separate from requested permissions. The historical accountSetup Google-discovery code is absent in current source and is not a current implementation recipe.

Scope: mailnews/base/src.
