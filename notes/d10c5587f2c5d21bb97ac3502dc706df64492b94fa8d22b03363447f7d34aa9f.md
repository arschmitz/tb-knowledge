# The legacy folder scanner is separate from the alert renderer

The cleanup removes parseFolder and its virtual-folder scanner dependency. The retained render method takes a real folder and already selected message keys; the alert supplies those keys and its own display limit. The original and accepted callers use this separate rendering API. Removing the unused scanner is distinct from the shared Bug's later translation, alert-role and screen-reader changes, with no fresh notification result.

Scope: New-mail folder summary widget.
