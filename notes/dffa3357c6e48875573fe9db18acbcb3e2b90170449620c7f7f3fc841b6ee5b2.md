# Use source stream failure status for IMAP offline recovery policy

The accepted ImapOfflineMsgStreamListener forwards OnStopRequest, retains its return as rv, clears and closes the channel, then gates DiscardOfflineMsg on the incoming stream status and mail.discard_offline_msg_on_failure. The destination callback result is a separate value and is returned after the recovery check. Keep the source-status versus consumer-return distinction in this path. Shared knowledge already covers the moved preference boundary, metadata invalidation and mbox safety. This source does not promise an immediate retry or reproduce a failed read. This is static source inspection only. No runtime, build, lint or live accessibility validation ran. Full Bugzilla and Phabricator discussion remains pending.

Scope: Offline failed-read recovery policy.
