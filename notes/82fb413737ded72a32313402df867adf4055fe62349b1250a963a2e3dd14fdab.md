# Crypto icon rendering uses both retained status values

The accepted S/MIME refresh converts both saved global states after an accepted signature or encryption update. OpenPGP also retains each nonempty result and passes both strings to the common renderer. The renderer recomputes the combined signature visibility. The original landing keeps raw OpenPGP secureMsgLoaded telemetry values separate from this display choice; that historical event block is not asserted to exist at the fixed accepted revision. No event ordering or crypto completion was exercised.

Scope: Message crypto header state.
