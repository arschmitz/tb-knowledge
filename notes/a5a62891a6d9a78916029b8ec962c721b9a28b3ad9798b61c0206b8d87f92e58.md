# Do not shadow the scan status needed after an inner pump block

The accepted MboxScanner OnStopRequest stores Continue status in an outer rv, then declares another rv while creating/starting the next pump. The later outer failure check does not observe an inner pump failure. Recommend one explicit status path when modifying this continuation, with a test for pump-creation or AsyncRead failure. This is a scoped static concern; no hang or callback omission was reproduced. This is static source and test-code inspection.
