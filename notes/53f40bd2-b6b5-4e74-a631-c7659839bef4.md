# Preserve tests for surviving behavior when removing a contact option

D210886 initially removed too much test coverage while deleting the per-contact flag. Review required tests of the global preference to stay, and corrected the summary because PreferDisplayName was a contact property rather than a vCard field. The landed browser test changes card.displayName to exercise fallback to full name plus email when a known card has no display name; the unit test still checks version increments. When retiring a setting, remove tests for the retired state but retain tests for global policy, no-value fallback, and cache updates.
