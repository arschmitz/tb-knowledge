# Refresh auto-form completion when navigating back

Entry 1492 exposes checkValidEmailForm so the controller can call it when returning to the auto-config step before focusing the appropriate input. Current code recomputes name/email validity and emits config-updated again. The forward button must reflect the restored form rather than completion from the later invalid manual step.
