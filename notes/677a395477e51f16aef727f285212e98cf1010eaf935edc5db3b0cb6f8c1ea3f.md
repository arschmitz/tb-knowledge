# The Thundermail URL test obtains its saved login through a simulated authorization round trip

After the setup URL loses its token parameter, the test registers an external authorization URL watcher before clicking Continue, then calls submitOAuthURL with the expected scope and fabricated credentials. The helper intercepts external protocol loading and emulates form submission plus a controlled callback or HTTP redirect. Only afterward does the test inspect the saved login and account fields. This source covers the mock authorization path, not a real external browser, provider or cryptographic validation. The shared PKCE-method equality also needs a nonempty expectation message; the existing field/error diagnostic finding is reused separately. No browser test ran.

Scope: Thundermail setup browser-test contract.
