# ConversationView disconnects its own localization root on removal

ConversationView creates its own DOMLocalization and connects the newly created shadow root during the first connectedCallback. Its disconnectedCallback disconnects that same root. This is a scoped ownership pair for this component, not proof of all listener cleanup or reconnection after reinserting an existing instance; connectedCallback still returns when a shadowRoot exists. The patch changes no tests, and no leak or UI check ran.

Scope: Conversation view localization lifecycle.
