# Certificate-check updates its exception state only after confirmed dialog closure

The widget opens the existing exception dialog and tracks its outcome through params.exceptionAdded. It ignores unrelated window closures, closes the dialog when its opener closes, and removes the observer on the dialog close event. UI state and telemetry change only after a confirmed result. The test arms its dialog promise before clicking and then checks the stored override and UI; cancellation and opener-first closure remain separate coverage.

Scope: account certificate-check exception dialog.
