# Tree-listbox repeat defers select notifications while keeping selection state current

A repeated navigation key sets a flag that suppresses select dispatch from row updates while classes, selection attributes and scrolling still update. The next keyup or blur clears the flag before dispatching; the first nonrepeat event stays immediate. The regression checks Down/Up event counts and Home/End positions, but not Page keys, blur, accessibility output or rendering latency. One new selected-index assertion lacks its message. No keyboard or browser test ran.

Scope: Tree-listbox keyboard repeat and select event delivery.
