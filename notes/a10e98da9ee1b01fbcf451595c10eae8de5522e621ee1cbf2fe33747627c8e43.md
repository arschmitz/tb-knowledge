# Removing the EWS rollout gate keeps account choices configuration-driven

The rollout preference removal calls native EWS conversion without a preference check, but conversion still requires an Exchange configuration. Accepted code keeps the missing-Exchange return and uses a later add-on option to add or replace that configuration. The found-config widget shows a protocol only when it is the incoming type or an available alternative; including EWS in its label list does not make every account offer EWS.

Scope: ews-account-configuration-choice.
