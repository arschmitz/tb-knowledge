# Search-dialog action dispatch follows the Fluent ID rather than translated button text

Mail Search/Stop handlers compare data-l10n-id with search-button; address-book handlers use ab-search-dialog-search-button. Mail search status updates switch the Fluent ID and pass the result count. Reset removes the status localization ID before clearing the value, and address-book search does the same before a new search. These are local state contracts; the address-book stop handler remains empty.

Scope: Mail and address-book search dialogs.
