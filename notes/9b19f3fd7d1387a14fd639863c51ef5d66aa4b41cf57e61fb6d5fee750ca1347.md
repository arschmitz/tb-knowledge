# Separate Account Hub service discovery from connecting selected services in message IDs

The localization migration names sync-accounts-found, sync-accounts-not-found and sync-accounts-failure separately, and current text distinguishes finding services from connecting selected services. Proposed manual naming rule for this notification family: name the actual stage and outcome, rather than a generic sync success/failure pair. The matching current strings show the distinction; they do not prove a new global localization convention was approved. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub service-stage Fluent names.
