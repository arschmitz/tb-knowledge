# Non-shippable localization tasks explicitly use five locales per chunk

Entry 1458 sets locales-per-chunk to 5 for non-shippable localization. The accepted kind retains that value. The author reports that localization takes too long without chunking, but this source study has no timing measurement. This is a scoped task-size configuration, not a recommendation that five is a universal optimum. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Non-shippable localization task sizing.
