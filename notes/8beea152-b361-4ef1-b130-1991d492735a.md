# Current compaction stages both files before the database handoff

The 2024 patch finished a safe output stream before notifying its folder listener and treated OnCompactionComplete errors as too late to abort. Bug 1925117 found a crash window when the live summary database changed before the mbox swap. Current code stages compacting and compacted files, moves originals to backups, calls OnCompactionComplete as the last abort point for database work, then installs the new mbox; OnFinalSummary reports final status. This improves recoverability but mbox and .msf are still not an atomic pair. Use current callback semantics when implementing or reviewing compaction, and inspect both staged files after interruption.

Scope: Folder compaction recovery.
