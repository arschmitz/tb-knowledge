# Removing the Skype preset preserves IMPP input through Other

The Skype change removes its preset from the IMPP selector. The existing component matches a stored/entered scheme to the remaining options and falls back to Other; it then applies that option pattern without rewriting the input value. This is a selector change, not contact-data migration or a generic URI-validation repair. The existing accessible labels remain. No contact edit/save or UI test ran.

Scope: Address-book instant-messaging editor.
