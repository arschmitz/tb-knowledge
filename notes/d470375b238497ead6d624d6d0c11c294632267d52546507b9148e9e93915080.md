# Keep Account Hub text clipping separate from list scrolling

The current sync list has a zero minimum inline size, bounded normal block size, a scrolling inner container and ellipsis on option text. The outer stacked state removes the fixed block size. Recommend retaining these separate size, overflow and text roles for this list rather than clipping the whole form. No large-font, narrow-window or translated render was run here. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
