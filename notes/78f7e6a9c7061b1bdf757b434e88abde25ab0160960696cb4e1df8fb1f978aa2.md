# Recheck queued custom mail alerts against current folder state

The custom alert queue stores folders rather than a frozen payload. When an alert finishes, the next folder recomputes eligible keys and skips itself if no NEW eligible keys remain. Candidate selection ignores non-Inbox SpecialUse or Virtual folders and tests watermark eligibility rather than raw new count alone. Preserve that replay-time check when changing queue behavior. This does not prove that every concurrent filter or folder deletion is handled. These conclusions come from static source inspection. No runtime test or accessibility session was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Custom mail alert queue lifecycle.
