# Scope the mica backdrop opt-in to the declared window

The 1783 platform port adds windowsmica=true to the main messenger window, and the accepted declaration still has that attribute. This is a per-window opt-in; it is not evidence that every Thunderbird dialog uses the backdrop. Keep platform appearance assumptions scoped to the actual window declaration. No Windows visual, contrast or paired Gecko backdrop behavior was inspected. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.
