# Configure common outgoing properties through the generic server and SMTP fields through QueryInterface

Bug 1882574 introduced nsIMsgOutgoingServer and nsIMsgOutgoingServerService so sending is not assumed to use SMTP. Account creation calls createServer("smtp"), then QueryInterface(Ci.nsISmtpServer) for SMTP hostname, port, and client ID; it uses the generic object for authMethod, username, password, identity and default-server management. The separate nsISmtpServer interface does not inherit from the generic one. Geoff suggested this exact split in D203799 and the author adopted it. Use that boundary when adding another outgoing protocol or a new SMTP setting. The legacy mail.smtpserver preference prefix is retained for compatibility.

Scope: Outgoing server architecture.
