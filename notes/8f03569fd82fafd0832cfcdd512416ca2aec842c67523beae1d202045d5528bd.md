# Quitting finishes the interactive OAuth request before rejecting its caller

The interactive authorization path registers its OAuth object for quit-application-granted. The new observer first clears connecting state, removes itself and closes/releases the active request, then reports application_closed through the stored failure path. connect exposes a Promise that is rejected by that path. This is scoped to interactive authorization: refresh-only network work and external browser-tab closure are not established by the change. Accepted code later moves observer registration earlier and keeps distinct cancellation guards. No shutdown test ran.

Scope: OAuth interactive authorization shutdown.
