# Use a component base class with its modifiers, and give a different component a different hook

This is a manual naming proposal grounded in shared widgets and the accepted vCard review. The shared icon-only and icon-button modifiers belong to .button. Custom vCard remove controls do not automatically inherit them; the accepted author chose only-icon to distinguish that separate style scope. Shared reusable hooks use kebab-case role names such as sidebar-panel-header, and CSS token families use --sidebar-header-* or --list-container-*. Existing page IDs such as folderPaneHeaderBar remain camelCase and serve page-specific hooks. Preserve consumer scope; do not mechanically rename those IDs or make only-icon a universal button class.

Scope: mail/themes.
