# The Calendar numeric format probe accepts trailing nondigits before date input is parsed

This landing changes the numeric format probe from a single optional trailing nondigit to any count, while preserving its three numeric captures. The probe uses a known UTC date to learn component positions. parseDateTime refuses parsing if that probe failed; the actual change listener then restores the prior date, and the recurrence caller commits its typed end date with Tab. The ordinary numeric parser already accepts a suffix. This source supports that bounded parser/setup connection, not recognition of every locale or proof that an OS-era marker caused every intermittent. No tests change, and reported forced-format Try results were not repeated.

Scope: Calendar datepicker format probing.
