# Derive Exchange socket type from its endpoint URL

CreateInBackend sets socketType only in the SMTP branch. Current shared Exchange server derives SSL/plain from https/http and rejects a direct SetSocketType call. Its endpoint property is now IExchangeOutgoingServer.exchangeUrl, so the historical nsIEwsServer.initialize(URL) call is stale. Preserve protocol-specific configuration instead of writing every outgoing field through a common branch.

Scope: mail/components/accountcreation/modules.
