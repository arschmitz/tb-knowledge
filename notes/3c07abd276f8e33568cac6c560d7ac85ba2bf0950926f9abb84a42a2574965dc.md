# The original CopyItem fake response used source IDs while its tests checked folder counts

At the original landing, the fake CopyItem handler creates sourceID_copy items but passes the original itemIds to a helper that serializes each supplied ID unchanged. The owned copy test checks folder counts and fake-server locations, so it does not directly catch a wrong EWS ID assigned to a copied local header. Current fake code passes newItemIds instead, and the refactored copy test checks subjects as well. This separates fake storage, response identity and local-header assertions. It is a static historical mismatch with a later changed implementation; no real Exchange failure, test run or causal claim about the later fix is made.

Scope: EWS mock copy response identity and direct assertion limits.
