# Calendar dialog tests wait on popup elements and distinguish focus attempts from focus assertions

Reminder and timezone selection wait on the menupopup element. The timezone dialog races activation with a timeout that calls focus, then continues after one event-loop turn. Its timeout completion records an attempt; no new assertion proves the window became active. The timezone scenario executes that helper and directly checks event position instead. Keep popup completion, focus attempts and direct test expectations separate. No browser run was performed.

Scope: Calendar item-editing browser helpers.
