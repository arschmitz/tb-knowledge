# Skipping hidden auto-tags must preserve both later entries and numbered-tag positions

The message tag-menu builder skips an unapplied auto-tag with index++ and continue. Returning would stop rebuilding the remaining menu. The index advances even for hidden entries because menu access keys and numbered-tag commands use positions in the complete tag list. Displayed item commands use their tag key directly. Keep that loop contract when changing the filter; this does not require displaying every auto-tag or establish a general rule against early returns.
