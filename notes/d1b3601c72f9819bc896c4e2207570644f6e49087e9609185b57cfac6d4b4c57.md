# Keep folder property names and byte values in their required encodings

GetTransferInfo converts Mork column names from UTF-8 to the property bag’s UTF-16 names, while values stay ACString bytes. Restore reverses the name conversion and asks each variant for ACString. The accepted review uses nsAutoCString for the short local name and value buffers. Preserve encoding at the interface boundary and use the nearby temporary-buffer family; this does not make every string Unicode or establish a universal ban on nsCString. The code ignores several property/enumerator errors, which the author acknowledged; that limitation is not a recommended error-handling rule.

Scope: Folder property encodings and local C++ style.
