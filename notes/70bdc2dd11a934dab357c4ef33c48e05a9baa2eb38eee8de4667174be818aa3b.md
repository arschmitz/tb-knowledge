# Isolate notification fixtures from the enabled production manager

918 moves the manager fixture test to the disabled manifest while setting the enabled manifest URL to empty, so background fetching cannot populate its manager. Current enabled tests still set mail.inappnotifications.url to empty, but the disabled manifest now contains only the disabled startup integration test. Keep the historical fixture split separate from the newer harness layout. Test packaging and preference isolation are part of the observation contract.

Scope: Notification test preference isolation.
