# The notification delay is exported by the shared extension utility module

1923 moves NOTIFICATION_COLLAPSE_TIME from the parent global into ExtensionUtilities and imports it in message, folder and identity code. Its accepted value is 200; each consumer retains its own keyed deferred task. Scoped manual naming recommendation: keep this shared delay in its named module export, and state milliseconds in its documentation when changing it. The identifier itself does not encode a unit. This is a family-level module convention, not a new repository-wide constant rule. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension notification constant ownership.
