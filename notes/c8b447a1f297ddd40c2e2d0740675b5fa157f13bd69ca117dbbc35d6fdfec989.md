# Correct the obsolete UTF-16 subscription comment

SubscribeToFolder now accepts nsACString, but its comment still describes aName as zero-padded UTF-16 modified UTF-7. The called service explicitly documents modified UTF-7 or UTF-8 server wire bytes. Recommend replacing the obsolete type explanation with the current wire-input contract. This is a scoped comment correction, not a reported protocol failure. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
