# Translate the loading state before a large ICS parse blocks the UI

The about:import item pane sets a localized loading message, shows the pane, waits for translateElements, and yields briefly before parsing the ICS file. That sequence gives the loading state a chance to appear before synchronous and list-building work. Current code retains the explicit translation and yield. This is relevant when work starts immediately after a localized pane transition.

Scope: Calendar import UI.
