# Do not package the prebuilt OTR library for unsupported Windows Arm64

665 returns before selecting the prebuilt libotr fetch directory when the target is WINNT/aarch64. This controls TB_LIBOTR_PREBUILT packaging even in automation. Current configure retains that target gate. Do not infer the wider chat feature matrix from one packaging flag, and do not replace the target check with a check of the host worker operating system.

Scope: Windows Arm64 OTR packaging.
