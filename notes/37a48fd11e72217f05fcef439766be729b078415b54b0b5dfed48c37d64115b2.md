# Check actual GPGME encoding before feeding a signed payload to RNP

When an external key signs a message that RNP will encrypt, GPGME is asked for binary output but user configuration can still produce ASCII armor. RNP checks the byte prefix and removes armor before combining the signed payload with encryption. GPGME returns a uint8 typed array and excludes the trailing C string terminator from the input length. Keep this boundary in bytes rather than decode arbitrary binary as a JavaScript UTF-8 string. The native rnp_dearmor declaration must match its input/output handle types. The helper cleanup on failure is not covered by the landing, and no native crypto tests were executed.

Scope: openpgp.
