# Route command-line ICS files through the shared import controller

Part 2 removed the old modal ICS dialog and sends an existing, nonempty command-line .ics file to toImport("calendar", file). The shared CalendarImporterController.useFile accepts both the file picker and supplied file. The accepted review noted resolveFile can throw for missing paths; the author kept file.exists() as a safety barrier. Preserve both entrypoint forms when changing the import wizard.

Scope: Calendar import entrypoints.
