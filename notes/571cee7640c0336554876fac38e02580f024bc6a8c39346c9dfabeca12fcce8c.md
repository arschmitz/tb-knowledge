# NNTP read queries use header flags while MarkHdrRead separately reconciles the newsrc set

The news database now inherits the raw-header read query and overrides MarkHdrRead for its second representation. It first calls the base DB update, then reconciles newsrc membership even when the header already matched. Missing readSet can fail after base state changes, and Add/notification results are not all propagated, so this is not an atomic persistence guarantee. Commit and the server dirty notification are separate steps. Preserve both roles when calling or refactoring this path. No NNTP or DB test ran.

Scope: Protocol-specific read representation and update boundary.
