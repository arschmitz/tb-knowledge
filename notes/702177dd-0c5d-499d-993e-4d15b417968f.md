# Check the chosen Outlook address-book array before reading its length

GetChildCardCount and GetChildCards choose m_AddressList for a mailing list or mCardList otherwise. Crash data pointed to GetChildCards dereferencing that chosen pointer when it was null. Bug 1895079 added NS_ENSURE_STATE(srcCards) in both methods before GetLength; the macro returns an error when the pointer is false. D209491 explicitly asked why the two-line fix stops the crash and accepted the explanation. This is a narrow guard, not evidence that the missing array state itself was repaired.

Scope: Outlook address book.
