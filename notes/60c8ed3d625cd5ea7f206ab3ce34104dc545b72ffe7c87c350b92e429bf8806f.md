# Bulk calendar selection must skip disabled entries and apply the checked state on accept

755 adds Select All and Select None to the detected-calendar wizard. setCalendarsSelected skips disabled rows, and the accept handler registers only checked calendars that are not already registered. Native buttons invoke the helper with a boolean checked state. A bulk operation must follow the same eligibility as individual controls. No calendar-server or wizard UI run was performed.

Scope: Calendar creation bulk selection.
