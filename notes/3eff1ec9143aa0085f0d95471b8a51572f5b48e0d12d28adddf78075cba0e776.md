# Set envelope metadata before any output writes

SetEnvelopeDetails asserts eInitial and stores both fields before the writer emits the separator. Its error-state early return handles a failed stream setup; it does not permit metadata changes after writing starts. In this stream family, document and enforce state-sensitive setter order rather than presenting it as an unrestricted property update. Later mutex changes are current refinements, not attributed to 839.

Scope: Mbox output state contracts.
