# The S/MIME callback bridge resolves with a verification status value

The verifier receives an object with a verifyCertFinished method whose function is the promise resolver. The command awaits the returned status value and branches on0 versus a failure code. Certificate verification failure is therefore represented by that status, not by deliberately rejecting the bridge promise. A short adjacent comment explains the callback-object shape, which is less obvious than the minimal object syntax. This is the scoped callback contract in the checked S/MIME helper; it does not guarantee every synchronous API exception is caught or every callback eventually fires. No runtime verifier test ran.

Scope: S/MIME verification callback and completion contract.
