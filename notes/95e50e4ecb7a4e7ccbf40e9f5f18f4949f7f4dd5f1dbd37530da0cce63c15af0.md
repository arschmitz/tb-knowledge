# Synthetic-message menus use the message folder when the tab has no folder

InitMessageMenu treats a selected message's folder as real context even when its synthetic tab has no folder. Mark prefers that message folder and falls back to the tab folder; tag/move depend on a stored message. New synthetic and standalone tasks use mode-derived menu-state assertions through menus/head.js. They do not directly test mark/tag mutations or establish a fix for the separate read-state report.

Scope: Message menu context for synthetic and standalone views.
