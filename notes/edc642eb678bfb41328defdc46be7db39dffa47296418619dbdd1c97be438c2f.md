# Separate the dark-reader frame mitigation from later idle and content-process checks

The three-line intermittent-test landing adds a second animation frame only for DEBUG, ASAN or TSAN builds. The fixed accepted helper also waits for an idle callback on that branch and checks message DOM styles through SpecialPowers.spawn. Its assertions check actual attributes and computed colors; they do not assert frame count or establish the race cause. Treat the later helper as separate evidence and the original slow-build explanation as a hypothesis. No new test or timing run.

Scope: Message-reader browser test timing.
