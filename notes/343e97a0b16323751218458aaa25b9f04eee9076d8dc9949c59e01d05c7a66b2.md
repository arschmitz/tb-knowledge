# The manual-configuration test port mixes raw true restoration with scoped preference overrides

The original old-flow manual task sets the manual preference false directly and writes true only at its normal tail, without recording a previous user value or matching manual-pref cleanup. The accepted later helper instead awaits the preference stack and a rendering update. A separate config-found task still calls pushPrefEnv without awaiting it before opening the dialog. These are distinct source lifetimes and ordering facts; they do not establish a reproduced leak, race or upstream harness isolation guarantee.

Scope: Account Hub browser-test preference lifetime.
