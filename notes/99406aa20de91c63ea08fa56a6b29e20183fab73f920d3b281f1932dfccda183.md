# Virtual tree row naming maps view IDs to stable CSS and row IDs

Accepted base and automatic tree rows map a column ID to `${column.id.toLowerCase()}-column` and a row to `${this.list.id}-row${this._index}`. The custom-element name remains tree-view-table-row, with TreeViewTableRow as its class. Preserve these local computed names when adding columns or tests, because selectors and active descendants depend on them. This is a component naming contract, not a repository-wide rule that all DOM IDs are dashed. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
