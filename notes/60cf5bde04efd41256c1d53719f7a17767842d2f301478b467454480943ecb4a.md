# Carry mailbox offsets in uint64_t through every native consumer

MboxMsgInputStream uses uint64_t for mMsgOffset, total byte count, and MsgOffset(), while buffer positions remain size_t. The scanner stores the returned value in uint64_t before serializing it as a token. A cast at final AppendInt cannot recover a value already truncated in an earlier size_t variable on a 32-bit build. This is a file-position contract, not a rule to use uint64_t for all buffer indices.

Scope: mailnews/base/src.
