# Calendar dropbox updates the active drag session before the DOM attribute

The dropbox setter gets the active native drag session, sets canDrop to true when a session exists, then adds or removes shadows. Adding shadows also requires the string true and a source node outside the widget. The setter finally calls the base XUL setter. The service-access cleanup removes cal.dragService; it does not remove this state change or prove how every native drag caller behaves. No drag operation was run.

Scope: Calendar drag-and-drop widgets.
