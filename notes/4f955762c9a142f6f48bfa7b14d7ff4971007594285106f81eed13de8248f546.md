# A date-facet node can receive hover callbacks before its visualization exists

The date-facet element initializes vis to null and creates it in buildFunc. Facet hover propagation checks for an existing node and then calls brushItems or clearBrushedItems. Those date-facet callbacks therefore use optional chaining on vis so an absent visualization is a no-op. When vis exists, the method still runs with vis as its receiver. This is a scoped lifecycle allowance, not a general rule to hide missing required objects or a live empty-search validation.

Scope: gloda-date-facet-optional-hover-receiver.
