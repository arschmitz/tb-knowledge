# Add typed function documentation when moving or exposing helpers

When touching reusable helpers in these components, put the contract in JSDoc with parameter and return types instead of leaving it in an inline comment. Both moved getUsageText and renamed vCard converters received this review request. Explain formats, units, exclusions and null behavior where relevant. Copy neither stale parameter types nor an inaccurate nullable return annotation. This is a proposed rule for new or touched reusable JS helpers, supported by two accepted reviews and current typed JSDoc. It does not claim all legacy functions comply.
