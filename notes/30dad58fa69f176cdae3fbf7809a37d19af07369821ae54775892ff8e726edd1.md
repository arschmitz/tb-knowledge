# Keep QR snapshot format changes separate from text encoding fixes

The historical 1164 fixture is an SVG data URI; the accepted fixture and renderer use BMP. Both the owned 2024 module change and current renderer convert text with MailStringUtils.stringToByteString. The existing UTF-8 boundary lesson remains valid, but fixture bytes change when rendering format changes. Scoped recommendation: check the rendering mode and fixture provenance when updating a golden snapshot. Geometry was excluded here and neither decoder behavior nor visual appearance was verified. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
