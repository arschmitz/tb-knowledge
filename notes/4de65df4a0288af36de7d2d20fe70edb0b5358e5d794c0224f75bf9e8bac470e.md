# Dialog position tests compare overhang edges in the container coordinate frame

The dialog-position tolerance helper compares overhang placement against containerRect.right/bottom minus the dialog margin or containerRect.x/top plus the margin. It names separate candidate predicates and reports their aggregates through four assertions. These are alternatives, not a unique-position assertion. Read the comparisons themselves: horizontalContainedInTarget actually places target edges inside the dialog, and verticalCoversTarget checks only target top y. Those names/comments are not accurate whole-containment contracts. Static test-source inspection only.

Scope: Calendar dialog geometry browser tests.
