# Preserve cell titles and accessible labels in tree row migrations

D207127 initially broke tooltips for clipped text, icon cells, and buttons, and lost accessible labels. The reviewer blocked the patch until the base row filled each cell’s title and optional Fluent aria-label; browser_autoTreeView.js checks both across visible columns. Current row code still sets localized cell attributes or a text title and sets row aria-label. When swapping a tree row implementation, test tooltips and the accessibility tree as behavior, not only visual cell text.

Scope: Tree view accessibility.
