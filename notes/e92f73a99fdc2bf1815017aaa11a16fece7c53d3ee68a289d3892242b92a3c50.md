# No-fetch tests preserve the configured endpoint after testing absence

The accepted test saves the configured URL, sets it to empty, tests absence, tests about:blank and then restores the saved URL. For this mutable updater fixture, recommend keeping restoration with the negative cases so later tests do not inherit a disabled endpoint. Assertions cover the return and update callback; they do not directly spy on fetch or prove every scheduling side effect is unchanged. This is scoped test guidance. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Notification updater no-fetch fixture restoration.
