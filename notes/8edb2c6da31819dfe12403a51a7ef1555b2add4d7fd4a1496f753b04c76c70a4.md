# Compose menu and password tests use different wait ordering

The historical753 File-menu test triggers the menu before awaiting waitForPopupEvent, and activates Send Now before waiting for the popup to hide. The selected accepted subtestFileMenu keeps that ordering. The accepted password-send helper instead creates the compose-window-close promise before its send action. This corrects the older claim that the send tests prearm their popupshown/popuphidden waits. These are the actual patterns in two different helpers. Prompt promises and the compose-open promise are separately armed before their actions. This inspection does not establish a missed event, timeout or race: the popup/window wait helper’s already-open or already-closed behavior was not inspected, and no UI test ran. The note describes source contracts and does not add a global test-ordering rule.

Scope: Compose test event ordering.
