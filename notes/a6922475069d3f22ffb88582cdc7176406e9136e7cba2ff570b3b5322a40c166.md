# Filelink provider buttons keep the full localized name in the tooltip

Entry 1469 crops a provider button at the end, sets its tooltip to the same localized display label and hides internal overflow. The accepted makeButtonForProvider retains those steps. In this provider chooser, recommend deriving visible label and tooltip from the same localized value before cropping. A tooltip supplies pointer context but is not evidence of a complete accessible name, touch behavior or screen-reader description. No long-provider-name layout, tooltip, keyboard or screen-reader check was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Filelink provider label overflow.
