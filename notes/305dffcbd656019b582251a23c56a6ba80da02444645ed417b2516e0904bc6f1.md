# Account Hub fills missing password input from retained credentials

When no truthy password is supplied, the Account Hub filler selects the retained incoming password, then the outgoing password, and passes that value to replaceVariables. hasPassword reports presence as a Boolean. replaceVariables only writes truthy supplied credentials and applies the selected value to incoming, outgoing and alternatives. The old empty argument did not clear all retained passwords. This fallback can replace a different outgoing credential, so it is not a general claim that both original credentials remain unchanged. No setup test was executed.

Scope: accountcreation.
