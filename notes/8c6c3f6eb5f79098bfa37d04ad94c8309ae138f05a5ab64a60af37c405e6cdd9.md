# Test the chrome widget table’s eager and lazy loading boundary

The chrome widget test declares eager and lazy entries in EXPECTED_CUSTOM_ELEMENTS. It checks initial registration, creates the first element, checks its factory and creates a second element. Preserve this table-specific loading boundary when changing registered widgets; a final registry check alone can miss unwanted early loading. The separate utility first-registration and definition-wait contracts already have scoped notes. Static source and test inspection only. No runtime, build, lint or accessibility tests ran; full bug and review discussion remains pending.

Scope: Chrome custom-element registry loading tests.
