# Virtual-folder SQL search binds escaped text and local civil dates separately from clause text

VirtualFolderFilter combines saved folder scope with a limited ordered term sequence. Text LIKE values escape slash, percent and underscore before adding the operator-specific wildcard; equality values remain raw bound text. Date terms format PRTime in local time and compare with SQLite DATE(..., localtime), so the inspected contract is a local calendar date, not a UTC instant. LiveView binds the resulting variants by index. The test matrix checks exact clauses and parameters, including literal wildcard characters and strict before/after operators. Unsupported attributes/operators only assert, and nested grouping, automatic refresh and live matching are not established. Three SQL assertion sites lack messages. No SQL or timezone test ran.

Scope: Panorama virtual-folder term conversion.
