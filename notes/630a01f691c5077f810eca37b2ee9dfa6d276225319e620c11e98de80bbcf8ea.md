# Removing the Address Book Hub checkbox retains its runtime preference switch

The focused Settings change removes the address-book checkbox, description, Boolean binding and matching Fluent messages together. The main experimental Hub checkbox remains in that owned phase. The stored address-book preference still exists: current Create Address Book chooses Hub or legacy UI from its value, and the App Menu observer changes opposite entries. The separate preceding default change and later Hub cleanup remain distinct phases. No checkbox, menu or account-creation runtime was exercised.

Scope: Address Book Hub Settings removal.
