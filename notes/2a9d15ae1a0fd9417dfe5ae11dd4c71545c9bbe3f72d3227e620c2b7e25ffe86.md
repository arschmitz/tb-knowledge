# Pass progress dialog URLs at the API string boundary

The 2024 Gecko port changed the progress dialog URL argument from a converted UTF-16 string to nsDependentCString(dialogURL). Current OpenProgressDialog now uses nsIWindowWatcher::OpenWindow and still passes that URL as nsDependentCString; the window name remains a UTF-16 literal. Manual C++ review proposal for this call boundary: use the callee contract for each argument and do not convert a URL to UTF-16 because another parameter is UTF-16. This is one preserved boundary example, not a universal string or ownership rule. The old OpenDialog call itself is no longer current.

Scope: progress-dialog.
