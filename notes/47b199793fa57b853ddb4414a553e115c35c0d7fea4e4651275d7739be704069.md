# messages.tags.get normalizes keys and rejects unknown tags

messages.tags.get lowercases its input, enumerates the tag service and finds a matching key. It returns the tag fields with an uppercase color, or rejects with ExtensionError when no key matches. The schema requires messagesTagsList and exposes an asynchronous MessageTag result. The added MV2 test directly checks the normalized lookup and missing-key rejection; it does not isolate permission denial, callback delivery or MV3. The convenience getter does not establish constant-time lookup or a rule for every extension getter.

Scope: WebExtension message tag lookup.
