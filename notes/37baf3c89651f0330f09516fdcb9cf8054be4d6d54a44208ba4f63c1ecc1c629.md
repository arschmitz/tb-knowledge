# Legacy remote compose paths wait for a fully started main window

Legacy -remote mailto and xfedocommand composemessage first await getOrOpen3PaneWindow and then require a default account before opening composition. The helper waits mail-startup-done for a newly opened window and delayedStartupPromise for both new and existing windows. Direct -compose uses the same ordering. This is a readiness and account contract for these branches; malformed legacy command parsing and generic protocol handling remain separate. No command-line or UI execution.

Scope: command-line-compose-startup.
