# The password-reveal policy guards both the button and its command

DisablePasswordReveal disallows the passwordReveal feature. Startup hides the reveal button for that feature, and the actual TogglePasswordVisible command checks the same feature again before prompting or changing the password column. The added browser task makes the button visible itself, clicks it and directly asserts that the column stays hidden, so its stated coverage includes the action guard as well as initial visibility. This is static code/test coverage; no policy, password, browser or accessibility run occurred, and no broader password-access boundary is claimed.

Scope: Password-manager enterprise policy UI/action guard and regression test.
