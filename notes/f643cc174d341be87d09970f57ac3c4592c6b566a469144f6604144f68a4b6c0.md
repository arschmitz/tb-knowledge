# Free the signed-MIME disposition value outside its optional fallback branch

938 adds PR_Free(disposition) after the optional charset fallback, inside the options/override guard that acquired the value. The accepted code keeps it outside the if(!disposition) branch, so a real disposition value is also released. Place temporary cleanup at the scope that owns the value, rather than only inside one use branch. No leak measurement or signed-message runtime test was performed.

Scope: Signed MIME temporary header cleanup.
