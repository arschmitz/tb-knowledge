# AutoSync hands semaphore release from startup guard to completion

The checked dispatcher acquires the folder semaphore and installs a scope guard before protocol-specific work. Early startup exits release it through that guard. After dispatch and the in-progress state succeed, guard.release leaves terminal release to the completion route. IMAP uses its URL listener; later Exchange uses a completion lambda. The original refactoring still rejects non-IMAP folders. Preserve the phase and ownership handoff when simplifying branches; this is not proof every error, reentrant callback or cancellation path is handled. No AutoSync run occurred.

Scope: AutoSync offline download dispatch and terminal notification.
