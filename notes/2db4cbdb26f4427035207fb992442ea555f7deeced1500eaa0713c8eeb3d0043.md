# Sound callers apply enablement checks while preference previews call playback directly

The checked manager gates incoming-mail playback with the branch Boolean, and chat gates playback with mail.chat.play_sound and window/tab focus. The general and chat preference previews call playSound directly with their own branch. playSound selects system versus custom sound from .type and .url; it does not inspect the branch Boolean. This lets a preview request playback independently of notification enablement. The original landing moves the sound service into this shared path; the fixed accepted API is now an exported singleton method rather than the original static class method. This is a caller/helper contract for these paths, not a global preference rule. No preview, sound or UI was run.

Scope: Mail and chat notification sound caller contract.
