# Defer initial compaction callbacks until Begin returns

Current BatchCompactor holds itself with mKungFuDeathGrip and dispatches a retained self to the main thread before StartNext can invoke listeners. Completion releases that reference. This lets Begin return before a callback and keeps the batch alive through timers and asynchronous folder work. Preserve both roles when changing scheduling; the self-reference alone does not establish callback ordering. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Batch compaction kickoff lifetime.
