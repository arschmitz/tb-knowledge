# Commands Patch Update task lifecycle and resume contract

`assertPatchSessionCheckout()` in `commands/graph/patch-session-store.mjs` rejects a resume when `git rev-parse HEAD` differs from `session.currentHash`, returns HTTP 409, and says no files changed. The exact D332509 error is `Cannot resume D332509: this checkout is on a different commit... No files were changed.` [Task 1]
