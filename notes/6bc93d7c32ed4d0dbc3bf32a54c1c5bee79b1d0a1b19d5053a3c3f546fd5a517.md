# Virtual-folder tests must distinguish searched data from backing-folder display

The current grouping test uses a real date search criterion when constructing both virtual folders. Its comment explains that this prevents an accidentally displayed backing folder from passing the test. A newer regression case selects a synthetic group header before leaving grouping and checks that the selection becomes -1, because a group header is not a persistent message selection. Manual test proposal for virtual lists: make fixtures exercise search behavior and cover synthetic-row selection during view changes. These are current added tests; they do not prove every virtual-folder path or platform. The test has explicit platform/debug skips.

Scope: message-list.
