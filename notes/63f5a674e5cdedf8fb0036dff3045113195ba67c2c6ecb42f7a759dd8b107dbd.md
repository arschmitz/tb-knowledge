# Filter recipient entries through the mailbox conversion contract

The historical adapters normalize both EWS recipient arrays and parsed MIME address lists into mailboxes before a shared formatter writes database recipient strings. The accepted shared adapter uses address.iter().filter_map and TryFrom to omit entries with no address; Reply-To separately collects Option<Vec<Mailbox>> and can fail the whole set. Preserve each field's conversion policy instead of assuming all address fields filter identically. Current shared adapters are source context with no proven active population caller.

Scope: Parsed recipient and Reply-To conversion policies.
