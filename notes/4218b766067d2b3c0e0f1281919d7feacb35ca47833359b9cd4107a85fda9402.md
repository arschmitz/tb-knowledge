# Compare offline and online message bytes to an independent expected fixture

The online-query test checks different message IDs and external flags, then compares each getRaw result to originalMessage after explicit newline normalization. The reviewer rejected an assertion that only compared the two actual results, because both could be wrong in the same way. Keep the expected fixture independent of both paths. Current xpcshell-nntp.toml registers this protocol-specific test; the older .ini registration is historical. The current named task is test_query_online. This is reviewed test syntax and diagnostic practice beyond lint. The test was not executed here.

Scope: Meaningful message query tests.
