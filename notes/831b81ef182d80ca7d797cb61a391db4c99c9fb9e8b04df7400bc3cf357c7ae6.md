# Run OS locale tests in separately configured processes

The i18n suites pair each browser_language_REGION.js file with its own TOML manifest and LC_ALL/TZ environment. Non-English suites enable OS regional preferences, and the manifests run on Linux. Changing application strings in one already-initialized window would not test the same OS-derived setup. Scoped filename pattern: retain the actual locale identifier with its language and region casing, rather than changing it to a general dashed filename convention. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: calendar/test/browser.
