# Empty status text and queue exhaustion have different meanings

Accepted queue handling avoids inserting empty strings in the middle of queued messages but distinguishes shift returning undefined from a valid empty string. A scoped manual JavaScript recommendation is to keep the explicit undefined check at this queue boundary instead of using a blanket falsy check; it controls interval shutdown and later clearing.
