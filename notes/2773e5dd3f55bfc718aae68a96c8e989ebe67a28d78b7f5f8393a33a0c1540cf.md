# The new flat-row cache assertions omit expected-behavior messages

The added cache/level/sibling assertions in test_treeDataAdapter and the top-level ARIA assertions in browser_autoTreeView have no message arguments. Give each assertion a nonempty expected-behavior message when reviewing or extending these checks; a nearby Cache comment does not replace a failure message. This is a scoped source-review finding, not a failed test run or permission to copy message-free accepted assertions.

Scope: Tree cache test review.
