# A typed sleep duration still has a bounded native timer conversion

The sleep helper accepts Duration and documents failure if its millisecond representation cannot fit in u32. It performs that checked conversion before InitWithCallback and propagates timer creation/initialization errors. A typed duration therefore does not remove the native timer's range limit. No overflow, submillisecond timing, cancellation or native test was run.

Scope: Rust asynchronous timer boundary.
