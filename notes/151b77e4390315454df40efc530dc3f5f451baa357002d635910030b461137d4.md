# EWS folder properties use their local server-type visibility map

Folder Properties hides EWS Sharing/Quota tabs, IMAP/POP retention descriptions and newsgroup offline controls through hidefor="...ews" tokens. Its local hideShowControls sets control.hidden from exact comma-delimited type membership, with additional folder/IMAP checks afterward. Generic retention and folder offline controls remain. This is the folder dialog UI contract, not backend feature removal or the different same-named account-settings helper. No dialog or EWS test ran.

Scope: EWS folder-properties options.
