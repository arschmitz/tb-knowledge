# Release tagging binds the head_rev action placeholder to the comm revision in the accepted configuration

The initial two-kind port added task_context and a tag revision placeholder sourced from head_rev. The fixed accepted early-tagging and version-bump configurations instead bind that placeholder to comm_head_rev. Comm decision code treats Gecko head_rev and comm_head_rev as distinct parameters. This is a source configuration finding; upstream substitution and Lando execution were not verified.

Scope: Thunderbird release tag task context.
