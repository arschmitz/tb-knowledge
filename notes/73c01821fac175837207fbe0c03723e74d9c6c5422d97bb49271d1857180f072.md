# Graph's all-channel default preserves the configuration option's type and gates

This landing defaults mail.graph.enabled to true for all channels and renames the Graph option's two Fluent IDs and English text. The radio value stays graph. Its checked widget consumer still reveals only the chosen configuration and alternatives, while XML/model readers retain explicit preference gates. The preference default and visible wording therefore do not establish Graph discovery, authentication or synchronization, nor remove the explicit false branch. Existing provider metadata and test findings are reused separately. No UI or server scenario was executed.

Scope: Graph Account Hub enablement.
