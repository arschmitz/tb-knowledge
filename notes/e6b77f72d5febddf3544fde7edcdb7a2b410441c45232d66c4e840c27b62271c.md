# Assert the absence of selection events when a context click must preserve selection

944 tests a collapsed thread selected while the single message is context-clicked, then the reverse. It verifies the context-menu target separately from the getter results and asserts zero selection-change events during each context action. The current test also waits for the host popup and acknowledges the extension request before continuing. Preserve these negative event checks alongside positive click checks; a correct getter value alone cannot prove event stability. This test uses pointer contextmenu synthesis and does not prove keyboard context-menu or screen reader behavior.

Scope: Extension context-click regression tests.
