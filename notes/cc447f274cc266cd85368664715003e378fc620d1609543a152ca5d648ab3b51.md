# Keep autosync priority and cleanup tied to database state

Current autosync priority compares GetDatabaseOpen first, then folder-type priority when those states match. The completed-state cleanup and search cleanup retain Inbox references and clear only when their database-open test is false. Do not describe these as current UI-window checks or a policy that closes every background folder database. The branches intentionally test the existing reference before clearing it. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Autosync and search database policy.
