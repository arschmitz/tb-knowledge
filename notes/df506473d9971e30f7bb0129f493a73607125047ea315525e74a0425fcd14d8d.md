# Carry POP3 move-count state across the per-message parser replacement

nsPop3Sink replaces nsParseNewMailState for each incorporated message. It swaps out the destination-count UniquePtr before releasing the old parser and swaps it into the new parser. Carry that batch state together with the not-new count and coalescer; otherwise moves from earlier messages disappear before EndMsgDownload. This ownership transfer is specific to the per-message parser lifecycle. No multi-message POP3 filter run was executed.

Scope: mailnews/local/src.
