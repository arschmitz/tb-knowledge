# PGP MIME part identifiers prepend one-based ancestry segments

Accepted determineMimePart walks each parent container, finds the child position, creates a named nsCString segment from i + 1, inserts it at the beginning and cuts the initial dot. The 1360 reland uses the named string and includes nsPrintfCString.h. Preserve ancestry order and one-based wire numbering when simplifying this helper; replacing the old buffer alone does not change part-selection semantics.
