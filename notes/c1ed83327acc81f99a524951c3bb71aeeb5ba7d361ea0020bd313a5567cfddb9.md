# The Git bootstrap clones Firefox first and Thunderbird under comm

The script directly clones Firefox from GitHub, then clones Thunderbird into the Firefox destination comm subdirectory and returns the Firefox directory to mach bootstrap. FIREFOX_HEAD_* and THUNDERBIRD_HEAD_* control separate optional overrides. Clone command failures raise, and main does not check the subsequent bootstrap return code before mozconfig. The complete accepted file matches this landing, but no clone, paired-revision setup or bootstrap result was executed.

Scope: Thunderbird standalone Git bootstrap.
