# Exercise search window selection and existing-tab reuse

The converted search dialog browser test checks all-books and one-book results, sort headers, criteria reset and Enter, count status, command disabled states for zero/one/many selected cards, Select All, compose, deletion by Delete/Backspace/button, and opening a contact in an Address Book tab. It then opens another contact via Enter and asserts the same tab is reused and updated. This is a useful migration test matrix for user behavior and shared tab state.
