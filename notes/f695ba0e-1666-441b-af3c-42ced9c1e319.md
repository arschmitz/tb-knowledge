# Route compose indent commands through the editor style command map

The compose indent and outdent buttons now use doStyleUICommand and map to document.execCommand, replacing the internal goDoCommand path. The patch adds browser_indentOutdent.js, which checks no indent, two nested indents, and both outdents through the toolbar. Keep the button command mapping and actual editor output covered together when changing compose formatting.

Scope: message compose editor.
