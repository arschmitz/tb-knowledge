# Keep offline recovery tests scoped to the store format they corrupt

The accepted downloadOffline test has a later mbox-only case that shifts each storeToken by three, expects NS_MSG_ERROR_MBOX_MALFORMED, checks token/size/Offline state clearing, streams again from the server, and finally reads with localOnly true. This is current context for the 2024 stream-strengthening change, not proof that the same offset corruption applies to maildir or that this study ran either backend. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mailnews/imap/test.
