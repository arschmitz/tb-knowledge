# Count selected messages rather than grouped view rows

GetNumSelected subtracts MSG_VIEW_FLAG_DUMMY rows and adds collapsed thread expansion only when the operation preference permits it. The changed/current selected-message test compares against numMsgsInView rather than rowCount. Preserve the distinction between selection rows, grouped headers and actual message count; they are not interchangeable totals.
