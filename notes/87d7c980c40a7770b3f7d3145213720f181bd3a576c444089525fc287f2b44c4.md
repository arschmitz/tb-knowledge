# Request raw attachment bytes before opening an attached encrypted message

AttachmentInfo.fetchAttachment appends outputformat=raw for message/rfc822 attachments or EML filename URLs. mimeDecrypt then caches raw data and returns it through returnData without the normal decrypt-processing path. In 2024 the URL marker was added unconditionally in the attachment open path; the accepted current helper scopes it to message attachments and is shared by saving. Do not apply the historical broad placement to every attachment type.

Scope: mail/modules/AttachmentInfo.sys.mjs.
