# Compose attachment cleanup listens even when no extension requests removal events

An unconditional windowTracker attachments-removed listener captures each attachment ID/window, emits internal removal events and then removes both attachment Map entries. Extension subscriptions use the tracker's on/off methods and receive captured values even if persistent-event wakeup is awaited. Window-close cleanup only covers attachments still in the bucket, so it cannot replace removal-time cleanup. Event emission is issued before forgetting; asynchronous extension delivery is not awaited.

Scope: WebExtension compose attachment lifetime.
