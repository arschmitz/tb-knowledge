# Name test DOM constructors for the window or document that supplies them

The helper cleanup renames shadowing MouseEvent and KeyboardEvent aliases to WinMouseEvent and WinKeyboardEvent; the observer argument becomes DocMutationObserver. Current code retains these names. They identify a constructor supplied by the target window/document rather than a replacement global. _getKeyboardEvent still probes the available global and falls back to the target window on constructor failure. Follow these local aliases when editing these helpers; no blanket prefix rule for other code is inferred.

Scope: mail/test/browser.
