# Thunderbird Bug 2073142 iMIP Details editor-tab routing

For `X-SHOWDETAILS`, get the main calendar window. If `calendar.item.editInTab` is true, call `calendarWindow?.modifyEventWithDialog(item)`; otherwise call `calendarWindow?.openEventDialogForViewing(item)`. Existing permission/invitation checks retain summary-dialog behavior for protected events. [Task 1]

Scope: general.
