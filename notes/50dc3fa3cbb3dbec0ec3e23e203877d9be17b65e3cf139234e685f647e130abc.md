# The Proton default list and WKD route differ between the owned landing and fixed comparison

The owned landing appends the Proton endpoint to the default keyserver list and removes the site-specific WKD path. The checked configured-list consumer reads supported scheme entries; this owned change adds no provider-domain filter to that path. At the fixed comparison revision, the list again has only VKS/Mailvelope and WKD URL creation calls getSiteSpecificUrl before constructing a standard WKD URL. These are two exact source phases. Provider/domain semantics, key correctness and network behavior remain unverified.

Scope: OpenPGP key discovery source phases.
