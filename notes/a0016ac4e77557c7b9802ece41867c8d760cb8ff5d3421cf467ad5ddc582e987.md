# The tray Quit wrapper does not observe the original cancellation out value

The original lint patch changes the native Quit out-parameter expression to a raw mutable pointer, but the wrapper never reads the Boolean after the call. It propagates the native status and returns success from the wrapper. Accepted later source uses a two-argument Quit call instead. Keep these API phases separate; neither source form proves that the application actually exits.

Scope: Rust tray Quit action.
