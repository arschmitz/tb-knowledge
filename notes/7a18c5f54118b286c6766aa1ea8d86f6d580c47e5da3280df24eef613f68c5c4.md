# Collapsed new-message badges share the unread outline while keeping their own color override

Collapsed folder rows compute new-message state across descendants. The unread badge CSS adds the exact collapsed new-message descendant selector to the shared transparent outline block, then keeps new-message text and border-color in its later override. Reusing that selector preserves the structural outline and its color precedence. This is a scoped selector/state relationship, not a global rule to merge CSS blocks. No rendered or runtime result was verified.

Scope: Folder pane unread and new-message badge CSS.
