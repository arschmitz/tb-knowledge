# Commands dashboard reliability: Phabricator loading and automatic build status

`getDashboardData()` uses browser discovery through `getDashboardRevisions` and ordinary `phab` API requests; they have different latency characteristics. Keep ordinary requests on the normal short timeout and give browser discovery its separate 120-second timeout. Fallback warnings must name the actual dashboard-loading error rather than universally saying `Phabricator is unavailable`. [Task 1]

Scope: console.
