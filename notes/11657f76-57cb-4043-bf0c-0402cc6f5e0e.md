# Do not let a redundant sort hide incorrect thread levels

Bug 1939725 traced a unified-folder threading fault to an older typo: when promoting a new root, the loop set every descendant level from m_levels[1] instead of incrementing each row’s own level. The prior double sort had masked some cases; removing it in Bug 1893793 made the fault visible. The 2025 fix changes each row to m_levels[i] + 1. The reporter reproduced it by toggling threaded view after expanding a thread. This is a later correction to the 2024 change, not proof that the removed double sort should return. Review D233248 accepted the fix, while the bug discussion says further cross-folder threading issues may remain.

Scope: Cross-folder threading.
