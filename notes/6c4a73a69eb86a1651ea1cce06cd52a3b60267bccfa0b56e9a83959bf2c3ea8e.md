# Group-by-sort rows do not enable thread commands

Current select-thread requires a DB view and rejects showGroupedBySort. Ignore-thread/subthread also require a selection, a folder and a single-folder view; watch-thread explicitly returns false for group-by-sort. Preserve those command availability checks when adding grouped rows. They describe supported operations, not a claim that grouped rows are message threads. No keyboard or command invocation was tested. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.
