# The multimessage arrow-key selector omits the HTML Star button

The new Star control is an HTML button, while headerToolbarNavigation enumerates only XUL toolbarbutton elements. Its arrow-key focus set is limited to the eligible XUL archive/delete controls and does not include Star. Native Tab access and activation-key handling are separate, so this does not establish complete keyboard inaccessibility. Accepted source retains the selector and later changes Star to aria-pressed; later test assertions cover that state attribute but still do not exercise arrow navigation. This is a bounded markup/navigation/test-code finding. No live keyboard, focus or screen-reader run occurred.

Scope: Multimessage header control accessibility.
