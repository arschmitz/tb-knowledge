# Date/time formatter tests allow known platform forms without removing meaning

The accepted formatter test uses a short list of permitted output strings for long/short dates and timed values, with the local zone set to Pacific/Fakaofo. Both date-only expected lists include All Day. It restores preferences at the end, rather than in finally, and the per-case timezone field is not directly read in the loop. Treat those as test limits; the assertion does not prove every locale, platform or cleanup-on-failure path. This is static source and test-code inspection.
