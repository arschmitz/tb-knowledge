# SetMsgUid names the parser input while preserving the legacy UID-to-key conversion

The landing renames SetNewKey to SetMsgUid and stores an ImapUid. The normal IMAP caller passes uid, while offline append casts its fake database key into that parameter. FinalizeHeaders still converts a supplied UID back to nsMsgKey; the rename makes the legacy boundary visible rather than separating server UIDs from local database keys. At the fixed accepted revision, the unset UID test is zero and creation uses the later automatic/specific-key APIs. No changed test or native run proves type or protocol equivalence.

Scope: IMAP parser UID and database-key boundary.
