# The many-tab warning uses the plural open-tabs Fluent identifiers

The warning branch passes open-tabs-warning-confirmation-title and open-tabs-warning-confirmation with the message count to synchronous Fluent formatting. Those exact identifiers exist in messenger.ftl. The branch runs after tabmail selection when the count exceeds mailnews.open_tab_warning; cancel returns before opening tabs. This fixes the inspected identifier mismatch. It does not establish prompt rendering, all locale forms or a browser-test pass.

Scope: MailUtils tab-opening confirmation.
