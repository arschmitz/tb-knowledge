# Encrypted URI names distinguish identity strings from message keys

Entry 1205 renames lastEncryptedMsgKey to lastEncryptedUri because the value is a message URI string. The accepted producer also names the separate network display identity lastEncryptedNeckoUri. For this tracking code, use names that identify the URI family and reserve key names for actual message keys. This is a scoped naming recommendation supported by the producer and its cleanup; it does not set a repository-wide acronym or ID convention, and review approval remains pending.

Scope: OpenPGP URI naming.
