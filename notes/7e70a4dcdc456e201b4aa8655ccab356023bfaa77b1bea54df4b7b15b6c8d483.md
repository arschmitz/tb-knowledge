# Verify non-mutating sort with a fixture that can change order

Accepted ranking uses toSorted, so it returns a new order without sorting the input in place. The inspected input-preservation test uses candidates tied in all sort fields and cannot strongly distinguish an in-place sort. A scoped test improvement is to supply unsorted candidates with different keys and compare the original array afterward. This is a proposed test rule, not a claim that the current implementation mutates input. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: In-app notification sort test strength.
