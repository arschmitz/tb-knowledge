# The bundled chat preview count excludes the preview message

The held message supplies the preview and _msgCounter increases only for later messages in the burst. That additional-message count reaches bundled-message-preview, whose text says and count more. Treating it as the total bundle size would be wrong despite the broader Fluent variable comment. The formatter is used only in full-content notification mode and only when the additional count is positive; the no-detail fallback keeps its separate legacy message. No native notification or privacy test was run.

Scope: Chat notification localization.
