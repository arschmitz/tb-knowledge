# Abort tests compare directory names in both directions

The compaction abort test snapshots the direct parent directory before and after the abort and checks both Set differences. One direction catches leaked names; the other catches lost names. It also checks unchanged mailbox size and expunged-byte state. For this cleanup test, retain both comparisons instead of checking only that a known temporary filename is absent. This tests direct directory-entry names, not recursive contents or file-byte equality. No abort or filesystem test was executed in this study. Full bug and review discussion remains pending.

Scope: Mbox compaction abort tests.
