# Check the localization result at the operation that fills the returned value

936 removes an unused result assignment for CreateBundle and declares the result beside GetStringFromID, where failure returns nullptr. Bundle creation is still followed by the m_stringBundle guard. Preserve that actual failure handling rather than generalizing this cleanup into permission to ignore every CreateBundle result. The returned UTF-8 allocation happens only after a successful string lookup.

Scope: MIME emitter result scope.
