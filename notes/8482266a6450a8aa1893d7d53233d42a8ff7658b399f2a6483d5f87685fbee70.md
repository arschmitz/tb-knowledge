# Require the theme data version before reusing parsed cache

Current startup cache reuse compares lwtData.dataVersion against LightweightThemeManager.DATA_VERSION. The historical port reused any lwtData and warned that application updates could interpret it differently. Prefer the current version check when working on this cache; a cache exists across launches and updates, not merely within one Theme instance. No restart/theme-update experiment was run.

Scope: mail/components/extensions/parent.
