# The merged-form reland checks the label element instead of an ariaLabel string

The reland preserves all ten original implementation/fixture/resource post-blobs and adds one separate input-test correction. It replaces formatted input.ariaLabel equality with Assert.deepEqual on ariaLabelledByElements and the actual label element. The implementation already assigns that label reference. The new assertion message states the expected relationship, and accepted source retains that property assertion. This is direct JavaScript property coverage, not a live accessible-name result or proof that this mismatch caused the reported test-breaking backout.

Scope: Account Hub input reland test contract.
