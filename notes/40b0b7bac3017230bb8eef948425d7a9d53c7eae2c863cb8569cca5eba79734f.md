# Await OTR notification changes before closing the ask-auth prompt

updateAuth saves the username, awaits notifyVerification on error, completed and waiting branches, then closes ask-auth by that saved name. closeAuth also takes a username rather than a Context, and closeAskAuthNotification returns early for a missing name. Keep this ordering and primitive identity boundary when changing authentication UI. A null-pointer check on individual Context getters is a separate safety measure.

Scope: chat/modules/OTRUI.sys.mjs.
