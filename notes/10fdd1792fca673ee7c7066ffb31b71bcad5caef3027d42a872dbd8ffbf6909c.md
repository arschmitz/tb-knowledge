# The Add-ons Nova override combines a preview alias, control selector and radius token

The manifest maps the Nova preview chrome URL to preview.svg. The Add-ons extra stylesheet hides aboutaddons-themes-mode, and shared variables map the search-radius token to the existing button radius. The actual Add-ons overlay appends that stylesheet, whose imports include the variables. This is static packaging/style evidence, not proof of the target image, computed rendering, theme availability or a backend policy.

Scope: Add-ons Manager Nova style overrides.
