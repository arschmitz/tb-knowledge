# Permissive RNP import skips experimental packets while preserving read-error failure

For tags 60 through 63, the parser takes the new skip branch only when skiperrors is enabled. A skip failure returns READ; a consumed packet returns BAD_FORMAT. The outer sequence loop tolerates that specific result only in permissive mode and avoids appending an empty reserved key. The new fixture test asserts strict rejection with zero public keys and permissive success with count two. It does not cover every tag, placement or read-failure path, and no import or crypto test was run here.

Scope: RNP permissive experimental-packet import.
