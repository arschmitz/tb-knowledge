# Verify that a send action reaches the protocol server

753 adds browser tests for toolbar, menu and keyboard sending. The tests wait for a usable compose editor and focus, trigger the real action and check the fake server message for a unique subject. Closing the compose window is only one part of the evidence. Account setup disables filing a copy so a transport test is not accidentally waiting for Sent-folder behavior. These tests were inspected, not executed against SMTP, EWS or Graph.

Scope: Compose send browser tests.
