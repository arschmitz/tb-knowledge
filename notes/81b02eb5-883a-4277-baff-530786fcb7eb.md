# Put the clickable inset on the compose address input

Bug 281299 reported a dead zone before address text where a click could not place the caret. D209916 asked to move the inline padding from .address-container onto .address-input, while leaving only block padding on the container in each platform stylesheet. The accepted patch also removed cursor:text from the whole container because address pills are not editable text. Bugzilla says this change made the cursor cue honest but did not fully remove every dead zone. The current CSS retains the input padding and pill cursor:default. When editing this surface, test caret placement and cursor shape separately.

Scope: Compose addressing.
