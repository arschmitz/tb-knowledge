# Keep folder property readiness failure distinct from missing customization

FolderTreeProperties starts JSONFile.load at module initialization, exposes ready, and throws "Folder tree properties cache not ready." before any getter/setter if loading is incomplete. After readiness, colors?.[folderURI] returns absence normally, and AccountManagerUtils applies its default. Await readiness at callers/tests instead of using optional chaining to hide an uninitialized store. Newer accepted source has this contract; no initialization runtime was run.

Scope: folder property persistence.
