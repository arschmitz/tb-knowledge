# The add-on install icon exception belongs to the host document image policy

D249063 adds the ATN host to messenger.xhtml img-src to preserve existing add-on icon behavior. Requiring manifest icons, always using an internal fallback and downloading a blob were discussed but not applied. The accepted source still passes the preferred icon to popupIconURL and assigns it to the popup icon attribute. The extension manifest CSP cannot replace this containing-document policy. No add-on installation or policy enforcement test ran.

Scope: Add-on post-install icon CSP.
