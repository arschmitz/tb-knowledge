# S/MIME certificate controls dismiss their owning popup before opening a tab

The signature and encryption buttons pass event.target.closest("panel") into their handlers. Each handler hides that popup and opens only when the matching global certificate exists. The markup uses focusable buttons with localized labels, lowerCamel IDs such as signatureCertView and dashed CSS classes such as button-focusable. Scoped control/naming recommendation: preserve the command-to-owning-popup relationship and existing namespace forms. This static wiring does not establish keyboard focus restoration or screen-reader behavior. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: S/MIME certificate control naming.
