# Removing the extraction locale menu leaves message extraction commands intact

The cleanup removes the two locale popups and their helpers, while plain event/task buttons still call extractFromEmail with gMessage. The removed locale helper supplied null, but extractFromEmail immediately reads message.folder and its decoded subject. That is a static caller-contract mismatch in the removed path. The surviving extractor still accepts fixed-language parameters; this patch does not remove the whole extraction service or establish a rendered menu result.

Scope: Calendar extraction toolbar commands.
