# Keep metric schema names distinct from generated language APIs

The Glean schema uses snake_case metric names such as folder_total_messages and boolean extra names such as is_signed. JavaScript accesses generated lowerCamelCase members such as folderTotalMessages, while C++ uses the schema spelling in mozilla::glean::mail::mails_read. Keep the schema name, generated member and declared label spelling paired. This is a local generated-API convention, not a reason to rename every ordinary identifier. Include the metric’s migration bug and event description with the right meaning: when an event fires differs from how many items a counter stores.

Scope: Telemetry naming and manual semantics.
