# Await window activation before returning the standalone message helper result

The old open_message_from_file called the async focus helper without await. This landing awaits a conditional activate promise before its final tick and return, so callers that await the message helper now include that barrier. The actual reply-format-flowed caller then performs its own focus step before opening a reply. Accepted code later adds a 5-second focus fallback; do not describe the original passive activate wait as equivalent to the removed nested-window focus logic or as a measured intermittent fix.

Scope: Mail browser-test window readiness.
