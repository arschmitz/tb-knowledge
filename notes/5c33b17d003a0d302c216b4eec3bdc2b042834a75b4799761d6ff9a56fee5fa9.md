# Decode positional BYDAY values before looking up Calendar weekday names

The migration's weekday map has numeric keys 1–7, while positional BYDAY values also encode an ordinal. Its original monthly branch uses the raw value as the key; for example 10 means position 1/weekday 2 and cannot match that map. Fixed accepted code decodes through day_of_week before lookup. Keep this original bug and later correction separate from the locale migration's broader claims. This is a static key/producer mismatch, with no rendered recurrence result or all-locale test.

Scope: Calendar recurrence localization weekday map.
