# The typed chat click method changes the receiver used by its state writes

The port replaces the chat alert's lexical arrow with an onAlertClick method but keeps this-based writes to timer and grouping state owned by Notifications. The inspected local mock invokes callbacks.onAlertClick(action), so that qualified call binds this to the callback object rather than Notifications. In that path the method's resets target the callback object. Preserve the intended Notifications receiver with a lexical callback or explicit owner when changing this code. The accepted source retains this shape; no native callback, chat click or runtime failure was reproduced.

Scope: Chat alert callback this binding.
