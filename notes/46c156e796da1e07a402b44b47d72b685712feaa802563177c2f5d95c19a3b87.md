# Folder URI preferences and completed folder creation are separate compose contracts

The rollback landing restores configured identity URI values so the send/copy caller can create remote Sent, Drafts or Templates folders. Its new copy tests directly assert created folders and local/fake-server messages, but manually create the identity and do not exercise createAccountInBackend. At the fixed accepted revision, getMsgFolderURIFromPrefs instead awaits asynchronous identity folder methods, and MessageSend awaits that result. Keep configuration, creation and copy assertions separate; a stored URI alone does not prove a remote folder exists. Static source only; required historical bug comment12 remains unavailable and this entry receives no full-audit credit.

Scope: Compose identity folder resolution and copying.
