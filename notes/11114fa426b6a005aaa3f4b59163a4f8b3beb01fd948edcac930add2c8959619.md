# Dynamic content browsers suppress the secondary default blank load before insertion

Entry 1306 sets nodefaultsrc on newly created content-tab and extension-popup browsers and removes an explicit about:blank popup source. The accepted code sets that attribute before insertion. The commit message reports a secondary about:blank navigation racing an extension protocol-handler error page after upstream changes; that explanation was not reproduced and the bug discussion has not been read. This is a scoped creation-order contract, not a claim that no initial blank document exists. No browser, error-page or application-chooser test was run.

Scope: Content browser default navigation.
