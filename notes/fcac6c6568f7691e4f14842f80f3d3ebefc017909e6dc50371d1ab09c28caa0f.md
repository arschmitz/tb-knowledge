# Edited PDF unload waits for save completion before allowing navigation

Entry 1474 adds edited-PDF Save/Cancel/Don't Save handling. The accepted Save branch installs its save-completion observer before sending PDFJS:Save to the PDF actor and waits for that promise before allowing departure. Cancel returns false; Don't Save allows departure without that wait. In this prompt flow, recommend registering completion before initiating the asynchronous operation so a fast completion cannot precede listener installation. This is a scoped ordering rule; no PDF save or navigation was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Edited PDF save/unload ordering.
