# NEEDS-ACTION relies on reset to clear the RSVP radio selection

The status callback returns for empty status or NEEDS-ACTION and does not uncheck a previous response. reset clears the checked input before removing the attribute. The standalone test calls reset before the NEEDS-ACTION case, while CSS only hides the decorative toggle. Consumers that need an unanswered state must preserve that reset step; a status string or hidden decoration alone does not prove the native radio state was cleared. This is static code/test coverage, not a live accessibility result.

Scope: Calendar acceptance widget status and reset contract.
