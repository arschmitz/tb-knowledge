# Filter-log header creation uses explicit file open flags after removing nsMsgFileStream

EnsureLogFile writes LOG_HEADER only when the log file is empty. After nsMsgFileStream and MsgGetFileStream were removed, this caller uses NS_NewLocalFileOutputStream with PR_RDWR | PR_CREATE_FILE and 0664, matching the removed InitWithFile open arguments. The earlier file-create branch still uses 0666. ClearLog disables logging, removes the file, calls EnsureLogFile and restores the enabled flag. This supports this output caller only; it does not prove identical seek, input, error mapping, short-write or close behavior across stream implementations. No new behavioral test or filesystem run was performed.

Scope: mailnews-filters.
