# Keep regression test identity and registration together when extending a test

929 extends the focus regression test to cover the popup close default and renames the file to browser_ext_windows_bug1732559_bug1902844.js. The accepted registration keeps both bug numbers. The current extension test manifests explicitly ask contributors to put new tests beside their alphabetical neighbors. Preserve an existing regression identity when its scenario gains related coverage, and update the correct manifest. This does not prescribe bug-number filenames for every test.

Scope: Extension regression test file naming.
