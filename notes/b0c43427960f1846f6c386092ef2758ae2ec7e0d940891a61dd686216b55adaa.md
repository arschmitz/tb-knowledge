# Use present-tense grammar for the environment-creation script

The make_venv.sh header uses the malformed verb sequence "will be create". The script creates an environment and installs packages from its requirements file. Suggested wording uses "creates" and "installs". This is an editorial suggestion checked against the source, not a new requirement inferred from frequent legacy wording.

Scope: Comment writing: taskcluster/docker.
