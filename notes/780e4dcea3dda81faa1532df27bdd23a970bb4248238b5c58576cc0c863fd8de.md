# Locale ellipsis replacement keeps each consumer text limit and output role

The port replaces local localized-preference reads with Services.locale.ellipsis. Extension labels keep code-point shortening; chat previews keep the 50-character crop and first-message condition; Gloda constructors fill their overflow labels. IM isTextSelection retains a Boolean return and only shortens a local variable. The shared value does not create a shared length limit, prove locale-change refresh of existing labels or establish the provider fallback behavior.

Scope: thunderbird-locale-ellipsis-consumers.
