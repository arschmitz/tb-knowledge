# Newsgroup Mark All Read stops filling unfetched article ranges while Download Headers retains its option

Removing the news override leaves Mark All Read on the base header-enumeration path. Current per-header news handling updates that article key in the read set rather than filling1..highWater. Download Headers separately permits marking a skipped older range read when markOldRead is enabled after the user accepts the dialog. Known fetched ranges are not read membership. This distinguishes two user actions; it does not promise atomic failure handling, persistence or correctness of every existing DB/newsrc mismatch. No NNTP/read-state test ran.

Scope: NNTP read state versus known download ranges.
