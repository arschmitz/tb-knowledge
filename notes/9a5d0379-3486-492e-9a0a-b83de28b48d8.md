# Name POP3 queue states like the existing connection lifecycle

In D206738 the reviewer explicitly requested _connectionWaitingQueue, _busyConnections, and onFree instead of the patch-specific onClientRunComplete and pop3ClientRunning names, to align with other mail protocol clients. The landed code uses those names. This supports a scoped naming rule: use established component terms for the same state and completion event. The same review requested deterministic completion instead of a 30-second poll, because a client could still be writing to a shared Inbox when the timeout expired; the landed code releases the queue from _actionDone.
