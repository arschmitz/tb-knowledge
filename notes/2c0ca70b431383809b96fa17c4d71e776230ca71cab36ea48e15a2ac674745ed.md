# Alternative protocol details use that alternative’s username

The historical selected-protocol display reads username from the default incoming configuration even after finding an alternative. The accepted display reads incoming.username from the selected incoming object. The current alternative-protocol test verifies changed username, host, port, security and authentication details. For this view, derive every displayed server field from the selected server, not a cached default. This is source-supported guidance; the test was inspected but not run, and the exact later repair history is outside this landing’s coverage. Full bug and review discussion remains pending.

Scope: Account Hub protocol details.
