# Reject stale folder-label localization before applying asynchronous results

Current #updateAriaLabel captures a serial number, awaits settled localization results and returns if a newer update took over. The scheduler debounces rapid changes separately. A timing-based test explicitly cannot guarantee that its localization promises overlap, so its final-value assertion alone does not demonstrate the race was exercised. The existing scheduling-versus-execution comment lesson is reused; this adds the actual result-ownership contract and test limit. This note is based on source inspection. Tests were not run, and full review discussion remains pending.
