# Document the actual value passed into a byte-array helper

The current decryptArray JSDoc still calls encrypted_array a string, but decrypt supplies a ctypes uint8_t array. Treat this as an unresolved documentation mismatch. Proposed manual rule: describe the concrete representation at foreign-library boundaries and keep the helper name, parameter type and caller consistent. A standard spelling or formatter check cannot establish that a parameter description matches the value. Do not copy this historical string annotation into new byte-array APIs.

Scope: OpenPGP manual API documentation.
