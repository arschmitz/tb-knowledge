# The all-headers forwarding test checks a whitespace-header name and the original body

This task stores a message whose final header value contains only space and tab, selects AllHeaders and calls the real compose-service inline-forwarding entry point with the local fake SMTP setup. It waits for nonempty captured DATA and checks that the header name and original body marker appear. Both assertions have explicit should messages. These direct substring assertions are narrower than exact header-value preservation, complete SMTP delivery or a crash/sanitizer result; no test was run in this source study.

Scope: MIME compose xpcshell tests.
