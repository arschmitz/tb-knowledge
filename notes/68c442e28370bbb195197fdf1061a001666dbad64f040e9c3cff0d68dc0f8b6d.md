# SMTP and POP3 log handshake certificates while retaining failedSecInfo propagation

The port changes only the certificate-array reads in SMTP/POP3 error diagnostics to handshakeCertificates. Both log a nonempty chain as common names and serial numbers after obtaining security info. The surrounding failure contract is separate: SMTP passes the original error/security context to its callback, and SMTP verification plus POP retain the URL property failedSecInfo. Do not mechanically rename that property with the diagnostic array. These comm call sites do not establish upstream array availability, certificate trust or a successful TLS operation.

Scope: SMTP and POP3 security diagnostics.
