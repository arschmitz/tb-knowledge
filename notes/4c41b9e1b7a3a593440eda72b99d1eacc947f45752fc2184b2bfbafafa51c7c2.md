# Offline-folder picker tests suppress AutoSync through a scoped default preference

The owned offline-settings setup disables the default autosync_offline_stores preference before server creation and clears it later; accepted setup uses pushPrefEnv for that same false value. The mapped server accessor feeds AutoUpdateFolders, which skips false values. Explicit offline/body-required download branches remain separate conditions. This is a test-isolation source contract, not proof that all downloads, timers or per-server overrides are disabled or that a leak was reproduced.

Scope: Offline settings test AutoSync isolation.
