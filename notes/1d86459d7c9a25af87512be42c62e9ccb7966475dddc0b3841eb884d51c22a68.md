# Treat OpenPGP MIME wrapping and cryptographic decryption status separately

The Git commit spoof fix removes MIME-side inference that a signature failure should still count as decryption success. At the fixed accepted source, mimeDecrypt adds PGP_MIME_ENCRYPTED only when RNP returns DECRYPTION_OKAY, and it throws when no return status exists. Preserve the cryptographic status boundary rather than inferring encryption from the outer MIME shape. The original landing was backed out and later relanded with a missing-status change; test-failure cause and discussion remain unread.

Scope: mail / extensions.
