# Mailnews password tests load the key database and selected login fixture together

setupForPassword copies the shared key4.db and a selected signons JSON file to the same test profile, names the JSON logins.json, and returns login-manager initialization. The IMAP failure test awaits that helper before reading its intentionally invalid stored password. The owned update refreshes the paired database and encrypted login records without changing production migration code. Keep fixture loading, later async password replacement, and production login migration as separate scopes. Static database/JSON inspection cannot prove NSS decryption or cryptographic coherence. No test ran.

Scope: Mailnews protocol password test fixtures.
