# Carry converted folder metadata through traversal

The virtual-folder fix uses convertedFolder.isUnified and convertedFolder.isVirtual instead of repeating raw flag checks during recursive traversal. Virtual-folder children may belong to different accounts, so traversal clears the account ID for them. D210298 author identified the old repeated lookup as expensive; the reviewer asked for a restriction test, which the landed patch added. This is a scoped API and review lesson: use already-computed folder metadata and cover the cycle boundary.

Scope: Extension folder API.
