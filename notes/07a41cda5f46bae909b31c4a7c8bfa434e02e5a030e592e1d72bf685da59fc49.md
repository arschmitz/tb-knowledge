# The Exchange service-URL step overrides the shared Account Hub grid gap

The .account-hub-step grid has a nested &:is(email-exchange-settings) selector that changes this host gap to var(--space-xlarge). The parent template gives that custom element the account-hub-step class. The selected code does not contain the trailing form selector from the corrected review proposal. This is a scoped source/layout input, not proof of a24px computed gap or rendered accessibility result.

Scope: Account Hub Exchange service-URL spacing.
