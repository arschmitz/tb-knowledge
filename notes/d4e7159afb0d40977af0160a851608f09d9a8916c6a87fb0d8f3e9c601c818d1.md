# Preserve subscription changes when filtering into cloned rows

Accepted SubscribeDataAdapter filters to flat clones that retain childPath and originalRow. Before replacing a filtered view or accepting the dialog, checked state is synchronized to those original rows. The final change collector compares checked with wasChecked across the master hierarchy. Reading only the visible filtered rows would lose hidden changes or mistake a clone for the backend path. This newer implementation is current context for the 2024 control removal; its later history is not counted covered. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/base/content.
