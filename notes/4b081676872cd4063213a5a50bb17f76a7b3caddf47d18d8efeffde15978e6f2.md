# Keep failed nested signature verification from replacing the outer plaintext

inlineInnerVerification starts with the outer plaintext and returns it unchanged if there is no inline signed block or inner verification fails. On success it replaces the text, combines status flags and copies key, user, signature and message details. It deliberately does not merge encToDetails from the inner verification. The inner attempt must not erase already available outer content or encryption recipients. The code paths were inspected; no nested decryption runtime test was run in this batch.

Scope: Nested OpenPGP status ownership.
