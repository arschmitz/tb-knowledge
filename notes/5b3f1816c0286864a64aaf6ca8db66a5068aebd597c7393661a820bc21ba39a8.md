# Folder discovery continues past selected child failures

PopulateFolderHierarchy skips a child when AddSubfolder fails unexpectedly and logs a recursive child failure before continuing siblings. DiscoverChildFolders, parent GetName, child lookup and null-child guards can still return errors. A final NS_OK can therefore coexist with skipped sub-hierarchies. Mbox passes its deep flag; the selected Maildir caller requests deep traversal. This bounds the recovery to traversal continuity; it does not repair the failing folder or remove filesystem path limits. No deep-error test or platform reproduction was run.

Scope: Shared folder hierarchy population.
