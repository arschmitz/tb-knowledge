# Windows Searchfox declares its App SDK fetch separately from ordinary builds

The win64-searchfox/debug task has its own fetches.toolchain list and explicitly requests winappsdk-x86_64-pc-windows-msvc. The earlier ordinary Windows build fetches and toolchain reference list do not by themselves add that request to Searchfox. When tracing a missing build artifact, check the actual consuming kind as well as reference-task availability. This is a scoped configuration contract. No taskgraph, toolchain download, Windows build or Searchfox job ran.

Scope: taskcluster.
