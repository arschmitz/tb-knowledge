# Cache Sync records so unknown types and properties survive a round trip

CachedStore stores complete incoming and outgoing record cleartext in compressed syncDataCache.lz4 under the profile, keyed by engine and record ID. Each engine overlays fields it understands when creating an outbound record. Unknown object types are not created locally, but cached records stay addressable; unknown fields on a known type remain in cleartext. The new test head preloads one unknown record per engine, and store tests encrypt and decrypt unknown types and extra fields to prove round-trip preservation. This is a forward-compatibility contract for older clients.

Scope: Thunderbird Sync compatibility.

Paths:

- `mail/services/sync/modules/CachedStore.sys.mjs`
