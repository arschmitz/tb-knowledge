# Platform selection must use the constants expected by native code

The hidden-window removal also changes the test modifier helper to AppConstants.platform. Entry 788 changes DNS worker input from mockable Services.appinfo.OS to AppConstants.platform and AppConstants.unixstyle. The worker uses win for Windows and freebsd or openbsd for special resolver-library candidates. Producer and consumer spellings change together. Manual platform naming proposal in these modules: use the constant namespace and exact values the consumer expects; do not mix WINNT-style application-info values with win-style platform constants. The DNS commit says Windows xpcshell mockAppInfo caused the wrong library load. That explanation was read from the commit, not reproduced with an actual Windows failure diagnostic.

Scope: native-platform-contract.
