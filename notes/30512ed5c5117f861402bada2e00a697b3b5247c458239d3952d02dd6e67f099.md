# RSS reply-button visibility is separate from compose-command enablement

Although IsReplyEnabled was deleted, UpdateReplyButtons still hides the reply buttons for feeds. IsReplyAllEnabled also returns false for a feed after its newsgroups check. The current common controller’s general reply/forward/EditAsNew enablement is based on identities and message selection; the inspected branch does not contain the old feed predicate. Keep button visibility and controller eligibility separate when reviewing this path. The source does not establish that an enabled command on a feed is a defect. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: mail reply command states.
