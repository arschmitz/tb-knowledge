# DAV stream errors preserve a native result while rejection still carries the response

CalDavSimpleResponse stores a Connection error exception with the native stream status, but resolves or rejects with the response according to Components.isSuccessCode. The exception is constructed for success too, so its presence alone is not failure. Calendar failure handlers extract streamError.result; CalDAV/ICS detection logs the exception as a separate argument while retaining special detection/auth/certificate rethrows and normal fallback behavior. The owned getter JSDoc still says nsresult; the fixed accepted getter says Exception, matching the review request. No network-error result was reproduced.

Scope: CalDAV and ICS network error logging.
