# Empty-space tree mousedown restores focus only when the event targets the host

The handler checks event.target==this before focusing the table body and preventing the default mousedown action. The current BaseTreeView helper names the body as the accessibility focus owner. Descendant row targets do not enter that branch, and the branch does not mutate selection. The selected test proves only its intended Tab-order assertions in source; it adds no direct empty-host pointer assertion. No focus or screen-reader execution ran.

Scope: Virtualized tree pointer and accessibility focus.
