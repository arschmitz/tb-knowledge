# Folder-upload confirmation uses a delayed affirmative button and default Cancel

The accepted folder-upload prompt places Cancel at the default button, delays enabling the affirmative Upload action and sets the prompt to tab modal for the supplied browsing context. The result is converted to true only for Upload. Preserve these distinct safeguards when adapting this prompt; they are local behavior, not a rule that every dialog must delay its primary button. No dialog, keyboard, button delay, focus or upload test was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Folder-upload prompt action policy.
