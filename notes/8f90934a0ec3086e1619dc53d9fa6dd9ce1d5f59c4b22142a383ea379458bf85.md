# A missing OpenPGP compose dependency is an initialization error

The accepted OpenPGP composeStartup throws "OpenPGP initialization failed" when gMsgCompose or its fields are absent. NotifyComposeFieldsReady directly queries the editor interface rather than hiding failures in an empty catch. For this initialized-compose contract, recommend making a missing required dependency visible instead of silently skipping setup. This does not show that every exception reaches a user-visible error message; no startup failure was reproduced and review disposition is pending.

Scope: OpenPGP compose initialization.
