# A minimized Account Hub restores the active flow before honoring a new flow request

Minimizing closes the modal without resetting the active view and exposes a placeholder. While minimized, open(type) restores that view and returns before loading the requested flow. Email and address-book subview changes request maximization, while request-close is ignored until restored. The tests directly check placeholder state, a simulated hidden-view transition and keeping the email config view when ADDRESS_BOOK is requested. The address-book completion helper separately requests close and opens the address-book tab; it does not itself request maximization, so the review's future confirmation idea is not an implemented guarantee. No UI result was reproduced.

Scope: Account Hub minimize and flow state.
