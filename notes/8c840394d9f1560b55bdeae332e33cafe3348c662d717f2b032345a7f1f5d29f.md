# Wait for the EML copy to reach its destination before closing the source window

browser_imageDisplay waits until gImageFolder.getTotalMessages(false) equals one before closing the EML window. The next test opens that folder and checks the embedded image. Keep this operation-completion condition: opening the message or choosing a copy menu is earlier than completion of the copy. The equality is tied to this one-message fixture, not a reusable predicate for every destination folder.

Scope: mail/test/browser.
