# Pass the activating event through compose commands so Shift keeps its meaning

Current command markup passes event, doCommand forwards its rest arguments, and _composeMsgByType selects OppositeOfDefault when event.shiftKey is true. This is why a compose action cannot replace an event-bearing call with a type alone without checking the format behavior. Scoped manual signature guidance: preserve the optional event through these command routes. No Shift-click or keyboard-format test was executed. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending.

Scope: compose command event contract.
