# The compose m_baseWindow removal changes a specific backend close sequence

The historical cleanup replaces cached tree-owner Destroy with outer-window Close after unregistering the compose docshell and clearing send/editor state. If the outer-window lookup fails, the method returns after those cleanup steps. Its JavaScript helper also has a direct window.close fallback, so this is a bounded backend path. Accepted source later uses direct close in the command and moves selected cleanup into the destructor; no native destruction timing or reproduced close result was measured.

Scope: Compose window ownership and cleanup phases.
