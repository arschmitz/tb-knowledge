# EWS fake-server listenPort is separate from its advertised identity port

EwsServer.listenPort configures the underlying HTTP listener, with -1 requesting a random port. Constructor hostname/port configure an advertised identity used by ServerTestUtils and do not choose the listener. The exposed port getter can return the HTTPS proxy port. Preserve these roles when constructing failure tests: the owned connection-error test used10101 to keep a reachable wrong-path server separate from intentional refusal at 10000. Static fixture inspection only.

Scope: EWS fake-server listener setup.
