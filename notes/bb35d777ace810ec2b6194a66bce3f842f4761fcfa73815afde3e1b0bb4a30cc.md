# Cleanup must tolerate already-removed paths

The imported Task 4 summary identifies a cleanup failure when another operation has already removed a directory. Task-worktree cleanup should tolerate missing paths rather than assume every selected directory still exists. This adds a concurrency constraint to cleanup; it does not authorize deleting dirty worktrees or protected recovery refs. The supplied evidence is a historical summary, so verify the current cleanup implementation before treating this behavior as implemented.

Scope: console worktree cleanup.
