# An empty attached-key UID list does not by itself request reimport

The attached-key path requests cached lookup but still permits loading an empty cache. Its update decision handles expiry/revocation first, then compares a nonempty incoming UID list by userId values. An empty incoming list alone does not trigger that UID update branch. The caller awaits silent import and warns on a false result. These are scoped source paths, not a key-import, trust or performance guarantee.

Scope: OpenPGP attached-key update comparison.
