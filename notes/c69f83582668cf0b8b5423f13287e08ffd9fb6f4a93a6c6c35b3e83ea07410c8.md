# The profile export test separates button readiness from export completion

After the export tab loads, the test yields an animation frame, asserts that Export is visible, focuses it and yields a tick before clicking. Progress and finish visibility are separate later waits. The final file check only requires export.zip to exceed 10 bytes; it does not inspect archive contents. These source-level steps do not establish a specific rendering barrier or a fresh timeout cure.

Scope: import-export/profile-tests.
