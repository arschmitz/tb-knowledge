# Deferred Calendar property forwarding was later restored to direct notification

The original patch queues uncached-calendar property forwarding on the main thread after capturing home. A later exact inverse restores direct ObserverSet.notify, and the fixed accepted code uses that direct call. ListenerSet invokes each observer method without awaiting returned promises, so direct dispatch is not a guarantee that asynchronous observer work has completed. Keep the attempted defer, reversal and current delivery distinct; the Avoid reentrancy comment is not an accepted general observer policy. No runtime or causal UI test was run.

Scope: Cached-calendar observer delivery phases.
