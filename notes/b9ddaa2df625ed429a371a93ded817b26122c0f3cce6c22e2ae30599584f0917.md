# Sync widget names connect module, tag, class and include template

This component uses email-sync-accounts-form.mjs, the email-sync-accounts-form custom tag, the EmailSyncAccountsForm class and the accountHubEmailSyncAccountsFormTemplate.inc.xhtml fragment with a matching template ID. Its DOM IDs use lowerCamelCase while local semantic CSS classes use hyphens. Follow each established name layer when adding related sync controls; this is a scoped naming pattern, not a rule to convert every Thunderbird file or legacy ID. Source/package references were inspected, but no resource load or registration test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub sync component naming.
