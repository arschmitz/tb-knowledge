# The checkbox clones its own template despite an input-template documentation line

The checkbox implementation looks up accountHubCheckboxTemplate, and that template contains a native checkbox and label. Its current class comment still names accountHubInputTemplate. The original addition also used the input tag name and a string checked type; those two descriptions are corrected in the accepted source. Keep the actual template, tag and Boolean receiver distinct when maintaining these copied comments. This is a documentation mismatch, not a failed-template or runtime claim.

Scope: Account Hub checkbox documentation and native receiver.
