# Keep external GPGME signing in the PGP/MIME base64 path

The signed PGP/MIME payload is forced to base64 when using an external key, even when encryption is enabled. The other case is signed but unencrypted PGP/MIME. The source warns that UTF-8 bytes given to GPGME can be transformed, and that transport can rewrite unencrypted signed 7bit/8bit payload encoding. Either change can break the signature. PGP/INLINE is outside this condition. Preserve that exact scope when changing compose encoding.

Scope: mail/extensions/openpgp.
