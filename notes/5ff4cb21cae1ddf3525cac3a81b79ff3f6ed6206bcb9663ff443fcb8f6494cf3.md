# Apply popup browser configuration before URI loading

extensionPopup sets allowscriptstoclose, usercontextid and messagemanagergroup on the existing requestFrame before emitting extension-browser-inserted and loading the requested URI. This keeps policy and container state on the browser used for the load. The historical removal of a replacement operation and popup container test are source evidence for this route, not proof that every popup teardown or identity flow is correct. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.

Scope: mail/components/extensions.
