# The Graph setup backout preserves newer discovery and EWS client changes

This 19-path backout restores the original pre-Graph blobs in 14 paths. Five files retain intervening work: sync-account discovery/Skip behavior and its strings/test, logical CSS properties, and cached EWS-client lifecycle changes. GetLocalStoreType returns the literal ews value again, while GetProtocolClient still reuses mClient and Shutdown still forwards to it. The backout is a scoped removal of Graph setup, not a full restoration of the older tree. The later accepted Graph/Exchange model is a separate phase.

Scope: Account Hub Graph/EWS setup history.
