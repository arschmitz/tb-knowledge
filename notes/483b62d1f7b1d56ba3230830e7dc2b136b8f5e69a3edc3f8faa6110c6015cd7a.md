# The CMake define generator preserves literal-valued defines

GeneratedFile substitutes configured @NAME@ values and lets a configured name override an existing #define value. If an unknown name already has a literal value, the generator preserves that value instead of converting the line into an undef comment. This supports literals such as [[fallthrough]] without treating the parser as a complete C preprocessor.

Scope: build/cmake-template-defines.
