# IMAP derives its locked SpecialUse mask from combined folder flags

SetBoxFlags starts with mFlags, adds mailbox-derived flags and locks the SpecialUse portion of the combined result. A pre-existing SpecialUse bit can therefore enter the mask; this is not a separate server-only bitset. ClearFlag and ToggleFlag return success without changing any bits when the requested mask intersects a locked bit, while SetFlags restores locked bits by OR. The added single-bit tests do not prove compound-mask behavior or local-bit provenance before a later discovery call. Actual user reachability and a runtime failure remain unverified.

Scope: IMAP special-use flags and shared flag mutation.
