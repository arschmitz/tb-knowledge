# Malformed-mbox gtest helpers return read failure to the test

Entry 1202 changes ExtractFromMbox from an assertion-hiding helper to an nsresult-returning helper, and its callers assert the result appropriate to the case. For this parser test family, propagate setup/read failures so a malformed fixture can assert the exact error rather than fail inside a helper intended for successful reads. This is a scoped test design recommendation; the helper and changed chunked tests were read but not compiled or executed. Full bug and review discussion remains pending.

Scope: Mbox parser C++ tests.
