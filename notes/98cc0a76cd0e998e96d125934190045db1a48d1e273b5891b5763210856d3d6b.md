# Reused thread rows clear twisty labels and expanded state when the row becomes a leaf

Both row layouts use container/collapsed classes produced by the base fill to choose a localized expand or collapse name and the inverse expanded value. When a virtual row becomes a leaf, both paths remove the Fluent ID, aria-expanded and aria-label instead of retaining the old thread metadata. The underlying click handler still toggles containers. These are static state/cleanup contracts; the retained template flags, localization completion and live keyboard/screen-reader exposure were not executed or proved.

Scope: Card/table twisty metadata and virtual-row state producer.
