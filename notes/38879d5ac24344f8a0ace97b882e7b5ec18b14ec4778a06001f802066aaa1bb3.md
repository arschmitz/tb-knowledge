# Named account-manager access retains a shutdown guard and a legacy commit result check

The account-manager migration uses the named Service accessor in normal operations and keeps typed nsCOMPtr ownership. Biff destruction can run after service removal during shutdown, so listener cleanup checks the returned manager. Legacy non-Panorama database Commit separately requests Service(&rv) before folder-cache work. These scoped exceptions prevent treating the migration as a global nonnull guarantee or permission to remove operation checks. No runtime test.

Scope: mailnews-static-service-lifetime.
