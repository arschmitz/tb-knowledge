# Keep malformed OpenPGP decryption fallback bound to external-key use

Entry305 routes BAD_FORMAT toward GPGME only when external GnuPG is enabled. Possession of the private key in RNP changes whether malformed inner armor yields BAD_FORMAT or a missing-key error, so testing only one key-storage setup misses the problem. The fallback must not pretend the malformed result has a verified signature. Current code keeps the external preference guard. This does not justify treating all malformed encrypted data as valid.

Scope: OpenPGP error fallback.
