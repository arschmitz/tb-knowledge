# Account-removal result assertions read the labels' hidden properties

The account-removal producer clears success.hidden after completion or failure.hidden in its catch path; both labels begin hidden. The selected test waits for either property to clear and asserts the success/failure properties directly. This checks explicit result state rather than rendered visibility, which also depends on ancestors. The later fixed helper uses acceptDialog, but that separate phase is not introduced by this property-check patch. No rendered visibility or runtime cure is claimed.

Scope: Account-removal browser-test completion.
