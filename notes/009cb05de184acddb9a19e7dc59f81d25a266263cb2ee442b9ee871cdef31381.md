# The Flatpak image switch pins the base, while the explicit command-entry reset belongs to a later phase

This landing replaces the Flatpak base tag with the reviewed upstream @sha256 identifier and removes the local pip installation. The release worker selects tb-flatpak and passes a bash command for repack.sh. The owned Dockerfile retains CMD but has no explicit ENTRYPOINT reset; the fixed accepted Dockerfile later adds ENTRYPOINT []. Keep those source phases separate. The repack caller records linter status and exits after artifact work, but the inherited image contents and Docker command behavior were not executed or independently verified.

Scope: Flatpak build image and release repack.
