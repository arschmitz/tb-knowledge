# Keyboard Save tests must account for the Close button

For D332891 at revision dab61204576552c4e7a6bce2f010ccb2b87047c1, the verification record reports that both dialog templates place a focusable Close button between the calendar selector and Save. The keyboard test expected one Tab to reach Save, so its Enter action could activate Close instead. The scoped recommendation is to test selector-to-Close-to-Save navigation and its reverse, and assert Save focus before activation. Keep Close-discard coverage separate. This is an AI-reported source inspection finding; no matching-build browser test ran, and no applied or accepted correction is recorded. It does not establish a general focus order for other dialogs.

Scope: Calendar event edit keyboard tests.
