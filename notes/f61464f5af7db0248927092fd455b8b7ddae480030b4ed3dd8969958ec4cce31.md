# Reply-selection tests rebuild each message range before its own compose action

The reply-selection tests create ranges inside the message browser through awaited SpecialPowers.spawn, then open the reply in the outer test flow. The plain-text test performs the text-range and whole-pre scenarios separately, closing the first compose window before changing selection. It directly checks exact selected lines in one scenario and long-line preservation in the other. This records test source intent, not observed cross-process quoting or a general iteration rule.

Scope: Thunderbird browser reply selection tests.
