# Preserve PDF content type in attachment open URLs

The internal PDF viewer depends on the attachment URL carrying type=application/pdf. A broad check for any type parameter prevented that value from being added and stopped PDF attachments opening internally.

Scope: attachments.

Paths:

- `mail/modules/AttachmentInfo.sys.mjs`
