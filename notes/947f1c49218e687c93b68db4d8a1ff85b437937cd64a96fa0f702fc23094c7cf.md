# Moving a mock Exchange item returns a new server ID

The insertion helper now rejects an existing ID. The move helper instead updates the existing item, emits deletion under the old ID and creation under a new moved-item ID, replaces the map key and returns the new ID. Tests that identify moved content must use that replacement identity or content assertions rather than assume the old ID survives. This scope is the shared mock server; it does not establish real Graph or EWS behavior.

Scope: Exchange test-server item identity.
