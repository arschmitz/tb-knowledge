# Account Hub localizes the close button title inside its shadow root

The Account Hub native close button binds account-hub-close-button, whose Fluent message supplies .title = Close. The icon keeps empty alt text. The header connects its shadow root to DOMLocalization with accountHub.ftl, so keep the button binding, message attribute and localization root together when changing this control. The title is source naming evidence; the computed accessible name, tooltip and announcements still require validation in the actual dialog. No keyboard or assistive-technology run occurred.

Scope: account-hub-accessibility.
