# Name preference-state tests for the state they actually assert

The current disabled integration manifest explicitly sets mail.inappnotifications.enabled=false. Its task still says test_documentContainsManagerWhenPrefTrue but asserts zero managers. Use scenario names that agree with setup and expected result, and set the tested preference in the manifest instead of relying on a changing product default. Historical 834 depended on the then-disabled default; that is not the preferred current registration pattern.

Scope: Notification integration test naming.
