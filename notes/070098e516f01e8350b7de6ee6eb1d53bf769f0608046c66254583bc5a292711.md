# Trace inherited input margins before matching Account Hub menu alignment

The Account Hub review traced a dropdown alignment mismatch to inherited m-c input margins. It also requested focus-visible and existing focus variables. The accepted patch resets menulist margin-inline and uses focus-visible with a component color and the shared outline offset. The broader container/flex/gap layout proposal is not fully established by that diff. Acceptance was limited to the light-theme scope with High Contrast work deferred. Recheck the real inherited rules and current control type; today's incoming form uses account-hub-select rather than the historical XUL popup.
