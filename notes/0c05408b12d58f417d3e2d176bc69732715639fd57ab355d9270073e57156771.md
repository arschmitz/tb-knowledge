# Filter continuation uses the confirmation Boolean rather than localization success

The Fluent continuation prompt formats filter-continue-execution with filterName, initializes returnVal to false and returns the value supplied by Confirm. Missing current filter, formatting failure or absence of a usable dialog does not produce a true continuation result. At the original landing the dialog came from m_msgWindow's docShell; fixed accepted source later uses the most recent window through nsIPromptService. Caller window guards and end/next-filter decisions remain separate from the helper's Boolean. No prompt or filter operation was run.

Scope: Post-filter failure prompts.
