# Prefix the combined changed and outgoing comm paths once

The decision task collects changed files from the comm repository. For try-comm-central hg-push it unions outgoing files into that set, then applies prefix_paths once to the combined set and sorts the result. The helper joins comm_src_path to each file and returns a set; its decision-task default prefix is comm/. Applying the prefix only to changed-since-base files would leave outgoing-only files in a different path form. This is the Part 2 follow-up to repository-based discovery, not a second audit of that original change. Imported repository and path-join implementations remain outside the paired comm evidence; no decision task or task-selection test was run.

Scope: taskcluster/decision/changed-files.
