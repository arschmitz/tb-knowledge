# The EmptyFolder fake does not establish recursive cleanup or exact response XML

The fake EmptyFolder handler calls emptyRemoteFolderById, which deletes direct messages and immediate child-folder entries. Its called deleteRemoteFolderById removes one folder entry and does not recurse, so nested descendant folders and their messages are not covered by this model. The existing trash test checks one child disappearing locally and remotely; it does not assert deeper contents or old-server completion. The fake also emits DeleteFolderResponseMessage children while the vendor response test uses EmptyFolderResponseMessage. Its error comment names ErrorFolderNotFound but code emits ErrorItemNotFound. Those are concrete fixture/comment limits; no XML parser failure is inferred. The handler adds operation support without new assertions. Use nested-folder, message and callback assertions before claiming those behaviors are tested; no tests ran in this study.

Scope: mailnews/test/fakeserver.
