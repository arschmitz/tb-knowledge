# The Exchange directory move preserves the owned EWS and Graph registration identities

The directory move updates components.conf header paths to protocols/exchange while preserving its owned CIDs, Ews class/constructor names and ews/graph contract IDs. The source build file still selects that manifest. Accepted code later uses Exchange-prefixed classes and further factory/interop changes, so those changes must not be attributed to this move. A directory name does not establish a renamed account type or protocol contract, and exact file identity does not establish unchanged callers or a successful build.

Scope: Exchange directory and component registration phases.
