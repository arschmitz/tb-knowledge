# Mailbox-info argument guards run before folder state changes

UpdateImapMailboxInfo checks aProtocol and aSpec before resetting pending counts, opening the database or reading the mailbox spec. The fixed accepted receiver retains these guards. Its inspected protocol caller passes this and a newly created reference-counted spec, then continues to header collection without checking the callback result. This establishes local ordering, not why null inputs were reported or that the crash was cured.

Scope: IMAP selected-mailbox callback.
