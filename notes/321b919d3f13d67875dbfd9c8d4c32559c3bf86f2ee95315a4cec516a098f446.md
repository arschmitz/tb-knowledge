# Make CSS selection overrides cover text and the folder icon together

The accepted preferences stylesheet pairs selected-row background with selected text color and gives focused selected synchronizeTree twisties and folder icons a currentColor-derived fill plus currentColor stroke. The historical msgSelectOffline.css file is absent. Preserve selector state and icon/text pairing when editing the surviving stylesheet; copying its !important declarations into unrelated selectors is not justified. Forced-color contrast and actual focus visibility need a live check.

Scope: mail/themes/shared.
