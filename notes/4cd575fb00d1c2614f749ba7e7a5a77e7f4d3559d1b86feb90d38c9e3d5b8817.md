# Describe the provider-detection collection by its actual key type

761 corrects detection documentation to a Map keyed by provider objects with arrays of calendars as values, rather than treating the keys as simple provider-type strings. Current callers consume those provider instances. Proposed manual JSDoc rule: trace the collection construction and iteration and name both key and value types. A similarly named type string is not interchangeable with the provider object.

Scope: Calendar discovery data shape.
