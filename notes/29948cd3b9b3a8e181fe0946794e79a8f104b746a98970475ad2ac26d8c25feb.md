# Exchange new-folder flags combine trash selection with offline preference

After base folder creation, Exchange reads existing flags, adjusts Trash from the configured path, optionally adds Offline and writes the combined flags once. The offline preference affects this new-folder route; a false value does not explicitly clear an existing Offline bit. There is no Trash/Junk exclusion in the checked block. This flag state does not prove messages were downloaded. No folder or offline test ran.

Scope: ExchangeFolder AddSubfolder flag assembly.
