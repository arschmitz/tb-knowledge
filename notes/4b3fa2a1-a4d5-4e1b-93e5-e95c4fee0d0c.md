# Name a MIME parts API for its actual output, not rendered message body

messages.listInlineTextParts returns flat text/* non-attachment MIME parts as content strings from the decrypted tree. It does not render one body or convert HTML to text, and it does not descend into an attached message/rfc822 to return that message's body. D210790 renamed the API and content field to prevent those expectations. Current isAttachment classification determines which related parts qualify, so the old discussion's blanket related-part exclusion is not current. Generalized filtering proposals were not implemented.

Scope: extensions MIME API naming.
