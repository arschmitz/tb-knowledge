# Hide absent search integration and disable a present but unavailable service

Bug 1852699 removed osVersionTooLow, an obsolete Windows XP era gate. In Preferences, a missing SearchIntegration hides the search option; an available module whose OS components are not running leaves the option visible but disables and unchecks it. The startup dialog also keeps a distinct Windows performance rule: if the option is off and the dialog is not opened from Preferences, it hides the checkbox and marks first run done. The current checkout keeps this distinction, and browser_general.js tests disabled, enabled, and unavailable cases. Do not collapse service availability into OS version or one generic hidden state.

Scope: Desktop search integration.
