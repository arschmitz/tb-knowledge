# Task-delete enablement first checks the selected task calendars

The task-delete command obtains getSelectedTasks and returns false for an empty selection or any selected calendar denied by userCanDeleteItemsFromCalendar. Passing that guard still falls through to the existing common command enablement expression. The helper obtains the current visible task tree and the delete action passes those selected tasks to deleteOccurrences. The ACL predicate separately allows absent/no access-control, owner or explicit delete permission; this source change does not prove complete authorization or native execution.

Scope: Calendar task toolbar command controller.
