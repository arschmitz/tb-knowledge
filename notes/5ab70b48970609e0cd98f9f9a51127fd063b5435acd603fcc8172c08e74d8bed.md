# The file-message helper replaces its explicit MsgLoaded wait with display polling

This landing removes the standalone MsgLoaded event wait but retains wait_for_message_display_completion(win,true). The comm helper checks the about:message document and message-browser load state, requires a nonblank URI, and yields a tick. Window-document selection, message display and subsequent focus remain separate barriers. These checks do not prove decryption, a particular message identity or native activation.

Scope: Message readiness phase.
