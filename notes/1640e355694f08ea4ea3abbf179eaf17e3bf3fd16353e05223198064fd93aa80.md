# The revoked-key dialog treats the reason code and owner text separately

For a revoked key, reloadData hides the acceptance selection and obtains code and owner text. A truthy code other than no selects a code message; nonempty owner text independently selects the reason message. Three named code IDs exist in Fluent. The dialog catches extraction errors and warns. These branches do not establish successful native extraction, translation or rendered accessibility behavior.

Scope: OpenPGP key details revocation display.
