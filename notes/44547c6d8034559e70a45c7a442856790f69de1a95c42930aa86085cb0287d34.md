# Follow the custom QR widget naming family without generalizing pane filenames

In this component, QrCodeWizard is a PascalCase JavaScript class, qr-code-wizard is the custom-element tag and qr-code-wizard.mjs is its module filename. The template and element IDs are lower camel case: qrCodeWizardTemplate and qrCodeWizard. Widget test files use browser_qrCodeWizard.js and a matching fixture name, while task names keep test_ and meaningful method/case suffixes. Preserve each existing namespace when adding neighboring code. This is a scoped naming pattern; the pane’s separate file conventions are owned by the preceding batch.

Scope: mail/components/preferences.
