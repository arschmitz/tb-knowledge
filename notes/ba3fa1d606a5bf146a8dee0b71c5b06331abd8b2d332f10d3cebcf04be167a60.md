# The original concrete mailbox casts and accepted object-query guards are different phases

The original interface-removal patch replaces QI with static_cast to nsMailboxUrl. The actual registered factory produces that concrete class on the inspected service route. Accepted later source uses do_QueryObject and explicitly rejects a missing concrete object during initialization; PrepareMessageUrl also checks the concrete result. Preserve the original assumption and later checks separately. These bounded producer/consumer proofs do not establish every external caller or an observed crash.

Scope: Mailbox URL receiver provenance.
