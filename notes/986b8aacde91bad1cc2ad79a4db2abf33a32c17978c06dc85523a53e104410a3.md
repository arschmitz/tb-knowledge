# Name native helper files for their class and keep their guards scoped to the path

The extracted helper pairs are MboxScanner.h/.cpp and MboxCompactor.h/.cpp; current header guards are COMM_MAILNEWS_LOCAL_SRC_MBOXSCANNER_H_ and ...MBOXCOMPACTOR_H_. Follow this local UpperCamelCase class/file pairing and full path guard when adding adjacent helpers. This is a scoped observed naming pattern, not a claim that all Thunderbird native files use the same prefix or casing. The implementation-only headers are not exported by this build list. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: mbox helper naming.
