# Keep the shortcut modal’s scroll region inside its fixed layout

The current shortcut dialog has grid rows auto 1fr auto, hidden outer overflow and a main region with overflow-y:auto. Header and footer remain outside that region. The historical patch’s temporary repeated headings are gone, and the controller still creates a placeholder row. Preserve the layout ownership when building the actual shortcut list; hardcoded placeholder headings and rows are not a localization or finished-product standard. No zoom, RTL layout or keyboard scroll session was run. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.
