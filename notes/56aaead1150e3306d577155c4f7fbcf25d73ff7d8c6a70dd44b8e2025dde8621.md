# Removing the Calendar origin fallback makes the caller's origin explicit

The change removes Calendar's local origin conversion. The accepted save helper uses aOrigin for the login-saving check, lookup and new login. Its actual CalDAV and ICS prepared-password callers pass aChannel.URI.prePath. Keep that caller responsibility separate from the unpaired storage backend's normalization or migration behavior. The callers are synchronous and do not await saving; this patch does not introduce that async boundary. No backend, profile or authentication test was run.

Scope: Calendar authentication.
