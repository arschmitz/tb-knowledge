# Compose file-URI attachment mode protects internal commas before splitting

The command-line attachment branch enables URI mode only for text beginning with file:, ignoring case. In that mode it encodes every comma not immediately followed by file:, then splits the result and passes entries to the existing URI resolver. The source therefore handles a narrow adjacent file-URI list convention; it does not add whitespace-aware, quoted or mixed-scheme list parsing. A filename containing the delimiter-like sequence remains ambiguous. No command-line or file attachment test was run.

Scope: Compose command-line attachment parser.
