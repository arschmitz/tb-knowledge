# The keyserver settings test distinguishes template children from actual server rows

This historical three-server test repair waits for numDefaultKeyservers+1 total children during list setup, then uses direct li counts for added/reset server rows. The inspected list builder keeps the template child and creates li elements for server entries, which explains that distinction. The count constant belongs to the original three-server phase; the fixed comparison again expects two defaults. These assertions cover preference/list settings, not key discovery or the correctness of a provider’s returned keys.

Scope: Privacy keyserver settings tests.
