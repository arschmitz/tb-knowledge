# The folder rename updates both generated interface names

The IEwsFolder rename also changes IEwsFolderOperationListener in the same IDL file. The folder and listener keep their separate UUIDs, method signatures and parameter order. The owned C++ callers update interface types, inheritance, support macros and generated method declarations together; build input changes to IExchangeFolder.idl. Existing completion and undo responsibilities remain at the actual callers. This is a checked source-level rename, not a compiled ABI guarantee. Remaining intra-EWS wording and the EwsFetchMsgsToOffline prose reference are not proof that every implementation or comment name was migrated.

Scope: Exchange folder and operation-listener interface rename.
