# Sync counters drive localized text through one observation path

The sync form updates counters through a Proxy whose setter calls observeSyncAccountCounter. That observer sets the selected-count message and chooses the Select all or Deselect all message based on actual checkbox state. The accepted Fluent resource documents $count and has one/other branches, although the English strings are identical. Preserve the data-to-localization connection in this form; do not replace it with a hard-coded English label or assume the other languages have identical plural text. This is scoped source and manual guidance. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub sync count localization.
