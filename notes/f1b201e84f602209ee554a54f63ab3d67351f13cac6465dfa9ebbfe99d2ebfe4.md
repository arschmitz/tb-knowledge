# Commands Thunderbird/Firefox desktop onboarding and guided setup

`desktop/setup-knowledge.cjs` clones `https://github.com/arschmitz/tb-knowledge.git` via HTTPS into managed storage, validates `.git`, `AGENTS.md`, and `CONSUMING.md`, uses temporary clone plus atomic promotion, preserves `.tb.json`, reuses valid configured paths, and defaults new config to `push: false`. `desktop/setup-runner.cjs` supports both ordinary setup and `task: "knowledge"` upgrades without rebuilding Thunderbird.
