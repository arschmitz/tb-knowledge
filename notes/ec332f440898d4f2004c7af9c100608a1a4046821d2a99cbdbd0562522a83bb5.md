# Distinguish online message delivery from writing an offline copy

The accepted protocol sends buffered data to the channel listener before its optional folder ParseAdoptedMsgLine echo. A failed offline echo triggers PseudoInterrupt, but the stream consumer and the store writer are different paths. The lock test can load a message while asserting that no local body/token/Offline flag was created. Do not infer that a folder lock forbids reading the already-delivered online content or that every consumer uses a document shell.

Scope: mailnews/imap/src.
