# Preserve completion across the extension parent-process boundary

folders.markAsRead uses async: callback and an optional callback with no result parameters in both manifest versions. The 2024 change removed async: false, which let the child return undefined before the parent operation had run. For a parent API, describe when the caller can await completion even when the method returns no value. This is a schema and process-boundary contract, beyond formatting. No add-on or cross-process test was run in this study.

Scope: Extension API completion.
