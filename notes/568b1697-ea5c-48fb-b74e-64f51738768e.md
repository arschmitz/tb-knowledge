# Delegate message-pane deletion before showing the confirmation

After confirmations moved to the front end, Shift+Delete from about:message inside about:3pane showed two dialogs. Delegate to the parent command first; only the command that performs the delete should ask for confirmation. The regression test places focus in the message pane.

Scope: message deletion.
