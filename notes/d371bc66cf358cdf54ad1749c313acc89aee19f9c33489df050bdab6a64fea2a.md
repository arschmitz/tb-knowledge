# Row diagnostics and completion waits provide different test evidence

The historical message-header patch reports row indices/counts and adds direct row-count assertions after trash/star actions. The diagnostic Assert.report calls do not assert that a row was selected. Fixed code registers DeleteOrMoveMsgCompleted before trashing and awaits it before checking the count; this later event wait is stronger than a tick alone. A reported JavaScript false==undefined explanation is incorrect and is not reused as a lesson. No intermittent failure or CI artifact was independently reproduced.

Scope: Browser test synchronization and oracles.
