# Search widgets translate enum values through explicit Fluent-ID APIs

The validity manager now maps numeric attributes and operators to Fluent IDs through separate APIs. Widget selected/list labels resolve those IDs synchronously; custom term names and custom-header text retain separate branches, and stored values remain numeric/custom IDs. Missing table entries return NS_ERROR_FAILURE. The changed unit test checks nonempty visited attribute labels, not operators; its truthy pop loop also stops when zero-valued Subject is popped. It therefore does not establish every mapped label, and its existing Assert.ok call lacks a message. No localization or search test ran.

Scope: Search widget localization and validity manager.
