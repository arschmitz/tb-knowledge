# An overlay guard skips shortcut dispatch before the event is consumed

The historical shortcut handler adds a tabmail.globalOverlay guard before preventDefault, stopPropagation and dispatch. The accepted module retains that boundary with later main-window lookup, optional access and repeat filtering. Returning here skips this dispatcher; it does not establish that all key handlers or native default actions are blocked. Keep the first landing, backout and later revised landing separate from the shared command-controller lifecycle.

Scope: shortcut-dispatch-overlay-guard-phase.
