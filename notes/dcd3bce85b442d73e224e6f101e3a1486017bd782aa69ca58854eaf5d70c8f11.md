# Unified message indicators use the incoming-server key for color identity

Cards request accountCol and serverKeyCol separately. Native column dispatch fetches the incoming-server key from the message folder. The card uses that key for its CSS custom-property reference and the display name only for the title. Folder indicators use the same server-key naming. The view-class predicate is limited to synthetic/smart/tag contexts; it does not cover every virtual folder. This establishes source data flow, not a benchmark, visual result or all-message traversal guarantee.

Scope: Thunderbird unified-folder account color data flow.
