# About dialog codename ID stays independent of the release

In the About dialog, commit 122f64c670fadf8fa256360926739a79c31bd17c replaced supernova-logo with codenameLogo and updated the selectors in all three branding stylesheets. Review feedback explicitly requested camelCase and an ID independent of the release. At source revision 0b93f0f7a926ed94c8a0646f18b6734ec7cc0f6d, codenameLogo remains while the image and localization key refer to Meadow. This supports a stable role-based ID for this component while release assets change; it does not establish a project-wide naming convention. The study checked source wiring, did not inspect artwork pixels, and ran no runtime tests.
