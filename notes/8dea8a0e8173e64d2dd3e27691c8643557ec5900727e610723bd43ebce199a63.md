# Match the stored closure tag to the partial-message footer consumer

933 stores isMimeObject in html_closure, but its partial-message footer checks isMimeMessage. 934 centralizes the getter without correcting that setter. Later 200a66f114bf changes the stored tag to isMimeMessage; the accepted source uses that tag and AsMimeMessage. Keep producer and consumer in the same check when adding a tagged wrapper. The later repair says recent regression, but its browser discussion and exact user-visible failure conditions remain unread. No crash cause is claimed.

Scope: Partial-message MIME closure tag repair.
