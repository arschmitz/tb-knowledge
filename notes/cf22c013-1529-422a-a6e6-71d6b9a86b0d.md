# Use the exported class name for a reusable Sync module file and explain its contract

D205784 reviewer requested changing cachedStore.sys.mjs to CachedStore.sys.mjs and adding a top-level explanation. The author agreed after checking Thunderbird and Mozilla Central naming, and the landed file uses the upper-case C with a comment explaining forward-compatible round trips. Other engine modules still use lower-camel plural names, so this is a rule for this exported reusable module shape, not a claim that every .sys.mjs filename is PascalCase.
