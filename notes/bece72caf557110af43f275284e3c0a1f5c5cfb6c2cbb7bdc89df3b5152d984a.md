# Attachment disposition policy is shared and compares parsed query values

The historical 1927 change copied whitelist coordination comments into IMAP, mailbox and EWS code. Current IMAP, mailbox and Exchange consumers call MsgPartUrlNeedsAttachmentDisposition instead. That helper parses URL parameters, requires part and compares type without case sensitivity. message/rfc822, application/x-message-display and application/pdf are exceptions. Scoped manual recommendation: change and test the shared helper rather than copying the old spec-string whitelist into another consumer. Escaped parameter values are an explicit reason given in its current comment. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Shared attachment disposition policy.
