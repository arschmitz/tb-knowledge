# The historical unified theme source still generated two stable add-on identities

At this landing one combined source holds light and dark colors, but GeneratedFile invokes separate variant entry points and jar packaging loads two manifests. The generator selects a theme branch, removes dark_theme from output and overrides the original compact-light/compact-dark IDs. One source manifest therefore does not mean one installed add-on identity. Accepted code later returns to separate checked-in manifests and preserves those IDs in its registry; the historical generator is not a current implementation pattern. No generator, install or visual/theme test ran.

Scope: Built-in theme source and packaged identity boundaries.
