# Dialog font scaling requires registration with the window manager

The historical landing adds UIFontSize registration to many dialog load paths. Current FilterListDialog and newFolderDialog still register their windows. The manager tracks registered windows, removes them on unload and applies the current root font size. Adding an import alone does not opt a dialog into this behavior. This is a contract for this manager and these dialog load paths; the removed calendar utility registration is not asserted to remain current. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Thunderbird dialog font integration.
