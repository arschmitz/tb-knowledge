# The comm message parameter stores extracted try syntax rather than the whole commit message

The comm schema adds message as a string. Its inspected producer assigns try_syntax_from_message(commit_message): the first try marker suffix through its first newline, or an empty string. The value then controls try-option parsing. The schema declaration and producer are separate contracts; the field name does not mean the whole commit message is retained. No schema-validation or decision-task run was performed.

Scope: Taskgraph comm parameters.
