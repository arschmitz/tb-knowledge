# Encode the extension identity in the shortcut view route

openShortcutSettings builds addons://shortcuts/ with encodeURIComponent(extension.id) and awaits openAddonsMgr. The latter reuses an Add-on Manager tab through EM-ping/EM-pong or opens one and waits for EM-loaded. The API test additionally checks current-view, current-param and focused-extension DOM state. Keep opening completion distinct from assuming correct rendered selection without those assertions. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mail/components/extensions.
