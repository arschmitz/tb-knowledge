# Preserve the distinct Calendar DOM, CSS and protocol names

In the attendee component, CSS classes use role-icon and usertype-icon, state attributes use attendeerole and usertype, JavaScript private fields use #roleIcon and #userTypeIcon, and protocol role values remain uppercase hyphenated constants such as REQ-PARTICIPANT. The custom element is event-attendee and the class is EventAttendee. Proposed scoped naming rule: follow each namespace and update its consumers, rather than copying one casing into every representation. The 652 breakage demonstrates why an attribute name is a behavior contract.

Scope: Calendar attendee naming.
