# Return the generated fake-server message when its body is part of the assertion

The shared IMAP head defines one MessageGenerator and addImapMessage returns the generated message after adding its data URI to the fake mailbox. The lock test can then compare the delivered/stored body with that exact generated subject instead of duplicating message setup or relying on a fixed incidental subject. This is a shared test-helper contract, not a general preference for global state in application code.

Scope: mailnews/imap/test.
