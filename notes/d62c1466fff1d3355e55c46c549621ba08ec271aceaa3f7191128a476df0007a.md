# The migrated delete wrapper waits for a listed folder event, not a success result

The key-name migration preserves press_delete registration before synthesis and its subsequent wait. It listens for either DeleteOrMoveMsgCompleted or DeleteOrMoveMsgFailed. FolderListener marks sawEvents when a listed event occurs on any folder, so the wait alone does not prove that the selected deletion succeeded. Callers still need their own state assertions. This is the bounded accepted helper contract, with no reproduced failure or runtime claim.

Scope: Thunderbird browser-test deletion helper.
