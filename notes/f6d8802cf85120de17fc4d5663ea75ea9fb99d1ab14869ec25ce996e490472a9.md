# A LiveView count follows its current grouping mode

The original view counts message rows. Fixed accepted CountMessages chooses COUNT(*) for unthreaded views, DISTINCT threadId for threaded views, and a distinct sort group for grouped-by-sort views. A caller must distinguish the current view/group count from a raw database message total. The old stub test assertions do not cover all current grouping combinations; this is a current source contract, not full study of the later grouping landings. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Panorama grouped view counts.
