# Separate OAuth authorization success from account server verification

The granular-scope browser test checks OAuth succeeded telemetry before checking whether ConfigVerifier succeeded. It can report a server verification error or retry IMAP with the cached token after OAuth has already completed. It then checks the saved grant realm and account auth methods. Preserve these separate outcomes in this test family so an OAuth success is not used as proof that the account can log in to its mail server. The retry comment gives an expected timing explanation, not a diagnosed failure reproduced here. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Account OAuth and verification outcomes.
