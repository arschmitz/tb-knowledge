# Calendar creation Fluent attributes retain their JavaScript consumers

Calendar creation panels expose Fluent button-label and access-key attributes that updateButton reads into the shared dialog buttons. The network location input also exposes both placeholder and default-placeholder; fillLocationPlaceholder restores the custom default when no nonempty username domain is available. These attribute lists preserve named JavaScript consumers. The migration retains this panel-metadata design rather than rewriting it.

Scope: calendar-creation-localization.
