# The initial Calendar assertion conversion reversed the first-window diagnostic predicate

Before part 5, an existing cache entered cal.ASSERT(windowCount > 1), which logged on false. The owned replacement instead logs inside an if whose count is > 1, reversing that diagnostic condition. Fixed accepted code checks count == 1. Preserve these source phases; the intervening repair commit and any real multi-window result are outside this study. The example does not show a startup crash or establish every possible window-count invariant.

Scope: Calendar logging migration startup phase correction.
