# EWS synchronization records server-reported size without requiring full-body download

The historical EWS sync change requests item:Size and stores a present value only if it fits the database u32 field. Overflow is logged instead of assigning a truncated size. A parsed message supplies its raw-message length through the same optional-size role. Synthetic tests compare generated message text lengths to reported or stored messageSize; they do not test missing values, overflow or Unicode byte accounting. Current stored-size checks explicitly exclude Graph. Server messageSize and local offlineMessageSize must stay distinct. No synchronization or test ran.

Scope: EWS sync size request, optional header metadata and synthetic tests.
