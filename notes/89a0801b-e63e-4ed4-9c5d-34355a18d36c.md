# Report certificate errors from folder-driven mail fetches

Changing the displayed folder can start a server fetch without the Get Messages URL listener. Route its certificate failure through mail session feedback listeners so the user receives the same security alert instead of a silent failure.

Scope: mail certificate alerts.
