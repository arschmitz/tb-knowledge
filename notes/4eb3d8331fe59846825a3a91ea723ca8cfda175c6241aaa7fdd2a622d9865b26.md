# Keep localization repository, branch and automation mode separate

576 migrates the Thunderbird locale source to the thunderbird-l10n GitHub repository and main branch. Its historical beta worker pushes while nightly does not; current task configuration has moved to Lando repository mappings and actions, so the old push policy must not be copied as current. The current actions still pair the l10n repository URL with main, platform exclusions and a comment to coordinate merge-automation changes. A repository migration must update every release-type branch and caller, not only the default URL.

Scope: Localization automation configuration.
