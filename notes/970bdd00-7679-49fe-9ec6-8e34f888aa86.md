# Test dual-use OpenPGP dialogs in both hosts

The key details and expiry dialogs open as standalone dialogs and inside Account Manager. Styles from one host leaked into the other, causing wrong buttons, missing radio styling and overflow. D204945 changed the style imports, dialogShadowDom setup and sizing after reviewers tested both contexts and several platforms. A dialog style review must include both hosts.
