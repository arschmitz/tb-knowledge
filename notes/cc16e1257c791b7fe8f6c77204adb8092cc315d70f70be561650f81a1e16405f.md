# The initial OAuth where extra records request selection and extends exact event expectations

The landing adds OAuth browser preferences to tracked boolean telemetry, missing flatpak/snap labels, and a string where authentication extra. The original authorization branch sets external before starting its loopback listener, or internal for its fallback, so the extra records selected path rather than proof a window opened. recordTelemetry still requires issuer and reason and clears reason after recording. Existing tests add internal expectations; new reset-and-check cases assert external with exact event extras. Later three-mode values and the stale two-value description are linked existing facts. The shared helper per-event deepEqual lacks a message. No auth flow or telemetry was run.

Scope: OAuth telemetry location and preference tracking.
