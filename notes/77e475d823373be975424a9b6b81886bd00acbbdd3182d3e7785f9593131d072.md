# Keep the packaged updater locale name aligned in both manifests

Entry 1800 changes update.locale to default.locale in the package manifest and allowed-duplicates list. Both current comm files retain default.locale. When updating this generated artifact name, check the package inclusion and duplicate allowance together. This study inspected those comm consumers only; it did not verify the Gecko producer, package contents or an updater run. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.
