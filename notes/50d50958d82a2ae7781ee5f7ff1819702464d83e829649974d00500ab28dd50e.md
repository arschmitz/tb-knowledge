# Calendar category popups de-duplicate the preference and item union before sorting

The task and item popups build a Set from preference names and item categories, then sort the resulting display list with the default Intl.Collator. This also removes preference duplicates from the popup. The separate preference writer only sorts and serializes its existing list. Keep display normalization distinct from stored category cleanup; no locale-order or rendered-menu result was tested.

Scope: Calendar category popup population.
