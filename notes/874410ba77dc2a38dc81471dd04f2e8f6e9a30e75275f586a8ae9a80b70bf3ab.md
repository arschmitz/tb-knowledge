# The desktop installer selects staged component manifests with one wildcard

The installer list uses components/*.manifest instead of maintaining separate entries and feature guards for each JavaScript component manifest. The owned build still stages MailComponents.manifest through EXTRA_COMPONENTS. Keep staging and packaging distinct: the glob selects existing inputs and does not create a missing manifest or prove every toolkit producer is enabled. The upstream port source and packaging engine were not read. No installer or build was run.

Scope: Owned desktop package manifest inputs.
