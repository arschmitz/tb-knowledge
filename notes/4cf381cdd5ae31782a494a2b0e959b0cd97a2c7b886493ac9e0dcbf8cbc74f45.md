# Folder-sync listener names distinguish each page token from all-pages success

Part 4 gives folder events concrete listener names and documents onSyncStateTokenChanged per page versus onSuccess after all required pages. Historical code pushes each page before its last-page test, and current split client retains that ordering. Local RefPtr/std::function captures keep needed objects available across detached work. Historical production folder listener still lacks the optional fallible interface, while its test adapter exposes both; current listener adds a failure closure/interface later. Do not turn naming or adapter acceptance into a global rule or failure-path proof. No sync, QI or test ran.

Scope: EWS Part4 folder-listener event contracts.
