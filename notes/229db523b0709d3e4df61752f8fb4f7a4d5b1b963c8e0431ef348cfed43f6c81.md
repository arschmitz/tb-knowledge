# Treat databaseOpen as a retained database reference rather than an open UI window

The openFolder removal retires nsIMsgWindow.openFolder and the mail-session IsFolderOpenInWindow checks. Current databaseOpen is simply whether mDatabase is non-null. That state can be used by cache, search and autosync code without proving that a folder is visible. Preserve the distinction in names and comments; the retained database itself may also outlive the folder reference through message headers. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Folder UI and database lifetime boundary.
