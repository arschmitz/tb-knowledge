# Login prompt settlement waits do not forward internal Promise rejection

The migrated public prompt methods keep a synchronous Boolean interface. They start an async helper, set result only on fulfillment, set finished in finally and spin until settlement. They do not catch and rethrow the rejected helper result. The inspected incoming-server caller treats a false result as cancellation. Waiting for settlement therefore does not establish failure propagation or a Promise-returning public API; no prompt or rejection was executed.

Scope: Synchronous authentication prompt bridge.
