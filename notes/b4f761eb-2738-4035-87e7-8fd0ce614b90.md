# Thunderbird Windows DNS worker frees successful record lists and normalizes typed results

load_dnsapi:351–522 opens DnsAPI through ctypes, declares UTF-16 DnsQuery_W and
DnsRecordListFree, and models SRV/TXT/MX plus linked DNS_RECORD layout. lookup:
478–520 returns [] for non-success, walks native pNext entries, maps matching
record types, adds type/nsclass0/signed ttl, then frees the returned record list.
The free call is after the mapping loop, not in finally. A mapping/read exception
can bypass it; actual Windows reproduction is unverified. Pointer value ownership
does not by itself establish automatic native record-list freeing.

_mapAnswer:441–471 casts union data: SRV reads priority/weight/port/target;
TXT uses dwStringCount to cast the trailing pointer array and reads each string;
MX reads priority/target. Common constructors:525–553 lowercase SRV/MX host and
retain TXT strings so detector sees consistent shapes across platforms. Complete
native Windows structure alignment/system API behavior was not validated here.
