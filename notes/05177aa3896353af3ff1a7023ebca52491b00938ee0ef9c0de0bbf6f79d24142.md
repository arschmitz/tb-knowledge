# Keep the notification interaction test coverage gap explicit

918 and 919 add manager tests that arm the custom event wait, click the actual anchor or close button, and assert one service call with the notification ID. Both tests remain skipped when Cu.isInAutomation is true, with Bug 1921222 named in the TODO. They therefore do not establish automated integration coverage of these clicks. The current showNotification helper waits for an ID-matched service event; that wait alone is not a layout-ready assertion.

Scope: Notification integration test limits.
