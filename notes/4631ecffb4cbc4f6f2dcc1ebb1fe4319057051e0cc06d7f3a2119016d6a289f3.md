# Both macOS settings menu identities share the Thunderbird command route

The Thunderbird markup supplies menu_preferences and menu_settings with the same localization ID, keyboard shortcut and command. Its comment explains the macOS rename; it does not implement local version detection. Fixed accepted code preserves both identities while using the later openPreferencesTab route. Treat the native selector as a separate upstream contract, not proof that both items are visible or a global duplicate-ID pattern.

Scope: macOS application menu markup.
