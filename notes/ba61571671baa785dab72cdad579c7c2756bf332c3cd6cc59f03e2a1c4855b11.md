# Column readiness waits for required IDs before a separate exact order assertion

checkTreeColumnsInOrder waits for expected column IDs to be a subset of visible treecol IDs, then sorts a fresh query by ordinal and deep-compares the entire ID array. All four owned callers await the helper after removing fixed delays. The readiness wait permits extra columns and does not check order; exact membership and order belong to the later assertion. This source pattern is not proof the intermittent was cured. The existing assertion lacks a message and must not be copied as an assertion-message example under current guidance.

Scope: Search Messages browser-test synchronization.
