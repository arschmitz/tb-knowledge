# Preserve explicit false when defaulting link options

Current openLinkExternally uses options?.addToHistory ?? true, so false disables history while absent options use the default. The option bag also accepts a triggering principal. Truthiness or || would change an explicit false decision. Optional chaining is valid for an absent option bag; required URI/service invariants still throw or fail through their normal contract.

Scope: testhelpers.
