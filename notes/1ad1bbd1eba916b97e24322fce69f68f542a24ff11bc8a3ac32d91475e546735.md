# Unknown network status is still an error after the Fluent port

The accepted C++ mapping returns Nothing for an unmapped status and FormatStatusMessage returns an error when no localization ID exists. NNTP likewise throws for a status outside its explicit map. Moving the strings to Fluent therefore does not make an unknown code a blank successful status. For this port, preserve that failure contract as well as the displayed strings. Source was read; no unknown-status or localization-failure test was run, and current progress delivery now uses the feedback service. Full bug and review discussion remains pending.

Scope: Mail network-status error contract.
