# Draft composition accepts protocol URIs without requiring nsIMsgMailNewsUrl

Entry 1484 makes QueryInterface to nsIMsgMailNewsUrl optional before calling SetSpecInternal. This allows EWS protocol URIs that do not implement that interface to continue into the generic composition path. The accepted compose service retains an optional do_QueryInterface branch, and ExchangeService implements StreamMessage and returns its URI while routing content through FetchMessage. In this compose boundary, recommend using optional protocol-specific interface behavior where the generic service contract is sufficient. This is not advice to ignore failures from every QueryInterface. No draft edit, stream conversion or message compose test was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Protocol-neutral draft URI interface.
