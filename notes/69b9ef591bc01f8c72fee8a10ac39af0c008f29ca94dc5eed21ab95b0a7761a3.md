# The dependent spellchecker freezes and restores its opener explicitly

EdSpellCheck Startup registers an opener-unload listener, remembers the active element and makes the opener document inert. The unload listener closes the dependent dialog. ExitSpellChecker clears inert, restores focus when the saved element exists and removes the listener. CancelSpellCheck sets the opener cancellation flag after exit; onClose clears it before closing. This is explicit lifecycle state for this dialog, separate from whether the send caller waits. Full patch and selected fixed methods were inspected; native focus, keyboard, accessibility behavior and all failure cleanup paths were not exercised. Bug 8 and full review remain pending.

Scope: Compose spellcheck opener lifecycle.
