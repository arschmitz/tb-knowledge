# Allow a quick-filter model without a matching built-in control

QuickFilterBar guards absent nodes in initialization, state reflection and post-processing, allowing Experiment add-ons to use a filter path without every standard DOM control. In post-processing the model is updated before the DOM guard, so the missing control does not discard the filter state. Preserve those separate model and presentation responsibilities. This is an internal accommodation, not a stable public quick-filter API guarantee. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
