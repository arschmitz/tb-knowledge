# Synchronous login searches can settle without an iterable result

These getters/prompts wait on a finished flag set in finally, while only fulfillment assigns the login array. On rejection, Chat retains the Promise in logins and iterates it outside the synchronous catch; CardDAV and incoming-server bridges leave logins undefined before iteration. Settlement is therefore separate from producing a valid iterable result. This is a source-level failure path, not a measured failure or a global rule against synchronous interfaces.

Scope: Login lookup bridges and failure values.
