# Primary fallback failure requires an unset accent token

The AI review record for D336388 at revision 938178e96fcd54acd48300758465d6feb76b68c9 identifies bare custom-property names in primary button var() fallbacks and proposes nested var() calls. The reported failure requires an accent variable to be unset; the record says defaults currently define all accent variables, so it treats this as nonblocking. A reported Chromium experiment produced a transparent background with the original fallback and rgb(19, 115, 217) with the nested fallback. No correction was applied for this finding, and this is not Thunderbird runtime confirmation or an accepted general style rule.

Scope: Shared primary button fallback colors.
