# The common offline read helper does not download a missing message

AsyncReadMessageFromStore requires the message, listener and source channel. It obtains the folder/key, checks HasMsgOffline and returns NS_ERROR_NOT_AVAILABLE when no copy exists. Only after that does it open the store stream and input pump. ExchangeMessageChannel chooses either that existing-copy path or a prior server fetch. Keep storage reading and remote retrieval as separate responsibilities in this helper. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Offline read responsibility.
