# Wait for attachment reminder state rather than a timer

The manual attachment reminder test was intermittent because it asserted command state before asynchronous updates finished. The patch replaces next-tick and two-second waits with waitForCondition on cmd_remindLater checked state, then removes the Linux skip. Use an observable state condition when testing asynchronous compose controls, and re-enable platform coverage when the cause is fixed.

Scope: compose attachment reminder tests.
