# Keep about:profiling aligned with its upstream resource filename

Entry 2100 updates the comm-owned about:profiling redirect from index.xhtml to index.html while preserving ALLOW_SCRIPT and IS_SECURE_CHROME_UI. The fixed accepted map still uses the HTML filename. AboutRedirector strips query and fragment text before looking up a module name, and returns that entry’s flags and destination through its channel path. A resource filename port must update the consuming chrome URL; the old extension is not an interchangeable alias. The upstream devtools file body, its packaging at the matching Gecko revision and an actual about:profiling load were not verified. No runtime, security-principal, keyboard or accessibility test ran. The port bug and review discussion remain pending.

Scope: About page redirect integration.
