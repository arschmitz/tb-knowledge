# The Save As caller repair removes an argument before the identity and filename

The original IDL takes URI, identity, filename and an optional bypass-picker Boolean. The repair removes the obsolete second true argument from both the selected-message and drag calls, leaving null as identity and the filename/path in the third slot. The added browser test exercises context-menu saving, not drag. The fixed source later uses MessageSaver instead of this native API; keep those contracts separate. No binding, picker, drag or save was executed.

Scope: Message saving.
