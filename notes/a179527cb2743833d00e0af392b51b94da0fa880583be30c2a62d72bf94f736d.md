# Telemetry schema names and generated JavaScript names are different namespaces

The metric is mail.oauth2_authentication in YAML and Glean.mail.oauth2Authentication in JavaScript. Its extra keys issuer, reason and result retain their payload spelling. Proposed naming rule for these metric changes: update and quote the schema key and generated language member explicitly; matching meaning does not require identical casing. This record does not claim a historical generated-member mismatch or data-review approval. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: OAuth telemetry naming.
