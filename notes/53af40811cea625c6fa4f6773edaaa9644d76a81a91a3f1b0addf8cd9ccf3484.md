# The initial telemetry tab filters are narrower than bridge injection

Version 2.0.5 injects token-bridge.js on production and staging Send URLs. Its telemetry request handler and runtime-change broadcast instead use startsWith("https://send.tb.pro"), which the staging origin does not satisfy. The bridge relays a query reply only when its response type matches. Accepted background source replaces the literal with configured BASE_URL; no staging outcome is inferred from that substitution. This is an exact source-condition comparison, not a live staging failure, URL-security proof or guarantee of page-side fallback behavior. No page or native experiment ran.

Scope: Thundermail telemetry request and broadcast URL conditions.
