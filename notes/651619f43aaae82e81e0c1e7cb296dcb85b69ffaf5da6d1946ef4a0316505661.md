# Template discovery skips database-access failure without retrying the same folder in that scan

findTemplates resets its enumerator for each identity, records a folder before opening its database and catches database access or enumerateMessages invocation failures. The existing empty-enumerator guard skips that identity; other folders can still return template choices, and a shared folder is not retried in the same scan. hideInvalidActions hides Reply with Template if no choices remain. Later header iteration is outside the catch. Source adopts a folder URI and error message; the proposed full error-object log is declined. No corruption repair or UI test was run.

Scope: Filter Editor template action discovery.
