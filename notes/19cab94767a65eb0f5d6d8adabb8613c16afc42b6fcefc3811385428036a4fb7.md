# Calendar fixture creation and navigation must share the same base date

The fixture repair makes baseDate an explicit option in createEvent, showEvent and openAndShowEvent. positionTest chooses its fixed date and forwards that date for both item creation and calendar navigation. Other helpers keep a current-date default. A global hardcoded todayDate had mixed those contracts. Preserve the same base through the chain; this does not prove every floating/date-only/timezone conversion or an intermittent cure. The fixed helper still carries separate start/end duration logic. No Calendar task ran.

Scope: Calendar test date contracts.
