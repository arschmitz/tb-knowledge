# When removing unusable servers, repair identity and default references too

Bug 2069949 UI migration 65 removes SMTP servers with no hostname, clears their preferences, clears smtpServerKey on identities that referenced them, and clears the default key if it points to a removed server. The current getServerByIdentity also falls back to the default when a nonempty identity key cannot resolve, covering manual prefs edits and deleted entries. Empty username is valid for nsMsgAuthMethod.none and must not be used as an invalid-server test; D325420 review asked this exact question and the author added a comment. Migration tests cover the cleanup. Treat persisted object deletion as a reference repair, not just list removal.

Scope: Profile migration.
