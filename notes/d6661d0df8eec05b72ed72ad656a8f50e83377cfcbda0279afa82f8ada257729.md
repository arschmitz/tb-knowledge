# CopyServiceListener names its copy callbacks and keeps the URL completion bridge separate

This landing names the two injectable slots mStartCopyFn and mStopCopyFn to match OnStartCopy and OnStopCopy. The utility returns NS_OK when a slot is unset; its progress/key stubs also return NS_OK, while GetMessageId returns NS_ERROR_NOT_IMPLEMENTED. The junk-action caller separately bridges the copy status to an optional URL listener's OnStopRunningUrl and returns NS_OK from that callback. Both utility blobs persist unchanged at the fixed revision, and the actual junk caller was checked separately. These are local adapter contracts, not a rule for other copy listeners or proof of a successful native copy.

Scope: Copy-service listener adapter.
