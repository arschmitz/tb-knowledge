# Calendar row styling preserves user font scale at the slotted content boundary

D238704 design acceptance requires700 label weight and removes0.9rem content shrink because users can already choose a smaller base font. Fixed .row-label is1rem/700 and the slotted content layout does not add that shrink. The review also corrects the initial assumption that an outside stylesheet is redundant: density variables must enter from the outside, while component selectors use host/slot boundaries. This is accepted local Calendar row practice, not a universal700 weight or a rule banning every smaller font.
