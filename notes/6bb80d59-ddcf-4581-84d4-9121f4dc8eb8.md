# IMAP pendingRemoval deletes only the local message copy during compaction

BuildKeepMap skips an IMAP header with pendingRemoval. It clears that header’s storeToken and Offline flag, but keeps the database entry and server message. A header without a storeToken is also excluded because it has no local copy. This distinction remains in current code. Tests or fixes for IMAP compaction must check the offline copy, database header, and server state separately.

Scope: IMAP offline store.
