# Name shared extension helpers for the selected data they return

944 adds a PascalCase ExtensionMailTabs.sys.mjs module with lowerCamelCase exported functions getMsgHdrsForIndex, getActualSelectedMessages and getActualSelectedFolders. Its browser test filename uses the browser_ext_ prefix and the mailTabs API spelling with an underscored context_clicks suffix. Follow this existing artifact family rather than converting each name to one global dash or camel convention. The actual-selection qualification is meaningful because context-menu action targets differ.

Scope: Extension shared helper and test naming.
