# Resolve the top-level window before executing action commands from an embedded menu

The menus handler obtains the target document global and then uses win.top before looking up browser, compose, or message-display action objects. A menu inside about3Pane is embedded in the mail window, while the toolbar lookup expects the main window. Preserve that boundary. Entry 635 adds no regression test; the inspected command test exercises shortcuts, not this context-menu path.

Scope: mail/components/extensions.
