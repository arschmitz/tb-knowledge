# Hidden MIME alternatives are parsed with suppressed output before attachments are collected

The owned patch parses a hidden alternative through a no-op output callback while preserving shared parser flags. Hidden leaves still count incoming bytes, and attachment collection walks parsed containers while treating body-type multipart/alternative siblings as alternatives. A filename or all-body-parts mode can still make a child listable. Accepted code later exempts an explicit part_to_load from suppression. This is static control-flow evidence for this MIME path, not a general claim that hidden parts are decoded correctly or that all attachment operations succeed.

Scope: MIME alternatives and attachment listing.
