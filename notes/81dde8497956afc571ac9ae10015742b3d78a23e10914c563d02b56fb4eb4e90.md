# Removing aggregate folder size also removes its direct parent-child assertions

The landing removes sizeOnDiskWithSubFolders from the interface, its recursive implementation and a test block that directly checked parent/child totals3/2 after assigning scalar sizes1/2. The removed implementation skipped virtual children and propagated nested failures, but that deleted test did not directly assert either condition. Scalar sizeOnDisk remains a separate API. No external-consumer compatibility or native test result is established by this removal.

Scope: Folder size API and unit-test scope.
