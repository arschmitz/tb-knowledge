# validateFileName transforms basenames before callers append an extension

validateFileName returns a transformed string using the same replacements on every platform, an exact case-insensitive reserved-name list, trimming and the space preference. It does not split extensions. GenerateValidFilename sanitizes its basename before concatenating the extension, and the main/search drag callers add .eml after collision handling. Whole-filename validation and a mimeService replacement were deferred. This contract does not establish every filesystem naming rule.

Scope: Saved-message filename construction.
