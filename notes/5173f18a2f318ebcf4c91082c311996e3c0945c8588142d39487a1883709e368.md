# Condensed address display falls back when address-book lookup leaves the name empty

The named AbManager lookup supplies a typed nsIAbManager even though the registered implementation is an ES module. GetDisplayNameInAddressBook returns a card display-name result when a card exists and NS_OK when absent. Sender and per-recipient callers separately fall back to header/full-address formatting when the output string is empty. No card is therefore an allowed display fallback, not evidence that all service or directory failures may be ignored. Static source only.

Scope: message-list-address-display.
