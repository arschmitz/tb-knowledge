# Keep Storybook filename and export namespaces distinct

Accepted shared widget stories use kebab-case stems plus .stories.mjs, PascalCase named story exports and hierarchy titles such as Design System/List Container. They import real shared CSS/widget modules and expose Boolean controls for state. This supports a scoped naming pattern for new sibling stories. Existing demo inline style and mock ChromeUtils are not production UI guidance or accessibility validation.

Scope: styles.
