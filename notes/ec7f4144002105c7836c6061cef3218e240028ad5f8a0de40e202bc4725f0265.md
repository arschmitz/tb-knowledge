# Translate reported message changes into the onUpdated property bags

The current tracker uses flag changes for read/new and the flagged callback for flagged. It reconstructs old boolean values as the inverse of reported new values. keywords become valid tag keys; junkscore strings become thresholded junk booleans. The extension event now includes oldProperties after changed properties, and converts the message before waiting for background wakeup. These bags contain reported changes rather than a full before/after database snapshot. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension message updates.
