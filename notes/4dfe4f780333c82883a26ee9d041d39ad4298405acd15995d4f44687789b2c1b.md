# The standalone title check needs an assertion message on each platform branch

The owned patch adds "title should be correct" to the document.title assertion used outside macOS. The macOS branch still compares titlebar-title-label.value with expectedTitle using only two Assert.equal arguments in the fixed accepted source. Add a nonempty expected-behavior message to that branch too, for example "The macOS title label should match the loaded message title." Preserve each platform’s title surface and expected value. This finding concerns a missing assertion message, not a missing should alone, and does not claim a native-platform test ran.

Scope: mail/message-window/tests.
