# Mail token encoding retains a separate LOGIN Latin-1 compatibility branch

The shared authenticator converts username strings to UTF-8 byte strings before PLAIN/CRAM framing, and OAuth encodes the whole optional SASL response frame before base64. LOGIN is conditional: when the Latin-1 compatibility preference is true and every credential character fits a byte, it encodes those bytes directly; otherwise it converts to UTF-8 first. Actual SMTP and POP3 LOGIN consumers use these common methods, and literal-byte unit cases cover the preference and nonrepresentable-character branches. These scoped code contracts do not establish all SASL standards compliance, real-server compatibility, OAuth/POP3 wire execution or cryptographic correctness.

Scope: Mail authentication byte-string framing.
