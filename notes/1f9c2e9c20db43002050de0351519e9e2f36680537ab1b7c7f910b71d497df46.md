# The XUL page is a documentation-tree entry while folder-tree-row is excluded from JSDoc

The added /frontend/xul navigation entry resolves through doc_trees frontend: mail/base/docs. In the same patch, the new folder-tree-row.mjs path sits inside JSDoc source.exclude. Keep these two tooling changes distinct: the source document is exposed in navigation, while that widget is excluded from JSDoc extraction. This source does not show runtime module removal, the exclusion rationale or a successful documentation build.
