# Do not skip tree row refresh merely because the index did not change

Accepted row documentation explicitly forbids short-circuiting an equal index because rows can be reused for new data at that position. TreeView invalidate assigns row.index = index again and updates selection without recreating the row. For these virtualized row setters, equality is not proof that displayed data and ARIA state are unchanged. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
