# Update the Sync transport mapping when removing a server mode

Current Sync SOCKET_TYPES has plain, alwaysStartTLS and tls, paired with the surviving nsMsgSocketType enums. Entry 799 removes tryStartTLS from both code and its record specification. Account migration and Sync serialization are separate boundaries. No importing of an old Sync record was tested here; the inspected find-based converters do not establish a recovery path for an obsolete unknown mapping.

Scope: mail/services/sync.
