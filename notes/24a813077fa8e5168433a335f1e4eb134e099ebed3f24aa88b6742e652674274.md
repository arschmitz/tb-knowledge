# The checked not-going state shares one text token across its three visual parts

The checked notGoing rule uses color-text-secondary for the moving toggle border, matching label and icon stroke. The original patch changes all three together and accepted source retains them. The native radio value remains DECLINED and the label association stays intact. This is a scoped styling fact, not a measured contrast or accessibility claim.

Scope: Calendar acceptance widget selected-state styling.
