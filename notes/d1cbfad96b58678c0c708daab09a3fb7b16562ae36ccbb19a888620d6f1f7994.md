# Queued EWS responses separate delivery errors from operation errors

The original queue macro returns a oneshot receiver whose delivered value is itself the operation Result. A consumer must handle a failed delivery separately from a failed EWS operation. Accepted enqueue_and_send still maps receiver failure before returning the inner operation result. Successful queue submission alone therefore does not prove successful delivery or operation completion.

Scope: ews/queue-response-results.
