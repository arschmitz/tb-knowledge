# Bridge Panorama folder IDs to nsIMsgFolder through the current interface

The fixed accepted getMsgFolderForFolder method bridges a numeric Panorama folder ID to nsIMsgFolder. Its interface rejects 0 or a missing folder, while getFolderByPath returns 0 for a missing path. Check that lookup succeeded before crossing this bridge. The interface comment identifies this method as its remaining coupling to nsIMsgFolder and proposes moving it; that proposal does not establish a completed move. The retired Folder objects have a separate historical note. This is a scoped current API observation, not a complete migration study; no Panorama test or build ran and full bug/review discussion remains pending.

Scope: Panorama current API boundary.
