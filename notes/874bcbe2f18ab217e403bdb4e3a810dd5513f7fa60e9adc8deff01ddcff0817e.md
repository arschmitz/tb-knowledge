# Notification placement names use logical axes and the nearby UI feature

Entry 887 packages and loads a separate manager stylesheet. Current styles use inset-block-end plus inset-inline-start or inset-inline-end through bottom-spaces-toolbar and bottom-today-pane classes. The spaces offset becomes zero when the actual spacesToolbar element is hidden; unified-toolbar customization hides the manager. The manager disables pointer events while its notification child enables them. Manual CSS naming proposal in this family: name axis offsets as inline or block and position variants after the UI feature they sit beside, and match the real hidden/customizing state selectors. Keep custom-element tags in dash form, their JS class names in PascalCase and this existing stylesheet resource name in camel case. These are component-local contracts, not a universal file naming rule. Pointer-event routing does not prove focus, contrast or screen-reader access.

Scope: notification-logical-position-names.
