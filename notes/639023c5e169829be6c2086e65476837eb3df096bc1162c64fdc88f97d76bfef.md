# Graph folder repair clears the shared per-folder sync-token property

The repair switch adds Graph beside EWS and clears the same ewsSyncStateToken folder property. The accepted repair code has moved into FolderCommands.mjs. The shared message-sync handler reads that property into the next protocol-client sync argument and writes new tokens through the same listener property. This is a per-folder stored-token reset, not proof of a completed full download or an account-wide reset.

Scope: Graph folder repair and shared sync-token storage.
