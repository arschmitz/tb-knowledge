# Deduplicate macOS attachment saves by destination path

On macOS, one drag callback can fire for each selected item while the transferable includes all selected items each time. An asynchronous attachment save can therefore repeat. Track the last saved destination per attachment and skip the same path during that drag.

Scope: attachments.

Paths:

- `mail/base/content/mailCore.js`
