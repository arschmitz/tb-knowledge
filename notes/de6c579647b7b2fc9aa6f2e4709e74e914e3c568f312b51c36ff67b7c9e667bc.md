# The send-progress start notification moves inside the visible-progress branch

Before this owned change, a supplied progress object received STATE_START after the dialog branch. The patch moves that notification inside the non-auto-save branch and the mailnews.show_send_progress preference check. The accepted counterpart retains that placement. The source proves a narrower notification condition; it does not prove an observer failure or define a general progress-event policy.

Scope: Compose send progress notification.
