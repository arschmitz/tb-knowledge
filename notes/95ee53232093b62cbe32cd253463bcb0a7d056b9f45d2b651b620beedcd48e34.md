# Panorama folder adapters route message changes to legacy header listeners

The per-folder adapter registers as a MessageDatabase listener. A database add or removal dispatches synchronously; the adapter checks folder membership before forwarding nsIDBChangeListener header callbacks. Entry2118 resets the storage statement before dispatch and removes a redundant header-interface lookup because Message already implements nsIMsgDBHdr. The accepted fixed revision obtains membership through GetMessageFolderId and forwards old removal flags. Historical RefPtr listener iteration later becomes raw MessageListener pointer iteration; do not transfer the original ownership model to current code. The full EndLimitedRange implementation was not traced. This extends the existing adapter note with notification behavior and leaves unrelated callers for source ingestion.

Scope: Panorama message notifications.
