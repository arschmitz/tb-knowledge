# Taskgraph parameter fixtures retain changed-file, prior-task and nightly-history inputs

The tgdiff source test copies Thunderbird parameter fixtures and passes their directory to mach taskgraph target. In the checked comm consumers, files_changed holds prefixed changed paths, get_existing_tasks supplies label-to-task-ID mappings, and an empty release_history makes the partials transform yield no jobs. The unchanged fixture updater clears non-partials promotion history while retaining nightly history. These collections are functional fixture inputs despite their generated provenance; this source finding does not establish an executed graph or live artifact result.

Scope: Thunderbird Taskgraph parameter fixture inputs.
