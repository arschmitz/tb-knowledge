# The optional NNTP charset lookup starts with failure before selecting a fallback

Inside the existing successful I18N-URL branch, the news charset lookup sets rv to failure before optional server and NNTP-interface lookup. Only GetCharset on a found NNTP server replaces that result. Success supplies the charset; otherwise the branch uses UTF-8. This prevents reuse of an earlier successful result in that branch. It does not establish that a generic news URL reaches the outer I18N guard or prove a fresh charset/runtime result.

Scope: MIME news charset lookup result handling.
