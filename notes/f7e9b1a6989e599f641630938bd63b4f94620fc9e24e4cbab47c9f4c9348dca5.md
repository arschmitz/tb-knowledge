# RSS folder status and favicons share the image content channel

The patch replaces the folder icon div with a decorative img and moves base/type icons to CSS content. A single-feed favicon sets inline page-icon content; busy/error selectors use important content to override it, with clock versus animation selected by the reduced-motion media condition. The owned non-important content:none does not override the important clock and is absent later. Current document-load waiting and color changes are separate phases. No RSS, animation, visual or accessibility test ran.

Scope: Folder-tree RSS icon state.
