# Local address-book creation consumes captured widget state through the hub forward event

The local widget captures the current addressBookName input as {name}. Its input event bubbles config-updated with form validity; the hub uses completed to enable or disable Forward. On Forward the hub captures the current subview state, creates a JS_DIRECTORY_TYPE address book with an empty URI and handles failures as a notification. Fixed source resolves the created directory ID, opens its UID and awaits reset; the original landing instead requested close and called reset without awaiting it. Unit-style browser assertions check captured names and directory existence; the integration task observes directory creation and hub closure. Those are written assertions, not a new UI run. Full bug/review context remains pending.

Scope: Account Hub local address-book state.
