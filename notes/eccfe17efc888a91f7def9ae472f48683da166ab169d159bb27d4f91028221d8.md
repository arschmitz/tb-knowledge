# An async Custom Headers overflow check must be awaited by its add guard

The Fluent migration makes customHeaderOverflow return a Promise. Original onAddHeader tests that Promise directly and returns before appending a valid nonempty header even when the check resolves false. Fixed accepted code awaits the result before deciding to return. Changing a Boolean helper to async requires checking its actual guard caller; the later repair is a separate phase.

Scope: custom-headers-localization.
