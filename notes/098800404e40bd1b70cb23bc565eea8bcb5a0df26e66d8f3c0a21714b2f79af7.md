# Keep typed property names and legacy storage names distinct

The public IDL/JS attribute is lower camel case storeToken; native accessors use GetStoreToken/SetStoreToken; the persisted string property has the same storeToken spelling. The compatibility column remains msgOffset. Scoped naming rule for this API: use the typed public name in callers and reserve the old column name for migration tests/implementation. A text search for msgOffset does not prove that messageOffset is still a supported public API. The bounded accepted symbol check establishes absence only in the listed header implementation and interface files.

Scope: mailnews/base/public.
