# S/MIME selection validates both usages locally and lets the user override a failure

The selection controls pass signing or encryption field IDs. smimeSelectCert chooses the matching verification usage, passes FLAG_LOCAL_ONLY, and asks for confirmation on failure. Declining returns before applying the new certificate and saving its dbkey; accepting continues. The Test UI shares the verifier but does not pass the local-only flag. This final source differs from the earlier hard-rejection summary/test plan. No certificate, PIN, network or native verification test was run.

Scope: Thunderbird S/MIME certificate selection validation.
