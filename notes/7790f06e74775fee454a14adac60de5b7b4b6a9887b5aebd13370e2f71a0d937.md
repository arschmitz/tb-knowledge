# Expose the hidden macOS mail menu item to keep Command+1 available

Entry 1488 includes tasksMenuMail on macOS and unhides it during hiddenWindowStartup. The key points to key_mail. Current focusOnMail selects a tab in an existing mail window or opens one when no window exists. Keep the menu visibility and key declaration together when changing the hidden-window flow; source inspection does not prove macOS keyboard behavior. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: macOS mail window.
