# The Exchange OAuth override setter must forward false as a value

The removed NS_ENSURE_ARG(value) guarded a bool setter value rather than an output pointer, so it rejected the valid disabled value before the details write. The accepted accessor macro keeps the bool* getter guard and forwards the bool setter value unchanged; the details implementation passes it to SetBoolPref. The rewritten browser task checks both enabling/editing the override and disabling it after reopening the dialog, ending with a direct false assertion on the incoming-server property. No profile write, UI or test was executed here; this is this property's value contract, not a rule to remove pointer guards elsewhere.

Scope: Exchange Boolean property setter and UI regression test.
