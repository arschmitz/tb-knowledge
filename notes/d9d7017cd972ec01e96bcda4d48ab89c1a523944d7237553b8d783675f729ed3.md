# Commands console reliability, task recovery, storage retention, and patch identity

Retention policy: shared Try download cache is capped at 5 GiB/7 days, assessment evidence at 2 GiB/7 days, build snapshots at 10 GiB/14 days, and daily logs at 256 MiB/14 days. Inactive assessment/task evidence is removed while verdict state remains; active tasks acquire storage leases. Imported Try history lacks saved source selection and is intentionally inactive; expose it as `imported-history`. [Task 2]

Scope: console.
