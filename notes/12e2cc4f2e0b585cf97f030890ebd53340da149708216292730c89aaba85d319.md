# Guard the absent tab-specific receiver before calling its optional method

Calendar extraction uses messagePane?.visibleMessagePaneBrowser?.() before falling back to currentAboutMessage.getMessagePaneBrowser(). A message tab returns its own content window through currentAboutMessage and may lack the three-pane messagePane object. Optional invocation alone did not guard that missing receiver. The fixed source preserves the message-tab and standalone-window fallback order. This is a specific allowed-absence contract, not a rule to hide required objects. Bug comment6 is unavailable; no UI test ran.

Scope: Calendar extraction message-tab receiver contract.
