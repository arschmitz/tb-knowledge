# Compare applied files when Phabricator raw binary patches differ

D204666 reviewer first requested changes because a raw Phabricator patch showed many binary test-data differences from an independent mach vendor run. The author suspected patch encoding; the reviewer applied the revision with moz-phab patch, exported it with hg, and found it matched the independent vendor result. The reviewer accepted without source changes. For binary vendor data, do not infer changed file contents from raw patch encoding alone; compare applied files or repository blobs. This lesson comes from the bulk import review, while the bulk source remains excluded from the code/style scan.
