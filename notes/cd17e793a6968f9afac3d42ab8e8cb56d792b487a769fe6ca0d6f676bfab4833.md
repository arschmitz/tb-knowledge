# Graph regeneration formats before and after automatic Clippy fixes

The registered mach wrapper runs a sequential extractor, fmt, Clippy-fix, fmt pipeline. check=True stops this caller on a failed subprocess. The comments explain clearer diagnostics before fixes and line-length changes afterward. This is the concrete package-scoped ms_graph_tb workflow, not policy for every generated file or proof the generated result builds.

Scope: Graph generator command completion.
