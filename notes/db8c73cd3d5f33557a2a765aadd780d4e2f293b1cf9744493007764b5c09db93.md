# The visible-column helper checks membership, so its reordering caller lacks an order assertion

The fixed assert_visible_columns predicate checks mutual membership with includes, not positional equality, despite its order JSDoc. test_column_reordering_persists mutates expected order and calls that predicate across tab/folder switches, so these checks do not distinguish a permutation of the same IDs. This is a bounded source assertion-gap finding; no observed failure or intermittent cause is inferred. A focused proposed test correction is to compare the complete ID sequence when the scenario intends to verify order. Keep visibility membership and ordering expectations distinct. This finding is not an applied change or a proven cause of the reported intermittent.

Scope: Thread pane column test assertion scope.
