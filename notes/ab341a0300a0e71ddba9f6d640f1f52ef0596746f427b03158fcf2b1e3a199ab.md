# A failed saved-password deletion can leave display reloads suppressed

FinalizeSignonDeletions sets reloadDisplay false and awaits each removal before restoring the flag and clearing the deletion queue. If removal rejects, those later statements are skipped. The storage observer only reloads while the flag is true, and the all-delete caller has already cleared the visible tree before awaiting finalization. This is the exact static failure path; no removal failure or rendered UI was tested.

Scope: Password manager deletion state.
