# Dialog fallback distinguishes zero-size triggers from absent trigger objects

The original hidden-trigger patch checks width===0 or height===0 and returns container.left + container.width/2 - dialog.width/2 and the corresponding vertical center. Fixed source adds !trigger before those property reads. PositionedDialog can pass an absent rectangle through optional chaining, and later unit/browser cases cover null and opening without an event. Keep that later missing-object guard distinct from the original zero-size check. The browser fixture removes button padding/border so its zero-size inputs have the intended geometry. These checks do not detect all offscreen, occluded or clipped triggers, and the source tests were not run.

Scope: Calendar dialog fallback geometry.
