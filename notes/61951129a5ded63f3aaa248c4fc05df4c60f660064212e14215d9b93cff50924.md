# The devtools about-link routing retains its regex despite a startsWith suggestion

Fresh full about-prefix routing patch and current compatibility helper read. openTrustedLinkIn sets a default system triggeringPrincipal in params, then sends about: strings to openContentTab(url) while other URLs go through openLinkIn(url,where,params). The about branch forwards only the URL; this is an existing trusted devtools/toolkit compatibility helper, not a new general navigation/security API. The reviewer proposes startsWith for the literal prefix, the author says either works and the path is rare, and the badge is marked Done. Actual landing and fixed0b93 retain /^about:/.test(url). The displayed suggestion is therefore not an applied source change or global regex ban. The Bug attributes about:blank/BAD_URI to a regression; no devtools/profiling, principal or routing test ran here.

Scope: Devtools trusted link compatibility routing.
