# Scope Message-ID privacy comments to the actual hostname fallback chain

Proposed comment refinement in MimeMessage: a valid From-derived hostname can be passed to the generator, but the native generator first considers an identity-forced FQDN and falls back to the identity email domain if the custom hostname is invalid. If no host is valid, it leaves generation to NNTP or SMTP. A comment that says the identity is never used is therefore broader than the inspected implementation. This is a static comment/caller contract concern, not a reproduced identity disclosure. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mailnews / compose.
