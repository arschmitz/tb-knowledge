# Shortcut matching normalizes base-key case before the separate modifier check

matches lowercases the event key once and each present stored shortcut key, filters by context and checks candidate conflicts. A unique candidate still needs its platform meta/ctrl/shift/alt state to match. Multiple same-base/context candidates throw before that modifier test, so case folding is not permission to create ambiguous definitions. This is string-key normalization, not event.code remapping, ignoring Shift, or proof for every keyboard layout. Main and compose callers retain separate gates/context. No key event or test ran.

Scope: ShortcutsManager base key and candidate ordering.
