# Retain a failure-path source-preservation check for IMAP-to-local moves

The accepted stopMovingToLocalFolder test stops the fake server from onProgress during a move and subsequently checks one source message and zero local destination messages. It disables auto-sync offline stores. This gives a narrow existing failure scenario for the EndMove boundary; it does not cover bulk offline-store moves, undo, restart persistence or partial batch rollback. The test was read, not run. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: IMAP to local move tests.
