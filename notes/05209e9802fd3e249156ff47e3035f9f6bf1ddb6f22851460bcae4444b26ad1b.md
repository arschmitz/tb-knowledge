# Keep Calendar dialog source packaging aligned with its current resource URL

The original dialog module was shipped through jar.mn as chrome messenger content. Current moz.build lists it under MOZ_SRC_FILES, and the browser fixture loads moz-src:///comm/mail/components/calendar/content/calendar-dialog.mjs. Preserve packaging and the consumer URL together for this component; the historical chrome URL is not its current packaging contract. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Calendar component module packaging.
