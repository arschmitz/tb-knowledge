# EWS settings hides unselected unsupported authentication choices and tests the fresh-account menu

EWS initialization calls hideUnlessSelected for Kerberos, NTLM and encrypted-password, so an already selected legacy option remains visible. External authentication is separately hidden outside IMAP. The browser scenario waits for initialized server settings, then directly checks a fresh EWS menu has two visible choices in password/OAuth2 order. It does not establish backend authentication support, password-method security equivalence or every persisted-selection case. All three added assertions have nonempty should messages. No runtime tests.

Scope: ews-account-settings-auth-menu.
