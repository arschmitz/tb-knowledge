# Commands graph selected Implementation base and checkout branch choice

Git permits separate branches in separate worktrees to point at one commit; it only rejects checking out the same branch twice. `resolveImplementationBase()` resolves branch/hash input to a full hash, pins `state.baseHash`, and calls `taskManager.prepare({ commRevision })`, so Implement can use an occupied branch's commit without checking out that branch.
