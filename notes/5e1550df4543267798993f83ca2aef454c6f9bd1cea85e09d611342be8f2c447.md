# Splitter test setup waits for vertical space after enlarging the window

This setup requests the available screen size, opens and loads the fixed-geometry splitter fixture, then waits until its document has zero vertical scroll range. The accepted source keeps this condition wait. Existing pane-size assertions remain separate: the predicate does not itself prove every drag result, horizontal fit, or a general resize-complete event. The window size is not restored here. No Linux or splitter test ran.

Scope: test-widgets.
