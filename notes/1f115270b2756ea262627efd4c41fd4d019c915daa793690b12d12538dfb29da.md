# Keep ownership and disclosure checks at space API boundaries

SpaceTracker.convert returns isBuiltIn and isSelfOwned, and exposes extensionId only with management permission. remove/update reject unknown IDs and data owned by a different extension. Removal deletes the data map but leaves the numeric index; a stale numeric lookup still resolves to null through the second map. This is observed static behavior, not proof of a user-visible stale-ID defect or a requirement to expose all owner IDs. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces ownership.
