# Keep explicit instruction notes outside automatic lesson generation

Explicit user-directed-code-style notes marked instruction can lack an ordinary evidence reference. Preserve that marker when importing them and skip instruction records during automatic learning, including older shared-note representations. Keep the reference requirement for ordinary evidence. A local reader repair passed focused import, identity, queue and immutable-file tests plus a real scoped search. The changes are not yet an accepted release; this observation does not let ordinary source evidence acquire instruction authority.
