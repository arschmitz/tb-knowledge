# Key revocation reason extraction has distinct missing, success and exception cleanup paths

The comm wrapper resolves a key handle, obtains its revocation signature and reads separate code and text buffers. Missing handles return a null pair. Normal completion frees the buffers, signature and key. A throw in nested extraction bypasses later destructor calls because the new wrappers have no finally. This describes the inspected control flow, not a reproduced native leak or an ABI guarantee.

Scope: OpenPGP revocation reason handles.
