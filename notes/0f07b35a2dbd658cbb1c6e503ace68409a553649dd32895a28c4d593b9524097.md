# Use the accepted Get names only in their historical copy-handler interface

D231154 specifically requests GetCurrentMessageHeader and GetIsMove for the copy-handler getters; the actual landing uses those names. This is a checked C++ naming example in that historical interface. Fixed Exchange architecture removes both getters and passes completion data through a different callback, so do not revive the removed methods or describe those historical declarations as current API. The existing source-side copy sequencing lessons remain separate from this naming observation.

Scope: Historical EWS copy handler getter names.
