# Late illegal folder characters use the same 47-unit prefix cap before hashing

This landing limits the prefix before an illegal folder-name character to MAX_LEN - 8, then hashes the full original UTF-16 name and appends eight hex digits. The 55-unit result bound counts UTF-16 code units; it does not define a filesystem byte or grapheme limit. The existing high-surrogate guard also applies when this cap is selected. The added GTest checks one literal ASCII expected result and the local-store test checks an exact leaf through a coupled JavaScript hash replica. The new GTest assertion has no nonempty message, which remains a scoped review finding. No native or test execution ran.

Scope: Local folder safe-name hashing.
