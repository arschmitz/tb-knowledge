# Folder rows remove stale special-type data after a flag is cleared

setFolderTypeFromFolder removes dataset.folderType when FolderUtils returns none; otherwise it assigns the lowercased recognized type. The flag-change caller recalculates that attribute and row names. Special-folder CSS selects icons/colors from the attribute, so retaining an old value would keep matching the old special type after its flag is lost. Other remaining special flags can still select a different recognized type. No icon rendering, accessibility check or runtime test ran.

Scope: Folder-pane row flag and CSS state.
