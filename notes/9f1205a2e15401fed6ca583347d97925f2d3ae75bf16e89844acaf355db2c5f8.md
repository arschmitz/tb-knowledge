# Account Hub selection snapshots filter controls before mapping URLs

In D228906, review requested filtering checked enabled controls in the selector and using Array.from's mapping argument. The landing and fixed email-sync-accounts-form keep Array.from(querySelectorAll("#addressBooks input:checked:enabled"), input => input.dataset.url), with the same calendar pattern. For this native form snapshot, prefer that local form over copying all checked inputs and then filtering disabled controls in JavaScript. The returned value is an array of URLs, so this is transformation code; it does not override the separate for...of guidance for actions. Preserve the enabled boundary and URL identity. This is an accepted local convention, not a requirement to convert every filter/map chain. Existing resource-selection lessons retain the behavior details. Static source and review inspection only; no form run.

Scope: Account Hub sync collection syntax.
