# Notification appearance is parameterized by type-specific CSS variables

The message and security additions specialize in-app-notification-* type classes by setting semantic variables such as icon fill, title text, button colors and content background. Common layout and focus rules consume those variables. In this component, prefer adding a type-specific variable block to duplicating the shared content/button structure. This is a source-supported component recommendation, not a project-wide CSS rule or measured contrast approval. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
