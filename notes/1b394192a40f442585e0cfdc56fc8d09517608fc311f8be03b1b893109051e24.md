# Cookie observer reads notification actions before the cookie payload

The accepted cookie manager treats cookie-changed subject as nsICookieNotification. It handles ALL_COOKIES_CLEARED before reading cookie, returns for unsupported actions, then processes COOKIE_CHANGED/COOKIE_ADDED through notification.cookie. External delete notifications remain unhandled by design in this consumer. Registration and teardown now cover cookie-changed alone. Preserve action eligibility before payload access; this is a comm consumer contract, not paired upstream interface proof. No cookie or observer runtime test ran.

Scope: Cookie manager notifications.
