# Calendar event lists use presentation wrappers while items own option names and selection

The three event-list layouts give their ordered lists a listbox role and their normal/drag-shadow li wrappers a presentation role. The actual calendar items call the shared option initializer, carry aria-selected and expose a normalized title or untitled fallback. Their label CSS disables label pointer targeting while the item retains its existing pointer setting. This is a source-level owner/attribute relationship, not a verified listbox keyboard model, native accessible tree or hit-test result; no new direct tests assert it.

Scope: Month/timed/all-day event list and inherited item accessibility setup.
