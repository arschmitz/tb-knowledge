# Application and language-pack Debian changelogs add the same version prefix

Both Debian changelog templates prepend the literal 1: to PKG_VERSION while keeping package-name, release/urgency and date placeholders unchanged. Fixed accepted source retains the paired templates, so preserve their synchronized version format when inspecting this packaging phase. The external renderer and Debian version comparison were not audited or run; this source alone does not prove a generated package version or an upgrade result.

Scope: Linux Debian packaging templates.
