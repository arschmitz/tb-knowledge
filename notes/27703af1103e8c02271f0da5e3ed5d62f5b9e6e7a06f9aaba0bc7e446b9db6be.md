# Cloud attachment text uses compose localization while updating the editor document

Cloud attachment helpers receive an editor Document for lookup and insertion, but format labels through the surrounding compose document.l10n. The compose chrome document loads messengercompose.ftl. Keep the localization owner distinct from the target document; replacing a localizer does not move the editor or establish that every synchronous compose localizer is gone.

Scope: compose-localization.
