# Skipped message-window tests filter the compose document instead of the display window

The migration changes both no-backing-view window watchers to an equality check for messengercompose.xhtml, while their trigger calls MailUtils.displayMessage and the message-window producer opens messageWindow.xhtml. The two affected tasks are explicitly skipped at the landing and fixed accepted revision. This is a latent predicate/producer mismatch in skipped tests, not evidence of an active test failure or a reproduced hang.

Scope: Message display test window predicates.
