# Attachment Delete remains handled while the shared action guard rejects modification

AttachmentListController advertises generic delete and shift-delete as enabled and handles them through HandleSelectedAttachments. HandleMultipleAttachments then returns when message policy forbids delete/detach. This keeps command handling separate from permission to modify content. Preserve that distinction when changing attachment keyboard behavior; a disabled command can have a different dispatch contract. The owned landing rejects a whole mixed selection through every(), whereas selected fixed code filters unusable entries. This is comm source evidence, not an executed controller-fallthrough test.

Scope: Attachment keyboard commands.
