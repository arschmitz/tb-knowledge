# EWS reviews can precede upstream dependency merge while landing still needs the final pin

The EWS reviewer allows ews_xpcom review before the matching ews-rs pull request merges because the reviewer can apply the patch and run mach tb-rust vendor. That qualifies an earlier WIP-until-merge suggestion. Landing still requires the proper upstream hash and revendored code; the author reports both and the assigned patch changes the dependency and vendor inputs. This is the scoped EWS workflow, not a rule that all unmerged dependencies are ready to land. The upstream PR, vendor command and Try were not executed here.

Scope: EWS dependency review.
