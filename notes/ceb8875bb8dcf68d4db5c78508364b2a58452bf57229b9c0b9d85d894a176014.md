# Pending edit Save ignores route changes

For D332899 at revision 3e22f6ce2506a323aecd485c174f9dab1c3a0298, the AI assessment reports that setCalendarEventRoute immediately skips the superclass call while edit Save is pending; it does not wait or queue a switch. Documentation should describe ignored route changes, which can target another event or occurrence, rather than only a calendar switch. Create-session replacement has a separate contract. Focused browser tests reportedly passed, but the proposed documentation change was not accepted.

Scope: Calendar event route changes.
