# Preserve spaces button and menuitem presentation together

Accepted creation builds a native button and menuitem with the same title, a decorative empty-alt image, and supported icon-style maps. Updates replace icon values and clear omitted badge text/styles. Keep both interactive presentations synchronized. A title attribute alone and static DOM reading do not prove the computed accessible name or focus result. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces native presentation.
