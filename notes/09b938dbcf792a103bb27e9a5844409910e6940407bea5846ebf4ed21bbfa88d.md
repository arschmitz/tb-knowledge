# Thunderbird Calendar create/edit attribute-driven source loader

Empty routes can be create mode only when the consumer allows them; partial routes fail with `incomplete-identity`, and complete routes load the event or requested recurrence occurrence. `CalendarEventSourceError` already forwards a caught error as `cause`. Selector maps are intentionally extensible: create/edit adds `createEditSession`/`draftState`, while legacy read dialog explicitly opts into raw-event retention. [Task 3]

Scope: calendar.
