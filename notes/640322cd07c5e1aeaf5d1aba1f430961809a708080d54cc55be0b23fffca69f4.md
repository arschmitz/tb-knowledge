# Folder lookup failure must survive a successful diagnostic lookup

FindFolderWithId records a failed remote-ID property read before calling GetURI for diagnostics. A successful URI lookup cannot replace that failure with NS_OK. The scan continues and can still return a later matching folder; another failed diagnostic may replace the retained error with a different failure. Update and creation callers propagate failed lookup before dereferencing, while the delete caller deliberately treats absence as already deleted.

Scope: exchange-folder-lookup.
