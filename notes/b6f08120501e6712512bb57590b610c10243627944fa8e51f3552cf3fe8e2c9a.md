# Register the compose-window waiter before activating a message link

The current EML mailto test installs domWindowOpenedAndLoaded with the compose document URI before synthesizing the click. It then waits for compose_window_ready and closes both windows. Follow this ordering for this actor-driven interaction. A window-opening assertion does not also prove To-field parsing, account selection, or screen-reader output.

Scope: mail/test/browser.
