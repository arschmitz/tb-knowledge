# The midnight-test guard samples UTC once and excludes the first minute after midnight

The test builds now from new Date and converts it to cal.dtz.UTC before computing a const skip flag. It skips sampled 23:56–23:59 and, after this follow-up, the whole sampled 00:00 minute. The dedicated manifest sets TZ=UTC, while CalMetronome uses local Date fields and a minute-based timer. The report-only task uses the inverse flag. This is a start-time exclusion; it is not recomputed during an asynchronous scenario and does not prove that a timer fired, a test cannot cross midnight later, or every platform delivers an update within 60 seconds. The preceding month-grid expectation change is a separate phase.

Scope: calendar/tests.
