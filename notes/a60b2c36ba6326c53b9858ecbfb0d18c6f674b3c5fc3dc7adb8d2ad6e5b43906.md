# Keep spaces-button identity separate from class names and decorative imagery

The created control is a native button with the supplied stable id, spaces-toolbar-button/spaces-addon-button classes, a title, and a tabIndex used by toolbar navigation. Its child image has alt="". Preserve these local identity/style/control roles rather than replacing the button with an image. This is a scoped source pattern; title and tabIndex alone do not prove screen-reader or keyboard behavior. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: extension spaces toolbar.
