# The folder ARIA race test checks final text without forcing localization overlap

testAriaLabelRaceCondition writes three synchronous counts, waits, then writes two more around a60ms delay and checks final label substrings. It restores the original unread count at the end. The test does not control pending Fluent promises, count localization requests or monitor all intermediate labels. A final expected value does not prove that older work never ran or deterministically exercise the stale-result guard. The fixed500ms waits were accepted for this case with explicit lint exceptions; they do not change the general event/state-wait guidance. No browser test was executed.

Scope: Folder pane browser-test timing and assertion limits.
