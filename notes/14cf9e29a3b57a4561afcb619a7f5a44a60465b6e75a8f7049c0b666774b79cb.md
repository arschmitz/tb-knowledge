# The modern prompt runner requires the async authentication listener method

RunnablePrompter calls onPromptStartAsync with an onAuthResult callback and rejects thrown calls. The removed code had retried the deprecated synchronous onPromptStart method. The IDL still declares both methods, and the checked IMAP adapter implements the async method by reporting its synchronous result through the callback. This is the runner contract, not evidence that the original shutdown issue was reproduced or fixed.

Scope: Message authentication prompt queue.
