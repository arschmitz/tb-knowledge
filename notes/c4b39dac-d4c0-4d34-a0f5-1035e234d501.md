# Name mail tab grouping groupType in Manifest V3 while preserving viewType in V2

The mail-tab values ungrouped, groupedByThread, and groupedBySortType describe message grouping. Bug 1899314 explicitly corrected the misleading early API name viewType to groupType for Manifest V3. The schema gates groupType to V3 and viewType to V2; conversion emits only the version-appropriate name, while update normalizes either input. Current code retains this compatibility path. For API naming, name the dimension represented by the values, and gate an incompatible rename by version rather than removing the older contract.

Scope: WebExtension mail tab API naming.
