# MIME depth tracking selects an external leaf above the container limit

The change passes numeric partDepth through child creation, independently of the CMS-policy parent pointer. mime_create selects MimeExternalObject only when partDepth is greater than 64, then stores the depth on the object. The child helper adds one to its parent depth. The external leaf still receives parser data and can perform leaf transfer decoding; this is a recursive-container cutoff, not a total input-size or resource guarantee. The encrypted-child path also checks allocation before decomposer access. No parsing or cryptographic execution was performed.

Scope: MIME parser nesting.
