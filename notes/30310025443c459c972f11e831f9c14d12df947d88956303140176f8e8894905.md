# Keep no-UI donation routing distinct from visible notification replay

Entry 823 adds the historical donations_old type, which executes a CTA rather than emitting a new UI event. Accepted code now treats donation_browser and donation_tab as no-UI types and excludes them from registration-time replay. NotificationOpener waits for active use for those routes, opens a tab only when requested and tabmail exists, and otherwise falls back to the external browser. Do not use the historical donations_old spelling as a current type or assume every current donation CTA opens externally.

Scope: mail/components/inappnotifications.
