# Historical EWS Disk Space exclusions differ from current offline controls

The historical EWS Disk Space patch hides offline/autosync controls and separately adds EWS to a retention confirmation list. That list triggers the old server-removal warning, not visibility. At the fixed accepted source, offline and autosync controls are visible for EWS, the test matrix has changed, and retention opens a dedicated sub-dialog. Preserve those phases instead of treating the old unsupported-setting list or warning implementation as current policy. Visibility tests do not prove downloads or retention behavior. No UI or backend test ran.

Scope: Account settings offline-pane evolution and retention warning.
