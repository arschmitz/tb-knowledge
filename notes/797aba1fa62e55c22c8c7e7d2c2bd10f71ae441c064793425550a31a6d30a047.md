# Botan ABI inputs preserve compiler flags before a conditional sysroot include

The owned Botan configure glue copies the compiler flags before building --cc-abi-flags, then searches sysroot/usr/include/c++ for a numeric-version include directory under its Linux ARM64 condition. It selects the highest numeric entry, injects it only when that path is a directory, and logs exceptions before continuing configuration. This changes compiler inputs; it does not install headers or prove a build succeeds. The original aarch64/arm64 patch is immediately backed out to its exact preimage. The fixed accepted source later contains a restoration limited to aarch64. Keep these phases and the imported compiler/Botan behavior separate; no configure or cross build was run.

Scope: third_party/OpenPGP/configure-glue.
