# Guard Account Hub add-on controls that are absent in enterprise builds

The current config-found template excludes add-on controls under MOZ_ENTERPRISE. The widget must therefore treat those controls as optional, and the account view uses whether add-on discovery is enabled when ewsifying the result. Keep compile-time control presence and configuration choice consistent. This is a scoped implementation and structural accessibility check; enterprise builds and their navigation were not run. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / components.
