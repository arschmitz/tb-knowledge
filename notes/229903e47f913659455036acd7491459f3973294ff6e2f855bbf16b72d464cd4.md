# The soft-delete empty-trash test checks a folder, not message contents

The soft-delete helper creates a remote folder, moves it to Deleted Items, then calls trashFolder.emptyTrash(null). It waits until Trash has no child folders and checks that the moved folder ID is absent from the fake server after sync. This directly checks folder deletion. The helper creates no message and does not assert message removal, multi-folder error handling, or calling emptyTrash on another folder. Keep those coverage limits separate from the comment that emptying should work from any folder. These are static test assertions, not executed results.

Scope: Exchange / folder operation tests.
