# Cancel an old tree animation before switching its state classes

Both tree transition directions cancel childList.animation, remove the opposite animating class and set their own class before starting an animation. Completion clears the class, commits height/hidden state, cancels the fill effect and deletes the animation handle. Recommend keeping that state sequence in this widget when adding interrupted transition behavior; rapid repeated toggles were not executed. These are fixed accepted source and test-code observations.
