# Moving AutoSync settings preserves preference keys and receiver types

The base server exposes offlineDownload and autoSyncOfflineStores as Boolean preferences, and autoSyncMaxAgeDays as an integer. Native and JavaScript implementations keep the same stored underscore keys. IMAP-only properties still require their separate interface. The auto-update caller checks both the enabled preference and an explicit imap/ews allowlist; a true default alone is not capability proof. Its age predicate applies only for positive values. No preference or AutoSync test ran.

Scope: Base incoming-server AutoSync preference migration.
