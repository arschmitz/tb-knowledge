# Do not treat an unused expected-URL variable as a URL assertion

The original manager test stub compared the external open URI with expectedURI. At the fixed endpoint, test_executeNotificationCTA_formatURL still computes expectedURI but checks the mock URL count instead. The separate container formatted-URL test does assert the formatted href. When reviewing this test family, distinguish opening-count coverage from exact destination coverage. A computed expected value alone is not an assertion. This observation is limited to the inspected manager test; it does not establish that all destination tests are absent. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Notification test assertion scope.
