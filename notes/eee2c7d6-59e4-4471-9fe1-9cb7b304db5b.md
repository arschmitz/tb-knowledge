# Cover focus and autocomplete when a search widget API changes

The widget browser test covers overrideSearchTerm with and without focus. It checks that a matching value does not emit another autocomplete event, that a focused nonempty input refuses an override, and that an empty focused input accepts one and emits autocomplete. These are the edge cases that protect the user-typing rule used by the extension API.

Scope: search-bar widget tests.
