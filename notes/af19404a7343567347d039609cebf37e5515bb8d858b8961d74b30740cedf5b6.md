# Filter pending message-property waits by both header and property

The junk-menu test waits for junkscore on the intended header, while the tag-menu helper now waits for keywords on its intended header. Matching only the message could resolve a wait on an unrelated property update. Both helpers unregister after the match and resolve after a tick. Popup closure is a separate wait: each helper waits for its own popup, and the tags helper checks whether a parent popup exists before waiting for it. This is the checked test-helper contract, not a generic guarantee about native menus or message reload timing. Review reports local test failures and uncertainty; no test ran here.

Scope: Message-menu test property waits.
