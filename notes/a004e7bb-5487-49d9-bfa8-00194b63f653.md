# Recheck label references during LDAP dialog layout changes

The accepted 2024 LDAP layout patch moved fields but left the hostname input with aria-labelledby="descriptionLabel" even though the visible hostname label is hostnameLabel. The current checkout still shows that mismatch. Review discussion covered layout and dismissal, not this label relationship. When touching this dialog, check each input’s aria-labelledby or control target against its own label; do not treat the prior accepted visual cleanup as accessibility validation. This is an observed gap, not an accepted style choice.

Scope: LDAP settings accessibility.
