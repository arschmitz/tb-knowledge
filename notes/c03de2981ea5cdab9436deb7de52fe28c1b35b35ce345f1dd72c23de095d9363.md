# Register migrated probes in Glean build inputs and retire obsolete test probes

The migration removed old Events.yaml, Histograms.json, Scalars.yaml and their obsolete build-configuration test probes. Thunderbird metrics and tags now enter Gecko’s Glean generation through MOZ_GLEAN_EXTRA_* configuration. Current configure also registers component metrics files and lists interesting Gecko metrics needed by tests and product features. Update build inputs, tests and documentation together when removing a probe system. Current documentation still contains older prefix wording, so it is not evidence that every metric needs a tb prefix. No configure or build was run.

Scope: Glean build architecture.
