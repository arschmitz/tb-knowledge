# DisableTelemetry adds a usage-upload preference request

When DisableTelemetry is true, the callback now also requests datareporting.usage.uploadEnabled=false through the policy preference helper. It leaves that request inside the existing true branch. This does not by itself prove all telemetry is disabled, native preference delivery or upload behavior; no runtime test was run.

Scope: Enterprise policy callback and source comparison.
