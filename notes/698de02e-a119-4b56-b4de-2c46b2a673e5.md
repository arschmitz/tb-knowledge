# The 2024 outgoing-send bridge waited for a cancellable request from the protocol server

At Bug 1882574, MessageSend called the JavaScript service through wrappedJSObject and awaited sendMailMessage. The service resolved only when nsIRequestObserver.onStartRequest supplied the cancellable request and started the URL listener; onStopRequest forwarded completion. The protocol server could wait for a pooled connection before delivering that request. This is historical 2024 behavior, not a current API instruction: the current OutgoingServerService no longer has that wrappedJSObject/sendMailMessage bridge. The enduring lesson is to trace when cancellation becomes available if moving send ownership between service and protocol implementation.

Scope: Outgoing send lifecycle.
