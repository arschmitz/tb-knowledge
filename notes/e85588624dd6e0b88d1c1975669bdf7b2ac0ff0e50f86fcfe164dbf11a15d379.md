# Use the calendar formatter for month-and-year display and accessible names

Entry 771 replaces the older Fluent month-and-year assembly with locale date formatting. Current month view, calendar print and minimonth use cal.dtz.formatter.formatMonthLong. That helper accepts a zero-indexed month and uses a long month with a numeric year. formatYear also documents that some languages format a year differently. The minimonth uses the month name alone in its calendar accessible name for the selected year and the formatted month and year for another year. Manual calendar API proposal: document zero-indexed month arguments and share the same formatter for visible text and accessible names. Do not teach the old inline Date calls as the current preferred pattern.

Scope: calendar-localized-date.
