# Font rebuild listeners bind the pane that owns their helper methods

The accepted _rebuildFonts method calls helpers through this. Its language-group change callback and newly created per-language default-font callback both bind gGeneralPane. That preserves the method receiver at these callback boundaries. The local pattern does not require binding every listener, changing unrelated callbacks or assuming callback identity/removal behavior that this code does not use.

Scope: font-preference-listener-receiver-style.
