# OpenPGP confirmation returns an acceptance string rather than an import result

confirmPubkeyImport returns null when the user cancels; otherwise it returns the chosen acceptance string. The dialog producer supplies undecided or unverified. Callers pass that value into importKeyAsync; import helpers report their separate Boolean outcome. Canceling the file workflow returns from the whole loop, while canceling the URL callback still returns before resolving its enclosing Promise. Do not infer one universal cancellation-completion result from this refactor. The existing key-import/acceptance lesson retains the separate trust boundary. Static source only.

Scope: OpenPGP confirmation and caller return contracts.
