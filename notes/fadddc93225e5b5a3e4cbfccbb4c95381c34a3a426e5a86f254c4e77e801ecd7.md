# Compose unload owns autocomplete cleanup when blur handling is overridden

Compose recipient inputs override normal autocomplete blur handling. The module therefore detaches each autocomplete controller when the document unloads. The added close-window test drops its local window and promise references, minimizes memory, and checks memory-reporter paths for detached windows. Accepted current code retains the unload callback; the historical test file is absent at the accepted revision. This is document cleanup after the local blur override, not proof that every memory leak is absent. The historical fixed500ms wait is not a new waiting rule. No test or memory run was performed.

Scope: Compose recipient autocomplete lifetime.
