# Set the delayed-send Message-ID before the protocol send

763 extracts the queued Message-ID or generates one from the sending identity, then sets it on compose fields before SendMessageFile. The SMTP DSN envelope ID therefore uses the same message identity as the serialized header. The test adds both a fixture with a header and one without it, and checks the server ENVID together with the delivered Message-ID pattern. This extends the earlier common outgoing Message-ID boundary lesson to the delayed-send caller. No SMTP transaction was run.

Scope: Delayed-send message identity.
