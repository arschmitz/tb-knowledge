# Document the UI telemetry sampling boundary instead of implying live state

Pane visibility reports the last visible3pane tab at foreground load/showTab. The accepted comment explicitly says later changes are not reflected until it is shown again. Folder modes are a comma-split string list from startup configuration; header values retain their actual string form. Proposed manual comment/schema rule: say when state is sampled, which values are recorded, and whether toggles update it. Tests that switch tabs validate a different boundary from tests that toggle in place.

Scope: ui-configuration-telemetry.
