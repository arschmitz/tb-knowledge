# Update Sync UI preference bindings when renaming an engine

Bug 1888023 renamed accounts to servers in the engine registration and default preference. Later Bug 1909393 records a regression: the Sync preferences page and dialog still referenced services.sync.engine.accounts. A July 2024 fix changed both UI bindings to services.sync.engine.servers; current code uses the new key. When renaming an engine, search UI preference mappings as well as module registration and defaults. The later fix is context only and will receive its full chronological review separately.

Scope: Thunderbird Sync integration.
