# Address-book deletion tolerates a row that is already absent

AbTreeListbox.getRowForUID returns querySelector’s result for a nonempty directory UID. That result can be null. The directory-deleted observer uses optional chaining before remove, so it still removes an existing row and skips the call when the row is already absent. The guard does not protect subject.QueryInterface or the neighboring update and request topics. This is a scoped absent-row contract; the reported asynchronous race was not reproduced.

Scope: Address-book tree directory-deletion observer.
