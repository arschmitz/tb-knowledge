# Exported lesson notes reject content collisions

At TB Tools revision c4b5b8fb8c80bafd44a62cffbb119234008f5efa, exportLessonNotes creates Markdown notes with exclusive file creation. If a target already exists, it accepts only a regular file whose text exactly matches the generated note; otherwise it throws an error. This prevents export from silently overwriting different content at the same lesson filename. Lessons already linked to shared notes are skipped before this check. The supplied code is from an unmerged implementation branch; the reported focused test result does not identify a dedicated collision test.
