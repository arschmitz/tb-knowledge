# Report the key operation and input that failed during OpenPGP test cleanup

RNP.deleteKey reports whether rnp_locate_key or rnp_key_remove failed and includes the fingerprint or deleteSecret value. The shared test helper explicitly rejects a missing requested key before continuing with key deletion, acceptance-state deletion and key-cache clearing. For this cleanup path, prefer operation-specific diagnostics over one generic failure string. The historical correction and current helper were read without deleting a key or running the tests. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / extensions.
