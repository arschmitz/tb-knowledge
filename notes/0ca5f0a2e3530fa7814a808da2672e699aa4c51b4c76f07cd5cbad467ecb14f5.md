# GetClearedOriginalOp has a side effect the removed GetOriginalOp lacked

Both historical helpers look up an original offline operation through its source folder and message key. The retained GetClearedOriginalOp additionally checks the move destination URI and clears kMoveResult for this folder. Fixed CopyMessagesOffline still calls that variant. Similar names are not proof of equivalent behavior; the unused non-clearing helper removal is a separate cleanup. No offline move test ran.

Scope: IMAP offline operation state.
