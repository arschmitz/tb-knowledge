# Rejected-word lint rule severity, task tier and file triggers are separate scopes

The rejected-words job uses commlint over comm, Treeherder and JSON output, and tier2. Individual error-level rules have their own exclusions and extensions. Only the first wrapped terminology rule excludes mailnews. Task trigger extensions differ from rule extensions, so scheduling does not prove every triggering file type is scanned by each rule. This is checked configuration, not new writing policy or actual lint execution.

Scope: taskcluster-commlint-rejected-words.
