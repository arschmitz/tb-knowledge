# Keep event-delivery exceptions separate from ordinary deleted-message filtering

The cached-flag race explains the event-only includeDeletedMessages option: an IMAP message may already carry its deleted flag when cached, so applying the general list filter during later event conversion loses the historical source payload. Ordinary lists still default to filtering these headers. The original tracker deliberately chose general filtering while recording compatibility concerns; the event exception does not reverse that choice. Review also permits explicit ?? false after the author explains that it makes the option default visible. The reviewer has no strong opinion; a proposed future lint rule is not active guidance. Existing source lessons cover the implementation routes. Partial historical evidence: related Bug 1881929comment3 unavailable; no new runtime validation.

Scope: message event review.
