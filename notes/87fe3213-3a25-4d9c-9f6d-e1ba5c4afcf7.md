# Wait for user approval before following Exchange autodiscover redirects

Exchange autodiscover can return a 301 redirect that would send account credentials to another endpoint. The config finder waits for the redirect callback resolver so the user can approve the destination before credentials are submitted.

Scope: account-setup.
