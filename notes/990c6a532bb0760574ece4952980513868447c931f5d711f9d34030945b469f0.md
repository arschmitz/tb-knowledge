# Use narrow iterator contracts for header recipient helpers

1108 changes its mailbox-list helper from a concrete EWS recipient array to impl IntoIterator<Item = ews::Mailbox>, allowing the parsed-message adapter to use the same formatter. Current shared MessageHeaders returns optional iterators of its own borrowed Mailbox type and uses impl AsRef<str> for string headers. Express the data the helper consumes rather than coupling it to one protocol container. This is a scoped Rust interface practice; it does not prove a performance result or justify changing unrelated APIs.

Scope: Rust message-header input abstraction.
