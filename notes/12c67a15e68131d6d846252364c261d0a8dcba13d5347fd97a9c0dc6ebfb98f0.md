# Validate embedded policy directive spelling separately from XHTML shape

The historical key wizard policy contains style-src: rather than style-src; the accepted policy uses style-src. Proposed manual review check for these meta content strings: verify directive names and separators, not only the markup attribute and indentation. The source difference justifies that check but does not establish the exact browser parser behavior or a reproduced window failure for the old typo. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Embedded CSP directive syntax.
