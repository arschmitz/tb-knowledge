# Coordinate Clang ports with upstream dependency state

Bug 1891452 ports Clang 18 toolchain jobs from mozilla-central. The patch renames Linux and Windows job identifiers, Treeherder symbols, raw toolchain fetches, and compiler-rt dependencies, with matching reference-jobs in kind.yml. The accepted D210554 was later backed out twice: once after an upstream mozilla-central regression caused build bustage, then because the upstream patch itself was backed out. It was relanded after upstream state changed. A reviewed toolchain port can still be wrong for the current upstream revision; inspect upstream dependency and later backout history before using a landed snapshot as a durable pattern.

Scope: Taskcluster toolchains.
