# Removing public view attributes leaves internal database and news-size state

The patch removes the db, supportsThreading and usingLines attributes and their base getters. It does not remove the internal database getter or mShowSizeInLines. The selected news-view setup still reads news.show_size_in_lines, and FetchSize still uses that member to choose line counts. The unused label and bounded source check do not prove compatibility for every downstream consumer. No build or test ran.

Scope: Message view interface cleanup.
