# Keep protocol exposure separate from external link diversion

572 exposes the chrome protocol in Thunderbird preferences. Current link handling sends non-exposed schemes and HTTP/HTTPS to the external link path. This explains why missing exposure could divert an internal chrome destination. The preference list also warns that content policy has its own list; exposure is not a blanket grant of privileges to message content. Review the protocol gate and the actual link actor together. No live chrome URL navigation was performed.

Scope: Protocol routing boundary.
