# Document the callback that resumes asynchronous IMAP playback

746 improves comments about offline operation playback and asynchronous control flow. Its historical CreateOfflineFolders step resumed through OnStopRunningUrl and no longer exists in that form in the accepted source. Current playback still calls ProcessNextOperation from completion paths, and the timer explicitly starts pseudoOffline processing. A return after starting asynchronous work is not the end of the state machine. Proposed manual comment rule: name the resuming callback and the mode when they explain otherwise non-linear flow.

Scope: IMAP offline playback state machine.
