# Wait for compose-window closure after accepting the close prompt

The address-book drag-to-compose helper registers domWindowClosed for the newly opened window before interacting with it. After cmd_close and the unsaved-change prompt result, it also awaits that close promise. Prompt completion and actual window teardown are different boundaries. The final address-book cleanup adds one tick before directory assertions, but the author explicitly did not establish the intermittent failure's cause. This is a scoped test mitigation, not a general delay-based cleanup recipe. No drag/drop or window test ran.

Scope: Address-book test window lifetime.
