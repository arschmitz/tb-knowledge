# Input help text gains initialization and explicit error-transition assertions

The original input reads non-empty l10n-help-text-id during connection, shows/localizes its helper and assigns description references. Added tests directly assert visibility/localization and error-to-help description transitions, including a present-but-empty attribute that stays hidden. The help attribute is not observed for dynamic changes. Accepted code later uses generated ids and syncDescription with additional options; those later mechanics are separate. Tests are source assertions only, with no executed DOM-parser, layout or screen-reader result.

Scope: Account Hub input help and description lifecycle.
