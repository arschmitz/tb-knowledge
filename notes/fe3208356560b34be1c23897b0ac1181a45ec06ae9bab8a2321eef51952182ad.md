# Panorama recipient ingestion shares decoded fields and SQL row order

Recipient ingestion carries To/Cc/Bcc from RawHdr through PerFolderDatabase into the message table and compatibility getters. The original INSERT/DELETE RETURNING statements share MESSAGE_SQL_FIELDS with positional decoding, avoiding divergent layouts. Current code has a CachedMsg reader and later threading fields, so keep its actual field order aligned instead of copying the old constructor. The direct test checks decoded accented recipient values; multi-occurrence headers and all fallback cases are not directly asserted by it.

Scope: Panorama recipient ingestion.
