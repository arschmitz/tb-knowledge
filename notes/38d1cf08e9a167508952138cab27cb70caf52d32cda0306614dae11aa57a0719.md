# Preserve content-policy decisions when skipping the docshell tweak

For a non-parent document the docshell tweak is skipped, but ShouldLoad continues through its later policy handling. In the parent branch a helper failure sets REJECT_TYPE and returns NS_OK. The component documents that failed return values cause the caller to ignore the decision. Do not summarize this fix as accepting all javascript: or disabling all content policy. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.

Scope: mailnews/base/src.
