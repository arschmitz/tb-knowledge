# Reset junk training data when a test marks a message as junk

1019 reports browser_markAsRead.js permanent failures and exactly restores 1018's owned paths. The only reland source delta in 1022 is MailServices.junk.resetTrainingData() in cleanup after account removal. The accepted navigation test still resets it. Account cleanup alone does not reset the classifier's global training state. Keep the source repair separate from an unverified account of the exact reported failure mechanism.

Scope: Mail context junk test state backout chain.
