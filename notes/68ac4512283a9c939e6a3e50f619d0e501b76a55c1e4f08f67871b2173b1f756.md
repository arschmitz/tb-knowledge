# Use scoped string ownership instead of copying historical free patterns

748 adds a missing PR_Free on the service-acquisition error path of GetNamespaceForFolder. The accepted function now stores the converted folder name in nsCString, so the early return does not require manual release of that string. The historical leak fix and newer ownership choice are both useful: match manual allocations on all exits, and prefer the current scoped owner in new code in this function family. No memory checker was run.

Scope: IMAP namespace string ownership.
