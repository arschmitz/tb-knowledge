# Archive publication maps and test-artifact fetches are separate configuration layers

The Daily and release-candidate changes each remove nine named test-package archive mappings, including target.test_packages.json. The comm beetmover-repackage configuration selects the candidate map for beta/release/esr and the nightly map by default. Separately, accepted macOS universal configuration still fetches selected test archives and test_packages.json. Removing an archive-publication mapping is therefore a different source change from changing build/test fetch declarations. These patches do not demonstrate uploads, retention, package generation, test execution or compression compatibility. No task or build ran.

Scope: thunderbird-artifact-publication.
