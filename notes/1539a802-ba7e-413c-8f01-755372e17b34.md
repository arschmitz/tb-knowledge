# Use AutoTreeView for reusable column and sort behavior

Bug 1890731 introduced AutoTreeView as a TreeView subclass that owns column resize, visibility, reorder, restore, sort, and UI-density events. The author chose a wrapper while other TreeView users still had older behavior, to limit unintended changes during the migration. The stack then introduced TreeDataAdapter and moved Address Book and contacts/search views. Current AutoTreeView still owns these column and sort actions. When adding a new reusable tree, inspect AutoTreeView and TreeDataAdapter rather than copying about:3pane handlers.

Scope: Tree view architecture.
