# The Rust cleanup keeps fixed error mappings while removing discarded-error closures

This landing replaces closures that discard their error input and return a named nsresult with .or(Err(CONSTANT)); its Option host lookup uses ok_or(CONSTANT). The selected old and new expressions use the same fixed constants. The inspected callers still differ: EWS preference updates are best effort, tray icon errors select a fallback, resource creation uses expect, and channel reads propagate errors. These are scoped source facts, not a rule for eagerly evaluating expensive error producers or replacing an error-dependent mapping. No compiler, runtime, performance or general semantic-equivalence guarantee is claimed.

Scope: Rust bridge fixed error mapping.
