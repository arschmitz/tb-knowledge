# Update the owned Matrix loader and packaging when imported module paths move

The 1276 integration exposes CryptoEvent and VerifierEvent from matrix-sdk/crypto-api and updates MatrixAccount lazy getters and event registrations. The loader maps empty type-only modules such as DownloadFileAction to empty.js, while moz.build packages the useful crypto-api modules. The update README explicitly connects package-list and loader changes. A scoped integration recommendation is to audit all three layers during SDK updates; imported naming/formatting is not a Thunderbird style mandate. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
