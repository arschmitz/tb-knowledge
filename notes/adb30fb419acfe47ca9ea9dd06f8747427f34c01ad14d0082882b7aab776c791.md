# The interrupted-move retention assertions lack failure messages

The related check_messages task compares source count to 1 and destination count to 0 with two-argument Assert.equal calls. Both need nonempty expected-behavior messages, such as 'The IMAP inbox should retain one message after the interrupted move' and 'The local inbox should contain no moved messages'. No native transfer or test result was reproduced.

Scope: IMAP interrupted-move test diagnostics.
