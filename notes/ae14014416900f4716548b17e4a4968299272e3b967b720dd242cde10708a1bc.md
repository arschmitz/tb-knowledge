# Exchange display URLs move the local message key out of the fragment

The fixed message service converts /Folder#MessageKey into /Folder/MessageKey and an internal x-moz-ews or x-moz-graph scheme while preserving the query. Changing only a fragment makes docshell treat the next message as the same document and skip opening a new channel. The internal channel resolves the local header and key; the remote Exchange ID is looked up later by the offline fetch helper. Message URI identity, channel URI identity and server ID are separate contracts. Manual review proposal here: verify sequential messages in one folder and query-bearing attachment URLs after any URI transformation change. No display execution was performed.

Scope: exchange.
