# Parsed MIME headers belong to the mail channel rather than its URI

The MIME producer initializes nsIMimeHeaders and attaches it to nsIMailChannel. The staged IDL makes that object available at onHeadersComplete, while attachments and iMIP data finish at onAttachmentsComplete. Header view passes the object to MDN processing after checking for a folder and header object. Channel/URI roles stay distinct; older JS attachment comments do not establish earlier availability. Static source only.

Scope: message-channel-mime-headers.
