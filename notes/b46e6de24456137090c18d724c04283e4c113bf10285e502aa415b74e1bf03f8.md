# Commit mutated NNTP read ranges once during request cleanup

Marking unfetched old articles read sets _commitReadKeySet. Current cleanUp writes the read set only when that flag is true and then resets the flag. NntpClient calls cleanUp from its guarded _actionDone before clearing the request. This separates ordinary read-set lookup from persistent mutation. Do not unconditionally rewrite newsrc for every downloaded header. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: mailnews/news/src.
