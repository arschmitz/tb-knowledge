# The original username requirement test checks a host property without forwarding it to the native input

The original checkbox handler assigns required to an AccountHubInput host. Its complete class only copies required into the native input at connection and has no required accessor or observer. The new test checks the host property, so that assertion does not establish the inner input requirement. The fixed accepted class later adds forwarding to the native input and host attribute. Keep the historical mismatch, the test limit and the later receiver repair separate. No form-submission failure or runtime result is claimed.

Scope: Account Hub manual configuration custom input receiver.
