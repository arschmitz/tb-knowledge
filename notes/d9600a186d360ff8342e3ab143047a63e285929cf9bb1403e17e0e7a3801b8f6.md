# Let the native DB view determine the secondary sort after a primary change

DBViewWrapper.sort now accepts a column and direction, invokes dbView.sort once, then reads primary and secondary state back through getSortStatusFromView. The native view makes the previous primary the new secondary. Current code retains that flow. Avoid rebuilding a separate four-argument secondary-sort model in the wrapper.

Scope: mail/modules/DBViewWrapper.sys.mjs.
