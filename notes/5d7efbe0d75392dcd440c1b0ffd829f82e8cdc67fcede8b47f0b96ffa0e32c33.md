# The attachment drag marker records a request before saving completes

The macOS guard writes attachment.lastSavedPath before createUnique and the asynchronous saveToFile call. The selected method has no failure-reset path and does not await saving. It records the last requested destination rather than a completed save or every destination ever visited. The explicit comparison allows a different requested destination to reach the save path. Native grouping, actual failures and broader attachment lifetime were not exercised; the temporary/final destination rationale is retained separately with the full review audit.

Scope: Attachment drag request marker timing.
