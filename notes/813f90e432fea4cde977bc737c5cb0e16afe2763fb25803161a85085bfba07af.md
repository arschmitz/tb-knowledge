# Register the payload builder and select its matching worker implementation

The port adds register_mozilla_taskgraph(graph_config) and changes Mac signing roles to iscript while Linux retains scriptworker-signing. Fixed registration also replaces upstream verifications with Thunderbird-specific checks. These are owned taskgraph integration contracts; imported builders, worker availability and signed output were not validated.

Scope: Taskgraph worker registration.
