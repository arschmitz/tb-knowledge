# Empty-folder tests wait for message state after the confirmation dialog closes

The reland waits for a zero message count after accepting each empty-folder prompt, then checks the result. Smart Trash waits for both backing folders; its aggregate view checks remain commented. Smart Junk keeps aggregate, backing-folder and view assertions. Closing the prompt alone does not establish deletion completion. The shared window logger records loaded windows and removes its observer during cleanup; log output is diagnostic evidence, not a completion assertion. These are source assertions and waits.
