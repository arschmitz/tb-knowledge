# Query the active mail tab explicitly in Manifest V3

tabs.getCurrent reports the extension script context, whereas the old mailTabs.getCurrent reported the active mail tab in the active window. The matching names concealed different behavior. Bug 1898150 limited mailTabs.getCurrent to Manifest V2; Manifest V3 tests now use mailTabs.query({active:true,currentWindow:true}) and read the first result. Current schema still has the version gate. In extension code and reviews, name the intended tab context and query it explicitly; preserve MV2 compatibility while migrating MV3.
