# ZIP admission and extraction choose profile depth at separate boundaries

The root-ZIP support patch checks a possible one-folder prefix before falling back to root candidates. It extracts with depth0 or1 instead of always discarding a first path segment. Admission tests alone do not check extracted filenames. The accepted extraction helper later counts every root entry and strips a directory only when it is the sole root entry; that is stricter than the original UI counting root directories alone. Keep these phases separate when reasoning about archives containing both root files and a folder. The validator uses RegExp.test for its Boolean filter; extraction retains match, so this is not a component-wide style conversion or a measured performance claim. No archive import or test ran.

Scope: Thunderbird profile ZIP admission and extraction phases.
