# The sent-copy regression test checks local read state after FCC arrival

This landing marks the created header read when the source is a file and the draft/template flag is false. It does not test the destination folder type. The added send scenario waits for one message in the FCC folder and directly asserts the local header isRead value. Server read state, draft behavior and creation or database errors are outside that direct assertion. No send or sync run was performed.

Scope: Exchange file-copy completion.
