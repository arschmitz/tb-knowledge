# Account Hub labels evolved from a formatted aria-label to the actual localized label element

The landing assigns Fluent attributes to the label and a separately formatted string to the native ariaLabel. Its test formats the expected string in the tab document instead of assuming en-US text. Accepted source later sets ariaLabelledByElements to the label and tests that element relationship plus localization IDs. Review contained a tentative wrong-document diagnosis; the final code supports the tab-document comparison, not proof of that historical cause. This is a scoped element/test contract, with no live translation or accessible-tree result.

Scope: Account Hub label localization and test scope.
