# The text-copy regression checks omit assertion messages

The new details-pane scenario checks copied name and email strings, but both Assert.equal calls omit message arguments. The extracted menu helper also checks the Copy item's enabled state with Assert.ok and no message. These sites remain in accepted source. They need nonempty expected-behavior messages under the current deliberate review rule; this is not a defect based only on a missing should. The menu helper substitutes goDoCommand on macOS, so this test does not click the native macOS menu.

Scope: Address Book copy regression-test diagnostics.
