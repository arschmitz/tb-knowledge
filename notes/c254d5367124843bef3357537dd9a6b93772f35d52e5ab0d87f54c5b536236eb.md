# E2E account settings load the shared tokens used by their arrow and menu controls

The E2E include loads colors.css and variables.css, while accountManage.css imports icons.css. Arrow controls use navigation icon tokens and separate button hover/active backgrounds; the OpenPGP more-menu dropmarker uses the shared icon with currentColor stroke and explicit appearance/display values. These are concrete stylesheet dependencies and state selectors. Resolved colors, focus, contrast and native rendering were not tested. In retained [D302371](https://phabricator.services.mozilla.com/D302371), reviewers request the shared include imports and icon variables; the owned source adopts those changes and the separately proposed appearance adjustment. Reported macOS retesting remains historical; Done marks alone are not the adoption proof.

Scope: Account encryption styling dependency.
