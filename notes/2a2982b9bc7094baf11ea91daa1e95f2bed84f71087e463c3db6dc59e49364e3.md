# S/MIME API test sizes track decoded blob bytes rather than whole message files

The expectation update changes envelope and inner signed-data sizes separately from raw headers and literal body lines. Accepted readSmimeExpectations derives Date, base64-decoded binary length and encoded lines from each selected fixture. The signed task loads separate outer and inner inputs. PKCS#7 part size is not whole .eml length; base64 validation does not establish CMS/signature validity. The historical literal change and exact backout remain distinct from the later loader.

Scope: Extension S/MIME fixture expectations.
