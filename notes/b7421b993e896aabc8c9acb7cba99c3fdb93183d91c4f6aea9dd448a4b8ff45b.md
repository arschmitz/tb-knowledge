# The numbered mail/base browser manifests preserve settings and ask for alphabetical placement

The original split replaces browser.toml with four build-registered numbered manifests, ten of the original40test entries in each. The DEFAULT configuration and each test entry settings remain the same. Each manifest asks new tests to stay with their alphabetical neighbors. Follow this explicit local placement convention when editing this family; it is not a global rule for other harnesses. Static membership and blob checks prove no listed JavaScript body changed, not that tests passed or that state/leak isolation improved. No test ran.

Scope: mail-base-browser-test-manifests.
