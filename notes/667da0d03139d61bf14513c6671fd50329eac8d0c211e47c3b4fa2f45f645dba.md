# Related MIME children without reference headers need both output selection and payload forwarding

For a non-head related child, this change returns true when neither Content-Location nor Content-ID yields a location. The multipart caller assigns that result to output_p and starts the child parser. The related line handler must also forward an output child to the superclass; otherwise its payload branch returns 0 without parsing that content. This is a bounded no-reference-header case. It does not establish that every unused CID, related attachment, draft or rewrite case is covered. Static source support; the required Bug discussion remains explicitly partial.

Scope: libmime multipart/related attachment output.
