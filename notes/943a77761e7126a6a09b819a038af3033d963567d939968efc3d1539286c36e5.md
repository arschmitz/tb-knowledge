# Attendee row matching lowercases both lookup keys while retaining the existing attendee

When an edited attendee address differs only in case, the dialog lowercases both parsed mailbox keys and the existing attendee email lookup. A match retains the current attendee object, updates its common name and removes that map entry before creating extra rows. This preserves role and participation state on that path; the test checks one attendee with DECLINED and CHAIR. New rows use lowercased map keys, while organizer comparison had a separate later change. This is a local dialog contract, not a global email-normalization rule or a fresh UI result.

Scope: Calendar attendee editing.
