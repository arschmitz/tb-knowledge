# Resolve and validate a space URL at the native conversion boundary

getNativeTabProperties resolves relative URLs against the extension base and rejects a missing URL or a protocol outside http, https and moz-extension. It also supplies the extension principal and browsing-context group. The schema permits an optional url inside the object, so runtime conversion still needs its explicit missing-URL error. This is this spaces API boundary, not an allowlist for all Thunderbird tabs. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension spaces URL and principal boundary.
