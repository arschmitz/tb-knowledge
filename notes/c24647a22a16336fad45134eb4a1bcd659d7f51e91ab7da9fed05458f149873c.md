# Chat MessagesDisplayed can announce a partial insertion batch

displayPendingMessages dispatches MessagesDisplayed both after a partial idle slice and after completing insertion. In the partial branch it schedules another idle callback; in the terminal branch it clears pending flags before dispatch. The log-search listener retries while a failed search still has pending messages, then removes itself. Consumers must use that state when they need completion rather than treating the event name as completion. This custom-element event is separate from the WebExtension event of the same words. No rendering test ran.

Scope: chat-message-display.
