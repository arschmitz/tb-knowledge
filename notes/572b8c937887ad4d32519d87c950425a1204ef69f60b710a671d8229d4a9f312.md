# Reset and release newly introduced per-message header state

763 initializes m_messageId but its historical destructor and BuildHeaders setup do not release or reset the new member. The header-building helper appends to an existing non-null header, so retained state can affect the next queued message. Accepted source now frees the member at destruction and resets it before parsing headers. Its later test sends the same header-bearing fixture twice to guard against doubled IDs. These later safeguards are current-source comparisons; their later landing is not counted fully studied. Ownership of the separate generated local buffer remains an unresolved static question rather than a proved leak.

Scope: Delayed-send state lifetime.
