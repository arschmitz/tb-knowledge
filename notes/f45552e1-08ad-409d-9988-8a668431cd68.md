# Preserve text selection while console output polls

For the Commands live console, polling must leave selected output stable so the user can copy it. The recorded implementation reuses unchanged child nodes, appends changed text, and scrolls only when content changed, the user was following the latest output, and no selection intersects it. New client modules must be registered in `GRAPH_CLIENT_SCRIPTS`. Targeted browser and graph tests passed; this claim is scoped to that polling UI.

Scope: console live output.
