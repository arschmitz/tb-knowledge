# Cloned Account Hub options need separate propagation for later source-option mutations

The initial widget clones slotted options into its native select and rebuilds them on slotchange. Existing form code changes source OAuth option visibility later; cloning alone does not keep the copies synchronized. Fixed accepted code adds assigned-node mutation observation and selection caching/reconciliation as later mechanisms. Keep the initial clone contract separate from those later changes, without inferring their exact repair chronology or a reproduced popup failure.

Scope: Account Hub select option ownership.
