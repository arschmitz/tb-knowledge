# Local-only S/MIME verification is scoped to the users configured certificate

VerifyEmailUsageLocalOnly passes FLAG_LOCAL_ONLY and explains that skipping OCSP is valid because callers use the user’s own configured certificate on the main thread. Compose looks up its per-identity signing/encryption certificates and uses that helper. VerifySelfCert clears an unusable certificate and records its reason while returning NS_OK unless reading its bytes fails. Scoped manual recommendation: document that trust and thread boundary whenever reusing this helper; it is not a general shortcut for received certificates. This is static source inspection. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: S/MIME self-certificate boundary.
