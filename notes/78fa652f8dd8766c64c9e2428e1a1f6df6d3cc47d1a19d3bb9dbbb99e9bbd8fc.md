# Global card lookup normalization and directory priority are distinct contracts

Accepted manager lookup trims and lowercases an email key, builds the map from reverse directory/card iteration so normal-order entries win, and tolerates a directory throwing during enumeration. A missing map entry returns undefined from the JavaScript Map; do not infer a strict null result for every direct JavaScript call merely from the interface documentation.
