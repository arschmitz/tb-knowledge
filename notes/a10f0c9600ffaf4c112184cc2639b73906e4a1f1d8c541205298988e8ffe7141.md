# Pass the selected default-folder flag rather than the requested mask

SetFlagsOnDefaultMailboxes tests a requested mask against each named default folder. The historical landing passed that whole mask to each existing folder; the local-account caller can pass composite SpecialUse. The later fixed method passes the selected folderFlag instead. The Bug records a followup for the all-flags mistake after the original review’s separate spurious-return fix. Keep mask selection and the per-folder operation distinct. This is a checked historical/current source difference, not a current defect or runtime reproduction.

Scope: Local default-folder flag selection.
