# Use the revised two-stage compaction completion contract

The February 2025 callback contract lets onCompactionComplete return an error before the new mbox is installed, so the lower layer can roll back. Do database commit work there. Use onFinalSummary for final status, byte savings, notifications, and UI updates; its return error is ignored. This replaces the May 2024 completion rule.

Scope: message store compaction.
