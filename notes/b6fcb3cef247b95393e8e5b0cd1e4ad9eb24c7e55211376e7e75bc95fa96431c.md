# Default alarm offset normalizes preference units before its two callers use it

getDefaultOffset accepts the listed duration units, substitutes minutes for an invalid unit, normalizes the length and makes the offset negative. Existing setDefaultValues still separately checks whether default alarms are enabled and creates an alarm; the new form only reads the offset for its selection. Reading an offset does not create or enable an alarm. No duration or alarm test ran.

Scope: Calendar default alarm duration.
