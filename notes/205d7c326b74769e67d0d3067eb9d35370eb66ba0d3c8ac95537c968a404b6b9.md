# Set remote content-tab state before panel insertion

At revision 0809d25f7537a299e02fd7d81b8754c2edc82620, the content-tab creation path sets remote="true" before inserting the clone into the tab panel when skipLoad is true and openWindowInfo.isRemote is true. The source comment says earlier insertion creates a docShell that later triggers MOZ_ASSERT, citing Bugs 1770105 and 1843741. Preserve this order when changing this creation path. This is a scoped source contract and recorded rationale, not a general rule for every browser element. The supplied evidence includes no runtime reproduction or test result.

Scope: Content-tab browser creation.
