# ANGLE package names use the platform suffix in two gated manifest sections

The artifact branch keeps vcruntime/msvcp globs inside XP_WIN while listing EGL/GLES for XP_WIN or XP_MACOSX. Both these entries and the separate MOZ_ANGLE_RENDERER entries use DLL_SUFFIX instead of literal .dll. The fixed manifest retains this declaration. No suffix-generation, artifact-content, installer or native rendering check was executed.

Scope: Thunderbird installer manifest.
