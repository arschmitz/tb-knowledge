# Check the selected excerpt before closing a retrieval gap

The current implementation draft distinguishes finding a parent record from
returning the source excerpt that the question needs. A parent ID alone does not
pass the query-gap retrieval check. The checked excerpt must fit in the selected
context, and the returned records must match the repository and explicit scope.

An automatic resolution covers evidence retrieval only. It does not certify the
meaning of a generated answer. Answer generation receives the question and
returned context without the expected facts or review scores. Semantic review
binds to the exact saved answer. Evaluation data remains outside learned evidence.
