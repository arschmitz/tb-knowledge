# NNTP response dispatch does not await the moved authentication actions

The moved authentication actions are async, but the response dispatcher invokes _nextAction inside a synchronous try/catch without await. A later rejection from credential search, localization or removal is not caught by that synchronous catch. The new-password branch also starts its retry without awaiting it. This is an exact source-level completion boundary, with no observed connection failure or runtime result.

Scope: NNTP asynchronous action completion.
