# Exchange switching preserves EWS auth without inheriting Graph's forced OAuth choice

The Exchange-type component remembers the last EWS authentication choice before Graph forces OAuth2, then restores that EWS value on return. An EWS config without a recognized method starts with the empty placeholder instead of inheriting Graph's OAuth2 choice. Tests directly check the NTLM roundtrip, empty placeholder/Fluent ID and custom tenant/client values across switching. These programmatic state checks do not prove native authentication or account creation.

Scope: Account Hub Exchange type state preservation.
