# Named alert initialization keeps caller-specific notification options explicit

The alert initialization migration names each supplied option instead of relying on positional init arguments. Connection failures retain a name and silent flag; certificate activity retains requireInteraction; new-message alerts retain their title, body and clickability. The original patch also passes identity cookies where used. Later accepted callback changes remove some cookies and adjust clickability, so those phases remain separate. The checked call sites do not establish unread upstream defaults or native notification behavior.

Scope: notifications/initialization.
