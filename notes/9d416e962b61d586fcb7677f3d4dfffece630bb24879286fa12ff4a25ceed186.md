# Create Save requires registered field helpers

The Bug 2061214 implementation and verification reports say Create Save stays unavailable until the required title and date helpers register. Those controls belong to linked bugs; this patch supplies validation and conversion hooks. When integrating those controls, preserve the missing-helper guard so an incomplete draft cannot start a transaction. This is reported behavior for the reviewed commit 15a5b7c23c0aa132c4e78e4d7c336c09d9c215af, not a general rule for all calendar dialogs. The later verification did not complete matching runtime tests.

Scope: Calendar event create Save.
