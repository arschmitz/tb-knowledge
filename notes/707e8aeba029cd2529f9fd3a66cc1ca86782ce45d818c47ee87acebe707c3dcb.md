# The QR data-URI regex is a format check, not an image decoder

The accepted QR tests use DATA_URI_REGEXP to check the BMP data-URI envelope and also compare generated data against snapshots. That regular expression does not validate decoded bitmap structure or prove that a mobile device can scan the code. When reviewing this test family, keep those validation claims separate and use an actual decode or scan test for that stronger claim. This is a scoped recommendation based on the test source; neither decoding nor the tests were run here. Full bug and review discussion remains pending.

Scope: Mobile QR tests.
