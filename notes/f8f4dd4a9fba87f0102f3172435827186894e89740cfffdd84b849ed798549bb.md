# Check object-map assertions use entries rather than characters of property names

The browser attribute test still uses for (const [key, value] in observedProperties). A standalone ECMAScript experiment shows that it destructures the property-name strings into characters, such as C and T for CTA. It does not iterate CTA and cta. Production correctly uses Object.entries(attributes). Proposed scoped rule: for key/value map assertions, iterate Object.entries and verify the actual full field names. This experiment does not prove whether the Thunderbird Assert helper reports failure; the intended attribute coverage is not established by this loop.

Scope: mail/components/inappnotifications.
