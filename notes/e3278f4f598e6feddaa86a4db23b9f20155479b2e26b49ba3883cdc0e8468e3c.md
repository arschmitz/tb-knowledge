# The Calendar event test helper constructs attendees from descriptors

The added callers supply plain objects with attendee properties. createEvent creates a CalAttendee for each object and copies Object.entries into it before adding it to the event. The changed calIAttendee[] JSDoc describes the constructed objects more narrowly than the actual descriptor input, so a descriptor type or property shape would document this helper more accurately. This is a scoped test-fixture contract; it does not change production attendee interfaces.

Scope: Calendar browser-test fixture input typing.
