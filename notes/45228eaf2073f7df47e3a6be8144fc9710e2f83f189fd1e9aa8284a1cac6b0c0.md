# Midnight test edge-cell messages should name the cell actually checked

The changed assertions inspect dayBoxes[0] for relation past and dayBoxes[6] for relation future, under conditions based on expected.weekday. Their messages interpolate expected.weekday, which is the weekday of today rather than the index of the checked edge cell. A failure can therefore name today’s number while checking Sunday or Saturday. Scoped review recommendation for this Sunday-first test: use a message such as “The Sunday cell should be in the past” or “The Saturday cell should be in the future.” The zero-today-box assertion already names the expected visibility. This diagnostic finding does not change the test or establish a rendered result.

Scope: calendar/tests.
