# Keep the initial programmatic CSP rollout distinct from tested window policies

The first security-policy rollout says its tags were added programmatically and not all windows were checked. The next landing selects policies according to tested window needs and changes fixture reads and icons. Later same-batch fixes remove accountSetup policy and allow required data images. Keep those stages and their stated limits in the history lesson; the repeated original policy string is not a project-wide template or proof that all windows worked. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Chrome window CSP rollout scope.
