# Sync fieldset headings need an actual grouping-name check

The accepted sync template places visible localized spans inside two fieldsets but has no legend or explicit aria-labelledby on those fieldsets. This source alone does not establish a programmatic group name. Recommend checking the accessibility tree and keyboard navigation for the address-book and calendar groups, then associating the visible title if needed. The nested checkbox labels remain a separate relationship. This is a scoped accessibility review proposal, not a confirmed screen-reader failure. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Account Hub sync grouping accessibility.
