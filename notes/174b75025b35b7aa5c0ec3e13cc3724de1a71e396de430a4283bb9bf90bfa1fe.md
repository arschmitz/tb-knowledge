# Treat mbox write logs as diagnostic evidence rather than a corruption fix

Entry 374 adds START/START-Q/FINISH/DISCARD log records with stream identity, folder and byte position or size. The historical fresh-file-size helper clones nsIFile to avoid cached file statistics. Bug 1890230 collected reports of correct message lists with wrong bodies and later separated stale database offsets from missing mbox data. The logging landing itself does not repair those paths. Record version, folder, original mbox and original index when interpreting a corruption report; copying or repairing first can alter the evidence. Later bug diagnoses and fixes were read as context, not fully rescanned or independently reproduced.

Scope: Mbox diagnostics and corruption study.
