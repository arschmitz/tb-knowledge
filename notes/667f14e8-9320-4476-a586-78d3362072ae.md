# CalDAV sessions and redirects enforce distinct token, password and header boundaries

Reuse [the checked OAuth sentinel lesson](5d98bbb45320c724c63dadeef0f01433cec2060ec7583ca81392777a8e7b53e0.md).
CalDavSession:56–90 first checks saved logins at the channel origin. A matching
username stores _oAuth=null. Otherwise OAuth initializes once from host/username
and stores exact prePath as _oAuthOrigin. It awaits token callback completion and
sets Bearer Authorization only for that origin. A cached decision is not re-created
when a later request changes host. This is a per-instance session; the checked
calendar ID setter:130–140 creates it from username or calendar ID.

DetectionSession:96–196 owns the input password, save flag and passwordSites Set.
toBaseSession creates a new username-only session. It does not transfer password,
site Set or OAuth state. promptAuth uses the actual
cal.provider.detection.isPasswordSite receiver, not an arbitrary matching helper.
calProviderDetectionUtils:66–96 rejects non-HTTP URIs, gets the effective site
through Services.eTLD.getSite and allows HTTPS for an HTTP-authorized site, but
does not allow HTTP for an HTTPS-authorized site. Detection provider:69–72 adds
the initial site; dnsSRV:196–202 adds the DNS-selected site. Complete native
effective-site rules and DNS trust behavior are separate source scopes.

promptAuth:166–195 supplies credentials only with a password, allowed site and
no PREVIOUS_FAILED flag. It optionally saves them; failure clears authInfo fields
and removes saved entry when enabled. asyncPromptAuth:153–161 schedules a timer
and calls onAuthAvailable or onAuthCancelled. It returns no cancel handle here.
No automatic release of the input password or timer cancellation was established.

RequestBase.asyncOnChannelRedirect:175–246 reuses/rewinds upload through
prepHttpChannel, retains method and selected DAV headers, and records old status.
It copies Authorization only for equal prePath. If Authorization exists and the
origin changes, it aborts redirect through verification callback. This callback
does not call session.prepareRequest again. Password site permission, OAuth
origin equality and redirect Authorization checks are distinct contracts.
prepHttpChannel:44–128 selects a per-username userContextId, or a fresh detection
container, then sets callbacks, bypass-cache flags and upload stream.

Direct session tests:80–114 check token on same-origin paths and absence on another
host/scheme;116–141 check permitted subdomains/port and HTTPS upgrade, denied
TLS downgrade and unrelated site. Redirect test592–637 checks copied DAV headers
and 302 status on same-origin redirect, not cross-origin Authorization rejection.
Requests and session runtime files failed in login-store initialization in the
installed build; no security behavior pass is inferred from those attempts.
