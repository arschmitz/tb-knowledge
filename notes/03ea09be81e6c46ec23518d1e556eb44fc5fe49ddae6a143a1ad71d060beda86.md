# Document the promise returned by an async tab helper

The accepted openTabs helper is async but its inspected return documentation says TestTab[]. A scoped manual documentation recommendation is to state Promise<TestTab[]> while keeping the eventual array element type. The 1569/1570 cleanup changed documentation without changing this contract; passing JSDoc lint alone is not evidence that the asynchronous return description is accurate.
