# Check message-header UI as well as extension data after a combined update

The browser regression test selects a message and alternates junk and tag combinations. After each awaited update it checks browser.messages.get and the rendered tag text from expandedtagsBox. Keep both surfaces in tests for this reload-sensitive update path. A correct API tag array alone does not prove that the displayed header refreshed. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Message update visible header assertions.
