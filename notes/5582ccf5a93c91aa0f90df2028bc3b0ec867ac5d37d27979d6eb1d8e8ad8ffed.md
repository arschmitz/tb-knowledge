# Sync preference packaging, markup, registration and tests share the build capability gate

The inspected Sync change uses MOZ_SERVICES_SYNC for the service build directory, packaged preference script and compiled pane category. Runtime preference registration checks AppConstants.MOZ_SERVICES_SYNC, while the browser manifest skips when !sync. Configure supplies both the option and preprocessor define from the same enable_sync result, currently False. A channel name alone does not describe these included artifacts. This is the checked cross-layer contract, not proof that toggling one file yields a working build or that servers are available. No build, UI or sync test ran.

Scope: Sync feature exposure across build and UI layers.
