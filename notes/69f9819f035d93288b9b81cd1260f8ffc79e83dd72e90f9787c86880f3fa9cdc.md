# Related child replay closes the head decomposition stream before each attachment cycle

In decompose mode, non-head related parts are buffered and replayed only if their objects remain visible attachments. The head stream closes before child init/read/close cycles. The draft writer uses a nesting counter: a nested init reuses the current attachment, and only the outermost close finalizes its stream. Normal ordering is supported by source; error returns and injected cleanup failures are not covered by the added test.

Scope: MIME related-part draft decomposition.
