# Scope task-tree click suppression

In the recorded BCT2 `browser_taskView.js` test, a synthetic double-click targeted virtual `treechildren` used to implement the tree, rather than a user-facing accessible row. The recorded decision scoped accessibility click-check suppression to that preparatory test action and reset it afterward. This does not justify suppressing checks for real task controls, which still need accessible behavior. The record says tests were not rerun after a later comment-only cleanup.
