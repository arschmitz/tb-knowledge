# ensureLocalStore creates only a missing path and propagates storage errors

Both implementations check the folder path and create only when it is absent. mbox creates a regular file at 0600; maildir delegates to CreateMaildir and checks its nsresult. The existing-path branch does not validate the path type or restore absent maildir children. This bounds what the method promises; no live repair or native I/O test ran.

Scope: Folder repair native storage.
