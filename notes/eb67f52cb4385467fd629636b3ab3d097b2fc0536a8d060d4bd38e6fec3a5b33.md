# Use logical dimensions and offsets for the notification layout

The accepted notification layout uses inline-size, padding-inline and logical close-button offsets, and mirrors the decorative icon for RTL. Its description is bounded in lh units and scrolls when longer. Follow these local patterns for direction-aware positioning and text-sized bounds. The source alone does not prove correct wrapping, scrolling, RTL, zoom or keyboard reachability.

Scope: Notification layout syntax.
