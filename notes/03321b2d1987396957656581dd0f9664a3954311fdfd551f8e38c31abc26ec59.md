# Convert restored XUL dimensions into the layout style that reads them

The XUL store still restored width and height attributes, but layout no longer honored those attributes. Calendar startup copies the listed persisted values into inline pixel styles after preparing the unifinder and before calendar-startup-done. Missing elements are skipped. This repairs the link from persisted state to actual layout; changing persistence alone would not help. The same landing removed CSS appearance and minimum-height rules, but that late cleanup caused trouble and was undone in entry 468, owned by the next batch. Do not recommend that CSS removal. Restart, splitter resizing, focus and zoom were not exercised here.

Scope: Calendar persistence and layout.
