# Normalize the sidebar document URL before saving tree state

The contacts sidebar document may load with a query string such as ?focus. It removes that query before using xulStore so the same column and sort settings apply across ways of opening the sidebar. The Address Book column also has special state: it is available for All Address Books, hidden in one book, and has a stored user choice when available. D208449 review raised a seeming default-visibility error that the author traced to the selected directory. Current code keeps this context-aware handling.

Scope: Address Book persistence.
