# Keep generated Rust paths in the mozpath family

The 736 landing also changes Rust synchronization path construction to mozpath, despite its compactor-only title. Current CargoFile uses mozpath.dirname/abspath/join, and generated dependency and patch paths use mozpath.relpath. The generator still uses os.path.isfile and os.path.exists for existence checks. Preserve this scoped distinction rather than converting every os.path call mechanically. Later 742/743/766 split the compactor and path changes; the sibling owns the full reland proof.

Scope: python/rocbuild/rocbuild.
