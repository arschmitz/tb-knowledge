# RSS composition reads the handler-owned summary state

The RSS compose helper reads FeedMessageHandler.gShowSummary after the cleanup removes its duplicate global state. It also checks whether a non-folder message view is forced to show the webpage by onOpenPref, so the handler field alone does not determine every window’s compose branch. The webpage branch tries Content-Base as a link and falls back to summary composition when that header is unavailable or setup throws. Keep the actual state owner and the separate window/open-mode condition when changing reply or forward behavior. Existing display-mode tests do not directly assert this compose output; no compose or browser test ran.

Scope: Feed display state and RSS compose content.
