# Recent-destination preferences invalidate generated menus before the next build

The initialized folder menu observes mail.folder_widget preferences through its listener object. A change calls teardown, removes generated content and the observer, then clears initialization state. A later initialization builds from the new preferences; observe does not immediately repopulate rows. The added General-pane test asserts preference updates, not the regenerated submenu, so it does not directly test this cache lifecycle. This is a scoped static contract, not a runtime menu result.

Scope: Folder-menu preference observers and cache lifetime.
