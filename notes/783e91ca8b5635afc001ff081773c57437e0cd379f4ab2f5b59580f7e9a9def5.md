# The original Graph page-size patch leaves the saved-token request unconfigured

The original initial and NextLink branches set the requested maximum, but the saved-token branch sends a newly converted GetDelta without its setter. GetDelta starts with None, so its conditional builder does not add this Prefer header. Accepted source explicitly sets the maximum in that branch, and later tests include a saved-token case. Keep these source phases separate; no live header trace or server failure was executed.

Scope: Graph delta sync maximum phases.
