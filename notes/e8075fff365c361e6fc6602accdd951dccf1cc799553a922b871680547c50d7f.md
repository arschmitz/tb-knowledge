# Address-book menu Fluent IDs use explicit service names matched by markup

The initial landing uses file-new-local-addressbook, file-new-carddav-addressbook and file-new-ldap-addressbook in both Fluent and menu markup. Current accepted source retains those exact names. The full addressbook suffix makes this local family easier to find than an ab suffix; this is an accepted scoped naming choice, not a global abbreviation ban or permission to rename existing public DOM/Fluent IDs. Keep label/accesskey attributes and dispatch targets separate from identifier spelling. The intervening backout restores the original files; later adoption does not make the first landing pass. No localization, access-key or menu test ran.

Scope: File New Address Book localization naming.
