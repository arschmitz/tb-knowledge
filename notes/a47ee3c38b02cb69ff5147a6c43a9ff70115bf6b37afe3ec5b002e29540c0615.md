# Remove a retired feature gate from both behavior and markup

563 makes settings search generally available by removing the browser.preferences.search preference gate and the initial hidden attribute. Current initialization still respects the element hidden state and registers the input listener and idle category initialization when visible. The current input is type=search. When retiring a gate, inspect the markup default and the setup path together. This source change did not add or run a search regression test.

Scope: Preferences search availability.
