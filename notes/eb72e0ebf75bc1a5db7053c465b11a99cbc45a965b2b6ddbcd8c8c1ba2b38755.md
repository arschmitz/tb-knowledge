# Fake IMAP nested-folder tests use onlineName for mailbox lookup

The cross-server folder test changes fake IMAP message insertion to query the mailbox with folder.onlineName after obtaining nsIMsgImapMailFolder. The new message-query helper uses the same full online name. A leaf folder.name does not carry the parent mailbox path for nested test folders. Fixed accepted source keeps that object-folder path and separately supports string mailbox names. getMessagesInFolder exposes the live _messages array, while addMessages waits a client update only for an object folder when requested. This is scoped fake-server behavior, not a production-folder naming rule or test-run result.

Scope: IMAP test server nested folders.
