# Prefer the current shared experimental badge over the historical custom label style

Entry 908 adds a bespoke label-experiment badge and accompanying CSS. The accepted General preference uses the shared badge experimental classes with role=presentation, while the row aligns the badge with the label. Use the current shared presentation pattern for this settings surface rather than copying the removed badge rule. Its visual contrast, localization fit and accessibility tree were not checked live.
