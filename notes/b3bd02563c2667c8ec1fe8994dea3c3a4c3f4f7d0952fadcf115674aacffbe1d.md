# Name EWS Create callbacks for the remote operation

D229190 changes saveMessage to createMessage and names IEWSMessageCreateCallbacks for creating a message on the server. Review found Save ambiguous with saving to disk. The applied overview identifies the EWS client owner/remote role and the consumer callbacks, while explicitly retaining database coupling as an architectural constraint for future work. The historical listener still expects a temporary file; future streaming/generalization is not implemented by its name alone. No remote creation or callback test ran.

Scope: EWS callback naming and documentation.
