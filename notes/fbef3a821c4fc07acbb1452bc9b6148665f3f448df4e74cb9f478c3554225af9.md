# The first multi-account badge fix set its discovery flag before store discovery succeeded

The original fix marks each base folder discovered before obtaining the store or listing child names, then adds missing child objects before recursion. The test recreates two local accounts and asserts discovery plus an unread sum of8. It does not test other protocols or a native dock badge. The fixed accepted base method no longer has that block, and the original test path is absent; the first fix and later replacement must stay separate.

Scope: Historical base-folder discovery for unread counts.
