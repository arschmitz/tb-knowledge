# Standalone message-window appmenu cleanup removes its resources and lifecycle together

This cleanup removes the standalone message window's appmenu stylesheet, localization bundle, panel script/include and related conditional Sync script. It also removes PanelUI startup/cleanup, extension-alert startup and appmenu-only menu-hiding lookups. The ordinary menubar, browser popup and toolbar-context path remain, including its labelled toolbar customization item. Scope the removal to this window and these resources; it does not remove the main window's appmenu or establish that all customization or extension alerts are gone.

Scope: standalone message window appmenu integration.
