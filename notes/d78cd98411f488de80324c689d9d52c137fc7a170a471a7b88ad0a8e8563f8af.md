# Normalize serialized Cargo paths and keep LF newlines

Entry766 restores path normalization separately from the mixed736 landing and adds more generated manifest inputs and output paths. The generator normalizes dependency and patch paths, writes relative Cargo paths through mozpath.relpath, and explicitly uses newline="\n" for the generated file. The already-published mozpath-family lesson covers the alias and retained filesystem checks. Additional scoped rule: normalize every path that crosses this serialization boundary and keep the declared LF output contract. This is source evidence for Windows portability, not a Windows generator or Cargo build result.

Scope: Generated Cargo path portability.
