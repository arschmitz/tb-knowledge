# Check whether a published repair is present

In this TB Tools repair case, a published repair was reported to have passed Try, but the current clean checkout still had both old #password selectors and did not contain the repair commit. A prior successful Try for another commit therefore did not make this checkout already fixed or ready for a matching-source Try.
