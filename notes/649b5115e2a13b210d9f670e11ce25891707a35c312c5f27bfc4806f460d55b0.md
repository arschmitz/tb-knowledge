# Clippy workspace settings are kept in both the generator and generated manifests

This patch selects thirteen named Clippy warnings, updates the generator template and checked-in workspace table, and adds explicit package inheritance. The sync path calls regeneration, whose writer uses the templates. The Graph model crate replaces its former two-warning local table with inheritance. These are concrete configuration requirements for these manifests, not activation of every pedantic lint or a rule for all Rust code. The list order was described as personal preference. Later Rust warning additions remain separate.

Scope: Thunderbird Rust workspace lint configuration.
