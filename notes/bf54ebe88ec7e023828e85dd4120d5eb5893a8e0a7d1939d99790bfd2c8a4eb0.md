# The custom issuer test checks tokenEndpoint with an authorization-endpoint message

The custom issuer test directly compares mod._oauth.tokenEndpoint with the token URL, but its message says Authorization endpoint should have been customized. The compared value and the diagnostic name differ. The surrounding current helper has a correctly named token-endpoint diagnostic, so a nonempty assertion message alone does not establish an accurate failure explanation. This is a bounded current test-source finding; the test was not run.

Scope: OAuth assertion diagnostics.
