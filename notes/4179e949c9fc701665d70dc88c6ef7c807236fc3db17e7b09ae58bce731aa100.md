# setAttendees returns before attendee summary localization finishes

setAttendees updates row visibility synchronously but does not await or return #setSummary. That helper awaits formatValues and writes textContent afterward. Callers that need finished summary text cannot treat the setter's return as completion; the existing test waits for the expected text. The checked helper has no request-generation guard or rejection handler, while the dialog can populate and clear the same rows. This is a source-level completion boundary and a conditional overlapping-request concern, not a reproduced stale result. Later list-render cancellation does not itself guard summary localization. Native localization scheduling and rejection behavior were not executed or independently paired.

Scope: New Calendar dialog asynchronous summary contract.
