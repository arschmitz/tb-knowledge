# The Exchange server rename keeps the EWS persistence group and URL key

The renamed ExchangeIncomingServer serves both ews and graph component contracts. Its exchangeUrl property still reads and writes the stored ews_url key. AccountManager uses the prefix before the first dot to select an interface group and the suffix as the property slot. Thus the hidden ews.exchangeUrl ID keeps the ews group while selecting the renamed property. The advanced exchangeUrl control and its label references change together. These exact bindings do not establish a profile migration or compiled ABI result.

Scope: Exchange incoming-server rename and account settings bindings.
