# Thunderbird selects the crash-ping YAML separately from crash metrics

In mail/moz.configure, the crash-ping port replaces toolkit/components/crashes/pings.yaml with toolkit/crashreporter/crashping/pings.yaml inside MOZ_GLEAN_INTERESTING_METRICS_FILES. The separate crashes/metrics.yaml entry remains. The fixed accepted source retains that split. These are configured input paths; the source does not prove a crash was submitted or validate the upstream schema.

Scope: build/Glean configuration.
