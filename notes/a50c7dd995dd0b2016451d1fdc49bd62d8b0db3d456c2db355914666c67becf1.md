# Windows 25H2 task labels and stored task IDs have separate roles

The port renames eight Windows test-platform families and replaces the worker-alias pattern with win11-64-25h2. It also removes two ccov child worker overrides. Seven existing_tasks fixtures change only 24h2 label bytes to 25h2 and retain their task IDs. The comm loader turns configured platform names into test descriptions before imported transforms run. Keep this checked configuration change separate from worker-image availability, graph results and successful Windows execution; those were not tested.

Scope: Taskcluster Windows test configuration.
