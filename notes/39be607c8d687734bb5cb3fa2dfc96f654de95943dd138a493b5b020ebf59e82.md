# The form-picker helper uses the returned panel and its current frame ID

After waitForDateTimePickerPanelShown resolves, checkABrowser queries DateTimePickerPanelPopupFrame on that returned panel, clicks a day cell in its document and waits for the panel to hide. It then directly checks that the content date input has a value; it does not assert a particular day. The one-line historical fix updates the internal frame ID. The older 250 ms workaround and unrelated HTML color-picker preference remain separate. Upstream engine bodies and a live picker run were not verified.

Scope: Browser date-picker test harness.
