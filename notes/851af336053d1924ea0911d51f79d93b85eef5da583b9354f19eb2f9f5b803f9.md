# Calendar alerts keep their item in a per-alert callback

The cookie-removal landing moves Calendar item identity from a shared ID map to a new observer closure for each alert. The fixed accepted caller keeps the item in an onAlertClick callback and opens that item’s event dialog. Mail independently keeps a generated message URI in alert.name and captures the header for clicks/actions. Match the actual callback API and consumer when reusing this pattern: accepted code now uses showAlertWithCallbacks, while this historical patch used observer topics. The browser task simulates a click; no native delivery, lifetime or multi-alert guarantee was tested.

Scope: Calendar alert identity and click ownership.
