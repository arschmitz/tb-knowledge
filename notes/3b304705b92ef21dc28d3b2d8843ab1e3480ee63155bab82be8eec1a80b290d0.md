# An incoming server remains shut down even when connection cleanup fails

Entry 1284 initializes m_hasShutDown to false and sets it after CloseCachedConnections before returning a failed result. The accepted queued-URL loader checks that flag before the offline check and refuses more work. Preserve this terminal state separately from ordinary offline status. It is a scoped shutdown contract, not a retry policy for every network error. The source order was read; no shutdown race, thread or connection test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: IMAP incoming-server shutdown.
