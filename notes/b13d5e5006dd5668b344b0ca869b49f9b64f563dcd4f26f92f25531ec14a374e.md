# Select the updater panel before moving keyboard focus

Current selectPanel assigns updateDeck.selectedPanel before finding/focusing the new button. The code explicitly documents this order. Focus must target a visible active panel, and a decorative icon state change is insufficient to establish that active panel. No keyboard interaction test was run.
