# Graph code generation keeps a supplied schema name beside its Rust identifier

CustomRustType stores the supplied original name and its PascalCase form for separate import/filter and Rust-identifier consumers. The borrowed base_str result uses the stored form rather than a temporary conversion. The supplied name can already be shortened by ref_simple_name; it is not necessarily the full OpenAPI reference. Current SchemaName keeps that distinction and adds a snake-case module form used by imports. The owned extra import branch only handles direct references, so it does not prove all compound custom-type imports work. This is a scoped generator contract, not a rule for unrelated Rust names.

Scope: Graph generator schema-name ownership and imports.
