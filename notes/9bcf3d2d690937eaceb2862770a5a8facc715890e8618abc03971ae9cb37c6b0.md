# Let decorative identity descriptions pass pointer events to the picker

The identity picker scopes pointer-events:none to its .menu-description and ::part(description). The secondary description had captured clicks instead of letting the editable menulist select the identity. Keep the rule under #msgIdentity and preserve the description text. This is a targeted hit-testing fix, not a rule to disable pointer events on controls or meaningful interactive text. The .menu-description class uses the local lower-case dash-separated spelling. Keyboard selection and accessible name/description relationships were not tested here.

Scope: Identity picker hit testing and CSS scope.
