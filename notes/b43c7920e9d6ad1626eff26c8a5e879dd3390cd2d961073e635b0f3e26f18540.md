# The yEnc resize branch conflicted with its initialized buffer size

The old resize condition required a declared line size greater than the existing 1000-byte buffer and at most 997. Under the normal initialized state, those conditions cannot both hold. The patch removes that dead branch and uses a fixed 1002-byte allocation while retaining header parsing. This bounded source fact is separate from the withdrawn simulation-based quoted-printable claim and does not establish a reproduced vulnerability or general decoder safety.

Scope: MIME yEnc buffer accounting.
