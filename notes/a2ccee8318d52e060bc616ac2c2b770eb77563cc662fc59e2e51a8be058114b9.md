# Autocomplete tests should assert both completion value and decorated label

The changed tests retain plain-address getValueAt assertions and add label checks with the address-book name when commentColumn is enabled. The no-context quick check expects identical value and label. Proposed local test coverage: check both API outputs across no-context, contextual and previous-result paths; testing only the popup label could miss an inserted-address regression. These unit tests do not establish spoken output or live popup rendering. This is static source and test-code inspection. No runtime, build, lint or live accessibility check ran. Full Bugzilla and historical review timeline and inline discussion remain pending; source landing does not prove approval of a proposed manual rule.

Scope: autocomplete test assertions.
