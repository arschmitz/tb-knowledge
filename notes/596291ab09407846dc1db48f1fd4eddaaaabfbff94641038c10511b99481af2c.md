# MIME draft decomposition remains a runtime choice after MIME_DRAFTS removal

Removing the MIME_DRAFTS definition and its ifdefs keeps draft support in the compiled source. MimeDisplayOptions still starts with decompose_file_p false and null callback pointers. Draft setup enables that flag and supplies the callbacks. Related-part code keeps its runtime display/decomposition conditions, and its decoded-output branch restores decoder_data after the callback. The removed preprocessor switch does not make every display a draft operation, remove ENABLE_SMIME guards or prove a build or message-processing result.

Scope: MIME draft decomposition hooks.
