# Keep omitted, null, and empty FCC folder IDs distinct

Manifest V3 ComposeDetails uses omit-key-if-missing for optional FCC folder IDs. In setComposeDetails, an omitted overrideDefaultFccFolderId leaves the current choice unchanged; null clears the per-message override and returns to identity defaults; an empty string sets nocopy:// to suppress a sent copy; a valid ID selects a folder. additionalFccFolderId similarly leaves state unchanged when omitted and clears it for null or empty string. getComposeDetails omits unset keys. The new browser test exercises the no-op, set, disable, clear, and invalid-folder cases. Preserve strict null checks here because treating null like undefined would change sent-copy behavior.

Scope: WebExtension compose API.
