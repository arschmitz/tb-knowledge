# The Graph event callback omits the generated time-zone field

The generated start/end object represents date_time and time_zone separately. The event-list operation extracts only date_time, and the callback interface forwards ID, title and two date-time strings. The JavaScript receiver parses them with UTC and explicitly documents that assumption; the accepted counterpart retains it. The generated time-zone field is therefore not evidence of provider time-zone support. No non-UTC, all-day, recurrence or live Graph scenario was run or claimed incorrect.

Scope: Graph calendar date-time conversion boundary.
