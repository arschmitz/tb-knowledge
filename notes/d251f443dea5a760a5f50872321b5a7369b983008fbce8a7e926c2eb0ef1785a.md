# Pane layout asks the page controller to perform message actions

The pane-layout component emits request-message-clear and request-message-selection when the message splitter collapses or expands. about3Pane connects those requests to messagePane and threadPane handlers. This lets layout own pane geometry while the page’s message controllers own the actual message action. For this component boundary, preserve those explicit request events instead of adding hidden controller calls into the widget. It is a scoped source pattern, not a rule for every custom element; message selection and keyboard behavior were not run. Full bug and review discussion remains pending.

Scope: Three-pane component boundary.
