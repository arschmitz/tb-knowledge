# Return an empty store token for a standalone file header

Current nsMsgFileHdr::GetStoreToken truncates the output and its setter returns NS_OK without persisting a token. A standalone .eml header is not a folder-backed local store position. The common interface does not guarantee that writing the attribute creates a local copy for every implementation. Keep backend/header implementation distinctions visible in callers and tests.

Scope: mailnews/local/src.
