# Keep unrelated OAuth refresh tokens when a new grant covers only part of the scope set

setRefreshToken updates existing logins only when the new granted scopes cover their stored scopes for the same origin and username. The focused test grants mail and calendar, keeps the separate address-book token and other origin, and checks the updated mail/calendar login. Preserve that subset relation when merging credentials; a successful authorization must not erase unrelated permission state.

Scope: mailnews/base/src.
