# Show the quick-filter text bar first

In the recorded BCT1 `browser_filterLogic.js` failure, the text filter bar was hidden while its filter value was null. Calling `set_filter_text("Hotel")` before `toggle_text_constraints("recipients", "subject")` made the target visible; the focused accessibility test then passed. Apply this ordering only where the current quick-filter helper and hidden-state behavior match. The record says removing a BCT2 command-controller change did not remove the old-order failure, so that change was not shown to cause it.

Scope: Quick Filter Bar browser test.

This is a workflow or historical planning observation.
