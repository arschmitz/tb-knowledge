# IMAP LANGUAGE uses a cached locale string and its existing one-request guard

The protocol constructor fills an nsCString accept-language member through LocaleService. Language keeps the existing one-request guard, truncates that member at a positive-position first comma, returns for an empty result and otherwise sends LANGUAGE with that value. The caller checks server capability. This does not establish malformed-list handling, live locale refresh, a retry after an empty value or server acceptance.

Scope: imap-locale-accept-language-command.
