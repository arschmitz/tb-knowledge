# S/MIME algorithm details share one localized collapsed disclosure

The S/MIME popup loader populates one HTML details/summary control for both signature and encryption algorithms. It shows each subgroup only when its algorithm strings are present, clears previous cipher localization attributes before replacing the value, hides an empty disclosure and resets open to false. The summary has its own Fluent text. This is presentation-source evidence, not a keyboard, screen-reader, native cryptographic or rendered-style result; the next header-reset change is separate.

Scope: S/MIME message security panel.
