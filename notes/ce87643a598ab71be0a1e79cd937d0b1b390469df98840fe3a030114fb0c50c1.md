# about:support visibility uses the same hidden state in markup and copied table headings

The support page starts reset, safe-mode and user.js sections hidden, then clears hidden only under the matching capability or snapshot condition. Its table serializer also reads a section's hidden flag before copying a title-column heading. The user.js formatter removes only no-copy, so other classes remain. This is the checked support-page contract; it does not enable Thunderbird's commented-out reset handler or establish a general hidden-node serializer rule.

Scope: about:support visibility and serialization.
