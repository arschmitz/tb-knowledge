# Accepted outgoing type lookup avoids constructing the protocol client

The historical extraction makes server_type call client() and then protocol_identifier. The fixed accepted method instead reads mail.smtpserver.<key>.type directly. Its comment explains that client creation may cache authentication data, which can request a password and then the server type again. Preserve that later dependency boundary rather than copying the historical client-backed getter. The stated risk is accepted source rationale; this study did not reproduce a recursion failure or audit the later fixing review.

Scope: Outgoing type and authentication initialization boundary.
