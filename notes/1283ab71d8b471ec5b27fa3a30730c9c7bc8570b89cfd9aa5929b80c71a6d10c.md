# A test-motivated URI-fixup setting entered packaged app defaults

The owned change adds browser.fixup.domainwhitelist.localhost=true to all-thunderbird.js with a comment about a test failure. That file is processed as an app preference file and installed under defaults/pref. The location therefore contributes an app default; the comment does not confine the setting to one test. The fixed accepted adjacent preference window no longer contains this insertion. These comm sources do not establish the current effective value or the engine URI-fixup result.

Scope: Thunderbird app preference packaging.
