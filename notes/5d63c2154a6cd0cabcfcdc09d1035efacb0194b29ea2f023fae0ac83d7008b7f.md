# Logical splitter CSS retains the physical resize API

The migration changes the grip dimension to block-size for vertical resize and inline-size for horizontal resize. The unchanged owned consumer still measures rectangle height or width by resizeDirection. Accepted JavaScript retains physical height/width property selection. The CSS spelling does not rename the widget API or stored dimension names. The selected splitter assertions measure physical rectangle size, but their fixture supplies its own CSS and does not load the production splitter stylesheet. They are written API checks, not a fresh result for this migration or proof of vertical writing-mode support.

Scope: mail-widgets.
