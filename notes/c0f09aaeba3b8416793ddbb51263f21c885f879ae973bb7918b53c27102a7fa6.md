# Use tabular numerals for the numeric message-list columns

Manual visual-style proposal: keep font-variant-numeric: tabular-nums on the received, date, size and ID column selector family. It aligns the width of digits without padding message data or replacing the values. The accepted folder-count badge uses it too. Scope the rule to numerical alignment in these UI surfaces; do not apply it to all text or infer a global column-class spelling rule from these legacy names. No font rendering or contrast test was run.

Scope: message-list.
