# Follow the declared startup interface instead of a stale Promise description

The 2024 DatabaseCore.startup returns a Promise after background folder loading. At the fixed accepted revision nsIDatabaseCore declares void startup and the C++ implementation returns nsresult synchronously. The IDL comment still describes a Promise, so it is not an accurate current signature. Proposed documentation rule for this interface: update return and readiness text with the declaration and caller; do not infer asynchronous readiness from an older comment. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.
