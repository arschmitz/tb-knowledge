# Search Messages puts id first in its migrated action buttons

The migrated Open, Delete, Open in Folder and Save as Search Folder buttons put id before data-l10n-id and command. Keep this accepted local order when working in that button group. It is a scoped markup convention, not a global attribute-order requirement or proof that whitespace lint passed. Unrelated controls and files keep their own local contracts.

Scope: Search Messages dialog markup.
