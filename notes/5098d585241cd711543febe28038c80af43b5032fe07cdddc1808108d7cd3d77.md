# Keep runtime diagnostic whitespace separate from source wrapping

The 1228 landing constructs geometry-wait diagnostics from short concatenated template-literal pieces. Variables interpolate and the final text stays on one line with the chosen spaces even though the source uses several lines. A multiline template literal would preserve its layout whitespace; a normal quoted string would leave ${...} uninterpreted. For similar messages in this test family, keep runtime output and source wrapping as separate checks. This supports readable concatenation, not a ban on code blank lines, a fixed line-length rule or replacing every existing string. Current row assertions separately use should and identify the property and row. No test ran; this record does not change deliberate user writing guidance.

Scope: Subscription browser-test diagnostics.
