# Rekey stored folder colors on a successful URI change with a path boundary

Current FolderTreeProperties follows folderRenamed and rekeys the old folder URI and descendants. A slash boundary avoids moving test1 while renaming test. Current browser_folderColorPersistence covers parent/child rename, refused rename, IMAP move by rename, old-key removal and shared-name-prefix sibling.
