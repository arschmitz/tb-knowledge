# OAuth scheme redirects require an issuer URI and the shell handler check

The custom-scheme request branch requires an issuer schemeRedirect URI, the global preference and a true shell capability result. The ordinary redirectionEndpoint stays separate, so Yahoo can keep its special net.thunderbird URI beside a loopback endpoint. Extension registration deletes schemeRedirect from supplied details before freezing the copy. The custom-scheme test stubs the capability to true; it does not validate OS ownership or a live provider login.

Scope: OAuth scheme redirect capability and issuer endpoints.
