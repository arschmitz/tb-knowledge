# Use role=status on the actual notification root

1111 fixes aria-role="status" to the semantic role="status" attribute on the outer notification root. Keep this role on the real owning root so its dynamic content can participate in the accessibility tree. The accepted root still has that attribute and the test starts an axe mutation watcher, but no screen-reader announcement or axe result was observed in this study. A source attribute alone does not prove the announced wording or timing.

Scope: In-app notification status root semantics.
