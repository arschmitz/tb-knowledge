# The Exchange remote-content test detects request attempts before image success

The HTTP fixture sets imageRequested when its path is requested and then returns404. The test checks both the remoteContent warning and !imageRequested after message load. A later image decoder or opaque-response failure cannot make an attempted request look blocked in this probe. This is the test mechanism, not a result from executing it or complete coverage of content-policy exceptions.

Scope: Exchange remote-content browser tests.
