# Keep dead key-details stubs separate from the working key-revocation action

1878 removes genRevocationCert, which threw "Not implemented" before a commented certificate-writing stub. 1888 removes the already commented manageUids block. Neither deleted block proves removal of a working user action. The accepted key manager still calls EnigRevokeKey; that function asks for confirmation, returns on cancel, awaits RNP.revokeKey and then reports success through its callback. Follow the surviving action when changing this dialog family; certificate export and UID management were not tested here. This is static source and test-code inspection at the fixed accepted revision. No runtime, build, lint or live accessibility check ran.
