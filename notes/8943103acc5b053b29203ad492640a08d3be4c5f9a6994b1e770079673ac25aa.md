# The Axe test integration registers a pinned npm bundle through test-module packaging

The manifest and package metadata both identify Axe4.12.1. The owned vendor script checks downloaded bytes against the SHA512 integrity value supplied by npm metadata and copies only its named regular archive members. Build configuration registers axe.min.js as a testing module, matching the helper's testing-common resource URL. Imported engine/license/documentation bodies stay outside this owned integration study, and no vendoring, build or external engine behavior was verified.

Scope: Axe vendor metadata and test resource wiring.
