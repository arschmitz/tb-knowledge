# Account Hub can keep a field invalid while delaying its error presentation

setErrorState with showError:false retains native custom invalidity while keeping aria-invalid false, removing the alert role and choosing help text or no accessible description. Manual state loading resets touched fields and captures validity without storing parsed field changes. Input marks its wrapper touched; explicit validation later exposes all field errors before the controller tests the configuration. Regression source checks neutral invalid indicators and the touched field, including native validity and description state. This is static source/test inspection, not a screen-reader, layout or successful connection result.

Scope: Account Hub touched-field validity and accessible descriptions.
