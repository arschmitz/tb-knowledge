# Chat markup cleanup removes foreign-namespace subtrees before HTML tag filtering

The cleanup loop removes an element outside the XHTML namespace with all of its children. It decrements the live child index before continuing, so the next sibling is still visited. This differs from the ordinary disallowed-HTML path, which may unwrap children. The added SVG/MathML cases run through the common strict, standard and permissive mode helper, but their five equality assertions have no messages. These static cases do not prove a general sanitizer or exploit claim.

Scope: Chat markup namespace filtering.
