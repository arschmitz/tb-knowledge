# Treat a MIME root that is an attachment as a listed attachment

A valid message may consist of one attachment MIME part with no outer multipart node. MsgHdrProcessor.listAttachments previously only walked child parts, so browser.messages.listAttachments() missed the root and browser.messages.query({attachment:true}) also omitted the message. Bug 1893864 returns [mimeTree] when the root itself is an attachment before recursing through children. Current ExtensionMessages.sys.mjs retains this branch. Review attachment code for both root-as-part and multipart-child shapes.

Scope: Extension message attachments.
