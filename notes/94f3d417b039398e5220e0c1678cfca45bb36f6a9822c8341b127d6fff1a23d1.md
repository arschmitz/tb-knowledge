# The search policy supplies an enterprise reason when it removes an engine

The removal loop resolves each named engine and awaits removeEngine with CHANGE_REASON.ENTERPRISE as a second argument. This records the caller's explicit reason value. The inspected comm test asserts that the engine is absent after applying Remove, but it does not assert the reason argument. The external SearchService implementation and runtime result remain unpaired or unrun.

Scope: Enterprise search policy removal.
