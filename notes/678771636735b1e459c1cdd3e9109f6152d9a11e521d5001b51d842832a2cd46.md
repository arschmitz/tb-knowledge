# Keep encoding fixture names and test tasks distinct

inline-signed-utf8.eml and inline-signed-latin1.eml state the signature form and encoding in lower-case dash-separated fixture names. Both tests must keep the accented body and armored signature visible when the key is unknown; the current display policy hides the unknown signature icon for this unencrypted case. Current code still gives both tasks the name testMessageUTF8. A justified new test-naming rule is to give each task a unique scenario name, for example testMessageLatin1 for the second task, while preserving the local browser_inlineOpenPGP.js filename family. This is a proposal, not a claim that the existing code already follows it. The unused openpgpProcessed helper is not evidence that these tasks wait for that event.

Scope: OpenPGP fixture and test naming.
