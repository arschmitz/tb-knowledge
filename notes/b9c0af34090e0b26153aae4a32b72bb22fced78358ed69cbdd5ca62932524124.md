# Encrypted URI normalization keeps message keys separate from display aliases

The inspected normalizer starts with the raw URI, accepts only nonempty normalized results for ref-less message URLs, and maps a file path to a mailbox display URL with number0. Message URIs keep their ref-bearing raw key; normalization does not replace the separate producer registration of message and display families. Original unit assertions cover matching query/file aliases and distinct message keys, but no native or browser test was run. The accepted service name/integrity tracking are a later phase.

Scope: Message security URI service.
