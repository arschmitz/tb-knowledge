# Header test-task names should describe the separate feature under test

Entry1566 renames a second test_add_contact_from_context_menu task to test_context_menu_list_id. Each function expression is separately passed to add_task; the duplicate name does not by itself replace a registered task. The new name distinguishes the two features in test reports. Proposed rule in this file: use a unique task name tied to the assertion’s feature. This is a scoped naming recommendation, not a global filename policy. Static source and test-code inspection only. Full Bugzilla and Phabricator discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: mail/test/browser.
