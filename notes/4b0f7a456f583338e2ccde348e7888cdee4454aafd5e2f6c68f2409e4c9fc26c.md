# Use unlimited mbox streams for whole-store scans and test extraction

A maxAllowedSize of 0 disables the output limit. MboxScanner and ExtractFromMbox intentionally construct unlimited streams because they consume each message and continue to the next. The limit counters are initialized once and Continue does not reset them, so the single-message safeguard should not be casually applied to a whole-store scanner. Close owns and closes the underlying raw stream; Continue requires a fully exhausted open stream. No whole-store scan was run. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Mbox scan versus single-message stream.
