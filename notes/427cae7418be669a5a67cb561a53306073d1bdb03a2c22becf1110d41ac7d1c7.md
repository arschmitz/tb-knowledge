# Attachment filename metadata is added separately from the MIME part URL

The extension builds a MIME part URL, then adds the attachment filename as separate query metadata before creating AttachmentInfo. The first patch appends the raw name; accepted later code encodes it. Internal PDF handling forwards that supplied URL to a content tab under its handler conditions. Preserve the part identity, filename and encoding phases separately; the viewer download-name behavior was not independently executed or inspected upstream.

Scope: extensions-open-attachment-filename-url-phase.
