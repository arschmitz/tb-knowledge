# Keep an attached encrypted message’s security status separate from its parent

The enabled browser regression opens the wrapper, checks its plain body and lack of encrypted status, opens the attached message, checks decrypted text and encrypted status in the new window, then checks the parent still lacks that encrypted status. Preserve both the child success and the parent no-side-effect assertions. The test now also checks that Delete does not act on the attachment in a standalone message. No actual decryption or window test ran for this study.

Scope: mail/test/browser.
