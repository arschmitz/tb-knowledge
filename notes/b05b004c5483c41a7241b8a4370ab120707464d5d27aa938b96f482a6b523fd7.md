# MozIconUtils formats srcset separators separately from CSS image-set strings

The helper builds default 1x, 2x and 3x moz-icon candidates, escapes srcset whitespace and commas, and leaves existing percent escapes intact. Optional query values and CSS string quoting have separate escaping steps. The attachment widget clears the opposite src/srcset attribute, while cloud-menu styles use the CSS formatter. Unit tasks assert exact strings; the compose scenario asserts that the spaced-name icon is loaded. No test or native icon lookup was run, and this is not a general URI sanitizer.

Scope: Thunderbird shared moz-icon candidate formatting.
