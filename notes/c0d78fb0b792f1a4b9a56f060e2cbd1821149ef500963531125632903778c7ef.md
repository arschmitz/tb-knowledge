# Name the XMPP tooltip list for its vCard role

The substantive follow-up 976 selects vCard for the list of localized tooltip fields and optional photo built from vCardInfo. Accepted code sends that list through nsSimpleEnumerator with user-info-received. Manual naming proposal for this family: name the list by the data role it carries, while keeping the observable payload and topic stable. The review request is unread, so no reviewer wording or acceptance rationale is claimed. The preceding bulk lint sweep is excluded from chronological coverage and retained only as code context.
