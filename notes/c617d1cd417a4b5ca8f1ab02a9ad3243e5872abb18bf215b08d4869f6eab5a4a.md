# An IMAP initiation error can advance the identity folder candidate through two paths

The identity folder helper retries from a failed OnStopRunningUrl and also loops when checkServer returns failure. The checked IMAP CreateSubfolderWithListener path calls that listener synchronously when service CreateFolder fails, then returns the same failure. Under that condition the recursive retry can start another candidate before the outer loop retries again and replaces rootFolder. Keep those two advancement paths distinct at this call site, for example by normalizing completion or guarding one candidate's settlement. This is a conditional static trace; no server failure, hang or Promise outcome was reproduced.

Scope: Identity async special-folder resolution.
