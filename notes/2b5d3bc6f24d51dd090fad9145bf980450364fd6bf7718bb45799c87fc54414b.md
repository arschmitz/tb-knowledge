# Use hyphenated Fluent message IDs within the menu localization family

D212626 explicitly rejected camel case for the new localized message ID. Landed and current help IDs are menu-help-get-release-help/appmenu-help-get-release-help. DOM command keys retain releaseSupportURL and legacy menu_openReleaseHelp. Preserve each namespace instead of mechanically renaming every identifier to one case. This is supported for menu Fluent IDs, not proof of one universal DOM convention.

Scope: mail/locales/en-US.
