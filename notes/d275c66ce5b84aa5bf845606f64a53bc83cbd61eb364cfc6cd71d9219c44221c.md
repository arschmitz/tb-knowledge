# Keep nullable name selection separate from the display-list fallback

Current formatDisplayName may return null. Own identities supply a context-specific Me label only when unambiguous, otherwise a full mailbox. An address-book card overrides that selection, with empty card.displayName producing null. formatDisplayNameList owns the next stage: it parses the decoded header, formats its first address, adds a localized and-others suffix for multiple addresses, and falls back to a mailbox string or the original header value. Current message-list callers pass mime2DecodedAuthor and from and set textContent to the result. Keep the helper null signal distinct from the list formatter string result. Entry522 adds string JSDoc types; it does not change fallback behavior. Static source and caller checks only; no rendered names or runtime tests.

Scope: mail/display-names.
