# Allow remote-content notices to have no override button

setRemoteContentMsg deliberately passes an empty button array when aCanOverride is false. Its firstElementChild optional chain decorates a button only when one exists. Preserve the notice and its origin collection in the no-button case rather than assuming every remote-content warning has a menu button. This guard concerns the optional child; it does not assert that notification or buttonContainer can be absent. No UI or policy case was run. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Remote-content notification optional controls.
