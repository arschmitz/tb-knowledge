# Extension menu API mutations wait for persisted menu initialization

Bug 1898592 replaced the local StartupCache menu map with ExtensionMenus persistence. onStartup stores an initialization promise. create, update, remove and removeAll await it and return if the extension shut down meanwhile. Current code keeps this boundary. Changes to extension menu APIs must preserve that order so a mutation cannot race with reconstruction of persisted menus, especially for event pages.

Scope: Extension menus.

- `mail/components/extensions/parent/ext-menus.js`
