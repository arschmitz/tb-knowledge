# Wait for the copied message before selecting its row in a forwarding test

The UTF-8 forwarding helper invokes the Copy menu, waits until the destination folder contains one message, then selects and checks the displayed message before forwarding. Preserve the copy-completion condition in this test; a menu command finishing does not prove the asynchronous message copy has finished. This is the local regression-test sequence, not proof that all copy operations finish at a count of one. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: UTF-8 forward test completion.
