# Unobtrusive header protection is placed on the top payload part below the crypto wrapper

MimeMessage predicts whether plain text, HTML, embedded content and attachments require a leaf or multipart payload. For signed-only unobtrusive output, it passes hp=clear to the actual top payload type rather than every child. When crypto's outer wrapper replaces the top Content-Type and multiple children must move down, _writePart adds the parameter to that new payload container. MimeMultiPart accepts an optional Content-Type suffix with an empty default. The prediction and body-building logic must stay equivalent for that placement to remain correct.

Scope: Compose MIME unobtrusive payload structure.
