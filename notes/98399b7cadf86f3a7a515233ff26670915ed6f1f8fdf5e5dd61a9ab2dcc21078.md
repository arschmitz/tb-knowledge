# Decode mailbox headers with a parser that preserves address structure

Entry 979 fixes the comma in an encoded display name by parsing known mailbox headers and rebuilding each mailbox with makeMimeAddress. Current parseEncodedAddrHeader and convertHeaders retain that path. Generic MIME-word decoding is used for other headers. Rebuilt addresses can gain required quotes or lose unnecessary ones, so decoded header text need not preserve the original spelling. The fixture expects "Hörst, Kenny" as one quoted display name. Do not apply a global comma replacement to all header values.

Scope: mail/components/extensions.
