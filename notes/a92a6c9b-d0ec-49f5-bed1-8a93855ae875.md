# Notify row count and invalidate the toggled tree row

On collapse, the first adapter removed every visible descendant, including open grandchildren, and sent rowCountChanged for the removed span; on expand it inserted visible children recursively and sent the positive count. It then invalidated the parent row so the disclosure marker updated. The current adapter uses a separate flat-row cache and row.rowCount, but retains rowCountChanged and invalidateRow. Expansion code must keep the visible row map, row count, and marker in sync.

Scope: Tree expansion.
