# Declare Thunderbird build options through configure dependencies

The four 2024 configure ports moved BROWSER_CHROME_URL, MOZ_DEVTOOLS and MOZ_PROFILE_MIGRATOR from shell configuration to imply_option and replaced environment mutation for source identity with declared dependencies. Current mail/moz.configure still sets the extension popup URL, requests the DevTools client with all, and enables the profile migrator. A packaging failure reported MOZ_SOURCE_REPO missing after the Gecko migration. Inspect the consumer and dependency graph when moving a build value; a copied shell assignment may no longer reach it. This study did not configure, package or build Thunderbird.

Scope: Build configuration.
