# Thunderbird console defaults use groupSimilarMessages instead of groupWarningMessages

This patch renames the Thunderbird default key from devtools.webconsole.groupWarningMessages to devtools.webconsole.groupSimilarMessages while preserving true. Current accepted source retains the new declaration and comment about grouping/repeating similar messages. The change supplies no saved-user-value migration or consumer/UI implementation, so those outcomes need separate evidence. This is the exact default namespace, not a global naming rule. No console or preference test ran.

Scope: Thunderbird developer-console default preferences.
