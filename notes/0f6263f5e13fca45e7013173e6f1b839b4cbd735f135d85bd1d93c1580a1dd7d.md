# Exclude extension archives from package nondeterminism rewriting

Both Debian rules files override dh_strip_nondeterminism with -Xxpi. That excludes extension archives from this normalization step. Preserve the package-specific exception and check both app and language-pack packaging when changing shared Debian rules. The source does not prove that all archive signatures or reproducibility properties have been tested. No Debian tools were run.

Scope: Debian packaging exception.
