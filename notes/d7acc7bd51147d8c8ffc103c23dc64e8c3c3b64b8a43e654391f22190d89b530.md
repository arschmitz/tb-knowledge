# The Windows Clang job exposes both stable toolchain aliases

The Windows Clang job supplies win64-clang and win64-clang-toolchain as its default aliases, while the toolchains project branch stays null. The assigned Clang 20 change adds the second alias to the same job; accepted Clang 22 configuration retains the pair. This configuration does not by itself prove upstream alias resolution, taskgraph execution or compiler compatibility.

Scope: taskcluster/windows-clang-aliases.
