# The initial Windows build workaround adds a browser XPIDL source only on WINNT

The initial workaround appends /browser/components/shell/nsILimitedAccessFeature.idl to XPIDL_SOURCES only inside the OS_ARCH == WINNT branch. The module remains shellservice. The fixed accepted Windows source and library lists do not contain that addition. Preserve the original and later removal as separate build-configuration phases; this source inspection does not establish an upstream interface contract or a successful Windows build.

Scope: Thunderbird Windows shell build registration.
