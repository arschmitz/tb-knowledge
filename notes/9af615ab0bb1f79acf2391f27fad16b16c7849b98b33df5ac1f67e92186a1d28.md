# Flat tree views still implement the parent lookup contract

669 adds getParentIndex returning -1 to both password-manager and permissions tree views. Current objects generate nsITreeView interfaces, identify every row as non-container and keep that parent method. A flat table still has interface consumers; omitting a method is different from returning no parent. The browser issue context is pending, so the precise failing consumer and any accessibility symptom are not established here. No tree accessibility or password-manager UI test was run.

Scope: Preferences tree interface behavior.
