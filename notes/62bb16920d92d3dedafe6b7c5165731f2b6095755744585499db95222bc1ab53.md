# Account Hub error telemetry counts explicit Fluent-title calls rather than every displayed error

showNotification increments accountHubError only for type error with a truthy explicit fluentTitleId. Title rendering also accepts a nested error-cause ID or raw title, so a displayed error can fall outside this counter. The address-book forward-action catch is one raw-title caller; remote incompatibility passes a specific Fluent ID. AccountHubStep forwards those options unchanged. The added test directly checks one known-incompatible count after waiting for that error title. It does not test every error source, duplicate counting or authentication success.

Scope: Account Hub error telemetry and notification titles.
