# Tree-listbox visual selection and active descendant describe separate state

Current updateRowClasses marks every selected row with selected/ariaSelected while only selectedRow receives current and aria-activedescendant. It promotes the last remaining selected item if the active row leaves selection and removes aria-activedescendant when selection is empty. The initialization path assigns treeitem or option from role. This source contract matters when changing scrolling or selection: the active target is not always the only selected item.
