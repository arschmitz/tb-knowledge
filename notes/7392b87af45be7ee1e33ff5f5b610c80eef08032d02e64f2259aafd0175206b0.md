# An exclude pair can target only the absent preference state

The 1374 commit documents excluding one profile with pref_true and another with pref_false for the same preference. The accepted caller rejects if any exclude profile matches. Under normal filtering, explicit true matches the first profile, explicit false matches the second, and an absent preference matches neither; the remaining notification is targeted to the absent state. With additional include/policy/date checks, those checks must also pass. This is a scoped targeting recipe supported by source and author explanation, not a tested complete notification fixture or a review decision. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Notification absent-preference targeting.
