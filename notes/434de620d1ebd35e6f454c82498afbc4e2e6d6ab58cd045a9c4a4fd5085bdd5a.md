# Standalone OAuth page localization uses value entries and a bounded raw-HTML body

The page is serialized for an external browser, so attribute-like localized text is stored in separate Fluent value entries. Normal text is assigned with textContent. The error body deliberately passes link delimiters and an escaped support URL through Fluent, changes newlines to br and uses innerHTML under a local exception. Template resources are cached, but localized pages are formatted for each call and carry app language/direction. Tests inspect parsed source and literal SVG properties; their role=image equality does not validate an accessible tree. This local design is not a general markup-sanitization or Fluent naming rule.

Scope: OAuth result-page localization and markup.
