# Keep requested compose mode separate from the completion event mode

goDoCommand uses sendMode to choose draft, template, sendNow or sendLater and restrict its listener's modes. The success callback destructures mode from the completion event and returns that result to the extension. The rename makes requested input and reported output distinct. Preserve that distinction when changing this command bridge; do not accidentally return a captured request instead of the actual completion mode.

Scope: Extension compose command mode roles.
