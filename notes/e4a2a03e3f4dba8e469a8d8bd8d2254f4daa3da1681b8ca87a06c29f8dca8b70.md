# Keep provider file, public API and internal event names in their own families

The extension implementation uses ext-addressBook.js, the test family uses test_ext_addressBook_provider and its _mv3 suffix, the public API is browser.addressBooks.provider.onSearchRequest, and the persistent-event module key is singular addressBook. Preserve those exact families when adding related coverage. The dashed UID event is an internal routing name, not a replacement public namespace. This is a scoped naming pattern rather than a repository-wide camel-case policy. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Extension address-book naming.
