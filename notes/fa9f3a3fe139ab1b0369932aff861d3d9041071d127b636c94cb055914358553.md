# Windows mica menu styling uses the current native Menu token

The 1999 port introduced pref-gated mica popup styling across the common and menu rules. The frozen accepted contextMenu rule uses Menu with !important and a transparent panel border under -moz-windows-mica-popups. It no longer supports teaching the original translucent background value as the current rule. Scoped CSS recommendation: inspect the platform rule and theme overrides together before changing popup tokens. Actual Windows appearance and preference combinations need a manual test. This is static source and test-code inspection at the frozen accepted revision. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator timeline and inline discussion remain pending; a landing does not prove approval of a proposed manual rule.

Scope: Windows mica menu theme.
