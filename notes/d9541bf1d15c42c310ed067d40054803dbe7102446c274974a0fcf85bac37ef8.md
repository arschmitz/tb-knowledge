# Gate Account Hub continuation on the selected configuration, not merely discovery

EmailConfigFound emits config-updated with completed true for a non-exchange selection or an exchange selection whose add-on is installed. Discovering an add-on alone is not enough for add-on Exchange. It uses the selected configuration rather than only the initial configuration. Preserve that event payload and selection dependency in this widget. Installation behavior changed after the original UI-only landing, and no add-on was installed during this study. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mail / components.
