# JSAccount summary access must not manufacture message-store files

The 2024 change removes CreateDummyFile from JaMsgFolder database opening. The current method opens or creates the folder summary database and handles a missing or outdated summary without that placeholder message-store file. It saves a local database reference around UpdateSummaryTotals because that call can clear mDatabase during initialization. Keep summary database lifetime and message-store creation separate when changing this base class. The out-of-date cache workaround remains legacy code with its own comments; no store backend or repair path was run.

Scope: jsaccount.
