# Notify timestamp observers from each folder timestamp write path

SetMRUTime and SetMRMTime write second-based string properties and emit their corresponding folder events. The separate DB view MRU writer also emits MRUTimeChanged. Entry 1799 moves events closer to setters so direct calls notify consumers. These setters do not check whether the stored second actually changed; do not describe them as deduplicating same-second notifications. Static source and test inspection only. No runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion is pending.

Scope: folder timestamps.
