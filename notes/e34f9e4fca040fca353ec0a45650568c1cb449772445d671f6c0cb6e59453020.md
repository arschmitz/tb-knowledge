# Scope Mica popup margin overrides to the platform condition and current consumer name

Entry 2107 sets --panel-shadow-margin to zero only for panel[type="arrow"] under -moz-windows-mica-popups. The fixed accepted comm rule now uses --panel-box-shadow-margin and Windows system Menu background, with a transparent border. The separately accepted Gecko popup consumer uses the newer variable for its negative outer margin, content margin and window input-region margin. Check the actual consumer name when applying a port; the historical spelling is not current API evidence. The Gecko comparison is at 00aad09a820405643aebd693e60a3333ccf04544 and its pairing to frozen comm is unverified. CSS source confirms condition and affected geometry only. No Windows rendering, contrast, forced-colors, keyboard, zoom, build or lint test ran. Full external discussion is pending.

Scope: Windows Mica popup CSS integration.
