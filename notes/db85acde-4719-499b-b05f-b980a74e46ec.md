# Use the HTML disabled property for action availability

Set button.disabled from capability state. Assign both true and false when selection changes. A CSS disabled class is visual only and can leave keyboard activation enabled or retain a stale state. D212377 rejected that approach and accepted the JS property, which maps to the HTML boolean attribute. Current address book code uses book.readOnly and supportsMailingLists to gate actions. Preserve reenabling for the all-address-books row.

Scope: address book HTML controls.
