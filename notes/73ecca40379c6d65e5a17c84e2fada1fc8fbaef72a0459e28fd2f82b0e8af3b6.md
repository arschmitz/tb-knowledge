# Keep toolbar platform media conditions scoped to the control container

The accepted unified-toolbar rule stretches .titlebar-buttonbox-container on Windows or Linux while retaining its fixed flex behavior. The explicit media-query or combines platforms; the containing toolbar also handles reversed GTK placement. This is the checked container/layout pattern, not a global rule to stretch every titlebar control. Native controls, RTL placement and window dragging were not exercised. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/themes/shared.
