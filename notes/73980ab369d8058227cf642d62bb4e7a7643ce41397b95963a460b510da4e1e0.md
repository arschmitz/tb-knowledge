# Changing folder loading to a promise requires awaited test setup

Entry 1214 changes loadFolders to return a Promise, makes installDB async, and awaits it in every changed test setup for flags, lookup, moves and relations. For this API transition, update the helper and its setup callers together so assertions start after initialization. The old loadFolders API has been removed from the fixed accepted ID-based Panorama interface, so the example is historical and the recommendation is scoped to comparable async setup changes. All changed tests were read; none was run. Full bug and review discussion remains pending.

Scope: Historical Panorama asynchronous initialization.
