# RNPLib adds failure and shutdown destruction for its native contexts

prepare_ffi now destroys a created context when either configured security rule fails. Init also destroys and nulls the default context on sanity-check failure, and its successful path registers guarded destruction/nulling at xpcom-shutdown. Registration follows awaited key loading, so this does not establish cleanup for all earlier initialization errors. No native destructor, shutdown race or ASan result was exercised.

Scope: OpenPGP default native context lifecycle.
