# The CSS resource helper uses an image context only for moz-icon and requires readable bytes

chromeFileExists parses the URI and selects TYPE_IMAGE for moz-icon, leaving other schemes at TYPE_OTHER. It then opens a system-principal channel and returns whether the stream reports bytes, so its result is a readable nonempty resource check. The caller uses it for CSS image references. This is scoped test setup; the upstream engine restriction, rendering and a fresh channel/CSS run remain unverified.

Scope: Static CSS image resource test helper.
