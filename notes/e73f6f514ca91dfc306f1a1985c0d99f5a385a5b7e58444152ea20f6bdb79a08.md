# Removing the OpenPGP header unload handler leaves header-start and message-frame cleanup

The owned cleanup removes the flexbuttonAction field and the header contentDocument unload listener/handler. Its header-start listener still calls forgetEncryptedMsgKey and is explicitly fired when the listeners are installed. A separate messagePane capture unload listener still calls Enigmail.msg.messageFrameUnload to clear message and UI state. Keep these targets and triggers distinct when assessing this removal. The fixed cleanup separately forgets saved display and network identities; that later behavior is linked as existing evidence. No unload-order equivalence, external-caller absence or runtime result was established.

Scope: OpenPGP header listener lifecycle.
