# Thunderbird Try failure-causality analysis with conservative unknowns

For every job, inspect every `errorsummary.log` line, then record target/parent/outgoing-stack reachability, exact signature, baseline comparison, platform/configuration, `USE_ARTIFACT`, `GECKO_HEAD_REV`, `COMM_HEAD_REV`, and actual installed artifact/source revision. A baseline exact-signature match only supports unrelated when the patch cannot affect the failing path and no extra current error remains. [Task 1]
