# Preserve outer encryption metadata and stop recursive external fallback

After successful external GPGME decryption, RNP may still need to process compression or an inner signature. It preserves result.encToDetails in options, removes an extra armor layer when the decoded output is still ASCII armored, and recursively processes the inner data with alreadyDecrypted=true. The external fallback also requires rnpCannotDecrypt, the user preference and loaded dependencies. The alreadyDecrypted gate prevents the same inner failure from invoking external GnuPG again. Current code adds an r2 null guard. These source checks do not prove every malformed message is recoverable.

Scope: OpenPGP nested processing.
