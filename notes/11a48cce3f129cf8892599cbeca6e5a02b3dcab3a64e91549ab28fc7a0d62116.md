# A file-path getter returns an independently mutable path for suffix work

1355 initializes a fresh path from mPath; accepted nsMsgDBFolder::GetFilePath now returns mPath->Clone(aFile). GetSummaryFile obtains that clone, appends SUMMARY_SUFFIX and returns it. These two implementations retain independent path ownership, even though the exact construction syntax changed. Preserve that contract so summary or log suffix work does not mutate the folder’s stored base path. This is static source and test-code inspection.
