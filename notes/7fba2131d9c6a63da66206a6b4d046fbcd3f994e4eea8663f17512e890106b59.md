# Activity event fallback changes only when the producer leaves iconClass empty

The widget uses a named SVG URL whenever iconClass is truthy. Only an empty value selects the class default, which this patch changes from defaultEventIcon.svg to the pre-existing defaultProcessIcon.svg for event items. Checked folder delete and move/copy producers set explicit deleteMail/moveMail/copyMail values. The default therefore does not replace every folder icon, and a nonempty unknown class is not checked for asset existence. The old IDL CSS wording is not the current selection mechanism. Static source does not establish the historical screenshot path or a complete visual fix.

Scope: Activity widget and producer icon contract.
