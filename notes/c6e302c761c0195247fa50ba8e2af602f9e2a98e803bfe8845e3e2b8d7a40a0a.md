# State zero-based month and weekday contracts in names and docs

Accepted month formatter parameters explicitly say zero-indexed. drawMonth computes (i + weekStart) % 7 and uses shortWeekdayNames[dayNumber] without the removed +1. Keep that index contract in nearby docs/tests rather than infer a one-based array from a calendar weekday label. This scoped syntax check is beyond indentation/formatting.
