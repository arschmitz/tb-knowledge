# Menubar initialization precedes custom-titlebar observation

The 1377 window startup runs AutoHideMenubar.init before CustomTitlebar.init, with a comment explaining that the titlebar code would otherwise pick up initial menubar mutations and cause unnecessary reflows. The accepted source retains that order. Preserve it when changing this startup sequence; this is a scoped initialization dependency supported by code comments, not a measured performance result. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Main-window menubar/titlebar startup.
