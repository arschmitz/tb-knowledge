# Separate account color preview from persistence and normalize reset

Account color preview only notifies observers. Save persists via FolderTreeProperties and notifies the account tree and folder pane; reset uses undefined just as saving the default does. Normalize case before comparing color values. Current default is #1373d9, so historical #2493ef is not a constant to copy. Test preview, save and reset on both UI surfaces with MockColorPicker.

Scope: account color behavior.
