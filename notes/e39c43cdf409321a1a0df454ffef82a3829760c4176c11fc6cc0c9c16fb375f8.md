# The IMAP header forward-declares a pointer-only thread interface

nsImapMailFolder.h uses nsIMsgThread pointers in declarations and forward-declares the interface. The cpp includes nsIMsgThread.h where its full interface is needed. Review explicitly questions and then accepts this file-role distinction. This is scoped C++ dependency guidance, not a mandate to forward-declare every type or proof of faster compilation. No transitive-include/build measurement ran.

Scope: IMAP header dependencies.
