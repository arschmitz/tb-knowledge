# The search-view command-status special case no longer writes its Boolean output

The interface cleanup removes the old explicit false assignment in nsMsgSearchDBView::GetCommandStatus. For runJunkControls and toggleThreadWatched, the owned and fixed accepted override returns NS_OK without assigning through status. Other commands delegate to the base. The actual junk-analysis callback consumes the runJunkControls result. This proves a missing native output write on those successful branches; the paired wrapper and caller initialization were not inspected, so no deterministic JavaScript value, enabled control or runtime failure is claimed.

Scope: mailnews search database view output contract.
