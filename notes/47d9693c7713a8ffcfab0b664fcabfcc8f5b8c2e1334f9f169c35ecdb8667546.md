# The compaction loop names selectedFolder separately from the optional command target

The compaction callback uses folder for its optional command target and const selectedFolder for each entry when it falls back to the selection. The loop therefore does not reuse or overwrite the outer target variable. That local name makes the per-entry server/folder dispatch clear. It is the adopted pattern for this callback, not a repository-wide naming or loop rule. No compaction execution was run.

Scope: folder-pane/naming.
