# Resolve nested SeaMonkey profile paths with appendRelativePath

Thunderbird imports SeaMonkey profiles using profiles.ini. Relative Path values can contain more than one component, so appendRelativePath is required; append accepts a single component. Invalid or nonexistent profile entries are logged and skipped independently so other valid profiles remain importable. The accepted class extends ThunderbirdProfileImporter. Reporter recovery does not establish nested mail folder import, which was a separate report.

Scope: profile-import.
