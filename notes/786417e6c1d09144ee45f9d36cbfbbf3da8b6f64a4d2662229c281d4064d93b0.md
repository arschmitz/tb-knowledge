# Test both changed and unchanged socket values in both server directions

The current migration test records incoming and outgoing socket types before calling MailMigrator._migrateUI with version 43. It expects only value 1 to change to alwaysSTARTTLS. It checks the other values remain equal to their previous values. The registered unit test covers configuration migration, not a TLS handshake, certificate policy or a downgrade attack. The unused expectedSocketTypeAFter fixture field is not a naming example to adopt.

Scope: mail/base/test.
