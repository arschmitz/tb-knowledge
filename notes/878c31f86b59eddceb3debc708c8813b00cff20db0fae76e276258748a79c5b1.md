# Give direct knowledge-service callers a bounded default context

Direct createKnowledgeService callers must get the same bounded retrieval as configured console callers. Without a default, subtracting an absent maxContextChars value produced NaN and removed the context limit. The service now defaults to 10,000 characters and clamps the limit to 1,000–24,000. The regression test passed. A live Codex check retrieved 8,631 characters, cited a supplied record and captured its result. This does not establish overall model quality.

Scope: knowledge.
