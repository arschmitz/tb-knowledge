# The expired Apple fixture test checks import identity with an explicit expired-key lookup

The test keeps the known problematic Apple key after expiry and selects its primary key object using getKeysByEmail with allowExpired=true. The helper default still excludes expired keys. The assertion checks primary key ID; the old native-handle encryption-subkey check is removed because the new lookup result has a different type. Reformatting the fixture expiry comment does not renew armored key data or relax production recipient validity. No import or crypto test ran. Primary comment4 is unavailable, so this remains source knowledge with zero full-audit credit.

Scope: OpenPGP fixture expiry and lookup result contracts.
