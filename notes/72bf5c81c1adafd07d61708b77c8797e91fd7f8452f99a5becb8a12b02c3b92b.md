# Credential-confirmation tests separate widget state, redirect decisions and UI outcomes

The patch adds three layers: isolated widget label/reset assertions, a controlled redirect server with descriptor/reject/accept checks, and browser Back/Continue/manual-config outcomes. The target server deliberately returns404 until the test flag permits its configuration. These assertions do not inspect real credential transmission, verify certificates or exercise external login. A null result after rejection belongs to the controlled test setup; parallel discovery can return another successful configuration in accepted source.

Scope: account-hub-credential-confirmation-test-boundaries.
