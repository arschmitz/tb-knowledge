# The shared Exchange IDL documents the implementation's connectivity and first-sync duties

The renamed IDL removes the EWS-only root-folder connectivity description and leaves the check mechanism implementation-defined. It explicitly assigns first-sync root-folder notification to the client implementation. Native and safe Rust listeners keep forwarding through the renamed callback interfaces, and build registration keeps the msgews module while changing the IDL file name. This documentation describes the shared boundary without assigning one transport's mechanism to both implementations or treating an initiating return as completion.

Scope: Exchange client documentation scope.
