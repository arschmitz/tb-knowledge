# Commands console artifact builds and cross-checkout snapshot reuse

`runConsoleBuild()` is the common path for manual, Review, task, landing, and scheduled builds: reusable snapshot → `mach artifact install` when needed → `mach build faster` → normal incremental `mach build`. Private writable object directories never cross worktrees. [Task 2]

Scope: console.
