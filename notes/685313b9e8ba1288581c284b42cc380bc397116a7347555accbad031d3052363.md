# Shared operation errors expose borrowed HTTP details to outgoing listeners

The shared DoOperation trait takes the protocol client and error as parameters. Its error contract borrows an inner moz_http::Error through TryInto and does not require Clone. The EWS and Graph adapters expose only their HTTP variant. The outgoing listener preserves transport-security status and security information when that borrowed variant is TransportSecurityFailure; other errors use their nsresult conversion. This is the scoped shared-listener interface, not a general ban on Clone or proof of a successful build.

Scope: Rust shared protocol failure handling.
