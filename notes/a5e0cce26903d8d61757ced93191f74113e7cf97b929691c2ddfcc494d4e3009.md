# The POP move guard covers early returns while preserving the explicit successful unlock

After acquiring the destination semaphore, MoveIncorporatedMessage creates a ScopeExit guard so subsequent early returns release it. On success, the function releases the guard and calls ReleaseSemaphore explicitly before later size refresh, move notification and source cleanup. The patch adds return-path coverage while retaining the existing successful unlock position. The source does not prove downstream callbacks require that position or a reproduced deadlock cure.

Scope: POP local move semaphore ownership.
