# Test registration and row availability are part of browser test coverage

A test file being enabled does not prove that its tasks run. Bug 1845239 found legacy Mozmill testSomething functions that the new harness did not discover. Its accepted change fixes the harness declarations, waits for virtualized rows before using them, and waits for popup lifecycle events. When porting these tests, inspect task discovery and the event/row helper contract as well as assertions. Static source was read; no browser test was run here.

Scope: mail/test.
