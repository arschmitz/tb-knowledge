# Folder hierarchy warnings flatten names at the formatting boundary

Both child-failure warnings pass childFolderName and parentName through PromiseFlatCString(...).get() before supplying them to %s formatting. This replaces direct Data() access without changing which child failures continue traversal. The exact accepted code retains both conversions. The claim is limited to these two diagnostics and does not establish a general DOM or string-storage rule.

Scope: Shared folder hierarchy diagnostics.
