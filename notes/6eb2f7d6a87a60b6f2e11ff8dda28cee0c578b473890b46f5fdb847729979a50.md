# Reset mail.inline_attachments in the messenger-settings test cleanup

The added messenger-settings case writes mail.inline_attachments=false through a parent Services.prefs.setBoolPref handler. The same file registers clearUserPrefs for cleanup and calls it during setup, but that helper never clears mail.inline_attachments. Its comments promise default state at both boundaries. When repairing this test, include the new preference in the helper so the test restores the setting it changes. Preserve the awaited message handshake before checking .get({}). This is a scoped cleanup mismatch visible in source; no subsequent failure or cross-process preference leak was reproduced.

Scope: mail/extensions/tests/cleanup.
