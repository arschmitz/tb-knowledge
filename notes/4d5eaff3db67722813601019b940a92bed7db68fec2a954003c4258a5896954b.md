# NNTP download selection and message retention use different settings and consumers

nsIMsgDownloadSettings is used by the inspected NNTP downloader to build unread/date search terms. Folder download settings and folder retention settings independently choose database values or incoming-server defaults. Retention deletion runs through the purge service and ApplyRetentionSettings; the retention getter avoids caching server defaults so later server changes remain visible. The comment-only landing documents these roles and implements no redesign. Moving download settings to NewsFolder and using AutoSync were review alternatives, not adopted code. Static inspection only; no download or purge ran.

Scope: Mailnews folder settings and purge ownership.
