# Removing dummy-envelope support still requires the protocol interfaces and callers to change together

The save-to-file change removes the dummy-envelope Boolean and its URL/listener state across the shared service surface and protocol implementations. It removes generation of From - and Mozilla status headers while retaining the canonical-line-ending option and URL completion contract. The factory still obtains the line-ending choice from the message URL, and Exchange supplies it directly. This option removal does not include the later in-place file-reservation repair or expanded message-store tests. No save or protocol test ran.

Scope: Message-service save-to-file API.
