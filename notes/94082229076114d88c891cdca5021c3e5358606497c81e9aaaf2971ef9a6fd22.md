# Notification action IDs name the behavior and remain separate from labels

The accepted notification family uses action IDs such as mark-as-read, delete and mark-as-starred, with separate Fluent IDs such as mark-as-read-action. The same behavioral action ID selects the implementation, appears in the ordered preference and keys the usage counter. Preserve these stored IDs and keep the user-facing translation separate. Historical action1/action2 names described positions and were replaced. This is the notification action family, not a global kebab-case rule for JavaScript symbols. No UI was run.

Scope: Notification action naming.
