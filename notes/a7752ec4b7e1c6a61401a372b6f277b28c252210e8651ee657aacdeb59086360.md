# The Calendar read-dialog titlebar clips overflow without changing line breaks

The landed change adds overflow: hidden to the titlebar that contains the calendar/actions row and event h2. It preserves the existing title line-break behavior and two-line clamp. The fixed accepted stylesheet retains parent clipping alongside the h2 overflow/ellipsis rules. This is a scoped containment choice; it does not establish that every title remains fully visible or that a long-title, zoom or accessibility test passed.

Scope: Calendar read-dialog titlebar CSS.
