# Check retained day-label calls against the current formatter API

The fixed accepted calendar-day-label date setter still calls dateFormatter.dayName twice. Its formatter module defines weekdayNames but contains no dayName method. The historical 1065 migration used the array. This is a static interface discrepancy to check during a formatter change; active use of this legacy setter is unestablished. The multiday heading uses calendar-header-container and does not establish this setter’s reachability. No runtime failure, fix or reviewer decision is claimed. Full bug and review discussion remains pending.

Scope: Calendar legacy day-label formatter references.
