# The font fallback test treats Linux default labels as a prefix check

The missing-font scenario first checks a two-entry font.name-list: a fake name followed by an enumerated available font. It sets font.name to the fake name and checks the preferences UI. For advanced-dialog defaults, Linux checks only the Default ( label prefix because the concrete font is system-dependent; other platforms check the full expected default label. Nondefault cases compare selected values. The exact comparison/UI helper bodies remain in the accepted revision; later preference setup uses pushPrefEnv. This is a scoped fixture contract, not proof of arbitrary fallback behavior or a fresh platform run.

Scope: preferences-tests.
