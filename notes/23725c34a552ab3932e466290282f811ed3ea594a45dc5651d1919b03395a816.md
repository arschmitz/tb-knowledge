# Name desired import properties separately from the header state

wantNew, wantRead and wantFlagged describe the requested result. The importer creates flags for copyFileMessage, then repairs returned read/flagged state and missing known tags if needed. A wrongly set new flag can be cleared through read state; the code says it cannot add a missing new state at this stage. Manual state naming proposal: use want* for target values when the current header can differ. Do not claim import can repair every protocol state merely because it accepts a property. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: mail/extensions/import-state-names.
