# Attachment Enter handling separates the command guard from the test claim

The attachment list calls cmd_openAttachment for unmodified Enter and excludes Ctrl, Alt, Meta and Shift. It also removes the old keypress Enter dispatch. The modifier test directly proves its expected no-open-command condition for platform Accel+Enter in source; it does not assert that a message was sent. The same rewrite narrows Space preventDefault to its no-Shift/no-Ctrl selection branch, leaving modified-Space behavior outside the new tests. Fixed accepted code retains the event branches and exact test file. No keyboard, dialog, send or browser test ran.

Scope: Attachment-list keyboard command routing.
