# Axe helper defaults merge rules but replace other caller options at the top level

The helper defaults preload.assets to media. It overlays caller options and separately merges rule entries, so caller rules override matching defaults without dropping unrelated defaults. A caller preload value replaces the default preload object rather than merging its nested fields. Both content and window entry paths receive these prepared options; static source does not prove the reported stylesheet error is cured.

Scope: Browser-test Axe option preparation.
