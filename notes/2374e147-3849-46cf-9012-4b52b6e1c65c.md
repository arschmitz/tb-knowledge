# Label each Today Pane cycle button with its next mode

The previous and next Today Pane cyclers change meaning as the mode changes. The accepted code picks localized tooltip keys by the current index, using (index + 2) % 3 and (index + 1) % 3, then sets each button attribute. It adds a separate localized close tooltip and registers the new FTL resource in messenger.xhtml. Current JS retains this mapping. When a control cycles modes, update its label to describe the action it will take next, and load its localization resource where the control appears.

Scope: Calendar Today Pane localization.
