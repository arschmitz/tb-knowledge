# Graph input-cache logs state the checksum result

The review asks to replace unclear pinned-file wording with the actual checksum outcome. Landed and accepted INFO messages say whether the cached OpenAPI file matches the expected checksum and whether it will be replaced. The source adopts clearer result wording, but it does not use warning severity merely because the reviewer called it a warning. This is a scoped log-message practice, not a global ban on the word pinned.

Scope: Graph generator status-message wording.
