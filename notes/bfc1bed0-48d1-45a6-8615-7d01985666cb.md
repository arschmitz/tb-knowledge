# Track only syncable changes and suppress feedback from incoming records

The new trackers watch a narrow set of preferences and object events. Calendar tracking accepts CalDAV and network ICS but ignores local storage calendars and presentation properties such as color. Address book tracking accepts CardDAV/LDAP but ignores local books. The tests check creation, changed values, unchanged values, deletion, and ignored properties. They set tracker.ignoreAll while applying incoming records and assert that those writes do not become new outgoing changes. This avoids Sync loops and noisy updates; tests should cover both tracked and deliberately ignored changes.

Scope: Thunderbird Sync tracking.
