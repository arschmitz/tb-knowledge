# Check the preference type as well as the telemetry label

The 1959071 repair moves mail.addressDisplayFormat from the Boolean collector/probe to the integer collector/probe in both MailGlue and metrics.yaml. Fixed source declares the preference int32_t and binds it as an integer in Settings. The collector uses getIntPref for initial reporting and observed changes. The probe named preferences_integer is declared labeled_string, so do not infer its generated serialization contract from its name. This adds a type boundary to the existing exact-name lesson; no telemetry or SDK coercion test ran here.

Scope: Preference telemetry boundaries.
