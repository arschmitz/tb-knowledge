# Auto-form and manual-config integration tests check different contracts

The isolated auto-form test checks config-updated completion, manual-action visibility, reflected ARIA values and captured input. The integration task chooses that action, waits for the incoming pane and checks its prefilled hostname and username. These assertions cover widget state and routing separately; they do not assert that discovery made no requests or that account creation succeeded. Later touched-input and Windows focus changes remain separate phases. No test ran.

Scope: Account Hub manual configuration tests.
