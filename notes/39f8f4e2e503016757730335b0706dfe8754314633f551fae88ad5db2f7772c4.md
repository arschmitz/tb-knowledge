# The attached-file statistics cleanup leaves MIME attachment size accounting in place

The 2613 patch removes public nsIMsgAttachedFile statistics and their accessors. The current native header still has separate size fields for attachment data and attached files. The MIME draft path counts decoded or written bytes, transfers that size into attachment data and passes it to the compose attachment SetSize call. Removing the public statistics does not remove all attachment size accounting, and the remaining fields are not evidence that every value is initialized on every path. Required Bug discussion has no Thunderbird-only selection and own reviews are deferred; these source-only findings receive zero audit credit.

Scope: Attachment size public/private boundary.
