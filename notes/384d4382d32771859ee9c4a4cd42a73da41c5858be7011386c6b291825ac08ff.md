# Compact folder rows require both stored state and mode support

_createFolderRow passes compact=true only when _isCompact and that mode canBeCompact are both true. A saved compact flag can remain even when the UI disables compact view for a mode, so the capability check belongs at row creation. Fixed code retains this conjunction. Missing Bug comments6/7 remain an explicit context gap; review approval does not independently establish a runtime cure. No folder-tree test ran.

Scope: Folder mode state.
