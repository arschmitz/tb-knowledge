# Sort a refreshed Calendar list once after bulk insertion

740 changes addItems to append mapped rows in bulk and then force a full sort. The former insertion search ran for each incoming item. Current #sortBy orders the full list and wraps selection preservation around the change. This supports avoiding repeated insertion work during a refresh. It is a static algorithm observation; no measured complexity or UI responsiveness result is claimed.

Scope: Calendar filter tree update.
