# Tab moves keep the primary mail tab first and compensate for removal indices

tabs.move rejects moving the primary mail tab and positions other tabs after it when index zero is requested. It calculates insertion per target window, using -1 for the end and clamping positive overshoots. Rightward same-window moves pass insertionPoint + 1 because tabmail removes the source before decrementing the target. getTabWindow obtains the tab’s owning global without requiring an active browser. The checked pre-validation is not a transaction guarantee. Cross-window ID continuity is a separate, unasserted follow-up in this phase; no runtime test ran.

Scope: WebExtension tabs.move and tabmail ordering.
