# Resolve QR outgoing data through the configured or default SMTP server

Current getAccountData uses the explicit smtpServerKey when set and otherwise uses outgoingServer.defaultServer. Selected context-only entry 1819 fixes the old direct lookup of an empty key. Exported identities still use the literal configured-key filter: no identity key, or a key equal to the default identity’s configured key, plus ASCII email. Do not silently reinterpret that filter as all identities that happen to resolve to the same server. Eligibility is owned by the preceding batch; this lesson covers serialization and its default-server repair.

Scope: mail/modules/QRExport.sys.mjs.
