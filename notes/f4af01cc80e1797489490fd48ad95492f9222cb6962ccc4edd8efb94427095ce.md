# The Exchange alert assertion checks a role string, not a spoken announcement

The warning test compares getAttribute("role") with "alert", while its message says the warning should announce dynamically. That assertion checks markup; it does not observe a screen reader or native accessibility event. A precise message would say that the warning banner should have the alert role. The other new warning assertions check visibility and completion directly. No browser or accessibility test was executed here.
