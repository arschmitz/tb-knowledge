# Keep extension icon layout rules scoped to their actual menu node types

Current Linux and Windows CSS reserve icon space for uniconed menu and menuitem nodes in extension popups, while macOS explicitly shows the icon and suppresses its extra pseudo-element. These platform rules have distinct target states; copying only a selector or only the padding value can change alignment. A scoped manual CSS recommendation is to check menu and menuitem coverage plus checked/icon-bearing state when altering this family. No platform rendering or keyboard inspection ran. This is static source and test-code inspection. Full Bugzilla and review timeline and inline discussion remains pending. No runtime, build, lint or live accessibility validation ran.

Scope: Extension menu platform selector scope.
