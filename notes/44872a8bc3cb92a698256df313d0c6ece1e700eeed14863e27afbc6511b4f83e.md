# Separate Account Hub option readiness from address-book discovery

The address-book view first assigns ready to #initUI, awaits it, and then runs init to discover books and set the option state. The hidden observer starts init again when the view is shown. Consumers waiting only for ready have not waited for discovery/count completion. The widget removes fetching and disables sync when no accounts or no remaining books exist; reset restores disabled/fetching state. This landing addresses UI-first ordering, while abortable fetching was explicitly deferred. No network or UI test ran.

Scope: Separate Account Hub option readiness from address-book discovery.
