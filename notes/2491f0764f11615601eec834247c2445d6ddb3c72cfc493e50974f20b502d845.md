# Splitter lifecycle checks had unresolved size failures

The imported D320309 patch-update history distinguishes resizeDirection, the resized-pane axis, from aria-orientation, the perpendicular separator axis. It proposes retaining each repeated Arrow-key size change while emitting one resize start and one end on keyup or blur. This is a scoped recommendation, not verified final behavior: the preview lifecycle assertion reportedly passed, but two width/value assertions failed with expected 160 and actual 230. Resolve those failures before treating the change as validated. The source was not independently rechecked.

Scope: Pane splitter keyboard resizing.
