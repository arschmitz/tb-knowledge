# Shared mock storage preserves distinguished-folder lookup before ordinary IDs

The extraction makes EwsServer and GraphServer inherit the same folder/item storage. getFolder and getDistinguishedFolder return null for absent entries, and EWS resolves a distinguished folder first before falling back to an ordinary ID with ??. items returns the Map entry iterator for consumers that need both IDs and ItemInfo. The accepted source keeps these lookup contracts. This scoped test-model interface does not prove protocol behavior or define global naming/style rules.

Scope: mailnews/test/fakeserver.
