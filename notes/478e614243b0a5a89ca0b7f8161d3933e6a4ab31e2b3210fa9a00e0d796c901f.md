# Removing nsIMailboxUrl leaves request state in the concrete mailbox URL

The patch removes the scriptable nsIMailboxUrl interface and moves action constants to MailboxAction. The concrete nsMailboxUrl still stores its copy handler, action, message size/key and multi-message keys/index. Interface removal therefore does not establish that the native URL becomes stateless or serializable. This is a declaration/state finding, with no engine serialization or runtime result.

Scope: Mailbox URL interface and request-state scope.
