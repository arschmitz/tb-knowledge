# Register every allowed calendar completion before adding the item

The special UID test prepares both onLoad and onAddItem resolvers before calendar.addItem and waits Promise.any because cached and uncached providers can finish through different notifications. It then verifies the original identity and removes/unregisters the item. Awaiting only one incidental event can miss a valid provider completion. Read tests only; no server run.

Scope: calendar/test/unit/providers.
