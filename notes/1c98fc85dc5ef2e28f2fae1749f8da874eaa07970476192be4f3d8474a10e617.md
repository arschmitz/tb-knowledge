# Forced PEEK also selects a different chunk-abort branch

The oversized-fetch patch changes whatToFetch to PEEK when automatic marking is disabled or delayed. FetchTryChunking passes that field through to FetchMessage, but its local partial-stream AbortMessageDownLoad branch checks only kEveryThingRFC822. The forced PEEK therefore skips that specific branch. This is an exact source consequence, not proof that all cleanup is skipped or that an interrupted transfer leaks. No fetch or cancellation test ran.

Scope: IMAP fetch-field propagation.
