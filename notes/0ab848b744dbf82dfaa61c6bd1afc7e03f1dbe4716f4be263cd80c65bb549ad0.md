# The CMS callback stops before memcpy when its first allocation fails

This landing checks the first decoded-buffer allocation before memcpy. On failure it records the out-of-memory error, clears output_fn and returns without appending/counting the chunk. The checked write/EOF paths also reject a cleared output callback. Later accepted CheckedInt arithmetic is a separate phase, not part of this five-line guard. No allocation-failure injection, crypto test or complete caller-recovery proof ran; required primary context is access denied and full-audit credit remains zero.

Scope: MIME CMS buffer handling.
