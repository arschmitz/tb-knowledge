# Unread-folder removal protects selected rows in the displayed mode

The Unread mode keeps a folder when it still has unread messages, or when its displayed row contains a selected row. It looks up that row in the Unread mode, so selection of the same folder in another mode does not protect it. Normal mode includes descendant unread counts; compact mode checks the folder itself. A count change passes the full bound keep predicate into ancestor removal. A later selection change removes read rows that no longer protect a selection. Keep this distinction when changing removal: mailbox ancestry or the single gFolder value does not describe all selected rows in the displayed tree. This is static code evidence; it does not establish measured focus preservation or performance. Bug 341266 and D248683 retain required gaps, so entry 4279 remains a partial source study.

Scope: Unread folder tree removal.
