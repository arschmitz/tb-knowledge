# Promoting a cross-folder thread root preserves each descendant depth

When AddHdr inserts a new parent ahead of an existing root, every previous row must increment its own m_levels[i]. The historical typo reused m_levels[1] and flattened different descendant depths. Current code also keeps keys, folders and levels aligned at each insertion. This is a scoped hierarchy invariant, not a claim that all remaining threading problems are fixed. This is static source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending.
