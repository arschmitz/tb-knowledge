# Account creation errors carry a readable message and structured localization cause

1364 replaces new Error(object) with a string message plus cause containing Fluent title/description IDs. Accepted validateAndFinish uses that form for duplicate accounts and authentication failures, preserving error.message when wrapping. In this Account Hub path, keep the technical error message distinct from structured user-facing localization data; passing the metadata object as the message loses that separation.
