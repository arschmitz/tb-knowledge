# The bad-size indexing matrix has different MIME and skip paths

The shared bad-size test halves one header's size, and offlineMsgSize when present, then waits and checks both expected messages were indexed. Local and offline IMAP indexing can stream MIME; online messages can use only headers. Two other shared scenarios return for all non-local injections even though one TODO names only online IMAP. Registering the same six functions in three harnesses does not prove identical paths or coverage in each mode. This is direct test-source evidence; no test ran.

Scope: Gloda bad-message test coverage.
