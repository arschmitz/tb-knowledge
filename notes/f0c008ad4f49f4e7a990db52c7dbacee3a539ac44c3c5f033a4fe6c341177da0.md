# Extension tests explicitly re-enable schema-warning failures in cleanup

These browser and xpcshell fixtures intentionally use unsupported or deprecated extension data. They call failOnSchemaWarnings(false), then explicitly call true in registered cleanup, replacing direct writes and clears of warnings-as-errors. The accepted callers retain that pair. Cleanup requests the normal strict mode; it does not restore an arbitrary earlier false setting or prove the internals of the external harness helper. No new assertions or test execution establish isolation here.

Scope: extension-tests.
