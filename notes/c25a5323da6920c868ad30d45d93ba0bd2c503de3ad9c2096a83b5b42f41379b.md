# Separate public schema names from manifest-version branches

The 2024 documentation cleanup removed internal _MV2 and _MV3 suffixes from the spaces button property type names. Current SpaceButtonProperties contains version-scoped choices under one public name. Use a stable public name for the concept and place manifest-version conditions in the schema branches when this API already follows that structure. This observation does not mandate renaming every versioned internal type.

Scope: mail/components/extensions.
