# The fixture generation notes use literal home names before expanding them in the appendix

The preparation section declares H_RNP and H_GPG as temporary-directory variables, then shows early commands with literal H_RNP and H_GPG arguments. The raw-command appendix uses quoted variable expansion instead. A reader must distinguish those forms; they do not name the same shell value unless manually substituted. This is a scoped documentation inconsistency, with no executed generation failure or tool-validation claim.

Scope: OpenPGP fixture regeneration documentation.
