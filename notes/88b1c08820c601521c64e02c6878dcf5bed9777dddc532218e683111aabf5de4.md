# Thunderbird extension update permission notifications use one exact observer topic

ExtensionsUI.init registers webextension-update-permission-prompt, and observe handles that exact topic. The branch marks the request as an update, immediately resolves updates with no promptable permissions or experiment APIs, and otherwise retains callbacks in updates before refreshing notifications. This is the local consumer contract; the upstream Gecko producer and end-to-end delivery were not checked in this source-only study.

Scope: mail extension update UI.
