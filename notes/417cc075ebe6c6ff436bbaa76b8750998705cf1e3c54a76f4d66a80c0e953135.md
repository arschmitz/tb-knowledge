# The Unix DNS lookup returns an empty result before advancing past a failed native name skip

The owned change checks each dn_skipname result before adding it to the question or answer cursor. A negative result returns an empty array. Accepted code retains this behavior alongside later, separate bounds checks. SRV/MX config consumers turn missing hosts into errors, while the checked MX test substitutes DNS.mx and never decodes native answers. These static guards and assertions do not establish that the macOS crash was cured.

Scope: Unix DNS parser error contract.
