# The historical math-shift parser exception narrows both source and error text

The historical entry is added only when mathml.math_shift.enabled is false. It requires a mathml.css source suffix and an Unknown property error naming math-shift. ignoredError requires both present regex criteria; it does not use isFromDevTools as a matching predicate. This suppresses one test diagnostic. It does not change parser behavior or ignore all MathML errors. Accepted source later omits this entry. No static CSS test ran.

Scope: Static CSS test allowlist matching.
