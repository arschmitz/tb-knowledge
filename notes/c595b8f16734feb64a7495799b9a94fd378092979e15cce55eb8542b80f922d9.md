# Panorama message conversion distinguishes aggregate rows from child-query rows

Top-level grouped selections append messageCount and sometimes dateGroup. A child-group selection returns only the eleven base message fields. The follow-up checks the statement column count before extracting aggregates, so grouping state alone no longer implies those fields exist. Fixed accepted code retains this shape distinction inside its later asynchronous listener. The >11 guard fits these selected queries; it is not a generic validation rule for arbitrary SQL result shapes. No assertion failure was rerun.

Scope: Panorama/query result shape.
