# Distinguish popup option indices from content values

The current form-picker harness asserts the parent select popup uses indexed values 0, 1 and 2, then asserts the selected content value is 3.141592654. Keep both representations in checks when testing a remoted native select. A correct popup label or index alone does not prove the content control received its original option value. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
