# The SEARCH UID iterator adopts unsigned conversion but keeps pointer parsing

The owned change replaces atoi with strtoul and names the returned value ImapUid. It does not inspect an end pointer, conversion error or numeric range. Char-pointer scanning remains, and the accepted scanner later changes how it advances across digits and lines. The reviewer's negative-value concern explains the request; actual source proves the conversion change, not complete input validation or a platform-independent numeric result.

Scope: IMAP SEARCH iterator conversion limits.
