# The Slice.mjs lint override separates parameter rebinding from draft-property updates

The local redux-immutable-slices configuration matches **/*Slice.mjs and enables no-param-reassign with props:false. This permits the slice pattern of updating draft properties while rejecting reassignment of the parameter binding. The suffix and option are scoped configuration; they do not define a rule for all JavaScript or prove that matching files are correct Redux implementations. No lint run was performed.

Scope: tooling/redux-lint.
