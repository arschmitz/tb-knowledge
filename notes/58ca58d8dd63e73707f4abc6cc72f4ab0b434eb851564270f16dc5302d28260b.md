# Attachment label fragments preserve the filename extension without changing row identity

MozAttachmentlist splits a filename into name and extension spans. The name can shrink and use an ellipsis; the extension grows into the remaining space. This keeps the extension visible in a narrow row. The widget explicitly treats this as a display convenience because MIME content type can differ from the extension. The option row owns the attachment and action. Its decorative image has an empty alt value, its size span has role note, and child pointer events are disabled so clicks and drags target the row. Preserve the established attachmentItem, attachmentcell-name, attachmentcell-extension, and attachmentcell-size hooks together in JS and CSS. These mixed legacy class names are a scoped exception to newer dashed shared classes. Check the actual option name in the accessibility tree before changing the label structure; no such runtime check was performed here.

Scope: architecture/attachment-widget.
