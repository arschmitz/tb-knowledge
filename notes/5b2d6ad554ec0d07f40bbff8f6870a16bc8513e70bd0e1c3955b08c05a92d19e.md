# The message-display icon wait covers the active initial icon check

Its only active background check is icon1.png from the manifest; the setIcon string/object update checks remain commented out. Do not count those disabled paths as exercised by this wait. CSS path equality does not assert loaded pixels or rendered accessibility, and no intermittent test was run.
