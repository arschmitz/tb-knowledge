# The news search converts its wildmat buffer before releasing it

This one-line landing introduces an explicit nsString argument to NS_ConvertUTF16toUTF8 for the allocated char16_t wildmat buffer. The local producer zero-terminates that buffer, and EncodeTerm appends the conversion result before free, preserving the wildcard and XPAT assembly order. Accepted later code uses nsDependentString instead; that is a separate wrapper phase. Gecko constructor/overload behavior was not paired, so this source check does not establish compiler compatibility, allocation cost or a general pointer-conversion rule. No search test ran.

Scope: News search encoding.
