# Use IMAP FETCH PEEK for oversized uncached messages when read is delayed

When a message is too large for the system cache, a normal full fetch can set the server Seen flag at once. If automatic marking as read is off or delayed, use the PEEK variant so a fetch does not mark the message read early.

Scope: imap.
