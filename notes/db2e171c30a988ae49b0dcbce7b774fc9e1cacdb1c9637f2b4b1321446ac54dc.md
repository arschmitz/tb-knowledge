# Limit the NoSpoofingSender claim to its actual heuristic

The retained helper expands the name to Full name <email> only when it finds @ followed by a dot in the name; otherwise it returns the name. The formatting tests include names that look like an address and explicit fallback cases. Describe this as the inspected heuristic, not a general identity-validation or phishing-prevention guarantee. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Panorama address display spoof heuristic.
