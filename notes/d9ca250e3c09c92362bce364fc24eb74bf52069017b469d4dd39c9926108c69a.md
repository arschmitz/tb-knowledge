The icon patch switches lwtheme-based selectors to nested non-native/light media conditions. Its partial backout restores only the two CSS files. Built-in manifest color and experiment removals stay applied. Accepted CSS selects default, dark or light icon variables from root theme state, with an important dark-scheme override for toolbar and spaces.
