# Public-key compose uses the actual default identity instead of an IMAP/POP helper fallback

The key-manager path now supplies defaultAccount?.defaultIdentity directly and removes its custom Enigmail helper. The old fallback scanned IMAP/POP when no default account was present; it is not the separate extension accounts.getDefaultIdentity API. Author and reviewer identify subtle EWS trouble and leave normal compose choice available, including NNTP. No EWS delivery or compose runtime ran.

Scope: OpenPGP compose identity receiver.
