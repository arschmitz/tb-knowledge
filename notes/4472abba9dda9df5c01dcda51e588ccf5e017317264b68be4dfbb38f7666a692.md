# Document fakeserver credential result shapes explicitly

AuthPLAIN returns one object with username/password; AuthCRAM returns username/digest. The human JSDoc patch made tags validator-valid, but current comments still repeat @returns to describe object fields. A scoped manual proposal is to document one return shape or a named typedef with properties, while retaining the distinct error contract. Passing JSDoc lint does not prove that a reader or generated page sees an unambiguous shape. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Fakeserver authentication documentation.
