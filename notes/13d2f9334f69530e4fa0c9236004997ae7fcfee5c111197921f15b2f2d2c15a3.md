# Resolve a search-dialog column from its closest treecol ancestor

The historical sorting fix replaces a direct localName == treecol test with closest("treecol"), so clicks on a header descendant reach HandleColumnClick. The fixed accepted implementation now lives in SearchDialog.js, with a capture-phase click listener on the tree. Recommend preserving the owner-element boundary when a header contains icons or labels. It is an observed handler pattern, not a requirement for every click listener. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
