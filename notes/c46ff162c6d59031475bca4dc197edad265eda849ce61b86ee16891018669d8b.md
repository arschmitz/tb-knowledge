# Register the plugin behind an inherited lint rule

In the historical promise/valid-params rollout, the shared rule reached comm-central before its plugin was registered locally. Upstream Bug 1845725 reports every comm file failing with a missing rule definition; the exact Thunderbird port adds promise to the existing .eslintrc.js plugin list. Check the repository integration as well as the shared rule when diagnosing this kind of configuration failure. This is a scoped historical configuration repair, not a manual syntax rule, a claim about today's resolved flat config or a linter result reproduced here. Suggestions to enable other plugin rules remain separate proposals.

Scope: Historical ESLint shared-rule integration.
