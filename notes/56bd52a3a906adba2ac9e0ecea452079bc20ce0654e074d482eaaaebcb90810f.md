# EWS sync requests mailbox recipients for persisted address lists

The historical EWS fix requests message:ToRecipients, CcRecipients and BccRecipients instead of the display-only To/Cc properties. Existing recipient-array consumers then populate the stored address lists. The current split sync module keeps those requests. The new test directly checks two persisted To addresses and one Cc address; it does not check Bcc or repair existing stored messages. The primary discussion has a missing human comment, so this source lesson grants zero complete-audit credit. No test ran.
