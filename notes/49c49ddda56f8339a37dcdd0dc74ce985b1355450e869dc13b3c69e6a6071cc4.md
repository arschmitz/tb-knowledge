# Keep the raw XPCOM macro signature separate from the checked Rust method

The read-status review corrected an attempted change to both signatures. For this xpcom_method! bridge, keep the macro argument as *const ThinVec<nsCString>; the generated wrapper checks it and passes &ThinVec<nsCString> to the inner Rust method. The final source follows that split. This adds the review correction to the existing ownership lesson; the later detached task still needs owned arguments. A reviewer reported a successful local compile, but no Rust build was run in this study.

Scope: rust/ews_xpcom/src/lib.rs.
