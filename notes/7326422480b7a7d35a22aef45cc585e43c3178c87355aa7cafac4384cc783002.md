# Filter action failure logging retains custom text while localizing internal IDs

Internal action failures pass a Fluent ID. Custom actions pass already-localized text and skip that lookup. The logger retains the supplied text when lookup fails or returns an empty value, then formats the shared failure prefix. Its UTF-8 composition still ends at the UTF-16 LogFilterMessage interface. Inline-capacity buffers and the review summary do not establish allocation or speed measurements.

Scope: Filter action Fluent logging.
