# Quit prompt tests select action IDs and check the quit veto

The compose tests prepare cancel or extra1 handling before notifying quit-application-requested, await the result and inspect the quit-veto flag. A two-window scenario chains extra1 then cancel. Running-filter tests use accept for the expected veto and cancel for the expected allowed quit. These are caller-specific action IDs and assertions; an action name is not a universal label or Boolean response rule.

Scope: quit-prompt-tests.
