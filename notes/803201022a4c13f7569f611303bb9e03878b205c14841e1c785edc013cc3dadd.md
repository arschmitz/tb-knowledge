# The renamed Exchange delete test still uses a different enum member name

The renamed delete-model test assigns Ci.IExchangeIncomingServer.DELETE_PERMANENTLY. The interface defines PERMANENTLY_DELETE and MOVE_TO_TRASH. The mismatch also remains in the accepted source and existed before this interface rename. This is a static member-name finding; the inspected comm source does not establish how an undefined member converts through generated bindings or whether the test fails.

Scope: Exchange delete-model test enum reference.
