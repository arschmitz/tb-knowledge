# Content-page navigation coverage does not replace removed script-injection coverage

This cleanup removes tests that deliberately reenabled old extension-page injection behavior and preserves the existing multiple-content-tab task byte for byte under a new filename. The preserved task asserts URL completion, distinct tab objects and lifecycle counts; it does not inject scripts/styles or exchange content messages. Keep navigation coverage separate from the removed compatibility-policy coverage and from any later rejection test. This is source and exact task-identity inspection, not a browser run.

Scope: WebExtension browser test scope.
