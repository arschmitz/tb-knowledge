# The general external-OAuth default retains a consumer gate, with later request branches separate

The owned change removes the Nightly-only false alternative and leaves mailnews.oauth.useExternalBrowser=true for every channel. Its historical OAuth2 consumer still requires an HTTP loopback redirect before choosing ExternalRequest. At the fixed accepted endpoint, the consumer instead combines global and issuer flags, then has a separate scheme-redirect branch before internal fallback. Keep the default-only landing and these later consumer changes separate. A true default does not prove that every provider authenticates externally; the separate private-browser preference concerns internal windows. No browser login, listener or platform behavior was executed.

Scope: OAuth interactive authorization defaults.
