# The recorded Account Central settings ID is renamed with its CSS and test consumer

The receiver uses dataset.telemetryId or DOM id before its attribute fallback. The settings button changes to accountSettingsButton in markup, both styling selectors and expected telemetry ids, while its label and viewSettings action remain. Keep that coupled identity change distinct from a visual redesign or a universal naming rule.

Scope: Account Central recorded widget naming.
