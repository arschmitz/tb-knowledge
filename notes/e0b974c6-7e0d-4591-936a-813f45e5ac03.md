# Extension parent scripts can collide on file-scope const names

The all-API-modules test failed with a SyntaxError when two loaded extension parent scripts declared const parserUtils at file scope. The landed fix uses var in ext-compose.js and current code keeps it. In this legacy shared script scope, check names across loaded modules before adding file-scope bindings; do not turn this scoped fix into a rule against const in modules or functions.

Scope: WebExtension parent script scope.
