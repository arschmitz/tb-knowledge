# Reject directory attachment URLs and check native temporary-file setup

The public attachment patch parses the URI once and rejects a file URL whose file is a directory before opening its channel. The current encoding caller catches attachment-fetch errors and reports a file-not-found exception. The native draft path now checks temporary-file creation, directory-query failure or a directory result, file-URL conversion and MIME-URI creation before keeping the attachment handle. The fixed source retains these checks. They establish these specific error boundaries, not complete attachment validation or a reproduced security outcome. Both assigned Bug and review are access denied; their rationale is unknown. No full-audit credit or runtime test.

Scope: Compose attachment error boundaries.
