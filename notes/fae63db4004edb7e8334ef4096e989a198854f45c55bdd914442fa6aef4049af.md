# Virtual folders must not bypass their Rename capability in the folder menu

The old folder-menu expression allowed isVirtual to bypass canRename. This change uses online && canRename and adds a unified Inbox to the menu-visibility test, both as the selected folder and as a right-click override. The rename shown list excludes that mode. The base getter already rejects SpecialUse folders; the existing focused Spam lesson covers that shared capability boundary. The new regression checks visible commands, not an attempted rename, persisted folder state or every protocol/extension entry point. New Folder was still shown for unified in this landing and was handled in a later separate follow-up.

Scope: Thunderbird folder command state.
