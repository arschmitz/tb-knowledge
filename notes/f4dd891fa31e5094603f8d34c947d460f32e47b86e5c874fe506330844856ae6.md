# The RNP Botan helper explicitly includes the header used by strlen

The owned compatibility change adds string.h in mem.cpp, whose hex_decode immediately uses strlen. Accepted RNP build metadata selects this file for the Botan backend. The other owned change is the file’s terminating newline; imported Botan bodies remain excluded. This is a direct include-dependency fact, not proof of compilation, cryptographic behavior or a general imported-code convention.

Scope: Thunderbird RNP Botan compatibility include.
