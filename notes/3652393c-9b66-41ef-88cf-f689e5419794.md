# Test extension script filters as a behavior matrix across API surfaces

The MV3 browser tests use parallel filter matrices for content, compose, and message-display scripts: absent filter, empty object, empty ID list, known ID, unknown ID, and mixed IDs. They assert returned details, exact errors, state after failed unregister, re-register, and final removal. This gives a concrete test pattern for Thunderbird wrappers around a shared upstream API. Files use browser_ext_<APIName>_mv3.js with API camelCase in this component; it is a scoped naming convention.
