# Card status localization and CSS use the same new/read/unread state

For real ThreadCard rows, the landing reads one properties set to select new/read/unread text and writes the same properties string to the dataset used by CSS. New and unread give the status image distinct Fluent IDs; read rows hide the image through a default display:none while preserving a status column. New icon CSS is nested under unread, so this is a scoped contract with the supplied property combination, not proof of all native flag states. The added test checks visibility and Fluent IDs, not a live tooltip or accessible-tree result.

Scope: Thread Cards status indicator.
