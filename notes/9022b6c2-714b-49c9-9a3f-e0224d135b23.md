# CalDAV free-busy requests turn scheduling XML and ICS into bounded intervals

CalDavCalendar.getFreeBusyIntervals:2123–2219 only proceeds when outbox/address
exist, this calendar is firstInRealm and calId has an accepted URI scheme. It
substitutes organizer address and creates actual CalDavFreeBusyRequest for the
requested interval. Missing prerequisites, request failure or bad recipient status
invoke listener.onResult(null,null). Success sends listener.onResult(null,intervals).
aBusyTypes is not used for filtering in this provider body. The operation returns
no cancel handle, so FreeBusyService cannot infer cancellability from the method name.
Reuse [service operation ownership](1723fcfd-17f6-4b34-828b-ad24adfb866f.md).

FreeBusyRequest:1102–1183 builds METHOD:REQUEST VCALENDAR/VFREEBUSY with generated
UID/stamp, UTC start/end, organizer and requested attendee. POST sets Originator
and Recipient. The actual response class retains requested range. Response:
1188–1257 reads recipient/request-status/calendar-data from scheduling XML, parses
ICS, skips failed/invalid recipient records and converts FREEBUSY periods. Period
end is a date or start+duration. Missing type defaults to BUSY; returned coverage
shorter than request adds UNKNOWN prefix/suffix. firstRecipient is the first
parsed dictionary entry, not a verified match to every requested recipient.

Direct test_caldav_requests.js:850–910 compares unfolded outgoing ICS, POST,
content type and Originator/Recipient. It checks recipient success and the exact
sequence UNKNOWN,FREE,BUSY,UNKNOWN plus interval boundaries, including a P7D
duration. This directly checks request serialization and response conversion.
It uses real request class and fixture XML but not every multi-recipient,
malformed status, busy-type filter, cancel or service timeout branch.
Provider/service and request-level null/failure results have distinct contracts.
The requests file did not reach these assertions in the installed build because
login-store setup failed. Static checked assertions do not imply a pass.
