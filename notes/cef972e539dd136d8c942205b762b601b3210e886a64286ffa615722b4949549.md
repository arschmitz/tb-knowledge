# The mailing-list avatar test reads CSS content rather than image src

The mailing-list avatar is supplied by CSS content through --icon-mail-list, while the component image src is cleared. The test follow-up therefore compares getComputedStyle(image).content to the icon URL; photo-card assertions continue to compare src. It also fixes the widget fixture chrome URL. These are scoped assertion/fixture corrections, not proof of image load or passing tests. The follow-up review has removed human context and keeps zero complete-audit credit.

Scope: Address-book avatar assertion contract.
