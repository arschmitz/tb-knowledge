# The runtime-context fixture uses an empty allowed_spaces list for all built-in spaces

The fixture adds allowed_spaces: [] to its action. The accepted action handler expands an empty array to mail, addressbook, calendar, tasks, chat, settings and default. It does not mean that the action is allowed nowhere. This is an explicit fixture setting and checked consumer contract; it does not establish live toolbar placement or completion of the options-page load.

Scope: WebExtension runtime context test fixture.
