# Password tree editing restores display reload only after the awaited update fulfills

The edit helper changes the visible login object, sets reloadDisplay=false, awaits modifyLoginAsync and then restores true and invalidates the row. The storage observer checks that same flag. No local finally restores it after rejection, so the inspected failure path can retain suppression. The previous synchronous path also lacked restoration on a throw. No failure or UI result was reproduced.

Scope: Password-manager edit error boundary.
