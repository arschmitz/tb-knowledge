# Panorama date-group predicates differ at local-midnight boundaries

Initial grouped selection obtains dateGroup from SQL; incremental add/remove recomputes it in JavaScript. The test helper stores Date milliseconds multiplied by 1000, while native Message dates use PRTime and CreateJSMessage divides by PR_USEC_PER_MSEC before creating the JavaScript Date. JS resets local hours/minutes/seconds/milliseconds to midnight and uses date > now; the native SQL helper builds local midnight with PR_LocalTimeParameters and uses date >= mToday, with inclusive earlier cutoffs. For equivalent instants under the same stable local timezone and day, exact-midnight predicates differ. Both the historical and fixed comparison retain that strict/inclusive difference. Native timezone/Date implementations were not independently paired, and clock or timezone changes were not exercised; no actual UI mismatch is claimed. Changed tests use ordinary relative dates without exact-midnight equivalence assertions. The separate future-threshold units lesson remains separate.

Scope: Panorama date-group boundary contract.
