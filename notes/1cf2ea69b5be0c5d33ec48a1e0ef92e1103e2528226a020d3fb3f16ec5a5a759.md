# Use named Fluent variables for locale-controlled widget order

The recurrence Fluent strings contain only variables whose values are DOM IDs. Localization notes allow reordering and require the article placeholder in a specific position when unused. Supported component pattern: named lowerCamel object keys in JavaScript, dashed Fluent message IDs and dashed recurrence widget IDs. Translate labels through Fluent attributes, but do not translate the passed DOM IDs or add words to an order string. No repository-wide ID casing rule follows from this dialog. This note is based on source inspection. Tests were not run, and full review discussion remains pending.

Scope: calendar/locales/en-US.
