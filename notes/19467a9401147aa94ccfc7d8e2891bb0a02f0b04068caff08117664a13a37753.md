# Use the attribute callback values when propagating notification state

918 makes attributeChangedCallback accept oldValue and newValue and uses newValue for text, URLs and IDs. connectedCallback supplies the current attribute value when it initializes the shadow tree. The accepted source still follows that contract and uses oldValue to replace type classes. Keep the callback and its manual initialization calls consistent; do not read a later attribute state in place of the supplied transition value.

Scope: Notification attribute transition values.
