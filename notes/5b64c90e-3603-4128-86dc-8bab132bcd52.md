# Strip conditional CSS from the parsed message DOM

When sanitizing HTML mail, remove conditional CSS from the already parsed document before serialization. Running a parser utility over serialized HTML caused redundant DOM parsing; the regression test keeps unconditional CSS intact.

Scope: mime.
