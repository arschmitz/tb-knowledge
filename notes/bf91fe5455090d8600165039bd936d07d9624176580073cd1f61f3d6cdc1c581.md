# Detached external signing checks the resolved signature before handling failure

This landing awaits GPGME.signDetached before checking its result in RNP.encryptAndOrSign's external sign-only branch. The async helper resolves to a signature string or null and may reject on validation/setup failures. Await makes the local falsy guard observe the resolved value; the old outer async return already adopted the Promise, so this is not evidence that every successful call previously returned a raw Promise to the final consumer. Combined sign/encrypt already awaits GPGME.sign. Later accepted source retains the await and adds separate key-selection work. This is a bounded async caller contract, not a global style rule, native signing result or guarantee about every error/resource path.

Scope: OpenPGP external signing.
