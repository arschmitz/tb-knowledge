# Guard each optional signature sink during nested MIME processing

When nested decryption ignores outer MIME part1, the request handler calls both S/MIME and OpenPGP status sinks when present. The channel and each sink can be absent, so the patch guards each sink separately. A present OpenPGP sink clears status already received from that part and filters later status. These calls suppress outer status; they do not authenticate the ignored signature. The author reports that a missing S/MIME sink stopped attachment and reply processing and proposes a separate automated test. This study checked the source and full discussion, not a decrypt/sign operation or attachment runtime.

Scope: Nested OpenPGP MIME status sinks.
