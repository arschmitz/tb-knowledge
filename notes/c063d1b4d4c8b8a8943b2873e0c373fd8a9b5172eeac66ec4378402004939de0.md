# Report corrupt local storage separately from ordinary write failure

The compaction fix uses compactFolderStorageCorruption for malformed local mbox rather than the generic compactFolderWriteFailed message. Current dispatch keeps disk-full, busy, malformed-storage and catch-all branches separate. Use the cause that the parser actually reports and a message that describes unexpected stored data. This is a scoped error-message recommendation, not a claim that the data can be repaired locally. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Compaction error classification.
