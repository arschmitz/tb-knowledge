# Keep new-tab handling within the content actor’s navigation policy

The relaxed actor opens an absent target in a new tab; the single-site actor allows its own host or base domain and sends other exposed web links externally; the strict actor permits the same document ignoring fragment before applying target handling. specialTabs maps linkHandler to the corresponding message-manager group. Keep these policy dimensions distinct when adding a target case, rather than assuming _blank always means a Thunderbird content tab. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Content actor navigation policy.
