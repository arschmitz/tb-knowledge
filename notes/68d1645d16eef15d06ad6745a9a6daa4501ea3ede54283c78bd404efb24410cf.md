# The initial fake folder-ID move misses item and map updates

The original unstable-ID branch passes a RemoteFolder object to a helper whose item lookup compares parentId with a string folder ID. It then leaves the folder lookup map under the old key after changing the object ID. Accepted code queries items using the old string ID before replacement and deletes/sets the map keys. This proves a bounded mock-state difference, not a real Graph identity guarantee or executed move failure.

Scope: Shared Exchange mock-server folder identity.
