# Use distinct detached input and live output variables for AttachHdr

The original local-copy conversion passed newHdr both as the input and through getter_AddRefs(newHdr). Full Bug 1952094comment18 reports that this produced a null input on Windows, while the precise platform difference remained unexplained. Fixed callers use separate detached/live variables before updating state. Follow the interface conversion contract even when Mork returns the same object. D251248also explicitly reverses the initial refusal to add checks and adds them before reacceptance. This is static source plus attributed historical failure evidence; no Windows or copy test ran.

Scope: Detached-to-live header caller identity.
