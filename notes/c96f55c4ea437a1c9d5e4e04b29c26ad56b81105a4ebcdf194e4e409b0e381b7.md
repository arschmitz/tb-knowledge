# Account Hub select widgets emit change while text fields emit input

Current manual forms attach input listeners to hostname, username and port fields and change listeners to authentication/security/protocol selects. The accepted outgoing form has its own username listener, unlike the duplicated hostname listener in the initial 1258 diff. A scoped recommendation is to audit the exact event and field when adding a listener; copying a nearby registration can leave the intended field disconnected. This does not define events for legacy XUL menus. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mail/components/accountcreation.
