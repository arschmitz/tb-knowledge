# Current outgoing completion differs from the original start-resolved request promise

Historical 1367 resolves its production requestPromise from onSendStart, while its unit PromiseMsgOutgoingListener already resolves from onSendStop. Accepted production code normally settles from onSendStop after delivery cleanup; the nsMsgSendUnsent branch returns early with a sendLater promise limitation. onSendStart retains the request and applies early cancellation. Some accepted comments still say the promise resolves on start or merely provides a request. Preserve the actual current settlement boundary when reviewing callers and update stale comments rather than teaching the original start-resolved contract.
