# LocalizeMessage formats named UTF-8 string arguments synchronously

LocalizeMessage maps UTF-8 string/string pairs into named L10nArgs and calls FormatValueSync. Callers supply an initialized resource and an output string; the helper propagates formatting failure as nsresult. Its signature does not accept numeric argument variants. LogJunkHit converts decoded author, subject and date to UTF-8 and separately passes the message ID and folder URI for a move record. This is a static comm caller/helper contract; engine formatting, generated locales and log output were not executed.

Scope: Native Fluent formatting.
