# A deferred Exchange message listener owns its header array

ExchangeSimpleMessageListener clones the incoming array into a const member and passes that member to its later success callback. RefPtr elements keep headers alive, while cloning keeps the array itself alive after the caller returns. Owning self, folders or a copy listener does not extend a borrowed array reference lifetime. This applies to this deferred listener family; it does not require copying every synchronous argument. Static source only; no lifetime test ran.

Scope: Exchange deferred listener ownership.
