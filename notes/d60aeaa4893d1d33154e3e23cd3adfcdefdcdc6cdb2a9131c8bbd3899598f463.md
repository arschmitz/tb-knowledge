# Quoted-printable chunk decoding combines pending bytes before in-place output

This landing handles pending quoted-printable bytes in a temporary buffer sized for the pending bytes plus the current input, checks the combined length and clears token_size before re-entering the decoder. The output callback runs before the temporary buffer is freed. This pairs the capacity explanation with the actual chunk state and draft/leaf consumers. The two new converter tests compare selected split outputs and check draft/filter completion; they do not directly assert allocation failure, every chunk partition, raw EOF flushing or memory bounds. Fixed source later normalizes Windows line endings in the test, which is a separate repair. No test or sanitizer was run.

Scope: MIME quoted-printable decoder.
