# Use instant scrolling when a UI test immediately acts on the target

1263 explicitly adds behavior: "instant" to scroll calls across Calendar and mail tests before clicks or other assertions. Accepted CalendarTestUtils retains it. A scoped test recommendation is to keep that explicit behavior while preserving each call’s block alignment; smooth scrolling can leave the target moving during immediate input. This does not require instant product scrolling and does not prove every reported timeout was fixed. This is source and test inspection only. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
