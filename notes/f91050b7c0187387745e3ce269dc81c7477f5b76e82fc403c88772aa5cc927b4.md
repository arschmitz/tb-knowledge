# Disabling a chat protocol hides setup choices while retaining a local failure path for existing accounts

This Odnoklassniki landing sets its disable preference to true. The inspected core filters that preference from getProtocols, and the setup wizard builds choices from that list. Direct registered-protocol lookup remains available for existing accounts; the account module now reports a localized error and then disconnected instead of constructing an XMPP session. The fixed accepted code retains these scoped contracts. This establishes local behavior only; no remote gateway or live connection was tested.

Scope: chat protocol lifecycle.
