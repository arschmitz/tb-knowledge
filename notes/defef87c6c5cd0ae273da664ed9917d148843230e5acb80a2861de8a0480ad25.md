# The fitted-image correction stops forcing automatic height and permits equality in its test

For fitted overflowing images, the patch replaces block-size:auto!important with object-fit:scale-down. The enlarged state keeps its separate size resets. The changed browser assertion uses lessOrEqual for clientHeight versus naturalHeight, so equality now passes despite the retained shrink wording. This records the exact CSS and test contracts; it does not establish pixel-perfect aspect ratios or a successful browser run.

Scope: message-reader/image-fitting-height.
