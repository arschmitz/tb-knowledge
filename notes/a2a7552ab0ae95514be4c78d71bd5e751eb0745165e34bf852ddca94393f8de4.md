# Spacing tokens separate a fixed step from a density-dependent base

spacings.css defines a fixed 3 px --space-step and a --space-base of 3/6/9 px for compact/normal/touch. Expressions can use the fixed step for density-independent values and the base for density-dependent gaps. UIDensity writes compact/touch on registered window roots and removes the attribute for normal mode. The Calendar application is a separate patch; packaging these tokens alone does not prove a visual change. This is a scoped source contract, not a global spacing rule.

Scope: Calendar dialog spacing.
