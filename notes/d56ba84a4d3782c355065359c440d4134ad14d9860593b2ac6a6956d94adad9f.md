# The CalDAV UTF-16 fixtures advertise encoding in two places

The two UTF-16 fixtures set text/xml; charset=utf-16 and also include an XML encoding="utf-16" declaration. Their comments and task documentation say the charset is only advertised in the header. Correct that wording or add a genuine header-only fixture. The existing cases still exercise decoded Japanese text and parsed XML/log content; they do not separately establish mismatch precedence or absent-declaration behavior.

Scope: CalDAV encoding test limits and comments.
