# Recheck route state after subview events

For Bug 2061760 at recorded revision 0a87f64f19c661a55de5cf627700e9127899aeae, the AI report identifies route replacement during navigation as a cause of focus moving to an obsolete control. It reports rechecking whether the route is still current after subview events and restoring focus when replacing a focused Back control. This is a scoped interaction hazard in the event dialog, not a general requirement for operation identifiers. Regression coverage reportedly passed; no landed diff is supplied.
