# Treat a missing selected message as the current null result

The accepted selected-header getter returns NS_OK with a null output when no row is selected; an expanded grouped dummy header also returns null. This is newer than the landing-era failure result for no selection. The about3Pane ignored-thread callback reads ?.messageKey. Use the current nullable contract when updating callers, not the old failure-only assumption. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check was run.
