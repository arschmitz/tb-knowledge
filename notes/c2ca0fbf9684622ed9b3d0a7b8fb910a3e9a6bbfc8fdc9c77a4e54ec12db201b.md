# Manual-form completion is calculated before dependent port adjustment

Security-change and debounced-port handlers start configChanged before adjusting the dependent field. configChanged captures errors and computes completed before emitting its event, even when notification rendering yields first. The parent uses that Boolean to enable the forward action. If an invalid port error is visible and the stored standard port lets a later SSL adjustment replace it with993, that event can still describe the earlier invalid capture; this path has no explicit second validation update. A focused test should inspect completion/footer state after the automatic correction rather than only the displayed port. This is a concrete static ordering trace, not a reproduced UI failure or a runtime timing guarantee.

Scope: Account Hub validation notification and automatic field updates.
