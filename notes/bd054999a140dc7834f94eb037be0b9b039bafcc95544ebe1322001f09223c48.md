# Reuse a loading preferences tab without calling selectPrefPane yet

preferencesTabType.shouldSwitchTo returns -1 only when it has no existing tab. If an existing tab is still loading, it skips selectPrefPane but still returns that tab’s index, so tabmail can select and reuse it. openTab initializes pageLoaded to false and changes it to true when the initial paneSelected event arrives. The loading-time request is not queued for later pane navigation by this branch. Once loaded, pane selection starts through an async function that this synchronous index-returning hook does not await. Keep tab reuse, document readiness and pane-selection completion distinct; no spaces-toolbar or timing test was run in this study.

Scope: mail/preferences/tab-lifecycle.
