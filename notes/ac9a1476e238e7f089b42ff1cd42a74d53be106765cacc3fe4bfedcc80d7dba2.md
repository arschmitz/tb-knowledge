# The upload storage poll resolves without proving that storage became ready

The new part path awaits retryUntilSuccessOrTimeout before creating metadata. That helper returns on a truthy callback, but also falls through after its timed loop and catches callback errors. The caller does not distinguish those outcomes. Awaiting this helper therefore does not establish a nonzero stored size. Exact accepted source retains this helper/caller contract, with later chunk handling kept separate. This is static source evidence; no timeout, upload or backend failure was run.

Scope: Thundermail generated upload polling and caller completion.
