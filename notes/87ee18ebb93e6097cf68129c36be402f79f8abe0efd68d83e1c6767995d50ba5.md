# Invalid view rows return an empty URI before folder lookup

GetURIForViewIndex clears the result and returns success for none, out-of-range or dummy indices and for an absent folder. The junk consumer now finds or skips rows by checking that URI value. Usable rows still forward the folder URI-generation result, so the change does not make all backend errors impossible. The first-selected helper also retains its null output-pointer guard; only the checked callers pass known valid local addresses. No runtime junk or crash result is established.

Scope: Message view URI and junk classification.
