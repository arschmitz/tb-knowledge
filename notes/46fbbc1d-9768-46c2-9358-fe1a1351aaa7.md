# Send a CardDAV update only when server data changed

A local-only address book property such as PopularityIndex must not trigger a CardDAV PUT. The synchronous modifyCard entry point compares old and new _vCard values, then starts asynchronous server work only when the vCard changed.

Scope: CardDAV address books.
