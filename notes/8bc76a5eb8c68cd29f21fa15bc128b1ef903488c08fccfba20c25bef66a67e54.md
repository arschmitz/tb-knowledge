# Avoid redundant reloads when restoring an unchanged selection

Current restoreSelection batches DB updates, compares rowCount and selected indices with the pre-restore state, and suppresses a select event when no meaningful change occurred. notify=false also avoids scrolling; discard=false retains state and refreshes rowCount. Preserve these side effects when extracting a helper; selection equality alone is not the complete restore contract.

Scope: view.
