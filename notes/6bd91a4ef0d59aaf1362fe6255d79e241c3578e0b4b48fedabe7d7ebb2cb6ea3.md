# CalDAV XML responses preserve raw chunks until charset decoding

Simple CalDAV responses use the HTTP channel contentCharset with a UTF-8 fallback. The XML handler instead stores raw byte chunks, concatenates them and then decodes using the recorded channel charset. Each new chunk invalidates the decoded cache; reset clears chunks, channel and cache. This removes the old per-chunk UTF-8 assumption. The source does not establish support for every encoding label, malformed input or split boundary without dedicated tests.

Scope: CalDAV response byte decoding.
