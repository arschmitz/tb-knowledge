# Compose shared close-button classes with local logical positioning

The shortcut dialog composes button, button-flat, button-round, icon-button, icon-only and modal-close-button. Shared widgets define round geometry and modal icon centering; local shortcut CSS only positions #close using inset-inline-end and inset-block-start. For similar consumers of these widgets, reuse the shared role/modifier classes and leave local placement in the component stylesheet. The class set is a source pattern, not a newly approved project-wide selector policy. This is static source evidence. No runtime, build or accessibility session was run. Full bug and review discussion remains pending.

Scope: Shared modal button composition.
