# Graph address headers reuse Mailbox formatting while null-field cases remain separate from quote coverage

The owned Graph converter delegates From/Sender and recipient-list rendering to the shared Mailbox Display implementation. That implementation encodes a supplied name through mail_builder and can also render a bare address or empty text from optional values. Getter success with null fields differs from a failed/missing getter; filter_map removes None conversion results but retains Some(empty string). The changed shared EWS/Graph test requires quoted To/Cc text for populated simple ASCII names. It does not cover null fields, embedded special characters, every locale or complete RFC compliance. The exact formatter window matches the original and fixed endpoint; model/caller phases remain separate.

Scope: Graph recipient header rendering.
