# Account Hub creates only checked enabled sync address books

The sync widget captures checked enabled input URLs and filters the available address-book objects by url.href. The forward handler calls create on that returned list. The patch also breaks after account selection initializes the sync view, so merely choosing an account does not run the forward action. Original tests assert create counts for all, one and zero selected books; this checks selection dispatch, not asynchronous create completion. Fixed accepted code later awaits create and opens the address book. The complete assigned review is reconciled in the private audit. No browser test ran.

Scope: Account Hub address book selection.
