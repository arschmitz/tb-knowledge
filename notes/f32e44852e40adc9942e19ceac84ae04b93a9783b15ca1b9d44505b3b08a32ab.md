# Keep an update badge independent of the open application menu

744 removes the badge clear from the branch for an already shown or open application menu. That branch dismisses doorhangers and updates the banner, while the focused-window branch and the no-notifications branch still have their own clear behavior. Do not fix badge persistence by removing every clear call. This establishes separate banner, doorhanger and badge state, without a live notification or accessibility announcement check.

Scope: Application menu notification state.
