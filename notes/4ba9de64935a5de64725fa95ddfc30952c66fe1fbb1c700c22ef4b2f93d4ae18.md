# Encrypted-URI cleanup tests check both captured identities after account removal

These new tasks capture message and derived network URI strings before removing their dedicated account, confirm that the network URI can no longer be derived, call the cleanup function directly and assert both service entries are gone. They ignore a thrown cleanup exception and test final membership, so they do not separately assert a normal return or automatic navigation/unload handling. Later accepted tasks add surviving-message display checks as another phase. The original setup executes fixture decryption support, not a new cryptographic-validity test, and no browser test ran.

Scope: OpenPGP and S/MIME cleanup regression assertions.
