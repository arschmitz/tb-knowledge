# Calendar batch completion includes awaited cache writes and cache callbacks

ICS adoptItem and modifyItem await their optional cached-calendar callback before endBatch runs in finally. The actual cache callback awaits its local write. The original refill loop also awaits each cache addition before ending its batch; accepted later code awaits allSettled additions and logs individual rejection instead. Keep those phases and error boundaries separate. This establishes source ordering, not transaction atomicity or complete failure/cancellation settlement.

Scope: ICS and cached Calendar write completion.
