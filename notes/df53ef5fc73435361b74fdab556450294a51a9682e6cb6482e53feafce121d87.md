# Star notification actions are offered for a single message

The fixed notification manager installs valid actions only when exactly one new message is represented. mark-as-starred calls the folder flagging API. Click handling records the used-action counter before dispatching the action. The added mocked test checks the offered IDs, resulting flagged state and counters; that does not validate a native notification button or accessibility. Preserve the stable action ID and localization family when extending this list. No notification task ran.
