# Read calendar file bytes before detecting their character encoding

CalIcsParser.parseFromStream now reads an unconverted byte string and detects its charset with MailStringUtils.detectCharset, decodes it with byteStringToString and then parses calendar text. MailStringUtils recognizes byte-order marks before using its encoding detector. CalIcsImporter delegates to that parser rather than forcing UTF-8 through a converter input stream. Preserve the bytes until the decoding decision. This tolerant import behavior does not mean all legacy encodings are preferred for newly written ICS files.

Scope: calendar/base/src.
