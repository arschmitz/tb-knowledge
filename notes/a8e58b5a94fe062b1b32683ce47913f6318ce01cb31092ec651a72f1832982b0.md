# Document action and callback completion in helper names

promiseSubDialog returns only after open,focus,awaited callback,and close. Its buttonNameOrID parameter names the two supported namespaces. Keep helpers named and documented for the completion they actually promise; a getter-like name would hide the UI actions. This is a scoped proposed manual naming rule supported by the accepted helper, not a lint rule.

Scope: testhelpers.
