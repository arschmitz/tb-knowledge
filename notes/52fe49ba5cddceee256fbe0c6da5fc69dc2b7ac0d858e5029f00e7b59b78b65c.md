# NNTP no-such-newsgroup status uses the folder localized name as a named Fluent argument

For the 411 response, NntpClient supplies the folder localizedName as newsgroup to no-such-newsgroup, then ends the request with NS_ERROR_FAILURE. The status helper formats that named Fluent message and wraps it with the server prettyName before reporting feedback. Folder and server receivers therefore keep different property contracts; this one-line repair is not a global prettyName rename. No NNTP request, translated display or status callback was executed.

Scope: NNTP status producer and localization consumer.
