# The initial EWS OAuth patch uses typed macro names and concrete collection names

In this reviewed initial landing, DEFINE_PREF_STRING_PROPERTY names the string-only getter/setter macro; the Boolean property stays explicit. Rust keeps the concrete name parameter_override_values when converting the collection to ThinVec, rather than the earlier ps name. Separate IDL property comments have blank lines. These adopted choices expose type and role in the affected code; they do not define a repository-wide macro, variable or spacing rule. The original undef still uses a different macro name, and the later accepted shared Exchange implementation replaces this macro. Historical review adoption does not prove the entire implementation or documentation is correct.

Scope: EWS OAuth C++ and Rust local naming and readability.
