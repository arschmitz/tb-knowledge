# Use the view string names that match their current storage role

The 2024 view strings use kHighestPriorityString and other k-prefixed nsString globals. Accepted nsMsgDBView uses sHighestPriorityString and related s-prefixed StaticAutoPtr fields, while instance state keeps m-prefixed names. These are mutable class-wide string caches, not a tree-wide naming rule for constants. For additions in this view family, follow the accepted s-prefixed cache fields and update declarations, initialization and dereferences together. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.

Scope: mailnews/base/src.
