# Use the shared disabled text token for disabled menu states

852 ports context menu and Linux menubar disabled colors to --text-color-disabled. The accepted context rule covers disabled hover and checked-disabled states and keeps their background transparent. Reuse the shared state token instead of a panel-specific foreground name. This is a scoped semantic token rule, not proof of live disabled contrast or native accessibility behavior.

Scope: Disabled menu color token naming.
