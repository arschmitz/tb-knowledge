# Change the smiley localization key when correcting its label

The Angry smiley keeps character128544 but changes its visible label from Yell to Angry. Review requires a new localization key, and the landed/fixed DTD and mail/Calendar menu consumers use smiley17Cmd.label rather than smiley10Cmd.label. Keep the label meaning, key and actual command value distinct. This source supports the exact DTD correction; other locales, rendered emoji and command execution were not checked.

Scope: Change the smiley localization key when correcting its label.
