# Treat the EWS root as required and optional special folders separately

The root response is processed and validated before any other distinguished folder. Any root failure propagates because child parent relationships need that ID. For the remaining folders, accepted code skips ErrorFolderNotFound and ErrorSchemaValidation and propagates other errors. The latter exception is broader than the original missing-folder-only landing. Keep this exact classification when adding error handling; skipping arbitrary root or optional-folder failures is not supported by this source. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: EWS required and optional folder errors.
