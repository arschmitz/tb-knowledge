# The MIME regression checks the related HTML body in two API results

The owned regression expectations change the unnamed Content-ID HTML part in invite.eml from an empty attachment name to a body in getFull, and add the same RELATED HTML body to listInlineTextParts. The existing named calendar attachment stays in the complete-tree expectation. Strict deep assertions check these returned structures; the separate new plain-text task checks API counts and skips IMAP. These are source assertions, not an executed parser or a guarantee for every MIME form.

Scope: Extension MIME body regression coverage.
