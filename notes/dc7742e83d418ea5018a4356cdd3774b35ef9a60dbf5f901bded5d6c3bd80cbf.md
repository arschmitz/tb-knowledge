# OpenPGP key-attachment default and existing identity migration are separate writes

The original change turns mail.identity.default.attachPgpKey off and writes attachPgpKey=false to every identity for existing profile versions below 59. Stored version zero is treated as a new profile and skips old migration blocks. This resets stored true values as well as supplying the new default. It does not remove the identity control or change attachment logic; the user can re-enable the preference. Accepted source retains the loop under a later migration version. These are static source facts, without a migration or crypto run.

Scope: openpgp-preferences.
