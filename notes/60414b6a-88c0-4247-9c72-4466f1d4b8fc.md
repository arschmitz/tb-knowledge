# Use the Address Book adapter for directory and search rows

D208448 moved the former ABView behavior into AddrBookDataAdapter, a TreeDataAdapter subclass. It can enumerate one directory or all address books, search those directories, sort card rows, and expose the contact and owning directory for a selected row. It implements directory-search and observer interfaces so the view reacts to contact/list changes. The former abView-new.js script was removed and the XHTML loads the module. Current code retains this adapter, though its search and row update logic evolved.

Scope: Address Book architecture.
