# Reset cached row geometry on both font and density changes

Current address-book card and table rows call updateRowHeight on font-size and density events, then reset the list. CSS row gaps also depend on compact, normal and touch density. Changing only CSS spacing can leave virtual row geometry stale. Current tests check actual contact-list heights across density changes, including 22-pixel normal and 32-pixel touch rows. A font-size round-trip test and live zoom/focus checks were not inspected or run.

Scope: mail/components/addrbook.
