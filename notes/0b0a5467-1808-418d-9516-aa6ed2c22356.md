# Use headless Playwright for local web checks

For Commands local Storybook or web UI checks, `iab` being unavailable does not establish that browser validation is blocked. The recorded `launchReviewBrowser()` path can start headless Playwright Chromium. It does not supply Phabricator authentication, and Chromium cannot validate Thunderbird chrome UI; that requires a matching Thunderbird headless harness. The recorded focused tests passed.

Scope: console browser validation.
