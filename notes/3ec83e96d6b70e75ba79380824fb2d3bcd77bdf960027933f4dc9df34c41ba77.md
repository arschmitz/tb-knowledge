# Removing CalDAV verbose guards adds argument and auxiliary-string work without replacing parser input

The removed verboseLogging wrappers previously skipped selected map/join and feature-list arguments; those arguments are now evaluated before debug. The SAX-style handlers also accumulate logXML without those guards. Their actual parser input is the separate _xmlString response buffer. A later accepted sync test directly checks non-ASCII text in logXML, so the field cannot be called unused from a search limited to its implementation file. Serialization in getSerializedItem was already required for the returned payload. The accepted charset-aware buffer rewrite is a separate later phase; no speed, memory or output result was measured.

Scope: Calendar CalDAV diagnostics and response state.
