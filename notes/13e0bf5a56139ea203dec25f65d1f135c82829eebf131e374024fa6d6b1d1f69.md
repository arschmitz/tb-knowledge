# Use domain labels for the Microsoft OAuth host family

926 registers office365.com, outlook.com and hotmail.com instead of a few named service hosts. The accepted built-in lookup lowercases the hostname and strips one complete leftmost label at a time, so a base-domain entry serves its subdomains without arbitrary substring matching. Existing tests cover one and two subdomain levels. This is provider lookup behavior, not evidence that a login or token request succeeded.

Scope: OAuth provider domain lookup.
