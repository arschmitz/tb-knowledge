# The auth-option assertion reverses its expected-visibility message

checkAuthMethods computes hide for an option that is not allowed by the protocol and compares that Boolean with item.hidden. Its message adds NOT when hide is true, so the stated expectation is opposite to the checked result. The message already contains should. Preserve this diagnostic mismatch separately from the patch's frame wait and removed setup click; no assertion or visibility failure was executed.

Scope: Account Hub browser-test assertion diagnostics.
