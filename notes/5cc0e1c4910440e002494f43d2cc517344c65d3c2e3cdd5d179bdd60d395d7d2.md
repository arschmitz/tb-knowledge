# The interrupted-move test selects an existing database header instead of calculating its key from a UID

The test now obtains its message from the inbox.messages enumerator instead of subtracting from the server UID counter and passing that number to getMsgHdrForKey. The actual API enumerates current database messages. This removes that test's numeric UID-to-key assumption without defining a general enumeration order or proving backend key independence. No IMAP or move test ran.

Scope: IMAP test message selection.
