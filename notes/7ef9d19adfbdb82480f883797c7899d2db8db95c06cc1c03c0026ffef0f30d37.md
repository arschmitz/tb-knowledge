# Calendar scheduling comparisons preserve configured address casing

The CalDAV organizer identity keeps the configured email casing and includes the mailto prefix, including ACL-owner identities. Scheduling consumers compare lowercase copies: attendee id and SENT-BY lookup returns the original matching attendee objects, and delegation lookup resolves display names across case differences. The added tests check mixed-case organizer values and these helper results. This is scoped Calendar behavior, not a global rule for email storage or proof that every server/client scheduling route avoids duplicate delivery.

Scope: Calendar scheduling identity matching.
