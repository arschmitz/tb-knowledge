# Restoring the last Calendar view now enters the normal switch path

The moved getter reads the persisted selected index or defaults to week, then invokes switchCalendarView before returning its cached type. The wrapper sets that cache before any mode switch, while the mode consumer requests the cached type and calls switchToView. The cache prevents the first-read path from repeating on every getter call. This is a local ownership and initialization change, not an unchanged move; no malformed-index, restart or mode-transition test ran. The separate later visibility deletion is not credited to this original patch.

Scope: Calendar selected-view cache and initialization.
