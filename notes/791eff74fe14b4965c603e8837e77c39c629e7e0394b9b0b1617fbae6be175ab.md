# Account Central's About test covers the legacy empty-folder page

The page now loads mailCore.js, which supplies openAboutDialog to its existing release-notes control. The helper focuses an existing About window or opens the About dialog. The testFirstRun task explicitly loads Account Central with an empty folderURI and checks the About window; its name does not make it an Account Hub startup test. The same file's final POP3 Inbox assertion lacks a message, which is separate from its direct destination coverage.
