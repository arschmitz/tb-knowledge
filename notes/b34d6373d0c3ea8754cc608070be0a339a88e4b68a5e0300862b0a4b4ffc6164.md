# Folder menu start cropping has a scoped direction-specific isolation workaround

The folder-menu stylesheet wraps start-cropped value labels and descriptions in isolation controls. The default branch uses LTR isolation; the RTL locale branch uses RTL isolation. This is an accepted local workaround for the stated punctuation-order problem. Its upstream correctness and rendered behavior were not verified, so it does not establish a general bidi or accessibility rule.

Scope: folder-menu-start-crop-isolation.
