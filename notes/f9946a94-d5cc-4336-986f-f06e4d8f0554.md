# Put test action options before expected-result options

For a helper that performs an action and verifies the result, group action modifiers before expected-event/result arguments. D203232 explicitly requested this for widget click helpers. The review suggested undefined when skipping a defaulted argument, but accepted and current call sites still use {}; treat that part as a proposed readability preference, not an established invariant. Name counts as number or count and arrays by their items, rather than calling discrete rows an amount.

Scope: syntax test helper signatures.
