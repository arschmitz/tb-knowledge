# Use focused helpers for Calendar Save readability

For D332899 at source revision 269f878aab01978ea1f5295133e3ecba8591a0cb, the author requested smaller helpers to make nested dialog logic and the large Save function easier to follow. The AI reports separating dialog rendering and lifecycle tasks, and splitting Save into field validation, calendar validation, and event creation helpers while preserving request checks and transaction order. This is scoped author intent for these two modules, not a general helper layout rule. The changes were reported applied but not individually accepted. Simulated comparisons and static checks were reported successful; native tests did not start, so native focus, accessibility, and runtime behavior remain unverified.
