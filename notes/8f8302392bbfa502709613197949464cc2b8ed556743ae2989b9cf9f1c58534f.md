# Historical auto-unsubscribe prevented cleanup from saving a removed news database

The historical unavailable-group path passes the folder name to a confirmation helper and clears _newsGroup only when removal was confirmed. _actionDone then skips cleanUp, which would otherwise notify, commit and close that database. At the fixed revision, missing-group handling instead reports status and finishes failure; that old auto-unsubscribe method is no longer the current path. Preserve this chronology rather than teaching the old prompt as current policy. Later removal rationale and external database behavior remain gaps. No unsubscribe ran.

Scope: NNTP group cleanup lifetime.
