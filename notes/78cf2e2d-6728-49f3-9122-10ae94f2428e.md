# Use a method for notification cache updates with side effects

In D210183, the reviewer asked if cache access should use a getter and setter. The author kept explicit updateNotifications/getNotifications methods because updates would gain side effects, and the review accepted that answer. In this component, prefer a named method when a write also persists state or notifies other code; do not hide those effects behind property syntax.

Scope: in-app notification syntax.
