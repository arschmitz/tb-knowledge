# Keep restored MIME class-tree comments aligned with the real base structs

1102 restores abstract MimeMultipart, MimeMultipartSigned, MimeEncrypted and MimeLeaf nodes in the include-side hierarchy without adding unused includes. Current MimeMultipart embeds MimeContainer, while MimeLeaf embeds MimeObject and provides transfer-decoding before decoded-buffer/line processing. Keep the documentation nodes when an include is removed so the diagram still describes the inheritance chain. This is scoped legacy MIME documentation, not a recommendation to make new C++ classes with this pattern.

Scope: Legacy MIME inheritance documentation.
