# Application lifetime changes metric retention configuration, while later observers update preference values

This landing adds lifetime: application to the Boolean and integer preference metric definitions without changing their producers or tests. Original MailGlue source reports typed preference values during startup telemetry. Fixed accepted MailGlue later registers observers that update those metrics when tracked preferences change. Keep that later producer behavior separate from the YAML-only retention change, and retain the integer metric labeled_string type. The expected Glean retention and ping effect is attributed historical rationale; no paired SDK or live ping was checked.

Scope: Preference telemetry definition and producer phases.
