# Dark message text uses a semantic token under two explicit conditions

The landing replaces white text with color-text-base-dark only when the dark color scheme and mail.dark-reader.enabled both match. It keeps the same dark background. The fixed accepted selector retains that token role, while the current palette resolves the token to #f7f7f8. Preserve token identity separately from historical/current RGB values and later test expectations; no computed color, contrast or accessibility result is inferred.

Scope: Message reader dark styling.
