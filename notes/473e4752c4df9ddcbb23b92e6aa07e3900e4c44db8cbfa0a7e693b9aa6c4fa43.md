# The macOS GPU helper uses separate packaging, duplicate and signing declarations

The installer passes MOZ_GPU_PROCESS_NAME to the manifest preprocessor and includes its .app under XP_MACOSX. The duplicate list names GPU helper metadata and executable paths; it does not create them. Two signing groups include gpu-helper.app. In the inspected accepted source one group is marked as signed without entitlements and the other uses utility.xml. No generated package, signing worker or native GPU launch was tested, and the upstream process-name value remains unpaired.

Scope: Mail macOS packaging.
