# Keep header timestamp extraction separate from fallback and storage units

Entry2184 adds an explicitly incomplete ParseMsgHeaders producer. It assigns Date only after successful parsing and leaves received-time and mbox/current-time fallback work unfinished. The same patch changes RawHdr.dateReceived to PRTime and converts a nonzero value to stored uint32 seconds. The fixed ParseRawMailHeaders contract still leaves timestamp fallbacks to its caller; current AddMessageBatch2 supplies PR_Now when the extracted date is zero. Keep extraction, caller policy and storage conversion separate. This does not credit the initial patch with later parser fields or complete protocol decoupling. Static inspection only.

Scope: Mail header extraction.
