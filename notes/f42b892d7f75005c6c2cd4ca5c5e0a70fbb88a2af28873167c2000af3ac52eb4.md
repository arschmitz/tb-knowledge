# Address-book result tests wait for pending Fluent mutations before checking status text

checkSearchResults becomes async and its callers await it. After row checks, the helper waits for L10nMutationsFinished only when the document reports pending localization mutations. It then asserts the expected zero, singular or plural status value. Row-name assertions are separate and still lack a message. This source shows the intended synchronization and assertions; it does not establish a passing run or every locale.

Scope: Address-book search browser tests.
