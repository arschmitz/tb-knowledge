# Compose locks restore only the controls marked disabledForSend

updateAllItems uses disabledForSend to mark its temporary lock changes. Locking skips controls already marked or already disabled, then adds disabled and the marker. Unlocking removes disabled only from marked controls and removes their marker. ToggleWindowLock calls the helper, updates editable fields separately and restores prior focus on unlock. The port changes the disabled representation while preserving ownership and the macOS help-menu exception. It does not make every control enabled after sending.

Scope: compose locking.
