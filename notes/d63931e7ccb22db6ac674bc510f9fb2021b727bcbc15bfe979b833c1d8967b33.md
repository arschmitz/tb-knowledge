# Do not URL-decode an actual file path in the Search Messages save provider

The assigned repair removes decodeURIComponent(file.path) from the provider. At the accepted endpoint both Search Messages and the three-pane provider pass a created filesystem path directly to MessageSaver.saveToFile. Preserve that distinction for paths containing percent characters. The current unique-file behavior is later source context; the original repair did not itself add that promise-based saver. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Search drag filesystem path boundary.
