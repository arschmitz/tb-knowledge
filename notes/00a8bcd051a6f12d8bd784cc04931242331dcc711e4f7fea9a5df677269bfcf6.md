# Selection adjustment can bypass redraw batching

For D324852 at revision 3db8992b23246ea57cc7d8b38630fe8c7e32ebae, the AI review reports that TreeView.rowCountChanged reaches threadTree.invalidateRange through TreeSelection.adjustSelection and selection.tree, bypassing the proposed batch scheduler. Its native quick-search experiment reportedly produced 14 immediate range invalidations for 14 later hits, followed by one scheduled full invalidation; the selected message stayed correct. When assessing this scheduler, trace selection-driven redraw calls as well as explicit invalidation calls. The proposed fix keeps index changes immediate while deferring row work. The experiment counted calls, not elapsed search time, so it does not establish a measured slowdown. The review task was cancelled; acceptance or rejection of this finding is not recorded.

Scope: Thread tree search batching.
