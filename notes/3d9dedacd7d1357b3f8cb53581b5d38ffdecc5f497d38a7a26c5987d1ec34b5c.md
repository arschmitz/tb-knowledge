# Treat Calendar stream queue size as a batching threshold

740 changes the default stream queue from 10 to 100 items. The stream factory documents the number of items to queue before providing them to a reader; its buffered controller flushes when the threshold is reached and forces the remaining chunk when closing. This is a batching policy, not a total memory ceiling for consumers such as Array.fromAsync that retain all chunks. Keep such thresholds near their factory contract rather than scattering unexplained values through consumers.

Scope: Calendar stream batching.
