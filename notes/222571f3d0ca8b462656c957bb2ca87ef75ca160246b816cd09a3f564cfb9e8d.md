# Window-event tests compare geometry separately from the created-event dimensions

Popup creation still requests 800-by-500 dimensions, while this patch replaces event-payload width/height expectations with separate geometry checks. The helper first compares the latest native window. On Linux, matching inner dimensions can replace outer dimensions; if either uses that fallback, the subsequent browser.windows.get comparison is skipped entirely. The normal retry setting permits up to six samples with five 200 ms waits, not an independent completion deadline. Only width/height are checked here. This is scoped test behavior, not proof of exact onCreated dimensions or a fixed native-window API.

Scope: extension-window-tests.
