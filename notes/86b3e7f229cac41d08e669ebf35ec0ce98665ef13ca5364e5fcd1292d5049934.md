# The hidden-alternative browser test omits its filename assertion message

The newly added helper checks two body-text conditions and attachment count with expected-behavior messages. Its filename Assert.equal has only actual and expected arguments, so the required assertion message is absent. The fixed accepted helper retains that exact call. The direct coverage is body selection, count and name; it does not check attachment payload, Open or Save. This is a scoped review finding, not a recommendation to copy the omission.

Scope: MIME browser test review.
