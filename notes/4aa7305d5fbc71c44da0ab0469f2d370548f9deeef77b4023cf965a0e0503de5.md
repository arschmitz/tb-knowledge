# Keep the default notification endpoint test in a manifest without a URL override

The ordinary notification unit-test manifest sets mail.inappnotifications.url to an empty string. The separate xpcshell_default.toml supplies consent and enabled preferences but omits the URL preference. test_DefaultUrlTelemetry replaces _getUrl with its local test-server URL so the fetch can finish without creating a URL user value. It initializes the profile and Glean, waits for onUpdate, checks the default-endpoint Boolean, clears scheduled updater state and restores the method. Merging the test into the ordinary manifest changes the state the metric checks. The browser enabled/disabled tests also have separate preference manifests. This is this telemetry test’s isolation contract. Static source and test inspection only. No Thunderbird runtime, build, lint or live accessibility check ran. Full Bugzilla and Phabricator discussion remains pending-single-browser-reader.

Scope: In-app notification default-preference test isolation.
