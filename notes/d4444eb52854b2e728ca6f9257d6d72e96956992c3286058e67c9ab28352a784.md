# The compound-import landing only narrows the Graph body media assertion

At commit 3fa7a87a, RequestBody::from checks application/json only for the inline OaSchema::Obj variant. The parser represents a direct $ref with application_type=None, so reference bodies bypass that check. The separate one-property assertion remains. RequestBody is also used for 2XX response metadata. The sole owned hunk does not change import emission despite its subject. Fixed accepted ApiBody later removes the media assertion entirely; keep that later pipeline separate. Static source does not prove arbitrary media/schema support or successful generation.

Scope: Graph OpenAPI body extraction at 3fa7a87a.
