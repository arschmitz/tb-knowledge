# Keep copy-mode feedback when destination lookup returns a generic failure

Template, Drafts, Sent and Outbox lookup failures change from dedicated compose results to NS_ERROR_FAILURE. That result does not select all user text: historical send reports and the compose fallback still choose messages by delivery mode, and fixed MessageSendReport retains separate draft/template/later cases. Outbox and drafts stay unread; templates and Sent stay read. The native copy call can fail immediately or complete through its listener; fixed source awaits a completion status and has later recovery behavior. The template commit TODO alone does not prove that every failure reaches a particular alert. Source only: Bug 783526 comment 14 is unavailable; reviews are unread. No runtime validation.

Scope: Compose destination copy failures.
