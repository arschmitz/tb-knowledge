# Store-backed message listeners preserve the original channel as request identity

The 1483 offline listener substitutes the message channel for the internal input-stream pump in start, data and stop callbacks. The accepted shared OfflineMessageReadListener retains this substitution, and the Exchange channel passes itself into AsyncReadMessageFromStore. In this channel family, recommend preserving the public channel identity through internal pumps and converters so consumers receive the expected request object. No listener or MIME conversion test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source adoption does not establish reviewer approval.

Scope: Exchange public channel request identity.
