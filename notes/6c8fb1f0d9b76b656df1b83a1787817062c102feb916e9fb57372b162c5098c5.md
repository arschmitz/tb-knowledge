# Edit configuration is a button action even when it looks like a link

The Account Hub edit control is a native button with type="button" and link-button styling. It changes the current workflow rather than navigating to a URL or submitting the form. For this action, preserve the explicit button type and native semantics when applying link styling. This is a scoped markup recommendation supported by the original and accepted control; keyboard activation and accessible-name output were not run. Full bug and review discussion remains pending.

Scope: Account Hub action controls.
