# New Folder command state uses the folder capability without an Inbox bypass

The command requires online state and canCreateSubfolders. The base getter denies Virtual/Queue folders, and the checked NNTP override denies news servers/groups, so an Inbox flag no longer grants New Folder capability. Popup visibility comes from command state; Inbox/server flags only select the supported action's label. The test removes unified from the visible-mode list and checks actual menu visibility. Direct FolderCommands.newFolder calls retain a separate root/default-account fallback. No filesystem or command-dispatch runtime was exercised.

Scope: Folder context command capability and unified Inbox.
