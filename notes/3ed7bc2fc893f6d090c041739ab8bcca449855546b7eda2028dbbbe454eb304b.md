# aboutMessage loads pane layout separately from standalone window minimums

aboutMessage.xhtml loads a dedicated packaged aboutMessage.css. That sheet imports messenger.css and contains the messagepaneboxwrapper, messagepanebox and messagepane layout rules. The standalone messageWindow sheet keeps its toolbar import and html minimum-size rules. Check the document link and skin mapping together when changing this boundary; this source split does not itself prove scroll or attachment visibility at a particular size.

Scope: Message document stylesheet boundary.
