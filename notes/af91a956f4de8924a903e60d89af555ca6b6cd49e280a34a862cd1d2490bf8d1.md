# Quarantine filter-move validation checks stored contents after another copy

The test named by the 2050 backout enables mailnews.downloadToTempFile, downloads two messages through a move-all Inbox filter, waits for both POP3 completion and destination msgsClassified, and checks the moved folder has two messages while Inbox is empty. It streams each message and checks distinctive body content, then copies the moved messages into a second folder and streams them again. These byte/content checks reach failures that a destination-row count alone can miss. Keep quarantine mode and subsequent message access when evaluating another POP3 move rewrite. This records the actual historical test code and reported failure locator; no test run or stream-corruption diagnosis is claimed. Static source and test inspection only.
