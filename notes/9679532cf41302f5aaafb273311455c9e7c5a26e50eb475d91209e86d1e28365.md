# NNTP HEAD fallback skips holes while keeping the requested range known

A newsgroup low/high range can contain article numbers that no longer exist. The client handles423 without error only while waiting for a HEAD response, advances past the missing article and creates a header only after221. It records the whole requested range before choosing XOVER or HEAD. The test deletes articles5/6 and directly checks command sequences and knownArtsSet1–8 for both handler families; it does not directly assert every parsed header field. processHeadLine separately normalizes field-name casing. No network test ran.

Scope: NNTP sparse article ranges.
