# Use xpcshell skip_if for conditional task skipping

The May cleanup replaced private __skipMe assignments with .skip(condition) across browser and xpcshell tests. That change silently skipped xpcshell tasks unconditionally because its .skip method does not take a condition. Bug 1898449 corrected affected xpcshell tests with add_task({ skip_if: () => condition }, async function testName() { ... }); use this newer accepted form for xpcshell conditional skips. Browser tests can use their own harness API. The regression shows why similar test harness methods must not be assumed to share semantics.

Scope: xpcshell test syntax.
