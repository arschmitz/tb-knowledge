# The XPCOM glue crate rename updates both Cargo paths and real consumers

The original rename changes the workspace member, package and library names, lockfile references, two path dependencies and both source consumers. It also removes Graph's unused direct dependency. Four source files move with identical blobs; their later accepted bodies are checked separately. The current HTTP import and awaited retry-sleep call use xpcom_async_glue. This scoped rename does not establish an async runtime, unchanged callers, native ABI compatibility or a successful build.

Scope: Rust XPCOM async glue integration.
