# Keep deletion sequencing and notification cleanup paired

649 routes copy, move and delete through ProcessNextFolder. A successful copy listener advances mCurIndex; successful deleteStorage advances immediately. Suppressed change notifications are released on the synchronous error path as well as OnDeleteCompleted, because an error can prevent that callback. Current OnDeleteCompleted also updates the XUL tree through an update batch and invalidates the JavaScript tree range. Review new error paths against both completion routes; no asynchronous callback order or failure injection was run here.

Scope: Cross-folder operation completion.
