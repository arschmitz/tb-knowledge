# The accepted unified-toolbar default icon assertion compares two expected strings

The owned patch checks computed icon content after returning to the default theme. In fixed accepted source, that assertion instead compares two image sets built from the same default URL. makeIconSet substitutes the normal URL when the 2x URL is absent, so the later assertion does not observe the icon element. Keep this limitation separate from the shared helper that still reads listStyleImage. No test was run and no later regressor is assigned.

Scope: Extension default icon assertion scope.
