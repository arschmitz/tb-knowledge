# The writable inline-spell-check setting maps to the compose preference

composeInlineSpellCheckEnabled requires messengerSettings permission and maps a Boolean setting to mail.spellcheck.inline. Its ordered test directly checks default true/controllable, set false/controlled and clear true/controllable, using a temporary extension and a running AddonManager. The compose consumer reads the preference when initializing its editor. Existing-window live updates and competing-extension precedence were not established. The existing exact module evidence is reused with its original timestamp.

Scope: messengerSettings writable preference.
