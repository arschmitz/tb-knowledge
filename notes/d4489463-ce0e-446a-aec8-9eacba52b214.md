# Marionette Python tests use test_ file and method names with a descriptive Test class

The landed command-line suite is mail/test/marionette/test_commandline.py, registers that path in manifest.toml, and defines TestCommandLine(MarionetteTestCase) with methods such as test_addressbook, test_import_ics_file, and test_compose. Current suite retains that structure. For a new Marionette test in this area, use a test_<topic>.py file, a descriptive Test class, and test_<behavior> methods; put shared restart/assert logic in a named helper such as subtest_open_tab.
