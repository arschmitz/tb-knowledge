# Gloda activity localization keeps message position, total count and elapsed seconds distinct

The Gloda producer passes a folder display string or null plus the raw job offset and goal. The activity consumer formats msgNumber as offset + 1 and count as the total, but sends the raw offset to setProgress. Its completion event uses message count for the title and elapsed seconds as the status message's count. Keep those units and synchronous formatting contracts separate when changing these messages. This is source inspection, without Fluent execution or a rendered progress test.

Scope: Activity Manager Gloda localization.
