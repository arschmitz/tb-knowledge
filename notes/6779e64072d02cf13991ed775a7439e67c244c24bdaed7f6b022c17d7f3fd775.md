# Use the unified account-setup entry point and its current routing

Entry 1170 renames openAccountSetupTab to openAccountSetup and routes existing-account launches through a pref-controlled hub while keeping initial setup on the old path. Accepted openAccountSetup has no initial argument and always focuses the most recent mail window and calls openAccountHub; startup also calls it without an argument. The old mail.accounthub.enabled experiment is no longer the current routing contract. Check the current helper rather than repeating the 2024 flag behavior. This is source and test inspection only. Full Bugzilla and historical review discussion remain pending. No Thunderbird runtime, build, lint or live accessibility check ran.
