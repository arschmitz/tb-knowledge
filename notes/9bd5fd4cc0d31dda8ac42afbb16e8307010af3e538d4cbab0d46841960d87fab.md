# Keep Calendar subview navigation names aligned across each consumer

Entry 2062 pairs the dashed calendar-dialog-subview-manager module/tag with CalendarDialogSubviewManager, camel-case view IDs, .back-button and the dashed calendar-dialog-back-button Fluent ID. Production markup, browser fixture, Storybook and jar registration must agree. The native Back button gets aria-label/title through Fluent. The dialog hides Back on default and shows it for another subview; the current dialog retains this state binding with selector handlers for expanded description, attachments and attendees. The changed test exercises pointer Back return and visibility. Proposed extra checks are Enter/Space, focus after hiding a view and after Back, reflow and computed accessible name. No live accessibility or runtime checks ran.

Scope: mail Calendar dialog navigation integration.
