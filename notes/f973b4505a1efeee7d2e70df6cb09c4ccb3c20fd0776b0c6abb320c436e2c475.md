# EWS read-status completion is separate from starting the detached task

The 1279 folder implementation updates the local database before calling ChangeReadStatus, whose Rust task logs later failures. A successful immediate return therefore did not prove server confirmation. The fixed accepted ExchangeFolder instead updates only the headers selected by the success callback and commits them there. Treat the 2024 optimistic update as historical behavior. The newer source is a limited current comparison, not a full study of its later repair or proof of a successful EWS exchange; no network or runtime test was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: EWS read-status completion.
