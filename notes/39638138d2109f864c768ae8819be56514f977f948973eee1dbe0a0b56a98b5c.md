# Custom Headers waits for the owned search popup to close before opening its modal dialog

The OtherHeader branch of onSelect checks the owned menupopup state. If it is not closed, it awaits a one-shot popuphidden listener before opening the modal Custom Headers dialog. The bound command listener preserves the widget receiver. After the dialog, the code uses a safe temporary value, rebuilds headers and restores the chosen or first item. The local comment names pointer-capture release as the reason; source ordering does not prove an engine capture contract or a cured focus hang. Other attribute choices do not take the popup wait.

Scope: search-attribute popup and modal ordering.
