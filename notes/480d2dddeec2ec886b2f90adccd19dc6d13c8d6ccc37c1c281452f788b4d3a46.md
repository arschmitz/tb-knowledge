# Thundermail popup initialization adds a runtime listener each time

PopupView calls initialize from its configuration query and enables refetch on mount and window focus. Each successful initialization registers an anonymous browser.runtime.onMessage listener for FILE_LIST and SIGN_OUT. The inspected component has no matching removal or registration guard. Repeating initialization therefore adds registrations in source; the study did not measure duplicate delivery, retention or an upload failure. This is a component lifetime finding, not a claim about every message listener or the imported query framework.

Scope: Thundermail generated PopupView initialization and query.
