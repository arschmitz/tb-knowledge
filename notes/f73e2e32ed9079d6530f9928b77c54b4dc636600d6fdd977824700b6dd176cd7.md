# The original EML retry checks a suggested filename rather than saved message bytes

In the original retry, the mock picker resolves defaultString and the test applies a nonanchored filename regex. That checks the suggested name, including a possible numeric suffix; it does not validate saved message bytes. The accepted later test uses a destination file, waits for data and compares normalized extracted-message bytes. Keep those later assertions separate from the original focus/window retry. No file-save or UI run was performed.

Scope: EML attachment-save test phases.
