# Reserve inline input space for the actual validation icon

Account Hub inputs keep 30px at the inline end, while a 16px warning/success icon plus end padding is positioned there. Password inputs restore 9px and number inputs adjust icon padding separately. Review input padding together with the real icon dimensions and exceptions. This is a scoped layout recommendation; existing validity/text-association lessons are reused and no RTL, zoom or contrast result was measured. This is static source evidence. No runtime, build, lint or live accessibility check was run. Full Bugzilla and Phabricator discussion remains pending.

Scope: Account Hub validation icon spacing.
