# Filelink icons use CSS backgrounds rather than message image elements

1351 replaces the paperclip and service icon img elements with div backgrounds, including protected-link icon selection and blocked chrome/moz-extension image conversion. Accepted source still creates those divs and stores backgroundImage; tests change from .src to style.backgroundImage. Preserve the representation and protected URL conversion boundary when checking generated attachment markup. Embedded asset strings were retained, but their geometry and actual recipient image behavior were not audited. This is static source and test-code inspection. Full Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.
