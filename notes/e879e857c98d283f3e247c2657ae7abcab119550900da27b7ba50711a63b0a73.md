# The shared-folder copy assertion reports one message while checking a growing count

The existing-target scenarios send, save a draft and save a template into the same IMAP folder. subtest derives expectedMessageCount from the starting count plus one, but its fake-server assertion still says one copy should be in the server mailbox. That diagnostic describes the wrong total on the second and third calls. Include expectedMessageCount in the message so it states the checked expectation. Other checked assertions have nonempty expected-behavior messages; no browser test ran.

Scope: Compose copy browser-test assertions.
