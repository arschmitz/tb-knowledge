# The subscribe click helper awaits frame and timer barriers rather than a state predicate

The timing repair changes all eight click callers to await. clickTreeRow scrolls, waits two animation-frame callbacks, dispatches the checkbox click, then resolves after a timer callback. The promise contains no checked-state predicate or backend-event wait. This proves the sequence used by the browser test, not universal layout completion, the claimed microtask cause or elimination of intermittent failures. Fixed accepted code later changes ownerGlobal to documentGlobal while retaining the ordering.

Scope: Subscribe browser-test scheduling.
