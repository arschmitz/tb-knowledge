# Folder deletion does not clear an existing Gloda limbo entry

The false compaction flag used by folder deletion clears matching entries from both pending-commit maps. It does not remove a pre-existing folder-URI limbo cache entry. Purging queued folder jobs is another operation and contains no such cache deletion. The inspected successful compaction-worker tail deletes the entry. The new header-healing test does not cover deleted-folder cache cleanup; no actual leak or universal absence of later cleanup is established.

Scope: Gloda pending-commit cache lifetime.
