# The early Calendar-cache warning checks the current main-window count

loadCalendarComponent logs its early-cache warning only when mCache already exists and exactly one mail:3pane window is enumerated. Opening another main window should not meet that count condition. The per-window repeated-call throw and shared manager cache initialization remain separate contracts. The patch changes the diagnostic predicate, with no new test or fresh multiwindow result. The one-window condition can also hold after the last main window closes and a new one opens; the primary report explicitly leaves that diagnostic limitation.

Scope: calendar/startup-diagnostic-scope.
