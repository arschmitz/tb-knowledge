# Test global and tab action values with clearing and live button state

The action property tests set a global value, override two tabs, change the global value, clear each tab override, and then clear the global value. They assert both the extension getter and the rendered button state after each step. The same sequence covers badge text, text color, and background color across browser, compose, and message-display actions. A new shared action property needs this inheritance and reset coverage, because a getter can be correct while a button still displays a stale override.

Scope: Extension action tests.
