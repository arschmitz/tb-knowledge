# The MIME fuzz initializer clears four external handler-file preferences

InitMimeDecoder writes empty strings to the global/private mime-types and mailcap file preferences, then returns zero. The fuzz registration supplies this initializer to the MIME target. The owned file and fixed accepted file have the same blob. This is target setup; it does not change production defaults or prove every external handler path is isolated. Existing async conversion ownership and completion are reused from their earlier source lesson. No fuzz run, preference-reader execution or test occurred.

Scope: MIME fuzz target setup.
