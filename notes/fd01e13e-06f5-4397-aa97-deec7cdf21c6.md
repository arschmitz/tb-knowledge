# Preserve local CardDAV properties after server refresh

When a server response replaces a CardDAV card, copy local non-vCard properties from the existing card. Exclude _vCard, _etag, _href, LastModifiedDate, and banished properties. Otherwise a local PopularityIndex update is lost when the card is fetched again.

Scope: CardDAV address books.
