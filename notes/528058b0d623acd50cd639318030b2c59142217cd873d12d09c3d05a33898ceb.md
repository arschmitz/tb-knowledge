# First-run setup excludes native address-book contacts, while its added test covers only a macOS predicate result

The populated-address-book condition excludes moz-abosxdirectory: and moz-aboutlookdirectory: before checking childCardCount. This keeps operating-system data from being enough to satisfy that setup condition. The added task runs only on macOS and asserts isFirstRun after attempting native-book creation; it does not itself arrange or assert a positive native contact count and has no Outlook case. Other setup conditions still apply. These are source and direct-assertion facts, without a native profile or platform run.

Scope: First-run native address-book exclusion.
