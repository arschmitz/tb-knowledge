# Name a URI variable for its identity dimension without renaming platform fields

The color-store helper uses oldURI/newURI/folderURI/movedURI to state source, destination and key identity, while the platform folder property stays URI. The case and suffix convey a real persisted key contract; a cosmetic rewrite of folder.URI or pref-bound dotted DOM IDs can break consumers. Keep local names specific and preserve externally defined field spellings. This is a scoped accepted pattern, not a project-wide acronym casing mandate.

Scope: naming identity.
