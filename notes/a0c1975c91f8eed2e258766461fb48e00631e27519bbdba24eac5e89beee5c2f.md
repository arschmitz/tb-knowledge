# Checkbox label tests check localization and labeling metadata

The localization assertion compares the label's Fluent ID with the host attribute. It does not compare translated label text, although its message says that text should display. The separate ariaLabelledByElements assertion checks the label relationship; it does not compute an accessible name. Keep these direct assertions separate from rendering, keyboard and screen-reader coverage. No browser or accessibility test ran.

Scope: Account Hub checkbox test assertions.
