# Thunderbird keeps a parent-process eval override tied to the Matrix JS SDK

The accepted Thunderbird profile explicitly sets security.allow_eval_in_parent_process to true with a comment that scopes the need to the Matrix JS SDK migration. The original patch removes a separate explicit system-principal false setting; it does not establish that both preferences have the same default or meaning. The full bug records an initial belief that false was safe, then corrects that belief after a Try run. The assigned review, paired Gecko default implementation and Matrix eval consumer remain uninspected. This is a scoped compatibility fact, not a general recommendation to enable eval. No runtime eval or Matrix test ran.

Scope: Matrix parent-process compatibility preference.
