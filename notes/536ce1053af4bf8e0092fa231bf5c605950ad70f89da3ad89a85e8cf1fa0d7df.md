# Pair system foreground and background colors in Windows contrast mode

751 and 752 replace the titlebar accent background and correct the Windows high-contrast branch. Current CSS pairs CaptionText with active/inactive caption backgrounds and uses Dialog/DialogText for the toolbox and spaces toolbar in the scoped non-theme branch. System colors preserve state-dependent foreground/background relationships; changing only a background can break that relationship. This is CSS inspection, not a measured contrast, screen-reader, native Windows or high-contrast rendering pass.

Scope: Windows titlebar contrast.
