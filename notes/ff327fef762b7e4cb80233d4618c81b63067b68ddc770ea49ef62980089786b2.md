# Historical spam progress supplied a misspelled Fluent argument

The original properties-to-Fluent patch passed precentage to spam-analysis-percentage, whose Fluent expression requires percentage. Fixed accepted source uses percentage. The value is a 0–1 processed/total fraction; Fluent percent formatting supplies the percentage presentation. This is an exact source mismatch and later source comparison, not a reproduced rendering failure or a test result.
