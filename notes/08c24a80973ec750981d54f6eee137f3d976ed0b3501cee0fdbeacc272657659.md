# Address-book link display has a policy boundary after URL parsing

_sanitizeHref first checks URL.canParse, then preserves selected schemes and replaces other exposed schemes with a text node. Nonexposed schemes remain anchors for external delegation. Callers apply it to telephone, website and instant-message entries; malformed IMPP text is also rendered as text. Parsing a URL is therefore distinct from deciding it should remain clickable. The external-service policy and runtime handling were not executed. This is source and test-code inspection. Complete Bugzilla and historical review timeline/inline context remain pending. No Thunderbird runtime, build, lint or live accessibility validation ran.

Scope: mail/components/addrbook.
