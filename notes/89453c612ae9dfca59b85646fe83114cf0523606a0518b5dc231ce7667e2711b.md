# Dependent folder properties retain explicit opener cleanup and focus restoration

The original patch replaces a modal folder-properties dialog with a dependent one so the opener can refresh during folder repair. In the checked current implementation, editFolder sets the opener document inert, stores the focused element, closes the child when the opener unloads, and supplies an unload callback that restores the opener and removes its listener. folderProps.js registers that callback. The accepted browser helper waits for inert removal, popup closure and focus restoration; the original patch only added animation-frame waits. These are static caller, cleanup and written-test contracts, not a live focus, accessibility or repair result. Virtual-folder properties use a separate modal branch.

Scope: Folder properties dialog lifetime.
