# Name the actual configuration owner consistently

The outgoing form has a private #currentConfig but #adjustPortToSSLAndProtocol writes this.currentConifg after editing a copied config. Recommend checking whether that assignment is meant to update #currentConfig and correcting the spelling/ownership if so. The UI port is updated separately, so this typo alone does not prove a user-visible port failure. This is a local source proposal, not a current naming rule for all configuration objects. These observations are scoped to the cited accepted source and historical changes. Full Bugzilla and historical review timeline/inline discussion remain pending.
