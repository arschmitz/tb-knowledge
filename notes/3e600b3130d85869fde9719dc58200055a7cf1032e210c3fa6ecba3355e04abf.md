# Firefox native HTML date input calendar support

Firefox desktop native `<input type="date">` and its popup are Gregorian only: `DateTimePickerPanel.sys.mjs` constructs its picker locale with `{ calendar: "gregory" }`, while HTML date values are proleptic Gregorian `YYYY-MM-DD`. [Task 1]

Scope: calendar.
