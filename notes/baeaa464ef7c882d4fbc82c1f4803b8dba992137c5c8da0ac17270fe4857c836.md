# Style the IMAP deleted state from the message flag

649 removes the dependence of the imapdeleted row and cell property on the view-wide delete model. A mixed-folder search may contain messages with different policies, so the message flag supplies the state. The current row property still checks IMAPDeleted directly. This supports deleted-state styling and the patch intent of enabling undelete; it does not verify a keyboard action, announcement or successful undo at runtime.

Scope: Message row state.
