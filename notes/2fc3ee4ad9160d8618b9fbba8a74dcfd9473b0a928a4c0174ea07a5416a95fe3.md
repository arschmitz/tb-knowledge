# ConversationView builds a detached message article before the caller inserts it

ConversationView's caller clones the template fragment and passes it to buildMessage. That helper fills the fragment, attaches its click listener and returns it; the caller appends it to the conversation. The build name fits this local boundary between preparing a detached node and inserting it into the component. The same file still has an addFullMessage fragment factory, so this accepted review example does not define a global method-prefix rule. The helper also keeps machine-readable dateTime in ISO format and the tooltip in locale format. Its historical tempalte typo and inaccurate surrounding fragment type annotations are not recommended documentation. No UI or localization test ran.

Scope: Scoped method naming and DOM mutation boundary.
