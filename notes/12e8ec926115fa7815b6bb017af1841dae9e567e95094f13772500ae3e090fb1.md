# Duplicate tag acceptance is stopped before asynchronous localization and the modal warning

Both duplicate-name handlers call preventDefault before starting the asynchronous warning and attach a rejection handler. alertForExistingTag awaits the Fluent value, then calls the standard modal prompt with the current document title. The new-tag resource supplies that text. This is the inspected ordering and caller contract; asynchronous formatting does not establish that the later modal prompt is nonblocking. No dialog runtime test ran.

Scope: Tag dialog duplicate handling.
