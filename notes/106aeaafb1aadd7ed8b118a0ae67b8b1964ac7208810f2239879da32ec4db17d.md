# The Manual Advanced Configuration test checks event dispatch rather than account creation

This landing adds a Manual Advanced Configuration button that dispatches a bubbling event from the subview. Its parent reads the current config and enters the existing confirmation/backend route. The new component test synthesizes a click and checks the event target only; it does not assert edited config values, backend account creation or Account Settings navigation. The checked captureState accessor returns stored state, so this test cannot establish fresh input capture.

Scope: Account Hub manual Advanced Configuration event route.
