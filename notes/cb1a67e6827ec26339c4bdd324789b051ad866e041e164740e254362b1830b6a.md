# Removing the Calendar UI migrator stops future transforms without clearing stored customization

The removed migrateCalendarUI helper read calendar.ui.version, copied old toolbar customization, renamed button-save in persisted sets and wrote version 3. Deleting the call and definition stops those transformations at startup. The patch contains no preference clear or XUL-store value deletion, and current startup proceeds directly from locale defaults to manager initialization. This scoped removal does not prove every old profile had already migrated or authorize a general age-based migration policy.

Scope: Calendar startup and old profile migration.
