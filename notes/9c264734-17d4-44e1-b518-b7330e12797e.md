# Display the contacts sidebar before loading its cards

After setting up AutoTreeView, columns, events, and the selected directory, AbPanelLoad schedules ChangeDirectoryByURI for the next turn of the event loop. The comment says contact loading is slow and the sidebar should display first. Browser tests wait for the sidebar document and then for nonzero view rows before making assertions. Current code retains the deferred load. Keep this startup responsiveness contract when changing sidebar initialization.

Scope: Address Book startup.
