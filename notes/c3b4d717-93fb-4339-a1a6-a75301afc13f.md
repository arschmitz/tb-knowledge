# Do not let a file-filter predicate mutate an IMAP folder path

An old .msf file predicate stripped the suffix from its input by reference. Later cleanup could then delete the mbox data file instead of the index file. Keep the actual file path separate from the derived folder name during IMAP subfolder discovery.

Scope: imap.
