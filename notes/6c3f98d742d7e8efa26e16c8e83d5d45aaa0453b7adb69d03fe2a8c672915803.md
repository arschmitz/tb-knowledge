# Let updater icon state control one decorative image without a hidden override

The accepted updater cleanup replaces a div containing several images with one img whose id is icons, role is presentation and alt is empty. The selected panel ID becomes the image class; CSS chooses the matching check, reload or spinner, and :not() sets display:none for all other states. The image has no hidden attribute that could conflict with the CSS visibility rule. D215838 explicitly requests this img/visibility change and the alt attribute; all three requests are applied and marked Done, then the patch lands. Keep this claim scoped to the updater decoration: the source does not establish a general rule to replace hidden attributes with CSS. The textual update deck and focus order have separate contracts. The reviewer says not to uplift this cleanup to 128. No runtime or accessible-tree validation ran.
