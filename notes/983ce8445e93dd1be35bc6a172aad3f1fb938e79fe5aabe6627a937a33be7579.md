# The tasks-key cleanup centralizes mail shortcuts while keeping compose keys separate

The main, message and hidden mail windows remove their tasks keysets and use the shared New Message keys. mainKeySet keeps the macOS accel,shift/accel split and non-macOS accel bindings; mainCommandSet supplies the command IDs. The compose window instead renames its local group to composeKeys and retains its direct goOpenNewMessage callback. The move does not establish that controller dispatch and every former callback behave identically or set a global naming rule.

Scope: Mail command and shortcut ownership.
