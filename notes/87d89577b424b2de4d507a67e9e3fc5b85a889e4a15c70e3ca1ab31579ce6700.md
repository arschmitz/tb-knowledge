# Keep explicit folder ordering separate from locale name sorting

The 2024 comparator adds Base sensitivity and numeric collation even though its commit message says case-sensitive. Current tests describe case-insensitive locale ordering, and current LessThan sorts explicit ordinals first, then special-folder rank, then AppCollator::CompareBase. Prefer the actual comparator and tests to the old prose when reviewing order changes. This comparison does not count the later sorting rewrites as studied. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.
