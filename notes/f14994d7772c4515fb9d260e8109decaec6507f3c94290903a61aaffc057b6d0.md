# The nested MIME parser moves to a header declaration and an explicit build entry

The change moves the unchanged nsMsgBodyHandler2 class declaration into nsMsgBodyHandler.h, removes the textual .cpp include from nsMsgBodyHandler.cpp, gives nsMsgBodyHandler2.cpp its own header includes and lists it in UNIFIED_SOURCES. The accepted source retains that boundary. This establishes source/build registration, not a fresh compile/link result or unchanged runtime behavior, and it does not create a global rule against all .cpp inclusion.

Scope: MailNews body-search parser build boundary.
