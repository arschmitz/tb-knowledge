# Migrate dialog settings when the new consumer ships

The D331828 review at revision 22aecaf44d459bb83d5abf0a82aad32739358bd2 reports that startup migration removes SearchDialog.xhtml settings while the current dialog still reads that URL. Its local headless experiment reportedly passed five settings checks before migration and failed all five afterward, covering search scope, column visibility, and sorting. For this migration, defer removal of old settings until the replacement dialog consumes the migrated values. Minimum test coverage: migrate saved settings, reopen the production dialog, and check the resulting state. This is a recorded review finding and experiment, not independent confirmation or an accepted change.

Scope: Search dialog settings migration.
