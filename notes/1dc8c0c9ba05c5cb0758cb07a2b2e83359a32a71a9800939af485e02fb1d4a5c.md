# The source documentation webhook job declares its worker type separately from its image

The original source-docs change replaces t-linux-large with t-linux-docker-noscratch. Fixed accepted configuration uses the later t-linux-docker-noscratch-amd name. It separately selects the debian12-amd64-build image, run-task wrapper, comm checkout and build-source-docs.sh command, with a source-docs index and scoped webhook secret. A worker-type name change is not evidence that the image, script, webhook result or permissions were tested. The kind file and complete one-line patch were inspected; full bug/review, generated task, worker implementation and documentation build remain uninspected.

Scope: Taskcluster source documentation job.
