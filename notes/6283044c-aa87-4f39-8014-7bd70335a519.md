# Do not reintroduce MsgHdrSyntheticView after the mail tabs rebuild

The old module fabricated a synchronous single-message nsIMsgDBView for FolderDisplayWidget.show. Coverage after the mail tabs rebuild showed it was unused; D211958 removed the module, its mailTabs.js lazy import, and its moz.build registration. Current mail and calendar sources have no MsgHdrSyntheticView reference. Before adding a single-message tab path, inspect current mail tab and message view code rather than reviving that pre-rebuild helper. The review accepted this deletion without a visible change request.
