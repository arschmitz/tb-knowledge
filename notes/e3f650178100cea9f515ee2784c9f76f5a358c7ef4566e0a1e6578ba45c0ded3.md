# Titlebar layout tests check geometry after the menu mutation frame

The current spaces-toolbar helper checks customtitlebar, changes menubar autohide/inactive attributes, waits one animation frame and asserts both the titlebar and menubar left edge equal the spaces-toolbar width. The 1377 change updates its titlebar attribute spelling without adding a new geometry algorithm. For this test family, recommend retaining actual geometry assertions; merely checking the attribute would not prove alignment. No Windows, macOS, Linux or live layout test was run. No test, build or runtime operation was run. Full Bugzilla and Phabricator discussion is pending; source landing alone does not establish reviewer approval.

Scope: Spaces-toolbar titlebar alignment tests.
