# OAuth custom-scheme callbacks route by state before authorization processing

The OAuth callback request is stored by authorization state. The handler dispatches a matching state to urlReceived, which deletes the entry before finishing the request and processing the authorization response. The actual command-line caller first chooses an observer service by URL host. Those are separate routing steps. close is empty, so callback-map cleanup must not be inferred from finishAuthorizationRequest alone. Later accepted host/path and shell-capability changes remain separate from the owned implementation; no OS delivery or cancellation result was executed.

Scope: Thunderbird OAuth custom-scheme callback routing.
