# The signed-footer Open and Show test checks visible Content-Type leakage only

The signed-footer test waits for the second message window and OpenPGP processing after clicking Open and Show. It directly checks expected message text and absence of Content-Type in rendered body text. It does not check all outer headers, the added queue-ID header, raw saved bytes or icon status. Keep this visible-text regression assertion separate from a complete MIME or cryptographic guarantee.

Scope: openpgp-nested-message-tests.
