# The UTF-8 truncation table test omits an explicit assertion message

The table contains sixteen inputs, limits and expected strings, but its one ASSERT_EQ(got,t.expected) has no explicit expected-behavior or case message. The nearby comments and test name do not supply that assertion argument. A future test edit should identify the input/limit and expected behavior in a nonempty message. This is a scoped diagnostic finding; it does not claim the test fails or establish a runtime result.
