# Keep the incomplete suffix when framing fake-server CRLF lines

The fake-server reader scans each byte index, emits only complete CRLF-delimited lines and keeps bytes after the last complete delimiter. A final CR remains buffered until a later read supplies LF. The input callback then dispatches the completed lines in order to the protocol handler. The indexed loop replaces recursion per line and repeated buffer truncation; this is a local index/boundary contract, not a blanket loop rule or a measured performance result. Existing large-message progress tests execute this path but do not directly assert every framing edge case. No test or memory benchmark ran.

Scope: MailNews fake-server input framing.
