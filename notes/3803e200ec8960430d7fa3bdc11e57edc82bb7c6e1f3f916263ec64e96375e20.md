# The new-star regression task simulates selection rather than restarting Thunderbird

The browser task creates explicit New state in a loaded mail3Pane tab, dispatches a select event for the same folder, waits for the row's new property and checks both header and folder state. A separate unit task calls close() and checks mark-read-on-exit. These tests specify the in-place rebuild and default-close contracts; their names and source do not establish a real application restart, POP fetch or executed result.

Scope: Folder-view New-state regression coverage.
