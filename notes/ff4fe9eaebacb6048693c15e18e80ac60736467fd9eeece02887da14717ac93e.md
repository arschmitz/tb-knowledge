# Calendar titlebar layout keeps native button actions separate from title clipping

The titlebar uses native Back and Close buttons with explicit type=button. The heading receives the flexible width and two-line clipping; the controls have their own inline-flex container. This keeps control semantics separate from overflow styling. Fixed accepted markup later splits the titlebar into two rows and adds a menu, while retaining the explicit button types and heading clipping. That later arrangement is a separate phase.

Scope: calendar-dialog.
