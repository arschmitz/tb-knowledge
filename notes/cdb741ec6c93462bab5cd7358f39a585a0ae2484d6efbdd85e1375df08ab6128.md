# IMAP URL setup and busy inspection share a reentrant monitor

The inspected patch moves m_urlInProgress=true and sink clearing into SetupWithUrl under mMonitor, replaces the old mutex at related sites and adds IsUrlInProgress under the same monitor. The fixed IsBusy consumer calls that getter. Shutdown marks the connection busy before it can be reused. Both assigned discussions are restricted, so the reason for every lock choice and complete lock ordering remain unresolved. This is source evidence for these named boundaries, not a proof that every access or race is safe.

Scope: IMAP URL busy state.
