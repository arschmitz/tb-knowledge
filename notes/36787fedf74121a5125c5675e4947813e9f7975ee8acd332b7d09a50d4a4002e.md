# Windows startup can read MOZ_MAXSTDIO before XRE_main

On Windows, do_main reads MOZ_MAXSTDIO before XRE_main. A present value is parsed with atoi and passed to _setmaxstdio only when it falls between 3 and 8192. The return comparison controls the failure message. This is a standard-stream startup setting, not a general OS handle limit or strict whole-string validator. The -1 comparison sentinel leaves that parsed invalid value silent. No Windows run was performed.

Scope: application/windows-startup.
