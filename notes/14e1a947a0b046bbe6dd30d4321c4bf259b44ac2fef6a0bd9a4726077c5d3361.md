# The Rust lint follow-up shortens trait paths already available in scope

The reviewer asks to avoid fully qualified trait names when the trait is already in scope, or import the trait when appropriate. The actual fallback uses map(Into::into), while shared address adapters import Address and use Address::first/iter. The author acknowledges overusing automatic fixes. This is accepted local readability practice for these method references. It is not a ban on qualified names, an automatic import rule or proof that every method has the same receiver contract.

Scope: EWS and shared Rust method-reference style.
