# Background mail errors skip modal prompts

At revision 620a0ed3802188e93a499ef795831ab0db630f05, the shown nsMsgMailSession error-alert path returns without a modal prompt when listeners have already been notified, the URL is absent, or the URL has no nsIMsgWindow. The source explains that a missing message window indicates background activity, such as autosync or biff. Preserve this distinction when changing this alert path so background work does not open modal dialogs. This does not establish that background errors receive no notification: AlertCertError separately forwards certificate errors to feedback listeners. This is static source evidence; no runtime validation was supplied.

Scope: Mail session error alerts.
