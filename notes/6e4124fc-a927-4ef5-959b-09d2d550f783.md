# Address book selected-row menu icon selector targets the immediate row content

The address book CSS changed its keyboard-focus selector from a broad descendant under a selected row to .selected > div &. The current selector retains that direct-child boundary while hover still uses the row container. In nested row markup, preserve the selector scope when changing menu icon visibility so descendant controls do not inherit the selected-row display condition by accident.

Scope: Address book row CSS selectors.
