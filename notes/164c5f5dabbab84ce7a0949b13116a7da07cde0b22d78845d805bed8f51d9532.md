# Deleting the default outgoing server updates the default before repairing identity references

The confirmed delete command chooses the first other configured server as default, or clears the default user pref when deleting the last server, before calling deleteServer. It then clears matching identity and loaded-panel keys; the actual identity lookup uses the default when its explicit key is empty. The null setter does not permanently disable defaults: the getter still chooses the first available server when one exists. This source ordering is not a reachable-server choice, atomic transaction or tested send result.

Scope: Outgoing-server panel, service null setter and actual identity fallback.
