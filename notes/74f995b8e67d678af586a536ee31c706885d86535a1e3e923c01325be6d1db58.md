# Carry browser context when replacing default link navigation

The parent actor gets the top embedded browser and passes its initial browsing-context group, link-handler group, user-context ID, document principal and CSP to openLinkInNewTab. The helper opens a content tab in the most recent mail window and forwards parameters. Preserve these context values in this actor path; opening just the URL can change isolation and permissions. The helper does nothing if no mail window exists, and its spread parameters can override url, so it is not an unconditional forced-destination primitive. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Content tab navigation context.
