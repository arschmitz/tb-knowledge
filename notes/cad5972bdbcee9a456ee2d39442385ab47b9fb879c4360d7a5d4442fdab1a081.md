# Commands selected-commit diff performance

In `commands/graph/data.mjs`, `renderLocalDiff` should check the current checkout and supplied worktrees before running `git worktree list --porcelain -z`; list other worktrees only when a changed file is unresolved. This preserves missing/renamed-file fallback links while avoiding ordinary-diff scans. [Task 1]

Scope: console.
