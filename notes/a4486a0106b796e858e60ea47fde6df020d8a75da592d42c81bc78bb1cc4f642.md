# Update failure-context constructors with the listener tuple contract

The original DoOperation landing changes OnSendStopArg to accept a two-item URI/message tuple and passes the error separately by reference. In that same revision, send_message still constructs the old three-item tuple with an Rc error, and its Rc import has been removed. These exact source facts show an incomplete caller migration. Check every constructor when changing an associated failure-context type, including callers outside the edited hunks, so each independently landed patch uses one contract. No compiler run or exact historical build-failure diagnosis is claimed.

Scope: EWS original DoOperation migration boundary.
