# Protocol completion releases its channel listener after notification

AsyncOpen stores the stream listener. OnStopRequest first sends the listener its completion callback, then clears m_channelListener with the other callback references before closing an open socket. The assigned change targets a reported cycle with a view-source wrapper. This establishes the inspected release order, not every cancellation/ownership path or an independently measured leak fix. No view-source or leak test ran.

Scope: Mail protocol listener lifetime.
