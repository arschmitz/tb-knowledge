# Named timer diagnostic arguments use the _ns literal suffix

The owned mailnews repair adds _ns to nine timer diagnostic-name literal arguments while retaining their text and other call arguments. The accepted comm call sites retain that form. The commit describes this as an nsITimer argument-type adaptation. Independently inspected Gecko signatures remain separate, unpaired context; they do not establish the engine paired with this landing or the fixed comm checkout. Do not infer changed timing, callback behavior or a rule for unrelated literals. No build or timer test ran.

Scope: Mailnews C++native timer API adaptation.
