# Preserve Calendar selection by item identity during row changes

The 740 tree update saves selection before adding, removing or sorting rows and restores it afterward. The restore path suppresses selection events and only selects rows that still exist, avoiding bogus out-of-range selections after deletion. The selected item identities and their new indices are separate state. This is important when a new range reorders occurrences. No live keyboard selection or focus test was run.

Scope: Calendar filter selection.
