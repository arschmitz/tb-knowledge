# Wait for the NNTP save callback before exposing a temporary message

retrieveMessageFromServer creates a unique temporary file with mode 0600, registers deletion on exit, calls saveMessageToDisk and awaits OnStopRunningUrl. It returns null for failure status or a zero-length file, and converts a file URI to a message header only after that check. Keep the interface callback spelling OnStopRunningUrl even though the ordinary helper uses lowerCamelCase. Completion, file lifetime and the external-message identity belong together; a call that merely starts the save does not satisfy them. No live NNTP request or failure-injection test was run.

Scope: NNTP callback completion and temporary file ownership.
