# Mail link handling finds the owning anchor before checking its URL

MailLinkChild uses event.target.closest("a")?.href, so clicking strong or another element inside an anchor uses the anchor URL. It returns when no href exists, the URL cannot be parsed, the click is not the main button, or the document is the compose editor. It then handles only its listed mail/news/message/attachment protocol cases. The new browser test clicks #mailtolink_strong and waits for the actual compose window. Manual event and test proposal in this actor: test an anchor and a nested child, and keep ancestor lookup separate from URL validation and protocol dispatch. The behavior-based test name extends the existing camelCase test family; it does not establish a global test naming rule. No arbitrary external-link security guarantee follows from this actor alone.

Scope: mail-link-events.
