# Keep native mailbox GTest suites aligned with their test file names

TestMsgMboxRead.cpp uses the TestMsgMboxRead suite with PascalCase case names such as Basics, OddCases, and LongMessage. Its run comment uses ./mach gtest "TestMsgMboxRead.*". Follow this local native mailbox test naming so the documented filter selects the suite. This is a scoped pattern from the current file, not a claim that every Thunderbird test framework uses the same naming.

Scope: mailnews/base/test.
