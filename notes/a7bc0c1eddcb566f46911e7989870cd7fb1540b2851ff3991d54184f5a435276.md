# Normalize persisted splitter sizes and store the actual CSS-bounded result

PaneLayout restores XULStore values as strings. PaneSplitter treats null, undefined and the empty string as an unset size; finite numeric conversions become numbers. On resize it rounds the requested value, applies it, then reads the actual element size after CSS constraints. Current vertical tests cover a restored string value and flexible 100% sizing. This augments the existing rounding lesson: a requested size is not proof that layout accepted it. Manual API proposal for persisted dimensions: normalize at the property boundary and document the nullable number/string input; keep the stored numeric value and accessibility value tied to the actual pane size.

Scope: pane-layout.
