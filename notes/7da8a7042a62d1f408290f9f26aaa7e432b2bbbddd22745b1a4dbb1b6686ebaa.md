# Treat application profile name case as persistent data compatibility

MOZ_APP_PROFILE controls application.ini Profile and the profile location. The 2024 lowercase workaround later changed absolute path keys in folderCache.json on Windows/macOS, so 128→140 profiles could miss cached entries and rebuild them. The accepted correction uses Thunderbird on Windows/macOS and thunderbird elsewhere; current enterprise variants are also explicit. Preserve platform spelling when porting vendor/app configuration. Do not simplify this to a global lowercase naming rule. The followup was not covered by automated tests according to its uplift request; no local migration was run.

Scope: mail/configure.
