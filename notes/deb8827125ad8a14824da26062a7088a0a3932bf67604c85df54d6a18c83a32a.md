# The PDF policy browser test checks handler choice but omits assertion messages

This browser test directly checks system/internal/helper MIME-handler actions, ask behavior, explicit handler precedence and preservation of a user choice after reapplying the false policy. All10 is(actual,expected) calls omit an assertion message, so failures lack the required expected-behavior message. The accepted test blob equals the original port. No test or MIME/native handler operation was executed.

Scope: Enterprise policy browser tests.
