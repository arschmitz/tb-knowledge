# Bound filter-header scanning by the supplied byte span

Filtering receives a list of NUL-terminated header strings and its size. GetNextFilterLine uses a non-owning Span to skip CR, LF, spaces and NULs within that size, then finds the next terminator within the same span. With no terminator it truncates the output and returns -1. The next span starts after the terminating NUL; the returned length includes that NUL. This replaces an unbounded strlen crash path. The synchronous MatchArbitraryHeader caller keeps the supplied headers available while iterating. The Span does not take ownership, so another caller must preserve the buffer lifetime. No crash reproduction or sanitizer run was done.

Scope: Message filtering memory and framing.
