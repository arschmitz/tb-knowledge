# Header emoji exceptions still remove joiners and selectors at specific positions

cleanToken permits U+200D and the text/emoji variation selectors through its first replacement ranges, then handles them separately. It replaces a joiner at a boundary or beside an ASCII space, removes leading or post-space selectors and keeps only the first selector in a consecutive run. These checks operate after earlier normalization, so the spaces need not all have been inserted by that step. The parser tests cover specific emoji and whitespace examples; this is not a blanket invisible-character allowance or proof against every spoofing case. No parser or security test ran.

Scope: JSMime header token normalization.
