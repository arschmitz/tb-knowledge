# Normalize Unicode names at insertion and lookup boundaries

Entry 1502 adds canonical composition normalization before inserting roots/children and comparing paths. Current insert and child lookup still normalize; DatabaseUtils now delegates to nfc_normalize. The test uses composed and decomposed representations of the same root name to retrieve the same ID. Proposed rule in this database family: normalize identity names at public boundaries, and state when an internal helper requires normalized input. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: Panorama Unicode identity.
