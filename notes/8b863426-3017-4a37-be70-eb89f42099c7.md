# Update Thunderbird Clang toolchain jobs and reference jobs together

The Clang 18 port changed the linux64 and win64 repack job names, Treeherder symbols, raw compiler fetches, and compiler-rt fetches in clang.yml. It also changed the matching imported reference-jobs in kind.yml. The current Clang 22 configuration keeps the same two-file relationship. When bumping a compiler version, update the repack job and all platform runtime dependencies with its referenced upstream jobs; verify the resolved task graph across Linux, Windows, macOS, and WASI.
