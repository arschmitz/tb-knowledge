# Graph batch construction can omit failed operations before typed response filtering

BatchRequest assigns IDs from input position, then filter_map omits operations whose build fails or whose request body is not UTF-8. Original request URLs use only path and JSON bodies must parse; the fixed module later preserves queries and skips empty bodies. The generic BatchResponse parses all item bodies before status filtering, so a deserialization error can fail the batch before unsuccessful items are removed. Typed responses are present in the owned source as requested in review; request payloads remain serialized strings. No external endpoint or failure result was exercised.

Scope: Graph batch serialization and error boundaries.
