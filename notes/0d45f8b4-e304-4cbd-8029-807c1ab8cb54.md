# Do not use the protocol allowlist as the JavaScript execution control

A treeherder failure led to the 2024 change that lets javascript: through ShouldBlockUnexposedProtocol. The commit and D210275 say JavaScript is disabled by other means. This helper is the unexposed remote-protocol filter inside nsMsgContentPolicy::ShouldLoad; returning false for javascript: here does not by itself enable script execution in mail. The function still blocks on errors and excludes most other unexposed protocols. D210275 notes a successful Try run and was accepted without a change request. Keep each security control tied to its actual layer when adjusting the scheme list.

Scope: Message content policy.
