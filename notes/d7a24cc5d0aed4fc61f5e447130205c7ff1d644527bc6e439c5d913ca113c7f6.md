# moz_http creates explicit cookie load information before constructing its channel

RequestBuilder creates a URI, obtains LoadInfo through a C ABI helper, then calls NewChannelFromURIWithLoadInfo. The helper checks the loading principal, builds LoadInfo, sets an eRegular cookie jar and propagates failures before returning the object. The Rust safety comment relies on failure instead of success with a null result. User-policy enforcement, actual cookie persistence and the later NTLM parts were not independently tested or proved by this bridge.

Scope: Rust HTTP request and C++ load-info bridge.
