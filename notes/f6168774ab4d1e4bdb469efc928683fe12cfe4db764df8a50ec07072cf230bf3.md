# Calendar iframe arguments are restored on the requested document

The tab producer first stores [aArgs] on the iframe window. Panel setup saves those arguments, or the dialog window's argument list, before setting src. A capturing DOMContentLoaded handler ignores about:blank, restores args and timezone state on the loaded iframe window, then removes itself with the same capture option. The owned sizing callback posts a timeout; accepted localization waiting is later. These exact ownership and ordering steps do not prove a dialog/focus result.

Scope: Calendar editing iframe argument ownership.
