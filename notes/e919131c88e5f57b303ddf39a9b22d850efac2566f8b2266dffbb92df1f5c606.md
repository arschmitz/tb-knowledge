# Preserve the legacy socket value in the migration after removing its enum

nsMsgSocketType no longer defines trySTARTTLS. MailMigrator still recognizes persisted numeric value 1 for profiles below UI version 44 and upgrades incoming accounts and outgoing servers to alwaysSTARTTLS. The other socket values remain 0, 2 and 3. Do not renumber the surviving values or replace the legacy literal with an enum member that no longer exists. New profiles skip old migrations. This is a persisted-data boundary, not a preference for unexplained numbers in normal code.

Scope: mailnews/base/public.
