# The Account Hub header test compares rounded vertical button-container positions

The header gains display:flow-root beside its relative positioning, while its controls remain an absolute container. The regression test compares the rounded top of that container after branding is shown, then after the subheader is also shown. Its visibility methods only unhide those elements. This directly specifies stable rounded vertical position in those two states; it does not measure horizontal bounds, subpixel motion, focus or accessible output.

Scope: Account Hub header content/layout regression test.
