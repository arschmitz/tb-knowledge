# Calendar bulk button IDs and label associations match the actual helper

The calendar wizard keeps dashed DOM IDs selectcalendars-all and selectcalendars-none, row classes calendar-selected/calendar-name, and the JavaScript helper adjustCheckboxesForAllCalendars(checked). The old naming note incorrectly called that helper setCalendarsSelected. Each calendar label’s control property names the generated checkbox ID; button labels come from the loaded calendar-creation Fluent resource. These linked static identities are checked in their actual consumers. This source correction does not turn one naming family into a global convention, certify focus order or imply a design-review endorsement. The full review’s separate keyboard-navigation and visual-balance concern remains explicit in the audit. No live accessibility test ran.

Scope: Calendar wizard naming and control semantics.
