# The fake IMAP IDLE extension supports explicit notification-count tests

The new fake-server extension exposes live mailbox connections and IDLE state, accepts DONE and sends unsolicited responses through the shared reader sender. IMAPServer resolves the requested RFC2177 option to that exact extension. The added test directly checks IDLE delivery, flag-sync deferral and a NOOP without a fresh unseen count; its shared manifest is included by the cpp-tagged mbox and maildir variants. This is bounded test infrastructure and assertion coverage, not complete protocol compliance or a claim that the tests ran.

Scope: IMAP fake-server unsolicited responses and regression coverage.
