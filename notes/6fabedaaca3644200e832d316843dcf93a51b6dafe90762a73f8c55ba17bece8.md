# Reset telemetry and assert the exact event count and extras

The OAuth utility tells tests to reset FOG before a scenario, checks event count, and compares each extra object. An empty expected event list checks the null result. Proposed testing pattern for these flows: verify absence as well as exact success/failure extras, so cached-token reuse is not accidentally counted as a new prompt. This tests the event contract, not the timing accuracy or production sampling. Static source and test-code inspection only. Full Bugzilla and Phabricator timeline and inline discussion remains pending. No runtime or live accessibility result is claimed.

Scope: OAuth telemetry tests.
