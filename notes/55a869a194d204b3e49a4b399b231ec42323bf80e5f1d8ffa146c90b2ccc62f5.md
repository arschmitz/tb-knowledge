# Graph queue completion follows the result channel, not enqueue completion

The operation owns the built HTTP request and request options. Enqueueing only submits it; send_raw_request_with_queue then awaits the one-shot result populated by perform. The original starts five arbitrary runners, while the later accepted source starts four. Keep those phases separate. Queue shutdown closes intake before sender shutdown; the separately inspected queue stop implementation closes its channel and clears runner references, so awaiting stop is not evidence that requests have drained. No concurrency or shutdown run was performed.

Scope: Graph request ownership and completion.
