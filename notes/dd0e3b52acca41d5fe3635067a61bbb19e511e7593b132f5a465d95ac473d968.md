# Yahoo's callback host registration and path check precede the active-state lookup

This landing adds the oauth host category for Yahoo's /yahoo callback alongside oauth2/callback. The normal content-handler caller checks net.thunderbird protocol and resolves the exact host category; the OAuth observer then rejects a wrong path for those known hosts and dispatches by active authorization state. The observer condition alone is not a complete all-host URI whitelist. The request removes its state entry before finishing/forwarding the response. These are bounded routing/lifetime facts, not proof of OAuth security, native scheme registration or successful provider login.

Scope: OAuth Yahoo custom-scheme callback routing.
