# Folder insertion skips sibling rewrites when the effective sort order has room

insertFolder sorts siblings in reverse and tests the neighboring effective sortOrder before creating room. Inserting after can use target+1 when the next sibling is larger or absent. Inserting before can use target-1 only when target is positive and the previous sibling is smaller or absent. Otherwise existing +2 sibling shifts remain. The moved folder is still assigned userSortOrder, its rows updated and the pane refreshed. A new-folder caller also uses this helper in already ordered groups. Keep stored/effective values and UI ordering separate from physical folder moves or atomic persistence. No drag, row, persistence or test run occurred.

Scope: Three-pane manual folder ordering gaps.
