# The current remote-address-book adapter separates discovery results, prompt choice and password storage

getAddressBooksForAccount awaits CardDAV detection and resolves the found-book array after marking existing books. Its current call passes false for forcePrompt and a separate storePassword value, whose adapter default is false. The all-account path passes true for password storage only after obtaining stored account credentials; current Promise.allSettled filters fulfilled nonempty results and contains rejected account tasks. Those are later accepted contracts; the original extraction used Promise.all and simpler account gating. The view awaits the returned account list before storing it. The stale singular/AccountAddressBooks JSDoc does not define the actual array return type. No remote discovery, OAuth, credential store or UI operation ran.

Scope: Account Hub remote address-book discovery contract.
