# Keep IMAP preview progress separate from autosync progress

The small human comment correction describes an existing branch: IMAP preview sets its own message progress text and counters; autosync has separate progress reporting. Keep that boundary when adding progress messages, so a one-message operation is not mixed into an unrelated autosync sequence. The comment is explanatory source evidence, not a measured UI behavior or a new formatter rule. Static source and test inspection only. No runtime, build, lint or live accessibility check ran.
