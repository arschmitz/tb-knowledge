# Check the quick-filter spinner resource in the branch that receives an uplift

The quick-filter CSS directly depends on chrome://messenger/skin/icons/spinning.svg and uses hourglass.svg for reduced motion. Bug 1874419 reports an ESR 128 uplift failure and backout when spinning.svg was absent, followed by a request for an ESR-specific patch using the Gecko spinner. The missing resource and crash/test failure are historical reports, not independently reproduced results. Proposed validation for an uplift of this CSS: verify the literal chrome URL and its registration in the receiving branch, then run the focused quick-filter test and CSS parsing test there. Approval and a current accepted CSS reference do not establish that the older branch packages the same resource. Linked Bug 1905839 and later D221737 were not read as full discussions.

Scope: mail/themes/shared/mail.
