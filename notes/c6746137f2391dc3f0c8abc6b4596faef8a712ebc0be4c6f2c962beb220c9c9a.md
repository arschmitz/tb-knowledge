# Pair compaction profiler intervals around actual started work

The accepted compactor opens and closes a FolderCompactor profiler interval using the folder URI as text and the MAILNEWS category. The final interval end shares the started-timer guard. Historical OTHER category and unconditional end placement should not be copied into a new current marker. The URI identifies the folder; it does not prove message-level timing or concurrent interval matching. Static inspection supports this component scope. No runtime test was run for this lesson, and full Bugzilla and Phabricator discussion is still pending.

Scope: Folder compaction profiler markers.
