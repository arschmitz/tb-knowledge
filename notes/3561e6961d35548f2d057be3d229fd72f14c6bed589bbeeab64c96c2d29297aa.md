# Prune hidden or removed tree selection and repair the active descendant

Current TreeListboxMixin prunes selected DOM rows no longer contained by the widget. Collapsing a subtree removes hidden descendant selections and promotes a selected descendant focus to the visible parent, then updates selected/current classes and aria-activedescendant. Keep actual focus on the composite widget. The state owner is the DOM-row Set; public indices are rebuilt from visible rows. This extends the older reland identity lesson with accessibility state transitions. No accessible-tree or focus runtime was checked.

Scope: tree selection accessibility.
