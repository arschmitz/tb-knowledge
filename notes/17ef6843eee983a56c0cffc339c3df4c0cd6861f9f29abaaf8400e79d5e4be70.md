# Compose parameter commands must reach the registered command object

The editor controller implements getCommandStateWithParams and doCommandWithParams by calling the registered command object’s getCommandStateParams and doCommandParams with the command and params. The smile menu uses this route: goDoCommandParams stores the selected face in state_attribute, and nsSetSmiley reads it before insertHTML. Ordinary doCommand is a different path. Keep the adapter method names, receiver and parameter object aligned when replacing controller machinery. The added test focuses the editor and asserts the inserted face in a paragraph; it does not directly cover every parameter command, focus restoration or accessibility behavior. No browser test ran.

Scope: Compose editor controller parameter routing.
