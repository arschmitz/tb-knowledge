# OpenPGP code calls RNP directly after the CryptoAPI cleanup

Bug 1891241 removed GnuPGCryptoAPI, the CryptoAPI parent class, and the EnigmailCryptoAPI wrapper in three incremental patches. Key import and revocation, MIME verification, and other callers now use RNP methods directly; current keyRing retains that form. New OpenPGP code should extend the direct RNP path in its component instead of recreating the removed dispatch layer. The review accepted this cleanup; it does not imply every wrapper elsewhere is unnecessary.

Scope: OpenPGP architecture.
