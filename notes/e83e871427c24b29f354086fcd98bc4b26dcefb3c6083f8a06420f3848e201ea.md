# Address book event checks include order and full arguments

In test_addressBooks_mv3 at revision 5bc47cc15bfa2aa6abfd4d6f4eff817b9503ac81, checkEvents checks the total event count, then consumes events in order and checks each namespace, event name, argument count, and full argument values. This can detect extra events, wrong ordering, and payload errors that an event-presence check would miss. Use this local test pattern when extending address book event coverage.
