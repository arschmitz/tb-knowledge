# The CSS test uses lexer tokens to collect references, while unused properties stay informational

The landing replaces regular-expression extraction with InspectorCSSParser token handling in processCSSRules. It counts style()/var() custom-property references, records custom-property declarations and collects non-data URL values for the later resource checks. The test then applies property-name/source exceptions separately from CSS error allowances, and unreferenced properties only produce info output. This is scoped test bookkeeping, not a dependency-graph proof, CSS-engine correctness result or visual compatibility check; no test was run.

Scope: Thunderbird CSS parser test reference collection.
