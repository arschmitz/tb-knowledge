# Subscribe filtering matches every word-like token without lowercasing the names

The migrated and accepted adapter take word-like Intl.Segmenter tokens and require every token to occur in the normalized row name. The code does not lowercase either operand; the removed NNTP search did. Empty word-like token lists restore the hierarchy. Do not infer case-insensitive or full Unicode-normalized matching from the search label. Checkbox clone synchronization is a separate later correction already documented.

Scope: Subscribe adapter filtering.
