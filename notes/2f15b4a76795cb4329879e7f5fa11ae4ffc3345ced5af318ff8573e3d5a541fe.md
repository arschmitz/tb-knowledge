# Load EML compose state without requiring a database message header

OpenPGP compose loads the original MIME tree without first requiring a database message header. getMsgProperties skips its header lookup for file URIs and matching mailbox number-zero forms, then still consults the encrypted-URI service. Current mailbox glue uses number=0 when rewriting standalone file messages. Draft-status restoration is a separate MIME-header step: its presence Boolean can suppress automatic defaults even when there is no stored DB property. The owned lookup used gMessenger; fixed accepted code later uses the message service. Preserve these sources of state instead of treating a missing DB header as missing MIME or remembered encryption. No forward, warning-capture or crypto test was run. The complete retained own review is reconciled in this audit.

Scope: mail/OpenPGP/compose-state.
