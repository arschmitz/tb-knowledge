# Virtual-folder deletion task names do not identify the window that executes the command

The helper executes cmd_delete on its Window argument. The four changed callers pass msgc, created as a separate message window, including tasks named for the folder or message tab. The header argument supplies the folder-event wait and log text, not selection. The following display assertions check synchronization separately. Keep command routing, notification completion and visible-state assertions distinct; no keyboard delivery or intermittent cure was reproduced.

Scope: Virtual-folder deletion browser tests.
