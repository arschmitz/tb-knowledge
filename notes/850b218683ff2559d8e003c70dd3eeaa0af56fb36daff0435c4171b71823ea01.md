# The RNP sized-delete shim is selected only for compatibility sanitizer builds

At accepted revision0b93f0f7a926ed94c8a0646f18b6734ec7cc0f6d, the rnp build adds /comm/build/unix/stdc++compat-tb.cpp only when MOZ_STDCXX_COMPAT is true and MOZ_ASAN or MOZ_TSAN is true. The local sized operator delete overload ignores its size argument and calls the unsized global operator delete with the pointer. Keep this limited to that build branch and overload. The source does not establish sanitizer interception, emitted binary symbol versions, or runtime correctness.

Scope: Build / RNP sanitizer compatibility.
