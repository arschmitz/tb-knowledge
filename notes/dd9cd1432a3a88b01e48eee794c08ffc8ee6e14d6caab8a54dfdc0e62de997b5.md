# A MIME content-type fallback can make a later null branch unreachable

MimeSunAttachment_create_child assigns APPLICATION_OCTET_STREAM when mime_ct is missing before duplicating it into the child. The human cleanup removes the later conditional choice between duplicating mime_ct and duplicating an empty string. Keep the earlier fallback in the proof before removing the defensive-looking branch. Optional encoding still has its own separate check. This is an observed local dead-code simplification, not a claim that all child allocation errors are handled. Complete Bugzilla and historical Phabricator timeline/inline discussion remains pending.

Scope: mailnews / mime.
