# Thunderbird Calendar architecture, Redux, and transaction documentation

`CalTransactionManager.commit()` awaits `doTransaction()`, removes a failure from `undoStack`, and rethrows; it does not call `undoTransaction()` automatically. A cross-calendar move adds the destination before deleting the source. `pendingMoveCopies` tracks a partial destination copy, preserves an externally changed copy, and retains failed cleanup for retry. `NONE` suppresses scheduling messages; `AUTO` requests automatic handling. Save completion does not prove remote synchronization or recipient delivery. [Task 2]

Scope: calendar.
