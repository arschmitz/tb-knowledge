# Separate provider-derived OAuth defaults from current Exchange overrides

The 2024 series removes persisted issuer and scope defaults from account setup. Accepted OAuth2Module derives details from provider lookup unless the gated custom override is active. AccountConfig now has optional Exchange oauthSettings, and backend application limits those settings to ews or graph. Therefore the old removal must not be summarized as a universal ban on oauthSettings or custom OAuth configuration. The scoped old issuer/scope preference search supports only the named inspected files. This is static source evidence. No runtime, build or live accessibility validation was run. Full bug and review discussion remains pending.

Scope: Account OAuth configuration sources.
