# The EWS rollout kept its stored preference name as a shipping switch

The non-Daily rollout removes the channel branch but keeps the Rust build guard and the existing experimental.mail.ews.enabled key. D252526 explains why the experimental name was not simply changed: users might have stored a value, and retaining the switch allowed the feature to be hidden again if141shipping problems appeared. Migration or removal was future, not an implemented part of this patch. Fixed mailnews.js no longer contains the key; that absence does not identify the later rollout mechanism. This is an EWS rollout, not an SMTP password fix. No release or network test ran.

Scope: EWS rollout preference chronology.
