# Distinguish no Rust update, an incoming update and a failed bot task

check-upstream success means no vendoring is needed. Exit code 88 is a defined incoming-change signal: announce it and return false so the bot continues. Other subprocess errors are raised. notify logs the message and uses the production sheriff channel only in production; development calls the user path. Task routes notify on-defined and on-resolved, so a resolved failure can be visible too. The bug’s explanation that default Rust caused the failure was a hypothesis, not a proved root cause. No live notification or bot run was performed.

Scope: Rust automation state and observability.
