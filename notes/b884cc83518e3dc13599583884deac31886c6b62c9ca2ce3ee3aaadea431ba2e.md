# Hide the named shortcuts overlay during toolbar customization

D230711 initially questions hiding the shortcut overlay, then accepts a concrete open-close-customize reproduction showing it behind toolbar customization. The landing adds shortcuts-container to the named hidden set; current customizingUnifiedToolbar CSS retains it. A broader dialog selector is only discussed with concern about future toolbar dialogs and is not adopted. Preserve the exact state/container relation when changing this UI. This is source plus historical reported reproduction, not a newly executed overlay, keyboard or focus test.

Scope: Shortcut overlay customization state.
