# Load fake-server certificates by the named fixture role

ServerTestUtils imports the named key as PKCS#12 except for selfsigned, fetches the corresponding .cert, strips PEM whitespace and uses a separate trust setting for selfsigned. The fixture specs bind role names to subject alternative names such as DAV or IMAP/SMTP hosts. Keep file role, matching test host and trust setup together; a validity string alone does not prove the key/certificate pair or a live TLS handshake. These are fixed accepted source and test-code observations. Full Bugzilla and historical review timeline/inline discussion remain pending. No Thunderbird runtime, build, lint, live accessibility or crypto/TLS validation ran.
