# Use the folder system URI rather than a generic string encoder for tag folders

The 2024 special-character tag fix used ESCAPE_URL_PATH because encodeURIComponent and folder URL escaping differed. Newer accepted SmartMailboxUtils now records folder.URI when it finds or creates a tag folder, keyed by tag.key. Prefer that known URI in current code. Keep a special-character creation/deletion test so a display label, key and URL cannot produce duplicate folders. getTagFolderUriForKey returns Map.get(key). It returns undefined when the key has no mapping. Its JSDoc still says string, which does not guarantee a value at runtime. The getter reads the known URI map and does not create a folder. Correction to lesson 9c1c076e0acb03ba16414d994065bc02dc081f72c23c6f72f873a571b91270f0: replace the ambiguous phrase "unknown URI" with the exact missing-key result.
