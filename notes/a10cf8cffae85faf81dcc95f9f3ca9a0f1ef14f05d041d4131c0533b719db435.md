# Font-language selection keeps the stored string and fallback return roles distinct

The font-language bindings use type string. Advanced fonts read the stored value, use Services.locale.fontLanguageGroup when it is missing or empty, and return that fallback value; otherwise the sync hook returns undefined. General rebuilding and message browser sizing read the locale property directly. The hook return does not mean asynchronous font lists are populated, and the provider relationship to stored values is outside this comm source scope.

Scope: font-language-preference-fallback.
